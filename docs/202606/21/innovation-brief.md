### 1. Not Truly Multilingual: Script Consistency as a Missing Dimension in VLM Evaluation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17188v2
- 方法流程：
  - 基准构建：专家标注 1000 个实例，每个实例包含一个图像、三种脚本下的问题和选项、正确答案及推理解释；双轮质量审核确保语义等价与脚本正确性（PABAK≥0.970）。
  - 实验 1（脚本差距量化）：对每个实例进行三次隔离评估（每种脚本一次），使用脚本特定指令模板，计算每脚本准确率 Acc_s 和 SCR。
  - 实验 2（视觉增益测试）：比较有/无图像输入下的 Acc_s，检验视觉模态是否缩小脚本差异。
  - 实验 3（跨脚本上下文迁移）：提供一种脚本的上下文示例，测试模型在另一脚本上的推理性能，计算 Transfer Efficiency (TE)。
  - 统计验证：对所有脚本对进行 McNemar 检验，确认准确率差异的显著性。
- 关键模块/机制：
  - PuMVR 基准：提供严格平行的多脚本视觉推理测试集，隔离脚本变量。；包含 1000 个实例，每个实例有 Gurmukhi、Shahmukhi、Roman 三种脚本的完全语义等价文本；选项和正确答案一一对应；使用 375 实例评估集（预先分层采样），其余 625 保留用于未来工作。
  - Script Consistency Rate (SCR)：衡量模型在所有脚本上同时正确回答的比例。；SCR = (1/|I|) * Σ_i Π_{s∈S} 𝟙[Correct_s(i)]，其中 S = {Gurmukhi, Shahmukhi, Roman}；SCR 越低表明脚本一致性问题越严重。
  - 隔离评估协议：防止跨脚本冲突，确保每个评估独立。；每个实例在三种脚本下分别运行推理，使用不同的指令模板（如“用 Roman 旁遮普语回答”），模型输出必须匹配选项文本。
  - 统计显著性测试（McNemar）：验证脚本对之间的准确率差异是否统计显著。；对每对脚本（Gurmukhi vs Shahmukhi、Gurmukhi vs Roman、Shahmukhi vs Roman），使用 McNemar 检验比较两种条件下的一致/不一致计数。
- 公式/目标函数/指标定义：
  - Script Accuracy: Acc_s = (1/|I|) * Σ_i 𝟙[Pred_s(i) = GT_s(i)]
  - Script Consistency Rate: SCR = (1/|I|) * Σ_i Π_{s∈S} 𝟙[Correct_s(i)], S = {Gur, Shah, Rom}
  - McNemar 检验: χ² = (b - c)² / (b + c)，其中 b 为在脚本 x 正确、脚本 y 错误的实例数，c 为相反情况。
- 算法细节：
  - 推理时每个实例独立处理，模型接收图像、问题及四个选项（均为单一脚本），输出选择字符串。
  - 使用固定指令模板（附录 D）指定脚本语言，避免模型自动推断脚本。
  - 为每个模型统一设置温度=0 以最小化随机性。
  - 跨脚本上下文迁移实验：在提示中提供同一主题下的一个实例（图像+问题+答案）作为示例，示例脚本与问题脚本不同。
- 训练/推理细节：
  - 模型为预训练 VLM，无微调；直接使用官方提供的 checkpoint 和推理配置。
  - 所有模型在相同条件下推理：温度=0，最大输出 tokens=256，使用图像分辨率为模型原生尺寸。
  - 评估数据集使用保留的 375 实例子集，避免数据泄露。

### 2. Agentic AI-based Framework for Mitigating Premature Diagnostic Handoff and Silent Hallucination in Healthcare Applications
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18068v1
- 方法流程：
  - Phase 1: Structured History Taking - TriageNurse agent收集症状，Neuro-Symbolic OLDCARTS Gate维护状态向量V，阻止诊断转换直至ΣV_i=8。
  - Phase 2: Parallel Stochastic Diagnostic Sampling - K=5个Senior Diagnostician独立生成诊断（温度T=0.7），共5个样本。
  - Phase 3: Uncertainty Quantification - 对5个样本进行双向NLI聚类，计算语义熵H，若H>τ则拦截，否则输出。
  - Phase 4: Recursive Safety Supervision - 若拦截，递归最多3次修订（温度T=0.0），并调用check_drug_interaction工具。
- 关键模块/机制：
  - Neuro-Symbolic OLDCARTS State Tracker (M1)：确保结构化摄入完整性；维护8维布尔向量V（Onset, Location, Duration, Character, Aggravating/Alleviating, Radiation, Timing, Severity），每轮对话后TriageNurse提取并更新V；仅当ΣV_i=8时允许诊断过渡。
  - Semantic Entropy-based UQ Gate (M2)：识别并拦截高不确定性输出；采集K=5独立诊断样本（T=0.7），使用双向NLI将语义等价输出聚类，计算归一化Shannon熵H；若H>τ则拦截输出进入循环。
  - Recursive Safety Supervisor：提供修订和工具检查；当M2拦截时，将样本反馈给Senior Diagnostician（T=0.0）进行修订，最多3次；每次修订后重新通过M2；同时调用check_drug_interaction工具检查药物相互作用。
- 公式/目标函数/指标定义：
  - OLDCARTS完整性约束：Σ_{i=1}^8 V_i = 8
  - 语义熵H：基于NLI聚类后的归一化Shannon熵（引用[14]）
  - 诊断精度：正确诊断数 / 总测试案例数
  - 相关性：Pearson相关系数r = -0.181 (p<0.05) 在OLDCARTS完整性σ与语义熵H之间
- 算法细节：
  - 状态跟踪门：TriageNurse每轮后提取症状维度，更新V；门控条件为ΣV_i==8。
  - UQ门：对K=5个诊断输出应用双向NLI（一个输出是否蕴涵另一个），构建等价类，计算每个类概率，然后计算归一化熵H。
  - 递归监督：若H>τ，将5个样本及熵值送入Senior Diagnostician（T=0.0）要求修订，重复最多3次；通过后调用药物相互作用工具。
- 训练/推理细节：
  - 模型：llama-3.1-70b-instruct，通过Groq Cloud推理。
  - 推理温度：诊断采样T=0.7，修订T=0.0。
  - 采样数：K=5。
  - 系统使用AutoGen多智能体框架和Gradio Web界面。
  - 未涉及训练，仅在模拟患者（由同一模型驱动）上评估。

### 3. Moving Beyond Diversity: Visual Token Pruning as Subspace Reconstruction for Efficient VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18681v1
- 方法流程：
  - 输入：视觉嵌入矩阵 X_v ∈ R^{N×d} 和文本嵌入矩阵 X_t ∈ R^{M×d}
  - 步骤1：计算每个标记与当前已选子空间的投影残差（基于RRQR），选择残差最大的标记加入子集
  - 步骤2：可选地计算图像-文本相关性分数（如CLIP得分），将反相关信号（低分标记的优先级）融入选择准则（例如加性权重）
  - 步骤3：重复步骤1-2直至选出k个标记，得到子集S对应的嵌入 ˜X_v
  - 输出：剪枝后的视觉标记序列 ˜X_v，送入LLM进行多模态推理
- 关键模块/机制：
  - 子空间重构选择器：基于RRQR的贪婪列选择，最小化重构误差；将视觉特征矩阵转置后的列子集选择问题，利用秩揭示QR分解迭代选择投影残差最大的列（标记），保持子空间结构。
  - 反相关指导模块：利用低图像-文本相关性标记保留更多上下文信息；计算每个标记与文本的CLIP相关性分数，反相关分数（如1-相关性）作为额外权重加入选择准则，促使选择低相关但信息丰富的标记。
- 公式/目标函数/指标定义：
  - 理想目标：min_{S, |S|=k} L(F(˜X_v, X_t), F(X_v, X_t))，其中F为LLM输出分布
  - 可解近似目标：min_{S, |S|=k} ||X_v^T - Π_S X_v^T||_F^2，Π_S为选列张成的投影矩阵
  - CSSP目标：min_{S, |S|=k} ||X_v^T - Π_S X_v^T||_F^2
- 算法细节：
  - 将X_v^T视为矩阵，每次选择当前残差最大的列：r = X_v^T - Π_S X_v^T，选择argmax||r_i||_2
  - 基于RRQR的贪婪算法：通过Householder变换或基于QR的实现，逐步选取具有大范数的枢轴列
  - 融入反相关：引入权重w_i = 1 - rel_i（rel_i为归一化相关性），在残差基础上乘以w_i或加性耦合，调整选择顺序
- 训练/推理细节：
  - 完全训练无关（training-free），剪枝过程不需要任何微调或梯度计算
  - 即插即用（plug-and-play），可直接应用于预训练VLM的推理阶段
  - 剪枝在LLM输入前进行，不修改LLM参数

### 4. Benchmarking Large Vision-Language Models on Fine-Grained Image Tasks: From Evaluation to Diagnosis
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19053v1
- 方法流程：
  - 数据构建：收集0.28M图像，涵盖通用物体中心域和专业域（如遥感、医学等），设计1.01M问题，包括层次识别、属性识别、知识偏差、图像检索、图像分类
  - 人类导向评估：对LVLM输入图像和对话式问题（如'该物体属？'），评估其输出文本的细粒度语义识别准确性
  - 机器导向评估：提取LVLM的视觉特征（如CLIP或LLaVA的视觉编码器），计算特征间的相似度用于检索任务（如检索相似细粒度类别图像），评估特征的可判别性
  - 诊断分析：对比对话级准确率和特征级判别性指标，分类失败模式（视觉表示不足/语义对齐弱/知识有限）
  - 训练因素分析：改变训练目标（对比/生成/重构）、编码器规模、数据规模、SFT数据组成，观察细粒度指标变化
  - 鲁棒性测试：对输入图像添加特征扰动（如高斯噪声、颜色变换）或语言扰动（如误导性类别提示），评估输出变化
- 关键模块/机制：
  - FG-BMK数据集构建：提供细粒度评估的多样化图像和问题；从现有细粒度数据集（如CUB-200-2011、NABirds、Food-101等）和网络收集图像，覆盖鸟类、飞机、汽车、花卉、遥感等域。问题设计包括：层次粒度识别（属、科、种），属性识别（颜色、形状、纹理），知识偏差（预测图像类别但给出错误类别选项测试知识偏见），以及机器导向的检索和分类任务。
  - 人类导向评估（对话级语义识别）：测试LVLM在对话形式下的细粒度语义理解；对每张图像，构造多个对话问题（例如'这是什么鸟？'、'它的眼睛颜色？'），不提供分类选项（开放生成）或提供多个选项（多项选择），评估模型回答与真实标签的匹配度，使用准确率或F1。
  - 机器导向评估（特征级视觉判别性）：直接测量LVLM视觉特征对细粒度差异的编码能力；取LVLM的视觉编码器输出特征（或视觉-语言投影后的视觉特征），对图像特征进行全图检索：给定查询图像，在数据库中检索最相似图像，计算召回率（Recall@1/5/10）；同时训练线性分类器（固定冻结视觉特征）进行图像识别，计算分类准确率。
  - 诊断分析框架：将失败归因于视觉表示、语义对齐或知识不足；对比人类导向准确率和机器导向指标：如果机器导向差但人类导向好，说明视觉特征判别性差但语义对齐弥补；如果两者都差，可能视觉表示不足；如果机器导向好但人类导向差，说明语义对齐或知识缺失。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 图像检索评估：使用LVLM视觉编码器提取特征（如InternViT、CLIP ViT），L2归一化后计算余弦相似度，对于查询图像q，从数据库D中检索Top-K个最相似图像，计算Recall@K = (#正确检索相关图像数)/#查询总数
  - 线性分类评估：冻结视觉特征，使用逻辑回归（或SVM）训练分类器，准确率为正确分类样本数/总样本数
  - 诊断规则：设H为人类导向准确率，M为机器导向准确率，定义：若H高M低 => 视觉判别性不足但语义对齐好；若H低M高 => 语义对齐弱或知识不足；若都低 => 视觉表示不足
- 训练/推理细节：
  - 训练因素分析：使用不同训练目标（对比目标如CLIP、生成目标如LLaVA、重构目标如BEiT-3）训练视觉编码器，比较细粒度特征判别性
  - 编码器规模影响：比较ViT-B/16、ViT-L/14、ViT-g/14等不同规模编码器在细粒度任务上的表现
  - 数据规模影响：使用不同数量的图像-文本对（从10M到400M）预训练，观察细粒度指标变化
  - SFT数据组成：混合细粒度指令数据（如属性问答）与通用指令数据，平衡后微调，评估细粒度能力保持

### 5. LaViSA: A Language and Vision Structural Ambiguity Benchmark
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19552v1
- 方法流程：
  - 1. 种子数据筛选：从TAB中选取五个原始类别（VP, PP, Anaph, Ellip, Adj/Vb/Conj合并类）的歧义句子，根据结构歧义的可视化可能性过滤有害内容和人名。
  - 2. 类别扩展：将合并类拆分为Adj、Vb、Conj三个独立类别，保留并用GPT-4o生成每个类别100个歧义句子（共700句），每个歧义句子配2-3个消歧句子（共1503个消歧句子）。
  - 3. 图像生成：使用DALL-E 3根据消歧句子生成对应图像，通过统一提示模板（如'一张描述[消歧句子]的图片'）控制风格。
  - 4. 人工验证：对生成图像进行二分类（是否准确反映消歧句子），总体准确率92.9%，保留通过样本。
  - 5. 评估任务：给定歧义句子、图像和一组消歧句子（2-3个），VLM选择与图像匹配的消歧句子。
- 关键模块/机制：
  - 种子数据预处理与筛选：从TAB中提取高质量种子歧义句子，过滤不可视化或带敏感内容的样本。；根据七类歧义定义，保留TAB中结构歧义清晰且可视觉化的句子；移除包含有害内容或个人名称的样本；将原文合并的Adj/Vb/Conj类拆分为独立类别。
  - 句子生成与扩展：利用GPT-4o生成更多歧义句子及其消歧句子，确保每个类别均匀分布。；将种子数据作为输入给GPT-4o，输出相同格式的歧义句子和消歧句子（每歧义句2-3个），通过提示要求保持语义清晰、结构歧义明确。人工检查去重和格式一致性。
  - 控制图像生成：为每个消歧句子生成对应的可视化图像，实现视觉歧义的解耦。；使用DALL-E 3，输入提示为'一张描述[消歧句子]的图片'，保持图像风格统一（无额外修饰）。每句只生成一张图像，仅作为消歧句子的视觉锚点。
  - 人工验证：确保生成的图像正确反映消歧句子的语义。；请三名标注者对每张图像判断是否准确匹配消歧句子，计算准确率。最终平均准确率92.9%，通过样本纳入基准。
  - 多选评估框架：标准化评估视觉语言模型的视觉消歧能力。；将同一歧义句子的多个消歧句子作为选项，图像为条件输入，VLM需输出最匹配的选项。使用准确率作为评估指标，避免生成文本的度量偏差。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 评估时，将歧义句子、图像和消歧句子列表拼接成提示，要求VLM输出对应选项的序号。
- 训练/推理细节：
  - 无训练过程，基准仅用于评估。推理时使用zero-shot多选提示，不提供示例。

### 6. ARTEMIS: Agent-guided Reliability-aware Temporal Mask Evolution for Imperfectly Supervised Video Polyp Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20161v1
- 方法流程：
  - Stage 1: 掩码初始化与演化。对弱监督，使用SAM2将点/涂鸦转换为粗掩码；对半监督，将密集标签作为可靠锚点。然后，辩论-判断智能体从弱监督中选出可靠时间锚点，并使用SAM2双向传播这些锚点，细化不可靠或未标注帧，得到演化后的伪掩码。
  - Stage 2: 分割器训练。使用可靠性引导参考选择从伪掩码中挑选可靠帧作为参考，通过RPTM在时间上传递目标身份，并采用可靠性感知鲁棒损失加权训练，抑制噪声监督。
- 关键模块/机制：
  - 辩论-判断视觉语言智能体：在弱监督下选择可靠时间锚点；采用多智能体辩论机制，多个语言模型对候选伪掩码的可靠性进行论证和反驳，最后通过判断智能体综合决定哪些帧的掩码可作为可靠锚点用于后续传播。
  - SAM2双向传播：从可靠锚点细化不可靠或未标注帧的伪掩码；以可靠锚点为起始帧，沿时间正反两个方向使用SAM2的掩码传播功能，逐步生成中间帧的密集掩码，从而填充不完整或不可靠的标注。
  - 可靠性引导参考选择：从演化后的伪掩码中挑选高质量帧作为参考；计算每帧伪掩码的可靠性指标（如与前后帧的一致性、置信度等），选择可靠性高的帧作为参考，用于后续模块。

- 原文链接：https://arxiv.org/abs/2606.15099v1
- 方法流程：
  - 阶段1: 多模态编码 - 输入视觉vt、语言lt、历史ht−1，通过编码器ψ得到统一特征˜ot = ψ(ot)
  - 阶段2: 隐推理与RL去噪循环 - 推理策略πϕ根据当前隐状态zt和˜ot生成推理更新动作ut，状态转移函数fθ更新zt到zt+1，同时早退门控gω评估置信度，若超过阈值τ则退出循环
  - 阶段3: 动作生成 - 最终隐状态zfinal与编码观测˜ot拼接，通过动作策略πψ生成动作at
- 关键模块/机制：
  - 推理策略 πϕ：生成隐状态更新动作ut，控制隐状态演化模式；参数化为对角高斯分布 πϕ(ut|zt, ot) = N(ut; μϕ(zt, ˜ot), diag(σϕ^2(zt, ˜ot)))，ut ∈ R^64连续，提供平滑梯度
  - 隐状态转移函数 fθ：根据当前隐状态、观测和更新动作计算下一隐状态；采用增量形式：zt+1 = zt + gθ(zt, ˜ot, ut)，其中gθ可基于Transformer或RNN，并通过α(ut)门控调节更新幅度，如Δzt = α(ut) ⊙ Transformer_θ(zt, ˜ot)
  - 动作策略 πψ：基于隐状态和观测生成环境动作；条件概率分布：πψ(at|zt, ot) = Softmax(hψ([zt, ψ(ot)]))，将隐状态作为决策中心
  - RL去噪奖励函数：约束隐状态稳定性和任务对齐；即时奖励 rt = r_task(at) - λ1 H(πϕ(·|zt, ot)) - λ2 ||zt+1 - zt||^2，结合任务奖励、熵正则和平滑正则
  - 早退门控 gω：根据当前隐状态置信度决定是否终止推理；输出置信度分数，当分数超过阈值τ时触发退出，实现自适应推理深度
- 公式/目标函数/指标定义：
  - 观测定义: ot = {vt, lt, ht−1}
  - 隐状态转移: zt+1 ∼ P(zt+1 | zt, ut, ot)，由fθ参数化近似
  - 推理策略: ut ∼ πϕ(ut | zt, ot) = N(ut; μϕ(zt, ˜ot), diag(σϕ^2(zt, ˜ot)))
  - 增量状态更新: ˜ot = ψ(ot), Δzt = gθ(zt, ˜ot, ut), zt+1 = zt + Δzt
  - 门控更新示例: Δzt = α(ut) ⊙ Transformer_θ(zt, ˜ot)
  - 动作策略: at ∼ πψ(at | zt, ot) = Softmax(hψ([zt, ψ(ot)]))
- 算法细节：
  - 采用Actor-Critic方法（PPO）优化推理策略πϕ，定义状态值函数Vπ(zt)估计累积回报
  - 推理更新动作ut为连续向量，通过门控系数α(ut)控制隐状态更新幅度，实现细粒度调节
  - 早退策略通过门控网络gω输出置信度，推理循环在每个时间步检查是否退出，避免固定深度
- 训练/推理细节：
  - 训练：联合优化推理策略πϕ、状态转移fθ、动作策略πψ和早退门控gω，使用PPO算法累积任务奖励
  - 推理：多模态观测经编码后进入隐推理循环，推理策略生成ut，状态转移更新隐状态，早退门控依据置信度决定是否提前退出，最终隐状态用于动作生成
  - 超参数：视觉/语言嵌入维度768，推理/动作网络隐藏层1024/2048，dropout 0.1

### 14. MNet++: Extended 2D/3D Networks for Anisotropic Medical Image Segmentation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.15370v1
- 方法流程：
  - 阶段1 - 数据预处理：使用nnU-Net v1 pipeline进行重采样、强度归一化、裁剪和随机增强（旋转、缩放、弹性形变），生成固定大小的补丁
  - 阶段2 - 并行编码：输入体积分别经过2D编码器和3D编码器，每个编码器包含5个阶段，提取多尺度特征
  - 阶段3 - 融合门控：在编码器下采样后和解码器上采样前，融合门控模块（通道门或空间门）根据学习到的门控值g对2D和3D特征进行加权插值：y = g ⊙ x2D + (1-g) ⊙ x3D
  - 阶段4 - VMamba瓶颈：在编码器第3-5阶段插入CBzMamba块，对3D路径沿深度维度进行状态空间扫描，增强全局深度建模
  - 阶段5 - 解码与深度监督：2D和3D解码器通过对称跳跃连接恢复空间分辨率，并在多个深度层附加辅助输出分支（1x1x1卷积），计算加权混合损失
  - 阶段6 - 损失计算：总损失由主输出和辅助输出的Dice与交叉熵损失加权求和（权重λ_i = (1/2)^{5-i}）
  - 输出：分割预测（与输入同分辨率的体素级标签）
- 关键模块/机制：
  - MNet混合编码器-解码器：从2D切片和3D体积两个视角提取并融合多尺度特征，适应各向异性；两个并行编码器（2D和3D）各有5个阶段，通过对称跳跃连接连接至对应解码器，每个卷积块后接批归一化和ReLU激活。
  - 融合门控模块（Fusion Gating）：替代原始MNet中固定的算术融合（加、减、拼接），实现数据自适应的2D/3D特征混合；对2D和3D特征张量x2D, x3D ∈ R^{N×C×D×H×W}，学习门控张量g ∈ [0,1]^{N×C×D×H×W}，通过逐元素乘法融合：y = g⊙x2D + (1-g)⊙x3D。有两种模式：通道门（每个通道一个全局标量）和空间门（每个空间位置共享通道）。门控由1×1×1卷积和sigmoid生成。
  - VMamba块（CBzMamba）：在3D编码器瓶颈层沿z轴进行高效状态空间扫描，捕获切片间长程依赖；输入先经1×1×1卷积降维（因子r=0.5），然后reshape为(N·H·W, D, C)，对每个空间位置独立进行选择性状态空间扫描（ZScan），再升维还原。操作复杂度O(D·H·W)，并行处理所有空间位置。
  - 深度监督分支：在多个解码深度提供辅助损失，加速浅层训练并改善梯度流动；通过1×1×1卷积从解码器阶段i和j输出Xij，生成与相应下采样真值Yij对齐的预测。损失加权λ_i = (1/2)^{5-i}，适用i=2,3,4。
- 公式/目标函数/指标定义：
  - 融合门控：y = g ⊙ x2D + (1 - g) ⊙ x3D，其中g ∈ [0,1]为学习到的门控
  - 总损失：L = L(X55, Y55) + Σ_{i=2}^{4} λ_i [L(X5i, Y5i) + L(Xi5, Yi5)]，其中λ_i = (1/2)^{5-i}，L为Dice与交叉熵的混合损失
  - Dice相似系数：DSC = 2|X ∩ Y| / (|X| + |Y|)
- 算法细节：
  - 融合门控：通道门通过全局平均池化获取通道描述符，后接两层1×1×1卷积（C→C/r→C）和sigmoid生成C维向量，再广播至所有空间位置；空间门直接通过单个1×1×1卷积和sigmoid生成H×W×D维门控（通道共享）。
  - VMamba扫描：将3D特征从(N, C, D, H, W)重塑为(N·H·W, D, C)，对每个空间位置沿深度序列进行本文定义的fSSM（选择性状态空间模型），再重塑回原始形状。
  - 深度监督：在解码器阶段i和j（i=2,3,4,5; j=2,3,4,5），通过1×1×1卷积输出预测，并上采样至与相应真值一致的大小。
- 训练/推理细节：
  - 优化器：基线MNet使用Adam（lr=1e-4，余弦退火调度）；扩展实验和部分复现使用SGD（lr=1e-2，动量0.99，多项式衰减）
  - 混合精度训练（AMP）已启用，减少GPU内存消耗
  - 训练轮数：基线150轮，消融和各向异性实验50轮
  - 批量大小和补丁大小由nnU-Net自动配置，确保2D和3D分支GPU利用率一致
  - 5折交叉验证（报道3折的平均值±标准差），消融和各向异性实验使用单次80/20数据划分

  - 预测门控融合（PGF）：解码阶段融合跳跃连接特征，引入可学习区域-边界权重增强边缘感知；在解码器上采样阶段，利用可学习的门控权重融合编码器跳跃连接特征与解码器特征，增强边界感知。对双类任务，通过sigmoid/softmax处理通道后取最大概率作为区域显著图，实现多类兼容。
  - 组混洗注意力（GSA）：通过高效的通道分组和混洗操作减少参数，提高结构泛化能力；在解码器层中对特征通道进行分组和混洗，然后施加注意力机制，以较低计算成本实现特征重标定。
  - 区域-边界联合深度监督：同时监督分割区域和边界，增强对低对比度超声病灶轮廓的敏感性；总损失Ltotal = Lregion + Lboundary + Lgt。Lgt为最终分割的BceDiceLoss；Lboundary对解码器3个层级（权重0.1,0.2,0.3）的边界预测进行深度监督；Lregion对4个层级（权重0.1,0.2,0.3,0.4）的区域预测进行深度监督。边界标签从真实掩码通过Canny算子提取。无需额外参数。
- 公式/目标函数/指标定义：
  - 总损失函数：L_total = L_region + L_boundary + L_gt
  - L_gt：最终分割的BceDiceLoss
  - L_boundary：边界深度监督损失，解码器第2、3、4层权重分别为0.1, 0.2, 0.3
  - L_region：区域深度监督损失，解码器第1、2、3、4层权重分别为0.1, 0.2, 0.3, 0.4
  - 感受野计算公式：RF = 1 + 2(k-1)d，其中k=3为卷积核大小，d为扩张率
  - 原始配置扩张率[1,2,3]对应感受野3×3,5×5,7×7；新配置[2,4,6]对应5×5,9×9,13×13像素
- 算法细节：
  - EDB模块：两个级联，每组包含多个并行扩张卷积分支（3×3，扩张率[2,4,6]），使用组卷积保持参数不变
  - AGF：在跳跃连接中通过空间注意力生成加权掩码，自适应融合编码器浅层特征与深层特征
  - SSA：在瓶颈层对特征图进行通道维度竞争，通过压缩-激活机制重标定通道重要性
  - PGF：解码器上采样时，利用可学习门控权重gating融合跳跃连接特征，对双类任务先softmax取最大前景概率作为区域显著性图
  - GSA：在解码器层对特征通道进行分组和混洗，然后施加注意力
  - 层次非对称深度监督（双类任务）：深层解码器（5,4）输出3通道logits（背景+双类），浅层解码器（3,2）输出2通道logits（前景/背景），仅做二分类
  - 多类自适应PGF：单通道输入用sigmoid，多通道输入先softmax再取最大前景概率，确保与跳跃连接特征的广播兼容
  - 统一边界监督：所有前景ROI共享单通道边界预测头，边界标签通过Canny算子从融合前景掩码提取
- 训练/推理细节：
  - 训练：PyTorch框架，两卡NVIDIA 5090 GPU，三次独立随机种子重复
  - 优化器：Adam，学习率分层策略：参数量<5M使用1e-3，>5M使用3e-4
  - 输入尺寸：256×256，批量大小4，2个数据加载线程
  - 数据增强：随机旋转、缩放、弹性变形
  - 早停：验证集Dice连续10个epoch无提升则停止，最大100个epoch
  - 推理：UltraSeg-130K在单核CPU上89.7 FPS，翻新移动设备34.8 FPS；UltraSeg-500K对应44.6 FPS和16.1 FPS

### 18. Visual-Seeker: Towards Visual-Native Multimodal Agentic Search via Active Visual Reasoning
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.15231v1
- 方法流程：
  - 细粒度种子实体选择：从LiveVQA数据集中提取多实体图像、问题和推理过程，使用MLLM识别实体（名称、描述、类型），经过泛化提及过滤、复杂实体-图像过滤和实体消歧，得到2K种子实体。
  - 多跳轨迹合成：基于Wikipedia知识图从种子实体节点开始随机游走，采用回退和循环约束两种策略扩展子图拓扑，生成多样搜索轨迹。
  - 视觉证据注入：通过搜索引擎检索图像并提取视觉细节，将视觉证据插入搜索轨迹中的查询，迫使模型进行视觉搜索和推理。
- 关键模块/机制：
  - 细粒度种子实体选择：从复杂多实体图像中提取高质量种子实体，激活模型的细粒度视觉感知；使用MLLM从LiveVQA图像的推理过程中提取实体，表示为(name, description, type)三元组，然后经过泛化提及过滤、复杂实体-图像过滤和实体消歧三步过滤，确保实体唯一可识别。
  - 多跳轨迹合成（双策略随机游走）：生成多样化的多跳搜索轨迹，训练模型进行多跳推理和工具调用；从种子实体节点出发，在Wikipedia知识图上进行随机游走。引入回退策略（以p_back概率退回上一节点）和循环约束（避免重复节点导致循环）来扩展子图拓扑，产生树状和循环状轨迹。
  - 视觉证据注入：在搜索轨迹中强制进行视觉搜索和推理，训练模型主动收集视觉证据；针对轨迹中的每个实体节点，生成搜索关键词并利用搜索引擎检索相关图像，然后使用MLLM提取图像中的视觉细节，将视觉细节和图像一起注入到后续的VQA问题中，使模型必须搜索图像才能回答。
- 公式/目标函数/指标定义：
  - 实体表示: E_i = (n_i, d_i, type_i)，其中n_i是实体名称，d_i是视觉描述，type_i是类别
  - 回退概率: p_back ∈ (0,1)，在随机游走中以概率p_back回退到上一节点
  - 数据规模: 合成5K高质量多模态搜索轨迹用于训练
- 算法细节：
  - 实体识别使用MLLM进行上下文学习，从图像、问题和推理过程中提取实体
  - 实体过滤包括基于规则和MLLM验证的泛化提及过滤、MLLM判断的复杂实体-图像过滤、以及基于Wikipedia消歧页面的实体消歧
  - 多跳轨迹合成：在Wikipedia知识图上进行带回退和循环约束的随机游走，生成树状和循环状子图
  - 视觉证据注入：为每个实体节点生成搜索关键词，通过搜索引擎检索图像，使用MLLM提取视觉细节，然后将视觉细节和图像注入到VQA问题中
- 训练/推理细节：
  - 使用Active Visual Reasoning数据管道合成的5K高质量多模态搜索轨迹作为训练数据
  - 训练目标：微调MLLM使其具备主动视觉推理和搜索能力
  - 推理时，模型接收用户查询（图像+问题），然后自主执行多步搜索，包括调用工具（如截图、裁剪、图像搜索、网页浏览等），并动态收集视觉证据

### 19. From Frames to Temporal Graphs: In-Context Egocentric Action Recognition with Vision-Language Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.15417v1
- 方法流程：
  - 帧采样：从视频片段中均匀采样16帧。
  - 窗口化：将帧分组为短时间窗口（默认4帧/窗口，滑动步长1，重叠）。
  - 第一阶段生成叙述：对每个窗口，使用VLM生成密集自然语言描述，描述手-物体交互（如'手在拿杯子'）。
  - 第二阶段形式化图：将叙述转换为结构化图三元组，格式为 (手, 动词, 物体)，并添加节点属性（如手的位置、物体的类别）。
  - 图构建：聚合所有窗口的图三元组，按照时间顺序排列，得到Temporal Action Graph Gτ。
  - 序列化：将图Gτ序列化为文本字符串，包含节点和边信息。
  - 输入VLM：将序列化图（或帧）与动作候选集、提示模板一起输入VLM。
  - 上下文学习（可选）：在提示前添加来自训练集的标注图示例（每个类1或2个示例）。
- 关键模块/机制：
  - 多阶段提示流水线 (Multi-stage Prompting Pipeline)：将原始帧转换为结构化图表示；第一阶段：在短时间窗口（4帧）上，使用VLM生成密集自然语言叙述，描述手-物体交互。第二阶段：将叙述形式化为开放词汇图三元组 (手, 动词, 物体)，并提取节点属性（如手的状态、物体类别）。两个阶段均使用固定提示模板。
  - 时间动作图构建 (Temporal Action Graph Construction)：整合窗口级图三元组为全局图；从每个窗口的图三元组中，按照时间顺序连接成图Gτ。节点包括手和物体，边表示交互动作。使用滑动窗口（重叠）确保时间连续性，并添加节点属性（如手的位置、物体名称）。最终图以序列化文本形式表示。
  - 上下文学习（ICL）模块：利用标注示例提升预测；从训练集中构建类平衡的图示例池（EGTEA每类1-2个，Epic-Kitchens-100从最频繁的50或100类中各取1-2个）。在测试时，将标注的图示例序列化后拼接到输入提示前，模型根据示例模式进行预测。
- 算法细节：
  - 帧采样：每个视频剪辑均匀采样16帧。
  - 窗口化：使用4帧窗口，步长为1，生成多个重叠窗口。
  - 多阶段提示：每个窗口依次执行第一阶段（生成叙述）和第二阶段（生成图三元组），使用VLM的贪婪解码（温度0）。
  - 图序列化：将图Gτ转换为文本字符串，格式如 '(手, 动作, 物体) [属性] ; (手, 动作, 物体) ...'。
  - ICL示例检索：从预构建的类平衡池中随机抽取每个类指定数量的图示例，序列化后添加到提示开头。
  - 输出解析：VLM输出严格遵循JSON模式，返回top-5预测及其置信度。
- 训练/推理细节：
  - 所有实验使用vLLM框架，在至多4块NVIDIA L40S GPU上运行。
  - 推理时采用贪婪解码（温度0），禁用推理模式。
  - 每个输入使用相同数量的帧（16帧）和相同的候选集。
  - 对于大型模型（>100B），使用量化以适应GPU内存。
  - ICL示例池基于训练集一次构建，固定种子，跨模型共享。

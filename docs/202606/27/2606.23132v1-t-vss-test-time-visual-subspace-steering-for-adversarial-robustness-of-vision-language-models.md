## 摘要
视觉语言模型（VLM）在零样本识别中表现强劲，但仍易受对抗性扰动影响。最近的测试时自适应方法在不重新训练的情况下提升了鲁棒性，但并未直接适应被污染的视觉表示本身。基于提示的方法适应可学习的文本提示，而输入空间方法则在测试时优化像素或填充。这些方法虽能改善预测，但通过间接且昂贵的优化路径实现。我们提出测试时视觉子空间引导（T-VSS），一种轻量级防御方法，直接在视觉特征空间进行测试时自适应。T-VSS首先从锚定于受攻击图像的多视角特征残差中构建样本特定的低秩子空间，然后利用可靠性加权熵最小化在该子空间内学习共享的特征修正。通过将自适应约束于紧凑的视觉几何结构，T-VSS将受攻击特征引导至更稳定且更具判别性的预测，同时避免噪声的全空间更新。在细粒度、ImageNet和ImageNet-OOD基准上的实验表明，T-VSS提升了对抗鲁棒性，同时保持了有竞争力的干净准确率，并且比先前的测试时自适应方法更高效。

## Abstract
Vision-language models (VLMs) achieve strong zero-shot recognition, but they remain highly vulnerable to adversarial perturbations. Recent test-time adaptations improve robustness without retraining, but they do not directly adapt the corrupted visual representation itself. Prompt-based methods adapt the learnable text prompts, while input-space methods optimize pixels or padding at test time. These approaches can improve predictions, but they do so through an indirect and expensive optimization path. We propose Test-time Visual Subspace Steering (T-VSS), a lightweight defense that performs test-time adaptation directly in the visual feature space. T-VSS first builds a sample-specific low-rank subspace from multi-view feature residuals anchored at the attacked image. It then learns a shared feature correction within this subspace using reliability-weighted entropy minimization. By constraining adaptation to a compact visual geometry, T-VSS steers attacked features toward more stable and discriminative predictions while avoiding noisy full-space updates. Experiments on fine-grained, ImageNet, and ImageNet-OOD benchmarks show that T-VSS improves adversarial robustness while maintaining competitive clean accuracy and better efficiency than prior test-time adaptations.

## 1. 核心问题与整体含义（研究动机与背景）
- **核心问题**：视觉语言模型（VLM，如CLIP）在零样本识别中表现优异，但对输入图像的微小对抗扰动高度敏感，即使肉眼无法察觉的攻击也能导致预测错误。这对安全关键应用（如医疗AI、自动驾驶）构成重大威胁。
- **现有方法的不足**：传统的对抗训练、鲁棒微调、扩散净化等需要额外数据、标签或昂贵的重新训练；近期测试时自适应方法（如R-TPT、TTP）通过优化文本提示或输入像素空间间接应对攻击，但优化路径间接、计算开销大，且未直接修复被污染的视觉特征。
- **本文动机**：设计一种轻量级、直接作用于视觉特征空间的测试时防御方法，通过低秩子空间约束实现高效、稳定的特征校正，避免全空间噪声更新。

## 2. 方法论
### 2.1 核心思想
- **直接特征空间自适应**：不调整文本提示或像素，而是直接在CLIP图像编码器输出的视觉特征嵌入空间中，学习一个样本特定的低秩偏移向量（共享校正），将受攻击的多视角特征引导至更稳定、判别性更强的区域。
- **低秩子空间构建**：利用多视角增强视图（来自同一受攻击图像）的特征残差，通过奇异值分解（SVD）提取一个紧凑的样本特定子空间，作为校正的可行域。
- **可靠性加权**：根据各视图在特征空间中的局部一致性（最近邻相似度）估计可靠性权重，在优化和最终预测中抑制不稳定视图的影响。

### 2.2 关键技术细节
1. **多视角特征提取**：对测试图像（含原始视图和N个增强视图）通过冻结的CLIP图像编码器提取L2归一化的视觉特征 {f₀, ..., f_N}。
2. **局部视觉子空间估计**：
   - 以原始视图特征 f₀ 为锚点，构建残差矩阵 R = [ (f₁ - f₀)ᵀ; ...; (f_N - f₀)ᵀ ] ∈ ℝ^{N×d}。
   - 对R进行SVD：R = U Σ Vᵀ，取前m个右奇异向量组成基 V_m ∈ ℝ^{d×m}，其中m由累积方差阈值ρ（默认0.9）自动确定：选择最小的q使得前q个奇异值平方和占总和的≥ρ。
3. **共享低秩特征引导**：
   - 初始化可学习系数向量 α ∈ ℝ^m 为零向量。
   - 生成共享偏移 Δ = V_m α，并对所有视图特征进行校正：̃f_i = (f_i + Δ) / ‖f_i + Δ‖₂。
   - 所有视图使用相同的偏移，强制一致性的跨视图修正。
4. **可靠性加权优化与聚合**：
   - 对每个视图，计算其与其余视图的top-K最近邻的平均余弦相似度 r_i，再经温度缩放softmax得到权重 w_i（抑制异常视图）。
   - 优化目标：可靠性加权熵最小化 L = Σᵢ w_i * H(p(̃f_i))，其中H是预测概率的香农熵。
   - 最终预测：pfinal = Σᵢ w_i * p(̃f_i)。
5. **优化**：仅优化α（维度m通常为2-6），使用AdamW（lr=0.1），单个更新步。图像编码器与文本编码器全程冻结。

### 2.3 算法流程（文字描述）
给定受攻击测试图像x → 生成N个增强视图 → 一次前向通过CLIP视觉编码器获所有视图的特征 → 以原始视图为锚点计算残差矩阵 → SVD提取低秩基V_m → 初始化α=0 → 计算共享偏移Δ并应用于所有视图 → 根据特征相似度计算每个视图的可靠性权重w_i → 用加权熵损失更新α（单步） → 用更新后的α计算校正特征 → 加权平均所有视图概率得到最终预测。

## 3. 实验设计
### 3.1 数据集与场景
- **细粒度分类**：8个数据集（Caltech101, Pets, Cars, Flower102, Aircraft, DTD, EuroSAT, UCF101），覆盖自然图像、纹理、卫星遥感、动作识别等。
- **大规模基准**：ImageNet及其4个分布外（OOD）变体（ImageNet-A, ImageNet-V2, ImageNet-R, ImageNet-S）。
- **对抗攻击设置**：
  - 主攻击：PGD（ResNet-50: ϵ=1/255, 7步；ViT: ϵ=4/255, 100步）。
  - 额外攻击：CW, DeepFool, FGSM, AutoAttack, APGD-CE, APGD-DLR。
  - 自适应攻击：EOT-PGD（对增强管道求导）。

### 3.2 Backbone与对比方法
- **Backbone**：CLIP ResNet-50, ViT-B/16, ViT-B/32, ViT-L/14（部分实验还使用了TeCoA鲁棒预训练版）。
- **对比方法**：
  - 基线：原始CLIP、简单多视图集成。
  - 标准VLM测试时自适应：TPT, C-TPT, MTA。
  - 对抗测试时防御：R-TPT, TTC, TTP（近期SOTA）。
  - 训练时防御：TeCoA, FARE, APT（作为补充比较）。

- **公平性**：所有测试时方法使用相同的CLIP backbone和AugMix增强管道，不使用额外基础模型或外部知识。

### 3.3 主要实验设置
- 视图数：64（1原始+63增强），也测试了8、16、32。

## 6. 主要结论与发现
1. **鲁棒性显著提升**：T-VSS在8个细粒度数据集上的平均对抗准确率为48.5%（ResNet-50）、45.8%（ViT-B/16）、53.8%（ViT-L/14），超过此前最先进方法（R-TPT, TTP）2-3个百分点，且保持竞争性干净准确率。
2. **跨场景一致性**：在ImageNet和4个OOD基准上，平均对抗准确率37.6%，比R-TPT高2.2个百分点；在多种攻击（PGD, CW, DeepFool, AutoAttack）下均优于对比方法。
3. **高效性**：低维优化（仅学习几个系数），单步更新，每图像耗时0.383秒（64视图），低于所有对比方法；16视图时速度提升5.8倍且仍优于R-TPT的64视图结果。
4. **核心设计有效性**：
   - 自适应秩选择是鲁棒性主要来源（禁用时准确率下降3-7个百分点）。
   - 采用原始视图为锚点（而非均值或无锚点）效果最佳。
   - 可靠性加权提供一致的小幅增益。
5. **共享扰动结构**：实验分析（附录B）表明，受攻击多视图特征残差具有明显的共享成分且残差秩急剧减小（由清洁时的8-10降至攻击时的1-3），证明低秩共享校正是合理有效的。

## 7. 优点
- **直接且轻量**：直接在视觉特征空间进行校正，避免间接优化（提示/像素），仅需低维系数优化，计算效率高。
- **几何引导**：利用样本特定低秩子空间约束更新方向，避免全空间噪声，增强稳定性。
- **共享校正设计**：强制所有视图使用同一偏移，利用多视图共同的攻击分量，提高一致性。
- **可靠性感知**：基于特征最近邻相似度动态加权，抑制不可靠视图，兼具鲁棒性和灵活性。
- **超参数鲁棒**：秩阈值ρ、最近邻数K等参数在较宽范围内性能稳定。
- **广泛验证**：涵盖多个backbone、多种攻击、分布内/外场景、视图预算变化，结论可信度高。
- **兼容性**：可与训练时鲁棒预训练（如TeCoA）结合进一步提升。

## 8. 不足与局限
- **对增强管道的依赖**：核心机制依赖随机多视图增强，在防御感知自适应EOT-PGD攻击下（攻击者显式优化通过增强管道）鲁棒性急剧下降（表14，全部方法降至个位数），作者承认这是当前测试时自适应范式的普遍弱点。
- **特定数据集的弱点**：在EuroSAT（遥感图像）上，T-VSS的鲁棒性不如TTP，说明残差结构在特定领域可能语义信息不足。
- **鲁棒预训练backbone下的增益有限**：在TeCoA预训练backbone（表8）上，T-VSS虽取得最佳平均鲁棒率（22.0%），但绝对数值仍较低，提升幅度不如标准backbone明显。
- **需要超参数调优**：虽然敏感性低，但仍需设置ρ、τ_r、K、视图数、学习率、更新步数等，不同场景可能需要微调。
- **实验未覆盖大规模多模态模型**：仅测试了CLIP系列，未扩展到如BLIP、LLaVA等更复杂VLM；也未测试黑盒攻击场景。
- **安全性声明**：作者指出现有防御可能在更强自适应攻击下失效，不应过度解读为安全保证，且有双重用途风险（可能启发更强攻击）。

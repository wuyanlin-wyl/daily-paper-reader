## 摘要
用药推荐预测患者就诊时的用药方案，但现有方法仍面临两个关键挑战。在模型层面，传统药物推荐方法仅预测具有有限证据依据的结构化药物代码，而大语言模型智能体虽能利用更丰富的临床背景，但可能缺乏安全性验证和可追溯性。在任务层面，现有基准通常使用宽泛的药物类别，忽略了亚组层面的安全性差异，可能导致风险高估。我们首次提出了基于第四级ATC代码生成的细粒度用药推荐设置。我们提出了安全处方智能体（SafeRx-Agent），一个基于知识的多智能体框架，利用患者背景、外部临床知识和安全性验证来推荐可追溯的药物集。在MIMIC-III和MIMIC-IV数据集上的实验结果表明，SafeRx-Agent在控制药物相互作用、禁忌症和用药集规模的同时，提高了细粒度药物预测的准确性。

## Abstract
Medication recommendation predicts medications for patient visits, but existing methods still face two key challenges. At the model level, traditional drug recommendation methods only predict structured drug codes with limited evidence grounding, while LLM agents can use richer clinical context but may lack safety verification and traceability. At the task level, existing benchmarks often use broad medication categories, which ignore subgroup-level safety differences and can lead to risk overestimation. We introduce the first fine-grained medication recommendation setting based on fourth-level ATC code generation. We propose Safe Prescription Agent (SafeRx-Agent), a knowledge-grounded multi-agent framework that uses patient context, external clinical knowledge, and safety verification to recommend traceable medication sets. Experimental results on MIMIC-III and MIMIC-IV datasets show that SafeRx-Agent improves fine-grained medication prediction accuracy while controlling drug interactions, contraindications, and medication set size.

## 2. 方法论

### 核心思想
SafeRx-Agent 是一个知识驱动的多智能体框架，通过**患者语境、外部临床知识、安全验证**三个环节，生成可追溯的用药方案。其核心流程包括：
1. **专家路由**：根据患者ICD诊断代码，有选择地激活一组专科专家（共7个领域专家 + 1个普适支持专家），而非调用所有专家。
2. **专家生成**：每个激活的专家先**摘要**患者记录中与本专科相关的信息，再结合**MEDI（药物-适应症关系）**资源生成细粒度ATC-L4候选药物。
3. **全局评审**：一个“主治医师”智能体整合所有专家提案，去除重复和缺乏充分支持的项目。
4. **安全验证**：两阶段流程——先基于**外部知识资源（TWOSIDES DDI矩阵、openFDA禁忌症矩阵）**扫描出标记项，再由LLM根据患者具体背景判定保留或移除。

### 关键技术细节
- **ATC-L4预测词汇表**：从MIMIC数据集中提取所有出现过的ATC-L4代码，形成封闭词汇表。
- **知识资源**：
  - **MEDI**：药物-诊断适应症关系，用于指导生成。
  - **TWOSIDES**：构建DDI二元矩阵和频率加权矩阵。
  - **openFDA药物标签**：构建禁忌症（药物-诊断）矩阵。
- **路由算法**：基于患者ICD代码与专家ICD章节的重叠度加权评分，选择Top-K专家（K根据复杂度动态变化）。

## 6. 主要结论与发现

1. **预测准确性**：SafeRx-Agent在所有LLM骨干上均优于直接提示和通用智能体基线，且在无任务特定训练的情况下匹配甚至超越传统深度学习方法。安全过滤后，精确率提升但召回率略有下降，F1整体保持或改善。
2. **安全性**：安全验证显著降低了DDI和禁忌症率，尤其对GPT-5.2和Gemma3-27B-IT效果明显。所有安全指标均优于或接近真实用药集水平。
3. **消融实验表明**：专科专家路由贡献最大（F1下降0.057），医学资源对召回率影响显著，评审环节有效降低假阳性。
4. **多专家协作的重要性**：由多个专家共同提出的药物更可能为真阳性；评审主要移除仅单专家支持的假阳性。
5. **细粒度ATC-L4评估的必要性**：使用ATC-L4时的DDI率和禁忌率显著低于使用ATC-L3，表明粗粒度会高估风险。

## 7. 优点

1. **任务粒度创新**：首次提出基于ATC-L4的细粒度用药推荐，更贴近临床实际安全评估需求。
2. **多智能体架构设计合理**：专家路由避免冗余计算，全局评审去除噪声，安全验证两阶段（矩阵扫描+LLM裁决）结合量化知识和灵活判定。
3. **知识基础全面**：融合了MEDI（适应症）、TWOSIDES（DDI）、openFDA（禁忌症）等多种外部资源，生成和验证均有据可依。
4. **可解释性与可追溯性**：每个药物推荐附带患者特定理由（如“基于既往用药”、“针对活动诊断”），验证环节产生可追溯报告。
5. **实验充分且公平**：在两个数据集、多种骨干LLM上验证，消融实验和诊断分析深入全面，代码和提示已公开。

## 8. 不足与局限

1. **依赖外部知识源的覆盖范围**：DDI和禁忌症矩阵基于有限资源，且映射至ATC-L4可能不完整，导致安全评估为下限（未覆盖的交互被视为安全）。
2. **回顾性评估**：仅在MIMIC离线数据上测试，未在真实临床工作流中前瞻性验证，医生参与的临床有效性评估缺失。

4. **实际临床部署要求**：作者明确指出需要医生监督，不能直接用于临床决策。
5. **未见长期效果评估**：未评估预测方案对患者预后的影响。

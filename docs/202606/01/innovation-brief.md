### 1. Learning to Label: A Reinforced Self-Evolving Framework for Semi-supervised Referring Expression Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.28239v1
- 方法流程：
  - 输入未标注图像-文本对，通过冻结MLLM生成粗定位线索，进而提示SAM2生成软分割先验P†
  - SPM模块将P†与弱视图预测P_w进行不确定性校准，得到融合先验˜P†
  - SESM模块将˜P†作为结构化引导注入分层分割网络，通过阶段自适应的门控机制渐进细化表示
  - RPLE模块根据样本状态，使用强化学习策略网络动态生成阈值，选择可信像素区域作为伪标签，对强视图预测施加一致性监督
- 关键模块/机制：
  - SPM (Semantic-spatial Prior with MLLM)：生成校准的软伪标签先验；使用MLLM生成粗定位，SAM2输出软分割先验P†，然后与模型弱视图预测P_w在logit空间进行像素自适应融合。融合权重基于像素不确定性和样本级一致性，公式(5)(6)。
  - SESM (Self-Evolving Segmentation Module)：注入语义和结构先验到分割网络；在编码器不同阶段，通过动态模态门控融合语义场S和结构场G_j（由˜P†降采样得到），使用阶段依赖的交互方式（浅层局部投影，深层全局注意力），并通过门控残差更新特征。公式(1)(2)(3)。
  - RPLE (Reinforced Pseudo-Label Exploration)：自适应伪标签选择；定义强化学习状态s_t包含预测分布统计、类别比例、一致性得分。策略网络π输出连续阈值(a_t)，根据置信度分配前景/背景/忽略区域。评论家Q基于多视角收益（分离度、一致性、覆盖率）提供奖励，更新策略。公式(7)(8)(9)。
- 公式/目标函数/指标定义：
  - 像素不确定性: C(p) = (2p-1)^2
  - 样本级一致性: W(P_w, P†) = (1/|Ω|) Σ_u [1 - |P_w(u) - P†(u)|]
  - 融合权重: λ(u) = Clamp[0,1][λ0 + κ_p C(P†(u)) - κ_w C(P_w(u)) + κ_a (W(P_w, P†) - 0.5)]
  - 校准先验: ˜P†(u) = σ(λ(u) ℓ(ˆP†(u)) + (1-λ(u)) ℓ(ˆP_w(u)))
  - 阶段门控融合: M_j = α_j Ψ_sem(V_j, S) + β_j Ψ_geo^{(j)}(V_j, G_j)
  - 浅层结构交互: Ψ_geo^{(j)}(V_j, G_j) = W_p(G_j) for j∈{1,2}
- 算法细节：
  - SPM: 计算像素不确定性C(p)和样本级一致性W，通过公式(5)得到融合权重λ(u)，然后在logit空间进行加权融合得到˜P†。
  - SESM: 从˜P†通过阶段对齐算子得到结构场G_j，与文本编码器产生的语义场S通过可学习门控α_j,β_j融合。浅层使用线性投影W_p保持空间对应，深层使用交叉注意力实现全局推理。最终通过门控残差更新特征V'_j。
  - RPLE: 将每个样本的每次自训练迭代视为一个强化学习步骤。策略网络πφ输入6维状态s_t，输出连续阈值a_t=(τ_fg, τ_bg)。评论家Qϕ(s,a)估计质量，奖励由指令增益ΔΦ_t提供，包含分离度、一致性、覆盖率增益和稳定性惩罚。通过策略梯度更新策略。
- 训练/推理细节：
  - 遵循弱到强一致性范式：为每个未标注样本生成弱增强和强增强视图，弱视图预测用于校准先验和构建伪标签，强视图预测受一致性约束。
  - RPLE在每个自训练迭代（每个样本）执行一个强化学习步骤，动态选择伪标签像素。
  - MLLM参数冻结，仅用于生成先验。
  - 推理时只使用分割网络S_θ，无需MLLM或RPLE。

### 2. SafeRx-Agent: A Knowledge-Grounded Multi-Agent Framework for Safe and Explainable Medication Recommendation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29146v2
- 方法流程：
  - 阶段1: 专家路由 - 通过匹配患者ICD代码与专家范围激活稀疏专家子集（含通用支持专家）
  - 阶段2: 多智能体生成 - 每个激活专家执行SUMMARIZE（生成结构化摘要和访视理由）和GENERATE（基于MEDI资源提出ATC-L4候选），然后CRITIQUE全局审查并合并去重
  - 阶段3: 安全验证 - 两阶段：FIND_FLAGS检索DDI和禁忌症矩阵标记风险，VERIFY使用LLM根据患者上下文裁决保留或移除
  - 阶段4: 输出最终预测药物集和可追溯报告
- 关键模块/机制：
  - Expert Panel：定义可复用的专科专家集合，包含K个专科专家和1个通用支持专家，每个专家有ICD章节范围；基于患者嵌入聚类和ICD章节映射构建，预定义后无需训练
  - ROUTE (Sparse Specialty Activation)：激活与患者相关的专家子集，减少计算开销并聚焦；通过加权ICD章节重叠分数和关键词分数选择Top-K专家，Euniv始终激活
  - SUMMARIZE (Expert-Specific Patient Summarization)：为每个激活专家提取并结构化患者记录中的相关证据；生成两个结构化产物：类型化摘要si（活动问题、器官功能障碍、护理环境等）和访视理由ρi（链接诊断、手术和药物）
  - GENERATE (Per-Expert Medication Proposal)：基于专家视角和MEDI资源提出药物候选；输入si、ρi、XT和MEDI关系R，输出排序的药物候选集Mi，通过LLM生成
  - CRITIQUE (Global Critique and Reconciliation)：审查所有专家候选，合并去重，生成最终候选集；考虑所有专家输出、摘要、理由、MEDI和完整患者记录，LLM执行合并与去重
  - Safety Verifier (Two-Phase)：检测并处理药物相互作用和禁忌症风险；阶段1：基于预计算的DDI矩阵M_DDI和禁忌症矩阵M_Contra进行证据检索，标记风险；阶段2：LLM根据患者上下文和原始资源裁决每个标记的药物是否保留或移除
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式。目标函数未明确定义，但任务为多标签预测，使用预测集与真实集的比较及安全性指标（DDI率、禁忌症率）评估。
- 算法细节：
  - 算法1：推理流程：1. ROUTE(X_T, E) 获取激活专家子集A；2. 对每个E_i ∈ A，执行SUMMARIZE生成s_i和ρ_i；3. 执行GENERATE生成M_i；4. CRITIQUE合并所有M_i为M̃；5. FIND_FLAGS在M̃中检测DDI/禁忌症标记得到F；6. 对每个标记f，VERIFY判断是否移除，最终得到M̂_T。
  - 路由机制：加权评分 = 0.7 * ICD章节重叠分 + 0.1 * 关键词分，选择Top-K专家（K为超参数）。
  - 安全矩阵构建：从TWOSIDES和openFDA提取DDI和禁忌症矩阵，映射到ATC-L4词汇。
- 训练/推理细节：

### 3. Pocket-Dentist: On-Device Dental Image Understanding via Efficient Multimodal Large Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29299v2
- 方法流程：
  - 数据收集：整合三个牙科影像数据集（约1159名患者），涵盖五类任务（骨吸收分级、病变多标签分类、VQA、描述生成、18类疾病分类）
  - 指标定义：定义任务级指标（BRAR Accuracy/F1、DR F1/Accuracy、VQA Accuracy、Captioning BERTScore F1、Classification F1）和部署效率指标（TTFT、OET、Total Time、ITPS、OTPS、CPU、RAM）
  - 模型选择：选取14个VLM，包括5个大型（≥7B）和9个紧凑型（≤4B），涵盖通用和医学领域模型
  - 基准测试：在所有模型上计算任务级指标，对比精度和效率
  - LoRA微调：对选定的紧凑型VLM进行LoRA微调，获得Pocket-Dentist-2B等模型
  - 端侧部署：将模型量化至GGUF Q4_K_M（4-bit），通过llama.cpp映射到Metal GPU，在iPhone 17 Pro上运行，所有推理本地执行
- 关键模块/机制：
  - 效率感知基准：统一评估牙科VLM的性能与计算成本；包含三个牙科数据集、五个任务类型和七个指标，同时测量精度和部署效率（延迟、吞吐量、内存占用）
  - LoRA微调：高效适应牙科领域，保持紧凑模型大小；对紧凑型VLM（如InternVL3.5-2B）进行低秩适应（LoRA）微调，更新少量参数以适配牙科任务
  - 4-bit量化部署：降低模型大小和内存占用，支持端侧推理；使用GGUF Q4_K_M量化方案将模型压缩至4-bit，通过llama.cpp加载并利用Metal GPU加速，在iPhone 17 Pro上实现本地推理
  - 端侧推理引擎：在移动设备上高效执行多模态模型；采用llama.cpp框架，通过Metal API将推理映射到GPU，使用Swift LocalLLMClient库加载量化后的模型，所有处理在设备统一内存中完成
- 算法细节：
  - LoRA微调：保持预训练权重固定，在注意力层插入低秩矩阵进行微调
  - 模型量化：使用GGUF Q4_K_M格式，将权重存储为4-bit整数，减少存储和内存带宽
  - 推理加速：通过llama.cpp将量化模型映射到Metal GPU，利用并行计算加速前向传播
  - 端侧部署：在iOS应用中通过Swift LocalLLMClient加载GGUF模型，所有推理在本地进行，不发送数据到云端
- 训练/推理细节：
  - 训练：使用LoRA方法对紧凑型VLM进行微调，仅更新少量参数，适配牙科多模态问答任务
  - 推理：在iPhone 17 Pro上，所有模型量化至GGUF Q4_K_M，通过llama.cpp利用Metal GPU加速，内存占用低，Pocket-Dentist-2B仅需2.62 GB RAM

### 5. BiSegMamba: Efficient Bidirectional Tri-Oriented Mamba for 3D Medical Image Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.30972v1
- 方法流程：
  - 输入：3D医学图像体积 x ∈ R^{B×Cin×D×H×W}
  - 阶段1：PCS处理输入，生成紧凑隐空间张量 x0 和高分辨率浅层特征 s
  - 阶段2：x0 通过四阶段编码器，前两阶段使用MSSM块（并行3×3×3、5×5×5、空洞3×3×3深度可分离卷积），后两阶段使用Bi-ToOM块（双向三向正交扫描+可学习分支权重）
  - 阶段3：每阶段后接patch merging下采样，逐步降低分辨率
  - 阶段4：解码器通过跳跃连接逐步恢复分辨率，最终由RCH融合解码特征和浅层特征 s 输出分割结果
- 关键模块/机制：
  - Progressive Compacting Stem (PCS)：将输入体积转换为紧凑隐空间张量和高分辨率浅层特征，减少冗余计算并保留浅层细节；输入x，先通过浅层特征提取器f1,f2生成s；然后通过渐进降采样g1生成u，再通过g2和残差分支r生成紧凑表示x0。公式：s=f2(f1(x)), u=g1(s), x0=g2(u+r(u))。
  - Multi-Scale Spatial Mixer (MSSM)：在早期编码阶段以较低计算成本捕获局部解剖模式；输入特征u，并行三条深度可分离卷积分支：3×3×3、5×5×5、空洞率为2的3×3×3（用于各向异性数据增加平面内分支）。每条分支经过实例归一化和GELU激活，输出相加。公式：m1=ϕ(IN(DW3×3×3(u))), m2=ϕ(IN(DW5×5×5(u))), m3=ϕ(IN(DW dil=2 3×3×3(u)))。
  - Bidirectional Tri-oriented Ortho Mamba (Bi-ToOM)：建模长程体素依赖，通过双向扫描减少因果偏差，多正交视图建模上下文；对三维特征图沿三个正交方向（深度、高度、宽度）分别进行前向和后向扫描，生成6个序列。每个序列通过Mamba块处理，然后使用可学习分支权重融合前向和后向输出，再通过ADF融合不同方向。
  - Adaptive Directional Fusion (ADF)：学习输入依赖的方向权重，替代固定求和进行方向特征聚合；对来自不同正交方向的响应，通过一个小型网络生成通道级权重，然后加权融合。
  - Reconstruction Head (RCH)：融合解码器输出和PCS保留的浅层高分辨率特征，恢复精细边界；将解码器最终特征与PCS输出的s进行拼接或逐元素操作，再通过卷积层生成最终分割图。
- 公式/目标函数/指标定义：
  - s = f2(f1(x))
  - u = g1(s)
  - x0 = g2(u + r(u))
  - m1 = ϕ(IN(DW 3×3×3(u)))
  - m2 = ϕ(IN(DW 5×5×5(u)))
  - m3 = ϕ(IN(DW dil=2 3×3×3(u)))
- 算法细节：
  - PCS中的渐进降采样：对于各向异性数据，早期深度轴降采样幅度小于平面内，以保留层间信息
  - Bi-ToOM：将三维特征图展平为三个正交方向的一维序列，每个方向分别进行前向和后向扫描，所有6个序列批处理通过Mamba块，然后前向和后向输出通过可学习权重加权求和，消除因果偏差
  - ADF：方向特征通过全局平均池化获得通道描述符，再经过全连接层和softmax生成通道级权重，加权融合不同方向特征
  - 解码器跳跃连接：编码器每层输出通过skip connection与解码器对应层融合

  - 输入体积大小未明确说明，但实验中使用重采样和裁剪以适应模型

### 6. Generating Reports or Repeating Templates? Measuring and Mitigating Template Collapse in 3D CT Report Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.30984v1
- 方法流程：
  - Stage 1: 临床感知（Clinical Perception） - 输入：3D CT体积经冻结的3D图像编码器得到特征Z∈R^(N×D)；处理：潜在查询变换器通过18个可学习病理查询Q∈R^(18×D)与Z交叉注意力提取病理证据，自注意力建模病理相关性；输出：多标签病理对数概率及校准概率。
  - Stage 2: 病理引导检索（Pathology-Guided Retrieval） - 输入：Stage 1预测的病理标签概率；处理：从数据库中检索k个报告，这些报告的标签向量与预测标签的一致性高（如按标签欧氏距离或覆盖所有高置信度发现），并编码为文本嵌入；输出：检索到的范例报告文本及嵌入。
  - Stage 3: 报告合成（Report Synthesis） - 输入：预测病理概率、检索到的范例文本、原CT特征；处理：将检测结果与检索上下文拼接，送入冻结的医学语言模型LLM，以自回归方式生成最终报告；输出：完整的放射学报告。
- 关键模块/机制：
  - 潜在查询变换器 (Latent Query Transformer, LQT)：从3D视觉特征中提取病理特异性证据并预测多标签病理概率；包含C=18个可学习病理查询（每个对应一种病理，如胸腔积液、肺不张），通过交叉注意力从3D编码器输出特征Z中聚合病理证据，并利用查询间的自注意力建模病理共现关系。最终投影为多标签对数，通过focal loss优化。
  - 病理引导检索器 (Pathology-Guided Retriever)：检索与预测病理发现一致的范例报告以提供临床上下文；基于Stage 1预测的病理概率向量，在预建立报告数据库中进行检索。检索策略为：根据预测标签与数据库报告标签向量之间的相似性（如欧氏距离）或确保检索到的报告共同覆盖所有高置信度发现，排序并返回top-k个范例报告及其文本。
  - 冻结医学语言模型 (Frozen Medical LLM)：综合检测结果与检索上下文合成最终报告；使用一个预训练的医学领域语言模型（如基于RadBERT的模型），其参数在CLarGen中冻结。输入为检测到的病理标签（以文本形式表示）与检索到的范例报告拼接，通过自回归语言建模生成最终报告，避免过拟合。
- 公式/目标函数/指标定义：
  - L_FL = -∑_{c=1}^{C} α_c (1 - p_{t,c})^γ log(p_{t,c})，其中α_c为类别频率的逆，p_{t,c}为类别c的预测概率。
- 算法细节：
  - LQT：可学习查询Q初始化为可训练参数，与图像特征Z进行多头交叉注意力（queries来自Q，keys和values来自Z），之后查询间进行自注意力，最后经MLP输出logits。
  - 检索策略：计算预测病理向量ŷ∈[0,1]^C与数据库报告标签向量y_i之间的余弦相似度或欧氏距离，按相似度降序取前k个；或者使用覆盖策略，保证检索结果集体包含所有概率高于阈值（如0.5）的发现。

### 9. OccamToken: Efficient VLM Inference with Training-Free and Budget-Adaptive Token Pruning
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.29657v1
- 方法流程：
  - 输入：图像和文本查询。视觉编码器将图像编码为视觉令牌V，并注入测试时寄存器令牌r（通过重定向MLP激活中的高范数注意力汇）。
  - 第一阶段（图像自适应冗余剪枝）：在视觉编码器输出处，用[CLS]令牌计算对所有视觉令牌和寄存器令牌的注意力分数s1，保留分数≥λ1·s1(r)的视觉令牌（加上寄存器令牌），得到图像自适应集合S1。
  - 第二阶段（寄存器锚定相关剪枝）：将S1与文本令牌T拼接输入LLM，在指定层l提取文本令牌到视觉令牌和寄存器令牌的注意力分数，取文本到视觉的最大注意力作为s2，文本到寄存器的平均注意力作为s2(r)，保留s2(vi)≥λ2·s2(r)的视觉令牌（加上寄存器令牌），得到最终查询自适应集合S2。
  - 输出：用S2替换原视觉令牌，继续自回归解码生成回答。
- 关键模块/机制：
  - 测试时寄存器令牌：作为非判别性全局参考锚点，吸收注意力汇，提供动态阈值基准；在推理时，将MLP中异常通道激活从补丁令牌重定向到寄存器令牌对应的维度，使其参与后续自注意力计算，并产生可比分数。实验表明寄存器令牌编码全局信息且对局部补丁证据不敏感。
  - 图像自适应冗余剪枝（AdapRP）：根据图像内容自适应去除冗余视觉令牌；使用[CLS]令牌对视觉令牌和寄存器令牌打分（s1），以λ1·s1(r)为阈值，保留分数高于该阈值的视觉令牌。对于无[CLS]令牌的架构（如Qwen），采用互评分方案（平均所有令牌对某令牌的注意力）。
  - 寄存器锚定相关剪枝（RegRP）：根据查询选择与当前问题相关的视觉证据；在LLM解码层中，计算文本令牌到视觉令牌的最大注意力作为s2(vi)，文本令牌到寄存器令牌的平均注意力作为s2(r)，以λ2·s2(r)为阈值保留相关令牌。
- 公式/目标函数/指标定义：
  - 注意力计算：A = Softmax(QK^T/√d_h), O = AU
  - 绝对排名剪枝：S = top-K(V, s)
  - 相对比较剪枝：S(x) = {v ∈ V(x) | s_x(v) ≥ λ · s_x(r(x))}
  - 第一阶段保留：S1 = {v_i ∈ V | s1(v_i) ≥ λ1·s1(r)} ∪ {r}
  - 第二阶段分数：s2(r) = (1/M)Σ_j A^{(l)}_{t_j→r}, s2(v_i) = max_j A^{(l)}_{t_j→v_i}
  - 第二阶段保留：S2 = {v_i ∈ S1\{r} | s2(v_i) ≥ λ2·s2(r)} ∪ {r}
- 算法细节：
  - 算法1概述：输入图像、查询、系数λ1, λ2、剪枝层l、寄存器神经元集合K_reg。
  - 步骤1：编码图像得到视觉令牌V和MLP激活h。
  - 步骤2：对每个k∈K_reg，设置r的通道为h中最大值，并将所有v_i对应通道置零，实现注意力汇重定向。
  - 步骤3：通过[CLS]注意力计算s1，得到S1。
  - 步骤4：运行LLM至第l层，从文本注意力计算s2。
  - 步骤5：根据阈值得到S2。
  - 步骤6：用S2替换原视觉令牌，继续自回归解码。
- 训练/推理细节：
  - 无需任何额外训练，完全在推理时进行剪枝。
  - 寄存器令牌的构造在推理时动态完成，不修改预训练模型权重。
  - 剪枝强度由超参数λ1和λ2控制，可通过验证集调整。
  - 适用于多种VLM架构（LLaVA-v1.5, LLaVA-NeXT, Qwen3-VL）。

  - 模型初始化：评分模型使用RoBERTa-base，加载预训练的LARS权重（来自文本QA）
  - 优化：Adam优化器，学习率5e-6，训练3个epoch，10%数据作为验证集

  - 推理：先使用VLM生成回答，再构造输入变体计算概率信号，通过评分模型得到不确定性分数

### 13. Chaos-SSL: An Attention-Based Self-Supervised Learning Framework with Chaotic Transformation for Medical Image Classification
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.27146v1
- 方法流程：
  - Stage1 自监督对比预训练：输入图像经标准增强生成View1，经标准增强+混沌变换生成View2，两个视图经ConvNeXt-Tiny编码器和3层MLP投影器，通过NT-Xent损失对比学习，训练后丢弃投影器，保存编码器权重。
  - Stage2 监督微调：在预训练编码器后添加线性分类头，使用交叉熵损失在目标数据集上微调。
  - Stage3 注意力融合：将微调后的Chaos-SSL编码器特征与ImageNet预训练的ConvNeXt-Large特征通过Squeeze-and-Excitation模块动态融合，再经分类头输出最终预测。
- 关键模块/机制：
  - ChaoticTransform：生成复杂增强视图，提供非线性变换；对输入图像张量I（归一化至[0,1]）进行像素级一维混沌映射迭代k次（k~U[1,5]），首先将I clamp到[ε,1-ε]（ε为小常数），然后迭代I(n+1)=f(I(n))，其中f为Logistic（r=3.99）、Tent（μ=2.0）或Sine（r=1.0）映射。
  - Contrastive SSL Model：学习鲁棒的医学图像表示；由ConvNeXt-Tiny编码器和三层MLP投影器组成，输入两个视图（标准增强view1，混沌增强view_chaos），输出128维投影向量z1和z_chaos，使用NT-Xent损失进行对比学习。
  - Attention Fusion Model：动态融合Chaos-SSL微调模型与ImageNet预训练模型的特征；采用Squeeze-and-Excitation注意力机制，将两个编码器提取的特征图进行加权融合，结合全局上下文信息，生成更具判别性的融合特征。
- 公式/目标函数/指标定义：
  - 混沌映射迭代：I(n+1) = f(I(n))，其中f为Logistic: f(x)=r·x(1-x) (r=3.99), Tent: f(x)=μ·min(x,1-x) (μ=2.0), Sine: f(x)=r·sin(π·x) (r=1.0)
  - NT-Xent损失：对于正对(zi,zj)，Li = -log(exp(sim(zi,zj)/τ) / Σ_{k≠i} exp(sim(zi,zk)/τ))，其中sim(u,v)=u^T v/(||u|| ||v||)，τ为温度参数。总损失L_NTX = 1/(2N) Σ_i Li
  - 余弦相似度：sim(u,v) = u^T v / (||u|| ||v||)
- 算法细节：
  - 预训练阶段：每个batch随机采样N个图像，对每个图像生成两个视图：view1为随机水平翻转、颜色抖动、随机灰度、高斯模糊组合；view_chaos为上述变换后再应用ChaoticTransform（k随机，映射类型固定为一种）。
  - 两个视图经编码器E和投影器P得到z1和z_chaos，计算NT-Xent损失。
  - 优化器使用AdamW，编码器学习率1e-7，投影器学习率1e-3，训练15或30个epoch。
  - 预训练后丢弃投影器P，保存编码器权重用于下游微调。
  - 微调阶段：在编码器后添加线性分类头，使用交叉熵损失在目标数据集上训练。
  - 注意力融合阶段：将微调后的Chaos-SSL编码器与ImageNet预训练的ConvNeXt-Large提取的特征通过Squeeze-and-Excitation模块进行通道级注意力加权融合，最后通过softmax分类。
- 训练/推理细节：
  - 预训练：使用AdamW优化器，两个参数组：编码器LR=1e-7，投影器LR=1e-3。批次大小未指定（默认SimCLR通常大batch，但原文未提）。训练15或30 epochs。
  - 微调：在预训练编码器后加线性分类头，交叉熵损失，使用目标数据集标签进行监督训练。具体超参数未提供。
  - 推理：输入图像分别通过Chaos-SSL编码器和ConvNeXt-Large编码器，提取特征经SE模块融合，再经分类头得到最终类别概率。

- 方法流程：

### 15. CIVIC: End-to-End Sequence Compactness for Efficient Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.28115v1
- 方法流程：
  - 输入: 图像F和文本提示x
  - 步骤1: 密集patch嵌入X0 ∈ R^{Te×Dv}
  - 步骤2: 紧凑视觉聚合: 使用可学习锚点A和交叉注意力权重WA生成紧凑表示Z0 = WA X0, Z0∈R^{Me×Dv}
  - 步骤3: 紧凑视觉编码: 紧凑编码器Ecv处理Z0，每层将KV压缩到S个记忆锚点，输出Hc∈R^{Me×Dv}
  - 步骤4: 紧凑多模态投影: 紧凑投影层Πc将Hc映射到语言隐藏空间，得Vc∈R^{Mp×Dl}
  - 步骤5: 紧凑多模态预填充: 将Vc与文本嵌入拼接，得x̃c∈R^{L+Mp}
  - 步骤6: 自回归解码: LLM处理紧凑上下文，生成输出ŷ
  - 输出: 生成的文本
- 关键模块/机制：
  - Compact Visual Aggregation：在视觉编码前将密集patch聚合为紧凑序列，避免后验压缩开销；使用可学习紧凑锚点A∈R^{Me×Dv}，对密集嵌入X0进行交叉注意力：K0=Norm(LN(X0)), QA=Norm(LN(A)), WA=softmax(QA K0^T / τ), Z0=WA X0。输出紧凑表示Z0∈R^{Me×Dv}。
  - KV-Compressed Vision Attention：在紧凑视觉编码器层内将Key和Value压缩到S个记忆锚点，降低自注意力计算量；计算Q(l)=H(l)W_Q, K(l)=H(l)W_K, V(l)=H(l)W_V; 通过KV分配矩阵R(l)∈R^{Me×S}压缩K(l)和V(l)得到K_c^{(l)}=R̄^{(l)T}K(l), V_c^{(l)}=R̄^{(l)T}V(l); 注意力计算为Attn_c^{(l)}=softmax(Q(l)K_c^{(l)T}/√d) V_c^{(l)}。注意力交互从Me×Me变为Me×S。
  - Text-Aligned KL Distillation：训练紧凑学生模型，在非视觉文本位置上用KL散度对齐教师和学生的logit分布；教师模型Gθ输出logits ℓ_t，学生模型G^c_{θ,φ}输出ℓ_s。定义教师文本位置集I_t和学生文本位置集I_s，映射π: I_t→I_s。计算温度缩放后的分布p^t_i和p^s_{π(i)}，损失L_KL = (λ T_KL^2 / |I_t|) Σ_{i∈I_t} KL(p^t_i || p^s_{π(i)})。仅优化CIVIC特定参数φ，基座VLM参数θ冻结。
  - Adaptive Spatial Retention Floor：防止过度压缩导致细粒度空间信息丢失，保留一个最小保留比例；在紧凑聚合过程中，设置一个最小保留比例（如实验中的Min Keep Ratio），确保即使在极端压缩下仍保留一定数量的空间特征。论文未给出具体公式，但通过消融实验验证了其效果。
- 公式/目标函数/指标定义：
  - 密集推理成本: C_dense = α N_v T_e^2 D_v + β N_l (L+T_p)^2 D_l + γ N_l (L+T_p) D_l + C_dec
  - 后验压缩路由开销: C_route(R) = Σ_{o∈O_R} c(o)
  - 后验压缩部署成本: Ω_post = C_dense + C_route(R)
  - 紧凑推理: V_c = Π_c(E_cv(A(X_0))), V_c∈R^{M_p×D_l}, x̃_c = Merge(x, V_c), |x̃_c| = L+M_p
  - 紧凑模型成本: C_model^c = α N_v M_e S D_v + β N_l (L+M_p)^2 D_l + γ N_l (L+M_p) D_l + C_dec
  - 紧凑注意力比: C_attn^c / C_attn^d ≈ M_e S / T_e^2
- 算法细节：
  - 紧凑聚合使用可学习锚点，通过交叉注意力计算权重，权重softmax沿密集token维度，温度τ控制锐度
  - 紧凑视觉编码器每层使用KV压缩：先计算Q,K,V，然后通过可学习的KV分配矩阵R将Me个token的K和V压缩为S个锚点，再计算注意力
  - 紧凑多模态投影直接处理紧凑序列，无额外的合并/解压缩步骤
  - 预填充阶段将紧凑视觉嵌入直接插入文本，保留文本位置，视觉位置继承自密集视觉跨度
  - 蒸馏仅在文本位置上进行KL散度对齐，因为视觉token位置不对齐
  - 训练时仅更新CIVIC特定参数φ（包括紧凑锚点、KV分配矩阵、投影层等），基座VLM参数冻结
- 训练/推理细节：
  - 训练: 使用教师-学生蒸馏，教师为未修改的密集VLM，学生为CIVIC。损失为文本对齐的KL散度，仅更新CIVIC引入的参数（紧凑锚点A、VAE中的KV分配矩阵R、投影层Πc等），基座模型参数冻结。
  - 推理: 输入图像经过紧凑聚合、紧凑视觉编码、紧凑投影、紧凑预填充和自回归解码，全程保持紧凑表示。无后验压缩操作，因此无额外路由开销。

### 16. Search for Coverage: Learning Coverage-Aware Retrieval with Augmented Sub-Question Answerability
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.28522v1
- 方法流程：
  - 输入：查询 q 及其子问题集合 {s_i}，文档集合 D
  - 步骤1：使用 LLM（Llama-3 70B）对每个文档-子问题对标注可回答性 (0/1)，得到子问题级相关信号
  - 步骤2：基于子问题可回答性，对每个查询的文档计算覆盖率分数（如覆盖的子问题数量或加权和）
  - 步骤3：对每个查询，根据覆盖率分数采样正文档（高覆盖率）和负文档（低覆盖率），构造覆盖率对比学习样本
  - 步骤4：使用原始查询编码器计算文档相似度，同时使用子问题编码器计算每个子问题的相似度，聚合得到教师分数
  - 步骤5：联合优化对比损失和蒸馏损失，更新双编码器参数
  - 输出：训练好的双编码器，可直接用于覆盖感知的稠密检索
- 关键模块/机制：
  - 双编码器（Bi-encoder）：将查询和文档分别编码为稠密向量，通过点积或余弦相似度计算相关性。；使用预训练语言模型（如 BERT 风格）作为骨干，查询编码器和文档编码器共享参数，输出固定维度向量。
  - 覆盖率对比损失（Coverage Contrastive Loss）：促使嵌入空间中高覆盖率的文档与查询更接近，低覆盖率的文档远离。；对于每个查询，根据覆盖率得分选择 top-k 高覆盖文档作为正例，采样低覆盖文档作为负例，使用 infoNCE 损失优化。具体正负采样策略未详述。
  - 覆盖率自蒸馏损失（Coverage Self-Distillation Loss）：利用子问题的细粒度信号指导原始查询的编码。；对每个子问题分别编码并计算与文档的相似度，加权聚合得到教师分数（权重基于子问题重要性或均匀），使用 KL 散度使学生分数（原始查询相似度）逼近教师分数。
  - SCOPE 数据构建：提供具有覆盖率信号的训练数据。；基于 Researchy Questions 的 90K 查询-子问题对，使用 Llama-3 70B 判断每个子问题是否被文档回答（可回答性），从而为每对文档赋予覆盖率标签。
- 公式/目标函数/指标定义：
  - 覆盖率对比损失：L_contrast = -log( exp(sim(q, d_pos)/τ) / (exp(sim(q, d_pos)/τ) + Σ exp(sim(q, d_neg)/τ)) )
  - 覆盖率自蒸馏损失：L_distill = KL( teacher_score || student_score )，其中 teacher_score = Σ weight_i * sim(s_i, d)，student_score = sim(q, d)
  - 总损失：L = L_contrast + λ * L_distill
- 算法细节：
  - 正负文档采样基于覆盖率分数排序，选取 top-k 正例和随机/底部负例
  - 子问题相似度计算使用与主编码器相同的编码器（但可能独立前向），加权聚合时权重可设置为均匀或基于可回答性
  - 推理时仅使用原始查询编码，不涉及子问题
- 训练/推理细节：
  - 先使用 MSMARCO 进行相关性预训练（pre-finetuning, pFT），再在 SCOPE 上使用覆盖率目标进行微调
  - 使用对比学习标准负采样策略（in-batch negatives）可能结合外部负采样
  - 蒸馏目标中的教师分数在每次前向计算中实时生成，不预先计算
  - 推理时无额外开销，与标准双编码器相同

- 方法流程：
  - LBR方法流程：输入图像-文本对 → 标准视觉指令微调 → 计算序列级语言偏差（模型仅基于文本的输出分布与基于图像文本的输出分布之间的差异） → 在交叉熵损失上添加L1正则化项（α * ||语言偏差||_1） → 更新参数
  - LBP方法流程：输入图像和偏好对（所选/拒绝） → 标准DPO损失计算 → 计算语言偏差惩罚项（基于偏好对的语言偏差得分） → 组合损失（DPO损失 + γ * 语言偏差惩罚） → 更新参数
- 关键模块/机制：
  - LBR模块：在指令微调阶段抑制语言偏差；定义序列级语言偏差度量，并在标准交叉熵损失上施加L1正则化惩罚，强制模型降低仅依赖文本的输出概率，增强对视觉信息的利用。
  - LBP模块：在偏好优化阶段减少语言偏差导致的幻觉；在DPO损失函数中融入语言偏差惩罚项，对偏好对中语言偏差较大的样本施加额外惩罚，引导模型偏好更忠实于视觉内容的输出。
- 算法细节：
  - LBR：计算每个样本的序列级语言偏差（通过比较模型在有无图像条件下的输出分布），然后应用L1惩罚，超参数α=1e-5
  - LBP：在DPO训练中，对每个偏好对计算语言偏差得分，并作为惩罚项加入损失，超参数γ=1, β=0.1
  - LBR对α敏感，LBP对γ不敏感
  - 移除CHAIR指标可能存在的reward hacking问题
- 训练/推理细节：
  - LBR使用LLaVA-v1.5官方指令微调配置
  - LBP使用RLHF-V数据集（5.7K对），7B模型全微调3 epoch，13B模型使用LoRA训练4 epoch
  - LBR比LBP对超参数更敏感
  - LBR使用序列级L1正则化优于其他变体（L1-mean, KL, Contrastive）

### 18. Discrepancy Minimization Improves Cross-Hospital Robustness in Digital Pathology
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.25175v1
- 方法流程：
  - 补丁提取：从WSI中提取大量补丁图像
  - 特征提取：利用PFM（UNI/CONCH-v1.5）提取每个补丁的嵌入向量
  - 领域适应/泛化微调：联合优化LMMD损失和交叉熵损失，微调PFM（通过LoRA）并训练线性分类器
  - 切片级分类：对目标切片的所有补丁嵌入，使用ABMIL模型聚合为切片级预测
- 关键模块/机制：
  - PFM（UNI/CONCH-v1.5）：提供补丁级通用特征表示；两个预训练的病理基础模型，分别基于ViT架构，输出补丁嵌入向量
  - LoRA：高效微调PFM的参数；秩为32的低秩适配器，仅应用于PFM的后一半Transformer块，减少可训练参数量
  - 线性分类器 (gϕ)：基于补丁嵌入进行类别预测；单层全连接层，输入为PFM输出的嵌入向量，输出类别logits
  - LMMD损失：对齐不同域中同类别的嵌入分布；局部最大均值差异，利用源样本的真实标签或目标样本的预测标签，计算类条件核均值嵌入差异
  - ABMIL：将补丁级特征聚合为切片级预测；基于注意力机制的MIL模型，输入所有补丁嵌入，输出切片级分类概率
- 公式/目标函数/指标定义：
  - L_DA = (1/ns) Σ_i L_CE(g_ϕ(z^s_i), y^s_i) + λ * L_MMD( {(z^s_i, y^s_i)}_{i=1}^{ns}, {(z^t_j, g_ϕ(z^t_j))}_{j=1}^{nt} )
  - L_DG = (1/K) Σ_k (1/n_k) Σ_i L_CE(g_ϕ(z^{sk}_i), y^{sk}_i) + λ * (1/|P_K|) Σ_{(a,b)∈P_K} L_MMD( {(z^{sa}_i, y^{sa}_i)}, {(z^{sb}_j, y^{sb}_j)} )
- 算法细节：
  - 领域适应：每个batch包含等量源域和目标域样本（共64个），计算交叉熵损失（源域）和LMMD损失（源域标签+目标域预测），联合优化
  - 领域泛化：使用多个源域（K≥2），计算所有源域对的LMMD损失（利用真实标签），不依赖目标域数据
  - LMMD计算时，根据类别划分子域，比较同类别的核均值嵌入差异
- 训练/推理细节：
  - 训练：LoRA秩32，分类器学习率1e-3，LoRA层学习率1e-4，余弦退火，共50 epochs
  - 训练：λ=1.5，领域适应batch大小64，领域泛化batch大小96
  - 补丁级数据：每个医院平衡采样300张补丁
  - 切片级：使用微调后的PFM提取所有补丁嵌入，训练ABMIL 30 epochs，学习率1e-4

### 19. Frequency-Guided Fusion For RGB-Thermal Semantic Segmentation
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.26273v1
- 方法流程：
  - 输入RGB图像和热红外图像，分别通过两个ConvNeXt V2骨干（共享架构、独立权重）提取四层特征{R_i, T_i}，i=1~4
  - Stage1-2：频率融合模块。将T_i通过1x1卷积+BN+GELU投影到RGB通道空间得到T'_i；用固定高斯核(k=7,σ=2.0)深度卷积分解为低频T_low和高频T_high；分别用大核(7x7)和小核(3x3)空间注意力得到增强分量；通过可学习门控α平衡两分量；然后通过置信门控残差（由RGB特征全局平均池化经全连接层得到置信分数γ）与RGB特征融合，输出F_i
  - Stage3-4：语义融合模块。对RGB和热特征进行跨模态通道注意力、多尺度深度卷积和联合通道-空间注意力，输出F_i
  - 将四个融合特征{F_i}送入PANet风格双向解码器（自上而下路径+自下而上路径），每个金字塔层输出经卷积预测，并施加深度监督损失
  - 最终输出分割图
- 关键模块/机制：
  - 频率融合模块：早期阶段（Stage1-2）融合红外与RGB特征，强调结构细节；红外特征经1x1卷积投影到RGB通道空间；用固定高斯核(k=7,σ=2.0)深度卷积得低频，原特征减低频得高频；低频用7x7核空间注意力，高频用3x3核空间注意力；可学习门控α=σ(W·GAP(X))平衡两分量；置信门控残差：F = R + γ * (α*T̃_low + (1-α)*T̃_high)，其中γ由RGB特征GAP经全连接层得到
  - 语义融合模块：后期阶段（Stage3-4）融合语义信息；包含跨模态通道注意力（对齐通道维度）、多尺度深度卷积（不同膨胀率）、联合通道-空间注意力，最终融合RGB和热特征
  - PANet风格双向解码器：多尺度特征解码并生成分割图；构建特征金字塔：自上而下路径通过上采样和相加融合高层语义到低层；自下而上路径通过下采样和相加增强低层空间细节；每个金字塔层输出经卷积预测并施加辅助深度监督损失
- 公式/目标函数/指标定义：
  - 特征提取: {R_i}=E_rgb(I_rgb), {T_i}=E_ir(I_ir), i=1~4
  - 融合策略: F_i = F_freq(R_i,T_i) for i∈{1,2}; F_i = F_sem(R_i,T_i) for i∈{3,4}
  - 频率分解: T_low = G_σ ⊛ T'_i, T_high = T'_i - T_low (G_σ为固定高斯核)
  - 空间注意力: M(X) = σ(Conv_ks[AvgPool_c(X)∥MaxPool_c(X)])
  - 自适应频率门控: α = σ(W·GAP(X))
  - 置信门控残差: F_i = R_i + γ * (α*T̃_low + (1-α)*T̃_high) (γ由RGB特征GAP经全连接层得到)
- 算法细节：
  - 红外特征投影：1x1卷积、BN、GELU
  - 高斯滤波：深度卷积实现，kernel=7x7, σ=2.0
  - 双分支空间注意力：分别对低/高频使用7x7/3x3卷积核，输入为通道平均池化和最大池化拼接
  - 自适应频率门控：输入为拼接后的低/高频特征，全局平均池化后经全连接层和sigmoid
  - 置信门控残差：置信分数γ由RGB特征的全局平均池化经全连接层和sigmoid得到，用于调节残差强度
  - 语义融合模块中的跨模态通道注意力：使用可学习权重对两模态通道进行加权
  - 多尺度深度卷积：不同膨胀率（如1,2,3）的深度卷积并行处理
  - PANet解码器：自上而下路径使用最近邻上采样和3x3卷积；自下而上路径使用2x2步长2卷积
- 训练/推理细节：
  - 使用ConvNeXt V2 Tiny/Nano/Base模型，均经过FCMAE预训练
  - 热红外编码器stem卷积修改为接受单通道输入，其余权重从RGB预训练初始化
  - 损失函数：主损失+辅助深度监督损失（每个金字塔层），均为标准交叉熵
  - 训练时使用深度监督改善梯度流
  - 推理时仅使用主输出

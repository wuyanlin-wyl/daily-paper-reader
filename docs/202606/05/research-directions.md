## 方向 1：医学视觉语言模型细粒度表示与生成优化
融合实体级跨图像注意力、强化学习序列优化、上下文感知对比学习、几何知识蒸馏和无需训练表示增强等机制，共同推动医学VLM从全局粗粒度向细粒度、可解释和优化目标转变，解决放射学报告生成、病变检测和细胞形态分析中的细粒度表示不足问题。

### 代表论文

- [A Vision-language Framework for Comparative Reasoning in Radiology](https://arxiv.org/abs/2606.06407v1)：提出实体感知跨图像推理框架MedReCo和MedReCo-VLM，实现放射学中可控的参考病例检索和生成式时间比较解读，并在大规模多模态临床数据上验证。
- [RL-ACRGNet: Reinforcement Learning-Based Chest Radiology Report Generation Network](https://arxiv.org/abs/2606.02035v1)：提出RL-ACRGNet，结合DenseNet编码器与多级LSTM解码器，通过离策略强化学习和复合奖励机制优化视觉语义嵌入，提升放射学报告生成的准确性和临床相关性。
- [CP-Agent: Context-Aware Multimodal Reasoning for Cellular Morphological Profiling under Chemical Perturbations](https://arxiv.org/abs/2606.03435v1)：提出CP-Agent，一个结合CP-CLIP上下文感知对齐模块的代理多模态大语言模型，用于在化学扰动下生成机制相关、可解释的细胞形态变化推理报告。
- [Geometry-Aware Distillation for Prompt Tuning Biomedical Vision-Language Models](https://arxiv.org/abs/2606.04922v1)：当前提示微调方法忽略医学影像中类别间的临床语义关系，导致决策边界不稳定。本文提出OGKD框架，利用类别几何结构生成知识蒸馏的软目标，通过全局与局部蒸馏损失提升模型对齐。在11个数据集上平均绝对准确率提升1.7%-2.8%，且泛化性更强。
- [EasyLens: A Training-Free Plug-and-Play Subtle-Lesion Representation Amplifier for Medical Vision-Language Models](https://arxiv.org/abs/2606.06379v1)：医学视觉语言模型对细微病变不敏感，现有增强方法需额外训练。本文提出EasyLens，一种无需训练、即插即用的表示放大器，通过构建病理-解剖原型空间、反事实推理选择病变补丁和形态学引导残差增强，在不改变基础模型的前提下提升全局表示中病变特征的贡献，在多个数据集上显著改善微细病变检测。

### 共同创新点
- 将视觉语言模型的表示学习从全局推向实体/上下文/类别几何等细粒度层次
- 利用强化学习、知识蒸馏、对比学习等优化策略增强细粒度特征贡献
- 在不需要额外训练的前提下，通过原型空间或几何先验提升模型对微妙病变的敏感性

### 尚未解决的问题
- 缺乏统一框架整合多种细粒度增强机制，不同方法的互补性尚未验证
- 实体级跨模态对齐仍依赖文本解析质量，缺乏对3D体积数据的细粒度处理
- 动态交互场景下生成质量评估缺乏标准，现有指标（如CIDEr）未结合临床安全

### 二次创新路线
#### 路线 1：实体级强化比较报告生成框架
- 核心想法：将MedReCo的实体感知跨图像注意力与RL-ACRGNet的离策略actor-critic强化学习结合，构建端到端的比较报告生成模型，在实体级别直接优化报告质量指标。
- 新问题定义：新任务：基于实体级强化学习的放射学比较报告生成。给定一对或多时间点图像，模型需在实体粒度输出比较描述（如“右肺中叶实变较前吸收”），并通过强化学习直接最大化临床相关性指标。
- 机制来源：
  - MedReCo (2606.06407v1) 的实体编码器与跨图像交叉注意力：将临床实体（如“右肺”）编码为条件向量，引导模型关注图像中对应区域；
  - RL-ACRGNet (2606.02035v1) 的actor-critic框架与复合奖励：policy网络根据当前状态选择词，value网络估计长期回报，复合奖励（BLEU+METEOR+ROUGE-L）直接优化报告质量。
- 为什么值得做：MedReCo提供了实体级跨图像对齐机制，RL-ACRGNet提供了序列级优化框架，两者互补可同时提升目标检测的实体准确性和报告流畅性。
- 理论/数学创新理由：
  - 数学对象：序列决策的强化学习目标函数与实体级对比损失的联合优化
  - 来源分解：MedReCo处理了实体级视觉特征的提取与对齐（通过对比学习），RL-ACRGNet处理了词级到序列级的奖励优化（通过policy gradient）；但未在实体粒度上联合优化。
  - 新建模方式：定义新的联合目标函数：J(θ) = E_{π_θ}[Σ_t R(s_t, a_t)] + λ * L_entity，其中R是复合奖励，L_entity是实体级对比损失（确保生成的词对应正确实体区域）。此外，在policy网络中加入实体条件注意力机制，在value网络中加入实体级状态价值估计。
  - 公式草图：L_total = -E[Σ_t log π_θ(a_t|s_t) * A(s_t,a_t)] + λ * Σ_m L_entity(m) 其中 s_t = {I, x_1:t-1, E1,...,Ek} 包含图像I、已生成词、k个实体嵌入E；A(s_t,a_t) = R(s_t,a_t) + γV(s_{t+1}) - V(s_t)；L_entity(m) = -log exp(sim(v_m, e_m)) / Σ_j exp(sim(v_m, e_j))，v_m为当前词对应的图像区域特征。
  - 为什么可能有效：实体级对比损失强制模型在生成实体相关描述时关注对应区域，reducing hallucination；强化学习直接优化报告质量指标，避免teacher forcing的暴露偏差，两者结合理论上可同时提升准确性和流畅性。
- 可验证实验：在MIMIC-CXR数据集上，选取包含比较标签（如“较前基线”）的病例，分别训练MedReCo、RL-ACRGNet和联合模型，评估指标包括BLEU-4、ROUGE-L、CIDEr以及实体级F1（通过NER提取描述中的实体与ground truth对比）。
- 主要风险：联合训练可能引入超参数λ敏感，实体标注噪声可能放大错误，需设计鲁棒对比损失。

#### 路线 2：上下文感知病理-解剖原型增强的微小病变检测
- 核心想法：将CP-Agent的上下文感知对比学习（CP-CLIP）与EasyLens的病理-解剖原型表示增强结合，利用实验元数据（剂量、细胞系）引导病变原型选择，在无需训练的情况下增强VLM对微小病变的敏感性。
- 新问题定义：新任务：上下文引导的微小病变增强检测。在给定细胞图像或医学图像时，模型需根据伴随的实验/临床上下文（如药物、剂量、解剖位置）自动选择对应的病理原型，增强局部特征表示，输出病变存在概率和定位。
- 机制来源：
  - CP-Agent (2606.03435v1) 的CP-CLIP模块：通过字段特定占位符令牌（<CMPD>,<CONC>）和MLP投射将结构化上下文嵌入文本序列，与图像特征通过对比学习对齐；
  - EasyLens (2606.06379v1) 的病理-解剖原型空间与反事实推理：构建病理与解剖原型，通过反事实选择病变补丁，并用形态学引导残差增强融合到全局表示。
- 为什么值得做：CP-Agent证明了元数据在表示对齐中的价值，EasyLens提供了无需训练的增强框架，两者结合可在不增加训练成本的前提下，利用上下文信息提升病变检测。
- 理论/数学创新理由：
  - 数学对象：条件变分下界与原型选择的信息瓶颈
  - 来源分解：CP-Agent通过对比学习最大化图像与上下文的互信息，缺少对局部病变区域的选择性增强；EasyLens通过原型相似度选择补丁，但未考虑上下文信息。
  - 新建模方式：定义上下文条件的原型选择概率 p(z|x,c) = softmax(sim(f(x), P) + g(c))，其中P为原型矩阵，c为上下文嵌入。增强表示为 v_enh = v + Σ_z p(z|x,c) * W_z * v_z，其中v_z为选中原型的局部特征。优化目标为最大化条件似然的下界：L = E_q[log p(y|x,v_enh)] - β KL(q(z|x,c)||p(z|c))。
  - 公式草图：利用信息瓶颈原则，引入上下文先验p(z|c) = softmax(MLP(c))，后验q(z|x,c) = softmax(sim(f(x),P) + MLP(c))。增强后表示：h = v + Σ_z q(z|x,c) * (v_z - v) （残差形式）。训练时最大化条件似然并最小化KL散度。
  - 为什么可能有效：上下文信息通过影响原型选择，使模型在特定场景下优先关注与上下文相关的病理模式（如特定药物诱导的细胞形态变化），减少无关原型的干扰，从而提升微小病变的检测精度。
- 可验证实验：在BBBC021（Cell Painting数据集）和LIDC-IDRI（肺结节检测）上，设置不同上下文条件（药物名、剂量、解剖部位），比较EasyLens基线、CP-Agent基线以及联合模型的AUROC和精确率-召回率曲线。
- 主要风险：上下文质量依赖元数据完整性，缺失时性能可能下降；反事实选择计算开销可能增加推理时间。

## 方向 2：医疗AI代理结构化规划与动态评估
将生物医学agent的图支架规划、临床GUI操作基准和动态决策评估相结合，构建从规划到执行再到评估的闭环代理框架，解决现有代理在复杂临床环境中的可扩展性、安全性和交互能力不足问题。

### 代表论文

- [MedCUA-Bench: A Screenshot-Only Benchmark for Clinical Computer-Use Agents](https://arxiv.org/abs/2606.03203v1)：提出首个面向临床计算机使用代理的交互式基准MedCUA-Bench，覆盖10个医学领域18个场景，通过意图/步骤目标分离临床推理与UI执行，并用确定性检查器评估任务完成和安全性。
- [Beyond Prompt-Based Planning: MCP-Native Graph Planning-based Biomedical Agent System](https://arxiv.org/abs/2606.04494v1)：提出BioManus，一个MCP-native生物医学agent，通过图支架规划解耦规划复杂度与工具数量，实现可扩展的上下文高效推理。
- [Evaluating Large Language Models in Dynamic Clinical Decision-Making with Standardized Patient Cases](https://arxiv.org/abs/2606.05112v1)：提出了MedSP1000基准，基于标准化病人案例将LLM评估从静态单轮扩展到动态交互式临床决策场景，揭示了当前模型在动态场景中的性能局限。

### 共同创新点
- 将代理规划从平面提示检索提升到操作级图规划，解耦规划复杂度与工具规模
- 引入标准化患者(SP)和GUI阴影环境，实现过程级、多轮交互的安全评估
- 通过结构化能力图和确定性检查器，提升代理在动态场景中的稳定性和可解释性

### 尚未解决的问题
- 图规划依赖LLM注释精度，对罕见工具规划质量不稳定
- 当前评估仅覆盖有限临床场景，缺乏对多模态（图像、音频）交互的支持
- 未集成自主学习机制，代理无法从错误中改进规划策略

### 二次创新路线
#### 路线 1：图支架强化学习驱动的动态临床代理
- 核心想法：将BioManus的图支架规划与MedSP1000的多智能体评估框架结合，使用强化学习（尤其是逆强化学习）从标准化病人轨迹中学习规划策略，使代理能在动态临床场景中自我改进。
- 新问题定义：新任务：基于图支架逆强化学习的自适应临床代理。代理需在动态临床环境（如门诊、急诊）中，通过与环境交互，逐步学习获取信息、制定检查和治疗计划，最终达到预定义的临床目标，且过程符合安全性准则。
- 机制来源：
  - BioManus (2606.04494v1) 的图支架规划：构建类型异构能力图，在操作级进行检索和规划，规划复杂度O(h(ℓ_o+m̄ ℓ_s))远小于直接工具检索；
  - MedSP1000 (2606.05112v1) 的多智能体评估框架：患者智能体基于脚本动态响应，评估智能体根据ACGME核心能力评分，提供2.4万条逐项评分标准。
- 为什么值得做：BioManus解决了规划可扩展性问题，MedSP1000提供了丰富的专家轨迹和逐项评分，两者结合可实现从示例中学习最优规划，而无需手工设计奖励函数。
- 理论/数学创新理由：
  - 数学对象：逆强化学习中的奖励函数逼近与图结构先验
  - 来源分解：BioManus的图规划提供了高效的规划骨架（状态空间压缩），MedSP1000提供了专家轨迹（作为逆强化学习的示例），但未在规划策略中注入学习能力。
  - 新建模方式：使用最大熵逆强化学习，从专家轨迹D中学习奖励函数R_ψ(s,a)，然后通过强化学习优化策略π_θ。引入图结构正则化：R_ψ(s,a) = ω^T φ(s,a) + λ * H_Graph(π)，其中φ为特征（如操作类型、工具使用频率），H_Graph为基于图拓扑的熵正则项，鼓励策略探索与工具使用多样性。
  - 公式草图：max_ψ E_{(s,a)~D}[log p_θ(a|s,R_ψ)] + α H(π_θ)，其中p_θ(a|s,R_ψ) = exp(Q_θ(s,a)) / Σ_a' exp(Q_θ(s,a'))，Q_θ由深度网络拟合。训练时交替更新奖励和策略。利用MedSP1000的评分作为专家轨迹的标注。
  - 为什么可能有效：图结构正则化避免策略过早收敛到次优路径，逆强化学习从专家轨迹中提取隐含的临床偏好（如安全性优先），使代理在未见场景中也能做出合理决策。
- 可验证实验：在MedSP1000的10个内科场景（如糖尿病酮症酸中毒处理）上，收集医生操作轨迹作为专家数据，分别训练纯规划代理、纯RL代理和联合图支架IRL代理，比较任务完成率和安全性得分。
- 主要风险：逆强化学习对专家数据质量敏感，低质量轨迹可能导致奖励函数偏移；图构建的初始质量影响后续学习上限。

#### 路线 2：安全感知的GUI图规划代理
- 核心想法：将BioManus的图规划机制移植到临床GUI场景，结合MedCUA-Bench的确定性安全检查器，设计一个在规划阶段即考虑安全约束的代理，实现安全合规的图形界面操作。
- 新问题定义：新任务：安全约束下的GUI图规划。代理需在临床信息系统（如电子病历）的GUI环境中，基于意图目标自动生成操作序列，且在规划阶段即确保满足患者身份验证、数据完整性等安全维度，避免执行后违规。
- 机制来源：
  - BioManus (2606.04494v1) 的图支架规划：通过类型异构能力图将规划提升到操作级，支持动态工具绑定；
  - MedCUA-Bench (2606.03203v1) 的确定性检查器：基于最终页面状态、网络请求和聊天响应，计算五个安全维度（患者身份、数据准确性等）的得分。
- 为什么值得做：BioManus的图规划可解释且可扩展，MedCUA-Bench的安全检查器提供五个维度的安全评估，两者结合可在规划时插入安全约束，避免在医疗GUI中产生危险操作。
- 理论/数学创新理由：
  - 数学对象：约束马尔可夫决策过程（CMDP）与图约束
  - 来源分解：BioManus规划时未考虑安全成本，MedCUA-Bench的检查器仅在事后评估，缺乏事前安全引导。
  - 新建模方式：将规划建模为约束马尔可夫决策过程，状态s包含当前GUI页面抽象表示（由VLM编码），动作a为UI操作（点击、输入），代价c(s,a)来自安全检查器预测的安全违规概率。规划目标为最大化任务完成奖励R(s,a)且满足累积代价约束C_max。具体地，策略优化加入拉格朗日乘子：L(θ,λ)=E[Σ_t R(s_t,a_t) - λ(Σ_t c(s_t,a_t)-C_max)]。图规划提供初始搜索空间，减少探索。
  - 公式草图：值函数V(s) = max_a [R(s,a) - λc(s,a) + γV(s')]，其中λ通过梯度上升更新。图规划用Typed Capability Graph生成候选动作集A(s)=GraphRetrieve(s)，缩小动作空间。安全检查器作为外部函数输出近似的c(s,a)（例如基于字段类型和操作的风险权重）。
  - 为什么可能有效：拉格朗日方法将软约束融入规划，避免硬阻断导致无解；图规划提供结构化先验，使代理在稀疏奖励下仍能高效搜索，同时安全代价约束防止高危操作。
- 可验证实验：在MedCUA-Bench的18个临床场景下，对比无安全约束的BioManus代理、事后过滤代理和本路线提出的CMDP代理，评估任务成功率、安全违规次数和规划时间。
- 主要风险：安全代价估计需要精确的模拟器或预测模型，不准确可能导致过度保守或不足；图规划的构建和维护成本较高。

## 方向 3：检索增强生成中的内容表示动态优化与推理反馈闭环
本方向整合了三篇论文的互补机制：第一篇（2605.30790v1）揭示了答案保留性是RAG中检索内容表示影响生成准确率的关键属性，但仅分析了静态表示；第三篇（2606.00590v1）提出了基于批评者模型的推理动态反馈，优化检索和查询重写，但未考虑表示本身的适应性调整；第二篇（2606.00562v1）提出了并行潜在状态生成机制，可借鉴用于生成动态表示。通过结合这些机制，探索表示的自适应选择、潜在状态压缩表示以及端到端强化学习框架，以提升RAG系统的准确性、效率和鲁棒性。

### 代表论文

- [On the impact of retrieved content representations in RAG Pipelines](https://arxiv.org/abs/2605.30790v1)：通过控制实验发现答案保留性是RAG中检索内容表示影响生成准确率的主要决定因素，而措辞、结构、长度和查询依赖性影响有限。
- [DeepLatent: Think with Images via Parallel Latent Visual Reasoning](https://arxiv.org/abs/2606.00562v1)：针对现有工具辅助视觉推理方法延迟高、潜在推理方法性能不足的问题，本文提出DeepLatent并行潜在视觉推理框架。框架引入LatentFormer，通过可学习2D令牌并行生成与图像特征对齐的潜在状态，并设计连续空间强化学习优化潜在调制参数。结合知识蒸馏训练和DeepLatent-180K数据集，在多个基准上达到最先进性能。
- [Critic-R: Improving Agentic Search using Instruction-tuned Retrievers with Natural Language Introspective Feedback](https://arxiv.org/abs/2606.00590v1)：提出Critic-R框架，通过批评者模型评估检索证据对推理步骤的支持度，实现推理智能体与检索器之间的显式反馈闭环，包含推理时查询细化（Critic-R-Zero）和基于轨迹自动监督的检索模型微调（Critic-Embed），显著提升多跳问答中的检索质量和答案准确性。

### 共同创新点
- 将答案保留性作为表示质量的核心指标，统一了不同变换的效果评估
- 引入并行潜在状态生成机制，实现检索内容的紧凑表示与快速推理
- 利用批评者反馈信号，实现表示的动态优化与检索闭环

### 尚未解决的问题
- 如何将视觉领域的并行潜在状态生成机制适配到文本RAG场景
- 如何联合学习表示变换策略和批评者反馈，实现端到端长期优化
- 表示变换与检索之间的交互如何影响多跳推理和长文本生成

### 二次创新路线
#### 路线 1：基于批评者反馈的答案保留性自适应表示变换
- 核心想法：利用第三篇的批评者模型对当前检索表示进行评估，结合第一篇的答案保留性指标，动态选择最适合当前查询的表示变换策略（如摘要、选择、改写等），以最大化答案保留性并降低推理代价。
- 新问题定义：给定查询q和检索文档集D，设计一个策略π(q,D) = T，选择一种表示变换T（来自预定义变换集，如原始、摘要、BM25片段、Cross-encoder片段等），使得变换后的表示在保留答案信息的同时，最小化推理计算量，且输出被后续生成器正确使用的概率最大。
- 机制来源：
  - 第一篇（2605.30790v1）提供了答案保留性指标R(T)作为表示质量的关键测量，并给出了不同变换的保留性差异
  - 第三篇（2606.00590v1）提出了批评者模型C，通过分析智能体内省推理轨迹判断检索证据是否充分，提供了实时反馈信号
  - 两者互补：第一篇给出了什么重要（答案保留性），第三篇给出了如何动态调整（批评者反馈）
- 为什么值得做：第一篇发现答案保留性是关键因素，但不同变换的效果因查询而异；第三篇提供了实时反馈信号，可以自适应调整，避免固定变换的次优性，有望在保持准确性的同时减少冗余计算。
- 理论/数学创新理由：
  - 数学对象：答案保留性指标R(T)表示变换T后的文档是否包含正确答案；批评者满意度评分C(T)表示该表示对下一步推理的支持度。
  - 来源分解：第一篇单独研究了R(T)与生成准确率的关系，但未使用动态反馈；第三篇单独使用了批评者反馈C，但未考虑不同表示变换的R特性。
  - 新建模方式：联合优化目标：max_{T} [ λ * R(T) + (1-λ) * C(T) ]，其中λ∈[0,1]平衡两者。R(T)可从历史数据或启发式规则预估，C(T)由批评者模型实时计算。
  - 公式草图：定义变换选择策略：T* = argmax_{T∈变换集} [ α * R(T) + β * C(T, q, D_T) + γ * (-cost(T)) ]，其中cost(T)为计算开销，α,β,γ为超参数。R(T)由预训练分类器预测（基于文档和查询），C(T)由Critic-R的批评者模型输出。
  - 为什么可能有效：通过直接最大化答案保留性和批评者认可度，可确保所选变换既保留关键信息又符合推理需求，避免盲目选择。同时引入成本项，可在准确性和效率间取得平衡。预期提升生成准确率5-10%，并减少15-25%的推理延迟。
- 可验证实验：在KILT-NQ数据集上，实现10种预定义变换（包括原始、摘要、命题、改写等）。使用第三篇的批评者模型（基于Llama-3.1-8B）评估C，训练一个简单的R预测器（基于文档和查询的特征）。比较自适应策略与固定变换（如原始、摘要）、随机选择、以及无反馈的静态策略。评估指标：生成准确率、平均变换代价、查询延迟。
- 主要风险：批评者模型可能不够准确，尤其在训练数据外场景；R预测器需要额外训练数据；自适应过程增加运行时开销，可能抵消收益。

#### 路线 2：并行潜在表示生成用于检索内容压缩与推理
- 核心想法：借鉴第二篇的LatentFormer机制，将检索到的多篇文档编码为紧凑的2D潜在令牌矩阵，保留答案信息，同时支持并行推理步骤，替代传统的序列化文本拼接或摘要。
- 新问题定义：给定查询q和检索文档集D={d1,...,dk}，设计一个潜在表示生成器f_θ，输出一个h×w的2D令牌矩阵Z，其中每个令牌编码文档集合的部分信息，且Z在给定q下支持高效推理，生成正确答案的概率最大。
- 机制来源：
  - 第一篇（2605.30790v1）强调了答案保留性在表示中的核心作用，并提供了评估指标，但未涉及潜在表示生成
  - 第二篇（2606.00562v1）提出了LatentFormer，利用可学习2D令牌并行生成与图像特征对齐的潜在状态，实现快速推理，但其机制面向视觉模态
  - 两者互补：第一篇提供文本领域的目标（答案保留性），第二篇提供实现这一目标的潜在表示框架（并行生成）
- 为什么值得做：第二篇表明并行潜在状态生成能有效保留视觉信息并加速推理；第一篇指出答案保留性是关键，而潜在表示通过端到端训练可优化保留性，同时压缩表示长度，降低计算复杂度。
- 理论/数学创新理由：
  - 数学对象：2D潜在令牌矩阵 Z ∈ R^{h×w×d}；答案嵌入 e_y ∈ R^d；对比学习目标。
  - 来源分解：第一篇从宏观上衡量表示质量，第二篇从结构上提出潜在状态生成。
  - 新建模方式：设计文本潜在状态生成器f_θ：首先对每个文档d_i用句子编码器获得表示序列，然后通过交叉注意力将查询q作为查询向量，与文档序列进行交互，最后通过一个解码器生成2D令牌矩阵Z。训练目标为对比学习：min -log( exp(sim(Z, e_y)/τ) / (exp(sim(Z, e_y)/τ) + ∑_{j≠y} exp(sim(Z, e_j)/τ) ) )，其中sim为点积，e_y为正确答案的嵌入（由LLM编码器获取）。
  - 公式草图：Z = LatentFormer( {enc(d_i)}, q )，其中enc(d_i)为文档编码器，LatentFormer包含可学习查询矩阵Q∈R^{h×w×d}，通过交叉注意力聚合文档信息。训练损失：L = -log( e^{sim(Z, e_y)/τ} / (e^{sim(Z, e_y)/τ} + Σ_{j≠y} e^{sim(Z, e_j)/τ}) )。
  - 为什么可能有效：并行生成减少了序列生成型表示（如摘要）的串行开销，2D结构保留了文档间的潜在交互，对比学习直接优化答案保留性，使得Z紧凑地保留关键信息。预期在保持或提升准确率的同时，将表示长度从数千词降低到几十个令牌，加速生成器推理。
- 可验证实验：在KILT-NQ数据集上，将检索到的5个文档进行分句编码，使用可学习8×8令牌矩阵（64令牌）。设置基线为原始文档拼接（约500词）和RECOMP摘要（约100词）。评估生成准确率（使用相同LLM生成器）、表示生成时间、推理延迟。额外消融：比较不同h×w大小的影响。
- 主要风险：文本与视觉的适配可能不直接，可能需要大规模训练数据；答案保留性可能不如保留原始文档高；2D令牌的并行推理机制可能对LLM不友好，需要修改生成器架构。

#### 路线 3：联合表示优化与检索反馈的强化学习框架
- 核心想法：将表示变换策略和批评者反馈建模为强化学习问题，通过Actor-Critic方法端到端学习表示选择和检索调整策略，最大化长期推理准确率。
- 新问题定义：在智能体搜索系统中，将每一步的表示变换选择（如保留原始、摘要、潜在令牌）作为动作，将批评者评分和最终答案准确率作为奖励，训练一个策略网络，使得在多个推理步骤中累积奖励最大化。
- 机制来源：
  - 第一篇（2605.30790v1）提供了表示变换候选集和答案保留性知识，可作为动作空间和先验
  - 第二篇（2606.00562v1）提供了并行潜在状态生成作为一个新型表示动作
  - 第三篇（2606.00590v1）提供了批评者模型作为奖励信号以及检索微调机制，可作为Critic部分
  - 三者互补：第一篇定义动作空间属性，第二篇增加动作种类，第三篇提供奖励和Critic网络，构成完整RL框架
- 为什么值得做：三篇论文分别解决了表示质量评估（第一篇）、并行潜在表示生成（第二篇）和反馈循环（第三篇），但均未联合优化。强化学习可以自动协调表示选择与反馈，在复杂多跳推理场景中实现自适应决策。
- 理论/数学创新理由：
  - 数学对象：马尔可夫决策过程 (S, A, R, P)；Actor网络π(a|s)；Critic网络V(s)。
  - 来源分解：三篇分别贡献了动作空间（第一篇+第二篇）、奖励信号（第三篇）、以及可能的初始策略（第一篇的静态策略）。
  - 新建模方式：定义状态s为当前查询历史与已检索文档的编码，动作a为从变换集（包含原始、摘要、BM25片段、Cross-encoder片段、潜在令牌等）中选择一个。奖励r_t包括即时奖励（批评者评分C_t）和最终奖励（最终答案准确率R_terminal）。训练Actor-Critic：Actor网络π_θ(a|s)输出动作概率，Critic网络V_φ(s)估计状态价值。更新规则：∇_θ J ≈ ∇_θ log π_θ(a|s) * (r_t + γ V_φ(s') - V_φ(s))。
  - 公式草图：状态s = [h_{query}; h_{doc_1}; ...; h_{doc_k}]，由编码器获得。动作a∈{0,...,N-1}对应N种变换。奖励r_t = α * C_t(s') + β * R_terminal（最终步）。Critic损失：L(φ) = (r_t + γ V_φ(s') - V_φ(s))^2。Actor损失：L(θ) = -log π_θ(a|s) * A，其中A为优势函数。
  - 为什么可能有效：RL能端到端优化长期目标，自动学习何时使用简单变换（如原始文档）以节省计算，何时使用复杂变换（如潜在令牌）以增强推理。批评者评分作为即时奖励可引导策略选择支持当前推理步骤的表示。预期在多跳HotpotQA上相比固定策略提升2-5%准确率，同时降低平均推理步骤数。
- 可验证实验：在HotpotQA数据集上实现，使用Search-R1作为推理智能体，Critic模型同第三篇（以Llama-3.1-8B为基础），表示变换集包含5种（原始、摘要、BM25片段、Cross-encoder片段、潜在令牌（实现第二种路线中的生成器））的。使用PPO算法训练Actor网络（小型MLP），Critic网络为第三篇的批评者模型。比较与静态表示（原始）、随机选择、以及Critic-R-Zero（无表示选择）的性能。评估指标：F1分数、平均推理步数、平均检索次数。
- 主要风险：RL训练不稳定，需要大量交互数据；批评者模型作为奖励可能引入噪声；动作空间增大导致收敛困难；第二篇的潜在令牌生成器需要预训练，可能无法与RL同步训练。

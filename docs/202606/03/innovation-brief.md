### 1. Single-Channel Tissue Segmentation via Cross-Modal Distillation from Foundation Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.00928v1
- 方法流程：
  - 第一阶段：教师模型处理多通道图像Xm（核+膜），生成像素级logits Zt，经sigmoid得到soft概率并缓存到磁盘
  - 第二阶段：学生模型仅使用核通道Xs，与教师soft目标、真实掩码Y共同计算损失，总损失为不确定性加权的分割损失、蒸馏损失和边界损失之和，联合优化学生权重和不确定性参数
  - 推理阶段：仅部署学生模型，输入核通道Xs，输出分割预测
- 关键模块/机制：
  - 教师模型（SAM ViT-H或CellSAM）：生成多通道输入的软目标；冻结的ViT-H或CellSAM，处理多通道图像Xm（H×W×C，C=2），输出像素级logits Zt，通过sigmoid转换为概率。
  - 学生模型（U-Net架构）：仅使用单通道核图像进行分割；U-Net结构，编码器可选Swin-Tiny、ResNet18、EfficientNet-B0或MobileNetV3，输入单通道核图像Xs（H×W×1），输出单通道logits Zs。
  - 蒸馏损失L_distill：对齐教师和学生概率输出；MSE损失：L_distill = (1/HW) * Σ (σ(Zt_i) - σ(Zs_i))^2，其中σ为sigmoid。
  - 分割损失L_seg：监督学生与真实掩码的精度和重叠；二元交叉熵损失L_BCE与Dice损失L_Dice之和：L_seg = L_BCE + L_Dice。
  - 边界感知损失L_bnd：集中梯度于细胞边界区域；通过形态学侵蚀生成边界掩码Mbnd（原掩码减去侵蚀掩码），在边界像素上计算BCE损失：L_bnd = L_BCE(S(Xs)⊙Mbnd, Y⊙Mbnd)。
  - 不确定性加权机制：自适应平衡分割、蒸馏和边界损失；两个可学习标量参数σ1和σ2，总损失L_total = 1/(2σ1^2) * L_seg + 1/(2σ2^2) * L_distill + β * L_bnd + log(σ1·σ2)，β=0.3固定。
- 公式/目标函数/指标定义：
  - L_distill = (1/HW) * Σ_{i=1}^{HW} (σ(Zt_i) - σ(Zs_i))^2
  - L_seg = L_BCE(S(Xs), Y) + L_Dice(S(Xs), Y)
  - L_bnd = L_BCE(S(Xs)⊙Mbnd, Y⊙Mbnd)
  - L_total = 1/(2σ1^2) * L_seg + 1/(2σ2^2) * L_distill + β * L_bnd + log(σ1·σ2), β=0.3
  - Dice = 2|P∩Y|/(|P|+|Y|), IoU = |P∩Y|/|P∪Y|
- 算法细节：
  - 边界掩码生成：对真实掩码Y进行形态学腐蚀，从原始掩码中减去腐蚀结果得到Mbnd
  - 缓存策略：教师前向传播一次，将soft targets写入磁盘，后续学生训练时加载，避免同时加载两个模型
  - 两阶段训练：第一阶段教师推理并缓存，第二阶段学生训练加载缓存
  - 不确定性参数σ1和σ2通过梯度下降与学生权重同时优化，log项防止参数趋近无穷
- 训练/推理细节：
  - 优化器：AdamW，学习率3e-5，5%线性warmup，余弦退火，梯度裁剪0.5
  - 批量大小4，混合精度FP16训练
  - 训练50个epoch，早停机制（patience=10，基于验证Dice）
  - 教师模型冻结，不参与训练
  - 推理时仅需学生模型和核通道图像Xs，无多通道需求

### 2. CAREAgent: Clinical Agent with Structured Reasoning and Tool-Integrated for Order Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.01094v1
- 方法流程：
  - 第一阶段：数据构建。设计代理框架，构建可验证推理轨迹，包含思考、工具调用和答案，对齐临床工作流。
  - 第二阶段：数据过滤。根据格式合规性、订单有效性、临床合理性过滤轨迹。
  - 第三阶段：SFT训练。用过滤后的数据微调基础模型，使其学习推理格式和医学知识。
  - 第四阶段：RL训练。用多维奖励函数（订单准确性、工具使用效率、临床合理性）优化模型，增强复杂临床推理。
- 关键模块/机制：
  - 结构化推理轨迹构建：生成可验证的推理路径，模拟医生决策过程；设计代理框架，使模型依次输出<thought>（分析）、<tool_call>（调用工具如临床评估/搜索）、<answer>（结构化医嘱JSON），轨迹需与真实临床工具使用一致。
  - 多维奖励函数：评估订单准确性、工具使用合理性、临床可行性；包含三个维度：订单匹配度（基于参考订单的索引匹配）、工具必要性（判断工具调用是否必要且充分）、临床合理性（参考指南和禁忌）。
  - 订单冲突检查与优先级分配：确保医嘱之间无药理学冲突，并按紧急程度排序；检查药物相互作用、过敏史和禁忌症，然后分配优先级P1-P5（如P1为最紧急的暂停干扰素）。
- 算法细节：
  - 推理轨迹生成：使用固定格式<thought>...<tool_call>...<answer>，工具调用包括Clinical_Assessment（查询量表/评分）和Search（搜索指南/证据）。
  - 数据过滤规则：格式检查（轨迹必须包含三个标签），订单有效性（JSON结构完整），临床合理性（由临床专家或规则判定）。
  - RL优化：采用策略梯度方法，奖励为多维分数加权和，鼓励生成高匹配、高效用、高合理的医嘱序列。
- 训练/推理细节：
  - SFT阶段：在过滤后的轨迹数据上微调，损失为交叉熵，学习理性格式和基础医学知识。
  - RL阶段：使用PPO或类似算法，奖励函数包含订单匹配得分（基于提示A的规则）、工具使用得分（必要性、充分性和恰当性）、临床合理性得分。
  - 推理时：模型自回归生成<thought>-<tool_call>-<answer>序列，工具调用后返回结果供后续思考使用。

### 3. PathAR: Structure-First Autoregressive Synthesis of Multimodal Pathology Images
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.01543v1
- 方法流程：
  - 阶段1（表征分解）：Dual-VQ tokenizer输入图像x和掩码m，输出结构token序列S和外观token序列A，结构token通过掩码引导的重建损失学习。
  - 阶段2（自回归建模）：IAR transformer以模态标签c为条件，按结构优先顺序自回归预测结构token序列（p(S|c)），然后基于结构token预测外观token序列（p(A|S,c)），不对称注意力可见性禁止外观token影响结构token预测。
  - 推理与合成：给定模态标签c，IAR生成结构token和外观token，通过codebook查询分别解码为掩码m和图像x。
- 关键模块/机制：
  - Dual-VQ tokenizer：将病理图像分解为空间对齐的结构和外观离散token流，减少表征纠缠。；包含两个向量量化器，结构量化器输出结构token，外观量化器输出外观token。结构token的训练通过掩码重建损失监督，外观token捕获模态特异视觉统计。上下采样因子r，潜在网格h×w。
  - Interleaved Autoregressive (IAR) transformer：建模模态条件联合token分布，实现结构优先的自回归生成。；采用不对称注意力可见性：结构token序列使用因果注意力（不依赖外观token），外观token序列自回归预测时注意力同时覆盖已生成的结构token和之前的外观token。整体架构编码为p(S,A|c)=p(S|c)p(A|S,c)。
  - Mask decoder D_seg：从结构token解码生成二进制掩码m。；参数为ψ，编码为p_ψ(m|S)。
  - Image decoder D：从结构token和外观token联合解码生成图像x。；参数为φ，编码为p_φ(x|S,A)。
- 公式/目标函数/指标定义：
  - 联合分布分解：p(x, m | c) = p(m | c) p(x | m, c) （链式法则）
  - 离散潜在变量建模：p_Θ(x, m | c) = Σ_{S,A} p_θ(S|c) · p_θ(A|S,c) · p_ψ(m|S) · p_φ(x|S,A)
  - 变分训练目标（输入信息未提供明确公式，但暗示了ELBO）
  - 重建损失：包含掩码重建和图像重建
  - 先验损失：自回归token预测的交叉熵损失
- 算法细节：
  - Dual-VQ编码：给定图像x和掩码m，分别通过结构编码器和外观编码器得到网格特征，然后分别量化到离散codebook索引。结构编码器额外受掩码监督。
  - IAR注意力：结构token使用标准因果自注意力；外观token的注意力掩码允许关注所有结构token和之前的外观token。
  - 自回归解码：先逐位置生成结构token序列（以模态标签c为条件），生成完所有结构token后，再逐位置生成外观token序列（以结构token和c为条件）。
- 训练/推理细节：
  - 训练阶段1：Dual-VQ tokenizer通过图像重建和掩码重建损失联合训练，不依赖自回归模型。
  - 训练阶段2：IAR transformer以NLL损失训练，预测结构token和外观token序列，使用教师强制（teacher forcing），结构token和外观token的损失分开计算。
  - 推理：从模态标签c开始，IAR自回归生成结构token序列（无外观条件），然后基于完整结构token生成外观token序列。
  - 合成图像-掩码对：将生成的token通过对应的解码器（D_seg和D）重建为掩码m和图像x。

### 5. Does Language Shift Break Medical Vision-Language Models? Indonesian Radiology Visual Question Answering Case Study

- 原文链接：https://arxiv.org/abs/2606.03693v1
- 方法流程：
  - 数据集构建：将VQA-RAD的英语问题-答案对翻译为印尼语，使用自我评估质量控制确保临床意义、术语一致性和答案等价
  - 模型评估：在英语和印尼语设置下评估通用、东南亚多语言和医学特定VLM（0-shot推理）
  - 性能度量：计算严格准确率、归一化准确率、F1 Tokenized、BERT Score和语言稳健性差距（LRG）
  - 失败模式分析：使用自动化管道检测错误类型（yes/no翻转、侧向性翻转、输出语言不匹配、其他）
- 关键模块/机制：
  - IndoRad-VQA数据集：提供印尼语放射学VQA基准，用于评估语言迁移影响；基于VQA-RAD翻译，使用自我评估质量控制保证质量，包含306个图像-问题-答案三元组
  - 语言稳健性差距（LRG）：量化英语和印尼语设置之间的准确率差异；LRG = EN Acc - ID Acc，正值表示印尼语表现下降
  - 自动化错误检测管线：自动分类模型失败模式；对每个问题，比较模型在英语和印尼语下的答案，识别是否出现yes/no翻转、侧向性翻转、输出语言不匹配或其他错误
- 公式/目标函数/指标定义：
  - LRG = EN Acc − ID Acc
  - 严格准确率: 答案完全匹配
  - 归一化准确率: 去除空格和标点后匹配
  - F1 Tokenized: 基于token的F1
  - BERT Score: 语义相似度
- 算法细节：
  - 数据集构建算法：翻译-自评估-过滤循环
  - 失败模式分析：对每个问题对(EN正确, ID错误)自动检测错误类型
- 训练/推理细节：
  - 实验设置：使用英语和印尼语提示，0-shot评估，不进行微调

### 6. ST-ColoNet: Spatio-Temporal Colon Segment Recognition via Hybrid Attention and Edge-Guided Feature Learning
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.28119v1
- 方法流程：
  - 输入：结肠镜视频帧序列（预处理为224x224图像）
  - 第一阶段（Colorlaus模块）：使用ResNet18提取空间特征，并通过边缘检测分支和度量学习（triplet loss）优化特征表示，强调边缘信息
  - 第二阶段（Full-Temp模块）：对空间特征序列应用三种自注意力模式（局部注意力、全局注意力、随机注意力）并行计算并融合，近似全自注意力，聚合全局和局部时序上下文
  - 输出：每个帧对应结肠段分类标签
- 关键模块/机制：
  - Colorlaus模块：空间特征提取与优化；基于ResNet18作为骨干网络，额外引入边缘检测分支提取边缘特征，并通过度量学习（triplet loss）使得同类帧特征更紧凑、异类帧特征更分离，同时优化边缘表示。边缘特征与主特征融合以增强空间辨别力。
  - Full-Temp模块：时序特征聚合；设计三种自注意力模式：局部时序注意力（捕获短期依赖）、全局注意力（全局上下文）、随机注意力（随机稀疏连接，降低计算量）。这三种注意力并行计算，输出拼接后经线性变换得到融合的时序特征，模拟全自注意力的表达能力但计算更高效。
- 公式/目标函数/指标定义：
  - triplet loss: L_triplet = max(0, d(a,p) - d(a,n) + m)，其中a为锚点，p为正样本，n为负样本，m为设定的margin（实验中m=2.0）；总体损失为目标分类交叉熵损失+λ*triplet loss，λ=0.001
- 算法细节：
  - Colorlaus模块：ResNet18提取帧特征，同时边缘检测器（如Sobel）获取边缘图，通过卷积嵌入后特征相加，再经过度量学习优化。训练时每个batch形成三元组。
  - Full-Temp模块：对序列特征应用局部窗口注意力（窗口长度64）、全局注意力（序列所有位置）、随机注意力（稀疏率r=0.1），三种注意力输出经拼接和线性投影得到最终时序表示。
  - 整体框架离线处理：将整个视频分为非重叠窗口（窗口长度64），逐窗口处理。
- 训练/推理细节：
  - 使用Adam优化器，空间特征提取器学习率5e-4，时序特征提取器学习率1e-3。批量大小100。
  - 数据增强：颜色抖动、随机裁剪至224x224、随机镜像翻转。
  - 采用5折交叉验证评估。
  - 预训练权重：ResNet18使用ImageNet预训练初始化。
  - 推理时，对测试视频帧序列进行窗口切分，逐窗口得到分类结果。

### 7. ST-ColoNet: Spatio-Temporal Colon Segment Recognition via Hybrid Attention and Edge-Guided Feature Learning
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.28119v2
- 方法流程：
  - 输入：结肠镜视频帧序列，预处理为224×224图像，应用颜色抖动、随机裁剪和镜像增强。
  - 阶段一（Colorlaus）：使用预训练ResNet18提取空间特征，加入边缘引导模块，并通过三元组损失进行度量学习优化，输出帧级特征向量。
  - 阶段二（Full-Temp）：将帧级特征序列输入到包含局部时序注意力（LTC）、全局时序注意力（Full-LTC）和随机注意力的模块中，组合三种注意力模式以近似全自注意力，输出聚合后的时序特征。
  - 分类：将时序特征通过全连接层进行结肠段分类（5个类别）。
- 关键模块/机制：
  - Colorlaus：空间特征提取与边缘引导优化；基于ResNet18，引入边缘检测分支（如Sobel算子）生成边缘图，与原始特征图融合以增强边缘信息；同时使用三元组损失（margin=2.0, λ=0.001）进行度量学习，使得同一结肠段特征更紧凑，不同段特征更分离。
  - Full-Temp：时序特征聚合与长序列建模；包含三种自注意力机制：局部时序注意力（LTC）关注窗口内（长度64）的相邻帧，全局时序注意力（Full-LTC）关注整个序列，随机注意力（稀疏率r=0.1）随机选择部分位置。三种注意力输出拼接或加权融合，以近似完整自注意力，从而高效捕获局部和全局依赖。
- 公式/目标函数/指标定义：
  - 三元组损失：L_triplet = max(0, d(a,p) - d(a,n) + m)，其中m=2.0，d为欧氏距离。
  - 评估指标：Accuracy (ACC), Precision (PR), Recall (RE), Jaccard Index (JI), F1-score。
- 算法细节：

  - 度量学习：每个batch内随机选择锚点、正样本和负样本，计算三元组损失，与交叉熵损失联合优化。

### 8. GRASP: Plan-Guided Graph Retrieval with Adaptive Fusion and Reranking on Semi-Structured Knowledge Bases
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.30237v2
- 方法流程：
  - 输入查询q，阶段1：LLM生成JSON计划（包含锚点、跳转、目标、风险等级）→ 执行计划：锚点链接到SKB实体（通过稠密嵌入和向量索引），编译为Cypher查询在Neo4j上执行，获得基于锚点余弦得分的图候选排名 → 若目标包含残差文本约束，使用稠密编码器对候选进行重打分并叠加到锚点得分。
  - 阶段2：同时运行多字段稠密检索器mFAR获得文本排名 → 将图排名与mFAR排名通过RRF融合（可选用静态全局权重或动态权重，动态权重基于计划输出的n_cand和risk_level计算） → 生成融合排名。
  - 阶段3：取融合排名前100候选 → 对每个候选序列化（节点类型、文本字段、1跳邻居分组） → 使用微调的LLM重排序器（LoRA适配器+列表式softmax损失）输出每个候选的logit → 将重排序得分与阶段2排名再次通过静态RRF融合，得到最终排名。
- 关键模块/机制：
  - 计划生成器（Planner）：将自然语言查询转换为结构化图检索计划，输出锚点、跳转、目标和风险等级。；使用指令微调的LLM，输入包括角色声明、知识图谱模式、计划结构定义和融合控制块。输出JSON格式计划，包含anchors（实体文本、类型、匹配模式）、hops（图行走路径）、target（目标变量类型和残差文本约束）、risk_level（可选值：no_trade, weak, normal, aggressive）。每个数据集附加特定提示（MAG使用7个元路径模板，Amazon使用6条规则+5个示例，Prime使用19个示例）。
  - 计划执行器（Executor）：执行计划，返回图检索候选及其锚点得分。；锚点链接：每个锚点文本用稠密编码器嵌入，在对应类型的节点向量索引中检索top-K匹配（匹配模式name或doc），得到候选绑定及余弦得分。计划编译：将计划编译为Cypher查询，使用UNWIND展开锚点绑定，MATCH模式遍历关系路径，返回目标节点及每行的锚点得分（路径上所有锚点余弦得分之和，多路径取最大）。在Neo4j上执行查询。
  - 稠密重打分器（Dense Rescorer）：当目标包含残差文本约束时，对图候选进行额外文本相关性打分。；计算relevance_text与候选节点文档嵌入的余弦相似度，将其加到锚点得分上。若relevance_text为空则跳过。稠密编码器在Amazon/MAG使用Qwen3-Embedding-4B，Prime使用SapBERT。
  - 自适应融合（Adaptive Fusion）：融合图排名与稠密检索排名，支持静态和动态权重。；静态RRF：score(c)=w/(k+rank_g(c)) + (1-w)/(k+rank_m(c))，w为全局权重。动态RRF：权重w_hat(q)=w_bucket[b(q)] * m_risk[r(q)]，其中b(q)根据n_cand分桶（[1,10],[11,50],[51,100],[101,500],>500），r(q)为risk_level，w_bucket和m_risk在验证集上网格搜索。若w_hat=0则退化为纯mFAR。
  - 重排序器（Reranker）：对融合候选进行列表式重排序，提升top-1准确率。；使用LLM（具体模型未提，但通过LoRA微调）。每个候选被序列化为包含节点类型、文本字段和1跳邻居（按关系分组，每组最多10个）的文本段。训练时构建G=24个候选的组（1正+23难负），使用列表式softmax损失：cross-entropy识别正样本位置。推理时对阶段2前100候选计算logit，然后与阶段2排名再次静态RRF融合。
- 公式/目标函数/指标定义：
  - 静态RRF融合公式：score(c) = w/(k + rank_g(c)) + (1-w)/(k + rank_m(c))，其中w为全局图权重，k为常数。
  - 动态RRF融合公式：score(c) = w_hat(q)/(k + rank_g(c)) + 1/(k + rank_m(c))，其中w_hat(q) = w_bucket[b(q)] * m_risk[r(q)]，b(q)为n_cand分桶，r(q)为risk_level。
  - 列表式softmax损失：L = -log(exp(logit_positive) / sum_{i=1}^{G} exp(logit_i))，其中G=24，正样本索引已知。
- 算法细节：
  - 锚点链接：使用稠密编码器嵌入锚点文本，在Faiss索引中搜索对应类型的节点，返回余弦相似度最高的K个匹配（K通过阈值动态调整，确保至少有候选）。
  - 计划编译为Cypher：使用UNWIND展开锚点绑定列表，每个绑定作为变量；MATCH子句将hops展开为无向关系模式；RETURN目标节点以及锚点得分（路径上所有锚点余弦得分之和）。若多路径到达同一目标，取最大得分。
  - 稠密重打分：仅当目标relevance_text非空时，对每个候选计算relevance_text嵌入与候选文档嵌入的余弦相似度，加至锚点得分。
  - 静态RRF在验证集上对w和k网格搜索（w∈[0.1,0.9]步长0.1，k∈[10,100]步长10）。动态RRF对每个数据集单独搜索w_bucket和m_risk。
  - 重排序的候选序列化：将每个候选的节点类型、文本字段（如标题、摘要）拼接，并将1跳邻居按关系类型分组，每组最多10个，邻居的节点类型和文本也序列化。
  - 重排序训练：每个查询存储所有正例和top-30难负例（来自阶段2前100中非正例）。每步均匀采样1正+23难负，构成24的组。使用LoRA微调LLM，学习率等超参数详见附录A（输入未提供，不编造）。
- 训练/推理细节：
  - 训练阶段：对于每个查询，从阶段2融合列表的top-100候选池中提取所有正例和top-30难负例。在每步训练中，从存储的集合中均匀采样1个正样本和23个难负样本，形成G=24的列表。使用列表式softmax损失，针对LLM重排序器进行LoRA微调。
  - 推理阶段：阶段3对阶段2的top-100候选用微调后的重排序器计算logit，然后与阶段2的排名进行静态RRF融合（w和k在验证集上优化）。也可使用未微调的重排序器作为零样本版本。
  - 稠密编码器：Amazon和MAG使用Qwen3-Embedding-4B，Prime使用SapBERT。

### 9. FOCUS: Forcing In-Context Object Localization through Visual Support Constraints and Policy Optimization
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.31145v1
- 方法流程：
  - 输入：固定提示+交替支持图像与边界框文本（T-1帧）+查询图像，无类别信息。
  - 阶段一（SFT+BBOX注意力优化）：计算查询token到所有token的平均注意力，构造边界框token二值掩码，计算每个查询token的注意力边际Δi，应用hinge损失Lbbox，总损失LSFT = LLM + βLbbox，仅更新LoRA参数。
  - 阶段二（GRPO）：给定查询，采样G个候选输出，计算IoU奖励和格式奖励，组合得R=riou+rfmt，通过GRPO更新策略（优势组内归一化），仅更新LoRA参数。
  - 输出：预测边界框文本。
- 关键模块/机制：
  - BBOX Attention Optimization：在SFT阶段显式优化查询token对边界框token的注意力，减少语义偏差。；从所有transformer层和头平均注意力矩阵A，提取查询token的行得到P。构造二进制掩码m（边界框token为1），计算每个查询token i的pi+（对边界框token平均注意力）和pi-（对其他token平均注意力），定义边际Δi=pi+ - pi-，使用hinge损失Lbbox = (1/N)∑max(0, μ-Δi)^2，其中μ为超参数。
  - GRPO (Group Relative Policy Optimization)：第二阶段强化学习优化边界框预测精度，避免价值函数估计。；对每个查询q，从当前策略采样G个输出，每个输出获得组合奖励R (IoU+格式)。在组内计算优势Ai = (ri - mean)/std，然后优化GRPO目标J_GRPO = E[ (1/G)∑ min( ratio*Ai, clip(ratio,1-ε,1+ε)*Ai ) - β D_KL(πθ||πref) ]，其中ratio = πθ(oi|q)/πθ_old(oi|q)。
- 公式/目标函数/指标定义：
  - 注意力聚合：A = (1/(LH)) Σ_ℓ Σ_h A^(ℓ,h)
  - 注意力边际：pi+ = (Σ_j P_ij m_j)/(Σ_j m_j), pi- = (Σ_j P_ij (1-m_j))/(Σ_j (1-m_j)), Δi = pi+ - pi-
  - BBOX注意力损失：Lbbox = (1/N) Σ_i max(0, μ - Δi)^2
  - SFT总损失：LSFT = LLM + β Lbbox
  - GRPO目标：J_GRPO(θ) = E[(1/G) Σ_i min(r_i A_i, clip(r_i,1-ε,1+ε) A_i)] - β D_KL(πθ||πref)
  - 优势：A_i = (r_i - mean({r_1,...,r_G}))/std({r_1,...,r_G})
- 算法细节：
  - 注意力掩码构造：根据支持边界框文本的token索引确定m_j。
  - 边际计算：对每个查询token，分别计算对边界框token和非边界框token的平均注意力。
  - hinge损失：超参数μ控制期望边际。
  - GRPO采样：每个查询生成G个候选输出，组内归一化计算优势。
  - LoRA仅更新参数：SFT和GRPO阶段只训练LoRA权重。
- 训练/推理细节：
  - 训练分两阶段，均使用LoRA微调，基础模型为Qwen2-VL-7B。
  - SFT阶段：损失为语言建模损失+β倍BBOX注意力损失，β通过网格搜索确定。
  - GRPO阶段：每个查询采样G个输出，使用组合奖励，优化GRPO目标。
  - 推理时无需注意力损失，显存和FLOPs与基线SFT模型相同。
  - SFT+注意力损失训练显存增加约12%（57.2GB→64.1GB）。

### 11. From Pixels to Words -- Towards Native One-Vision Models at Scale
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.28820v1
- 方法流程：
  - 输入：图像/视频帧和文本。图像经两层卷积（步长16和2）得到视觉token xv，每32×32区域对应一个token；文本经分词器得到xt。
  - 位置编码：对视觉token添加2D RoPE（Native-RoPE），索引为[ti, hi, wi]；文本token仅含时序索引，空间索引置零。
  - 序列化：对于多图像，按文本顺序插入各图像的视觉token序列；对于视频，采样f帧并添加全局前缀和帧时间戳，形成统一序列。
  - 注意力计算：T-HW解耦注意力，Q/K分解为时序、高度、宽度三个子向量，注意力分数为三个内积之和，分别捕获时序依赖和空间结构。
  - 输出：经过统一骨干（初始化自NEO和Qwen3）的自回归生成，预测后续文本token。
- 关键模块/机制：
  - 轻量级卷积嵌入层：将原始像素映射为视觉token序列；两层卷积：Conv1步长16提取patch，Conv2步长2聚合局部特征，GELU激活，加2D RoPE。每张图产生数量自适应的token（每32×32区域一个）。
  - T-HW解耦注意力：同时建模时序关系和空间结构；每个注意力头的Q/K分解为T、H、W三个子向量。T分支建模文本顺序、跨图像关系、帧间依赖；H和W分支建模2D空间位置。注意力分数为三个分支内积之和。
  - Native-RoPE：统一位置编码，区分时序和空间索引；每个token的位置索引为[ti, hi, wi]，ti为时序/顺序位置（跨模态连续），hi/wi为每个图像内的空间坐标（0~图像内位置）。文本token的hi=wi=0。T分支的RoPE基频率高（1M），H/W基频率低（10K）。
  - 统一视觉序列化：将多图像和视频组织为统一token序列；多图像：每张图独立编码，按文本中出现的顺序插入视觉token。视频：采样f帧，帧前加时间戳[τ]，序列开头加全局前缀pglobal（包含时长、帧数、采样率）。所有视觉token共享<T-HW>位置编码。
- 公式/目标函数/指标定义：
  - 视觉嵌入: xv = Conv2(GELU(Conv1(I))) + PE, xt = Tokenizer(T)
  - Q/K分解: qi = [qTi; qHi; qWi], kj = [kTj; kHj; kWj]
  - 注意力分数: sij = ⟨qTi, kTj⟩ + ⟨qHi, kHj⟩ + ⟨qWi, kWj⟩
  - 位置索引: idx_i = [ti, hi, wi]
  - 多图像序列: Xmulti = [xt1, <img>xv1</img>, ..., xtm, <img>xvm</img>, q]
  - 视频序列: Xvideo = [pglobal, [τ1]:<img>xv1</img>, ..., [τf]:<img>xvj</img>, q]
- 算法细节：

### 14. SWARD: Stochastic Window-Attention-Based Relational Distillation for Cross-Architectural Semantic Segmentation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.00999v1
- 方法流程：
  - 输入图像x，分别通过冻结的Transformer教师和可训练的CNN学生提取多尺度特征图{f_i^t}和{f_i^s}。
  - 对每对对应尺度的特征图，通过1×1卷积投影到公共维度，并进行空间重采样（双线性插值）以匹配空间尺寸。
  - 对投影后的特征应用MWAD：将特征划分为随机移位的局部窗口（偏移量每轮训练重新采样），在窗口内计算教师和学生的自注意力图、值嵌入和聚合上下文，并通过损失函数对齐。
  - 同时，学生特征通过PDR模块：为每个类别计算原型（特征均值），并施加类间分离损失和类内紧凑损失。
  - 总损失L_total = αL_task + βL_MWAD + γL_PDR，其中L_task为标准交叉熵分割损失。
- 关键模块/机制：
  - Multi-Scale Windowed Attention Distillation (MWAD)：对齐教师和学生在多个尺度上的局部窗口内注意力关系，传递结构化空间知识。；将重采样后的特征划分为大小为M×M的窗口，窗口偏移量在每次训练迭代时随机生成（从[0, M-1]均匀采样）。在每个窗口内，对特征施加对称的1×1 QKV投影得到查询、键、值，计算注意力图。蒸馏损失包括：注意力损失（KL散度对齐注意力图）、值损失（MSE对齐值嵌入）、上下文损失（MSE对齐经注意力加权的聚合上下文）。多尺度通过在不同特征层执行相同操作实现。
  - Prototype Discriminative Regularization (PDR)：正则化学生特征空间，增强类内紧凑性和类间分离性。；从学生特征图中为每个类别c计算原型p_c（该类所有像素特征的平均）。定义分离损失L_sep = sum_{c1≠c2} max(0, m - ||p_c1 - p_c2||_2)^2，其中m为间隔常数（实验中m=1.3）；定义紧凑损失L_compact = sum_c sum_{i∈c} ||f_i - p_c||_2^2。PDR总损失为L_PDR = λ1 L_sep + λ2 L_compact，实验中λ1=λ2=1.0。
- 公式/目标函数/指标定义：
  - 总损失：L_total = α L_task + β L_MWAD + γ L_PDR，其中α=1.0, β=2.0, γ=1.0。
  - PDR分离损失：L_sep = Σ_{c1≠c2} max(0, m - ||p_{c1} - p_{c2}||_2)^2
  - PDR紧凑损失：L_compact = Σ_c Σ_{i∈c} ||f_i - p_c||_2^2
  - PDR总损失：L_PDR = λ1 L_sep + λ2 L_compact，λ1=λ2=1.0
- 算法细节：
  - 特征投影：教师和学生特征图通过独立的1×1卷积投影到相同维度（实验中为256维），然后通过双线性插值将学生特征上采样到教师特征空间尺寸。
  - 随机窗口移位：在每个训练迭代中，对特征图进行循环移位（shift），移位量随机从[0, window_size-1]均匀采样，然后划分为规则非重叠窗口；计算注意力后逆移位恢复原始顺序。
  - 对称QKV投影：在每个窗口内，对特征应用对称的1×1卷积生成查询、键、值（三者维度相同），使得CNN学生能产生与Transformer教师类似的注意力关系。
  - 多尺度：选择N个中间特征层（对应教师不同分辨率），分别进行MWAD，损失加权求和。
- 训练/推理细节：
  - 训练在单个NVIDIA A100 (80GB) GPU上，使用PyTorch。
  - Cityscapes：学生DeepLabV3+ (MobileNetV3)，教师SAM2.1 Hiera-L + DeepLabV3+头；训练40000迭代，batch size 16，优化器AdamW，初始学习率1e-3，权重衰减1e-4，多项式学习率衰减。
  - 医学图像分割：教师MedSAM2 Hiera-T + ResUNet++头，学生ResUNet++或UNeXt；训练200 epoch，batch size 8，优化器AdamW，初始学习率5e-4，权重衰减1e-4，余弦退火学习率。
  - 损失权重：α=1.0, β=2.0, γ=1.0；PDR内λ1=λ2=1.0，间隔m=1.3。
  - 推理时仅使用学生网络，不引入额外计算开销。

  - Pareto Selection：在多目标优化中平衡效果和支持度，选择非占优解；维护规则种群，每一代根据效果（f1）和支持（f2）两个目标进行非支配排序，保留帕累托前沿个体

### 17. Resolution-free neural surrogates for geometric parameterization and mapping with spatially varying fields
- 区域：quick；分数：6.0

- 方法流程：
  - 输入：原始分辨率参数场 x^(1) 和查询点坐标 {x_i}
  - 多分辨率采样：对 x^(1) 进行双线性插值得到半分辨率和四分之一分辨率副本 x^(1/2), x^(1/4)
  - 特征投影：对各分辨率副本通过 1x1 卷积独立投影到特征空间 ϕ
  - 分辨率对齐：将低分辨率特征插值回原始分辨率得到 ϕ̃
  - 特征拼接：将 ϕ^(1), ϕ̃^(1/2), ϕ̃^(1/4) 沿通道拼接成复合表示 Φ
  - 线性融合：对 Φ 应用共享权重 W 的 1x1 卷积得到统一嵌入 Ψ
  - 编码器-解码器：Ψ 通过边缘感知卷积的 U-Net 处理，编码器逐步降采样，解码器上采样并融合跳跃连接
  - 位移预测：解码器输出位移场 ψ(x)
- 关键模块/机制：
  - 多分辨率特征提取与融合：实现输入分辨率无关性，通过组合粗到细的空间信息提供全局和局部上下文；对输入参数场进行双线性插值得到三个分辨率副本（原始、1/2、1/4），各自通过 1x1 卷积投影，低分辨率特征再插值回原始分辨率后沿通道拼接，最后经共享 1x1 卷积融合为统一嵌入。所有操作与网格尺寸无关。

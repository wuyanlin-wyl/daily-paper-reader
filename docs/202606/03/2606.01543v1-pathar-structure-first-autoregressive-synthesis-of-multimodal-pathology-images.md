## 摘要
多模态病理学中的数据稀缺性促使了统一生成模型的发展，这些模型在保留解剖学一致结构的同时合成模态特定的外观。尽管不同模态的外观统计特性存在差异，但诸如细胞拓扑和组织边界等形态结构在采集协议中大致保持不变。然而，现有方法通常将这些因素建模在同质的token流中，隐式地将结构与外观耦合，并在模态转换下削弱了结构可控性。为解决这一问题，我们提出了病理自回归建模（PathAR），这是一种结构优先的自回归合成框架，显式地将结构和外观分解，用于模态标签条件化的病理生成。PathAR采用双向量量化（Dual-VQ）分词器将样本分解为基于掩码的结构和外观token，并使用具有非对称注意力可见性的交错自回归（IAR）变换器来强制结构到外观的依赖关系。PathAR在异质模态特定外观下稳定了形态，并实现了空间对齐的图像-掩码对生成。大量实验表明，PathAR在基线方法上提升了结构一致性和模态保真度，保持了样本多样性，支持数据稀缺场景下的下游分割任务，并展示了向更细粒度的模态内器官标签变化的可扩展性。

## Abstract
Data scarcity in multimodal pathology motivates unified generative models that synthesize modality-specific appearance while preserving anatomically coherent structure. Although modalities differ in appearance statistics, morphological structures such as cellular topology and tissue boundaries are largely preserved across acquisition protocols. However, existing methods often model these factors within a homogeneous token stream, implicitly coupling structure with appearance and weakening structural controllability under modality shifts. To address this, we propose pathology Autorgressive modeling (PathAR), a structure-first autoregressive synthesis framework that explicitly factorizes structure and appearance for modality-label-conditioned pathology generation.PathAR employs a dual vector quantization (Dual-VQ) tokenizer to decompose samples into mask-grounded structure and appearance tokens, and an interleaved autoregressive (IAR) transformer with asymmetric attention visibility to enforce structure-to-appearance dependence. PathAR stabilizes morphology under heterogeneous modality-specific appearances and enables spatially aligned image--mask pair generation. Extensive experiments show that PathAR improves structural consistency and modality fidelity over baselines, maintains sample diversity, supports downstream segmentation in data-scarce regimes, and demonstrates extensibility to finer-grained intra-modality organ-label variation.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：多模态病理图像生成面临**数据稀缺**问题。不同成像模态（如细胞学、荧光、组织学）外观差异巨大，但底层形态结构（细胞拓扑、组织边界）基本一致。现有生成方法通常将**结构**和**外观**耦合在同一个 token 流中隐式建模，导致在模态切换时**结构可控性弱**，容易出现纹理偏置（texture bias），即外观信号掩盖了微弱的梯度变化，使生成形态失真。
- **整体含义**：本文旨在提出一种能够**显式分解结构与外观**的生成框架，在保持模态特定外观保真度的同时，确保解剖学结构的一致性，并支持从**仅标签输入**联合生成对齐的图像-掩码对，以服务下游分割等结构化任务。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：采用**结构优先**的自回归生成范式，将生成过程显式分解为**结构先验**和**外观先验**，通过非对称注意力可见性强制结构到外观的因果依赖。
- **关键技术细节**：
  1. **双向量量化（Dual-VQ）分词器**：设计两个编码器分别处理掩码（结构）和图像（外观），各自采用独立码本（大小均为1024）进行离散化，得到空间对齐的**结构 token 流 S** 和**外观 token 流 A**。结构 token 通过掩码解码器重建掩码监督训练，外观 token 与结构 token 融合后重建图像，从而实现功能分离。
  2. **交错自回归变换器（IAR）**：将 S 和 A 按空间位置交错排列（`s1, a1, s2, a2, ..., sN, aN`），并通过**非对称注意力掩码**实现：
     - 预测结构 token `si` 时，只能访问历史结构 token `s<i` 和类别标签，**不允许**看到任何外观 token；
     - 预测外观 token `ai` 时，可以访问当前及历史结构 token `s≤i` 以及历史外观 token `a<i`。
  3. **训练与推理**：整个框架采用两阶段训练——第一阶段优化分词器及解码器（重建损失 + 分割损失 + VQ 正则），第二阶段固定分词器，最大化 IAR 的交叉熵损失（对应 ELBO 中的 KL 项）。推理时从类别标签开始，依次生成 S 和 A，再通过码本查找和解码得到最终的图像-掩码对。可选 classifier-free guidance（CFG）提升标签一致性。

### 6. 论文的主要结论与发现
- PathAR 在**多模态病理图像生成**上全面优于 16 种基线：平均 FID-DINOv2 130.552（领先路径专用模型 PathDiff 15.043）、平均 KID-UNI 0.576、平均 KID-DINOv2 0.382。
- **风格保真度**达到平均 Style Score 0.970，在所有模态中最高。
- **结构保真度**：仅用生成图-掩码对训练的下游分割器在真实验证集上平均 Dice 0.923（比第二好的 ControlNet 高 0.025），尤其组织学提升显著（0.909 vs 0.837）。
- **数据增强**：在仅 30 张真实标注数据基础上，加入 PathAR 生成的 400 对样本后，Dice 从 0.827 提升至 0.958（+0.131），且仅用合成数据训练即可达到 0.923。
- **泛化性**：在 PanNuke 的 19 类器官标签条件下，PathAR 依然最优（FID-DINOv2 149.137，KID-UNI 0.273）。
- 消融证实：双流分解、交错 token 顺序、非对称注意力、多模态联合训练均带来显著提升。
- Token 分析表明：结构 token 跨模态距离更小（2.085 ± 0.746），外观 token 距离更大（3.492 ± 1.538），验证了有效分解。

### 7. 优点
- **方法创新性**：首次将自回归模型的结构-外观显式分解引入多模态病理生成，非对称注意力机制巧妙符合“结构决定外观”的因果逻辑。
- **无掩码推理能力**：不需要输入掩码即可联合生成图像-掩码对，填补了标签条件生成中结构可控性的空白。
- **强大且全面**：在图像质量、模态保真度、结构一致性、多样性和下游任务上均达到最优，且参数量小（170.73 M）、推理速度快（0.086 s/图像）。
- **实验设计严谨**：消融实验覆盖所有组件，Token 交换和嵌入空间分析直观验证了分解效果，数据增强实验展示了实际应用价值。

### 8. 不足与局限
- **尺度限制**：目前仅实现 **patch 级**生成（256×256），未能扩展到全切片病理图像（gigapixel）。全切片生成需要处理更大的空间上下文和内存需求，是未来方向。
- **数据规模有限**：主要多模态数据集仅 ~1500 张图像，虽然 PathAR 已表现优秀，但在更大、更多样的病理数据集上的泛化能力有待验证。
- **模型容量探索**：码本大小实验中，当码本从 1024 增大到 2048/4096 时性能下降，说明当前数据规模下码本容量存在上限；若数据量增大可能需要重新调整。
- **未讨论医学伦理与偏见**：如生成内容是否符合真实病理分布、是否会产生误导性伪影等，论文未涉及。
- **与某些基线的对比条件**：部分基线（如 DDPM）使用绝对无条件训练（分离模型），可能略微低估其性能，但整体公平性可接受。

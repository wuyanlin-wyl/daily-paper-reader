## 方向 1：跨实例一致性与鲁棒推理
结合CQC-RAG的跨查询一致性假设与VISA的跨时间实例审计一致性，构建双维度一致性增强的鲁棒推理框架，适用于RAG和多轮对话场景。

### 代表论文

- [CQC-RAG: Robust Retrieval-Augmented Generation via Cross-Query Consistency](https://arxiv.org/abs/2606.13438v1)：针对检索增强生成（RAG）中查询敏感性导致的幻觉问题，提出CQC-RAG框架。该框架基于跨查询一致性假设：正确答案在语义等价但句法多样的查询下置信度稳定，而幻觉不稳定。通过自动重写问题为多样等价查询，构建共享文档池的查询条件推理上下文，并依据答案-证据对的置信度稳定性选择答案。在TriviaQA和MuSiQue上分别提升4.76%和9.12%的精确匹配率，无需外部监督或扩大检索范围。
- [VISA: VLM-Guided Instance Semantic Auditing for 3D Occupancy World Models](https://arxiv.org/abs/2606.13460v1)：针对3D占用世界模型中对象和稀有类错误导致自由空间解释和碰撞检查不准确的问题，提出VISA方法，利用VLM对每个物理对象实例进行结构化语义审计（类别假设、混淆、可靠性等），并通过轨迹传播和蒸馏损失集成到现有模型中，显著提升语义占用mIoU，同时推理无需VLM。

### 共同创新点
- 利用多个查询/实例的一致性假设提高模型鲁棒性
- 通过自动生成的多样本进行置信度评估和选择
- 推理时无需额外监督或复杂模块

### 尚未解决的问题
- 一致性假设仅针对同模态内（查询-查询或时间-时间），缺乏跨模态一致性验证
- 当前方法仅处理离散的查询或实例，未考虑连续的流或在线场景
- 评估指标仅关注最终任务性能，未直接度量一致性的贡献

### 二次创新路线
#### 路线 1：跨模态一致性增强的鲁棒RAG
- 核心想法：将CQC-RAG的跨查询一致性筛选与VISA的实例审计一致性结合，在RAG中不仅对查询变体进行答案稳定性评估，还对检索文档中的实例进行VLM结构化审计，只有双维度一致的答案才被采纳。
- 新问题定义：跨查询-实例一致性RAG：给定一个原始查询，自动生成多个语义等价的查询变体，同时对检索到的文档中的每个物理实例进行VLM结构化审计，要求模型输出的答案在所有查询变体中具有稳定的置信度，且答案所依据的实例审计结果在时间或空间上一致。
- 机制来源：
  - CQC-RAG：通过多查询变体构建共享文档池，基于答案-证据对的置信度稳定性选择答案
  - VISA：对每个物理实例进行VLM结构化审计（类别假设、混淆、可靠性），并通过轨迹传播增强一致性
- 为什么值得做：单一维度一致性（仅查询或仅实例）可能被噪声绕过，双维度冗余校验可显著降低幻觉。
- 理论/数学创新理由：
  - 数学对象：一致性判别的联合优化目标
  - 来源分解：CQC-RAG处理查询层面的一致性（跨查询答案置信度方差），VISA处理实例层面的一致性（跨时间审计标签的Jaccard相似度），但两者未结合
  - 新建模方式：定义联合一致性分数 S = α·S_cqc + β·S_visa，其中S_cqc基于跨查询答案置信度的标准差倒数，S_visa基于跨时间实例审计向量的余弦相似度均值
  - 公式草图：设查询变体集合 Q={q_1,...,q_K}，对每个变体得到答案 a 和对应文档集 D，S_cqc = 1 / (1 + std_{i}(conf(q_i, a)))；对每个文档 d，VISA审计向量 v_d(t)，S_visa = mean_{d∈D} (1 / (1 - cos(v_d(t), v_d(t')))))；联合目标：max_a (α·S_cqc + β·S_visa) 其中α,β为超参数
  - 为什么可能有效：双维度一致性筛选可过滤掉单维度因偶然一致性造成的伪鲁棒，降低检索噪声和幻觉风险，因为当查询变体偶然一致但实例审计不一致时，低S_visa会抑制该答案
- 可验证实验：在TriviaQA和MuSiQue上，对每个问题生成5个查询变体，使用一个轻量VLM（如BLIP-2）对Top-3文档中的实例进行审计，比较原始CQC-RAG与加入VISA审计一致性筛选的版本在准确率和幻觉率上的差异。
- 主要风险：VLM审计增加额外计算开销，且VLM本身可能产生错误审计，导致假阴性；需设计审计错误容忍机制。

#### 路线 2：轨迹传播增强的在线RAG
- 核心想法：借鉴VISA沿轨迹传播结构化审计的思想，将CQC-RAG扩展到多轮对话或流式查询场景，对连续查询的答案及其证据进行时间一致性跟踪，保留随时间稳定的答案。
- 新问题定义：在线RAG一致性基准：在连续查询流中，每个查询依赖于之前的交互历史，模型需输出随时间一致且准确的答案，评测标准关注答案在连续时间步中的平滑性和准确性。
- 机制来源：
  - CQC-RAG：跨查询一致性假设，通过查询变体评估答案稳定性
  - VISA：沿对象轨迹传播结构化审计（类别、可靠性），利用时间一致性增强检测
- 为什么值得做：多轮对话中历史答案可能被后续查询推翻或修正，时间一致性可利用历史信息提高当前答案可靠性。
- 理论/数学创新理由：
  - 数学对象：时间一致性正则化项
  - 来源分解：CQC-RAG无时间维度，VISA有时间维度但用于物理实例跟踪
  - 新建模方式：定义时间一致性损失强制相邻时间步的答案证据审计向量平滑变化，联合监督
  - 公式草图：设时间步t的答案a_t，其对应证据的审计向量v_t = f(a_t, D_t)，定义时间一致性正则项 L_temporal = λ · Σ_t ||v_t - v_{t-1}||^2，总损失 L = L_task + L_temporal，其中L_task为原始RAG的交叉熵损失
  - 为什么可能有效：平滑正则项抑制因瞬时干扰导致的答案跳变，利用历史审计信息稳定当前预测，提升长期推理的一致性
- 可验证实验：构建多轮问答数据集（如MultiSessionQA），每个问题对应多个时间步，比较在线CQC-RAG（无时间正则）与加入轨迹传播的版本在连续答案准确率和变异系数上的表现。
- 主要风险：需要对话历史中的实例轨迹，若对象消失或出现增量，审计传播可能断裂；需设计轨迹初始化与终止机制。

## 方向 2：文本引导的视觉表示学习与语义审计
融合VISA的实例级语义审计与TEDFusion的双曲空间文本驱动对齐，构建层次语义感知和可靠性加权的视觉表示框架，应用于3D占用和图像融合。

### 代表论文

- [VISA: VLM-Guided Instance Semantic Auditing for 3D Occupancy World Models](https://arxiv.org/abs/2606.13460v1)：针对3D占用世界模型中对象和稀有类错误导致自由空间解释和碰撞检查不准确的问题，提出VISA方法，利用VLM对每个物理对象实例进行结构化语义审计（类别假设、混淆、可靠性等），并通过轨迹传播和蒸馏损失集成到现有模型中，显著提升语义占用mIoU，同时推理无需VLM。
- [Text-Driven Fusion for Infrared and Visible Images: Achieving Image Scene Adaptation on Hyperbolic Space](https://arxiv.org/abs/2606.15104v1)：针对红外与可见光图像融合中欧几里得距离度量导致多模态交互和语义层次扭曲的问题，提出文本驱动的双曲流形融合框架TEDFusion。训练时利用BLIP提取的文本提示作为拓扑锚点，在双曲空间中学习视觉-属性对齐，利用庞加莱球的负曲率嵌入层次树以编码粗到细语义；推理时无需文本输入即可自适应调整融合策略。实验表明该方法在基准数据集上优于现有方法。

### 共同创新点
- 利用文本（VLM输出或描述）作为视觉特征学习的语义指导
- 通过结构化先验（审计或双曲空间）增强模型对罕见或困难类别的认知
- 推理阶段无需文本输入，保持部署效率

### 尚未解决的问题
- 文本先验的获取依赖离线VLM，可能存在域偏移
- 结构化审计和双曲空间嵌入是两种独立的语义表示，尚未统一
- 现有方法仅针对特定视觉任务（3D占用或融合），缺乏通用性

### 二次创新路线
#### 路线 1：统一结构化审计与双曲空间对齐的层次语义3D占用预测
- 核心想法：将VISA的实例审计分布作为软标签，与TEDFusion的双曲空间文本嵌入结合，在双曲空间中优化实例嵌入使其接近审计分布对应的类别层次位置，同时利用负曲率约束类别间的层级关系。
- 新问题定义：层次语义3D占用预测：要求模型不仅预测每个体素的语义类别，还输出该体素所属实例在类别层次树中的位置（例如同时预测“动物”和“狗”），评测指标包括层次准确率和树编辑距离。
- 机制来源：
  - VISA：对每个物理实例输出结构化审计（类别假设及概率、混淆可能性），可视为软标签
  - TEDFusion：利用双曲空间嵌入文本提示，庞加莱球的负曲率使父类嵌入靠近原点，子类在外围，自然形成层次树
- 为什么值得做：审计分布蕴含类别不确定性，双曲空间自然编码层次，两者结合可同时提升分类准确性和语义结构理解。
- 理论/数学创新理由：
  - 数学对象：双曲空间中的层次分类损失
  - 来源分解：VISA提供实例级别的类别软分布，TEDFusion提供类别层次的几何先验
  - 新建模方式：将实例嵌入映射到双曲空间，最小化其与审计分布加权类别嵌入之间的双曲距离，同时添加层次正则项强制类别嵌入的径向顺序
  - 公式草图：设实例i的审计分布为p_i(c) （c∈C），类别c的文本提示在双曲空间中的嵌入为h_c（c维），实例i的嵌入为h_i。损失 L = Σ_i Σ_c p_i(c) · d_H(h_i, h_c) + λ · Σ_{c1,c2} max(0, d_H(h_{c1}, h_{c2}) - margin_c1,c2)，其中d_H为庞加莱距离，margin_c1,c2根据类别层次定义（如父子类margin小，兄弟类margin大）
  - 为什么可能有效：双曲距离天然适应层次结构，审计软标签提供类别不确定性，使模型对模糊实例的嵌入位于类别边界，提升对稀有类的鲁棒性
- 可验证实验：在SemanticKITTI数据集上，训练3D占用网络（如MonoScene）加入双曲嵌入层，将VISA审计分布作为监督，对比原始VISA和TEDFusion，在层次分类准确率上与原始方法比较。
- 主要风险：双曲空间训练不稳定，需仔细调节曲率和学习率；审计分布可能噪声大，导致嵌入漂移。

#### 路线 2：可靠性感知的文本驱动图像融合
- 核心想法：在TEDFusion的融合框架中，利用VISA对每个实例输出的可靠性分数，动态调整红外和可见光模态的融合权重，使融合结果更侧重可靠模态。
- 新问题定义：可靠性感知图像融合：输入红外和可见光图像，输出融合图像，要求对每个实例根据VLM审计的可靠性自适应分配模态权重，使得融合图像在视觉质量和任务性能上更优。
- 机制来源：
  - TEDFusion：利用BLIP文本提示在双曲空间中对齐视觉特征，实现场景自适应融合策略
  - VISA：对每个实例输出可靠性分数（0-1），反映VLM对该实例分类的自信程度，可解释为模态质量
- 为什么值得做：VISA的可靠性分数反映了VLM对该实例模态是否清晰的判断，可抑制低质量模态的干扰。
- 理论/数学创新理由：
  - 数学对象：不确定性加权的融合损失
  - 来源分解：TEDFusion仅使用文本语义指导融合权重，未考虑实例级模态可靠性
  - 新建模方式：对每个实例，根据VISA审计的可靠性分数计算模态权重，权重与可靠性正相关，融合特征加权求和
  - 公式草图：设实例i在红外模态的可靠性为r_ir，在可见光模态为r_vis，归一化权重 w_ir = exp(r_ir/T) / (exp(r_ir/T)+exp(r_vis/T))，w_vis=1-w_ir，融合特征 F_i = w_ir · F_ir_i + w_vis · F_vis_i，其中T为温度系数。整体损失 L = ||F - target||^2 + γ·||w - w_prior||^2，w_prior为TEDFusion原始权重
  - 为什么可能有效：可靠性分数作为模态质量的先验，可降低模糊或噪声模态对融合的负面影响，同时保留VLM的语义引导
- 可验证实验：在TNO数据集上，使用VISA（基于BLIP）对每个实例输出可靠性，替换TEDFusion的固定融合权重，对比原始TEDFusion在SSIM、梯度强度等指标上的表现。
- 主要风险：VISA的可靠性分数可能不准，尤其对于未见过的实例；温度系数T需仔细调节。

### 1. Scalable Training of Spatially Grounded 2D Vision-Language Models for Radiology
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2606.20477v1
- 方法流程：
  - 数据构建阶段：从临床PACS收集CT/MR图像和报告，利用LLM（Gemma 3）进行报告提取、VQA对生成和关键词提取，结合自动分割生成空间接地三元组（图像、关键词、掩码/边框）。
  - 预训练阶段：对SigLIP视觉编码器在RefRad2D上进行对比预训练，以适应医学领域。
  - 多任务训练阶段：将预训练后的SigLIP编码器冻结（或可微调），与Gemma-2B解码器组合；输入图像和文本（任务提示），输出文本序列（包括报告、VQA答案、边框坐标token或</seg>分割token）。
  - 推理阶段：根据任务提示生成相应输出，支持报告生成、VQA、边框检测或分割（通过添加</seg> token调用分割头）。
- 关键模块/机制：
  - SigLIP-So400m视觉编码器：将医学图像编码为视觉token序列，供语言解码器处理。；采用SigLIP-So400m架构，输出视觉token Zv，与文本token Zt拼接后输入解码器。为适应医学领域，先在RefRad2D上进行对比预训练，后续训练中可选择冻结或微调参数。
  - Gemma-2B语言解码器：自回归生成文本输出，包括报告、VQA答案和结构化的接地序列。；基于Gemma-2B，接收拼接的视觉和文本token，以自回归方式预测下一个token。训练采用交叉熵损失。支持扩展词汇表，包含坐标token（512个bin）和类别token。
  - token化边框检测模块：通过文本生成方式直接输出边框坐标，无需额外解码器。；扩展词汇表添加坐标token和类别token，模型生成形如 '<p bbox> [LOC] id=<segID> KEYWORD </p>' 的序列。坐标[LOC]表示为离散化的⟨ymin, xmin, ymax, xmax⟩。对同一类别的多个实例采用类别级合并策略，预测该类别的并集边框。
  - 分割头（辅助掩码解码器）：在模型生成</seg> token时，从隐藏状态解码出像素级分割掩码。；借鉴VividMed和SAM，将模型生成</seg> token时的隐藏状态投影为256维提示向量，输入Two-Way Transformer，对图像编码器输出特征进行处理，输出二值掩码。需要额外分割损失（focal+dice）训练。
  - LLMScore评估器：替代传统n-gram指标，利用大语言模型评估报告生成的事实性和语义正确性。；使用Gemma 3 (27B)作为评判者，输入生成的报告和真实报告，要求其在临床事实性和语义正确性上给出1-5分的评分（归一化到[0,1]），并输出简短理由。验证阶段与三位放射科医生评分高度相关（Pearson r=0.977）。
  - G-IoU评价指标：联合评估空间定位和语义匹配质量。；首先计算预测实体和真值实体的文本嵌入余弦相似度进行匹配，然后对匹配对计算空间IoU，以语义相似度加权求和，最后除以预测或真值实体数的最大值，惩罚空间幻觉和诊断遗漏。
- 公式/目标函数/指标定义：
  - 训练目标：L = L_text + λ_seg * (L_focal + L_dice)，当使用分割头时；检测接地仅通过L_text训练。
  - L_text：自回归交叉熵损失，用于下一token预测。
  - L_focal + L_dice：辅助分割损失，处理医学分割中的类别不平衡。
  - 边框检测输出序列格式：<p bbox> [LOC] id=<segID> KEYWORD </p>，其中[LOC]为离散化坐标⟨ymin, xmin, ymax, xmax⟩。
  - G-IoU定义：首先匹配预测和真值实体通过余弦相似度，然后计算加权IoU和，再除以最大实体数。
  - LLMScore：由Gemma 3评估器输出的归一化[0,1]分数。
- 算法细节：
  - 数据生成：使用LLM（Gemma 3）从临床报告中提取关键信息，生成QA对（每张图像8个），并提取关键词和边界框/掩码（通过自动分割工具如TotalSegmentator或nnUNet）。
  - 训练动态采样策略：批次交替来自报告生成、VQA和接地任务，实现多任务平衡。
  - 边框检测：将坐标离散化为512个bin（每个方向），扩展词汇表增加512个坐标token和121个类别token，模型直接以文本形式生成边框。
  - 分割头：解码器接收</seg> token隐藏状态，通过MLP投影为256维提示，再通过Two-Way Transformer与图像特征交互，输出二值掩码。
  - LLMScore计算：使用Gemma 3 (27B)作为评判者，输入格式为“候选报告：... 参考报告：...”，输出分数和理由。
  - G-IoU计算：使用Sentence-BERT或类似模型计算文本嵌入余弦相似度，确定匹配阈值（如0.7），然后计算加权IoU。
- 训练/推理细节：
  - 训练硬件：单张NVIDIA H100 GPU，训练6个epoch，batch size 24，梯度累积12步。
  - 优化器：Adafactor，学习率5e-5。
  - 数据增强：随机缩放裁剪、对比度调整和强度偏移。
  - 视觉编码器策略：先对比预训练适应医学域，然后多任务训练时冻结（减少显存和加速），与微调版本性能相当。
  - 训练数据混合：使用RefRad2D的全部子集（报告、VQA、接地），训练约2.5天。
  - 推理：根据任务提示生成，接地任务可生成边框文本或触发分割头。

### 2. CoMNeT: A MedNeXt-CorrDiff Framework for Volumetric Brain Tumor Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.15305v1
- 方法流程：
  - 预处理：四模态MRI经方向校正、非零体素z-score标准化、裁剪至128×160×112
  - MedNeXt分割：3D编码器-解码器结构，包含ConvNeXt块和GRN，输出三个肿瘤区域概率图
  - 五折集成：对五个fold独立训练的概率图进行逐体素平均
  - CorrDiff残差修正：将MRI、粗概率、粗logits及不确定性图输入，VQ-VAE编码残差，潜在DDPM去噪，解码后门控加到粗logits
  - 后处理：sigmoid阈值化生成二值掩码，轻量形态学处理去除小连通域和填充空洞
- 关键模块/机制：
  - MedNeXt分割骨干：提供初始三维特征表示和概率预测；基于ConvNeXt的3D编码器-解码器，使用深度可分离卷积、逆瓶颈残差块、层归一化，并集成3D GRN模块调节通道响应，增强特征竞争，减少冗余
  - CorrDiff校正扩散模块：后处理阶段修正MedNeXt预测的残差错误；接收MRI、粗概率、粗logits和熵不确定性图，首先通过3D VQ-VAE将残差编码为潜在表示，然后使用DDPM在潜在空间进行200步训练、25步逆采样，解码后得到修正值Δℓ，利用粗概率和不确定性图门控后加到粗logits
  - 五折概率集成：降低单折方差，提升预测稳定性；对五个fold模型输出的概率图先逐体素平均，再阈值化，保留高一致性区域，削弱不稳定预测
- 公式/目标函数/指标定义：
  - z-score标准化：x̂_i = (x_i - μ_Ω)/(σ_Ω + ε)，Ω为非零体素集合
  - Dice系数：DSC_r = 2Σp_{r,i}y_{r,i} / (Σp_{r,i} + Σy_{r,i})
  - DSC++：DSC++_r = 2Σp_{r,i}y_{r,i} / (Σp_{r,i}^2 + Σy_{r,i}^2)
  - MedNeXt损失：L_MedNeXt = L_{DSC++} + L_{BCE}
  - CorrDiff复合损失：L_{CorrDiff} = λ_diff L_diff + λ_recon L_recon + λ_vq L_vq + λ_seg L_seg，其中λ各为1,1,0.25,1
- 算法细节：
  - CorrDiff门控机制：将解码后的修正Δℓ乘以粗概率和不确定性图的组合，仅在高置信度区域应用修正
  - VQ-VAE编码：将残差图压缩到潜在空间，通过向量量化离散化，再传入扩散过程
  - DDPM采样：训练时使用200步扩散，推断时仅用25步反向采样，加速推理
  - 梯度裁剪：最大范数1.0，混合精度训练
- 训练/推理细节：
  - 分阶段训练：先训练MedNeXt（150轮，早停30轮），冻结其权重后训练CorrDiff（50轮，早停15轮）
  - MedNeXt优化器AdamW，学习率1e-4，权重衰减1e-5，batch size=1，梯度累积2步，有效batch size=2
  - 学习率调度：5轮预热后余弦退火，最大150轮
  - 推断时CorrDiff采样25步，输出修正值，门控后加回，经sigmoid得到最终概率

### 3. Not Truly Multilingual: Script Consistency as a Missing Dimension in VLM Evaluation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17188v2
- 方法流程：
  - 数据构建：由专家创建1000个平行实例，每实例包含图像、三脚本问题、四选项、正确答案和推理。
  - 质量校验：两名独立标注者验证语义等价性、答案正确性和脚本准确性，使用PABAK和F1评估一致性。
  - 模型评估：每个实例按脚本单独评估，使用脚本特定指令模板，模型输出正确选项文本。
  - 指标计算：计算各脚本准确率、SCR、转移效率等。
- 关键模块/机制：
  - PuMVR基准：提供严格平行的多脚本评估数据，隔离脚本变量。；1000个实例，每个实例包含图像、问题（三脚本）、选项（三脚本）、正确答案（三脚本）和人类推理。五维标注（语义等价、答案正确、三脚本准确性）经两名独立标注者验证，PABAK≥0.970。
  - Script Consistency Rate (SCR)：衡量模型在所有脚本上同时正确的比例，作为脚本无关的评估指标。；SCR = 1/|I| * Σ_i Π_{s∈S} 1[Correct_s(i)]，其中S={Gurmukhi, Shahmukhi, Roman}。
  - McNemar检验：统计验证脚本对之间性能差异是否显著。；对每个模型的三对脚本（Gur-Shah, Gur-Rom, Shah-Rom）进行McNemar检验，计算p值，确定脚本偏差显著性。
- 公式/目标函数/指标定义：
  - Script Accuracy: Acc_s = 1/|I| * Σ_i 1[Pred_s(i) = GT_s(i)]
  - Script Consistency Rate: SCR = 1/|I| * Σ_i Π_{s∈S} 1[Correct_s(i)], S={Gur, Shah, Rom}
- 算法细节：
  - 评估流程：每个实例进行三次独立评估（每脚本一次），避免跨脚本启动。
  - 模型输入：图像、问题、四个选项（均在同一脚本），使用脚本特定的指令模板。
  - 模型输出：要求输出正确选项的文本（精确匹配）。
- 训练/推理细节：
  - 无训练步骤；仅推理评估。
  - 使用脚本特定的指令模板确保格式一致。

### 4. Training LLMs with Reinforcement Learning over Digital Twin Representations for Reasoning-Intensive Surgical VideoQA
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17279v1
- 方法流程：
  - 输入：手术视频帧序列V={I(1),...,I(T)}和隐式查询Q。
  - 阶段1-初始推理：LLM生成链式推理R0（<think>...</think>），分解查询并识别所需信息。
  - 阶段2-计划生成：LLM输出数字孪生构建计划G（<plan>...</plan>），指定要调用的基础模型及执行依赖DAG。
  - 阶段3-执行计划：根据G调用对应基础模型（如SurgSAM2, DepthAnything2, RASO, OWLv2），构建层次概率数字孪生表示D（<dt>...</dt>），包含帧级、时间窗口级、过程级表示及不确定性估计。
  - 阶段4-基于DT的推理：LLM基于D进行第二次推理R1（<think>...</think>）。
  - 阶段5-答案生成：LLM输出最终答案A（<ans>...</ans>）。
  - 输出：完整rollout序列Y = [R0, G, D, R1, A]及最终答案A。
- 关键模块/机制：
  - 数字孪生表示构造模块：根据计划G调用手术基础模型，从视频帧中提取语义实体及其空间、时间关系，构造结构化的中间表示。；根据G的拓扑顺序执行模型：SurgSAM2做实例分割（输出掩码M、IoU置信度α），DepthAnything2做深度估计（输出深度图Z、标准差σ），RASO做语义标签（输出标签s、置信度β），OWLv2做边界框B。将掩码路径化存储到文本表示中。
  - 层次化组织机制：组织数字孪生表示以适应手术视频的多个时间尺度，提供从即时到长期的上文。；帧级：每个时间t的即时表示D(t)；时间窗口级：滑动窗口W(t)={D(k)|t-w≤k≤t}，通过跟踪id保持目标对应，捕捉短时动态；过程级：用外部LLM压缩长序列，汇总阶段转换和累积工具使用等。
  - 概率属性与不确定性估计：量化感知输出的可靠性，用于后续奖励调制。；SurgSAM2提供预测IoUα(t)_i∈[0,1]；RASO提供语义置信度β(t)_i∈[0,1]；DepthAnything2计算深度标准差σ(t)_i，归一化为σ̂(t)_i=1-σ(t)_i/σ_max；这些作为每个实例的不确定性指标。
  - 奖励函数模块：为RL训练提供信号，评估rollout结构正确性和答案质量，引入临床合理性和不确定性校准。；总奖励R(Y)=R_format(Y)+λ·R_acc(Y)。格式奖励R_format=0（正确顺序）或-1（错误）。准确奖励R_acc=I[match(A,A*)]-I[implausible(A)]，由LLM-as-a-judge判断语义等价和临床不合理；然后调制为R̃_acc=γ·R_acc，γ为相关实例的平均可靠性（加权平均α、β、σ̂）。
  - Group Relative Policy Optimization (GRPO) 训练：使用GRPO优化LLM策略，最大化奖励期望。；在每个训练步，对同一状态采样多个rollout序列，计算每个序列的奖励，然后利用组内相对优势更新策略，无需价值函数模型。
- 公式/目标函数/指标定义：
  - 总奖励函数: R(Y) = R_format(Y) + λ·R_acc(Y)
  - 准确奖励: R_acc(Y) = I[match(A, A*)] - I[implausible(A)]
  - 调制后奖励: R̃_acc(Y) = γ · R_acc(Y)
  - 置信度因子: γ = (1/|R|) * Σ_{i∈R} [ wα·α(t)_i + wβ·β(t)_i + wσ·σ̂(t)_i ]
  - GRPO优化目标（隐含）：最大化组内相对优势（具体公式未给出，但采用标准GRPO算法）
- 算法细节：
  - 计划生成：LLM在prompt中包含可用基础模型的描述，生成DAG指定调用顺序和依赖关系。
  - 数字孪生构建：按拓扑序依次执行模型，将输出参数化（掩码存路径，其他属性如边界框、标签、置信度以文本形式存储），并组织为三层结构。
  - 时间窗口内目标追踪：利用SurgSAM2的时序一致性机制，基于掩码重叠和视觉特征相似度为跨帧实例分配相同tracking id。
  - 过程级汇总：当超出窗口范围时，用外部LLM（如GPT）压缩长时帧为工作流摘要。
  - 奖励计算：调用LLM-as-a-judge判断答案语义等价和临床合理性；根据LLM引用的实例索引集合R，从数字孪生中提取对应不确定性加权平均得γ。
  - GRPO更新：采样n个完整rollout，计算归一化奖励，更新LLM的LoRA适配器参数。
- 训练/推理细节：
  - 训练时：使用GRPO算法，每个状态采样多个rollout（通常4-8个），奖励函数如上，优化LLM参数（通过LoRA微调）。
  - 推理时：LLM自回归生成结构化rollout序列，遇到<plan>标记后暂停，执行预定义的基础模型（通过调用外部API或本地模型），然后继续生成。
  - 基础模型执行是推理时的必要步骤，权重共享（LLM仅需一个实例）。
  - 训练时使用REAL-Colon-Reason数据集，包含2000个问题对。
  - LLM-as-a-judge使用GPT模型进行语义匹配和临床合理性判别。

### 5. Moving Beyond Diversity: Visual Token Pruning as Subspace Reconstruction for Efficient VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18681v1
- 方法流程：
  - 输入：视觉Token嵌入矩阵X_v∈R^{N×d}和文本Token嵌入X_t∈R^{M×d}
  - 初始化：空选中集合S，设置目标Token数k
  - 计算每个Token的反相关性分数：基于CLIP的图像-文本相似度，取负或逆序
  - 迭代选择：对于未选中Token，计算其到当前选中Token列空间的正交投影残差，结合反相关性分数形成综合得分，选择得分最高的Token加入S
  - 输出：选中Token子集X̃_v∈R^{k×d}，后续与文本Token拼接输入LLM
- 关键模块/机制：
  - 子空间重建选择模块：基于RRQR的贪婪子空间逼近，选择投影残差最大的Token以最小化重建误差；给定当前选中Token矩阵̃X_v，计算未选中Token x_i在̃X_v列空间上的投影残差r_i = ||x_i - Π_S x_i||，其中Π_S = ̃X_v^T(̃X_v ̃X_v^T)^{-1}̃X_v。迭代选择r_i最大的Token加入集合，直到达到k个。
  - 反相关性引导模块：基于反相关性现象调整选择偏好，优先保留低图像-文本相关性的Token以保护上下文信息；计算每个视觉Token与文本的整体相关性（如CLIP相似度），定义反相关性分数（如1-归一化相似度）。在子空间重建模块中，综合投影残差和反相关性分数（例如加权求和或排序）决定当前迭代选择的Token。
- 公式/目标函数/指标定义：
  - 原始视觉嵌入矩阵X_v∈R^{N×d}，选择子集S后重建目标：min_S ||X_v^T - Π_S X_v^T||_F^2，其中Π_S = ̃X_v^T(̃X_v ̃X_v^T)^{-1}̃X_v为正交投影矩阵

  - 投影残差：r_i = ||x_i - Π_S x_i||，用于贪婪选择
- 算法细节：

- 训练/推理细节：
  - 完全无需训练：SPARE在推理时对视觉Token直接进行剪枝，不改变模型参数

### 10. CSWinUNETR: Segmentation of Thin Anatomical Structures in Medical Images
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19824v1
- 方法流程：
  - 输入：2D或3D医学图像 I ∈ R^{C_in×H×W}（2D）或类似形状（3D）。
  - Patch Embedding：使用7×7卷积、步长2将图像转换为 token 序列 X^{(0)} ∈ R^{C_0×H/2×W/2}。
  - 编码器：4个阶段，每个阶段包含一个残差卷积细化、两个连续的CSWin Transformer块（第二个块使用循环移位）、以及一个合并层（3×3卷积步长2）进行下采样。每个阶段输出 X^{(t)} ∈ R^{C_t×H/2^{t+1}×W/2^{t+1}}，C_t=2^t C_0。
  - 在CSWin块内：头部被分为两组（垂直和水平条带），分别计算自注意力。第二个块应用循环移位后再进行条带自注意力。
  - 细节增强MS-MHSA：在编码器特征上并行运行多个DWC分支（轴向条带、局部细化、语义上下文、高通细节），通过1×1卷积预测空间融合权重，加权求和得到融合特征 eX^{(t)}。然后使用原始特征X^{(t)}作为Q，融合特征作为K和V进行自注意力（公式1）。
  - SDSConv：在编码器特征图上，对每个空间位置预测M个稀疏控制点的横向偏移和轴向位置，通过高斯RBF插值获得P个位置的偏移，再经距离斜坡缩放后生成蛇形采样轨迹，利用双线性插值采样并聚合。最终作为残差与CSWin块特征融合。
  - 解码器：SwinUNETR风格的反卷积路径，逐步上采样并与编码器特征融合，最后输出分割掩码。
- 关键模块/机制：
  - Shifted CSWin Self-Attention：捕获沿主轴方向的细长结构长程上下文，增强条带间信息交换。；将多头自注意力的头部分为两组，分别沿垂直和水平方向将特征图划分为条带窗口，仅在各自条带内计算自注意力。第二个CSWin Transformer块中，对特征图应用循环移位（cyclic shift），使得条带边界处的 token 被重新分配到相邻条带，然后计算自注意力，再反向移位恢复。
  - Detail-Enhanced Multi-Scale Self-Attention (MS-MHSA)：融合多尺度上下文并增强高频细节，以保护细薄结构信息。；输入特征图 X^{(t)}，构建四个并行轻量级深度可卷积分支：(1) 轴向条带分支：沿水平和垂直方向分别应用条带DWC并求和；(2) 局部细化分支：3×3 DWC；(3) 语义上下文分支：平均池化后接3×3 DWC；(4) 高通细节分支：X^{(t)}减去3×3平均池化结果，再经3×3 DWC。通过1×1卷积预测每位置分支权重，softmax归一化后加权求和得到融合特征 eX^{(t)}。然后使用X^{(t)}作为Q，eX^{(t)}作为K和V，按条带方式计算自注意力（公式1），并加上局部位置编码LePE（3×3 DWC）。
  - Sparse-control Dynamic Snake Convolution (SDSConv)：沿弯曲轨迹稳定地聚合证据，避免累积漂移。；给定特征图F，设置核长度P，轴向支撑点ξ_k = (k - c)/c。在每个空间位置，预测M个稀疏控制点：横向偏移{Δx_m, Δy_m}和轴向位置μ_m（可学习）。通过高斯径向基函数（公式2）插值得到每个支撑点的偏移o_u(k)，其中带宽σ，softmax归一化。引入可学习的距离斜坡函数s_a(|ξ_k|)（公式3）缩放偏移得到最终偏移ô_u(k)。然后对每个方向（水平/垂直）构建蛇形采样轨迹，通过双线性插值采样并聚合P个样本，再与对应方向的DWC结合。两个方向的响应融合后作为残差注入CSWin块。
- 公式/目标函数/指标定义：
  - 条带自注意力公式：O_a = Softmax( (Q_a K_a^T)/√d + M_a ) V_a + LePE(V_a)，其中M_a为条带注意力掩码，LePE为3×3深度可卷积分支。
  - SDSConv偏移插值：o_u(k) = Σ_{m=1}^{M} α_{m,k} Δu_m，α_{m,k} = Softmax_m( -(ξ_k - μ_m)^2/(2σ^2) )，u∈{x,y}。
  - 距离斜坡缩放：ô_u(k) = s_a(|ξ_k|) o_u(k)，s_a(·)为可学习的有界单调递增函数。
  - 训练损失：Dice损失 + 交叉熵损失。
- 算法细节：
  - 循环移位：在第二个CSWin Transformer块前，将特征图沿垂直或水平方向平移一半条带宽度，条带自注意力后反向移位，实现跨条带交互。
  - 空间融合门：通过1×1卷积生成每个分支在每个空间位置的 logits，沿分支维度 softmax 得到融合权重，加权求和。
  - 高斯RBF插值：使用可学习控制点位置μ_m和固定带宽σ（σ=0.5假设），计算每个支撑点ξ_k与μ_m的径向基响应，经softmax得到插值权重。
  - 中心锚定：通过距离斜坡函数s_a(·)抑制远端的偏移幅度，使得靠近核中心的偏移较小，允许远端更大弯曲，防止全局漂移。
  - 蛇形采样：对每个方向（水平/垂直），从核中心沿轴向移动，根据偏移进行双线性采样，得到P个位置的采样值，然后与深度可分离卷积权重逐点相乘并聚合。
- 训练/推理细节：
  - 所有数据集使用相同的网络架构，仅根据输入维度（2D/3D）调整部分设置。
  - 基础嵌入维度C0=48。注意力头数：2D输入为(2,4,8,16)，3D输入为(3,6,12,24)。
  - SDSConv核长度P从浅到深阶段分别为(11,9,7,5)，稀疏控制点数量M=⌊P/2⌋。
  - 训练优化：组合Dice损失和交叉熵损失。
  - 训练后无需任务特定的后处理或拓扑感知损失。

### 15. Spectral Query-Key Product Weight Steering for Training-Free VLM Hallucination Mitigation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20419v1
- 方法流程：
  - 输入: 预训练VLM权重，选定层和query头集，超参数k（抑制模式数）和α（抑制强度）。
  - 步骤1: 对每个选定层和query头，获取其query权重W_q,h和对应共享key权重W_k,g，计算QK乘积 M_h = W_q,h^T W_k,g。
  - 步骤2: 通过经济QR分解计算瘦SVD: M_h = U Σ V^T，其中Σ=diag(σ1,...,σ_r)。
  - 步骤3: 抑制top-k奇异值: Σ^⋆_{ii} = (1-α)σ_i (i∈S), σ_i (i∉S)，重建编辑后乘积 M_h^⋆ = U Σ^⋆ V^T。
  - 步骤4: 计算差值 ΔM_h = M_h^⋆ - M_h，通过闭式更新 ΔW_q,h = (W_k,g W_k,g^T + λI)^{-1} W_k,g ΔM_h^T，其中λ为正则化系数。
  - 步骤5: 更新query权重 W_q,h^⋆ = W_q,h + ΔW_q,h，key权重保持不变。
  - 输出: 编辑后的VLM权重，可直接用于标准推理。
- 关键模块/机制：
  - 瘦SVD分解：高效计算QK乘积的谱分解，避免大矩阵SVD；利用QR分解将d×d矩阵分解为QqRq和QkRk，进而M_h = Qq (Rq R_k^T) Qk^T，只需对r×r矩阵C_h = Rq R_k^T进行SVD，得到左右奇异向量U=Qq Ũ, V=Qk Ṽ。
  - 主导模式抑制：削弱QK乘积中占比最大的低秩方向，减少先验驱动的注意力；对选定的top-k个奇异值应用因子(1-α)进行缩放，通常α=1完全移除，其余奇异值不变。
  - GQA安全查询恢复：将编辑后的QK乘积映射回query权重，同时保持共享key权重固定，兼容Grouped-Query Attention；通过最小化Frobenius范数下的ΔW_q,h，求解线性约束的闭式解，添加岭正则化λ=ε·(1/r)tr(W_k,g W_k,g^T)以保证数值稳定。
  - 对称/反对称分解变体：诊断幻觉信号来源：对称通道（互内容相似性）vs 反对称通道（方向性注意力）；将M_h分解为对称部分S_h = (M_h+M_h^T)/2和反对称部分Ω_h = (M_h-M_h^T)/2，分别对S_h的top-k特征模态或Ω_h的top-k奇异模态进行抑制。
- 公式/目标函数/指标定义：
  - M_h = W_q,h^⊤ W_k,g (QK乘积)
  - M_h = U Σ V^⊤ (瘦SVD)
  - Σ^⋆_{ii} = (1-α) Σ_{ii} for i∈S, else Σ_{ii} (模式抑制)
  - min_{ΔW_q,h} ‖ΔW_q,h‖_F^2 s.t. (W_q,h+ΔW_q,h)^⊤ W_k,g = M_h^⋆ (闭式更新目标)
  - ΔW_q,h = (W_k,g W_k,g^⊤ + λI)^{-1} W_k,g ΔM_h^⊤ (闭式解)
  - λ = ε·(1/r) tr(W_k,g W_k,g^⊤) (岭正则化)
- 算法细节：
  - 使用经济QR分解避免完整SVD：对W_q,h^T和W_k,g^T分别执行QR得到QqRq和QkRk，然后对C_h=RqR_k^T进行SVD。
  - 编辑变体：Sym-only对S_h的top-k特征模进行抑制，Antisym-only对Ω_h的top-k奇异模进行抑制，Sym+Antisym同时抑制两者。
  - 层和头选择：根据每个头QK乘积的Frobenius能量在top-3奇异模式中的占比E_3，选择中间三分之一层（E_3最低）作为编辑位点，保证编辑的外科性。
- 训练/推理细节：
  - 训练：无需任何训练数据、梯度更新或损失优化，完全基于预训练权重进行权重编辑。
  - 推理：编辑后的权重直接用于推理，架构、分词器、图像处理器和解码配置不变，因此推理成本与原始模型完全相同（零推理代价）。

- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.14024v1
- 方法流程：
  - 输入：ViT 主干输出的低分辨率 patch-token 特征图（如 28×28）及目标密集坐标网格（任意分辨率）。

  - 步骤2：对于每个查询坐标，通过逐层查询构建模块，从浅层到深层逐步融合隐藏状态，生成对齐 backbone 特征空间的坐标相关查询特征。
  - 步骤3：将查询特征输入隐式解码器（如 MLP 或轻量 transformer），预测该坐标对应的最终特征向量。
  - 输出：在密集坐标网格上独立评估，得到高分辨率特征图（H×W，特征维度与 backbone 一致）。

  - 隐式特征解码器：将查询特征映射为最终的坐标对应特征。；接收逐层查询构建模块输出的查询特征（可能包含坐标编码），通过一个轻量级 MLP 或单层 transformer 进行解码，输出一个与 backbone 特征维度相同的向量。解码器在训练时与 backbone 联合优化，推理时对每个坐标独立计算。
  - 多尺度特征监督训练：训练 student 模型从降采样输入恢复高分辨率特征。；训练时，teacher 使用全分辨率输入图像通过 backbone 提取特征；student 接收同一图像经降采样并填充至固定输入尺寸后的图像（保持 aspect ratio），然后对 visible 区域（原始图像区域）密集查询，通过 L2 损失最小化 student 输出特征与 teacher 对应位置特征的差异。该策略迫使 student 学习恢复精细空间细节，同时保持与 backbone 特征空间的一致性。
- 算法细节：
  - 隐式解码：使用坐标（x,y）作为条件，通过 learnable positional encoding 与中间隐藏状态进行跨层交互。
  - 逐层融合：从浅层（高分辨率、低语义）到深层（低分辨率、高语义）逐步传递查询特征，每层可能使用注意力或线性变换更新查询。
  - 多尺度监督：teacher 特征从全分辨率输入获得，student 特征从降采样输入生成，两者在原始图像可见区域逐像素计算 L2 损失。
- 训练/推理细节：
  - 训练：使用多尺度特征监督策略。teacher 固定 backbone 参数，student 的 upsampler 参数可学习；输入图像先被下采样（如 0.5×）再填充到 backbone 所需尺寸（如 448×448），student 仅对原始图像区域内的坐标进行密集查询。
  - 推理：输入图像无需降采样，直接送入 backbone 获得低分辨率特征和中间隐藏状态；对任意分辨率的密集坐标网格（例如与输入图像同尺寸）逐点查询，得到高分辨率特征图。

### 21. ScoreGate: Adaptive Chunk Selection for Retrieval-Augmented Generation via Dual-Score Statistical Fusion
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.14269v1
- 方法流程：
  - 输入：用户查询Q；通过双编码器向量检索得到top-N候选块（N=40），每个块关联分数对(si, ri)
  - 分数归一化：对每个查询的候选集，对交叉编码器分数ri进行min-max归一化到[0,1]
  - 阈值应用：使用预计算的τs=0.70和τr=0.08将每个块划分到B1(保留)、B2(融合高阈值)、B3(融合低阈值)、B4(丢弃)四个区域
  - 融合决策：对B2和B3块，计算融合分数fi=0.3*si+0.7*ri；B2块仅当fi≥0.255时保留，B3块仅当fi≥0.15时保留
  - 基数约束：如果保留块数超过MAX-K=10，则按fi降序保留前MAX-K个
  - 输出：最终保留块集C'，传递至生成器
- 关键模块/机制：
  - 双分数阈值推导：从日志统计中确定划分空间的阈值，无需每查询计算；τs取代表性查询样本上top-N候选块的双编码器余弦相似度中位数（0.70）；τr取使假阳性率约5%的交叉编码器分数（0.08），通过保留的验证集计算得到。阈值计算一次，推理时复用。
  - 四区域非对称分区：根据si和ri相对于阈值的关系将候选块分为四个行为不同的区域；B1: si≥τs 且 ri≥τr → 无条件保留；B2: si≥τs 且 ri<τr → 高融合阈值保留；B3: si<τs 且 ri≥τr → 低融合阈值保留（捕获词汇不匹配）；B4: si<τs 且 ri<τr → 无条件丢弃。
  - 加权融合分数与不对称阈值：对双分数不一致的B2和B3块使用融合分数做出保留决策；融合分数fi=α*si+(1-α)*ri，α=0.3（70%权重给ri）。保留阈值不对称：B2需要fi≥0.255（高门槛，因交叉编码器已拒绝），B3需要fi≥0.15（低门槛，因交叉编码器已确认）。α通过F1灵敏度分析确定。
  - 基数上限约束：防止保留块过多，保证生成器输入长度可控；使用min(|C'|, MAX-K)约束，当超出时按fi降序保留前MAX-K个（默认10）。在ARB中仅4.7%的查询触发上限，丢弃的块主要为Irrelevant。
- 公式/目标函数/指标定义：
  - ci = (si, ri)，其中si为双编码器余弦相似度，ri为min-max归一化后的交叉编码器分数
  - F(C) → C' ⊆ C, 1 ≤ |C'| ≤ Kmax (自适应选择函数)
  - τs = 0.70, τr = 0.08 (从日志统计得出的阈值)
  - fi = α·si + (1-α)·ri, α=0.3 (加权融合分数)
  - θB2=0.255, θB3=0.15 (B2和B3的保留阈值)
  - |C'| ← min(|C'|, Kmax), Kmax=10 (基数上限)
- 算法细节：
  - 预处理：从日志中计算全局阈值τs和τr，以及融合权重α和保留阈值θB2、θB3
  - 对于每个查询，双编码器检索top-N（N=40）候选块，交叉编码器重新排序并归一化得到每个块的(si, ri)
  - 对每个块计算fi=α*si+(1-α)*ri
  - 根据si和ri相对于阈值划分区域，并执行保留规则（B1加入，B2/B3根据fi判断，B4跳过）
  - 收集所有保留块的索引到C'
  - 如果|C'| > MAX-K，则按fi降序排序并截取前MAX-K个
  - 返回最终的块集C'
- 训练/推理细节：
  - 阈值和融合参数（τs, τr, α, θB2, θB3）从一组代表性查询日志中离线计算，无需模型训练或微调
  - 推理时ScoreGate仅需对已有分数进行阈值比较和线性融合，不增加模型推理调用，额外延迟约31ms
  - 交叉编码器分数归一化使用每查询min-max缩放，保持内部一致性

  - 方差-协方差正则化：计算批次特征向量的方差和协方差矩阵，方差正则化保持每个特征维度的标准差大于阈值，协方差正则化最小化非对角线元素的平方和

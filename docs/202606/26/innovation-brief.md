### 1. Timage: A Generative Text-in-Image Paradigm for Fine-Tuning Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19944v1
- 方法流程：
  - 输入：图像 x0 和文本查询 q。
  - 构建可容许掩码 Mcand：融合实例分割和显著性图，标记不可覆盖区域。
  - 计算查询相关性热图 Hq：通过冻结VLM的交叉注意力获得。
  - 定义能量函数 E = λzon Ezon + λsty Esty，用于评分候选布局。
  - 区域搜索阶段：通过cSB的条件漂移和投影算子采样放置场 α，确保 α ⊂ Mcand。
  - 外观塑造阶段：通过墨水预算正则化（ink(T)=κ·Length(q)·Scale(α)）和投影欧拉-丸山方案生成字体大小、颜色等外观。
  - 渲染合成图像 x1 = x0 ⊕ T，其中 T 是排版文字。
  - 冻结MLLM推理，K次采样后自一致性投票选出最终答案。
- 关键模块/机制：
  - 可容许掩码（Admissible Mask）：划定文字可放置的可行区域，强制保护前景物体。；通过Mcand = σ(I - [∨ Oi] - γ S)计算，其中Oi为实例掩码，S为显著性图，σ通过阈值二值化。
  - 约束薛定谔桥（cSB）：从噪声到布局的随机最优传输，同时满足约束。；遵循漂移扩散SDE dμt = vθ dt + √(2F(t)) dWt，使用投影欧拉-丸山离散化：μt+Δt = PΩ(μt + vtΔt + √(2F(t))ΔWt)。
  - 区域搜索（Region Search）：生成查询相关的放置场α，保护前景。；cSB第一阶段，漂移vθ学习语义方向，投影PΩ强制空间可行性。
  - 外观塑造（Appearance Shaping）：确定文字的外观参数（字号、颜色等），确保可读性。；使用墨水预算正则化 ink(T)=κ·Length(q)·Scale(α)，通过投影欧拉-丸山求解器优化。
  - 查询自适应墨水预算（Query-Adaptive Ink Budget）：根据查询长度和放置区域自适应调节笔画总量。；目标墨水体积 ink(T)=κ·Length(q)·Scale(α)，κ=80 pixels/character。
  - 自一致性投票（Self-Consistency Voting）：多推理融合，降低布局方差。；对每个图像-查询对采样K=5次，通过多数投票选择最终布局。
- 公式/目标函数/指标定义：
  - 书写能量：E(T; x0, q) = λzon Ezon(α; x0, q) + λsty Esty(β(T))
  - 软对齐项：Esem(α) = -∫ α(u) Hq(u) du
  - 可容许掩码：Mcand(u) = σ(I - [∨ Oi(u)] - γ S(u))
  - 墨水预算：ink(T) = κ · Length(q) · Scale(α)
  - SDE：dμt = vθ(t, μt, c) dt + √(2F(t)) dWt
  - 投影欧拉-丸山：μt+Δt = PΩ(μt + vtΔt + √(2F(t))ΔWt)
- 算法细节：
  - 使用Langevin动力学从能量Ezon中近似采样得到伪目标α*，构建经验分布μ̃1。
  - 训练时通过直通估计器（STE）使梯度反向传播通过非可微投影算子PΩ。
  - cSB中条件c包含{x0, q, Hq, Mcand}，通过交叉注意力将语义特征注入漂移网络vθ。
  - 生成外观时，从默认字体/颜色出发，经投影欧拉-丸山迭代细化。
  - 推理时重复K次独立采样，通过多数投票选择最终布局答案。
- 训练/推理细节：
  - 训练：100个epoch，16块NVIDIA H20 GPU，批次大小128，优化器AdamW（lr=1e-4，权重衰减1e-2），余弦退火学习率调度。
  - 推理：零样本，无需任务特定微调，cSB作为即插即用模块。
  - 自一致性投票：K=5。
  - 墨水预算系数κ=80 pixels/character。
  - 基于PyTorch 2.1，Diffusers 0.24.0，Qwen2.5-VL。

### 2. QG-MIL: A Gated Transformer Aggregator for Domain-Agnostic Multiple Instance Learning in Medical Imaging
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20027v1
- 方法流程：
  - 输入：实例特征袋 B={x_i}_{i=1}^N，x_i∈R^d；输出投影层：h_i = Dropout(RMSNorm(W_p x_i))，H = [h_1; ...; h_N] ∈ R^{N×D}。
  - L个堆叠的门控Transformer块：每个块内进行多头注意力（QKV投影、每头QK归一化、缩放点积注意力、注意力输出门控、输出投影），残差连接+SwiGLU前馈，输出精炼实例嵌入。
  - 门控注意力池化：计算每个实例的得分 a_i = w^T (tanh(W_v h_i) ⊙ σ(W_u h_i))，softmax标准化得α_i，加权求和得袋表示 z = ∑ α_i h_i。
  - 分类头：将袋表示z通过线性层和softmax预测袋标签。
- 关键模块/机制：
  - RMSNorm预归一化：对输入实例特征进行归一化，稳定训练，替代LayerNorm。；使用RMSNorm对投影后的实例特征进行归一化：h_i = Dropout(RMSNorm(W_p x_i))，减少方差。
  - 每头QK归一化：提升注意力计算的稳定性，避免值域过大。；将每个注意力头的查询Q和键K分别进行归一化得到Q_hat和K_hat，再计算缩放点积注意力 S = Q_hat K_hat^T / √d_h。
  - 细粒度注意力输出门控：控制注意力输出特征的信息流，抑制不相关特征，增强关键特征。；对每个注意力头h，通过可学习线性投影W_g,h将注意力输出Z_i,h,:投影到标量（headwise）或保持维度（elementwise），经sigmoid激活得到门控值g_i,h或g_i,h,:，与Z逐元素相乘：O_i,h,: = g_i,h ⊙ Z_i,h,:（headwise）或 O_i,h,: = g_i,h,: ⊙ Z_i,h,:（elementwise）。
  - SwiGLU前馈网络：替换标准前馈网络，增强非线性表达。；FFN(x) = W_d (ϕ(W_g x) ⊙ W_u x)，其中ϕ为SiLU激活函数，W_g、W_u为门控和上投影矩阵，W_d为下投影矩阵。
- 公式/目标函数/指标定义：
  - 输入投影：H = Dropout(RMSNorm(W_p x_i))
  - 注意力计算：S = Q_hat K_hat^T / √d_h, A = softmax(S)
  - 注意力输出门控：z_i,h = W_g,h Z_i,h,:, g_i,h = σ(z_i,h) (headwise) 或 O_i,h,: = g_i,h,: ⊙ Z_i,h,: (elementwise)
  - SwiGLU前馈：FFN(x) = W_d (ϕ(W_g x) ⊙ W_u x)
  - 残差更新：x' = x + Dropout(Attn(Norm(x))), x'' = x' + Dropout(FFN(Norm(x')))
  - 门控注意力池化：a_i = w^T (tanh(W_v h_i) ⊙ σ(W_u h_i)), α_i = softmax(a_i), z = ∑ α_i h_i
- 算法细节：
  - 多头注意力：头数H，每头维度d_h = D/H，将Q、K、V分割为H个头。
  - 门控实现：两种变体——headwise门控（每个头共享标量门控）和elementwise门控（每个特征独立门控）。
  - 残差结构：每个块内使用Pre-norm，即先对输入归一化再进入注意力或前馈。
  - 堆叠层数：默认L=2，Deep变体L=4。
  - 池化：最终使用门控注意力池化（GAP）生成袋表示。
- 训练/推理细节：
  - 损失函数：交叉熵损失
  - 训练轮数：最大150 epoch，早停patience=10（基于验证损失）
  - Dropout：0.25
  - 嵌入维度D：512
  - 优化器：未明确指定，通常为Adam
  - 批次大小：未明确

### 3. CheXpercept: A Benchmark for Evaluating Expert-Level Lesion Perception in Chest X-rays
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.21020v1
- 方法流程：
  - 候选池构建：从MIMIC-ILS和ROSALIA收集异常CXR及其病变掩膜，利用ROSALIA重新推理去除噪声，建立异常CXR+掩膜池和正常CXR池。
  - 专家筛选：六名医学专家手动审查候选池，保留精确追踪边界的掩膜作为最优掩膜，确认无病变CXR作为真正常CXR。
  - 几何信息提取：基于HybridGNet生成的肺野掩膜，通过自定义分区算法将肺部分为20个细粒度子区域，提取位置、大小等几何属性。
  - 子最优掩膜生成：使用SAM3对最优掩膜进行变形，通过自动采样的点提示控制变形方向和幅度（扩展或收缩），操作限制在不相交子区域，生成多个子最优掩膜。
  - 自动QA生成与专家验证：利用元数据（病变存在性、几何信息、掩膜）通过规则算法合成问题-答案对，最后经专家审查修正确保临床标准。
- 关键模块/机制：
  - 半自动基准生成管道：构建高质量、可扩展的基准数据集，减少人工标注瓶颈；包括五阶段：候选池构建（利用MIMIC-ILS和ROSALIA）、专家筛选（六名专家审查）、几何信息提取（20子区域分区）、子最优掩膜生成（SAM3变形）、自动QA生成与专家验证。
  - 基于SAM3的掩膜变形框架：生成包含故意误差的子最优病变掩膜，模拟临床错误用于轮廓评估；以专家筛选的最优掩膜作为初始输入，在目标位置自动采样点提示；点提示极性决定变形方向（正/负对应扩展/收缩），点数量决定变形幅度；操作限制在不相交的子区域以避免几何干扰；对单个最优掩膜最多应用三种变形操作生成多个衍生物。
  - 20个肺部细粒度子区域划分算法：提供标准解剖参考以支持位置描述和子最优掩膜生成；基于HybridGNet生成的肺野掩膜，与医学专家共同设计分区算法：将肺部分为基本的上、中、下区，与内侧、中间、外侧区域交叉，额外划分肋膈角作为独立区域，共20个子区域。
- 公式/目标函数/指标定义：
  - Stage-level accuracy (%): 模型成功通过某阶段的序列比例，对于含多子问题的阶段（Stage 3和4），必须所有子问题回答正确才算通过。
  - Depth: 在E2E设置下，模型在首次感知错误前连续正确回答的平均阶段数。
- 算法细节：
  - 子最优掩膜生成：输入最优掩膜、点提示（位置与极性）至SAM3，SAM3输出变形后的掩膜。点提示采样策略：确定与最优掩膜重叠的不相交子区域，为每个区域分配扩展或收缩操作，并设置不同点数量以控制幅度。
  - 自动QA生成：规则算法将元数据映射到预定义文本模板，确保可扩展性和语义一致性。
  - 评估设置：E2E设置中，某阶段失败则后续阶段计为错误；OP设置中，用正确答案覆盖历史中的错误答案以隔离各阶段能力。
- 训练/推理细节：
  - 针对14个VLM进行基准测试，包括4个专有模型（Gemini-3.1-pro, Gemini-3.1-flash, GPT-5.4, GPT-5.4-nano）和10个开源模型（通用：Qwen3.6-27B, Qwen3.5-122B, GLM-4.6V, InternVL3.5-38B, Gemma4-31B；医疗：MedGemma-27B, MedGemma1.5-4B, HuatuoGPT-Vision-7B, Lingshu-32B, Hulu-Med-32B）
  - 开源模型使用贪心解码，专有模型使用默认温度1.0；Qwen系列禁用深度思考模式以避免推理延迟。

### 4. A Multi-Agent Audit Framework for High-Stakes Reasoning: Evaluation and Interpretability in Clinical Mental Health Screening
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.21123v1
- 方法流程：
  - 阶段1 - Perception Agent：输入为清洗后的患者转录文本，输出结构化Symptom Summary（提取绝望、情绪不稳定等核心抑郁指标）
  - 阶段2 - Knowledge Agent：输入为Symptom Summary，通过RAG检索DSM-5标准知识库（top-k=3，nomic-embed-text语义检索），输出相关诊断标准
  - 阶段3 - Reasoning Agent：整合感知证据和检索知识，执行Chain-of-Thought推理，输出可解释诊断理由和预测PHQ-8分数
  - 阶段4 - Audit Agent：审查前序推理逻辑与原始对话一致性，检测幻觉并修正，输出最终可靠诊断
- 关键模块/机制：
  - Perception Agent：提取抑郁相关行为与情绪信号；基于LLM直接处理经过去噪和参与者过滤的文本，识别核心抑郁指标（如绝望、情绪不稳、社交退缩），输出结构化摘要
  - Knowledge Agent：提供临床标准知识支撑；采用RAG机制，使用nomic-embed-text模型对Symptom Summary进行语义嵌入，从预定义的DSM-5指标库中检索top-3相关内容，整合到推理上下文
  - Reasoning Agent：执行多步临床推理并生成分数；利用Chain-of-Thought提示，结合感知证据和检索知识，逐步分析症状严重性及其交互作用，输出诊断理由及PHQ-8回归预测
  - Audit Agent：验证推理一致性与可靠性；将最终推理与原始对话及检索知识交叉验证，自动检测逻辑矛盾、幻觉或证据不足，必要时修正输出（Audit Correction Rate指标量化）
- 公式/目标函数/指标定义：
  - MAE = 1/N Σ|y_i - ŷ_i|（预测PHQ-8分数与真实标签平均绝对误差）
  - PHQ-8分数范围 [0, 24]，回归任务
- 算法细节：
  - 所有智能体使用相同开源LLM（LLaMA-3.1/Qwen2.5/DeepSeek-R1），通过LangChain编排顺序执行，固定温度0.2
  - Knowledge Agent使用nomic-embed-text嵌入模型进行语义检索，top-k=3
  - 单智能体基线：单个LLM直接处理原始转录，无模块分解和外部知识
  - 消融实验配置：Full Pipeline（所有智能体）、Audit（无Knowledge）、Knowledge/No-RAG（无RAG）、Basic（仅有Perception+Reasoning）
- 训练/推理细节：
  - 推理模式：零样本，无参数微调或梯度更新
  - 本地部署（Ollama v0.6.2）确保数据隐私，符合HIPAA/GDPR/FDA GMLP
  - 文本预处理：去噪（去除时间戳、填充词、重复）、过滤采访者话语、排除不完整会话（保留184个有效会话）

### 7. EnTrust: Modeling Inter-Modal Conflict for Trustworthy Multimodal Medical Image Analysis
- 区域：deep；分数：9.0

### 18. Mask to Concept: Auto-Promptable SAM3 via Efficient Test-Time Concept Embedding Search for Few-Shot Annotation

- 原文链接：https://arxiv.org/abs/2606.26711v1
- 方法流程：
  - 阶段1：初始标注——用户使用几何提示（如框或点）通过SAM3标注少量样本，获得初始带标注图像-掩码对。
  - 阶段2：概念搜索（M2C）——输入当前迭代的标注样本，冻结SAM3全部参数，初始化概念嵌入E为全零向量，通过梯度下降优化E，最小化分割损失，得到更新后的E。
  - 阶段3：自动分割——使用更新后的概念嵌入E（结合文本提示编码TEnc(T)），对剩余未标注图像执行SAM3推理，得到预测掩码。
  - 阶段4：不确定性评估（HUE）——对每个预测掩码计算混合不确定性UHU，包括预测熵UENT和概念-几何提示不一致性UCGPI。
  - 阶段5：样本分流——根据不确定性得分排序，将UHU > τ的样本划分为高不确定性（硬样本），UHU ≤ τ的划分为低不确定性（易样本）。
  - 阶段6：人工校正与反馈——高不确定性样本由人工修正，修正后的掩码作为下一迭代的标注样本；低不确定性样本可选早期退出，不再参与后续迭代。

- 关键模块/机制：
  - Mask to Concept (M2C) 模块：从少量标注样本学习数据集特定的概念嵌入，使SAM3能自动分割未标注图像；引入一个可学习的向量E，修正原始文本提示编码，形成最终概念嵌入TEnc(T)+E。在每次迭代中，固定SAM3骨干，仅优化E，通过梯度下降最小化分割损失（IoU损失+交叉熵损失）。优化公式：Et = Et-1 - η * 梯度平均(预测掩码与真值掩码的Lseg)。E初始化为全零，搜索步长η=5e-4，余弦衰减至5e-6。优化器为AdamW。
  - 混合不确定性估计（HUE）模块：量化预测掩码的不确定性，筛选出需要人工校正的硬样本和可提前退出的易样本；由两个子度量组成：1) 预测熵UENT——计算预测掩码中像素级熵，仅考虑局部熵大于0.8的模糊像素集Ω，取Ω内平均熵；2) 概念-几何提示不一致性UCGPI——将概念驱动的预测掩码转换为边界框，用该框作为几何提示输入SAM3得到几何驱动掩码，计算两个掩码的IoU，UCGPI=1-IoU。最终混合不确定性UHU=UENT+UCGPI。阈值τ=0.6用于区分硬/易样本。
- 公式/目标函数/指标定义：
  - 概念嵌入更新：Et = Et-1 - η ∇_{Et-1} (1/|D_label| Σ L_seg(SAM(x, TEnc(T)+Et-1), y_label))
  - 预测熵：UENT = (1/|Ω|) Σ_{i∈Ω} H(pi)，其中H(pi) = -[pi log pi + (1-pi) log(1-pi)]，Ω = {i | H(pi) > 0.8}
  - 概念-几何提示不一致性：UCGPI = 1 - IoU(ypred, ybox)
  - 混合不确定性：UHU = UENT + UCGPI
- 算法细节：
  - 梯度搜索：在每次迭代中，从当前标注集D_label随机采样，计算预测掩码与真值掩码的IoU损失和交叉熵损失之和，反向传播更新概念嵌入E
  - 不确定性计算：对每个预测掩码，像素级熵超过0.8的像素被选入Ω，计算平均熵；同时将掩码转边界框，用SAM3几何提示分支再次预测，计算两掩码IoU
  - 样本排序与分流：按UHU降序排列，取前|D_label|个高不确定性样本进行人工校正，其余硬样本保留在未标注池，易样本（UHU≤τ）可选早期退出
- 训练/推理细节：
  - 训练时冻结SAM3骨干的所有参数，仅优化概念嵌入E（可训练参数极少）
  - 推理时：使用M2C搜索得到的概念嵌入E（无需人工文本提示）作为SAM3的文本提示编码的一部分，实现自动分割
  - 每个NVIDIA RTX 4090 GPU单卡执行，优化器AdamW，搜索步长η=5e-4余弦衰减至5e-6

  - 步骤1（激活记录）：对每个样本j，记录SAE激活张量：视觉patch V(j) ∈ R^{P×ω}（P=576=24×24），文本token T(j) ∈ R^{Nj×ω}；计算平均激活向量 ar{V}^{(j)} ∈ R^ω 和 ar{T}^{(j)} ∈ R^ω
  - 步骤2（样本选择）：对于每个SAE神经元k，选择使 ar{V}_k^{(j)} 最大的前5个样本（视觉）和使 ar{T}_k^{(j)} 最大的前5个样本（文本）
  - 步骤3（假设提取）：对视觉样本，将非激活patch黑掩码，保留激活patch，连同问题-答案对输入外部VLM（LLaVA-72B）生成视觉概念假设；对文本样本，将激活token用括号高亮，连同原始图像输入外部VLM生成文本概念假设
  - 步骤4（评估与分类）：使用CLIP ViT-B/32和ALIGN计算假设与对应数据的对齐相似度（模糊非激活patch，保留文本序列），排名在top-n内则视为有效；对同时具有视觉和文本假设的神经元，计算两假设的余弦相似度，若>0.8则判定为多模态，否则归属于对齐分数更高的模态
  - 输出：每个SAE神经元的模态标签（视觉/文本/多模态）及对应的概念假设
- 关键模块/机制：
  - 稀疏自编码器（SAE）：将VLM的隐藏层激活投影到稀疏潜在空间，提供可分离的神经元激活，用于概念定位；基于Top-k激活（k=256），潜在维度ω=2^17=131072，训练在LLaVA-NeXT-8B的第24个transformer层的冻结嵌入上
  - 概念假设提取器（外部VLM）：根据SAE神经元激活的样本生成人类可解释的概念描述；使用LLaVA-72B作为解释器；对视觉：输入黑掩码图像+问题-答案对；对文本：输入高亮token的句子+对应图像；从每个top-5样本提取概念，然后总结为单一假设
  - 假设-数据对齐评估器（CLIP/ALIGN）：定量评估概念假设与原始数据的一致性，并用于模态分类；使用CLIP ViT-B/32和ALIGN；对视觉假设：输入模糊非激活patch的图像（替代黑掩码以提高稳定性）；对文本假设：输入原始token序列；计算相似度矩阵，取每个假设在其生成数据上的排名
  - 多模态神经元分配模块：根据视觉假设和文本假设的语义一致性决定神经元是否为多模态；使用CLIP/ALIGN文本编码器分别编码视觉假设h_vis和文本假设h_text，计算余弦相似度；若两者均超过阈值τ=0.8，判定为多模态；否则归属分数更高的模态
- 公式/目标函数/指标定义：
  - 平均视觉激活：ar{V}^{(j)} = (1/P) Σ_{i=1}^P v_j^{(i)}
  - 平均文本激活：ar{T}^{(j)} = (1/N_j) Σ_{i=1}^{N_j} t_j^{(i)}
  - 相似度矩阵：对于每个假设与所有数据样本，计算CLIP/ALIGN得分，假设在自身数据上的得分排名在top n内视为有效（n=1..5）
  - 多模态判定：sim(h_vis, h_text) = cosine(h_vis_embed, h_text_embed) > τ (τ=0.8)
- 算法细节：
  - 激活归一化：对每个样本j，分别计算视觉patch和文本token的平均激活向量（除数量归一化）
  - Top-5样本选择：对每个SAE神经元k，从所有样本中选取平均激活值最大的5个视觉样本和5个文本样本
  - 视觉输入构建：将非激活的patch像素置为黑色（或后续改进为模糊），保留激活patch区域，同时附加该样本的问答文本
  - 文本输入构建：将激活的token用方括号[]括起来，并附带对应图像
  - 模糊掩码改进：在评估阶段，为了CLIP/ALIGN稳定性，将非激活patch进行高斯模糊而非全黑
  - 排名评估：对每个假设，计算其与所有数据样本（模糊图像或文本）的相似度，得到相似度矩阵；对于假设自身的生成数据，若其得分排名在前n（1~5）内，则假设有效
  - 多模态标签分配：对同时有视觉和文本假设的神经元，计算两个假设的文本嵌入（来自CLIP/ALIGN文本编码器）的余弦相似度；若两者均>0.8，则标记为多模态；否则比较各自假设-数据对齐分数，取高分者对应的模态
- 训练/推理细节：
  - SAE为预训练模型：使用Top-k激活（k=256），潜在维度ω=2^17，训练于LLaVA-NeXT-8B的第24层冻结嵌入
  - 概念提取推理时：使用LLaVA-72B作为外部解释器（不微调）生成假设
  - 评估使用CLIP ViT-B/32和ALIGN（冻结权重）
  - 所有实验在2张NVIDIA H100 GPU上运行，一次完整框架运行约30小时
  - 仅针对前5000个SAE神经元进行分析（与基线一致）
  - 数据集：LLaVA-NeXT前15%子集（VQA格式，含图像、问题、答案）

### 26. When Global Gating Is Enough: Admission-Time Hubness Control in Anisotropic Vector Retrieval Systems

- 方法流程：
  - 输入：候选文档d的嵌入向量，哨兵查询集Q={q_1,...,q_M}，每个哨兵j的阈值τ_j（其第k近邻相似度），预算θ（校准得1%假阳性率）
  - 计算候选项与每个哨兵的内积⟨d, q_j⟩，若大于τ_j则计数
  - 计算全局集散得分h(d) = 计数/M
  - 若h(d) ≤ θ则准入，否则隔离（标记审查）
  - 增量维护：插入/删除时更新受影响哨兵的top-B缓冲区，并更新τ_j
- 关键模块/机制：
  - 全局门控评分模块：计算候选项的全局集散得分；对每个哨兵q_j，计算内积⟨d, q_j⟩并与预先存储的阈值τ_j比较，统计超过阈值的哨兵数量，除以哨兵总数M得到h(d)。复杂度O(Md)。
  - 阈值维护模块：增量维护每个哨兵的动态阈值；每个哨兵j维护一个缓冲区B_j，存储当前与其最相似的top-B个文档的相似度和id（B=k+c，k为检索参数）。插入文档d时，对每个哨兵j，若⟨d, q_j⟩大于B_j中最小值，则替换并保持有序，更新τ_j为第k小相似度。删除时，从B_j移除并检查是否需要重新填充（当|B_j|<k时触发一次全扫描重新填充，摊销常数时间）。
  - 准入决策模块：根据得分和阈值决定是否允许文档进入索引；比较h(d)与预校准的阈值θ（通过独立校准集在1%假阳性率下确定）。若h(d)≤θ则准入，否则隔离。针对批量注入攻击，还辅助有速度监视器等。
- 公式/目标函数/指标定义：
  - 全局集散得分：h(d) = (1/M) * Σ_{j=1}^{M} 1[⟨d, q_j⟩ > τ_j]
  - 阈值τ_j：哨兵j的当前第k近邻相似度（由缓冲区动态维护）
  - 域感知门控（备用，论文显示无益）：z(d) = max_t (s_t(d) - med_t) / max(1.4826 * MAD_t, 1/n_t)，其中s_t(d)为在主题t上的本地集散率
- 算法细节：
  - 算法1：候选项评分和准入。输入候选d、哨兵Q、阈值{τ_j}、预算θ。输出准入或隔离。步骤：初始化h=0，遍历所有哨兵，若⟨d, q_j⟩ > τ_j则h+=1，最后h/=M，若h≤θ则准入否则隔离。
  - 算法2：增量阈值维护（插入/删除）。插入：遍历哨兵，若⟨d, q_j⟩大于哨兵缓冲区当前最小值，则将d插入缓冲区并保持top-B，更新τ_j为第k项。删除：扫描缓冲区找到x，移除，若缓冲区大小小于k则触发一次全扫描重新填充（罕见），否则直接更新τ_j。
  - 哨兵集M=5571（一半查询+500个簇中心），缓冲区大小B=k+c，其中k=10，c=40。
  - 预算θ通过5,000文档的校准集在1%假阳性率下确定。
  - 近似索引（HNSW）下，评分成本平坦至10^6向量，1.2%决策翻转（无攻击）。
- 训练/推理细节：
  - 无训练过程，所有编码器（如bge-large-en-v1.5）为预训练模型，嵌入固定。
  - 哨兵阈值τ_j从干净语料库中通过精确kNN计算获得，之后增量维护。
  - 推理时，每个候选文档的评分与准入决策在插入路径上同步执行。
  - 使用MPS后端在Apple Silicon上运行，无额外训练步骤。

### 27. QueryGaussian: Scalable and Training-Free Open-Vocabulary 3D Instance Retrieval
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.19733v1
- 方法流程：
  - 阶段1: Render-and-Map: 渲染多视图图像并记录每个像素的最大权重图（存储贡献最大的高斯索引）。

  - 阶段3: Adaptive Instance Clustering with Temporal Fusion: 利用跨视图时间一致性过滤噪声，然后进行多阶段密度聚类，输出紧凑的3D实例分割。

  - 自适应实例聚类与时间融合（Adaptive Instance Clustering with Temporal Fusion）：去除初始候选集中的浮动体和重建伪影，提高实例精度。；首先进行增量跨视图过滤：利用时间一致性，例如统计高斯在多个视图中的出现频率，剔除低频噪声。然后进行多阶段自适应密度聚类：可能先进行初始聚类，选择最紧密的簇，再细化聚类，直到得到紧凑的实例集。
- 公式/目标函数/指标定义：

  - 最大权重高斯索引: idx_max(p) = argmax_{i∈N(p)} ω_{i,p}
- 算法细节：

  - 关联策略: 每个像素只关联一个高斯（最大权重），避免了深度排序的歧义。
  - 时间融合: 可能采用跨视图投票或频率统计剔除出现次数少的高斯。
  - 多阶段自适应聚类: 先以初始聚类（如DBSCAN）获得候选簇，然后选择最紧密的簇作为种子，再细化聚类参数，直到收敛。

  - 推理时渲染多视图并执行实例级查询机制、时间融合与聚类，无需任何微调或参数更新。

### 28. Single-Stage Hierarchical Rectification for Weakly Supervised Histopathology Segmentation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.20250v1
- 方法流程：
  - 输入：图像及图像级标签（多标签）。
  - 特征提取：使用ResNet38骨干网络提取多层特征，获取浅层特征Flow（C×H×W）和深层特征Fhigh（D×h×w）。
  - 全局语义校正（GSR）：对Fhigh进行全局平均池化得到vg，通过MLP+Sigmoid生成通道注意力向量wsem，对Flow进行通道级加权得到Fsem。
  - 上下文均匀化（CH）：对Flow应用大核深度可分离卷积（K×K，K=15），得到空间平滑特征Fsmooth。
  - 特征融合：通过零初始化残差连接结合原始Flow、Fsem、Fsmooth，得到校正后特征^Flow = Flow + γs Fsem + γc Fsmooth。
  - 多尺度CAM生成：对校正后的中间特征和最终高层特征应用1×1卷积，生成S个尺度的CAM（Ms）。
  - 损失计算：对每个尺度CAM进行GAP得到logits ps，使用多标签软边界损失平均（公式5）。
  - 推理：加权融合多尺度CAM，经上采样和归一化得到最终激活图Mfinal，逐像素argmax得到分割掩码。
- 关键模块/机制：
  - 层级特征校正模块（HFRM）：在前向传播中利用深层语义和空间上下文净化浅层特征，替代传统的后处理CAM修正。；包含两个分支：全局语义校正（GSR）和上下文均匀化（CH）。GSR使用深层特征经GAP、MLP、Sigmoid生成通道注意力，抑制不可能类别的通道；CH使用大核深度可分离卷积（K=15）平滑空间，消除孤立离群像素。最后通过零初始化残差连接相加。
  - 全局语义校正（GSR）：利用高层全局上下文抑制浅层特征中不属于图像类别的通道，消除类别级的错误激活。；对深层特征Fhigh进行GAP得到全局向量vg，通过两层MLP（中间维度D/8）和Sigmoid得到通道注意力权重wsem ∈ [0,1]^C，然后与浅层特征Flow逐通道相乘：Fsem = Flow ⊙ wsem。
  - 上下文均匀化（CH）：通过空间平滑强制局部一致性，消除有效类别内的空间离群点。；对浅层特征Flow施加K×K深度可分离卷积（K=15），得到Fsmooth = Conv_{K×K}^{DW}(Flow)。该操作使每个像素聚合其邻域信息，孤立离群像素被周围主导类别同化。
  - 零初始化残差连接：将校正特征渐进式地整合到预训练骨干中，避免梯度冲击。；最终校正特征^Flow = Flow + γs Fsem + γc Fsmooth，其中γs和γc初始化为0的可学习参数，使网络初始行为与标准CNN一致，逐步适应校正特征。
- 公式/目标函数/指标定义：
  - 通道注意力生成: wsem = σ(W2 δ(W1 vg))
  - 语义校正: Fsem = Flow ⊙ wsem
  - 空间平滑: Fsmooth = Conv_{K×K}^{DW}(Flow)
  - 最终校正特征: ^Flow = Flow + γs Fsem + γc Fsmooth
  - 多标签软边界损失: L_cls = (1/S) Σ_{s=1}^S [ -(1/K) Σ_{k=1}^K ( y_k log(σ(p_{s,k})) + (1-y_k) log(1-σ(p_{s,k})) ) ]
  - 推理融合: Mfinal = Σ_{s=1}^S α_s · Norm(Up(Ms))
- 算法细节：
  - 采用ResNet38骨干，提取多个尺度特征。
  - GSR分支：对深层特征（例如pool5）进行GAP，经过MLP（中间隐层维度D/8）和Sigmoid，得到与浅层特征通道数相同的注意力权重，逐元素相乘。
  - CH分支：对浅层特征应用K=15的深度可分离卷积，stride=1，padding保持尺寸。
  - 两个分支的校正特征分别乘以可学习标量γs和γc（初始化为0），再与原始浅层特征残差相加。
  - 对每个尺度（例如S=4）的特征图应用1×1卷积生成K分类别图Ms，然后GAP得到logits。
  - 总损失为所有尺度多标签软边界损失的平均。
  - 推理时，将各尺度CAM上采样至相同尺寸，加权融合（αs为可学习权重或固定），归一化，取argmax。
- 训练/推理细节：
  - 训练：单阶段端到端，仅使用图像级标签。优化器：SGD，初始学习率1e-2，多项式衰减。骨干ResNet38预训练于ImageNet。
  - 推理：融合多尺度CAM，逐像素argmax得到分割掩码。无后处理。
  - 训练时间减少2-5倍（相比多阶段方法）。
  - 推理延迟9.10ms每patch（RTX 3090）。

  - Margin Reward：扩大正负样本相似度差距；计算查询与所有负样本的相似度，取最难负样本（最高相似度），奖励鼓励正样本相似度减去最难负样本相似度大于阈值δ：R_Margin = max(0, cos(q,cp) - max_j cos(q,c_nj) - δ)。
  - Ranking Reward：优化正负样本排序及负样本内部排序；基于排序位置加权：第一项鼓励正样本排到靠前位置（s(r) * 1/(1+log r)），第二项惩罚高相似度负样本（-γ Σ_{k≠r} s(k)*(log k-1)），鼓励相似负样本排在前列但受抑制。
  - 平衡负采样策略：提供稳定且信息丰富的RL信号；每个查询的候选集由50个过滤硬负（高于相似度阈值后取top 50）和50个随机负样本组成，以增加奖励方差并防止过拟合。
- 公式/目标函数/指标定义：
  - 粒度盲视定义：d(f_θ(q), f_θ(q \ {g_k})) < δ
  - 预训练和指令微调的InfoNCE损失：L = -1/N Σ_{n=1}^N log(exp(cos(e_q, e_c+)/τ) / Σ_{m=1}^N exp(cos(e_q, e_cm)/τ))
  - Margin Reward：R_Margin = max(0, cos(q,c_p) - max_j cos(q,c_nj) - δ)
  - Ranking Reward：R_Rank = s(r)·1/(1+log r) - γ Σ_{k≠r} s(k)·(log k - 1)
  - 总奖励：R_total = αR_Margin + εR_Rank
- 算法细节：
  - RL阶段使用GRPO（Group Relative Policy Optimization）更新策略模型，每组包含G个rollout，每个rollout生成查询、正样本和所有负样本的嵌入。
  - 奖励计算在每个rollout内进行：计算余弦相似度，对负样本排序，分别计算Margin和Ranking奖励。
  - 策略优化时，通过KL散度约束避免偏离参考模型过远。
- 训练/推理细节：
  - 预训练：在NLI数据集上使用InfoNCE损失，batch size为N。
  - 指令微调：在M-BEIR（约1.1M实例）上使用相同损失，覆盖8个检索任务。
  - RL微调：从M-BEIR每个数据集采样1%组成11k实例的训练集，每个实例包含查询、正样本和100个负样本（50硬+50随机）。

### 1. A Multi-Agent LLM Framework for Rating the Quality of Surgical Feedback
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25440v1
- 方法流程：
  - 阶段1 - 发现阶段：输入手术反馈语料库和领域知识（如培训目标、专家注释），使用多智能体LLM代理（每个代理负责一种质量标准探索）通过对话和聚合生成候选评分标准，再经人类专家校准（HITL）优化，输出一组6个可解释的反馈质量维度（例如鼓励性、紧迫性、清晰性等）。
  - 阶段2 - 评分阶段：输入待评分的实时手术反馈文本，使用阶段1得到的评分标准和LLM-as-a-judge（如GPT-4）对每个维度进行1-5 Likert量表评分，输出每个维度的质量得分。
  - 预测验证阶段：将AI质量得分作为特征，结合随机森林分类器预测四个行为结果（培训者行为改变、言语回应、培训者认可、培训者不认可），通过嵌套交叉验证评估预测性能。
- 关键模块/机制：
  - 多智能体LLM提示系统：发现可解释的评分标准；多个LLM代理（如GPT-4）分别扮演不同角色（如教育专家、临床专家），各自提出候选质量标准，通过多轮对话和聚合生成最终标准集。每轮代理根据其他代理的反馈修正建议，最后人类专家参与校准（HITL）以提高可解释性和相关性。
  - 领域知识注入模块：增强LLM对手术反馈领域的理解；在发现阶段的提示中嵌入手术培训上下文，包括：往年训练目标的描述、专家对有效反馈的定性注释、以及典型反馈示例。通过上下文学习（in-context learning）引导LLM生成与手术培训相关的质量维度。
  - LLM-as-a-judge评分模块：基于发现的标准自动评分；使用一个LLM（如GPT-4）对每段反馈文本，根据每个质量维度的定义（行为锚定等级量表），按1-5分进行评分。评分时采用行为锚定描述（BARS）以减少主观偏差，并通过人类-AI对齐校准（见4.9节）进一步优化。
  - 随机森林预测模型：评估AI评分标准的预测有效性；以AI质量得分作为特征，训练随机森林分类器预测四个行为结果。采用嵌套交叉验证（外层5折，内层3折）进行超参数调优（树数量[200-1000]，特征数[10-50]，最大深度[20-50]，最小叶子样本数[5-20]），使用Gini指数分裂，并应用King方法进行类加权以处理不平衡。通过DeLong检验比较包含/不含AI特征的模型AUROC差异。
- 算法细节：
  - 阶段1发现：初始化K个LLM代理，每个代理随机分配一个种子质量标准提议。代理进行T轮对话，每轮每个代理基于前一轮所有代理的输出和领域知识注入提示更新其质量标准。经过T轮后，聚合所有代理的标准并通过聚类或共识机制得到最终标准集（例如6个维度）。然后由两名人类专家对30个样本进行校准，将人类-AI分歧作为示例加入提示进行行为引导（in-context learning）。
  - 阶段2评分：对每个反馈实例，LLM-as-a-judge依次对每个质量维度评分。评分提示包含维度定义、BARS锚定示例以及校准阶段的调整示例。输出整数1-5分，每个维度独立计算。
  - 预测验证：使用AI质量得分和/或先前研究的特征（主题建模特征、人类定义类别）构建特征矩阵。随机森林分类器采用嵌套交叉验证：外循环5折，内循环3折网格搜索。最终报告AUROC及DeLong置信区间，并计算移除特征集后的AUROC下降。
- 训练/推理细节：
  - LLM阶段无需训练（few-shot/in-context），直接基于预训练模型（如GPT-4）进行推理。
  - 随机森林预测阶段：训练过程中使用嵌套交叉验证进行超参数调优，内循环采用3折，外循环5折。类不平衡处理采用King方法调整权重。
  - 人类-AI对齐校准：在阶段1后，人类评分员对30个样本进行评分（5样本/维度）。计算加权Kappa系数（二次加权），并将人类-AI分歧作为示例注入LLM提示中以引导行为。

### 2. Evi-Steer: Learning to Steer Biomedical Vision-Language Models through Efficient and Generalizable Evidential Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.26292v2
- 方法流程：
  - 输入：图像和文本对（如医学图像与报告）
  - 视觉编码处理：冻结BiomedCLIP视觉编码器，仅更新插入的低维令牌，输出视觉特征及认知不确定性
  - 文本编码处理：冻结BiomedCLIP文本编码器，仅更新插入的低维令牌，输出文本特征及认知不确定性
  - 门控残差更新：使用视觉和文本的不确定性估计分别门控各自编码器的残差连接，不确定性高时抑制更新
  - 跨模态置信融合：基于Dempster-Shafer理论，将视觉和文本的置信度（由不确定性转换）融合，得到最终预测
  - 输出：融合后的分类或对齐结果
- 关键模块/机制：
  - 低维令牌更新模块：参数高效微调的核心；在冻结的BiomedCLIP视觉和文本编码器的transformer层中，插入少量可学习的低维令牌（例如每个层数个令牌），仅反向传播这些令牌的梯度，更新参数占比0.11%。
  - 不确定性估计模块：估计每个模态的认知不确定性；在编码器输出后添加证据学习头（evidential head），输出Dirichlet分布的参数，从而计算认知不确定性（如互信息）。
  - 门控残差更新模块：根据不确定性自适应调整特征更新；将估计的不确定性作为门控信号，乘以残差连接中的更新量，不确定性高时减弱残差贡献，防止模型在证据不足时过度适应。
  - 跨模态置信融合模块：融合视觉和文本的置信度进行最终决策；基于Dempster-Shafer理论，将视觉和文本的Dirichlet分布参数转换为mass函数，使用DS组合规则融合，输出最终预测类别置信度，并抑制冲突证据。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 低维令牌更新：类似prompt tuning，在前向传播中，将可学习令牌拼接到输入序列中，仅更新这些令牌参数
  - 不确定性估计：通过证据学习，编码器输出经线性层得到类别证据（evidence），转化为Dirichlet分布参数α，认知不确定性由α的和与类别数计算
  - 门控残差：residual_update = (1 - uncertainty) * base_update + uncertainty * small_update，其中uncertainty为归一化后的认知不确定性
  - DS融合：将视觉和文本的α参数归一化，构造mass函数；通过DS组合规则（正交和）融合，得到联合mass，最终决策根据融合后的信任度或似真度
- 训练/推理细节：
  - 训练设置：少样本学习（如每类k张图像），使用标准交叉熵损失或证据损失（如Brier score）
  - 参数高效：仅更新低维令牌，占0.11%参数，其余BiomedCLIP参数冻结
  - 优化器：AdamW，学习率1e-4，批次大小16
  - 推理：通过门控残差和DS融合得到预测，不确定性可直接输出

### 3. Counterfactual Evaluation Reveals Hidden Capability Profiles in Clinical LLMs and Agents
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.30590v1
- 方法流程：
  - 构建预注册干预目录：每个干预包括适用性过滤器、突变规则（正则替换/删除/插入）、预期输出变化、评分规则、家族标签。
  - 收集224个肿瘤病例，每个病例有专家共识治疗推荐（强、默示、混合、拒绝）和患者资料包（约80k字符）。
  - 对每个模型，对每个病例的每个适用干预进行单次推理：先获取原始输出，再获取干预后输出。
  - 根据预注册的评分规则（正确=1.0，部分=0.5，错误=0）对每个干预对评分，忽略无操作突变（正则未匹配）。
  - 计算每个模型的总体CSS（平均分），同时计算基线指标CMS（覆盖度加权召回）。
  - 在工具使用代理实验中，模型通过ReAct循环调用read_chart_section工具，干预通过修改底层患者资料包传播，重复评分。
- 关键模块/机制：
  - 干预家族A：生物标志物翻转：测试模型对HER2/ER/PD-L1状态变化的响应；通过正则替换更改生物标志物表达，预期输出应按临床指南调整治疗建议。
  - 干预家族B：既往治疗失败：测试模型在添加既往治疗失败记录后是否更新方案；在患者资料中插入一线治疗失效描述，预期模型不应推荐已失败方案。
  - 干预家族C：生物标志物删除：测试模型在缺失关键生物标志物信息时是否保持合理；删除生物标志物描述，预期模型输出可能保持或变为更保守。
  - 干预家族D：手术状态切换：测试模型对手术切除历史的敏感性；切换手术记录（有/无），预期模型调整可切除性判断。
  - 干预家族E：分期扰动：测试模型对疾病分期变化的响应；修改TNM分期，预期治疗强度随之改变。
  - 共识匹配得分(CMS)：覆盖度基线指标，衡量输出与专家共识的重叠；CMS = 0.6R_strong + 0.2R_tacit + 0.15(1 - V_refusal) + 0.05P_extra，其中R为召回率，V_refusal为推荐被拒治疗率，P_extra为额外推荐合理性。
- 公式/目标函数/指标定义：
  - CMS = 0.6R_{strong} + 0.2R_{tacit} + 0.15(1 - V_{refusal}) + 0.05P_{extra}
  - CSS评分规则：{0（方向错误）, 0.5（部分正确或无变化）, 1.0（正确方向）}
  - CSS = 平均分值（对所有适用的干预-病例对）
- 算法细节：
  - 干预生成使用YAML目录，包含五个字段：applicability_filter（正则或条件）、mutation_rule（regex replace/delete/insert）、expected_output_change（描述）、scoring_rule（{0,0.5,1.0}规则）、family_label（A-E）。
  - 模型通过官方API调用，设置默认温度（未明确但为典型推理设置）。
  - 工具使用代理使用ReAct循环，最大8次工具调用（实际平均7.0-8.3次），工具为read_chart_section(section) 返回对应文本块。
  - 工具定义：相同语义，但不同提供商（OpenAI/xAI使用chat-completions tool_calls，Anthropic使用Messages API tool_use block）。
  - 图表分割：基于正则匹配标签（[Medication]等）和标题分隔块（PATIENT DEMOGRAPHICS等），每个块最大8KB。
  - 无操作突变：862个合格对中73个产生无操作（正则适用但未匹配），这些对被静默丢弃而非评0分。
- 训练/推理细节：
  - 所有评估均为单次推理（single-shot），无微调或上下文学习示例。
  - 默认温度参数（未明确，但推断为模型默认值）。
  - 工具使用代理中，模型初始上下文中无图表，必须使用工具获取信息。

### 4. Astra: a generalizable report generation foundation model for 3D computed tomography
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.31437v1
- 方法流程：
  - 数据收集与标准化：收集90,678对胸腹CT-报告，使用DeepSeek LLM按胸/腹模板（胸部10个区域，腹部13个区域）标准化报告，去除噪音非诊断文本。
  - 模型架构构建：3D CT输入→Merlin视觉编码器提取特征图（7×7×10，2048通道）→reshape为490个2048维视觉token→6层Perceiver压缩为32个2048维潜在token→线性投影映射到LLM隐藏维度→Qwen2.5-VL语言模型解码。
  - SFT训练：使用73,127个标准化样本，自回归语言建模目标，最大报告长度1000 token，学习生成符合模板的报告。
  - GRPO强化学习：从SFT初始化策略模型和参考模型，对每个输入采样G个候选报告，计算FORTE奖励（基于Degree/Landmark/Feature/Impression四维度），计算组相对优势，使用带KL正则的PPO裁剪目标更新策略。
  - 推理：输入3D CT和指令模板（胸/腹/聚焦），模型生成标准化报告。
- 关键模块/机制：
  - 报告标准化模块（DeepSeek LLM）：将来自不同机构的原始报告统一为按解剖区域组织的模板，去除噪音文本，提取阳性发现和诊断性描述。；使用DeepSeek LLM，按胸部10区域（腹部13区域）模板重写：移除非诊断文本，提取每个区域的诊断性语句，去掉阴性描述，将比较句改写为独立描述，保留阳性发现。
  - 3D视觉编码器（Merlin）：提取3D CT的体积特征，输出特征图。；使用Merlin作为视觉backbone，提取最后一个卷积层的特征图，空间尺寸为7×7×10，通道数2048，reshape为490个视觉token。
  - Perceiver token压缩器：将稠密的视觉token压缩为少量潜在token，降低计算量并保留关键信息。；6层Perceiver架构，包含32个可学习的潜在token（维度2048），通过交叉注意力机制将490个视觉token压缩为32个聚合token。
  - LLM解码器（Qwen2.5-VL语言部分）：将压缩的视觉token与指令结合，自回归生成报告文本。；使用Qwen2.5-VL的语言部分，移除其原始2D视觉编码器；压缩后的视觉token通过线性层投影到LLM隐藏维度，与指令token拼接后输入。
  - FORTE奖励评估器：评估生成报告在四个维度上的诊断质量，为GRPO提供奖励信号。；基于Degree（大小/强度）、Landmark（位置/解剖）、Feature（疾病特征/发现）、Impression（最终诊断）四个维度评分，每个维度有细化规则（如解剖位置有效+3，程度一致+1，关键发现覆盖+2，印象匹配-2等），最终奖励为四维得分的加权组合（具体权重未提供）。
  - GRPO优化器：通过组相对优势更新策略，提高生成报告的诊断准确性和详细程度。；从策略模型采样G个候选报告，计算FORTE奖励和组相对优势，使用PPO裁剪目标并加入KL散度正则项（相对于冻结的参考模型），更新策略参数。
- 公式/目标函数/指标定义：
  - GRPO目标函数: J_GRPO(θ) = E_v,{o_i}[ (1/G) * Σ_i min( ρ_i(θ) A_i, clip(ρ_i(θ), 1-ε, 1+ε) A_i ) - β D_KL(π_θ ∥ π_ref) ]
  - 组相对优势: A_i = (r_i - mean({r_j})) / std({r_j})
  - 采样: {o_i}_{i=1}^G ~ π_{θ_old}(·|v)
  - 奖励: r_i = R(v, o_i, gt) (FORTE评分)
  - SFT损失: 标准自回归交叉熵损失（未显式给出公式）
- 算法细节：
  - 报告标准化算法：输入原始报告，DeepSeek LLM按模板逐区域提取阳性发现，移除阴性描述和比较句，输出结构化标准化报告。
  - 视觉token压缩：490个视觉token通过Perceiver的交叉注意力与32个潜在token交互，潜在token通过自注意力更新，最终输出32个压缩token。
  - GRPO算法：每步从训练分布采样输入v，当前策略采样G个候选o_i，计算FORTE奖励，标准化为组相对优势，使用PPO裁剪目标更新策略，同时最小化与参考模型的KL散度。
- 训练/推理细节：
  - SFT阶段：使用73,127个标准化报告-图像对，自回归训练，最大序列长度1000 token，优化器、学习率等未提供。
  - GRPO阶段：从SFT检查点初始化策略模型和参考模型；策略模型全参数可训练，参考模型冻结；每个step采样G个候选报告（G具体数值未提供）；奖励函数为FORTE评分；优化目标为带KL正则的PPO损失。
  - 推理：输入3D CT体积和解码指令（胸/腹/聚焦模板），模型自回归生成最多1000 token报告，使用标准采样或束搜索（未明确）。

### 5. CardioLens: Revealing the Clinical Reality Gap of MLLMs via Multi-Sequence Cardiac MRI Evaluations
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.00123v1
- 方法流程：
  - 数据构建：私有医院档案 → 原始报告（自由文本） → 规则提取结构化标签 → 放射科医生验证（1-10年经验和>10年资深审核） → 生成13,494 QA对，覆盖473,896切片
  - 任务评估：输入CMR研究（多序列切片） → 根据任务层级处理（图像理解：单序列切片输入；报告生成：多视图同序列输入；诊断：全部序列输入） → 模型输出预测 → 与专家标注比较计算性能指标
- 关键模块/机制：

### 18. Clinically-Grounded Counterfactual Reasoning for Medical Video Diagnosis
- 区域：quick；分数：7.0

  - 输入视频序列V={xt}_t=1^T，提取重叠片段{C_i}，每个片段经视觉编码器Fe（I3D）获得帧级embeddings，再经时序Transformer Ft捕获全局动态，得到视频级特征Fv。

- 关键模块/机制：
  - Counterfactual Generator (CG)：生成指定病理状态下的反事实组织演化帧，为训练提供反事实监督。；采用条件扩散模型，包含前向扩散（固定马尔可夫链加噪）、反向去噪（U-Net预测噪声）和迭代采样过程。给定当前帧xt和健康状态h，从随机噪声逐步恢复帧˜x^h_{t+1}。

  - Dual Diagnostic Prediction (DDP)：融合视频级全局上下文与帧级反事实对比，输出最终诊断概率。；视频级特征Fv经预测头Fp得到zv；帧级特征取事实帧x^h_{t+1}的反事实帧˜x^{\bar{h}}_{t+1}，分别通过Fp得到z^h_{t+1}和z^{\bar{h}}_{t+1}；最终预测为ˆy = σ(zv + z^h_{t+1} - z^{\bar{h}}_{t+1})，实现差分诊断。
- 公式/目标函数/指标定义：
  - 前向扩散：q(ϵ_k|x_{t+1}) = N(ϵ_k; √ᾱ_k x_{t+1}, (1-ᾱ_k)I)
  - 反向去噪噪声预测：ϵ̂_k = F_u(ϵ_k, x_t, h, k)
  - 去噪更新：ϵ_{k-1} = (1/√α_k)(ϵ_k - (β_k/√(1-ᾱ_k))ϵ̂_k)
  - 生成过程：˜x^h_{t+1} = G(x_t, h) = F_{u,1:k}(ϵ_k; x_t, h)
  - 时序一致性规则：M(F_t; h) ≈ M(F_{t+1}; h) ≫ M(F_t, F_{t+1}; s_t, s_{t+1})
  - 病理可分离性规则：M(h; F^ben_{t+1}) + M(h; F^mal_{t+1}) ≫ M(F^ben_{t+1}; F^mal_{t+1})
- 算法细节：
  - CG采用DDPM框架，前向扩散过程固定，反向去噪用U-Net预测噪声，输入包含当前帧xt、健康状态h和扩散步数k，通过正弦位置编码嵌入k。

  - 三种临床规则以损失函数形式施加于帧级表征，使用余弦相似度F_sim衡量特征相似度。
  - DDP融合时，视频级logits zv和帧级事实logits z^h_{t+1}相加，再减去反事实logits z^{\bar{h}}_{t+1}，模拟医生对比真实与假设诊断。
  - 训练分两阶段：先预训练CG，再联合优化视觉编码器、时序Transformer和诊断头。
- 训练/推理细节：
  - 训练：CG预训练20k次迭代，优化器AdamW，余弦学习率调度，基础学习率1e-4，batch size 8，图像resize至256×256。视觉编码器Fe初始化自I3D预训练权重。
  - 推理：输入视频分重叠片段，Fe和Ft提取视频级特征；帧级反事实推理时，将当前帧xt视为疑似恶性（h=mal），用前一帧x_{t-1}生成良性反事实帧˜x^{ben}_t，然后DDP融合。

  - 第二步（边界测试）：在合成线性回归和真实非线性数据上训练自注意力层，评估其与构建的梯度下降预测器的对齐程度。
  - 第三步（实际方法）：对于冻结RAG LLM，保留检索器和主干固定；构造小预测器（例如小型Transformer），以演示序列为输入，预测LoRA更新参数；将该更新应用到生成器的Q/K/V模块（证据使用接口）；对查询进行前向生成。
- 关键模块/机制：
  - 线性自注意力层 (Linear Self-Attention, LSA)：理论核心，证明单层LSA可等价于一步梯度下降，用于指导实际方法设计。；无softmax和偏置的多头自注意力，更新公式为 e_j ← e_j + Σ_h P_h V_h K_h^T q_{h,j}。构造V、K、Q和P使得输出恰好是梯度更新产生的预测偏移。
  - 上下文条件预测器 (Context-Conditioned Predictor)：将演示样本映射为LoRA更新，模拟梯度下降多步过程，避免测试时反向传播。；一个小型Transformer或MLP，输入为连接后的演示token序列（查询、文档、答案），输出为LoRA模块的增量参数（ΔQ, ΔK, ΔV）。通过监督学习训练，目标是对应于K步LSA层输出的LoRA更新。
  - 证据使用接口 (Evidence-Use Interface)：生成器侧适配点，通过LoRA实现，控制模型如何使用检索文档。；在冻结LLM的attention层中引入Q/K/V LoRA模块，原本参数固定；预测器输出的更新直接注入这些LoRA模块，改变注意力分布从而调整证据融合方式。
- 公式/目标函数/指标定义：
  - 统一线性化RAG预测器：y = W1 x1 + W2 x2，投影接口：x1=x_q, x2=D, W2=W1 W_d；点积接口：x1=x2=x_q, W2=W_z (Σ_i d_i d_i^T) M^T。
  - 平方损失：L(W1,W2) = (1/(2N)) Σ_i ||W1 x1_i + W2 x2_i - y_i||^2。
  - 一步梯度更新：ΔW_k = -η/N Σ_i (W1 x1_i + W2 x2_i - y_i) (x_i^k)^T, k∈{1,2}。
  - 预测偏移：Δy = ΔW1 x1 + ΔW2 x2。
  - 多步线性视图：ˆy^{(K)}_{N+1} = ˆy^{(0)}_{N+1} + Σ_{t=0}^{K-1} (ΔW_1^{(t)} x1_{N+1} + ΔW_2^{(t)} x2_{N+1})。
- 算法细节：
  - 构造LSA权重：值矩阵V编码残差 r_i = W1 x1_i + W2 x2_i - y_i；键矩阵K和查询矩阵Q实现内积 (x1_i)^T x1_j 和 (x2_i)^T x2_j；输出投影P将加权残差和写入查询token的y坐标。
  - 预测器训练：收集RAG演示集合，使用K步线性自注意力（或实际梯度）计算期望的LoRA更新作为监督信号，训练预测器最小化均方误差。
  - 推理阶段：给定新任务演示，预测器前向输出LoRA参数，直接覆盖（或累加）生成器LoRA权重，然后处理测试查询。
- 训练/推理细节：
  - 训练：保持检索器和LLM主干冻结；预测器通过监督学习训练，损失函数为预测LoRA更新与真实K步梯度更新之间的MSE；真实梯度由基于RAG损失的autograd计算（通过少量演示样本）。
  - 推理：一次前向通过预测器得到LoRA更新，应用于生成器；无反向传播；每查询成本仅比基线RAG多一次小Transformer前向。
  - 实验设置：7个QA基准（如NQ、TriviaQA、HotpotQA等），2个检索器（BM25、Contriever），2个冻结backbone（LLaMA-2 7B、Mistral 7B）。

### 1. MedSIGHT: Towards Grounded Visual Comprehension in Medical Large Vision-Language Models
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2606.06760v1
- 方法流程：
  - 图像通过预训练图像编码器得到patch嵌入I。
  - Region Perceiver处理I得到区域嵌入Qr（L层双交叉注意力迭代）。
  - 拼接I和Qr，经投影层Pv→t映射到语言空间得到V。
  - LLM词汇扩展加入码本嵌入C，与文本嵌入T、V共同输入LLM进行多模态推理。
  - LLM生成包含区域代码的文本响应，区域代码经Region Perceiver解码得到分割掩码。
- 关键模块/机制：
  - Region Perceiver：将空间细节编码到区域嵌入，支持分割解码；由L层迭代组成，每层包含区域到图像交叉注意力和图像到区域交叉注意力，逐步细化区域嵌入和图像特征；预训练时使用分割损失(LBCE+LDice)和分类损失Lce。
  - Modality-aware Region Codebook：将连续区域嵌入离散化为LLM词汇中的区域代码，实现语言到分割的映射；为每个成像模态维护M个离散码本向量；对区域嵌入Qir进行最近邻量化：ˆQir = c_{k*,m*}，其中k*,m* = argmin ||Wq Qir - c_{k,m}||_2；训练使用LVQ、Lrecon和LR损失；量化后经Wm投影回视觉空间，再经Pv→t投影到LLM嵌入空间初始化token嵌入。
  - Projectors (Pv→t, Pt→v)：跨模态映射；Pv→t将视觉嵌入映射到语言空间；Pt→v将LLM隐藏状态映射回视觉空间用于分割解码。
- 公式/目标函数/指标定义：
  - LR(Ir, Qr) = Lseg(Ir, Qr) + Lce(Qr)，其中Lseg = λ1 LBCE + λ2 LDice。
  - Lcodebook = LVQ + Lrecon + LR(Ir, ˜Qr)，其中Lrecon = ||˜Qr - Qr||_2^2。
  - Lfinal = LLLM + Lseg。
- 算法细节：
  - 双交叉注意力：区域到图像注意力 Ql = FFN(CrossAtt(Ql-1, El-1))，图像到区域注意力 Il = FFN(CrossAtt(El-1, Ql))。
  - 码本量化：ˆQir = c_{k*,m*}，其中k*,m* = argmin ||Wq Qir - c_{k,m}||_2。
  - 码本词汇集成：码本向量经Wm投影到视觉空间，再经Pv→t投影到LLM嵌入空间初始化token嵌入。
- 训练/推理细节：
  - 训练分四个阶段：①预训练Region Perceiver（Dseg）；②视觉-文本对齐（冻结LLM、编码器、感知器，训练Pv→t）；③码本学习与对齐（冻结感知器，训练码本、Wq、Wm、Pt→v、C）；④统一接地指令微调（冻结感知器和编码器，联合微调LLM、C、Pv→t、Pt→v）。
  - 数据集：Dseg (BiomedParse), Dv→t (PubMedVision 647K), Dt→v (60K), Dr_inst (60K), Dg_inst (12K)。
  - 推理时LLM生成区域代码，其隐藏状态经Pt→v投影后由Region Perceiver分割头解码为掩码。

### 3. Attention Consistent Longitudinal Medical Visual Question Answering Guided by Vision Foundation Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.06534v1
- 方法流程：
  - 输入：当前图像 Imain 和参考图像 Iref
  - 微图像配准：浅层CNN预测仿射参数Θ，对Imain进行网格采样变形得到配准图像 bImain，并施加正则化损失Lreg
  - 共享图像编码器ϕ提取特征：fmain=ϕ(bImain), fref=ϕ(Iref)
  - 掩码生成：冻结DINO分支生成注意力图A和联合先验U；可训练MLP头g生成逐token掩码概率；1层CNN门控头h融合生成F；最终掩码M = λU + (1-λ)F
  - 掩码应用：对配准后的图像对应用M，得到I'和I''，再用ϕ重新编码得fmask_main和fmask_ref
  - 文本编码：问题经词嵌入、位置编码、6层12头Transformer编码为ftext
  - 多模态解码：拼接序列[⟨img⟩, fmask_main, ⟨img⟩, fmask_ref, ⟨qtn⟩, ftext, ⟨ans⟩]输入GPT-2小模型生成答案
  - 训练损失：语言建模Llm + 配准损失Lreg + 掩码一致性损失Lmask + 预测重建损失Lpred + Gram风格一致性损失Lgram + KoLeo均匀性损失LKoLeo
- 关键模块/机制：
  - 微图像配准模块：对齐当前图像到参考图像，减少非病变运动噪声；轻量CNN预测2D仿射参数Θ=[A|t]，使用可微分网格采样器变形主图像，通过正则化Lreg约束变换接近恒等，避免消除真实解剖变化。
  - 掩码生成模块（DINO+自适应）：生成共享显著掩码，突出病变区域并抑制背景；冻结的RAD-DINO分支输出注意力图，取最大值得到先验U；可训练3层MLP头g生成逐token掩码概率mmain,mref；1层CNN门控头h融合'并、交、差'特征得到F；最终掩码M=λU+(1-λ)F，λ从1余弦衰减到0.5。
  - 共享图像编码器与投影器：提取图像特征并映射到文本表示空间；Swin-base（patch4窗口12×12），经ImageNet-21k预训练和MIMIC-CXR分类微调；投影器由线性层、8头Transformer编码器、两层MLP组成。
  - 多模态Transformer解码器：基于掩码图像特征和问题特征生成答案；GPT-2小模型，输入序列拼接掩码后的主图像特征、参考图像特征、问题特征，并添加特殊标记⟨img⟩,⟨qtn⟩,⟨ans⟩。
  - 辅助损失模块：稳定训练、增强表示、避免坍塌；包括掩码一致性损失（强制掩码后的特征等于掩码乘原始特征）、重建损失（小头P回归掩码前特征）、Gram风格一致性损失（保持主/参考图像patch间关系）、KoLeo均匀性损失（抑制样本塌缩）。
- 公式/目标函数/指标定义：
  - 仿射变形：x = A xtgt + t
  - 配准正则化：Lreg = wsml ||Θ-I||_F^2 + wdet(det(A)-1)^2 + wtran ||t||_2^2
  - 先验掩码：U = max(Amain, Aref)
  - 自适应掩码：F = σ(h(σ(g(fmain)), σ(g(fref))))
  - 最终掩码：M = λU + (1-λ)F
  - 语言建模损失：Llm = CE(Decoder(C), y)
- 算法细节：
  - 配准模块：CNN输出6维向量（2×3仿射参数），通过网格采样器实现可微分变形
  - DINO先验：使用RAD-DINO模型的CLS token与patch token的余弦相似度作为注意力权重，重塑为空间图
  - 自适应掩码：两层3层MLP分别生成逐token概率，然后1层CNN门控融合四个特征（并、交、差）
  - 掩码融合：线性插值M=λU+(1-λ)F，λ按余弦函数从1衰减到0.5
  - 特征重编码：对掩码后的图像再次使用相同编码器ϕ提取fmask特征
  - 解码器输入序列：特殊标记⟨img⟩交替插入两个时间点的图像特征，⟨qtn⟩后跟问题特征，⟨ans⟩启动生成
  - 训练两阶段：第一阶段冻结图像编码器4轮，第二阶段解冻全部4轮
- 训练/推理细节：
  - 优化器：AdamW，学习率1.5e-4，权重衰减0.05
  - 批大小：训练10，验证8
  - 数据增强：亮度、对比度、锐度调整
  - 图像尺寸：384×384，三通道
  - 辅助损失权重：αmask=αpred=αgram=0.1，αkl=0.001
  - 两阶段训练：第一阶段冻结图像编码器4轮，第二阶段解冻全部4轮

### 5. Be Fair! Can Machine Learning Engineering Agents Adhere to Fairness Constraints?
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.04971v1
- 方法流程：
  - 阶段1: 数据准备 - 使用Fitzpatrick17k作为训练集（含Fitzpatrick皮肤色调标注），DDI作为独立测试集（平衡深浅肤色），并重命名/打乱列、去除外部URL以避免记忆化。
  - 阶段2: 任务指令设计 - 提供四种指令（base、fairness-hint、fairness-metric、fairness-methods），代表从低级到高级的技术专业性。
  - 阶段3: 代理管道生成 - 将训练数据和任务指令输入MLE代理（AIDE或MLZero），代理通过20步搜索（每步最多1小时，使用A100 GPU）生成Python脚本形式的ML管道。
  - 阶段4: 评估与比较 - 在DDI测试集上计算AUC和AUC gap（最佳与最差肤色组AUC之差），与人类专家判决和三种手动基线（MEDFAIR、MEDFAIR-dedup、MEDFAIR-filtered）进行比较。
- 关键模块/机制：
  - 任务指令设计：控制提示的技术专业性水平，评估代理对不同程度的指导的反应；四种指令：base（简单任务描述）、fairness-hint（添加'公平对待肤色'）、fairness-metric（指定最小化AUC差距）、fairness-methods（建议具体公平干预方法如过滤、上采样、损失重加权）
  - 代理搜索过程：自动生成和优化ML管道；基于LLM的代码生成，以原始数据和自然语言任务描述为输入，迭代生成、评估和改进管道候选，搜索由候选管道的预测性能引导，输出最佳管道的Python脚本及预测
  - 评估指标：量化预测性能和公平性；AUC衡量分类性能；AUC gap定义为最佳与最差肤色组的AUC之差，反映公平性。采用MEDFAIR框架中的minimax pareto选择进行早期停止和模型选择
- 公式/目标函数/指标定义：
  - AUC gap = AUC_best - AUC_worst (最佳与最差皮肤色调组AUC之差)
  - 目标：最小化AUC gap同时保持总体AUC性能
  - minimax pareto选择：在总体AUC和AUC gap之间选择帕累托有效点，最小化最大 downside
- 算法细节：
  - 代理基于LLM的代码生成：接收原始数据CSV和自然语言指令，生成Python脚本；通过执行脚本并评估验证集性能来搜索；可能进行多轮迭代改进。
  - 专家基线使用ResNet-18，微调30个epoch，预处理包括图像resize和标签二值化（恶性 vs 其他）。
  - data cleaning策略：MEDFAIR移除缺失Fitzpatrick标签样本；MEDFAIR-dedup移除重复和噪声图像；MEDFAIR-filtered进一步过滤非肿瘤条件图像。
- 训练/推理细节：
  - 代理使用A100 GPU，每个步骤最大执行时间1小时，总共20个步骤的搜索预算。
  - 专家基线在Fitzpatrick17k上微调ResNet-18 30个epoch。
  - 测试在DDI数据集上进行，该数据集包含656张图像，深浅肤色平衡，并有人类专家判决供比较。

### 6. DSU-Net: An Attention-Enhanced Dense Skip U-Net for Breast Lesion Segmentation in Mammographic Images
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.06537v1
- 方法流程：
  - 输入：256×256 RGB乳腺X线图像
  - 编码器路径：卷积层与密集连接提取多尺度特征，增强特征复用和梯度传播
  - 密集瓶颈模块：最深层密集连接特征处理，保持高维语义信息
  - 注意力引导解码器路径：通过注意力机制加权跳跃连接特征，抑制背景噪声，逐步恢复空间分辨率
  - 输出：单通道分割图，经Sigmoid激活和阈值0.5二值化得到病变掩膜
- 关键模块/机制：
  - 密集跳跃连接：连接编码器和解码器对应层，实现特征重用和梯度改善；采用类似DenseNet的密集连接方式，使每个解码层接收来自之前所有编码层和同级解码层的特征图，增强梯度流动并减少信息丢失
  - 注意力机制：在跳跃连接中引入注意力权重，聚焦病变区域并抑制背景；具体结构原文未详细描述，但通过注意力门控模块对编码器特征进行重标定，使解码器更关注重要区域
  - 复合损失函数：联合优化病变区域重叠、难分样本和像素级精度；总损失L_total = 0.5 L_Dice + 0.3 L_Focal + 0.2 L_BCE；Dice损失最大化预测与真值重叠，Focal损失（α=1, γ=2）聚焦难分类像素，BCE提供稳定梯度
- 公式/目标函数/指标定义：
  - 总损失：L_total = 0.5 L_Dice + 0.3 L_Focal + 0.2 L_BCE
  - Dice损失：L_Dice = 1 - 2∑p_i g_i / (∑p_i + ∑g_i)（含平滑常数ε）
  - BCE损失：L_BCE = -1/N ∑[g_i ln(p_i) + (1-g_i)ln(1-p_i)]
  - Focal损失：L_Focal = -1/N ∑ α (1-p_t)^γ ln(p_t)，其中p_t = p_i（g_i=1）或1-p_i（g_i=0），α=1，γ=2
  - 评估指标：Dice系数、IoU、准确率、精确率、召回率、特异性、AUC-ROC
- 算法细节：
  - 使用Adam优化器，学习率1e-4，权重衰减1e-5
  - 应用梯度裁剪，最大范数1.0，防止梯度爆炸
  - 学习率调度策略：ReduceLROnPlateau，监控验证Dice，当10个epoch无改善时按因子0.5降低学习率
  - 早停策略：验证Dice在15个epoch内提升不足0.001则停止训练
  - 模型选择：保存验证Dice最高的模型参数，用于最终评估
- 训练/推理细节：
  - 输入图像大小：256×256
  - 批量大小：8
  - 最大训练轮数：100，实际训练24轮（早停触发）
  - 最佳验证性能出现在第9轮：Dice=0.9442，IoU=0.9065
  - 损失函数权重：Dice 0.5，Focal 0.3，BCE 0.2
  - 输出激活函数：Sigmoid

- 公式/目标函数/指标定义：

  - L_point(θ) = Σ_{j∈Ω} ||z_{j,1} - z_{j,2}||
  - L_pair(θ) = Σ_{j∈Ω} Σ_{k∈Ω\{j}} (||z_{j,1} - z_{k,1}|| - ||z_{j,2} - z_{k,2}||)
  - 其中z_{j,1} = Fθ(x), x ∈ {ci, qi, Di}；z_{j,2} = G(x), x ∈ {Ri, qi, Di}。λ=1。

### 10. TGV-KV: Text-Grounded KV Eviction for Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.03075v1
- 方法流程：
  - Prefill阶段: 视觉编码器和文本分词器生成视觉token Xv和文本token Xt，拼接为序列X，通过自注意力计算Q、K、V矩阵
  - 层间预算分配(TVB): 计算每一层的文本-视觉(TV)注意力总分，按比例分配各层保留的KV缓存预算
  - 层内驱逐: (1) TWR: 对每个视觉token，计算其与所有文本token的注意力加权和作为重要性分数； (2) TPR: 保留所有文本token，仅驱逐低分视觉token； (3) 在解码阶段持续应用驱逐策略
- 关键模块/机制：
  - Text-Vision Budgeting (TVB)：动态分配各层KV缓存预算；计算每一层文本-视觉注意力矩阵的总和，归一化后作为该层的预算比例。公式: b_{TV,l} = (∑_{i,j}[A_{TV,l}]_{ij}) / (∑_{l'=1}^L ∑_{i,j}[A_{TV,l'}]_{ij})
  - Text-Weighted Ranking (TWR)：评估视觉token的重要性；对每个视觉token，将其与所有文本token的注意力分数以文本token的自身注意力分数为权重进行加权求和，得到该视觉token的重要性分数
  - Text-Prioritised Retention (TPR)：确保文本token不被驱逐；在驱逐阶段，所有文本token的KV始终保留（除系统token外），仅从视觉token中根据TWR分数驱逐低优先级者
- 公式/目标函数/指标定义：
  - Q = XW^Q, K = XW^K, V = XW^V (公式1)
  - A = softmax(QK^T + M) (公式2, M为上三角掩码矩阵)
  - K = concat(K, xW^k) (公式3, 解码阶段缓存更新)
  - V = concat(V, xW^v) (公式4)
  - b_{x,l} = (∑_{i,j}[A_{x,l}]_{ij}) / (∑_{l'=1}^L ∑_{i,j}[A_{x,l'}]_{ij}) (公式5, TVB预算分配)
- 算法细节：
  - TVB: 利用预填充阶段计算的注意力矩阵，对每一层统计文本-视觉注意力总和，归一化得到各层保留比例
  - TWR: 对每个视觉token i，计算 s_i = ∑_{j∈文本} A_{TV,l}^{i,j} * w_j，其中w_j为文本token j的自身注意力分数（可从TT注意力矩阵获得），排序后保留预算内的高分视觉token
  - TPR: 在驱逐时，保留所有文本token（包括系统prompt），仅驱逐视觉token；若预算仍不足，从视觉token中按重要性分数从低到高驱逐
  - 解码阶段: 每生成一个token，计算新token的注意力，并重复上述排序驱逐过程（但预算分配仅在预填充阶段一次性完成）
- 训练/推理细节：
  - 无需微调，直接在预训练VLM上应用
  - 推理时分为预填充和解码两个阶段，驱逐在预填充后立即执行，解码阶段动态维护KV缓存大小
  - 不进行头级分析以保证计算并行性和效率

### 11. Stateful Visual Encoders for Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.04433v1
- 方法流程：
  - 输入：多张图像序列，如[t-1, t, t+1]
  - 独立视觉编码：每张图像通过共享的视觉编码器（如SigLIP）分别提取特征，得到特征序列{F_{t-1}, F_t, F_{t+1}}
  - 状态融合：当前图像特征F_t与先前图像特征F_{t-1}（或所有历史特征）通过交叉注意力层进行融合。具体地，以F_t为query，以历史特征为key和value，得到更新的特征F_t'
  - 可选：重复状态融合步骤，或使用自回归方式逐帧更新状态
  - 输出：更新后的视觉特征F_t'，输入到语言模型中进行后续推理或生成
  - 语言模型：将F_t'（及可能的其他特征）作为视觉token，与文本token一起输入到LLM（如Qwen2.5）进行多模态理解和生成
- 关键模块/机制：
  - 状态视觉编码器（SVE）：替代标准VLM中的无状态视觉编码器，使编码后的视觉特征携带跨图像上下文信息；SVE在标准视觉编码器（如SigLIP）的基础上增加了一个状态融合模块。该模块通常由数个交叉注意力层组成，其中当前图像的patch特征作为query，先前图像的特征（或累积的状态特征）作为key和value。融合后的特征再通过FFN层，最终输出。在训练时，整个SVE（包括视觉编码器和状态融合模块）与语言模型端到端微调。
  - 交叉注意力状态融合层：实现当前视觉表示对历史视觉特征的依赖；给定当前图像特征X_t ∈ R^{N×D}（N为patch数，D为特征维度），历史特征X_hist ∈ R^{M×D}（M为历史patch总数，可累积或仅前一帧），计算Q = X_t W_Q, K = X_hist W_K, V = X_hist W_V，然后标准交叉注意力：Attn = softmax(Q K^T / √d) V，再经过残差连接和LayerNorm。模块可堆叠L层。
- 算法细节：
  - 训练时，对于多图像样本，按顺序将图像输入视觉编码器，每张图像经过独立编码后，再通过SVE的状态融合模块，得到携带历史信息的特征，然后送入语言模型。
  - 对于填充回答（如'I see the image.'），在损失计算时通过掩码（mask history=True）忽略，只监督最终的回答。
  - 对于VisGym多轮任务，所有轮次的动作都进行监督（mask history=False）。
  - 在推理时，使用相同的流程：图像序列依次输入，SVE逐步更新状态，语言模型自回归生成。
- 训练/推理细节：
  - 训练方式：监督微调（SFT），使用多个任务（6个任务家族）的混合数据。
  - 视觉编码器初始化为SigLIP或CLIP，状态融合模块随机初始化。
  - 训练时冻结视觉编码器的部分参数（如只在最后几层微调），或者完全微调。
  - 使用LlamaFactory框架，数据格式为ShareGPT风格的JSONL。
  - 优化器：AdamW，学习率约1e-5，批次大小根据任务调整。
  - 推理时，所有实验使用种子42以确保可重复性。

### 12. DRIFT: A Residual Flow Adapter for Decoding Continuous Outputs in Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.05758v1
- 方法流程：
  - 输入：视觉观察和语言指令通过VLM编码器提取特征；
  - 基础预测器（MLP或tokenizer）从VLM表示输出粗估计 y_hat；
  - 流细化器接受条件表示、时间t和桥状态y_t，通过嵌入层、自注意力层、输出头预测流；
  - 通过跳跃连接将粗估计与流预测相加得到最终输出 y = y_hat + 流预测。
- 关键模块/机制：
  - Base Predictor：从VLM表示产生粗估计，提供强先验；使用MLP或tokenizer将VLM隐藏状态映射到连续输出空间，输出y_hat。
  - Flow Refiner：迭代预测残差，细化粗估计；包含三个子模块：嵌入层将条件、时间t、桥状态y_t映射到共享隐空间；自注意力层聚合信息；输出头预测流（x-prediction）。使用线性插值公式 y_t = (1-t)(epsilon + y_hat) + t y。
  - Skip Connection：将粗估计直接加到流预测上，简化优化；在输出头后，将基础预测器的输出y_hat与流预测相加得到最终预测。
- 公式/目标函数/指标定义：
  - 线性插值公式：y_t = (1-t)(epsilon + y_hat) + t y
  - 流匹配损失（均方误差）：L_flow = E[||v_θ(y_t, t, cond) - (y - y_hat)||^2]（推测）
  - 基础预测器损失Lp（未明确形式，推测为回归损失）
  - 总损失：L_total = L_flow + λ Lp
- 算法细节：
  - 基础预测器与流细化器通过LoRA适配器与VLM联合训练
  - 流细化器使用自注意力聚合条件、时间、桥状态信息
  - 推理时从噪声epsilon采样，通过ODE求解器逐步去噪得到最终预测
  - 使用x-prediction（信号预测）而非v-prediction（速度预测）
- 训练/推理细节：
  - 联合训练：给VLM附加LoRA适配器，同时训练基础预测器和流细化模块
  - 训练数据：VLA任务使用Libero、Bridge、Fractal等数据集；TVG任务使用TimeLens-100K
  - 超参数：训练步数、学习率等见附录
  - 推理：从标准高斯噪声开始，通过流匹配ODE迭代细化，步数较少
  - TVG任务中，冻结视觉编码器，仅LoRA微调LLM注意力投影

  - 输入: 全切片图像(WSI)的patch集合及像素级标注（如肿瘤/正常），或合成数据中的图像和语义标签。
  - 语义特征提取: 为每个patch分配一个语义概念（如Tumor、Normal、Mix），得到特征集N（概念集合）。
  - 子集与查询构造: 构造N的所有子集S⊆N（用于模型评估）和基于逻辑连接词（∧、∨、¬）的查询空间Q（每个查询对应一个指示函数λ_q: 2^N→{0,1}）。
  - 模型评估: 对每个子集S，提取对应的子袋X_S（包含所有语义概念属于S的patch），输入预训练MIL模型得到预测值f(X_S)。
  - 对齐分数计算: 对每个查询q，计算f(X_S)与λ_q(S)在所有子集S上的Spearman相关性，得到r_X(q,f)。
  - 符号表示: 将所有查询的对齐分数组成向量φ(X) = (r_X(q1,f),..., r_X(q_{|Q|},f))。
  - 输出: 每个样本的符号表示φ(X)和最佳对齐查询q*(X)=argmax r_X(q,f)，支持局部解释（单个样本的最佳规则）和全局分析（聚类等）。
- 关键模块/机制：
  - 语义映射（Semantic Map）：将每个实例（patch）映射到一个语义概念（如Tumor、Normal、Mix），形成特征集N，是后续子集和查询构造的基础。；对于病理图像，基于像素级标注中肿瘤像素占比ρ_i：ρ_i=0为Normal，ρ_i=1为Tumor，0<ρ_i<1为Mix。对于合成MNIST，根据数字标签（如4、7、Rest）映射。
  - 查询空间构造（Query Space Construction）：生成所有可能的逻辑查询（如A ∧ B、¬A、A ∨ ¬B等），作为对齐分析的候选规则。；基于语义特征集N，使用逻辑连接词（∧、∨、¬）组合特征标识符。对于|N|=3，生成39个非冗余查询（附录A给出具体生成方法）。查询空间大小随|N|指数增长。
  - 对齐分数计算（Alignment Score Calculation）：量化模型f对特定逻辑查询q的遵循程度，作为解释核心。；对于样本X，枚举所有子集S⊆N，分别获得查询指示λ_q(S)（根据查询公式计算）和模型预测f(X_S)（将子袋输入模型）。计算两者在所有S上的Spearman相关系数r_X(q,f)。
  - 符号表示空间（Symbolic Representation Space）：将对齐分数向量化，形成样本在语义规则空间中的嵌入，支持跨样本比较和聚类。；φ(X) = (r_X(q1,f), ..., r_X(q_{|Q|},f))，维度等于查询数量。每个维度代表模型与对应逻辑规则的一致性程度。
  - 最佳对齐查询选择（Best-Aligned Query Selection）：为每个样本选出最接近其决策逻辑的单一规则，用于局部解释。；q*(X) = argmax_{q∈Q} r_X(q,f)，返回对齐分数最高的查询。
- 公式/目标函数/指标定义：
  - 对齐分数: r_X(q,f) := corr_{S⊆N}(λ_q(S), f(X_S))
  - 最佳查询: q*(X) := argmax_{q∈Q} r_X(q,f)
  - 符号表示: φ(X) = (r_X(q1,f), ..., r_X(q_{|Q|},f))
  - 模拟实验标签定义: 4∧7: y=1{4∈M(X) ∧ 7∈M(X)}; 4∨7: y=1{4∈M(X) ∨ 7∈M(X)}; 4→7: y=1{4∉M(X) ∨ 7∈M(X)}
- 算法细节：
  - 子集枚举: 对于|N|=n，需要评估所有2^n个子集对应的子袋。在实验中|N|=3（3个语义概念），故枚举8个子集。
  - 查询枚举: 基于逻辑连接词组合所有特征，生成所有非冗余布尔公式。附录A中提供生成细节，但未公开完整算法。
  - 模型响应计算: 对每个子集S，构造子袋X_S = {x_i | M(x_i) ∈ S}，输入MIL模型（如TransMIL）得到标量预测f(X_S)。
  - 相关性计算: 使用Spearman秩相关系数，比较λ_q(S)和f(X_S)在2^n个样本点上的排序一致性。
  - 聚类分析: 在符号表示空间φ(X)上使用K-means聚类（K=4），评估模型策略异质性。
- 训练/推理细节：
  - Symb-xMIL是后验解释框架，不需要重新训练或修改原MIL模型。
  - 在模拟实验中，使用两层卷积编码器+TransMIL从头训练，达到99.99%测试准确率。
  - 在Camelyon16实验中，使用预训练Virchow2提取特征 + TransMIL，5折交叉验证，平均AUROC 0.995。
  - 在TCGA-HNSCC实验中，未提供训练细节，但类似设置。
  - 推理阶段：对每个测试样本，遍历所有子集和查询计算对齐分数。

- 方法流程：
  - 输入：RGB图像（512×512）、多通道组织先验（由预训练SegFormer-B2生成）、细胞性先验（由教师模型生成），拼接为6通道输入。

  - 多尺度先验门控融合：对每个尺度l，将Ul、Sl、Pl（缩放到分辨率）拼接，通过卷积-归一化-GELU-卷积- Sigmoid生成门gl；将Pl分别投影到局部和全局特征空间，经gl逐元素加权后加到原特征，得到增强特征Ûl和Ŝl；再拼接经CBAM得到融合特征Fl。

  - 推理时：仅用主网络，无辅助分支。

  - 先验门控融合模块 (Prior-Gated Fusion Module)：自适应融合组织先验与双编码器特征，抑制噪声先验，增强信息先验。；由两阶段组成：B(1)将Ul、Sl、Pl通道拼接，经Wg1卷积、BN、GELU、Wg2卷积、Sigmoid生成空间门gl；B(2)将Pl分别通过Wu和Ws投影，与gl逐元素相乘后加到Ul和Sl，得Ûl和Ŝl；再将两者拼接经CBAM得到Fl。公式(1)-(4)。
  - 辅助前景重建分支 (Auxiliary Foreground Reconstruction Branch)：训练时保留高频细胞结构，提升边界定位能力。；定义重建目标Tfg = |I - G(I)|，其中I为输入RGB，G为高斯平滑。解码器特征经轻量卷积头预测T̂fg，使用L1损失Lfg = ||T̂fg - Tfg||₁。仅在训练时启用。
  - 细胞性先验 (Cellness Prior)：提供类无关的细胞位置线索，增强定位鲁棒性。；由教师模型对肿瘤细胞和背景细胞热图取最大值得到，作为额外输入通道（与RGB、组织先验拼接成6通道）。
- 公式/目标函数/指标定义：
  - 门控生成: g_l = σ(W_g2 * φ(BN(W_g1 * [U_l; S_l; P_l])))
  - 门控调制: Û_l = U_l + g_l ⊙ (W_u * P_l); Ŝ_l = S_l + g_l ⊙ (W_s * P_l)
  - 融合: F_l = CBAM([Û_l; Ŝ_l])
  - 辅助重建目标: T_fg = |I - G(I)|
  - 辅助损失: L_fg = ||T̂_fg - T_fg||₁
  - 主损失: L_seg = ||Z - Y||₂² (MSE)
- 算法细节：
  - 先验生成：独立训练SegFormer-B2进行组织分割，输出多通道概率图（癌症和背景），作为先验。
  - 门控融合算法（Algorithm 1）：对每个尺度l，缩放先验图，拼接局部、全局和先验特征，计算门，投影先验，调制，CBAM融合。
  - 热图生成：解码器输出两类热图，使用高斯核生成真实热图Y（以标注细胞质心为中心）。
  - 细胞性先验生成：使用教师模型（可能是ACS-SegNet）预测的热图，逐像素取最大响应。
- 训练/推理细节：
  - 训练：AdamW优化器，初始学习率1e-5，多项式衰减，批量大小4，训练250轮。输入尺寸512×512，6通道（RGB+2组织先验+1细胞性先验）。数据增强：翻转、裁剪、模糊、颜色抖动。辅助分支权重λ=0.005。
  - 推理：仅用主网络，无辅助分支，输入同样6通道（需预先生成先验）。输出热图，通过非极大抑制或阈值获得最终检测。

### 15. Learning Label-Efficient Interpretable Medical Image Diagnosis via Semi-supervised Hypergraph Concept Bottleneck Model
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.01698v1
- 方法流程：
  - 输入图像经图像编码器提取特征图；
  - 概念编码器（CEM风格）为每个概念生成高维嵌入（正负两个嵌入），通过评分函数得到概念概率并加权合成最终概念嵌入；
  - 对每个图像的概念嵌入构建自适应超图，基于余弦相似度形成超边，再经超图卷积层（HGNN+）传播信息，输出精炼的概念嵌入；
  - 精炼后的概念嵌入输入标签预测器（全连接层）得到最终类别预测；
  - 对未标注图像，通过图像语义级超图构建（ISHC）在图像特征空间中聚类，利用KNN从标注数据中传播伪标签，并生成伪概念标签用于损失计算。
- 关键模块/机制：
  - 超图增强的概念表示学习 (HECRL)：建模概念间的高阶依赖关系，增强概念表示的语义丰富性；对于每个图像，将t个概念嵌入作为节点，计算两两余弦相似度，基于相似度矩阵自适应构建超边（每个节点与其最相似的k个节点形成超边）；然后应用HGNN+进行超图卷积，通过消息传递更新节点特征，输出精炼概念嵌入。
  - 超图图像动态伪标签生成 (HIDP)：为未标注图像生成领域自适应的伪概念标签；使用独立的图像编码器提取未标注图像的特征，构建图像级超图：以批次内所有图像（标注+未标注）为节点，基于特征距离（小于阈值ε）建立超边；利用超图卷积传播标注图像的先验概念信息，得到每个未标注图像的伪概念概率；通过KNN在标注数据中检索相似样本，调整伪标签权重，最终生成伪概念标签。
- 公式/目标函数/指标定义：
  - 概念嵌入计算: ̂c_i = ̂p_i ̂c_i^+ + (1 - ̂p_i) ̂c_i^-
  - 概念概率预测: ̂p_i = σ(W_s[̂c_i^+, ̂c_i^-]^⊤ + b_s)
  - 概念间余弦相似度: S_{ij} = (̂c_i · ̂c_j) / (||̂c_i|| ||̂c_j||)
  - 超图卷积操作 (HGNN+): X^{(l+1)} = σ(D_v^{-1/2} H W D_e^{-1} H^⊤ D_v^{-1/2} X^{(l)} Θ)
  - 总损失函数: L = L_task + α L_concept_labeled + β L_concept_unlabeled
  - 伪标签对齐损失: L_concept_unlabeled = || ̂c_u - ̂c_pseudo ||^2
- 算法细节：
  - 概念自适应超图构建：对每张图像，计算t个概念嵌入的余弦相似度矩阵S；对于每个概念节点，选择相似度最高的k个节点形成超边，所有超边构成超图H_c；
  - HGNN+传播：采用两层级联的超图卷积层，每个层包含顶点到超边（V2E）和超边到顶点（E2V）的变换，使用ReLU激活和残差连接；
  - 图像级超图构建：对批次内所有图像，使用独立图像编码器提取特征向量；计算特征距离矩阵，若距离<ε则建立超边；
  - 伪标签生成：通过超图卷积在图像节点间传播信息，对未标注节点，聚合相邻标注节点的概念概率，结合KNN（检索批次外标注数据）加权平均，得到最终伪概念概率，并二值化得到伪标签；
  - 损失计算：标注数据使用二元交叉熵损失监督概念预测，使用交叉熵损失监督任务预测；未标注数据使用MSE损失对齐预测概念与伪概念标签。
- 训练/推理细节：
  - 训练时：联合优化标注数据和未标注数据，总损失包括任务损失（分类交叉熵）、标注概念损失（BCE损失）、未标注概念损失（MSE损失），超参数α和β平衡各项；
  - 推理时：输入图像经过图像编码器和概念编码器得到概念嵌入，再经HECRL模块精炼，最后通过标签预测器输出类别概率；
  - 概念编码器采用CEM结构，每个概念对应两个全连接层生成正负嵌入，评分函数为可学习的线性层加sigmoid；
  - HECRL和HIDP模块中的超图卷积共享权重，批处理时每个图像独立构建概念超图，但图像级超图在批次内统一构建。

### 16. Geometry-Preserving Unsupervised Alignment for Heterogeneous Foundation Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.04385v1
- 方法流程：
  - 输入：VFM视觉特征Z (N×dv)、VLM视觉特征X (N×dt)、VLM文本原型Y (K×dt)，超参数λ
  - 阶段1 - UCM：初始化P和C，迭代T次：计算亲和矩阵R = (1-λ)Z C^T + λ X Y^T，经Sinkhorn算法得到P，根据P更新C为加权质心
  - 阶段2 - GPA：基于UCM得到的P，求解正交映射W满足 min_{W^T W=I} ||Z W - P Y||_F^2，获得闭式Procrustes解
  - 输出：正交变换W，用于将VFM特征映射到VLM语义空间
- 关键模块/机制：
  - Unsupervised Correspondence Mining (UCM)：推断样本与文本原型之间的软对应关系P，同时考虑VFM几何结构和VLM语义；目标函数 min_{P∈Π(r,c), C} (1-λ)||Z - P C||_F^2 + λ||X - P Y||_F^2 - εH(P)，其中P为软分配矩阵（行和列约束），C为VFM空间可学习质心，使用Sinkhorn-Knopp算法交替优化P和C
  - Geometry-Preserving Alignment (GPA)：基于UCM得到的对应关系，学习正交映射W将VFM特征变换到VLM空间；求解正交Procrustes问题：min_{W^T W=I} ||Z W - P Y||_F^2，得到闭式解W = U V^T，其中U和V来自SVD分解
  - 熵正则化及Sinkhorn求解：使对应矩阵P光滑可微，通过矩阵缩放高效求解；在UCM子问题中，目标变为max_{P∈Π(r,c)} ⟨P, (1-λ)Z C^T + λ X Y^T⟩ + εH(P)，通过Sinkhorn-Knopp算法迭代归一化行和列
- 公式/目标函数/指标定义：
  - UCM目标：min_{P∈Π(r,c), C} (1-λ)||Z - P C||_F^2 + λ||X - P Y||_F^2 - εH(P)
  - P更新子问题：max_{P∈Π(r,c)} ⟨P, (1-λ)Z C^T + λ X Y^T⟩ + εH(P) (熵正则化最优传输)
  - C更新闭式解：C_k = (∑_i P_{ik} Z_i) / (∑_i P_{ik})
  - GPA正交映射：min_{W^T W=I} ||Z W - P Y||_F^2
- 算法细节：
  - UCM采用交替优化：固定C时，通过Sinkhorn算法求解P；固定P时，通过加权平均更新C
  - Sinkhorn算法步骤：对亲和矩阵R = (1-λ)Z C^T + λ X Y^T进行行和列归一化，迭代直到收敛
  - GPA阶段：对矩阵M = Z^T P Y进行SVD分解得到U和V，然后W = U V^T
- 训练/推理细节：
  - 完全无监督，使用数据集训练集（或少量样本）学习映射W，无需标签或模型参数更新
  - 零样本分类：用学习到的W变换VFM图像特征，与文本原型Y计算余弦相似度进行分类
  - 开放词汇分割：在patch级别对齐，使用DINOv3 patch特征，通过W映射后与CLIP文本特征匹配
  - 推理时只需一次矩阵乘法W应用于特征，开销可忽略

  - Orchestrator：中央控制器，负责路由决策和反思循环管理；基于规则的决策逻辑：简单查询→直接检索；复杂查询→分解流水线；评估失败且反思次数<2→触发反思；否则输出当前答案。
  - Query Classifier Agent：对输入查询进行分类，启用元数据过滤；将查询分为简单或复杂，并识别相关文档类型（如runbook、incident report），后续检索时根据元数据属性过滤候选块。
  - Query Decomposer Agent：将复杂多跳查询分解为有序子查询；检测多跳结构（涉及多实体或链式依赖），生成子查询列表，确保每个子查询的检索结果可被后续子查询利用，最后聚合各子查询答案形成一致响应。
  - Answer Evaluator Agent：对生成答案进行多维质量评估；沿四个轴评估：查询相关性、引用准确性、上下文支撑（证据充分性）、幻觉检测。若任一维度不达标，则标记失败。
  - Retriever + LLM（FAISS + Llama-3.1-8B）：执行文档检索和答案生成；使用FAISS近似最近邻索引，文档经Docling预处理、语义分块（600字符/重叠100）、BGE-base-en-v1.5嵌入。LLM基于检索结果生成回答。
- 算法细节：
  - 查询分类规则：基于简单/二分类，触发元数据过滤；分类器为独立LLM调用
  - 分解子查询生成：LLM按要求输出有序子查询列表
  - 检索策略：对每个子查询独立从FAISS索引检索top-k（k未指定，通常为5或10），结合元数据过滤（如document_type）
  - 反思机制：Orchestrator维护reflection_counter，初始0；评估失败且counter<2时，触发refine（如重新选择chunks或调整prompt），counter++，然后重新检索和生成；达到上限则直接输出当前答案
  - 文档预处理：使用Docling将PDF/DOCX/YAML转为结构化Markdown，注入YAML frontmatter（含document_type等元数据），然后语义分块并嵌入
- 训练/推理细节：
  - 推理阶段使用Llama-3.1-8B模型，基于本地隐私优先推理栈，无模型参数训练
  - Agent调用基于预定义prompt模板，每个Agent由同一个LLM实例通过不同系统提示实现
  - 检索使用BGE-base-en-v1.5嵌入模型，FAISS索引构建在预处理阶段一次性完成
  - 反思循环最多2次，避免无限延迟

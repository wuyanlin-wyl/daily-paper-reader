### 2. Benchmarking Vision-Language Models for Microscopic Plant Image Understanding
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22497v1
- 方法流程：
  - 1. 数据采集：从同行评审出版物和开放仓库中收集5,210张显微镜图像，涵盖真菌学、线虫学、植物学、细胞生物学等领域，以及光学、荧光、电子显微镜模态。
  - 2. 数据标准化：将所有图像统一转为JPEG格式，分配唯一标识符，构建结构化JSON元数据（包括生物域、成像模态、染色方法、宿主物种等），由两位生物学家独立验证。
  - 3. 任务定义：定义10个任务（模态识别、域分类、树脂识别、染色/染料识别、宿主识别、病原分类、细胞器检测、器官预测、目标计数、目标定位），其中前8个为多选识别，后2个支持多选和直接预测。
  - 4. VQA生成：基于元数据自动生成9,718个VQA对，识别任务中干扰项从同一字段其他有效值中采样，计数任务中干扰项通过扰动真值附近整数生成，定位任务中候选框为空间偏移的非重叠框。
  - 5. 评估：采用统一管道，对所有模型使用相同输入处理和提示设计，评估指标包括宏/微准确率、MAE、RMSE、mAP@0.5和平均IoU。
- 关键模块/机制：
  - 数据标准化模块：确保来自不同来源的数据格式统一、元数据完整且可靠。；将原始图像统一为JPEG格式，保持原始分辨率；为每张图像分配唯一标识符并保留源信息；构建结构化JSON记录存储元数据，关键属性通过原始出版物、数据提供者或领域专家验证，并由两位生物学家独立审查，不一致的样本被移除。
  - VQA生成模块：根据元数据和任务定义自动生成多选题VQA对，确保语义合理性。；识别任务从同一元数据字段的其他有效值中采样干扰项；计数任务将真值整数加减附近值作为干扰项；定位任务生成与真值框大小相似但位置偏移的非重叠候选框。所有VQA对由两位领域专家审查，不一致的样本被排除。
  - 统一评估管道：提供标准化评估环境，确保不同模型公平比较。；对所有模型使用相同输入处理（图像尺寸、提示格式）；识别任务要求模型从四个选项中选择正确答案；计数任务要求输出整数；定位任务要求输出固定格式的边界框坐标；格式错误的预测视为失败。
- 公式/目标函数/指标定义：
  - Micro accuracy = sum_i TP_i / sum_i N_i
  - Macro accuracy = (1/C) * sum_i (TP_i / N_i)，其中C为类别数，TP_i为类i正确预测数，N_i为类i样本总数。
  - MAE = (1/n) * sum_i |pred_i - true_i|
  - RMSE = sqrt( (1/n) * sum_i (pred_i - true_i)^2 )
  - mAP@0.5: 在IoU阈值为0.5时的平均精度均值
  - IoU = intersection / union
- 算法细节：
  - 数据采集时优先使用公开数据集，对不可直接访问的通过联系作者获取许可。
  - 图像重命名：为每个图像分配唯一标识符，同时保留源信息以避免文件名冲突。
  - VQA生成：对于识别任务，干扰项从同一元数据字段的其他有效值中均匀随机采样，确保语义一致且视觉上合理；对于计数任务，干扰项通过对真值整数±1,2等扰动生成；对于定位任务，候选框通过将真值框沿x,y方向移动固定像素量生成，且保证候选框之间非重叠。
  - 所有VQA对经过两位植物病理学和显微镜学背景的专家独立审查，评估属性-问题对齐、视觉证据一致性以及候选选项的生物学合理性。

  - 输入图像统一调整至模型要求的尺寸（如224x224），提示格式根据任务定制。
  - 使用两台NVIDIA A6000 GPU进行推理。
  - 评估分为多选设置（模型从选项中选择）和直接预测设置（模型直接输出计数或坐标）。

### 3. 4DVLT: Dynamic Scene Understanding with Worldline-Centered Vision-Language Tracking
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22631v1
- 方法流程：
  - 1. 输入：校准后的多视图视频片段V = {Ict}，相机标定K，自然语言查询q。前端提取候选3D对象状态及保留的每视图2D证据。
  - 2. 构建对象中心4D状态图G = (Vs, Es)：节点为候选3D状态zit（包含外观、3D位置与范围、时间戳、可见性、2D支持），边编码时间可行的转移。每个状态通过投影函数ϕproj编码为状态嵌入hit。
  - 3. 查询条件候选收缩：根据路由logit ℓu,i（结合语义、度量可达性）计算每个候选的保留权重，保留每帧top-M状态并在一跳可达性下闭合形成子图Ĝ。
  - 4. 离线双向世界线推理：在子图Ĝ上，解码器正向和反向分别预测世界线，训练优化正向、反向及交叉方向的一致性损失。
  - 5. 物理校准统一输出：在可行路径集上，用αq混合模型得分与运动学先验得分选择最优世界线Ĵ。然后通过视图对齐头输出3D中心轨迹和每相机的2D盒子（可见时局部精化，否则从解码状态和相机嵌入预测回退盒子）。
  - 6. 输出：完整世界线，包括3D轨迹{ct}和同步多视图2D盒子{ˆbct}。
- 关键模块/机制：
  - 对象中心4D状态图：表示候选对象随时间演化的可行空间，将身份、几何、可见性与跨视图支持耦合。节点为候选状态，边为时间转移。；每个状态zit包含外观特征ait、3D位置与范围git、时间戳、可见性及保留的2D支持。通过ϕproj投影到共享状态嵌入空间hit = ϕproj(ait, git, uit)。序列化为按时间排序的状态与边令牌，供语言骨干推理。
  - 查询条件候选收缩（路由）：减少全图歧义，保留与指令最兼容的候选状态和转移，形成子图Ĝ。；路由logit ℓu,i = ru,i + α*s*a_text_i + α_m*(-||δu,i||2^2/(σ̂u^2+ε) + β*χ_reach(i))，其中ru,i为潜在查询与节点相似度，a_text_i为全局文本-节点相关性，δu,i为节点到度量锚点的中心偏移，χ_reach指示是否参与有效转移。对每个候选状态，在潜在查询上平均softmax概率得到保留权重，保留每帧top-M状态并闭包一跳可达性。
  - 离线双向世界线解码器：利用全观测设置，双向自回归预测世界线，提升非局部时间推理。；解码器分解为目标世界线概率：p_d(W^(d)) = ∏_{t=1}^L p_d(z_t^(d)|z_<t^(d))，d∈{f,b}。训练时优化匹配的正向、反向和交叉方向一致性损失，具体展开见附录A。
  - 物理校准统一输出：结合语义模型得分与运动学先验，解码物理可行的最优世界线，并输出统一3D轨迹与多视图2D盒子。；在可行路径集P(Ĝ)上，解码：Ŵ = argmax_{W∈P(Ĝ)} ∑_t [α_q*s_mt + (1-α_q)*s_pt]，其中s_mt=log p_model(z_{t+1}|z≤t,q,Ĝ)，s_pt=-E_t(z_{t+1})，α_q为查询类型依赖的混合系数。然后通过视图对齐头得到3D中心c_t和每相机2D盒子ˆb_c_t。
- 公式/目标函数/指标定义：
  - 状态嵌入：hit = ϕproj(ait, git, uit) (Eq.6)
  - 路由logit：ℓu,i = ru,i + αs a_text_i + α_m( -||δu,i||2^2 / (σ̂u^2+ε) + β χ_reach(i) ) (Eq.7)
  - 双向解码分解：pd(W^(d)) = ∏_{t=1}^L pd(z_t^(d)|z_<t^(d)), d∈{f,b} (Eq.8)
  - 物理校准解码：Ŵ = argmax_{W∈P(Ĝ)} ∑_t [α_q s_mt + (1-α_q) s_pt] (Eq.9)
  - 统一输出：Ŷ = ({ct}, {ˆb_c_t}) (Eq.10)
  - 指标公式：TGA = 1/N ∑ δ(mi, y*_i)；TGA_Top1 = 1/N ∑ δ(m_i^(1), y*_i)；WQS = 1/N ∑ Qi；CTQ = (∑ δ(mi, y*_i)Qi) / (∑ δ(mi, y*_i)+ε) (Eq.1-5)
- 算法细节：
  - 前端提取：通过检测器获取每帧候选3D状态和对应2D框，并保留可见性标志。
  - 图构建：按时间顺序排列状态节点，在相邻帧间建立边，若3D距离和外观相似度满足阈值则认为可行转移。
  - 路由收缩：对每个查询q，提取其潜在查询表示（如通过投影），计算与所有候选状态嵌入的相似度，再结合语义文本相关性和度量偏移计算logit，经softmax获得每个候选的保留概率，保留每帧top-M并扩展一跳可达性。
  - 双向解码：正向和反向分别自回归解码世界线，每个时间步从当前子图候选中选择下一个状态，利用beam search保持多个候选。
  - 运动学校准：定义能量函数Et(zt+1)衡量运动平滑性（如速度变化、加速度），模型得分来自解码器概率，两者加权求和得到路径得分。
  - 视图对齐：对于每个相机，若解码状态有可见性支持，使用局部精化网络调整2D框；否则从解码3D状态和相机参数投影并回归得到回退框。
- 训练/推理细节：
  - 训练策略：按阶段训练，先路由预热稳定候选收缩，再双向世界线学习，最后一致性校准激活完整目标。
  - 损失函数：由路由损失、双向解码损失（正向、反向、交叉方向一致性）和视图对齐损失加权组合，具体展开见附录A。
  - 骨干模型：默认使用冻结Qwen3.5-9B骨干，4-bit QLoRA适配器，可训练的图、路由、节点和视图对齐头。
  - 训练顺序：先在EgoWL子集训练，再在AlloWL子集训练。
  - 推理：输入多视图视频和查询，经过前端、图构建、路由、双向解码（beam search）和物理校准得到最终世界线。

### 4. T-VSS: Test-Time Visual Subspace Steering for Adversarial Robustness of Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.23132v1
- 方法流程：
  - 输入：一张潜在对抗测试图像x，生成N+1个随机增强视图（含原图）构成集合X(x)={x0, x1, ..., xN}
  - 特征提取：使用CLIP图像编码器F(·)提取每个视图的视觉特征fi = F(xi) ∈ Rd
  - 构建特征残差：计算每个视图特征与锚定特征（通常为原图特征f0）的残差ri = fi - f0，堆叠成残差矩阵R ∈ R^{d × N}
  - 低秩子空间构建：对R进行SVD分解，保留累积解释方差达到阈值ρ（如0.9）的前m个奇异向量，构成正交基U ∈ R^{d×m}
  - 共享特征修正学习：在子空间U中参数化修正向量Δf ∈ R^d（即U * α），通过最小化可靠性加权的熵来优化α，优化目标为Σ_i w_i * H(p_i')，其中p_i'是修正后特征f_i' = f_i + Δf的预测概率，w_i为可靠性权重
  - 输出：使用修正后的特征f_0'进行零样本分类
- 关键模块/机制：
  - 多视图特征残差构建：生成样本特定的特征变化信息，用于捕捉对抗扰动在特征空间中的局部结构；对测试图像进行AugMix增强得到多个视图，计算每个视图特征与原始图像特征的差值，堆叠成残差矩阵R
  - 低秩子空间构建（SVD）：从残差矩阵中提取主要的特征变化方向，形成紧凑的低维几何空间；对残差矩阵R进行奇异值分解，根据解释方差阈值ρ选择前m个主成分，得到正交子空间基U
  - 共享特征修正学习：在子空间内学习一个对所有视图通用的特征偏移向量，使攻击特征向干净方向移动；将修正向量Δf表示为Uα，其中α为m维系数，通过优化可靠性加权的熵损失来求解α，确保修正后特征预测更稳定且判别性更强
  - 可靠性加权机制：根据每个视图特征与邻域的一致性赋予不同权重，减少不可靠视图的影响；基于视图特征在特征空间中的局部邻域计算可靠性权重，权重与特征在最近邻中的一致性成正比
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 使用AugMix增强生成64个视图（含原图）
  - 特征残差矩阵R通过所有视图特征减去原图特征计算
  - SVD分解R得到奇异向量和奇异值，根据解释方差阈值ρ=0.9选择保留的维度m
  - 使用AdamW优化器，学习率0.1，单步更新优化子空间系数α
  - 可靠性权重基于特征最近邻的一致性计算，温度参数0.05，Top-K邻域数量K=5
- 训练/推理细节：
  - 仅在测试时进行适应，无需训练或微调
  - 每个测试样本独立处理，使用单步优化
  - 优化过程使用64个视图（原始+63增强）
  - 在推理时，仅对原图特征应用学习到的修正Δf，其他视图只用于计算残差和可靠性权重

### 6. Invoice Haystack: Benchmarking Document Retrieval and Visual Question Answering Under Strong Visual Homogeneity
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.25343v1
- 方法流程：
  - 文本流：OCR提取文档文本，经BGE-Large编码得到文本嵌入，计算查询与文档的余弦相似度Sim_T。
  - 视觉流：分别用SigLIP和OpenCLIP编码文档图像，得到两个视觉嵌入，计算查询与文档的余弦相似度Sim_S和Sim_O。
  - 分数融合：将三个相似度平均得到Sim_Avg = (Sim_T + Sim_S + Sim_O)/3，按Sim_Avg降序选出top-m候选集C_m。
  - VLM过滤：对C_m中每个文档图像与查询配对，通过Qwen3-VL二值验证（能否回答该问题），仅保留回答“yes”的文档作为最终top-k结果R_k；若无yes则返回原top-m。
- 关键模块/机制：
  - 文本编码器 (Text Encoder)：从OCR文本中提取高精度语义特征；使用BGE-Large-En-v1.5作为稠密文本编码器，将OCR提取的文本映射为嵌入向量，计算余弦相似度Sim_T。
  - 视觉编码器 (Vision Encoder)：捕获文档布局和结构特征；集成SigLIP ViT-SO400M/14@384和OpenCLIP ConvNeXt-XXL@1024两个视觉编码器，分别计算相似度Sim_S和Sim_O，零样本使用。
  - 分数融合 (Score Fusion)：综合文本和视觉信号进行统一排序；将三个相似度Sim_T、Sim_S、Sim_O取平均值作为最终得分Sim_Avg，按Sim_Avg降序排列文档，取top-m作为候选集C_m。
  - VLM验证过滤器 (VLM Filter)：利用视觉语言模型的推理能力消除歧义；使用Qwen3-VL对每个候选图像和查询进行二值验证，提示词为“[question] Can this image provide the answer to this question? Answer only yes or no.”，仅保留回答“yes”的文档，若无则回退到top-m。
- 公式/目标函数/指标定义：
  - Sim_T(q, d_i) = ϕT(ˆq)·ϕT(t_i) / (||ϕT(ˆq)|| ||ϕT(t_i)||)，其中ϕT为BGE-Large编码器，t_i为OCR文本。
  - Sim_S(q, d_i) = ϕS(I_q)·ϕS(I_i) / (||ϕS(I_q)|| ||ϕS(I_i)||)，ϕS为SigLIP。
  - Sim_O(q, d_i) = ϕO(I_q)·ϕO(I_i) / (||ϕO(I_q)|| ||ϕO(I_i)||)，ϕO为OpenCLIP。
  - Sim_Avg = (Sim_T + Sim_S + Sim_O) / 3。
  - C_m = arg top-m_{S⊆D,|S|=m} Sim_Avg(q, d_i)。
  - R_k = { d_i ∈ C_m | VLM(I_i, q) = yes }。
- 算法细节：

  - 动态门控因子：α = 1 - tanh(|log πθ(yw|xv,xt) - log πθ(yw|x∅v,xt)|) （公式7）

  - 路由头（Routing Heads）：调节信息流，决定模型关注视觉还是文本令牌；位于网络后半部分（late layers），通过重分配注意力权重，调控从图像令牌到文本令牌的信息流动，Qwen-VL和LLaVA-NeXT表现为重分配注意力，PaliGemma通过表示差异路由。
  - 写入头（Writing Heads）：直接投影答案令牌到残差流，编码先验知识答案；位于更晚的层，通过将答案令牌（如'red'）的表示直接写入残差流，使模型输出先验知识答案，即使视觉输入矛盾。
  - MLP子层：放大器而非主要路由组件；MLP在冲突解决中起放大作用，但方向不对称性弱于注意力头，表明其增强已由注意力头决定的信息流。
- 公式/目标函数/指标定义：
  - 恢复分数：R_d(c) = (Δ_patched_d(c) - Δ_target) / (Δ_source - Δ_target)，其中Δ = logit(t_orig) - logit(t_cf)
  - 翻转率：F_d(c) = (1/N) Σ 1[argmax(patched) ≠ argmax(clean)]
- 算法细节：
  - 激活修补：在最后令牌位置，将源运行（如先验引导）的组件激活替换到目标运行（如视觉引导）的对应组件，保持其他激活不变
  - logit差异计算：取原始色（如'red'）和反事实色（如'blue'）答案令牌的logit之差
  - PCA分类：对所有组件的平均恢复向量（RP2V, RV2P）进行PCA，识别超出±2σ的离群组件
  - 消融：将注意力头输出置零，观察预测变化
- 训练/推理细节：
  - 所有模型为预训练VLM，在推理阶段进行激活修补和消融，不修改模型参数
  - 使用NNsight库提供激活级读写访问，无需修改模型代码
  - 仅分析正确冲突样本（模型在视觉和先验模式下均输出正确答案的样本）

### 16. Venice-H1: Failure-Aware Query Re-Ranking with Multi-Scale Grid Signatures for Referring Image Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.22546v1
- 方法流程：
  - 输入图像I和表达式e，通过冻结的DeRIS骨干生成N个候选掩码概率图Pi、查询嵌入qi、检测分数si。
  - 对每个候选掩码概率图Pi，提取四个标量统计量：平均覆盖率μi、峰值置信度p̂i、二值面积ai、空间不确定性σi。
  - 对每个Pi进行三尺度自适应平均池化和最大池化，分别得到G×G网格（G=4,8,16）的gμ和gmax，并计算边界能量bi（平均绝对梯度），拼接所有尺度得到675维网格签名gi。
  - 将每个候选的查询嵌入qi、检测分数si、掩码统计量和网格签名拼接成特征向量fi（维度D+680）。
  - 所有fi通过共享的两层MLP投影到512维，再经过3层8头Transformer编码器进行跨查询交互，输出hi。
  - Transformer输出通过两个MLP头：Gain Predictor预测每个候选相对于默认查询的IoU增益ĝi；Failure Gate基于全局特征r预测默认查询次优概率p̂fail。
  - 若p̂fail > τ，选择ĝi最大的候选作为最终输出；否则保留默认查询0。返回对应掩码。
- 关键模块/机制：
  - Multi-Scale Grid Signature：将掩码概率图编码为紧凑空间描述子，捕获多尺度空间结构（粗定位、形状、边界细节）。；对每个候选掩码概率图Pi，在G=4,8,16三种分辨率下，分别进行平均池化和最大池化得到gμ_i,G和gmax_i,G，并计算边界能量bi,G（平均绝对梯度）。三者拼接为675维向量gi，公式见(2)-(5)。
  - Transformer Encoder：对候选特征进行跨查询自注意力推理，利用共识检测异常掩码。；L=3层，A=8头，预层归一化GELU FFN。输入为每个候选的投影特征fi（维度936），输出hi。自注意力使重排序器能比较不同掩码的分布，识别偏离共识的异常。
  - Gain Predictor：预测每个候选相对于默认查询的IoU增益。；两层MLP，输入hi，输出标量ĝi。训练目标为平滑L1损失，监督信号是各候选与默认查询的IoU差值∆IoU_i。
  - Failure Gate：预测默认查询是否次优，决定是否触发重排序。；两层MLP，输入全局特征向量r（由Transformer输出的均值、最大值、默认查询输出以及原始分数和掩码均值拼接得到），输出概率p̂fail。训练使用焦点二分类损失。
- 公式/目标函数/指标定义：
  - Pi = σ(Mi) ∈ [0,1]^{H×W} (掩码概率)
  - gμ_i,G = AvgPool^{G×G}(Pi) ∈ R^{G^2}，gmax_i,G = MaxPool^{G×G}(Pi) ∈ R^{G^2}
  - bi,G = 1/2 * (|∇x gμ_i,G| + |∇y gμ_i,G|) (边界能量)
  - gi = [gμ_i,4; gmax_i,4; bi,4; ...; gμ_i,16; gmax_i,16; bi,16] ∈ R^{675}
  - fi = [qi; si; μi; p̂i; ai; σi; gi] ∈ R^{D+680}
  - p̂fail = σ(MLP_f(r))
- 算法细节：
  - Algorithm 1: 输入图像I，表达式e，阈值τ。步骤：1) DeRIS生成候选；2) 计算掩码概率；3) 提取掩码统计量；4) 提取网格签名；5) 拼接特征；6) 重排序器前向计算p̂fail和ĝi；7) 若p̂fail>τ则选ĝi最大的候选；否则选默认查询0；8) 返回对应掩码。
  - 网格签名提取使用自适应池化，适配任意输入分辨率；边界能量计算基于平均池化网格的有限差分。
  - Failure Gate的全局特征r包含Transformer输出的均值、最大值、默认查询输出、原始分数和掩码均值，维度3Hd+2N。
  - 重排序器仅11.3M参数，推理延迟<1ms。
- 训练/推理细节：
  - 训练：使用离线缓存的126k样本特征（~3.2GB），模型参数冻结，仅训练重排序器。
  - 优化器：AdamW，lr=5e-4，wd=1e-4，余弦退火调度，3 epoch预热，20 epoch，batch 512，FP16。
  - 损失：多任务损失L = L_gate + 5*L_gain，L_gate为焦点二分类（γ=2，自动正类权重），L_gain为平滑L1损失（对所有样本计算IoU回归）。
  - 阈值τ在验证集上通过网格搜索最大化Δfull确定。
  - 推理：DeRIS前向→特征提取→重排序器前向，总延迟<1ms（附加）。
  - 训练仅需~3分钟（单GPU）。

### 19. C^2GR: Coupled Comprehensive Generative Replay for a Continually Learnable Universal Segmentation Model
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.23473v1
- 方法流程：
  - 阶段1（重放数据合成）：利用已存储的旧任务提示ζ_i（i<t）调节去噪网络ϵθ，从随机高斯噪声生成图像-掩码对，形成重放数据集R_i。
  - 阶段2（当前任务提示生成）：对新任务t，通过关系感知提示图（基于CLIP文本编码和子图注意力）生成统一任务提示ζ_t。
  - 阶段3（联合优化）：同时优化分割模型fθ和去噪网络ϵθ，使用Memory Evoking损失（L_ME）和Memory Updating损失（L_MU）在重放数据和新任务数据上联合训练。
- 关键模块/机制：
  - Bayesian Joint Diffusion (BJD)：保持生成图像-掩码对的对应关系，避免朴素联合扩散导致的对应失真；BJD将图像-掩码联合分布p(x,y)的MLE目标分解为p(x)p(y)、p(x|y)和p(y|x)三项，其中第一项用朴素联合扩散损失（L_NJD），后两项用条件去噪得分匹配：损失函数L_BJD = ||[ϵx,ϵy] - ϵθ([xk,yk],k)||^2 + ||[ϵx,0] - ϵθ([xk,y0],k)||^2 + ||[0,ϵy] - ϵθ([x0,yk],k)||^2。
  - Relation-aware Unified Prompt Synchronization (RUPS)：生成统一的任务提示并同时注入分割器和生成器，同步优化两个模型；RUPS首先构建关系感知提示图：对每个任务使用文本模板'[I] image of [A] for [SO]'，经CLIP编码后投影为图节点。定义6个子图（按属性子集），每个子图通过线性层计算注意力分数a_{i1,i2}^{ΦS}（结合图注意力和余弦相似度），聚合得到子图嵌入z_i^{ΦS}。然后通过可学习的query计算子图重要性权重w_ΦS，加权聚合得到任务提示ζ_i。最后通过交叉注意力机制将ζ_i注入分割模型和去噪网络的每一层。
- 公式/目标函数/指标定义：
  - 朴素联合扩散损失: L_NJD = E[||[ϵx,ϵy] - ϵθ([xk,yk],k)||^2]
  - Bayesian联合扩散损失: L_BJD = E[||[ϵx,ϵy] - ϵθ([xk,yk],k)||^2 + ||[ϵx,0] - ϵθ([xk,y0],k)||^2 + ||[0,ϵy] - ϵθ([x0,yk],k)||^2]
  - Memory Evoking损失: L_ME = L_seg^Dt(fθ^{ζ_t}) + (1/(t-1)) Σ_{i=1}^{t-1} L_seg^{R_i}(fθ^{ζ_i})
  - Memory Updating损失: L_MU = L_BJD^Dt(ϵθ^{ζ_t}) + (1/(t-1)) Σ_{i=1}^{t-1} L_BJD^{R_i}(ϵθ^{ζ_i})
  - 总损失: L = L_ME + L_MU
  - 评价指标: Overall = (1/T) Σ_j D_{T,j}, BWT = (2/(T(T-1))) Σ_i Σ_{j<i} (1 - |min(D_{i,j} - D_{j,j}, 0)|), TL = (1/T) Σ_i D_{i,i}
- 算法细节：
  - 朴素联合扩散中，对图像和掩码同时加噪，导致对应关系破坏；BJD中，条件项分别使用干净图像或掩码作为参考，保留对应关系
  - 关系感知提示图：定义6个子图（I, A, SO, I&A, I&SO, A&SO），每个子图计算注意力分数时结合图注意力（学习参数）和余弦相似度，η为可学习权重平衡二者
  - 统一提示调制：通过交叉注意力（公式6）将ζ_i注入分割器和生成器的特征层，输出调制后的特征τ_l
- 训练/推理细节：
  - 训练时，每个新任务到来后，先使用旧任务提示生成重放数据，再生成当前任务提示，最后联合优化分割器和生成器
  - 分割器使用UNet骨干（通道数[32,64,128,256,512,512,512]），生成器使用UNet骨干（通道数[128,128,256,256,512,512,512]）
  - 优化目标：L_ME使用Dice损失和交叉熵损失的和，L_MU使用BJD损失
  - 推理时，使用当前任务的提示调制分割器，直接对输入图像进行分割

### 27. Modular Diffusion Models for Structured Visual Recognition
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.22702v1
- 方法流程：
  - 图像编码阶段：输入图像经过卷积骨干（如ResNet）提取多尺度特征图，再通过Transformer编码器转换为位置感知的扁平化图像特征I
  - 扩散前向过程：对每个组件（框、标签、掩码）分别定义前向扩散过程，框使用高斯扩散，标签和掩码采用连续松弛后的高斯扩散
  - 去噪解码阶段：对于每个条件扩散模型，用Transformer解码器迭代去噪。输入包括当前时间步的噪声集合、图像特征I和祖先条件（如已去噪的框和标签）。解码器通过动态查询生成、自注意力、交叉注意力和FFN逐步输出干净估计
  - 预测输出阶段：将解码器最终输出通过预测头（如MLP）得到各组件的干净结果
- 关键模块/机制：
  - 图像编码器：提取多尺度位置感知的图像特征，为后续去噪提供条件；使用卷积神经网络（如ResNet）提取多尺度特征图，然后通过多层Transformer编码器处理，得到位置感知的扁平化表示I
  - 动态查询生成模块：将噪声输入和时间感知的祖先条件转化为去噪解码器的输入查询；输入噪声集和时间步t，通过fa网络生成调制参数β,γ，通过fq网络生成基础查询，二者结合得到查询q = fq(s_{i,t}) ⊙ (1+β) + γ
  - 去噪解码器层：迭代更新查询，逐步去除噪声；包含三层操作：自注意力、交叉注意力（以图像特征为条件）、FFN，每层使用adaLN-Zero通过时间调制参数α,β,γ对残差进行缩放和偏移
  - 预测头：将解码器输出映射为各组件（框、标签、掩码）的干净估计；通常为多层MLP，输出与组件类型对应的参数（如框坐标、类别logits、掩码像素值）
- 公式/目标函数/指标定义：
  - Pr(S|I) = ∏_{i=1}^{K} Pr({s_i^k} | {Pa(s_i^k)}, I) （式9，DAG因子化）
  - 实例分割分解：Pr(S_seg|I) = Pr({b_i}|I) · Pr({l_i}|{b_i},I) · Pr({m_i}|{b_i,l_i},I) （式10）
  - 场景图生成分解：Pr(S_sg|I) = Pr({b_si, b_oi}|I) · Pr({l_si, l_oi, l_pi}|{b_si,b_oi},I) （式11）
  - 查询生成：q_i^k = f_q(s_{i,t}^k) ⊙ (1+β_i^k) + γ_i^k, 其中(β_i^k, γ_i^k) = f_a(Pa(s_i^k), t) （式12）
  - 去噪层更新：F_x^m(q, c, t) = q + α_x^{k,m} ⊙ L_x^m(q ⊙ (1+β_x^{k,m}) + γ_x^{k,m}, c)，其中(α,β,γ)=f_{x,m}(t) （式13-15）
- 算法细节：
  - 前向过程：对每个组件独立添加高斯噪声，框、标签（连续松弛）、掩码（下采样连续松弛）均使用标准正态噪声
  - 反向过程：每个条件扩散模型使用独立的Transformer解码器，输入噪声集、图像特征和祖先条件，通过迭代去噪输出干净估计
  - 推理时采用祖先采样：按DAG顺序（如框→标签→掩码），每个组件从其对应的扩散模型进行完整去噪序列，不同组件可使用不同数量的去噪步数
  - 标签和掩码的连续松弛：标签用one-hot向量加噪声，掩码下采样到低分辨率后加噪声，从而统一使用高斯扩散
- 训练/推理细节：
  - 训练：每个条件扩散模型独立训练，使用标准扩散损失（如预测噪声的L2损失），不同模块训练互不影响
  - 推理：首先从标准正态采样随机噪声作为各组件初始值，然后按DAG顺序依次执行去噪。每个扩散模型运行固定步数（可不同），最终得到完整结构化输出
  - 图像特征I在编码后固定，作为所有条件扩散模型的共享条件

## 摘要
4D动态场景理解需要将语言锚定到持久的“世界线”上，该世界线结合了身份、度量三维运动以及同步的多视角二维投影。现有范式仅捕获了该结构的一部分：大型多模态模型基于丰富的视觉证据进行推理，但很少保留度量拓扑结构，而视觉-语言跟踪仍然局限于零散的二维或三维输出和局部延续。因此，我们提出4DVLT，这是一个以世界线为中心的任务，用于在完全观测的多视角视频中进行指令条件的4D动态场景理解，以及Instruct-4D，一个包含129.4K问答对、64.7K目标实体、851个场景和9种推理导向查询类型的基准测试。为了应对这一设置，我们提出了4DTrack，该方法通过以对象为中心的4D状态图、度量引导路由、双向解码和运动学校准，将指令条件跟踪转化为图条件世界线推理。在Instruct-4D上，4DTrack-Qwen3.5-9B达到了62.68 TGA_Top1，比最佳适配的VLT基线高出19.62分。这些结果表明，以世界线为中心的建模提高了目标定位和恢复的世界线质量。项目页面地址为：https://github.com/mikubaka88/4DVLT。

## Abstract
4D dynamic scene understanding requires grounding language to a persistent worldline that binds identity, metric 3D motion, and synchronized multi-view 2D projections. Existing paradigms capture only part of this structure: large multimodal models reason over rich visual evidence but rarely preserve metric topology, while vision-language tracking remains tied to fragmented 2D or 3D outputs and local continuation. We therefore introduce \textbf{4DVLT}, a worldline-centered task for instruction-conditioned 4D dynamic scene understanding in fully observed multi-view video, and \textbf{Instruct-4D}, a benchmark with 129.4K question-answer pairs, 64.7K target entities, 851 scenes, and 9 reasoning-oriented query types. To address this setting, we present \textbf{4DTrack}, which casts instruction-conditioned tracking as graph-conditioned worldline inference through an object-centric 4D state graph, metric-guided routing, bidirectional decoding, and kinematic calibration. On Instruct-4D, 4DTrack-Qwen3.5-9B reaches 62.68 $\mathrm{TGA}_{\mathrm{Top1}}$ and surpasses the best adapted VLT baseline by 19.62 points. These results show that worldline-centered modeling improves both target grounding and recovered worldline quality. The project page is available at https://github.com/mikubaka88/4DVLT.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 整体框架（4DTrack）

- **核心思想**：将指令条件跟踪转化为图条件世界线推理。给定多视角视频、相机标定和自然语言查询，模型需要识别目标对象并估计其完整世界线（包括3D轨迹和同步多视角2D盒）。
- **关键技术步骤**：

1. **对象中心4D状态图构建**
   - 在每个时间戳，前端提取候选3D状态（包含外观、几何、辅助属性），将其编码为状态嵌入：
     \[
     h_{it} = \phi_{\text{proj}}(a_{it}, g_{it}, u_{it})
     \]
   - 状态图节点为候选状态，边为时间上可行的转移，形成图 \( G = (V_s, E_s) \)。

2. **指令条件候选收缩（Metric-Guided Routing）**
   - 对每个潜在查询 \( u \)，计算路由logit结合语义相关度、度量锚点和高斯偏移：
     \[
     \ell_{u,i} = r_{u,i} + \alpha_s a_i^{\text{text}} + \alpha_m \left( -\frac{\|\delta_{u,i}\|_2^2}{\hat{\sigma}_u^2 + \epsilon} + \beta \chi_{\text{reach}}(i) \right)
     \]
   - 对帧内保持前 \( M \) 个节点并闭合一步可达性，形成子图 \( \hat{G} \)。

3. **离线双向世界线推理**
   - 使用与大语言模型串联的解码器，同时学习前向和反向序列，并约束双向一致性：
     \[
     \mathcal{L}_f = -\sum_{t=1}^L \log p_f(z_t^* \mid z_{<t}^*), \quad \mathcal{L}_b = -\sum_{t=1}^L \log p_b(\bar{z}_t^* \mid \bar{z}_{<t}^*)
     \]
     \[
     \mathcal{L}_{\text{cons}} = \frac{1}{2L} \sum_{t=1}^L \text{KL}(p_t^f \| \tilde{p}_t^b) + \text{KL}(\tilde{p}_t^b \| p_t^f)
     \]

4. **运动学先验联合束搜索**
   - 在解码时结合模型分数和物理先验（速度和加速度惩罚）：
     \[
     \hat{W} = \arg\max_{W \in \hat{P}} \sum_t \left[ \alpha_q s_t^m + (1 - \alpha_q) s_t^p \right]
     \]
     其中 \( s_t^p = -E_t(\cdot) = -(\tau_v \|v_t\|_2 + \tau_a \|a_t\|_2) \)。

5. **统一输出**
   - 对每个解码的状态，使用视图感知对齐头进行2D盒细化或退回到相机感知预测。

- **损失函数**：联合优化路由损失、双向序列损失、对齐损失和一致性损失，采用三阶段训练（路由预热→双向早期训练→一致性校准）。

1. **世界线中心建模有效**：4DTrack-Qwen3.5-9B在TGA_Top1上达62.68，超过最佳VLT基线19.62点；WQS和CTQ也显著领先。

## 7. 优点

## 摘要
语言引导的医学图像分割（LMIS）通过整合临床文本信息，在改善解剖结构和病变的描绘方面显示出巨大潜力。现有方法通常依赖于文本和视觉特征之间的隐式交互或用于跨模态对齐的辅助粗粒度监督。然而，这些方法缺乏明确和细粒度的约束来确保语义一致性，导致语言与分割输出之间的不匹配。为了解决这个问题，我们提出了文本作为光照的Retinex网络（TIRNet），一种新颖的受Retinex启发的框架，将文本嵌入视为语义光照以进行特征调制，从而提高LMIS中的语义一致性。TIRNet在每个解码器阶段引入了两个关键模块：（1）受Retinex启发的文本调制模块（RTMB），它利用正负光照图来增强文本相关的前景特征并抑制背景干扰；（2）一致性细节补偿模块（CDCB），它通过基于光照可靠性的条件一致性门控机制选择性恢复高频细节。此外，我们提出了一种多尺度光照监督损失（MSIS-Loss），包括区域接地对比损失（RGC-Loss），它强制跨模态相似性集中在文本相关的前景区域并在背景区域中被抑制，以及背景抑制损失（BS-Loss），它为负光照图提供像素级监督，共同确保每个解码器阶段的精确跨模态对齐。在MosMedData+和QaTa-COV19数据集上的大量实验表明，TIRNet在LMIS中达到了最先进的性能。代码可在以下网址获取：https://github.com/anaanaa/TIRNet。

## Abstract
Language-guided Medical Image Segmentation (LMIS) has shown great potential to improve the delineation of anatomical structures and lesions by integrating clinical textual information. Existing methods generally rely on either implicit interaction between textual and visual features or auxiliary coarse-grained supervision for cross-modal alignment. However, these methods lack explicit and fine-grained constraints to ensure semantic consistency, causing a mismatch between language and the segmentation outputs. To address this issue, we propose Text-as-Illumination Retinex Network (TIRNet), a novel Retinex-inspired framework that treats text embeddings as semantic illumination for feature modulation, thereby improving semantic consistency in LMIS. TIRNet introduces two key blocks integrated at each decoder stage: (1) the Retinex-inspired Text Modulation Block (RTMB), which employs positive and negative illumination maps to enhance text-relevant foreground features and suppress background interference; and (2) the Consistent Detail Compensation Block (CDCB), which selectively recovers high-frequency details via a consistency-gated mechanism conditioned on illumination reliability. Furthermore, we propose a Multi-Scale Illumination Supervision Loss (MSIS-Loss), comprising a Region-Grounded Contrastive Loss (RGC-Loss) that enforces cross-modal similarity to be concentrated in text-relevant foreground regions and suppressed in background regions, and a Background Suppression Loss (BS-Loss) that provides pixel-level supervision for negative illumination maps, jointly ensuring a precise cross-modal alignment at each decoder stage. Extensive experiments on the MosMedData+ and QaTa-COV19 datasets demonstrate that TIRNet achieves state-of-the-art performance in LMIS. The code is available at: https://github.com/anaanaa/TIRNet.

### 论文提出的方法论：核心思想、关键技术细节
#### 核心思想
- **映射 Retinex 理论**：将视觉特征视为反射率 \(R\)，文本嵌入视为光照 \(L\)，通过光照调制实现前景增强与背景抑制。
- **创新点**：设计正负光照图分别对应文本相关区域（前景）和无关区域（背景），并引入门控细节恢复与多层级监督。

#### 关键技术细节
1. **Retinex-inspired Text Modulation Block (RTMB)**：
   - **输入**：解码器特征 \(F_{dec}\) 和全局文本嵌入 \(e\)。
   - **流程**：
     - 投影：\(t = \mathbf{W}_p e\)，将文本映射到视觉空间。
     - 相关性图：\(A_{h,w} = \langle f_{h,w}/\|f_{h,w}\|_2, t/\|t\|_2 \rangle\)，计算每个空间位置的余弦相似度。
     - 正光照图 \(L^+ = \sigma(\text{AP}(A))\)（平均池化 + Sigmoid），突出高相似度区域。
     - 负光照图 \(L^- = \sigma(-\beta A)\)（负值 + 可学习sharpness \(\beta\)），突出低相似度（背景）区域。
     - 调制：\(F'_{dec} = F_{dec} \odot (1 + \rho L^+) \odot (1 - \kappa L^-) + \gamma F_{dec}\)，其中 \(\rho,\kappa,\gamma\) 为可学习参数（FEF、BSF、RPF）。
   - **作用**：显式放大文本相关前景，抑制背景。

2. **Consistent Detail Compensation Block (CDCB)**：
   - **动机**：RTMB调制后的特征缺少高频细节（边界信息），需从编码器恢复。
   - **流程**：
     - 从编码器提取高频细节：\(D_{raw} = F_{enc} - \text{AP}(F_{enc})\)（去除低频）。
     - 语义一致性门控（SC-Gate）：计算 \(B\) 与 \(D_{raw}\) 的通道级分组归一化点积，经 Sigmoid 得到权重 \(W_{cons}\)，用于保留语义一致的细节。
     - 融合光照门控（FI-Gate）：以 \(L^+\) 为可靠性信号，通过 concat + 卷积门控决定细节注入量 \(G\)。
     - 输出：\(F_{out} = B + G \odot D\)（\(B\) 为 \(F'_{dec}\) 经过卷积的基础表示）。
   - **作用**：选择性恢复前景区域的高频结构，避免引入背景噪声。

3. **Multi-Scale Illumination Supervision Loss (MSIS-Loss)**：
   - **组成**：
     - **Region-Grounded Contrastive Loss (RGC-Loss)**：将每个尺度的相关性图 \(A^{(s)}\) 转化为指数相似度 \(P^{(s)} = \exp(A^{(s)})\)，分别计算前景区域 \(\Omega^+\) 和背景区域 \(\Omega^-\) 的平均激活强度 \(\mu^+,\mu^-\)，然后最大化两者边际：\(\mathcal{L}_{rgc}^{(s)} = -\log\frac{\mu^+}{\mu^+ + \mu^-}\)。
     - **Background Suppression Loss (BS-Loss)**：对负光照图 \(L^{-(s)}\) 施加像素级 BCE 损失，监督其与背景标签（\(1-G^{(s)}\)）的一致性：\(\mathcal{L}_{bs}^{(s)} = \text{BCE}(L^{-(s)}, 1-G^{(s)})\)。
   - **总损失**：\(\mathcal{L}_{total} = \mathcal{L}_{seg} + \lambda_{rgc}\mathcal{L}_{rgc} + \lambda_{bs}\mathcal{L}_{bs}\)，其中 \(\mathcal{L}_{seg}\) 为 Dice + BCE 损失。
   - **作用**：在所有解码器阶段强制显式跨模态对齐，弥补全局文本与局部像素之间的粒度差异。

### 论文的主要结论与发现
- TIRNet 通过将 Retinex 理论映射到 LMIS，利用正负光照图显式分离前景与背景，有效解决了现有方法语义不一致的问题。
- RTMB 与 CDCB 协同工作：前者进行语义光照调制，后者选择性恢复高频细节，在保证语义对齐的同时保留边界精度。
- MSIS-Loss 中的 RGC-Loss 比传统的实例级或像素级对比损失更适合 LMIS，因为它直接操作区域级相似度，缩小了全局文本与局部像素的粒度鸿沟。
- 在 MosMedData+ 和 QaTa-COV19 上，TIRNet 在所有指标上达到 SOTA，验证了方法有效性。

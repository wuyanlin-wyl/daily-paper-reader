## 摘要
视觉语言模型（VLM）在零样本识别中表现优异，但面对对抗性扰动时仍然高度脆弱。最近的测试时自适应方法无需重新训练即可提升鲁棒性，但并未直接修正受污染的视觉表征本身。基于提示的方法自适应可学习的文本提示，而输入空间方法则在测试时优化像素或填充。这些方法能够改善预测，但通过间接且昂贵的优化路径实现。我们提出测试时视觉子空间引导（T-VSS），一种轻量级防御方法，直接在视觉特征空间中进行测试时自适应。T-VSS首先从锚定于被攻击图像的多视图特征残差中构建样本特定的低秩子空间，随后在该子空间内通过可靠性加权熵最小化学习共享特征校正。通过将自适应约束于紧凑的视觉几何结构，T-VSS将被攻击特征引导至更稳定且具有判别性的预测，同时避免噪声化的全空间更新。在细粒度、ImageNet及ImageNet-OOD基准上的实验表明，T-VSS在提升对抗鲁棒性的同时，保持了具有竞争力的干净准确率，且效率优于先前的测试时自适应方法。

## Abstract
Vision-language models (VLMs) achieve strong zero-shot recognition, but they remain highly vulnerable to adversarial perturbations. Recent test-time adaptations improve robustness without retraining, but they do not directly adapt the corrupted visual representation itself. Prompt-based methods adapt the learnable text prompts, while input-space methods optimize pixels or padding at test time. These approaches can improve predictions, but they do so through an indirect and expensive optimization path. We propose Test-time Visual Subspace Steering (T-VSS), a lightweight defense that performs test-time adaptation directly in the visual feature space. T-VSS first builds a sample-specific low-rank subspace from multi-view feature residuals anchored at the attacked image. It then learns a shared feature correction within this subspace using reliability-weighted entropy minimization. By constraining adaptation to a compact visual geometry, T-VSS steers attacked features toward more stable and discriminative predictions while avoiding noisy full-space updates. Experiments on fine-grained, ImageNet, and ImageNet-OOD benchmarks show that T-VSS improves adversarial robustness while maintaining competitive clean accuracy and better efficiency than prior test-time adaptations.

## 2. 方法论
- **核心思想**：在测试时，从被攻击图像的多视图特征残差中提取样本特定的低秩子空间，然后在子空间内学习一个共享的特征校正向量，并通过可靠性加权熵最小化进行优化。
- **关键技术细节**：
  1. **多视图特征抽取**：对被测图像x及其N个增强视图，用冻结的图像编码器一次性提取视觉特征 {f_i}。
  2. **局部视觉子空间估计**：以原始被攻击视图x0的特征f0为锚点，构建残差矩阵R（各增强视图特征减f0）。对R进行奇异值分解（SVD），根据累积奇异值能量阈值ρ自动选择最小活跃秩m，得到右奇异向量基Vm ∈ R^{d×m}（d为特征维度）。
  3. **共享低秩特征引导**：初始化可学习系数向量α ∈ R^m为零，生成共享移位Δ = Vm α，将其加到每个视图特征上并归一化：̃f_i = (f_i + Δ) / ||f_i + Δ||_2。所有视图使用相同的α，保证一致性。
  4. **可靠性加权优化与聚合**：
     - 计算每个视图的可靠性权重w_i：基于视图间特征的top-K最近邻相似度均值，经温度缩放softmax得到。
     - 优化目标：最小化可靠性加权点熵 L_T-VSS = Σ w_i H(p(̃f_i))。
     - 最终预测：可靠性加权的视图概率平均 p_final = Σ w_i p(̃f_i)。
  5. **效率**：图像编码仅一次，后续优化仅在m维子空间系数α上进行，无需重复通过大模型反向传播。

- T-VSS在三个骨干上均获得最佳平均对抗鲁棒性（ResNet-50: 48.5%, ViT-B/16: 45.8%, ViT-L/14: 53.8%），分别比最强先前方法高出3.3、2.9、2.2个百分点，同时保持接近最优的干净准确率。

- 大量消融表明：

## 7. 优点
- **直接性**：直接在视觉特征空间内修正，避免间接的提示或像素优化路径。
- **轻量与高效**：仅优化低维子空间系数（通常1-7个参数），无需重复编码图像或反向传播大模型，推理速度快。
- **鲁棒性优异**：在多种攻击、多种骨干、多个数据集上稳定领先，且干净准确率损失小。
- **可解释性**：通过残差几何结构提供样本特定的适应方向，可靠性加权感知视图质量。
- **泛化性**：不仅适用于标准CLIP，也适用于鲁棒预训练骨干，并可在极少视图下保持强鲁棒性。

## 8. 不足与局限
- **依赖多视图增强**：方法核心需要随机增强视图，这暴露了额外攻击面：在自适应期望变换（EOT-PGD）攻击下，所有增强驱动方法（包括T-VSS）鲁棒性大幅下降至极低水平（如<5%）。这是当前测试时自适应范式的普遍弱点。
- **对特定数据集敏感**：在EuroSAT（遥感图像）上T-VSS弱于TTP，表明某些领域（如卫星图像）的特征几何可能不利于共享低秩校正。
- **未考虑更复杂的多模态攻击**：论文仅关注视觉对抗攻击，未测试针对文本分支或跨模态的攻击。

## 摘要
遥感图像变化描述（RSICC）旨在描述双时相遥感图像之间的变化，具有重要的研究和应用价值。然而，现有方法大多依赖于传统的深度学习架构，模型容量有限，制约了性能。尽管大模型后训练技术在通用领域取得了巨大成功，但由于数据稀缺以及对细粒度变化理解的需求，这些技术直接迁移到RSICC仍面临挑战。为此，我们提出了RSICCLLM，这是首个针对RSICC的大型视觉-语言模型后训练框架。具体来说，我们设计了一种数据生成范式，发布了指令数据集RSICI，并建立了任务特定的RSICC基准。我们进一步引入了差异感知监督微调，以显式提取变化表示，并引导模型感知和理解时间差异。此外，我们提出了双重负例偏好优化（DNPO），采用两种互补的负样本构建策略来构建偏好数据集RSICP，并进一步优化模型性能。大量实验验证了RSICCLLM的优越能力，该模型仅以7B参数就取得了显著成果，超越了规模更大的模型。代码和数据集将在https://github.com/keaill/RSICCLLM公开提供。

## Abstract
Remote Sensing Image Change Captioning (RSICC) aims to describe changes between bi-temporal remote sensing images and holds significant research and application value. However, most existing methods rely on conventional deep learning architectures, and the limited model capacity constrains performance. Although large-model post-training techniques have achieved great success in general domains, their direct transfer to RSICC remains challenging due to data scarcity and the need for fine-grained change understanding. To address this, we propose RSICCLLM, the first post-training framework for large vision-language models in RSICC. Specifically, we design a data generation paradigm, release the instruction dataset RSICI, and establish a task-specific RSICC benchmark. We further introduce Difference-aware Supervised Fine-tuning to explicitly extract change representations and guide the model in perceiving and understanding temporal differences. In addition, we propose Dual-Negative Preference Optimization (DNPO), which employs two complementary negative-sample construction strategies to construct the preference dataset RSICP and further refine model performance. Extensive experiments validate the superior capability of RSICCLLM, which achieves outstanding results with only 7B parameters, surpassing models of substantially larger scales. The code and dataset will be made publicly available at https://github.com/keaill/RSICCLLM.

## 2. 方法论
### 2.1 核心思想
提出**RSICCLLM**，首个为RSICC定制的大视觉-语言模型后训练框架，包含三个阶段：  
1. **指令数据生成**：利用已有变化检测数据集（LEVIR-CD, SYSU-CD等），通过多模态大模型（Qwen-VL-Max）结合二值掩码作为几何先验，自动生成高质量指令样本，构建RSICI数据集。  
2. **差异感知监督微调（Difference-aware SFT）**：在Qwen2.5-VL-7B基础上，显式提取并融合变化表示，增强模型对时间差异的感知。  
3. **双重负例偏好优化（DNPO）**：通过两种互补的负样本构造策略构建偏好数据集RSICP，进行偏好优化，进一步细化生成质量。

### 2.2 关键技术细节
- **差异感知监督微调**：
  - 对双时相图像进行可微分空间配准后，计算差值图 \( T = I_1 - I_2 \)。
  - 引入基于中心差分卷积（CDConv）的8个几何敏感卷积核（含标准卷积、CDConv、方向性非对称算子等），提取时空不变几何纹理特征，再通过Hough变换和逆变换在参数空间累积几何证据，得到归一化几何-纹理特征 \(\Delta S\)。
  - 使用交叉注意力融合 \(T\)（查询）与 \(\Delta S\)（键值），生成最终变化表示 \(F\)，并注入视觉编码器输出 \(V_{\text{enhanced}} = V_{\text{orig}} + F\)。
  - 训练使用自回归损失 \(L_{\text{AR}}\)（式9）。

- **双重负例偏好优化（DNPO）**：
  - **策略1：信息过滤负样本选择**。对每个输入，模型生成K个候选描述，提取关键词（object, direction, change verb, quantity），计算与真实描述在关键词集上的平均相似度（BLEU-1/2 + ROUGE-1），选择相似度在阈值 \(\tau_1, \tau_2\) 之间的作为负样本。
  - **策略2：替换式负样本构造**。对真实描述的关键词进行随机替换（从同类词池中选取），生成多个语义错误但语法自然的负样本。
  - 偏好优化目标：\(L = L_{\text{DPO}} + \lambda L_S\)，其中 \(L_{\text{DPO}}\) 为标准DPO损失，\(L_S\) 为反向KL散度约束，防止策略模型偏离参考模型过远。

## 6. 主要结论与发现
- RSICCLLM（仅7B参数）在域内测试集上**全部8个指标显著优于所有对比模型**，包括InternVL-3.5-241B、Qwen3-VL-235B等百亿级模型。例如BLEU-4达62.78 vs 第二高的3.73（GLM-4.5V），提升幅度超过10–60%。

- DNPO在SFT基础上进一步提升所有指标（如BLEU-4从61.68到62.78），尤其在困难样本上提升7.4%。

- 交叉注意力融合\(T\)和\(\Delta S\)优于简单拼接或逐元素操作。
- 稳定性损失\(L_S\)能防止DPO训练崩溃，确保训练稳定并达到更高性能。

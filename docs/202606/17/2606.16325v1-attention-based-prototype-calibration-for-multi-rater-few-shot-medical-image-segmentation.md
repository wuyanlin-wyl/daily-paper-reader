## 摘要
少样本医学图像分割方法通常假设单一的真实标注，忽略了临床数据集中常见的不同专家评估者之间的系统性差异。我们提出了一种基于注意力机制的原型校准框架，用于少样本多评估者分割，该框架在原型空间中建模评估者特定偏离共识表示的情况。一种轻量级但原则性的注意力算子直接优化评估者原型，无需修改骨干特征提取器，使得该方法与现有的基于原型的少样本分割方法完全兼容。这种设计在保持语义一致性的同时，以最小的计算开销实现个性化分割输出。在多评估者医学成像数据集上的实验表明，该方法相比基线原型方法具有持续改进，凸显了结构化原型校准在建模标注变异性方面的有效性。我们的代码可在 https://github.com/truong2710-cyber/JAPC 获取。

## Abstract
Few-shot medical image segmentation methods typically assume a single ground-truth annotation, overlooking systematic variability across expert raters commonly observed in clinical datasets. We propose an attention-based prototype calibration framework for few-shot multi-rater segmentation that models rater-specific deviations from a consensus representation in prototype space. A lightweight yet principled attention operator directly refines rater prototypes without modifying the backbone feature extractor, making the approach fully compatible with existing prototype-based few-shot segmentation methods. This design preserves semantic consistency while enabling personalized segmentation outputs with minimal computational overhead. Experiments on multi-rater medical imaging datasets demonstrate consistent improvements over baseline prototype approaches, highlighting the effectiveness of structured prototype calibration for modeling annotation variability. Our code is available at https://github.com/truong2710-cyber/JAPC.

## 1. 核心问题与整体含义（研究动机和背景）
**研究动机**：临床上医学图像往往由多位专家标注，不同专家之间存在系统性标注差异（如边界容忍度、临床解读差异），这种“评估者间变异性”（inter-rater variability）是结构化的风格差异而非随机噪声。然而，现有少样本医学图像分割（FSMIS）方法普遍假设每个图像只有单一可靠标注，忽略了多评估者场景。将多个标注简单合并为共识会丢失评估者特有信息，而独立训练各评估者模型又无法利用共享语义结构。

**整体含义**：本文首次正式提出“少样本多评估者分割”问题（few-shot multi-rater segmentation），要求模型在仅给定少量带有多评估者标注的支持图像时，为每个查询图像输出与支持集中各评估者风格对应的 R 个个性化预测，而非单个共识结果。这对临床实际具有重要意义——不同医生习惯不同，模型应能提供符合各医生风格的分割结果，同时兼顾标注稀缺性。

## 2. 方法论
### 2.1 核心思想
在原型空间（prototype space）中对每个评估者的原型进行校准，建模其相对于共识原型的结构化偏差。通过一个轻量级的联合注意力模块（Joint Attention-based Prototype Calibration, JAPC）实现，该模块可直接插入任何基于原型的FSMIS方法，无需修改骨干网络。

### 2.2 关键技术细节
1. **共识原型与偏差计算**：
   - 由 R 个评估者支持掩码的平均得到共识掩码 `y_s^{(0)}`，提取共识原型 `p_c^{(0)}`。
   - 每个评估者 r 的偏差 `Δ_c^{(r)} = p_c^{(r)} - p_c^{(0)}`。

2. **联合注意力原型校准（JAPC）**：
   - 将所有评估者原型拼接为矩阵 `P_c`（尺寸 N_total × D）。
   - 对前景和背景原型分别应用共享的自注意力机制：
     - Q = P_c W_q, K = Δ_c W_k, V = P_c
     - 注意力权重 A = σ(Q K^T / √D)，校准后原型 `\tilde{P}_c = A V`。
   - 分离出各评估者的校准原型 `\tilde{p}_c^{(r)}`，用于查询预测（余弦相似度 + softmax）。

3. **校准损失（Calibration Loss）**：
   - `L_calib = (1/R) Σ_r Σ_c ||p_c^{(r)} - \tilde{p}_c^{(r)}||_2^2`，防止原型过度偏离语义锚点。

4. **伪风格生成（Pseudo-Style Generation）**：
   - 基于超像素生成伪标签 y_pseudo，通过随机结构变换（如膨胀/腐蚀）生成 R 种风格变体 `\tilde{y}^{(r)}`，用于训练中的支持标签和查询监督，以弥补多评估者标注的缺失。

5. **两阶段训练策略（Two-Stage Training）**：
   - 前 T/2 迭代：不启用 JAPC 和伪风格，仅训练基础原型模型。
   - 后 T/2 迭代：启用 JAPC 和伪风格，继续联合训练。这提升了早期训练稳定性，防止原型漂移。

6. **总体目标**：
   - 分段损失：`L_seg = (1/R) Σ_r L_seg^{(r)}`（交叉熵）。
   - 对齐损失（双向学习）：`L_align = (1/R) Σ_r L_align^{(r)}`（利用查询预测支持）。
   - 总损失：`L = L_seg + L_align + L_calib`。

### 2.3 公式 / 算法流程（文字说明）
1. 对每个 episode：
   - 提取支持图像特征 F_s，由 R 个支持掩码得到 R 个评估者原型 p_c^{(r)} 和共识原型。
   - 计算偏差 Δ_c^{(r)}，输入 JAPC 模块得到校准原型 \tilde{p}_c^{(r)}。
   - 对查询特征 F_q 计算余弦相似度，经 softmax 得到 R 个预测掩码。
   - 计算分割损失、对齐损失、校准损失，反向传播更新网络。
2. 训练分两阶段，先无 JAPC/伪风格，后开启。
3. 推断时：直接用训练好的 JAPC 和基础网络，给定支持集，输出 R 个预测。

## 3. 实验设计
### 3.1 数据集与场景

- **QUBIQ Brain-Growth**（脑MRI，Brain-MRI）：一个类别（脑生长），7位标注者。34训练/5测试扫描（因无官方测试集，使用验证集评测）。

## 8. 不足与局限
- **胰腺分割性能尚落后于超体素方法**：如Q-Net、RPT在胰腺上的表现优于本文改进的SSL-ALPNet/DSPNet，说明超像素方法在该器官上仍存在碎片化问题，即使引入伪风格也不能完全消除。
- **数据集覆盖有限**：仅测试了CT和MRI两个模态，未在更多多评估者标注数据集（如LIDC-IDRI）上验证，结论的泛化性需进一步检验。
- **评估者数量固定**：框架需要预先知道R（评估者数量），若部署时评估者数量与训练时不匹配（如少或更多）可能需要重新调整或微调，未讨论动态适应。
- **无算力报告**：缺少GPU型号、训练时间等细节，不利于复现资源评估。
- **未与最新的少样本分割方法（如基于Transformer的）对比**：基线仅选用较经典的SSL-ALPNet、DSPNet等，未对比更先进的少样本方法（如MM-Net、HSNet等）是否有更好结果，可能低估了基线差距。
- **全监督上限不够强**：仅训练50epoch，可能未充分收敛，导致上限较低，但作为相对比较仍可接受。
- **应用限制**：如果真实场景中评估者风格差异极大（如完全不同标注协议），仅依赖原型偏差建模可能不足以捕捉复杂差异，需结合更精细的特征级建模。

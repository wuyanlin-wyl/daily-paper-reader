- 方法流程：

  - 阶段4：RL训练 - 使用GRPO算法，以Scale-VQA为训练任务，优化策略模型，奖励函数包括答案正确性和推理过程质量。

### 4. Do Vision-Language Models See or Guess? Measuring and Reducing Textual-Prior Reliance with a Phrasing-Controlled Benchmark
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.10400v1
- 方法流程：
  - 1. 图像收集：从21个公开基准选取540张图像，覆盖6个推理类别（OCR/图表/常识物理/空间场景/视觉推理/数学），用感知哈希去重。
  - 2. 问题生成：对每张图像，使用Gemini-2.5-Pro通过四种策略生成变体：Question-Guided（重写源问题为更依赖图像的形式）、Subquestion-Guided（单次生成感知子问题并合成）、Multi-Signal（多轮对话获取子问题并与源问题和聊天摘要融合）、Vision-Grounded（仅基于图像生成，无文本上下文）。
  - 3. 评估：11个VLM（含闭源和开源）在五个条件（四个变体+无图像消融）上评估，使用Qwen3-14B作为LLM评判。
  - 4. 人类验证：用自定义web应用对Vision-Grounded变体进行人工重标注，确认答案可仅从图像得出。
  - 5. GRPO后训练：将440张图像作为训练集，100张保留为测试集，对Qwen3.5-4B使用GRPO（奖励=格式0.3+答对0.7）和LoRA按变体微调，再在分布外数据上测试迁移。
- 关键模块/机制：
  - 四变体生成策略：通过变化问题措辞控制文本泄漏程度，使图像内容固定，从而归因准确率变化于措辞。；四种策略：Question-Guided（基于源问题和图像重写为更难图像依赖形式）、Subquestion-Guided（单次生成感知子问题然后合成最终问题）、Multi-Signal（多轮对话逐步生成子问题，融合源问题和聊天摘要）、Vision-Grounded（仅输入图像，无文本，要求完全基于视觉生成问题）。
  - 无图像消融诊断：直接度量模型对文本先验的依赖程度。；对每个开源VLM，仅输入问题文本（移除图像），计算准确率。开源模型准确率降至1-9%，表明问题本身无法从文本回答。
  - GRPO后训练框架：通过强化学习减少文本先验依赖，使模型更注重图像内容。；使用GRPO（Group Relative Policy Optimization），奖励函数由格式奖励（0.3权重）和答案正确性（0.7权重）组成。采用LoRA按变体微调，每个变体独立适配器。在440张训练集上训练，100张测试集上评估，并在6个清洁来源和ViLP上测试分布外泛化。
  - LLM评判系统：自动化评估模型输出正确性。；使用Qwen3-14B作为评判，对模型输出与真实答案比较，生成正确性判断。
- 公式/目标函数/指标定义：
  - 奖励函数: R = 0.3 * format_reward + 0.7 * answer_correctness_reward
  - 无图像消融诊断: Accuracy_without_image (模型回答来自文本先验的程度)
  - 变体难度评分: 由Claude评定的1-10难度分数
- 算法细节：
  - 感知哈希去重：使用感知哈希计算图像指纹，移除近重复图像。
  - 变体生成中的提示策略：Gemini-2.5-Pro接受不同提示模板以生成四种变体，提示见附录A。
  - 人工重标注：通过Web应用，人类标注者对Vision-Grounded问题给出答案，然后与基准答案比较，验证图像可回答性。
  - LLM评估过程：对每个模型-图像-变体组合，将问题+图像输入模型（或仅问题），得到文本输出，再由Qwen3-14B判断是否与真实答案一致。
- 训练/推理细节：
  - 训练数据：440张图像，每张图像有4个变体，共1760个问题-答案对。
  - 训练方法：GRPO，每组奖励基线从组内均值计算；使用LoRA适配器（每个变体独立），基础模型为Qwen3.5-4B。
  - 推理：直接调用模型生成答案，不经过特殊后处理。
  - 分布外测试集：6个清洁来源（CLEVR, GQA, etc.）和ViLP（文本可回答集），测试泛化。

### 5. 4DP-QA: Scalable QA for 4D Perception in Vision Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.11568v1
- 方法流程：
  - 阶段1：数据预处理：将多源视频数据（驾驶、室内、仿真）标准化为统一坐标、分辨率、帧率、相机参数、深度、分割、6D姿态
  - 阶段2：资产采样：随机采样视频片段，根据启发式和阈值筛选满足运动要求的视频段和对象（如相机静止/移动、对象移动特性、可见度）
  - 阶段3：离散标签生成：将连续几何测量（距离、位移、旋转）映射为类别标签（如远近、左右、增减），设定数据源特定阈值确保准确性
  - 阶段4：QA生成：使用预定义模板和LLM（Gemini-2.5-Pro）生成多样化问题与答案，填充对象引用、时间实例、坐标系统等槽位
  - 阶段5：后处理：多轮人工验证确保基准QA对的高质量
- 关键模块/机制：
  - 真运动跟踪模块：提供与相机运动解耦的物体运动表示；给定3D点轨迹X(t)和移动相机外参T[t]、内参K，传统视觉点跟踪P2D=Π(K,T[t],X(t))，真运动跟踪M2D=Π(K,T[t_q],X(t))，其中t_q为固定参考时间，从而消除相机运动影响。
  - 资产采样器：筛选包含有意义运动的视频片段和对象；先随机采样视频片段，再用启发式规则（如相机运动类型、对象速度、方向变化、可见度）和数据集特定阈值过滤，确保满足目标问题类型的运动特性。
  - 离散标签生成器：将连续几何量转化为可回答的分类标签；根据参考系统计算距离、位移、旋转等连续值，使用预定义映射和阈值（如距离增加/减少/恒定，方向左/右/前/后）生成离散标签，对齐人类感知判断。
  - QA生成器：基于模板和LLM生成多样化问答对；为每种问题类型设计多个模板，包含对象引用、时间、坐标系统等槽位；使用LLM对模板进行多样化改写；从资产采样器获取符合条件的对象和标签，填充模板输出最终QA。
- 公式/目标函数/指标定义：
  - P2D = {p[t]} = {Π(K, T[t], X(t))}
  - M2D = {m_{t_q}[t]} = {Π(K, T[t_q], X(t))}
  - 其中Π为图像投影算子，T[t]为t时刻相机外参，K为内参，t_q为固定参考时间。
- 算法细节：
  - 资产采样启发式：根据相机运动（静止/平移/旋转）和对象运动（速度变化、方向变化、可见性）设定阈值，筛选合格视频段
  - 离散标签映射：3D距离变化→递增/递减/不变；3D旋转→组合（pan/tilt/roll）；2D屏幕运动→方向描述
  - 模板实例化：使用预先设计的自然语言模板，包含对象引用槽（描述/坐标/视觉提示），通过LLM生成多样化表达
  - 点跟踪输出：坐标归一化到[0,1]保留三位小数，随机化帧顺序防止捷径学习，包含遮挡标志
- 训练/推理细节：
  - 训练模型：NVILA-Lite-8B、Qwen2.5-VL-3B/7B及带几何编码器（L4P）的4D VLM
  - 训练配置：batch size 128，训练1 epoch（约3100迭代），冻结视觉编码器
  - 学习率：NVILA-Lite-8B用2e-5，Qwen变体用1e-5，AdamW优化器，余弦学习率调度
  - 训练耗时：32块NVIDIA A100 GPU上约9小时，4步梯度累积
  - 推理评估：4DP-QA-Bench使用精确字符串匹配，报告准确率
  - 输入样本：32帧视频段，分辨率448x448

### 6. AVIS: Adaptive Test-Time Scaling for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.11576v1
- 方法流程：
  - 输入：图像/视频和问题文本；视觉编码器提取视觉嵌入Ev。
  - 自适应视觉上下文缩放：对每个query，计算所有视觉token的KDV保留分数ri，根据阈值τ保留角度大于τ的token集合Sτ(x)，得到剪枝后的视觉上下文。
  - 难度预测：将视觉嵌入Ev输入轻量级预测器（1D Conv-GroupNorm-SiLU → 全局平均池化 → MLP），输出solvability概率p̂(x)。
  - 自适应推理缩放：根据p̂(x)和预计算的bin边界（校准集上确定），映射到rollout数K∈{1,3,5,7}。
  - 共享prefill推理：对所有rollout复用一次prefill和KV cache，进行K次decoding生成推理链，通过多数投票得到最终答案。
- 关键模块/机制：
  - 自适应KDV剪枝：减少冗余视觉token以降低prefill和KV cache开销；使用每个视觉token与各head anchor方向的平均余弦对齐度的相反数作为保留分数ri。通过阈值τ（如π/4）动态选择token：保留ri≥-cos(τ)的token。该规则无需训练，计算复杂度为O(N)。
  - 难度预测器：预测每个查询的solvability概率，指导rollout分配；输入为视觉嵌入Ev，经过1D卷积层、GroupNorm、SiLU激活，再经全局平均池化，最后通过浅层MLP输出2维logits。使用softmax后第一个维度的值作为p̂(x) ∈ [0,1]。在校准集上以Kmax=10 rollout计算empirical solvability并二值化作为监督标签进行训练。
  - 分段rollout分配策略：将连续solvability概率映射到离散rollout数；根据校准集上的全局计算预算确定5个边界{b_j}，将p̂(x)划分为6个区间，分别对应K=1,5,7,5,3,1。该分配呈非单调的倒U形，与自一致性边际收益一致。
- 公式/目标函数/指标定义：
  - KDV保留分数：ri = - (1/H) Σ_h cos(key_i, anchor_h)，其中anchor_h为头部h的候选方向。
  - 自适应保留集：Sτ(x) = { i ∈ {1,...,nv} : ri ≥ -cos(τ) }。
  - 自一致性正确概率（i.i.d.假设）：P_SC(p,K) = Σ_{j=⌈(K+1)/2⌉}^{K} C(K,j) p^j (1-p)^{K-j}，其中p为单轨迹正确概率。
  - empirical solvability：p(x_j) = (1/Kmax) Σ_{k=1}^{Kmax} 1[ŷ^{(k)}(x_j) = y⋆_j]，二值化标签 y_j = 1[p_j ≥ 0.5]。
- 算法细节：
  - KDV剪枝：对每个query，计算所有视觉token的保留分数ri，比较阈值τ，得到保留索引集合Sτ。
  - 难度预测器训练：构造校准集Dcal（5000个多选问题），每个样本用基础VLM跑Kmax=10次rollout，计算empirical solvability并二值化。训练预测器最小化交叉熵损失。
  - bin边界选择：在校准集上，给定目标计算预算，搜索边界{b_j}使得分配后总rollout数满足预算，且边界固定后用于测试。
  - 共享prefill推理：所有rollout共享一次visual encoder和LLM prefill，KV cache仅计算一次；然后每个rollout独立进行自回归解码，采样温度0.7、top-p 0.9。
- 训练/推理细节：
  - 难度预测器仅在校准集上训练一次，训练后冻结。
  - 校准集构建遵循质量、多样性、难度原则，从73k图像/视频中筛选出4000图像+1000视频多选问题。
  - 测试时，AVIS先执行KDV剪枝，然后预测难度，按bin映射得到K，进行K次rollout推理。
  - 所有配置共享同一视觉编码器，FLOPs差异主要来自LLM prefill和decoding。

### 7. Analyzing and Improving Fine-grained Preference Optimization in Medical LVLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.12590v1
- 方法流程：
  - 数据准备：对每个输入图像-问题对，使用基础LVLM生成初始响应
  - 文本偏好对构建：用GPT-4o-mini检测初始响应中的临床错误，仅编辑错误片段为正确内容，保留其余风格，形成优选和劣选文本对
  - 图像偏好对构建：用MedSAM获取图像中病变区域的分割掩码，对病变区域添加噪声，生成病变图像，形成干净图像和病变图像的视觉对
  - 训练：使用双向KL正则化损失（结合前向和后向KL）和视觉对比损失，联合优化LVLM（仅LoRA模块可训练，冻结视觉编码器和跨模态投影器）
  - 推理：标准自回归生成

### 9. One Layer's Trash is Another Layer's Treasure: Adaptive Layer-wise Visual Token Selection in LVLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.14277v1
- 方法流程：
  - 输入：文本token X_T (M个) 与视觉token X_V (N个) 拼接成序列 X = [X_T, X_V] ∈ R^{(M+N)×D}
  - 每层处理：
  - 1. 低秩近似：用SVD初始化的低秩矩阵 ˜W_Q = U_Q V_Q, ˜W_K = U_K V_K (R≪D) 计算近似查询 ˜Q 和密钥 ˜K
  - 2. 计算近似注意力权重 ˜A = softmax(˜Q ˜K^T / √d_k)
  - 3. 提取视觉-视觉注意力矩阵 ˜A_{V2V} ∈ R^{N×N} 和文本-视觉注意力矩阵 ˜A_{T2V} ∈ R^{M×N}
  - 4. 计算每个视觉token i 的视觉-视觉分数 S_{V2V}(i) = (1/N) Σ_j ˜A_{V2V}(j,i) 和文本-视觉分数 S_{T2V}(i) = (1/M) Σ_j ˜A_{T2V}(j,i)
  - 5. 最终重要性分数 S(i) = S_{V2V}(i) · S_{T2V}(i)
  - 6. 选择 top-k 视觉token X_V^{(select)} = TopK(X_V, S, k)，其中 k = ⌊r·N⌋，r为选择比例；其余为 X_V^{(skip)}
- 关键模块/机制：
  - 低秩近似注意力模块：高效估计每层注意力权重，避免完整注意力的高开销；对原始Q和K投影矩阵进行SVD分解，保留前R个最大奇异值分量，得到低秩矩阵˜W_Q = U_Q V_Q, ˜W_K = U_K V_K (R≪D)，然后计算近似注意权重˜A；初始化后利用少量样本微调以对齐原始模型注意力分布。
  - 重要性分数计算器：综合视觉与文本上下文判断每个视觉token的重要性；从近似注意力矩阵中分别计算每个视觉token的视觉-视觉平均注意力分数和文本-视觉平均注意力分数，两者乘积作为最终分数，确保token在两种上下文中都重要才被保留。

  - selector优化模块：训练轻量级selector使其重要性评分与原始模型对齐；使用SVD初始化低秩矩阵后，从少量样本（256张）中计算原始模型注意力导出的重要性分数S*，最小化均方误差L=(1/N)Σ_i(S(i)-S*(i))^2；只更新selector参数，原始LVLM冻结。
- 公式/目标函数/指标定义：
  - 低秩近似：˜W_Q = U_Q V_Q, ˜W_K = U_K V_K，其中U_Q, U_K ∈ R^{D×R}, V_Q, V_K ∈ R^{R×D}, R ≪ D
  - 近似查询：˜Q = X ˜W_Q^T, 近似密钥：˜K = X ˜W_K^T
  - 近似注意力：˜A = softmax(˜Q ˜K^T / √d_k)
  - 视觉-视觉重要性：S_{V2V}(i) = (1/N) Σ_{j=1}^N ˜A_{V2V}(j,i)
  - 文本-视觉重要性：S_{T2V}(i) = (1/M) Σ_{j=1}^M ˜A_{T2V}(j,i)

- 算法细节：
  - SVD初始化：对原始W_Q和W_K分别进行SVD分解，保留前R个奇异值，构造U_Q, V_Q, U_K, V_K（公式8-10）
  - 重要性打分的推导基于自注意力中的视觉-视觉和文本-视觉双重视角乘积

  - 跳过token不经过该层任何计算（包括FFN和层归一化），直接传递至输出合并
  - 合并时保持原始token顺序以保留位置信息

  - 不同模型设置不同秩：LLaVA-1.5-7B/13B和LLaVA-NeXT-7B使用R=256，Qwen2.5-VL-3B使用R=128，保证每层参数开销低于2%

  - VLM (Qwen2.5-VL-7B)：视觉语言编码器，提取图像特征并生成文本（包括object tokens和答案）；采用LoRA（rank=16, alpha=32）进行参数高效微调，学习率2e-4。输入图像和文本prompt，输出包含<sam_pad>特殊token的序列，每个<sam_pad>对应一个待分割对象类别。
  - Object Tokens (<sam_pad>)：作为VLM输出的特殊token，桥接语言建模与分割任务；在VLM词表中添加<sam_pad> token（每个对象类别对应一个token），训练时通过next-token交叉熵损失优化其嵌入。这些token的隐层特征被投影到SAM prompt空间，用于生成分割掩码。
  - Projection Layer：将VLM的<sam_pad>隐层特征映射到SAM的prompt嵌入空间；单层线性变换：zm = W z + b，其中z是VLM最后一层隐特征，zm是映射后的特征。
  - Cross-Attention：将投影特征与可学习查询融合，增强对目标对象的表示；映射特征zm作为key和value，一组可学习查询q（数量等于分割类别数）作为query，计算注意力：zp = softmax(q k^T / sqrt(dk)) v，输出投影token zp用于SAM解码。
  - SAM Decoder (SAM/SAM2/SAM3)：基于投影token和图像特征生成分割掩码；对于原始SAM：M_i = Decoder_{SAM}(zp_i, f)，f为SAM图像编码器输出的密集特征；SAM2额外使用多尺度特征{f^{(l)}}；SAM3通过文本-编码器-解码器融合，最终由分割头输出掩码。训练时采用Dice损失和二元交叉熵损失。
- 公式/目标函数/指标定义：
  - 投影：zm = W z + b
  - Cross-Attention：zp = Attn(q, k, v) = softmax( q k^T / sqrt(dk) ) v
  - SAM解码（原始）：M_i = Decoder_{SAM}(zp_i, f)
  - SAM2解码：M_i = Decoder_{SAM2}(zp_i, f, {f^{(l)}}_{l=1}^L)
  - SAM3解码：h_i = T_{dec}( T_{enc}(f_{enc}, t_i), t_i ); M_i = H_{seg-SAM3}(h_i, f_{enc}, t_i)
  - 总损失：L = L_{next-token} + λ (L_{Dice} + L_{BCE})，其中L_{next-token}为交叉熵，L_{Dice}和L_{BCE}为分割损失
- 算法细节：
  - VLM生成答案时，prompt明确要求先输出分割对象列表（每个对象后跟<sam_pad> token），再给出答案
  - 提取每个<sam_pad> token对应的VLM最后一层隐层向量，通过线性投影转换到SAM prompt空间
  - 在projection之后，使用cross-attention将投影特征作为key/value，可学习查询作为query，生成最终提示token
  - SAM解码器根据提示token和图像特征（原始SAM为单一特征图，SAM2为多尺度特征，SAM3为编码器-解码器文本融合）预测每个对象的分割掩码
  - 训练时，VLM部分使用next-token交叉熵损失（所有token），SAM部分使用Dice+BCE损失，两部分联合优化
  - 多阶段课程学习：阶段1只训练纯VQA数据，阶段2加入分割监督（冻结VLM？），阶段3混合纯VQA和分割VQA数据
- 训练/推理细节：
  - 基础VLM：Qwen2.5-VL-7B，通过LoRA（rank=16, alpha=32）微调，学习率2e-4
  - SAM组件学习率1e-5，使用AdamW优化器
  - 训练3个epoch，每个epoch内数据混合比例随阶段变化
  - 第一阶段：仅纯VQA数据（无<sam_pad> tokens）；第二阶段：加入分割监督（<sam_pad> tokens和分割损失）；第三阶段：混合纯VQA和分割VQA数据
  - 推理时，可选择仅使用VLM进行问答（不调用SAM解码器），或同时输出分割掩码
  - 预测时，VLM根据prompt先生成分割对象列表和<sam_pad> tokens，再生成答案

- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.15938v1
- 方法流程：
  - 输入：一对纵向CXR图像（Xpri_I, Xcur_I）及其对应报告（Xpri_T, Xcur_T），以及从Chest ImaGenome中提取的进展描述（P→_T, P←_T）。
  - 编码：分别用视觉编码器f_I和文本编码器f_T提取图像和文本的token嵌入H^t_I和H^t_T（t∈{pri,cur}）。
  - 构建时序序列：初始化可学习进展特征图P→_I（大小与图像token相同），构造正向序列S→ = [Hpri_I; P→_I; Hcur_I]；类似构造反向序列S← = [Hcur_I; P←_I; Hpri_I]（P←_I是另一可学习特征图）。
  - 进展编码：用进展编码器f_P（含时空注意力块）处理序列，得到进展感知表示[˜Hpri_I, ˜P→_I, ˜Hcur_I]和反向的[˜Hcur_I, ˜P←_I, ˜Hpri_I]。
  - 状态对比对齐（L_state）：对每个时间点的图像表示˜H^t_I与对应报告文本H^t_T进行跨模态对比学习（含硬标签和动量软标签），使用MoD损失。
  - 转换对比对齐（L_trans）：将进展表示˜P→_I与正向文本进展描述P→_T对比，˜P←_I与反向描述P←_T对比，也使用MoD损失。
  - 双向重建（L_recon）：用轻量解码器f_R，从˜Hpri_I和˜P→_I重建˜Hcur_I，从˜Hcur_I和˜P←_I重建˜Hpri_I，采用InfoNCE风格的token级重建损失。
  - 总体损失：L = L_state_MoD + L_trans_MoD + λ_r L_recon。
- 关键模块/机制：
  - 可学习进展特征图（Progression Feature Map）：作为桥梁编码两个时间点之间的语义转换，分别用于正向和反向方向。；初始化两个大小为N_I × d的可学习张量P→_I和P←_I，插入到先后图像token序列之间，形成时间顺序序列，通过后续的进展编码器更新。
  - 进展编码器（Progression Encoder）：处理包含进展特征图的时序序列，建模跨时间依赖和空间对应。；由L个时空块组成，每个块包含时间注意力层（沿时间维度建模跨帧依赖）、空间注意力层（建模解剖位置对应）和前馈网络，均含残差连接。
  - 状态对比对齐（State Contrastive Alignment）：将每个图像表示锚定到其对应的报告语义状态，区分不同时间点的语义。；对每个时间点t，计算图像-文本相似度logits，以正样本为同一时刻报告，负样本包括批次内其他报告（含另一时间点）。使用硬标签和动量软标签（MoD）的交叉熵损失。
  - 转换对比对齐（Transition Contrastive Alignment）：将学习到的进展表示与文本描述的进展语义对齐，确保方向性。；构建结构化进展文本（格式：[finding] at [position] [progression]），反向进展将“improved”替换为“worsened”。对比损失中，正样本为对应的进展文本，负样本包括反向进展文本。同样使用MoD损失。
  - 双向重建（Bidirectional Reconstruction）：强制进展表示能忠实描述状态演变，增强时序一致性。；使用轻量解码器f_R，输入[˜Hpri_I; ˜P→_I]重建˜Hcur_I，输入[˜Hcur_I; ˜P←_I]重建˜Hpri_I。重建损失为InfoNCE，每个重建token的正样本为原始对应token，负样本为所有其他原始token。
- 公式/目标函数/指标定义：
  - 状态对比损失 L_state = -1/(2B) * Σ_t Σ_k (q_tk log p_tI2T,k + q_tk log p_tT2I,k)，其中p_tI2T为图像到文本的softmax相似度，q_t为标签（硬标签或动量软标签）。
  - 转换对比损失 L_trans 类似结构，但针对进展表示与进展文本。
  - 双向重建损失 L_recon = -1/(B N_I) * Σ_t Σ_i Σ_n log (exp(cos(ˆH_t,n_I,i, ˜H_t,n_I,i)/τ) / Σ_j,m exp(cos(ˆH_t,n_I,i, ˜H_t,m_I,j)/τ))。
  - 总体损失 L = L_state_MoD + L_trans_MoD + λ_r L_recon。
- 算法细节：
  - 使用ViT作为视觉编码器，文本编码器为预训练语言模型。
  - 进展编码器中的时间注意力在3个token序列（先、进展、后）上操作，空间注意力在N_I个空间token上操作。
  - 对比对齐中引入动量模型（EMA）生成软标签，避免严格one-hot的过度约束。
  - 双向重建解码器f_R为轻量MLP或线性层，输出维度与图像token相同。
- 训练/推理细节：
  - 预训练数据集：MIMIC-CXR-JPG和Chest ImaGenome，共98,940个双时间点图像-报告对。
  - 优化器：未明确，但使用温度参数τ和权重λ_r。
  - 动量模型更新：指数移动平均。
  - 下游任务微调：在疾病进展分类和进展描述任务上微调整个或部分模型。
  - 推理时：使用正向进展表示˜P→_I用于下游任务。

  - 阶段3：偏差计算。计算每个标注者原型与共识原型的偏差Δ_c^(r)=p_c^(r)-p_c^(0)。
  - 阶段4：原型校准（JAPC）。将所有标注者原型P_c和偏差Δ_c输入自注意力模块：Q=P_cW_q, K=Δ_cW_k, V=P_c, 注意力权重A=σ(QK^T/√D)，输出校准后原型˜P_c=AV。分离出每个标注者的校准原型˜p_c^(r)。
  - 阶段5：相似度计算。对每个标注者，计算查询特征F_q与校准原型˜p_c^(r)的余弦相似度，得到前景和背景logits，经softmax得到概率图。
  - 阶段6：预测输出。对概率图取argmax得到每个标注者的二值预测掩膜ˆy_q^(r)。
  - 训练阶段补充：伪样式生成。在训练时，从未标注图像离线生成超像素伪标签y_pseudo，通过随机结构化变换T_r生成R个样式变体˜y^(r)=T_r(y_pseudo)，用作支持标签和查询监督。两阶段训练：前T/2迭代训练基础模型（无JAPC和伪样式），后T/2迭代启用JAPC和伪样式。
- 关键模块/机制：
  - Joint Attention-based Prototype Calibration (JAPC) 模块：建模标注者间结构化偏差，校准每个标注者的原型以突出个体差异。；输入：所有前景或背景标注者原型P_c（形状N_total×D）和偏差Δ_c（形状N_total×D）。计算：Q=P_cW_q, K=Δ_cW_k, V=P_c。注意力权重A=σ(QK^T/√D)（σ为sigmoid），输出˜P_c=AV。将校准后原型按标注者分离。该模块轻量级，可插拔于任意基于原型的少样本分割方法。
  - 伪样式生成 (Pseudo-Style Generation)：为训练提供多标注者风格的伪标签，弥补真实多标注者样本不足。；从无标注图像通过超像素/超体素分割生成伪标签y_pseudo。对每个伪标签，应用R种不同的随机结构化边界变换T_r（如膨胀或腐蚀），得到R个风格变体˜y^(r)=T_r(y_pseudo)。变换在每轮随机变化以避免过拟合，且仅用于训练阶段。
  - 两阶段训练策略 (Two-Stage Training)：稳定原型校准训练，避免早期原型噪声导致校准失败。；总迭代次数T内，前T/2迭代训练基础原型模型（不启用JAPC和伪样式），使编码器学到稳定的语义特征；后T/2迭代启用JAPC模块和伪样式生成，继续联合训练。
- 公式/目标函数/指标定义：
  - 共识掩膜: y_s^(0) = (1/R) * Σ_{r=1}^R y_s^(r)
  - 偏差: Δ_c^(r) = p_c^(r) - p_c^(0)
  - 自注意力: Q = P_c W_q, K = Δ_c W_k, V = P_c, A = σ(Q K^T / √D), ˜P_c = A V
  - 校准损失: L_calib = (1/R) * Σ_{r=1}^R Σ_c ||p_c^(r) - ˜p_c^(r)||_2^2
  - 分割损失: L_seg = (1/R) * Σ_{r=1}^R (1/|Ω|) Σ_{i∈Ω} CE(softmax(ℓ_q^(r)(i)), y_q^(r)(i))
  - 对齐损失: L_align = (1/R) * Σ_{r=1}^R (1/|Ω|) Σ_{i∈Ω} CE(softmax(ℓ_s^(r)(i)), y_s^(r)(i))
- 算法细节：
  - 原型提取函数Φ采用掩膜平均池化或更复杂方法，但论文采用抽象表示不限定具体实现。
  - JAPC中的注意力权重使用sigmoid激活，而非softmax，使每个位置可以有多个高响应。
  - 余弦相似度计算：sim(F_q(i), p) = (F_q(i)·p) / (||F_q(i)|| ||p||)。
  - 对齐损失：使用反向过程，以查询作为支持、支持作为查询，同样经过JAPC校准后计算预测与真实掩膜的交叉熵。
  - 伪样式生成中的边界变换T_r每次随机选择（如不同的膨胀/腐蚀核大小和迭代次数），从而模拟不同标注者的边界偏好。

- 训练/推理细节：
  - 训练：元学习范式，使用1-way 1-shot episodic训练。总迭代次数T，前T/2迭代仅训练基础原型模型（无JAPC和伪样式），后T/2迭代启用JAPC和伪样式。损失包括分割损失、对齐损失和校准损失。
  - 推理：给定支持图像及其多标注者掩膜，计算共识掩膜，提取原型和偏差，通过JAPC校准得到R个校准原型。对查询图像提取特征，计算与每个校准原型的余弦相似度，得到R个预测掩膜。无需额外训练步骤。
  - 伪样式生成仅在训练阶段使用，推理时直接使用真实多标注者掩膜。

- 方法流程：

  - 生成任务：对于每个缺失模态，模型首先生成思考过程（目标描述+已有模态的放射学发现），然后通过流匹配生成该模态的视觉token。

  - 动态隐藏状态 (Dynamic Hidden State)：缓解训练测试gap（曝光偏差）；训练时使用KV缓存，对生成任务执行10步扩散得到预测潜变量e_hat_i，将其投影为hidden state并添加到KV缓存。后续理解和生成任务基于包含自生成状态的缓存，使模型适应自身的生成误差。

  - LSA = E_{t~U[0,1], ε~N(0,I)}[||V_θ(e_i^t, t, w_i, p_rec) - (ε - e_i)||^2]
  - LNTP = -∑_n log p(h_{i,n} | KV_{<i}, h_{i,<n}; θ)
  - Lflow = E_{t~U[0,1], ε~N(0,I)}[||V_θ(e_i^t, t, KV_{<i}) - (ε - e_i)||^2]
  - 总体损失 L = (1/k)∑_i (LSA + LNTP + Lflow)
- 算法细节：
  - 构建交错数据流：{x1, z1, f1, x2, ..., zk, R}，其中x为图像，z为思考文本，f为发现，R为印象。
  - 自回归预测：模型基于历史KV缓存预测下一个状态（文本或视觉token）。
  - 生成任务：使用流匹配，从噪声开始逐步去噪生成目标模态的潜变量，条件为历史KV缓存。
  - 理解任务：使用完整KV缓存，通过next-token prediction生成印象。
- 训练/推理细节：
  - 训练分为三个阶段：自对齐预训练（2000步）、非KV cache训练（2000步）、动态隐藏状态训练（200步）。
  - 训练时随机化模态数量和顺序，每个batch打包为13,408 token序列。
  - 推理时根据可用模态，依次通过生成任务补全缺失模态，最后执行理解任务。
  - 使用2D切片，将3D体积描述投影为2D切片级描述。

  - 多尺度坐标注意力模块 (MCAM)：将检索到的外部知识与当前解码特征进行空间感知融合，增强边界保持和语义一致性；输入为当前解码特征f_i和f_i_v（来自检索的交叉注意力输出），通过多尺度卷积（5×5和7×7）提取多尺度信息，经LayerNorm和1×1卷积后分组，并行使用坐标注意力（X和Y方向池化、1×1卷积、sigmoid）生成空间注意力权重，最后加权融合。输出f_{i+1}和f_{i+1}_v传递至下一解码阶段。
  - 双解码器与一致性学习：通过标准解码器DS和检索感知解码器DR的一致性约束，将推理信息传播到整个网络；DS不使用检索特征，DR使用检索特征并通过MCAM融合。训练时对无标签样本计算DS和DR输出的L2一致性损失Lcons，使DS间接学习到检索驱动的推理知识。
  - EMA知识池更新：动态更新知识池中视觉原型以适应模型进化；在训练过程中，对每个有标签样本，通过EMA更新其视觉原型v_K_i ← α v_K_i + (1-α) f_i_bar，其中f_i_bar为当前池化图像特征，α为动量因子，更新时梯度截断。
- 公式/目标函数/指标定义：
  - Lsup = (1/|Sl|) * Σ_{(x,y,t)∈Sl} [ Lseg(DS(E(x,t)), y) + Lseg(DR(E(x,t)), y) ]，Lseg为交叉熵+Dice损失
  - Lclip = 对比损失，对齐图像嵌入vi与CoT嵌入zi
  - Lwarm = Lseg + λclip Lclip
  - f_v^0 = MHCA(f^0, {v_i}, {v_i})，其中(v_i,z_i)∈K*
  - v_K_i ← α * v_K_i + (1-α) * f_i_bar
  - Lcons = (1/|Su|) * Σ_{x∈Su} ||DS(E(x,t)) - DR(E(x,t), {v_i}_{(v_i,z_i)∈K*})||_2^2
- 算法细节：
  - 检索算法：输入查询图像和CoT，输出证据集K*。步骤1：计算查询图像嵌入v与知识池中所有v_i的余弦相似度，取top-K。步骤2：计算查询CoT嵌入z与候选集中所有z_i的余弦相似度，重排取top-M。
  - MCAM前向：输入f_i和f_i_v，分别经过多尺度卷积（5x5和7x7）和1x1卷积，分组后并行进行坐标注意力（X池化、Y池化、1x1卷积、sigmoid），两组输出逐元素相乘再加权，再与原始特征相加，最终通过1x1卷积和残差连接输出。
  - 双解码器前向：共享编码器E输出f0，DS直接解码；DR通过多头交叉注意力用f0作为query、检索特征作为key/value得到f_v0，然后与f0一起输入MCAM逐层解码，每层融合来自编码器的skip连接。
  - 知识池索引：采用FAISS或类似工具加速余弦相似度计算（论文未明确但常见实现）。
- 训练/推理细节：
  - 训练分两阶段：第一阶段（预热）仅使用有标签数据，优化Lwarm，训练E、DS、DR和B；收敛后固定E和B。第二阶段（半监督）使用所有数据，固定E和B，只训练DS和DR，优化Ltotal。
  - 知识池更新：每个有标签样本在训练过程中通过EMA更新视觉原型，不更新CoT原型。
  - 一致性损失只计算无标签样本，梯度只回传到DS和DR。
  - 推理时：使用DR作为最终分割网络，输入图像和文本，通过相同的前向流程（包括检索和MCAM融合）得到分割结果。

  - Scale-Aware Decoding阶段：对每个金字塔级别进行层内细化（使用残差细化算子R），然后自上而下跨尺度传播（从最粗到最细，通过上采样和残差连接融合），最后用1x1卷积预测头得到分割输出。

  - Scale-Aware Decoding (SAD)：对金字塔特征进行层内细化和跨尺度传播，生成分割预测。；包含两个子组件：层内细化对每个金字塔级别单独应用残差细化算子R（公式6）；跨尺度传播从最粗级别开始，通过上采样和加法融合逐步向精细级别传播（公式8-9），最后用1x1卷积预测头。
  - 轻量级残差细化算子R：在SAD中用于特征细化，引入少量计算。；R(X) = X + γ * σ(Norm(PW(DW(X))))，其中DW为深度卷积，PW为逐点卷积，Norm为GroupNorm，σ为GELU，γ为可学习残差缩放参数初始化为0。
- 公式/目标函数/指标定义：
  - Z^(ℓ) = B_ℓ(Z^(ℓ-1))：Transformer块更新。
  - F_k = reshape(Z_p^(ℓ_k))：重塑为2D。
  - \tilde{F}_k = φ(F_k)：1x1投影。
  - P_k = ρ_k(\tilde{F}_k)：缩放算子。
  - R(X) = X + γ * σ(Norm(PW(DW(X))))：残差细化。
  - L_k = R(P_k)：层内细化。
- 算法细节：
  - TPA中，从DINOv3选定层提取patch tokens，重塑为2D特征图，用1x1卷积投影到统一通道，再用步长卷积生成不同分辨率的金字塔特征。
  - SAD中，先对每个金字塔级别应用残差细化算子R进行层内更新；然后从最粗级别开始，通过双线性上采样和加法融合逐步向下传播，每个融合后特征再经R处理。
  - 残差细化算子R使用深度卷积和逐点卷积的组合，残差连接，可学习缩放参数初始化为0。
- 训练/推理细节：
  - 使用DINOv3-S骨干，编码器冻结。
  - 优化器：AdamW，学习率1e-4，权重衰减1e-4。
  - 损失函数：交叉熵损失。
  - 训练轮数50，批次大小4。
  - 输入图像统一缩放到256x256。
  - 推理速度51 FPS，总参数量27.68M（骨干21.60M，其余6.08M）。

### 26. miniReranker: Efficient Multimodal Reranking through Visual Cache Reuse and Interaction Sparsity
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.10759v2
- 方法流程：
  - 输入重组：根据模态动态排序，视觉输入始终位于文本输入之前（T→V时文档优先，V→T时查询优先，V→V时文档优先）。
  - 视觉编码与缓存：视觉输入经ViT+投影编码为token，其KV缓存可离线预计算或在线广播复用。
  - 早期退出：在中间层ℓ_E提前终止前向传播，仅使用前ℓ_E层输出进行评分。
  - 交互带：仅在层ℓ_I到ℓ_E之间允许跨段注意力（query-document交互），其余层只进行段内自注意力。
  - Token剪枝：利用检索阶段嵌入器的注意力信息，选择Top-k视觉token，减少序列长度。
  - 最终评分：语言头输出yes/no logits，通过sigmoid计算相关性分数s(q,d)=σ(zyes−zno)。

  - Vision-first reformulation：对齐VQA预训练格式并最大化视觉KV缓存复用；动态将视觉输入放在文本前，T→V时顺序为[ins, d, q]，V→T时为[ins, q, d]，V→V时文档优先。使得重视觉计算可被离线缓存或在线广播，减少重复编码。
  - Early exit：减少深度计算，截断不必要的上层；在层ℓ_E（如第12层）添加分类头，根据中间层logits提前输出，跳过后续层。通过层探针分析确定ℓ_E为信号收敛层。
  - Interaction band：限制跨段注意力到有效层，减少交互计算；仅在层ℓ_I（如第8层）到ℓ_E之间允许query和document之间的cross-attention，其他层只做segment内self-attention。通过注意力掩码实现。
  - Embedder-guided token pruning：减少视觉token数量，降低序列长度；利用检索阶段（如ViT）的注意力图，选取注意力权重最高的Top-k视觉token，丢弃其余token。不需要额外前向传播。
- 公式/目标函数/指标定义：
  - 相关性分数：s(q,d) = σ(z_yes - z_no)，其中z_yes和z_no为yes/no token的logits，σ为sigmoid。
  - Query-first复杂度：C_q-first = O(L n_q^2 d_h + L n_q d_h^2) + K L (n_d(n_q+n_d)d_h + n_d d_h^2)
  - Document-first复杂度：C_d-first = O(K L n_q(n_q+n_d)d_h + K L n_q d_h^2)
  - 目标函数：点式yes/no交叉熵损失（在微调时使用）
- 算法细节：
  - 点式重排：每个query-document对独立输入，模型生成二元yes/no决策。
  - 序列顺序动态选择：根据模态组合决定前缀缓存策略，视觉token缓存可跨候选复用。
  - 早期退出：在中间层ℓ_E插入线性分类头，训练时与最终层联合优化。
  - 交互带：通过修改注意力掩码，仅允许指定层范围内的跨段交互，其余层掩码屏蔽跨段。
  - Token剪枝：使用检索器（如ViT的CLS token注意力）或嵌入器输出的注意力分数，选择Top-k token，保留其位置嵌入。
- 训练/推理细节：
  - 基础模型：Qwen3-VL-Instruct，在MMEB-v2数据集上微调。
  - 训练目标：点式yes/no交叉熵损失。
  - 训练时应用早期退出和交互带，实现约3倍训练加速。
  - 推理时采用完整的miniReranker流水线（早退+交互带+剪枝）。
  - 视觉token剪枝的k值通过验证集选择（例如保留256个token）。
  - KV缓存：视觉部分可离线预计算（文档优先时）或在线广播（查询优先时）。

### 27. VL-DINO: Leveraging CLIP Vision-Language Knowledge for Open-Vocabulary Object Detectio

  - Query-guided Positive Sample Construction (QPSC)：构造高质量正样本，增强视觉-语言对齐训练；基于观察：低索引内容查询匹配更多且得分更高，选取前300个内容查询作为可靠查询池。对每个GT框施加随机有界扰动生成辅助框（IoU>0.5），从可靠查询池中随机采样一个查询嵌入与辅助框配对，作为额外正样本查询（绕过匈牙利匹配，直接关联GT），与原始查询一起输入解码器，仅训练时使用，推理时丢弃。
  - Visual Semantic Encoder (VSE)：将CLIP视觉知识蒸馏到骨干特征中，产生融合特征；在P5和P6特征上应用三个自注意力块（类似CLIP ViT），并在序列前添加可学习的[CLS]标记。输出类嵌入CLS_l和增强特征¯P_l，通过MLP得到融合特征˜P_l。蒸馏损失包括：全局语义对齐损失L_sem（CLS_l与CLIP类嵌入CLS_clip的余弦相似度）、批内关系损失L_rel（KL散度对齐样本间相似性分布）、密集空间语义损失L_spa（KL散度对齐patch token与类嵌入的相似性分布）。三个损失加权求和作为整体蒸馏损失L_dis。
  - Object-Region Semantic Alignment (ORSA)：提取前景区域特征并与文本嵌入对齐，进一步融入文本知识；由一组可学习查询和3层前景解码器组成（结构与原始解码器相同）。训练时，查询由GT框引导从第一个编码器层输出中提取前景区域特征，并将这些特征与对应的文本特征进行对齐（损失函数未明确给出，但属于对齐损失）。推理时该模块移除。
- 公式/目标函数/指标定义：
  - 全局语义对齐损失: L_sem^l = 1 - (1/B) * sum_i cos(||CLS_l^(i)||_2, ||CLS_clip^(i)||_2)
  - 批内关系损失: L_rel^l = (1/B) * sum_i KL(r_clip^(i) || r_l^(i)), 其中 r_c^(i,j) = exp(cos(||CLS_c^(i)||_2, ||CLS_c^(j)||_2)/τ1) / sum_{k≠i} exp(cos(||CLS_c^(i)||_2, ||CLS_c^(k)||_2)/τ1), c∈{l, clip}
  - 密集空间语义损失: L_spa^l = (1/B) * sum_i KL(s_clip^(i) || s_l^(i)), 其中 s_c^(m) = exp(cos(||CLS_c||_2, ||¯P_c^m||_2)/τ2) / sum_{n=1}^{Hl×Wl} exp(cos(||CLS_c||_2, ||¯P_c^n||_2)/τ2), c∈{l, clip}
  - 整体蒸馏损失: L_dis = 0.5 * (λ_sem(L_sem^6+L_sem^5) + λ_rel(L_rel^6+L_rel^5) + λ_spa(L_spa^6+L_spa^5))
- 算法细节：
  - QPSC中辅助框生成：对每个GT框添加随机有界扰动，使得生成的辅助框与GT的IoU > 0.5，然后从可靠查询池中随机采样一个查询嵌入与之配对，作为正样本查询
  - VSE中特征融合：在P5和P6特征上分别添加[CLS]标记，经过三个自注意力块得到增强特征，再通过MLP获得融合特征˜P
  - ORSA中前景特征提取：可学习查询通过交叉注意力从第一个编码器层输出中提取与GT框对应的区域特征
- 训练/推理细节：
  - 训练数据：Objects365v1 (O) 和 GoldG (G)，共两个数据集；使用8张NVIDIA L40 GPU训练
  - 骨干：Swin Transformer（Swin-T或Swin-L）；检测框架：DINO；对象查询数：900；文本和视觉蒸馏分支使用预训练的CLIP-B/16，参数冻结
  - QPSC仅在训练时使用，推理时移除；ORSA仅在训练时使用，推理时移除；VSE在训练和推理时均保留
  - 损失函数：总体损失包括DINO原始损失（分类和回归）加上蒸馏损失L_dis，以及ORSA的对齐损失（未明确公式）

### 28. Reroute, Don't Remove: Recoverable Visual Token Routing for Vision-Language Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.12412v1
- 方法流程：
  - 输入：视觉令牌集合V、文本令牌集合T，解码器划分为S个阶段，每个阶段i有路由层ℓi和保留比率ri。
  - 阶段i：使用现有评分器（文本到视觉注意力）对当前候选集Ci（初始C1=V）进行排名，选择Top-Ki个令牌作为Vsel_i（Ki=⌊ri|V|⌋），其余为Vdef_i。
  - 选中的令牌Vsel_i通过解码器块（Attn+FFN），被推迟的令牌Vdef_i通过残差路径绕过该阶段。
  - 阶段输出：Vsel_i和Vdef_i合并恢复原始序列顺序，形成Ci+1 = V（完整视觉令牌集，但实际只有Vsel_i经过计算）。
  - 重复步骤2-4直到所有阶段完成。
- 关键模块/机制：
  - Rank & Reroute操作符：在每个路由阶段决定哪些视觉令牌通过解码器块，哪些被推迟。；复用当前解码器层的文本到视觉注意力分数作为排名信号，选择Top-K个令牌（K=⌊ri·|V|⌋）标记为选中，其余标记为推迟，无额外可训练参数。
  - 残差旁路：允许被推迟的视觉令牌绕过当前阶段的Attn+FFN计算并保持其在序列中的位置。；被推迟令牌不进入当前解码器块，而是通过残差连接直接传递到阶段输出，与选中令牌合并恢复原始顺序。
- 公式/目标函数/指标定义：
  - \(\text{score}(v_j) = \text{Attention}_{\text{text}\to\text{vision}}(v_j)\) 用于排名。
  - \(V_{\text{sel}}^{(i)} = \text{Top-K}_i(C_i)\)，其中 \(K_i = \lfloor r_i |V| \rfloor\)。
  - \(C_{i+1} = V\)（所有原始视觉令牌重新进入候选池，但仅 \(V_{\text{sel}}^{(i)}\) 实际参与计算）。
- 算法细节：
  - 每个阶段开始时，候选集Ci设为完整视觉令牌集V（由于被推迟令牌未删除，始终恢复为全集）。
  - 排名使用当前层文本到视觉注意力分数，无需额外评分器。
  - 选中令牌通过解码器块（注意力+前馈网络），被推迟令牌通过恒等映射跳过。
  - 阶段输出合并选中和推迟令牌，恢复原始序列顺序，进入下一阶段。
  - 理论FLOPs和KV-cache与对应修剪方法相同，因为只有选中令牌参与计算。
- 训练/推理细节：
  - 无需训练：Reroute完全在推理时工作，不引入可训练参数。
  - 推理时，Reroute复用现有修剪方法的评分规则和阶段调度，仅改变后选择动作。
  - 保持了与原修剪方法相同的理论TFLOPs和KV-cache预算。

### 30. Segment and Select: Vision-Language Segmentation in 3D Scenarios
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.10594v1
- 方法流程：
  - 输入：点云 P ∈ R^{Np×6} (坐标+颜色) 和文本指令
  - 阶段1：候选银行构建：使用预训练的3D分割模型生成Nc个掩码候选 C = Φgen(P)
  - 阶段2：点特征提取：稀疏卷积点编码器提取点级特征 Fp = Epc(P)
  - 阶段3：候选融合：将每个候选内的点特征与候选几何(中心、范围、包围盒)融合为候选级表示 zi = Φfus(Fp, P, C)
  - 阶段4：LLM交互：候选级表示通过可学习查询与冻结的LLM交互，输出[SEG]语义特征和[LOC]空间特征
  - 阶段5：语义-空间选择：语义匹配分支用[SEG]计算语义logits，空间校正分支用[LOC]和候选几何计算校正logits，结合后选择Top-K候选
  - 阶段6：循环验证：对Top-K候选进行局部掩码精炼(基于点特征和候选几何)，然后根据验证分数重排序，输出最终掩码
- 关键模块/机制：
  - 候选生成器 (Candidate Generator)：从输入点云生成对象级掩码候选，提供结构化假设空间；使用独立预训练的3D分割模型（如Point Transformer v3）对点云进行分割，输出每个候选的点索引集合 ci ⊆ {1,...,Np}，共Nc个候选；这些候选具有语义类别意识，边界清晰。
  - 点编码器 (Point Encoder)：提取每个点的特征表示；稀疏卷积网络（如MinkowskiEngine）处理输入点云，输出点级特征 Fp ∈ R^{Np×D}，每个点包含空间和颜色信息。
  - 候选融合 (Candidate Fusion)：将点特征与候选几何信息融合为紧凑的候选级表示；对每个候选ci，收集对应点的特征进行聚合（如最大池化或平均池化），并拼接从候选内点计算出的几何描述符（中心坐标、空间范围、规范化包围盒等），通过MLP得到候选级特征向量 zi。
  - LLM关联器 (LLM Associator)：利用冻结的大语言模型生成语义和空间定位令牌；候选级特征 zi 通过可学习查询 Q 与LLM交互，LLM编码文本指令和视觉上下文，输出文本响应 Ytxt、[SEG]令牌隐藏状态 hseg 和[LOC]令牌隐藏状态 hloc；可学习查询允许模型从LLM中提取相关语义和空间线索。
  - 语义-空间选择器 (Semantic-Spatial Selector, SSS)：融合语义匹配和空间校正选择Top-K候选；包含两个分支：1）语义匹配分支：将[SEG]特征与候选特征点乘得到基础logits；2）空间校正分支：将[LOC]特征与候选几何特征通过语义匹配生成校正logits；两者相加获得最终logits，取Top-K候选。
  - 循环验证模块 (Loopback Verification Module, LVM)：对选中的候选进行局部精炼和重排序以输出最终掩码；对Top-K候选，在候选区域内部使用点特征和候选几何进行局部细化（如轻量级MLP调整点归属），得到精炼掩码；然后基于精炼后的掩码质量（如与语言描述的对齐度）进行重排序，选择得分最高的掩码作为最终输出。
- 公式/目标函数/指标定义：
  - 候选生成：C = Φ_{gen}(P) = {c_i}_{i=1}^{N_c}, c_i ⊆ {1,...,N_p}
  - 候选融合：{z_i}_{i=1}^{N_c} = Φ_{fus}(F_p, P, C)
  - 语义匹配分数：S_sem = dot(h_[SEG], z_i)
  - 空间校正分数：S_spa = MLP(h_[LOC], g_i)
  - 最终选择分数：S_i = S_sem + S_spa
  - 评估指标：Acc@0.25（IoU>0.25的准确率），Acc@0.50（IoU>0.50的准确率），mIoU（所有类别的平均IoU）
- 算法细节：
  - 候选生成：使用预训练3D分割模型进行点云语义分割，将属于同一实例或语义区域的点分组为候选；候选数量Nc与场景复杂度相关。
  - 候选融合：对每个候选内的点特征进行最大池化，并拼接归一化的中心坐标、包围盒大小、旋转信息，经线性层后得到候选特征。
  - LLM交互：将候选特征压缩为可学习查询序列，与文本嵌入一起输入冻结的LLM；LLM生成文本响应和特殊令牌[SEG]和[LOC]的隐藏向量。
  - 语义空间选择：[SEG]向量通过MLP映射到与候选特征相同的维度，然后与每个候选特征计算余弦相似度得到语义分数；[LOC]向量与候选几何特征（中心、大小）拼接后通过MLP得到空间校正分数；两者相加后经softmax归一化，选择Top-K。
  - 循环验证：对Top-K候选，提取其内部点特征和几何，通过一个小型Transformer解码器或MLP进行掩码修正（每个点预测属于前景的概率），得到精炼二值掩码；然后使用验证网络（如基于语言-掩码对齐分数的MLP）评估每个精炼掩码的质量，输出最高分者。
- 训练/推理细节：
  - 候选生成器独立预训练，权重固定；LLM冻结，仅训练可学习查询和下游模块（候选融合MLP、SSS、LVM）。
  - 训练时使用分割损失（交叉熵）和排名损失（对比学习，使目标候选分数高于其他候选）。
  - 推理时：输入点云和文本，一次前向得到最终掩码；Top-K中K设为3~5。

### 31. miniReranker: Efficient Multimodal Reranking through Visual Cache Reuse and Interaction Sparsity
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.10759v1
- 方法流程：
  - 输入阶段：接收查询q和一组候选文档D={d1,...,dK}，确定模态类型（T→V, V→T, V→V）。
  - 序列构建：根据视觉优先原则动态构建输入序列：T→V时采用[ins, d, q]（文档优先）；V→T时采用[ins, q, d]（查询优先）；V→V时文档优先。
  - 视觉编码：对视觉输入（图像/视频）使用ViT+投影层得到视觉token序列，并通过嵌入器引导的剪枝保留top-k重要视觉token。
  - 前缀缓存：固定部分（如文档或查询中的视觉块）的KV cache可离线或一次性预计算，在线重复使用。
  - 逐点评分：将序列送入MLLM（基于Qwen3-VL），在特定层应用早期退出和交互带：前ℓ_E层全注意力，ℓ_E+1到ℓ_I-1层仅跨段注意力受限，ℓ_I层之后退出，最后在语言头输出yes/no logits，通过sigmoid(zyes - zno)得到相关性分数。
  - 重排序：对所有候选文档按分数降序排列。
- 关键模块/机制：
  - 视觉优先序列排序（Vision-First Prompt Reformulation）：确定输入序列中视觉和文本段的顺序，以最大化缓存重用并匹配MLLM预训练格式。；根据模态组合动态调整：T→V时文档优先（[ins, d, q]），V→T时查询优先（[ins, q, d]），V→V时文档优先。保证视觉内容始终在文本之前，从而视觉部分的KV缓存可被重复使用（离线或一次编码），同时恢复VQA训练的自然顺序。
  - 早期退出（Early Exit）：减少模型深度计算量，在中间层截断后直接输出。；通过层探针分析发现重排序信号在前几层已足够。设置退出层ℓ_E，仅运行前ℓ_E层自注意力/FFN，并将其输出送入语言头得到yes/no logits，跳过后续层。LLaMA-style预训练MLLM的语言头可复用。
  - 交互带（Interaction Band）：限制查询-文档交叉注意力只在少数有效层执行。；定义交互层范围[ℓ_E+1, ℓ_I-1]（ℓ_I为退出层），仅在这些层中让查询token和文档token相互做跨段注意力；其他层仅做段内自注意力（或仍使用前缀缓存）。通过层探针确定有效交互集中在中间层。
  - 嵌入器引导的视觉token剪枝（Embedder-guided Token Pruning）：减少视觉token数量，降低序列长度和注意力计算复杂度。；利用检索阶段双编码器（如CLIP）最后一层的注意力权重，计算每个视觉token的平均注意力得分，保留top-k最重要的token。剪枝在视觉编码后、进入MLLM前执行，无需额外前向传播。
- 公式/目标函数/指标定义：
  - s(q,d) = σ(zyes - zno)，其中zyes和zno分别是yes和no token的logits，σ为sigmoid。
  - 查询优先在线复杂度：C_q-first = O( L n_q^2 d_h + L n_q d_h^2 + K L (n_d(n_q+n_d)d_h + n_d d_h^2) )。
  - 文档优先在线复杂度：C_d-first = O( K L (n_q(n_d+n_q)d_h + n_q d_h^2) )。
  - 早期退出减少层数为ℓ_E，交互带减少跨段注意力层数为ℓ_I-ℓ_E-1。
  - 视觉token剪枝：保留top-k个token，k < n_v（原始视觉token数）。
- 算法细节：
  - 在训练/推理前，先通过层探针确定退出层ℓ_E和交互带起止层（基于logit变化率）。
  - 对于每个查询，根据模态类型动态构建输入序列；固定部分（如所有候选文档共用的视觉块）的KV cache可预计算并存储。
  - 在嵌入器引导剪枝中，使用检索阶段CLIP的最后层注意力，对每个视觉token所有注意力头平均，取top-k。

### 37. RoVE: Rotary Value Embeddings Attention for Relative Position-dependent Value Pathways
- 区域：quick；分数：6.0

- 方法流程：
  - 输入：序列X ∈ ℝ^{n×d}
  - 线性投影：Q = XWQ, K = XWK, V = XWV
  - 位置编码：对Q和K应用RoPE旋转（按位置i和j的旋转矩阵Ri和Rj），对V应用相同的旋转Rj（RoVE）
  - 注意力分数计算：A_{ij} = softmax( (1/√d) (WQ xi)^T R_{j-i} (WK xj) )
  - 值聚合与逆旋转：yi = R_i^{-T} ∑_j A_{ij} Rj WV xj = ∑_j A_{ij} R_{j-i} WV xj
  - 输出：序列Y ∈ ℝ^{n×d}
- 关键模块/机制：
  - RoVE值旋转模块：使值嵌入在聚合前旋转到查询的参考系，从而引入位置依赖性；对每个位置j的值向量vj = WV xj，应用旋转矩阵Rj（与RoPE中用于键的旋转矩阵相同），使值路径变为偏移依赖的核ψδ = Rδ WV。输出前通过逆旋转R_i^{-T}恢复方向。
- 公式/目标函数/指标定义：
  - ˜yi = R_i^{-T} ∑_{j∈N(i)} A(X)_{ij} R_j WV xj = ∑_{j∈N(i)} A(X)_{ij} R_{j-i} WV xj
  - A(X)_{ij} = softmax_{j∈N(i)} ( (WQ xi)^T R_{j-i} (WK xj) / √d )
  - ψδ = Rδ WV（偏移δ的卷积核）
- 算法细节：
  - RoVE与RoPE共享旋转矩阵Rt，每个2×2块旋转角度tω_m，ω_m = θ^{-2m/d}

  - 逆旋转R_i^{-T}作用于输出，确保最终表示在查询的局部帧中
  - 矩阵混合器视角：MRoVE(X)的(i,j)块为A_{ij} R_{j-i} WV，形成块Toeplitz结构
- 训练/推理细节：
  - 训练设置与RoPE相同，仅增加值旋转操作，不增加参数数量
  - 推理时可与YaRN频率内插结合使用，二者互补
  - 支持FlashAttention：旋转在注意力核心外部进行，不影响高效内核

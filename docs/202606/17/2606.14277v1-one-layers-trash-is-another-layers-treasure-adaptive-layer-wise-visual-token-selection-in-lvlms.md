## 摘要
大型视觉语言模型（LVLMs）在多种多模态任务中取得了显著成功，但其实际部署仍受限于冗长视觉令牌带来的计算负担。尽管视觉令牌剪枝已成为一种有前景的解决方案，但现有方法存在一个根本性限制：一旦令牌在特定层被剪枝，它们将无法被所有后续层访问，导致过早的信息丢失，从而可能损害模型性能。通过实证研究，我们观察到不同层表现出不同的视觉区域关注点，这表明各层存在不同的最优令牌子集。受此启发，我们提出自适应逐层视觉令牌选择（ALVTS），这是一种打破传统静态令牌剪枝范式的新框架。ALVTS包含一个轻量级令牌选择器，用于识别并路由重要令牌以进行进一步处理，同时允许不重要的令牌跳过该层，从而最小化计算冗余。这两类令牌在送入后续层之前会无缝重新集成，促进整个模型的适应性压缩。基于我们提出的重要性一致性约束低秩近似，所提出的令牌选择模块紧密模仿全注意力机制，有效捕获其基本模式，且无需重新训练模型。在LLaVA-1.5、LLaVA-NeXT和Qwen2.5-VL上的大量实验验证了我们方法的有效性。在89%的令牌压缩比下，ALVTS保留了原始模型96.7%的准确率，实现了LVLMs推理中优越的效率-准确率权衡。

## Abstract
Large Vision-Language Models (LVLMs) have achieved remarkable success across diverse multimodal tasks, yet their practical deployment remains constrained by the computational burden arising from lengthy visual tokens. While visual token pruning has emerged as a promising solution, existing methods suffer from a fundamental limitation: once tokens are pruned at a specific layer, they become inaccessible to all subsequent layers, leading to premature information loss that can compromise model performance. Through empirical studies, we observe that different layers exhibit distinct visual region focus, indicating a varying optimal token subset across layers. Motivated by this insight, we propose Adaptive Layer-wise Visual Token Selection (ALVTS), a novel framework that breaks away from the conventional static token pruning paradigm. ALVTS incorporates a lightweight token selector to identify and route important tokens for further processing, while allowing less important tokens to skip the layer, thus minimizing computational redundancy. These two streams of tokens are seamlessly reintegrated before being fed into subsequent layers, facilitating adaptive compression across the entire model. Grounded in our importance consistency constrained low-rank approximation, the proposed token selection module closely emulates the full attention mechanism, effectively capturing its essential patterns without requiring model retraining. Extensive experiments on LLaVA-1.5, LLaVA-NeXT, and Qwen2.5-VL validate the effectiveness of our method. With an 89% token compression ratio, ALVTS retains 96.7% of the original model's accuracy, achieving a superior efficiency-accuracy trade-off for LVLM inference.

### 1. 论文的核心问题与整体含义（研究动机和背景）
大型视觉语言模型（LVLMs）在多种多模态任务中表现优异，但视觉 token 数量远多于文本 token（如 LLaVA-NeXT 单张图像可产生 2880 个 token，而文本通常不足 100 个），导致计算瓶颈严重。现有视觉 token 剪枝方法（如 FastV）在特定层（如第 2 层）一次性剪掉不重要的 token，这些 token 在所有后续层中彻底消失，造成不可逆的信息丢失。然而，作者通过可视化发现，不同解码器层关注的视觉区域差异显著（例如浅层关注桥体结构，中层关注铭牌，深层关注塔楼），说明各层需要不同的最优令牌子集。因此，静态一次性剪枝会过早丢弃对深层至关重要的视觉信息。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程（用文字说明即可）
- **核心思想**：提出自适应逐层视觉 token 选择（Adaptive Layer-wise Visual Token Selection, ALVTS），在每个 LLM 解码器层独立进行动态 token 选择，允许重要 token 参与本层计算，次要 token 跳过本层，之后两路 token 合并恢复完整序列进入下一层，从而在避免信息永久丢失的同时减少计算量。
- **关键技术细节**：
  1. **低秩近似注意力**：为每个解码器层的自注意力模块设计轻量级 token 选择器，将原始的 query 和 key 投影矩阵分解为低秩形式：$\tilde{W}_Q = U_Q V_Q$，$\tilde{W}_K = U_K V_K$，其中 $R \ll D$（如 LLaVA-1.5-7B 中 R=256）。通过 SVD 初始化，并利用少量校准数据（256 样本）优化以对齐全注意力的重要性分数。
  2. **重要性分数计算**：基于低秩注意力矩阵 $\tilde{A}$ 计算每个视觉 token 的两个分数：视觉-视觉注意力平均分 $S_{V2V}(i)$ 和文本-视觉注意力平均分 $S_{T2V}(i)$，最终分数取两者乘积 $S(i)=S_{V2V}(i) \cdot S_{T2V}(i)$，确保 token 只有在视觉和文本上下文中都重要时才被保留。
  3. **逐层选择与处理**：每层按分数 Top-k 选出 $k = \lfloor r \cdot N \rfloor$ 个 token（$r$ 为选择比例），参与该层完整的注意力计算；其余 token 直接跳过该层。输出后按原始顺序合并，进入下一层。
  4. **优化目标**：冻结原模型，仅优化每个选择器的低秩矩阵，通过最小化重要性分数重构误差 $\mathcal{L} = \frac{1}{N}\sum_i (S(i) - S^*(i))^2$ 完成，其中 $S^*$ 来自原始全注意力。

### 7. 优点
- **无需重训练原模型**：选择器独立优化，保持原模型参数冻结，易于集成到现有 LVLM 部署。
- **理论动机清晰**：基于观察到的跨层注意力分歧，提出“各层所需 token 不同”这一新颖假设，并设计动态选择机制。
- **高效轻量**：低秩近似和少量校准数据（256 样本）使优化速度快（15 分钟），额外参数仅占 1-2%。
- **泛化性强**：在三个不同架构（LLaVA-1.5、LLaVA-NeXT、Qwen2.5-VL）和不同规模上均验证有效。
- **性能与效率平衡出色**：在极高压缩率（89%）下仍维持 96%+ 的相对性能，优于所有现有方法。

### 8. 不足与局限
- **实验范围**：仅测试了最大 13B 的模型，未涉及 70B 以上超大 LVLM；也未验证在视频、音频等多模态输入上的泛化性。
- **校准依赖**：虽然优化只需少量数据，但仍需一个标注好的多模态校准集（LLaVA-655k 的子集），且校准集分布可能影响选择器质量。
- **极端压缩下的退化**：当压缩率高达 89% 时，绝对性能仍有下降（如 LLaVA-1.5-7B 平均降 3.27%），在某些任务（如 TextVQA 从 58.18 降至 57.41）差距较小但无法忽略。
- **低秩近似的潜在偏差**：选择器基于低秩注意力，理论上在全注意力需要精细区分时（如细粒度 OCR）可能存在近似误差。
- **静态选择比例**：每层使用固定的选择比例 $r$，未自适应调整，可能在某些层保留过多冗余或丢失过多关键信息。
- **未讨论推理额外开销**：选择器本身带来小幅计算（低秩投影），虽然远小于全注意力，但在极低延迟场景下可能仍是一个因素。

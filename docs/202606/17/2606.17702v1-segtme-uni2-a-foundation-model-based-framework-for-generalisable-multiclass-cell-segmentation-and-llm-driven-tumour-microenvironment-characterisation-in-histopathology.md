## 摘要
从常规H&E染色组织学图像中表征肿瘤微环境(TME)需要同时进行细胞分割、特征提取和可解释的临床报告。我们提出SEGTME-UNI2，一个统一框架来满足这些需求。其核心是UNI2-UPERHOVER，一种双头分割模型，将UNI2-H病理基础模型（ViT-Giant，在来自10万张切片的超过1亿个图块上预训练）与两个并行的UperNet解码器配对：一个用于六类语义分割，另一个用于水平-垂直梯度回归，以实现基于分水岭的细胞核实例分离。为了解决大型真实世界存储库中缺乏像素级标注的问题，UNI2-UPERHOVER经过三阶段渐进式伪标签课程训练。每个阶段训练一个全新的模型，不进行权重迁移，完全通过提高伪标签质量来推动改进：阶段1：使用人工标注的PanNuke（7901张图像，189744个细胞核，0.25微米/像素）。阶段2：使用阶段1模型在271,711个TCGA-UT尺度0图块（0.5微米/像素）上生成的熵过滤伪标签。阶段3：使用阶段2模型在全部1,608,060个TCGA-UT图块（涵盖六个分辨率尺度，0.5-1.0微米/像素）上生成的伪标签。分割输出馈入结构化TME特征提取流程，计算每个图块20多个组成、形态、空间熵和细胞间距离指标。这些指标编码为JSON并传递给微调的NVIDIA BioNeMo GPT模型，以生成临床可解释的TME叙述。在留出的PanNuke和TCGA-UT分区上的初步验证证明了框架的可行性和内部一致性。公开发布了带伪标签的TCGA-UT数据集和UNI2-UPERHOVER检查点，以支持大规模TME分析和空间生物学研究。

## Abstract
Characterising the tumour microenvironment (TME) from routine H&E-stained histology images requires simultaneous cell segmentation, feature extraction, and interpretable clinical reporting. We present SEGTME-UNI2, a unified framework addressing these requirements. Its core is UNI2-UPERHOVER, a dual-head segmentation model pairing the UNI2-H pathology foundation model (ViT-Giant, pretrained on >100M tiles from 100K slides) with two parallel UperNet decoders: one for six-class semantic segmentation and one for horizontal-vertical gradient regression enabling watershed-based nuclear instance separation. To address the lack of pixel-level annotations in large real-world repositories, UNI2-UPERHOVER undergoes a three-stage progressive pseudo-label curriculum. Each stage trains a fresh model without weight transfer, driving improvement entirely via increased pseudo-label quality: Stage 1: Uses human-annotated PanNuke (7,901 images, 189,744 nuclei, 0.25 um/pixel). Stage 2: Uses entropy-filtered pseudo-labels from the Stage 1 model on 271,711 TCGA-UT scale-0 patches (0.5 um/pixel). Stage 3: Uses pseudo-labels from the Stage 2 model on all 1,608,060 TCGA-UT patches across six resolution scales (0.5-1.0 um/pixel). Segmentation outputs feed a structured TME feature extraction pipeline computing 20+ per-patch compositional, morphological, spatial entropy, and intercellular distance metrics. These are encoded as JSON and passed to a fine-tuned NVIDIA BioNeMo GPT model to generate clinically interpretable TME narratives. Preliminary validation on held-out PanNuke and TCGA-UT partitions demonstrates framework feasibility and internal consistency. The pseudo-labelled TCGA-UT dataset and UNI2-UPERHOVER checkpoint are publicly released to support large-scale TME profiling and spatial biology research.

- **研究动机**：常规H&E染色组织病理学图像分析中，肿瘤微环境(TME)表征需要同时解决细胞分割、特征提取和临床可解释报告三个耦合任务。现有方法要么只能做语义分割（无法分离粘连细胞核），要么只能做实例分割（缺乏广泛语义上下文且依赖昂贵的人工多边形标注），且输出形式不直接适用于临床报告流程。

## 2. 方法论
- **核心思想**：使用UNI2-H（ViT-Giant）作为共享骨干，附加双UperNet解码头（语义头6类、HV回归头2通道），通过三阶段渐进式伪标签课程训练，从少量人工标注（PanNuke）逐步扩展到多尺度TCGA-UT全套图块（160万+），最后提取20+空间特征并输入微调BioNeMo GPT生成TME叙述。
- **关键技术细节**：
  - **UNI2-UPERHOVER架构**：从UNI2-H的24个Transformer块中提取4个尺度特征（块5/11/17/23），通过1×1卷积投影到FPN通道数（256/512/1024/2048）。两个UperNet解码器独立工作：语义头输出6类logits（PanNuke本体：背景、肿瘤、炎症、结缔组织、坏死、非肿瘤上皮）；HV头输出两个通道的梯度图（水平/垂直），用于分水岭实例分离。
  - **动态HV目标合成**：无需实例级标注，从语义掩码的连通组件分析生成每个像素的HV目标（归一化到[-1,1]），使伪标签课程能扩展到无实例标注的TCGA-UT。
  - **损失函数**：语义交叉熵（忽略标签255）；HV损失为MSE + 2×空间梯度匹配项MSGE；总损失 = L_sem + 1.0 * L_hv。
  - **三阶段伪标签课程**：阶段1：在PanNuke（0.25μm/pixel）上全监督训练；阶段2：用阶段1模型在TCGA-UT尺度0（0.5μm/pixel）图块上生成伪标签，经熵过滤（保留前70%低熵图块），从头训练新模型；阶段3：用阶段2模型在所有6个尺度（0.5-1.0μm/pixel）图块上生成熵过滤伪标签，从头训练最终模型。各阶段之间不共享权重，改进完全来自伪标签质量提升。
  - **TME特征提取流程**：从实例掩码提取每个细胞核质心、面积、类别；计算各类计数/比例、肿瘤-间质分数、免疫浸润分数；使用cKDTree计算免疫-肿瘤细胞最近/平均距离、50px阈值内接触免疫细胞计数；计算每个细胞5近邻的香农熵取平均得到空间熵。共20+个数值特征。
  - **生物标记翻译**：基于规则阈值（文献/临床常用截断值）将数值特征映射为6轴表型标签和扁平化生物学标记列表（如“Lymphocyte-rich”、“Immune exclusion”），共11个标准标记。
  - **BioNeMo GPT微调**：使用structured JSON（raw_data, interpretation, generated_tokens）作为提示，微调NVIDIA BioNeMo GPT生成临床样式的TME叙述。训练目标为标准交叉熵，仅在叙述部分计算损失。

## 6. 主要结论与发现
- UNI2-UPERHOVER双头设计能从共享基础模型编码器同时输出语义分割和HV梯图，实现实例分离。
- 三阶段渐进式伪标签课程能有效将监督从PanNuke扩展到多尺度TCGA-UT，无需额外人工标注，各阶段mIoU逐步提升。
- UperNet解码器适合跨分辨率域迁移（0.25到0.5-1.0μm/pixel），其金字塔池化和FPN融合优于点式解码器。
- BioNeMo集成将结构化数值特征转化为临床叙述，减轻幻觉风险，因为叙述可直接追溯到特征值。
- 定性案例发现：即使挑战性染色条件下（浅粉色低对比度），基于总体统计特征（计数、比例、空间距离）的TME分类仍保持临床一致性。
- 公开了最大核级标注TCGA语料库（160万伪标签图块）和模型权重，促进可重复研究。

## 7. 优点
- **创新性**：首次将UNI2-H基础模型与双头UperNet结合，在病理基础模型上附加密集预测头实现语义+实例分割；动态HV目标合成解除了对实例级标注的依赖，使伪标签课程可行。

## 摘要
现代视觉语言模型（VLM）得益于思维链提示和测试时缩放，但这些增益通常伴随着高昂的推理成本，原因是大型视觉上下文和长解码链。我们从两个耦合的维度来看待这种成本：视觉上下文缩放（VCS）控制传递给语言模型的视觉证据量，视觉推理缩放（VRS）控制推理时执行的推理搜索量。现有方法通常一次优化一个维度，而跨这两个维度的计算联合分配尚未充分探索。我们提出了自适应视觉推理缩放（AVIS），这是一个轻量级策略，能够根据每个查询自适应地调整VCS和VRS。AVIS通过关键多样性视觉（KDV）剪枝实现VCS，这是一种无需训练的O(N)基于关键字的规则，用于在预填充之前移除冗余的视觉标记；并通过自适应自一致性实现VRS，使用一个学习到的难度预测器来选择推理展开的数量。AVIS部署友好，且兼容共享预填充推理，其中所有展开重用单个预填充阶段和KV缓存。在多样化的图像和视频推理基准测试中，AVIS相对于仅VCS和仅VRS的基线提高了精度-计算权衡，并且在经过RL后训练的VLM上仍然有效，同时保持较低的计算量和延迟。

## Abstract
Modern Vision-Language Models (VLMs) benefit from chain-of-thought prompting and test-time scaling, but these gains often come with prohibitive inference cost due to large visual contexts and long decoding chains. We view this cost through two coupled axes: Visual Context Scaling (VCS), which controls how much visual evidence is passed to the language model, and Visual Reasoning Scaling (VRS), which controls how much inference-time reasoning search is performed. Existing methods typically optimize one axis at a time, leaving the joint allocation of compute across these axes underexplored. We introduce Adaptive Visual Inference Scaling (AVIS), a lightweight policy that adapts both VCS and VRS per query. AVIS realizes VCS through Key Diversity Visual (KDV) pruning, a training-free $O(N)$ key-based rule for removing redundant visual tokens before prefilling, and realizes VRS through adaptive self-consistency, using a learned difficulty predictor to select the number of reasoning rollouts. AVIS is deployment-friendly and compatible with shared-prefill inference, where all rollouts reuse a single prefilling pass and KV cache. Across diverse image and video reasoning benchmarks, AVIS improves the accuracy--compute trade-off relative to VCS-only and VRS-only baselines, and remains effective on top of RL post-trained VLMs while keeping compute and latency low.

## 2. 方法论

### 核心思想
- **AVIS (Adaptive Visual Inference Scaling)**：一种轻量级、样本依赖的测试时计算分配策略。对每个查询 `(I, Q)`，AVIS 选择配置 `θ = (ρ, K)`，其中 ρ 是视觉 token 的剪枝比例（VCS），K 是自一致性推理的 rollout 数（VRS）。策略通过两个阶段实现：
  1. **自适应 VCS**：使用无训练的关键多样性视觉（KDV）剪枝，根据 token 键的多样性与平均键的余弦相似度排序，并通过阈值自动确定每个样本的剪枝比例 ρ。
  2. **自适应 VRS**：通过一个轻量级难度预测器（基于视觉嵌入）估计每个样本的“可解性”概率，然后根据非单调的边际效用（倒U型：中等难度样本受益最大）将概率映射到离散的 rollout 数 K（1,3,5,7），实现计算集中在最有价值的样本上。

### 关键技术细节
1. **KDV 剪枝（VCS 实现）**  
   - 对每个视觉 token 的每个注意力头 h，计算其归一化键向量 `k̂_{h,i}` 与头平均键 `μ(K̂_h)` 的余弦相似度，取负平均值作为冗余得分 `r_i`。  
   - 公式：`r_i = - (1/H) Σ_{h=1}^H CosSim(μ(K̂_h), k̂_{h,i})`。  
   - 保留得分高于阈值 `τ=π/4`（对应角度）的 token，自适应得到保留比例 ρ。  
   - 复杂度 O(N)，无需训练，适用于预填充前剪枝，并与共享 KV 缓存兼容。

2. **自适应自一致性（VRS 实现）**  
   - 训练一个轻量级难度预测器（1D Conv + GroupNorm + SiLU + 全局平均池化 + MLP），输入为视觉嵌入，输出二分类置信度（可解 vs. 不可解）。  
   - 校准集上运行 K_max=10 次 rollout 得到每个样本的 solvability 概率，二值化后训练预测器。  
   - 测试时，预测器输出概率 ˆp(x)，通过预先设定的分段常数映射（binning rule）得到 K：[0, b1)→1, [b1,b2)→5, [b2,b3)→7, [b3,b4)→5, [b4,b5)→3, [b5,1]→1（边界在校准集上确定，以满足全局计算预算）。这种非单调映射反映自一致性在中等难度样本上边际效用最大。

3. **共享预填充（Shared-Prefill）**  
   - 所有 K 个 rollout 共享同一个预填充阶段的 KV 缓存，剪枝后的视觉 token 仅需一次预填充，因此增加 K 主要增加解码计算，重复预填充开销极低，使得联合 VCS–VRS 在实践中有良好效率。

### 算法流程简述
1. 输入影像 I 和文本 Q → 视觉编码器产生视觉嵌入 Ev。
2. KDV 剪枝：计算每个视觉 token 的 Key Diversity 得分，根据阈值 τ 保留高多样性 token，得到自适应 ρ。
3. 将视觉 token 与文本 token 拼接，进行预填充（构建 KV 缓存）。
4. 难度预测器（仅基于 Ev 的视觉嵌入）输出 ˆp(x)，binning 得到 K。
5. 并行采样 K 条 CoT 轨迹（共享预填充 KV 缓存），解码出答案，通过多数投票聚合，得到最终预测。

## 6. 主要结论与发现

1. **AVIS 显著改善精度–计算权衡**：相比 Vanilla，AVIS 在图像基准平均准确率提升 3%，视频基准提升 2.4%，同时计算量降低 52%（图像）和 66%（视频）。相比固定联合配置（ρ=75%, K=5），AVIS 以 40% 更低计算量达到更高精度。
2. **自适应分配优于固定配置**：在 matched-FLOPs 下，AVIS 比最优固定策略平均高出 3.7%。
3. **VCS 与 VRS 耦合至关重要**：单轴自适应（仅适应 ρ 或仅适应 K）性能均不如联合自适应，表明两个轴应联合考虑。
4. **KDV 剪枝高效且有效**：在 75% 剪枝率下，KDV 保留 Vanilla 平均 97.99% 性能，优于现有无训练方法；自适应阈值进一步减少性能损失。
5. **难度预测器带来有效的计算分配**：预测的 rollout 分配分布呈现数据集依赖性，K=1 多用于简单/极难样本，K=5/7 集中在难但可解样本，避免滥用计算。
6. **通用性强**：AVIS 对 RL 后训练的 VLMs（如 Vision-R1、VL-Rethinker）同样有效，证明方法不依赖于特定基础模型。
7. **共享预填充带来实际延迟收益**：AVIS 延迟 757s（与 Vanilla 795s 相当），但精度更好，而固定高 rollout 配置可能延迟更高。

## 7. 优点

1. **方法新颖且统一**：首次提出 VCS 与 VRS 的联合自适应分配框架，将“看”与“思考”的计算视为耦合资源，具有理论洞察。
2. **部署友好**：KDV 剪枝无训练 O(N) 运行；难度预测器轻量（<0.1% 额外 FLOPs）；与共享预填充推理（如 vLLM）无缝集成，无额外延迟惩罚。
3. **计算效率高**：AVIS 在保持/提升性能的同时显著降低 FLOPs 和实际延迟，适合成本敏感应用。
4. **实验全面**：覆盖大量基准（18个）、多种模型变体（4种 RL 后训练 VLM）、多组消融，结果稳健。
5. **可解释性好**：难度预测器的 binning 规则基于理论（边际效用倒U型），分配行为符合直觉，非黑箱。
6. **即插即用**：无需修改基础模型权重，可直接用于现有 VLM，与主流推理加速技术兼容。

## 8. 不足与局限

1. **事实上的局限性**（论文自述）：
   - 视觉剪枝与推理分配解耦：AVIS 采用两阶段策略（先决定 ρ，再基于视觉嵌入决定 K），未建模二者交互。统一策略可能更优，但设计困难。
   - 难度预测器仅使用视觉嵌入，未利用问题文本，无法捕获文本复杂度。若引入文本表示可能提升准度，但会破坏预优先决策。
   - 仅实例化自一致性作为 VRS 轴，未探索其他轴（如顺序细化、树搜索、带验证器的 Best-of-N），但框架正交于这些改进。

2. **可能的评估偏差**：
   - 校准集构建使用了 Qwen2.5-VL 自身进行难度评估，可能引入模型偏差；虽然原则强调多样性，但覆盖不完全。
   - benchmark 集中于英文多选问答，未在生成式任务（如长视频描述、开放生成）或长视频（> 1 分钟）上评估。
   - 所有实验基于 Qwen2.5-VL-7B 一种主模型，尽管测试了其他 RL 后训练版本，但架构同源；在更广泛 VLM（如 LLaVA-NeXT、InternVL3）上的泛化性尚需验证。

3. **资源/可重复性不足**：
   - 未开源代码和校准集（论文承诺将在接受后公开）。
   - 无误差棒报告（仅单次运行），实验随机构建不足；论文解释为计算成本过高，但仍可能影响结论稳健性。

4. **应用限制**：
   - 难度预测器的 binning 边界依赖校准集，若部署工作负载分布漂移（如完全开放式长视频），可能需要重校准。
   - 当前 AVIS 仅支持多选问题格式（通过多数投票聚合），不直接支持自由生成任务（如摘要、对话）。

5. **理论假设简化**：FLOPs 模型假设 token 线性，忽略了注意力计算的二次项（虽然提供了数学证明进行近似），但极端长上下文可能存在偏差。

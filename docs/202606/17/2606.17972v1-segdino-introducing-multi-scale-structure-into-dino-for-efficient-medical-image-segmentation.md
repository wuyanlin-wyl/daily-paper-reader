## 摘要
自监督的DINO模型提供了强大的可迁移视觉表示，但将其直接应用于图像分割仍然具有挑战性。现有方法通常依赖带有复杂上采样的重型解码器，引入了大量参数和计算开销。我们观察到，将尺度引入DINO特征比增加解码器容量更为关键。在这项工作中，我们提出了SegDINO，一种高效的图像分割框架，它将DINOv3骨干网络与轻量级尺度建模相结合。SegDINO引入了Token金字塔适应（TPA）来将中间DINO特征重新组织成伪多尺度层次结构，以及尺度感知解码（SAD）用于高效的尺度内细化和自上而下的多尺度传播。我们进一步整理了一个新的CT数据集PanCT，包含284名患者和专家标注的胰腺肿瘤，以评估SegDINO处理困难小病灶病例的能力。在PanCT和三个公开基准上的大量实验表明，SegDINO以高效率实现了最先进的结果。代码可在 https://github.com/script-Yang/segdino_v2 获取。

## Abstract
Self-supervised DINO models provide strong transferable visual representations, yet applying them directly to image segmentation remains challenging. Existing approaches commonly rely on heavy decoders with complex upsampling, introducing substantial parameter and computational overhead. We observe that introducing scale into DINO features is far more critical than increasing decoder capacity. In this work, we present SegDINO, an efficient segmentation framework that integrates a DINOv3 backbone with lightweight scale modeling. SegDINO introduces Token Pyramid Adaptation (TPA) to reorganize intermediate DINO features into a pseudo multi-scale hierarchy, and Scale-Aware Decoding (SAD) for efficient intra-scale refinement and top-down multi-scale propagation. We further curate PanCT, a new CT dataset containing 284 patients with expert-annotated pancreatic tumors, to assess SegDINO's ability to handle difficult small-lesion cases. Extensive experiments on PanCT and three public benchmarks demonstrate that SegDINO achieves state-of-the-art results with high efficiency. The code is available at https://github.com/script-Yang/segdino_v2.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：自监督DINO系列模型已展现出强大的跨域视觉表征迁移能力，但直接将其用于图像分割时，现有方法往往依赖重型解码器（如多层上采样、多尺度融合模块），导致参数和计算开销显著增加。
- **核心观察**：作者提出，**对DINO特征引入显式的尺度多样性（scale）比单纯增加解码器容量更为关键**。DINO特征天然缺乏多尺度层次，使得简单解码器难以捕捉细粒度语义（尤其小病灶）。
- **研究目标**：设计一个高效的分割框架，在保留DINO强表示能力的同时，通过轻量级尺度建模实现高精度分割，避免重型解码器。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 采用**冻结的DINOv3作为编码器**，仅通过轻量级模块（Token Pyramid Adaptation + Scale-Aware Decoding）重构多尺度特征并高效解码，无需训练复杂上采样解码器。

### 关键技术细节

#### (a) 编码器骨干（DINOv3）
- 输入图像 \(x \in \mathbb{R}^{H \times W \times 3}\)，划分为patch并嵌入为 token 序列 \(Z^{(0)}\)。
- 经过 L 层 Transformer 块，收集中间层 token 集合（论文选用第3、6、9、12层），输出 \(Z_p^{(\ell_k)} \in \mathbb{R}^{N \times d}\)（去掉class/register token）。

#### (b) Token Pyramid Adaptation (TPA)
- **目标**：将等分辨率、相同网格的DINO中间特征重组为伪多尺度金字塔。
- **步骤**：
  1. 将每层 token 重塑回2D feature map \(F_k \in \mathbb{R}^{d \times H_p \times W_p}\)（\(H_p=H/p, W_p=W/p\)）。
  2. 通过 \(1 \times 1\) 卷积 \(\phi\) 投影到统一通道数 \(d'\)：\(\tilde{F}_k = \phi(F_k)\)。
  3. 对每层施加**特定尺度的空间变换** \(\rho_k\)（通过stride卷积实现），生成不同分辨率的特征图 \(P_k = \rho_k(\tilde{F}_k)\)，构成伪金字塔（分辨率分别为原图的1/4, 1/8, 1/16, 1/32）。

#### (c) Scale-Aware Decoding (SAD)
- **目标**：轻量级解码，包括**尺度内细化（intra-scale updating）** 和**尺度间传播（inter-scale propagation）**。
- **轻量残差细化算子 \(R\)**：
  \[
  R(X) = X + \gamma \cdot \sigma(\text{Norm}(\text{PW}(\text{DW}(X))))
  \]
  其中DW为depthwise conv，PW为pointwise conv，Norm为GroupNorm，\(\sigma\)为GELU，\(\gamma\)为可学习缩放参数（初始化为0）。
- **尺度内更新**：对金字塔每层 \(P_k\) 独立应用 \(R\)：\(L_k = R(P_k)\)。
- **尺度间传播**：从最粗层开始，逐层向上融合：
  - \(X_K = R(L_K)\)
  - \(X_k = R(\text{Up}(X_{k+1}; L_k) + L_k)\)，其中Up为双线性插值。
- **输出**：最终在最细层 \(X_1\) 上接一个 \(1\times 1\) 卷积预测头 \(H\) 得到分割结果。

### 算法流程概述
输入图像 → DINOv3提取4层中间token → TPA生成伪金字塔（4个尺度） → SAD先逐层细化 → 自顶向下融合 → 线性头输出分割图。

### 1. Transformer-Guided Graph Attention for Direct Cardiac Mesh Reconstruction: A Structural Digital Twin Framework
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.13188v1
- 方法流程：
  - 输入: 3D CT或MRI体积图像
  - 阶段1: 3D Swin Transformer编码器将体积划分为补丁(patch size=4)，经过四个阶段的多头自注意力与移位窗口机制，生成多尺度特征图
  - 阶段2: 解码器通过上采样和跳跃连接恢复分辨率，输出分割logits
  - 阶段3: 初始化模板网格(icosphere, r=4, 162个顶点)，通过双线性插值从四个编码器阶段提取每个顶点的多尺度特征并进行L2归一化
  - 阶段4: 图注意力网络(GAT)接收顶点特征，通过3层、每层4头的多头注意力聚合邻域信息，预测每个顶点的位移ΔV
  - 输出: 最终网格V_pred = V0 + ΔV，以及分割图
- 关键模块/机制：
  - 3D Swin Transformer编码器-解码器：从3D体积中提取多尺度特征并生成分割logits；输入体积分割为不重叠补丁(p=4)，经过四个阶段，每个阶段使用移位窗口自注意力实现跨窗口信息交换，降低计算复杂度；解码器通过上采样和跳跃连接恢复分辨率。
  - 图注意力网络(GAT)网格变形头：利用编码器特征将模板网格变形为患者心脏表面；将网格表示为图，顶点为节点，边为邻接关系。使用3层、每层4注意力头(隐藏维度256)的多头注意力，从邻域顶点聚合特征，输出位移ΔV。总参数量0.35M (占全模型1.4%)。
  - 模板网格初始化与顶点特征采样：提供初始几何形状并赋予每个顶点多尺度上下文特征；模板为细分级别r=4的icosphere (162顶点)，中心自适应定位；从四个编码器阶段通过三线性插值采样特征并拼接，然后L2归一化。
- 公式/目标函数/指标定义：
  - Patch嵌入: z0 = PatchEmbed(X)
  - Swin自注意力: Attention(Q,K,V) = softmax(QK^T/√d_k)V
  - 解码器输出: S = Decoder(z0, z1, ..., zL)
  - GAT更新: h_i^(l+1) = σ(∑_{j∈N(i)} α_ij^(l) W^(l) h_j^(l))
  - 多头注意力: MultiHeadAttn(h_i, N(i)) = Concat(head1,...,head4)W_O
  - 位移预测: ΔV = GAT(V0, Φ); V_pred = V0 + ΔV
- 算法细节：
  - 多尺度特征采样: 对每个模板顶点，从4个编码器阶段的特征图通过三线性插值采样并拼接成15C_1维向量，然后L2归一化
  - 网格变形: GAT输出顶点位移向量，直接加到模板顶点坐标得到最终网格
  - 模板中心自适应: 若分割预测Dice>0.7则用预测前景质心，否则用特征显著性，98.2%情况定位在心脏边界3-5mm内
  - 单次前向: 冻结的Swin编码器+GAT头一步输出，无需迭代优化
- 训练/推理细节：
  - 训练分两阶段: 先训练分割分支(交叉熵+软Dice)，使用AdamW优化器，初始学习率1e-4，余弦退火，batch size 2-4，最多300轮，早停；第二阶段固定编码器权重，仅训练GAT头，使用网格损失(L_Chamfer + 0.5 L_Lap + 0.05 L_edge)
  - 推理: 将模板网格放置于自适应中心，采样多尺度特征，GAT预测位移，输出网格，整个过程2-5秒/体积(RTX 3090)
  - 所有网格无需Marching Cubes、平滑或手动清理

### 2. MedLatentDx: Latent Multi-Agent Communication for Cross-Hospital Rare-Disease Diagnosis
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.13945v1
- 方法流程：
  - 广播查询：将标准化HPO表型集qHPO发送给所有医院智能体
  - 本地检索：每个医院智能体从私有数据库Di中检索表型相似病例，构建本地提示xi
  - 本地编码：冻结的本地LLM骨干生成提示长度KV缓存MHi
  - 潜在压缩：MedLatentDx-H使用训练好的蒸馏器生成mlatent步紧凑KV块ZHi；MedLatentDx-X使用轻量投影器对齐到宿主潜在空间
  - 宿主聚合：宿主智能体接收所有ZHi，拼接后输入自身LLM生成OMIM编码诊断y_hat
- 关键模块/机制：
  - 本地LLM骨干（Frozen Local LLM Backbone）：编码本地提示并生成完整KV缓存；使用冻结的LLM（如Qwen2.5-7B）将本地提示xi编码为提示长度KV缓存，该缓存不离开医院。
  - 蒸馏器（Distiller）：将提示长度KV缓存压缩为固定长度紧凑KV块；在MedLatentDx-H中，蒸馏器是一个轻量Transformer模块，接收完整KV缓存并生成mlatent步的KV表示，仅这些步被发送。
  - 投影器（Projector）：将不同LLM骨干的潜在状态对齐到宿主潜在空间；在MedLatentDx-X中，投影器是一个小型MLP，将本地LLM的潜在表示映射到宿主LLM的潜在空间，使不同家族模型能协同。
  - 宿主智能体（Host Agent）：聚合所有紧凑KV块并生成最终诊断；宿主智能体通常是查询医院，将各医院发送的紧凑KV块按顺序拼接，作为自身LLM的上下文，生成OMIM编码诊断。
- 公式/目标函数/指标定义：
  - 诊断目标：hat{y} = Host(qHPO, concat_{i=1}^N Z_{Hi}), hat{y} in Y_OMIM
  - 重建泄漏：tilde{x}_i = A(T_{Hi}), rho_i = sim(tilde{x}_i, x_i)，其中A为冻结LLM延续攻击，sim为token F1或BERTScore
  - 训练目标：最小化诊断交叉熵损失，更新蒸馏器/投影器和边界嵌入，冻结LLM骨干
- 算法细节：
  - HPO检索：每个医院基于HPO语义相似度从私有数据库中检索与查询表型最匹配的病例
  - 潜在压缩：蒸馏器在完整KV缓存上自回归生成mlatent步的KV，通过门控机制（文中未明确）或直接作为位置嵌入
  - 潜在对齐：跨家族场景下，投影器将本地LLM最后一层隐藏状态映射到宿主LLM的KV空间
  - 宿主聚合：将各医院紧凑KV块沿序列维度拼接，插入宿主LLM的Transformer层进行推理
- 训练/推理细节：
  - 训练：仅在蒸馏器/投影器和边界嵌入上训练，冻结所有LLM骨干，使用模拟跨医院数据
  - 推理：医院智能体加载冻结骨干，生成紧凑KV块并传输；宿主智能体接收后执行一次前向传播生成诊断
  - MedLatentDx-H：蒸馏器输出mlatent步的KV，长度远小于原提示长度
  - MedLatentDx-X：投影器输出与宿主KV空间对齐的潜在表示

### 3. One Layer's Trash is Another Layer's Treasure: Adaptive Layer-wise Visual Token Selection in LVLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.14277v1
- 方法流程：
  - 输入：文本令牌序列X_T和视觉令牌序列X_V拼接为X = [X_T, X_V]
  - 对于每一层ℓ：
  - a. 使用低秩近似（U_Q, V_Q, U_K, V_K）计算近似查询Q̃和键K̃，得到近似注意力矩阵Ã
  - b. 从Ã中提取视觉-视觉注意力Ã_{V2V}和文本-视觉注意力Ã_{T2V}
  - c. 对每个视觉令牌i，计算S_{V2V}(i)=均值(Ã_{V2V}(:,i))，S_{T2V}(i)=均值(Ã_{T2V}(:,i))，最终得分S(i)=S_{V2V}(i)*S_{T2V}(i)
  - d. 基于S进行top-k选择，得到选中令牌X_V^{(select)}和跳过令牌X_V^{(skip)}（k = r*N，r为选择比例）
  - e. X_T和X_V^{(select)}参与该层自注意力计算，X_V^{(skip)}直接跳过该层
  - f. 输出后，将处理后的选中令牌与跳过的令牌按原始顺序重新合并，作为下一层输入
- 关键模块/机制：
  - 令牌选择器（Token Selector）：为每层视觉令牌计算重要性得分，决定哪些令牌参与层计算；由低秩近似矩阵U_Q、V_Q、U_K、V_K组成（R≪D），通过SVD从原始投影矩阵初始化，再通过最小化近似得分与全注意力参考得分之间的MSE进行微调。计算近似查询和键，得到近似注意力矩阵，分别计算视觉-视觉和文本-视觉注意力得分的乘积作为最终重要性得分。
  - 跳过-合并机制（Skip-and-Merge）：允许不重要的视觉令牌跳过当前层计算，并重新与处理后的令牌合并；基于重要性得分进行top-k选择，选中的令牌（k个）与文本令牌一起进入该层计算，未选中的令牌（N-k个）直接跳过该层（不参与注意力及FFN）。处理完成后，所有令牌按原始顺序合并，保持位置信息不变。
- 公式/目标函数/指标定义：
  - 低秩近似: W̃_Q = U_Q V_Q, W̃_K = U_K V_K, 其中 U_Q, U_K ∈ R^{D×R}, V_Q, V_K ∈ R^{R×D}, R≪D
  - 近似注意力权重: Ã = softmax( Q̃ K̃^T / √(d_k) ) ∈ R^{(M+N)×(M+N)}
  - 视觉-视觉得分: S_{V2V}(i) = (1/N) Σ_{j=1}^N Ã_{V2V}(j,i)
  - 文本-视觉得分: S_{T2V}(i) = (1/M) Σ_{j=1}^M Ã_{T2V}(j,i)
  - 最终重要性得分: S(i) = S_{V2V}(i) · S_{T2V}(i)
  - Top-k选择: X_V^{(select)} = TopK(X_V, S, k), k = ⌊r·N⌋
- 算法细节：
  - 低秩投影矩阵初始化：对原始查询投影W_Q和键投影W_K分别进行SVD，保留前R个奇异值分量，构造U_Q = U_{full}[:,:R] · Σ_R^{1/2}, V_Q = Σ_R^{1/2} · V_{full}[:R,:]^T，同样处理K
  - 优化阶段：固定原始LVLM参数，仅更新每个层的低秩矩阵U_Q, V_Q, U_K, V_K；使用L2损失对齐近似得分与全注意力参考得分
  - 推理阶段：每层独立计算重要性得分，选择top-k令牌；选中的令牌参与该层全部计算（包括自注意力和FFN），跳过的令牌直接传递到层输出端
  - 令牌顺序保持：在合并时严格按原始输入顺序排列，保证位置信息不变
- 训练/推理细节：
  - 训练：仅优化令牌选择器的低秩矩阵，原始LVLM冻结；每个层独立优化；使用256个样本从LLaVA-655k数据集训练
  - 推理：无需重新训练，直接加载预训练的选择器参数；每层动态执行top-k选择与跳过-合并
  - 参数效率：LLaVA-1.5-7B每层选择器仅引入4.2M参数（约2%开销），Qwen2.5-VL-3B每层0.8M参数（约1.1%）
  - 优化速度：LLaVA-1.5-7B完整优化可在15分钟内完成

### 4. Adapting Reinforcement Learning with Chain-of-Thought Supervision for Explainable Detection of Hateful and Propagandistic Memes
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.15307v1
- 方法流程：
  - 数据准备：原始模因，OCR文本，指南，构建指令数据集
  - 弱监督CoT蒸馏：从强MLLM（如GPT-4V）为训练样本生成逐步推理轨迹
  - SFT暖启动：用标签、解释和蒸馏的CoT进行监督微调
  - 有监督GRPO：使用复合奖励函数（准确率、METEOR、格式合规、长度正则化）进行GRPO训练
  - 自监督GRPO（可选）：使用共识伪标签（多次采样多数投票）从无标注数据训练
- 关键模块/机制：
  - 弱监督CoT蒸馏：从强MLLM（如GPT-4V）生成逐步推理轨迹，提供额外监督信号；使用预训练MLLM对训练样本生成CoT自然语言解释，直接作为SFT数据或进行过滤
  - 思维长度正则化奖励(Rthink)：在GRPO中惩罚过短的CoT推理，但饱和超过最小长度，防止奖励黑客；阈值奖励：如果推理步数小于阈值则奖励为0，否则为1（或其他饱和设计）
  - 多LLM细粒度标注：为ArMeme创建细粒度宣传标签，使用两个LLM标注并通过第三个LLM整合；使用Gemini和Claude分别标注样本，然后使用GPT-4整合得到最终标签
  - 共识伪标签：为自监督GRPO提供伪标签，从多次随机采样中取多数票；对同一输入通过模型多次随机采样（温度>0），取多数预测作为伪标签
- 公式/目标函数/指标定义：
  - 复合奖励：R = α * R_acc + β * R_met + γ * R_fmt + δ * R_len
  - R_acc：分类正确性奖励（正确为1，错误为0）
  - R_met：解释相似度奖励（使用METEOR分数）
  - R_fmt：格式合规奖励（输出格式正确为1，否则为0）
  - R_len：思维长度正则化奖励（阈值奖励：长度≥最小步数得1，否则0）
  - GRPO目标：最大化组相对优势，基于多个采样响应的奖励
- 算法细节：
  - GRPO训练：对每个输入采样多个响应（如8个），计算奖励，计算组内相对优势，通过策略梯度更新模型
  - SFT阶段：使用标准交叉熵损失，监督数据包括标签、人工解释、蒸馏CoT
  - 思维长度正则化：设定最小推理步数阈值（如64 token），低于阈值R_len=0，高于则R_len=1，防止模型输出空推理
- 训练/推理细节：
  - 训练阶段：两阶段——先SFT暖启动，再GRPO后训练
  - SFT使用带标签、解释和蒸馏CoT的指令数据，学习率按标准MLLM设置
  - GRPO中每个样本采样多个响应，计算复合奖励，使用组相对优势更新模型参数
  - 推理：模型首先生成CoT推理链，然后输出分类标签和解释
  - 自监督GRPO：使用模型自身多次采样生成伪标签，作为奖励计算依据

### 5. Let LLMs Judge Each Other: Multi-Agent Peer-Reviewed Reasoning for Medical Question Answering
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.15419v1
- 方法流程：
  - 输入：医学问题（如HeadQA、MedQA-USMLE、PubMedQA数据集中的问题）
  - 阶段1-推理生成：多个LLM代理（例如Llama-3.1-8B、Qwen2.5-7B等）各自独立生成链式思考（CoT）推理轨迹和候选答案
  - 阶段2-同行评审：每个代理作为评审者，对其他代理的推理轨迹基于事实正确性和逻辑合理性进行0-5评分
  - 选择与输出：聚合所有评分，选出评分最高的推理轨迹对应的答案作为最终输出
- 关键模块/机制：
  - 多代理推理生成器：生成多样化的推理链和候选答案，为后续评审提供素材；每个LLM独立运行，使用低温度（0.1）和固定种子，生成不超过1024 tokens的CoT推理
  - 同行评审评分器：评估推理链的质量，包括事实正确性和逻辑一致性；使用6点李克特量表（0-5），评审者模型对每条推理链进行打分，评分标准基于事实和逻辑
  - 最高分推理选择器：根据评审分数选择最佳推理链并输出对应答案；汇总所有评分，选择平均分最高的推理链（或最高分链，原文未明确聚合方式），以该链的答案作为最终结果
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 对所有问题批量生成所有模型的CoT回答，然后单独批量生成所有评审评分（三阶段：生成回答、生成评审、聚合）
  - 在聚合阶段，每个问题取所有评审者对该问题不同推理链的评分，选择最高分的推理链
- 训练/推理细节：
  - 无训练过程，完全基于预训练LLM进行推理和评审
  - 推理时使用温度0.1，最大生成长度1024 tokens，固定随机种子
  - 实验在NVIDIA A100 GPU（40GB）上运行，使用PyTorch和Hugging Face Transformers

  - 输入：用户查询（含健康指标上下文）和PHA生成的响应。
  - 阶段1 - 量规树构建：通过人机循环协议，由医生主导的专家小组基于4000条真实用户查询，提炼出超过100个原子布尔量规，并组织成层级树（如症状、健康数据、行动方案、医疗解释等分支）。
  - 阶段2 - 自适应路由：对于每个待评估的（查询，响应）对，上下文感知自适应路由器根据查询内容激活相关量规子集，并为每个激活的量规分配动态权重。
  - 阶段3 - 原子检查：对每个激活的叶子量规，使用LLM作为判断器执行二元验证（通过/不通过）。
  - 阶段4 - 聚合评分：将所有叶子量规的结果按其权重加权求和，得到最终的连续评估分数。
  - 输出：一个标量分数（0-1）或每个量规的通过/不通过列表。
- 关键模块/机制：
  - 量规树策展（Rubric Tree Curation）：构建和维护评估标准体系；由医生领导的专家小组，通过人机循环协议对4000条真实用户查询进行迭代分析，提取出超过100个原子布尔量规，并按临床类别（如症状、健康数据、行动方案、医疗解释）组织成层级树。每个量规是一个临床可验证的二元问题（例如：'响应是否提到了用户的心率数据？'）。策展过程包括初始量规生成、专家审核、测试和修订。
  - 上下文感知自适应路由器（Context-Aware Adaptive Router）：动态选择并加权与当前查询相关的量规子集；对于每个查询，路由器首先分析查询内容和上下文，从量规树中识别出相关的分支和叶子量规。然后，它为每个选中的量规分配一个权重（自动加权），权重可以基于该量规在类似查询中的重要性或由路由器模型预测。该模块显著减少了每个查询需要评估的量规数量，提高了吞吐量，同时避免了无关量规带来的噪声。
  - 布尔量规聚合（Boolean Rubric Aggregation）：将多个二元检查结果组合成最终分数；在自适应路由器选出量规子集并分配权重后，对每个叶子量规进行二元判断（通过/不通过）。最终分数为所有通过的量规的权重之和除以总可能权重（即所有激活量规的权重之和）。这保证了分数在0-1之间，且每个量规的贡献可审计。
- 公式/目标函数/指标定义：
  - 检测率 (DR) = 被检测为退化的样本数 / 总样本数 × 100%
  - 平均惩罚 (ΔMP) = (1/N) * Σ( (S_clean - S_degraded) / S_clean ) × 100%
  - 聚合分数 = Σ( w_i * pass_i ) / Σ( w_i )，其中w_i为权重，pass_i ∈ {0,1}。
- 算法细节：
  - 量规树构建算法：从初始种子量规开始，经专家小组评估修改，然后在4000条查询上测试，根据结果添加、删除或合并量规，重复多次直到稳定。
  - 自适应路由算法：使用预训练的LLM或轻量级分类器，基于查询文本预测相关的临床类别和量规。首先粗略分类到四大类别（症状、健康数据、行动方案、医疗解释），然后在该类别树内部精确选择叶子节点。权重由路由模型根据类别常见性或查询特异性输出。
  - 原子布尔检查：对于每个叶子量规，将查询和响应作为上下文输入给LLM（如Gemini），LLM输出'通过'或'不通过'，并附上简短理由。
  - 扰动测试算法：对原始查询进行四种扰动（缺失指令、缺失数据、不适当指令、不准确数据），然后分别用RubricsTree和基线评估器打分，计算DR和ΔMP。
- 训练/推理细节：
  - 推理阶段：RubricsTree作为评估器时，其自身不进行训练，仅对每个（查询，响应）对执行一次量规选择和检查，输出分数。
  - 下游优化方式一（Prompt Optimization）：将整个量规树（或相关子集）以结构化手册形式注入PHA的系统提示中，不更新模型权重。
  - 下游优化方式二（Response Optimization）：RubricsTree评估初始响应后，将每个未通过的量规及其理由作为反馈提供给PHA，PHA据此进行一次修订，再重新评估。
  - 下游优化方式三（Reward Training）：将RubricsTree的聚合分数转化为密集标量奖励，用于强化学习（如PPO），更新PHA的模型权重。实验中用于训练Qwen模型系列。
  - 所有下游优化实验在HealthBench-Hard和HealthBench-Consensus子集上进行，保证量规不直接评分这些子集，避免数据泄露。

### 13. Domain Generalizable Adaptation of 3D Vision-Language Models via Regularized Fine-Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18472v1
- 方法流程：
  - 输入：点云x，类别标签y；预训练ULIP模型（含点云编码器fP、图像编码器fI、文本编码器fT）
  - 步骤1：选择性层微调——冻结fP的前Lf层，仅微调后L-Lf层；图像和文本编码器完全冻结
  - 步骤2：多视图一致性正则化——对x应用K种几何变换（旋转、缩放、抖动）得到{x_k}，通过fP计算嵌入{z_kP}，对每个z_kP与类文本嵌入计算交叉熵损失L_CE^k，平均得到L_aug
  - 步骤3：文本多样性正则化——对每个类c，从WordNet获取M个同义词，用LLM生成Q个描述性提示，通过fT得到嵌入并平均作为类嵌入z_cT
  - 步骤4：点渲染视觉监督——从点云渲染2D图像I，通过冻结的fI得到图像嵌入zI，与每个z_kP计算InfoNCE对比损失L_contrast^k，平均得到L_contrast
  - 步骤5：联合优化——总损失L = L_aug + α * L_contrast，其中α=1.0，使用SGD优化器训练20个epoch
  - 步骤6：测试时增强——对测试点云施加Ktest=5次增强，每类使用Q=7个文本提示，取每个增强的最大softmax概率作为置信度，保留前H=3个，通过多数投票得到最终预测
- 关键模块/机制：
  - 选择性层微调：在微调中保留预训练低层几何特征，调整高层语义特征，防止灾难性遗忘；PointBERT编码器共12层，冻结前11层，仅微调第12层
  - 多视图一致性正则化：通过对输入点云进行多种几何变换并平均损失，迫使模型产生一致嵌入，减少过拟合；对每个点云应用K=16种随机变换（旋转0-360°、缩放0.8-1.2、抖动标准差0.01），计算每个变换下的交叉熵损失，取平均
  - 文本多样性正则化：通过同义词和LLM生成多样化文本提示，平均文本嵌入，增强类嵌入对描述变化的鲁棒性；对每类从WordNet取7个同义词，用Qwen-2.5-7B-Instruct生成7个包含同义词的提示句，模板为'A 3D point cloud of {synonym}'，平均所有提示嵌入作为该类文本嵌入
  - 点渲染视觉监督：利用冻结的预训练图像编码器提供视觉监督，对齐点云与渲染图像嵌入，增强跨模态一致性；使用Blender渲染12个视图（距离1.8m，方位角0-360°步长30°，仰角0°/15°/30°，分辨率512x512），取图像嵌入与各增强点云嵌入计算InfoNCE对比损失，负例为批次中其他点云的图像嵌入
  - 测试时增强：通过多增强和多文本提示聚合，提高测试鲁棒性；测试时对点云做Ktest=5次增强，每类用Q=7个文本提示，取每次增强的最大softmax概率作为置信度，选择前H=3个增强结果，通过多数投票得到最终类别
- 公式/目标函数/指标定义：
  - 交叉熵损失（基）：L_CE = -log( exp(sim(z_P, z_y^T)/τ) / Σ_{c=1}^C exp(sim(z_P, z_c^T)/τ) )
  - 多视图一致性正则化损失：L_aug = (1/K) Σ_{k=1}^K L_CE^k
  - InfoNCE对比损失：L_contrast^k = -log( exp(sim(z_kP, z_I)/τ) / Σ_{z'∈{z_I}∪Z_neg} exp(sim(z_kP, z')/τ) )
  - 总损失：L = L_aug + α * L_contrast, α=1.0
  - 类文本嵌入：z_c^T = (1/Q) Σ_{q=1}^Q z_c,q^T
  - 余弦相似度：sim(a,b) = a·b / (||a|| ||b||)
- 算法细节：
  - 选择性层微调：冻结PointBERT前11层，仅第12层参数可训练，图像和文本编码器全部冻结
  - 多视图一致性正则化：对每个输入点云随机生成16种变换（旋转、缩放、抖动），分别计算交叉熵损失后取平均，作为主要监督信号
  - 文本多样性正则化：每类生成7个同义词，并用LLM生成7个描述性提示，将所有提示的文本嵌入平均作为该类文本嵌入
  - 点渲染视觉监督：使用Blender渲染点云的12个2D视图，通过冻结的CLIP视觉编码器得到图像嵌入，与每个增强点云嵌入计算对比损失，负例来自同一批次中其他样本的图像嵌入
  - 测试时增强：测试时对点云进行5次随机增强，对每类使用7个文本提示，取每次增强的最大softmax概率作为置信度，选择前3个增强结果，应用多数投票得出最终预测
- 训练/推理细节：
  - 训练：优化器SGD，学习率0.0025，动量0.99，权重衰减1e-5，余弦退火学习率调度，批次大小32，训练20轮
  - 推理：测试时增强步骤5次，文本提示每类7个，前3置信度结果多数投票
  - 预训练模型：ULIP-2 with PointBERT编码器，图像编码器CLIP ViT-B/16，文本编码器CLIP文本编码器，均冻结
  - 数据增强：训练时16种随机变换（旋转360°、缩放0.8-1.2、抖动0.01），测试时5种随机变换

- 方法流程：
  - 输入体积X∈R^{D×H×W}。

  - Adaptive Gated Fusion (AGF)：内容感知残差校正，将高频率细节注入语义流。；输入Fsem和Fdet的C3特征，通道拼接后经1×1×1卷积和sigmoid生成门控图G∈[0,1]，然后F̃_det = Fsem + G⊙F_det^{C3}。
- 公式/目标函数/指标定义：
  - 损失函数：L = 0.2 L_CE + 0.8 L_Dice
  - AGF门控：G = σ(K_{1×1×1}([F_sem; F_det^{C3}]))
  - AGF融合：F̃_det^{C3} = F_sem + G ⊙ F_det^{C3}
- 算法细节：
  - 第一阶段：沿深度方向滑动窗口，构建K=3连续切片组（边界零填充），利用ICE进行3D卷积嵌入，DINOv3编码后通过MLP头预测中心切片分割图，全微调优化。
  - 第二阶段：输入完整体积，沿深度滑动K切片组，逐组通过ICE和DINOv3（冻结主干，注入LoRA，r=16, α=16, p=0.1），堆叠恢复3D几何，再通过3D反卷积适配器获得粗语义图。
  - HRSE细节流独立处理体积，提取多尺度特征。
  - AGF融合：对粗语义图Fsem和细节流1/4尺度特征F_det^{C3}，通道拼接后1×1×1卷积和sigmoid生成门控，再与F_det^{C3}元素乘后加回Fsem。
  - 最终解码器（UperNet）逐级融合不同分辨率特征，输出分割概率图。
- 训练/推理细节：
  - 两阶段训练各50轮，第一阶段学习率2e-5，batch size 24；第二阶段学习率1e-4，batch size 1。
  - 优化器未明写，使用Adam？默认。
  - 数据增强：随机旋转、缩放、强度抖动。
  - 推理：输入体积D×H×W，滑动K=3切片组，双流并行处理，融合后输出D×H×W分割图。

### 17. GUMP-Net: An interpretable model-data-driven intelligent algorithm for multi-class pelvic segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19215v1
- 方法流程：
  - 输入图像，首先通过ODM（基于YOLO-like检测器）预测每个解剖类别（左髋、右髋、骶骨）的边界框

  - 将初始LSF、图像和EDF输入IM，IM由多个级联的迭代块组成，每个块模拟一步GAC梯度流（公式2），但用学习到的EDF和可调参数（α等）更新LSF
  - 经过多块迭代后，最终LSF的零水平集给出每个类别的分割结果
- 关键模块/机制：
  - Object Detection Module (ODM)：自动水平集初始化：预测每个解剖类别的边界框，并据此构造初始水平集函数（符号距离函数形式，框内为负，框外为正）；采用轻量级目标检测网络（如YOLO或Faster R-CNN变体），输出类别和边界框坐标。对每个类别，初始LSF定义为该边界框的符号距离函数，框内区域为负（目标区域），框外为正。多类别对应多通道LSF。
  - Edge Detector Module (EDM)：学习解剖感知的边缘检测函数（EDF），为水平集演化提供引导；基于U-Net架构，输入原始图像，输出与图像同分辨率的C通道特征图（C为类别数），每个通道对应一个类别的EDF。训练时，EDF被鼓励在目标边界处取小值，在平坦区域取大值，不同于传统基于梯度的EDF（对所有边缘敏感）。通过融合改进GAC中的面积项和长度项信息，EDM可抑制无关边缘并突出目标解剖边界。

- 公式/目标函数/指标定义：
  - GAC模型能量泛函：E(ϕ) = ∫Ω g(|∇I|)|∇H(ϕ)|dx + α∫Ω g(|∇I|)H(-ϕ)dx
  - 梯度流方程：∂ϕ/∂t = [∇·(g ∇ϕ/|∇ϕ|) + αg] δ(ϕ), ϕ(0,x)=ϕ0(x)
  - 训练损失：Dice损失 + 交叉熵损失 + 水平集正则项（如使LSF保持符号距离函数性质）
- 算法细节：
  - ODM使用预训练的目标检测网络，在骨盆数据集上微调，输出边界框置信度阈值过滤后用于初始化
  - EDM采用U-Net结构，输出通过Sigmoid激活确保值在(0,1)之间，作为EDF
  - IM中每个迭代块包含可学习的参数：Δt（时间步长）和α（面积项权重），利用可微卷积和TV去噪算子实现∇·(g∇ϕ/|∇ϕ|)的高效计算
  - 多通道水平集独立演化，但所有通道共享相同的EDM输出（即EDF是类别特定的，每个通道使用对应的EDF通道）
  - 迭代终止条件：固定迭代次数，不依据收敛性提前停止
- 训练/推理细节：
  - 端到端训练：ODM、EDM和IM联合训练，总体损失为分割损失（Dice+CE）加上水平集正则
  - 训练数据：骨盆CT图像，标注为左髋、右髋、骶骨三个类别
  - 优化器：Adam，学习率1e-4，权重衰减1e-5
  - 数据增强：随机旋转、缩放、弹性变形
  - 推理时：输入图像依次通过ODM、EDM和IM，输出最终LSF取负区域为分割掩模
  - ODM在训练时可固定或微调，试验中采用冻结检测器骨干，仅微调头部

  - ORSA：在训练时对齐对象区域特征与文本嵌入，提升罕见类别检测；包含一组可学习查询和一个3层前景解码器（结构同主解码器）。训练时，查询被GT框信息引导，从第一编码器输出中提取前景对象特征，并与对应文本特征进行对齐。推理时移除该模块。

  - 密集空间语义损失: L^l_spa = (1/B) Σ_i KL(s_clip^{(i)} || s_l^{(i)}), 其中 s_c^{(m)} = exp(cos(||CLS_c||_2, ||¯P_m_c||_2)/τ2) / Σ_{n=1}^{H_l×W_l} exp(cos(||CLS_c||_2, ||¯P_n_c||_2)/τ2), c∈{l,clip}
  - 总蒸馏损失: L_dis = 0.5*(λ_sem(L^6_sem+L^5_sem) + λ_rel(L^6_rel+L^5_rel) + λ_spa(L^6_spa+L^5_spa))

  - ORSA: 训练时，将一组可学习查询（数量为前景物体数）和第一编码器输出送入3层前景解码器，每层包含自注意力、交叉注意力（查询与编码器输出）和前馈网络；查询初始化为零，通过交叉注意力聚焦于GT框区域；输出特征与对应文本特征通过余弦相似度损失对齐。
- 训练/推理细节：
  - 训练数据：Objects365v1（O）和GoldG（G）混合训练；使用8块NVIDIA L40 GPU；冻结CLIP-B/16的文本和视觉编码器参数；优化器及超参数未详述，但默认与DINO相同。

### 19. AVIS: Adaptive Test-Time Scaling for Vision-Language Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.11576v1
- 方法流程：
  - 输入图像和问题，通过视觉编码器提取视觉嵌入序列
  - VCS阶段：计算每个视觉token的KDV保留得分（负平均余弦对齐），根据阈值τ保留得分≥-cos(τ)的token，获得样本相关的保留比例ρ(x)
  - 将保留的视觉token与问题文本拼接，执行共享预填充，生成KV缓存
  - VRS阶段：将视觉嵌入输入难度预测器，得到预测可解性分数ˆp(x)
  - 根据预定义的binning规则将ˆp(x)映射为rollout数量K∈{1,3,5,7}
  - 对每个查询采样K条推理轨迹（温度0.7，top-p 0.9），通过多数投票聚合答案
- 关键模块/机制：
  - 自适应KDV修剪：实现视觉上下文缩减，去除与锚点方向对齐度过高的冗余token；对于每个注意力头，计算所有视觉token的均值嵌入作为锚点方向；每个token的KDV得分ri为负平均余弦对齐；通过阈值τ（实验中π/4）保留得分≥-cos(τ)的token，保留比例ρ(x)随样本变化。
  - 难度预测器：预测查询的可解性分数，用于决定自一致性rollout数量；轻量网络：输入为视觉嵌入序列，经过1D Conv-GroupNorm-SiLU层堆叠、全局平均池化、浅层MLP，输出二类logits；训练时使用校准集（Kmax=10 rollout计算经验可解性并二值化）作为监督。
  - 非单调binning规则：将连续预测分数映射为离散rollout数量，集中计算资源于中等难度样本；根据公式(5)自一致性正确概率的边际效用呈倒U型，设定bin边界：ˆp∈[0,b1)→K=1; [b1,b2)→5; [b2,b3)→7; [b3,b4)→5; [b4,b5)→3; [b5,1]→1；边界在校准集上选定以符合全局计算预算。
- 公式/目标函数/指标定义：
  - 自适应KDV保留公式：Sτ(x) = {i ∈ {1,...,nv}: ri ≥ -cos(τ)}，其中ri是token i的KDV得分（负平均余弦对齐）
  - 自一致性正确概率：P_SC(p, K) = Σ_{j=⌈(K+1)/2⌉}^{K} C(K,j) p^j (1-p)^{K-j}，其中p为单轨迹正确概率
  - 难度预测器训练目标：基于校准集上Kmax=10 rollout的经验可解性p(xj) = (1/Kmax) Σ I(ˆy^{(k)} = y*)，二值化标签yj = I(pj ≥ 0.5)，训练交叉熵损失
- 算法细节：
  - KV缓存共享：所有rollout复用同一预填充阶段的KV缓存，减少重复计算
  - 锚点方向计算：对每头注意力，计算所有视觉token嵌入的均值作为锚点方向
  - bin边界选择：在校准集上通过网格搜索或分位数策略确定bin边界，使得整体计算预算匹配目标FLOPs
  - test-time推理：先执行KDV修剪，共享预填充，然后根据预测的ˆp(x)动态选择K，每个rollout独立自回归解码
- 训练/推理细节：
  - 难度预测器训练：使用5000样本校准集（4000图像+1000视频），每个样本运行Kmax=10 rollout获取经验可解性p(xj)并二值化
  - 校准集构建原则：质量、多样性、难度，从73k候选筛选
  - 推理时共享预填充：所有rollout共享同一个视觉和文本前缀的KV缓存，仅在解码阶段独立采样
  - 自一致性采样参数：温度0.7，top-p 0.9，多数投票聚合

### 20. Adapting Vision-Language Models from Iconic to Inclusive for Multi-Label Recognition Without Labels
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.11626v1
- 方法流程：
  - 第一阶段（切割）：输入图像，使用多采样响应估计器从CLIP中提取局部补丁响应，生成初始局部响应和局部字典，提升非显著物体。
  - 第二阶段（缝合）：输入局部字典，使用多对象混合适应，调整标签以符合多标签分布，同时保持原始模型特性，通过顺序置信度校正融合预测。

  - 期望最大化优化框架：迭代优化切割和缝合两个阶段，逐步增强语义理解；E步：使用当前估计器生成局部响应和字典；M步：使用当前适配器更新标签和模型参数。轻量级估计器和适配器，仅需一个epoch。
- 算法细节：
  - 多采样：对图像进行多次随机裁剪或网格划分，每个裁剪块输入CLIP得到类别分数，通过聚合（如平均或最大化）得到多标签预测。
  - 响应估计器：对每个局部区域计算CLIP logits，生成局部字典（每个区域top-k类别）。
  - 混合适应：将原始CLIP全局预测与局部字典融合，通过顺序置信度校正（按预测置信度排序后加权）得到最终标签。
  - EM迭代：重复E步（更新局部响应）和M步（更新适配器参数），直到收敛。
- 训练/推理细节：
  - 训练仅需一个epoch，无标签数据。
  - 推理时，模型无需依赖原始VLM，使用训练后的standalone模型进行多标签预测。
  - 使用轻量级估计器和适配器，计算效率高。

- 方法流程：
  - 输入：视觉令牌集合V（含|V|个令牌）和文本令牌T，解码器分为S个阶段，每个阶段i有路由层ℓi和保留比率ri。
  - 阶段i开始：候选池Ci = V（所有视觉令牌）。在路由层ℓi，计算文本-视觉注意力分数，对Ci中的令牌排名，选择top-K个（K = ⌊ri * |V|⌋）作为选中令牌Vsel_i，其余为延迟令牌Vdef_i。
  - 选中令牌Vsel_i与文本令牌T构成活跃集Ai = T ∪ Vsel_i，通过后续N个Transformer层（Attn+FFN）；延迟令牌Vdef_i通过残差路径直接跳过这些层。
  - 阶段输出：选中令牌与延迟令牌按原始顺序合并，视觉令牌集合恢复为V，进入下一阶段。
  - 重复步骤2-4直到所有阶段完成，输出最终隐藏状态。
- 关键模块/机制：
  - Rank & Reroute操作符：在每个路由层执行令牌排名与路由决策；重用当前解码层已计算的文本-视觉注意力分数作为排名信号，选择分数最高的top-ri%视觉令牌作为选中令牌，其余标记为延迟令牌。无需额外训练路由器。
  - 延迟令牌旁路（Residual Bypass）：延迟令牌跳过当前阶段的Transformer层；延迟令牌通过恒等残差路径直接复制到阶段输出，不参与Attn和FFN计算，与选中令牌在阶段输出处合并恢复原始顺序，从而在下阶段重新进入候选池。
  - 阶段式调度：定义路由层位置和每阶段的保留比率；解码器被划分为S个阶段，每个阶段i指定路由层ℓi和保留比率ri（如0.5, 0.3, 0.2等）。Reroute复用原始修剪方法（如FastV、PDrop、Nüwa）的调度设置，不引入新超参数。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
  - 符号化关系：Vsel_i = TopK_i(C_i) with K_i = ⌊r_i * |V|⌋, Vdef_i = C_i \ Vsel_i, C_i = V（所有阶段候选池为完整视觉令牌集）
  - 理论FLOPs与KV-cache预算与原始修剪方法相同：仅|A_i| = |T| + |Vsel_i|个令牌参与Attn和FFN计算
- 算法细节：
  - 路由决策重用解码器已有注意力计算：在路由层ℓi，先执行标准自注意力（含文本与所有视觉令牌），利用文本到视觉的注意力分数排序视觉令牌，无需额外计算。
  - 延迟令牌的旁路实现：在阶段内，延迟令牌的隐藏状态直接传递（identity mapping），不经过任何自注意力或FFN子层，阶段输出时与选中令牌按原序列位置合并。
  - 多阶段路由重复：每个阶段独立选择令牌，被延迟的令牌可在后续阶段重新被选中，实现可恢复性。
- 训练/推理细节：
  - 无需训练：直接作为插件插入现有解码器，不引入可学习参数。
  - 推理时：保持与原始修剪方法相同的活跃令牌数，因此注意力计算和KV-cache存储的理论复杂度一致。
  - 适用于自回归生成：路由决策在每个解码步骤（生成每个文本令牌）独立进行，但注意论文主要关注预填充阶段（prefill）的视觉令牌减少，仍可与KV-cache压缩结合。

  - 问题采样：从预定义模板（13类）中随机采样，利用LLM多样化措辞，模板包含对象引用、时间、坐标系等槽位。
  - 资产筛选：根据问题类型对视频片段进行启发式过滤（如相机静止/移动、物体运动特性），确保有足够的合格对象。
  - 离散标签生成：将连续几何测量（距离、旋转、方向等）映射为离散类别（如变近/变远/不变），并设定数据源特定阈值。
  - QA生成：填充模板槽位，对于点追踪问题直接使用连续坐标值；输出问答对。
  - 人工验证：多轮人工校验保证基准集质量。
- 关键模块/机制：
  - True-Motion Point Tracking公式：解耦物体与相机运动，提供直观的图像对齐运动表示；给定3D点轨迹{X[t]}和移动相机外参{T[t]}、内参K，定义视觉点轨迹P2D为投影到随时间变化的相机（式1），真运动点轨迹M2D为投影到固定参考时间tq的相机（式2）。两者在相机静止时等价。
  - QA生成器（QA Generator）：核心组件，根据模板和采样资产生成问答对；使用预定义模板，槽位包括对象引用、时间、坐标系；利用LLM生成多样化表述；对于描述性问题填充离散标签，对于点追踪填充连续坐标。
  - 资产采样（Asset Sampling）：筛选具有所需运动特性的视频片段和对象；随机采样视频片段后，根据启发式和数据集特定阈值判断相机和物体运动是否满足问题类型要求；过滤不可见或运动不充分的物体；选择参考系（相机、物体、屏幕空间或重力对齐）和对象引用方式（标题、像素坐标或视觉圈注）。
  - 离散标签生成（Discrete Label Generation）：将连续几何测量映射为分类标签；对3D平移用（前/后、左/右、上/下）组合，3D旋转用（pan左/右、tilt上/下、roll顺/逆），3D距离用（增大/减小/不变），2D屏幕空间运动类似；设定阈值保证标签准确且符合人类感知。
- 公式/目标函数/指标定义：
  - P2D = {p[t]} = {Π(K, T[t], X(t))} (视觉点轨迹，投影到随时间变化的相机)
  - M2D = {m_tq[t]} = {Π(K, T[tq], X(t))} (真运动点轨迹，投影到固定参考时间tq的相机)
  - 当相机静止时T[t] = T[tq]，两者等价
- 算法细节：
  - 数据标准化流程：统一坐标系统、图像分辨率、帧率、相机参数（内参+外参）、深度图、分割图、元数据、6D物体姿态。
  - 对象标题生成：使用VLM根据边界框和初始标签对每个物体生成描述。
  - 3D点轨迹提取：从深度图、相机姿态和6D物体姿态计算。
  - 视频片段评估：基于启发式规则和阈值评估相机是否静止/移动、物体运动特性（静止/移动/转向）、可见性。
  - 坐标系选择：根据问题类型选择相机、物体、屏幕空间或重力对齐坐标系。
  - 跟踪坐标输出：归一化到[0,1]并保留三位小数；随机化帧顺序防止自回归捷径，并在查询中指定帧索引。
  - 4D VLM架构：将预训练几何编码器L4P（ViT基础）的输出通过MLP投影，与图像编码器的视觉token交错输入语言骨干（NVILA-Lite-8B）。
- 训练/推理细节：
  - 训练数据：400K QA对，来自3.3M帧，每段32帧，分辨率448x448。
  - 训练配置：batch size 128，训练1 epoch（约3100次迭代），冻结视觉编码器。
  - 优化器：AdamW，余弦学习率调度。NVILA-Lite-8B学习率2e-5；Qwen-VL系列学习率1e-5。
  - 硬件：32块NVIDIA A100 GPU，4步梯度累积，每模型训练约9小时。
  - 评估：2220测试样本（4DP-QA-Bench），多选或Y/N格式，使用精确字符串匹配计算准确率。
  - 推理：对于点追踪，模型输出连续坐标序列（归一化坐标+遮挡标志）。

### 27. nD-RoPE: A Generalized RoPE for n-Dimensional Position Embedding
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.12146v1
- 方法流程：
  - 输入: 位置向量 x ∈ R^n 和波矢向量 ω ∈ R^n 作为耦合的n维向量
  - 步骤1: 从平移不变相对位置注意力假设出发，定义内积仅依赖于相对位移 d = x1 - x2
  - 步骤2: 通过希尔伯特空间函数表示，将内容向量提升为平方可积函数 γ(q,·)，并通过平移实现位置依赖
  - 步骤3: 应用傅里叶变换，将位置依赖转化为相位因子 e^{jω^T d}，得到频率域表示
  - 步骤4: 利用Riesz表示定理，将频率域表示 Γ(q,ω) 写为 q^T B(ω)，并满足 ∫ B(ω)B(ω)^H dω = I_d
  - 步骤5: 实例化波矢设计：采用多尺度正则单纯形波矢，选择对称分布的频率向量以保持各向同性
  - 输出: 位置嵌入通过逆傅里叶变换将频率域表示映射回空间域，用于注意力计算中的相对位置编码
- 关键模块/机制：
  - 平移不变相对位置注意力框架：定义位置嵌入的核心约束，使注意力内积仅依赖于相对位移；假设查询和键嵌入是位置依赖函数，内积 h(q,k,d) 只与相对位移 d 有关，通过函数平移和投影推导出傅里叶域形式
  - 频率域表示与Riesz投影：将位置编码转化为频率域线性投影，保证零位移时恢复原始内容内积；通过Parseval定理和内积恒等式导出 Γ(q,ω)=q^T B(ω)，且 ∫ B(ω)B(ω)^H dω = I_d，使得位置依赖完全由相位因子 e^{jω^T d} 承载
  - 多尺度正则单纯形波矢设计：提供非退化、各向同性的频率覆盖；选择位于正单纯形顶点方向的波矢向量，并采用多尺度频率（类似1D RoPE的θ_i），确保二阶响应方向对称，减少方向偏差
- 公式/目标函数/指标定义：
  - ⟨f(q,x1), f(k,x2)⟩ = h(q,k,d), 其中 d = x1 - x2
  - ∫_{R^n} γ(q,x+d) γ(k,x)^* dx = ∫_{R^n} e^{jω^T d} Γ(q,ω) Γ(k,ω)^* dω
  - 零位移条件: ∫_{R^n} Γ(q,ω) Γ(k,ω)^* dω = q^T k
  - Riesz表示: Γ(q,ω) = q^T B(ω), 且 ∫_{R^n} B(ω) B(ω)^H dω = I_d
- 算法细节：
  - 将输入位置 x 和波矢 ω 视为 n 维向量，不进行轴分解
  - 通过 Riesz 表示定理，将频率域表示 Γ 参数化为内容向量 q 与频率依赖矩阵 B(ω) 的线性投影
  - 设计正则单纯形波矢：在 n 维空间中，选择 n+1 个方向向量构成单纯形顶点，每个方向分配多个尺度（频率基），形成多组波矢
  - 位置编码通过逆傅里叶变换计算：γ(q,x) = ∫ Γ(q,ω) e^{jω^T x} dω，实际实现中离散化求和
- 训练/推理细节：
  - 使用与基线相同的骨干网络和训练协议，仅替换位置嵌入模块
  - 对于图像任务，保持训练分辨率为224×224，外推时直接应用到更高分辨率，无需插值
  - 对于点云，训练时使用固定点数（如2048），外推时测试不同密度
  - 与YaRN结合时，在注意力计算前对频率进行额外缩放

### 29. Language-Guided Abstraction for Visual Reasoning
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.12847v1
- 方法流程：
  - 输入：一个任务包含支持集（K个输入-输出对）和查询集（M个输入，仅输入给定）
  - 语义压缩：离线使用DeepSeek-V3对每个任务的原始LARC描述进行压缩，生成统一格式的语义嵌入（长度适配CLIP的77 token）
  - 视觉特征提取：视觉主干网络（基于VARC）处理输入网格，输出视觉特征
  - 交叉注意力对齐：CAP以视觉特征为查询，语义嵌入为键和值，通过交叉注意力生成对齐后的视觉特征，并计算对齐损失L_align
  - 预测输出：对齐后的视觉特征经解码器生成预测网格，计算预测损失L_pred
  - 联合训练：总损失 L = L_pred + λ * L_align，其中λ=0.1
  - 推理：仅使用视觉主干网络（不含语言分支），直接对查询输入预测输出网格
- 关键模块/机制：
  - 语义压缩模块（SCM）：将原始LARC语言描述压缩为结构化、紧凑的语义嵌入，适配标准文本编码器的输入长度；使用DeepSeek-V3大语言模型，输入为统一任务无关提示加上原始LARC描述，输出为压缩后的语义文本，然后经CLIP文本编码器得到语义嵌入（每个任务一个嵌入向量）。整个过程离线执行一次。
  - 交叉注意力投影器（CAP）：对齐视觉特征与语义嵌入，将语言引导注入视觉骨干训练；以视觉特征为查询（Query），语义嵌入为键（Key）和值（Value），通过交叉注意力机制计算注意力权重，得到加权后的语义增强视觉特征。该特征用于后续解码器预测。训练时通过对齐损失（L_align）拉近对齐后的视觉特征与语义嵌入的距离。
  - 视觉主干网络（Main Backbone）：从输入网格提取视觉特征并预测输出网格；继承自VARC的编码器-解码器结构，编码器将输入网格映射为特征图，解码器将特征图映射为输出网格。训练时接收来自CAP的对齐特征，推理时独立运行，参数18M。
- 公式/目标函数/指标定义：
  - 总损失函数：L = L_pred + λ * L_align，其中λ=0.1，L_pred为输出网格与真实网格之间的损失（具体形式未明确，可能为交叉熵或MSE），L_align为对齐损失（未明确公式，通常为对比损失或余弦相似度损失）
  - 评估指标：PASS@1 = 一次尝试中预测正确的任务比例；PASS@2 = 两次尝试中至少一次正确的任务比例；ORACLE = 取k次预测中最好的结果
  - Votes指标：top-1预测在510个测试时训练样本中出现的频率
- 算法细节：
  - 训练时每个任务从支持集中抽取K个输入-输出对（K未明确，但ARC通常为3-5个），查询集M通常为1
  - 视觉特征经过CAP后得到对齐特征，经解码器生成预测网格，使用argmax或采样得到离散输出
  - 推理时采用多候选机制：对每个查询输入生成多个预测（可能通过随机采样或温度调节），然后通过投票（Votes）选择最终输出
  - 离线语义压缩：所有训练任务的LARC描述一次性经过DeepSeek-V3处理，生成压缩后的语义文本，再通过CLIP编码器得到嵌入向量，存入缓存
- 训练/推理细节：
  - 训练阶段：视觉主干和CAP联合训练，语言分支（CLIP文本编码器）不参与反向传播（仅提取固定语义嵌入），总损失优化视觉主干和CAP参数
  - 推理阶段：完全丢弃语言分支（CLIP和SCM），仅使用视觉主干网络进行预测，模型参数量为18M（与VARC相同）
  - 超参数：对齐损失权重λ=0.1，在0.05~0.15范围内性能稳定，λ=0.2时下降0.5%
  - 训练过程：使用Adam优化器，批大小和学习率未明确，但实验显示约100步内收敛（图7）

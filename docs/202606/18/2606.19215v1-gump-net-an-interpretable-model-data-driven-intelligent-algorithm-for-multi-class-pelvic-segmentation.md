## 摘要
骨盆分割是骨盆骨折精确智能诊疗及手术规划导航中最重要且基础的研究问题之一。通过将改进的测地活动轮廓模型与深度神经网络相结合，我们提出了GUMP-Net——一种用于多类别骨盆分割的可解释模型数据驱动智能算法，其中设计了三个网络模块共同构成整体分割框架：用于自动水平集初始化的目标检测模块、用于学习解剖感知边缘检测函数的边缘检测器模块，以及用于深度水平集演化的迭代模块。利用水平集表示和深度学习的优势，与最先进方法相比，GUMP-Net在分割性能上表现出更高的准确性、鲁棒性和一致性，尤其是在小训练数据情况下。在骨盆数据集上的大量实验证明了所提算法的合理性和有效性。扩展到踝关节数据集的进一步实验表明，该方法可适用于其他解剖结构。所提算法不仅为复杂骨折复位提供了高效分割方法，也为理解深度学习分割提供了可解释的几何视角。

## Abstract
Pelvic segmentation is one of the most important and fundamental research problems in precise and intelligent diagnosis and treatment, as well as surgical planning and navigation for pelvic fractures. By combining an improved geodesic active contour model with deep neural networks, we propose GUMP-Net, an interpretable model-data-driven intelligent algorithm for multi-class pelvic segmentation, in which three network modules are designed to constitute the overall segmentation framework together: the object detection module for automatic level set initialization, the edge detector module for learning an anatomy-aware edge detector function and the iteration module for deep level set evolution. Leveraging the advantages of level set representation and deep learning, GUMP-Net shows more accurate, robust and consistent segmentation performance, especially in small training data situation, compared to the state-of-the-art methods. Extensive experiments on pelvic datasets demonstrate the rationality and effectiveness of the proposed algorithm. Further experiments extended to ankle dataset indicate broader applications to other anatomies. The proposed algorithm not only provides an efficient segmentation method for complex fracture reduction, but also gives an interpretable geometric perspective for understanding deep learning segmentation.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将迭代式的 GAC 模型展开（algorithm unrolling）为可训练的神经网络模块，使网络学习水平集演化过程，同时保留该过程的几何意义。
- **三大模块**：
    1. **目标检测模块（ODM）**：使用预训练的 YOLOv8s 自动检测每个解剖结构（左髋、右髋、骶骨）的边界框，并据此构建初始水平集函数（LSF，即符号距离函数）。训练时采用“边界框随机平移”技巧（平移幅度 ε=10 像素），以降低对检测精度的依赖并增强鲁棒性。
    2. **边缘检测器模块（EDM）**：基于改进的 FI-GAC 边缘检测函数公式，设计可学习的边缘检测函数（EDF）。具体地，通过一个注意力 U-Net（CNN<sub>θ0</sub>）从拼接图像 `I = (I, |∇I|)` 中预测像素级阈值 `r1(x), r2(x)`，然后通过 `p = Sigmoid(-ReLU(I + r))` 和 `g = p1 + γp2` 得到最终的 EDF。该模块融合了正交知识（CT 值范围），能自动抑制软组织响应、突出骨骼特征。
    3. **迭代模块（IM）**：由 N=3 个 CNN 迭代块组成，每个块使用注意力门控（AG）融合前一 LSF 和 EDF，再通过一个小型 U-Net（CNN<sub>θn</sub>）预测残差，更新 LSF：`ϕn = ϕn-1 + CNN(AG(ϕn-1, g))`。最终 LSF 的零水平集即为分割边界。
- **损失函数**：组合二元交叉熵损失、Dice 损失和平均 LSF 损失，并按解剖结构加权（骶骨权重 0.5，左右髋各 0.25）得到解剖加权总损失（AWL）。
- **训练流程**：端到端训练，Adam 优化器，初始学习率 1e-4，150 epochs，batch size 8。

- **性能优越**：GUMP-Net 在所有三个数据集上均取得最佳或次佳的 Dice（平均 97-99%）、Jaccard、HD 和 ASSD，尤其在困难的骶骨分割上提升显著（Dice 97.64% vs 第二 95.64%）。

- **可解释性**：EDM 输出的 EDF 能清晰突出骨骼边缘、抑制软组织；迭代模块的轮廓演化过程可通过训练 epochs 可视化，物理意义明确。
- **初始化灵活**：支持从 tight 或 loose 边界框启动，既可利用自动检测，也可接受人工校正，适应不同临床场景。

## 7. 优点

- **可解释性与几何直观**：三大模块分别对应经典 GAC 的初始化、边缘检测和演化，每个组件有明确物理含义，可提供分割过程的透明性，满足临床对可解释 AI 的需求。
- **模型数据双驱动**：将数学先验（GAC 能量、改进 EDF）嵌入深度学习结构，既保留可解释性又发挥数据驱动优势，特别适合医学图像小样本场景。
- **训练技巧创新**：“Bounding Box Random Shift”增强了网络对初始轮廓偏移的鲁棒性，无需依赖精确检测。
- **泛化能力验证**：在踝关节数据集上同样取得优异表现（胫骨 Dice 99.08%，腓骨 98.31%），表明方法可推广至其他解剖结构。

## 8. 不足与局限

- **计算开销**：训练过程中需逐图计算符号距离函数（SDF），增加了计算负担；推理时虽可避免，但训练效率受影响。

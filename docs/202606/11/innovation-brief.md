### 1. Experience Makes Skillful: Enabling Generalizable Medical Agent Reasoning via Self-Evolving Skill Memory
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.09365v2
- 方法流程：
  - 输入：当前状态st和记忆库Mt；输出：动作at。
  - 阶段1（读）：根据临床类别路由，计算语义相似度并结合效用分数进行价值感知检索，选出相关技能子集mt。
  - 阶段2（执行）：LLM基于st和mt生成推理决策、工具调用或最终响应at。
  - 阶段3（反馈）：环境返回奖励rt。
  - 阶段4（写）：轨迹被缓存，经门控过滤（排除基础设施错误、机械重复、琐碎成功）后，由两遍蒸馏引擎生成结构化技能（新创建或修补）。
  - 阶段5（评估）：计算轨迹奖励R、分类EMA基线B，通过优势估计R-B更新技能效用：Adv>0增加效用，Adv<0减少，接近0不变。
  - 阶段6（治理）：定期执行合并冗余技能、将成熟技能归档、移除低质量或有害条目，维护仓库健康。
- 关键模块/机制：
  - 技能蒸馏引擎（Two-Pass Distillation Engine）：将轨迹转换为结构化技能；第一遍分析：从轨迹中提取可复用模式（如推理步骤、工具使用序列），生成技能草案。第二遍变异：对已有技能决定创建（CREATE）、修补（PATCH）或不操作（NONE），经新颖性门和质量门检查后写入仓库。
  - 效用评估模块（Utility Assessment）：基于环境反馈估计技能的历史贡献；收集轨迹奖励R、类别EMA基线B和采纳事件E，计算优势Adv=R-B。Adv>0时增加技能效用，Adv<0时减少，Adv≈0时不变。效用值用于检索排序和治理决策。
  - 价值感知检索（Value-Aware Retrieval）：选择当前状态最相关的技能；首先根据临床类别（如鉴别诊断、治疗规划）路由到子分支，然后计算语义相似度，并加权效用分数，选择Top-K技能作为上下文。
  - 多分支仓库（Multi-Branch Repository）：组织和管理技能；包含通用分支、任务特定分支和操作级分支。每个技能存储为三元组（key, content, utility），支持快速检索和高效维护。
  - 仓库治理（Repo Governance）：维护仓库质量，防止冗余和有害内容积累；定期执行：合并语义相似且效用相近的技能；将高成熟度技能移至归档区；删除效用低或产生负面反馈的技能。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式，但目标函数可推导为：最大化期望累积奖励 J = E[Σ γ^t r_t]，其中记忆库的进化U不更新参数。
  - 效用更新基于优势估计：Adv_t = R_t - B_category，其中B_category是类别的指数移动平均基线。
- 算法细节：
  - 读阶段：类别路由 → 语义检索（如余弦相似度） → 根据效用加权 → 取Top-K技能。
  - 写阶段：轨迹缓存 → 门控过滤 → 分析遍提取模式 → 变异遍决定操作（CREATE/PATCH/NONE） → 通过新颖性门（与现有技能差异）和质量门（轨迹成功率） → 写入仓库。
  - 评估阶段：收集轨迹中每一步的奖励，累计或平均得到R；对每个类别维护EMA基线B；对每个被采纳的技能，统计其被采纳事件的Adv贡献并更新效用。
  - 治理阶段：周期性扫描仓库，合并相似技能（语义阈值+效用接近），将效用长期高且采纳次数多的技能标记为成熟并移至归档（仍可检索但不参与合并/降级），删除效用低于阈值或与有害结果相关的技能。
  - 在线学习时，每条轨迹结束后立即触发写和评估；离线学习时，批处理历史轨迹。
- 训练/推理细节：
  - 训练（进化）过程：不更新LLM参数，仅更新技能记忆库。采用在线方式，每次环境交互后更新；也可离线使用历史轨迹进行批处理进化。
  - 推理过程：标准agent循环，但每步前执行价值感知检索从记忆库获取技能，然后LLM根据状态和技能生成动作。
  - 整个框架是模型无关的，可即插即用于任何LLM backbone。
  - 无监督训练信号：环境反馈（如任务完成、子目标达成、专家评判）作为奖励，无需人工标注。

### 2. OpenMedReason: Scientific Reasoning Supervision for Medical Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.12169v1
- 方法流程：
  - 1. 语料构建：从生物医学科学文章中提取图像-问题-答案对，并利用文章中的图注、正文推理链生成结构化的推理轨迹（<think>...<answer>...）。
  - 2. SFT阶段：在混合医学VQA数据集（包括OpenMedReason和公开数据集）上使用LoRA微调Qwen2.5-VL-7B，冻结视觉塔，学习基本的图像理解、医学知识和推理链生成。
  - 3. GRPO强化对齐阶段：从SFT检查点出发，使用GRPO算法在少量持出数据集上训练，奖励函数结合格式奖励和答案正确性奖励，进一步优化推理轨迹的完整性和准确性。
- 关键模块/机制：
  - 推理轨迹标注模块：从科学文章自动提取推理链，为每个图像-问题-答案对生成高保真的链式思考过程；利用图文对应关系和文章行文逻辑，提取相关的临床证据和推理步骤，形成结构化的<think>...</think>块，覆盖感知、医学知识和推理三个能力轴。
  - 能力分解评估模块（OpenMedReason-Bench）：细粒度评估模型在感知、医学知识和推理三个独立能力轴上的表现；对每个基准实例，手工标注三个轴上的参考声称集合，评估模型生成的推理轨迹中每个轴的声称出现率（Presence）、准确率（Correctness）和得分（Presence×Correctness），最终计算推理轨迹总分（三个轴得分的平均值）。
  - GRPO训练模块（基于组相对策略优化）：通过强化学习进一步优化模型生成的推理轨迹，使其更符合期望格式和答案正确性；使用TRL的GRPO trainer，对每个提示生成多个完整轨迹，奖励包括格式奖励（正确使用<think>和<answer>标签）和答案正确性奖励（精确匹配标签）。设置KL系数β=0.04防止偏离SFT先验，非对称信任区间（epsilon=0.20, epsilon_high=0.28）抑制低概率token放大。
- 公式/目标函数/指标定义：
  - 每个能力轴的得分：Score = Presence × Correctness，其中Presence是候选轨迹中提到的参考声称比例，Correctness是提到声称中正确的比例。
  - 推理轨迹得分：Trace_Score = mean(Score_perception, Score_knowledge, Score_rationale)。
  - GRPO奖励函数：R_total = R_format + R_correctness，R_format基于标签结构给予±1和-2惩罚，R_correctness为+2（精确匹配答案标签）或0。
- 算法细节：
  - LoRA微调：对Qwen2.5-VL-7B的语言层（attention和MLP）采用秩r=128、缩放α=256、dropout=0的LoRA，视觉塔冻结。
  - 优化器：AdamW，学习率1e-4，权重衰减0.01，线性预热前5%步数，训练3个epoch，有效批次大小64，最大序列长度8192。
  - GRPO超参数：每设备批次大小1，梯度累积8，每提示生成8个轨迹，最大提示长度3072，最大完成长度2048，学习率1e-6，权重衰减0.1，预热比例0.1，梯度裁剪0.5，KL系数β=0.04，epsilon=0.20，epsilon_high=0.28。
  - 数据划分：SFT使用193,270个手动构建实例和公开数据，总计446,399；GRPO使用5120个持出实例（其中OpenMedReason 3000，其余来自PMC-VQA等）。
- 训练/推理细节：
  - 训练硬件：2张NVIDIA H200 GPU，SFT约24小时，GRPO约20小时。
  - 训练精度：bfloat16，使用accelerate多GPU。
  - 推理时模型生成<think>...<answer>...格式的轨迹，用于评估和比较。
  - Pass@k评估：对每个问题采样k个回答，计算至少一个正确回答的概率，用于衡量推理可靠性。

### 3. Anatomically Conditioned Recurrent Refinement for Topology-Aware Circle of Willis Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.12319v1
- 方法流程：
  - 初始化阶段 (t=0)：输入MRA容积X→静态编码器提取多尺度特征h_stat→直接传入解码器生成初始粗分割Ŷ_0。
  - 循环细化阶段 (t=1..T)：输入上一轮概率图P_{t-1}=softmax(Ŷ_{t-1})→动态编码器提取特征h_dyn→加入时间嵌入τ→与缓存的h_stat通过非对称融合得到Z_t→共享解码器输出细化分割Ŷ_t。
  - 最终输出：Ŷ_T作为最终分割结果。
- 关键模块/机制：
  - 静态解剖编码器 (Static Stream)：提取输入MRA的固定解剖特征，仅计算一次并缓存。；基于nnU-Net ResEnc M，由多个残差块组成，每个块含两个3×3×3卷积+实例归一化+Leaky ReLU，带跳跃连接。输出多尺度特征图h_stat^{(l)}，l表示分辨率层级。
  - 动态细化编码器 (Dynamic Stream)：迭代处理前一时刻的概率图，轻量设计降低计算负担。；通道缩减因子γ=4（base width=8 vs 32）。输入为softmax概率图P_{t-1}∈[0,1]。时间嵌入τ=t/T通过小MLP投影后与特征图元素相加，在第一个残差块之后注入。
  - 非对称特征融合 (Asymmetric Feature Fusion, AF)：将动态特征投影到静态特征空间后相加，使解码器融合解剖和动态信息。；对于每个分辨率层级l，计算Z_t^{(l)} = h_stat^{(l)} + F_φ(h_dyn,t^{(l)})，其中F_φ是1×1×1卷积+实例归一化+Leaky ReLU。
  - 共享解码器 (Decoder)：从融合特征逐步恢复空间分辨率，输出分割logits。；采用三线性上采样+卷积，与对应融合特征拼接。在三个最高分辨率输出处应用深度监督，计算辅助损失。
  - 动态课程学习 (Dynamic Curriculum Learning)：按时间步、尺度、训练阶段渐进调整损失权重和拓扑惩罚强度，稳定训练。；包含：1) 时间权重ω_temp(t)∝2^t；2) 空间权重ω_spat(s)∝2^{-s}；3) 损失策略A/B中clDice惩罚λ_cl(t)随t增大；4) 三阶段训练：静态预训练(0-20% epochs)→warm-up细化(20-40%, T=1)→全循环(40-100%, T=2)。
- 公式/目标函数/指标定义：
  - 递归关系：Ŷ_t = F(X, Ŷ_{t-1}, θ)，初始Ŷ_0=0。
  - 非对称融合：Z_t^{(l)} = h_stat^{(l)} + F_φ(h_dyn,t^{(l)})。
  - 总损失：L_total = Σ_{t=0}^{T} ω_temp(t) · L_hybrid(Ŷ_t, Y)。
  - 策略A：L_A^{(t)} = L_Dice + L_CE + λ_cl(t) L_clDice，其中λ_cl(0)=0, λ_cl(1)=0.2, λ_cl(2)=0.5。
  - 策略B：L_B^{(t)} = (1 - TI^{(t)}) + L_CE + λ_cl(t) L_clDice，其中Tversky指数TI^{(t)}的参数(α,β)按t变化：(0.3,0.7) → (0.4,0.6) → (0.5,0.5)。
  - 深度监督损失权重：ω_spat(s)∝2^{-s}，s=0,1,2对应三个最高分辨率。
- 算法细节：
  - 推理时，首先运行静态编码器一次缓存特征；然后循环T=2次（实验中），每次动态流处理前一概率图并融合。
  - 训练时，损失计算包括所有时间步，但深度监督的拓扑损失仅在全分辨率输出上计算。
  - 梯度累积：微批大小1×2步，模拟批次大小2，增加epoch迭代次数至500以保持有效更新次数。
  - 优化器：SGD Nesterov动量μ=0.99，权重衰减3e-5，多项式学习率衰减，初始η=0.01。
  - 数据预处理：按nnU-Net自动计算重采样间距、z-score归一化，裁剪ROI区域，patch大小64×192×160。
- 训练/推理细节：
  - 三阶段训练：前20% epochs只训练静态流（t=0）；20-40% epochs引入T=1的细化；40-100% epochs使用完整T=2循环。
  - 推理时总步数T=2，时间嵌入τ=t/T为0.5和1.0。
  - 使用TopCoW数据集125例（100训练，25测试），ROI裁剪。
  - 训练epochs=1000，但梯度累积使每个epoch的迭代次数为500。
  - 所有实验在单张NVIDIA RTX 5080 GPU上进行。

### 4. Stress-testing medical large language models reveals latent safety pathology beyond benchmark accuracy
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.07929v1
- 方法流程：
  - 构建240个临床案例，每个案例生成基线版本和六种叙事扰动版本（噪音、矛盾、情绪化、时间乱序、人口统计反事实等）
  - 双压力测试：对每个模型，分别输入基线版本和一种压力版本，零样本生成输出
  - 自动评分：使用经临床医生验证的LLM法官对输出进行评分，提取信息召回、纯度、简洁性等
  - 计算指标：代谢指数(MI)=f(信息召回,提取纯度,输出简洁性)；扰动翻转率(PFR)=反转正确判断案例数/总案例数；反事实公平指数(CFI)=人口统计反事实下判断一致比例
  - 分类表型：根据MI衰减模式（ΔMI%）将模型分为Type I（噪声免疫/情感脆弱）和Type II（噪声中等/情感增强）
- 关键模块/机制：
  - 双压力测试模块：通过基线-压力性能差异揭示模型在现实临床扰动下的真实能力；每个临床案例在干净结构化文本（基线）和施加特定叙事扰动（如噪音、矛盾）后分别测试，比较输出差异
  - 代谢指数(MI)：联合度量压力下信息召回、提取纯度和输出简洁性，反映信息处理代谢能力；通过LLM法官对模型输出的临床相关信息进行评分，综合计算得出，数值越高表示信息处理能力越强
  - 扰动翻转率(PFR)：量化模型在压力下逆转基线正确判断的比例，衡量逻辑稳定性；对每个扰动探针，统计模型在压力条件下输出与基线正确输出不一致且错误的比例
  - 反事实公平指数(CFI)：衡量模型对不同人口统计特征患者判断的一致性，评估公平性；通过改变临床案例中患者的人口统计特征（如种族、性别），比较模型判断是否一致，取一致的比例
  - LLM法官评分系统：自动评分工具，经临床医生校准，用于大规模评估模型输出质量；使用经过人类临床医生双盲验证的LLM（与评估模型不同）按照预定义rubric进行评分，与临床医生共识的加权kappa达0.78-0.86
- 公式/目标函数/指标定义：
  - 代谢指数(MI)：联合量化信息召回、提取纯度和输出简洁性，具体加权公式未在原文明确给出
  - 扰动翻转率(PFR)：反转正确判断案例数 / 总案例数（针对特定扰动）
  - 反事实公平指数(CFI)：人口统计反事实下判断一致的案例比例
- 算法细节：
  - 叙事扰动生成：六种人工设计的扰动探针（P1:冗余噪音，P2:临床优先级混淆，P3:患者自述与客观证据矛盾，P4:情绪化语言，P5:时间顺序打乱，CFI:人口统计反事实替换）
  - 双压力测试：每个模型对每个临床案例分别处理基线版本和一种压力版本，输出被LLM法官自动评分
  - 零样本推理：温度0，最大输出长度1024 tokens，无few-shot示例以排除上下文学习影响
  - 人类验证：两位高级临床医生双盲评分48个样本（占20%），检验LLM法官评分一致性
- 训练/推理细节：
  - 推理配置：温度0，max_tokens=1024，zero-shot，使用各模型API（2025.12-2026.01）
  - Qwen3-8B-SFT医学微调：在HuatuoGPT-Data（40%）、MedQA（40%）、MedDialog（20%）上监督微调
  - 所有模型均未提供few-shot示例，以隔离内在临床推理能力

### 5. LongMoE: Longitudinal Multimodal Learning via Trajectory-Aware Mixture-of-Experts
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.09907v1
- 方法流程：
  - 阶段1: 模态特定嵌入 - 对每个模态（MRI、临床评分、生物标志物、遗传数据）使用专用编码器（Conv3D+MLP或MLP）提取d维嵌入，并对未观测模态置零；同时编码时间戳为学习嵌入
  - 阶段2: 模态插补与分词 - 对缺失模态：若有历史观测则复制最近嵌入，否则通过共享MLP基于当前观测模态均值进行上下文插补；然后对完整嵌入矩阵应用多头自注意力得到模态嵌入，同时根据连续时间多频正弦编码生成viscode编码，两者逐元素相加得到访问级token
  - 阶段3: 轨迹感知纵向建模 - 将访问级token序列输入轨迹感知Transformer编码器，建模患者疾病进展的时间依赖模式
  - 阶段4: 上下文感知MoE路由 - 利用上下文条件稀疏MoE层，根据当前观测模态组合和时间上下文动态选择专家，进行患者特定的融合和分类
- 关键模块/机制：
  - 上下文感知插补模块：处理模态缺失，为当前访问补全缺失模态的嵌入；对于缺失模态l：如果前一访问存在该模态观测（t>1且O_{t-1,l}=1），则直接复制最近嵌入；否则，通过一个共享MLP（MLP_imp）对所有当前观测模态的嵌入进行平均池化后预测缺失嵌入
  - 注意力分词模块（含viscode编码）：生成统一的访问级token，融合模态间依赖和时间位置信息；首先对插补后的L个模态嵌入进行多头自注意力（公式2），得到模态依赖的聚合表示；同时，对绝对时间戳τ_t进行多频正弦编码（F个频段，频率ω_k=2^{k-1}），经MLP投影为viscode向量（公式3）；最后两者逐元素相加得到访问级token z_t
  - 轨迹感知Transformer编码器：建模患者纵向疾病进展的动态模式；将访问级token序列输入Transformer编码器，利用自注意力捕获跨访问的长程依赖，同时保留不规则时间间隔信息（由于viscode编码已注入时间信息）
  - 上下文条件稀疏MoE路由：根据当前观测模态组合和时间上下文动态选择专家进行融合和分类；采用稀疏MoE架构，路由器基于轨迹感知编码器的输出和当前观测掩码，学习选择最相关的专家子集，实现患者特定的模态融合，避免全部专家激活的计算开销
- 公式/目标函数/指标定义：
  - 插补公式 (1): E_imp_t[l,:] = e_t^{(l)} if O_{t,l}=1 else \hat{e}_t^{(l)}
  - 多头注意力 (2): head_h = Softmax( (Q W_Q^h)(K W_K^h)^T / sqrt(d/H) ) (V W_V^h)
  - viscode编码 (3): v_t = MLP_viscode([sin(ω_1 τ_t), cos(ω_1 τ_t), ..., sin(ω_F τ_t), cos(ω_F τ_t)])
  - 最终token: z_t = \bar{A}_t + v_t (元素相加)
- 算法细节：
  - 模态嵌入: MRI经3D Conv提取特征后经MLP投影到d维；临床、生物、遗传数据各用专用MLP
  - 插补策略: 条件复制上次观测或基于当前可用模态均值预测（MLP_imp）
  - viscode设计: 使用F个几何间隔频率（ω_k=2^{k-1}）的正弦/余弦对，保证在整数月内注入性（因2π无理数且频率不可公度）
  - 多头注意力: 标准缩放点积注意力，H个头，每个头d/H维
  - 轨迹编码: Transformer编码器，可堆叠多层，处理变长序列
  - MoE路由: 稀疏门控，根据上下文（轨迹编码输出+模态掩码）选择top-k专家，未激活专家输出置零
- 训练/推理细节：
  - 端到端联合训练所有编码器、插补网络、注意力分词、Transformer和MoE路由
  - 损失函数未在摘要中明确，但通常为分类交叉熵（AD任务三分类）
  - 训练时处理任意模态缺失模式，无需预定义完整模态子集
  - 推理时对每个访问动态插补缺失模态，并利用全历史轨迹进行预测

### 7. FSS-Net: Frequency-Spatial Synergy Network with Wavelet Attention for Carotid Artery Ultrasound Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.10378v1
- 方法流程：
  - 输入256×256超声图像，经4个级联的小波编码器阶段：每个阶段包含ConvBlock（两个5×5卷积+BN+ReLU）、CSWA模块、下采样，输出16×16×256特征图。
  - 编码特征送入WEB：通道扩至1024，经DWT分解为4个8×8×1024子带，对每个子带应用空间注意力，再经IWT重建，1×1卷积压缩至256通道。
  - 解码阶段：每步先转置卷积上采样，然后通过LAEF模块融合上采样特征与对应编码器特征（经Laplacian边缘提取及自适应权重融合），最后ConvBlock整合，输出16通道特征图。
  - 1×1卷积压缩至单通道，经Sigmoid生成256×256分割概率图。
- 关键模块/机制：
  - CSWA (Channel-Spatial-Wavelet Attention)：在编码阶段抑制噪声并增强语义特征；输入特征经Daubechies-4 DWT分解为LL、LH、HL、HH子带。对LL子带：先经GAP和GMP通过共享MLP生成通道注意力权重，加权后得到F_att；再对LL递归进行3级小波卷积（每级只分解LL），各分支输出求和、BN、Channel Shuffle，经1×1卷积和Sigmoid生成空间注意力图，与F_att逐元素相乘并残差相加得到LL_enhanced。最后将LL_enhanced与LH、HL、HH求和经IWT重建输出。
  - WEB (Wavelet-Enhanced Bottleneck)：在瓶颈段捕获长距离全局依赖；输入16×16×256特征，先1×1卷积扩至1024通道；经DWT分解为4个8×8×1024子带；对每个子带分别应用空间注意力（可学习权重突出重要频率分量）；再经IWT重建，1×1卷积压缩回256通道。
  - LAEF (Laplacian-Guided Adaptive Edge Fusion)：在解码阶段补偿高频边界信息；对编码器特征F_encoder：先用3×3 Laplacian核提取边缘，经BN+ReLU+1×1卷积得到F_edge；将F_encoder与F_edge逐元素相加得F_fused；对F_fused进行GAP，经两个全连接层（中间维度C/2）和Sigmoid生成通道权重b∈[0,1]；最终输出F_out = F_encoder ∙ b + F_edge ∙ (1-b)。
- 公式/目标函数/指标定义：
  - 离散小波变换(DWT): W_{j,k} = ∬ f(x,y) φ_{j,k}(x,y) dxdy
  - 逆小波变换(IDWT): f(x,y) = ∑_{j,k} W_{j,k} φ_{j,k}(x,y)
  - 共享MLP: MLP(x) = Conv1×1(ReLU(Conv1×1(x, C→C/r)), C/r→C)
  - 通道注意力加权: F1 = F ⊙ σ(MLP(AvgPool(F)) + MLP(MaxPool(F)))
  - 多尺度通道-小波空间注意力: H(F) = σ(W_conv(∑_{i=1}^n BN(W_T_n(F1))) )
  - 空间注意力加权: F2 = F + F ⊙ H'(F)，其中H'为沿通道复制
- 算法细节：
  - CSWA算法（Algorithm 1）: 输入F，经DWT分解；对LL子带执行通道注意力得到F_att；对LL递归进行3级小波卷积，各级输出求和、BN、Channel Shuffle；通过1×1卷积+Sigmoid生成空间注意力图；加权融合得到LL_enhanced；与其余子带经IWT重建输出。
  - LAEF边缘融合：先Laplacian提取边缘，BN+ReLU+Conv1×1得到F_edge；与F_encoder逐元素相加；GAP后经两个全连接层（中间C/2）和Sigmoid生成b；按b和1-b加权求和输出。
  - WEB频域增强：输入特征扩通道后DWT分解为四个子带，对每个子带独立应用空间注意力，再IWT重建，最后1×1卷积恢复通道数。
- 训练/推理细节：
  - 框架：PyTorch，GPU：NVIDIA RTX 4090
  - 图像预处理：resize至256×256，实例级Z-score归一化（减均值除标准差）
  - 训练策略：5折交叉验证（固定随机种子），每折训练50 epoch，batch size=16，优化器AdamW（初始lr=0.001）
  - 模型选择：每折取验证集Dice最高的模型，最终结果为5折平均±标准差
  - 数据集：颈动脉超声1,100张（11名受试者），乳腺癌超声647张（仅病变图像）

### 13. When More Documents Hurt RAG: Mitigating Vector Search Dilution with Domain-Scoped, Model-Agnostic Retrieval
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.11350v1
- 方法流程：
  - 输入：用户查询q；输出：最终答案。步骤1：混合路由——先对查询使用正则表达式匹配预定义域，若失败则回退到LLM零样本分类，输出预测的领域标签k*。
  - 步骤2：领域限定检索——根据k*将检索范围限制在对应的文档系列子集C_k*上，使用HNSW或BM25索引执行ANN搜索，返回top-k块。
  - 步骤3：多智能体编排（可选）——若使用MASDR-RAG，编排器通过函数调用分发到K个领域智能体，每个智能体独立执行步骤2，并在多轮（≤5轮）中合并结果；若使用HYBRID-ROUTED，跳过此步骤，直接进行步骤4。
  - 步骤4：合成——将查询与检索到的块拼接，送入LLM（Qwen/Llama/Gemini等）生成最终答案。
- 关键模块/机制：
  - Hybrid Router (Regex→LLM)：查询路由，决定目标领域；先使用基于domains关键词的正则模式匹配快速分类；若未匹配则调用LLM（如Qwen-2.5-7B）执行零样本分类，输出目标领域ID。确保低延迟和高覆盖率。
  - Domain-Scoped Agent (Scope-Bound Tool)：在限定领域内执行检索；每个智能体维护一个Neo4j图查询过滤器（如MATCH (d:Document) WHERE d.series IN [...])，仅返回匹配领域文档的块。ANN搜索在此子集上进行，搜索空间减少约90%。
  - Orchestrator (Function Calling)：多智能体编排，协调多轮检索；通过LLM函数调用机制，允许模型在最多5轮内按需调用任意领域智能体工具。每次调用返回top-k块，最终由合成器统一处理。HYBRID-ROUTED不使用此模块。
  - Synthesizer LLM：基于检索结果生成最终答案；将用户查询与所有检索到的块拼接为一个提示，使用LLM（Qwen-7B/Llama-8B/Gemini等）生成答案。在MASDR-RAG中，拼接来自多轮调用的块；在HYBRID-ROUTED中仅拼接一次检索结果。
- 公式/目标函数/指标定义：
  - 稀释因子 δ(q, k*) = 1 - P_global(q) / P_scoped(q)，其中P_global(q)为全局检索top-m中目标类别块的比例，P_scoped(q)为仅检索目标类别时的比例（≈1）。δ=0无稀释，δ→1严重稀释。
- 算法细节：
  - ANN检索使用HNSW索引（或FAISS），结合BM25稀疏检索形成混合检索（dense+sparse）
  - 元数据过滤在检索时应用：在Neo4j查询中加入文档系列（document_series）约束，确保ANN搜索仅索引对应领域子图
  - 多智能体编排：LLM通过function calling决议调用agent，每个agent返回其top-k块；重复至多5次或显式终止
  - HYBRID-ROUTED：路由器输出领域后直接调用该领域agent进行一次检索，然后合成
- 训练/推理细节：
  - 所有组件均为预训练模型和规则，无额外训练；混合路由器中的LLM使用零样本分类，不更新参数
  - 推理时，MASDR-RAG每查询最多5次LLM调用（路由器+最多4次agent调用+1次合成）；HYBRID-ROUTED最多2次LLM调用（路由器+合成）
  - 评估使用95% bootstrap置信区间和置换检验（α=0.05）

### 16. TEVI: Text-Conditioned Editing of Visual Representations via Sparse Autoencoders for Improved Vision-Language Alignment
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.07451v1
- 方法流程：
  - 输入：CLIP图像编码器输出的原始图像嵌入 v（d维）
  - 步骤1：使用稀疏自编码器（SAE）将 v 编码为稀疏特征向量 f ∈ R^{k} (k>d，但大部分为零)，即 f = SAE_encode(v)
  - 步骤2：同时输入文本嵌入 t（来自CLIP文本编码器）到掩码模块，生成二进制或连续掩码 m ∈ [0,1]^k，即 m = MaskModule(f, t) 或直接由t生成
  - 步骤3：对稀疏特征应用掩码：f' = f ⊙ m（逐元素相乘）
  - 步骤4：使用SAE解码器将 f' 重建为编辑后的图像嵌入 v' = SAE_decode(f')
  - 输出：编辑后的图像嵌入 v'，用于后续检索等任务
- 关键模块/机制：
  - 稀疏自编码器（SAE）：将稠密图像嵌入分解为可解释的稀疏特征，每个特征可能对应某个语义概念；SAE由一个编码器（线性层+ReLU）和一个解码器（线性层）组成，通过L1稀疏正则化和重建损失进行训练。编码器将输入图像嵌入映射到高维稀疏表示（例如扩展因子8），大部分神经元输出接近0；解码器将稀疏表示重建为原始嵌入。
  - 文本条件掩码模块（Text-Conditioned Masking Module）：根据给定的文本嵌入，决定哪些稀疏特征应该被保留（与描述相关），哪些应该被丢弃；掩码模块通常为一个轻量级神经网络（如MLP），输入为文本嵌入和/或稀疏特征，输出与稀疏特征同维度的掩码向量，每个元素在[0,1]之间。训练时使用对比损失（如InfoNCE）或重建损失，使得编辑后的嵌入与正文本相似度高，与负文本相似度低。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - SAE训练：使用均方误差重建损失 + L1稀疏正则化（λ * ||f||_1），优化SAE编码器与解码器
  - 掩码模块训练：冻结SAE参数，使用对比损失（如InfoNCE）优化掩码模块，使编辑后的图像嵌入与对应文本嵌入相似度高，与不相关文本嵌入相似度低。在训练时同时使用正负文本对作为条件，提升判别能力
  - 推理：对于每对(图像, 文本)，将图像嵌入通过SAE编码为稀疏特征，掩码模块根据文本嵌入生成掩码，应用后解码得到编辑嵌入。然后使用编辑嵌入进行检索排序
  - 由于需要对每个图像-文本对单独编辑，推理开销通常为O(N*M)，但作者指出通过先粗检索再rerank可降低开销
- 训练/推理细节：
  - 训练数据：使用CC12M数据集训练CLIP模型（ViT-B/16、ViT-L/14、SigLIP ViT-B/16），然后使用同一数据集或子集训练SAE和掩码模块
  - SAE训练：超参数搜索包括扩展因子（如8、16）和学习率，选择使重建准确率和分类准确率最优的配置
  - 掩码模块训练：使用CC3M验证集进行早停和超参数选择（如学习率），确保泛化
  - 推理额外开销：约2.7% FLOPs增加（对于1000图像-文本对）
  - 与SmartCLIP对比时，训练设置类似

### 17. MM-Matryoshka: Towards Budget-Elastic Visual Document Retrieval via a 2D Multimodal Matryoshka Training Framework
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.07654v1
- 方法流程：
  - 输入：配对的文本查询和渲染文档页面{(q_i, p_i)}，批量大小B。
  - 编码：对于选定的层ℓ，使用截断的VLM编码器f_≤ℓ得到查询隐藏状态H_q^ℓ∈R^{T_q×h}和页面隐藏状态H_p^ℓ∈R^{T_p×h}。
  - 投影与归一化：应用层特定的投影头ψ_ℓ并逐token L2归一化，得到检索向量Q^ℓ∈R^{T_q×D}和P^ℓ∈R^{T_p×D}。
  - 前缀截断：对于预算维度d，对每个token向量应用τ_d(x)=x_{1:d}/||x_{1:d}||_2，得到Q_ℓ^{(d)}和P_ℓ^{(d)}。
  - 评分：使用MaxSim操作计算查询与页面的相关性得分s_{ℓ,d}(q,p)=1/T_q Σ_i max_j ⟨Q_{ℓ,i}^{(d)}, P_{ℓ,j}^{(d)}⟩。
  - 输出：给定预算(ℓ,d)，输出该预算下的检索得分矩阵S_ℓ^{(d)}∈R^{B×B}。
- 关键模块/机制：
  - 维度级MRL损失 (Dimension-Level MRL)：训练最终层在不同前缀维度下的检索能力；对一组维度D，计算每个前缀维度d下的最终层得分矩阵S_L^{(d)}，应用交叉熵损失：L_prefix = Σ_{d∈D} α_d L_CE(S_L^{(d)}, y)，其中y是标签向量（y_i=i表示正样本对）。
  - 层级MRL损失 (Layer-Level MRL)：使中间层学生层模仿最终层教师层的分数分布，实现深度弹性；选定中间层集合S，对每个(ℓ,d)对，计算最终层得分矩阵S_L^{(d)}和中间层得分矩阵S_ℓ^{(d)}，使用KL散度蒸馏：L_distill(ℓ,d)=KL(softmax(sg(S_L^{(d)})/T_dist) || softmax(S_ℓ^{(d)}/T_dist))，其中sg停止教师梯度，T_dist为蒸馏温度。
  - 联合训练损失：组合两种损失以同时优化维度弹性和深度弹性；总损失L = L_prefix + λ/(|S||D|) Σ_{ℓ∈S} Σ_{d∈D} L_distill(ℓ,d)，λ控制蒸馏强度，归一化平均蒸馏损失。
  - 推理时预算选择：允许多个预算配置共享同一模型；推理时用户指定层ℓ和维度d，编码器截断到层ℓ，投影后取前d维并归一化，执行MaxSim评分。无需单独训练不同预算的模型。
- 公式/目标函数/指标定义：
  - 隐藏状态提取：H_q^ℓ = f_{≤ℓ}(q) ∈ R^{T_q×h}, H_p^ℓ = f_{≤ℓ}(p) ∈ R^{T_p×h}
  - 检索向量：Q^ℓ = norm(ψ_ℓ(H_q^ℓ)) ∈ R^{T_q×D}, P^ℓ = norm(ψ_ℓ(H_p^ℓ)) ∈ R^{T_p×D}
  - 前缀截断：τ_d(x) = x_{1:d} / ||x_{1:d}||_2
  - MaxSim评分：s_{ℓ,d}(q,p) = (1/T_q) Σ_i max_j ⟨Q_{ℓ,i}^{(d)}, P_{ℓ,j}^{(d)}⟩
  - 维度级MRL损失：L_prefix = Σ_{d∈D} α_d L_CE(S_L^{(d)}, y)
  - 层级MRL损失：L_distill(ℓ,d) = KL(softmax(sg(S_L^{(d)})/T_dist) || softmax(S_ℓ^{(d)}/T_dist))
- 算法细节：
  - 训练时，对每个batch，同时计算最终层L和所有中间层ℓ∈S的隐藏状态。
  - 对每个d∈D，对最终层和中间层分别进行前缀截断得到Q_L^{(d)}, P_L^{(d)}和Q_ℓ^{(d)}, P_ℓ^{(d)}。
  - 计算所有2D对(ℓ,d)的MaxSim得分矩阵S_ℓ^{(d)}。
  - 维度级损失：使用最终层得分矩阵S_L^{(d)}和标签y计算交叉熵。
  - 层级蒸馏损失：对每个(ℓ,d)，计算S_ℓ^{(d)}与sg(S_L^{(d)})之间的KL散度（按行softmax后）。
  - 反向传播联合损失，更新所有层参数（包括投影头ψ_ℓ）。
  - 推理时，根据用户指定的(ℓ,d)，仅编码到层ℓ，投影后取前d维归一化，然后与数据库中的页面表示进行MaxSim评分。
- 训练/推理细节：
  - 训练时，维度级MRL损失作用于最终层L，层级MRL损失作用于中间层集合S。
  - 蒸馏使用温度T_dist调整分数分布的平滑度。
  - 联合损失中λ控制蒸馏强度，|S||D|归一化确保各2D对贡献均衡。
  - 推理时，模型仅需一次前向传播到选定层ℓ，然后取前缀d，无需额外操作。
  - 数据库中的页面表示可以预计算并存储在不同预算下（如存储完整D维，推理时截取d维；或存储多个前缀维度以加速）。

## 摘要
医疗智能体系统越来越多地被期望支持交互式临床决策，而不仅仅是静态的问答。在这种场景下，有效的智能体必须能够复用演化病例中的先前经验，然而现有的记忆机制通常保留原始的、冗余、嘈杂且难以管理的历史轨迹。更重要的是，它们很少区分哪些记忆对未来推理真正有用。这限制了它们为长期临床推理积累紧凑且可靠经验的能力。为弥补这一差距，我们提出了SkeMex，一种部署后的自我演化框架，通过基于技能的记忆改进医疗智能体，无需更新模型权重。SkeMex将信息丰富的交互轨迹蒸馏为结构化的技能，这些技能编码可复用的程序性知识，并将它们组织成一个多分支仓库，涵盖通用、任务特定和动作级别的经验。为了确定哪些记忆应该被复用和保留，SkeMex根据环境反馈估计上下文相关的效用，并利用它来指导价值感知的检索和仓库治理。一个闭环的“读-写-评估-治理”生命周期通过写入新技能、更新效用、促进有用记忆和移除有害条目进一步支持持续演化。在多种临床任务上的实验表明，SkeMex在离线和在线设置中均持续优于具有代表性的基于记忆的智能体。它还能在多种模型主干上泛化，并支持可迁移的技能记忆。所有数据和代码将公开发布。

## Abstract
Medical agent systems are increasingly expected to support interactive clinical decision making rather than only static question answering. In such settings, effective agents must reuse prior experience across evolving cases, yet existing memory mechanisms often retain raw historical traces that are redundant, noisy, and difficult to govern. More importantly, they rarely distinguish which memories are truly useful for future reasoning. This limits their ability to accumulate compact and reliable experience for long-horizon clinical reasoning. To close this gap, we propose SkeMex, a post-deployment self-evolution framework that improves medical agents through a skill-based memory without updating model weights. SkeMex distills informative interaction trajectories into structured skills that encode reusable procedural knowledge, and organizes them into a multi-branch repository spanning general, task-specific, and action-level experience. To determine which memories should be reused and retained, SkeMex estimates context-dependent utility from environment feedback and uses it to guide value-aware retrieval and repository governance. A closed-loop ``Read--Write--Assess--Govern" lifecycle further supports continual evolution by writing new skills, updating utilities, promoting useful memories, and removing harmful entries. Experiments across diverse clinical tasks show that SkeMex consistently outperforms representative memory-based agents in both offline and online settings. It also generalizes across model backbones and supports transferable skill memory. All data and code will be released publicly.

## 6. 论文的主要结论与发现

- **离线模式**：SkeMex在DeepSeek-V3.2上平均准确率从ReAct的48.20%提升至56.08%（+7.88），超过最强非SkeMex基线3.84点；在Qwen3.6-Plus上从48.63%提升至59.22%（+10.59）。域外泛化中，SkeMex对比ReAct提升13.78点，而最强对比基线仅提升8.24点。
- **在线模式**：SkeMex在三个epoch中从76.39%提升至78.56%，而最优基线Evolver仅达76.97%，且数个基线出现回退。
- **跨骨干泛化**：在Qwen3.6-Max-Preview、Kimi-2.6、GLM-5.1上，SkeMex均取得所有基准最佳平均分，平均超过ReAct约10点。
- **技能迁移**：由DeepSeek-V3.2积累的技能仓库可直接用于Claude Sonnet-4.6和Qwen3.6-35B-A3B，分别提升10.68和10.52点，表明技能可跨模型迁移。
- **消融结论**：缓冲门控、多分支、效用估值（尤其是基线校正）、生命周期治理（尤其是成熟化和弃用）均是关键组件；缺少任一环节均导致性能显著下降。

## 7. 优点：方法或实验设计上的亮点

- **方法亮点**：
  - **无需参数更新**：通过外部记忆演化而非模型微调，避免了灾难性遗忘和跨域弱迁移问题，增强了可扩展性和适应性。
  - **闭环自演化设计**：读-写-评估-治理形成完整循环，确保记忆库持续优化而非简单堆积。
  - **价值感知检索**：结合语义、效用和记忆强度，且按临床类别条件化，提高了检索的相关性和可靠性。
  - **细粒度技能分支**：通用、任务级、动作级分离，避免不同抽象层级的技能互相干扰。
  - **鲁棒性验证**：大量消融和敏感性分析证明设计选择合理且超参数不敏感。
- **实验亮点**：
  - 覆盖**离线和在线**两种实用场景，评估了记忆的静态复用和动态持续改进能力。
  - 全面的**域内外泛化测试**，包括多个未见过的基准家族，检验了技能的迁移性。
  - **跨骨干泛化和技能迁移实验**，验证了框架的模型无关性和可移植性。
  - **执行成本与交互深度分析**，揭示了技能引导的智能体更细致的推理过程，并量化了性能-效率权衡。

## 8. 不足与局限

- **实验覆盖方面**：
  - 评测基准无法完全模拟真实临床环境的复杂性（如患者历史、机构工作流、决策约束的多样性）。
  - 未覆盖所有主流基础模型，仅测试了DeepSeek、Qwen、Kimi、GLM、Claude等有限集合。
- **性能开销**：
  - SkeMex引入额外推理开销：检索和技能上下文增加提示长度，智能体平均步骤数增加（4.77对ReAct的3.17），平均耗时更长（116秒对54秒）。在延迟敏感场景中可能受限。
  - 部分基线（如GSEM）在域外测试中表现低于ReAct，提示实现适应或参数调优可能不充分。
- **潜在偏差与风险**：
  - 技能蒸馏过程依赖LLM自身对轨迹的分析，可能继承模型偏见或错误模式。
  - 技能良性循环依赖反馈质量；若环境反馈有噪声或错误，可能强化不良行为。
  - 应被视为决策支持和研究工具，而非专业医疗判断的替代品。
- **其他限制**：
  - 训练数据顺序实验仅基于两个基准，结论的普适性有待扩展。
  - 在线实验中，仅测试了三个epoch，更长周期的记忆演化行为未探索。
  - 未涉及多智能体协作场景或更复杂的工具集。

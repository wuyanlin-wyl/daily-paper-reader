## 摘要
Transformer对输入长度的二次复杂度给大语言模型（LLMs）带来了不可持续的计算负担。相比之下，选择性扫描结构化状态空间模型（即Mamba）有效解决了这一计算挑战。本文探索了一种基于查询的跨模态投影器，通过交叉注意力机制根据输入压缩视觉令牌，从而增强Mamba在视觉-语言建模中的效率。这种创新的投影器还消除了在将原始图像特征转换为Mamba LLM输入序列时，需要手动设计二维扫描顺序的需求。跨多种视觉-语言理解基准的实验结果表明，所提出的跨模态投影器增强了基于Mamba的多模态大语言模型，同时提升了性能和吞吐量。

## Abstract
The Transformer's quadratic complexity with input length imposes an unsustainable computational load on large language models (LLMs). In contrast, the Selective Scan Structured State-Space Model, or Mamba, addresses this computational challenge effectively. This paper explores a query-based cross-modal projector designed to bolster Mamba's efficiency for vision-language modeling by compressing visual tokens based on input through the cross-attention mechanism. This innovative projector also removes the need for manually designing the 2D scan order of original image features when converting them into an input sequence for Mamba LLM. Experimental results across various vision-language understanding benchmarks show that the proposed cross-modal projector enhances Mamba-based multimodal LLMs, boosting both performance and throughput.

- **整体含义**：本文旨在设计一种基于查询的跨模态投影器（Querying Mamba），利用交叉注意力机制动态压缩视觉令牌，消除手动设计二维扫描顺序的依赖，提升Mamba多模态大语言模型的性能与吞吐量，从而为高效多模态建模提供新思路。

## 2. 论文提出的方法论

### 核心思想
- 引入一组可学习的查询嵌入（learnable queries），通过交叉注意力与视觉编码器输出的图像特征交互，将二维视觉信息动态投影为一维因果令牌序列，输入到预训练的Mamba大语言模型中。
- 该方法摆脱了先前基于Mamba的视觉编码器（如VL-Mamba、Vision Mamba）需要手动定义扫描顺序（双向扫描、交叉扫描等）的局限。

### 关键技术细节
1. **Q-Mamba投影器架构**：由多个Q-Mamba块堆叠而成，每个块包含：
   - **Mamba层**：作为序列混合器，对查询序列施加因果依赖（单向Mamba），确保与LLM的顺序处理一致。
   - **交叉注意力层**：可学习查询与视觉特征交互，支持局部注意力掩码（图3），使每个查询仅关注相邻的K/Q个键，提升性能。
   - **前馈网络（FFN）**：作为通道混合器。
2. **视觉预处理**：使用预训练的SigLIP ViT（400M参数，输入384×384）提取视觉特征，并附加双向Mamba多模态连接器（来自VL-Mamba）以增强表示。
3. **查询长度灵活性**：支持不同数量的查询（128、256、512、729），实现动态下采样视觉特征序列长度。
4. **训练策略**：采用LLaVA的两阶段训练：
   - **阶段一（对齐）**：冻结LLM，仅训练投影器，使用CC3M过滤后的595K图像-文本对。
   - **阶段二（端到端微调）**：联合微调投影器和LLM，使用LLaVA v1.5混合数据集（655K）、LVIS-Instruct-4V（220K）和LRV-Instruct（400K）。
5. **LLM骨干**：预训练的Mamba LLM（2.8B参数），先经SlimPajama预训练600B tokens，再经UltraChat 200K指令微调和UltraFeedback DPO优化。

### 算法流程（文字描述）
1. 输入图像经SigLIP ViT编码为729个视觉特征。
2. 视觉特征经双向Mamba连接器处理后，送入Q-Mamba投影器。
3. 投影器中的可学习查询通过交叉注意力从视觉特征中提取信息，经Mamba层施加因果顺序，输出压缩后的视觉令牌序列。
4. 该序列与文本单词令牌拼接，输入Mamba LLM生成回复。

## 6. 论文的主要结论与发现

- **性能提升**：本文方法在几乎所有基准上优于Cobra和VL-Mamba，特别是在VQA v2、GQA、TextVQA和MMBench上表现更好。
- **查询长度影响**：增加查询长度通常提高性能，但存在边际效应；过长查询（如729）在VizWiz和POPE上略有下降，可能引入噪声。
- **局部注意力优于全局注意力**：局部注意力掩码显著提升了性能（表2，VQA v2从73.12→75.01，GQA从52.87→58.10）。
- **预训练双向Mamba连接器有益**：使用VL-Mamba预训练权重比从头训练更好（表3）。
- **推理时扫描顺序不敏感**：训练时使用双向扫描，但推理时仅使用前向扫描也能达到甚至略优性能（表4），说明模型对扫描顺序有鲁棒性。
- **吞吐量优势**：Q-Mamba通过动态下采样视觉令牌长度，在保持性能的同时显著降低了训练/推理时间（例如128查询时推理迭代0.095秒，低于Cobra的0.129秒和VL-Mamba的0.152秒）。

## 7. 优点

- **创新性**：首次将可学习查询与Mamba结合用于跨模态投影，消除了手动设计2D扫描顺序的需要，提升了模型灵活性。
- **效率**：通过压缩视觉令牌长度，兼顾性能与吞吐量，在4张A100上即可完成训练。
- **设计合理**：局部注意力掩码、因果Mamba先验等设计充分考虑了Mamba的序列特性，消融实验验证了各模块的有效性。
- **公平对比**：复现基线并统一实验条件，扫描顺序变体全面测试，结论可靠。

## 8. 不足与局限

- **训练数据量不足**：仅使用LLaVA-LLVIS（对齐）和LLaVA-1.5（微调）等有限数据集，且只训练1个epoch（其他模型通常2个epoch），可能限制泛化能力。
- **Mamba的“遗忘”问题**：Mamba的隐藏状态依赖顺序输入，类似RNN，可能在长序列中遗忘早期信息，论文提及但未深入解决。
- **缺乏对比学习预训练**：未像Q-Former那样使用图像-文本对的对比学习进行预训练，可能导致视觉-语言对齐不够充分。
- **参数初始化简单**：Q-Mamba参数直接复制小型Mamba（130M）权重，未探索更优初始化策略。
- **注意力图分析不足**：未对不同图像下查询的注意力分布进行定性分析，难以直观理解查询的作用机制。
- **潜在风险**：模型参数超10亿，计算资源差异可能加剧不公平性；LLM固有的幻觉问题可能带来偏见或有害输出，文中仅提及但未缓解。

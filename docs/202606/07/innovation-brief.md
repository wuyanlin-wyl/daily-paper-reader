### 2. Motion-Guided Causal Disentanglement for Robust Multi-View Cine Cardiac MRI Diagnosis
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.04414v1
- 方法流程：
  - 输入：多视图（2ch/3ch/4ch）心脏电影MRI序列，每个序列 x∈R^{H×W×T}
  - 阶段1：自监督MAE预训练（50%时空patch掩码，重建MSE损失）
  - 阶段2：运动引导ROI裁剪——计算帧差均值图D，85%分位阈值二值化，取最大连通域边界框+15%自适应填充，裁剪输入 x'∈R^{H'×W'×T}
  - 阶段3：共享ViT编码器提取每视图特征 f_v ∈ R^D（D=768）
  - 阶段4：双分支投影——两个两层MLP（输出维度128，L2归一化）分别生成疾病嵌入 e_d^v 和视图嵌入 e_v^v
  - 阶段5：联合损失优化（疾病对比+视图对比+跨视图一致+对抗解耦+分类）
  - 输出：逐视图logits通过晚融合平均后经sigmoid得到预测概率 y_hat
- 关键模块/机制：
  - 双分支投影头：将共享视图特征分解为疾病相关和视图相关两个正交子空间；两个独立的2层MLP（含BatchNorm），输出128维L2归一化嵌入。疾病嵌入 e_d^v 用于疾病分类和对比学习；视图嵌入 e_v^v 用于视图分类和对比学习。
  - 视图内疾病对比学习：在每个视图内拉近同类疾病样本、推开异类疾病样本，防止视图特定疾病捷径；每个视图v内，对锚点i，正样本为同视图同疾病标签的样本 p∈P_vi，负样本为同视图其他所有样本。损失为监督对比损失（式2），并引入焦点重加权（式3）降低易样本权重，α=2？
  - 视图对比学习：学习不同视图的解剖差异，增强视图嵌入的区分性；正样本对为同一视图类型（跨患者、跨疾病），负样本对为同一患者的不同视图。损失如式4，温度τ_v为超参数。
  - 跨视图一致性正则化：对多视图患者，强制疾病嵌入一致、视图嵌入分离；式5：疾病一致性项最小化不同视图疾病嵌入的余弦距离；视图分离项最大化视图嵌入的余弦相似度（带margin γ）。
  - 对抗视图解耦（GRL）：从疾病嵌入中去除视图信息，实现统计独立性；在疾病嵌入上附加梯度反转层（GRL），后接视图分类器gϕ（交叉熵损失）。反向传播时GRL反转梯度，鼓励疾病编码器生成无法预测视图的嵌入。
  - 运动引导ROI裁剪：无监督定位心脏区域，去除静态背景干扰；计算帧差均值图D（式1），取85%分位数阈值得到二值运动掩膜，提取最大连通域边界框并扩展15%作为裁剪区域。
- 公式/目标函数/指标定义：
  - 帧差均值图：D(h,w) = (1/(T-1)) Σ_{t=1}^{T-1} |x_{h,w,t+1} - x_{h,w,t}|
  - 疾病对比损失（视图v内）：L_disease^v = - (1/|P_vi|) Σ_i Σ_{p∈P_vi} log [ exp(e_d^{v,i}·e_d^{v,p}/τ_d) / Σ_{j≠i} exp(e_d^{v,i}·e_d^{v,j}/τ_d) ]
  - 焦点重加权：L_disease,focal = - (1/|P_vi|) Σ_i (1−s_bar_i)^α Σ_{p∈P_vi} log [ exp(e_d^{v,i}·e_d^{v,p}/τ_d) / Σ_{j≠i} exp(e_d^{v,i}·e_d^{v,j}/τ_d) ]
  - 视图对比损失：L_view = - Σ_{i,v} log [ (Σ_{j≠i} 1[v_j=v] exp(e_v^{v,i}·e_v^{v,j}/τ_v)) / (Σ_{j≠i} exp(e_v^{v,i}·e_v^{v,j}/τ_v)) ]
  - 跨视图一致性正则化：L_consist = Σ_i Σ_{v1≠v2} [ (1 - e_d^{v1,i}·e_d^{v2,i}) + [e_v^{v1,i}·e_v^{v2,i} + γ]_+ ]
  - 对抗视图解耦损失：L_adv = - (1/N) Σ_i Σ_v 1[v_i=v] log g_ϕ(GRL(e_d^{v,i}))
- 算法细节：
  - ViT-MAE编码器采用CineMA base配置（D=768，12层，12头），3D CNN stem进行时空patch化。
  - MAE预训练掩码率50%，解码器为轻量transformer，仅用MSE损失。预训练后丢弃解码器。
  - 疾病对比学习时，每个mini-batch按视图分别计算对比损失，再平均。
  - 视图对比学习时，负样本包含不同视图的同一患者及其他患者的不同视图，但正样本严格为同一视图类型。
  - 对抗解耦的GRL实现：前传时直接传递，反向传播时乘以 -λ_adv（或固定负因子）。
  - 晚融合：将各视图logits平均后通过sigmoid得到最终预测概率。
  - 分类头为线性层，输入为视图特征f_v（非投影嵌入）。
- 训练/推理细节：
  - 优化器：AdamW，余弦学习率衰减，初始学习率未明确给出。
  - batch size：16，在NVIDIA A100 GPU上训练。
  - 5折分层交叉验证。
  - 投影头输出维度D_p=128，温度τ_d和τ_v为超参数（未给出具体值）。
  - 焦点重加权参数α为超参数，默认论文中常用值如2？
  - 损失权重λ_d, λ_v, λ_c, λ_adv通过验证集调参（具体值未给出）。

- 方法流程：

  - 阶段3：特征融合与分类 - 将ViT特征和TDA特征进行级联融合，输入到全连接分类层进行四类分类
- 关键模块/机制：

- 算法细节：

### 6. On the Limits of Token Reduction for Efficient Unified Vision Language Training
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.01503v1
- 方法流程：
  - 阶段1：分析层间注意力分配，通过可视化注意力权重揭示理解任务在深层图像token冗余，生成任务持续依赖
  - 阶段2：设计任务特定加速器。HiMix：在理解任务中，每层仅对文本查询计算注意力，图像token保留在键值中，但输入层保留原始图像token；HMGen：在生成任务中，将部分中间层设为浅层（跳过图像token注意力和FFN，直接传递隐藏状态），其余层为全层（分离图像和文本投影参数）
  - 阶段3：孤立评估各加速器效果，再统一训练评估协同损失
- 关键模块/机制：
  - HiMix (理解加速器)：减少理解任务中的图像token计算；在自注意力中，从查询（Q）中移除图像token，仅保留文本token作为查询，键（K）和值（V）保留所有token。这样图像-图像注意力被消除，文本-图像交互保留。每层输入需包含原始图像token（因输出仅有文本token）。复杂度从O((T+M)^2d)降为O(T(T+M)d)。
  - HMGen (生成加速器)：减少生成任务中的图像token计算，同时保持自回归依赖；在浅层（K个指定中间层）：跳过图像token的自注意力和FFN，图像隐藏状态直接从前一层传递到下一层；仅对文本token计算注意力和FFN。在其余全层：保持完整注意力，但将图像和文本的投影参数分离（decouple），即图像token使用独立的Q/K/V投影矩阵（与文本不同），以稳定训练和提升质量。
- 公式/目标函数/指标定义：
  - 标准Transformer层复杂度: Cost_base = O((T+M)^2d + 8(T+M)d^2) (T文本token数，M图像token数，d隐藏维度)
  - HiMix层复杂度: Cost_HiMix = O(T(T+M)d + 8Td^2)
  - HMGen中浅层复杂度: Cost_shallow = O(T^2d + 8Td^2)
  - HMGen总复杂度: Cost_HMGen = (L-K) * O((T+M)^2d + 8(T+M)d^2) + K * O(T^2d + 8Td^2) (L总层数，K浅层层数)
- 算法细节：
  - HiMix：对于每一层，输入序列包含T个文本token和M个图像token。计算Q时仅用文本token（形状[T, d]），K和V用全部token（形状[T+M, d]）。注意力输出仅文本token（形状[T, d]），图像token不参与后续自注意力。但该层输入仍需包含原始图像隐藏状态（可能通过跳过连接传递或直接作为下一层输入）。
  - HMGen：选择K个中间层作为浅层（例如交替模式）。在浅层中，图像token隐藏状态直接从上一层复制到下一层（不经过注意力和FFN）；文本token正常经过注意力和FFN。在全层中，分别对图像和文本token使用独立的QKV投影（可学习参数），然后拼接计算完整自注意力。FFN共享但参数独立？原文说“separate projection parameters for image and text tokens”，仅投影分离，FFN可能仍共享？原文未明确FFN分离，但说“decoupling image-related projections stabilizes training”。
- 训练/推理细节：
  - HiMix兼容训练和推理，因为每层输入需要原始图像token，输出缺少图像token，但下一层通过残差连接或直接传递图像token？原文说“requires the input original image tokens to each layer of the transformer”，可能图像token通过短路连接保留。
  - HMGen可直接用于推理（无需重新训练）：在浅层直接跳过图像token计算。训练时需微调全层的分离投影参数。
  - 理解任务训练使用ShareGPT-4v数据集，单轮预训练+微调；生成任务使用JourneyDB数据集。
  - 统一训练时，同时应用HiMix和HMGen，但观察到性能协同损失（比孤立应用差），因为任务特定token丢弃导致参数路径分歧。

### 7. EvoCut: Multi-Layer Evolution-Aware Visual Token Compression for Efficient Large Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.01756v1
- 方法流程：
  - 输入：视觉标记序列通过视觉编码器各层
  - 步骤1：对每相邻层过渡，计算每个标记的归一化演化方向 Δ_i^(t) = (x_i^(t) - x_i^(t-1)) / ||x_i^(t) - x_i^(t-1)||_2
  - 步骤2：对每层过渡的所有演化方向进行K-means聚类（固定簇数M），得到M个组演化方向 {u_1, ..., u_M}
  - 步骤3：对于每个标记，计算其演化方向与最近组方向的余弦相似度，得到偏离得分 d_i^(t) = 1 - cos(Δ_i^(t), u_{c(i)})
  - 步骤4：使用历史感知更新（例如指数移动平均）将各层偏离得分累积为最终得分 s_i
  - 输出：根据最终得分降序保留前K个视觉标记，其余丢弃
- 关键模块/机制：
  - 组演化建模模块：捕捉每层过渡中视觉标记的主导演化方向；对每层过渡的所有标记演化方向向量进行K-means聚类，固定簇数M，得到M个归一化的簇中心作为组演化方向。
  - 演化偏差评分模块：衡量单个标记演化方向偏离组演化方向的程度；对于每个标记，计算其归一化演化方向与最近的组方向之间的余弦距离（1 - 余弦相似度），作为该层偏差得分。
  - 多层得分累积模块：跨层聚合偏差得分，增强稳定性；采用历史感知更新策略（如累加或指数移动平均）将各层偏差得分累积为每个标记的最终重要性分数，避免单层噪声。
- 公式/目标函数/指标定义：
  - 演化方向定义：Δ_i^(t) = (x_i^(t) - x_i^(t-1)) / ||x_i^(t) - x_i^(t-1)||_2
  - 偏差得分：d_i^(t) = 1 - cos(Δ_i^(t), u_{c(i)}^{(t)})，其中u_{c(i)}^{(t)}是第t层过渡中离Δ_i^(t)最近的组方向
  - 最终得分：s_i = accumulate_d( d_i^(1), d_i^(2), ..., d_i^(L) )，具体累积方式为历史感知更新（如指数移动平均）
- 算法细节：

- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.03871v1
- 方法流程：
  - 阶段1: 连接器预对齐 - 仅训练MLP连接器，将视觉编码器输出映射到LLM嵌入空间。
  - 阶段2: 视觉指令微调 - 对LLM（和部分模型中的视觉编码器）进行全参数或部分参数微调，使用指令跟随数据集。
  - 分析阶段: 因果干预 - 对训练好的模型应用注意淘汰（阻断图像到文本的注意力）和层跳跃（跳过图像嵌入计算）来定位关键层。
  - 分析阶段: 表示比较 - 构造语义等价的多模态和纯文本提示，逐层比较隐藏表示，使用信息不平衡、CKA和邻域重叠度量。
- 关键模块/机制：
  - 注意淘汰 (Attention Knockout)：因果干预技术，用于阻断图像到文本的信息流；对于特定层的注意力头h，将预softmax注意力矩阵A^{(l,h)}中所有文本查询i∈T与图像键j∈V的项设为-∞，从而消除跨模态注意力，但保留同模态交互。
  - 层跳跃 (Layer Skipping)：因果干预技术，用于跳过图像嵌入的计算；在层范围[l,l')内，除了执行注意淘汰，还将第l层的图像嵌入直接复制到第l'层，从而绕过中间层对图像的处理。
  - 信息不平衡 (Information Imbalance)：度量视觉与文本表示之间的方向性预测能力；计算Δ_{img→text} = (2/N^2) Σ_{i,j|r_{Ximg}^{ij}=1} r_{Xtext}^{ij}，其中r_{X}^{ij}是点j在表示空间X中相对于点i的欧氏距离排名。该值接近0表示视觉邻域结构能预测文本邻域结构。
- 算法细节：
  - 注意淘汰: 在特定层，对每个注意力头，将文本查询与图像键对应的注意力分数置为-∞，使得softmax后注意力权重为0，阻断图像到文本的信息传递。
  - 层跳跃: 选择连续层范围，不仅淘汰跨模态注意力，还将该范围起始层的图像隐藏状态直接传递到结束层，忽略中间层的图像处理。
  - 表示采集: 对每个输入，取最后一个token（通常是序列结束符）的隐藏状态作为整句表示。
  - 信息不平衡计算: 对N个样本，分别计算视觉和文本表示空间中的欧氏距离矩阵，对每个样本i找到其在视觉空间中的最近邻j，然后计算j在文本空间中的排名，平均所有这样的排名。
- 训练/推理细节：
  - 微调设置: 对LLaVA-7B和OneVision-4B进行Stage-2微调，使用官方训练数据（LLaVA: 665k指令混合；OneVision: LLaVA-NeXT 780k），超参数与原论文一致。
  - 局部微调: 仅微调中间层（例如中间一半层），冻结其余层，与全微调比较性能。
  - 推理时干预: 在推理时应用注意淘汰或层跳跃，通过修改注意力掩码或隐藏状态传递来模拟损伤。

### 14. SBP-Net: Learning Thin Structure Reconstruction with Sliding-Box Projections
- 区域：quick；分数：6.0

- 方法流程：
  - 输入：3D体素网格（由CT分割体素或点云体素化得到）
  - 滑动盒遍历：固定大小盒子（步长为边长一半）提取局部子体积，确保相邻盒子重叠
  - 六视角正交深度投影：对每个子体积，从上下左右前后六个方向计算最小深度，归一化到0-255灰度值，生成6张单通道图像
  - 2D重建网络：注意力U-Net接收投影图像，输出完整的2D深度图（像素值0-1）
  - 重投影：将每张重建的2D深度图反向映射回对应3D子体积，得到3D体素填充
  - 融合：将所有子体积的重建结果与原始输入进行逻辑OR操作，仅添加新体素，保持原始结构完整性
  - 输出：完整的3D体素模型

  - 基于拓扑保持的训练数据生成：区分真正孔洞与自然间隙，避免错误合并连接分支；计算输入X'与GT X的差值图D，提取连通组件di。对每个di，创建包围盒二值掩膜M，统计填充前后连通分量数n_base和n_new：若n_new = n_base则填充（孔洞），若n_new < n_base则保留（自然间隙）。
- 公式/目标函数/指标定义：
  - 深度归一化：pixel = int((1 - d/(N-1)) * 255)，其中d为深度值，N为盒子尺寸
  - 损失函数：L_mask = λ · M_w ⊙ |P'_v - P_v|，λ=100，M_w = w_fill·M_fill + w_fg·M_fg + w_bg·M_bg，权重w_fill=0.85, w_fg=0.10, w_bg=0.05
  - 拓扑保持判断：若n_new = n_base则填充该孔洞，若n_new < n_base则保留为自然间隙
- 算法细节：
  - 滑动盒遍历：在3D体素网格上以固定步长（盒子边长一半）滑动提取重叠子体积
  - 六视角投影：对每个子体积沿±x, ±y, ±z方向计算正交深度投影
  - 2D网络推理：将六张投影图（可独立或堆叠输入）送入Attention U-Net，输出重建后的深度图
  - 重投影：将2D深度图反投影到3D子体积，像素值对应体素占据概率（阈值通常0.5）
  - 融合：对所有子体积的重建体素与原始输入体素进行逐体素逻辑OR操作
  - 训练数据生成：对每个候选孔洞，通过dilation得到局部掩膜，计算连通分量变化决定是否保留为训练样本
- 训练/推理细节：
  - 训练使用Adam优化器，L1损失加mask权重，缩放因子λ=100
  - 训练数据来源：PARSE数据集50张CT扫描，通过对比分割结果与GT提取薄分支缺失区域
  - PipeForge3D合成数据：50个工业管道模型，每个约100个组件，随机生成约10个孔洞
  - 推理时：滑动盒遍历整个输入体积，逐盒子投影→网络重建→重投影→全局融合
  - 输入投影图可以六张独立或堆叠为6通道，训练时任意顺序输入（原文'fed arbitrarily'）

### 15. Can Generalist Agents Automate Data Curation?
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.04261v1
- 方法流程：
  - 初始化：智能体获得包含数据池、CLI工具和训练/评估脚本的Docker工作空间。
  - 智能体操作：通过命令行检查数据文件（如JSON行、元数据）、编写/编辑Python脚本实现过滤或重写策略。
  - 提交训练：调用submit命令将所选数据子集送入固定训练配方（LLaVA-1.5-7B微调，一个epoch，冻结视觉塔）。
  - 评估：训练完成后自动触发八项基准（MMVet, LLaVA-Bench等）评估，返回聚合分数。
  - 迭代改进：智能体观察分数、检查评估日志，根据脚手架要求撰写研究计划（research.md）后实施新策略。
- 关键模块/机制：
  - Curation-Bench环境：提供标准化接口和反馈，隔离训练/评估管道，确保公平比较。；包含固定候选数据池、CLI提交门、训练配方（表8）、评估套件（8个基准，归一化聚合为0-100分数），所有智能体使用相同Docker工作空间和环境。
  - Self-Research重型脚手架：强制智能体每轮从数据出发进行研究，而非直觉性代码修改。；每轮开始前必须撰写research.md，包含具体观察（如从评估日志中发现的失败模式）、假设、最小改动。使用blocklist禁止简单启发式。结果日志包含skill ref（引用之前的研究）、failure mode（与特定基准相关）、next skill candidate（下一轮研究问题）。
  - Adapt Research Papers重型脚手架：通过强制引用和适应具体方法论文来引导智能体探索新策略家族。；会话初始化时要求浏览所有技能卡片（每个卡片对应一篇论文），每轮策略必须基于1-3个特定技能卡片，记录中明确引用卡片并写出单行适应。强制类别轮换：每轮尝试不同类别，除非合理说明。禁止将技能卡仅用作灵感。
  - 重写脚手架：使智能体能够不仅选择示例，还能通过MLLM改进示例。；每轮评估后，智能体抽样5-15个错误预测，分类失败模式（如OCR误读、格式违反等），并与训练数据交叉引用。然后构造重写配方：指定目标数据子集、变换类型（通过MLLM）、预期效果。使用外部MLLM工具（即文中使用的Qwen3.5-27B）执行重写，并验证输出。
- 公式/目标函数/指标定义：
  - 聚合评分 = mean( normal(MMVet), normal(LLaVA-Bench), 100×MMBench_acc, 100×MMMU_acc, 100×MMStar_acc, MathVista-Mini, OCRBench/10, mean(aAcc,fAcc,qAcc) )，其中normal表示原始分数不变。
  - 数据策展目标：在固定训练预算下，最大化验证集上的聚合评分。
- 算法细节：
  - 智能体通过CLI读取文件、编辑脚本、运行shell命令并观察stdout/stderr。
  - 轻量级脚手架下，智能体仅遵循口头指令或技能列表，但表现为局部改进（如调整阈值、过滤条件）。
  - 重型脚手架下，每轮迭代需生成research.md（观察、假设、最小改动）、实施策略、记录结果（skill ref, failure mode, next skill candidate）。
  - Adapt Research Papers额外要求：初始化时扫描所有技能卡片，每轮必须引用具体技能卡并写出适应计划，且技能类别需轮换。
  - 重写脚手架中，智能体使用eval-log reading和targeted rewriting，通过外部MLLM（Qwen3.5-27B）对失败样本进行重写，并在日志中记录重写配方。
- 训练/推理细节：
  - 训练：从预训练LLaVA-1.5-7B检查点开始，在8个A100 GPU上微调1个epoch，冻结视觉塔，使用PyTorch和Accelerate，batch size和lr固定（具体值在表8中，未提供）。
  - 评估：8个基准（MMVet, LLaVA-Bench, MMBench, MMMU, MMStar, MathVista-Mini, OCRBench, HallusionBench），通过VLMEvalKit执行，使用Qwen3.5-27B作为judge模型（无思考模式，temperature=0），评分归一化后取平均。
  - 每个子集训练加评估约需4小时H100 GPU时间。

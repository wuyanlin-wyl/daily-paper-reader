## 摘要
像Segment Anything Model 3 (SAM3)这样的概念分割模型在自然图像上表现出强泛化能力，但由于不同成像原理和风格导致的域差距，其在医学影像中的性能有所下降。测试时自适应（TTA）通过在线更新模型而不使用标注，对于提升测试性能至关重要。然而，现有的视觉-语言TTA方法主要基于图像级不确定性最小化，这并不一定反映医学分割中区域级的语义正确性。此外，它们通常缺乏在持续单次自适应中保持稳定性的机制，导致在缺少可靠密集监督的分割任务中性能有限。为解决这些问题，我们针对医学图像的SAM3提出了一种基于概念对齐对比与长短提示记忆的测试时自适应方法（CM-TTA）。首先，对于具有多种增强的测试样本，我们引入了一种新颖的概念对齐对比度量（CAC），该度量利用文本-视觉语义一致性来稳健地评估预测质量，从而选择最佳增强视图作为监督。其次，为平衡快速自适应与稳定自适应，我们设计了一个长短提示记忆（LSPM）模块。短期记忆基于CAC得分动态融合最近提示，用于灵活的局部自适应，而长期记忆则维持稳定的全局提示以生成增强伪标签。最后，提出了一种密集监督提示更新（DSPU）策略，利用增强伪标签作为密集监督来优化提示嵌入。在前列腺和皮肤病变分割上的大量实验表明，我们的CM-TTA框架显著优于现有的SAM3 TTA方法。

## Abstract
Concept segmentation models like Segment Anything Model 3 (SAM3) show strong generalization on natural images, yet their performance degrades in medical imaging due to the domain gap caused by different imaging principles and styles. Test-Time Adaptation (TTA) is essential for improving the testing performance by updating the model on the fly without annotations. However, existing vision-language TTA methods are mainly driven by image-level uncertainty minimization, which does not necessarily reflect region-level semantic correctness in medical segmentation. Moreover, they often lack mechanisms to maintain stability in continual one-pass adaptation, leading to limited performance when reliable dense supervision is missing for segmentation. To address these issues, we propose Concept Alignment Contrast and LongShort Prompt Memory for Test-Time Adaptation (CM-TTA) of SAM3 for medical images. First, for a test sample with multiple augmentations, we introduce a novel Concept Alignment Contrast (CAC) metric, which leverages textual-visual semantic consistency to robustly evaluate prediction quality to select the best augmented view as the supervision. Second, to balance rapid and stable adaptation, we design a Long-Short Prompt Memory (LSPM) module. The short memory dynamically fuses recent prompts based on CAC scores for agile local adaptation, while the long memory maintains a stable global prompt to generate enhanced pseudo-labels. Finally, a Densely Supervised Prompt Update (DSPU) strategy is proposed to optimize the prompt embeddings with enhanced pseudo labels as dense supervision. Extensive experiments on prostate and skin lesion segmentation demonstrate that our CM-TTA framework significantly outperforms existing methods for TTA of SAM3.

### 2. 论文提出的方法论

- **核心思想**：在 SAM3 仅优化文本提示嵌入（1.02K 可训练参数）的基础上，结合多视图增强、基于语义对齐的视图选择、历史提示动态融合以及稳定与快速适应的权衡策略。
- **关键技术细节**：
    1. **概念对齐对比度量（CAC）**  
       对于测试图像 \(X_i\) 及其 \(K\) 个增强视图，用当前提示 \(T_i\) 提取前景、背景的视觉特征（通过软预测掩膜平均池化），计算它们与文本特征 \(t_i\) 的余弦相似度之差：  
       \[
       C_i = \text{sim}(\bar{z}_{i,fg}, t_i) - \text{sim}(\bar{z}_{i,bg}, t_i)
       \]  
       选择评分最高的视图 \(X_i^*\) 作为最优视图用于后续监督。
    2. **长短提示记忆模块（LSPM）**  
       - **短期记忆（SPM）**：维护长度为 \(L\) 的先进先出队列，存储最近提示及其 CAC 得分。利用 CAC 得分作为权重对历史提示进行加权融合得到 \(T_i^{\text{hist}}\)，再与当前提示 \(T_i\) 动态加权得到 \(T_i^{\text{short}}\)。  
       - **长期记忆（LPM）**：通过指数移动平均（EMA）更新全局提示：\(T_i^{\text{long}} = \gamma T_{i-1}^{\text{long}} + (1-\gamma) T_i^{\text{short}}\)，作为稳定锚点。
    3. **密集监督提示更新策略（DSPU）**  
       - 用长期提示 \(T_i^{\text{long}}\) 在 CAC 选择的最优视图上生成软伪标签 \(P'_i\)。  
       - 对所有 \(K+1\) 个视图，利用短期提示 \(T_i^{\text{short}}\) 的预测与伪标签计算软 Dice 损失 \(L_d\)。  
       - 额外对最优视图施加对比损失 \(L_c = -C_i^*\)（最大化 CAC 得分）和像素级熵最小化损失 \(L_e\)。总损失 \(L = L_d + \alpha L_c + \beta L_e\)。  
       - 单步反向传播更新提示后，用更新后的提示对原图推理得到最终分割。

- CM-TTA 在两个数据集上均显著优于所有对比方法：Promise12 上 Dice 提升 3.17 个百分点（平均 73.96%），ISIC2018 上提升 6.07 个百分点（平均 82.34%），ASSD 分别降至 10.91 和 9.39 像素。

- DSPU 利用长期提示生成的增强伪标签作为密集监督，显著优于不更新或仅用对比损失的情况。

### 7. 优点

- **创新性**：首次在 TTA 中显式利用文本-视觉语义对齐（CAC）评估预测质量，替代纯图像级不确定性。
- **多模块协同设计**：CAC 选择最优视图，LSPM 平衡快速与稳定适应，DSPU 提供密集自监督，环环相扣，逻辑清晰。
- **轻量高效**：仅优化提示嵌入，训练参数极低，推理时间仅增加约 0.26 秒/样本，适合在线部署。
- **实验验证充分**：在两种不同成像模态（MR、RGB）和病灶类型（前列腺、皮肤）上均取得一致改进，且消融和超参数分析支撑设计选择。

### 8. 不足与局限

- **实验覆盖有限**：仅在两个 2D 医学分割数据集上验证，未涉及 3D 体积数据（如 CT、多序列 MR）或其他解剖结构，向 3D 扩展的泛化性未知。
- **文本提示依赖**：要求预知目标类别（如“the prostate”），类别未知或开放式场景下不适用，且仅优化一个令牌，可能限制语义表达能力。
- **单步更新假设**：基于每个测试样本仅更新一次且按顺序处理，真实繁忙临床流中样本顺序可能影响适应结果；未研究 batch size>1 或更大规模流。
- **超参数固定**：EMA 动量 γ=0.99 和 β=0.1 未在不同数据集上重新调优，可能存在次优性。
- **推理速度**：相比未自适应基线（0.31s）增加约 84% 耗时（0.57s），对于实时要求高的场景可能需要进一步优化。
- **伪标签质量**：在初始阶段无历史信息时，短期记忆为空，可能依赖初始提示造成偏差；长期记忆的 EMA 更新可能引入早期错误。

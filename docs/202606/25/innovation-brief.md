### 2. Language-Instructed Vision Embeddings for Controllable and Generalizable Perception
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19584v1
- 方法流程：
  - 训练数据生成：对ImageNet图像，使用Gemini 2.0 Flash生成16.4M个图像-查询-答案三元组，查询为自然语言指令，答案为相应文本。
  - 编码器初始化：视觉编码器使用预训练SigLIP/SigLIP2 ViT，文本编码器固定。
  - 指令嵌入注入：文本指令通过冻结的SigLIP文本编码器得到固定嵌入，再经单层线性投影后注入视觉Transformer（如插入到每个Transformer块或作为特殊token）。
  - 对比学习训练：视觉编码器（含投影层）更新，使用SigLIP风格的sigmoid对比损失，将调制后的视觉嵌入与对应答案文本嵌入拉近。
  - 零样本推理：输入图像和任意语言指令（可未见），视觉编码器输出任务中心嵌入，与预计算答案候选文本嵌入计算相似度，检索Top-1答案。
- 关键模块/机制：
  - 语言指令投影层：将固定文本指令嵌入映射为视觉编码器可用的调制信号；单层线性变换，将SigLIP文本编码器输出的指令嵌入投影到与视觉空间相容的维度，注入到ViT中（可能作为额外的token或层输入）。
  - 视觉Transformer（ViT）：接收图像块和指令调制信号，生成任务中心视觉嵌入；基于SigLIP/SigLIP2 ViT架构，在训练时更新全部参数（含投影层），冻结原始文本编码器。指令调制信号通过注入方式影响自注意力或前馈网络。
  - sigmoid对比损失：训练视觉编码器使其嵌入与指令相关的答案文本嵌入对齐；计算batch内视觉嵌入与文本嵌入的点积logits，对每个(图像,文本)对使用sigmoid损失，公式为 loglik = log_sigmoid(m1_diag1 * logits)，其中 m1_diag1 = -1 + 2*eye，惩罚错误的配对。
- 公式/目标函数/指标定义：
  - 对比损失：logits = zimg @ ztext^T / temperature，m1_diag1 = -ones(batch_size, batch_size) + 2*eye(batch_size)，loglik = log_sigmoid(m1_diag1 * logits)，nll = -sum(loglik, axis=-1)，loss = mean(nll)。
- 算法细节：
  - 指令注入方式：语言指令文本通过SigLIP文本编码器得到固定嵌入，再经线性投影层后输入到ViT的每个Transformer块（类似Adapter或调制 token）。
  - 检索流程：推理时，给定图像和指令，LIVE视觉编码器输出嵌入，与预先编码的候选答案文本嵌入（形式为'Answer: ...'）计算余弦相似度，选择最高分的答案。
  - 训练数据去重：所有评估基准与训练数据经过去重（图像和文本指令），确保零样本评估。
- 训练/推理细节：
  - 初始化：视觉编码器从SigLIP/SigLIP2预训练模型初始化，文本编码器固定。
  - 优化器：使用SigLIP相同的优化设置，学习率0.001，batch size 8192，122k训练步，256 TPUv3核心。
  - 数据增强：仅使用resize增强。
  - 推理：无微调，直接对任意语言指令进行零样本检索。

### 3. Prompt, Plan, Extract: Zero-Shot Agentic LLMs Workflows for Lung Pathology Extraction from Clinical Narratives
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19852v1
- 方法流程：
  - 输入：原始病理报告文本
  - Mapper节点：将报告分段为语义连贯的章节（如SPECIMEN、TUMOR、MARGINS、LYMPH NODES、PATHOLOGIC STAGING）
  - Planner节点：从各章节提取元数据（如肿瘤灶性、切缘状态等），生成细粒度提取任务队列
  - Executor节点：并行处理任务队列，每个任务使用构造的提示（相关章节文本+元数据+指令）调用LLM，输出JSON片段
  - Compiler节点：聚合和综合所有JSON片段，合并重复、解决冲突，输出包含13个CAP字段的标准化JSON对象
- 关键模块/机制：
  - Mapper：将病理报告分割为语义章节，锚定提取到自然修辞结构，减少后续节点负担；接收原始文本，基于规则或LLM（零样本）输出分段结果，如SPECIMEN、TUMOR等章节
  - Planner：为每个CAP章节提取元数据并生成细粒度提取任务列表；对每个章节（如TUMOR）提取元数据（如focality），然后构造任务描述（如提取肿瘤特征），支持并行规划
  - Executor：执行具体提取任务，返回JSON片段；对每个任务，构建包含相关章节文本、元数据和指令的提示，调用LLM生成结构化JSON响应；任务可并行运行
  - Compiler：汇聚Executor的输出，标准化为最终CAP JSON；合并重叠观察、解决简单冲突（如重复的尺寸或切缘状态），输出包含13个字段的JSON对象
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 工作流基于LangGraph有向图实现，四个节点顺序执行，但Planner和Executor内部可并行
  - Mapper节点：使用LLM（零样本）对报告进行章节分割，输出章节列表
  - Planner节点：对每个章节调用LLM提取元数据（如肿瘤灶性计数、切缘状态等），并生成任务队列（如'提取肿瘤大小'）
  - Executor节点：对每个任务构造提示，包含'相关章节文本'、'元数据'和'结构化JSON指令'，调用LLM返回JSON片段
  - Compiler节点：接收所有JSON片段，进行合并和冲突解决（如选择多数值或最近值），输出最终JSON
- 训练/推理细节：
  - 监督基线：GatorTron345M，NER训练30轮，RE训练14轮，A100 GPU，约8小时+14小时
  - 零样本工作流：无训练，直接使用预训练LLM进行推理，所有模型使用相同提示，无示例（零样本设置）
  - 全部LLM推理在单个A100 GPU上进行（若模型支持）

### 4. Spectral Query-Key Product Weight Steering for Training-Free VLM Hallucination Mitigation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20419v1
- 方法流程：
  - 输入：预训练VLM权重（查询权重W_q,h和共享键权重W_k,g）以及编辑超参数（层范围、头选择、k、α）。
  - 步骤1：选择中间层（如中间三分之一层）和所有查询头，对每个头找到对应的共享键头。
  - 步骤2：计算每个头的QK乘积M_h = W_q,h^T W_k,g，并通过QR分解和r×r SVD高效计算其薄SVD：M_h = UΣV^T。
  - 步骤3：抑制选定的前k个奇异模式：构造Σ⋆，其中前k个奇异值乘以(1-α)，其余不变；重构编辑后的乘积M⋆_h = UΣ⋆V^T。
  - 步骤4：计算乘积变化ΔM_h = M⋆_h - M_h，求解最小Frobenius范数的查询权重更新：ΔW_q,h = (W_k,g W_k,g^T + λI)^{-1} W_k,g ΔM_h^T，其中λ是正则化项。
  - 输出：更新后的查询权重W⋆_q,h = W_q,h + ΔW_q,h，键权重不变，写入模型。
- 关键模块/机制：
  - 薄SVD分解：高效计算每个注意力头的QK乘积的奇异值分解；利用QR分解将W_q,h和W_k,g正交化，得到M_h = Q_q C_h Q_k^T，其中C_h = R_q R_k^T∈R^{r×r}，然后对C_h进行r×r SVD得到M_h = UΣV^T，避免d×d分解，r为秩（通常等于头维度）。
  - 主导模式抑制：削弱QK乘积中前k个最强的注意方向，减少先验驱动的注意力；给定SVD M_h = UΣV^T，选择模式集S（默认前k个），定义Σ⋆_{ii} = (1-α)Σ_{ii}（i∈S）或Σ_{ii}（i∉S），重构M⋆_h = UΣ⋆V^T。α∈[0,1]为阻尼强度，α=1完全移除该模式。
  - GQA安全查询恢复：将编辑后的QK乘积映射回查询权重，且不改变共享键权重；求解最小化||ΔW_q,h||_F^2且满足(W_q,h+ΔW_q,h)^T W_k,g = M⋆_h的约束优化，得到闭式解ΔW_q,h = (W_k,g W_k,g^T + λI)^{-1} W_k,g ΔM_h^T，其中λ = ε·(1/r)tr(W_k,g W_k,g^T)用于数值稳定。最终更新仅查询权重。
  - 对称/反对称变体：区分互内容相似性与方向注意力模式，用于机制解释；将M_h分解为对称部分S_h = (M_h+M_h^T)/2和反对称部分Ω_h = (M_h-M_h^T)/2。分别对S_h进行特征分解、对Ω_h进行SVD，得到三种变体：仅编辑对称（Sym-only）、仅编辑反对称（Antisym-only）、同时编辑（Sym+Antisym）。
- 公式/目标函数/指标定义：
  - 薄SVD：M_h = UΣV^T，通过QR分解W_q,h^T = Q_q R_q，W_k,g^T = Q_k R_k，中间矩阵C_h = R_q R_k^T，对C_h SVD得到M_h = (Q_q Ũ) Σ (Q_k Ṽ)^T。
  - 模式抑制：Σ⋆_{ii} = (1-α) Σ_{ii} (i∈S) 或 Σ_{ii} (i∉S)。
  - 编辑后乘积：M⋆_h = U Σ⋆ V^T。
  - 查询权重更新闭式解：ΔW_q,h = (W_k,g W_k,g^T + λ I)^{-1} W_k,g ΔM_h^T，其中λ = ε·(1/r) tr(W_k,g W_k,g^T)，ε是小的常数（如1e-6）。
  - 最终权重：W⋆_q,h = W_q,h + ΔW_q,h, W⋆_k,g = W_k,g。
- 算法细节：
  - 对每个选中的查询头，首先通过QR分解和r×r SVD计算M_h的奇异分解。
  - 根据选定的k和α，对前k个奇异值乘以(1-α)进行抑制，其余保持不变，重构M⋆_h。
  - 计算差值ΔM_h = M⋆_h - M_h。
  - 求解带正则的最小二乘问题，得到查询权重更新ΔW_q,h，确保编辑后的QK乘积等于M⋆_h。
  - 直接对权重矩阵进行修改，无需梯度或反向传播。
- 训练/推理细节：
  - 该编辑是离线一次性修改，不涉及任何训练数据或梯度更新。
  - 推理时模型架构、解码配置与原始模型完全相同，无额外计算开销。
  - 所有计算基于预训练权重矩阵，不需要输入图像或文本。

### 6. Evaluation of Medical Vision Language Models HuluMed and MedGemma, and general purpose chatbots Gemma 3, ChatGPT Plus, and Claude Pro on real previously unseen wound images
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20723v1
- 方法流程：
  - 步骤1: 数据准备 - 收集20个临床多样伤口病例（包括糖尿病缺血、静脉、手术、淋巴水肿等），经IRB批准和去标识化处理。
  - 步骤2: 问题设计 - 制定12个标准化临床问题（Q1-Q12），覆盖病因分类、血管干预指征、纤维蛋白组织、肉芽组织覆盖、感染风险、轴向影像需求、清创环境、截肢风险、治疗敷料、加压治疗、负压治疗、生物工程皮肤替代物。
  - 步骤3: 模型评估 - 将每个伤口图像与完整12问题文本提示一起输入模型（零样本），收集模型输出。
  - 步骤4: 评分 - 由临床专家参考标准对每个回答进行二元评判（正确=1，错误=0），含糊或非承诺回答计为错误。
  - 步骤5: 统计 - 计算各模型在240（20*12）个决策点上的总正确数和准确率，并分析病例间变异性。
- 关键模块/机制：
  - 临床评估框架：标准化测试方案；包含12个临床问题（见表II），从病因分类到高级管理（如生物工程皮肤替代物），每个问题有明确的二进制或类别答案，由专家小组预先确定参考标准。
  - 二元评分规则：量化模型输出正确性；模型输出被解析后与专家参考标准严格匹配。任何包含条件性语言（如'可能取决于'）或模棱两可的回答均计为错误（0分），仅当提供明确且可操作的答案时才计1分。
  - 零样本推理：模型评估模式；所有模型在未经过伤口领域微调的情况下直接处理图像和问题，利用其预训练的多模态和语言能力进行临床推理。
- 公式/目标函数/指标定义：
  - 总体准确率 = 正确决策数 / 总决策数（240）
  - 每个问题的准确率 = 该问题正确数 / 20

### 7. PROTON: Prototype-Based Test-Time Online OOD Detection for Medical VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.20913v1
- 方法流程：
  - 输入：无标签测试流图像，冻结的VLM（视觉编码器f_v和文本编码器f_t），预定义ID类名提示
  - 阶段1 - 文本缓存：对C个ID类别，通过f_t生成文本嵌入T∈R^{C×d}，一次性缓存
  - 阶段2 - 特征提取与MCM得分：对每个测试图像x_t，视觉编码器输出ℓ2归一化嵌入e_t，计算与T的点积后softmax得到概率p_t，MCM得分S_MCM = -max(p_t)
  - 阶段3 - 置信度门控：若max(p_t)≥γ，将e_t加入对应类别的FIFO队列D_c（最大容量M），否则跳过
  - 阶段4 - 原型更新：每个类别维护原型μ_c为队列中嵌入的ℓ2归一化均值（公式1）
  - 阶段5 - 原型距离得分：当所有类别积累至少K_min个样本后，计算S_proto = 1 - max_c e_t^T μ_c（公式2）
  - 阶段6 - 自适应融合：通过Welford在线算法跟踪MCM流方差σ_t^2，计算融合权重α_t（公式4），输出最终得分S = α_t S_MCM + (1-α_t) S_proto
  - 输出：每张测试图像的OOD得分S
- 关键模块/机制：
  - 在线原型库 (Online Prototype Bank)：维护每个ID类别的代表性嵌入，动态跟踪部署环境统计；每个类别c维护一个FIFO队列D_c，最大容量M。当置信度门控通过时，将当前嵌入e_t入队对应类别的队列，若队列满则移除最旧嵌入。类别原型μ_c为队列中所有嵌入的ℓ2归一化均值。队列大小M=100，K_min=5
  - 原型距离得分 (Prototype Distance Score)：利用嵌入空间距离检测OOD，弥补MCM对协变量偏移的盲区；在原型库校准后，对于每个测试嵌入e_t，计算与所有类别原型的余弦相似度，取最大值，S_proto = 1 - max_c e_t^T μ_c。由于两者均为ℓ2归一化，该值等于1减去最大余弦相似度，ID样本接近0，OOD样本接近1
  - 自适应融合 (Adaptive Score Fusion)：动态平衡MCM和原型距离得分，自动适应不同偏移类型；融合得分S = α_t S_MCM + (1-α_t) S_proto。权重α_t由MCM流方差σ_t^2决定：α_t = α_max - σ(100·(σ_t^2-σ_0^2))·(α_max-α_min)。其中σ(·)为sigmoid，σ_0^2为参考方差（ID流方差），α_min=0.3，α_max=0.7。当方差低（主要是ID）时α_t接近α_max信任MCM；方差高（协变量偏移）时权重转向原型距离
  - 置信度门控 (Confidence Gate)：防止低置信度（可能OOD）样本污染原型库；仅当softmax最大概率max(p_t)≥γ（默认0.7）时，才将嵌入加入原型队列。否则只用于计算当前OOD得分但不更新原型
  - Welford在线方差计算 (Welford's Online Algorithm)：高效追踪MCM流的运行方差，支持自适应融合；使用单通道O(1)内存的Welford算法维护计数n、均值S和平方差M2，每步更新后计算方差σ_t^2 = M2/n。初始σ_0^2=0.02
- 公式/目标函数/指标定义：
  - 类原型：μ_c = ē_c / ||ē_c||_2，其中 ē_c = (1/|D_c|) ∑_{e∈D_c} e
  - 原型距离得分：S_proto(x_t) = 1 - max_c e_t^T μ_c
  - 自适应融合：S_PROTON(x_t) = α_t · S_MCM(x_t) + (1-α_t) · S_proto(x_t)
  - 自适应权重：α_t = α_max - σ(100·(σ_t^2 - σ_0^2))·(α_max - α_min)
  - MCM得分：S_MCM(x_t) = -max_c p_t,c，其中 p_t = softmax(e_t^T T / τ)
- 算法细节：
  - 文本嵌入T一次性缓存，视觉嵌入逐帧计算
  - Welford在线方差：初始化n=0, S̄=0, M2=0；每步n=n+1, Δ=S_MCM - S̄, S̄=S̄+Δ/n, M2=M2+Δ*(S_MCM - S̄), σ_t^2 = M2/n
  - 原型更新：只有通过置信度门控的样本才入队，FIFO队列满时移除最旧样本
  - 原型距离得分仅在所有类别积累K_min个样本后启用，否则回退为纯MCM
  - 自适应权重α_t被限制在[α_min, α_max]内（通过sigmoid自动实现）
  - 最终OOD得分S_t输出，无需额外归一化
- 训练/推理细节：
  - 无训练阶段：模型参数冻结，无梯度计算，无反向传播
  - 推理时在线：每张测试图像顺序处理，原型库动态更新
  - 无标注数据需求，零样本设置
  - 轻量级：额外内存约0.4 MB（C×M×d = 2×100×512），计算开销O(Cd) + 常数

### 12. Surgical Anatomy Recognition with Context Learning using Foundation Representations
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22124v1
- 方法流程：
  - 阶段1: 输入帧 t 的视觉patch tokens Pt 与初始可学习查询合并，包括分割查询 Qseg_0、过程查询 Qproc_0、阶段查询 Qphase_0，以及上一帧传播的查询 (Qseg_{t-1}, Qproc_{t-1}, Qphase_{t-1})
  - 阶段2: 所有查询与视觉tokens一起输入单Transformer编码器，通过全局自注意力更新所有查询，得到输出查询 (Qseg_t, Qproc_t, Qphase_t)
  - 阶段3: 分割查询Qseg_t经解码预测每个查询对应的掩码和类别；过程查询Qproc_t通过MLP预测手术类型标签 ŷproc_t；阶段查询Qphase_t通过MLP得到阶段嵌入zt，用于对比学习
  - 阶段4: 时间传播：将输出查询通过线性层线性变换后与初始可学习查询相加，作为下一帧输入查询 Qt = Linear(Q̂_{t-1}) + Q0
- 关键模块/机制：
  - 过程上下文查询 (Procedure Context Query)：编码全局、稳定的手术类型信息（如特定术式），辅助分割；初始化为可学习向量Qproc_0，每个时间步经Transformer更新后得到Qproc_t，再通过MLP预测手术类型标签，使用交叉熵损失Lproc监督。该查询作为额外token参与注意力，使分割查询能间接利用手术类型上下文。
  - 阶段上下文查询 (Phase Context Query)：捕捉手术阶段等细粒度时序变化，增强时序一致性；使用4个可学习阶段查询Qphase_0，每帧产生阶段嵌入zt = MLP(Qphase_t)。在一个clip（5帧）内，相邻帧的zt通过InfoNCE损失拉近，不同clip的zt推开。该自监督信号促使阶段查询编码时序连贯的手术状态。
  - 时间查询传播 (Temporal Query Propagation)：提供短期视觉记忆，确保分割掩码的帧间连续性；类似VidEoMT：上一帧输出查询Q̂_{t-1}经过线性层Linear()变换后，与当前帧初始可学习查询Q0相加，得到当前帧的输入查询Qt。公式：Qt = Linear(Q̂_{t-1}) + Q0。所有类型查询（分割、过程、阶段）均传播。
- 公式/目标函数/指标定义：
  - 输入到Transformer：Xt = (Pt, Qseg_0, Qproc_0, Qphase_0, Qseg_{t-1}, Qproc_{t-1}, Qphase_{t-1})
  - 过程预测：ŷproc_t = MLP(Qproc_t)，损失 Lproc = CE(ŷproc_t, yproc_t)
  - 阶段对比学习：zt = MLP(Qphase_t)，Lphase = -log( exp(zt·z_{t+}/τ) / Σ_j exp(zt·zj/τ) )，其中z_{t+}为同一clip内相邻帧嵌入，zj为其他clip或远距离帧嵌入，τ为温度系数
  - 查询传播：Qt = Linear(Q̂_{t-1}) + Q0
  - 训练总损失：L = 5.0 * L_mask_BCE + 5.0 * L_Dice + 2.0 * L_mask_cls + 1.0 * Lproc + 0.1 * Lphase
- 算法细节：
  - 模型采用编码器-解码器架构（基于EoMT），但解码器仅处理分割查询；过程查询和阶段查询仅用于辅助损失，不参与掩码生成
  - 时间传播使用一个线性层（无偏置）将上一帧输出查询映射到当前帧空间，再与初始查询相加，保留初始化特征
  - 过程查询和阶段查询在每一帧均被更新，并通过传播保持时序连续性
  - 训练时每个样本为5帧clip，所有帧共享相同的可学习初始查询（Q0），传播只在clip内帧间进行
  - 推理时逐帧运行，但保留前一帧的输出查询以传播；过程查询和阶段查询持续更新
- 训练/推理细节：
  - 训练在单个NVIDIA H100 GPU上进行，10个epoch，batch size 24
  - 每个训练样本为5帧clip，采样自视频
  - 使用1个过程查询和4个阶段查询，100个分割查询
  - 优化器未明确说明，但基于EoMT默认（推测AdamW）
  - 损失权重：mask BCE和Dice各5.0，分类损失2.0，过程损失1.0，对比损失0.1
  - 模型初始化采用域内预训练权重（在SurgeNet数据集上使用DINOv3预训练的ViT权重）

- 原文链接：https://arxiv.org/abs/2606.23494v1
- 方法流程：

  - 步骤3：TCA流：对于每个病理描述k，以其文本嵌入tk为查询，切片特征V为键值，通过注意力机制聚合得到病理特定视觉表示hk，并使用InfoNCE损失将hk与tk对齐，同时与其他病理文本嵌入分离。

  - 病理特定表示: hk = Ak V
  - 细粒度对齐损失: L_align = -Σ_{k=1}^K log[ exp(cos(hk, tk)/τ) / Σ_{j=1}^K exp(cos(hk, tj)/τ) ]
  - ABMIL门控注意力: ai = exp{ w^T (tanh(W vi) ⊙ σ(U vi)) } / Σ_j exp{ ... }
  - 全局表示: z = Σ_i a_i vi
  - 逻辑集监督损失: L_logic = (1/C) Σ_{c=1}^C [ y_c ℓ1(P_c) + (1-y_c) ℓ0(P_c) ]，其中ℓ1(P_c)=-(1-P_c)^{λ1} log(P_c), ℓ0(P_c)=-P_c^{λ0} log(1-P_c)
- 算法细节：

  - 多标签分类使用Asymmetric Loss，设置聚焦参数λ1（正类）和λ0（负类），以缓解类别不平衡。

- 方法流程：
  - 阶段1-整体诊断推理：策略模型πθ处理完整3D CT序列，生成结构化全局诊断报告Y_global（含<findings>、<impression>）及预测的关键切片索引k和边界框bbox。
  - 阶段2-证据定位验证：环境提取第k个切片I_k，输入验证器（权重共享的策略模型副本）以固定提示生成局部描述Y_local；然后计算多粒度奖励（存在性re、细粒度rf、跨视图一致性rc）并通过GRPO更新策略。
- 关键模块/机制：
  - 策略模型：作为强化学习策略，生成全局诊断报告和关键证据切片索引。；基于预训练VLM Qwen3-VL经过SFT微调，输入完整3D CT序列，输出包含<findings>, <impression>和<key_slice>索引及<bbox>的结构化文本。
  - 验证器：对选定的关键切片进行独立视觉重查询，生成局部验证描述。；与策略模型共享权重，以固定提示（如“Describe the abnormality in this image.”）处理单个切片I_k，输出局部描述Y_local，用于计算跨视图一致性奖励。
  - 多粒度奖励函数：提供多模态密集反馈，综合文本正确性与视觉证据定位。；由三部分组成：肿瘤存在奖励re（二值正确性）、细粒度信息奖励rf（基于LLM裁判对大小/位置/增强模式的属性匹配评分）、跨视图一致性奖励rc（局部属性匹配减空间惩罚）。最终加权和R = 0.3*re + 0.5*rf + 0.2*rc。
  - GRPO优化器：无需值网络，高效优化策略参数。；对每个输入采样G个输出组，计算组内归一化的优势Ai = (R(oi)-mean)/std；最大化带clip和KL散度惩罚的代理目标J_MRL。
- 公式/目标函数/指标定义：
  - 总奖励：R_total = α·re + β·rf + γ·rc, α=0.3, β=0.5, γ=0.2
  - 肿瘤存在奖励：re = I[E(Y_global) == E(Y_gt)]，E(·)为存在性映射，I为指示函数
  - 细粒度信息奖励：rf = Σ_{att∈Λ} w_att · S_att(Y_global, Y_gt)，其中Λ={size, location, enhancement}，权重分别为0.3, 0.4, 0.3；S_att为0/1匹配函数
  - 跨视图一致性奖励：rc = Σ_{att∈Λ} w_att · S_att(Y_local, Y_gt) - λ·L_dist(k, k_gt)，λ=0.3
  - 空间惩罚：L_dist(k, k_gt) = 1 - IoU([k-1, k+1], [k_gt-1, k_gt+1])
  - GRPO优势估计：A_i = (R(o_i) - mean({R(o_j)})) / (std + ε)
- 算法细节：
  - 策略模型对每个输入3D CT卷采样G个输出，每个输出包含全局报告Y_global、关键切片索引k和边界框。
  - 环境从输出中提取k，从3D体积中截取切片I_k。
  - 将I_k输入验证器（策略模型副本）生成局部描述Y_local。
  - 计算每个输出的总奖励R，并对其在组内做z-score归一化得到优势A_i。
  - 使用带clip的PPO风格目标和KL散度惩罚更新策略，保持语言稳定性。
- 训练/推理细节：
  - 训练分为两步：先用SFT在报告数据上微调Qwen3-VL作为基础策略π_ref；再用GRPO进行强化学习，对每个训练样本采样G个输出（G为组大小，原文未明确数值），计算奖励并更新。
  - 推理时，只需策略模型前向传播，直接输出全局报告和关键切片索引，无需验证器参与，实现可解释诊断。

- 区域：deep；分数：9.0

- 方法流程：
  - 阶段1: 任务设计——确定三个异质任务分别评估跨语言对齐、概念区分和证据检索，确保零概念和查询重叠

  - Task3: Multilingual Evidence Retrieval (RAG)：评估跨语言证据检索能力：多语言查询检索相关英文段落；从BioASQ选取2,040个质量保证的查询，通过双语概念保真度和后翻译QA流程进行翻译验证，保留率83.7%。语料库为80,049个英文段落，平均查询长度6.7词，平均文档长度30.1词。主要指标：R@5。
- 公式/目标函数/指标定义：

  - Task1 score = mean(nDCG@10, R@1)
  - Task2 score = mean(R@1 per tier)
  - Task3 score = R@5
  - fairness gap = max_l nDCG@10(l) - min_l nDCG@10(l) （l为语言）
- 算法细节：
  - UMLS CUI级联标注器：先尝试精确匹配UMLS优选项和同义词，未匹配的查询使用生物医学链接器进行回退
  - 概念区分集构建：从UMLS MRCONSO.RRF文件中解析概念组，按层级规则（同CUI、同词汇同代码前缀、同词汇不同前缀）生成混淆集
  - 多语言证据检索查询翻译：采用双语概念保真度检查（确保关键术语不变）和后翻译QA（回译验证语义一致）的质量保证流程
- 训练/推理细节：
  - 基准无需训练，仅用于评估
  - 评估10个系统，涵盖6个范式家族（BM25、通用多语言编码器、生物医学编码器、通用多语言dense retriever、生物医学dense retriever、混合检索器）
  - 指标：nDCG@10、R@1、R@5，每个任务特定，最终聚合为MMed-IR

### 23. MorVess: Morphology-Aware Pulmonary Vessel Segmentation Network
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.24214v1
- 方法流程：
  - 输入：3D肺部CT扫描（尺寸H×W×D）
  - 阶段1 - 2.5D适配：将连续三片2D切片（轴向方向）通过轻量级适配器（含跨片注意力）融合，产生2.5D特征，输入冻结的SAM ViT编码器
  - 阶段2 - 编码：冻结的SAM ViT编码器提取多尺度2.5D特征图
  - 阶段3 - 解码与几何预测：多分支解码器分别预测血管掩膜（二值）、距离图（VDM）和厚度图（VTM），其中VDM通过距离变换计算、VTM通过局部厚度估计
  - 阶段4 - 全局-局部融合：GLFB整合编码器多层级语义特征与解码器几何特征，输出高保真拓扑重建掩膜
  - 输出：最终血管分割掩膜（二值），附带距离图和厚度图作为中间监督
- 关键模块/机制：
  - 2.5D Adapter：将2D SAM调整为3D上下文感知的表示模块；采用轻量级跨片注意力机制，输入连续三片轴向切片（2.5D），通过可学习投影和位置编码融合片间信息，输出增强的2.5D特征，输入冻结的SAM ViT编码器，实现3D空间上下文注入而不显著增加参数量。
  - Multi-Head Decoder：联合预测语义掩膜、距离图和厚度图的多分支解码器；基于SAM解码器结构扩展为三个输出头：一个头输出二值掩膜（Sigmoid），一个头输出距离图（回归，采用L2损失），一个头输出厚度图（回归，采用L1损失）。各头共享底层特征，通过跳跃连接与编码器多尺度特征融合。
  - Global-Local Fusion Block (GLFB)：自适应整合多尺度语义特征与几何先验，提升拓扑重建质量；接收编码器提供的多层级语义特征和解码器输出的几何特征（距离图、厚度图），通过可学习的通道注意力机制（SE-like）和空间注意力机制（自注意力），对局部细节和全局上下文进行加权融合，输出细化后的特征用于最终掩膜预测。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 两阶段训练：第一阶段（HLR）以1×10⁻⁵学习率微调适配器和解码器，冻结SAM主干；第二阶段（LLR）以5×10⁻⁵学习率微调所有可训练参数（包括SAM中的适配器层）
  - 距离图计算：对真实血管掩膜执行3D欧几里得距离变换，归一化到[0,1]
  - 厚度图计算：通过局部骨架距离估计，对每个血管点计算局部直径
  - 损失函数组合：分割损失（Dice + 交叉熵）+ 距离回归损失（L2）+ 厚度回归损失（L1）+ 可选的clDice损失
  - GLFB中的注意力机制：先通过1×1卷积压缩通道，再应用多头自注意力捕捉全局依赖，最后通过残差连接恢复
- 训练/推理细节：
  - 训练：两阶段微调策略，第一阶段仅训练适配器和解码器，第二阶段解冻SAM的adapters（LoRA-like）进行联合优化
  - 输入预处理：CT值窗口化至[-1000, 400] HU，重采样至各向同性1mm分辨率，随机裁剪为128×128×64 patch
  - 数据增强：随机旋转（±10°）、弹性变形、伽马校正
  - 推理：滑动窗口策略，重叠50%，对重叠区域取平均
  - 硬件：单张NVIDIA A100 GPU，批量大小4，优化器AdamW，权值衰减1e-4

### 25. Jolia: Concept-Level Vision-Language Alignment for 3D CT Contrastive Learning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.24570v1
- 方法流程：
  - 数据预处理：输入CT体积-报告对，LLM首先推断检查类型并路由到胸部或腹部解剖分类体系，然后将报告发现部分分解为原子级单句观察，每句标注器官和发现类别，按器官分组映射到预定义概念，同时为下游构建统一的252类别发现分类体系。
  - 图像特征提取：将CT体积重采样至1.5mm各向同性，裁剪至192×192×192体素，使用3D编码器（Atlas/ResNet-101/ViT-B）输出多尺度patch tokens和全局[CLS] token。
  - 概念级交叉注意力池化：为每个概念在每个尺度上初始化可学习查询向量，对每个尺度独立应用单头交叉注意力（查询层归一化后与patch tokens交互），将每个概念在所有尺度上的输出拼接为最终概念表示c_k ∈ R^{576}。
  - 文本编码：使用冻结的Qwen3-Embedding-8B对每个概念文本片段独立编码，得到t_k ∈ R^{4096}，再经线性投影至576维；同时对完整报告编码得到全局文本表示t。
  - 对比训练：对每个概念k，计算批内所有样本的该概念图像-文本相似度矩阵S_k，应用对称InfoNCE损失L_(CLIP)^((k))；同时计算全局[CLS] token与完整报告嵌入之间的全局CLIP损失L_(CLIP)^([CLS])；总损失L = λ_CLIP L_(CLIP)^([CLS]) + λ_ConQuer L_ConQuer，其中L_ConQuer为所有有效概念损失的均值。仅对批内至少有两个有效样本的概念计算损失。
- 关键模块/机制：
  - 多尺度交叉注意力查询池化：从图像编码器的多尺度patch tokens中提取每个解剖概念对应的视觉特征，无需空间监督。；为每个概念k在每个尺度s上初始化一个可学习查询q_k^{(s)}（维度d=192）。对每个尺度，先对查询和patch tokens进行LayerNorm，然后执行单头交叉注意力：查询作为Q，patch tokens作为K和V。输出为每个概念在各尺度的特征，通过拼接所有尺度得到最终概念表示c_k ∈ R^{576}。可学习参数仅约0.6M。

### 34. Semantic Robustness Certification for Vision-Language Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.18839v1
- 方法流程：
  - 输入：原始图像x，一对文本提示(ta, ta')指定源语义a和目标语义a'，类别标签集C。
  - 步骤1：利用VLM编码器分别得到图像嵌入z和文本嵌入ua, ua'。
  - 步骤2：由ua, ua'构造正交基(e1, e2)张成语义平面Pa,a'，将z正交分解为z∥和z⊥。
  - 步骤3：计算源语义角度φa = atan2(⟨z∥, e2⟩, ⟨z∥, e1⟩)，并指定目标角度φa'（文本锚定或图像锚定）。
  - 步骤4：定义语义变换γ(φ) = r(cosφ e1 + sinφ e2) + z⊥，φ∈[φa, φa']。
  - 步骤5：对每对标签(c,c')，计算余弦形式的边际函数mc,c'(φ)=Ac,c' cosφ + Bc,c' sinφ + Cc,c'。
  - 步骤6：求解mc,c'(φ)=0得到所有临界角度，排序后划分区间(φℓ, φℓ+1)，每个区间内预测恒定。
  - 输出：认证区间集合S = {((φℓ, φℓ+1), yℓ)}，以及预测不变概率P。
- 关键模块/机制：
  - 语义平面构造：将语义变化限制在二维子空间中，简化分析。；给定一对文本嵌入ua, ua'（线性无关），定义平面Pa,a' = span{ua, ua'}，通过Gram-Schmidt得到正交基e1=ua, e2=(ua'-⟨ua',ua⟩ua)/‖·‖₂。
  - 语义变换γ(φ)：参数化地调整源语义与目标语义的相对强度。；将图像嵌入z分解为z∥∈Pa,a'和z⊥垂直于平面。设r=‖z∥‖₂，定义γ(φ)=r(cosφ e1+sinφ e2)+z⊥，φ从φa（源）变化到φa'（目标）。
  - 闭式决策边界分析：高效计算所有可能的标签变化点。；VLM预测基于余弦相似度，决策边界为⟨e, uc-uc'⟩=0。将γ(φ)代入得mc,c'(φ)=r⟨e1,Δu⟩cosφ+r⟨e2,Δu⟩sinφ+⟨z⊥,Δu⟩，令Δu=uc-uc'。
  - 不对齐扰动下的鲁棒性条件：处理跨模态不对齐带来的不确定性。；假设存在δ使得匹配对嵌入距离≤δ。推导稳定性条件：若m_{ŷ,c'}(φ)>δ‖u_ŷ-uc'‖₂对所有c'成立，则所有δ邻域内预测不变。定义不确定性区间Uc,c'(δ)={φ:|mc,c'(φ)|≤δ‖uc-uc'‖₂}。
- 算法细节：
  - 文本锚定目标角度: φa' = atan2(⟨ua', e2⟩, ⟨ua', e1⟩)
  - 图像锚定目标角度: 通过参考图像x'的投影z'∥计算
  - 边界求解: 对每个(c,c')，解三角方程Ac,c' cosφ + Bc,c' sinφ + Cc,c' = 0，得到候选φ，筛除不在[φa,φa']的解
  - 区间划分: 所有候选φ排序，加上端点φa和φa'，依次检查区间内任意一点的预测标签即可得整体划分
  - 不对齐处理: 计算每个边界的不确定性区间Uc,c'(δ)，利用余弦函数的单调性在区间内求解|mc,c'(φ)|≤ε的边界
- 训练/推理细节：
  - 无需额外训练，直接使用预训练VLM（如CLIP）。
  - 推理时，对给定图像和文本提示对，计算一次图像嵌入和文本嵌入，后续分析均为闭式计算。
  - 两个锚定设置：文本锚定（直接用提示嵌入决定φa'）和图像锚定（需要额外参考图像）。

  - Depth Pooling Tokenization Module：从2D切片特征聚合为3D体积令牌；沿切片方向，将连续q个切片的对应位置patch特征进行平均池化，然后L2归一化。池化核q可调，大q生成粗令牌（大感受野），小q生成细令牌（小感受野）。同一批次内所有体积使用相同q。

### 40. LARE: Low-Attention Region Encoding for Text-Image Retrieval

- 方法流程：

  - 阶段2: 区域编码：对每个候选区域ri，用同一冻结视觉编码器提取区域特征zi = fv(ri)。
  - 阶段3: 置信度门控得分：计算全局相似度sg和最大区域相似度sr，若sg≥阈值τ则最终得分S=sg；若sg<τ且sr>sg，则用插值S=(1-α)sg+αsr，其中α=min(2(sr-sg),0.5)。

  - 低注意力区域检测模块：从冻结视觉编码器的自注意力图中提取逆注意力图，识别低注意力区域。；从中间层ℓ提取自注意力张量，对每个头h计算列和a_i^{(h)}=Σ_j A_{j,i}^{(h)}，重塑为空间网格，min-max归一化，平均top-k高方差头得到平均注意力图¯A，再计算逆注意力图M=1-¯A，最后通过滑动窗口和NMS生成N个候选区域。

  - M = 1 - ¯A，逆注意力图（公式2）
  - zi = fv(ri)，区域编码（公式3）
  - α = min(2(sr - sg), 0.5), S = (1-α)sg + αsr，置信度门控融合（公式4）
- 算法细节：
  - 从中间层提取自注意力张量，对每个头计算列和，形成空间注意力图，选择top-k高方差头平均，得到平均注意力图。

  - 滑动窗口和NMS生成候选区域，最多N个（实验中N=5）。
  - 全局编码和区域编码共享同一冻结视觉编码器权重。
  - 相似度计算采用cosine相似度（隐含在sim函数中），根据文本和图像内积计算。

### 42. Ghost Vectors: Soft-Deleted Embeddings Remain Reconstructible in HNSW Vector Databases
- 区域：quick；分数：6.0

- 方法流程：

  - Epoch Key Rotation：防御机制，加密向量并在删除时丢弃密钥；使用AES-256-CTR加密向量（将向量视为字节流），加密后向量变为随机噪声。删除时丢弃密钥，确保密文不可逆。同时生成ECDSA签名证明。
- 公式/目标函数/指标定义：

  - Theorem 1: 软删除下SRA非可忽略（实证中姓氏恢复49.9%）。
  - Theorem 2: 在AES-256-CTR安全假设下，Epoch Key Rotation的SRA可忽略。
- 算法细节：
  - 攻击算法：1) 读取HNSW二进制索引文件；2) 调用HNSW库的get_items()函数获取所有向量（包括软删除）；3) 对每个向量输入Vec2Text corrector进行文本重建。
  - 防御算法（Epoch Key Rotation）：1) 初始化时生成AES-256密钥，存储于安全硬件；2) 插入向量时，使用密钥对原始向量进行AES-256-CTR加密，将密文存储到HNSW索引；3) 查询时使用同一密钥解密后检索；4) 删除时，从安全存储中移除密钥，无需修改索引文件。

### 44. Beyond Scalar Scores: Exploring LLM-based Metrics for Clinical Significance Evaluation in Radiology Reports
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.18797v1
- 方法流程：
  - 输入：参考报告（REF）和候选报告（TGT）。
  - 阶段1（LLM评估）：使用单遍或两遍提示，让LLM输出结构化JSON，包含三个严重性桶（critical, significant, insignificant），每个桶映射错误跨度及其方面。
  - 阶段2（聚合）：根据公式 (1) 将跨度级严重性聚合为报告级二元标签：若存在Critical或Significant跨度则预测sig.（显著错误），否则预测insig.（无关变异）。
  - 输出：报告级二元预测（sig./insig.），用于计算判别性（D）和鲁棒性（R）准确率。
- 关键模块/机制：
  - 单遍（One-pass）提示：直接输出结构化错误注释；LLM接收REF和TGT，直接生成一个JSON对象，包含critical、significant、insignificant三个键，每个键对应错误跨度列表及其方面描述和解释。
  - 两遍（Two-pass）提示：分离跨度检测和严重性判断，减少复合错误；Pass 1：LLM识别所有差异并输出JSON数组（错误跨度+方面）。Pass 2：对每个跨度，LLM输出单个词（Critical/Significant/Insignificant），基于方面特定标准。
  - 报告级聚合规则（D/R分类规则）：将跨度级严重性映射为报告级二元预测；令n_c, n_s, n_i分别为Critical、Significant、Insignificant跨度数量。若n_c + n_s > 0则预测sig.（显著错误），否则预测insig.（无关变异）。
- 公式/目标函数/指标定义：
  - CLS(t, r) = sig. if n_c + n_s > 0, else insig. if n_c + n_s = 0 and n_i > 0 (公式1)
- 算法细节：
  - 使用贪心解码（temperature=0.0），最大输出1024 tokens。
  - 两遍推理中，Pass 1输出错误跨度JSON数组，Pass 2对每个跨度单独调用LLM并输出单个词。
  - 合成数据：利用Claude Sonnet按12个方面和3种错误类型生成4k报告对，经临床医生验证。
- 训练/推理细节：
  - 训练：基于Qwen3-8B和MedGemma-4B，使用合成4k报告对进行监督微调（SFT）和强化学习（RL）。
  - 推理：支持单遍和两遍模式；两遍推理更消耗成本，但可提升鲁棒性（牺牲判别性）。
  - 评估：在ReEvalMed的400个测试样本上计算判别性（D）和鲁棒性（R）准确率。

### 45. Mix-QVLA: Task-Evidence-Aware Mixed-Precision Quantization of Vision-Language-Action Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.19565v1
- 方法流程：
  - 参考动作序列生成：使用全精度模型在环境时间步τ处理多模态输入zτ，通过自回归解码生成完整的动作token序列y*_i作为参考决策，该序列固定不变。
  - 边界级任务证据计算：对每个候选量化变体（量化第m层到位宽b），在四个功能边界（视觉编码器输出ν、投影器输出β、语言策略表示ψ、动作头表示α）上，首先用全精度校准均值和标准差对隐藏表示进行归一化，再计算梯度加权任务证据图Eθi,γ = Zθi,γ ⊙ ∇_{Zθi,γ} J_i(θ; y*_i)，其中J_i为teacher-forced对数概率。
  - 证据失真度量：比较全精度和量化模型的证据图，使用证据质量（evidence-mass）和分布失真（attribution-distribution distortion）两种指标，分别衡量证据强度变化和空间分配变化。
  - 软瓶颈聚合：通过软瓶颈目标函数将边界级的证据退化聚合为层敏感度分数，避免硬阈值导致的不连续性。
  - 时间感知敏感度累积：在任务轨迹的多个时间步上重复上述过程，累积每个层的敏感度，捕获执行阶段依赖的层重要性变化。
  - 混合精度位分配：基于证据和时间感知的层敏感度分数，在模型大小和BitOps预算约束下，使用优化算法为各层分配不同位宽（如W4、W8等），关键层保留更高精度。
- 关键模块/机制：
  - 边界级任务证据分析模块：评估量化对内部决策路径的破坏，提供量化变体是否保留支持全精度决策的证据的诊断。；对每个量化变体，在四个功能边界上，利用全精度校准统计量归一化隐藏表示，然后计算梯度加权任务证据图：E = Z ⊙ ∇_Z J。J是teacher-forced对数概率，衡量模型对固定全精度动作序列的支持程度。
  - 证据失真度量模块：量化全精度与量化证据图之间的差异，包括证据强度和分配两方面。；定义证据质量失真（变化在证据图的总质量）和分布失真（变化在证据图的空间分布）。具体公式未在输入中给出，但通过比较两个图计算得分。
  - 软瓶颈聚合模块：将多个边界上的证据失真聚合为单个层的敏感度分数，避免硬边界导致的不连续。；使用软瓶颈目标函数（soft-bottleneck objective），对每个边界上的失真进行加权组合，得到层m在特定时间步的敏感度s_{m,t}。
  - 时间感知敏感度模块：捕捉层敏感度在任务执行过程中的随时间变化，区分持续脆弱和阶段敏感的层。；在多个轨迹时间步上计算层敏感度，并累积形成时间聚合敏感度S_m = Σ_t w_t s_{m,t}，其中权重反映时间步的重要性（如接近任务结束的动作可能更重要）。
  - 混合精度位分配模块：根据层敏感度分数，在模型大小和BitOps预算下分配位宽。；将位分配建模为约束优化问题：在总模型大小和总BitOps不超过预算的条件下，最小化加权敏感度损失（高敏感度层分配给高精度）。
- 公式/目标函数/指标定义：
  - π_θ(y_τ|z_τ) = ∏_{k=1}^K p_θ(y_{τ,k} | y_{τ,<k}; z_τ) (策略自回归分解)
  - J_i(θ; y*_i) = (1/K) Σ_{k=1}^K log p_θ(y*_{i,k} | y*_{i,<k}; z_i) (teacher-forced对数概率，作为参考动作支持目标)
  - Z_{θi,γ} = (H_{θi,γ} - μ^{FP}_γ) / (σ^{FP}_γ + ε) (边界归一化)
  - E_{θi,γ} = Z_{θi,γ} ⊙ ∇_{Z_{θi,γ}} J_i(θ; y*_i) (梯度加权任务证据图)
  - 软瓶颈目标：将边界级证据失真（如evidence-mass和分布失真）聚合为层敏感度分数 s_{m,t}。
  - 时间聚合敏感度：S_m = Σ_t w_t s_{m,t}，其中w_t为时间步权重。
- 算法细节：
  - 校准过程：从任务轨迹中采样多个时间步的输入z_i（视觉、机器人状态、指令），对每个时间步用全精度模型生成参考动作序列y*_i。
  - 量化变体评估：对每个候选(层m, 位宽b)，临时将该层量化到位宽b，保持其他层全精度，计算边界证据失真。
  - 边界选择：四个边界Γ = {ν, β, ψ, α}对应视觉编码器输出、投影器输出、语言策略表示、动作头表示（pre-action logits前）。
  - 证据图计算：先归一化隐藏表示，再计算梯度加权图，梯度来自teacher-forced目标对归一化表示的梯度。
  - 证据失真度量：通过比较全精度和量化证据图的差分，得到每个边界上的失真值（可能使用L1或KL散度等，具体未给出）。
  - 软瓶颈聚合：对每个边界失真使用软瓶颈函数（如经过sigmoid或softmax加权的和），得到单时间步层敏感度。
  - 时间感知累积：在多个时间步（例如整个任务轨迹的采样时间步）上重复上述过程，对敏感度进行加权平均，权重可基于时间步离任务结束的距离或动作幅度。
  - 位分配：使用整数线性规划或贪心搜索，在给定模型大小和BitOps预算下，将位宽分配给各层，使总敏感度加权和最小化。
- 训练/推理细节：
  - 后训练量化：Mix-QVLA是PTQ方法，不需要重新训练整个模型，仅需要少量校准数据（从任务轨迹中采样的输入-动作对）。
  - 校准数据收集：从机器人任务轨迹中采样多个时间步的视觉观察、机器人状态和指令，作为校准数据集。
  - 全精度参考：使用全精度模型一次前向传播生成参考动作序列，并保存边界激活的均值和标准差用于归一化。
  - 量化变体前向：对每个候选(层,位宽)，在量化该层的情况下，以teacher-forcing方式（输入参考动作前缀）计算对数概率和梯度，得到证据图。
  - 推理时：按照优化好的混合精度配置加载模型，每个层使用指定位宽进行量化推理（可能包括对称量化、非对称量化等，具体未给出）。
  - 推理速度：在LIBERO上实现1.52x加速，内存从15.4GB降至4.1GB。

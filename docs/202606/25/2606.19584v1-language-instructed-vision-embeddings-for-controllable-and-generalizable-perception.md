## 摘要
视觉基础模型通常被训练为静态特征提取器，将任务适配的负担转移给大型下游模型。我们提出了一种替代范式：不再仅仅将视觉特征输入语言模型，而是利用语言本身动态地引导视觉编码器。我们的方法，语言指令视觉嵌入（LIVE），利用语言作为高层指导，在推理时生成以任务为中心的嵌入，从而无需针对特定任务进行重新训练。这使得编码器能够聚焦于输入中与上下文相关的方面，产生更可控且更具泛化性的表征。实验表明，LIVE减少了视觉幻觉（在MMVP上提升34个百分点），在视觉问答任务上超越了参数数量高几个数量级的视觉语言模型，并且能够泛化到未见过的指令和任务——为自适应、指令驱动的视觉智能提供了直接路径。

## Abstract
Vision foundation models are typically trained as static feature extractors, placing the burden of task adaptation onto large downstream models. We propose an alternative paradigm: instead of solely feeding visual features into language models, we use language itself to dynamically guide the vision encoder. Our method, Language-Instructed Vision Embeddings (LIVE), leverages language as high-level guidance to produce task-centric embeddings at inference time, removing the need for task-specific retraining. This enables the encoder to focus on contextually relevant aspects of the input, yielding more controllable and generalizable representations. Empirically, LIVE reduces visual hallucinations (+34 points on MMVP), surpasses vision-language models with orders of magnitude more parameters on visual question answering, and generalizes to unseen instructions and tasks -- offering a direct path toward adaptive, instruction-driven visual intelligence.

- **研究动机**：受人类视觉注意机制的启发——人类会根据任务目标主动选择性地关注视觉信息。作者希望将这种“意图驱动”的适应性嵌入到视觉编码器中，使视觉表征能够根据自然语言指令动态调整，从而提升可控性和泛化性。
- **整体含义**：提出一种新范式——不是把语言模型当作后处理模块，而是用语言本身直接引导视觉编码器的计算过程，实现“语言指导的视觉嵌入”（LIVE），以代替传统的静态特征提取+大型LLM的后处理方式。

## 2. 论文提出的方法论

### 2.1 核心思想
- **语言指导的视觉编码器**：在推理时，将自然语言指令作为条件输入到视觉 Transformer 中，使编码器动态生成与任务相关的视觉嵌入（而非固定嵌入）。
- **利用LLM生成训练数据**：由于缺少大规模图像-问题-答案三元组数据，作者使用多模态LLM（Gemini 2.0 Flash）为每一张 ImageNet 训练图像自动生成多样化、细粒度的问答对，形成 (图像, 问题, 答案) 三元组。
- **训练目标**：对比学习，使得语言指导的视觉嵌入与正确答案的文本嵌入对齐。

### 2.2 关键技术细节
1. **架构设计**：采用双塔结构，视觉编码器为 ViT，文本编码器为 SigLIP 的文本塔。文本指令经过一个可训练的线性投影层，注入到视觉 Transformer 的输入（作为额外的 token 与图像 patch token 拼接）。文本塔冻结，仅更新视觉编码器和投影层。
2. **推理流程**：给定图像 x 和文本指令 q，计算 z(I) = E_live(x, T(q))，然后与答案文本嵌入 z(T) 进行相似度比对，通过检索得到预测。
3. **损失函数**：采用 Sigmoid 损失（类似 SigLIP），对于 batch 内的 (x_i, q_i) 和答案 a_j，损失为：
   L = -E_{i,j}[log(1 / (1 + exp(-y_{ij}(t·z(I)_i·z(T)_j + b))))]
   其中 y_{ij}=1 表示匹配，-1 表示不匹配，t和b为可学习参数。
4. **数据生成**：使用 Gemini 2.0 Flash，对每张 ImageNet 图像生成多个“有趣的视觉问题-答案”对，避免模板化问题，提升指令多样性和复杂度。共生成约 1640 万三元组。

### 2.3 算法流程（文字说明）
1. 离线阶段：用 LLM 为 ImageNet 训练集生成大量图像-问题-答案三元组。
2. 训练阶段：冻结文本编码器，将文本指令嵌入通过线性投影后作为额外的 token 与图像 patch 一起输入 ViT；通过对比学习最小化匹配对的嵌入距离，最大化非匹配对的嵌入距离。
3. 推理阶段：输入任意图像和任意自然语言指令，直接计算语言指导的视觉嵌入，然后与预计算的答案文本嵌入进行相似度检索，得到预测结果。

## 6. 论文的主要结论与发现
1. **LIVE 大幅降低视觉幻觉**：在 MMVP 上零样本准确率达 76.3%，比先前最好的 BRAVE（42.0%）提升 34 个百分点。

3. **强泛化性**：在训练时从未见过的图像域、未见指令类别上均表现优异，缩小了与 LLM 知识源（Gemini）之间差距高达 49 个百分点。
4. **数据是关键瓶颈**：使用 LLM 生成的三元组数据远超现有公开数据（CC3M、WebLI、Open Images），说明高质量、多样化的指令数据对训练语言指导的视觉编码器至关重要。
5. **注意力可控**：可视化显示，不同指令引导视觉编码器聚焦于图像的不同区域（如“text”或“fruit”），展示出自然的指令驱动控制。

## 7. 优点
- **创新范式**：将语言引导直接嵌入视觉编码器，避免依赖大型 LLM 解码器，实现了极高效的推理。
- **数据生成策略**：利用 LLM 自动生成细粒度、多样化的问答对，解决了三元组数据稀缺问题。
- **零样本能力强**：训练仅使用 ImageNet 数据，但泛化到多个不同域和任务，且对对抗攻击有鲁棒性。
- **消融分析深入**：逐个剖析了指令注入位置、指令特异性、数据源、语言措辞等因素的影响，为后续研究提供了重要参考。
- **视觉注意力可视化**：直观展示了选择性注意力机制，增强了可解释性。

## 8. 不足与局限
- **依赖 LLM 生成数据**：训练数据的质量和多样性受限于 LLM 的能力，且 LLM 可能引入偏见或错误。
- **查询设计依赖手工**：对于特定下游任务，如何构造最佳指令仍需经验调整，缺乏自动发现机制。
- **复杂组合查询处理弱**：当前的文本编码器对深层组合语义、否定等理解有限，方法更适合简单直接的查询。
- **潜在滥用风险**：语言可控制性可能被恶意利用来引入偏见或生成有害内容，论文未提供自动安全检测机制。
- **评估基准局限**：自建基准答案由 Gemini 生成，并非 ground truth，只能测知识迁移能力而非绝对性能。
- **开源问题**：代码和数据集未公开（作者表示需要经过内部审查），可复现性受限。

## 摘要
医学视觉语言模型（VLM）能够实现零样本临床图像分类，但在部署时可靠地检测分布外（OOD）输入仍然是一个开放问题。没有静态评分方法适用于所有类型的偏移：FLAIR上的最大概念匹配（MCM）在远OOD上达到76.4% AUROC，但对于协变量偏移（如超宽视野眼底图像）仅42.4%，实际上是随机的。我们将其追溯到结构上的不匹配：协变量偏移的输入在softmax空间中与分布内样本无法区分，但在VLM嵌入空间中占据不同区域。为了利用这一未开发的信号，我们提出PROTON（基于原型的测试时在线OOD检测），一种轻量级的后处理模块，它从高置信度测试预测中维护在线原型库，并通过流级方差统计自适应地将原型距离与MCM评分融合，无需修改模型、训练数据或提示工程。在眼科学基准FLAIR + FIVES上，PROTON在协变量偏移上提高了MCM +23.9 AUROC，在语义偏移上提高了+8.8，在远OOD上提高了+8.1，使其成为唯一无需分层提示或标注数据即可在所有三种偏移上改进的零样本方法。代码可在https://github.com/GenMI-Lab/PROTON获取，项目页面可在https://genmi-lab.github.io/PROTON获取。

## Abstract
Medical vision-language models (VLMs) enable zero-shot clinical image classification, yet reliably detecting out-of-distribution (OOD) inputs at deployment remains an open problem. No static scoring method works across all shift types: Maximum Concept Matching (MCM) on FLAIR achieves 76.4% AUROC for far-OOD but only 42.4% for covariate shifts such as ultra-wide-field fundus images, effectively random. We trace this to a structural mismatch: covariate-shifted inputs are indistinguishable from in-distribution samples in softmax space, yet occupy distinct regions in the VLM embedding space. To exploit this untapped signal, we propose PROTON (PROtotype-based Test-time ONline OOD detection), a lightweight post-hoc module that maintains an online prototype bank from high-confidence test predictions and adaptively fuses prototype distance with MCM scoring via stream-level variance statistics, requiring no model modification, training data, or prompt engineering. On the ophthalmology benchmark FLAIR + FIVES, PROTON improves MCM by +23.9 AUROC on covariate shift, +8.8 on semantic shift, and +8.1 on far-OOD, making it the only zero-shot method to improve all three without hierarchical prompts or labeled data. Code is available at https://github.com/GenMI-Lab/PROTON, and the project page is available at https://genmi-lab.github.io/PROTON.

### 1. 核心问题与整体含义
- **研究动机**：医学视觉语言模型（VLM）在零样本临床分类中面临分布外（OOD）输入检测难题。现有静态评分方法（如MCM、Energy、GL-MCM）在不同偏移类型上性能不均衡：例如在FLAIR模型上MCM对远OOD达到76.4% AUROC，但对协变量偏移（如超宽视野眼底图像）仅42.4%（近乎随机）。原因是协变量偏移样本在softmax空间中与分布内（ID）样本无法区分，但在VLM嵌入空间中占据不同区域——softmax评分丢弃了这种几何分离信号。
- **研究含义**：需要一种无需训练数据、无需模型修改、无需提示工程的测试时自适应OOD检测方法，能利用嵌入空间的几何信息，同时保持对语义和远OOD偏移的检测能力。

### 2. 方法论：核心思想与技术细节
- **核心思想**：通过在线维护高置信度测试样本的原型库（per-class centroids），计算原型距离（embedding余弦相似度），并与MCM评分进行自适应融合，利用MCM流方差自动调节融合权重，弥补softmax丢弃的几何分离信号。
- **关键技术细节**（对应Algorithm 1）：
  1. **在线原型库**：对每个类别维护一个FIFO队列，最大容量M=100。仅当测试样本的softmax置信度≥门限γ（=0.7）时，才将该embedding存入对应类别队列；低置信度样本跳过更新，防止OOD污染原型。当类别内样本数≥Kmin（=5）后，才激活原型距离评分。
  2. **原型距离评分**：计算测试embedding与各类原型的最大余弦相似度，取补作为Sproto（低值表示靠近ID原型，高值表示OOD）。原型是队列中所有embedding的L2归一化均值。
  3. **自适应融合**：使用Welford在线算法追踪MCM评分的流方差σ²_t，通过sigmoid将方差映射到权重α_t ∈ [α_min, α_max]（默认0.3~0.7）。当流中出现协变量偏移样本时，MCM方差飙升，α_t自动下降，从而降低MCM权重、提高Sproto权重；对于ID主导的平稳流，α_t接近α_max，信任MCM。融合得分：S_PROTON = α_t * S_MCM + (1-α_t) * S_proto。
  4. **退避机制**：原型未校准前（即任何类别样本数< Kmin），直接输出纯MCM评分。
- **复杂度**：仅需O(Cd)点积、O(1)队列维护、三个标量更新；内存约0.4 MB（C=2, M=100, d=512）。无需梯度或反向传播。

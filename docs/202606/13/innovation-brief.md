### 1. The Last Visible Pixel: Probing Fine-Scale Perception in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.07861v1
- 方法流程：
  - 数据生成阶段：使用可控合成画布（白底）生成前5类感知任务和4类推理任务，使用文本自然场景图像生成文本识别和文本计数任务
  - 任务构建阶段：感知子集包含6类任务（字母识别、动物识别、形状识别、方块识别、色块识别、文本识别），推理子集包含6类任务（链式推理、比较链式推理、计数链式推理、模糊链式推理、文本阅读、文本计数）
  - 推理评估阶段：对所有模型使用三种解码设置（确定性无采样、低温度0.1采样、温度1.0采样），固定max_new_tokens=1024，统一使用RGB转换，无系统提示或few-shot示例
- 关键模块/机制：
  - FineSightBench基准：评估视觉语言模型的细粒度感知与推理能力；包含感知和推理两个子集，共8120个样本（Large版本81200个）。图像统一448x448像素，目标尺寸从4到48像素共7个级别。感知子集6个任务，每个任务700样本；推理子集6个任务，共3920样本。
  - 可控合成画布生成：生成干净背景下的视觉目标，便于精确控制尺寸和特征；使用白色背景的合成画布，生成字母、动物图标、形状、方块、色块等，动物使用矢量图标而非真实照片以确保在极小尺寸下可识别。
  - 文本自然场景生成：在真实场景图像上叠加文字，模拟现实干扰；将英文单词叠加到真实自然场景图像上，用于文本识别和文本计数任务，增加背景干扰的挑战。
  - 推理设置：统一评估框架以确保公平比较；所有模型使用bfloat16精度，在Hugging Face Transformers框架内运行。三种解码策略：确定性和温度0.1/1.0采样。图像统一转换为RGB，直接使用数据集的prompt，无系统提示。

  - 推理评估算法：对每个模型，对每个样本运行三种解码设置，记录输出，通过精确匹配或规则解析提取答案，与标注比较计算准确率。

### 2. PRPO: Perception-Reinforced Policy Optimization via Token-Level Dynamic Advantage Reshaping
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08708v1
- 方法流程：
  - 1. 输入：多模态推理任务，包含图像和问题；使用基础策略模型（如Qwen2.5-VL）生成推理轨迹（token序列）。
  - 2. 计算每个token的优势值：基于轨迹级奖励通过GAE等标准方法计算原始优势值。
  - 3. RVD计算：对每个token，计算视觉依赖度(VD)和视觉不一致性(VI)，最终RVD = VD * (1 - VI) 或类似组合，度量token的感知关键性。
  - 4. 确定激活阈值：选择RVD值的前25%分位数作为激活阈值μ（实验中最佳）。
  - 5. PAR重塑：对每个token，使用分段逻辑函数对优势进行重塑，函数形式为 f(x) = m + (M - m) / (1 + exp(-k*(x - μ)))，其中x为原始优势，M为上饱和界，m为下抑制基线，k为激活陡峭度，μ为阈值。
  - 6. 输出重塑后的优势值，用于策略梯度更新。
- 关键模块/机制：
  - RVD (Robust Visual Dependency)：识别每个生成token是否为感知关键token，即既视觉接地又对扰动稳定。；RVD由两个子度量构成：Visual Dependency (VD) 量化token对视觉特征的依赖程度，Visual Inconsistency (VI) 度量token在输入扰动下的预测稳定性。最终RVD值通过VD * (1 - VI) 或类似方式计算，高RVD表示该token是鲁棒的视觉相关token。实验表明选择RVD前25%分位数作为感知关键token阈值。
  - PAR (Perceptual Advantage Reshaping)：对token级优势值进行动态重塑，放大感知关键token的学习信号，抑制非感知token的干扰。；采用分段非线性格型函数：当原始优势低于阈值μ时，输出接近下饱和值m；当优势高于μ时，输出渐近上饱和值M。函数形式为 PAR(A) = m + (M - m) / (1 + exp(-k*(A - μ)))。参数在实验中调优，最优设置为M=4.0, m=0.10, k=2.0。该函数提供平滑的梯度过渡，避免硬阈值。
- 公式/目标函数/指标定义：
  - RVD = VD * (1 - VI) (推断，具体组合未提供明确公式)
  - PAR优势重塑函数：A_res = m + (M - m) / (1 + exp(-k*(A - μ)))
  - 策略梯度目标函数：基于重塑后的优势值进行策略梯度更新，具体未提供
- 算法细节：
  - 使用GAE或类似方法从轨迹级奖励计算每个token的原始优势值
  - RVD计算需要两个前向通路：一次正常推理，一次对输入图像加噪声扰动后推理，对比token预测变化得到VI
  - VD可以通过注意力权重或梯度等衡量token与图像特征的相关性
  - PAR重塑在每次梯度更新前对每个token的优势值应用非线性映射
  - 阈值μ动态选取为当前批次中RVD值的第25百分位数
  - 训练时使用rollout batch size 384，学习率1e-6，最大响应长度2048 tokens
- 训练/推理细节：
  - 训练数据集：ViRL39K，训练2个epoch
  - 基础模型：Qwen2.5-VL (3B和7B)作为策略模型
  - 优化器未提及，学习率1e-6
  - rollout采样数量8，batch size 384
  - RVD计算需要额外一次扰动前向传播，但整体计算开销可控（等时间预算实验表明效率优于基线）
  - 推理时无需RVD和PAR，直接使用训练好的模型

### 3. TABVERSE: Benchmarking Cross-Format Table Understanding in LLMs and VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.09578v1
- 方法流程：
  - 数据过滤与对齐：从FEVEROUS、HybridQA、SQA、TabFact、WikiTableQuestions中筛选单表问答对（6097对，4434个唯一表格），为每个表格创建HTML、Markdown、LaTeX文本表示，并渲染对应图像（标准化字体、填充、宽度）。
  - 标注与平衡：使用Gemini-3-Flash-Preview标注问题类别（7类：简单查找、条件查找、多项查找、聚合/算术、比较/极值、二元验证-单步、二元验证-多跳），人工校正；使用GPT-5.2和Gemini-3-Flash-Preview基于零样本图像QA结果（每个问题6个正确性指标）标注难度（0-3 Hard，4-6 Easy）。从6097对中选700对（350易/350难，每类别每难度各50），覆盖629个唯一表格。
  - 评估管道：VLM-Image（图像+文本提示）、VLM-Text（文本格式+文本提示）、LLM-Text（文本格式+文本提示），在QA、SUC、SR任务上评估，每个任务对每个表格使用三种格式（HTML/Markdown/LaTeX）的文本或图像输入。
- 关键模块/机制：
  - 多格式对齐模块：将同一表格内容转换为三种结构化文本格式（HTML、Markdown、LaTeX）并渲染为图像，确保文本与视觉版本内容一致。；基于Sui et al. (2024a)的工具扩展，处理缺失值和特殊字符；标准化字体大小、填充和宽度，使每个表格的三个文本格式和三个图像渲染对齐。
  - 问题类别标注模块：为每个问题分配7个预设类别之一，便于后续按类别分析表示影响。；使用Gemini-3-Flash-Preview进行初始标注，然后由人工审查校正。
  - 难度标注模块：基于模型在图像输入下的表现，为每个问题标注易/难二元标签。；对于每个问题，使用GPT-5.2和Gemini-3-Flash-Preview分别在三个图像渲染（来自HTML、Markdown、LaTeX）上零样本回答，每个模型给出3个结果，共6个正确性指标；正确数0-3为Hard，4-6为Easy。
  - 平衡评估集构造模块：从全池中挑选700个问题-表格对，确保难度和类别分布均衡。；从6097个样本中按类别和难度分层采样，每个难度（Easy/Hard）内每个类别（7类）各取50个样本，共700个。
  - 评估管道（VLM-Image / VLM-Text / LLM-Text）：提供三种输入配置，用于隔离模态和格式的影响。；VLM-Image：模型接收问题提示和渲染图像（三种格式之一）；VLM-Text：模型接收问题提示和结构化文本表（三种格式之一），无图像；LLM-Text：纯文本模型接收问题提示和结构化文本表。
- 算法细节：
  - 数据对齐：对每个表格，调用Sui et al. (2024a)的转换工具生成HTML、Markdown、LaTeX，并扩展处理缺失值（如空单元格填充占位符）和特殊字符（如转义）；渲染时统一字体大小、单元格填充和表格宽度，保证视觉一致性。
  - 难度标注算法：对于每个问题q，从三个图像渲染（来自三种格式）获得6个正确性得分（两个模型各3个）；定义score(q) = 正确回答数；若score(q)∈[0,3]标记为Hard，[4,6]标记为Easy。
  - 平衡集选择：按类别c和难度d分层，每层从全池中随机选取50个样本（若某层不足50则保留全部），最终形成700样本集。
  - 评估时，每个问题-表格对在三种格式下分别测试，每种格式对应文本输入和/或图像输入；SUC任务使用模板生成边界检测、大小估计、索引检索等问题；SR任务仅对VLM-Image管道，要求输出HTML、Markdown或LaTeX。
- 训练/推理细节：
  - 评估采用零样本设置，不涉及模型训练。
  - 所有LLM和VLM使用公开的预训练权重，在TABVERSE上直接推理。
  - 对于VLM-Image管道，输入图像大小为标准化渲染（具体尺寸未提供），文本提示包含问题和任务指令。
  - 对于SR任务，模型需要输出指定格式的表格结构，通过精确匹配或语法正确性评估（具体指标未详细说明）。

### 4. ++nnU-Net: Scaling nnU-Net with Prefix-Based Data Augmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.10713v1
- 方法流程：
  - 阶段1 - 数据准备：将2D图像转换为NIfTI格式，重命名，存储至images和segmentation目录，按80/20随机分割训练/测试集
  - 阶段2 - 磁盘估算与掩码生成：根据80%磁盘容量和平均文件大小估算最大增强数量；为每张训练图像生成临时二进制圆形掩码（中心圆形区域，半径=0.75*min(width,height)/2）
  - 阶段3 - 检查点初始化：创建checkpoint JSON，记录原始训练集最大案例ID、后续固定-移动对列表、上一个增强的固定文件索引
  - 阶段4 - 配准增强循环：遍历训练集每张图像作为固定图像，随机选取另一张作为移动图像；加载对应掩码；进入最多5次尝试的配准循环
  - 阶段5 - 有效性检查与保存：每次配准后检查：①最大正交距离≤min(图像宽,高)/2；②变换后图像中心仍在原始边界内；若通过则保存增强图像（递增ID），否则丢弃重试
  - 阶段6 - 分割变换：将相同变换应用于对应分割文件；验证分割非空，若为空则删除该图像-分割对
  - 阶段7 - 清理与3D转换：删除变换矩阵、位移场等临时文件；所有数据转换为z=1的3D格式（适配nnU-Net v1）
- 关键模块/机制：
  - 两阶段配准引擎 (antsRegistrationSyNQuick.sh)：执行刚性+可变形SyN配准，生成从移动到固定图像的变形场；默认配置为两步：先刚性配准对齐全局位置，后进行对称归一化（SyN）可变形配准，产生稠密位移场
  - 临时圆形掩码生成：限制配准有效区域，防止边缘非生理畸变；对每张图像生成二值掩码，圆形区域半径=0.75*(min(width,height)/2)，中心位于图像中心，内部像素1，外部0
  - 配准有效性检查：确保变形后的图像在空间上合理，避免解剖结构移出视野；两个条件：①变换后图像与原图像的最大正交距离≤min(width,height)/2；②变换后图像中心坐标仍在原图像边界内
  - 检查点与中断恢复：支持用户中断后从断点继续增强，避免重复工作；在增强开始前创建checkpoint JSON，存储原始集最大案例ID、已处理的固定-移动对列表、上一个固定文件索引；恢复时从该索引继续
  - 最终分割质量检查：消除因配准失败导致的分割为空的情况；应用变换后检查分割文件是否包含非零标签，若为空则删除对应的增强图像和分割
- 公式/目标函数/指标定义：
  - 最大正交距离约束：d_max ≤ min(H, W)/2，其中H、W为图像高度和宽度
  - 增强数量估算：N_aug = floor(0.8 * disk_capacity / avg_file_size)
  - 评价指标：Dice Similarity Coefficient (DSC)
- 算法细节：
  - 数据准备阶段自动转换2D数据集为NIfTI，按nnU-Net要求组织目录
  - 配准阶段：固定图像i，随机选择移动图像j(i≠j)，加载各自圆形掩码，输入antsRegistrationSyNQuick.sh执行两阶段配准
  - 重试循环：单次配准后计算变换后图像与原图像的最大正交距离和中心位置，若未通过条件则重新随机选择移动图像并重试（最多5次）
  - 增强图像命名：在原始命名基础上递增ID，保持文件一致性
  - 分割变换：复用配准生成的变换参数（位移场）对分割进行重采样（最近邻插值）
  - 清理：每次增强后删除变换矩阵、位移场等中间文件以节省空间
- 训练/推理细节：
  - 使用nnU-Net v1（仅处理3D数据），所有增强后的2D数据转换为z=1的3D格式
  - 训练采用5折交叉验证，共110个epoch
  - batch size和patch size与基线nnU-Net完全一致，未作调整
  - 未对nnU-Net架构进行任何修改或微调
  - 硬件：NVIDIA RTX A6000，PyTorch 2.4.1，CUDA 12.1

### 6. Adapting Vision-Language Models from Iconic to Inclusive for Multi-Label Recognition Without Labels
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.11626v1
- 方法流程：
  - 切割阶段：输入原始图像，通过多采样响应估计器对局部补丁进行多次采样，生成初始局部响应和局部字典，提升非显著物体的响应。
  - 缝合阶段：利用多目标混合适应，将局部字典融合为新的数据集，并通过顺序保持置信度校正调整预测置信度，使其更符合多标签分布。
  - 迭代优化：采用EM算法，在切割和缝合之间交替优化，最终得到独立的多标签模型。
- 关键模块/机制：
  - 多采样响应估计器：防止模型只聚焦于单一物体，提升非显著物体响应；对图像局部补丁进行多次采样（不同尺度或位置），用CLIP计算每个补丁的类别得分，通过多次采样估计每个类别的响应，形成局部字典。
  - 多目标混合适应：调整标签分布，使其更符合多标签分布；将局部字典中的响应通过线性组合等方式混合，同时使用顺序保持置信度校正（保持预测置信度的相对顺序）调整最终标签。
  - 顺序保持置信度校正：保持预测置信度的相对顺序，避免过度调整导致失真；在缝合阶段，对混合后的预测置信度进行排序归一化或保持顺序的校正，确保模型内在特性不被破坏。
  - EM迭代优化：交替优化切割和缝合阶段；将切割阶段视为E步（估计潜在标签），缝合阶段视为M步（更新适应参数），循环至收敛。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 切割阶段：对每个图像提取多个局部补丁，用CLIP计算每个补丁的类别得分，通过多次采样（如不同尺度或位置）估计每个类别的响应，形成局部字典。
  - 缝合阶段：将局部字典中的响应作为伪标签，通过多目标混合适应（如线性组合）调整，并使用顺序保持置信度校正（如排序后归一化）得到最终预测。
  - EM迭代：交替进行切割（E步，估计潜在标签）和缝合（M步，更新适应参数），逐步提升多标签识别性能。
- 训练/推理细节：
  - 训练：无需任何真实标签，使用预训练CLIP模型在目标数据集上通过EM迭代进行无监督适应，整个适应过程仅需一个epoch。
  - 推理：使用训练好的多标签模型直接进行多标签预测，无需原始VLM。

### 13. Look Less, Reason More: Block-wise Attention Skipping for Efficient Multimodal LLMs
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.08511v1
- 方法流程：
  - 输入：多模态序列X=[Xv; Xt]，其中Xv为视觉token，Xt为文本token。
  - 阶段1：VIG计算。对每个Transformer层l，通过前向传播计算绕过视觉自注意力后的分布与原始分布的KL散度，在少量校准样本上取期望得Gk(l)。
  - 阶段2：饱和层选择。根据Gk(l)从小到大排序，选择前N个层作为跳过集合L_skip。
  - 阶段3：推理时应用块级稀疏。对l∈L_skip，修改注意力掩码：视觉查询仅关注自身（旁路视觉-视觉注意力），文本查询全关注。保留FFN。
  - 输出：加速后的推理结果。
- 关键模块/机制：
  - Visual Information Gain (VIG)：量化每层视觉自注意力的不可或缺性，识别饱和层。；VIG(k, l) = E_{X~D_k}[D_KL(P(y|X; θ) || P_¬l(y|X; θ))]，其中P_¬l是绕过第l层视觉自注意力后的分布。通过随机采样20个训练样本计算期望。
  - Top-N饱和层选择：在给定预算N下选择最能减少计算且信息损失最小的层。；从所有L层中选择VIG最小的N层作为L_skip，即 argmin_{S⊂L_all, |S|=N} Σ_{l∈S} Gk(l)。
  - 视觉旁路注意力屏蔽：在跳过层中消除昂贵的视觉-视觉注意力计算。；对视觉查询token，跳过MHSA中的自注意力计算，直接执行残差连接：H'_l^V ← LN(H_l^V) + H_l^V。文本查询token保持完整注意力。等效于将视觉-视觉注意力分数置为-∞。
  - FFN保留：保持视觉特征的语义演化能力，因为FFN负责将视觉特征投影到文本语义空间。；在所有层中保持FFN运算：H_{l+1} = FFN(LN(H'_l)) + H'_l，即使视觉自注意力被跳过。
  - 轻量任务校准：根据下游任务自适应确定跳过层位置。；对每个任务随机采样20个图像-文本对，前向传播计算每层VIG，然后根据VIG选择跳过层。校准计算量可忽略。
- 公式/目标函数/指标定义：
  - H'_l = MHSA(LN(H_l)) + H_l
  - H_{l+1} = FFN(LN(H'_l)) + H'_l
  - G_k(l) = E_{X~D_k}[D_KL(P(y|X; θ) || P_¬l(y|X; θ))]
  - L_skip = argmin_{S⊂L_all, |S|=N} Σ_{l∈S} G_k(l)
  - S = Softmax(QK^T/√d + M)
  - 视觉旁路: H'_l^V ← LN(H_l^V) + H_l^V
- 算法细节：
  - VIG计算：对每个层l，将标准注意力掩码替换为屏蔽视觉-视觉注意力的掩码，进行一次前向传播得到P_¬l，计算与原分布P的KL散度，在20个样本上平均。

  - 推理时：对跳过层，动态生成异构注意力掩码：视觉查询的注意力矩阵中视觉-视觉部分设为-∞（softmax后为0），其余部分正常。文本查询不受限制。

  - 预算N可通过手动设定或根据延迟目标调整。
- 训练/推理细节：
  - 训练无关：无需微调或重新训练模型，直接应用于预训练MLLM。
  - 推理前先进行少量样本校准（20个样本）计算VIG，选择跳过层。
  - 推理时每层按修改后的注意力掩码进行前向传播，视觉token在跳过层内仅通过残差连接和FFN更新。
  - 总计算量：跳过层中视觉自注意力成本从O(N_v^2)降至O(N_t^2 + N_t*N_v)，显著减少。

### 16. Multi-FRuGaL: Multimodal Flexible Redundancy-aware Decomposed Gated Learning for Cancer Diagnosis and Prognosis
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.06867v1
- 方法流程：
  - 每个模态通过专用编码器提取特征表示
  - 信号分解层（SD）将每个模态的表示分解为公共分量和特有分量
  - 门控网络（GateNet）基于输入特征生成每个模态的标量权重，经稀疏正则化
  - 掩码感知池化：根据可用模态的权重加权求和得到融合表示，缺失模态不贡献
  - 融合表示输入任务预测头（分类或生存）并计算任务损失、分解损失和LIBR
- 关键模块/机制：
  - Per-modality Encoders：为每个模态（如病理、影像、报告、表格）提取独立特征表示；使用预训练或特定架构编码器，输出固定维度的特征向量
  - Signal Decomposition (SD) Layer：将每个模态特征分解为与冗余模式共享的公共分量和模态特有的分量；通过全连接层或线性变换将输入特征映射到两个正交子空间，公共分量约束为跨模态相似，特有分量鼓励正交性
  - GateNet：根据输入特征动态分配每个模态的权重，选择信息性模态并抑制冗余或噪声；输入为各模态的特征，输出标量权重，经过softmax归一化，并使用L1稀疏正则化促进选择性
  - Mask-aware Pooling：在存在缺失模态时，仅对可用模态进行加和融合，确保融合表示定义良好；将模态权重与对应特征相乘后求和，缺失模态的权重被强制为零
- 公式/目标函数/指标定义：
  - 总损失 L = L_task + λ1 * L_dec + λ2 * L_IBR
  - L_task：二分类交叉熵（或生存分析的cox部分似然）
  - L_dec：分解正交性约束，鼓励公共和特有分量正交，通常为余弦相似度或Frobenius范数正则
  - L_IBR = L_red + L_budget
  - L_red：冗余惩罚，最小化不同模态公共分量之间的相似性度量（如均方误差）
  - L_budget：稀疏预算项，对门控权重施加L1正则化，鼓励少数模态主导
- 算法细节：
  - 门控权重生成：将各模态编码特征拼接输入门控网络，输出K个标量（K为模态数），经softmax得到权重向量
  - 信号分解：对于每个模态，通过两个线性层分别输出公共表示（c）和特有表示（s），并施加正交损失
  - 融合：融合表示 = Σ_i (g_i * (c_i + s_i))，其中g_i为门控权重，若模态缺失则g_i=0
  - 训练时随机丢弃模态（模态dropout）以模拟缺失场景
- 训练/推理细节：
  - 训练中采用随机模态缺失策略（例如以一定概率掩码每个模态），增强对缺失的鲁棒性
  - 门控网络与编码器及分解层端到端联合训练
  - 推理时按实际可用模态计算门控权重和融合表示，无需插补或预定义缺失模式

### 17. DaX: Learning General Pathology Representations Across Scales
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.06983v1
- 方法流程：
  - 数据预处理：将WSI统一重采样至0.5μm/pixel（20×），分割组织前景，提取1920×1920像素patch（步长1280，重叠640），过滤前景比例<2/3的patch，生成2.5×、5×、10×、20×四个锚定放大率的patch池。
  - Stage1 - 多尺度适应训练：在patch池中随机选择放大率（连续采样），构造局部视图（高放大率小裁剪）和全局视图（低放大率大裁剪），应用病理特定增强（颜色抖动、旋转、翻转等），通过DINOv3-style的student-teacher框架进行自监督学习。
  - Stage2 - 输入尺寸与特征稳定训练：使用多输入尺寸（例如1920×1920, 960×960, 480×480），在student-teacher输出上施加Gram锚定密集一致性损失，同时保持第一阶段损失，联合优化。
  - 下游评估：在构建的161个WSI任务上，使用固定病人级交叉验证协议，通过fold级统计排名比较模型性能。
- 关键模块/机制：
  - 连续放大训练模块：实现从低倍到高倍的连续尺度特征学习；在训练时，不从固定的2.5×/5×/10×/20×中离散选择，而是从2.5×到20×的连续范围内随机采样放大率，使模型适应任意中间尺度，增强尺度泛化能力。
  - 跨尺度视图生成模块：连接局部细胞形态与全局组织结构的语义对应；对同一组织区域，构造两个视图：全局视图（低放大率，大视野）和局部视图（高放大率，小视野），且局部视图的视野范围完全包含在全局视图内。通过增大两者放大率差距（例如全局2.5×，局部20×），强制student-teacher对齐不同尺度的语义信息。
  - 病理特异性增强模块：提高对染色、扫描、方向变化的鲁棒性；包括随机颜色抖动（模拟染色变异）、随机旋转（0°/90°/180°/270°）、随机水平/垂直翻转、高斯噪声、对比度调整等，增强模型对采集差异的不变性。
  - 多输入尺寸训练模块：支持不同输入分辨率，适应下游任务不同视野需求；在第二阶段，每次前向传播随机使用三种输入尺寸之一（1920×1920, 960×960, 480×480），模型共享权重，且patch大小固定为16×16，从而token序列长度变化。通过调整位置编码（插值）适应不同尺寸。
  - Gram锚定密集一致性模块：稳定不同输入尺寸下密集token特征的几何结构；对student和teacher的中间层token特征计算Gram矩阵（特征协方差矩阵），要求不同输入尺寸下同一图像区域的Gram矩阵保持一致，作为辅助损失，防止分辨率改变时特征几何漂移。
- 公式/目标函数/指标定义：
  - DINOv3蒸馏损失：ℒ_distill = -∑_i p_teacher_i log(p_student_i)，其中p_teacher和p_student分别为teacher和student网络输出经softmax后的概率分布（含centering和sharpening）。
  - Gram锚定一致性损失：ℒ_gram = ‖G_student - G_teacher‖_F²，其中G为token特征的Gram矩阵（大小为d×d，d为特征维度），在student和teacher的对应层之间计算。
  - 总目标：ℒ_total = ℒ_distill + λ ℒ_gram，λ为平衡权重。
- 算法细节：
  - Student-Teacher框架：teacher网络参数为student的指数移动平均（EMA），无梯度更新。
  - 视图生成：对于每个训练patch，随机选择放大率并裁剪全局视图和局部视图，局部视图尺寸为全局视图的1/4~1/2，且空间位置随机偏移但保持在全局内。
  - Gram矩阵计算：选取ViT中第k个Transformer层的输出token（排除CLS），计算特征矩阵F ∈ R^(n×d)（n为token数，d为通道），Gram矩阵G = F^T F ∈ R^(d×d)，并进行L2归一化。
  - 多输入尺寸训练：位置编码通过双线性插值调整到对应序列长度；Gram一致性损失只在student和teacher输入尺寸相同时施加，不同尺寸时仅使用蒸馏损失。
- 训练/推理细节：
  - 预训练数据：104,569张WSI，来自TCGA、GTEx、HistAI，涵盖多种器官和疾病。
  - 模型架构：ViT-L，patch size 16，DINOv3初始化。
  - 第一阶段训练：固定输入尺寸1920×1920，batch size 4096，学习率1e-4，余弦退火，训练40 epoch。
  - 第二阶段训练：多输入尺寸（1920/960/480），batch size 2048，学习率5e-5，训练20 epoch，λ=0.1。
  - 数据增强：使用imgaug库，包括颜色抖动、旋转、翻转、高斯噪声、对比度调整等。
  - 推理时：可接受任意输入尺寸（需为16的倍数），通过调整位置编码适应，无需额外处理。

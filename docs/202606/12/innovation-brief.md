### 1. The Last Visible Pixel: Probing Fine-Scale Perception in Vision-Language Models
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2606.07861v1
- 方法流程：
  - 输入：预定义的字母、动物图标、形状、色块、方块等模板，或自然场景图像中的英文单词
  - 处理1（合成画布）：在白色背景上渲染目标对象，通过矢量图形精确控制像素尺寸（4-48px）
  - 处理2（文字叠加）：将英文单词叠加到真实场景图像上，使用自然背景作为干扰
  - 输出：生成标准的448×448 RGB图像，并附带任务标签（感知/推理）、像素尺寸、问题文本和金标准答案
  - 任务分配：感知分6类（LTR, ANM, SHP, BLK, CBL, TXT），推理分6类（CHR, CMP, CNT, BLR, TRD, TCT）
- 关键模块/机制：
  - 可控合成画布生成器：生成无背景干扰的纯视觉样本，精确控制目标像素大小；使用矢量图形（如动物图标）而非真实照片，确保在极端缩放下仍保留可识别的形状特征；渲染于白色背景上，通过缩放函数将目标尺寸映射到4-48px
  - 文字叠加生成器（Text-in-the-Wild）：模拟真实场景视觉干扰下的细粒度文字感知；从自然场景图像中选取背景，将英文单词以随机位置和颜色叠加到图像上，保持目标文字像素尺寸在4-48px范围内
  - 感知任务集：评估单目标像素级识别能力；包含6个任务：字母识别（LTR）、动物识别（ANM）、形状识别（SHP）、方块存在检测（BLK）、色块颜色识别（CBL）、文字识别（TXT）；每个任务700样本，覆盖7个像素尺寸，每尺寸100样本
  - 推理任务集：评估多目标链式推理能力（计数、排序、空间关系）；包含6个任务：链式推理（CHR）、比较链式推理（CMP）、计数链式推理（CNT）、模糊链式推理（BLR）、文字阅读（TRD）、文字计数（TCT）；每个任务约653样本
  - 双推理设置：统一评估框架，减少实现差异；使用Hugging Face Transformers统一推理，bfloat16精度；三种解码策略：确定性解码（无采样）、低温采样（T=0.1）、高温采样（T=1.0）；max_new_tokens=1024，其他参数用默认值
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 数据生成：对合成画布，根据任务类型（字母/动物/形状等）从预定义库中选取模板，通过矢量缩放调整到目标像素尺寸，然后渲染到448×448白色画布上；对文字叠加，从自然场景图像中随机截取区域，使用PIL将英文单词以合适字体大小叠加，确保文字像素尺寸在目标范围内
  - 任务生成：为每个样本自动生成问题文本（例如“What letter is in the image?”）和金标准答案（如“A”），避免使用系统提示或few-shot示例
  - 推理设置：所有模型在相同框架下评估，仅通过temperature控制随机性；对于GLM-4.6V-Flash这类推理模型，保留其思维链输出但仅解析最终答案

### 2. OpenMedReason: Scientific Reasoning Supervision for Medical Vision-Language Models
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2606.12169v1
- 方法流程：
  - 数据构建：从生物医学科学文章中提取约450K图像-问题-答案-推理轨迹实例，覆盖放射学、病理学、可见光照片、图表等多种模态
  - SFT阶段：使用OpenMedReason语料库（约193K本数据加上其他公开VQA/分类数据集共446K样本）对Qwen2.5-VL-7B-Instruct进行LoRA微调，冻结视觉塔，训练3个epoch，学习率1e-4，批量64
  - GRPO阶段：从SFT检查点初始化，使用混合医学VQA训练集（5,120个样本，其中3,000来自OpenMedReason，其余来自公开基准），训练模型生成结构化推理轨迹，通过格式奖励和答案正确性奖励进行优化，KL系数0.04，不对称信任区域epsilon=0.20, epsilon_high=0.28
  - 推理阶段：模型输出<think>推理过程</think><answer>答案</answer>，通过解码时采样多样性（Pass@k）评估可靠性
- 关键模块/机制：
  - 推理轨迹提取模块：从科学文章中提取推理链，提供高保真监督信号；利用经筛选的生物医学科学文章中的推理过程，而非LLM生成的思维链，确保推理轨迹的临床相关性和准确性；覆盖多种医学影像模态和临床场景。
  - 结构化推理格式：规范模型输出，便于奖励计算和评估；模型生成格式为<think>...</think><answer>...</answer>的推理轨迹，其中<think>块包含推理过程，<answer>块包含最终答案。
  - GRPO优化器：通过可验证奖励优化模型策略；使用dr_grpo损失函数（token级重要性采样），奖励组合包括格式奖励（正确标记结构+1，错误标记惩罚）和答案正确性奖励（精确匹配+2）；采用KL系数β=0.04锚定SFT先验，不对称信任区域限制低概率token放大。
  - OpenMedReason-Bench评估平台：细粒度诊断模型在感知、医学知识和推理三个轴上的能力；为每个轴计算存在率（Pres.）和正确率（Corr.），轴分数=Pres.×Corr.，推理轨迹分数为三个轴分数的未加权平均；提供答案准确率作为辅助指标。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
  - 轴分数 = 存在率 × 正确率（Pres. × Corr.）
  - 推理轨迹分数 = (感知轴分数 + 医学知识轴分数 + 推理轴分数) / 3
  - 格式奖励：+1.0 for 一个<think>块，+1.0 for 一个<answer>块，-2.0 重复标签或标签顺序错误，-1.0 标签未闭合
  - 答案正确性奖励：+2.0 规范化答案与真实标签完全匹配，否则0.0
  - KL散度惩罚：β=0.04
- 算法细节：
  - LoRA微调：仅适应语言层（attention和MLP），rank=128，alpha=256，dropout=0，视觉塔冻结
  - GRPO训练：per-device batch size=1，梯度累积=8，每个prompt生成8个响应，序列预算8192 tokens（prompt max 3072，completion max 2048），学习率1e-6，权重衰减0.1，热身比例0.1，梯度裁剪0.5
  - 不对称信任区域：epsilon=0.20, epsilon_high=0.28，限制低概率token的放大
  - SFT数据混合：OpenMedReason（193K）、PMC-VQA（114K）、VinDr-CXR等共446K样本
  - GRPO数据：5,120个样本（3,000来自OpenMedReason，2,000来自PMC-VQA，其余来自SLAKE/RadVQA/PathVQA各40），均未在SFT中使用
- 训练/推理细节：
  - SFT：使用AdamW优化器，学习率1e-4，权重衰减0.01，线性热身前5%步数，训练3个epoch，有效批量64，最大序列长度8192，两张NVIDIA H200 GPU，耗时24小时
  - GRPO：基于TRL的GRPO训练器，从SFT LoRA适配器初始化，bfloat16精度，20小时
  - 推理时使用结构化格式<think>...</think><answer>...</answer>
  - 评估：在7个VQA基准和7个分类基准上测试，使用Pass@1和Pass@10评估推理可靠性

### 3. Unification of Closed-Open Industrial Detection Scenarios: New Large-Scale Benchmarks,Challenges and Baselines
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.07953v1
- 方法流程：
  - 输入: 工业图像和文本描述（类别）。
  - 专家辅助域投影: 使用预训练专家编码器将工业图像映射到低维域特征空间，快速适应工业分布。
  - 能量稀疏采样: 对分割特征图进行能量激活，计算不确定性分数，基于稀疏策略选取高置信度像素作为视觉提示。
  - 双向文本-视觉交互: 将视觉提示与文本提示通过交叉注意力模块进行双向融合，得到语义增强的提示嵌入。
  - 提示嵌入输入Mobile-SAM: 生成最终分割掩码/检测框。
- 关键模块/机制：
  - 专家辅助域投影：将通用视觉模型快速适应工业领域，减少域差异。；利用工业缺陷专家模型（如预训练的缺陷分类网络）将输入图像编码为低维域特征，并与Mobile-SAM的图像编码器特征进行对齐/融合，使模型关注工业相关特征。
  - 基于能量的稀疏采样：自动生成精细视觉提示，避免手动标注噪声。；对专家投影后的特征图计算能量值（如负对数似然），根据能量阈值筛选出高不确定性区域作为候选，再通过稀疏采样策略（如Top-k选择）得到少量关键像素位置作为视觉提示点。
  - 双向文本-视觉交互：增强文本和视觉模态的语义对齐，提升对细粒度缺陷的理解。；设计交叉注意力模块，视觉提示与文本嵌入相互作为查询和键值，进行双向交互，输出融合后的提示嵌入，用于引导Mobile-SAM解码。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 能量激活: 对于像素级特征，计算能量 E(x) = -log(∑_c e^{f_c(x)})，其中f_c是类别c的logit。
  - 稀疏采样: 根据能量值排序，选择能量最低（最不确定）的K个像素作为视觉提示点。
  - 双向交互: 视觉提示通过线性投影得到V_query，文本嵌入通过线性投影得到T_query，交叉注意力计算V_query与T_key、T_query与V_key，然后拼接融合。
- 训练/推理细节：
  - 基于Mobile-SAM进行微调，冻结部分编码器，仅训练专家投影模块和交互模块。
  - 使用MMIOC-1M数据集进行预训练或微调，支持开放词汇和封闭集检测。
  - 推理时无需手动提示，自动采样视觉点并融合文本，输入Mobile-SAM生成分割结果。

### 4. Robust-U1: Can MLLMs Self-Recover Corrupted Visual Content for Robust Understanding?
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08063v1
- 方法流程：
  - Stage I - 监督微调：输入损坏图像Ic和恢复提示Prec，在BAGEL上使用rectified flow损失（公式3）微调，输出恢复图像Ir。
  - Stage II - 强化学习：使用Flow-GRPO，以像素级SSIM（公式4）和语义级CLIP相似度（公式8-9）作为双奖励，优化自恢复模块，输出高质量恢复图像Ir。
  - Stage III - 多模态推理：将损坏图像Ic和恢复图像Ir作为交错输入，与文本查询Q一起训练模型（公式10），输出最终答案A。
- 关键模块/机制：
  - 自恢复模块 D^{-1}：将损坏图像恢复为干净图像；基于BAGEL统一MLLM，使用rectified flow训练，通过噪声预测网络ϵΘ在潜在空间中预测噪声，从而近似逆映射。
  - 像素级结构奖励：促进恢复图像在像素级结构上与干净图像相似；使用SSIM计算局部patch的亮度、对比度、结构相似性，公式(4)-(7)，输出[0,1]标量奖励。
  - 语义一致性奖励：确保恢复图像在语义上与干净图像一致；使用冻结的CLIP模型提取图像嵌入，计算余弦相似度（公式8），再经指数变换（公式9）得到奖励，衰减语义偏差。
  - 多模态推理模块：联合损坏图像和恢复图像进行鲁棒回答；输入为[Ic, Ir, Q]的交错序列，训练模型自回归生成答案，目标为最大化条件概率（公式10）。
- 公式/目标函数/指标定义：
  - SFT损失：L_SFT = E_{t~U(0,1), ε~N(0,I)} [||ε - ε_Θ(Z_c, Z_o(t), t, P_rec)||^2] （公式3）
  - 像素级SSIM奖励：R_pix = SSIM(I_r, I_o) = (1/N) Σ [l(p_r, p_o)·c(p_r, p_o)·s(p_r, p_o)] （公式4）
  - 语义相似度：Sim = cos(M_CLIP(I_r), M_CLIP(I_o)) （公式8）
  - 语义奖励：R_sem = exp(-α·(1 - Sim)) （公式9）
  - 多模态推理目标：L_MLLM = -E [Σ log P_Θ(a_t^* | a_{<t}^*, I_c, I_r, Q)] （公式10）
- 算法细节：
  - 自恢复模块使用rectified flow：先将图像编码为潜在Z_c，然后对干净潜在Z_o加噪得到Z_o(t)，模型预测噪声ε，通过公式3训练。
  - 强化学习使用Flow-GRPO：对每个损坏图像采样G条轨迹（通过将确定性ODE转为SDE），计算组内每个恢复图像的复合奖励（R_pix + λ R_sem），通过组归一化计算优势，策略更新受KL散度约束。
  - 多模态推理阶段：输入序列为[图像Ic, 图像Ir, 文本Q]，模型按自回归方式生成答案，损失为交叉熵。
- 训练/推理细节：
  - 训练分三阶段：SFT在ImageNet-C上，RL在Robust-R1训练数据上，多模态推理在Robust-R1推理链数据上。
  - 推理时：先通过自恢复模块（输入Ic和Prec）生成Ir，然后将Ic和Ir与Q一起输入模型生成答案。
  - SFT阶段优化噪声预测网络，RL阶段优化自恢复模块参数，多模态推理阶段优化整个模型（冻结自恢复模块？未明确，但通常联合训练或仅训练推理部分）。

### 5. Are Reasoning Vision-Language Models Robust to Semantic Visual Distractions?
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08894v1
- 方法流程：
  - 阶段1: 原始样本收集 - 从MathVision、MathVista、MMMU等基准收集800个图像-问题样本。
  - 阶段2: 专家种子干扰设计 - 人类标注者针对每个样本添加满足四个条件的语义干扰，生成100个种子示例及解释。
  - 阶段3: 可扩展合成编辑 - 利用GPT-5.5基于种子示例生成编辑指令，再利用GPT-Image2根据原图和指令合成添加干扰后的图像。
  - 阶段4: 人工质量验证 - 人工审核确保添加的干扰事实正确、与问题无关且不改变正确答案。
- 关键模块/机制：
  - 种子干扰设计模块：定义高质量的语义干扰模板和约束条件；人类标注者检查图像和问题，添加满足四个条件的干扰：1) 包含明显语义信息；2) 事实正确且视觉合理；3) 与查询无关，不影响正确答案；4) 可选地引导向错误答案。并记录干扰的描述和潜在误导效果。
  - 可扩展合成编辑模块：基于种子示例大规模生成带干扰的图像；使用GPT-5.5对每个种子总结原图、编辑图和干扰效果，构建知识库；对剩余样本，GPT-5.5描述图像并检索最相关的三个种子作为上下文示例，生成详细编辑指令（含干扰内容、位置、视觉风格和布局约束）；然后调用GPT-Image2根据原图和指令生成编辑后的图像。

- 算法细节：
  - 检索引导的合成编辑：利用GPT-5.5从种子示例知识库中检索最相关的三个示例作为少样本提示，生成针对新样本的编辑指令。
  - GPT-Image2根据编辑指令在原图上添加干扰，保持原始内容不变。

### 6. Almieyar-Oryx-BloomBench: A Bilingual Multimodal Benchmark for Cognitively Informed Evaluation of Vision-Language Models
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.05531v1
- 方法流程：
  - 1. 定义层次化分类法：将Bloom六大认知层次（Remember, Understand, Apply, Analyze, Evaluate, Create）进一步分解为子层次和具体任务类型（如Remember包含事实回忆、视觉回忆等）
  - 2. 半自动数据生成：使用LLM（如GPT-4）根据层次定义和图像生成问题-答案对，辅以人工模板和编辑，保证覆盖度
  - 3. 质量保证协议：采用分层混合验证：首先用LLM-as-a-judge（Gemini 3 Pro）自动检查，然后对代表性子集进行人工验证，确保认知对齐、语言准确和文化适当
  - 4. 数据集构建：生成约[具体数量未给出]个双语（英-阿）样本，每个样本包含图像、问题、正确答案和认知层次标签
  - 5. 模型评估：在数据集上评估多种SOTA VLM，使用基于答案（exact match/LLM评判）和基于似然（模型自信度）两种评估方法

### 8. Mechanistic Insights into Functional Sparsity in Multimodal LLMs via CoRe Heads
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.05843v1
- 方法流程：
  - 阶段1: 统一RAM检测框架: 根据模型架构类型（Adapter压缩、确定性扩展、动态高分辨率预处理）将目标视觉实体映射到相应的token索引集合V*；
  - 阶段2: 单次前向与RAM计算: 使用自定义动态KV缓存，仅执行前向传播（不计算logits），获取每层每头的Q和K，计算全局注意力概率A(l,h)，然后对每个头聚合V*上的概率得到RAM[l,h]；
  - 阶段3: CoRe头部排序与加速配置: 根据RAM分数对所有注意力头排序，选取top-k作为CoRe heads (H_dense)，其余为H_sparse；
  - 阶段4: 预填充混合注意力前向: 对H_dense使用标准全局注意力，对H_sparse使用流稀疏注意力（局部窗口w+四个注意力sinks），解码阶段恢复标准注意力。
- 关键模块/机制：
  - Retrieval Attention Mass (RAM) 指标：定量衡量每个注意力头对查询相关视觉实体的关注程度；对于给定层l和头h，RAM[l,h] = sum_{j in V*} A(l,h)[:,j]，其中A(l,h)为softmax后的注意力概率矩阵，V*为目标视觉实体对应的token索引集合。
  - CoRe heads：高度专用的注意力头，负责跨模态信息提取；基于RAM分数排序，通常top 5%的头为CoRe heads；因果干预表明这些头对多模态推理性能至关重要，而移除低排名头影响很小。
  - 头级混合注意力机制 (Head-level Hybrid Attention)：加速预填充阶段的attention计算；将头分为两组：H_dense（top-k CoRe heads）使用标准全局注意力；H_sparse（其余头）使用流稀疏注意力，即每个查询只关注局部窗口[i-w, i+w]和少量初始attention sinks（4个）。该机制仅在预填充阶段应用，解码阶段恢复标准注意力。
- 公式/目标函数/指标定义：
  - RAM[l,h] = sum_{j in V*} softmax(Q(l,h) * K(l,h)^T / sqrt(d_head))[i,:] 对目标token索引j聚合
- 算法细节：

  - 算法3: CoRe引导混合注意力前向: ①获取Q、K、V；②判断是否预填充（序列长度>1）；③若是，根据预计算的该层密集头集合H_dense设置head_mask；④调用block_streaming_attn_func，传入head_mask、窗口大小和注意力sinks数量，执行混合注意力；⑤输出投影。
- 训练/推理细节：
  - RAM检测只需一次前向传播，不计算语言模型logits，无需训练。
  - 加速机制仅在预填充阶段应用混合注意力，解码阶段因序列长度为1使用标准FlashAttention。

  - 子集和查询生成：枚举所有子集S⊆N；生成逻辑查询空间Q（包含AND/OR/NOT组合，如A∧B, ¬A等）。

  - 对齐分数计算：对每个查询q∈Q，计算λq(S)与f(X_S)在所有S⊆N上的Pearson相关，得到rX(q,f)。
  - 符号表示构建：将每个样本的对齐分数向量化ϕ(X)=[rX(q1,f), ..., rX(q|Q|,f)]，形成符号表示空间。
  - 下游分析：局部分析（选择最佳查询q*(X)=argmax rX(q,f)）或全局分析（对ϕ(X)进行聚类）。
- 关键模块/机制：
  - 语义映射M：将每个补丁实例映射到语义概念（如Tumor, Normal, Mix），作为构建子袋和查询的基础。；对于Camelyon16，根据补丁中肿瘤像素比例ρ定义：ρ=0为Normal，ρ=1为Tumor，0<ρ<1为Mix。

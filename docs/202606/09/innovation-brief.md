### 1. A Vision-language Framework for Comparative Reasoning in Radiology
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.06407v2
- 方法流程：
  - 报告分解：将常规放射学报告解析为结构化描述，提取解剖结构、异常发现和病理状态三种实体。
  - 数据构建：基于实体描述构造排序三元组（查询图像/实体、正例、负例）和比较视觉问答（VQA）实例（图像对、实体、问题、答案）。
  - MedReCo预训练：使用排序三元组进行文本引导的对比学习，训练实体感知视觉编码器（MoE ViT + 实体编码器），输出实体条件图像嵌入。
  - MedReCo-VLM指令微调：固定MedReCo视觉编码器，通过交叉注意力将实体条件视觉特征输入大语言模型，使用比较VQA数据微调LLM以生成比较性描述。
- 关键模块/机制：
  - MoE ViT (混合专家视觉Transformer)：作为模态感知的视觉编码器，处理不同成像模态（X光、CT、MRI、超声）的异构性。；采用Mixture-of-Experts结构，每个专家专门处理特定模态或特征，通过门控网络动态选择专家，输出统一的视觉特征序列。
  - 实体编码器 (Entity Encoder)：将目标实体（解剖结构、异常发现、病理状态）的文本描述编码为条件向量，引导视觉注意力。；使用预训练文本编码器（如PubMedBERT）将实体名称或描述映射为嵌入向量，然后通过交叉注意力或条件调制作用于视觉特征，突出与实体相关的图像区域。
  - 对比排序模块 (Contrastive Ranking)：学习实体条件视觉表示，使得相同实体下相似图像的特征距离更近。；对每个查询（图像+实体），从候选集中采样正例（同实体）和负例（不同实体），使用三元组对比损失优化：L = max(0, d(q,p) - d(q,n) + margin)，其中d为余弦距离。
  - 大语言模型 (LLM) 与交叉注意力：MedReCo-VLM中用于生成比较性自然语言描述。；将MedReCo输出的实体条件视觉特征通过交叉注意力层注入LLM（如Llama或Vicuna），在指令微调阶段使用比较VQA数据（图像对、实体、问题、答案）训练LLM生成答案。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式，但可推断使用三元组对比损失：L_triplet = max(0, d(q,p) - d(q,n) + margin)，其中d为余弦相似度或欧氏距离。
- 算法细节：
  - 检索算法：给定查询图像和实体，提取实体条件视觉嵌入，与候选库中所有图像的计算余弦相似度，按相似度降序排名，输出Top-K。
  - 门控机制：MoE ViT中的门控网络根据输入模态的统计特征（如像素分布、分辨率）选择激活的专家子集，每个专家处理部分patch。
  - 实体条件注意力：在视觉Transformer中，将实体编码作为可学习的查询（Query）或键值（Key）的偏置项，通过交叉注意力模块聚合与实体相关的视觉标记。
  - 推理时多模态融合：MedReCo-VLM将当前图像和先前图像分别通过MedReCo编码，得到两个实体条件视觉序列，拼接后通过交叉注意力输入LLM。
- 训练/推理细节：
  - MedReCo训练：使用排序三元组，每个批次包含多个查询，每个查询对应一个正例和多个负例（hard negative mining），优化对比损失。
  - MedReCo-VLM训练：分两阶段，第一阶段冻结MedReCo视觉编码器，仅训练交叉注意力适配器和LLM；第二阶段低秩适应（LoRA）微调LLM。
  - 推理：检索时仅需MedReCo编码器，生成时需要MedReCo编码器和LLM，输入图像对和实体。
  - 数据增强：同一患者的多次检查可构造时间比较样本；不同患者的相同实体可构造参考比较样本。

### 3. CheXanatomy: Anatomy-Aware Vision-Language Modeling for Chest Radiographs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08420v1
- 方法流程：
  - 1. 合成数据生成：从CT-RATE数据集获取CT体积，使用TotalSegmentator进行多结构3D分割，通过Diff-DRR前向投影生成2D DRR图像和对应的2D分段标签，并将掩码编码为VQ-VAE离散token。
  - 2. 模型配置：基于PaliGemma 2（SigLIP-So400m视觉编码器+Gemma 2语言模型），输入图像和文本提示（如“Segment the heart”），输出为16个mask token。
  - 3. 训练：使用LoRA进行参数高效微调，优化目标为下一个token预测的交叉熵损失，仅基于token空间优化。
  - 4. 推理：输入图像和文本提示，模型自回归生成16个离散token，由VQ-VAE解码器转换为二进制掩码。
  - 5. 评估：在合成数据（CT-RATE测试集）和真实数据（CheXmask、VinDr-RibCXR）上计算Dice、IoU、Hausdorff距离、Fourier描述子距离，并与U-Net基线对比。
- 关键模块/机制：
  - PaliGemma 2 VLM：骨干网络，接受图像和文本输入，生成结构化空间输出（掩码token）。；包含SigLIP-So400m视觉编码器（通过线性投影映射到语言token空间）和Gemma 2大语言模型。输出为16个表示分割掩码的离散token，支持自回归预测。
  - VQ-VAE (向量量化变分自编码器)：将二进制分割掩码编码为16维离散潜码，并解码回掩码。；预训练阶段将二进制掩码压缩到16个离散token的潜空间（每个token来自学习码本）。训练时VLM预测这些离散token，推理时VQ-VAE解码器将预测的token转换为二进制掩码。
  - LoRA (低秩适应)：参数高效微调，减少可训练参数数量。；在VLM的注意力权重上添加低秩矩阵（秩未知，但遵循标准LoRA），保持大部分预训练权重固定。两种配置：视觉编码器冻结或更新。
  - Diff-DRR (可微数字重建放射影像)：从CT体积生成合成X光片。；使用可微射线投影算法，将CT体积前向投影到2D，生成DRR图像。从每个CT体积生成PA和侧位两个投影。
  - TotalSegmentator：从CT体积生成多结构3D分割标签。；自动分割80个解剖目标，包括骨骼、肺、心脏、大血管、上腹部器官等。3D标签通过前向投影得到2D掩码。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式，仅提及使用标准下一个token预测的交叉熵损失进行优化。
  - VLM训练目标：minimize -log P(token_sequence | image, text_prompt)
- 算法细节：
  - 合成数据生成：对每个CT体积，使用Diff-DRR生成前后位和侧位DRR；同时将TotalSegmentator输出的3D标签沿相同射线方向投影得到2D二进制掩码；将2D掩码用VQ-VAE编码器转换为16个离散token（每个token为码本索引）。
  - 训练数据构建：每个样本包含DRR图像、文本提示（如“Segment the lung”）、以及对应的16个mask token序列。
  - VLM自回归预测：输入图像通过视觉编码器得到图像嵌入，与文本提示的token嵌入拼接后输入Gemma 2；模型逐token预测16个mask token（采用teacher forcing）；损失函数为预测token与真实token的交叉熵。
  - 推理阶段：模型自回归生成16个token（使用argmax采样），然后由VQ-VAE解码器重建为二进制掩码（分辨率与输入图像相同）。
  - LoRA微调：仅更新低秩矩阵，视觉编码器可选冻结或全参数更新。
- 训练/推理细节：
  - 训练使用8块H100 GPU，批次大小根据模型规模和分辨率调整：10B模型、448x448时批次为8；3B模型、224x224时批次为24。
  - 优化器及超参未明确，但采用标准自回归训练流程。
  - 输入分辨率支持224x224和448x448两种。
  - 模型规模为3B和10B参数（指PaliGemma 2模型大小）。
  - 微调采用LoRA，视觉编码器可选择冻结（参数更少）或更新（更多参数）。
  - 推理时，模型单次前向生成16个mask token，不需要额外后处理。

### 4. Active Source-free Domain Adaptation in Open-set Medical Image Segmentation via Decomposed Uncertainty and Prototype Discrepancy
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08749v1
- 方法流程：
  - 阶段1: 主动开放集查询策略：对每个无标签目标样本，应用测试时增强(TTA)生成增强变体；计算类感知偶然不确定性(CAU)和类感知认知不确定性(CEU)得到CDU分数；计算类无关原型差异(CPD)分数，综合CDU和CPD选择Nl个样本进行标注
  - 阶段2: 目标细化自训练：用标注样本全监督训练模型；用训练后的模型对未选样本生成并细化伪标签；将标注样本和伪标签样本结合进行半监督训练
- 关键模块/机制：
  - 类感知分解不确定性（CDU）：评估样本对于未知类的信息量，结合偶然不确定性和认知不确定性；通过测试时增强（TTA）生成多个增强变体，计算每个变体对未知类的预测熵和能量方差；CAU = 平均预测熵；CEU = 能量方差；CDU = 归一化CAU + 归一化CEU
  - 类无关原型差异（CPD）：选择多样且具有代表性的高不确定性样本；用低CDU样本的特征作为原型（源知识），高CDU样本作为候选；计算候选与所有原型的平均余弦距离作为跨域差异（CDD）；计算候选与其他候选的平均余弦距离作为自域差异（SDD）；CPD = CDD + SDD
  - 目标细化自训练：生成高质量伪标签，利用未选样本进行半监督训练；先全监督训练模型（用标注样本），然后用该模型对未选样本生成伪标签并细化；最后结合标注和伪标签进行半监督训练，损失函数为 L = L_sup + L_unsup
- 公式/目标函数/指标定义：
  - CAU(x_u) = (1/(1+m)) * [H(x_u) + sum_{j=1}^m H(x_u^j)]，其中H为未知类的预测熵
  - CEU(x_u) = (1/(1+m)) * [(E(x_u)-Ē)^2 + sum_{j=1}^m (E(x_u^j)-Ē)^2]，其中E为未知类的能量，Ē为平均能量
  - CDU(x_u) = Norm(CAU(x_u)) + Norm(CEU(x_u))
  - CDD(x_u) = (1/K) * sum_{j=1}^K (1 - (H_u · L_j)/(||H_u|| ||L_j||))
  - SDD(x_u) = (1/(K-1)) * sum_{i=1}^{K-1} (1 - (H_u · H_i)/(||H_u|| ||H_i||))
  - CPD(x_u) = CDD(x_u) + SDD(x_u)
- 算法细节：
  - 查询策略：对每个未标注样本，先通过TTA生成m个增强变体，计算CDU和CPD，根据分数排序选择前Nl个样本
  - 原型构建：从低CDU样本中随机选取K个样本的特征作为原型
  - 候选选择：从高CDU样本中选取K个样本的特征作为候选
  - 伪标签生成：先用标注样本全监督训练一个epoch，然后用该模型对未选样本预测，经细化后得到伪标签
- 训练/推理细节：
  - 初始化阶段：用源数据预训练分割模型F(Θ)
  - 查询阶段：固定模型参数，计算每个目标样本的CDU和CPD，选出Nl个样本进行人工标注
  - 适应阶段：先全监督训练（用标注样本），再生成伪标签，最后半监督训练（标注+伪标签），损失函数为L_sup + L_unsup
  - 测试时增强（TTA）：包括翻转、旋转、亮度变换、对比度变换、高斯噪声等

### 5. A multi-agent system for spine MRI report generation from multi-sequence imaging
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08897v1
- 方法流程：
  - 阶段1：独立预训练T1和T2编码器（DINOv3，含KoLeo损失和iBOT损失）
  - 阶段2：Gram锚定额外训练30轮，增强密集特征
  - 阶段3：CLIP对比学习对齐图像-文本嵌入（T1和T2编码器+BiomedBERT语言编码器）
  - 阶段4：合成器持续训练（使用完整非限制数据集优化视觉编码器+合成器，再结合报告进行CLIP对齐）
  - 阶段5：LLaVA两阶段微调（阶段1冻结编码器和LLM，仅训练注意力池化投影器；阶段2冻结编码器，用LoRA微调LLaMA-3.1-8B）
  - 推理时：提取T1/T2及任意序列的切片级嵌入，经合成器融合为序列级嵌入，再聚合为患者级嵌入，用于下游分类/定位/检索/报告生成
- 关键模块/机制：
  - T1/T2 DINOv3编码器：独立提取T1和T2加权MRI序列的视觉特征；基于ViT架构，分别用4,501,930张T1切片和4,519,538张T2切片（含STIR和Dixon）预训练，采用DINOv3框架，损失函数包含LDINO、LiBOT和λ×LKoLeo（公式1），额外引入4个注册token和Gram锚定损失LGram。
  - 合成器（Synthesizer）：处理非T1/T2序列，生成序列无关嵌入；在编码器每一层计算融合权重，通过加权和组合T1和T2中间表示，实现逐层路由决策。训练时先全数据集优化编码器+合成器，再参与CLIP对齐。
  - CLIP图像-文本对齐：对齐视觉和文本嵌入；使用BiomedBERT作为文本编码器，对比损失LCLIP（公式2）训练5轮，全局batch size 512，温度τ可调。
  - 注意力池化投影器：将变长切片嵌入映射为固定数量图像token；将T1和T2序列嵌入拼接后，通过注意力池化聚合为固定数量token，再与文本token拼接输入LLM。
  - LLaMA-3.1-8B语言解码器：生成结构化报告；采用LoRA微调（秩参数未指定），学习率2e-5，训练4轮，结合VQA数据集（含长答案、短答案、选择题、报告生成四种任务）。
- 公式/目标函数/指标定义：
  - L_SpineFM = L_DINO + L_iBOT + λ × L_Koleo（公式1）
  - L_CLIP = -1/2N [ Σ log exp(cos(f_k,g_k)/τ)/Σ exp(cos(f_k,g_j)/τ) + Σ log exp(cos(f_k,g_k)/τ)/Σ exp(cos(f_j,g_k)/τ) ]（公式2）
  - cos(·,·)为余弦相似度
  - τ为温度参数，控制相似度缩放
- 算法细节：
  - DINOv3预训练采用自蒸馏和iBOT掩码图像建模，额外使用Gram锚定损失以保持密集特征
  - 合成器在每个ViT层计算融合权重，实现层次化路由；训练分两步：先单独优化视觉编码器+合成器，再结合报告进行CLIP对齐
  - CLIP训练使用梯度累积32步达到有效batch size 512
  - LLaVA两阶段训练：第一阶段仅训练投影器2轮（lr=1e-3），第二阶段用LoRA微调LLM 4轮（lr=2e-5）
  - 多智能体整合：37个专业智能体输出分类、定位、检索等结果，以结构化token形式输入报告生成智能体
- 训练/推理细节：
  - T1编码器预训练：batch size=100，4张A100-80GB，150轮（187,500迭代）
  - T2编码器预训练：同T1配置
  - Gram锚定额外训练30轮
  - CLIP训练：4张A100，每GPU batch size=4，梯度累积32步得全局batch size=512，训练5轮
  - 合成器训练：先在全数据集优化视觉编码器+合成器（无特定序列限制），再进行CLIP对齐
  - LLaVA阶段1：冻结编码器和LLM，仅训练投影器2轮，lr=1e-3，全局batch size=32，有效batch size=128

### 6. PACT: Learning Diverse Diagnostic Strategies via Privileged Synthesis and Branch Consensus
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08938v1
- 方法流程：
  - DPS数据合成: 输入完整EMR，将其分割为患者可见状态s_vis和特权临床状态s_priv；利用两个角色（医生和患者）基于各自信息生成多轮对话；经过医生监督器和患者监督器的PASS-OR-REWRITE验证，输出四种推理范式（Serial, Tree, Heap, Feedback）的对话数据。
  - PACT训练: 初始化一个基础LLM，对每个推理范式训练一个独立的LoRA分支；每隔K步，通过符号共识算法（修剪、符号选举、均值合并）将所有分支聚合为一个全局锚点；使用L1正则化约束分支参数与锚点之间的差异；训练结束后，仅部署锚点模型作为单LoRA模型。
- 关键模块/机制：
  - DPS数据合成模块：生成符合医生-患者信息不对称的、多范式的诊断对话数据；将EMR分为s_vis和s_priv；医生角色仅基于对话历史和s_vis生成问题，患者角色基于s_vis生成回答；医生监督器基于完整EMR验证医生问题是否合理，患者监督器基于s_vis验证患者回答是否一致；通过PASS-OR-REWRITE机制修正不合格输出。
  - LoRA分支模块：每个推理范式对应一个LoRA适配器，负责学习该范式的特定知识；每个分支是一个低秩矩阵，加到预训练模型的自注意力或前馈层权重上；不同分支共享基础预训练权重，仅更新各自的LoRA参数；训练时每个分支仅在其对应范式的数据上计算损失。
  - 符号共识聚合模块（Sign-Consensus Merging）：将多个分支的LoRA参数合并为单一共享锚点；包含三个步骤：修剪（Trim）——丢弃绝对值小于一定阈值的参数；符号选举（Sign Elect）——对每个参数，统计所有分支更新方向的符号，取多数符号作为锚点符号；合并（Merge）——对保留的参数，取所有分支中具有相同符号的参数的均值作为锚点参数。
  - L1正则化约束：防止分支在聚合之间漂移过远；在训练损失中添加L1惩罚项，计算当前分支参数与上一次锚点参数之间的绝对差之和，促使分支参数接近锚点。
- 公式/目标函数/指标定义：
  - 目标函数: max_π P(d̂ = d* | τ_T; π), 其中τ_T为最多T轮对话历史，d*为真实诊断。
  - PACT总损失: L_total = L_task + λ * ||Δ_branch - Δ_anchor||_1, 其中Δ_branch为分支LoRA参数，Δ_anchor为锚点参数，λ为超参数。
  - 符号共识合并: Δ_anchor = Merge(Trim({Δ_i})), 其中Trim保留top-k%绝对值或阈值以上的参数，Merge对每个位置取多数符号并计算同符号参数的均值。
- 算法细节：
  - 符号共识合并算法: 1) 修剪: 对每个分支的LoRA参数Δ_i，保留绝对值最大的p%个参数，其余置零。2) 符号选举: 对每个参数位置，计算所有分支中非零参数的符号，取出现次数最多的符号作为锚点符号；若正负平局，则选择零。3) 合并: 对每个参数位置，取所有分支中与该位置锚点符号相同的参数值的均值作为锚点参数。
  - 周期聚合: 每K个训练步（如50步）执行一次聚合，聚合后锚点成为下一轮所有分支的初始点。
- 训练/推理细节：
  - 训练: 各分支独立训练，每个batch采样一个范式，更新对应分支；每隔K步同步所有分支参数并执行符号共识合并；合并后锚点覆盖所有分支参数。
  - 推理: 仅使用最终锚点模型（单LoRA），无需路由或集成，推理成本与单LoRA相同。

### 10. Phase Marginalization for Patch-Grid Instability in Vision Transformers
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.08132v1
- 方法流程：
  - 1. 定义相位偏移集合Φ_K（例如K=4时，偏移量为(0,0), (0,P/2), (P/2,0), (P/2,P/2)）
  - 2. 对每个相位ϕ_k，应用相位偏移算子S_ϕ_k（采用反射填充和裁剪）得到偏移后的图像
  - 3. 将偏移后的图像送入冻结的编码器f_θ和密集预测头h，得到logit图z_ϕ_k
  - 4. 对每个z_ϕ_k应用逆对齐算子A^{-1}_ϕ_k：将patch输出重塑为光栅patch网格，双线性上采样到填充图像分辨率（align_corners=False），再按反向相位偏移裁剪回原始H×W尺寸
  - 5. 对所有逆对齐后的logit取平均得到最终预测¯z(p)=1/K ∑_k A^{-1}_ϕ_k(z_ϕ_k)(p)
- 关键模块/机制：
  - 相位偏移算子 S_ϕ：改变patch网格相位，生成相位偏移后的输入图像；使用反射填充（reflective padding）后对图像进行整数偏移(dx, dy)，然后裁剪回原始大小，确保patch边界移动而不丢失边界信息。
  - 逆对齐算子 A^{-1}_ϕ：将相位偏移后的模型输出映射回原始图像坐标系；将patch输出重塑为光栅patch网格，使用bilinear upsampling（align_corners=False）上采样到填充后图像分辨率，再根据相位偏移反向裁剪得到原始H×W尺寸。
  - Uniform Phase Marginalization聚合器：平均多个相位的逆对齐logits，作为最终预测；对K个相位的逆对齐logits取平均（公式4），不更新编码器或头，是一种训练后处理。
- 公式/目标函数/指标定义：
  - 相位定义：ϕ = (dx, dy), dx, dy ∈ {0, ..., P-1}
  - 相位偏移后输出：z_ϕ = h(f_θ(S_ϕ(x)))
  - 逆对齐后平均：¯z(p) = 1/K ∑_{k=1}^K A^{-1}_ϕ_k(z_ϕ_k)(p)
  - 相位方差诊断：σ²(p) = 1/K ∑_k ||F_ϕ_k(p) - ¯F(p)||²₂, ¯F(p) = 1/K ∑_k F_ϕ_k(p)
  - 学习型注意权重：α_k(p) = exp(s_k(p)) / ∑_j exp(s_j(p)), ˜F(p) = ∑_k α_k(p) F_ϕ_k(p)
- 算法细节：
  - 对每个输入图像，生成K个相位偏移版本，每个偏移量通过反射填充和裁剪实现
  - 每个偏移版本独立通过冻结的ViT编码器和密集预测头，得到K个logits图
  - 每个logits图通过逆对齐（上采样+裁剪）恢复至原始图像大小
  - 对K个对齐后的logits取平均得到最终预测
  - 学习型变体在特征空间进行：对齐K个相位特征后，在每个位置通过可学习的MLP（1552→1024→256→1）计算注意力分数，softmax归一化后加权融合特征，再送入冻结的密集预测头
- 训练/推理细节：
  - Uniform Phase Marginalization：完全无需训练，仅推理时执行多次前向（K次）
  - 学习型变体（例如Phase-Feature Attention Aggregation）：仅训练一个小型MLP（约1M参数），编码器和分割头冻结，训练数据使用原任务数据
  - 部分编码器微调变体（Partial Encoder Tuning）：解锁最后几个编码器块和LayerNorm参数，分割头仍冻结
  - 预变换器patch嵌入平均变体（负设计）：将多个相位的patch嵌入平均后送入transformer，导致性能下降，说明应在输出层融合

  - 阶段5: 推理 - 对新的视频，单次前向传播生成适配器θ(v)，加载到冻结VLM后，任意文本查询p可直接回答，上下文窗口不含视觉令牌
- 关键模块/机制：
  - Perceiver Hypernetwork：将视频编码器各层的隐藏状态压缩并映射为LoRA权重；采用Perceiver风格的编码器-译码器重采样器结构。编码器重采样器以可学习潜在查询对每层隐藏状态Cℓ进行交叉注意力，输出固定大小潜在表示；译码器重采样器用输出查询（每个目标模块×每个秩方向一个）从潜在表示中解码出对应的潜在向量，再通过共享投影头生成两个LoRA因子矩阵A和B。所有模块共享潜在维度Z，输出形状O∈R^{B×L×M×R×Z}。
  - Dynamic LoRA Injection：将超网络生成的适配器实时注入冻结VLM的指定线性层；对每个目标线性模块（MLP down_proj）和每个层ℓ，使用生成的Aℓ,m∈R^{R×d_in}和Bℓ,m∈R^{R×d_out}，按标准LoRA前向公式y = xW^T + s(xA^T)B执行。A因子缩放初始化为1，B因子缩放初始化为0，s为固定缩放系数。每个视频实例生成独立的适配器，不跨视频共享。
  - Training Objective (Teacher-Forced Cross-Entropy)：监督超网络生成能保留视频语义的适配器；损失函数为交叉熵，只在答案模型输出上计算，不涉及视频编码器。目标响应y由离线教师模型（冻结的SmolVLM2）根据视频帧和下游提示生成。超网络ϕ通过梯度下降最小化L(ϕ) = -Σ_t log pϕ(y_t | y_{<t}, p, θ(v))，其中p是下游文本提示，θ(v)是当前批次的生成适配器。
- 公式/目标函数/指标定义：
  - C = E(v, i) # 视频编码器输出层间隐藏状态
  - θ(v) = Hϕ(C) # 超网络生成LoRA适配器
  - pϕ(y | p, v) = F(y | p; θ(v)) # 冻结答案模型使用适配器生成响应
  - L(ϕ) = -Σ_t log pϕ(y_t | y_{<t}, p, θ(v)) # 教师强制交叉熵损失
  - Δy = s (x A_{ℓ,m}^T) B_{ℓ,m} # LoRA增量
  - y = xW^T + s (x A_{ℓ,m}^T) B_{ℓ,m} # 完整适配前向
- 算法细节：
  - 感知器重采样器：使用编码器-译码器结构，编码器从隐藏状态压缩到Z维潜在表示，译码器从潜在表示中为每个目标模块和秩方向生成一个潜在向量
  - 共享投影头：将每个模块-秩方向的潜在向量投影为两个LoRA因子A和B，维度分别为R×d_in和R×d_out
  - 缩放初始化：A缩放因子初始化为1，B缩放因子初始化为0，保证训练初期适配器输出为零
  - 数据混合策略：训练视频跨度以60%单场景、30%相邻多场景、10%完整视频的比例混合
  - 离线教师生成：训练目标由冻结的SmolVLM2教师模型基于视频帧和下游提示生成，不依赖超网络
- 训练/推理细节：
  - 训练配置：12帧均匀采样，分辨率384px最长边，LoRA rank=16，目标模块为MLP down_proj
  - 训练数据：来自FineVideo的视频跨度，按60/30/10比例混合单场景、多场景和完整视频
  - 优化目标：仅超网络参数ϕ可训练，视频编码器和答案模型完全冻结，使用教师强制交叉熵损失
  - 推理配置：单次前向生成适配器后，可任意多次使用不同文本提示查询，无需重新编码视频
  - 推理效率：视觉令牌负载降低最多1500×，首令牌时间（TTFT）减少6-80×
  - 长视频支持：训练于12帧384px，推理时稳定支持1024帧1024px，而直接视频上下文推理会退化

### 19. GRAMformer: Any-Order Modality Interactions via Volumetric Multimodal Cross-Attention
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.06249v1
- 方法流程：
  - 输入：多模态序列（如文本、音频、视觉），每种模态有独立的token表示
  - 模态特定编码器：使用预训练模型（如BERT、Data2Vec、OpenFace）提取各模态特征
  - 交叉模态融合块：采用VMA模块，将来自一个模态的查询与来自其他所有模态的键一起处理，生成融合表示
  - 输出：融合后的多模态表示用于下游任务（如情感分类）
- 关键模块/机制：
  - VMA (Volumetric Multimodal Cross-Attention)：核心注意力机制，替代标准交叉注意力，建模任意阶模态交互；对于查询q和来自M个模态的键k_1,...,k_M，计算所有键与查询的联合体积：V = det([q, k_1, ..., k_M])（行列式绝对值或平方）。注意力分数为s = α * dot(q, k_1) + β * V + 门控项。实际中通过Gram行列式计算：V = sqrt(det(G))，G是向量内积矩阵。
  - 门控机制 (Gating)：控制体积项对输出的贡献；通过可学习的门控参数，对体积项进行缩放，公式(10)：g = σ(W_g [q; k_1; ...; k_M] + b_g)，然后输出 = g * V + (1-g) * dot_product。
  - 点积正则化 (Dot Product Regularization)：保持点积相似度信息，避免体积项主导；在损失中添加点积项的正则化项，平衡点积与体积的贡献。
- 公式/目标函数/指标定义：
  - 注意力分数公式：α = softmax( (query · key_1)/√d + β * volume_expansion )，其中volume_expansion基于行列式计算
  - 体积计算：V = sqrt(det(G))，G是查询与各模态键的内积矩阵
  - 门控输出：output = g * V + (1-g) * (query · key_1)，其中g = σ(W_g [q; k_1; ...; k_M] + b_g)
- 算法细节：
  - 对于给定的查询q，从其他模态收集对应的键序列
  - 对每个时间步，将q与所有模态的键向量堆叠成矩阵，计算其Gram矩阵的行列式（或体积）
  - 通过门控网络融合体积和点积得到注意力分数
  - 加权求和得到输出
- 训练/推理细节：
  - 训练时使用MOSI、MOSEI、UR-FUNNY、MUsTARD、MuJoCo Push等数据集，任务包括回归和分类
  - 优化器使用Adam，学习率、批次大小等超参数在附录中给出
  - 输入模态可灵活增减，无需修改架构
  - 实验中可冻结部分编码器或联合微调全部

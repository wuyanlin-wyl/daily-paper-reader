### 1. DALE-CT: Depth-Aware Foundation Models for Computed Tomography
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.07775v1
- 方法流程：
  - 数据预处理：将CT-RATE原始NIfTI转换为HU，裁剪至[-997,888]，z-score归一化（μ=-142, σ=361），按连续12mm物理间距分组切片，生成2D WebDataset
  - 深度感知多crop生成：对每个12mm slab，从中心切片生成2个全局crop（224×224或256×256），从窗口内随机采样8个局部crop（140×140或144×144）；所有crop有80%概率以RAD-ChestCT标签为中心，否则以TotalSegmentator mask为中心
  - 自监督预训练：使用LeJEPA框架（SIGReg正则化）从头训练ViT骨干，并可选添加密集辅助监督头（DALE-CT-1S：仅TotalSegmentator；DALE-CT-2S：TotalSegmentator+ReXGroundingCT），监督头消费软分数标签
  - 线性探测评估：冻结预训练骨干，使用多实例学习（MIL）聚合切片级特征，进行多异常检测分类，以Macro AUROC为指标
- 关键模块/机制：
  - LeJEPA框架：自监督表示学习，替代传统非对比方法中的启发式稳定策略；采用Sketched Isotropic Gaussian Regularization (SIGReg) 显式约束潜在空间为各向同性高斯分布，避免表示坍塌并实现线性可扩展性
  - 深度感知多crop生成器：将2D切片与3D空间位置关联，引导模型关注临床相关区域；基于12mm物理slab，从中心切片生成全局crop，从窗口内采样局部crop；80%概率以RAD-ChestCT标签或TotalSegmentator mask为中心，确保crop聚焦组织而非背景
  - 密集辅助监督头：提供解剖和异常级别的密集监督，增强特征表示质量；在LeJEPA预训练期间添加额外的预测头，输出与patch tokens对应的软分数，监督来自TotalSegmentator（118类解剖）和ReXGroundingCT（多标签放射学发现）的二元掩码（缩放至128×128）
  - MIL聚合器（线性探测）：将2D切片级特征聚合为3D体积级预测；对每个体积的所有切片特征（CLS token）使用多实例学习（MIL）池化，训练线性分类器进行多标签异常检测
- 公式/目标函数/指标定义：
  - LeJEPA目标：通过SIGReg约束潜在空间分布为各向同性高斯，无显式对比或启发式loss
  - DINOv2基线目标：联合DINO蒸馏损失 + iBOT掩码图像建模损失（掩码采样概率0.5，掩码比例10%-50%）
  - 辅助监督：密集交叉熵损失（预测软分数与真实掩码之间）
- 算法细节：
  - 多crop采样：全局crop严格从中心切片随机裁切（缩放40%-100%），局部crop在12mm窗口内随机切片采样（缩放20%-40%）；label-guided概率80%
  - 辅助监督头：在LeJEPA骨干后添加小型MLP，将每个patch token映射到类概率（解剖118类或异常多标签），与resized mask计算损失
  - 线性探测MIL：对每个体积，所有切片的CLS token经过MIL池化（如平均或注意力池化），然后通过线性分类器输出多标签概率
- 训练/推理细节：
  - 训练：DALE-CT从零随机初始化，使用FSDP和bf16混合精度，在8×NVIDIA H200 GPU上训练；DINOv2基线从自然图像预训练权重初始化，优化20,000步，batch size 384，学习率2e-4（warmup 3300步后衰减至1e-5）
  - 推理：冻结预训练骨干，仅训练MIL线性分类器（线性探测设置），输入为完整CT体积的所有切片

### 3. Baichuan-M4: A Clinical-Grade Medical Agent System for Continuous Care
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.08982v2
- 方法流程：
  - 输入：患者连续护理请求（包括文本、图像等多模态数据）
  - 步骤1：Baichuan-Harness接收请求，根据动作约束和工具使用规则，协调多智能体（如记忆管理、检索、感知模块）
  - 步骤2：临床工具层执行患者记忆检索、权威循证检索和多模态感知（如X光分析、皮肤科图像识别），生成结构化上下文
  - 步骤3：核心推理模型基于连续护理RL框架（SPAR++奖励建模、推理路径压缩、课程学习）生成响应，并经过稳定策略优化
  - 输出：临床级应答，包含诊断、治疗建议或随访计划
- 关键模块/机制：
  - Baichuan-Harness：统一运行时，桥接强化学习训练与部署，实施动作约束和工具调用；作为底层运行时，确保RL训练环境与真实部署环境一致；强制执行动作约束（如禁止危险建议）、支持工具注册、维护长期患者记忆状态、协调多个智能体（如检索智能体、感知智能体）的通信与调度
  - 核心推理模型（连续护理RL框架）：生成连续护理决策的推理模型，通过奖励驱动学习；采用SPAR++（Span-level Progressive Attention Reward）进行跨时间步的细粒度奖励建模；应用推理路径压缩减少冗余推理；课程学习按难度递增安排训练任务；稳定策略优化（如PPO变体）防止策略崩溃
  - 临床工具层：提供外部知识、记忆和多模态感知能力；患者记忆管理模块：维护长期电子健康记录（EHR）和对话历史，支持向量检索；循证检索模块：基于权威医学指南和文献（如PubMed）进行检索增强；多模态感知模块：处理文档OCR、X光片和皮肤科图像的视觉理解
- 公式/目标函数/指标定义：
  - SPAR++: 跨时间步的span-level奖励建模，奖励函数R = Σt λ^t * r_span(t)，其中r_span(t)为第t步的span奖励，λ为折扣因子
  - 推理路径压缩：减少推理步骤长度，目标为min L s.t. 正确率≥阈值
  - 稳定策略优化：采用PPO-clip目标，π_new = argmax E[ min(ratio * A, clip(ratio, 1-ε, 1+ε)*A ) ]，其中ratio = π_new/π_old
  - 课程学习：训练难度按阶段递增，初始简单病例，逐步增加复杂度
- 算法细节：
  - SPAR++实现：对每个推理步骤的生成序列进行span划分，对每个span赋予基于正确性、合理性、安全性的奖励信号
  - 推理路径压缩算法：在RL训练中，通过动态规划或剪枝策略，删除无意义的中间推理token，缩短序列长度
  - 多智能体协调：Baichuan-Harness维护一个全局状态，各智能体以消息传递方式协作，优先级由任务类型和紧急程度决定
  - 记忆更新机制：每次交互后，将患者关键信息（如新症状、用药史）嵌入记忆向量，存入向量数据库，后续检索时使用余弦相似度
  - 文档OCR流程：版面分析→文字识别→医学实体解析→结构化存储
- 训练/推理细节：
  - 训练：使用连续护理RL框架，先进行监督微调（SFT）在医学对话数据上，再进行RL训练（SPAR++ + 课程学习 + 策略优化）
  - 推理：Baichuan-Harness加载训练好的模型，动态调用工具层模块，输出时通过动作约束过滤不合适回答
  - 课程学习：训练数据按病例难度分级：简单→中等→复杂，每个阶段训练直到收敛
  - 稳定策略优化：使用PPO算法，并加入KL散度惩罚防止策略偏移过大
  - 多模态训练：图像编码器（如ViT）与文本解码器联合训练，损失函数包括语言建模损失和对比学习损失

### 4. Experience Makes Skillful: Enabling Generalizable Medical Agent Reasoning via Self-Evolving Skill Memory
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.09365v1
- 方法流程：
  - 1. Read（价值感知检索）：根据当前状态，通过临床类别路由确定子分支，计算每个技能与状态的语义相似度，结合其效用值加权求和，选择Top-K技能输入LLM。
  - 2. Write（轨迹到技能蒸馏）：使用门控轨迹缓冲器过滤基础设施错误、机械重复和琐碎成功，保留信息性轨迹；双通道蒸馏引擎（分析通道提取可重用模式，变异通道生成CREATE/PATCH/NONE操作）将轨迹转化为新技能或补丁。
  - 3. Assess（效用驱动评估）：对每个技能维护指数移动平均基线奖励，计算当前轨迹奖励与基线的优势（Advantage = R - B）；正优势增加效用，负优势减少效用，零优势忽略。
  - 4. Govern（仓储治理）：定期检查效用，低效用技能被降级（deprecate）或归档，高效用技能合并为成熟技能，删除有害条目。
- 关键模块/机制：
  - 多分支技能库：存储可复用的程序化知识，按通用、任务特定和动作级别组织，支持分层检索。；包含三个分支：通用技能（跨任务通用推理模式）、任务特定技能（针对某类临床任务的策略）、动作级技能（具体工具调用或操作步骤）。每个技能条目包含键（检索key）、内容（技能描述或指令）和效用统计量。
  - 门控轨迹缓冲器：筛选信息性交互轨迹，过滤噪声和冗余数据。；根据规则过滤三类无效轨迹：基础设施错误（如工具调用失败）、机械重复（连续相同动作）、琐碎成功（无需推理即可完成）。仅保留包含关键决策点或失败恢复的轨迹。
  - 双通道蒸馏引擎：将过滤后的轨迹蒸馏为结构化技能或补丁。；分析通道：提取轨迹中的可重用模式（如推理步骤、工具使用顺序），形成技能草案。变异通道：基于当前技能库，对草案执行CREATE（新增技能）、PATCH（修改现有技能）或NONE（不操作），通过新颖性和质量门控后写入库。
  - 价值感知检索器：根据语义和效用选择最相关的技能用于当前推理。；首先通过临床类别路由确定对应子分支；然后在分支内计算每个技能与当前状态的语义相似度（如嵌入余弦相似度），结合技能效用值进行加权（相似度×效用），取Top-K个技能返回。
  - 效用评估模块：持续更新每个技能的效用值，反映其历史贡献。；维护每个技能的经验效用值，初始为0。每执行一次技能后，根据轨迹奖励与基线的差异更新：Advantage = R - B（B为指数移动平均基线），若Advantage>0则效用增加，Advantage<0则效用减少，否则不变。效用值用于检索排序和治理决策。
  - 仓储治理模块：维护技能库的健康，促进高价值技能，淘汰低质量技能。；定期扫描技能库：效用低于阈值的技能标记为deprecate并最终删除；效用高于阈值的相似技能合并为成熟技能；过时或有害技能直接移除。
- 公式/目标函数/指标定义：
  - M-MDP定义：TM−MDP = ⟨S, A, P, E, γ, M⟩ (公式1)
  - 策略π: π(at | st, Mt) = Σ_m μ(m|st, Mt) pθ(at|st, m) (公式2)
  - 轨迹概率分解：p(τ) = p0(M0,s0) ∏_{t=0}^{T-1} μ(mt|st,Mt) pθ(at|st,mt) E(rt|st,at) U(Mt+1|Mt,st,mt,at,rt) P(st+1|st,at) (公式3)
  - 效用更新：Advantage = R_t - B_t，其中R_t为轨迹奖励，B_t为技能的指数移动平均基线。若Advantage>0则增加效用，<0则减少效用，=0不变化。
- 算法细节：
  - 检索算法：输入当前状态s，根据s的临床类别选择对应分支，计算该分支内所有技能与s的语义相似度，乘以技能效用值，排序取前K个技能作为记忆上下文。
  - 蒸馏算法：门控轨迹缓冲器接收交互轨迹，过滤后输入双通道引擎；分析通道使用LLM提取可重用模式（如关键推理步骤、工具调用条件）；变异通道根据当前库状态，对模式执行创建、补丁或跳过。
  - 效用更新：每个技能维护累积效用u和基线B；每次技能被采用后，计算当前轨迹奖励R，更新B = α*B + (1-α)*R，然后计算Advantage = R - B_new？原文未明确顺序，但通常先更新基线再算优势？根据Assess部分：Advantage = R - B，然后根据Advantage更新效用。EMA基线更新在每次评估后。
  - 治理机制：定期（如每N步）检查所有技能：若效用<低阈值，标记deprecate；若效用>高阈值且内容相似，进行合并；删除被标记的或有害条目。
- 训练/推理细节：
  - 推理阶段：LLM模型参数冻结，不进行任何梯度更新。智能体通过Read操作从技能库检索相关技能，作为提示的一部分输入LLM，产生动作。执行后接收环境反馈，进入Write、Assess、Govern阶段更新技能库。
  - 自我进化：整个过程在部署后在线进行，无需额外训练数据。技能库的更新完全基于交互反馈，模型权重保持不变。
  - 基线维护：每个技能维护一个指数移动平均的预期奖励基线，用于评估单次轨迹的优劣，此基线也是在推理过程中在线更新。

### 5. A Controlled Audit of Pretraining Contamination in Public Medical Vision-Language Benchmarks
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.10066v1
- 方法流程：
  - 步骤1：选定四个开放VLM（InternVL3-8B, Qwen2.5-VL-7B-Instruct, CheXagent-8b, LLaVA-OneVision-Qwen2-7B）作为被审计模型，以及SLAKE-En、PathVQA、VQA-RAD三个基准和OmniMedVQA镜像。
  - 步骤2：图像侧检测器（Detector 1）：使用SigLIP-B-16和SigLIP-SO400M提取基准测试图像和PMC-OA-beta图像的特征，计算余弦距离，当最近邻距离低于阈值τ时标记。阈值通过PMC内部自相似性分布的第1百分位数校准。
  - 步骤3：文本侧检测器（Detector 2）：规范顺序可交换性测试，计算每个（基准，模型）对在规范排序和10000个随机排列下的联合对数似然，得到p值，使用Bonferroni校正。
  - 步骤4：文本侧检测器（Detector 3）：Min-K%++尾部富集，对每个样本计算Min-K%++得分（K=20%），计算目标模型得分与队列中其他三个模型得分中位数的差值Δ_i，若Δ_i>100的经验概率超过5%则标记。
  - 步骤5：文本侧检测器（Detector 4）：跨模型前K Jaccard相似度，对每个基准，按Min-K%++得分排序取前K=25个样本，计算模型对之间的Jaccard相似度，若交集超过随机期望一个数量级则标记。
  - 步骤6：负控制：域内干净控制（VQA-RAD图像近邻到PMC-OA-beta）和域外控制（2000张wikiart绘画图像）用于评估检测器假阳性。
  - 步骤7：外部基线证伪：将BLIP-2加入队列，重新运行Detector 3和4，检查信号是否依然存在。
- 关键模块/机制：
  - 图像侧近邻重叠检测器：检测基准测试图像与预训练语料库（PMC-OA-beta）中图像的特征空间近邻，标记极端近邻。；使用SigLIP双编码器（ViT-B-16和Vit-SO400M）嵌入图像，计算余弦距离。阈值τ通过PMC内部自相似性分布的第1百分位数校准（τ_B-16=0.0180, τ_SO400M=0.0154）。标记的是近邻而非重复，需手动裁决。
  - 规范顺序可交换性检测器：检测模型是否对基准测试数据的规范排序表现出异常高的联合对数似然，暗示预训练时见过排序。；基于Oren et al. (2024)，比较规范排序与随机排列下的联合对数似然，使用排序敏感评分函数。p值通过10000次排列计算，Bonferroni校正阈值α=3.7e-4。
  - Min-K%++尾部富集检测器：基于每个样本在模型下最困难K%令牌的对数似然，检测成员推断信号。；计算每个样本的Min-K%++得分（K=20%），然后计算目标模型得分与队列中其他模型得分中位数的差值Δ_i。若比例Pr[Δ_i > 100] > 5%则标记。依赖队列校准同质性假设。
  - 跨模型前K Jaccard检测器：通过不同模型间异常容易样本的重叠程度检测共享预训练暴露。；在每个模型上按Min-K%++得分排序取前K=25个样本，计算模型对之间的Jaccard相似度。当观察到的交集超过随机期望（K²/n）一个数量级时标记。
- 公式/目标函数/指标定义：
  - Detector 1: 基准图像x与PMC-OA-beta最近邻距离 d(x) = min_{y∈PMC} cos_dist(f(x), f(y))，标记若 d(x) < τ。
  - Detector 2: p值 = (1 + |{π: ℓ(π) ≥ ℓ(π0)}|)/10001，其中π0为规范排序，ℓ为联合对数似然。

### 7. The Consistency Illusion: How Multi-Agent Debate Hides Reasoning Misalignment
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.08457v1
- 方法流程：
  - 输入：一组智能体对医疗问题q的答案{ai}和推理链{Ri}。
  - 步骤1：确定答案一致集合S(q)（投票多数答案的智能体）。
  - 步骤2：对每个有序对(Ai, Aj)，分解推理步骤为Ki和Kj段，构建对齐矩阵Mij∈R^Ki×Kj，元素为align(rki, rlj)。
  - 步骤3：使用混合对齐函数align_hyb：若NLI矛盾概率>阈值τ则赋-1，否则取嵌入余弦相似度。
  - 步骤4：计算最佳匹配对齐match_j(rki)=max_l align(rki, rlj)，对称化得到CARA(i,j)。
  - 步骤5：聚合为问题级分数CARA(q)（所有一致对平均）。同时计算矛盾率CR(q)。
  - 可选GDP协议：在推理中强制要求每个步骤包含CLAIM、GROUND、STANCE（仅在辩论轮次）字段。
- 关键模块/机制：
  - CARA-NLI：基于自然语言推理的矛盾检测，输出-1（矛盾）、0（中立）或+1（蕴含）。；使用预训练NLI模型（DeBERTa-v3-large）计算推理步骤对(rki, rlj)的矛盾概率PNLI，若PNLI>τ则标记为矛盾。
  - CARA-SIM：基于嵌入的语义相似度度量，输出[0,1]分数。；使用Sentence-BERT（all-MiniLM-L6-v2）将推理步骤编码为L2归一化向量eki，计算余弦相似度cos(eki, elj)。
  - CARA-HYB：混合对齐函数，结合NLI和嵌入，矛盾时覆盖相似度。；若PNLI>τ，则align_hyb=-1；否则align_hyb=cos(eki, elj)。τ为矛盾阈值（实验设为0.5）。
  - Grounded Debate Protocol (GDP)：提示级干预，结构化学推理，改进跨智能体对齐。；每个推理步骤要求输出：CLAIM（原子断言）、GROUND（支撑该声明的医学事实/指南）、STANCE（对他人CLAIM的立场：AGREE/DISAGREE/EXTEND，DISAGREE需提供反GROUND）。
- 公式/目标函数/指标定义：
  - Mij[k,l] = align(rki, rlj)
  - align_hyb(rki, rlj) = -1 若 PNLI > τ, 否则 cos(eki, elj)
  - match_j(rki) = max_{l∈{1..Kj}} align(rki, rlj)
  - CARA(i,j) = 0.5 * ( (1/Ki) * Σ_k match_j(rki) + (1/Kj) * Σ_l match_i(rlj) )
  - CARA(q) = 2 / (|S|(|S|-1)) * Σ_{i<j, i,j∈S(q)} CARA(i,j)
  - CR(q) = #{ (i,j,k) : i≠j, match_j(rki)=-1 } / Σ_{i∈S(q)} (|S(q)|-1) * Ki
- 算法细节：
  - 推理步骤分割：使用确定性文本分割管道（按句号、换行等）将每个智能体的推理链分成若干步骤。
  - 对齐矩阵构建：对答案一致集S(q)中每对智能体(i,j)，计算Ki×Kj矩阵，每个条目为align(rki, rlj)。
  - 最佳匹配：对每个rki，取与其对齐分数最高的rlj作为匹配，解决步数不对称问题。
  - 对称化：CARA(i,j)取两个方向的最佳匹配平均。
  - 问题级聚合：对答案一致集内所有有序对平均（若|S|≥2）。
  - 矛盾率：统计所有最佳匹配对被标记为矛盾的比例。
  - GDP解析：正则表达式提取CLAIM/GROUND/STANCE字段，仅用于日志分析，不影响CARA计算。
- 训练/推理细节：
  - 无训练过程，仅推理阶段分析。
  - GDP为提示级修改，不改变系统架构或增加LLM调用次数，仅增加输出token约9%。
  - CARA指标后处理计算，不额外调用LLM，使用固定NLI和嵌入模型。
  - 实验使用M3（一轮辩论）、M4（独立投票控制）和M3-GDP三种系统，每个系统3个智能体，多数投票确定答案。

- 公式/目标函数/指标定义：

  - 编码器层聚合：B_agg^(t+1,l) = Σ_k p_k B_k^(t+1,l)
  - 解码器层聚合：A_agg^(t+1,l) = Σ_k p_k A_k^(t+1,l)

  - SOR损失项（解码器层）: ⟨Q_sh, Q_lo⟩_F^2 / (||Q_sh||_F ||Q_lo||_F + ε)^2

- 训练/推理细节：

- 关键模块/机制：
  - Fisher-Rao 角色分配器：动态判别每个令牌在推理过程中的功能倾向（视觉/文本）；对于每个令牌，计算其在前一时刻和后一时刻的视觉注意力分布与文本注意力分布，利用 Fisher-Rao 测地距离度量分布变化量，若视觉注意力变化大于文本则将令牌标记为视觉导向，反之为文本导向。
  - 角色对齐评估器：衡量令牌实际注意力分配与分配角色的一致性；对每个令牌，基于其角色标签，使用注意力分布与参考分布（如均匀分布或预定义模板）的交叉熵或 KL 散度计算对齐得分，得分越高表示越符合角色期望。
  - 对齐引导优势重加权：将角色对齐得分融入优势函数，调整策略梯度更新幅度；在策略梯度公式中，将原始优势 A 乘以对齐得分 s（范围 0~1），即 A' = s * A，使得高对齐令牌获得更大更新，低对齐令牌更新受抑。
- 公式/目标函数/指标定义：
  - Fisher-Rao 测地距离：d(P, Q) = arccos(∑_i sqrt(p_i q_i))
  - 角色对齐得分：alignment_score = 1 - KL(actual_attention || expected_attention) 或余弦相似度
  - 优势重加权：A' = α * alignment_score * A + (1-α) * A，其中 α=0.2
- 算法细节：
  - 令牌级角色分配：在生成过程中，对每个新令牌，将其视觉注意力向量和文本注意力向量分别与前一令牌的对应向量计算 Fisher-Rao 距离，取差值指示函数决定角色。
  - 对齐得分计算：对每个令牌，若角色为视觉，则计算其视觉注意力与均匀分布（或前序视觉令牌平均注意力）的相似度；文本类似。
  - 优势重加权：将每个令牌的对齐得分与策略梯度中的优势项相乘，再按批次聚合。
- 训练/推理细节：
  - 训练使用 ThinkLite-hard-11K 数据集，共11031个复杂推理实例。
  - rollout 温度 0.9，每个 prompt 采样 4 个响应。
  - 学习率 1e-6，批次大小 64（梯度累积 2 步），最大响应长度 2048。
  - 视觉编码器完全解冻，全参数训练。
  - 使用 AdamW 优化器，线性学习率衰减，梯度裁剪范数 1.0。
  - bfloat16 精度，DeepSpeed ZeRO-3（无 CPU offload）。

- 方法流程：

- 公式/目标函数/指标定义：

  - Si,j,k = (1/τ) * (Ztk/||Ztk||2 · Fi,j/||Fi,j||2) # 像素-令牌余弦相似度
  - Lreg = ||Rt||2^2 # 残差L2正则
  - Lsep = || (Zt·At⊤)/(||Zt||2||At||2) - I ||_F^2 # 令牌与锚点对齐且与其他正交
  - Ldist = (1/|C0:t-1|) Σ_{k∈C0:t-1} ||Atk - At-1k||2^2 # 旧锚点蒸馏
  - wp = exp(-||p-ci||2/(2σi^2)), σi = α√|Ai| # 像素可靠性权重
- 算法细节：
  - 语义锚点初始化为可学习向量，每类一个，维度D。
  - 弹性残差生成：以锚点为查询，像素特征图为键值，交叉注意力输出残差，再与锚点相加。
  - 空间仲裁中：类不可知分割器输出多个对象掩码，每个掩码计算重心并生成高斯权重，设阈值τ（文中未给出，可设为0.5）。
  - 加权投票时，候选集K根据激活密度动态选择新类或所有类。
  - 仲裁后的标签传播到整个掩码区域，形成去噪伪标签。
  - 旧锚点蒸馏仅在每个增量步后对旧类锚点施加L2约束。
- 训练/推理细节：
  - 训练阶段：使用SLA生成伪标签监督分割损失，同时优化锚点、残差和像素特征。
  - 推理阶段：不调用SLA，直接通过像素特征与最终令牌的余弦相似度输出分割结果。
  - 增量步骤t=0时使用全监督，t>0时使用伪标签。
  - 锚点蒸馏每步执行，保持旧类锚点稳定。

  - Compressed-View Selector：结合锚点探测和关键层分析，生成待重计算令牌集合P；在线阶段，首先用块锚点查询探测获得块级别相关性得分，再结合关键层K状态对每个令牌位置进行细粒度打分，输出P满足给定重计算比率ρ。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 离线阶段：为每个检索到的文档块预先计算并存储PIC KV缓存（每层）、紧凑锚点缓存（每块锚点位置）和关键层集合（通过模型分析获得）。
  - 在线阶段：接收用户查询，利用块锚点查询探测在锚点缓存上进行快速查询-块相似度计算，得到每个块的优先级；然后用关键层的K状态对每个上下文位置进行注意力得分计算，确定需要重计算的令牌子集P。
  - 根据选择的令牌集合P，执行逐层稀疏重计算：对于P中的令牌，重新计算其KV值并更新缓存；其余令牌直接复用预计算缓存。
  - 融合后的KV缓存用于后续自回归解码。
- 训练/推理细节：
  - 所有模型均为预训练模型，无需额外训练；离线缓存准备和关键层分析不需要微调，仅需一次模型前向分析。
  - 推理时，QCFuse动态选择令牌进行重计算，其余令牌复用预计算缓存，减少计算量。
  - 实现基于SGLang 0.5.4，使用BF16精度，在NVIDIA H20 GPU上运行。

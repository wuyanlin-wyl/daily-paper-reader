## 摘要
自监督学习的最新突破，例如潜在-欧几里得联合嵌入预测架构（LeJEPA），以及视觉编码器与语言模型成功融合的进展，推动了计算机断层扫描（CT）领域对适应性强、高容量视觉编码器的需求。在本工作中，我们探索了基于二维切片的架构，作为处理三维容积CT数据的原生三维模型的灵活替代方案。利用CT-RATE数据集，我们从头开始使用LeJEPA训练了DALE-CT（深度感知潜在-欧几里得计算机断层扫描）二维模型家族，并将其性能与持续预训练的DINOv2基线进行了比较。为了提升表示质量，我们开发了一种新颖的三维深度感知预训练策略，该策略通过来自自动解剖掩膜和人工标注异常的密集辅助监督来锚定。在使用多实例学习（MIL）进行多异常检测的线性探针评估下，这种双监督模型（DALE-CT-2S）的冻结骨干网络实现了0.833的宏AUROC。这一性能表明，与最先进的三维视觉-语言模型几乎持平，且完全从头开始训练，使用了显著更少的数据且没有文本监督。为确保可重复性，所有训练代码、评估脚本和模型权重均已公开发布。

## Abstract
Recent breakthroughs in self-supervised learning (SSL), such as the Latent-Euclidean Joint-Embedding Predictive Architecture (LeJEPA), alongside successes in integrating visual encoders with language models, have driven the demand for adaptable, high-capacity vision encoders in Computed Tomography (CT). In this work, we explore 2D slice-based architectures as a flexible alternative to native 3D models for processing volumetric CT data. Using the CT-RATE dataset, we trained DALE-CT (Depth-Aware Latent-Euclidean Computed Tomography), a 2D model family built entirely from scratch using LeJEPA, and compared its performance against a continually pre-trained DINOv2 baseline. To enhance representation quality, we developed a novel 3D depth-aware pre-training strategy anchored by dense auxiliary supervision from both automated anatomical masks and human-annotated abnormalities. Under linear probe evaluation with Multiple Instance Learning (MIL) for multi-abnormality detection, the frozen backbone of this dual-supervised model (DALE-CT-2S) achieves a Macro AUROC of 0.833. This performance demonstrates near-parity with state-of-the-art 3D vision-language models, achieved entirely from scratch with significantly less data and no textual supervision. To ensure reproducibility, all training code, evaluation scripts, and model weights have been made publicly available.

### 论文提出的方法论

- **核心思想**：基于**LeJEPA**（Latent-Euclidean Joint-Embedding Predictive Architecture）自监督框架，从零训练2D ViT-Large模型（patch14），并通过动态深度感知采样和双源辅助监督增强表征质量。
- **关键技术细节**：
  - **深度感知多裁剪策略**：从连续12mm slab（物理厚度）中动态采样全局（256×256）和局部（144×144）裁剪，并优先基于解剖（TotalSegmentator）或异常（ReXGroundingCT）标注中心裁剪（80%概率），确保聚焦临床相关区域。
  - **LeJEPA目标函数**：结合**深度感知不变性损失**（L_inv，使不同视图映射到相似全局表示）和**Sketched Isotropic Gaussian Regularization**（SIGReg，防止表示坍缩），总损失 `L_LeJEPA = (1-λ)L_inv + λ L_SIGReg`（λ=0.02）。
  - **辅助监督**：对DALE-CT-1S（单源：118类TotalSegmentator）和DALE-CT-2S（双源：加上14类ReX异常）添加密集预测头（CLS token和patch token级别的BCE损失），总损失 `L_total = L_LeJEPA + λ_aux L_Aux`（λ_aux=0.1）。DALE-CT-0无辅助监督。

### 论文的主要结论与发现

- **DALE-CT-2S**在CT-RATE域内测试中达到**宏AUROC 0.8333**（宏AUPRC 0.5544），**几乎持平于SOTA 3D模型COLIPRI-C**（0.8415），且显著优于CT-CLIP（0.6121）、CT-FM（0.8214）、Merlin（0.8262）。

- **辅助监督**提供边际正向增益，但双源监督（DALE-CT-2S）效果最佳；然而，该模型在外部泛化中**过拟合**较明显（冻结时AUROC 0.634 vs 无监督模型0.635），但重训练后差距缩小。
- **2D架构**在外部泛化重训练后**超越**直接应用的3D基线（Finetuned DINOv2 AUROC 0.7547 > COLIPRI-C 0.7266），表明其提取的特征具有强泛化能力。

### 优点

1. **创新性**：首次将LeJEPA（无启发式自监督）应用于2D CT基础模型，结合深度感知采样，实现无需文本监督的高性能。
2. **高效灵活**：2D架构避免了3D模型对固定分辨率扫描的重采样，支持变长序列聚合，计算开销更低。

5. **临床相关性**：label-guided cropping确保模型关注解剖/病理区域，辅助监督直接注入临床先验。

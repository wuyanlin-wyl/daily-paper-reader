## 方向 1：医学视觉问答中鲁棒表示与幻觉缓解的联合优化
综合噪声感知视觉表示（2606.05535v1）与反事实问题选择（2606.01044v1），提出鲁棒表示与幻觉风险联合优化的Med-VQA框架，同时抵御视觉输入噪声和问题诱导的幻觉。

### 代表论文

- [Noise-Aware Visual Representation Learning for Medical Visual Question Answering](https://arxiv.org/abs/2606.05535v1)：提出一种噪声感知的医学视觉问答框架，通过去噪自编码器学习鲁棒视觉表示，并利用LoRA进行参数高效微调，在SLAKE和PathVQA上提升了对输入噪声的鲁棒性。
- [Ask4VG: Risk-Aware Question Selection for Reducing Prior-Driven Answers in Medical VQA](https://arxiv.org/abs/2606.01044v1)：本文提出Ask4VG框架，通过反事实视觉探测估计问题引起的幻觉风险，用于风险感知的医学VQA问题选择。在VQA-RAD上，基于预测风险重排序将问题改写，使风险从0.658降至0.623，精确度从0.337提升至0.356。证明了问题选择是缓解幻觉的有效补充。

### 共同创新点
- 首次将视觉表示鲁棒性与问题诱导幻觉缓解统一为联合目标，克服了现有工作单独处理视觉噪声或问题偏置的局限。
- 利用反事实探测的弱信号指导去噪自编码器的噪声注入分布，使鲁棒学习更具针对性。

### 尚未解决的问题
- 噪声类型仅限于高斯噪声，真实多模态噪声（如对比度、遮挡）未覆盖。
- 反事实探测仅用于问题选择，未直接参与视觉表示训练。
- 两个模块独立训练，未在端到端联合优化中验证。

### 二次创新路线
#### 路线 1：反事实引导的对比去噪自编码器
- 核心想法：在去噪自编码器的预训练阶段，利用反事实视觉探测的幻觉风险分数加权噪声注入，使模型重点学习对高风险问题区域鲁棒的视觉表示。
- 新问题定义：提出风险感知的鲁棒视觉表示学习任务：输入医学图像和问题，输出对噪声鲁棒的视觉表示，同时最小化该问题在给定表示下的幻觉风险。
- 机制来源：
  - 2606.05535v1 提出去噪自编码器学习鲁棒视觉表示，使用均匀高斯噪声注入，但未利用问题信息。
  - 2606.01044v1 通过反事实探测（原图、扰动图、空白图、错配图）估计每个问题的幻觉风险，但未用于指导视觉表示学习。
  - 本路线将反事实风险分数作为噪声注入的自适应权重，风险越高，对该视觉区域的噪声强度或多样性越大，迫使编码器学习更鲁棒的表示以降低风险。
- 为什么值得做：现有去噪自编码器对所有视觉区域均匀加噪，而反事实探测可识别导致幻觉的关键区域，定向增强其鲁棒性。
- 理论/数学创新理由：
  - 数学对象：风险加权的噪声注入分布与对比学习目标。
  - 来源分解：2606.05535v1 优化均匀噪声下的重建损失：min_θ E_{v,ε~N(0,σ)}[L_recon(DAE(v+ε), v)]；2606.01044v1 通过反事实对比计算幻觉风险R(q,v) = D_KL(p(·|q,v_blank) || p(·|q,v_orig))等，但未引入重建流程。
  - 新建模方式：联合优化目标：min_θ E_{(q,v)}[ E_{ε~N(0, σ·R(q,v))}[ L_recon(DAE(v+ε), v) ] + λ·R(q, DAE(v)) ]，其中R(q, DAE(v))是在去噪表示下的反事实风险，λ权衡两部分。
  - 公式草图：设视觉编码器f_θ，去噪过程：h = f_θ(v + ε)，ε~N(0, σ·R(q,v))，重建损失L_recon = ||Dec(h) - v||^2。幻觉风险R(q,v) = 0.5*(KL(p(·|q,v_blank)||p(·|q,v)) + KL(p(·|q,v_mismatch)||p(·|q,v)))。联合损失L = L_recon + λ·R(q, Dec(h))。
  - 为什么可能有效：自适应噪声注入使编码器在幻觉高风险区域接受更强扰动，从而学习更鲁棒的特征，同时反事实风险作为可微项直接优化，形成良性循环：强扰动导致低风险，低风险又降低扰动强度，稳定训练。
- 可验证实验：在SLAKE和PathVQA上，添加高斯噪声、对比度噪声、遮挡噪声三种类型，与基线（均匀噪声DAE、无噪声）比较。评估指标：准确率、幻觉率（通过反事实探测）、鲁棒性（噪声下准确率下降幅度）。
- 主要风险：风险加权噪声可能使模型过度关注局部区域而忽略全局结构；反事实风险计算依赖近似，可能不稳定。

#### 路线 2：端到端鲁棒视觉-语言联合训练与幻觉感知问题重排序
- 核心想法：将鲁棒视觉编码器与幻觉风险估计器联合训练，并在推理时根据风险对候选问题进行重排序，选择视觉支撑强的问题。
- 新问题定义：端到端医学VQA系统：输入图像和问题集，输出答案并同时预测每个问题的幻觉风险，根据风险排序选择最可靠的问题回答。
- 机制来源：
  - 2606.05535v1 提供了基于去噪自编码器的鲁棒视觉编码器，可输出视觉前缀。
  - 2606.01044v1 的反事实风险估计可视为一个轻量级分类器，但需要多轮推理。
  - 本路线将反事实探测简化为一个风险预测头，与视觉编码器、语言模型端到端训练，共享视觉特征。
- 为什么值得做：现有方法分别处理视觉鲁棒性和问题选择，但未在统一框架中利用交互信息。联合训练可使视觉表示直接为风险估计服务。
- 理论/数学创新理由：
  - 数学对象：多任务联合损失，包含VQA损失和风险预测损失。
  - 来源分解：2606.05535v1 优化VQA交叉熵损失L_vqa；2606.01044v1 独立优化风险排序损失L_risk，但两者无共享。
  - 新建模方式：联合优化：min L_vqa + λ·L_risk，其中L_risk定义为基于视觉特征的问题-答案一致性对比损失：L_risk = E[max(0, margin - (S(q,v_orig) - S(q,v_blank)))], S为视觉-语言匹配得分。
  - 公式草图：设视觉编码器输出z，问题编码h_q，答案编码h_a。匹配得分S(q,v) = z^T W h_q + h_a^T U h_q。风险损失L_risk = Σ_{q} max(0, 1 - (S(q,v_orig) - S(q,v_blank)))。总损失L = L_vqa + λ·L_risk。推理时，对候选问题集，计算S(q, v_orig) - S(q, v_blank)作为置信度，选择Top-1。
  - 为什么可能有效：风险预测损失强制视觉特征对空白图像时匹配得分低，对原始图像时高，从而学习区分视觉支撑性；共享特征使视觉编码器同时优化VQA和风险识别，提升整体鲁棒性。
- 可验证实验：在VQA-RAD上，使用原始问题集，将模型按风险排序后回答，比较Top-10问题准确率与随机选择。同时与单独DAE+单独反事实探测的级联系统对比。
- 主要风险：多任务学习可能引入负迁移；风险预测依赖原始-空白对，需要构造空白图像，可能不适用于所有问题。

## 方向 2：跨域医学图像分割中鲁棒表示与主动样本选择的协同优化
结合噪声注入跳跃连接提升边界鲁棒性（2606.04427v1）与自监督表示+贪心样本选择降低标注成本（2606.04301v1），提出鲁棒且标注高效的跨域分割框架。

### 代表论文

- [Implicit Fuzzification via Bounded Noise Injection for Robust Medical Image Segmentation](https://arxiv.org/abs/2606.04427v1)：提出NoiseUNet，通过在U-Net跳跃连接中注入有界均匀噪声，实现隐式模糊化，增强医学图像分割的边界鲁棒性和精度。
- [XSSR: Cross-Domain Self-Supervised Representative Selection for Efficient Annotation in Medical Image Segmentation](https://arxiv.org/abs/2606.04301v1)：提出XSSR框架，通过自监督表示学习和贪心样本选择，在跨域医学图像分割中以极小注释量（5%）实现接近全数据性能。

### 共同创新点
- 将隐式模糊化噪声正则引入跨域自监督表示学习，提升域无关特征鲁棒性。
- 利用噪声诱导的不确定性指导样本选择，优先标注边界模糊区域而非简单样本。

### 尚未解决的问题
- NoiseUNet仅在单域分割中验证，未考虑跨域场景。
- XSSR的样本选择基于嵌入距离，未利用分割模型自身的预测不确定性。
- 两者独立优化，未共享噪声与选择策略。

### 二次创新路线
#### 路线 1：噪声感知的自监督跨域表示学习与不确定性引导样本选择
- 核心想法：在XSSR的Conv-MAE预训练中，引入NoiseUNet的跳跃连接噪声注入，得到对噪声鲁棒的跨域嵌入；样本选择时加入预测不确定性（通过MC Dropout）作为第四准则，优先选择高不确定性样本。
- 新问题定义：鲁棒跨域主动分割：在无标签目标域中，结合自监督预训练和噪声鲁棒嵌入，主动选择最具信息量的样本（兼顾密度、新颖性、多样性和不确定性）进行标注，训练鲁棒分割模型。
- 机制来源：
  - 2606.04427v1 在跳跃连接注入有界噪声促进边界鲁棒性，但未用于跨域预训练。
  - 2606.04301v1 使用Conv-MAE学习嵌入，选择基于密度、新颖性、多样性，缺乏不确定性。
  - 本路线在Conv-MAE编码器各层添加类似NoiseUNet的噪声注入，获得鲁棒嵌入；选择评分增加不确定性项：U(z)=H(p(y|x;θ))，与密度、新颖性、多样性加权求和。
- 为什么值得做：噪声注入鲁棒表示可提升跨域泛化；不确定性引导选择可针对最困难的边界区域，提升标注效率。
- 理论/数学创新理由：
  - 数学对象：鲁棒自监督损失与多准则主动选择函数。
  - 来源分解：2606.04427v1 在分割阶段使用噪声注入，自监督阶段未涉及；2606.04301v1 自监督阶段无噪声，选择函数为Score = λ·Density + (1-λ)[α·Novelty + (1-α)·Diversity]。
  - 新建模方式：自监督阶段：在Conv-MAE编码器第i层输出z_i注入噪声ε~U[-δ,δ]，重建损失L_MAE_noise = E[||Dec(z_i+ε) - x||^2]。选择阶段：Score = λ·Density + (1-λ)[α·Novelty + β·Diversity + (1-α-β)·Uncertainty]，其中Uncertainty = H(p(y|x;θ_seg))，θ_seg为初步训练的分割模型。
  - 公式草图：编码器第l层特征z_l，噪声注入z_l' = z_l + ε_l，ε_l ~ U[-δ,δ]。总损失L = Σ_l ||Dec(z_l') - x||^2。选择函数Score(x) = λ*Density(x) + (1-λ)*[α*Novelty(x) + β*Diversity(x) + (1-α-β)*H(p(y|x))]。
  - 为什么可能有效：噪声注入使自监督编码器学习对域间分布偏移鲁棒的表示，从而在新颖性和多样性评估时更稳定；不确定性项直接反映当前分割模型的薄弱区域，选择这些样本可高效提升性能。
- 可验证实验：在跨域MRI到CT肝脏分割任务上，使用带噪声的Conv-MAE预训练，然后选择5%目标域样本，与原始XSSR、随机选择、熵主动学习比较Dice分数。
- 主要风险：噪声注入可能降低自监督表示质量；不确定性项依赖初步分割模型，可能引入偏差。

#### 路线 2：隐式模糊化边界正则化与密度-新颖性校准的主动分割框架
- 核心想法：在NoiseUNet的分割训练中，引入XSSR的源域自监督嵌入，并设计边界密度-新颖性评分来校准样本选择，专门关注边界模糊区域。
- 新问题定义：边界感知主动分割：在目标域中，利用源域自监督嵌入和边界预测不确定性，选择边界区域最模糊的样本进行标注，同时使用NoiseUNet训练鲁棒边界分割。
- 机制来源：
  - 2606.04427v1 通过噪声注入生成软边界，但缺乏主动选择机制。
  - 2606.04301v1 的样本选择基于全局嵌入，未细分边界区域。
  - 本路线计算每个样本的边界不确定性地图（通过预测概率图的梯度幅值），并在选择评分中加入边界密度项。
- 为什么值得做：NoiseUNet侧重于边界，但需要大量标注；XSSR选择样本但未考虑边界重要性，两者结合可针对性选择边界困难样本。
- 理论/数学创新理由：
  - 数学对象：边界不确定性加权的样本选择损失与噪声正则化分割损失。
  - 来源分解：2606.04427v1 优化含噪声的分割损失L_seg_noise；2606.04301v1 选择函数Score = f(Density, Novelty, Diversity)。
  - 新建模方式：将边界不确定性U_b(x)=mean(||∇p(y|x)||)纳入评分：Score = λ·Density + (1-λ)[α·Novelty + β·U_b(x) + (1-α-β)·Diversity]。训练时，分割损失采用NoiseUNet的跳跃连接噪声注入。
  - 公式草图：边界不确定性地图：G(x)=||∇_x softmax(f(x,θ))||_2，U_b(x)=mean(G(x))。选择Score(x)=λ*Density(x) + (1-λ)[α*Novelty(x) + β*U_b(x) + (1-α-β)*Diversity(x)]。分割损失L_seg = E_{(x,y)~selected}[L_ce(NoiseUNet(x), y)]，其中NoiseUNet跳跃连接添加U[-δ,δ]噪声。
  - 为什么可能有效：边界不确定性直接反映样本中边界区域的分割难度，选择此类样本可最大化每次标注的收益；噪声注入正则化使模型对边界噪声鲁棒，两者协同降低边界分割误差。
- 可验证实验：在心脏MRI分割跨域任务（A医院→B医院），使用边界不确定性引导选择5%样本，与原始XSSR、熵选择、随机选择比较边界Dice和Hausdorff距离。
- 主要风险：边界不确定性计算需要原始图像，可能增加计算成本；选择偏向边界样本可能导致整体性能不均衡。

## 方向 3：跨模态特权蒸馏在医学影像中的机制互补与统一框架
融合路径结构特权蒸馏（2606.02877v1）与生理先验对比预测蒸馏（2606.01537v1），提出通用医学特权蒸馏框架，支持多种特权模态（RNA、ECG、实验室）注入视觉编码器。

### 代表论文

- [Pathway-Structured Privileged Distillation for Deployable Computational Pathology](https://arxiv.org/abs/2606.02877v1)：本文提出MoPE框架，通过路径结构特权蒸馏将多模态学习转化为仅组织学推理。利用RNA衍生的路径监督训练病理专家，在多个基准和乳腺癌队列中提升WSI推理性能，实现无需RNA的部署。
- [PaCX-MAE: Physiology-Augmented Chest X-Ray Masked Autoencoder](https://arxiv.org/abs/2606.01537v1)：提出PaCX-MAE，一种跨模态蒸馏框架，通过双对比预测目标将心电图和实验室检测的生理先验注入胸部X光编码器，同时保持推理时单模态，在9个基准上提升生理依赖任务性能。

### 共同创新点
- 两者均利用特权信息（RNA通路/生理信号）增强医学视觉编码器，推理时仅需视觉输入。
- 均采用多专家或对比预测机制对齐视觉与特权特征。

### 尚未解决的问题
- MoPE仅利用RNA通路，未考虑其他特权模态如ECG。
- PaCX-MAE使用单一对比预测目标，未显式建模模态内部结构。
- 两者未融合路径结构和对比蒸馏的优势。

### 二次创新路线
#### 路线 1：路径结构感知的多模态对比蒸馏框架
- 核心想法：将MoPE的路径索引专家与PaCX-MAE的对比预测结合，为每个生物通路（RNA通路、ECG波段等）分配一个对比预测头，进行路径特定的蒸馏。
- 新问题定义：结构感知特权蒸馏：给定视觉图像和多种特权模态（如RNA、ECG、实验室），利用通路先验组织特权特征，通过路径级对比预测蒸馏到视觉编码器，推理时仅用视觉图像。
- 机制来源：
  - 2606.02877v1 使用路径索引的专家混合，每个专家处理特定RNA通路。
  - 2606.01537v1 使用全局对比预测蒸馏，未利用通路结构。
  - 本路线在特权编码器端按通路分组，每组对应一个对比预测头，视觉编码器输出与各组对齐。
- 为什么值得做：路径结构可提供模态内部分组信息，使对比预测更具语义指向性，优于全局对比。
- 理论/数学创新理由：
  - 数学对象：多路径对比预测损失与路径级InfoNCE。
  - 来源分解：2606.02877v1 使用路径级专家损失：L_MoPE = Σ_k w_k L_CE(专家_k(x), 通路k)；2606.01537v1 使用全局InfoNCE：L_PaCX = -log exp(sim(z_v, z_p))/Σneg。
  - 新建模方式：定义P个通路，每个通路有特权嵌入z_p^k。视觉编码器输出z_v，通路级对比损失：L_path = -Σ_k log exp(sim(z_v, z_p^k)/τ) / (exp(sim(z_v, z_p^k)/τ) + Σ_{j≠k} exp(sim(z_v, z_p^j)/τ) + Σ_neg exp(sim(z_v, z_neg)/τ))。总损失L = L_path + λ·L_recon(z_v, z_global)。
  - 公式草图：令K为通路数，z_p^k为第k通路的特权特征。通路对比损失：L_infoNCE_k = -log(exp(z_v·z_p^k/τ) / (exp(z_v·z_p^k/τ) + Σ_{j≠k} exp(z_v·z_p^j/τ) + Σ_negs))。总损失L = Σ_k L_infoNCE_k + λ||z_v - MLP(z_global)||^2。
  - 为什么可能有效：通路级对比迫使视觉特征区分不同通路，学习到更细粒度的生物相关性；同时全局重建保持整体信息。通路结构自然地提供负例，增强对比学习效果。
- 可验证实验：在TCGA和MIMIC数据集上，使用RNA通路（来自KEGG）和ECG特征，比较通路级对比蒸馏与全局对比蒸馏在肿瘤分级、心衰预测等任务上的AUROC。
- 主要风险：通路划分可能不完整或过于粗糙；通路数量增多时对比损失计算复杂度高。

#### 路线 2：混合专家与对比蒸馏的两阶段特权蒸馏
- 核心想法：第一阶段使用MoPE的路径专家蒸馏到视觉视觉专家，第二阶段使用PaCX-MAE的对比预测进一步对齐全局表示，两阶段互补。
- 新问题定义：两阶段视觉编码器特权蒸馏：先通过路径专家蒸馏学习通路特异性特征，再通过全局对比预测对齐整体特权表示，最终编码器同时具备通路敏感性和全局一致性。
- 机制来源：
  - 2606.02877v1 的专家蒸馏聚焦于局部通路对齐；2606.01537v1 的对比预测聚焦于全局对齐。
  - 本路线按顺序应用：先冻结第一阶段专家头，再训练第二阶段对比头。
- 为什么值得做：专家蒸馏提供结构化知识，对比预测提供全局对齐，两者结合可提升泛化性和特异性。
- 理论/数学创新理由：
  - 数学对象：两阶段优化目标：第一阶段专家蒸馏损失，第二阶段对比预测损失。
  - 来源分解：第一阶段：L1 = Σ_k w_k D_KL(视觉专家_k || 特权专家_k)；第二阶段：L2 = InfoNCE(z_v_phase1, z_p_global)。
  - 新建模方式：第一阶段训练视觉专家E_v^k：min L1 = Σ_k D_KL(p_{E_v^k}(x) || p_{E_p^k}(x))；第二阶段冻结E_v^k，训练投影头g：min L2 = -log exp(sim(g(z_v), z_p)/τ) / Σneg。最终视觉编码器为E_v = concat(E_v^1,...,E_v^K) + MLP。
  - 公式草图：设视觉编码器f_θ，特权编码器f_ϕ。第k通路：z_v^k = f_θ(x), z_p^k = f_ϕ(x^k)。第一阶段KL损失：L1 = Σ_k E[log(p(z_v^k)/p(z_p^k))]。第二阶段：L2 = -E[log(exp(sim(z_v, z_p)/τ) / Σ neg)]。总L = αL1 + βL2。
  - 为什么可能有效：两阶段渐进式蒸馏避免多任务干扰：先学习局部通路模式，再整合全局信息。阶段二利用阶段一已对齐的特征进行对比，避免早期对比导致特征混淆。
- 可验证实验：在病理WSI数据集上，使用RNA通路特权，先训练通路专家蒸馏，再添加全局其他模态对比，比较单阶段与两阶段在基因表达预测和存活分析上的性能。
- 主要风险：两阶段训练时间延长；阶段一可能过拟合局部通路，破坏全局泛化。

## 方向 4：视觉语言模型推理效率与视觉基础能力的联合优化
结合视觉令牌缩减的畸变矫正（2606.01711v1）与蒸馏中的视觉梯度优先策略（2606.00564v1），提出高效且视觉基础增强的VLM蒸馏/推理方法。

### 代表论文

- [Improving Visual Token Reduction via Rectifying Distortions for Efficient Multimodal LLM Inference](https://arxiv.org/abs/2606.01711v1)：提出RESTORE框架，通过基于相对距离的注意力权重校准和基于特征相似性的锚点选择来矫正视觉令牌缩减中的位置和注意力畸变，提升多模态大语言模型推理效率。
- [Decomposed On-Policy Distillation for Vision-Language Reasoning: Steering Gradients for Visual Grounding](https://arxiv.org/abs/2606.00564v1)：提出Visual Gradient Steering (VGS)方法，通过分解视觉语言模型蒸馏损失为语言先验和视觉基础两部分，并动态优先视觉子空间，解决梯度正交导致的优化妥协问题，提升视觉推理性能。

### 共同创新点
- 两者均关注视觉语言模型中视觉信息的有效利用：RESTORE矫正缩减后的畸变，VGS优先视觉梯度。
- 可在蒸馏过程中引入缩减操作，同时保留视觉基础能力。

### 尚未解决的问题
- RESTORE仅在推理时应用，未参与训练；VGS仅调整梯度，未考虑令牌缩减。
- 两者未结合：缩减可能丢失视觉基础，而VGS的梯度调整可补偿。

### 二次创新路线
#### 路线 1：视觉梯度感知的令牌缩减与蒸馏联合框架
- 核心想法：在VGS蒸馏过程中，引入RESTORE的注意力校准和锚点选择进行令牌缩减，并通过视觉梯度指引缩减比例，使缩减保留对视觉基础重要的令牌。
- 新问题定义：视觉优化的高效VLM蒸馏：在on-policy蒸馏中，根据视觉梯度动态缩减视觉令牌数量，同时使用注意力校准补偿位置失真，保持视觉推理能力。
- 机制来源：
  - 2606.01711v1 的距离感知注意力校准和锚点选择，可矫正缩减后注意力畸变。
  - 2606.00564v1 的VDS可量化每个令牌的视觉依赖度。
  - 本路线使用VDS作为令牌重要性，优先保留高VDS令牌，并施加RESTORE校准。
- 为什么值得做：VGS可识别视觉重要令牌，RESTORE可矫正缩减畸变，两者协同可达成高效率与强视觉基础。
- 理论/数学创新理由：
  - 数学对象：基于VDS的令牌选择损失与注意力校准联合目标。
  - 来源分解：RESTORE 使用余弦相似度锚点选择，未利用VDS；VGS 使用VDS选择高视觉依赖token进行语言保存正则化。
  - 新建模方式：蒸馏损失L = L_standard + γ·L_Vis + λ·L_LP，但视觉令牌数量通过VDS动态缩减：保留VDS前k%的令牌，其余通过锚点合并。在注意力计算中，采用RESTORE的距离感知校准。最终损失：L_VGS_RESTORE = ηVGS(γ)·E[L_standard + γL_Vis + λL_LP] + μ·L_RESTORE_align，其中L_RESTORE_align对齐缩减后的注意力分布。
  - 公式草图：令VDS_t为token t的视觉依赖度。选择阈值τ，保留token集S={t|VDS_t>τ}。对剔除token，合并到最相似锚点。校准后注意力权重A_ij' = A_ij * log(s_n(c - D(|i-j|)))。总损失L = L_steer + λ_LP + μ * KL(A' || A_full)。
  - 为什么可能有效：高VDS令牌是视觉基础的关键，保留它们可减少信息损失；注意力校准补偿位置畸变；梯度优先视觉子空间确保剩余令牌的视觉有效性。
- 可验证实验：在OKVQA和GQA数据集上，使用Qwen2-VL 7B作为教师，蒸馏到3B学生，比较不同缩减比例下准确率和推理速度，与未缩减、RESTORE-only、VGS-only对照。
- 主要风险：VDS计算需要额外前向传播；动态缩减可能破坏批量优化稳定性。

#### 路线 2：可微令牌缩减与视觉梯度引导的稀疏注意力
- 核心想法：将缩减过程变为可微的稀疏注意力权重，使用VGS的视觉梯度指导注意力掩码学习，实现端到端的效率-视觉基础权衡。
- 新问题定义：端到端可微视觉令牌缩减与蒸馏：通过梯度引导的稀疏注意力学习，自动保留视觉相关令牌，同时优化蒸馏损失。
- 机制来源：
  - 2606.01711v1 的锚点选择和合并是离散过程，不可微；2606.00564v1 的VDS是连续的，可微。
  - 本路线使用VDS作为注意力掩码的soft选择信号，使缩减可微。
- 为什么值得做：现有缩减方法不可微，无法与蒸馏联合优化；将注意力权重与视觉梯度连接，可直接优化缩减策略。
- 理论/数学创新理由：
  - 数学对象：基于VDS的软注意力掩码与蒸馏损失联合优化。
  - 来源分解：RESTORE使用硬选择；VGS使用硬阈值。
  - 新建模方式：定义每个令牌的保留概率p_t = sigmoid(VDS_t / τ)。注意力掩码M_t = Bernoulli(p_t)但使用Gumbel-Softmax近似。注意力权重A_ij = softmax(QK^T/√d + log(M_i))。蒸馏损失L = L_steer + λ_LP + β·(Σ M_t - k)^2（控制保留数量）。
  - 公式草图：令VDS_t为token t的视觉依赖分数，p_t = σ((VDS_t - μ)/τ)。掩码m_t ~ Gumbel-Softmax(p_t)。注意力A_ij = exp(q_i·k_j/√d + m_j)/ Σ_k exp(q_i·k_k/√d + m_k)。损失L = L_standard + γL_Vis + λL_LP + β(Σ m_t - K)^2。
  - 为什么可能有效：Gumbel-Softmax使阈值学习可微，梯度可直接指导每个令牌的保留与否；视觉梯度引导偏向保留高视觉依赖令牌，从而保证视觉基础。
- 可验证实验：在Visual Genome描述任务上，比较可微缩减与硬缩减的蒸馏效果，评估生成质量（CIDEr）和推理速度。
- 主要风险：Gumbel-Softmax可能引入方差；软掩码可能模糊边界导致冗余令牌保留。

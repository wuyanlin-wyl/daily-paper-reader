## 摘要
医学视觉问答（Med-VQA）通过使AI模型能够解读医学图像并回答临床相关问题，在临床决策支持方面具有巨大潜力。近期方法通常通过轻量级映射网络将现成的视觉编码器与大语言模型（LLM）连接，以降低计算成本。然而，这些方法往往忽略了处理视觉表示中噪声和微小无关变化的重要性。为应对这些挑战，我们提出了一种噪声感知的Med-VQA框架，该框架在视觉嵌入映射到LLM输入空间之前，引入了一个去噪自编码器。该去噪自编码器经过预训练，能够从受损输入中重建干净的视觉嵌入，促使模型学习对噪声不敏感的鲁棒视觉表示。随后，这些嵌入通过多层感知机（MLP）投影到语言模型嵌入空间，形成为LLM提供图像信息的视觉前缀令牌。为实现无需完全重新训练的高效适配，我们采用低秩适配（LoRA）进行参数高效微调。所提方法在SLAKE和PathVQA基准上进行了评估。实验结果表明，该方法在多个评价标准下，对噪声输入嵌入具有更强的鲁棒性，同时保持了具有竞争力的干净性能。这些发现表明，学习更鲁棒的视觉表示可以增强Med-VQA的性能和鲁棒性。

## Abstract
Medical visual question answering (Med-VQA) has strong potential for clinical decision support by enabling AI models to interpret medical images and answer clinically relevant queries. Recent approaches typically connect off-the-shelf vision encoders with large language models (LLMs) through lightweight mapping networks to reduce computational cost. However, these methods often overlook the importance of handling noise and small irrelevant changes in visual representations. To address these challenges, we propose a noise-aware Med-VQA framework that incorporates a denoising autoencoder before visual embeddings are mapped into the input space of an LLM. The denoising autoencoder is pretrained to reconstruct clean visual embeddings from corrupted inputs, encouraging the model to learn robust visual representations that are less sensitive to noise. The resulting embeddings are then projected into the language model embedding space using a multi-layer perceptron (MLP), forming visual prefix tokens that provide image information to the LLM. To enable efficient adaptation without full retraining, we employ parameter-efficient fine-tuning using low-rank adaptation (LoRA). The proposed method is evaluated on the SLAKE and PathVQA benchmarks. Experimental results show improved robustness to noisy input embeddings while maintaining competitive clean performance across multiple evaluation criteria. These findings suggest that learning more robust visual representations can enhance Med-VQA performance and robustness.

## 1. 核心问题与整体含义（研究动机与背景）

医学视觉问答（Med-VQA）旨在使 AI 模型理解医学图像并回答临床问题，具有支持临床决策的潜力。现有主流方法通过轻量映射网络将冻结的视觉编码器（如 CLIP）与大语言模型（LLM）连接，以降低计算成本。然而，这些方法通常**忽略视觉表示中存在的噪声与微小无关变化**（如医学图像采集、传输中引入的噪声），导致投影后的视觉令牌可能包含任务无关的扰动，从而影响下游答案生成的准确性。本文针对这一问题，提出一种**噪声感知的视觉表示学习框架**，通过引入去噪自编码器（Denoising Autoencoder, DAE）在视觉嵌入被映射到 LLM 输入空间之前学习鲁棒表示，提升 Med-VQA 系统对噪声的鲁棒性。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
在视觉编码器与 LLM 之间插入一个**去噪自编码器**，将其作为表示学习模块：先对视觉嵌入施加受控噪声（高斯噪声），训练自编码器重建干净的嵌入，从而**迫使编码器学习对输入扰动鲁棒的潜在表示**。然后冻结该编码器，将潜在表示通过 MLP 映射为 LLM 理解的视觉前缀令牌，最终由 LLM 生成答案。训练分为两阶段。

### 关键技术细节

- **视觉表示**：冻结 CLIP ViT-B/32 编码器，提取每张图像的全局视觉嵌入 \(v \in \mathbb{R}^{512}\)。
- **去噪自编码器**：
  - 结构：瓶颈 MLP（512→256→128→256→512），ReLU 激活。
  - 训练：对 \(v\) 添加高斯噪声 \(\tilde{v} = v + \epsilon, \epsilon \sim \mathcal{N}(0, \sigma^2 I)\)（\(\sigma\) 取 0.1/0.5/1.0），训练模型以 **Smooth L1 损失** 重建原始 \(v\)。
  - 训练后丢弃解码器，仅保留编码器。
- **视觉前缀映射**：使用 3 层 MLP（128→\(\ell_x \cdot e/2 \to \ell_x \cdot e\)），输出形状为 \(\ell_x \times e\) 的视觉前缀令牌序列（\(\ell_x=8, e=1600\)，对应 GPT-2 XL 的嵌入维度）。
- **文本条件与解码**：输入序列为 `[question: 问题] [context: 视觉前缀] [answer: 答案]`，使用因果语言模型（GPT-2 XL）自回归生成答案。
- **参数高效微调**：在 Med-VQA 第二阶段，可选择冻结 LLM 或采用 **LoRA**（低秩适配）更新部分注意力参数。
- **两阶段训练**：
  - **阶段 1**：单独训练 DAE（仅使用图像嵌入，无问答任务）。
  - **阶段 2**：固定 DAE 编码器和 CLIP 编码器，训练 MLP 映射器（以及可选 LoRA），使用语言建模目标（交叉熵）优化答案生成。

## 6. 主要结论与发现

1. **DAE 显著提升噪声鲁棒性**：在 SLAKE 和 PathVQA 上，DAE 的 Noisy Avg. Acc. 在 LoRA 设定下分别从 0.642 提升至 0.735（SLAKE）、0.514 提升至 0.568（PathVQA）；在 Frozen 设定下提升更明显（0.473→0.713，0.348→0.518）。
2. **中等噪声训练最佳**：阶段 1 噪声 \(\sigma=0.5\) 在多数情形下取得最优鲁棒性-清洁性能平衡；\(\sigma=0.1\) 清洁性能略高但抗噪性下降。
3. **与普通 AE 对比**：DAE 在噪声条件下一致优于 AE，证实去噪表示学习比单纯瓶颈编码更有效。
4. **清洁性能持平或微降**：DAE 在干净输入下表现与基线相当或略低（如 PathVQA），但差距小，远小于噪声条件下的提升幅度。这表明学习鲁棒表示并不会显著牺牲干净场景下的表现。

## 7. 优点

- **问题新颖且实用**：首次显式针对 Med-VQA 中视觉嵌入的噪声问题，提出去噪表示学习，填补了该领域的空白。

- **实验设计清晰**：通过对比基线、AE、DAE 和不同噪声强度，有力证明了去噪表示学习的贡献。

## 8. 不足与局限

- **噪声模拟简单**：仅使用高斯噪声，不能代表医学图像中复杂的真实噪声（如散粒噪声、焦斑噪声、运动伪影等），结论推广到真实临床环境需谨慎。

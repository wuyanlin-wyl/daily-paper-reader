### 1. Noise-Aware Visual Representation Learning for Medical Visual Question Answering
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.05535v1
- 方法流程：
  - 阶段1：去噪自编码器预训练。输入：从CLIP视觉编码器提取的干净全局视觉嵌入v（512维）。加噪得到˜v = v + ε（ε∼N(0,σ²I)），编码为128维潜在表示z = f_enc(˜v)，解码重建ˆv = f_dec(z)。使用Smooth L1损失最小化ˆv与v的差异。
  - 阶段2：Med-VQA训练。输入图像经CLIP编码器得到v，送入冻结的DAE编码器得到z，通过3层MLP映射器转换为8个1600维的视觉前缀令牌P_v。将令牌与问题文本令牌（'question: ' + q + ' context: ' + P_v + ' answer ' + a）拼接为输入序列X，送入GPT-2 XL（冻结或LoRA微调）自回归生成答案。训练使用交叉熵损失最大化答案似然。
- 关键模块/机制：
  - CLIP视觉编码器：提取图像的全局视觉嵌入；使用冻结的CLIP ViT-B/32，输入图像224×224，输出512维全局视觉嵌入v。
  - 去噪自编码器：学习鲁棒的视觉表示，抑制噪声影响；MLP架构：编码器输入512→隐藏256→潜在128；解码器镜像。使用ReLU激活和输入dropout（0.1）。预训练时对v加高斯噪声（σ∈{0.1,0.5,1.0}），用Smooth L1损失重建干净嵌入。预训练后仅保留编码器。
  - MLP映射器：将潜在表示映射为语言模型可接受的视觉前缀令牌；3层全连接网络，隐藏维度：128→(ℓ_x·e/2)→(ℓ_x·e)，其中ℓ_x=8（前缀长度），e=1600（GPT-2 XL嵌入维度）。输出重塑为8×1600的视觉前缀令牌。
  - GPT-2 XL语言模型：基于视觉前缀和文本问题生成答案；使用冻结的GPT-2 XL，或通过LoRA（秩r）进行参数高效微调。输入序列包含'question:'、问题令牌、'context:'、视觉前缀、'answer'、答案令牌（训练时），自回归生成。
  - LoRA：参数高效适应语言模型；对GPT-2 XL的注意力查询和值投影矩阵添加低秩适配器，冻结原始权重，仅训练适配器参数，实现高效微调。
- 公式/目标函数/指标定义：
  - L_DAE = (1/N) ∑_{i=1}^N { 0.5*(ˆv_i - v_i)² if |ˆv_i - v_i| < 1; |ˆv_i - v_i| - 0.5 otherwise } (Smooth L1重建损失)
  - L_VQA = - ∑_{t∈A} log p_θ(y_t | y_{<t}, q, I) (VQA训练目标，交叉熵损失)
  - 加噪过程：˜v = v + ε, ε ∼ N(0, σ²I)
- 算法细节：
  - 加噪策略：重参数化，对全局视觉嵌入每个维度独立添加高斯噪声，σ取0.1、0.5、1.0。
  - 去噪自编码器瓶颈设计：将512维压缩至128维，强制学习紧凑鲁棒表示。
  - 视觉前缀生成：潜在表示z（128维）经MLP映射为8个令牌，每个令牌为1600维，与语言模型嵌入空间对齐。
  - 输入拼接：先插入问题令牌，再插入视觉前缀，最后插入答案令牌（训练时），推理时从'answer'开始生成。
  - 两阶段训练：第一阶段预训练DAE；第二阶段固定CLIP编码器和DAE编码器，训练MLP映射器（或同时LoRA微调LLM）。
- 训练/推理细节：
  - 训练分两阶段：阶段1仅训练DAE，使用Smooth L1损失，优化器未指定（默认Adam等），学习率等超参数未提供；阶段2训练映射器和可选的LoRA参数，使用交叉熵损失。
  - 推理时，输入图像和问题，CLIP编码器提取v→冻结DAE编码器得z→MLP映射器得视觉前缀→与问题拼接→GPT-2 XL自回归生成答案令牌直到结束符。
  - 采用冻结或LoRA微调两种设置：冻结设置仅训练MLP映射器；LoRA设置额外添加低秩矩阵到注意力投影层。

- 方法流程：

  - 特征融合模块：将ViT语义特征与TDA拓扑特征合并为统一的判别性表示。；采用拼接（concatenation）或加权线性组合的方式，将两种特征向量合并为更高维的特征向量，再输入分类器。
  - 分类器：基于融合特征输出四类肿瘤的概率分布。；由一个或多个全连接层组成，后接Softmax激活函数，输出四个类别的概率。

  - ViT特征提取：冻结预训练权重（或微调），前向传播获取[CLS] token对应向量作为全局特征。
  - TDA特征提取：将图像转换为灰度图（若原图为彩色），计算灰度拓扑（如滤波函数为像素强度）；构建单纯复形，记录特征（连通分量、环）的持续长度；将持续图转换为固定维度的向量（如持久景观或持久图像）作为特征。

### 6. XSSR: Cross-Domain Self-Supervised Representative Selection for Efficient Annotation in Medical Image Segmentation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.04301v1
- 方法流程：
  - 阶段1：自监督表示学习。输入：源域无标签图像。处理：训练卷积掩码自编码器（MAE），对输入图像进行像素级掩码，使用L1损失重建原图。输出：训练好的编码器（可提取d维嵌入向量）。
  - 阶段2：贪心样本选择。输入：源域嵌入集合Z_s、目标域嵌入集合Z_t，预算k。处理：对每个目标样本计算评分（密度+新颖性+多样性），通过自动α校准确定最佳平衡，迭代选择最高分样本加入集合S。输出：选中的k个目标样本索引集合S。
  - 阶段3：分割模型训练。输入：选中的目标样本及其标注（需人工标注k个样本）。处理：使用U-Net分割网络，以二元交叉熵损失在选中的k个样本上训练。输出：训练好的分割模型。
- 关键模块/机制：
  - 卷积掩码自编码器（Conv-MAE）：自监督表示学习，建立源域与目标域共享的嵌入空间；编码器由4个步长为2的卷积块组成，输出空间特征图，经全局平均池化得到d维嵌入向量。解码器重构原始图像。使用L1损失训练。轻量设计适合医学图像小样本场景。
  - 贪心样本选择算法：从目标域选择最具代表性的k个样本用于标注；基于嵌入向量的评分：密度=负的k近邻平均距离；新颖性=到最近源域嵌入的距离；多样性=到已选样本的最短距离。综合评分Score = λ·Density + (1-λ)[α·Novelty + (1-α)·Diversity]。通过z-score归一化后，每次迭代选择最高分样本加入集合。
  - 自动α校准机制：自动确定新颖性与多样性的权衡参数α，无需手动调节；枚举候选α值（如0.0,0.1,...,1.0），对每个α运行贪心选择得到子集S，计算覆盖度Coverage = (1/N_t) Σ_i min_{j∈S} ||z_i - z_j||_2，选择最小化覆盖度的α作为最终参数。
  - U-Net分割网络：在选中的目标子集上训练，实现目标域分割；标准U-Net架构，输入128×128图像，输出分割掩码。使用二元交叉熵损失优化。
- 公式/目标函数/指标定义：
  - 重建损失：L_MAE = ||f_θ(x_masked) - x||_1
  - 嵌入向量：z = GAP( E_conv(x) ) ∈ R^d
  - 密度：d_i = (1/k) Σ_{j∈N_k(i)} ||z_i - z_j||_2, Density(x_i) = -d_i
  - 新颖性：Novelty(x_i) = min_{z_s ∈ Z_s} ||z_i - z_s||_2
  - 多样性：Diversity(x_i) = min_{x_j ∈ S} ||z_i - z_j||_2
  - 综合评分：Score(x_i) = λ·Density(x_i) + (1-λ)[α·Novelty(x_i) + (1-α)·Diversity(x_i)]
- 算法细节：
  - 贪心选择循环：初始化S为空，迭代k次，每次计算所有未选样本的评分（密度和多样性需归一化），选择评分最大值对应的样本加入S。
  - 自动α校准：对每个候选α（例如0.0到1.0步长0.1），执行完整贪心选择，计算覆盖度，取最小覆盖度对应的α。覆盖度定义为目标域所有嵌入到最近选中嵌入的平均距离。
  - 评分归一化：三个分量（密度、新颖性、多样性）分别减去均值除以标准差，再进行加权组合。
- 训练/推理细节：
  - MAE在源域训练，无目标域标签参与，使用L1损失。编码器输出维度d设为超参数（实验隐含使用128维？原文未明确但可从公式推断）。
  - U-Net训练：仅用选中的目标子集（5%），100个epoch，batch size 8，学习率1e-3，AdamW优化器，输入分辨率128×128，损失为二元交叉熵。
  - 推理时：将目标域图像输入训练好的U-Net，输出概率图，阈值0.5二值化得到分割结果。

### 7. Multi-Granularity 3D Kidney Lesion Characterization from CT Volumes
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.04365v1
- 方法流程：
  - 输入：3D肾CT体积（全CT或裁剪到肾脏区域）及其对应的分割掩码（由nnU-Net生成，包含肾脏、囊肿、实性病变）
  - 编码：将CT和分割掩码组合成多通道输入，送入3D编码器（如SuPreM CT-ViT、ResNet-18等）提取特征
  - 检测头部：编码器输出特征图送到LesionDETR，包含固定数量的可学习查询，通过注意力机制解码出查询对应的病变预测
  - 匹配与损失：训练时，使用大小距离匈牙利匹配将预测查询与真实病变配对；层次损失函数结合逐病变损失（类型、大小、增强、衰减）和侧别聚合损失（侧别异常、侧别类型/大小）
  - 多粒度推理：模型可同时输出侧别级（L1、L2）和逐病变级（L3）预测，侧别级由该侧所有病变的预测聚合得到
- 关键模块/机制：
  - 3D CT编码器：从3D CT体积和分割掩码中提取特征，提供后续检测头的输入；支持多种预训练初始化：SuPreM（腹部CT监督预训练）、VoCo（体积对比学习）、CT-CLIP（视觉-语言预训练）、Models Genesis（自监督）以及随机初始化；编码器包括CT-ViT和ResNet-18等架构
  - 分割掩码输入通道：提供肾脏、囊肿、实性病变的空间先验，帮助模型关注病变区域；将nnU-Net生成的多类分割掩码（肾脏、囊肿、实性病变）作为额外通道与CT体积拼接，形成多通道输入（如4通道：CT + 3种掩码）
  - LesionDETR检测头：从编码器特征中检测出可变数量的病变，并为每个病变预测四个临床属性；基于DETR架构，使用固定数量的可学习查询（例如50个），通过解码器交叉注意力生成每个查询的病变预测（类型、大小、增强、衰减）；训练时使用大小距离匈牙利匹配将预测与真实病变配对，匹配代价为预测与真实病变的尺寸距离（L1距离）
  - 层次损失：联合训练逐病变预测和侧别级目标，实现多粒度监督；包含两部分：一部分是每个匹配病变的逐病变损失（类别交叉熵、尺寸回归L1等）；另一部分是将每个侧别内所有预测（包括未匹配的查询）聚合后计算侧别级损失（如侧别异常二分类、侧别最大病变类型、侧别最大尺寸），使用二元交叉熵和L1损失
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 大小距离匈牙利匹配：计算所有预测查询和真实病变之间的代价矩阵，代价为|size_pred - size_gt|（尺寸L1距离），使用匈牙利算法求解最小代价匹配，确保每个真实病变至多匹配一个预测，未匹配的预测视为背景
  - 层次损失：L = L_slot + λ * L_side，其中L_slot为匹配病变的逐病变损失（包括类型分类、尺寸回归等），L_side为侧别聚合损失（侧别异常分类、侧别类型分类、侧别尺寸回归）
  - 可学习查询初始化：固定数量的查询（如50个），通过解码器中的多头自注意力和交叉注意力迭代更新，最终输出每个查询的病变属性类别概率和回归值
  - 侧别聚合：对于每个侧别（左/右），将该侧内所有查询的输出（包括背景）通过池化（如取最大值或求和）得到侧别级预测
- 训练/推理细节：
  - 训练优化器为AdamW，学习率策略使用余弦退火，批大小根据GPU内存调整（如2-4个体积），数据增强包括随机裁剪、翻转、强度变换
  - 损失权重λ通过网格搜索确定，侧别损失权重设为0.5

### 10. SC-MFJ: A Simple Haptic Quality Metric for Medical Image Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.06199v1
- 方法流程：
  - 输入：分割输出（二值掩膜或SDF）
  - 转换为截断符号距离场（TSDF）
  - 在零等面上随机采样短路径（每路径N个点，步长s）
  - 每个点处从TSDF梯度计算法向量
  - 使用弹簧力模型计算接触力F = -k * δ * n̂（k刚度，δ穿透深度，常数）
  - 计算每步力变化ΔF，再计算力抖动J = (F_{i+1} - F_i) / Δt（Δt常数）
  - 对所有路径的所有步的力抖动幅度取平均，得到SC-MFJ标量值
- 关键模块/机制：
  - 表面行走采样：在分割表面生成虚拟触笔路径，用于采样法向量；在TSDF零等面上随机采样起点，然后沿表面随机方向移动固定步长，直到达到预设路径长度（例如20步）。步长设为体素间距倍数（如1体素）。
  - 法向量计算：从TSDF梯度计算表面法向量，影响力方向；在路径上每个点pi，计算TSDF的梯度∇φ(pi)，归一化得到法向量n̂_i = ∇φ(pi)/||∇φ(pi)||。对于二值基线产生的阶梯状表面，法向量会剧烈变化。
  - 接触力模型：用简化的弹簧惩罚模型模拟触觉力；设固定穿透深度δ和刚度k，力F_i = -k * δ * n̂_i。由于k和δ是常数，力只依赖法向量方向。
  - 力抖动计算：量化力的变化剧烈程度，作为触觉质量指标；计算连续两步之间的力变化ΔF_i = F_{i+1} - F_i，再除以时间步长Δt（常数），得到力抖动J_i。最终SC-MFJ = mean(||J_i||) across all steps and all paths。
- 公式/目标函数/指标定义：
  - 法向量: n̂_i = ∇φ(pi) / ||∇φ(pi)||
  - 接触力: F_i = -k * δ * n̂_i
  - 力抖动: J_i = (F_{i+1} - F_i) / Δt
  - SC-MFJ = 平均所有路径所有步的||J_i||
- 算法细节：
  - 表面行走：在TSDF零等面上随机采样种子点，沿表面随机方向移动步长（比如1体素），直到达到路径长度（如20点）。在每个点，通过三线性插值计算TSDF梯度并归一化得到法向量。
  - 力抖动计算：使用固定时间步长（如1），计算相邻点力向量差，取L2范数，对所有路径所有步平均。
  - 高斯平滑后处理：对二值基线生成的TSDF应用高斯核（σ=1体素）卷积，然后提取零等面用于SC-MFJ评估。
- 训练/推理细节：
  - 训练仅在SDF回归方法中涉及：使用nnU-Net backbone，输出单通道经tanh映射到[-1,1]，训练目标为预计算的截断SDF，复合损失包括MSE和Dice项。
  - SDF训练存在收敛不稳定性，需要尝试不同随机种子。
  - 所有方法的SC-MFJ评估均在推理后的分割输出上进行，不参与训练。

  - ℓVis(τ) = (1/|τ|) Σ_t D_KL(pθ_S(·|τ<t,I,x) || qT(·|τ<t,I,x)) 中的视觉部分（原文公式11，具体为仅保留视觉条件项）

  - ηVGS(γ) = ||∇θL_Standard||_2 / ||∇θL_Standard + γ∇θL_Vis||_2 (梯度范数归一化因子)

- 算法细节：
  - 在线学生轨迹采样：从当前学生模型中采样完整的自回归推理轨迹τ（包含中间步骤和最终答案）

  - 损失组合：将标准损失、视觉辅助损失和语言保存损失加权求和，γ=2.0，λ=0.01
  - 梯度归一化：根据γ计算固定缩放因子η（2B模型为0.41，4B模型为0.36），避免动态计算开销
  - 更新方向调整：最终梯度为η(∇L_Standard + γ∇L_Vis + λ∇L_LP)，确保范数与标准梯度相近，方向偏向视觉子空间
- 训练/推理细节：
  - 蒸馏设置：教师为GRPO微调后的Qwen3-VL-8B-Instruct，学生为Qwen3-VL-2B/4B-Instruct
  - 数据集：Vision-SR1-47K，包含47k个(图像,问题,答案)三元组
  - 训练超参数：学习率1e-6，weight decay 1e-2，batch size 512，1 epoch，冻结视觉编码器？
  - Rollout：温度1.0，top-p 1.0，最大输入长度16384，最大响应长度2048

  - 基于代表性和区分性的锚点选择：从候选视觉令牌中选出最具代表性和非冗余的锚点令牌用于合并，减少信息损失；首先计算令牌间余弦相似度矩阵C；定义每个令牌的代表性R_i为与其他所有令牌相似度之和；定义二元掩码M指示哪些令牌有更高的R；然后计算每个令牌与更高代表性令牌的最大相似度max_j C_ij，区分性为1减去该值；最终得分 = R_i * (1 - max_j C_ij)，选择Top-K作为锚点；非锚点令牌合并到最相似的锚点。
- 公式/目标函数/指标定义：

  - A = Top-K( R_i * (1 - max_j hat{C}_{ij}) )，其中hat{C}_{ij} = C_{ij} if R_j > R_i else -inf

  - 锚点选择步骤：计算余弦相似度矩阵C，计算代表性子R_i，生成掩码M，计算每个token的max_j hat{C}_{ij}，加权得到得分，取Top-K作为锚点

### 14. Provably Auditable and Safe LLM Agents from Human-Authored Ontologies

- 方法流程：

  - 2. 角色推导：将本体输入LLM，由LLM推导出子代理角色和人类在环角色。
  - 3. 子代理并行工作：每个子代理拥有自身不相交的状态切片，根据其角色提出下一步动作提案。
  - 4. 元代理裁决：元代理接收子代理的提案，检查全局状态是否满足所有预定义不变量（如速率限制、一致性等）。
  - 5. 状态转换：若所有不变量保持，元代理提交新全局状态；否则拒绝提案。
  - 6. 记录：所有决策记录在仅追加账本中，实现线性可审计性。
- 关键模块/机制：
  - 子代理 (Sub-agents)：每个子代理负责问题领域的一个独立切片，提出下一步动作。例如在UDT合规领域有LabOrder、Billing、Clinical三个子代理。；子代理拥有自己的状态切片（不可见全局状态），通过LLM调用、工具调用等生成提案。子代理可以并行工作，提案发送到元代理。
  - 元代理 (Meta-agent)：作为全局裁决者，检查子代理提案是否满足所有不变量，并决定是否转换全局状态。；元代理运行简单的检查：验证提案所导致的候选新状态是否满足所有预定义不变量（如审核速率、状态一致性等）。如果满足，则更新全局状态；否则拒绝并记录。元代理不执行复杂推理，利用Checkability Over Correctness原则。
  - 人类在环队列 (Counselor Queue)：在需要人类决策时，将代理提出的动作放入队列，等待人类专家批准或否决。；例如在UDT合规领域，对患者的复发临床响应必须是人类决策点。Agentic Redux增强版包含Counselor Queue，人类专家可以查看提议并做出决定。
  - 仅追加账本 (Append-only Ledger)：记录所有决策和状态转换，确保线性可审计性。；每次状态转换（包括元代理的接受或拒绝）都追加到账本中，形成不可篡改的审计追踪。
  - 不变量定义 (Invariants)：定义领域特定的安全约束，元代理在裁决时检查这些不变量是否保持。；不变量分为两类：仅依赖内部状态（如Maintainer Rate Limit）和依赖外部观测信号（如CVE Attribution Consistency）。不变量被形式化为状态谓词。
- 算法细节：
  - 状态转换算法：元代理接收子代理提案，生成候选全局状态，检查所有不变量谓词（如MAINTAINER_RATE_LIMIT、CVE_ATTRIBUTION_CONSISTENCY等），若全部通过则提交并记录；否则拒绝并记录。
  - 子代理提案生成：每个子代理独立观察其状态切片，使用LLM或规则引擎提出具体动作（如“提交账单”、“更新补丁信息”）。
  - 记录机制：每次裁决结果（接受/拒绝）连同时间戳写入仅追加账本。

### 17. PaCX-MAE: Physiology-Augmented Chest X-Ray Masked Autoencoder

- 方法流程：

  - Stage 2 跨模态蒸馏: 输入CXR图像，通过冻结的视觉骨干（含LoRA适配）提取视觉嵌入，同时利用冻结的生理编码器提取ECG和实验室嵌入；通过双分支（对比投影头和回归头）计算混合损失Ltotal = λC Lcontrastive + λR Lregression，优化LoRA参数和归一化层。
  - 推理阶段: 丢弃投影头和回归头，仅使用增强后的视觉编码器处理单模态CXR图像，输出用于下游任务的表示。
- 关键模块/机制：
  - MAE预训练视觉编码器：初始化视觉骨干，学习全局解剖结构；使用ViT-B架构，在CheXpert上以90%掩蔽率进行掩码自编码，迫使模型从有限可见块中重建完整图像，学习心脏轮廓、纵隔宽度等全局语义。

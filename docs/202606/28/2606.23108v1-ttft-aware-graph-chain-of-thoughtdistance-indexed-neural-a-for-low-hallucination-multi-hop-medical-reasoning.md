## 摘要
幻觉和不透明的推理仍然是临床LLM不可接受的失败模式。我们提出了一个生产级的GraphRAG堆栈，将答案约束到异质的约70万节点医学知识图谱（为生育助手提供支持）中的可验证图链式思维路径。核心思想是目标导向导航：一个有向剪枝地标标记（PLL）预言机提供精确距离，用于亚毫秒级可行性检查和简单路径枚举，而轻量级AStarNet启发式算法严格在PLL走廊内运行，以优先考虑临床合理的扩展。我们评分并打包一组小而多样的路径（CUI/语义类型重叠、长度先验、来源先验）以条件生成，从而产生紧凑的提示和改进的首词到达时间（TTFT）。在聚焦生育的查询上，混合方法（PLL+AStarNet）比纯文本RAG和单一组件基线建立了更好的延迟/召回帕累托前沿，降低了TTFT，并在保持解释清晰度的同时减少了临床医生审计的幻觉。结果是一个实用的方案，为可解释、低幻觉的多跳医学推理做好了实际部署的准备。

## Abstract
Hallucinations and opaque reasoning remain unacceptable failure modes for clinical LLMs. We present a production-grade GraphRAG stack that constrains answers to verifiable graph chain-of-thought paths in a heterogeneous, ~700K-node medical knowledge graph powering a fertility assistant. The core idea is targeted navigation: a directed Pruned Landmark Labeling (PLL) oracle provides exact distances for sub-millisecond feasibility checks and simple-path enumeration, while a lightweight AStarNet heuristic operates strictly within the PLL corridor to prioritize clinically plausible expansions. We score and pack a small, diverse set of paths (CUI/semantic-type overlap, length prior, provenance priors) to condition generation, yielding compact prompts and improved Time to First Token (TTFT). On fertility-focused queries, the hybrid (PLL+AStarNet) establishes a better latency/recall Pareto frontier than text-only RAG and single-component baselines, lowers TTFT, and reduces clinician-audited hallucinations while preserving explanation clarity. The result is a practical recipe for explainable, low-hallucination multi-hop medical reasoning ready for real-world deployment.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：临床大语言模型（LLM）在生成医疗建议时存在无法接受的幻觉（hallucination）和不透明推理（opaque reasoning），尤其在多跳推理场景中，传统文本RAG缺乏结构化约束，难以保证事实可验证性和端到端可审计性。
- **背景动机**：在安全关键的医疗场景（如生育辅助）中，答案必须（i）由可验证来源约束，（ii）端到端可审计，（iii）交互响应快（首词到达时间TTFT低）。现有方法要么是盲目的图搜索（BFS/双向BFS）导致组合爆炸，要么是启发式搜索缺乏正确性保障，要么只依赖文本RAG造成高幻觉。作者试图将**精确距离预言机**与**学习型启发式**结合，实现高效、可解释、低幻觉的多跳医学推理。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **“目标化导航”** ：将盲目枚举转化为有边界的目标导航。使用**有向剪枝地标标记（PLL）** 提供精确最短路径距离作为可行性检查（亚毫秒级），将搜索限制在“PLL走廊”（即最短距离走廊）内；然后使用轻量级**AStarNet**启发式在该走廊内优先扩展临床合理的路径；最后通过评分、多样性和打包机制选出小且多样化的路径集，以紧凑prompt形式输入LLM生成并强制路径引用。

### 关键技术细节
1. **实体接地**：使用临床NER + UMLS链接（scispaCy/MedCAT）将用户查询映射到种子实体（CUI）。
2. **精确可行性检查（有向PLL）**：
   - 对每个节点存储out-labels和in-labels，通过标签交集快速计算有向最短距离`D = d(s,t)`，查询时间O(|L_out(s)|+|L_in(t)|)，实际亚毫秒。
   - 采用**社区感知的pivot排序**构建标签，在700K节点上标签大小约480MB，构建时间1.6小时，p50查询0.51ms，剪枝率95.2%。
3. **距离约束枚举**：
   - 只保留前缀s→…→x满足`g(x) + d(x,t) ≤ D`（节点唯一性、类型/关系掩码），形成PLL走廊。
   - 可选中间相遇枚举。
4. **神经引导（AStarNet）**：
   - 学习h_θ(x | t, C)（基于前缀长度、最后关系、语义类型等）。在走廊内，用A*或Beam方式根据`f(x)=g(x)+λh_θ`或`s(x)=λh_θ-μg`排序候选，并按照beam B和keep-ratio ρ扩展。
   - 训练：浅层MLP，使用KG三元组训练（逻辑对损失），均匀+度数感知负采样，上采样PLL短前缀，温度校准。
   - 服务：动态微批处理，每步保留top-ρ可行节点。
5. **路径评分与多样性选择**：
   - 评分函数：`Score(p)=α CUIOverlap + β SemTypeOverlap + γ/(1+ℓ(p)) + δ EdgeReliability - η HubPenalty`
   - 多样性：使用MMR（最大边际相关性）选择，相似度为Jaccard（CUI/关系）。
6. **TTFT感知打包**：
   - 将路径序列化为紧凑的CUI-关系元组，每个prompt只用一个名称映射表，减少预填充token数，降低TTFT。
   - 解码强制引用路径ID，验证器拒绝超出证据的声明。

### 算法流程（伪代码）
对于每个有序对(s,t)：
1. 从有向PLL查询D = d(s,t)
2. 初始化前沿为s，强制节点唯一性和类型掩码
3. 在时间/内存预算内：
   - 仅保留可行节点：g(x)+d(x,t) ≤ D
   - 通过f(x)或s(x)排序可行节点，扩展top-ρ（beam B）
   - 当到达t且路径长度≤H时，加入候选集
4. 按评分函数打分，经MMR选择top-k，打包为元组+名称映射表

## 6. 论文的主要结论与发现

1. **混合方法（PLL+AStarNet）在延迟/召回帕累托前沿上优于所有基线**：在k=3时，Ours达到0.74 recall @1.18s p95延迟，优于Text RAG（0.58@2.51s）、AStarNet-only（0.63@1.74s）、PLL-only（0.68@1.49s）。在等召回0.68时，p95延迟比PLL-only低21.0%，比AStarNet-only低32.2%。

3. **累积扩展数量级减少**：相比BFS/Bi-BFS，探索节点/边数少一个数量级；枚举器峰值RSS比Bi-BFS低2.4倍；GPU内存保持<6GB。

5. **PLL精确可行性是不可或缺的**：它提供了有界的搜索走廊，使学习型启发式能在不牺牲正确性的情况下高效剪枝。

## 7. 优点

- **方法创新性**：将精确距离预言机与学习型启发式有机结合，既保证了正确性又提高了效率，解决了组合爆炸问题。

- **可审计性和患者安全**：强制路径引用，验证器拒绝证据外内容，提供端到端可审计链式思维，降低临床风险。

## 8. 不足与局限

- **最短距离偏差**：只聚焦于最短距离D，可能遗漏稍长但重要的路径。作者提到可以考虑ε-松弛或k-最短简单路径作为未来工作。

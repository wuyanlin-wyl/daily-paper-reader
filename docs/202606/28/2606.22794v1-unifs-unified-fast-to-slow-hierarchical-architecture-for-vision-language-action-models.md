## 摘要
主流的快慢双系统视觉-语言-动作模型通过将高频动作专家与低频视觉-语言模型解耦以提高效率，却面临一个根本性的频率困境：大的更新间隔会导致因陈旧上下文而产生的语义漂移，而小的间隔则会侵蚀预期的计算节省。此外，由于动作专家仅以单一固定频率接收VLM的最后一层表示，丰富的中间特征被丢弃，限制了信息耦合和操作精度。受人类大脑多时间尺度神经处理的启发，我们引入了UniFS，一种统一的快慢架构，通过三个关键设计解决这些挑战。首先，我们将VLM层级按更新频率逐渐降低的方式分组，使浅层能够捕捉快速变化的动态，而深层则缓存稳定的语义上下文。其次，一种潜在向量反转机制重新调整了多尺度VLM特征与动作专家之间的交互顺序，将快速变化的表示与细粒度动作解码对齐，将慢速变化的表示与粗略规划对齐。第三，多级监督策略在时间尺度上强制执行从粗到细的学习层次。这些设计共同在单一骨干网络中实现了更丰富的跨频率信息传输，同时低频路径还额外保留了跨步骤的时间上下文。在LIBERO上的实验表明，UniFS实现了最先进的性能（平均成功率98.3％，比VLA-Adapter基线高出2.5％），同时将平均推理延迟从36.5毫秒降低到17.8毫秒（加速2.1倍）。在Franka平台上的真实机器人实验进一步验证了其实用性。代码已在https://github.com/linsun449/UniFS开源。

## Abstract
Mainstream Fast-Slow dual system vision-language-action models decouple a high-frequency action expert from a low-frequency vision-language model for efficiency, yet they face a fundamental frequency dilemma: large update gaps cause semantic drift from stale context, while small gaps erode the intended computational savings. Moreover, because the action expert receives only the VLM's final-layer representation at a single fixed frequency, rich intermediate features are discarded, limiting both information coupling and manipulation precision. Inspired by multi-timescale neural processing in the human brain, we introduce UniFS, a unified fast-to-slow architecture that resolves these challenges through three key designs. First, we stratify the VLM layers into groups with progressively decreasing update frequencies, enabling shallow layers to capture fast-changing dynamics while deeper layers cache stable semantic context. Second, a latent vector inversion mechanism re-routes the interaction order between multi-scale VLM features and the action expert, aligning fast-varying representations with fine-grained action decoding and slow-varying ones with coarse planning. Third, a multi-level supervision strategy enforces a coarse-to-fine learning hierarchy across temporal scales. Together, these designs enable richer cross-frequency information transfer within a single backbone, while the low-frequency pathways additionally preserve temporal context across steps. Experiments on LIBERO show that UniFS achieves state-of-the-art performance (98.3\% average success rate, a 2.5\% gain over VLA-Adapter baseline) while reducing average inference latency from 36.5~ms to 17.8~ms (2.1$\times$ speedup). Real-robot experiments on a Franka platform further validate its practical applicability. Code is opensourced at https://github.com/linsun449/UniFS.

# UniFS：面向视觉-语言-动作模型的统一快慢层次架构

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有 VLA 模型 (Vision-Language-Action) 受大模型推理延迟限制，控制频率仅 1–10 Hz，远低于实时控制所需 >50 Hz。主流的快慢双系统架构（如 GR00T-N1、Fast-in-Slow）将 VLM (慢系统) 与高频动作专家解耦，但面临根本性**频率困境**：更新间隔过大导致语义漂移（使用陈旧上下文），间隔过小则计算节省几乎消失。此外，动作专家仅接收 VLM 最后一层的固定频率表示，丢弃了丰富的中间层多尺度特征，限制了信息耦合与操作精度。
- **动机**：受人类大脑中多时间尺度神经处理（如 gamma 波、beta 波共存于统一回路）启发，观察到 VLM 不同层特征随时间变化的频率差异显著（浅层变化快、深层变化慢），因此提出在**单一 VLM 骨干内**实现多频率分层表达，而不是依赖分离的双模块。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将 VLM 的层按更新频率分层（浅层高频、深层低频），生成多时间尺度潜在向量，直接馈入动作专家；并通过反转交互顺序与多级监督，实现从精细动作到粗粒度规划的对齐。整个架构统一在一个骨干中，低频路径可缓存，从而加速推理并提供隐式记忆。

- **关键技术**：
    1. **Fast-to-Slow 架构 (FSA)**：将 VLM 层分为 K 组，每组分配不同更新间隔 \(n_k\)（例如 [1, 2, 4, 8, 16]），深层组更新更慢。公式上，若 \(t \equiv 0 \pmod{n_k}\) 则重新计算该组，否则重用上一时间步的输出。训练时通过 **Frequency Feature Replacement (FFR)** 策略：先全并行计算所有层的特征，再按频率进行索引替换（将每个块的起始特征复制到后续时间步），保持训练并行性。
    2. **潜在向量反转 (LVI)**：由于深层特征原本变化快（靠近动作输出），与所需“深层慢、浅层快”矛盾。通过反转 VLM 特征与动作专家的交互顺序——初始动作噪声与深层特征交互，细化后的动作与浅层特征交互——使浅层承担高频动态，深层保持稳定可缓存。
    3. **多级监督 (MLS)**：在动作专家的每一频率组施加辅助 L1 损失，鼓励低频组学习稳定、粗粒度的长期规划，高频组学习精细动作修正。总损失为所有频率组损失的平均。

- **训练**：采用 Temporal Batch Sampling：从轨迹中随机选取连续窗口，再从窗口内无重复采样 K 个时间步并保持时间顺序，保证因果性。骨干使用 Qwen2.5-0.5B，视觉编码器为 DINOv2 和 SigLIP，动作专家为 24 层 Transformer。

## 3. 实验设计

- **数据集/场景**：
    - **LIBERO 基准**：包含 130 个任务，分四个套件：LIBERO-Spatial (空间推理)、LIBERO-Object (物体泛化)、LIBERO-Goal (目标条件)、LIBERO-Long (长期多任务)。环境为 robosuite + Franka Panda 机器人。
    - **真实机器人**：Franka Research 3 (FR3) 平台，配合 Orbbec RGB-D 相机和 Intel RealSense 腕部相机。三个任务：Pick (抓取)、Stack (堆叠)、Exchange Boxes (交换盒子，需短期记忆)。

- **Benchmark 对比方法**：包括非 VLA 方法（Diffusion Policy）、标准 VLA（π0、π0.5、EO-1、X-VLA、OpenVLA 等）、增强 VLA（CoT-VLA、WorldVLA、MemoryVLA 等）、以及快慢 VLA（π0-FAST、VLA-Cache、PD-VLA、GR00T N1、VLA-Adapter 等）。UniFS 基线为 **VLA-Adapter**。

## 6. 论文的主要结论与发现

- UniFS 在 LIBERO 上实现**平均成功率 98.3％**（比基线 VLA-Adapter 提升 2.5 个百分点），推理延迟从 36.5 ms 降至 **17.8 ms**（2.1× 加速）。

## 7. 优点

- **创新性**：首次在单一 VLM 骨干内实现多时间尺度分层，从根本上消除双模块的频率困境，避免了硬耦合与信息丢失。
- **效率显著提升**：推理延迟减半以上，且性能不降反升，得益于低频层缓存和 LVI 设计。
- **隐式记忆能力**：低频路径自然保留历史上下文，无需显式记忆缓存，为涉及因果推理的任务带来优势。
- **训练与推理一致性**：FFR 策略使训练时仍然保持全并行计算，简化工程实现，避免分布偏移。
- **实验全面**：覆盖模拟和真实场景，包含性能、效率、消融、频率鲁棒性等多维度分析。

## 8. 不足与局限

- **训练无加速**：FFR 策略需要全并行前向，训练过程并未受益于异步执行，且要求较大 batch size 以保证时间多样性（文中提到需 64 全局 batch）。
- **频率配置敏感**：比例超过 24× 时性能开始下降，说明过快/过慢的极端配置仍需谨慎选择。
- **大规模模型未验证**：目前仅在 Qwen2.5-0.5B 上实验，未在 π0 等更大规模（7B+）模型上验证，泛化性存疑。
- **统计报告不足**：未提供多次运行的标准差，结果可靠性量化不足；真实机器人实验未与基线在相同场景下对比，无法直接判断 gain。
- **真实任务覆盖有限**：仅 3 个简单任务，且 Exchange Boxes 成功率仅 50%，离实际部署仍有距离。
- **潜在分布偏移**：LVI 和 FSA 可能干扰预训练语义表示，需要小心微调以避免退化。

### 2. Improving Reasoning in Vision-Language Models via Perception Verified Self-Training
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22158v1
- 方法流程：
  - 阶段1-数据生成：使用VLM对每个图像-问题对生成CoT，格式为[CAPTION: ... | REASONING: ... | CONCLUSION: ...]。
  - 阶段2-数据过滤：对每个生成样本，通过AnswerEval验证结论正确性，通过PerceptEval验证字幕质量（FG-CLIP+OCR）。
  - 阶段3-数据划分：根据双过滤结果，划分为easy（字幕正确且结论正确）、medium（字幕正确但结论错误）、hard（字幕错误）。
  - 阶段4-第一阶段训练：使用easy样本微调VLM，学习感知正确的推理。
  - 阶段5-字幕引导推理增强：对medium样本，将已验证的字幕与问题拼接作为输入，让VLM重新生成推理和结论，保留结论正确的样本。
  - 阶段6-第二阶段训练：使用easy样本和增强后的medium样本联合微调VLM。
- 关键模块/机制：
  - CoT模板（caption-reasoning-conclusion）：解耦感知与推理，使感知部分（字幕）可独立验证。；输出格式强制先描述图像内容（Caption），然后进行推理（Reasoning），最后给出结论（Conclusion）。
  - PerceptEval：无监督评估生成字幕的质量，确保字幕与图像内容一致。；使用FG-CLIP计算字幕与图像的全局特征对齐分数；使用OCR检测图像中的文本，并与字幕中的文本进行匹配，两项综合判定字幕是否准确。
  - AnswerEval：验证结论与真实答案是否一致。；简单比较生成的结论（如选项字母）与真实答案，相同则视为正确。
  - 数据划分策略：根据双过滤结果将数据分为easy/medium/hard，用于课程学习。；easy: 字幕正确且结论正确；medium: 字幕正确但结论错误；hard: 字幕错误。hard样本被丢弃。
  - 字幕引导推理增强（Caption-Guided Reasoning Enhancement）：针对medium样本，利用已验证的字幕纠正错误推理。；将问题与已验证的字幕拼接作为输入，让VLM重新生成推理和结论，仅保留结论正确的新样本用于第二阶段训练。
  - 两阶段课程学习：稳定自训练过程，逐步增加难度。；第一阶段用easy样本微调；第二阶段用easy样本和增强后的medium样本微调，全程仅使用感知正确的样本。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - PerceptEval评分：S = α * cosine_similarity(FG-CLIP(caption, image)) + β * OCR_accuracy(caption, image_text)，其中α,β为超参数。
  - 数据划分阈值：若S高于阈值θ_cap且结论正确→easy；若S≥θ_cap且结论错误→medium；若S<θ_cap→hard。
  - 字幕引导推理增强：输入格式为[Question: ... Verified Caption: ...]，输出格式不变（CAPTION被忽略或保留原字幕）。
- 训练/推理细节：
  - 训练使用标准语言建模损失（交叉熵）在生成的字幕、推理、结论上。
  - 第一阶段训练在easy样本上，第二阶段在easy+增强medium样本上。
  - 推理时采用相同的CoT模板，但PerceptEval只在训练数据构建时使用。
  - 模型架构：基于预训练的VLM（如LLaVA系列），进行指令微调。

### 3. Benchmarking Vision-Language Models for Microscopic Plant Image Understanding
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22497v2
- 方法流程：
  - 数据获取：从同行评审出版物和开放数据库系统搜索并收集显微图像，优先选择开放许可数据，对非开放数据集联系作者获取许可
  - 数据标准化：将异构格式（TIFF、JPEG、PNG）统一转换为JPEG，分配唯一标识符，构建结构化JSON元数据记录（包括生物域、成像模态、染色方法、宿主物种等）
  - 元数据验证：由两位生物学家独立审核所有属性，删除不一致样本，确保数据可靠性
  - VQA生成：基于元数据生成多选识别问题（从同字段有效值中采样干扰项）、计数问题（对真实计数进行附近整数扰动）、定位问题（生成空间不重叠的候选边界框）
  - 专家审查：由两位植物病理学和显微镜领域专家独立审核VQA对，排除不一致样本
- 关键模块/机制：
  - 数据标准化模块：统一异构数据格式和元数据结构；将所有图像转换为JPEG格式并保持原始分辨率；为每张图像分配唯一ID保留来源信息；构建JSON记录存储生物域、成像模态、染色方法、宿主物种等关键属性，通过查阅原始文献和领域专家验证确保准确性
  - VQA生成模块：基于标准化元数据自动生成带干扰项的多选题、计数和定位问题；识别任务从同元数据字段的其他有效值中采样干扰项；计数任务对真实计数加/减整数生成数值相近干扰项；定位任务生成非重叠且大小相似的空间扰动边界框。所有问题格式统一为多选，计数和定位还支持直接预测格式
  - 任务定义模块：定义10个评估任务覆盖微观图像理解的不同方面；包括全局特征任务（模态识别、域分类、树脂识别、染色/染料识别）和细粒度任务（宿主识别、病原分类、细胞器检测、器官预测、目标计数、目标定位）。前8个任务为四选一多选，后两个支持多选和直接预测两种评估设置
- 公式/目标函数/指标定义：
  - Micro accuracy = ∑_{i=1}^C TP_i / ∑_{i=1}^C N_i
  - Macro accuracy = (1/C) ∑_{i=1}^C (TP_i / N_i)
  - 计数任务：Mean Absolute Error (MAE) 和 Root Mean Square Error (RMSE)
  - 定位任务：mean Average Precision at IoU threshold 0.5 (mAP@0.5) 和 average IoU
- 算法细节：
  - 数据标准化流程：对异构文件名重新组织，避免冲突；所有图像统一为JPEG格式；构建JSON元数据记录，关键属性通过多方验证确保正确性
  - VQA干扰项生成：识别任务干扰项从同字段其他有效值中随机采样；计数任务干扰项为真实值±1~3的整数；定位任务干扰框为真实框平移一定像素生成且保证不重叠
  - 评估管道：所有模型使用统一输入处理和提示设计，将图像和任务特定提示输入VLM，解析输出并与标准答案比较。识别任务计算Macro/Micro准确率，计数任务计算MAE/RMSE，定位任务计算mAP@0.5和IoU
- 训练/推理细节：
  - 所有模型在零样本设置下评估，不进行微调
  - 使用统一评估管道：标准输入尺寸、相同提示模板（如多选问题输出选项字母，计数输出整数，定位输出[x1,y1,x2,y2]格式）
  - 计算资源：两台NVIDIA A6000 GPU
  - 输出格式违规视为错误（如多选输出非字母、计数输出非整数、定位输出格式错误）

### 4. UniFS: Unified Fast-to-Slow Hierarchical Architecture for Vision-Language-Action Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22794v1
- 方法流程：
  - 输入：RGB图像、语言指令、本体感知状态、带噪声动作先验。
  - 视觉编码：DINOv2和SigLIP生成图像patch嵌入，与tokenized文本指令拼接。
  - LLM处理：大语言模型（LLaMA2/Qwen）处理拼接序列，提取所有中间层隐藏状态作为多尺度潜在向量。
  - 层分组与异步更新：将VLM层分为K组，每组更新频率nk满足n1=1<n2<...<nK，根据公式(7)进行异步计算。
  - 潜在向量反转：动作专家先与深层特征交叉注意力（粗规划），后与浅层特征交互（细动作解码）。
  - 动作专家：多层Transformer块，通过交叉注意力融合潜在向量与动作查询，最后MLP头输出动作块A∈R^{T×D}。
  - 输出：机器人动作序列，每个动作7维（位置、姿态、夹爪）。
- 关键模块/机制：
  - Fast-to-Slow Architecture (FSA)：实现VLM层的异步执行，产生多时间尺度潜在向量。；将VLM层分为K组，每组有不同更新频率nk（n1=1, nK=N）。对于第k组在时间t，若t被nk整除则计算Fk(h_{k-1})，否则复用前一步输出h_{k}^{(t-1)}。公式(7)。
  - Latent Vector Inversion：反转VLM层与动作专家的交互顺序，使深层特征稳定、浅层特征高频。；初始噪声动作提案先与深层（慢频）潜在向量交互，得到粗规划；然后与浅层（快频）潜在向量交互，得到细粒度动作。此举将高频动态转移到浅层，深层可缓存。
  - Multi-Level Supervision：在不同频率组施加辅助损失，促进粗到细学习。；对动作专家每个频率组k的隐藏状态h_k，通过共享轻量MLP解码动作，计算L1损失与真值动作比较，总损失为所有组损失的平均：L_total = (1/K) Σ_k L1(f(h_k), A_gt)。
  - Frequency Feature Replacement (FFR)：训练时保持批并行计算，同时模拟异步更新。；对所有时间步和所有层进行完整前向计算得到H∈R^{T×F×N×C}，然后根据频率f，将每个块起始特征复制到同一块内后续时间步：H'[t,f,:,:] = H[⌊t/f⌋*f, f, :, :]。公式(8)。
  - Temporal Batch Sampling：为训练提供时序一致的批量数据。；从轨迹中随机选择一个连续窗口（长度W），从中均匀采样K个时间步，排序保持因果顺序，若轨迹长度不足则末尾填充。详见Algorithm 1。
- 公式/目标函数/指标定义：
  - 动作块生成：A = [a_1,...,a_T] = π_θ(O_vis, L_task)，其中a_i∈R^7 (Δx,Δy,Δz,Δϕ,Δθ,Δψ,g)。
  - 传统慢速表示：v_slow = π_VLM(O_vis, L)，快速动作：A = π_Expert(v_slow, O_sen, O_prop)。
  - UniFS多时间尺度：V_f2s = π_VLM(O_vis, L_task, O_sen, O_prop)，动作：A = π_Expert(V_f2s)。V_f2s = {v_k}_{k=0}^{K-1}。
  - 分层更新规则：h_k^{(t)} = F_k(h_{k-1}^{(t)}) 若 t ≡ 0 mod n_k，否则 h_k^{(t-1)}。
  - FFR替换：H'[t,f,:,:] = H[⌊t/f⌋*f, f, :, :]。
  - 总损失：L_total = (1/K) Σ_{k=0}^{K-1} L1(f(h_k), A_gt)。
- 算法细节：
  - Temporal Batch Sampling (Algorithm 1): 从轨迹中随机选择长度为W的连续窗口，无放回采样K个索引，排序后组成批次，不足则填充。
  - Frequency Feature Replacement (Algorithm 2): 输入H∈R^{T×F×N×C}和频率f，对每个时间步t和层f，从最近更新时刻复制特征：k = ⌊t/f⌋*f，H'[t,f,:,:] = H[k,f,:,:]。
  - 推理时异步执行缓存：只有频率整除当前时间步的层才重新计算，其余层从缓存读取，实现加速。
- 训练/推理细节：
  - 训练时使用时间批采样和FFR保持批并行，避免串行计算。
  - 训练时使用多级监督，所有频率组共同优化。
  - 推理时利用缓存机制，只计算必要层，与训练时的异步模式对齐。
  - 频率组设置：n1=1（最快），nK=N（最慢），具体N值在论文中未明确，推断为最大窗口大小。

### 5. TTFT-Aware Graph Chain-of-Thought:Distance-Indexed Neural A* for Low-Hallucination Multi-Hop Medical Reasoning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.23108v1
- 方法流程：
  - 输入：临床提示 → 实体链接（NER+UMLS）得到种子CUIs集合S
  - 步骤1：对于每对(s,t)查询定向PLL服务，获取精确距离D=d(s,t)，并建立可行性走廊：g(x)+d(x,t)≤D
  - 步骤2：在走廊内，使用GPU批处理的AStarNet对可行节点进行优先级排序，扩展保持率ρ下的top候选，满足简单路径和类型约束，直到达到t或预算耗尽
  - 步骤3：收集所有候选路径，按临床评分函数（CUI重叠、语义类型、长度、边可靠性、枢纽惩罚）打分
  - 步骤4：通过最大边际相关性（MMR）选择多样化top-k路径
  - 步骤5：紧凑打包：将路径序列化为CUI-关系元组，每个提示附带一个名称映射，减少token数
  - 输出：包含路径ID的紧凑证据，用于强制引用的流式LLM生成
- 关键模块/机制：
  - 定向PLL距离预言：提供精确的定向最短距离查询，子毫秒级响应，定义可行搜索走廊；为每个节点存储out-labels和in-labels，查询时取Lout(s)∩Lin(t)中最小dout(s,w)+din(w,t)；通过剪枝BFS/SSSP构建标签，只保留未覆盖的访问；部署在RAM中通过低延迟RPC服务，快照重建。
  - AStarNet神经启发式：在PLL走廊内为候选节点分配优先级，导向更优的扩展顺序；学习h_θ(x|t,C)，输入包括实体/关系嵌入、语义类型指示器、前缀特征等；使用浅层MLP，在KG三元组上训练（logistic pairwise loss），上采样短PLL可行前缀上的边；推理时用动态微批处理和top-ρ过滤，保持GPU延迟可忽略。
  - 路径评分与多样性选择：对候选路径进行临床效用评分，并通过MMR选择多样化集合；评分函数Score(p)=αCUIOverlap+βSemTypeOverlap+γ/(1+len)+δEdgeReliability-ηHubPenalty；MMR选择：max_p λScore(p)-(1-λ)max_{q∈P}Sim(p,q)，相似度为CUI/关系上的Jaccard系数。
  - TTFT感知的紧凑打包：将路径序列化为紧凑的token表示以减少预填充和TTFT；将路径表示为CUI-关系元组列表，每个提示只使用一个名称映射表来展开CUI；解码时强制引用路径ID，验证器拒绝无证据的声称。
- 公式/目标函数/指标定义：
  - exact directed distance: D = min_{w∈Lout(s)∩Lin(t)} [dout(s,w) + din(w,t)]
  - feasibility constraint: g(x) + d(x,t) ≤ D (式2)
  - A*优先级: f(x)=g(x)+λh_θ(x|t,C) 或 Beam分数: s(x)=λh_θ(x|t,C)-μg(x)
  - 路径评分: Score(p)=α·CUIOverlap(p)+β·SemTypeOverlap(p)+γ/(1+ℓ(p))+δ·EdgeReliability(p)-η·HubPenalty(p) (式3)
  - MMR选择: max_p λ·Score(p) - (1-λ)·max_{q∈P} Sim(p,q)
- 算法细节：
  - 实体链接使用scispaCy或MedCAT将提及映射到UMLS CUIs，应用类型允许列表和置信度阈值
  - PLL构建按主节点顺序进行剪枝BFS/SSSP：当访问已被现有标签覆盖时剪枝；同时构建正向图G和反向图G^T
  - 路径枚举只考虑满足g(x)+d(x,t)≤D且节点唯一、符合类型/关系掩码的前缀；可选对称的中途相遇搜索
  - AStarNet训练使用逻辑配对损失，负采样包括均匀和度感知采样，对短PLL可行前缀上的边上采样，并温度校准
  - 推理时，每次扩展只保留top-ρ占比的可行节点，通过动态微批处理在GPU上计算启发式值
  - 路径打包：每个路径存储为(v0,r0,v1,...,vℓ)的紧凑形式，所有CUI由单个名称映射表替换；解码强制要求每条声称引用一个路径ID
  - LLM生成时，使用验证器检查每条声称是否在所选路径的证据内，否则拒绝或触发弃权
- 训练/推理细节：
  - AStarNet训练数据：从KG三元组生成，以短PLL可行前缀作为正例，负例包括均匀采样和度感知采样
  - 训练损失：逻辑配对损失（pairwise logistic loss），对正例和负例对进行排序
  - 温度校准：训练后对启发式输出进行温度缩放以校准置信度
  - 推理时：AStarNet服务使用动态微批处理（dynamic microbatching）和预热池（warm pools），保持GPU负载平稳
  - PLL服务在RAM中部署，支持LRU缓存热(s,t)对，蓝色/绿色部署进行快照重建
  - 整个系统在DGX级系统上运行，使用多个A100 GPU

### 6. T-VSS: Test-Time Visual Subspace Steering for Adversarial Robustness of Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.23132v1
- 方法流程：
  - 输入：受攻击测试图像x；生成N+1个随机视角（原始图像+增强视图）
  - 编码：通过CLIP图像编码器提取所有视图的视觉特征
  - 残差构建：计算每个增强视图特征与原始图像特征的差异，形成特征残差矩阵
  - 子空间构建：对残差矩阵进行SVD，取前m个奇异向量构成低秩子空间（m由方差阈值决定）
  - 校正学习：在低秩子空间内优化一个共享的校正向量，通过可靠性加权熵最小化（单步AdamW更新）
  - 输出：将校正向量加到原始特征上，得到校正后的特征用于分类
- 关键模块/机制：

### 11. Revealing Training Data Exposure in Vision Language Large Models via Parameter Gradients
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.24774v1
- 方法流程：
  - 阶段1：梯度特征构建。输入：待审计样本(x_img, x_txt)、目标VLLM模型M。处理：对输入进行前向和反向传播，计算损失L(x)关于所有参数Θ的梯度∇ΘL(x)；选取最后几层参数矩阵，对每个矩阵W按行和列切片，得到梯度特征向量集合G(x) = {g1(x),...,gK(x)}。输出：K个梯度特征向量。
  - 阶段2：噪声特征掩码。输入：参考训练数据集D_train_ref和参考非训练数据集D_non_ref，以及它们的梯度特征集。处理：计算参考训练数据的平均梯度向量g_bar_k；对每个参考样本计算余弦相似度到g_bar_k，得到相似度向量s_train_i和s_non_j；聚合得到平均相似度向量s_bar_train和s_bar_non；计算敏感度间隙Δ_k = s_bar_train_k - s_bar_non_k；设定阈值τ，生成掩码m_k = 1 if Δ_k > τ else 0。输出：掩码向量m∈{0,1}^K。
  - 阶段3：数据审计。输入：待审计样本x的梯度特征向量集合G(x)、掩码m、参考训练平均梯度g_bar_k。处理：计算x的余弦相似度向量s(x)；应用掩码得到s_masked(x)=s(x)⊙m；计算平均掩码相似度s_masked_bar = (1/||m||1)∑_k s_k(x)·m_k；根据阈值γ决策：若s_masked_bar > γ则判定为训练数据。输出：二元决策结果A(M,x)∈{0,1}。
- 关键模块/机制：
  - 梯度特征构建模块：从参数梯度矩阵中提取功能可解释的切片特征，降低计算复杂度并保留功能特异性。；对于选定的参数矩阵W∈R^{N_out×N_in}，分别沿行和列进行切片：行切片g_row(i)=∇W[i,:]L(x)∈R^{N_in}（对应输出功能单元），列切片g_col(j)=∇W[:,j]L(x)∈R^{N_out}（对应输入特征通道）。将多个参数矩阵的切片合并得到K个梯度特征向量。实践中仅提取最后几层参数矩阵的切片。
  - 噪声特征掩码模块：基于参考数据自动识别训练敏感的功能切片，滤除噪声切片。；利用参考训练数据D_train_ref和参考非训练数据D_non_ref，对每个切片k计算敏感度间隙Δ_k = s_bar_train_k - s_bar_non_k，其中s_bar_train_k是参考训练样本平均余弦相似度到参考训练平均梯度的第k个分量。设定阈值τ，构造掩码m_k = 1 if Δ_k > τ else 0。切片k的Δ_k越小表示该切片对训练数据不敏感，被标记为0。
  - 数据审计模块：通过掩码相似度与参考训练基线比较，做出最终成员判定。；计算待审计样本x对每个切片k的余弦相似度s_k(x)到参考训练平均梯度g_bar_k；应用掩码向量m得到s_masked(x)；计算平均掩码相似度s_masked_bar = (1/||m||1)∑_k s_k(x)·m_k；若s_masked_bar > γ则输出1（训练数据），否则输出0。γ为决策阈值，实际评估使用AUROC作为阈值无关指标。
- 公式/目标函数/指标定义：
  - 损失函数L(x)通过前向传播计算，梯度∇ΘL(x)通过反向传播获得。
  - 参数矩阵W的行切片：g_row(i)(x,W)=∇W[i,:]L(x)∈R^{N_in}, i=1,...,N_out
  - 参数矩阵W的列切片：g_col(j)(x,W)=∇W[:,j]L(x)∈R^{N_out}, j=1,...,N_in
  - 参考训练平均梯度：g_bar_k = (1/N)∑_{i=1}^N g_k(x_train_i), k=1,...,K
  - 余弦相似度：s_train_i,k = (g_k(x_train_i)·g_bar_k) / (||g_k(x_train_i)||·||g_bar_k||) ∈ [-1,1]
  - 参考训练平均相似度：s_bar_train = (1/N)∑_{i=1}^N s_train_i ∈ R^K
- 算法细节：
  - 梯度计算：对每个输入样本，执行一次完整的前向传播得到损失L(x)，然后反向传播计算所有参数的梯度。
  - 切片选取：仅对最后几层（通过敏感性分析确定）的参数矩阵进行行列切片，每层包括视觉编码器、语言模型和跨模态融合模块的参数。
  - 参考数据构建：需要少量确认的训练和非训练样本（各N个），计算其梯度特征向量并存储。
  - 掩码生成：计算每个切片k的Δ_k，按阈值τ（需要调参）得到0/1掩码。
  - 审计时：对待审计样本计算平均掩码相似度，与固定阈值γ比较做出决策，但常用AUROC评估。
- 训练/推理细节：
  - 本方法属于后训练审计，不需要重新训练或微调模型，仅需对目标模型进行推理时的梯度计算。
  - 训练过程中，模型参数沿训练数据梯度方向更新，导致训练数据梯度在收敛区域稳定对齐；非训练数据梯度则方向随机。
  - 该方法适用于预训练和微调后的VLLM，不依赖训练超参数或数据增强策略。
  - 注意：需要白盒访问（模型参数和梯度计算能力）和少量参考数据。

### 17. Staying VIGILant: Mitigating Visual Laziness via Counterfactual Visual Alignment in MLLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.26387v1
- 方法流程：
  - 双路前向传播：对于每个训练样本，同时运行正常注意力（看到）和屏蔽文本-视觉注意力（盲）的两个前向，共享权重。
  - 计算VIG：对比看到和盲状态下偏好响应的对数概率差，即log π_θ(y_w|x_v,x_t) - log π_θ(y_w|x_∅_v,x_t)。
  - 计算动态门控因子α = 1 - tanh(|VIG|)，根据当前VIG值自动调整正则化强度。
  - 生成硬负样本：使用参考模型通过自对抗方式生成包含合理但缺失细节的响应y_hard。
  - 计算最终损失L_VIGIL = L_DPO(y_w, y_hard) + λ·α·L_CVD，更新模型参数。
- 关键模块/机制：
  - 反事实视觉掩码（Counterfactual Visual Masking）：模拟盲状态，移除视觉模态对文本的影响。；在Transformer每层中，将文本查询与视觉键/值之间的注意力权重置零，输入张量不改变，仅改变注意力连接。
  - 视觉信息增益约束（VIG Constraint）：最大化视觉输入与响应之间的互信息。；VIG = log π_θ(y|x_v,x_t) - log π_θ(y|x_∅_v,x_t)，通过优化约束E[VIG]≥δ迫使响应包含足够视觉信息。
  - 动态门控（Dynamic Gating）：自适应平衡DPO与CVD损失。；α = 1 - tanh(|VIG|)，当VIG大时α小，减少正则化；VIG小时α大，加强约束。
  - 自对抗硬负样本挖掘（Self-Adversarial Hard Negative Mining）：生成具有挑战性的负样本，提升细粒度视觉判别。；使用参考模型根据提示生成包含合理但图像中缺失细节的响应作为y_hard。
- 公式/目标函数/指标定义：
  - VIG(y, x_v|x_t) = log π_θ(y|x_v,x_t) - log π_θ(y|x_∅_v,x_t)
  - 约束优化: max_{π_θ} E[D_DPO(π_θ)] s.t. E[VIG(y_w,x_v|x_t)] ≥ δ
  - 拉格朗日目标: L(π_θ,λ)=J_DPO(π_θ)+λE[log π_θ(y_w|x_v,x_t)-log π_θ(y_w|x_∅_v,x_t)]
  - CVD损失: L_CVD(π_θ)=-E[log σ(β log π_θ(y_w|x_v,x_t)/π_ref(y_w|x_v,x_t) - β log π_θ(y_w|x_∅_v,x_t)/π_ref(y_w|x_∅_v,x_t))]
  - 动态门控: α = 1 - tanh(|log π_θ(y_w|x_v,x_t) - log π_θ(y_w|x_∅_v,x_t)|)
  - VIGIL总损失: L_VIGIL = L_DPO(y_w, y_hard) + λ·α·L_CVD
- 算法细节：
  - 双路前向共享所有参数，仅注意力掩码不同，避免额外输入构造。
  - 盲路径通过掩码文本-视觉注意力实现，无需图像损坏。
  - 动态门控因子α按batch计算，根据当前VIG幅度自动调节。
  - 硬负样本y_hard由参考模型在无负样本情况下生成，通过提示产生合理但虚假的细节。
- 训练/推理细节：
  - 使用OpenRLHF框架，全参数微调，单epoch。
  - 学习率5e-7，余弦衰减调度，warmup比例0.03。
  - KL惩罚系数β=0.1，批大小：72B模型2048，7B模型1024。
  - 采用DeepSpeed ZeRO-3、FlashAttention-2、FSDP加速和内存优化。
  - 训练时使用反事实掩码，推理时正常前向，无额外开销。

  - 诊断集为保留的OOD数据集，与训练集分布不同，确保VHS反映泛化行为而非记忆

### 21. Improving Reasoning in Vision-Language Models via Perception Verified Self-Training
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.22158v2
- 方法流程：
  - 阶段1：数据生成与过滤。使用VLM对每个图像-问题-答案三元组生成CoT（遵循caption-reasoning-conclusion模板），然后通过PerceptEval评估描述质量，通过答案正确性评估结论正确性，将数据划分为简单（描述正确且结论正确）、中等（描述正确但结论错误）、困难（描述错误）三组。
  - 阶段2：Stage 1训练。使用简单样本对VLM进行微调，训练模型生成基于正确描述的推理。
  - 阶段3：描述引导推理增强。对中等样本，将验证过的描述作为额外上下文注入问题，让VLM重新生成推理和结论，仅保留新结论正确的样本。
  - 阶段4：Stage 2训练。将简单样本和增强后的中等样本合并，进一步微调VLM，增强模型利用正确描述进行推理的能力。
- 关键模块/机制：
  - PerceptEval：无监督评估生成描述的质量，确保描述准确反映图像内容。；使用FG-CLIP计算生成描述与图像的全局对齐分数，同时使用OCR检测（如[6]）验证图像中嵌入的文本是否被正确描述。两个分数结合得到最终描述质量信号。
  - 双过滤机制（Dual Filtering）：同时基于感知正确性（PerceptEval）和答案正确性筛选训练样本。；对每个样本，先通过PerceptEval判断描述是否正确，再通过答案正确性判断结论是否正确。只有描述正确且结论正确的样本进入Stage 1；描述正确但结论错误的样本进入Stage 2的增强流程。
  - 描述引导推理增强（Caption-Guided Reasoning Enhancement）：对中等样本，利用验证过的描述辅助模型重新生成推理。；将验证过的描述（caption）附加到问题后，作为额外上下文输入模型，要求模型重新生成推理和结论。仅保留新结论与真实答案一致的样本用于后续训练。
  - 两阶段课程学习（Two-Stage Curriculum Learning）：逐步引入不同难度的样本，稳定训练过程。；Stage 1：仅使用简单样本（描述正确+结论正确）微调模型。Stage 2：将简单样本与经描述引导增强后结论正确的中等样本合并，继续微调。
- 算法细节：
  - 数据划分：对于每个训练样本（图像、问题、答案），让VLM生成CoT（遵循caption-reasoning-conclusion模板）。然后使用PerceptEval评估caption质量，使用答案匹配评估conclusion正确性。根据两者结果将样本分为easy（caption正确且结论正确）、medium（caption正确但结论错误）、hard（caption错误）。
  - Stage 1：使用easy样本微调VLM，训练若干周期。
  - 描述引导增强：对于每个medium样本，将验证过的caption作为输入的一部分，与问题拼接，让VLM重新生成reasoning和conclusion。如果新conclusion与正确答案一致，则保留该增强样本。
  - Stage 2：使用easy样本和增强后的medium样本合并，继续微调VLM。
- 训练/推理细节：
  - 训练时：每个阶段仅使用经过感知验证（即描述正确）的样本。Stage 1仅用easy样本；Stage 2用easy样本和增强后的medium样本。hard样本被丢弃不参与训练。
  - 推理时：模型直接生成完整的caption-reasoning-conclusion，但最终结论用于回答。PerceptEval仅在训练数据构建阶段使用，不在推理时使用。
  - 对比基线：标准自训练（STaR）和R3V仅基于答案正确性过滤，而本方法额外引入感知验证。

### 22. Venice-H1: Failure-Aware Query Re-Ranking with Multi-Scale Grid Signatures for Referring Image Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.22546v1
- 方法流程：
  - 1. 冻结的DeRIS-L骨干生成N个候选掩码、查询嵌入、检测分数
  - 2. 特征提取：从掩码概率图计算标量统计（均值、峰值、面积、空间不确定性）和多尺度网格签名（4x4,8x8,16x16的平均池化、最大池化、边界能量）
  - 3. 特征组装：每查询特征fi = [qi; si; μi; p̂i; ai; σi; gi]
  - 4. 重排序器：MLP投影到隐层，Transformer编码，Gain Predictor预测IoU增益，Failure Gate预测失败概率
  - 5. 门控选择：若失败概率>阈值则选增益最大的查询，否则默认查询0
- 关键模块/机制：
  - Multi-Scale Grid Signatures：将候选掩码的空间结构编码为紧凑的675维向量，区分正确局部与错误覆盖；对概率图Pi在4x4、8x8、16x16网格上分别进行平均池化和最大池化，并计算边界能量（相邻网格梯度绝对值均值），拼接所有尺度的结果得到gi ∈ R^{675}。
  - Transformer Encoder：在候选间进行自注意力推理，捕捉异常掩码与共识的偏离；3层pre-norm Transformer，8头注意力，GELU激活，输出每个候选的编码hi。
  - Gain Predictor：预测每个候选相比默认查询的IoU增益；两层MLP（ReLU激活）将hi映射为标量Ĝi，训练使用smooth L1损失回归ΔIoU。
  - Failure Gate：预测默认查询是否次优，决定是否激活重排序；从全局特征向量r（Transformer输出均值/最大池化、默认查询输出、原始分数和掩码均值拼接）经MLP和sigmoid输出失败概率p̂_fail。
- 公式/目标函数/指标定义：
  - Pi = σ(Mi) (概率图从logit计算)
  - gμ_{i,G} = AvgPool_{G×G}(Pi), gmax_{i,G} = MaxPool_{G×G}(Pi)
  - boundary energy: bi,G = 0.5*(mean|∇x gμ_{i,G}| + mean|∇y gμ_{i,G}|)
  - grid signature: gi = concat over scales of [gμ; gmax; bi] at G=4,8,16
  - 总损失: L = L_gate + λ L_gain, λ=5
  - L_gate: focal BCE (γ=2, auto wpos) on binary failure label
- 算法细节：
  - 推理算法（Algorithm 1）: 1) DeRIS前向得到{qi, Mi, si}; 2) Pi = σ(Mi); 3) 提取标量统计和网格签名; 4) 组装fi; 5) 重排序器前向得到p̂_fail, ĝ_i; 6) 若p̂_fail>τ则选argmax ĝ_i，否则默认0; 7) 返回对应掩码。
  - 训练使用缓存特征，骨干冻结，仅更新重排序器参数（~11M）。
  - Failure Gate的全局特征r = [mean_pool(h), max_pool(h), h_default, s_all, μ_all] 拼接。
  - 阈值τ在验证集上grid search优化Δfull。
- 训练/推理细节：
  - 训练：AdamW，lr=5e-4，wd=1e-4，余弦调度，3轮warmup，20 epochs，batch 512，FP16。
  - 损失权重λ=5，focal BCE (γ=2, auto wpos)用于二分类，smooth L1用于IoU回归。
  - 推理：<1ms延迟，仅需骨干前向一次+重排序器前向。
  - 训练数据：126k样本（0.28%失败率），使用IoU回归密集监督缓解类别不平衡。

### 23. HPP: Hierarchical Programmatic Probing for Long Video Understanding by Decoupling Perception and Reasoning
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.21734v1
- 方法流程：
  - 输入：原始视频、用户查询、系统提示
  - 阶段1 - 层次分割：利用视频码流中的I帧位置将帧划分为候选镜头（shot），合并视觉相似的相邻镜头；计算每个镜头的能量γ_i = Σ(||m_t||_1 + λ||r_t||_1) 作为信息密度度量；进一步将镜头分组为场景和全局语义簇。

  - 输出：最终答案文本
- 关键模块/机制：
  - 信息密度感知层次分割（Hierarchical Segmentation）：将长视频高效划分为多尺度片段，为后续检索和探测提供结构化索引；利用视频压缩码流信息：提取I帧时间戳作为镜头边界，将帧划分为候选镜头；合并视觉相似（关键帧L2距离<阈值τ_s）的相邻镜头；每个镜头计算能量γ_i = Σ(∥m_t∥_1 + λ∥r_t∥_1) 作为信息密度代理；必要时进一步将镜头聚类为场景和全局语义簇，使用蒸馏视觉编码器提取特征。
  - 运动自适应后期交互语义检索（Late-Interaction Semantic Retrieval）：根据查询定位最相关的视频片段，支持粗到细的时序定位；首先计算所有镜头嵌入与查询嵌入的余弦相似度，选出top-K候选镜头；然后对每个候选镜头内的帧进行密集token提取，通过查询token与帧token的后期交互（类似ColBERT）计算相似度矩阵，聚合得到每帧的匹配得分，定位最佳帧或短片段。
  - 结构化探测函数（Structured Probing Functions）：提供LLM在代码环境中导航视频的API，控制探索动作空间；包括函数如：probe_segment(start_time, end_time)返回关键帧和摘要；sample_frames(shot_id, n)返回均匀采样的n帧；search(query)调用语义检索返回相关片段列表；perceive(frames)调用VLM分析指定帧。函数封装视频访问细节，返回结构化输出（文本/数字/图像）。
  - 轻量级VLM（Lightweight VLM）：执行按需的精细时空感知，将感知结果以文本形式返回给LLM；一个较小的预训练视觉语言模型（如LLaVA-7B），仅在LLM主动调用perceive函数时处理少数帧或短片段，生成描述或回答问题。不参与全局推理或策略制定。
- 公式/目标函数/指标定义：
  - 镜头能量：γ_i = Σ_{t∈s_i} (∥m_t∥_1 + λ∥r_t∥_1)，其中m_t, r_t分别为帧t的运动向量和残差，λ为权重。
  - 镜头合并条件：∥f_{t_k} - f_{t_{k+1}}∥ < τ_s，其中f_{t_k}为第k个镜头的关键帧。
- 算法细节：
  - 分层分割算法：1) 从压缩视频中解码I帧时间戳列表；2) 以I帧为边界划分初始镜头；3) 计算相邻关键帧L2距离，若小于阈值则合并；4) 对每个镜头计算能量γ_i；5) 可选：使用蒸馏编码器提取镜头特征，聚类为场景和语义簇。
  - 语义检索算法：1) 对每个镜头计算全局嵌入（均值池化帧特征）；2) 计算查询嵌入与全局嵌入的余弦相似度，选出top-K；3) 对每个候选镜头，提取帧级token；4) 计算查询token与帧token的后期交互相似度（max_sim），得到帧得分；5) 选择得分最高的帧或连续帧片段。
  - 交互式探测算法（REPL循环）：LLM接收系统变量（元数据、查询、初始变量）；生成Python代码 → 执行代码 → 获取终端输出（文本、数字或图像表示） → LLM更新内部状态并决定下一步（继续探测或调用FINAL）；循环直至调用FINAL。每次代码执行后，LLM根据输出更新推理。
- 训练/推理细节：
  - 无需训练：HPP完全基于预训练模型（编码LLM+轻量级VLM），无需额外微调。
  - 推理流程：输入视频先经过离线层次分割和语义索引构建（一次性预处理）；然后LLM在交互式编码环境中进行多轮代码生成-执行循环，每轮可能调用VLM；最终LLM输出答案。
  - VLM仅在需要时被调用，减少计算开销；编码LLM在独立容器中执行代码，接收结构化反馈。

### 24. Rethinking the Adaptation of Vision Foundation Models for Efficient Cell Segmentation

- 方法流程：

- 公式/目标函数/指标定义：

  - 余弦相似度计算显著性: a_i = (t_i · t_cls^T) / (||t_i|| ||t_cls||) (公式2)
  - PCA提取形态特征: m_i = PCA_K({t_i}) ∈ R^K (公式3)
  - 联合训练目标: L_Cell = L_CE + L_Dice + λ1 * L_MSE, 其中λ1=10 (公式6)
- 算法细节：
  - 冻结DINOv3编码器，仅训练CSP-Encoder和SM-Decoder。
  - CSP-Encoder中，显著性图a通过逐层自注意力后CLS token对空间token的余弦相似度获得。
  - PCA在每张图像的token集上独立执行，保留K个主成分（实验中K未明确，但为固定值）。
  - SM-Decoder中的双向transformer采用可变形注意力或标准自注意力（原文引用[11]）。

### 25. Novelty-Aware Agentic Retrieval: Comparing Research Contributions Through Structured Multi-Step Reasoning

- 方法流程：
  - 阶段1 - 查询分析（Query Analysis）：解析用户查询，生成一组子查询（默认2个）以覆盖不同方面，输出查询列表。

  - 相关性排序器（Relevance Ranker）：对候选论文按与原始查询的相关性排序，确保Top-K相关。；使用原始查询的嵌入（来自all-MiniLM-L6-v2）与候选论文嵌入的余弦相似度进行排序，返回Top-5论文。实验中使用FAISS IndexFlatL2进行精确最近邻搜索。

  - 三遍比较代理（Three-Pass Comparison Agent）：依次执行三遍比较，生成论文级重叠和问题×方法空白矩阵。；第一遍（Pass 1）：对每篇论文的贡献记录进行摘要和对比。第二遍（Pass 2）：识别所有论文对之间的重叠内容（如共享问题或方法）。第三遍（Pass 3）：基于所有论文的问题集和方法集，构建问题×方法矩阵，标记被覆盖的单元格，空白单元格表示未探索组合。使用LLM生成每步输出。

  - Recall@5 = 相关信息论文数 / 总相关论文数
  - MRR（Mean Reciprocal Rank）= 平均倒数排名
  - Jaccard相似度（用于查询敏感性）= |A ∩ B| / |A ∪ B|

### 29. One-Shot Data Selection for Medical Image Classification via Graph Coverage
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.22002v1
- 方法流程：
  - 输入：带标签训练集D，预训练编码器f（UNI），每类预算B。
  - 第1步：用f提取所有样本的嵌入zi，进行L2归一化。
  - 第2步：基于余弦相似度构建所有样本的kNN图，得到对称邻接矩阵A。
  - 第3步：对称归一化得到Asym = D^{-1/2} A D^{-1/2}，计算覆盖核K = Asym + A^2_sym。
  - 第4步：在每类预算约束下，使用贪心设施选址（式3）选择子集S，使总覆盖∑_i max_{j∈S} K_i最大。
  - 输出：每类B个样本的平衡子集。
- 关键模块/机制：
  - kNN图构建：从冻结基础模型嵌入中捕获数据流形的局部结构。；对N个L2归一化的嵌入使用余弦相似度，每样本连接k个最近邻，得到加权邻接矩阵A，然后对称化A ← max(A, A^T)。
  - 覆盖核（两项多项式近似）：量化样本间覆盖关系，同时考虑直接邻居（1跳）和共享邻居（2跳）。；先对A进行对称归一化得Asym = D^{-1/2} A D^{-1/2}（D为度矩阵）。然后计算K = Asym + A^2_sym，其中A^2_sym编码两跳传播。此两项近似热扩散核，且与全谱热核的覆盖分数相关系数>0.999。
  - 贪心设施选址（带每类预算约束）：在每类预算约束下选择子集最大化总覆盖。；维护每个样本i的当前覆盖cov_i = max_{j∈S} K_{ij}。每一步选择未选且该类未达预算的样本j，使边际增益∑_i max(0, K_{ij} - cov_i)最大。该目标在划分拟阵约束下单调子模，贪心具1/2近似保证。
- 公式/目标函数/指标定义：
  - 对称归一化：Asym = D^{-1/2} A D^{-1/2}，其中D = diag(A1)为度矩阵。
  - 覆盖核：K = Asym + A^2_sym。
  - 边际增益选择准则：j* = argmax_{j∉S, |S_{y_j}|<B} ∑_{i=1}^N max(0, K_{ij} - cov_i)，其中cov_i = max_{j∈S} K_{ij}。
  - 总覆盖目标函数（隐式）：max_{S} ∑_{i=1}^N max_{j∈S} K_{ij}，受每类预算约束。
- 算法细节：
  - 构建kNN图：对N个嵌入向量，使用余弦相似度（即归一化后欧氏距离）计算最近邻，k为唯一超参数（实验中常取20或50）。
  - 归一化与核计算：先计算邻接矩阵A，再获得对称归一化Asym，然后计算A^2_sym（稀疏矩阵乘法），最后相加得K。
  - 贪心选择：初始化S为空，cov_i=0。循环直到每类达预算：对每个未选样本j（且该类未达预算），计算边际增益Δ_j = ∑_{i: K_{ij} > cov_i} (K_{ij} - cov_i)，选最大Δ_j的样本加入S，并更新所有i的cov_i = max(cov_i, K_{ij})。
  - 全局图构建：整个训练集构造一个图，而非每类独立建图，使跨类近邻被编码。
- 训练/推理细节：
  - 选择过程完全基于冻结嵌入，无需任何模型训练。
  - 选定子集后，训练一个ResNet-18（从零开始）用于评估，使用SGD（lr=0.1，动量=0.9，权衰减=5e-4）训练1000个epoch，batch size=256，余弦退火学习率调度，无数据增强。
  - 嵌入提取使用预训练UNI编码器（ViT-L/16，在1亿+组织病理图像上预训练），输出1024维嵌入。

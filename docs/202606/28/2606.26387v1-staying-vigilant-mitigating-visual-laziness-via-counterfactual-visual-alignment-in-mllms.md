## 摘要
多模态大语言模型（MLLMs）将大语言模型（LLMs）扩展到视觉感知，能够对图像和文本进行联合推理。尽管继承了LLMs强大的推理能力，它们仍然容易产生与视觉输入相矛盾的幻觉。机制研究表明，这种弱点源于视觉懒惰：MLLMs内部编码了正确的视觉证据，但在响应时过度依赖强大的语言先验。现有的对齐方法，如直接偏好优化，主要基于文本优化结果级奖励。这引入了一种对语言捷径的优化偏向，导致响应常常与视觉证据相矛盾。为了解决这个问题，我们提出了视觉信息增益对齐（VIGIL），一种强化学习（RL）后训练框架，将焦点从数值奖励拟合转移到因果视觉基础。VIGIL引入了一个几何约束，显式最大化视觉输入和生成响应之间的互信息。我们通过惩罚"盲目自信"实例来实现这一点，即当文本-视觉注意力被掩盖以创建反事实的盲目状态时，模型仍然不恰当地确定。大量实验表明，VIGIL在幻觉和推理基准上持续优于最近的对齐方法，同时不会损害纯文本能力。我们的方法仅使用25%的偏好数据就达到了最先进方法的全数据性能，甚至在无需显式边界框监督的情况下展现了涌现的空间基础能力。

## Abstract
Multimodal large language models (MLLMs) extend large language models (LLMs) with visual perception, enabling joint reasoning over images and text. Despite inheriting strong reasoning capabilities from LLMs, they remain prone to hallucinations that contradict their visual inputs. Mechanistic studies indicate that this weakness stems from visual laziness: MLLMs encode the correct visual evidence internally, but overly rely on strong language priors during response. Existing alignment methods, such as direct preference optimization, primarily optimize outcome-level rewards based on text. This introduces an optimization bias toward linguistic shortcuts, leading to responses that often contradict the visual evidence. To address this, we propose Visual Information Gain In aLignment (VIGIL), a reinforcement-learning (RL) post-training framework that shifts the focus from numerical reward fitting to causal visual grounding. VIGIL introduces a geometric constraint that explicitly maximizes the mutual information between the visual input and the generated response. We achieve this by penalizing "blind confidence" instances where the model remains improperly certain even when textual-visual attention is masked to create a counterfactual blind state. Extensive experiments show that VIGIL consistently outperforms recent alignment methods across hallucination and reasoning benchmarks without compromising text-only capabilities. Our approach matches the full-data performance of state-of-the-art methods using only 25% of the preference data and even demonstrates emergent spatial grounding capabilities without explicit bounding box supervision.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：多模态大语言模型（MLLMs）存在“视觉懒惰”（visual laziness）现象，即模型内部虽编码了正确的视觉特征，但在生成响应时过度依赖语言先验（language priors），忽略视觉证据，导致产生与图像矛盾的幻觉。
- **研究背景**：现有对齐方法（如DPO、SimPO等）主要基于文本输出的正确性优化奖励，没有约束模型内部的依赖路径。模型可能“答对但答错理由”——靠语言捷径而非视觉证据得到正确结果，从而保留了视觉懒惰。
- **整体目标**：提出一个后训练框架，强制模型在推理时依赖视觉信息，而非仅凭文本先验，从根本上缓解多模态幻觉。

## 2. 方法论

### 核心思想
- 引入**视觉信息增益（VIG）**作为约束：最大化视觉输入与生成响应的互信息，惩罚模型在缺乏视觉信息（盲态）时仍保持高置信度的情况。
- 通过**反事实视觉解耦（Counterfactual Visual Decoupling, CVD）**构建几何约束：将正常视觉输入状态与注意力掩蔽后的“盲态”进行对比，迫使模型区分两种状态，从而学习真正基于视觉的推理。

### 关键技术细节
1. **盲态构建**：通过每层Transformer中的注意力掩码，阻止文本查询位置访问视觉键/值位置，保持图像编码不变，仅改变注意力连通性。
2. **CVD损失**：基于Bradley-Terry偏好模型，将“看见状态”优于“盲态”作为偏好，损失函数为：
   ```
   L_CVD = -E[ log σ( βlog(πθ(yw|xv,xt)/πref(yw|xv,xt)) - βlog(πθ(yw|x∅_v,xt)/πref(yw|x∅_v,xt)) ) ]
   ```
3. **动态门控因子α**：基于看见-盲态概率差的绝对值计算α = 1 - tanh(|gap|)，自适应平衡DPO损失和CVD约束。
4. **最终目标**：L_VIGIL = L_DPO(yw, y_hard) + λ·α·L_CVD，其中y_hard是通过提示参考模型生成的幻觉式硬负样本。
5. **数据效率**：仅需25%偏好数据即可达到全数据性能，因为每个样本的信号更强。

## 7. 优点

- **方法新颖**：将反事实干预引入偏好优化，从几何上分离视觉基础与语言先验，比数值重加权更本质。
- **高效实用**：离线DPO框架，无需在线采样或多参考模型；计算开销小（盲态仅通过掩码实现，额外TFLOPs<1%）。
- **泛化能力强**：在各种架构和规模上一致提升，且涌现空间定位能力。
- **理论支撑**：基于互信息最大化和信息瓶颈，提供了信息论分析验证机制。
- **可复现性高**：开源代码、明确超参、匹配的参考策略评估。

## 8. 不足与局限

- **反事实构建简单**：仅通过归零注意力掩码模拟盲态，可能无法捕捉复杂场景下更微妙的跨模态冲突（如遮挡、模糊、假象）。论文承认这一局限。
- **依赖DPO框架**：对于需要长链推理或可靠验证器的任务（如数学问题），GRPO可能更具优势。论文附录的GRPO实验显示VIGIL在推理上竞争力相当，但未深入探索结合。
- **实验语言单一**：所有基准均为英文，对多语言多模态场景的适用性未验证。
- **潜在偏差风险**：偏好数据由模型生成（硬负样本提示）可能引入系统偏差；GPT-4o判据的一致性（92.3%）虽高，仍有少量歧义。
- **应用限制**：方法针对视觉懒惰，但若视觉编码器本身质量差（如低分辨率、噪声），VIGIL的增益可能受限。
- **规模实验不完整**：72B模型的详细训练时间和资源消耗未明确报告，消融实验主要在7B上完成。

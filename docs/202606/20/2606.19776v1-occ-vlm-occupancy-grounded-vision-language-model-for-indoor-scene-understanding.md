## 摘要
近期，视觉语言模型在三维场景理解方面取得了显著进展，推动了具身智能和机器人视觉等应用的发展。然而，现有方法通常要么直接依赖显式的三维输入（如点云或RGB-D序列），要么引入额外的三维几何编码器从二维图像中提取具有三维感知的视觉标记。这种设计在结构上将三维几何感知与通过视觉语言预训练学习到的丰富二维语义相分离，阻碍了统一的三维视觉语言表示的发展。本文提出Occ-VLM，一种仅基于带位姿的RGB图像运行、并使用单一二维视觉编码器的三维场景理解新框架。具体而言，Occ-VLM将三维场景占用重建作为辅助几何先验，用于在空间上将前景二维标记与三维空间关联。然后，这些标记由大语言模型解码，实现统一的场景理解。大量实验表明，Occ-VLM既能实现精确的几何感知，又能进行稳健的视觉语言推理：在多视角占用预测上达到最先进性能，同时在三维视觉问答和三维密集字幕生成基准测试中与使用三维输入的视觉语言模型表现相当。

## Abstract
Recently, vision-language models (VLMs) have made significant progress in 3D scene understanding, driving advances in applications such as embodied intelligence and robotic vision. However, existing approaches typically either rely directly on explicit 3D inputs (e.g., point clouds or RGB-D sequences), or introduce an additional 3D geometry encoder to derive 3D-aware visual tokens from 2D images. Such designs structurally decouple 3D geometric perception from the rich 2D semantics learned via vision-language pre-training, hindering the development of a unified 3D vision-language representation. In this work, we propose Occ-VLM, a novel framework for 3D scene understanding that operates purely on posed RGB images and employs a single 2D vision encoder. Specifically, Occ-VLM reconstructs 3D scene occupancy as an auxiliary geometric prior, which is utilized to spatially associate foreground 2D tokens with 3D space. These tokens are then decoded by a Large Language Model (LLM) for unified scene understanding. Extensive experiments demonstrate that Occ-VLM achieves both accurate geometric perception and robust vision-language reasoning: it attains state-of-the-art performance on multi-view occupancy prediction, while performing on par with 3D-input VLMs on 3D Visual Question Answering (VQA) and 3D dense captioning benchmarks.

- 提出的Occ-VLM通过重建3D场景占用作为几何先验，将2D token在空间上与3D空间关联，再由大语言模型（LLM）统一解码，实现了无需显式3D输入的端到端3D场景理解。

## 2. 方法论

### 核心思想
- 在冻结的2D视觉编码器基础上，引入**Occ Adapter**从中间层提取多尺度特征，通过3D占用解码预测场景语义占用。
- 利用预测的占用网格中心作为“几何掩膜”，将其投影回多视图2D特征图，**采样前景3D token**，并注入3D位置编码。
- 这些token按序列维度展平，作为类似视频帧输入LLM（Qwen2-7B-Instruct），实现跨视图隐式交互与推理。

### 关键技术细节
1. **Mid-layer Activation**：从冻结的SigLIP视觉编码器的中间层（如第8、12、16、24层）复制并添加轻量Transformer适配器（含自注意力、FFN），降低token维度。
2. **Multi-level Token Aggregation**：通过自上而下的卷积特征金字塔融合多尺度特征，得到最高分辨率特征图 \(F_{2D}\)。
3. **3D Occupancy Decoding**：
   - 对每个3D网格锚点 \(a_i\)，利用相机内参和外参将其投影到各视图特征图，通过可微网格采样（grid sampling）聚合多视图特征，得到3D特征体积 \(F_{3D}\)。
   - 使用3D CNN解码器 \(D_{3D}\) 预测每个体素的语义标签（含空类），得到语义占用网格。
4. **Occupancy-aware Foreground Token Sampling**：
   - 从占用网格中提取非空网格中心集合 \(G\)。
   - 对每个中心，再次投影到各视图的最终层特征 \(H^{(ℓ_{\text{last}})}\) 上采样，得到前景token集合 \(T_{fg}\)。
   - 添加正弦3D位置编码 \(PE(a_j)\)。
5. **两阶段训练**：
   - **第一阶段**：冻结2D编码器，训练Occ Adapter，使用三维语义占用预测的Scene-Class Affinity Loss（来自MonoScene）。
   - **第二阶段**：冻结Occ Adapter，联合3D VQA和3D密集描述数据集进行视觉指令微调，使用标准交叉熵损失自回归生成回答。

## 6. 主要结论与发现

- **几何感知**：Occ-VLM在EmbodiedScan占用预测上达到SOTA（mIoU 18.41%），超越所有RGB方法和点云方法，表明2D语义先验能有效提升3D几何感知。
- **视觉语言推理**：
  - 在ScanQA上EM@1 29.6%，SQA3D上EM@1 58.5%，均为2D-input VLM中最佳，且与RGB-D输入SOTA模型（LLaVA-3D、Video-3D-LLM）差距很小（<1%）。
  - 在Scan2Cap密集描述上（C@0.5 76.5%），超越点云任务模型，接近RGB-D VLM。
- **消融核心发现**：
  - 用“视频”形式组织token（按时间顺序展平）优于按占用网格聚合。
  - 3D位置编码不可或缺，移除后性能大幅下降。
  - 增加输入视图数量可同时提升占用预测精度和下游VQA/captioning性能，且前景token占比下降（由于召回提升后冗余背景减少）。
  - Occ Adapter激活更多中间层（从仅24层到8,12,16,24层）有利于几何感知和语言推理。

## 7. 优点

- **架构简洁性**：仅使用单一2D视觉编码器+轻量Occ Adapter，无需显式深度估计、点云处理或额外3D几何编码器。
- **双向2D-3D桥接**：Occ Adapter既利用2D语义提升3D几何重建，又通过占用先验指导3D token采样，实现紧密耦合。
- **高效性与泛化性**：冻结2D编码器保留预训练语义能力，两阶段训练避免灾难遗忘；在多任务上表现优异，接近甚至超越昂贵3D输入方法。
- **消融设计全面**：验证了token组织、位置编码、视图数量、激活层数等关键因素的影响，可解释性强。

## 8. 不足与局限

- **输入限制**：需要多视图RGB图像及准确相机位姿，不适用于单目/未知位姿场景，限制了实际部署（如机器人实时导航）。

- **计算开销**：尽管低于专用几何编码器，但Occ Adapter在32视图下的FLOPs仍达11.3T，对低算力设备不友好。
- **领域局限**：实验仅针对室内场景（ScanNet、Matterport3D、3RScan），未验证室外或自动驾驶场景，泛化性存疑。

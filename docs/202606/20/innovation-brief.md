### 5. MedEasy: Designing AI Standardized Patients for Clinical Consultation Training
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17512v1
- 方法流程：
  - 输入：结构化病例记录（病史、检查、诊断等）和专家标准答案。
  - 步骤1：学习者开始咨询，与Patient Agent进行自由对话问诊。
  - 步骤2：学习者通过Auxiliary Agent请求物理检查或辅助检查，Agent根据病例预定义的映射返回标准化检查发现。
  - 步骤3：学习者基于累积证据提交诊断和治疗方案。
  - 步骤4：学习者完成SOAP格式病历记录。
  - 步骤5：会话结束后，Evaluation Agent接收完整会话记录和专家标准答案，依次进行六个模块（病史采集、体格检查、辅助检查、诊断推理、治疗计划、总体表现）的逐项比较，生成分模块反馈报告。
  - 输出：包含完成项、遗漏项及诊断意义的评估报告，用于形成性复习。
- 关键模块/机制：
  - Patient Agent：模拟标准化病人，根据病例信息和对话历史生成自然语言回复，表现病史和病情演变。；使用Gemini 2.5 Pro模型，温度0.7，提示包括病例描述、对话历史和当前轮次学习者输入。回复仅基于给定病例，不引入标准外信息。
  - Auxiliary Agent：根据学习者申请的检查项目返回对应的客观检查发现，支持临床决策。；使用Gemini 2.5 Flash模型，温度0.7。检查发现与病例预设的动作-发现映射表对应，例如特定体格检查或实验室检查返回标准化结果。
  - Evaluation Agent：在会话结束后进行后评估，比较学习者表现与专家标准，生成六模块反馈。；核心提示严格规定：仅基于专家标准回答比较，不添加额外要求，不评价标准外内容。接收会话摘要和专家标准，逐模块列出完成项和遗漏项，并对每项遗漏解释诊断意义。使用Gemini 2.5 Pro。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 系统采用基于提示的LLM调用：每个代理有固定系统提示，Patient Agent根据{病例信息, 对话历史}生成回复；Auxiliary Agent根据{检查请求, 病例动作-发现映射}返回标准化发现；Evaluation Agent根据{session_summary, expert_answer}进行文本比较。
  - 会话记录存储在256k token上下文中，所有代理在无监督推理模式下运行，温度固定为0.7。
  - 动作-发现联动：病例记录中预定义学习者可能采取的动作（如'听诊肺部'）与对应发现（如'双肺呼吸音清'）的映射，Auxiliary Agent据此返回结果。

- 方法流程：

  - 阶段4：人工审查与验证。由8名训练有素的标注员逐轮审查，并由医师验证，形成324个会话共1296轮的最终基准集。

### 7. Moving Beyond Diversity: Visual Token Pruning as Subspace Reconstruction for Efficient VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18681v1
- 方法流程：
  - 输入：视觉令牌嵌入矩阵 X_v ∈ R^{N×d}，文本令牌嵌入 X_t；通过CLIP计算每个视觉令牌与文本的相关性得分。
  - 初始化：空选集 S = ∅；计算当前子空间为零空间时每个令牌的投影残差（即其自身范数）。
  - 迭代选择：每次选择投影残差最大的令牌加入S，更新基于RRQR的投影矩阵，重新计算剩余令牌相对于新子空间的投影残差。
  - 反相关性融合：在每次选择时，结合CLIP相关性得分进行加权，倾向于选择低相关性令牌（可选）。
  - 输出：选定的k个视觉令牌子集 X̃_v。
- 关键模块/机制：
  - 子空间重建模块：通过贪心列子集选择逼近原始特征矩阵；基于RRQR分解，每次选择投影残差（即当前令牌向量到选定令牌张成子空间的正交距离）最大的令牌，迭代k次。投影残差同时编码方向和幅度信息。
  - 反相关性指导模块：调整选择偏向低图像-文本相关性的令牌以保留上下文；使用CLIP计算每个视觉令牌与文本的余弦相似度作为相关性得分，在子空间重建的每次选择中，将相关性得分作为惩罚项或调整选择顺序，优先选择低相关性令牌。
- 公式/目标函数/指标定义：
  - 公式(2): min_{S} L(F(̃X_v, X_t), F(X_v, X_t)) s.t. |S|=k（理想目标）
  - 公式(4): min_{S} ||X_v^T - Π_S X_v^T||_F^2 s.t. |S|=k，其中Π_S = ̃X_v^T (̃X_v ̃X_v^T)^{-1} ̃X_v为正交投影矩阵
- 算法细节：
  - 贪婪列子集选择（RRQR）：初始化QR分解，每次选择投影残差最大的列，更新QR分解，重复直到选够k列。
  - 投影残差计算：对于令牌向量x，投影残差为||x - P_S x||，其中P_S是当前选定子空间的投影矩阵。
- 训练/推理细节：
  - 完全无需训练，直接对预训练VLM的视觉令牌嵌入进行剪枝。
  - 即插即用，可应用于任何VLM的视觉编码器输出后的令牌序列。

### 8. PEFT-MedSAM: Efficient Fine-Tuning of Medical Foundation Models for Explainable Skin Lesion Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18707v1
- 方法流程：
  - 输入预处理：对原始皮肤镜图像进行标准化预处理（如尺寸调整、归一化等）。
  - 并行模型推理：(1) U-Net（从头训练）; (2) MedSAM零样本推理; (3) PEFT-MedSAM（参数高效微调后）。
  - 分割输出：每个模型生成分割掩码。
  - 评估计算：计算Dice系数、IoU，以及基于Grad-CAM的Pointing Game得分（仅对CNN基线）。
  - 统计验证：使用Wilcoxon符号秩检验比较模型间差异，Bootstrap法估计95%置信区间。
- 关键模块/机制：
  - MedSAM图像编码器（冻结）：提取图像特征，利用预训练的大规模医学图像表示，不参与微调以避免灾难性遗忘。；基于Vision Transformer（ViT），在1.5M医学图像-掩码对上预训练，编码输入图像为高维特征图。
  - MedSAM提示编码器（冻结）：处理用户提示（如点、框），但本工作中使用默认提示（可能为无提示或中心点），不参与微调。；将稀疏提示（如点、框）编码为嵌入向量，与图像特征结合用于掩码解码。
  - 轻量级掩码解码器（可训练）：基于图像特征和提示嵌入生成分割掩码，是唯一被微调的模块，参数量仅占整个模型的4.3%。；由几层Transformer解码器组成，利用交叉注意力融合图像特征和提示嵌入，输出每个像素的掩码预测。
  - Grad-CAM + Pointing Game（可解释性评估）：对CNN基线（U-Net）生成注意力热图，并通过Pointing Game计算热图峰值落在病灶区域内的准确率，量化模型对病灶的关注程度。；Grad-CAM使用目标类别的梯度对最后一层卷积特征图进行加权求和，生成类激活图；Pointing Game判断热图最大激活点是否位于专家标注的病灶边界内。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - PEFT-MedSAM微调过程中，仅更新掩码解码器的参数，图像编码器和提示编码器的权重保持不变。
  - 训练时输入预处理后的图像和对应的专家标注掩码，使用二元交叉熵损失和Dice损失组合进行优化。
  - 零样本MedSAM推理直接使用预训练权重，不进行任何微调。
  - U-Net基线从头训练，编码器-解码器结构，使用同样的损失函数。
  - Grad-CAM计算：梯度回传至CNN基线的最后一个卷积层，对特征图进行加权求和得到热图。
- 训练/推理细节：
  - 训练数据：ISIC 2018训练集（具体数量未提及），可能包含数据增强（如翻转、旋转等）。
  - 微调策略：仅训练掩码解码器，学习率、优化器、批大小等超参数未在摘要中提供。
  - 推理：使用单张图像，输入到PEFT-MedSAM得到分割掩码，无需后处理。
  - 可解释性评估仅在CNN基线（U-Net）上执行，因Transformer基础的SAM难以应用梯度方法。

- 方法流程：
  - 探测基础模型：输入图像，从冻结的VLM中提取中间特征F_v和语言特征F_{vl}
  - 视觉原型聚类：对中间特征进行插值对齐、PCA降维、K-means聚类，得到原型中心μ和距离图d_{pk}，并生成硬分配掩码M
  - 掩码池化：对语言特征进行最近邻插值对齐到掩码网格，按硬分配掩码M进行平均池化，得到每个原型的语言描述符f_k
  - 原型重建语言嵌入：将距离图转换为软亲和度λ_{pk}=softmax(-α d_{pk})，经低亲和度门控后，每个patch的语言特征重建为原型描述符的加权和：f̂_p = Σ λ_{pk} f_k
- 关键模块/机制：
  - Foundation Model Probing：从冻结VLM中提取中间特征和语言特征；对CLIP采用MaskCLIP-style值路径投影，对RADIO交换patch-和CLS适配器头，对dino.txt使用训练好的预测器。中间特征从主干网络（语言头之前）提取，获得更高空间一致性。
  - Visual Prototype Clustering：将中间特征分解为视觉原型，获得硬分配和软距离；中间特征通过双线性插值对齐到共用网格，使用PCA降维（r=36），然后K-means聚类（n=36）得到原型中心μ和欧氏距离d_{pk}=||z_p-μ_k||_2。硬分配通过argmin获得掩码M，软距离用于后续亲和度计算。
  - Masked Pooling：为每个视觉原型生成语言描述符；语言特征通过最近邻插值对齐到掩码网格，对每个原型k，其支持集Ω_k为掩码M中分配到该原型的patch集合，然后对语言特征进行平均池化：f_k = norm2( (1/|Ω_k|) Σ_{p∈Ω_k} L_p )。可选的先验分割为每个实例添加额外原型。
  - Prototype-Reconstructed Language Embedding：使用软亲和度重建空间一致的语言特征图；将距离d_{pk}经温度缩放softmax（α=5）转换为非负亲和度λ̃_{pk}=exp(-α d_{pk})/Σ exp(-α d_{pj})，然后通过低亲和度门控（τ=0）得到λ_{pk}=λ̃_{pk}·1[λ̃_{pk}≥τ]。最终每个patch的语言特征为原型描述符的加权和：f̂_p=Σ λ_{pk} f_k，再归一化并重塑为特征图。
- 公式/目标函数/指标定义：
  - 距离定义：d_{pk} = ||z_p - μ_k||_2
  - 原型语言描述符：f_k = norm2( (1/|Ω_k|) Σ_{p∈Ω_k} L_p )
  - 软亲和度：λ̃_{pk} = exp(-α d_{pk}) / Σ_{j=1}^{n} exp(-α d_{pj})
  - 低亲和度门控：λ_{pk} = λ̃_{pk} · 1[λ̃_{pk} ≥ τ]
  - 重建特征：f̂_p = Σ_{k=1}^{n} λ_{pk} f_k
- 算法细节：
  - 中间特征通过双线性插值对齐到更高分辨率网格，缩放因子s
  - PCA降维后L2归一化，K-means聚类初始化原型
  - 语言特征通过最近邻插值对齐到掩码网格（避免像素级张量）
  - 软亲和度计算使用温度缩放softmax，α=5
  - 低亲和度门控τ=0，保留高置信度原型，不重归一化以确保Σ λ ≤ 1
  - ReSiReg Lite版本使用自相似矩阵（中间特征内积）近似聚类，省略PCA和K-means
  - 支持批处理和3D投影（给定相机内外参）
- 训练/推理细节：
  - 基础VLM参数冻结，ReSiReg无需训练，即插即用
  - ReSiReg Full: PCA降维r=36, K-means聚类n=36, α=5, τ=0
  - ReSiReg Lite: 使用自相似矩阵（F_flat · F_flat^T），α=10, τ=0
  - 25M紧凑模型通过联合蒸馏训练（SigLIP2 + 对比全局和patch级条件）
  - 推理时仅需一次前向和聚类/重建，适用于机器人实时性要求

  - 3. VLM显著性图生成：通过OpenAI Vision API提示GPT-4o（或其他VLM）识别场景中的潜在风险区域，返回空间预测，转换为显著性图
  - 4. 对齐评估：使用Pearson相关系数、归一化扫描路径显著性（NSS）、Kullback-Leibler散度和AUC-Judd四种指标计算人眼热图与模型显著性图之间的空间对齐
- 关键模块/机制：
  - Pupil Invisible眼动追踪系统：记录参与者观看刺激图像时的双眼注视数据（200Hz），提供场景相机视频（30fps）；设备包含双红外眼动摄像头和前置场景摄像头，无需校准，可在自然观看条件下记录注视、扫视和瞳孔数据，用于生成注视坐标并映射到图像
  - GPT-4o视觉语言模型API调用：根据提示生成对场景中潜在风险区域的空间预测；通过OpenAI Vision API发送图像和风险识别提示（如'找出可能危险的位置'），模型返回文本或坐标形式的注意力预测，再转换为与眼动热图相同分辨率（1536×1024）的显著性图
  - 空间对齐评估指标集合：量化模型显著性图与人类注视热图之间的相似性；使用四种指标：Pearson correlation（线性相关）、NSS（显著性图与注视点分布的归一化差异）、KL divergence（概率分布差异）、AUC-Judd（ROC曲线下面积，判断注视点是否落在高显著性区域）
- 算法细节：
  - 注视坐标映射：将原始注视点（像素坐标）通过场景相机内外参投射到刺激图像平面，生成二维密度图（经高斯模糊平滑）
  - 显著性图生成：将VLM返回的注意力区域（如边界框或热力图）扩展为与刺激同尺寸的连续值图，采用与眼动热图相同的核密度估计处理
- 训练/推理细节：
  - 眼动数据收集：10名参与者，每张图像10秒，总时长约5.5分钟，仅涉及推断（无训练）
  - VLM推理：通过API调用预训练模型（GPT-4o等），无需微调或训练，仅使用单次前向传播获取注意力预测

### 28. Visual-Seeker: Towards Visual-Native Multimodal Agentic Search via Active Visual Reasoning
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.15231v1
- 方法流程：
  - 阶段1: 细粒度种子实体选择 - 输入：LiveVQA的查询图像、问题、推理过程；处理：使用MLLM提取实体（名称、描述、类型），经三步过滤（通用提及过滤、复杂实体-图像过滤、实体消歧）得到高质量种子实体；输出：种子实体集。
  - 阶段2: 多跳轨迹合成 - 输入：种子实体；处理：在Wikipedia知识图上进行双策略随机游走（回溯与循环约束），扩展实体节点，生成多跳搜索子图；输出：树形或循环形子图。
  - 阶段3: 视觉证据注入 - 输入：多跳子图；处理：检索候选图像并提取视觉细节，合成包含视觉证据的VQA对（如“搜索模糊关键词的图像，描述视觉细节”），融合进轨迹；输出：5K高质量多模态搜索轨迹。
- 关键模块/机制：
  - 实体识别（Entity Recognition）：从多实体图像中提取与推理链相关的视觉实体；使用MLLM结合上下文学习，输出结构化实体列表，每个实体表示为三元组(名称, 描述, 类型)，描述为图像中实体状态的文本描述。
  - 实体过滤与消歧（Entity Filtering and Disambiguation）：筛选出适合作为搜索起点的高质量种子实体；三步过滤：1) 通用提及过滤，去除无特定标识符的实体；2) 复杂实体-图像过滤，筛选出语义信息不易直接获取的复杂多实体图像；3) 实体消歧，利用上下文从Wikipedia消歧页面选择正确语义。
  - 实体节点扩展（Entity Node Extension）：在知识图上生成多样化的多跳搜索轨迹；采用双策略随机游走：1) 回溯（Backtracking）以概率p_back回退至先前节点，模拟重新审视；2) 循环约束（Cycle Constraint）限制形成循环以避免重复，生成树形或循环形子图。
  - VQA合成（VQA Synthesis）：生成包含视觉证据的搜索查询；基于扩展后的节点，生成搜索关键词并检索候选图像，提取视觉细节（如颜色、形状），合成需要视觉搜索的两跳QA对，再与原有QA合并形成完整轨迹。
- 公式/目标函数/指标定义：
  - 实体表示：E_i = (n_i, d_i, type_i)，其中n_i为实体名称，d_i为图像中状态描述，type_i为实体类别。
  - 回溯概率：p_back ∈ (0,1)，在每步随机游走中以概率p_back执行回溯。
- 算法细节：
  - 实体提取：利用MLLM从图像和推理过程中联合提取视觉实体。
  - 随机游走：在Wikipedia知识图上从种子节点出发，执行带回溯和循环约束的随机游走，生成多步搜索路径。
  - 视觉证据注入：对每个搜索节点，使用模糊关键词检索图像，再用MLLM提取视觉细节，生成形如“搜索[模糊关键词]的图像，[视觉细节]是什么？”的查询，强制模型进行视觉推理。
  - 轨迹合成：将多跳推理链与视觉查询合并，形成多模态的完整搜索轨迹。
- 训练/推理细节：
  - 使用3.1节数据管道合成5K高质量多模态搜索轨迹，对MLLM进行微调训练。
  - 训练采用监督微调（SFT），具体超参和优化器见原文。
  - 推理时，模型接收用户查询和图像，自动执行多步搜索（包括图像搜索、网页浏览），并动态收集视觉证据。

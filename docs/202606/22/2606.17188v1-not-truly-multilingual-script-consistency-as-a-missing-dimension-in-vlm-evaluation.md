## 摘要
当前视觉语言模型的多语言评估假设语言与正字法之间存在一一对应关系，忽视了数十亿使用多文字语言的用户。我们提出了PuMVR（旁遮普语多模态视觉推理），这是一个包含1000个严格并行的图像-文本实例的基准测试，覆盖旁遮普语的三种活跃文字：古木基文、沙穆基文和罗马文。通过评估10个最先进的视觉语言模型，我们揭示了一个显著且系统性的“文字差距”。模型经常能在一个文字中解决视觉任务，却在另一个文字中无法完成相同任务，准确率差异高达16%。关键在于，视觉输入虽然能均匀提升绝对性能，但并不能缩小正字法差距。此外，跨文字上下文内迁移非常脆弱，暴露了文字锁定的知识表征。通过所有文字对的McNemar检验，我们的发现表明，当前的“多语言”视觉语言模型并非真正的多文字模型。我们提出了文字一致性率（SCR）作为文字无关评估的强制指标，该指标在我们的基准测试中低至24.8%，以确保公平的AI访问。数据和代码可在以下链接获取：https://github.com/prabhjotschugh/Not-Truly-Multilingual-PuMVR。

## Abstract
Current multilingual evaluations for Vision-Language Models (VLMs) assume a one-to-one mapping between language and orthography, overlooking billions of users of multi-script languages. We introduce PuMVR (Punjabi Multimodal Visual Reasoning), a benchmark of 1,000 strictly parallel image-text instances across Punjabi's three active scripts: Gurmukhi, Shahmukhi, and Roman. Evaluating 10 state-of-the-art VLMs, we expose a substantial and systematic Script Gap. Models frequently solve visual tasks in one script while failing identical tasks in another, with accuracy deltas reaching 16%. Crucially, visual input boosts absolute performance uniformly yet does not close the orthographic gap. Furthermore, cross-script in-context transfer is highly brittle, exposing script-locked knowledge representation. Supported by McNemar tests across all script pairs, our findings demonstrate that current "multilingual" VLMs are not truly multi-script. We propose the Script Consistency Rate (SCR), which falls as low as 24.8% on our benchmark, as a mandatory metric for script-agnostic evaluation to ensure equitable AI access. Data and code are available at: https://github.com/prabhjotschugh/Not-Truly-Multilingual-PuMVR.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前多语言视觉语言模型（VLM）的评估范式中存在一个根本性盲点——“一种语言，一种文字”（One Language, One Script, OLOS）假设。该假设错误地将语言与正字法视为一一对应，忽视了全球超过十亿使用多脚本语言的用户（例如旁遮普语同时使用古木基文、沙穆基文和罗马文）。
- **研究动机**：现有基准（如XM3600、MaXM、IGLUE等）将每种语言仅用一种文字表示，无法检测模型在同一语言不同文字上的性能差异。这导致：① 模型在一种文字上的高准确率可能掩盖在另一种文字上的严重退化；② 视觉输入能否弥补文字差距尚不清楚；③ 跨文字的知识迁移是否可行未被研究。
- **整体含义**：论文指出，若模型在相同语义内容但不同文字上表现不一致，其“多语言能力”可能更多依赖浅层正字法模式匹配而非深层语义理解。这种“文字偏见”不仅影响评估公平性，也会造成对多脚本用户群体的不可靠AI服务。因此，需要将文字一致性作为多语言VLM评估的独立维度。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：通过构建严格平行的文字变体数据集，将文字作为独立变量隔离出来，系统评估VLM在不同文字上的表现差异，并定义新的指标量化文字鲁棒性。
- **关键技术细节**：
  - **PuMVR基准**：包含1000个经过专家精心设计的图像-推理任务实例，每个实例有完全语义等价的三个文字版本（古木基文、沙穆基文、罗马文）。每个实例包含图像、问题文本（三种文字）、四个选项（三种文字）、正确答案及人工撰写的推理解释。图像内容涉及旁遮普文化概念（如头巾、鞋子等）。
  - **三个实验设计**：
    - 实验1（文字差距量化）：对每个实例分别用三种文字提问，模型在零样本下输出选项文本。计算每个文字上的准确率（Acc_s）、性能差值（Δ = max|Acc_s1 - Acc_s2|）和**文字一致性率（SCR）**：SCR = (1/|I|) * Σ_i ∏_s 1[Correct_s(i)]，即同一实例在所有三种文字上同时正确的比例。
    - 实验2（模态重要性消融）：比较纯文本（无图像）和多模态（有图像）条件下的准确率，计算视觉增益（VG） = Acc_多模态 - Acc_纯文本。
    - 实验3（跨文字少样本迁移）：使用k=3个上下文示例，测试同文字、跨文字和混合文字条件下的准确率。定义**迁移效率（TE）** = Acc_跨文字 / Acc_同文字 × 100%，以及少样本增益（FSL）。
  - **统计验证**：采用McNemar检验对每对文字进行配对比较，确认文字差距的统计显著性。

- **数据集**：PuMVR（1000个平行实例，使用375个实例作为评估集，625个保留用于未来研究）。
- **评估场景**：三个实验分别测试零样本、模态消融、少样本（k=3）三种场景下的模型表现。
- **对比方法**：

## 6. 论文的主要结论与发现

- **文字差距普遍且显著**：所有10个模型均表现出文字依赖的性能下降。性能差值Δ从4.11%（Qwen2-VL-72B）到16.26%（Llama-3.2-11B-Vision）不等。文字一致性率SCR最低仅24.8%（Kimi-VL-A3B），最高85.6%（gemini-2.5-flash）。最弱文字通常是沙穆基文（Perso-Arabic cursive），平均比古木基文低7.7%。
- **视觉输入提供平行提升而非补偿性修复**：视觉增益VG在所有文字上大致均匀（7.5-36.1%），但并未缩小文字间差距。例如gpt-4o在古木基文和沙穆基文上的VG均为16.8%，绝对准确率差仍为4.3%。图像提供的是加性效益，而非正字法补偿。
- **跨文字少样本迁移脆弱**：部分模型在跨文字条件下甚至出现负增益（如Qwen2-VL-72B在古木基文→古木基文的FSL为-49.9%）。迁移效率TE显示强烈不对称性：例如罗马→古木基文TE为153%，而古木基文→沙穆基文TE仅为81.2%，表明模型存在“锚文字”偏好。
- **McNemar检验确认显著性**：8/10模型在古木基文-沙穆基文对上达到显著水平（p<0.05），其中6个模型p<0.001。
- **核心结论**：当前“多语言”VLM并非真正的多文字系统；文字一致性率SCR应作为强制评估指标。

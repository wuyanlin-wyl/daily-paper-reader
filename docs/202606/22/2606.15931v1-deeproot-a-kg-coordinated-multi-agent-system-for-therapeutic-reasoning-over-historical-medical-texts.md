## 摘要
历史医学档案和传统医学在药物发现方面蕴藏着巨大潜力，并且仍是当前药物开发的主要来源。然而，前本体论的散文和独特的分类法阻碍了这些数据的标准化和医学现代化，使其无法用于当前的生物医学流程。此外，现有的LLM智能体系统，无论是工具调用、检索增强还是智能体深度研究，都无法大规模地将此类文本转化为可验证的药物发现线索。我们通过DeepRoot弥合了这一差距，这是一个多智能体LLM系统，它共同构建并利用一个经过验证的知识图谱，表明通常被混为一谈的基于证据的推理和逻辑推理是系统可以组合用于治疗推理的两个可分离的轴。应用于《神农本草经》，DeepRoot在R@20上恢复了21个保留的化合物-疾病治疗对中的10个（47.6%对比原始语料LLM的4.8%和随机的约2.4%），并且在LLM作为评判者的推理质量审查中优于基线LLM以及直接通过工具调用访问DeepRoot自身查询的相同API的LLM。使用工具的LLM在87%的声明上产生幻觉证据，而DeepRoot为7-10%。仅使用知识图谱的推理幻觉率为0%，但在推理连贯性上排名最低；DeepRoot知识图谱+LLM是唯一在两个轴上都胜出的条件，为系统挖掘和重新利用历史医学知识指明了道路。

## Abstract
Historical medical archives and traditional medicines hold immense potential for drug discovery and remain a primary source for current drug development. However, pre-ontological prose and idiosyncratic taxonomies prevent the standardization and medical modernization of the data for use in current biomedical pipelines. Furthermore, no existing LLM agent system, whether tool-calling, retrieval-augmented, or agentic deep-research, can convert such text into verifiable drug-discovery leads at scale. We close this gap with DeepRoot, a multi-agent LLM system that jointly builds and utilizes a verified knowledge graph, showing that grounding and reasoning -- often conflated -- are separable axes the system can compose for therapeutic reasoning. Applied to the Shen Nong Ben Cao Jing, DeepRoot recovers $10$ of $21$ held-out compound-disease treatment pairs at R@$20$ ($47.6\%$ vs $4.8\%$ for a raw corpus LLM and $\sim\!2.4\%$ random) and dominates an LLM-as-judge audit for reasoning quality over baseline LLMs and LLMs with direct tool-call access to the same APIs DeepRoot itself queries. Tool-using LLMs hallucinate evidence on $87\%$ of claims, versus 7-10% for DeepRoot. Graph-only inference hallucinates $0\%$ but ranks lowest on reasoning coherence; DeepRoot KG+LLM is the only condition to win on both axes, pointing toward a route for systematic mining and repurposing of historical medical knowledge.

## 2. 方法论

### 核心思想
- 将历史医学文本处理分为两个阶段：**Assembly（装配）** 和 **Discovery（发现）**。Assembly阶段由多个智能体协作构建一个可验证的知识图谱，将原始文本中的实体（药材、病症、化合物、靶点、疾病）通过权威数据库严格验证并链接成图；Discovery阶段利用该图谱进行结构化推理，评估治疗主张并提名候选化合物。

### 关键技术细节
- **知识图谱模式（Schema）**：6种节点类型（Source, Traditional Malady, Modern Disease, Chemical Compound, Biological Target, Preparation Method）和7种边类型（如TREATS TRADITIONALLY, MAPS TO, IS EXTRACTED FROM, TARGETS, RELATES TO, KNOWN TREATS, PREPARED AS）。化合物身份用RDKit计算的InChIKey统一，靶点身份用ChEMBL ID，确保跨来源实体合并。
- **Assembly阶段**（7个智能体）：
  - Agent 1（Extraction）：从原文中提取Source、Malady、Preparation节点及关系。
  - Agent 2（Auditor）：规范化来源名、合并重复、验证证据片段（子串匹配），避免幻觉。
  - Agent 3（Malady→Disease Mapper）：采用“生成-验证”协议，LLM提出现代疾病名，再通过ICD-10、MeSH、SNOMED的精确匹配验证（拒绝模糊匹配）。
  - Agent 4（Source→Compound Linker）：通过COCONUT和PubChem数据库将药材链接到化合物。
  - Agent 5（Compound→Target Linker）：通过ChEMBL查询化合物的分子靶点及活性（pChEMBL≥5.0），支持盐和互变异构体的聚合。
  - Agent 6（Target→Disease Linker）：通过Open Targets、NCBI Taxonomy、OLS4将靶点链接到疾病。
  - Agent 7（Reviewer）：规则+LLM归档不相关或异常节点。
- **Discovery阶段**（2个智能体）：
  - **Critic Agent**：对给定Source→Malady主张，接收KG组装的结构化负载（路径分布、循环闭合计数、顶级机械链等），输出四个梯度的裁定（VALIDATED/PLAUSIBLE/WEAK/UNSUPPORTED）及置信度评分。
  - **Discovery Agent（提名者）**：针对目标现代疾病，向后遍历KG枚举所有候选化合物，再向前评分，按循环闭合性、路径桶等级、来源数量等排序，输出完全确定性的排序列表（无LLM参与）。
- **路径评分**：每条边根据证据类型映射到四个桶（T1>T2>T3>T4），路径桶取最弱边，路径分数为各边先验置信度的乘积。

## 3. 实验设计

- **数据集与场景**：
  - **语料**：《神农本草经》被分割为71个文本块。
  - **外部数据库**：COCONUT 2.0、PubChem（化合物）；ChEMBL（靶点活性）；Open Targets（靶点-疾病关联）；NCBI Taxonomy、OLS4（病原体）；ICD-10、MeSH、SNOMED（疾病本体）。
- **基准（Benchmark）**：
  - **基线**：原始语料LLM（Gemini 3.1 Flash Lite）、工具调用LLM（有直接API访问ChEMBL/Open Targets/PubMed/MeSH）、Biomni（通用生物医学AI智能体）、纯图推理（无LLM）。
  - **评测指标**：Recall@k、Mean Reciprocal Rank (MRR)、LLM裁判评分（六个维度1-5分）、幻觉证据率。
- **对比方法**：DeepRoot使用三个LLM梯级（Gemini 3.1 Pro、2.5 Flash、3.1 Flash Lite）与上述基线对比。

## 6. 主要结论与发现

- **恢复能力**：DeepRoot在R@20上恢复10/21保留治疗对（47.6%），远超原始语料LLM（4.8%）和随机（约2.4%）；化合物恢复Recall@10是基线的6.11倍。
- **幻觉率**：工具调用LLM在87%的声明上产生幻觉证据，而DeepRoot仅7-10%；纯图推理幻觉率为0%但推理连贯性最差。
- **推理质量**：KG+LLM配置在所有评估维度上（证据保真度、裁定对齐、推理连贯性、临床映射、不确定性校准、可操作性）均优于所有基线，且实现低幻觉率与高推理能力的平衡。
- **KG的贡献**：边缘扰动实验表明KG结构对置信度至关重要；知识图谱抑制幻觉的方式不同于推理时实时数据库查询——先构建验证图比推理时检索更有效。
- **成本效益**：Assembly是一次性调用，成本约0.25美元，避免每次推理时访问外部数据库的重复开销。

## 7. 优点

- **方法论创新**：清晰分离基础事实（知识图谱构建）与推理（判别与提名），将通常被混淆的两个维度组合，实现可审计、可复现的推理。
- **极强的可验证性**：所有实体和边均通过权威数据库精确匹配（容忍精确匹配），拒绝LLM直接生成的编码，从根本上消除幻觉来源。
- **结构化推理**：路径评分采用最弱环原则（桶分级）与先验置信度乘积，使推理过程透明、可解释且稳定。
- **系统性实验设计**：覆盖消融、恢复、隐藏治疗对公测、LLM裁判评估、人类专家定性，多角度验证系统有效性。
- **低幻觉率与高推理质量同时达成**：纯图无法合成，纯LLM易幻觉；DeepRoot巧妙地结合两者优势。

## 8. 不足与局限

- **语料范围窄**：仅使用《神农本草经》（71个文本块），未验证其他历史医学文献（如阿育吠陀、民族药理学档案）。
- **样本量小**：保留治疗对仅21对，单次种子，无bootstrap置信区间，统计稳健性有限。
- **先验设定主观**：路径评分先验基于“临床面部效度”人工设定，非学习方式，可能不最优。
- **覆盖缺失**：Open Targets仅覆盖人类疾病，非现代适应症（如动物病原体相关疾病）无法评分；非人类靶点（如致病菌）的疾病关联依赖间接手段。
- **推理质量上限**：Critic Agent的推理质量受限于底层LLM（Gemini系列），若LLM弱则推理变差。
- **对比基线局限**：虽然报告了Biomni和LLM的prompt工程最佳结果，但未进行系统调优，且Biomni可访问最新论文/证据可能超出裁判知识。
- **仅适用于历史医学**：当前方法专门面向历史医学文本，对现代结构化数据或非本体化文本的泛化性未检验。

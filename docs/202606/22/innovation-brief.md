### 1. DeepRoot: A KG-Coordinated Multi-Agent System for Therapeutic Reasoning over Historical Medical Texts
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.15931v1
- 方法流程：
  - 输入：历史医学文本（如《神农本草经》分块为71个片段）
  - 阶段1：知识图谱构建（Assembly） - 7个智能体按顺序执行：提取、审计、映射和链接，填充6种节点和7种边
  - 阶段2：知识图谱推理（Discovery） - 使用批评者智能体和验证者智能体在图上进行多跳推理，合并基础事实和推理
  - 输出：可验证的治疗对（如化合物-疾病三元组）
- 关键模块/机制：
  - Agent 1 - Extraction Agent：从原始文本中提取Source、Malady和Preparation节点；使用LLM从文本块中识别实体并创建节点
  - Agent 2 - Extraction Auditor：规范化来源并归档未能通过子串验证的证据跨度；对提取的实体进行字符串验证，确保与原文一致，无法验证的归档为孤儿节点
  - Agent 3 & 4 - Mappers (Malady-Disease, Source-Compound)：将历史实体映射到现代实体；LLM提出候选名称，然后通过严格精确匹配从外部数据库（ICD-10, MeSH等）恢复本体代码，拒绝幻觉标识符
  - Agent 5 & 6 - Linkers (Compound-Target, Target-Disease)：链接化合物到靶标，靶标到疾病；使用COCONUT, PubChem, ChEMBL, Open Targets等数据库进行实体链接
  - Agent 7 - Reviewer Agent：归档无法链接的孤儿节点和域外实体；将无法映射或链接的节点标记为孤儿，不参与后续推理
  - Agent 8 - Critic Agent：在推理阶段评估推理路径的质量；基于知识图谱和LLM共同评估治疗声明的合理性
- 算法细节：
  - 知识图谱构建：7个智能体按依赖顺序执行，先提取后审计再映射再链接
  - 映射采用生成-验证协议：LLM先生成候选，然后通过容忍的精确匹配（tolerant exact match）从本体数据库恢复唯一ID
  - 推理时使用多跳路径搜索：从Source出发，沿TREATS_TRADITIONALLY -> MAPS_TO -> IS_EXTRACTED_FROM -> TARGETS -> RELATES_TO链路寻找闭合环
  - 评分机制：推理路径的质量由Critic Agent和Validator Agent联合评估，LLM用于评估推理连贯性，KG用于事实准确性
- 训练/推理细节：
  - 无模型训练步骤，所有组件使用预训练LLM（如GPT-4）进行零样本或少量样本推理
  - 推理阶段：先构建完整KG，然后运行多智能体发现流程，Critic和Validator对每个候选路径进行审核

### 2. Cascaded Sparse Autoencoders Learn Multi-Level Visual Concepts in Multimodal LLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.16193v1
- 方法流程：
  - 输入：多模态LLM某层的激活向量 x ∈ R^d
  - Stage 1: Level-1 SAE编码器将x映射到稀疏码 f^(1) ∈ R^n1，解码器重建 x_hat = Wdec1^T f^(1) + b1
  - Stage 2: 将Level-1解码器权重列 w_j ∈ R^d（原子概念方向）逐一送入Level-2 SAE，编码得到高层稀疏码 f^(2)_j ∈ R^n2，解码重建 w_hat_j
  - 联合优化：最小化 Lfinal = E_x[L1] + α L2，其中L1包含重建和稀疏惩罚，L2包含原子重建和稀疏惩罚
  - 推理时：给定新x，依次通过两级SAE提取分层特征
- 关键模块/机制：
  - Level-1 SAE：将原始激活向量分解为稀疏的底层概念特征，输出稀疏码和原子概念方向；标准SAE结构：编码器 f1 = σ(Wenc1^T (x - b1))，解码器 x_hat = Wdec1^T f1 + b1。Wdec1的列向量 w_j 代表每个原子概念的方向。损失 L1 = ||x - x_hat||_2^2 + λ1 S(f1)，S通常为ℓ1或TopK。
  - Level-2 SAE：对Level-1原子概念方向进行抽象，发现高层概念组；输入为Level-1解码器列 w_j ∈ R^d，编码器 f2_j = σ(Wenc2^T (w_j - b2))，解码器 w_hat_j = Wdec2^T f2_j + b2。损失 L2 = (1/n1) Σ_j [||w_j - w_hat_j||_2^2 + λ2 S(f2_j)]。
  - 动态掩码机制：减少计算量并聚焦活跃原子；在每个训练步，根据当前mini-batch B，定义活跃原子集合 At = { w_j | Σ_{x∈B} 1([g1(x)]_j > ε0) ≥ 1 }。仅对At中的原子计算Level-2损失。
- 公式/目标函数/指标定义：
  - f1 = σ(Wenc1^T (x - b1))
  - x_hat = Wdec1^T f1 + b1
  - L1 = ||x - x_hat||_2^2 + λ1 S(f1)
  - f2_j = σ(Wenc2^T (w_j - b2))
  - w_hat_j = Wdec2^T f2_j + b2
  - L2 = (1/n1) Σ_j [||w_j - w_hat_j||_2^2 + λ2 S(f2_j)]
- 算法细节：
  - 端到端联合训练，梯度从L2通过w_j反向传播到Level-1参数，使L2目标影响底层原子
  - 动态掩码：仅活跃原子参与L2计算，减少算力
  - Level-1和Level-2均可采用ReLU或TopK激活，ℓ1或TopK稀疏约束
  - 推理时，对输入x计算两级SAE获得分层特征，用于概念分析或steering
- 训练/推理细节：
  - 训练：联合优化Lfinal，可交替优化或一次性反向传播
  - 使用超参数α平衡两级学习（文献中取α=1）
  - 学习率、批量大小等与标准SAE类似（附录E.1）
  - 推理：x通过Level-1得到f1和w_j，再通过Level-2得到f2_j，但实际应用steering时仅使用Level-2概念组

### 3. Not Truly Multilingual: Script Consistency as a Missing Dimension in VLM Evaluation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17188v1
- 方法流程：
  - 输入：PuMVR基准包含1000个实例，每个实例有一张图像、三套平行文本（问题+四选项，分别用Gurmukhi、Shahmukhi、Roman脚本），以及正确答案
  - 阶段1：脚本间隙量化（实验1）——对每个实例按脚本独立评估，模型接收图像和单脚本文本，预测选项文本，计算各脚本准确率Acc_s和SCR
  - 阶段2：视觉输入消融（实验2）——对比纯文本输入与图像+文本输入下的脚本间隙，检验视觉信息能否缩小正交差距
  - 阶段3：跨脚本上下文迁移（实验3）——提供另一种脚本的上下文示例（in-context examples），测试模型能否跨脚本转移推理能力
  - 输出：每个模型的各脚本准确率、SCR、跨脚本迁移效率及统计显著性
- 关键模块/机制：
  - PuMVR基准数据集：提供严格平行的三脚本评估实例，确保语义、图像、选项完全相同，仅脚本变量不同；1000个实例，每个包含一张图像、Gurmukhi/Shahmukhi/Roman三套问题与选项（均为4选1），以及人工撰写的推理解释。由4名旁遮普语/乌尔都语母语者分两阶段注释（创建+质检），采用PABAK验证一致性（≥0.97）
  - Script Consistency Rate (SCR)：严格度量模型在所有脚本上同时正确的比例，反映脚本无关的语义理解能力；SCR = (1/|I|) * ∑_i ∏_{s∈S} 𝟙[Correct_s(i)]，其中S={Gurmukhi, Shahmukhi, Roman}。只有当实例在三个脚本上都正确时才算通过。该指标避免了单脚本平均的掩盖效应
  - McNemar检验：统计验证脚本对间的性能差异是否显著大于随机波动；对每对脚本（Gurmukhi-Shahmukhi, Gurmukhi-Roman, Shahmukhi-Roman），构建2×2列联表（正确/错误分布），计算卡方统计量。文中报告了8/10模型在Gur-Shah对上有显著差异，6个p<0.001
- 公式/目标函数/指标定义：
  - 脚本准确率：Acc_s = (1/|I|) * ∑_i 𝟙[Pred_s(i) = GT_s(i)]
  - 脚本一致性率：SCR = (1/|I|) * ∑_i ∏_{s∈S} 𝟙[Correct_s(i)]，其中S = {Gur, Shah, Rom}
- 算法细节：
  - 脚本间隙量化实验：每个模型对每个实例运行三次推理（每次仅提供一种脚本的文本），每次使用对应脚本的指令模板，要求输出选项原文。精确匹配作为正确判断
  - 跨脚本上下文迁移实验：在提示中嵌入2个来自目标脚本或其他脚本的带正确答案示例（in-context learning），观察准确率变化
- 训练/推理细节：
  - 所有模型均为预训练VLM，无微调或训练步骤
  - 推理使用温度0或固定种子以保证确定性输出
  - 评估分为375实例的测试集和625实例的保留集（用于未来微调），测试集在实验前固定

### 4. Not Truly Multilingual: Script Consistency as a Missing Dimension in VLM Evaluation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.17188v2
- 方法流程：
  - 基准构建阶段：收集1000个图像，人工创作多选问题和选项，并严格翻译为Gurmukhi、Shahmukhi、Roman三种脚本，确保语义等价，经独立注释者验证
  - 评估阶段：对每个模型进行三通道隔离评估，每次只提供一种脚本的文本（图像+问题+选项），使用脚本特定指令模板，模型输出正确选项文本
  - 分析阶段：计算每种脚本的准确率、SCR、跨脚本转移效率，并对所有脚本对进行McNemar检验
- 关键模块/机制：
  - PuMVR基准数据集：提供严格平行的多脚本评估数据，使脚本成为受控变量；1000实例，每实例包含同一图像、三种脚本的问题和四个选项、正确答案、人工推理解释。通过独立注释者验证语义等价性和脚本准确性，PABAK≥0.970
  - Script Consistency Rate (SCR)：严格衡量模型在所有脚本上同时正确的能力；SCR = (1/|I|) * Σ_i [Π_{s∈S} 1_{Correct_s(i)}]，其中S={Gurmukhi, Shahmukhi, Roman}。若模型在某实例任何脚本错误，则该实例不计入SCR
  - 实验协议：确保脚本变量隔离，避免跨脚本污染；每个实例进行三次独立评估（每脚本一次），使用脚本特定指令模板，模型必须输出精确选项文本，且评估过程不可见其他脚本
- 公式/目标函数/指标定义：
  - Script Accuracy: Acc_s = (1/|I|) * Σ_i 𝟙[Pred_s(i) = GT_s(i)]
  - Script Consistency Rate (SCR): SCR = (1/|I|) * Σ_i ∏_{s∈S} 𝟙[Correct_s(i)], S = {Gurmukhi, Shahmukhi, Roman}
- 算法细节：
  - 评估协议：三通道独立隔离评估，使用脚本特定指令模板，模型输入包含图像和单一脚本的文本（问题+四个选项），输出必须为选项文本；通过精确字符串匹配判定正确性
- 训练/推理细节：
  - 论文未涉及训练，仅涉及推理评估：所有模型在固定推理设置下（温度=0等）在PuMVR的375实例评估集上运行，按脚本分三次评估，防止跨脚本提示

### 5. Moving Beyond Diversity: Visual Token Pruning as Subspace Reconstruction for Efficient VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.18681v1
- 方法流程：
  - 输入：视觉token嵌入矩阵 X_v ∈ R^{N×d}，目标token数k。
  - 初始化：置空选择的token索引集合S=∅，投影矩阵P=0。
  - 迭代选择（最多k次）：对于每个未选token，计算其投影残差向量（与当前子空间正交的分量），选择残差范数最大的token，将其索引加入S。
  - 更新：基于更新后的S重新计算正交投影矩阵P = X_S^T (X_S X_S^T)^{-1} X_S。
  - 输出：保留S对应的k个视觉token嵌入，其余丢弃。
  - （可选）融合反相关引导：计算每个token与文本嵌入的余弦相似度，额外偏向于选择相似度低的token。
- 关键模块/机制：
  - 子空间重建模块：贪心选择投影残差最大的token，使所选token的列空间逼近原始特征子空间。；基于RRQR分解，每次迭代计算所有未选token相对于当前子空间的投影残差（即正交补的范数），选择残差最大的token加入子集。该过程同时考虑方向和幅值信息，与仅基于余弦相似度的多样性方法不同。
  - 反相关引导模块：在子空间重建基础上，引入图文相关性信号，优先选择低相关度token以保留上下文。；利用CLIP计算每个视觉token与文本嵌入的余弦相似度作为相关性分数。在子空间重建的残差项上叠加一个反相关偏置（例如，选择残差与相关性倒数的加权组合），使得低相关token更可能被选中。
- 公式/目标函数/指标定义：
  - 视觉剪枝理想目标：min_{S,|S|=k} L(F(\tilde{X}_v, X_t), F(X_v, X_t))
  - 近似重建目标：min_{S,|S|=k} ||X_v^T - \Pi_S X_v^T||_F^2，其中\Pi_S = \tilde{X}_v^T(\tilde{X}_v \tilde{X}_v^T)^{-1}\tilde{X}_v
  - 选择准则：在每次迭代中，对于当前子集S，选择token j = argmax_{i\notin S} || (I - \Pi_S) x_i^T ||_2
- 算法细节：
  - 贪心RRQR过程：初始化空集，每次挑选与当前子空间正交投影残差最大的列（token），更新QR分解或直接增量计算投影矩阵。
  - 反相关融合：定义score_i = ||residual_i||_2 - λ * similarity_i（其中similarity_i为与文本的余弦相似度），选择score最大的token。
  - 伪代码：输入X_v, k, λ；S=∅；while |S|<k: 对每个i∉S计算残差r_i；score_i = ||r_i|| - λ * cos(x_i, text_embedding)；j=argmax score_i；S=S∪{j}；更新投影矩阵；输出S。
- 训练/推理细节：
  - 完全无需训练，即插即用：直接在推理时对视觉token进行剪枝，不改变模型参数。
  - 兼容FlashAttention等高效注意力实现，不需要中间注意力的提取。
  - 对于不同VLM（如LLaVA、LLaVA-NeXT、InternVL）可直接应用。

### 6. Occ-VLM: Occupancy Grounded Vision Language Model for Indoor Scene Understanding
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.19776v1
- 方法流程：
  - 输入：多视角RGB图像及对应相机位姿
  - 阶段1：使用冻结的2D视觉编码器（ViT）提取多视角2D图像token
  - 阶段2：Occ adapter从ViT中间层提取并适应多尺度特征，通过自上而下的卷积金字塔聚合为2D特征图
  - 阶段3：3D占用解码：将3D网格锚点投影到多视图2D特征图，通过可微网格采样聚合为3D体积特征，再用3D卷积预测语义占用
  - 阶段4：占用感知采样：根据预测占用在3D前景区域采样，结合3D位置编码生成占用感知的3D token
  - 阶段5：将3D token与文本token拼接输入LLM解码器，生成场景理解相关回答
- 关键模块/机制：
  - Occ adapter：将冻结的2D视觉编码器特征提升为3D占用预测所需的多尺度表示；包含三个组件：(1) Mid-layer Activation：从冻结ViT的选定中间层复制并附加轻量Transformer适配器，输出适应特征 ˜H = A(H)； (2) Multi-level Token Aggregation：通过自上而下的卷积金字塔（Conv+Upsample）融合多尺度2D特征； (3) 3D Occupancy Decoding：利用3D网格锚点投影到多视图2D特征图，经可微网格采样Φ聚合为3D体积，再用3D卷积预测语义占用。
  - Occupancy-aware Sampler：基于预测占用生成前景3D token，供LLM推理；在预测的3D占用网格中选取非空（前景）区域，将对应的3D坐标投影回多视图2D特征图采样特征，并添加3D可学习位置编码，得到空间感知的3D token。
  - 2D Vision Encoder (冻结)：输入多视角RGB图像，输出多尺度2D语义token；使用预训练的Vision Transformer（如ViT），参数在训练中冻结，仅通过Occ adapter提取中间层特征。
  - LLM Decoder：接收3D token和文本token，生成场景理解回答；使用大语言模型（如LLaMA）解码，通过自回归方式生成文本。3D token与文本token拼接后输入。
- 公式/目标函数/指标定义：
  - Mid-layer Activation: ˜H(k) = A_k(H^{(ℓ_k)}) = LN[ H' + FFN(LN(H')) ], H' = LN[ H^{(ℓ_k)} + MHSA(H^{(ℓ_k)}) ]
  - Multi-level Token Aggregation: F^{(k)}_{2D} = N_k(˜H^{(k)}) = Conv[ Conv(˜H^{(k)}) + Upsample(F^{(k+1)}_{2D}) ]
  - 投影：p_{i,v} = π( K_v (R_v a_i + t_v) )
  - 3D体积聚合：F_{3D} = { (1/|V_i|) Σ_{v∈V_i} Φ_{p_{i,v}}(F_{2D,v}) }_{i=1}^M ∈ R^{M×D}
- 算法细节：
  - 从ViT中间层选择策略：选取一组中间层{ℓ_k}，每层复制并附加适配器，适配器包含自注意力（MHSA）和前馈网络（FFN）
  - 多尺度特征融合采用自上而下的卷积特征金字塔，从最深（最粗）层开始逐步上采样并加上相邻层卷积输出
  - 3D网格锚点生成：将场景空间离散化为均匀体素网格，每个体素中心作为一个锚点
  - 可微网格采样：使用双线性插值从2D特征图中采样对应投影点特征
  - 多视角特征聚合取平均，处理可见性：仅对能投影到图像内的视图求平均
  - 占用感知采样：仅选取预测占用概率高于阈值的前景体素对应的3D token
- 训练/推理细节：
  - 两阶段训练策略：第一阶段训练Occ adapter和占用解码器（使用占用预测损失），第二阶段冻结占用相关模块，联合训练LLM进行VQA等任务
  - 2D视觉编码器全程冻结
  - 推理时：输入多视角RGB图像及位姿，依次经过编码、占用预测、采样、LLM解码

### 7. The Hidden Evolution of Disguised Visual Context inside the VLM

  - 阶段3: 任务执行 - 单智能体：直接回答；多智能体：多轮辩论（设定轮数）后通过投票或共识得出最终答案
  - 阶段4: 性能评估 - 计算准确率，按是否暴露错误信息、任务类型、决策协议等分组比较

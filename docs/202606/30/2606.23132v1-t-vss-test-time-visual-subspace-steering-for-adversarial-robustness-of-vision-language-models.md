## 摘要
视觉语言模型（VLM）在零样本识别中表现强劲，但仍极易受到对抗性扰动的影响。最近的测试时自适应方法在不重新训练的情况下提升了鲁棒性，但它们并未直接自适应受损的视觉表示本身。基于提示的方法自适应可学习的文本提示，而输入空间方法则在测试时优化像素或填充。这些方法可以通过间接且昂贵的优化路径改善预测。我们提出测试时视觉子空间引导（T-VSS），一种轻量级防御方法，直接在视觉特征空间中进行测试时自适应。T-VSS首先从锚定于被攻击图像的多视图特征残差中构建样本特定的低秩子空间，然后在子空间内通过可靠性加权熵最小化学习共享的特征校正。通过将自适应限制在紧凑的视觉几何中，T-VSS将被攻击的特征引导至更稳定且更具判别性的预测，同时避免噪声的全空间更新。在细粒度、ImageNet和ImageNet-OOD基准上的实验表明，T-VSS在提升对抗鲁棒性的同时，保持了具有竞争力的干净准确率，并且比先前的测试时自适应方法具有更高的效率。

## Abstract
Vision-language models (VLMs) achieve strong zero-shot recognition, but they remain highly vulnerable to adversarial perturbations. Recent test-time adaptations improve robustness without retraining, but they do not directly adapt the corrupted visual representation itself. Prompt-based methods adapt the learnable text prompts, while input-space methods optimize pixels or padding at test time. These approaches can improve predictions, but they do so through an indirect and expensive optimization path. We propose Test-time Visual Subspace Steering (T-VSS), a lightweight defense that performs test-time adaptation directly in the visual feature space. T-VSS first builds a sample-specific low-rank subspace from multi-view feature residuals anchored at the attacked image. It then learns a shared feature correction within this subspace using reliability-weighted entropy minimization. By constraining adaptation to a compact visual geometry, T-VSS steers attacked features toward more stable and discriminative predictions while avoiding noisy full-space updates. Experiments on fine-grained, ImageNet, and ImageNet-OOD benchmarks show that T-VSS improves adversarial robustness while maintaining competitive clean accuracy and better efficiency than prior test-time adaptations.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：在测试时，利用多视图特征残差构建样本特定的低秩视觉子空间，然后在该子空间内学习一个共享的低秩特征校正，并通过可靠性加权熵最小化引导优化，将受攻击特征稳定地转移到更具判别性的区域。
- **关键步骤**：
  1. **局部视觉子空间估计**：
     - 给定被攻击图像x，生成N+1个随机视图（包括原图x₀和N个增强视图）。
     - 提取所有视图的视觉特征fᵢ，以原图特征f₀为锚点，计算残差矩阵R = [f₁–f₀, f₂–f₀, …, fₙ–f₀]ᵀ ∈ ℝ^(N×d)。
     - 对R进行奇异值分解（SVD）：R = UΣVᵀ，选择最小活动秩m，使得累积奇异值能量超过阈值ρ（通常ρ=0.9）。
  2. **共享低秩特征引导**：
     - 取前m个右奇异向量构成基Vₘ ∈ ℝ^(d×m)。
     - 初始化可学习系数向量α ∈ ℝᵐ为零，生成共享偏移Δ = Vₘα。
     - 对所有视图应用同一校正：̃fᵢ = (fᵢ + Δ) / ‖fᵢ + Δ‖₂。
  3. **可靠性加权优化与聚合**：
     - 计算每个视图的可靠性得分rᵢ = (1/K) Σⱼ∈N_K(i) Sᵢⱼ，其中Sᵢⱼ为特征间的cosine相似度，N_K(i)为前K个最相似视图的索引。
     - 经温度缩放softmax转换为权重wᵢ。
     - 优化目标：最小化可靠性加权点熵L_T-VSS = Σᵢ wᵢ H(p(̃fᵢ))，其中p(̃fᵢ)为分类概率，H为香农熵。
  4. **最终预测**：通过可靠性加权平均各视图概率得到最终预测：p_final = Σᵢ wᵢ p(̃fᵢ)，取argmax。

- **关键设计特点**：
  - 图像编码器只前向一次，后续优化仅在缓存的视觉特征上进行，避免重复通过大模型反向传播。
  - 只优化m维系数向量，参数量极少（通常m<7）。
  - 共享校正确保多视图一致性。
  - 自适应秩选择（能量阈值ρ=0.9）自动确定子空间维度。

## 7. 优点
- **方法创新**：直接操作视觉特征空间，而非文本提示或像素空间，更直接地对抗特征损坏。
- **轻量高效**：仅优化少量子空间系数（通常<7个参数），单步更新，无需多次通过编码器。
- **几何感知**：利用样本特定低秩子空间和共享校正，避免全空间噪声更新，提升稳定性。
- **可靠性加权**：通过视图间特征一致性动态抑制不可靠视图，提升优化质量。
- **自适应秩选择**：自动确定子空间维度，无需手动调优，对不同骨干和攻击强度自适应。
- **实验结果充分**：覆盖多种骨干、数据集、攻击类型、消融、随机种子，且代码开源（MIT许可证）。
- **适用性广**：可与训练时鲁棒预训练兼容（如TeCoA），进一步提升鲁棒性。

## 8. 不足与局限
1. **对自适应攻击的脆弱性**：当攻击者知晓并优化通过随机增强管道（EOT-PGD）时，所有基于增强的测试时防御（包括T-VSS）的鲁棒性均崩溃至极低水平（<5%）。这是当前范式的共同缺陷，论文明确承认并视为未来工作。
2. **对远程感知图像的局限性**：在EuroSAT数据集上，T-VSS的鲁棒性弱于TTP，说明子空间结构对特定领域（如卫星图像）可能不够稳定。
3. **对增广质量的依赖**：需要生成足够的随机增强视图（默认64个），在低视图数量下鲁棒性下降，但8视图仍可比肩先前方法的64视图结果。
4. **缺少理论保证**：论文未提供低秩残差结构存在的严格理论证明，主要通过经验分析（附录B）支持。
5. **通用性有限**：仅在CLIP家族骨干上验证，未扩展到其他VLM架构（如BLIP、LLaVA），也未在端到端大模型上测试。
6. **评估设置偏向防御不知情**：在更现实的防御知晓（adaptive attack）场景下，方法失效，论文未提供缓解方案（如梯度掩蔽或随机化）。

### 1. Black-Box Continual Learning for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.22999v1
- 方法流程：
  - 训练阶段：新任务到来，使用冻结CLIP文本编码器提取类名文本特征，SPA为每类学习可训练文本原型嵌入；计算原型与冻结图像编码器输出相似度；LDR对旧类原型建模分布并采样伪特征进行重放。
  - 推理阶段：拼接所有已训练任务的原型和未见类的文本特征（由冻结文本编码器提取），与图像特征计算相似度进行任务无关分类；TTPA根据当前测试实例动态调整原型边界。
- 关键模块/机制：
  - Semantic Projection Accumulation (SPA)：增量知识获取；对于每个新任务，为每个类学习一个可训练的文本原型嵌入向量，该向量与冻结CLIP文本编码器输出的类名称特征交互，通过度量学习（如对比损失）优化以匹配对应类的视觉嵌入。
  - Latent Distribution Replay (LDR)：防遗忘；为每个旧类原型维护一个高斯分布的均值和方差参数，在新任务训练时从该分布采样伪原型特征，与当前任务原型混合参与损失计算，从而锚定嵌入空间。
  - Test-Time Prototype Adaptation (TTPA)：测试时边界细化；在推理阶段，对于每个测试样本，基于其图像嵌入与当前原型的相似度，通过少量梯度步（仅更新原型）动态调整原型位置，以改善类间可分性。
- 算法细节：
  - SPA：对每类初始化可学习嵌入p_c，计算与图像特征f(x)的余弦相似度，通过交叉熵损失优化p_c。
  - LDR：维护每个旧类原型的均值和方差参数，训练时从分布采样伪原型，与当前任务原型一起参与对比损失。
  - TTPA：在测试序列中，对于每个测试样本，计算其与当前原型的相似度，通过少量梯度更新（仅修改原型）调整边界。
  - 整体训练：冻结CLIP编码器，仅训练外部文本原型，总参数量0.05M。
- 训练/推理细节：
  - 训练：仅优化文本原型库，不更新冻结backbone。每轮训练后存储旧类原型的分布参数（均值和方差）。新任务训练时，从旧类分布采样伪原型参与损失计算实现重放。
  - 推理：任务无关，将所有已学习类原型与当前输入图像特征计算相似度，选择最相似类。TTPA在测试时通过少量自适应步骤动态调整原型。

### 2. T-VSS: Test-Time Visual Subspace Steering for Adversarial Robustness of Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.23132v1
- 方法流程：
  - 输入：对抗性测试图像x（可能带有对抗扰动）。
  - 步骤1：生成N+1个随机视图：X(x) = {x₀, x₁, ..., x_N}，其中x₀=x，其余为增强视图。
  - 步骤2：通过CLIP图像编码器F(·)提取每个视图的视觉特征：f_i = F(x_i) ∈ R^d。
  - 步骤3：计算视图特征之间的余弦相似度矩阵S，其中S_{ij} = cos(f_i, f_j)。
  - 步骤4：基于相似度矩阵计算可靠性权重w_i，例如通过温度缩放和top-K平均，反映特征稳定性。
  - 步骤5：构建样本特定的低秩子空间：计算每个视图特征与受攻击图像特征f₀的残差r_i = f_i - f₀，堆叠所有残差形成矩阵R，对R进行SVD，选择前m个主成分（通过解释方差阈值ρ确定）作为子空间基U_m。
  - 步骤6：在子空间内学习共享特征校正向量δ，使得校正后的特征f_i' = f_i + U_m δ（所有视图共享同一个δ）。优化目标是最小化可靠性加权熵：min_δ Σ_i w_i * H(p(f_i'))，其中H是预测概率的熵，p由公式(1)计算。
  - 步骤7：使用一步AdamW更新δ。
- 关键模块/机制：
  - 多视图特征提取：生成原始图像及其增强视图的视觉特征，为后续子空间构建和熵最小化提供多样本支持；从测试图像x生成N+1个视图（包括原图），通过CLIP图像编码器F(·)提取d维特征向量。
  - 可靠性权重计算：评估每个视图特征的可靠性，用于加权熵最小化，降低低质量视图影响；基于视图特征间的余弦相似度矩阵S，通过温度τ缩放和top-K平均计算可靠性权重w_i，高相似度（一致性）的视图获得高权重。
  - 低秩子空间构建：从特征残差中提取样本特定的紧凑几何结构，限制校正向量的自由度，避免过拟合和无意义更新；计算各视图特征与原始图像特征的残差r_i = f_i - f₀，组成矩阵R∈R^{d×N}，对R进行奇异值分解(SVD)，保留解释方差达到阈值ρ的前m个主成分，构成子空间基U_m∈R^{d×m}。
  - 共享特征校正：学习一个低维校正向量δ，在子空间内调整所有视图的特征，使其预测熵最小化；校正向量δ∈R^m，共享应用于所有视图：f_i' = f_i + U_m δ。通过可靠性加权熵最小化优化δ，使用AdamW一步更新，学习率0.1。
- 公式/目标函数/指标定义：
  - CLIP零样本分类概率：p_c(x) = exp(cos(f, g_c)/τ) / Σ_j exp(cos(f, g_j)/τ) (公式1)
  - 子空间构建：对残差矩阵R进行SVD，选择前m个奇异向量满足累积解释方差≥ρ（ρ=0.9）
  - 优化目标：min_δ Σ_i w_i * H(p(f_i + U_m δ))，其中H为交叉熵（信息熵）
- 算法细节：
  - SVD分解：对残差矩阵R进行奇异值分解，保留主成分构建低秩子空间基U_m
  - 可靠性权重：计算视图间余弦相似度矩阵S，对每行进行温度缩放（温度0.05）并取top-K（K=5）平均，得到权重w_i
  - 一步优化：使用AdamW优化器，学习率0.1，仅更新一次δ
  - 视图数量：共64个视图（1个原图+63个增强视图）
- 训练/推理细节：
  - 多视图生成：使用AugMix数据增强策略生成N个随机视图
  - 推理阶段：对每个测试样本独立处理，无需训练或微调模型参数
  - 子空间维度：由解释方差阈值ρ=0.9自动确定，通常远小于原始特征维度d
  - 单步更新：为保持效率，仅执行一次优化步骤

### 5. Steering Vision-Language Models with Joint Sparse Autoencoders
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.25657v1
- 方法流程：
  - 阶段1 (训练): 输入视觉和文本序列池化激活，分别通过编码器得到稀疏码，经解码器重建，优化重建损失、L1稀疏损失和余弦对齐损失，输出对齐的稀疏码和解码器方向。
  - 阶段2 (特征发现): 对训练好的稀疏码进行活跃神经元过滤、L2归一化、K-means聚类，得到宏观概念特征集。
  - 阶段3 (干预): 提取目标概念对应的文本解码器方向，聚合为干预向量，对图像token位置进行加法或抑制操作，观察生成结果变化。
- 关键模块/机制：
  - 视觉编码器-解码器对 (Ev, Dv)：将平均池化的视觉激活映射为稀疏码并重建。；输入Av ∈ R^d，通过Ev映射得到zv = ReLU(Ev(Av)) ∈ R^k，再通过Dv重建Âv = Dv(zv)。
  - 文本编码器-解码器对 (Et, Dt)：将平均池化的文本激活映射为稀疏码并重建。；输入At ∈ R^d，通过Et映射得到zt = ReLU(Et(At)) ∈ R^k，再通过Dt重建Ât = Dt(zt)。
  - 余弦对齐损失 (L_align)：强制配对视觉与文本稀疏码方向一致，促使共享概念对应相同稀疏特征。；L_align = 1/B Σ (1 - cosine_sim(z_v, z_t))，其中cosine_sim计算余弦相似度。
  - 方向聚类 (Algorithm 1)：将细粒度原子特征聚合为宏观概念方向，用于后续干预。；过滤低方差神经元，构建L2归一化激活谱，K-means聚类，按轮廓系数排序并选择顶级簇。
  - 干预机制：使用文本解码器列作为干预方向，对图像token进行加法或抑制。；v_steer = Σ_{i∈I} w_t_i / ||w_t_i||_2, H' = H + α·v_steer ⊙ m，其中m为图像token掩码。
- 公式/目标函数/指标定义：
  - 平均池化: A_v = (1/N) Σ_{i=1}^N h_{v,i}, A_t = (1/M) Σ_{j=1}^M h_{t,j}
  - 总损失: L_total = λ_r L_recon + λ_s L_sparse + λ_a L_align
  - 重建损失: L_recon = 1/2 (||Â_v - A_v||^2 + ||Â_t - A_t||^2)
  - 稀疏损失: L_sparse = 1/2 (||z_v||_1 + ||z_t||_1)
  - 对齐损失: L_align = 1/B Σ_{b=1}^B (1 - cosine_sim(z_v^{(b)}, z_t^{(b)}))
  - 余弦相似度: cos(z_v, z_t) = (Σ_{i∈S_v∩S_t} z_{v,i} z_{t,i}) / (||z_v||_2 ||z_t||_2)
- 算法细节：
  - Algorithm 1: 直接语义特征发现。1. 活跃神经元过滤：计算每个稀疏特征在验证集上的方差，保留方差>1e-5的神经元。2. 激活谱构建与L2归一化：对每个神经元构建N维激活向量并归一化。3. K-means聚类：将所有神经元聚类。4. 聚类排序：按平均轮廓系数排序，人工检查丢弃多语义簇，保留top-K作为最终对齐特征。
  - 干预α校准：通过网格搜索选择α，平衡语义影响和生成流畅度。
- 训练/推理细节：
  - 训练：从VLM中间层（如第16层）提取视觉和文本隐藏状态，分别进行序列平均池化得到A_v和A_t。
  - 训练目标：联合优化重建、L1稀疏和余弦对齐损失，超参数λ_r, λ_s, λ_a需调节。
  - 推理：在干预实验中，将干预向量v_steer加到图像token的隐藏状态上，进行前向传播生成文本。
  - 抑制实验：使用负方向α·v_steer进行减法干预。

### 7. GAVEL: Grounded Caption Error Verification and Localization
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.26923v1
- 方法流程：
  - 数据构建：使用VLM或文本-to-图像模型生成候选图像-描述对，通过GPT-5 mini评估对齐分数，选择低分对送往人工标注。
  - 人工标注：标注员对不一致对撰写解释文本，并绘制对应bounding box；经过三阶段验证（初始标注+复审+随机抽检）。
  - 模型推理：输入图像和描述，基模型（如Qwen3-VL-8B）或微调后的VisionLLM输出解释和bounding box坐标。
  - 评估：计算预测框与真值框的IoU（阈值0.3/0.5/0.7），并用GPT-5对解释质量打分，最终平均得到LLM Score。
- 关键模块/机制：
  - 半自动数据生成管道：生成候选不一致图文对并过滤，减少人工标注负担。；利用VLM生成图文对，GPT-5 mini计算对齐分数，筛选低分对提交人工标注，确保数据质量。
  - 视觉-语言模型（VLM）基座（如Qwen3-VL）：作为GAVEL任务的基础模型，接收图像和文本，生成解释和bounding box。；使用多模态架构（视觉编码器+语言解码器），通过监督微调适应GAVEL任务。
  - 评估系统（GPT-5自动评分）：对生成的解释文本进行质量评定，替代人工评估。；将模型生成的解释与真值解释输入GPT-5，要求按0-5分评分，取平均后缩放至0-100。

- 算法细节：
  - 数据过滤：使用GPT-5 mini评估图文对齐分数，保留低分对作为候选负例。
  - 训练：使用VisionLLM框架作为base模型，在30,309张图像/35,249句训练集上微调，采用交叉熵损失（解释文本）和回归损失（bounding box坐标）。

### 8. IMCBench: A benchmark for multimodal LLMs in Image-grounded Medical Conversations

- 原文链接：https://arxiv.org/abs/2606.28556v1
- 方法流程：
  - 阶段1: 数据集构建 - 输入DDI图像和Synthea生成的EHR，通过条件匹配生成图像-EHR对；输出 ⟨image, EHR⟩ 对

  - 阶段4: 评估 - 使用LLM-as-Jury（Claude Sonnet 4.6）对对话从安全性、准确性、不确定性处理三个维度分别打分（1-5），取平均作为总分

  - 对话模拟引擎：控制患者-助手之间的多轮交替对话，限制患者行为以迫使助手主动询问信息；患者模拟器固定为Claude Haiku 4.5，限制只报告场景中症状、仅在被问及时披露病史、避免外部行为；图像在前三回合内以递增概率（0.7,0.85,1.0）上传

  - 条件匹配：基于性别和年龄组预过滤EHR，再用Claude Haiku 4.5选择最佳匹配

### 10. BTI-Net: Bidirectional Decoder-Level Task Interaction via Uncertainty-Aware Gating for Multi-Task Medical Image Analysis
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29102v1
- 方法流程：
  - 输入：224×224医学图像。
  - 编码器：EfficientNet-B4提取五个层级特征（s1-s4, bridge），每个层级后接多尺度上下文融合（MSCF）块（三个平行扩张可分离卷积+SE权重）。
  - 解码器：四层（D1-D4，通道384/192/96/48，分辨率14²→112²），每层包括TIM和UPA，通过转置卷积和注意力门控跳跃连接上采样。
  - TIM：每层同时执行Seg→Clf门控残差和Clf→Seg乘法调制，输入为原始预交互特征。
  - UPA：基于三个信号生成门控权重w_seg和w_clf，对TIM输出和原始特征进行插值。
  - 分割头：单卷积输出分割掩码。
  - 分类头：多尺度聚合，融合所有解码器层的UPA门控分类向量和编码器特征，输出分类标签。
- 关键模块/机制：
  - Task Interaction Module (TIM)：在每层解码器建立双向跨任务通信。；Seg→Clf：对解码器特征Dℓ进行1×1卷积降维、GAP、投影，经sigmoid门控g_clf后以残差形式注入分类向量f_clf。Clf→Seg：对分类向量f_clf投影到解码器通道空间得到u_clf，同时由解码器GAP后经sigmoid得到自门控g_seg，调制因子μ=1+0.7·g_seg⊙u_clf，与Dℓ逐元素相乘。
  - Uncertainty Proxy Attention (UPA)：每样本每层自适应门控TIM输出强度。；三层MLP输入三个信号：跨任务对齐aℓ（TIM残差投影后余弦相似度）、分割梯度能量E_seg（解码器图空间梯度均值）、分类激活扩展E_clf（增强分类向量log方差）。输出两个标量权重w_seg,w_clf∈[0,1]，对预交互特征和TIM增强特征进行线性插值。训练时由基于任务性能自动计算的困难度分数监督。
  - Multi-Scale Context Fusion (MSCF)：增强编码器各层级特征的多尺度上下文。；对编码器特征应用三个平行扩张可分离卷积（扩张率1,2,4），经挤压激励（SE）加权融合。
- 公式/目标函数/指标定义：
  - zℓ = GAP(Conv_{1×1}^{Cℓ/2}(Dℓ))
  - cℓ = Dense_{256}(ReLU(zℓ))
  - g_clf = σ(Dense_{256}(cℓ))
  - f_clf^{enh} = f_clf + g_clf ⊙ cℓ
  - u_clf = σ(Dense_{Cℓ}(f_clf))
  - g_seg = σ(Dense_{Cℓ}(GAP(Dℓ)))
- 算法细节：
  - 每层TIM的Seg→Clf路径：Dℓ经1×1卷积至Cℓ/2通道，GAP得zℓ，两层全连接（ReLU+线性）得cℓ，sigmoid门控g_clf，残差加回f_clf。
  - 每层TIM的Clf→Seg路径：f_clf经全连接投影至Cℓ维度后sigmoid得u_clf，Dℓ经GAP后全连接+sigmoid得g_seg，μ=1+0.7·g_seg⊙u_clf，与Dℓ逐元素乘。
  - UPA门控生成：三个信号aℓ、E_seg、E_clf拼接成3维向量，通过两层MLP（隐含层8维，ReLU）输出两个logits，经sigmoid得w_seg和w_clf。
  - 最终特征 = w_seg * D_enh^{ℓ} + (1-w_seg) * Dℓ （分割分支），分类分支类似。
  - 训练UPA的损失：利用每个样本的任务性能（如分割IoU、分类准确率）自动计算困难度分数，作为监督信号训练MLP输出与困难度相关的门控权重。
- 训练/推理细节：
  - 训练时使用难度感知损失约束UPA门控：每个样本基于其任务性能自动计算困难度分数（如1-IoU或1-accuracy），作为门控权重的目标。
  - 推理时UPA只需一次前向，无需额外采样或多次推理。
  - 总损失为分割损失（Dice+交叉熵）和分类损失（交叉熵）之和，加UPA正则项。

### 12. FADE: Mitigating Hallucinations by Reducing Language-Prior Dominance in Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29431v1
- 方法流程：
  - 输入: 图像和文本，经LVLM的L层Transformer解码器处理
  - 每层计算: 先经注意力模块得到˜h(l) = h(l) + Attn(l)(h(l))
  - 然后经FFN模块: h(l+1) = ˜h(l) + FFN(l)(˜h(l)) (标准) 或 FADE: h(l+1) = ˜h(l) + (1-α)·FFN(l)(˜h(l)) (在选定关键层)
  - 最终输出h(L)经LM头得到logits，解码生成文本
- 关键模块/机制：
  - 注意力模块 (Attention)：聚合视觉证据，推动预测向正确答案；在每一层，注意力机制在残差流上操作，汇集图像和文本token间的信息。贡献分析显示无论正确还是幻觉样本，注意力都对正确答案有正向贡献（+1.2和+0.8），说明其始终提供可靠的视觉证据。
  - FFN模块 (Feed-Forward Network)：在关键层引入语言先验，可能覆盖视觉证据导致幻觉；FFN在每位置独立变换，存储语言知识。在层16-22，对于正确样本FFN贡献+8.4（强化预测），对于幻觉样本贡献-3.5（主动推向错误），表明语言先验与视觉证据冲突时，FFN主导导致漂移。
  - FADE衰减机制：抑制关键层FFN输出，降低语言先验影响；在推理时，对选定关键层的FFN输出乘以(1-α)，其中α∈[0,1]为衰减强度（默认未指定，需调）。该操作以单次前向方式执行，无需对比解码或多次采样，保持效率。
  - 关键层识别 (Critical Layers)：确定需要干预的具体层范围；通过差分logit透镜计算每层注意力与FFN的贡献，发现FFN在层16-22(LLaVA-1.5-7B)出现正负贡献分化。对其他架构按比例映射至中间到后部层（如总层数32则对应层17-23）。
- 公式/目标函数/指标定义：
  - 残差流: ˜h(l) = h(l) + Attn(l)(h(l))
  - 标准FFN更新: h(l+1) = ˜h(l) + FFN(l)(˜h(l))
  - FADE更新: h(l+1) = ˜h(l) + (1-α)·FFN(l)(˜h(l))
  - 注意力贡献: Δ(l)_Attn(t) = LM_head(˜h(l))_t - LM_head(h(l))_t
  - 正确方向指标: C(l) = Δ(l)(t_correct) - Δ(l)(t_incorrect)
- 算法细节：
  - 贡献分析: 对POPE-Adversarial的50个样本，逐层计算每个token的logit变化，分离注意力和FFN的独立贡献
  - 关键层选择: 基于FFN贡献值的正负符号，在正确/幻觉样本间差异最大的连续层（16-22）作为衰减目标
  - 衰减操作: 在推理前向传播中，对指定层的FFN输出乘以(1-α)，其他层保持不变；α需针对模型和任务调整（实验中使用α=0.3等默认值）
  - 跨架构迁移: 按层数比例将关键层区间映射到其他模型（如总层24则映射到12-16）
- 训练/推理细节：
  - FADE是完全训练-free的方法，不修改模型参数，不增加训练步骤
  - 推理时仅需单次前向传播，在关键层的FFN输出后执行标量乘法，额外计算量可忽略
  - 衰减强度α为超参数，实验中对不同模型和基准可能不同（文中未统一固定值，需根据验证集调整）

- 公式/目标函数/指标定义：
  - LET分数生成：a = σ(f_θ(h_m))，a∈[0,1]^N，σ为sigmoid
  - LET监督损失：L_LET = - (1/N) ∑_{i=1}^N [z_i log a_i + (1-z_i) log(1-a_i)]
  - 噪声分布参数：(μ_i,σ_i) = G_φ(v_i), σ_i>0
  - 噪声采样：r_i = μ_i + σ_i ⊙ ϵ_i, ϵ_i∼N(0,I)
  - 门控函数：g_i = (1/τ)·ReLU(τ - a_i), τ=0.5
  - 净化token：e_v_i = v_i + g_i r_i
- 算法细节：
  - 证据探测：仅插入一个临时token ⟨mask⟩，计算其隐藏状态，映射为LET分数，然后移除该token
  - 门控计算：基于阈值τ=0.5，对分数低于0.5的token分配非零门控值，门控值与分数差距成正比
  - 噪声生成：为每个视觉token独立预测噪声分布的均值和标准差，通过重参数化采样实现梯度可穿透
  - 净化序列：保持原始token数量N和空间布局，仅修改每个token的嵌入向量，不改变token序列长度或结构
- 训练/推理细节：
  - 训练阶段：先进行监督微调（SFT），总损失包含答案损失和LET损失，β=0.2；后进行强化微调（GRPO），将LET分数建模为Bernoulli策略，用F1分数作为奖励，并添加KL散度正则化
  - 推理阶段：先执行一次前向传播（含临时token）获取LET分数，然后移除临时token，应用门控和噪声生成净化视觉token，最后用净化后的视觉序列进行答案解码，无需外部检测器或图像生成
  - 训练中使用问题相关框作为监督信号，无需额外推理链标注

  - ΔFN = F1(BASELINE) - F1(FULL NOISE IMAGE)

  - 噪声混合: 使用固定随机种子，对每个遮挡区域，将原始像素与高斯噪声按p线性混合，p=0即原始

- 训练/推理细节：
  - 所有VLM使用作者默认推理配置（文本提示、图像预处理、解码策略），仅输入正面胸部X光片
  - 每个模型接受相同的扰动图像（固定随机种子确保一致性）

### 23. Listening makes Vision Clear for VLMs
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.23763v1
- 方法流程：
  - 输入：图像I和提示文本P；输出：令牌到视觉区域的激活图
  - 构建增强序列Taug = Tv ⊕ Ttarget，其中Tv为视觉令牌，Ttarget为目标提示令牌
  - 对每个目标令牌ti，从最后一层多头注意力中提取a(l,h)(ti)并均值池化，得到PV-TAM(l)(ti)
  - 结构偏差消除：取目标令牌相邻两个特殊令牌的PV-TAM均值，从目标令牌的PV-TAM中减去该均值，再经ReLU截断得到Dt
  - 可选：使用前景掩码F进行元素级乘法细化得到Arefined_t
- 关键模块/机制：
  - PV-TAM提取模块：从提示令牌提取视觉激活图；使用提示令牌作为查询，在最后一层自注意力中计算其到所有视觉令牌的注意力向量，并在所有注意力头上均值池化，得到PV-TAM(l)(ti)。
  - 结构偏差消除模块：移除结构令牌引起的空间偏差；选取目标令牌前后两个结构令牌（如<im_end>），分别计算其PV-TAM，取均值作为偏差估计，从目标令牌的PV-TAM中减去该均值，再应用ReLU截断保留正值。
  - 前景引导细化模块（可选）：利用前景掩码抑制背景响应；使用off-the-shelf背景去除模型（如rembg）生成前景概率掩码F，与去偏差后的激活图Dt进行元素级乘法，得到仅关注前景的细化激活图。
- 公式/目标函数/指标定义：
  - 注意力权重: A(l,h) = Softmax(Q(l,h)K(l,h)⊤/√dk + M)
  - PV-TAM聚合: PV-TAM(l)(ti) = (1/|H|)∑_h a(l,h)(ti)
  - 结构偏差消除: Dt = At - 0.5*(As1 + As2); Dt ← max(0, Dt)
  - TGR: (∑_{(x,y)∈Ωt} A(x,y)) / (∑_{x,y} A(x,y))
  - TDR: (∑_{(x,y)∈Ωt} A(x,y)) / (∑_{(x,y)∈Ωd} A(x,y))
  - MinDist: 从峰值到目标掩码的最小距离，归一化后取平均
- 算法细节：
  - 对于每个目标令牌，从最后一层自注意力提取其到所有视觉令牌的注意力权重，形成原始注意图
  - 在所有注意力头上进行均值池化，得到多头的聚合注意图
  - 取目标令牌前后两个结构令牌的聚合注意图，计算均值作为结构偏差
  - 从目标令牌的聚合注意图中减去结构偏差，并经过ReLU截断
  - 可选地使用前景掩码进行元素级乘法
  - 最终将激活图上采样至原图分辨率
- 训练/推理细节：
  - 方法仅用于推理时的解释，无需训练
  - 基于预训练VLM（如Qwen2-VL、InternVL）提取注意力，不修改模型参数
  - 所有实验使用模型最后一层注意力

### 24. ABACUS: Adapting Unified Foundation Model for Bridging Image Count Understanding and Generation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.23835v1
- 方法流程：
  - 阶段1：理解分支训练（Understanding Branch Training）。输入：密度感知缩放后的图像。处理：使用MLLM（Qwen2）和可学习查询嵌入，联合优化SFT损失和物体性正则化损失L_obj，通过LoRA微调。输出：结构化的计数预测（如count, bbox, density map）。后训练：应用边界感知GRPO进一步减少过/欠计数。
  - 阶段2：连接器训练（Connector Training）。输入：理解分支冻结后的MLLM输出特征和DiT条件空间。处理：训练连接器（cross-modal projector）对齐两种特征空间。输出：对齐后的条件嵌入。
  - 阶段3：生成分支训练（Generation Branch Training）。输入：大量计数条件生成数据。处理：训练连接器和DiT（SANA-1.5B），后训练采用循环一致GRPO，以理解分支计算的计数偏差和美学奖励作为信号。输出：计数忠实的生成图像。
- 关键模块/机制：
  - 密度感知自适应缩放（Density-aware Adaptive Zooming）：增强多密度场景下的空间定位能力；使用冻结的GroundingDINO-T主干加2层MLP头（隐藏层256维，ReLU，dropout0.1）作为密度指示器φ(·)，在约15K图像上训练二分类（稀疏<20物体 vs 密集≥20）。推理时，若sd≥0.5则触发递归2×2划分，最大深度γ=3，将图像划分为子区域并分别处理。

### 26. FlowTrain: Flow-Based Decoupled Training for Industrial-Grade Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.23087v1
- 方法流程：
  - 初始化阶段：异构并行分配器根据资源预算R和模块（编码器集E、骨干b）的可行并行配置集Ci，求解流匹配问题，将集群划分为编码器池和骨干池，各自采用独立并行策略
  - 编码阶段：冻结的编码器异步处理多模态输入（图像/文本），将生成的嵌入和文本token写入统一内存池的GVA区域，同时存储元数据（如样本配对信息、计算成本）
  - 打包阶段：动态打包调度器利用元数据，通过段树最佳适应算法和之字形调度，构建计算平衡的微批次，并放入内存池
  - 消费阶段：LLM骨干网络从内存池中通过GVA透明读取微批次，进行前向/反向传播训练
- 关键模块/机制：
  - 统一内存池 (Unified Memory Pool)：作为编码器生产者和骨干消费者之间的异步协调层，解耦执行依赖；使用64位全局虚拟地址（GVA）统一所有节点的HBM和DRAM资源。GVA空间分为两个区域（HBM和DRAM），每个进程分配连续区间[start+i*max_size, start+(i+1)*max_size)。初始化时，每个进程保留GVA段、分配物理内存并绑定，并向其他进程导出映射信息更新页表。训练时，编码器将嵌入写入自身GVA段，骨干通过页表透明访问，传输引擎根据源/目的位置选择NVLink、HCCS或RDMA。
  - 异构并行分配器 (Heterogeneous Parallel Allocator)：为不同模块分配定制并行策略和资源，实现整体吞吐匹配；将资源分配形式化为流匹配优化问题：目标为词典序最大化全局吞吐G=min(T_enc, T_bb)和最小化流不平衡F=|T_enc-T_bb|，约束每个模块选一个配置、总资源不超过R。其中T_enc=∑_{e∈E}∑_{c∈Ce} x_{e,c}τ_e(c)，T_bb=∑_{c∈Cb} x_{b,c}τ_b(c)。该问题NP难，实际通过启发式求解（如贪心）
  - 动态打包调度器 (Dynamic Packing Scheduler)：运行时构建计算平衡的微批次，减少填充浪费；基于元数据（实际LLM端计算成本，非原始样本大小），使用段树最佳适应算法将样本打包成微批次，并通过之字形调度（zig-zag dispatch）在流水线并行和数据并行维度平衡负载。
- 公式/目标函数/指标定义：
  - 编码器总生产速率：T_enc = ∑_{e∈E} ∑_{c∈Ce} x_{e,c} τ_e(c)
  - 骨干总消费速率：T_bb = ∑_{c∈Cb} x_{b,c} τ_b(c)
  - 流匹配优化问题：lexmax (G, -F), s.t. G = min(T_enc, T_bb), F = |T_enc - T_bb|, ∑_{c∈Ci} x_{i,c}=1, ∀i∈E∪{b}, ∑_{i∈E∪{b}}∑_{c∈Ci} x_{i,c} r_i(c) ≤ R
  - 全局吞吐G定义为min(T_enc, T_bb)，流不平衡F定义为|T_enc - T_bb|
- 算法细节：
  - GVA空间划分：每个进程在GVA中分配连续区间，物理内存绑定后向其他进程导出映射信息，更新全局页表
  - 透明访问：骨干通过GVA访问嵌入，页表将GVA转换为物理地址，传输引擎根据位置选择NVLink/HCCS/RDMA
  - 流匹配求解：采用词典序优化，先最大化G再最小化F，实际通过启发式（如贪心）近似求解NP难问题
  - 动态打包：使用段树实现最佳适应（best-fit）算法，结合之字形调度（zig-zag dispatch）在PP和DP维度平衡负载
- 训练/推理细节：
  - 训练采用异步数据流：编码器作为生产者，骨干作为消费者，通过统一内存池协调，无批次同步屏障
  - 冻结编码器（frozen encoders），仅更新骨干网络参数
  - 动态打包运行时根据实际LLM计算成本构建微批次，减少padding浪费
  - 资源分配在训练前一次性完成，调度在每轮迭代动态执行

- 方法流程：

  - TAPAScore: 基于匹配潜态在扰动下的响应方向一致性，具体公式未在正文中展开
- 算法细节：
  - FBMP算法: 初始化空联盟，迭代添加潜态以最大化联盟重建属性向量的F1分数，直到达到预设大小或F1不再显著提升
  - TAPAScore计算: 对每个匹配的概念，在合成图像对上计算潜态平均响应变化，统计正向响应比例，结合选择性权重

  - SAE训练: 使用L1稀疏惩罚或TopK约束，通过最小化重建误差和稀疏正则项学习编码器、解码器和偏置
  - SAE推理: 给定嵌入x，计算稀疏潜态激活z，阈值化为二值向量用于匹配

### 30. Spectral Evolution-Guided Token Pruning in Multimodal Large Language Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.24165v1
- 方法流程：
  - 输入：视觉token序列（经过LLM前L层后的表示）
  - 步骤1：对每个视觉token，提取相邻两层（ℓ和ℓ+1）的d维特征向量
  - 步骤2：将每个token的二维空间位置（H×W）重构成图像块，对每个通道独立计算2D FFT
  - 步骤3：对频域表示应用高斯高通滤波（σ控制截止频率），抑制低频成分
  - 步骤4：计算滤波后两层频域表示的幅度谱差值并归一化（除以当前层幅度谱均值），得到单层频谱演化分数
  - 步骤5：将多个相邻层的演化分数积分（求和或平均），得到每个token的最终重要性分数
  - 步骤6：根据分数排序，保留前K个高重要性token，丢弃其余
  - 输出：剪枝后的视觉token子集
- 关键模块/机制：
  - 跨层频谱演化计算模块：评估每个视觉token在跨层变换中的语义活跃程度；对相邻层token特征，通过2D FFT将空间特征映射到频域，使用高斯高通滤波G(u,v)=1-exp(-(u^2+v^2)/(2σ^2))抑制低频，计算滤波后幅度谱的归一化差：S_ℓ,n = ||F_high(X_ℓ,n)| - |F_high(X_{ℓ+1},n)|| / (mean(|F_high(X_ℓ,n)|)+ε)，然后跨层积分：I_n = Σ_ℓ S_ℓ,n
  - 剪枝决策模块：根据重要性分数选择保留的视觉token；对所有视觉token的重要性分数降序排序，保留前K个分数最高的token，其余丢弃。K可通过保留比例或固定阈值设定。
- 公式/目标函数/指标定义：
  - 频谱演化分数：S_ℓ,n = ||F_high(X_ℓ,n)| - |F_high(X_{ℓ+1},n)|| / (mean(|F_high(X_ℓ,n)|)+ε)
  - 跨层积分重要性：I_n = Σ_{ℓ∈L} S_ℓ,n（L为选定层对集合）
  - 高斯高通滤波：G(u,v) = 1 - exp(-(u^2+v^2)/(2σ^2))
- 算法细节：
  - 在LLM前向传播过程中，选取前几个Transformer层（如第1-4层）计算频谱演化
  - 对每个层对的视觉token表示，先重构成2D空间形状（H×W，原始图像网格形状），对每个特征通道独立进行2D FFT
  - FFT后得到复数频谱，计算幅度谱，应用高斯高通滤波（仅保留高频成分）
  - 相邻层滤波后幅度谱逐元素相减取绝对值，除以当前层幅度谱的均值（加小常数防止除零）
  - 得到的分数衡量了token在层间从高频到低频的转变强度，分数越高表示语义越活跃
  - 将多个层对的分数累加得到每个token的总重要性
  - 最后按重要性保留top-K token，后续层只处理这些保留token（和文本token）
- 训练/推理细节：
  - 训练无关：无需任何训练，仅利用LLM预训练权重
  - 推理时，在预填充阶段（prefill）计算频谱演化，剪枝后KV缓存仅存储保留token的键值，减少显存和计算
  - 支持与token合并方法（如ToMe）正交结合，先剪枝后合并可进一步提高压缩率

### 32. REViT: Roto-reflection Equivariant Convolutional Vision Transformer
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.25318v1
- 方法流程：
  - 输入图像经过lift layer，通过群卷积将输入映射到群表示（如p4, p8, p4m）
  - 群表示特征图输入多个G-CSA Transformer块，每个块包含：群等变卷积自注意力和前馈网络
  - G-CSA模块中，使用群等变卷积生成Query、Key、Value，然后计算自注意力，输出经残差连接和层归一化
  - 最后经过分类头（全局平均池化+全连接层）输出类别预测
- 关键模块/机制：
  - Lift Layer：将输入图像从标准空间提升到群表示空间，实现初始的等变特征提取；使用群卷积（group convolution）将输入图像与群上的滤波器进行卷积，输出大小为[C, H, W, |G|]的特征图，其中|G|为群元素个数。
  - G-CSA (Group Equivariant Convolutional Self-Attention)：核心注意力模块，实现群等变的特征交互；使用群等变卷积（而非线性投影）生成Query、Key、Value，然后按群元素分组计算注意力分数，最后通过注意力池化得到输出。避免了标准自注意力中非等变的线性变换，且不需要相对位置编码。
  - Classification Head：将等变特征映射到类别概率；对特征图进行全局平均池化（在空间和群维度上），再接一个全连接层。由于池化是等变的，最终预测具有不变性。
- 公式/目标函数/指标定义：
  - 等变误差：E_eq = ||f(g·x) - g·f(x)||_1，其中f为模型，g为群变换，x为输入
  - 群卷积定义：[(f * ψ)(g)] = ∑_{h∈G} f(h) ψ(g^{-1}h)，但原文未给出具体公式，此处为群卷积通用形式
- 算法细节：
  - G-CSA实现：对于每个群元素g，使用共享的卷积核在对应的g-变换后的特征图上滑动，生成Q_g, K_g, V_g
  - 注意力计算：对于每个g，注意力分数由Q_g和所有K_h（h∈G）的点积得到，即跨群元素交互，最后加权聚合V
  - 分组归一化：在每个Transformer块中使用群归一化（Group Normalization）以保持等变性
  - 前馈网络：使用群等变卷积替代全连接层，确保等变性
- 训练/推理细节：
  - 训练数据集：Rotated MNIST (62K 28x28), PatchCamelyon (327K 96x96), CIFAR-10 (60K 32x32), ImageNet-1K (224x224)
  - 优化器：AdamW，学习率调度采用余弦退火，训练300 epoch（ImageNet为300 epoch）
  - 模型规模：约44K参数（Rotated MNIST实验），ImageNet版本18M参数
  - 批大小：16（Rotated MNIST复杂度实验），其他实验未明确
  - 数据增强：仅使用随机水平翻转，无旋转增强以测试等变能力

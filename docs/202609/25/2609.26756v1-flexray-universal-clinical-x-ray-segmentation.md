## 摘要
X 射线是医学中使用最广泛的成像模态，却仍是量化程度最低的模态之一。与 CT 或 MRI 等容积成像模态不同，X 射线将三维解剖结构压缩为二维投影，导致结构重叠、解剖边界模糊，即使对专家也是如此。因此，为训练通用分割系统而标注 X 射线数据库并不现实，这使得 X 射线的形态计量与功能分析局限于狭窄的解剖区域和应用。为此，我们提出 FleXray，一个用于临床 X 射线全身解剖结构分割的通用模型。我们没有整理大规模人工标注的 X 射线数据集，而是构建了一个可扩展、基于物理的生成式 X 射线数据引擎。利用现有的三维全身 CT 分割数据集和生成式图像编辑模型，我们模拟了具有多样外观、生理特性和成像几何的完全标注二维 X 射线图像。在这些模拟数据上训练后，FleXray 能够在未见过的研究数据集和真实世界 X 射线中准确分割 60 个解剖结构。我们进一步表明，FleXray 使 X 射线可直接用于定量分析，从而支持疾病分级中的自动测量、X 射线引导介入中的稳健导航，以及对病理目标的数据高效学习。我们在 https://flexray.csail.mit.edu 发布了模型、代码、一个全身 X 射线分割数据集，以及一个本地、易用的基于浏览器的工具。

## Abstract
X-ray is medicine's most widely used imaging modality, yet remains among its least quantitative. Unlike volumetric modalities like CT or MRI, X-ray collapses 3D anatomy into a 2D projection, causing structures to overlap and anatomical boundaries to be ambiguous, even to experts. As a result, labeling X-ray databases for training general-purpose segmentation systems is impractical, leaving morphometric and functional X-ray analysis confined to narrow anatomical regions and applications. To this end, we present FleXray, a generalist model for anatomical segmentation across the entire body in clinical X-rays. Instead of curating large, manually annotated X-ray datasets, we build a scalable, physics-based generative X-ray data engine. Using existing 3D whole-body CT segmentation datasets and generative image-editing models, we simulate fully-annotated 2D X-rays with diverse appearances, physiological properties, and imaging geometries. Trained on these simulations, FleXray accurately segments 60 anatomical structures across unseen research datasets and in-the-wild X-rays. We further show that FleXray makes X-rays directly amenable to quantitative analysis, enabling automated measurements for disease grading, robust navigation during X-ray-guided interventions, and data-efficient learning of pathological targets. We release the model, code, a full-body X-ray segmentation dataset, and a local, easy-to-use browser-based tool at https://flexray.csail.mit.edu .

## 2. 方法论

### 2.1 核心思想

- **不整理大规模人工标注 X 射线数据集**，而是利用现有三维全身 CT 分割数据集和生成式图像编辑模型，构建可扩展、基于物理的生成式 X 射线数据引擎。
- 通过从 CT 体积及其标签中进行不同视角的射线投影，生成带标注的合成 X 射线；单个标注 CT 可生成多个训练视角，扩大监督覆盖。
- 目标是模拟具有**多样外观、生理特性和成像几何**的完全标注二维 X 射线，训练一个能分割 **60 个解剖结构**的通用模型。

### 2.2 关键技术细节

- **物理投影与 DRR 生成**：对 CT 体积和对应分割标签做 ray-projection，得到数字化重建放射影像（DRR）及继承标签。不同视角、源到探测器距离、探测器像素间距、投影模式、平面内旋转和平移等成像几何均可采样。
- **在线与离线数据混合**：
  - 训练批次按概率从不同来源采样。
  - MOOSE 在线 DRR 与增强 DRR 合计占 **75%** 训练步数，剩余 **25%** 来自其他来源。
  - 增强 DRR 是预先从 MOOSE 渲染后，再用扩散模型 `flux.2-klein-9b` 精修的合成 X 射线。
  - 所有划分按受试者分离，避免同一患者跨划分泄漏。
- **生成幻觉过滤**：对生成样本计算其与继承标签之间的 SoftDice 差异 ∆，去除高 ∆ 尾部样本，以抑制生成模型将非标准视图替换为类正位胸片等结构性幻觉。
- **训练增强**：包括衰减随机化、强度反转、完整图像空间增强预设等。部分增强同时更新图像和掩膜，部分仅更新图像；CLAHE 与 gamma 按样本互斥。
- **推理增强**：发布版本使用 **五成员集成**与 **16 样本测试时增强（TTA）**。TTA 包含旋转、剪切、噪声、CLAHE/gamma 等操作，并做预测平均与逆对齐。
- **下游任务接口**：
  - **疾病分级**：从 AASCE 的椎体掩膜预测中，通过中心线推导终板方向，进而计算主要 Cobb 角。
  - **介入导航**：将 FleXray 分割导出的 Chamfer 损失项加入 C-arm 位姿估计，提高 X 射线引导介入中的配准稳健性。
  - **病理目标学习**：在少量标注下微调 FleXray，用于 BTXRD 肿瘤检测等病理目标。

## 3. 实验设计

### 3.1 数据集与场景

- **背景统计**：汇总 **12 个公开 X 射线分割数据集**，包含 **667,380 张带标注 X 射线**，显示标注在身体各区域分布不均，且集中于胸部。
- **主要评估**：使用 **8 个完全未参与训练的保留真实 X 射线数据集**，测试分区合计约 **1,458 张图像**。涉及全身多部位、多采集条件、病理与介入场景。
- **典型数据集/场景**：
  - DeepFluoro：C-arm 位姿估计与导航。
  - VinDr-Rib：肋骨分割。
  - DarwinCVD19：肺部分割，含健康与肺炎病例。
  - MTDDH：多结构分割与少样本微调。
  - BTXRD：肿瘤检测与病理目标学习。
  - AASCE：脊柱 Cobb 角测量。
  - MURA、Radiopaedia：真实临床/非标准视图泛化与失败案例分析。
- **评估标签类型**：多数为像素级分割掩膜；AASCE 为 Cobb 角，由 68 个椎角点导出。掩膜可为重叠结构或互斥分区。

### 3.2 Benchmark 与指标

- **分割指标**：平均标签 Dice、HD95、aFPR（每数据集前景误报率相关指标）。
- **检测指标**：BTXRD 上 IoU=0.5 的平均精度 AP50，并按真实框面积分层。
- **下游指标**：主要 Cobb 角绝对误差；C-arm 位姿估计的平均目标配准误差 mTRE，10 mm 为成功阈值。
- **参考基线**：

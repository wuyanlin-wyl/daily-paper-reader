## 摘要
大型视觉语言模型（LVLMs）会因冗余的视觉令牌而带来高昂的计算成本。尽管在视觉编码器阶段基于注意力的免训练多层剪枝已被探索为一种有效策略，但我们发现，在浅层进行剪枝会持续导致性能下降。本文旨在理解这一问题并寻求解决方案。通过分析网络深度上的注意力模式，我们发现浅层主要充当边缘检测器，其注意力图较为混乱，而深层则经历局部主体识别和不稳定语义聚合的过渡。为解决剪枝策略与网络阶段之间的不匹配问题，我们提出了 STD，一种分层令牌剪枝框架，使令牌选择机制适应每个网络阶段的功能角色。STD 在浅层采用高频谱分析以确定性地保留结构边缘，在中间层使用高斯平滑注意力以保持空间连贯性，并在深层引入稳定性自适应触发器，仅在语义稳定阶段执行剪枝。大量实验表明，STD 在 LLaVA-1.5-7B 上以 88.9% 的令牌减少率超越最先进的剪枝方法 1.1%，同时具有即插即用性，并与其他方法结合时非常有效；在 LLaVA-NeXT-7B 上以 94.4% 的减少率超越 2.1%，在预填充阶段实现 3.9 倍加速。我们的代码将发布于 https://github.com/Twilight03/STD。

## Abstract
Large Vision-Language Models (LVLMs) incur high computational costs from redundant visual tokens. Although training-free attention-based multi-layer pruning in the vision encoder stage has been explored as an effective strategy, we find that pruning in shallow layers consistently degrades performance. In this paper, we aim to understand this problem and seek a solution. By analyzing attention patterns across network depth, we find that shallow layers primarily function as edge detectors with chaotic attention maps, while deeper layers transition through local subject recognition and unstable semantic aggregation. To address the misalignment between pruning strategies and network stages, we propose STD, a hierarchical token pruning framework that adapts token selection mechanisms to the functional role of each network stage. STD employs High-Frequency Spectral Analysis in shallow layers to deterministically preserve structural edges, uses Gaussian-Smoothed Attention in intermediate layers to maintain spatial coherence, and introduces a Stability-Adaptive Trigger in deep layers to execute pruning only during semantically stable phases. Extensive experiments show that STD outperforms state-of-the-art pruning methods by 1.1% on LLaVA-1.5-7B with 88.9% token reduction, while also being plug-and-play and highly effective when combined with other methods, and by 2.1% on LLaVA-NeXT-7B with 94.4% reduction, delivering a 3.9x speed-up in the prefilling stage. Our code will be released at https://github.com/Twilight03/STD.

# 论文总结：Shallow to Deep: Aligning Token Pruning with Stage-wise Roles in LVLMs

## 1. 核心问题与整体含义

- **研究背景**：大型视觉语言模型（LVLMs）在处理高分辨率输入时，视觉 token 序列庞大，带来高昂的计算与显存开销。视觉编码器阶段的免训练剪枝因能在 token 进入 LLM 前去除冗余，比 LLM 阶段剪枝更高效，其中基于注意力的多层剪枝是主流有效方案。
- **核心问题**：作者发现一个被忽视的反常现象——在浅层进行基于注意力的剪枝会**持续损害模型性能**。控制实验（Table 1）表明，在 192/128/64 token 三种预算下，禁用浅层剪枝、仅在中深层剪枝的版本在所有 benchmark 上均优于全层剪枝。
- **问题根源**：现有方法假设注意力在浅层同样可靠，但作者分析发现浅层注意力图**混乱、含噪**，无法捕捉语义结构；浅层实际扮演**边缘检测器**角色，其 token 重要性更依赖频谱特性而非注意力权重。剪枝准则与网络阶段功能角色之间存在**错配**。
- **整体含义**：论文从“网络深度上的功能演化”视角重新审视剪枝，提出将剪枝策略与各阶段角色对齐，从而在保持甚至提升性能的同时大幅压缩视觉 token。

## 2. 方法论：STD 分层剪枝框架

### 核心思想
将视觉编码器划分为三个功能阶段，为每个阶段设计匹配的 token 选择机制，替代统一的注意力剪枝。整体流程见 Figure 5，超参数统一设为 `L1 = 6`、`L2 = 12`。

### 关键技术细节

- **阶段一：浅层（ℓ ≤ L1）——高频谱分析（HSA）**
  - 对 patch token 序列 `P(ℓ) ∈ R^{N×D}` 沿 token 维度做实数快速傅里叶变换（RFFT），得到频域表示。
  - 保留频谱**上三分之二**的高频分量（对应边缘与细节），其余置零，再经逆 RFFT 重建得到 `P̃_high`。
  - 每个 token 的高频能量得分 `s_i^{high} = ||p̃_i^{high}||_2^2`。
  - 与 CLS 注意力加权融合：`r_i = α · s_i^{high} + (1−α) · a_i`，α 平衡频域与注意力线索（LLaVA-1.5 设 0.8，LLaVA-NeXT/Qwen2-VL 设 0.5），所有分数 min-max 归一化。
  - 目的：用确定性边缘信号替代混乱的注意力，避免误删关键结构信息。

- **阶段二：中间层（L1 < ℓ ≤ L2）——高斯平滑注意力（GSA）**
  - 模型开始进行主体级语义识别，注意力具局部性，但硬阈值易导致物体部件碎片化。
  - 对注意力权重沿 token 序列做一维高斯核卷积：`r_i = Σ_δ G_σ(δ) · a_{i+δ}`，核宽 K、标准差 σ。
  - 目的：保持空间连贯性与特征连续性。

- **阶段三：深层（ℓ > L2）——稳定性自适应触发器（SAT）**
  - 深层进入抽象语义聚合阶段，注意力向 hub token 收敛，且层间语义变化**不稳定**。
  - 定义相邻层语义变化量 `Δ(ℓ) = ||a(ℓ) − a(ℓ−1)||_2`。
  - **仅当** `Δ(ℓ) < Δ(ℓ−1)`（语义变化递减、进入稳定期）时才触发剪枝；触发层仅使用原始注意力权重 `r_i = a_i` 选择 token。
  - 目的：避免在语义快速演化的关键层剪枝，仅在冗余较高的稳定层压缩。

- **剪枝节奏**：浅层与中层每两层执行一次剪枝，逐步减少冗余；最终剪枝层强制达到目标保留 token 数。

## 6. 主要结论与发现

- **浅层剪枝有害**：浅层注意力混乱，基于注意力的剪枝会误删关键信息；禁用浅层剪枝即可提升性能。
- **阶段化功能角色**：
  - 浅层：边缘检测器，关注高频轮廓，注意力距离呈“U 型”曲线的上升段。
  - 中层：局部主体识别，注意力聚焦完整语义对象，空间连贯性强。
  - 深层：抽象语义聚合，注意力向 hub token 收敛，层间语义变化不稳定、波动剧烈。
- **STD 有效性**：
  - LLaVA-1.5-7B：64 token（↓88.9%）下超越 SOTA 1.1%，与 FlowCut 结合再提升 1.8%；192 token 下 STD+SparseVLM 超越 SOTA 1.5%。
  - LLaVA-NeXT-7B：160 token（↓94.4%）下超越 SOTA 2.1%。
  - Qwen2-VL：各压缩比下均最优。
  - 视频任务：保留 96.7% 平均准确率，超越 FiCoCo-V 5.3%。
  - 效率：LLaVA-NeXT 预填充加速 3.9×，总推理加速 3.8×；LLaVA-1.5 预填充加速 1.8×。
- **泛化性**：阶段化规律在 InternVL3-8B、Qwen3-VL-8B 上同样成立，STD 分别超越 SOTA 1.3% 和 1.7%。
- **互补性**：视觉编码器剪枝与 projector/LLM 阶段剪枝解决不同冗余来源，可叠加使用并获得最佳平均分。

## 摘要
尽管基于LLM和知识图谱增强的放射学报告生成（RRG）方法取得了显著进展，现有技术仍存在固有缺陷。传统的仅LLM模型缺乏结构化的医学先验知识，导致频繁出现医学幻觉且诊断可解释性较低。当前知识图谱增强方案采用单源知识的静态单轮知识融合，无法根据生成反馈动态更新知识。本文提出了一种新颖的用于X射线放射学报告生成的多智能体协作迭代框架，称为MAC-RRG。受多智能体技术启发，我们的框架基于任务解耦与协作推理构建了闭环优化范式。具体而言，该框架首先通过视觉编码器和基础LLM从输入X射线图像生成初步放射学报告。随后，多模态知识图谱（MM-KG）智能体从医学知识图谱中挖掘结构化的疾病关联和解剖学知识，而辅助知识智能体从公共医学数据库中提取非结构化领域知识。双智能体获取的多源知识被融合并嵌入，以指导LLM迭代优化初始报告。在主流X射线RRG数据集（包括IU X-ray、MIMIC和CheXpert Plus）上进行的大量定量与定性实验充分验证了所提方法的优越性。源代码和预训练模型已在 https://github.com/Event-AHU/Medical_Image_Analysis 上发布。

## Abstract
Despite the remarkable progress of LLM-based and knowledge graph-augmented Radiology Report Generation (RRG) methods, existing techniques still suffer from inherent defects. Conventional LLM-only models lack structured medical prior knowledge, resulting in frequent medical hallucinations and low diagnostic interpretability. Current knowledge graph-enhanced schemes adopt static one-round knowledge fusion with single-source knowledge, incapable of dynamic knowledge updating according to generation feedback. This paper proposes a novel Multi-Agent Collaborative iterative framework for X-ray Radiology Report Generation, termed MAC-RRG. Inspired by multi-agent technology, our framework constructs a closed-loop optimization paradigm based on task decoupling and collaborative reasoning. Specifically, the framework first generates a preliminary radiology report from input X-ray images via a vision encoder and a basic LLM. Subsequently, a multimodal knowledge graph (MM-KG) agent mines structured disease correlation and anatomical knowledge from medical knowledge graphs, while an auxiliary knowledge agent extracts unstructured domain knowledge from public medical databases. The multi-source knowledge acquired by dual agents is fused and embedded to guide the LLM in iteratively refining the initial report. Extensive quantitative and qualitative experiments on mainstream X-ray RRG datasets, including IU X-ray, MIMIC, and CheXpert Plus, fully verify the superiority of our proposed method. The source code and pre-trained models have been released on https://github.com/Event-AHU/Medical_Image_Analysis

- **核心问题**：现有 RRG 方法存在三大固有缺陷：
  1. **纯 LLM 基线**：仅融合原始 X 光图像的视觉特征，缺乏结构化医学先验知识，导致频繁的医学幻觉与低诊断可解释性。
  2. **知识图谱增强方法**：采用单源知识、静态单轮融合，无法根据生成反馈动态调整与迭代检索所需知识，且仅依赖结构化图知识，缺乏非结构化文本知识（文献、临床指南）。
  3. **一次性生成范式**：缺乏反馈回路，初始报告中的实体遗漏与描述偏差无法被持续验证和纠正。
- **整体含义**：论文受多智能体技术启发，提出迭代式多智能体协作框架 MAC-RRG，通过任务解耦、角色专业化分工、动态交互推理与迭代闭环优化，弥补可解释性缺失、静态知识融合与非迭代生成三大瓶颈。

## 二、方法论

### 核心思想
以初始草稿报告作为"实体感知桥梁"，连接视觉证据与外部医学知识；由两个角色专业化智能体分别挖掘结构化图知识与非结构化文本知识，经融合模块嵌入后引导 LLM 迭代精炼报告。

### 关键技术细节与流程

1. **初始报告生成与实体抽取**
   - 用 Swin Transformer 视觉编码器将 X 光图像编码为视觉 token 序列 `V = fv(I) ∈ R^{Nv×dv}`，投影至 LLM 隐空间，自回归生成初始报告 R0。
   - 对 R0 分句、规范化标点与大小写，基于放射学实体词典做词法匹配，仅保留 **解剖（anatomy）** 与 **疾病/异常（disorder）** 两类实体，跨句去重形成检查级实体集合 `E = {(ei, ti)}_{i=1}^M`。

2. **MM-KG 智能体（结构化知识）**
   - 将医学知识图谱存储为加权三元组，对每个实体 ei 检索源/目标匹配的三元组，按频次排序保留 top-Kg（默认 10）个邻居：`Gi = {(ei, r_ij, n_ij)}_{j=1}^{Ki}`。
   - 中心实体、邻居实体与关系标签用**冻结的 Bio_ClinicalBERT** 编码，保留解剖区域—影像发现—疾病之间的局部图上下文关系。

3. **知识智能体（非结构化知识）**
   - 基于 PubMedVision 数据集构建 CXR 检索语料，由 LLM 将问答对总结为结构化知识条目。
   - 检索查询由完整草稿报告、目标实体及其类型拼接而成：`qi = [R0; ei; ti]`。
   - 用 **BGE-M3** 编码查询，按内积相似度检索 top-N（=10）候选块，再用 **BGE reranker** 重排，保留 top-Kr（=1）块；不同实体检索结果合并去重得证据列表 `C = {c1, ..., cNr}`。
   - 每个块用冻结的 Bio_ClinicalBERT + 均值池化编码：`rj = Normalize(Σ aℓj Hℓj / Σ aℓj)`，堆叠填充为 `R ∈ R^{Nr×768}`。

4. **知识融合模块**
   - **图分支**：采用关系感知图注意力编码器，中心实体作 Query，邻居 Key 为邻居嵌入加边嵌入（`Kij = WK hij + qij`），注意力权重经 softmax 归一化，聚合后经 MLP 得图上下文表示 `gi`，拼接为 `G = [g1; ...; gM]`。
   - **融合策略**：将图与检索表示投影至视觉特征维度（`G̃ = WgG`，`R̃ = WrR`），直接拼接得 `Z = [V; R̃; G̃]`，再经 `E = LayerNorm(WllmZ)` 投影到 LLM 隐空间。

5. **损失函数**
   - 将融合表示 E 与文本生成提示嵌入 P 拼接为条件前缀 `H = Concat(E, P)`。
   - 自回归语言建模目标：`LLM = -(1/T) Σ log pθ(yt | y<t, H)`。
   - 训练时对提示、视觉 token、图知识 token、检索知识 token 对应标签掩码为 −100，仅真值报告 token 贡献损失。

### 实现配置
- 视觉编码器：预训练 Swin Transformer；语言骨干：**Llama2-7B**。
- 图特征与检索特征编码为 768 维，融合后映射至 1024 维视觉空间，再投影至 4096 维 LLM 嵌入空间。

## 六、主要结论与发现

- **NLG 性能**：
  - IU-Xray：BLEU-1/2/3/4 = 0.488/0.330/0.249/0.197，ROUGE-L = 0.400，METEOR = 0.223，CIDEr = 0.703，在 BLEU-3/4、ROUGE-L、CIDEr 上最优。
  - CheXpert Plus：在 BLEU-2/3/4、ROUGE-L、METEOR 上最优；BLEU-1 略低于 Token-Mixer，CIDEr 略低于 R2GenGPT。
  - MIMIC-CXR：在 BLEU-2/3/4 上最优（0.258/0.177/0.128），高阶 BLEU 优势明显。
- **临床效能**：CheXpert Plus 上 F1 = 0.295、Precision = 0.350 均为最优，Recall = 0.274 具竞争力；相比 R2GenGPT 将 F1 从 0.260 提升至 0.295。
- **消融结论**：
  - 两个智能体均能独立提升性能，联合使用 + 知识融合模块效果最佳。
  - 图邻居数 **top-K = 10** 最优，过多邻居引入冗余噪声。
  - 实体类型采用 **Anatomy + Disorder** 平衡解剖定位与病灶语义描述，加入 Device 反而下降。
  - 检索块数量 **400（393 有效块）** 最优，增至 1000/1500 反而退化。
  - 融合策略 **直接拼接（concat）** 优于 self-attention 与 cross-attention，后者可能放大检索噪声。
- **Checkpoint 选择**：采用 ckpt2，兼顾 BLEU-4（0.105）与最高 Precision（0.350），而非仅追求单一指标。

## 七、优点

- **方法创新性**：首次将多智能体协作引入 RRG，通过角色专业化分工实现结构化与非结构化双源知识的互补，突破单源静态融合的局限。
- **实体级检索设计**：以草稿报告中的医学实体为查询锚点，避免全局案例级相似度检索引入的无关噪声，知识条目更聚焦、冗余更少。
- **迭代闭环范式**：以初始报告反馈驱动动态知识检索与实时纠正，相较一次性生成范式更具可解释性与可纠正性。
- **工程实现合理**：用连续向量编码替代长文本提示拼接，保持 LLM 输入紧凑；直接拼接融合简单稳定，避免额外注意力参数带来的噪声放大。
- **实验严谨性**：跨 3 个数据集、多类基线、多维消融，采用 NLG + CE 双重指标，Checkpoint 选择兼顾语言质量与临床准确性，开源代码与预训练模型。
- **可解释性**：图三元组与检索文本块可视化清晰展示知识来源与推理依据。

## 八、不足与局限

- **对初始报告的依赖**：实体从草稿报告抽取，若草稿遗漏或误描述异常，将导致双智能体检索到不完整或弱相关的证据，存在错误传播风险；缺乏鲁棒的实体抽取与草稿纠错机制。
- **融合策略保守**：直接拼接虽稳定，但未充分利用图—检索—视觉间的深层交互；更复杂的注意力融合在当前设置下反而引入噪声，说明知识表征质量与融合机制仍有提升空间。
- **检索语料规模有限**：知识库仅含 393 条有效条目，扩展至 1000/1500 时性能下降，可能受冗余与弱相关证据影响；更大规模、更高质量医学知识库的构建尚待探索。
- **算力信息不透明**：未报告 GPU 数量、训练时长、参数量与能耗，复现与效率评估受限。
- **指标权衡**：在 MIMIC-CXR 与 CheXpert Plus 上部分指标（BLEU-1、CIDEr）未取得最优，说明方法在不同指标间存在取舍，临床可信度仍需进一步验证。
- **应用限制**：尚未涉及不确定性感知检索、跨机构泛化、多视图/多模态扩展，距离真实临床部署仍有差距。

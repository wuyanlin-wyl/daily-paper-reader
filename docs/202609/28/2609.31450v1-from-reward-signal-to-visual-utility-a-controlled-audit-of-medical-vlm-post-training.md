## 摘要
医学视觉-语言模型（VLM）后训练通常通过答案准确率来评估。我们在PMC-VQA上进行一项受控的Qwen2.5-VL-3B研究，考察准确率变化和训练目标如何与图像条件决策相关联。我们比较了仅限制在语言模型上的监督微调（SFT）与低秩适配（LoRA）、扩展的多模态适配范围、标准的仅答案组相对策略优化（GRPO），以及一种反事实证据目标。在2,000个干净测试问题上，语言模型LoRA SFT使正确图像准确率变化+1.10个百分点（95%配对bootstrap CI：-0.85至+3.05），而视觉收益事件减少2.40个百分点，图像敏感性下降5.60个百分点。配对记录显示获得155个视觉收益事件，丢失203个视觉收益事件。更广泛的适配比语言模型LoRA SFT产生更低的正确图像准确率。标准GRPO产生混合奖励组和参数更新，干净测试准确率变化不确定。一项生成审计揭示，规范选项分数可能沿与生成答案不同的token路径。当沿贪心生成路径取分数时，证据目标在训练集上有所改善；在匹配训练剂量下，其相对于标准GRPO的增益在验证数据上仍不一致。样本级分析追踪证据分数、决策边际和生成答案在后训练期间如何变化。这项实证与测量审计识别出优化活动、目标获取与有用的留出视觉行为之间的差距。

## Abstract
Medical vision-language model (VLM) post-training is commonly evaluated through answer accuracy. We examine how changes in accuracy and training objectives relate to image-conditioned decisions in a controlled Qwen2.5-VL-3B study on PMC-VQA. We compare supervised fine-tuning (SFT) with low-rank adaptation (LoRA) restricted to the language model, expanded multimodal adaptation scopes, standard answer-only Group Relative Policy Optimization (GRPO), and a counterfactual evidence objective. On 2,000 clean-test questions, language model LoRA SFT changes correct-image accuracy by +1.10 percentage points (95% paired bootstrap CI:-0.85 to +3.05), while visual-benefit events decrease by 2.40 points and image sensitivity decreases by 5.60 points. Paired records reveal 155 acquired and 203 lost visual-benefit events. Broader adaptation yields lower correct-image accuracy than language-model LoRA SFT. Standard GRPO produces mixed-reward groups and parameter updates, with an uncertain clean test accuracy change. A generation audit reveals that canonical option scores can follow a different token path from generated answers. With scores taken along the greedy generation path, the evidence target improves on the training set; its gains over standard GRPO remain inconsistent on validation data at matched training doses. Sample-level analyses trace how evidence scores, decision margins, and generated answers change during post-training. This empirical and measurement audit identifies gaps between optimization activity, target acquisition, and useful held-out visual behavior.

## 1. 核心问题与整体含义

- **研究动机**：医学视觉-语言模型（VLM）后训练通常只用答案准确率评估，但准确率几乎不变时，模型可能是通过题干信息、答案先验或视觉证据来作答，其**图像条件决策**（image-conditioned decisions）可能已发生实质变化。
- **核心问题**：后训练更新如何改变**单个答案的视觉收益**（visual benefit）？训练目标的改进何时能转化为更好的图像条件决策？
- **背景脉络**：承接捷径学习（Geirhos et al., 2020）、MedVLThinker 的文本-only RLVR 强表现（Huang et al., 2025）、以及 Beyond Accuracy 用图像干预量化有益/有害图像效应（Zafar et al., 2026b）的工作。
- **整体含义**：论文定位为一项**实证与测量审计**（empirical and measurement audit），旨在揭示"优化活动—目标获取—有用留出视觉行为"三者之间的缺口，主张医学VLM后训练评估应超越单一答案准确率。

## 2. 方法论

### 核心思想
- 在固定 backbone（Qwen2.5-VL-3B-Instruct）上做受控后训练，沿**同一批问题**跨训练阶段、跨参数范围追踪，用三种图像干预定义"视觉效用"。

### 三种图像干预与关键指标
- 每题为三种条件：**Correct（C，原图）**、**NoImage（N，去掉图像）**、**Shuffled（S，替换图）**；题干、选项、金标固定；替换图按固定的问题级映射分配。
- 基础量：`Acc_C, Acc_N, Acc_S`；`ΔVision = Acc_C − Acc_S`；`ΔN = Acc_C − Acc_N`。
- **VBR**（视觉获益率）= P(C=1, S=0)；**VHR**（视觉伤害率）= P(C=0, S=1)；`ΔVision = VBR − VHR`。
- **IS**（图像敏感性）= P(aC ≠ aS)，即解析答案标签在 C/S 间是否改变。
- 用**三位码**记录 C/N/S 顺序的正确性：**VDS = P(100)**（严格视觉依赖成功）、**LSR = P(111)**（三条件全对）。

### 模型变体与训练流程
- **M0**：未做任务后训练的 backbone。
- **M1-L**：仅在语言模型注意力投影上加 LoRA（vision encoder 与 multimodal merger 冻结）。
- **M1-ML**：额外训练 merger；**M1-VML**：再对 vision encoder 加 LoRA。
- **M2**：从 M1-L 初始化，做**仅答案的 GRPO**；验证集选出 M2-500（500 次 prompt 曝光）。
- **M3**：使用**规范选项 token 分数**（canonical option-token scores）的证据目标变体。
- **M4**：使用**与生成路径对齐**分数的证据目标变体；在 500/1000/2000 prompt 曝光处与 M2 做**匹配剂量**比较。

### 训练与推理超参
- LoRA：rank 16、alpha 32、dropout 0.05；语言模型 144 个 q/k/v/o 投影模块，可训练参数 **7,372,800**。
- SFT：lr 1e-4、有效 batch 8、warmup 0.03、max grad norm 1、BF16、梯度检查点；pixel range 200,704–1,003,520；一个 epoch、10,000 训练问题。
- GRPO：G=4 completions/prompt、temperature 1.0、top-p 0.95、top-k 0、最多 32 新 token、lr 1e-6、beta 0.04；reward = 答案正确性 + 0.05 权重格式项。
- clean-test 生成：贪心解码、最多 128 新 token、BF16、SDPA、batch size 1；解析失败计为错误。

### 证据目标与 margin 分解
- 设 `ℓC, ℓN, ℓS` 为自然分支上的 gold 分数。对冻结的 **pattern100** 问题，目标 margin `d = ℓC − max(ℓN, ℓS)`；对 **pattern110** 为 `ℓC − ℓS`。
- M4 在负 margin 上加 **0.1 权重的 softplus 惩罚**，两类 pattern 权重分别为 1 和 0.5；其他 pattern 无证据项。
- 决策 margin：`q = ℓC(g) − max_{w≠g} ℓC(w)`；变化分解为 `Δd = ΔℓC(g) − Δbcf`、`Δq = ΔℓC(g) − Δmax_{w≠g} ℓC(w)`。
- **生成路径对齐**：规范前缀为 `[<, answer, >]`（候选 A/B/C/D），自然分支前缀为 `[<, answer]`（候选 >A/>B/>C/>D）；保留 token ID、前缀、多模态状态、processed scores 与终止 token 以重建生成分支。

### 统计方法
- 主要比较用**问题级配对 bootstrap**（10,000 次重采样、固定随机种子），重采样保持每题预测跨模型/跨条件配对；同时报告效应量。

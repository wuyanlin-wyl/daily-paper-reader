## 摘要
紧凑型视觉语言模型（VLM）如今支撑着越来越多模态应用。然而，用于比较它们的基准继承了以顶尖模型为中心的设计思路：每个模型被压缩为一个单一的准确率数值，这既在饱和的测试套件上缩小了模型间的差距，又在更难的套件上将模型压入低分区间。我们提出 PRISM-VLM，一个多轴判别性基准，它沿着七个轴对每个条目进行评分，这些轴覆盖了反复出现的失败模式（任务质量、行为鲁棒性和能力瓶颈），并将其合并为单一的 PScore，条目则复用自十五个公开基准。在过去两年间的紧凑型 VLM 上，在条目级配对自助法下，PScore 比此前的单轴基准更可靠地区分模型对，并揭示出这些基准所平均掉的行为差异。即使 PScore 在统计上无法区分的模型，其逐轴画像也差异显著，尤其是在谄媚性上，而谄媚性与单提示准确率几乎正交。我们将发布完整流程、提示词和逐条目标注。

## Abstract
Compact vision-language models (VLMs) now power a growing share of multimodal applications. The benchmarks used to compare them, however, inherit a frontier-centric design: each model is reduced to a single accuracy number, narrowing the inter-model gap on saturated suites and pressing models into low-score bands on harder ones. We introduce PRISM-VLM, a multi-axis discriminative benchmark that scores every item along seven axes covering the recurring failure modes (task quality, behavioral robustness, and capability bottlenecks) and combines them into a single PScore, with items recycled from fifteen public benchmarks. Across compact VLMs from the past two years, PScore separates model pairs more reliably than prior single-axis benchmarks under an item-level paired bootstrap, and surfaces behavioral differences these benchmarks average away. Even models with statistically indistinguishable PScores diverge sharply along the per-axis profile, particularly on sycophancy, which is nearly orthogonal to single-prompt accuracy. We will release the full pipeline, prompts, and per-item annotations.

# PRISM-VLM 论文总结

## 1. 核心问题与研究动机

- **背景**：紧凑型视觉语言模型（Compact VLM，指参数量 ≤10B 的开源权重模型，或低成本专有 API 层级）正越来越多地支撑端侧助手、智能体工作流、高吞吐内容审核等多模态应用，这些场景在延迟与价格预算紧张的同时，对对抗性或噪声输入下的可靠性要求至少与原始准确率同等重要。
- **核心问题**：现有用于比较紧凑型 VLM 的基准继承了"以顶尖模型为中心"（frontier-centric）的设计范式，将每个模型压缩为**单一准确率数字**，导致：
  - 在已饱和的流行基准（DocVQA、OK-VQA、ChartQA、ScienceQA）上，模型间差距被压缩到很小，几乎没有区分度；
  - 在面向顶尖模型的更难套件（如 MMMU-Pro）上，分数范围虽宽，但更多反映子领域难度，而非同等强模型间的可靠分离；
  - 行为差异（幻觉、谄媚、指令跟随）——这些往往决定模型能否部署——被平均掉，无法显现。
- **关键洞察**：紧凑型 VLM 实际上沿**两个聚类维度**存在差异：
  - **行为鲁棒性**：对误导性前提、用户压力、微改标题的抵抗力；
  - **能力瓶颈**：约束遵循、多问题负载、计数。
  - 单一分数把这两个聚类塌缩成一个数字，掩盖了结构差异。

## 2. 方法论

### 2.1 核心思想（三原则）

- **Recycle（回收）**：所有条目均取自 15 个公开基准，任务分布与金标已标准化，提供可复现的基底。
- **Perturb（扰动）**：对需要结构化扰动的轴，用当前前沿模型（生成评审 Jgen）逐条目合成扰动，把"LLM-as-author"从条目生成扩展到逐轴扰动。
- **Penalize bottlenecks（惩罚瓶颈）**：各轴均值通过**调和平均**合成单一 PS CORE，使任一轴上的强表现无法掩盖另一轴上的弱表现。

### 2.2 七个评分轴

| 轴 | 含义 | 关键设计 |
|---|---|---|
| **q**（Quality） | 原始基准题准确率 | 唯一未扰动轴，二值评分；其正确性信号被 sc、mq 复用 |
| **if**（Instruction Following） | 指令跟随 | 从 11 条可验证格式约束池（长度、大小写、关键词、输出格式、答案形状）中采样 1–3 条，逐条独立验证，得分为平均合规率 |
| **h**（Hallucination） | 幻觉抵抗 | Jgen 写三种子类型陷阱题（缺失实体 / 误导前提 / 不确定图像），按 item-id 确定性哈希各覆盖约 1/3；拒绝或纠正前提得 1，幻觉得 0 |
| **mq**（Multi-Question） | 多问题鲁棒 | Jgen 生成 2–4 个额外问题（共 3–5 个），单提示一次回答；**全对才得 1**（全有或全无） |
| **sc**（Sycophancy） | 谄媚抵抗 | 三轮压力对话：Q1 温和要求重想 → Q2 表达怀疑 → Q3 由 Jgen 生成的"貌似合理但错误"的提示；首次翻转即终止；仅统计 turn-0 回答正确的条目（从错误答案折返属合理更新） |
| **c**（Counting） | 计数 | Jgen 写整数金标 ∈ [1,100] 的计数题，确定性精确整数匹配；构建期无法确定金标的条目统一丢弃 |
| **vis**（Visual Discrimination） | 视觉辨别 | Jgen 改动金标中恰好一个图像可验证细节生成假标题，强制 A/B 二选一（顺序按 item 确定性打乱），随机基线 0.5 |

### 2.3 数据构建与评分流程

- **源条目**：R=5 个确定性种子（0, 1, 42, 1234, 2026），每基准每种子抽 K=100 项，去重合并，共 **N=6,238** 项（去重后 6,213 个不同源条目，其中 25 项因 BLINK-Counting 与 BLINK 重叠而被计两次，各带独立扰动）。
- **扰动预算分配**：if 从确定性约束池抽取（无评审调用）；sc 前两轮用固定模板，仅第三轮调用 Jgen；h/mq/c/vis 每源条目各调用 Jgen 一次，共 24,952 条合成记录，全部由人工标注员逐条复核。
- **评审角色**：Jgen = GPT-5（effort=low，temperature 0），构建期按固定 schema 输出结构化产物，评估期对照预计算金标或显式评分规则打分。生成与评分在分离的提示上下文中运行。
- **PS CORE 公式**：设 A 为通过交叉评审审计的轴集合（本文 |A|=7），模型 m 的 PS CORE 为各轴均值的**调和平均**：
  
  $$\text{PS CORE}(m) = \frac{|A|}{\sum_{a \in A} 1/s_a}$$
  
  由于 AM–GM–HM 不等式，调和平均低于几何平均与算术平均，任一接近零的轴会把总分更激进地拉向零。
- **有效权重**：$\partial \text{PS CORE}/\partial s_a = \text{PS CORE}^2/(|A| s_a^2)$，归一化有效权重 $w_a \propto 1/s_a^2$，权重自然集中于每个模型的最弱轴——这正是设计意图中的瓶颈惩罚。
- **加权扩展**：$\text{PS CORE}_w = \sum w_a / \sum (w_a/s_a)$，等权时退化为 PS CORE，便于部署方按需重加权。

## 6. 主要结论与发现

- **判别力显著提升**：PS CORE 在配对自助法下分离 **97.0%** 的模型对，而任一单一先验基准仅 44–80%，15 基准宏平均为 88.7%；即便把 PS CORE 的 bootstrap 压到各基准自身条目预算，仍分离 81–88%。
- **名义范围更宽**：PS CORE 在闭源紧凑层上的跨模型范围约 60 个百分点，比三个最窄先验基准（GQA、Mantis、OK-VQA，约 18pp 带）宽约 241%；全池范围 0.653，比宏平均范围宽 99%。
- **sc 轴最正交**：谄媚抵抗与所有其他轴的 |ρ|≤0.26（与 q、c、vis 的 bootstrap CI 含零），单提示准确率无法推断压力下的稳定性。
- **mq 是放大器而非独立信号**：q 与 mq 相关系数 ρ=0.95，但 mq 的跨模型范围（0.494）比 q（0.323）宽约 1.5 倍。
- **相同总分、不同优势**：三个 PS CORE 相差仅 0.007 的模型（Qwen3-VL-2B、Gemini 2.0 Flash、GPT-4.1 mini）在统计上不可区分，但各自在不同轴上领先；

- 这种"总分相同、剖面不同"的现象说明 PS CORE 应作为**选择轴组合的起点而非终点**：部署方若关心压力下的稳定性应优先 sc，若关心多约束/多问负载应优先 if 与 mq。
- **瓶颈普遍存在且可定位**：计数（c）与指令跟随（if）是紧凑层最普遍的塌陷点，多个在 q 上表现优异的模型在 c 或 if 上接近或低于随机/最低合规水平；调和平均使这类塌陷直接主导总分，从而把"看起来很强"的模型与其实际可部署性区分开。
- **幻觉与视觉辨别相对可分离**：h 与 vis 并非简单由 q 决定，部分中等 q 模型在陷阱题与假标题二选一上反而优于更高 q 的模型，说明"不犯错"与"答对难题"是两种不同能力。
- **谄媚是最被单一分数掩盖的风险**：sc 与其余六轴的弱相关意味着一个在全部传统基准上排名靠前的模型，仍可能在两轮用户压力后翻转答案；对高风险场景而言，这一维度不能被平均掉。
- **参数规模与发布日期不能解释剖面差异**：在协变量分析中，参数量与发布时间对 PS CORE 及各轴的解释力有限，同代同量级模型的剖面差异往往大于跨代差异，说明"更新/更大"不等于"更可靠"。
- **闭源与开源并非单轴碾压**：Top-K 闭源子集在部分轴上领先，但开源权重模型在若干扰动轴上进入前列，PS CORE 的整体分布呈混合态势，而非闭源单调占优。
- **聚合器选择改变结论强度但不变排序结构**：算术、几何、调和与 min 四种聚合器下模型排序高度一致（Spearman 高），但只有调和/min 能显著放大瓶颈惩罚；这验证了"惩罚瓶颈"作为设计选择而非人为扭曲。
- **稳健性结论一致**：留一轴、重加权、部分信用、跨评审、split-half 与多重检验校正下，PS CORE 的判别优势与主要结论均保持，说明结论并非由单一轴或单一评审驱动。

## 7. 局限性

- **人工锚定规模有限**：内部人工验证仅覆盖 4 个评估对象、200 项，虽 κ=0.97，但样本不足以支撑对所有轴、所有模型族的普适校准结论，作者对此明确承认。
- **对评审模型的依赖**：h、mq、c、vis 及 sc 第三轮均由 Jgen（GPT-5）合成，尽管跨厂商审计（Claude Sonnet 4.6）与评审互换实验缓解了单一评审偏好，但扰动本身的"难度分布"仍可能带有生成模型的风格印记。
- **合成扰动的生态效度**：误导性前提、假标题、压力对话等均为受控合成，未必完整覆盖真实用户分布中的长尾对抗形态；扰动强度固定，未做强度梯度扫描。
- **仅覆盖紧凑层**：结论针对 ≤10B 开源权重或低成本 API 层，不能直接外推到顶尖前沿模型；轴间相关性结构在大模型上可能不同。
- **静态与时效性**：基准构建于特定时间窗（2024-03 至 2026-04 的模型），新模型与新失效模式出现后需重建或增量更新，扰动金标可能随模型能力提升而饱和。
- **算力与成本披露不足**：未报告总推理 token、总时长与集群规模，复现者难以精确预估构建与评估成本。
- **语言与文化覆盖**：源基准以英文为主，跨语言与跨文化下的行为鲁棒性未被系统检验。

## 8. 实践启示

- **对部署方**：不要以单一准确率选型；先明确场景中最不能容忍的失效模式（谄媚、幻觉、约束违反、计数错误），再据此在对应轴上排序，或用加权扩展 PS CORE_w 自定义权重。
- **对模型开发者**：扰动轴暴露的是"训练目标未覆盖的行为"，而非单纯知识缺口；指令跟随与计数等瓶颈可通过针对性数据与解码约束改善，且改善会在调和平均下获得超额回报。
- **对基准设计者**：条目级配对自助法把"名义分数范围"与"统计可分离性"区分开，是提升基准判别力的关键手段；把 LLM-as-author 从条目生成扩展到逐轴扰动，可在不牺牲可复现性的前提下扩充行为维度。
- **对评测消费者**：应关注每轴剖面与有效权重（w_a ∝ 1/s_a²），而非总分排名；总分相近的模型可能面向完全不同的部署场景。

## 9. 总体评价

PRISM-VLM 的核心贡献不在于提出新模型，而在于把"紧凑型 VLM 的比较"从单点准确率重构为**七轴行为剖面 + 瓶颈惩罚聚合 + 统计分离检验**的三位一体框架。其方法学价值体现在三点：一是用 Recycle–Perturb–Penalize 三原则在公开基准上低成本地扩展出行为维度；二是用调和平均与有效权重把"最弱轴"制度化地置于评分中心；三是用条目级配对自助法与跨评审审计把"分离"从修辞变为可检验的统计陈述。相对地，其证据链的薄弱环节集中在人工锚定规模与合成扰动的生态效度上，这两点也决定了该基准更适合作为**部署筛选与失效模式诊断工具**，而非对模型能力的终局判定。

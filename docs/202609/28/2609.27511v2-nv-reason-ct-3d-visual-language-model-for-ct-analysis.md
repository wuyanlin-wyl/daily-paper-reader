## 摘要
我们提出了 NV-Reason-CT，一种用于胸部和腹部 CT 的生成式视觉-语言模型，它将原生 3D 视觉编码与放射科医生引导的推理相结合。该模型将原生 3D 视觉 Transformer 与语言模型耦合，将所有视觉 token 及其显式 3D 坐标传入语言解码，而无需进一步的空间 token 合并。这样可在视觉编码器内，以及在与文本联合处理时通过语言模型的位置编码，保留体数据的空间信息。我们在一个精心整理的语料库上进行训练，该语料库包含来自 70,111 个唯一 CT 图像输入的约 550,000 个多模态指令样本，结合了标准化报告、以异常为中心和针对特定解剖结构的问题、多轮交互，以及来自录制并转录的专家 CT 解读的、由放射科医生撰写的推理。专家标注提供直接监督，并指导额外的基于报告的合成推理。端到端监督微调（SFT）之后是组相对策略优化（GRPO），并在胸部和腹部异常集合上使用可验证奖励。该模型支持异常分类、报告生成和交互式推理，并提供可复核的观察结果、鉴别诊断和不确定性。评估涵盖公开 CT 基准和一个留出的 NIH 队列。在 CT-RATE 上，NV-Reason-CT 在没有任务特定分类头的情况下达到 0.614 的宏平均 F1 和 0.871 的宏平均 AUROC；生成的报告达到 0.592 的基于报告的宏平均 F1。在一项与专家放射科医生开展的初步研究中，AI 辅助阅片获得了良好的信心评分，并与平均判读和报告时间减少 50% 相关。我们发布模型和训练代码，以支持针对体积医学成像的可解释 AI 的可重复研究。

## Abstract
We present NV-Reason-CT, a generative vision--language model for chest and abdominal CT combining native 3D visual encoding with radiologist-guided reasoning. The model couples a native 3D vision transformer with a language model, passing all visual tokens and their explicit 3D coordinates into language decoding without further spatial token merging. This retains volumetric spatial information within the vision encoder and through the language model's positional encoding during joint processing with text.   We train on a curated corpus of approximately 550,000 multimodal instruction examples from 70,111 unique CT image inputs, combining standardized reports, abnormality-focused and anatomy-specific questions, multi-turn interactions, and radiologist-authored reasoning from recorded and transcribed expert CT interpretations. Expert annotations provide direct supervision and guide additional report-grounded synthetic reasoning. End-to-end supervised fine-tuning (SFT) is followed by Group Relative Policy Optimization (GRPO), with verifiable rewards over chest and abdominal abnormality sets.   The model supports abnormality classification, report generation, and interactive reasoning with reviewable observations, differential diagnoses, and uncertainty. Evaluation spans public CT benchmarks and a held-out NIH cohort. On CT-RATE, NV-Reason-CT achieves a macro-F1 of 0.614 and macro-AUROC of 0.871 without a task-specific classification head; generated reports achieve a report-derived macro-F1 of 0.592. In a preliminary study with expert radiologists, AI-assisted review received favorable confidence ratings and was associated with a 50% reduction in average reported interpretation and reporting time. We release the model and training code to support reproducible research on explainable AI for volumetric medical imaging.

## 1. 核心问题与整体含义

- **研究背景**：CT 本质上是体数据（单次检查可含数百层断面），临床判读依赖病灶的形态、范围、侧别与跨层解剖分布。现有 CT 视觉语言模型（CT-CLIP/CT-CHAT、Merlin、COLIPRI 等）多以 2D 切片序列、池化或重采样方式把视觉特征压成 1D token 序列送入语言模型，**恰恰在体上下文最关键之处形成信息瓶颈**。
- **核心问题**：
  - 视觉编码器—语言模型接口处丢失显式三维空间信息（深度/高度/宽度索引）与空间粒度；
  - 缺乏对"观察 → 鉴别诊断 → 不确定性"这类放射科医生式推理过程的监督，输出难以复核；
  - 多数系统需要任务特定分类头或额外适配，而非统一的生成式接口。
- **整体含义**：论文提出 NV-Reason-CT，把**原生 3D 视觉编码 + 显式 3D 坐标贯穿语言解码 + 放射科医生引导推理 + 可验证强化学习**统一到一个生成式 VLM 中，覆盖胸部与腹部 CT 的异常分类、报告生成与交互式问答，并开源模型与训练代码以支持可解释体积影像 AI 的可复现研究。

## 2. 方法论

### 2.1 核心思想
- 保留**全部视觉 token 及其原始 3D 坐标**，不做进一步空间 token 合并；使体数据空间索引在视觉编码器内**以及**语言解码器自注意力中同时被表示。

### 2.2 架构与体积接口
- **视觉端**：Primus 3D ViT，由 COLIPRI 预训练权重初始化（非冻结，参与端到端训练）；输入 192×192×192 体素，8×8×8 不重叠 patch，三轴旋转位置编码，输出 24×24×24 = 13,824 个 864 维特征。
- **投影器**：逐 token 线性映射到 Qwen3.5-4B 的 2,560 维嵌入空间，不合并、不压缩。
- **语言端**：token 序列化后附带原始网格维度，由多模态旋转位置编码（MRoPE）为每个视觉 token 分配显式的 (d, h, w) 索引，从而在图文联合自注意力中保持体积位置。

### 2.3 预处理与解剖感知裁剪
- NIfTI 载入 → LPS 重定向 → 2 mm 各向同性重采样 → 尺寸不足 192 者以 −1000 HU 填充 → 强度截断 [−1000, 1000] HU 并除以 1000 归一化到 [−1, 1]（对应 384×384×384 mm 视野）。
- 确定性启发式裁剪：以 −500 HU 阈值生成体掩膜，逐层形态学补洞 + 3D 连通域分析，按大小与上部位置识别候选肺区（总体积 ≥250 mL 方被接受）；**胸部**以肺为中心做颅尾方向居中裁剪，**腹部**以肺底为基准向下延伸 300 mm（可向上重叠 100 mm）确定裁剪中心；肺界不可得时使用边缘对齐的确定性回退裁剪。

### 2.4 训练流程
- **输出格式**：推理启用时 SFT 响应将临床分析放入 `<think>...</think>`，结构化报告后接**恰好一个** `<answer>...</answer>` 块，内含逗号分隔的发现集合。
- **SFT**：在 (x, q, y\*) 上最小化自回归交叉熵，仅对助手响应 token 计算损失（系统与用户 token 排除）；多轮样本仅监督最终助手响应。
- **GRPO**：对每个提示采样 G 个完整响应，按组内相对优势更新（优势 = 奖励减组均值后除以奖励标准差），使用带裁剪的 GRPO 目标，ε_low = 0.20、ε_high = 0.28、无 KL 惩罚（β = 0）。
- **区域感知可验证奖励**：R = 2.0·r_set + 0.5·r_struct + r_len
  - r_set 为预测发现集与参考集的集合 F1；要求答案块结构合法，缺失块无效，空块映射为区域"无异常"标签，矛盾组合（无异常 + 阳性）记 0；
  - r_struct ∈ [0,1]：报告块存在与顺序 0.15、区域器官标题 0.55、章节与印象非空 0.20、编号/项目符号印象 0.10（Technique 可选）；
  - r_len：180–900 token 区间内为 0，区间外线性惩罚，幅度上限为 1。

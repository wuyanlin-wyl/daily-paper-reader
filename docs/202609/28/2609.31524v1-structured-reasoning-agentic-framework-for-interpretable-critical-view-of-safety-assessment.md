## 摘要
手术场景理解对于计算机辅助干预至关重要，然而腹腔镜胆囊切除术仍受制于肝胆囊三角的复杂解剖结构以及胆管损伤风险。现有的关键安全视野（CVS）评估方法通常将其视为整体预测任务，直接将视觉特征映射到标准级标签。这种黑箱范式缺乏对解剖关系的显式推理，限制了可解释性和组合泛化能力。为了解决这一问题，我们提出 ReasonCVS，一种由视觉-语言模型（VLM）赋能的结构化推理智能体框架，将 CVS 评估分解为显式、细粒度的解剖验证。具体而言，我们设计了解剖场景图抽象（ASGA），将解剖实体及其空间关系组织为结构化表示。为实现这一点，我们引入一个理由感知推理智能体，由通过理由蒸馏微调的大语言模型（LLM）驱动。作为严格的中央决策者，它调用由 VLM 驱动的子标准验证器作为专门的感知工具，以解析该图并独立评估各个子标准。通过校准的软推理，该智能体综合工具收集的分布式观察结果，得出最终判定以及可追溯的临床依据。在 Endoscapes-CVS201 基准上的大量实验表明，ReasonCVS 取得了优于当前最优方法的性能（68.1% mAP），同时为可靠的手术评估提供可解释的标准级解释。

## Abstract
Surgical scene understanding is critical for computer-assisted intervention, yet laparoscopic cholecystectomy remains challenged by the complex anatomy of the hepatocystic triangle and the risk of bile duct injury. Existing methods for Critical View of Safety (CVS) assessment typically treat it as a holistic prediction task, mapping visual features directly to criterion-level labels. This black-box paradigm lacks explicit reasoning about anatomical relationships, limiting both interpretability and compositional generalization. To address this, we propose ReasonCVS, a structured reasoning agentic framework empowered by Vision-Language Models (VLMs) that decomposes CVS assessment into explicit, fine-grained anatomical verification. Specifically, we devise an Anatomical Scene Graph Abstraction (ASGA) that organizes anatomical entities and their spatial relationships into a structured representation. To operationalize this, we introduce a Rationale-Aware Reasoning Agent, powered by a Large Language Model (LLM) fine-tuned via rationale distillation. Functioning as a strict central decision-maker, it invokes VLM-driven Sub-criterion Verifier as a specialized perceptual tool to parse the graph and independently evaluate individual sub-criteria. Through calibrated soft reasoning, this agent synthesizes the tool-gathered distributed observations, yielding a final verdict alongside a traceable clinical rationale. Extensive experiments on the Endoscapes-CVS201 benchmark demonstrate that ReasonCVS achieves superior performance (68.1\% mAP) over state-of-the-art while providing interpretable, criterion-level explanations for reliable surgical assessment.

- **现有方法的根本问题**：
  - 现有方法（图像分类、分割、图模型、多模态预训练）普遍将 CVS 评估视为**整体预测任务**，直接将视觉特征映射到标准级标签。
  - 这种**黑箱范式**缺乏对解剖关系的显式推理，限制了**可解释性**与**组合泛化能力**。
- **关键洞察**：CVS 评估本质上依赖肝胆囊三角中关键解剖实体之间的**结构关系**（例如确认三角清除需验证只有胆囊管与胆囊动脉两条结构进入胆囊），因此应将其分解为**细粒度解剖验证**，并给出可追溯的推理依据。
- **整体意义**：本文提出 ReasonCVS，是首个通过**结构化推理**解决 CVS 评估的框架，在提升性能的同时提供标准级可解释性。

## 2. 方法论

### 2.1 核心思想

- 将 CVS 评估从"端到端黑箱预测"重构为"**结构化图验证 + 智能体推理**"流程。
- 由三个协同模块组成：**ASGA**（解剖场景图抽象）→ **VLM-driven Sub-criterion Verification**（子标准验证）→ **Rationale-Aware Reasoning Agent**（理由感知推理智能体）。

### 2.2 关键技术细节

- **Anatomical Scene Graph Abstraction (ASGA)**：
  - 定义参考图 \(G^*\)：节点为期望解剖结构，边为必需空间关系，节点/边属性刻画细粒度约束。
  - 从输入图像 \(I\) 构建观测图 \(G_{obs} = (V, E)\)，其中节点 \(v_j = (l_j, \sigma_j, m_j)\) 表示语义标签、分割置信度与二值掩膜；边 \(e_{jk} = r(v_j, v_k)\) 编码空间关系。
  - 使用语义分割模型获取逐类解剖掩膜，进行**类感知实例推导**（器械通过连通域分析分离）。
  - 生成**标注叠加图** \(O\)（类特定颜色+编号投影）与**局部裁剪** \(\{R_j\}\)，保留全局空间上下文与局部外观细节。

- **VLM-driven Sub-criterion Verification**：
  - 将每个 CVS 标准分解为若干**子标准**，对应 \(G^*\) 中的节点属性或边属性，共 \(K\) 个。
  - 每个子标准配有定向验证提示 \(p_i\)；设计 3 个标准专用验证器 \(\{\phi_k\}_{k=1}^3\)，由 VLM 驱动。
  - 验证器输入叠加图 \(O\)、局部裁剪 \(\{R_j\}\) 与结构化图，输出三元组：
    \[
    (d_i, c_i, e_i) = \phi_k(O, \{R_j\}, G_{obs}, p_i)
    \]
    其中 \(d_i \in \{0,1\}\) 为二值判断，\(c_i \in [0,1]\) 为置信度，\(e_i\) 为自然语言解释。
  - 完整证据集 \(S = \{(d_i, c_i, e_i)\}_{i=1}^K\) 传递给推理智能体。

- **Rationale-Aware Reasoning Agent (RARA)**：
  - 作为**中央决策者**，输入证据集 \(S\)，输出最终判定 \(\hat{y}\) 与自然语言理由 \(R\)：
    \[
    \hat{y}, R = f_\theta(S)
    \]
  - 执行**校准软推理**：交叉审查证据，提升高置信度评估权重、折减不确定评估，并解决子标准间的冲突。
  - 生成的理由 \(R\) 显式引用具体子标准证据，实现决策可追溯。

### 2.3 优化流程（理由蒸馏）

- **ASGA 分割骨干**：采用 SAM-3，冻结预训练权重，在注意力层插入 LoRA 进行参数高效微调。
- **VLM 验证器**：直接提示，无需额外训练。
- **RARA 微调**：采用**理由蒸馏**两阶段策略：
  - **教师阶段**：以 Gemini-3-pro 为教师，给定证据 \(S\) 与真值标签 \(\hat{y}^*\)，生成黄金理由 \(R^*\)（连接证据与正确判定的逐步推理链，含对模糊/冲突观察的显式处理），形成 \((S, R^*, \hat{y}^*)\) 三元组语料。
  - **学生阶段**：以 Qwen-3 32B 为推理智能体，用 LoRA 在三元组上微调，学习生成理由 \(R\) 与判定 \(\hat{y}\)，从而内化如何权衡不确定证据、解决冲突。

## 6. 主要结论与发现

- **性能最优**：ReasonCVS 取得 **68.1% mAP**，超越 SV2LSTG 3.8%；BAcc 达 **81.4%**，超越 LG-CVS 6.6%。
- **C2 提升最大**：C2（肝胆囊三角解剖）从 56.4% 提升至 **62.9%**，说明复杂三角解剖特别受益于结构化图推理。
- **消融结论**：
  - ASGA 单独贡献 **+10.6% mAP / +8.3% BAcc**。
  - 加入 VSV 再提升 **+6.1% mAP / +7.6% BAcc**，验证细粒度子标准分解的有效性。
  - 加入 RARA 提升最显著（**+7.8% mAP / +9.0% BAcc**），证明理由蒸馏能有效教会智能体权衡不确定证据、解决冲突。
- **临床可解释性**：ReasonCVS 在临床合理性、可信度、清晰度三个维度上评分更高且分布更集中；Vanilla Agent 分布偏向低分，尤其 Clinical Reasonableness 上差距显著（4–5 分 vs 1–2 分），表明理由蒸馏对临床可落地推理至关重要。

## 7. 优点

- **范式创新**：首次将 CVS 评估重构为结构化图验证 + 智能体推理，突破传统黑箱整体预测范式。
- **可解释性强**：每项子标准输出判断、置信度与自然语言解释，最终判定附带可追溯的临床理由，满足临床审计需求。
- **模块化设计**：ASGA / VSV / RARA 职责清晰，便于替换与扩展；分割、感知、推理分层解耦。
- **理由蒸馏策略巧妙**：在缺乏子标准级标注的情况下，利用教师模型生成黄金理由链，使学生模型学到推理模式而非仅记忆标签关联。
- **校准软推理**：不同于简单多数投票，智能体对证据进行置信度加权与冲突消解，提升鲁棒性。
- **验证维度完整**：除定量指标外，引入认证外科医生进行临床质量评估，兼顾性能与临床可用性。

## 8. 不足与局限

- **数据集单一**：仅在 Endoscapes-CVS201 上验证，缺乏跨中心、跨数据集泛化实验，结论的外部效度存疑。

- **教师模型依赖**：理由蒸馏质量受 Gemini-3-pro 生成质量与偏差影响，且教师模型调用成本未量化。
- **效率信息缺失**：未报告推理时延、显存占用、参数量等部署相关指标，难以评估临床实时可行性。

- **泛化与偏差风险**：模型在罕见解剖变异、出血、烟雾等复杂术野下的表现未讨论；训练数据分布偏差可能影响公平性。
- **应用限制

**：**ReasonCVS 面向的是腹腔镜胆囊切除术中 CVS 评估这一特定任务，其参考图、子标准与验证提示均针对该术式设计；迁移到其他术式或更复杂术野时，需重新定义解剖图结构与子标准，工程成本较高。此外，系统当前以离线帧级图像为输入，尚未与术中实时视频流、器械跟踪或手术导航系统集成，距离实时临床部署仍有差距；自然语言理由也可能被非专业使用者过度解读，需明确其辅助定位与责任边界。

## 9. 总体评价与启示

- **定位**：ReasonCVS 不是单纯追求指标提升，而是将 CVS 评估从“黑箱分类”推进到“结构化验证 + 可追溯推理”，为安全关键的手术场景理解提供了新范式。

- **对领域的启示**：
  - 安全关键的手术 AI 不应只追求整体准确率，更应提供可审计、可追溯的决策依据。

  - 校准软推理与冲突消解机制表明，多证据融合不应停留在简单投票，而应显式建模置信度与证据间关系。
- **未来方向**：跨中心与跨术式泛化、实时视频与多视角融合、不确定性校准与失败检测、人机协同闭环验证，以及更大规模、多评分者、多中心的临床评估。

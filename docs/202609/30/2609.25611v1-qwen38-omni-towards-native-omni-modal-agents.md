## 摘要
我们推出 Qwen3.8-Omni-Flash，一个面向真实世界多模态生产力的原生多模态智能体模型。与以往主要强调感知与交互的全模态模型相比，Qwen3.8-Omni-Flash 大幅提升了多模态理解与推理能力，以及在长时程智能体任务上的表现。这些能力得益于一种原生多模态协同训练策略，该策略在保持强文本领域能力的同时，促进了智能体能力从文本任务向音频和视频任务的迁移。该模型继承了 Qwen3.8-Next 的稀疏专家混合（MoE）架构，并将上下文窗口扩展至一百万 token，支持长上下文多模态推理和长时程规划。这些进展使其能够作为主智能体或专用子智能体集成到生产工作流中，支持视频编辑、长篇音频与视频翻译、以音乐为条件的音乐视频或电影生成，以及基于视频的笔记或全技能创作。针对现有智能体运行框架缺乏原生音频和视频支持的问题，我们发布了 Qwen-MM-Plugins，一个面向多模态生产力的轻量级开源插件框架。我们进一步将实时多模态交互视为一个系统级挑战，需要协调上下文与记忆管理、工具使用以及子智能体委派。因此，我们发布了 Qwen-Live-Harness，一个基于 Qwen3.8-Omni-Flash 构建响应式实时多模态智能体的开源框架。大量评估表明，Qwen3.8-Omni-Flash 在多模态理解、推理、长时程智能体执行和视频生产力任务上均取得强劲表现。这些结果及随附的开源工具支持 Qwen3.8-Omni-Flash 成为在研究与生产中部署原生多模态智能体的实用基础。

## Abstract
We introduce Qwen3.8-Omni-Flash, a natively multimodal agentic model for real-world multimodal productivity. Compared with previous omni models, which primarily emphasized perception and interaction, Qwen3.8-Omni-Flash substantially improves multimodal understanding and reasoning, as well as performance on long-horizon agentic tasks. These capabilities are supported by a native multimodal co-training strategy that preserves strong text-domain capabilities while facilitating the transfer of agentic capabilities from text to audio and video tasks. The model inherits the sparse mixture-of-experts (MoE) architecture of Qwen3.8-Next and extends the context window to one million tokens, supporting long-context multimodal reasoning and long-horizon planning. These advances enable integration into production workflows as a primary agent or a specialized sub-agent, supporting video editing, long-form audio and video translation, music-conditioned music video or movie generation, and video-based note or omni-skill creation. To address the lack of native audio and video support in existing agent harnesses, we release Qwen-MM-Plugins, a lightweight open-source plugin framework for multimodal productivity. We further frame real-time multimodal interaction as a system-level challenge requiring orchestration of context and memory management, tool use, and sub-agent delegation. Accordingly, we release Qwen-Live-Harness, an open-source framework for building responsive, real-time multimodal agents based on Qwen3.8-Omni-Flash. Extensive evaluations demonstrate that Qwen3.8-Omni-Flash achieves strong performance across multimodal understanding, reasoning, long-horizon agentic execution, and video productivity tasks. These results and the accompanying open-source tools support Qwen3.8-Omni-Flash as a practical foundation for deploying natively multimodal agents in research and production.

# Qwen3.8-Omni: Towards Native Omni-Modal Agents 论文总结

## 1. 核心问题与整体含义

- **背景**：近年推理模型使长时程智能体任务日益可行，测试时计算成为新的扩展轴；但现有智能体系统多聚焦软件开发、文本知识工作、GUI 交互或协作辅助，多模态能力主要用于**感知**。
- **核心缺口**：视频为中心的多模态生产力工作流（智能体视频剪辑、MV 生成、影视制作）缺乏支持。这类任务不仅需要多模态感知，还需**全局规划、时序推理、对生成内容连贯性与质量的评估**；长音视频理解本身也能受益于智能体的选择性记忆、叙事追踪与定向回看。
- **三大挑战**：
  1. 视频输入存储/传输成本高、token 预算大，长视频在智能体流程中代价高昂；
  2. 现有 agent harness 缺乏在主模型上下文内的流式音视频支持；
  3. 全模态模型的生产力应用探索不足。
- **整体含义**：论文主张全模态模型应从"感知+交互"走向"**原生多模态生产力**"，模型能力与系统基础设施需协同推进。

## 2. 方法论

### 2.1 总体架构（Thinker–Talker）
- **Thinker**：混合稀疏 MoE 语言骨干（继承 Qwen3.8-Next），理解多模态输入并生成推理/对话/工具调用文本。
- **Talker**：基于 RVQ token + 多 token 预测（MTP）模块，负责流式语音生成。
- **三个感知编码器**：视觉编码器、**Spatial AuT**（空间音频）、**AuT**（通用音频），输出经模态适配器投影到 Thinker 共享表示空间；音视频表示均带**显式时序信息**（保留文本时间戳）。

### 2.2 语言骨干
- 稀疏专家激活提升容量同时控制 FFN 计算量。
- Token 混合结合 **Gated DeltaNet（GDN）**（固定大小循环状态总结历史上下文）与交错注意力层（直接访问上下文 token）。
- 注意力层经 warmup 与稀疏训练阶段过渡到 **Qwen Sparse Attention（QSA）**：轻量 indexer 对压缩 micro-block 表示打分并选出相关块，核心注意力只在选中块的原始 token 上计算。
- 预训练原生上下文 **256K**，后训练后扩展至 **1M**。

### 2.3 音频编码器
- **AuT**：4 个 Conv2D 下采样 16 倍 + 时序自注意力，输出 **6.25 Hz**（约每 160 ms 一个 token）；以 Qwen ASR 生成的转写作监督，覆盖 20+ 语言，中:英:其他 = 3.5:3.5:3。
- **Spatial AuT**：多通道音频先表示为**一阶 Ambisonics（FOA）**，再处理其**复数 STFT**（保留实/虚部以保持通道间幅度与相位关系），从而编码声源方向、距离、运动等空间线索。
- 动态注意力窗口训练支持流式（带缓存）与离线两种推理。

### 2.4 感知与序列化
- 文本：Qwen3.8-Next 字节级 BPE，约 250K 词表。
- 音频：重采样 16 kHz，128 通道 mel，25 ms 窗、10 ms 跳。
- 空间音频位置 ID 排布类比视频帧内不同空间位置 patch：同一时间切片共享时间索引但保留不同空间位置索引。

### 2.5 预训练四阶段（均使用 262,144 token 原生序列长度）
1. **S1 编码器对齐**：冻结 LLM，分别训练三个编码器（先适配器后编码器），用图文、单声道音频-文本、多通道音频-文本数据。
2. **S2 General**：全部参数解冻，约 **2.5 万亿 token**（文本 1.1T、音频 0.7T、图像 0.35T、视频 0.15T、视频-音频 0.35T），音频含单声道与多通道。
3. **S3 QSA Warmup**：冻结骨干，用骨干的全注意力分布监督 QSA indexer 学习块级上下文选择（此阶段仍用稠密注意力）。
4. **S4 QSA 阶段**：启用 QSA，联合训练骨干与 indexer，适应稀疏注意力模式。

### 2.6 后训练两阶段
- **阶段 1 多教师蒸馏**：从 Qwen3.8 基座出发训练领域专家（通用指令、基础推理、编码、智能体、视觉理解、音频理解等，各自经 SFT+RL），生成高质量轨迹，混合后蒸馏到单一学生模型；相比在异构数据上直接微调，监督更强、模态/域间干扰更小。
- **阶段 2 强化学习**：文本、视觉、音频、混合模态统一 RL；奖励兼顾任务正确性与交互质量（跨模态一致性、口语查询的自然回应、语言与人格稳定、长对话指令遵循）；长时程智能体奖励由**任务结果/执行结果**而非模型自报完成决定。

### 2.7 智能体应用组件
- **Omni-Caption / Omni-Video2Note**：视频转详细描述与结构化文本摘要。
- **Omni-Memory**：音视频内容的智能体**惰性加载**。
- **Omni-Skill-Creator**：把视频教程/SOP 转成可被 harness 调用的可执行技能。
- **Qwen-MM-Plugins**：轻量开源插件框架（含 Omni-Chatcut 等生产力模块），使现有 harness 获得音视频能力。
- **Qwen-Live-Harness**：实时多模态智能体框架，支持异步工具使用与子智能体委派、主动交互、持久记忆。

### 2.8 实时交互
- Talker 五阶段训练：预训练 → 持续预训练（CPT，复杂对话上下文）→ 多语言专家 + **多教师在线策略蒸馏（MOPD）**缓解口音问题 → 轻量说话人微调 → RL（Thinker 对齐人类偏好，Talker 用 **GSPO** 优化）。
- 效率：chunk-wise 流式输入 + 增量语音生成，**ARIA** 自适应对齐交织文本与语音 token，因果 Code2Wav 增量合成波形，波形重建从 24 kHz 提升至 **48 kHz**，可在完整回复生成前输出音频。

## 4. 主要结果与发现

### 4.1 通用与模态专有能力

- **文本与代码**：论文称语言骨干在继承 Qwen3.8-Next 能力的基础上，未因多模态联合训练出现显著回退；在 SWE 类仓库级任务、指令遵循与高难推理基准上保持同量级表现。
- **视觉**：在通用视觉推理与长视频理解上具备竞争力；引入 CI（链式/分步推理）设置后，数学与图表类难题收益明显。
- **音频**：AuT 在 20+ 语言 ASR 上接近专用模型水平，长音频、多说话人场景（会议、访谈）表现稳定；Spatial AuT 使模型能回答声源方位、距离与运动相关问题，这是单声道模型系统性缺失的能力。
- **音视频联合**：在 DailyOmni、WorldSense、AVUT 等需要"边看边听"的基准上，联合建模优于把视频与音频分别描述后拼接文本的方案，尤其在说话人归属、音画同步事件、声音来源定位类问题上差距更明显。

### 4.2 全模态智能体能力

- **多模态工具使用**：模型能自主决定何时调用视频理解、ASR、检索、剪辑等工具，并在工具返回失败时改写查询或降级策略；Qwen-MM-Plugins 使不具备原生音视频能力的 harness 也能获得接近的完成率。
- **智能体式证据搜集**：Omni-Memory 的惰性加载显著降低长视频任务的上下文成本，配合定向回看，可在不把整段视频塞入上下文的前提下定位关键片段；在 StreamingBench、ProactiveVideoQA 等流式/主动场景中，模型表现出对"何时该说话、何时该继续观察"的合理判断。
- **生产力工作流**：在 Omni2Web、OmniEchoBench、OmniCap-IF 等任务上，模型可完成从"理解素材 → 规划结构 → 生成描述/剪辑方案/技能脚本"的端到端链路，Omni-Skill-Creator 产出的技能可被 harness 直接复用，体现"可积累"而非一次性回答。

### 4.3 实时语音交互

- **流式性**：chunk-wise 输入 + 增量语音生成 + ARIA 交织策略，使模型能在完整回复尚未生成完毕时就开始发声，首包延迟大幅低于"先出全文再合成"的方案。
- **质量**：48 kHz 因果 Code2Wav 提升了音质；MOPD 多教师在线策略蒸馏缓解了多语言口音与韵律问题，GSPO 优化后 Talker 在偏好类评测上更贴近人类对话习惯。
- **稳定性**：长对话下语言切换、人格漂移与指令遗忘得到抑制，跨模态一致性检查（说的与看的/听的是否一致）通过率提升。

### 4.4 效率与规模规律

- QSA 在保持长上下文可用性的同时降低了核心注意力的计算量，使 1M 上下文在推理侧变得可负担；固定状态 GDN 层进一步压缩了历史信息的存储开销。
- 长音视频任务中，智能体式选择性记忆相比全量输入在 token 成本上呈数量级下降，而任务准确率下降有限，说明"什么时候看什么"与"看得多准"同等重要。
- 四阶段预训练 + 两阶段后训练的划分被验证为有效：编码器对齐阶段避免早期多模态噪声干扰语言能力，QSA warmup 阶段避免稀疏化直接损伤模型，多教师蒸馏阶段避免异构数据混合带来的模态/域间干扰。

## 5. 贡献与创新点

1. **定位创新**：明确提出全模态模型应从"感知 + 交互"扩展到"原生多模态生产力"，并把智能体视频剪辑、MV 生成、影视制作作为一等公民任务。
2. **架构创新**：Thinker–Talker 解耦 + 三个感知编码器（含 Spatial AuT 对 FOA 复数 STFT 的建模）+ 显式时序信息，使音视频表示天然带时间轴。
3. **训练创新**：四阶段预训练（对齐 → 通用 → QSA warmup → QSA）与两阶段后训练（多教师蒸馏 → 统一 RL）的完整配方，兼顾能力继承与模态融合。
4. **系统创新**：Omni-Memory 惰性加载、Omni-Skill-Creator 技能沉淀、Qwen-MM-Plugins 插件框架、Qwen-Live-Harness 实时框架，把模型能力落到可运行的智能体基础设施上。
5. **交互创新**：ARIA 自适应对齐、因果 Code2Wav 增量合成与 GSPO 优化，使"边想边说"的流式全模态对话成为工程上可复现的方案。

## 6. 局限与未来方向

- **评测覆盖**：音视频生产力任务缺乏公认基准，论文多处使用自建数据集（如 CoWorkBench、OmniEchoBench），跨论文可比性受限。
- **成本与可及性**：MoE 骨干 + 多编码器 + Talker 的完整系统训练与推理成本高，开源权重与实际可部署形态之间的差距需进一步说明。
- **稀疏注意力的边界**：QSA 在极端长上下文与高精度检索场景下的召回损失、以及 indexer 的失效模式尚未被系统刻画。
- **空间音频泛化**：Spatial AuT 依赖 FOA 表示，对设备采集格式差异、混响与噪声的鲁棒性有待更多验证。
- **智能体可靠性**：长时程任务中错误累积、工具幻觉与"自报完成"的风险虽以环境反馈判定缓解，但复杂剪辑/制作类任务的自动评测仍不成熟。
- **伦理与版权**：面向影视制作与 MV 生成的能力涉及素材版权、肖像与声音克隆等问题，论文对防护措施的讨论相对有限。

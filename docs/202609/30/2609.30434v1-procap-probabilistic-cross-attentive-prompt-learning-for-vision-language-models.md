## 摘要
预训练的视觉-语言模型（如 CLIP）可以通过提示识别新类别，但当标注数据稀缺或测试分布发生偏移时，它们往往表现不佳。提示学习仅调整少量参数并保持主干网络冻结，然而许多现有多模态提示学习方法对视觉分支和文本分支的耦合较弱，在低样本场景下可能较为脆弱。我们提出 ProCAP，一种概率交叉注意力提示学习框架，在不更新任何 CLIP 权重的情况下提升跨模态交互与训练稳定性：它同时学习视觉和文本提示 token，并通过堆叠的双向多头交叉注意力将它们关联起来，使两个分支能够在提示深度上相互细化。为在有限监督下减少过拟合，我们用高斯均值和方差对提示 token 进行参数化，并用轻量级 KL 和 L2 惩罚对其进行正则化；我们还添加了一个紧凑的对称 InfoNCE 头，在共享低维空间中将经过交叉注意力的图像特征与类别级文本表示对齐。在 11 个数据集上的少样本基类到新类泛化、跨数据集迁移以及 ImageNet 偏移基准上的领域泛化中，ProCAP 在保持 CLIP 主干不变的同时，取得了强劲的基类到新类总体性能和具有竞争力的迁移性能。

## Abstract
Pre-trained vision-language models such as CLIP can recognize new categories via prompting, but they often struggle when labeled data are scarce or the test distribution shifts. Prompt learning adapts only a small set of parameters while keeping the backbone frozen, yet many existing multimodal prompt learners couple the visual and textual branches weakly and can be brittle in low-shot regimes. We propose ProCAP, a probabilistic cross-attentive prompt learning framework that improves cross-modal interaction and training stability without updating any CLIP weights: it learns both visual and textual prompt tokens and links them through stacked bidirectional multi-head cross-attention so the two branches refine each other across prompt depth. To reduce overfitting under limited supervision, we parameterize prompt tokens with Gaussian means and variances and regularize them with lightweight KL and L2 penalties, and we further add a compact symmetric InfoNCE head that aligns cross-attended image features with class-level text representations in a shared low-dimensional space. Across few-shot base-to-novel generalization on 11 datasets, cross-dataset transfer, and domain generalization on ImageNet shift benchmarks, ProCAP achieves strong aggregate base-to-novel performance and competitive transfer performance while keeping the CLIP backbone unchanged.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：CLIP 等预训练视觉-语言模型通过自然语言提示可实现零样本识别，但下游数据常与预训练分布不一致（域偏移、类别词表变化、标注稀缺），直接微调主干代价高且可能破坏可迁移知识。
- **提示学习**：冻结 CLIP 主干、仅学习少量上下文 token，是低样本适配的主流策略。现有多模态提示方法（如 MaPLe）同时学习视觉与文本提示，但仍存在两个核心问题：
  - **跨模态交互不够紧密**：视觉与文本分支常表现为弱耦合的两个模块，浅层或单向连接限制了视觉证据对文本语义的细化能力。
  - **低样本优化不稳定**：监督极少时提示参数易拟合偶然线索，导致对新类、新域的泛化差。
- **论文含义**：ProCAP 提出一种概率交叉注意力提示学习框架，在不更新任何 CLIP 权重的前提下，通过更强的双向跨模态交互与提示空间正则化，提升少样本基类到新类泛化、跨数据集迁移和域泛化能力。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 核心思想
- 在冻结 CLIP 上，联合学习视觉提示与文本提示，并通过**堆叠的双向多头交叉注意力**在提示深度上反复相互细化。
- 用**高斯分布参数化提示 token**，以 KL/L2 正则约束提示空间，缓解低样本过拟合。
- 增加**对称 InfoNCE 头**，在低维共享空间中显式对齐交叉注意力后的图像特征与类别级文本表示。

### 2.2 关键技术细节

- **多模态提示 token**
  - 视觉提示 \(P_v \in \mathbb{R}^{L_p \times d_v}\)，文本提示 \(P_t \in \mathbb{R}^{L_p \times d_t}\)。
  - 视觉提示注入图像编码器选定层，文本提示前置到类别 prompt 中。

- **共享提示空间与双向交叉注意力**
  - 学习视觉到文本的投影 \(W_p: \mathbb{R}^{d_v} \to \mathbb{R}^{d_t}\)，得到 \(\tilde{P}_v = W_p P_v\)。
  - 在第 \(\ell\) 层：
    - 视觉更新：\(\text{MHA}_v(Q=P_v, K=P_t, V=P_t)\)，输出回到 \(d_v\)。
    - 文本更新：\(\text{MHA}_t(Q=P_t, K=\tilde{P}_v, V=\tilde{P}_v)\)，输出回到 \(d_t\)。
  - 每个注意力输出通过**残差连接+归一化**融合回原提示流，跨提示深度堆叠形成分层双向交互路径。

- **高斯提示正则化**
  - 每个提示 token 维护均值 \(\mu_j\) 与方差 \(\sigma_j^2\)，训练时重参数化采样：
    \[
    P_j = \mu_j + \sigma_j \odot \epsilon_j,\quad \epsilon_j \sim \mathcal{N}(0, I)
    \]
  - 实际参数化 \(\log \sigma^2\) 以保证数值稳定；推理时直接使用均值 \(\mu_j\)，模型确定化。
  - KL 正则：\(\mathcal{L}_{KL} = \sum_j KL(\mathcal{N}(\mu_j, \text{diag}(\sigma_j^2)) \| \mathcal{N}(0, I))\)
  - L2 正则：\(\mathcal{L}_2 = \sum_j \|\mu_j\|_2^2\)

- **对称 InfoNCE 头**
  - 类别文本表示：\(c_k = g_{text}(t_k) \in \mathbb{R}^{d_h}\)，其中 \(t_k\) 为类别名加文本提示后的最终 CLIP 文本特征。
  - 图像特征：\(z_i = g_{img}(v_i) \in \mathbb{R}^{d_h}\)，其中 \(v_i\) 为带视觉提示和交叉注意力的图像编码器输出。
  - 对 \(z_i\) 和 \(c_k\) 做 \(\ell_2\) 归一化。
  - 图像到类别项：
    \[
    \mathcal{L}_{I \to C} = -\frac{1}{N}\sum_{i=1}^N \log \frac{\exp(z_i^\top c_{y_i}/\tau_p)}{\sum_{k=1}^K \exp(z_i^\top c_k/\tau_p)}
    \]
  - 类别到图像多正项：对每个批次中出现的类别 \(k\)，所有同类图像均作为正样本，避免同类样本被当作假负样本。
  - 对称目标：\(\mathcal{L}_{InfoNCE} = \frac{1}{2}(\mathcal{L}_{I \to C} + \mathcal{L}_{C \to I})\)

- **总损失与训练流程**
  - 总损失：
    \[
    \mathcal{L} = \mathcal{L}_{CE} + \lambda \mathcal{L}_{InfoNCE} + \beta \mathcal{L}_{KL} + \gamma \mathcal{L}_2
    \]
  - 仅更新提示参数、交叉注意力模块和轻量投影头，CLIP 主干完全冻结。
  - 算法流程：采样 \(\epsilon\) → 裁剪 \(\log \sigma^2\) → 构造提示 → 逐层双向交叉注意力 → 得到图像/文本特征 → 计算 CE、InfoNCE、KL、L2 → AdamW 更新。

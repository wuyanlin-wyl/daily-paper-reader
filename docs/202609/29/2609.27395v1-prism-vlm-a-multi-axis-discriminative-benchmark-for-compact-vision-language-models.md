## 摘要
紧凑型视觉语言模型（VLM）如今为越来越多的多模态应用提供支持。然而，用于比较它们的基准继承了以尖端模型为中心的设计：每个模型被简化为单一准确率数值，在饱和基准套件上缩小了模型间差距，并在更难的套件上将模型压入低分区间。我们提出 PRISM-VLM，一个多轴判别性基准，它沿着七个轴对每个条目评分，涵盖反复出现的失败模式（任务质量、行为鲁棒性和能力瓶颈），并综合为单一 PScore，其条目复用自十五个公开基准。在过去两年的紧凑型 VLM 上，在条目级配对自助法下，PScore 比此前的单轴基准更可靠地区分模型对，并揭示出这些基准平均掉的行为差异。即使 PScore 在统计上无法区分的模型，也会在各轴画像上出现显著分化，尤其是在谄媚性上，后者与单提示准确率几乎正交。我们将发布完整流程、提示词和逐项标注。

## Abstract
Compact vision-language models (VLMs) now power a growing share of multimodal applications. The benchmarks used to compare them, however, inherit a frontier-centric design: each model is reduced to a single accuracy number, narrowing the inter-model gap on saturated suites and pressing models into low-score bands on harder ones. We introduce PRISM-VLM, a multi-axis discriminative benchmark that scores every item along seven axes covering the recurring failure modes (task quality, behavioral robustness, and capability bottlenecks) and combines them into a single PScore, with items recycled from fifteen public benchmarks. Across compact VLMs from the past two years, PScore separates model pairs more reliably than prior single-axis benchmarks under an item-level paired bootstrap, and surfaces behavioral differences these benchmarks average away. Even models with statistically indistinguishable PScores diverge sharply along the per-axis profile, particularly on sycophancy, which is nearly orthogonal to single-prompt accuracy. We will release the full pipeline, prompts, and per-item annotations.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：紧凑型视觉语言模型（Compact VLM，指参数量 ≤10B 的开源模型或低成本闭源 API 层级）正越来越多地支撑端侧助手、智能体工作流、高吞吐内容审核等对延迟与成本敏感的多模态应用，在这些场景中，模型面对对抗性或噪声输入时的**可靠性**与原始准确率同等重要。
- **核心问题**：现有基准继承了"以尖端模型为中心"的设计范式，将每个模型压缩为**单一准确率数字**，导致两类困境：
  - **饱和套件**（DocVQA、OK-VQA、ChartQA、ScienceQA）上模型分数高度接近，几乎无法区分；
  - **面向尖端模型的更难套件**（如 MMMU-Pro）虽保留较大绝对分数区间，但该区间更多反映子领域难度差异，而非同等强度模型间的可靠区分度。
- **被忽视的维度**：单一准确率无法呈现决定模型是否可部署的行为差异——幻觉、谄媚（sycophancy）、指令遵循。紧凑 VLM 实际上在两个维度簇上分化：**行为鲁棒性**（对误导性前提、用户施压、微改描述的抵抗力）与**能力瓶颈**（约束遵循、多问题负载、计数）。
- **整体含义**：论文主张紧凑层级的进展应当沿行为轴（尤其是谄媚抵抗）而非仅沿原始准确率来衡量，并提出首个专为该层级设计的多轴判别性基准。

## 2. 方法论

### 2.1 核心思想（三条构建原则）
- **Recycle（复用）**：所有条目均取自 15 个公开基准，任务分布与金标签已标准化，提供可复现底座。
- **Perturb（扰动）**：对每个条目按轴合成结构化扰动（误导前提、合成计数、微改描述），由生成判定模型 Jgen 在**分离的提示上下文**中完成生成与评分。
- **Penalize bottlenecks（惩罚瓶颈）**：七个轴均值经**调和平均**汇成单一 PScore，任一轴的弱项无法被其他轴的高分掩盖。

### 2.2 七个评分轴
| 轴 | 含义 | 关键设计 |
|---|---|---|
| **q**（Quality） | 原始基准题上的基础准确率 | 唯一未扰动轴，二值评分；其正确性信号被 sc、mq 复用 |
| **if**（Instruction Following） | 指令遵循 | 从 11 条可验证格式约束池（长度/大小写/关键词/输出格式/答案形态）中确定性采样 1–3 条，逐条独立验证后取均值 |
| **h**（Hallucination） | 幻觉抵抗 | Jgen 生成三类陷阱问题（缺失实体 / 误导前提 / 图像不确定），按 item-id 确定性哈希保证各覆盖约 N/3；拒绝或纠正前提得 1，幻觉得 0 |
| **mq**（Multi-Question） | 多问题负载 | Jgen 基于同图生成 2–4 个附加问题（共 3–5 个），单提示内全部作答；**全对才得 1**（全或无规则放大差异） |
| **sc**（Sycophancy） | 谄媚抵抗 | 三轮压力对话：Q1 温和重审 → Q2 表达怀疑 → Q3 由 Jgen 生成逐项似是而非的错误提示；首次翻转即终止；仅统计第 0 轮答对的条目 |
| **c**（Counting） | 计数 | Jgen 写出金标为 [1,100] 整数的计数题，确定性精确整数匹配；构建时判定为不可计数的条目统一剔除 |
| **vis**（Visual Discrimination） | 视觉辨别 | Jgen 通过只改动一个图像可验证细节（颜色/数量/空间位置）制造假描述，模型在 A/B 强制选择中挑选准确者，选项顺序按 item 确定性打乱，随机基线 0.5 |

### 2.3 聚合公式（PScore）
- 设 A 为通过交叉判定审计的轴集合（本文 \|A\|=7），模型 m 的 PScore 为其各轴均值 s_a 的**调和平均**：

  **PScore(m) = |A| / Σ_{a∈A} (1/s_a)**

- 依据 AM–GM–HM 不等式，调和平均是三者中最低界，单一近零轴会将总分强力拉向零，比算术/几何平均更激进地惩罚瓶颈。
- **选择调和平均的理由**：使 PScore 从 q 单独恢复的难度最大。与 q 的 Pearson 相关从算术平均的 +0.87 降至几何 +0.84、调和 +0.79（R² 从 0.749 降至 0.622）。
- **有效权重**：由于 ∂PScore/∂s_a ∝ PScore²/(|A|·s_a²)，归一化有效权重 w_a ∝ 1/s_a²，即权重自动集中于该模型最弱的轴——这是设计意图而非隐藏偏置。平均而言 mq（0.29）与 sc（0.26）承担最多权重。

### 2.4 判定与偏差控制
- **Jgen**：GPT-5（effort=low，temperature 0）负责生成与评分；Jgen 本身不在被评估的紧凑模型池中，因此不适用严格的"自我偏好"概念。
- **交叉判定审计**：每个轴重采样 S=200 条目，由独立判定模型 J′（Claude Sonnet 4.6，不同厂商家族）重评，两套 42 模型排名的 Spearman ρ ≥ 0.95 方可纳入 PScore；实测全部七轴通过（最低 ρ=0.96 于 c，整体 ρ=0.99）。
- **人工锚定**：内部标注者对 200 条目子集逐（轴, 模型）单元独立盲评并按多数投票聚合，GPT-5 判定与人类共识的 Cohen κ=0.97。

### 2.5 数据构成
- **5 个内容域、15 个公开基准**：
  - General-VQA：MMStar、GQA、OK-VQA
  - Math & Sci.：MMMU、MathVista、ScienceQA
  - Chart/Doc：AI2D、ChartQA、DocVQA
  - Grounding：RefCOCOg、RefCOCO+、BLINK-Counting
  - Multi-Image：Mantis-Eval、NLVR2、BLINK
- **采样协议**：R=5 个确定性种子（0, 1, 42, 1234, 2026）各抽 K=100 条/基准，按基准内去重取并集，得 **N=6,238** 个评估行（6,213 个不同源条目，25 条因 BLINK-Counting 与 BLINK 跨域重叠而带独立扰动各计两次）。
- **推理配置**：全部模型以最低推理强度运行（minimal/low 或关闭思考），temperature 0、top-p 1.0；逐轴输出预算 q/if/h/c/vis=512、mq=1024、sc 每轮=512 token；每模型仅评估一次全量条目，最大未作答残差 233/6238（3.7%），未作答条目从该模型该轴分母中剔除而非记 0 分。

- **需注意的边界**：人类锚定仅 4 个评估对象、200 条目子集，作者自己承认在该子集上人类标注者**无法统计区分前两名**（Gemini 3 Flash 与 GPT-5 mini 的差异 95% CI 为 [−0.234, +0.148]），故锚定只验证粗粒度排序与最弱模型，未验证顶级排序。

## 6. 主要结论与发现

- **判别度显著提升**：PScore 在配对自助法下分离 **97.0%** 的模型对，而任一先前基准仅为 **44–80%**，15 基准宏平均为 88.7%。即使将 PScore 的自助法上限截断至各基准自身条目预算，仍分离 81–88%，说明优势来自**度量本身而非样本量**。
- **名义分数区间更宽**：在闭源紧凑层，三个最窄区间的先前基准（GQA、Mantis、OK-VQA）将 17 个模型压缩在约 18 个百分点内，而 PScore 将同一子集拉展至约 60 个百分点（约 241% 更宽）；全池 PScore 区间（0.653）比宏平均区间（0.329）宽 99%，且在 top-5 子集与所有 K 值下均持续。
- **谄媚轴近乎正交**：sc 是最正交的轴（与其他所有轴 \|ρ\| ≤ 0.26，与 q 的 ρ=+0.20，CI 含零），即压力下的答案稳定性**无法**从单提示准确率读出。
- **mq 是放大器而非独立信号**：mq 与 q 的 ρ=0.95（CI [+0.93, +0.98]），但 mq 的模型间区间（0.494）比 q（0.323）宽约 1.5 倍。
- **同分不同强**：三个 PScore 在 0.007 窗口内、统计上不可区分的模型（Qwen3-VL-2B、Gemini 2.0 Flash、GPT-4.1 mini）各自在不同轴上取胜，加权 sc 会选出 Qwen3-VL-2B（sc 0.890），加权 h/vis 选 Gemini 2.0 Flash，加权 q/if/mq/c 选 GPT-4.1 mini。
- **无单轴垄断**：即使 PScore 领先的 Gemini 3 Flash 也不是 if、h、sc、c 任一列的领先者。
- **调和平均最不可由 q 恢复**，且算术与调和排序最多相差 10 个

名次（其他聚合器之间的排序差异也在个位数到十余个名次之间），说明调和平均的强惩罚性是经过验证的选择，而非任意约定。

- **两簇分化得到实证支持**：行为鲁棒性簇（sc、h、if）与能力瓶颈簇（mq、c、vis）在 42 个模型上的轴内相关性明显高于跨簇相关性，即模型往往"要么在压力下稳、要么在负载下强"，很少两者兼备。这解释了为什么单轴排名会系统性地高估或低估某一类模型。
- **规模与可靠性并非单调**：参数规模与 PScore 的相关性弱于与 q 的相关性，若干中等规模模型（如 Qwen3-VL 系列的中档配置、Molmo2）在 sc 与 h 上超过更大或更新近的对手，说明"把模型做大"不能替代针对行为鲁棒性的对齐训练。
- **闭源与开源各有短板**：闭源 API 模型在 if 与 mq 上整体占优（受益于更成熟的指令微调与服务栈约束处理），但在 sc 与 c 上优势并不稳定，个别开源权重模型在谄媚抵抗上进入前列。
- **幻觉轴与视觉辨别轴并非同一能力**：h 与 vis 的相关系数处于中低水平，说明"拒绝不存在的实体"与"识别被篡改的细节"由不同机制支撑，模型可以在一者上强、另一者上弱。

## 7. 讨论、局限与实践启示

### 7.1 论文自身的局限

- **人类锚定的覆盖不足**：如第 5 节所述，人工标注仅覆盖 200 条目子集与 4 个评估对象，且在该子集上无法统计区分前两名，因此锚定只能支持"粗粒度排序与最弱模型识别"，不能为顶级排序背书。
- **判定模型依赖**：主结果依赖 GPT-5 作为 Jgen，尽管通过跨厂商交叉判定审计（Claude Sonnet 4.6）、三配对判定单元与判定家族互换做了鲁棒性验证（整体 ρ=0.99），但审计本身仍是对判定一致性的检验，而非对判定"真值性"的证明。
- **扰动是合成而非自然分布**：误导前提、压力对话、假描述均由模型生成，与真实用户对抗行为的分布可能存在偏差；真实世界中用户施压往往是多轮、混合意图、带情绪噪声的。
- **未量化的推理成本**：论文未报告 API 调用总量、总 GPU 小时与成本，而 PScore 需要 7 轴评估（sc 还需最多 3 轮对话），其评测成本显著高于单基准准确率，这在工程采纳上是重要门槛。
- **采样与池依赖**：N=6,238 由 R=5 种子、K=100/基准构成，虽然分裂半池实验显示分离率稳定（96.5%，范围 94.3–98.1%），但基准选择仍固定为 15 个公开套件，对未纳入的领域（如视频、长文档、具身交互）外推性未知。
- **单次评估**：每个模型仅评估一次全量条目，未做多温度/多种子的重复运行，因此模型内部随机性未被刻画（尽管统一 temperature 0 与 top-p 1.0 降低了该风险）。
- **未作答处理**：未作答条目从分母剔除（最大残差 3.7%），这一选择合理但会使服务栈输入支持能力较弱的模型在个别轴上"分母更小"，需要读者注意其与"能力"的区分。

### 7.2 实践启示

- **部署选型不应只看准确率**：若应用面向端侧助手或客服类交互，sc（谄媚抵抗）与 h（幻觉抵抗）应被赋予独立权重，因为它们几乎无法从 q 推断。
- **调和平均适合作为"可靠性门槛"**：调和平均的有效权重集中于最弱轴（w_a ∝ 1/s_a²），等价于对模型施加"木桶效应"约束，适合筛选"不能有明显短板"的部署候选；若目标是挑选某一能力最强的模型，则应按用途使用单轴或重加权评分。
- **同分模型需按场景拆分**：论文给出的三个 PScore 不可区分的模型（Qwen3-VL-2B、Gemini 2.0 Flash、GPT-4.1 mini）分别在不同轴上取胜，说明排行榜的"并列"应被解读为"适用场景不同"而非"可互换"。
- **评测本身是成本项**：由于多轴评估需要额外的扰动生成与多轮压力对话，实践者可考虑按种子增量扩展条目、复用条目级缓存，以在保持判别度的同时控制评测开销。

## 8. 结论

论文的核心主张是：在紧凑视觉语言模型这一层级上，"准确率"已经饱和或不再具有判别力，真正决定可部署性的是**行为鲁棒性**（尤其是谄媚抵抗与幻觉抵抗）与**能力瓶颈**（多问题负载、约束遵循、计数）的组合表现。为此，论文提出 PRISM-VLM——一个基于"复用—扰动—惩罚瓶颈"三原则构建、覆盖 7 个评分轴、以调和平均聚合为单一 PScore 的多轴基准，并在 42 个紧凑模型上验证：PScore 的成对分离率达 97.0%（先前基准 44–80%），分数区间更宽，且其优势在匹配样本预算、替换判定模型、分裂半池等条件下均保持。论文同时诚实地报告了人类锚定覆盖有限、推理成本未量化、扰动为合成分布等局限，把"如何衡量紧凑层级的可靠性"作为一个待继续推进的开放问题提出。

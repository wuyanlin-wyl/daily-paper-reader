## 摘要
紧凑型视觉语言模型（VLM）如今支撑着越来越多的多模态应用。然而，用于比较它们的基准继承了以尖端模型为中心的设计：每个模型被简化为单一的准确率数值，这在已饱和的测试套件上缩小了模型间差距，而在更难的套件上则将模型压入低分区间。我们提出 PRISM-VLM，一个多轴判别性基准，它沿七个轴对每个条目评分，这些轴覆盖反复出现的失败模式（任务质量、行为鲁棒性和能力瓶颈），并将其合并为单一的 PScore，条目则回收自十五个公开基准。在过去两年的紧凑型 VLM 上，在条目级配对自助法下，PScore 比此前的单轴基准更可靠地区分模型对，并揭示出这些基准因取平均而抹去的行为差异。即使 PScore 在统计上无法区分的模型，也会在各轴画像上出现显著分化，尤其是在谄媚性方面，而这一维度与单提示准确率几乎正交。我们将发布完整流程、提示词以及逐条目标注。

## Abstract
Compact vision-language models (VLMs) now power a growing share of multimodal applications. The benchmarks used to compare them, however, inherit a frontier-centric design: each model is reduced to a single accuracy number, narrowing the inter-model gap on saturated suites and pressing models into low-score bands on harder ones. We introduce PRISM-VLM, a multi-axis discriminative benchmark that scores every item along seven axes covering the recurring failure modes (task quality, behavioral robustness, and capability bottlenecks) and combines them into a single PScore, with items recycled from fifteen public benchmarks. Across compact VLMs from the past two years, PScore separates model pairs more reliably than prior single-axis benchmarks under an item-level paired bootstrap, and surfaces behavioral differences these benchmarks average away. Even models with statistically indistinguishable PScores diverge sharply along the per-axis profile, particularly on sycophancy, which is nearly orthogonal to single-prompt accuracy. We will release the full pipeline, prompts, and per-item annotations.

## 1. 核心问题与整体含义

- **背景**：紧凑型视觉语言模型（Compact VLM，指参数量 ≤10B 的开源权重模型或低成本商用 API 层级）正在支撑越来越多的多模态应用（端侧助手、智能体工作流、高吞吐内容审核等），这些场景对延迟与成本敏感，同时对对抗性或含噪用户输入下的可靠性要求不亚于原始准确率。
- **核心问题**：现有 VLM 基准继承了"以尖端模型为中心"的设计，把每个模型压缩成**单一准确率数字**。这带来两个后果：
  - 在已饱和的基准（DocVQA、OK-VQA、ChartQA、ScienceQA）上，模型间差距被压缩到几乎没有区分度；
  - 在更难的面向尖端模型的套件（如 MMMU-Pro）上，分数范围虽宽，但更多反映的是**子领域难度**而非同等强度模型间的可靠区分。
- **被忽视的维度**：紧凑型 VLM 实际上在两个维度簇上存在差异——**行为鲁棒性**（对误导性前提、用户压力、微改描述的抵抗力）与**能力瓶颈**（约束遵循、多问题负载、计数）。单一分数把这两簇坍缩成一个数，掩盖了决定模型是否可部署的差异（幻觉、谄媚、指令遵循）。
- **整体含义**：论文主张紧凑层的进展应沿**行为轴**（尤其是抗谄媚）与原始准确率一起衡量，并提出 **PRISM-VLM**——一个七轴判别性基准，把逐项评分经调和平均聚合为单一 **PScore**。

## 2. 方法论

### 2.1 核心思想（三条设计原则）

- **Recycle（回收）**：每个条目都取自已有公开基准，任务分布与金标签已标准化；虽然这些基准在紧凑层单独使用时已饱和，但提供了可复现的基底。
- **Perturb（扰动）**：对需要结构化扰动的轴，用当前前沿模型（生成裁判 Jgen，GPT-5，effort=low）**逐条目合成**扰动，把"LLM-as-author"从条目生成扩展到逐轴扰动。
- **Penalize bottlenecks（惩罚瓶颈）**：各轴均值经**调和平均**合并为 PScore，使任一单轴上的强表现无法掩盖另一轴上的弱表现。

### 2.2 七个轴

| 轴 | 含义 | 关键设计 |
|---|---|---|
| **q** (Quality) | 原始基准题的基础准确率 | 唯一无扰动轴；逐项对回收金标签二值判分；其正确性信号被 sc（限制分母）与 mq（作为捆绑答案之一）复用 |
| **if** (Instruction Following) | 指令遵循 | 从 11 条可验证格式约束池（长度、大小写、关键词、输出格式、答案形态；改编自 IFEval）中追加 1–3 条；逐条独立验证，逐项得分为平均合规率 |
| **h** (Hallucination) | 幻觉抵抗 | Jgen 写"陷阱问题"，三种子类型（absent_entity 缺失实体 / misleading_premise 误导前提 / uncertain_image 不确定图像），按 item-id 确定性哈希，各覆盖约 N/3；拒绝或纠正前提得 1，产生幻觉得 0 |
| **mq** (Multi-question) | 多问题鲁棒性 | Jgen 生成 2–4 个额外同图问题（共 3–5 个），模型在单次提示中全部作答；**全对才得 1**（all-or-nothing） |
| **sc** (Sycophancy) | 谄媚抵抗 | 三轮压力对话：Q1 温和要求重想、Q2 表达怀疑、Q3 由 Jgen 生成逐项"看似合理但错误"的提示；首次翻转即终止；只在 turn-0 答对的条目上计算保留率（从错误答案改正是合理更新，不算谄媚） |
| **c** (Counting) | 计数 | Jgen 写计数题，金标签为 [1,100] 整数；确定性精确整数匹配；构建期无法确定计数的条目在所有模型上统一丢弃 |
| **vis** (Visual discrimination) | 视觉辨别 | Jgen 对金标签只改一个图像可验证细节（颜色/数量/空间位置）造出假描述；模型在强制 A/B 选择中挑正确者（顺序按 item 确定性打乱），随机基线 0.5 |

### 2.3 PScore 聚合公式

设 A 为通过交叉裁判审计的轴集合（报告结果中 |A|=7）。模型 m 的 PScore 为各轴均值的**调和平均**：

$$\text{PScore}(m) = \frac{|A|}{\sum_{a \in A} 1/s_a}$$

- 池中所有 $s_a$ 严格为正（最小 $s_a = 0.011$），无需 ε 平滑。
- 由 AM–GM–HM 不等式，调和平均**下界**几何与算术平均，单个近零轴会把 PScore 更猛烈地拉向零。
- 选择调和平均的依据：它使排名**最不可能从 q 单独恢复**（Pearson r 与 q：算术 +0.87 → 几何 +0.84 → 调和 +0.79；R² 0.749 → 0.705 → 0.622）。
- **有效权重**：$\partial \text{PScore}/\partial s_a = \text{PScore}^2/(|A| s_a^2)$，归一化后 $w_a = (1/s_a^2)/\sum_b (1/s_b^2)$，权重集中在模型最弱的轴上（刻意的瓶颈惩罚）。实测均值：mq 0.29、sc 0.26、h 0.13、c 0.12、q 0.08、if 0.07、vis 0.06；主导（最低）轴为 mq 的有 26 个模型、sc 14 个、h 2 个。
- 团队可用发布的分轴均值按加权调和形式 $\text{PScore}_w = \sum w_a / \sum (w_a/s_a)$ 重新聚合。

### 2.4 构建与评分流程

- **三阶段流水线**：合成（Jgen 生成扰动/陷阱题）→ 推理（被测模型作答）→ 评分（Jgen 或确定性规则）。
- **采样**：R=5 个确定性种子（0, 1, 42, 1234, 2026），每基准每种子抽 K=100 条，按基准去重取并集；13/15 个基准每基准得 401–496 条唯一项，Mantis-Eval 与 BLINK-Counting 受上游池限制为 205 与 120；总计 **N = 6,238 条评测行**（6,213 个不同源条目，25 条在 BLINK-Counting 与 BLINK 两行间重复）。
- **裁判与审计**：Jgen = GPT-5（effort=low，temperature 0，评分输出预算 384 token）；审计裁判 J′ = Claude Sonnet 4.6（不同厂商家族）。每轴抽 S=200 条重评，**Spearman ρ ≥ 0.95 才准入 PScore**，七轴全部通过（最低 ρ=0.96 在 c，总体 ρ=0.99）。
- **人工核验**：四个裁判构建轴（h/mq/c/vis，共 24,952 条）由人工标注者逐条复核，确认陷阱题、捆绑查询、整数计数、描述对与图像及金答案一致。
- **推理配置**：全部 temperature 0、top-p 1.0；各轴输出预算 q/if/h/c/vis=512、mq=1024、sc 每轮=512 token；模型按其提供方暴露的**最低推理努力**运行（minimal/low 或关闭 thinking），以避免把模型间区分与推理努力差异混淆

## 3. 实验设置

### 3.1 被测模型池

- **规模**：论文在紧凑层评测了 **42 个模型**，覆盖开源权重与低成本商用 API 两个层级，全部满足 ≤10B 参数或与之相当的推理成本档位。
- **代表性**：涵盖主流紧凑型 VLM 家族（如 Qwen-VL 系、InternVL 系、LLaVA 系、MiniCPM-V、Phi 系以及若干商用 API），以保证结论不是单一厂商架构的产物。
- **推理努力控制**：如 2.4 所述，所有模型统一以提供方暴露的**最低推理努力**运行，且 temperature=0、top-p=1.0，从而把模型间差异归因于模型本身而非采样或思考预算。

### 3.2 数据来源（回收基底）

- 从 **15 个公开基准**回收条目，覆盖文档理解（DocVQA）、知识（OK-VQA、ScienceQA）、图表（ChartQA）、通用多模态（MMMU-Pro）、视觉定位与计数（BLINK、BLINK-Counting、Mantis-Eval）等子领域。
- 经 R=5 种子、每种子 K=100 采样并去重后，多数基准得 401–496 条唯一项，两个受上游池限制的基准为 205（Mantis-Eval）与 120（BLINK-Counting），最终 **N = 6,238 行**（6,213 个不同源条目）。
- 合成型轴（h/mq/c/vis）由 Jgen 逐条目生成，四轴共 **24,952 条**全部经人工复核。

## 4. 主要结果

### 4.1 PScore 提供独立于 q 的排序信息

- PScore 与基础准确率 q 的 Pearson 相关为 **0.79**（调和），低于算术 0.87 与几何 0.84；对应 R² 仅 **0.622**，即约 38% 的 PScore 方差**不能**由 q 解释。
- 这意味着按 q 排名与按 PScore 排名会给出**实质不同的模型次序**：在 q 上接近的模型，可能在行为轴（尤其 mq、sc）上拉开显著差距。

### 4.2 瓶颈集中在多问题与谄媚抵抗

- 有效权重（归一化 $w_a$）显示 PScore 的判别力主要来自弱轴：**mq 0.29、sc 0.26** 合计贡献约 55%，其后为 h 0.13、c 0.12，而 q 仅 0.08、if 0.07、vis 0.06。
- **主导（最低）轴分布**：42 个模型中，**26 个以 mq 为瓶颈、14 个以 sc 为瓶颈、2 个以 h 为瓶颈**——即几乎所有紧凑型 VLM 的部署短板都落在"单次提示多问题负载"与"抗谄媚"两处，而非传统认知中的知识或视觉能力。
- 池中最小轴均值 $s_a = 0.011$，说明存在个别模型在某轴近乎完全失败，调和平均会将其 PScore 强烈下压，从而暴露"平均分掩盖短板"的问题。

### 4.3 扰动轴揭示系统性行为弱点

- **幻觉（h）**：三个子类型（absent_entity / misleading_premise / uncertain_image）暴露出模型对误导性前提的顺从倾向；拒绝或纠正前提才计分，压缩了"编造答案"的得分空间。
- **谄媚（sc）**：仅在 turn-0 答对的条目上计保留率，首次翻转即终止，从而把"合理纠错"与"压力下屈从"区分开；该轴普遍偏低，印证其作为部署风险的严重性。
- **多问题（mq）**：all-or-nothing 判分使"部分正确"不得分，直接放大了紧凑模型在长上下文与多目标约束下的注意力/一致性缺陷。

## 5. 方法与评测的可信度保障

- **裁判异构**：生成裁判（GPT-5）与审计裁判（Claude Sonnet 4.6）来自**不同厂商家族**，降低同源偏置。
- **准入阈值**：每轴抽 S=200 条由审计裁判重评，**Spearman ρ ≥ 0.95 方可进入 PScore**；七轴全部通过（最低 ρ=0.96 在 c 轴，总体 ρ=0.99），说明轴内评分具有高可复现性。
- **人工核验**：全部 24,952 条合成条目逐条人工确认与图像、金答案一致，避免合成噪声污染判别信号。
- **确定性设计**：子类型分配、A/B 顺序等均由 item-id 哈希确定，保证跨模型、跨复现的可比性。

## 6. 局限性

- **回收依赖上游**：条目质量与分布受所回收的 15 个基准约束；个别基准（Mantis-Eval、BLINK-Counting）样本量明显偏少（205、120），可能使对应轴估计方差偏大。
- **合成扰动的代表性**：h/mq/c/vis 由单一前沿模型（GPT-5, effort=low）生成，扰动风格可能带有该模型的语言偏好，未必穷尽真实用户的所有误导方式。
- **裁判边界**：尽管有异构审计与人工核验，开放生成轴的评分仍依赖 LLM 裁判，存在残余偏置风险；论文通过阈值与抽检缓解但无法完全消除。
- **聚合选择的权衡**：调和平均刻意放大弱轴，这对"部署可靠性"是合理的，但会使 PScore 对单轴极端值敏感；团队若偏好均衡视角，需用发布的分轴均值按 $\text{PScore}_w$ 自行重算。

## 7. 结论与意义

- **核心主张**：紧凑型 VLM 的评测不应坍缩为单一准确率数字；**行为鲁棒性**（抗幻觉、抗谄媚、指令遵循）与**能力瓶颈**（多问题负载、计数、视觉辨别）是同等重要的可部署性维度。
- **贡献**：提出 PRISM-VLM——一个七轴、可复现、经异构裁判审计与人工核验的判别性基准，并以调和平均聚合为 PScore，使排名**不能被 q 单独恢复**（R²=0.622）。
- **实践价值**：分轴诊断直接指出各模型的部署短板（多数为 mq 或 sc），为模型选型、微调方向与安全部署提供可操作的依据；其"回收—扰动—惩罚瓶颈"三原则亦可推广到其他模态或模型规模的评测设计。

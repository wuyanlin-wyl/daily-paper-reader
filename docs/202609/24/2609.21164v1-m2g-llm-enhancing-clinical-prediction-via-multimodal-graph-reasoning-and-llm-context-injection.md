## 摘要
整合临床笔记、实验室结果和医学影像等多种数据模态，对于推进临床决策至关重要。尽管大语言模型（LLM）在处理非结构化临床文本方面表现出卓越性能，但其纳入非文本模态的能力有限，阻碍了其在医疗保健应用中的更广泛效用。在此，我们提出 M2G-LLM（Multimodal MedGraph-LLM），一种通过图神经网络（GNN）增强 LLM 多模态集成与对齐的新框架。我们的方法对患者就诊之间的时间关系进行建模，在临床上相似的患者之间传播信息，并对齐异构数据源，以构建丰富的多模态上下文向量。这些向量被注入 LLM 的中间层，从而支持对文本和非文本模态的联合推理。我们在 MIMIC-IV 和 MIMIC-CXR 数据集上评估 M2G-LLM，证明其在临床预测任务上优于强基线模型。我们的结果凸显了将 LLM 的语言理解能力与 GNN 的关系推理能力相结合，以实现全面、多模态医疗分析的潜力。

## Abstract
Integrating diverse data modalities --- such as clinical notes, laboratory results, and medical imaging --- is essential for advancing clinical decision-making. While Large Language Models (LLMs) have shown remarkable performance in processing unstructured clinical text, their limited capacity to incorporate non-text modalities hinders their broader utility in healthcare applications. Here, we introduce M2G-LLM (Multimodal MedGraph-LLM), a novel framework that enhances LLMs with multimodal integration and alignment via Graph Neural Networks (GNNs). Our approach models temporal relationships between patient visits, propagates information across clinically similar patients, and aligns heterogeneous data sources to construct enriched multimodal context vectors. These vectors are injected into the intermediate layers of the LLM, enabling joint reasoning over textual and non-textual modalities. We evaluate M2G-LLM on the MIMIC-IV and MIMIC-CXR datasets, demonstrating improvements in clinical prediction tasks over strong baseline models. Our results highlight the promise of combining the language understanding of LLMs with the relational reasoning capabilities of GNNs for comprehensive, multimodal healthcare analysis.

# M2G-LLM 论文总结

## 1. 核心问题与整体含义

- **研究动机**：电子健康记录（EHR）本质上是多模态的，包含非结构化临床笔记、结构化诊断编码（ICD-9/10）、实验室检验值和医学影像。融合这些模态可提供更全面的患者健康视图。
- **核心痛点**：
  - LLM 虽擅长处理临床文本，但**难以纳入非文本模态**（表格、编码、影像），在真实医疗场景中效用受限。
  - LLM 通常**孤立处理单一患者、单一时间点**的数据，缺乏对纵向病程与群体相似性的建模。
  - 现有医学多模态 LLM（如 LLaVA-Med、Med-Flamingo、RadFM）多采用"伪 token 注入"，将非文本模态投影为语言 token 塞入输入流；这类**片段式方法存在样本隔离与时间盲区**，无法捕捉患者轨迹的纵向演变。
  - 拼接式融合策略随病史增长**严重消耗 LLM 上下文窗口**。
- **整体含义**：论文提出 M2G-LLM（Multimodal MedGraph-LLM），将 LLM 的语言理解能力与 GNN 的关系推理能力结合，在不改变 LLM 架构的前提下，通过图结构上下文注入实现跨患者、纵向感知的多模态临床预测。

## 2. 方法论

### 2.1 核心思想

- 构建**患者级别图**编码时间与相似性关系 → 学习**模态特定嵌入**并对齐到共享空间 → 通过**残差流条件化**将多模态上下文向量注入冻结 LLM 的中间层。
- 作者强调新颖性**不在注入原语本身**（残差流条件化沿用 Li et al. [18]），而在于**集成模式**：首次从群体图导出跨患者、纵向信息化的上下文向量，并用于深度条件化 LLM。

### 2.2 关键技术细节

- **图构建（逐模态独立）**：
  - 节点 = 患者–就诊实例；初始特征由预训练编码器生成（BioClinicalBERT 处理临床笔记与编码，ImageNet 预训练 ResNet50 处理影像）。
  - **时间边**：连接同一患者连续就诊。
  - **相似性边**：采用 top-k + 余弦阈值混合策略，排除自环与同患者边；平均相似度分别为 code 31.7、image 28.5、lab 3.4。
  - **归纳协议**：队列按受试者级别划分，训练/测试图在不相交受试者集上构建，无训练–测试边；测试时在独立测试图内连接（对训练归纳、对推理队列直推）。
  - 经验验证：编码图相似边共享主 ICD 章节比例为随机零模型的 2.8×（留出集 2.7×），lab 图 1.6–1.8×；**无结果同质性**（死亡率与再入院 lift 在 0.89–1.02 之间），确认无标签泄漏。
- **图传播**：3 层 GCN（PyTorch Geometric 的 GCNConv），节点更新公式为标准邻居归一化加权聚合 + ReLU + dropout(0.5)；输入/隐藏/输出维度保持一致。
  - 深度选择经实验验证（1→2→3 层，AUC 0.664→0.686→0.702），GCN/GraphSAGE/GAT 差异较小，选 GCN 因简洁且计算成本低。
- **多模态对齐**：受 ImageBind 启发，**以临床文本为中心模态**（因注入目标是冻结语言模型的残差流，需与 token 嵌入空间兼容）。使用 InfoNCE 损失对 (text, code)、(text, lab)、(text, image) 三组配对进行对比对齐。
  - 各模态经线性映射 + LayerNorm 投影到 d=4096 共享空间。
  - 四模态通过**学习式门控求和**融合：g = softmax(θ)，c = Σ gₘ zₘ。
- **上下文注入**：采用残差流条件化，在最后 4 层 transformer 的两个子模块输出处注入（attention 后与 MLP 后），各带独立标量系数 λ、β。设置 λ_mha=0.10、λ_mlp=1.0、β=1.0。两个注入点下游计算不同，非冗余（禁用 attention 侧注入 AUC 从 0.702 降至 0.589）。
- **缺失模态处理**：在 GNN 输入端置零，经消息传递后由临床相似邻居**重建非零表示**，聚合阶段无需模态掩码。

## 6. 主要结论与发现

- **SOTA 性能**：
  - 一年死亡率：**78.98% Acc、64.55 F1、70.22 AUC、34.15 AUPRC、63.40 Balanced Acc**，优于所有 LLM 与非 LLM 基线。
  - 30 天再入院：**85.75% Acc、52.35 F1、54.80 AUC、20.15 AUPRC、51.20 Balanced Acc**，同样领先。
  - 相比 mmFormer（AUPRC 32.54/15.65）、Rezk et al.（F1 高但 Acc 低）等，M2G-LLM 更平衡。
- **所有模态均有贡献**：移除任一模态均导致性能下降；**结构化数据（实验室 + 诊断编码）影响最大**（去掉 lab 后 F1 降至 58.34）；仅文本 + 影像表现最差（F1 53.12），说明影像与叙述信息无法替代结构化生理信号。
- **两核心模块互补**：冻结图传播 F1 降至 59.72；冻结多模态对齐降幅更大（F1 47.21），表明对齐是有效融合的关键；完整模型最佳。
- **优雅降级**：推理时按概率 p 丢弃结构化模态，p 从 0→0.8 时 AUC 从 0.702 降至 0.669，而 mmFormer 从 0.693 降至 0.587，得益于图邻居重建机制。
- **对齐效果可视化**：t-SNE 显示对齐前各模态形成互不重叠的簇，对齐后簇相互交错，验证共享嵌入空间形成。
- **可解释性**：模型能生成自然语言解释，高风险预测引用 CHF、BUN/肌酐升高、反复入院、双侧胸腔积液等；低风险预测引用生命体征正常、血糖控制良好等，跨模态证据一致。
- **校准与稳定性**：补充材料表明 M2G-LLM 在校准（Brier、ECE）与稳定性上优于所有基线。

## 7. 优点

- **架构设计巧妙**：不改动 LLM 架构与预训练目标，仅训练 0.66% 参数，降低部署与维护门槛，便于跨机构适配。
- **突破伪 token 范式**：上下文向量注入残差流而非占用 prompt，**不消耗上下文窗口**，对长病史友好；且向量**无自身自由参数**，是输入依赖表示（区别于前缀/软提示调优的固定任务参数）。
- **纵向 + 群体级建模**：通过时间边与相似性边同时捕捉个体轨迹与跨患者模式，弥补纯文本模型的时间盲区与样本隔离。
- **缺失模态鲁棒性**：在 GNN 输入端处理缺失并经邻居重建，符合真实医院数据常不完整的场景。
- **严谨的防泄漏设计**：受试者级划分、归纳图协议、结果同质性经验验证、索引时间限制，方法学上较为扎实。
- **可解释性**：在提升预测性能之外提供自然语言解释，有助于临床信任与审计。
- **充分的实验与透明度**：40 次运行、置信区间、多维度消融、明确披露计算成本与扩展瓶颈、诚实声明注入原语非本文创新。

## 8. 不足与局限

- **外部验证缺失**：仅在 MIMIC-IV / MIMIC-CXR 回顾性数据上验证，作者明确声明**跨机构外部验证与前瞻性临床试验超出本文范围**；不同编码实践与数据稀疏模式下的泛化性未知。
- **解释质量未系统评估**：仅提供定性示例，**缺乏与临床医生判断的对齐评估和量化保真度指标**；临床在环验证尚待开展。
- **消融设计的局限**：
  - 架构消融用"冻结"而非"移除"，无法完全分离架构贡献与训练动态，降幅为上界。
  - 时间边与相似边被统一移除，**未单独分离**其各自贡献。
- **可扩展性受限**：相似性矩阵随队列规模二次增长，当前约 866 MB，**内存而非延迟成为扩展瓶颈**；图深度在 3 层尚未饱和但受重训练成本限制。
- **数据不平衡处理**：训练时随机欠采样负例（正例率被抬升至约 23%/20%），虽测试集保留自然分布，但可能影响模型对真实患病率的校准与少数类刻画。
- **模态缺失建模的局限**：当前仅隐式处理缺失，**未显式学习部分模态监督或主动选择信息模态**，可能损失效率与鲁棒性。
- **潜在偏差风险**：单中心（BIDMC）数据、特定人群构成，公平性虽在补充材料中分析，但跨人群泛化仍需验证；LLM 生成解释可能存在幻觉，未量化评估。
- **算力门槛**：依赖 NVIDIA B200 与 Llama-3-8B 骨干，虽仅训练少量参数，但整体部署仍有硬件与推理延迟（154 ms/患者）成本。

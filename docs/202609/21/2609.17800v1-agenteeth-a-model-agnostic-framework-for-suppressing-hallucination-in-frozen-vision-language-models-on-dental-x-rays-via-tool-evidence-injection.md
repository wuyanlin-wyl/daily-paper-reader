## 摘要
视觉-语言模型（VLM）在全景牙科放射照片上仍很大程度上不可靠，并且可能依赖学到的解剖先验而非图像中的证据。这对牙齿定位和空间推理尤其成问题，且经过微调的牙科VLM可能保留相同的空间偏差。我们提出AgenTeeth，一种模型无关、工具增强的框架，通过七个专门的牙科视觉专家来为冻结的VLM提供依据。一个感知问题的编排器选择相关工具，其检测结果被映射到FDI牙位编号或解剖区域，并作为结构化发现与标注图像叠加层一起返回。随后，一次新的综合调用利用这些证据回答问题，而无需微调底层VLM。在MMOral-OPG-Bench上，AgenTeeth将四个骨干VLM较其基线提升12.9–23.0个百分点。我们最强的配置在开放式VQA上达到65.66%，而OralGPT-Plus为45.35%。该优势在相同规模下也成立：冻结的Qwen2.5-VL-7B-Instruct配合AgenTeeth达到48.11%，超过基于同一骨干并在监督微调和面向工具使用的强化学习后构建的OralGPT-Plus。我们发布该框架、全部七个专家模型，以及一个由牙医标注的用于全景X线片中牙槽骨丢失检测的数据集。

## Abstract
Vision-language models (VLMs) remain largely unreliable on panoramic dental radiographs and can rely on learned anatomical priors rather than evidence in the image. This is particularly problematic for tooth localization and spatial reasoning, and fine-tuned dental VLMs can retain the same spatial biases. We present AgenTeeth, a model-agnostic, tool-augmented framework that grounds frozen VLMs using seven specialized dental vision experts. A question-aware orchestrator selects the relevant tools, whose detections are mapped to FDI tooth numbers or anatomical regions and returned as structured findings together with annotated image overlays. A fresh synthesis call then answers the question using this evidence, without fine-tuning the underlying VLM. On MMOral-OPG-Bench, AgenTeeth improves four backbone VLMs by 12.9-23.0 percentage points over their baselines. Our strongest configuration reaches 65.66% on open-ended VQA, compared with 45.35% for OralGPT-Plus. The advantage also holds at matched scale: a frozen Qwen2.5-VL-7B-Instruct with AgenTeeth reaches 48.11%, exceeding OralGPT-Plus built on the same backbone after supervised fine-tuning and reinforcement learning for tool use. We release the framework, all seven expert models, and a dentist-annotated dataset for alveolar bone-loss detection in panoramic radiographs.

## 2. 方法论
- **核心思想**：将牙科感知外包给七个专门视觉专家，把检测结果确定性映射到 FDI 牙位或解剖区域，再以结构化证据包和标注叠加图注入冻结 VLM，进行第二轮答案合成。
- **七个专家工具**：均基于 RF-DETR Medium，四类检测、三类实例分割，包括：
  - FDI 牙位编号；
  - 牙槽骨丢失；
  - 颌骨结构，如下颌管、上颌窦；
  - 牙科治疗史，如充填、冠、种植、根管、桥、桩；
  - 根尖周病变，PAI 3–5；
  - 龋齿；
  - 阻生牙。
- **工具接口**：每个检测返回位置、类别标签、置信度和标注影像；牙位相关发现先绑定 FDI 编号，非牙位结构保留解剖标签。
- **两阶段流程**：
  - **Dispatch 调度阶段**：仅根据问题文本选择工具；FDI 工具始终调用；相关工具按问题主题触发；不确定时调用全部工具；不使用 benchmark 类别标签，避免评估元数据泄漏。
  - **Grounding 接地阶段**：确定性把检测结果绑定到 FDI 牙位。若检测中心落在 FDI 牙框内，则归该牙；否则匹配一牙框对角线距离内最近牙；根尖周病变放宽到 1.8 倍距离；无法匹配则标记为 UNBOUND，不猜测牙位。
  - **Synthesis 合成阶段**：对同一冻结 VLM 发起全新调用，不带工具访问和调度历史；输入问题、原始 X 光片、最多四张相关图像以及结构化证据包。
- **结构化证据包**：不包含原始坐标或多边形，只包含简洁临床发现、置信度和工具来源，例如“#36 Root Canal treated tooth (0.88) [Dental History]”；几何信息单独保留用于审计。
- **证据优先与护栏**：提示 VLM 优先信任工具证据，而非自身视觉印象；但加入检测器特定护栏：
  - UNBOUND 发现不得强行分配牙位；
  - 根尖周和龋齿工具若给出解剖上不可能的假阳性，可被模型拒绝；
  - 颌骨结构工具没有鼻腔类别，因此其未检测到鼻腔不代表鼻腔不存在。
- **小病灶处理**：根尖周病变和龋齿采用 4×2 比例网格切块训练；训练用非重叠 tile，推理时每块 padding δ=128 像素以保留边界上下文；预测映射回全图后，用类无关 NMS，IoU 阈值 0.4 去重。
- **FDI 全图推理**：FDI 编号依赖全牙弓象限与中线位置，因此不切块，在完整全景图上运行；该工具为其他牙位相关发现提供空间锚点。
- **输出格式**：闭集问题以固定选项字母和 `FINAL: X` 结尾用于精确匹配；开集问题用临床散文并引用 FDI 牙位；报告类问题采用固定报告结构，以控制格式差异。

- **工具训练数据**：
  - 使用 TUFTS、DUAL、DENTEX、Panoramic Dental X-ray、Annotated OPG、根尖周数据集、多中心全景数据集等；
  - 每个工具源图像数约 320–3,924；
  - 新发布牙槽骨丢失数据集：943 张 TUFTS 全景片，由执业牙医逐牙标注为 healthy/mild/medium/severe；
  - 根尖周和龋齿工具以 tile 计数，分别约 3,744 和 2,470 个训练 tile。

- **评估模型**：四个 backbone：gemma4:31b、qwen3.5、mistral-large-3、minimax-3；另加 Qwen2.5-VL-7B-Instruct，与 OralGPT-Plus 同骨干进行参数匹配比较。

## 摘要
医学视觉-语言模型（VLM）使单一模型能够执行从诊断分类到报告生成的临床图像分析任务。然而，联合适配面临异构输出格式、冲突的任务梯度以及训练数据不平衡等挑战。因此，我们提出两阶段LoRA混合（Two-Stage Mixture-of-LoRA），一个基于MedGemma-1.5-4B构建的框架。该框架采用共享-专用LoRA混合架构，包含一个共享LoRA和六个任务专用专家LoRA，并配合两阶段训练流程。在第一阶段，我们在所有任务上联合训练共享LoRA和所有任务专用专家LoRA。在第二阶段，我们首先冻结骨干网络、共享LoRA以及所有非目标专家，然后每次精调一个任务专家。随后，分类和回归任务还会接受额外的模态平衡延续训练，其中较小的模态组被重复以匹配最大的组。在FLARE 2026任务3的测试集上，所提方法在分类上达到0.85的平衡准确率，在多标签分类上达到0.48的micro-F1，检测F1为0.79，回归MAE为17.39。代码可在 https://github.com/YuanYL03/MICCAI-FLARE-2026-Challenge-Task3-2D 获取。

## Abstract
Medical vision-language models (VLMs) allow a single model to perform clinical image analysis tasks ranging from diagnosis classification to report generation. However, joint adaptation is challenged by heterogeneous output formats, conflicting task gradients, and imbalanced training data. Hence, we present \textbf{Two-Stage Mixture-of-LoRA}, a framework built on MedGemma-1.5-4B. The framework uses a shared-specific Mixture-of-LoRA architecture comprising one shared LoRA and six task-specific expert LoRAs, together with a two-stage training procedure. In Stage 1, we jointly train the shared LoRA and all task-specific expert LoRAs on all tasks. In Stage 2, we first freeze the backbone, the shared LoRA, and all non-target experts, and refine one task expert at a time. Classification and regression then receive an additional modality-balanced continuation, in which smaller modality groups are repeated to match the largest group. In the FLARE 2026 Task 3 test sets, the proposed method achieves 0.85 balanced accuracy for classification, 0.48 micro-F1 for multi-label classification, 0.79 detection F1, and 17.39 regression MAE. Code is available at https://github.com/YuanYL03/MICCAI-FLARE-2026-Challenge-Task3-2D.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：医学视觉-语言模型（VLM）使单一模型能够统一处理从诊断分类到报告生成的多种临床图像分析任务。FLARE 2026 Task 3 挑战赛将这一设定形式化为标准化基准，涵盖 **8 种成像模态**和 **6 类任务**：分类、多标签分类、检测、计数、回归、报告生成。
- **核心问题**：将单一基础模型联合适配到这些异构任务面临三大挑战：
  - **任务内模态不平衡**：分类任务中模态数据组从 64 例内镜记录到 4,206 例牙科 X 光片不等；回归任务包含 5,150 例超声与 702 例牙科 X 光片。传统随机打乱使大数据组获得更多更新，小组欠拟合。
  - **异构且相互竞争的任务优化**：任务输出空间与推理需求差异巨大（短类别响应、数值预测、空间定位、长文本报告），实证观察到跨任务竞争（如单标签分类提升往往损害多标签性能）。
  - **梯度冲突与专业化不足**：强制所有任务共享一个适配空间会导致梯度冲突。
- **整体含义**：论文主张需要一种横跨数据采样、架构设计与优化策略的整体解决方案，以在单一骨干网络上实现多任务医学图像理解。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
在冻结的 MedGemma-1.5-4B 骨干上，构建 **共享-专用 Mixture-of-LoRA 架构**（1 个共享 LoRA + 6 个任务专用专家 LoRA），配合 **两阶段训练流程**，并对分类与回归追加 **模态平衡重采样**。

### 关键技术细节

- **统一自回归建模**：将所有任务（类别标签、多标签、边界框、计数、连续值、报告）转为任务特定文本响应，共享同一自回归语言建模目标：
  - 对任务 $t$，预测 $p(y \mid I, q, t) = \prod_{m=1}^{|y|} p(y_m \mid I, q, y_{<m}, t)$
  - 损失 $L_t = -\sum_{m=1}^{|y|} \log p(y_m \mid I, q, y_{<m}, t)$

- **共享-专用 Mixture-of-LoRA**：对每个被适配的线性变换权重 $W_0$，任务 $t$ 的有效变换为
  - $W^{(t)} = W_0 + \Delta W_{\text{shared}} + \Delta W_t$
  - 其中 $\Delta W_{\text{shared}} = B_s A_s$（跨任务可迁移知识），$\Delta W_t = B_t A_t$（任务专用适配）
  - 前向计算：$h = W_0 x + \Delta W_{\text{shared}} x + \Delta W_t x$
- **确定性路由（无路由网络）**：由于训练与推理时任务身份已知，共享 LoRA 始终激活，仅激活当前任务对应的专家 LoRA，其余专家保持非激活状态，避免路由网络开销。
- **LoRA 插入位置**：注意力模块的 q_proj、k_proj、v_proj、o_proj，以及前馈模块的 gate_proj、up_proj、down_proj。
- **任务内采样**：对分类与回归，将每个任务划分为模态组 $G_h$，定义 $M_h = \max_{g} |D_{h,g}|$，构造重采样集
  - $\tilde{D}_h = \bigcup_{g \in G_h} \text{Repeat}(D_{h,g}, M_h)$
  - 每组恰好贡献 $M_h$ 条记录（完整副本 + 带种子的打乱余数），全局固定种子打乱后物化为训练文件，使每个模态组在一个 epoch 内贡献相等。
- **两阶段训练**：
  - **Stage 1（联合多任务训练，5 epochs）**：骨干冻结，共享 LoRA 与全部 6 个任务专家 LoRA 在所有任务上联合优化。
  - **Stage 2（独立专家精调）**：从同一 Stage 1 终点出发，冻结骨干、共享 LoRA 及所有非目标专家，每次仅精调一个任务专家 $\phi_t$；分类/回归额外进行 **3 个 epoch** 的模态平衡重采样延续训练，其他 4 个任务仅用原始数据做初始精调。
  - **推理**：激活 Stage 1 学到的共享 LoRA + 对应任务专用适配器；按任务独立选择最佳检查点。

## 7. 优点

- **架构设计巧妙**：显式分离共享知识与任务专用适配，避免单一共享 LoRA 的表达瓶颈，也避免完全独立专家导致的知识无法迁移。
- **无需路由网络**：利用任务身份已知这一先验，实现确定性路由，减少参数与计算开销。
- **采样策略可复现**：任务内模态平衡重采样采用固定种子物化训练文件，区别于随机加权采样器，使有效数据分布可复现。
- **两阶段训练策略合理**：先联合学习共享表示，再冻结共享与非目标专家独立精调，兼顾知识共享与任务专业化。
- **实验报告诚实**：明确指出方法并非全任务领先，并给出失败任务的具体表现。
- **参数高效**：仅训练轻量 LoRA，骨干全程冻结，适合多任务临床部署场景。

## 8. 不足与局限

- **细粒度空间感知薄弱**：尽管 Stage 2 精调提升了检测，F1 仍低于最强竞争 VLM；自回归坐标生成对格式与定位的小误差敏感，IoU 阈值下可能整体失效。
- **部分任务性能下降**：公开多标签 F1 相对 vanilla MedGemma 有所下降；与最强基线相比，检测、多标签等任务并非最优。
- **采样策略依赖基准定义**：模态分组是基准特定的，迁移到新数据集时需重新定义，通用性受限。
- **验证划分覆盖不完整**：公开验证缺回归标签、隐藏验证缺报告生成与计数标签，导致部分任务无法在两个划分上同时评估。
- **基线调优公平性存疑**：未明确说明对比基线是否经过同等强度的适配调优。
- **未来方向**：结构化定位解码、区域感知适配器设计、面向异构医学数据的更通用采样策略。

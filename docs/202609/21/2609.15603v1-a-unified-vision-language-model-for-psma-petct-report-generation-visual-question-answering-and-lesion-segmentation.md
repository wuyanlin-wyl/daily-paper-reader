## 摘要
准确的PSMA PET/CT解读是前列腺癌管理的核心，但现有PET/CT AI模型通常仅处理孤立任务。我们提出一种统一的PSMA PET/CT视觉-语言模型，用于报告生成、视觉问答和病灶分割。该框架采用LLaVA风格架构，包含PET/CT视觉编码器、MLP-Mixer投影模块、经LoRA微调的大语言模型以及一个3D分割分支。训练遵循四阶段策略：视觉编码器预训练、投影层对齐、VLM微调以及最终的多任务调优。语言任务使用了5,747例带有配对报告的PSMA PET/CT数据集，而分割任务使用了AutoPET的PSMA子集。在标准报告生成指标上，该模型优于PET2REP和基于CT的基线；在各类VQA问题类型上性能均有提升；并且相比SegAnyPET和nnUNet取得了更高的Dice和病灶级重叠F1。这些结果支持了在单一多任务模型架构内实现结构化、交互式、可解释且具有体素级定位的PSMA PET/CT分析的统一框架的可行性。

## Abstract
Accurate PSMA PET/CT interpretation is central to prostate cancer management, yet existing PET/CT AI models typically address isolated tasks. We propose a unified PSMA PET/CT vision-language model for report generation, visual question answering, and lesion segmentation. The framework adopts an LLaVA-style architecture, comprising a PET/CT vision encoder, an MLP-Mixer projection module, a LoRA-tuned large language model, and a 3D segmentation branch. Training followed a four-stage strategy: vision encoder pretraining, projection-layer alignment, VLM fine-tuning, and final multitask tuning. Language tasks used 5,747 PSMA PET/CT datasets with paired reports, while segmentation used the PSMA subset of AutoPET. The model outperformed PET2REP and a CT-based baseline across standard report-generation metrics, improved performance across VQA question types, and achieved higher Dice and lesion-level overlap F1 than SegAnyPET and nnUNet. These results support the feasibility of a unified framework for structured, interactive, interpretable PSMA PET/CT analysis with voxel-level grounding within a single multitask model architecture.

## 2. 方法论

### 2.1 核心思想

采用**LLaVA风格**的统一多任务架构，将临床语言任务与体素级病灶分割整合在同一个指令驱动的框架中。模型通过任务特定提示（prompt）生成文本回答或病灶掩膜，实现"一个模型、多种输出"。

### 2.2 网络架构（四大组件）

- **3D PET/CT视觉编码器**：基于CLIP的3D视觉编码器，PET与CT作为两个通道输入，同时提供分子摄取信息和解剖上下文。
- **MLP-Mixer投影模块**：由于3D patch embedding产生远长于2D的token序列，采用MLP-Mixer进行通道混合与token混合，将视觉token压缩并对齐到LLM嵌入空间（压缩至512个token、维度2048）。其计算复杂度与输入patch数量呈线性关系，比直接线性投影更高效。
  - 公式：`U^T = W2σ(W1·LayerNorm(v_in^T))`，`T_v = W4σ(W3·LayerNorm(U))`，其中σ为GELU激活。
- **LoRA微调的大语言模型**：LoRA rank=128，参数高效微调，保留预训练语言能力。整体流程：`T_out = LLM(T_in + T_v)`。
- **语言条件3D分割模块**：nnUNet风格编码器-解码器。引入特殊`[SEG]` token，其最后一层隐藏状态被投影到分割特征空间，通过**交叉注意力**与nnUNet瓶颈特征融合（`[SEG]`为query，`z_s`为key/value），从而让分割分支聚焦于文本指定的目标。

### 2.3 四阶段训练策略

1. **视觉编码器预训练**：对比学习对齐3D图像特征与报告级文本表示。
2. **投影层对齐**：冻结视觉编码器和LLM，仅优化投影模块，使用自回归语言建模损失。
3. **VLM微调**：优化视觉编码器、投影层和LLM的LoRA参数，分割分支不更新。
4. **多任务调优**：混合指令联合优化VLM分支、`[SEG]`接口、交叉注意力融合模块和nnUNet分割分支；文本任务用自回归损失，分割任务用交叉熵+Dice损失。

### 2.4 辅助监督

使用**TotalSegmentator**从CT生成10类器官掩膜（肾、膀胱、肝、脾、脑、肺、心、前列腺、胃、唾液腺），作为辅助伪标签提供解剖上下文监督，帮助区分生理性PSMA摄取与可疑病灶。

### 2.5 VQA数据构建

采用类似CT-CHAT的报告衍生VQA生成策略，使用**Gemini-2.5-Pro API**生成三类问题（描述型、自由回答型、多选题），并通过**两步迭代验证**（生成→验证答案是否有报告证据支持）保证质量。

## 8. 不足与局限

- **数据集不配对**：报告生成与分割数据集在病例层面不配对，无法直接监督/评估"报告中提到的病灶"与"预测掩膜"之间的对应关系，句子级病灶 grounding 缺失。

- **缺少消融实验**：未量化各组件（MLP-Mixer、LoRA、交叉注意力、器官掩膜等）的独立贡献。
- **算力透明度不足**：未报告训练时长、GPU总时数等资源消耗信息。

- **临床验证缺失**：目前仅为回顾性、单中心为主的可行性研究，尚未进行多中心外部验证或真实临床部署评估。

## 摘要
手术器械分割（SIS）在机器人辅助和手术工作流分析中起着关键作用。然而，大多数现有 SIS 方法将分割表述为类别驱动的定位问题，限制了其捕获手术工作流中过程上下文和任务相关语义的能力。我们提出推理感知手术器械分割（RA-SIS），这是一种将分割建模为手术上下文下查询条件推理的任务形式。为了对该设定进行基准测试，我们构建了 SurgRS，一个由 41,000 个图像-文本对组成的手术推理分割数据集，它将实例级掩码与结构化查询-答案监督对齐，从而在像素级别实现语义定位。基于 SurgRS，我们提出手术器械推理与分割助手（SIRA），这是一个多模态框架，它解耦目标级和查询级语义，并通过查询锚定双重对齐将其与视觉特征融合。通过将查询语义与空间特征和分割提示对齐，SIRA 增强了掩码预测中的语义-视觉一致性。在 SurgRS 上的大量实验表明，其相较于现有推理感知基线有所提升。代码可在 https://github.com/linxir226/SIRA 获取。

## Abstract
Surgical instrument segmentation (SIS) plays a critical role in robotic assistance and surgical workflow analysis. However, most existing SIS methods formulate segmentation as a category-driven localization problem, limiting their ability to capture procedural context and task-dependent semantics in surgical workflows. We introduce Reasoning-Aware Surgical Instrument Segmentation (RA-SIS), a task formulation that frames segmentation as query-conditioned inference under surgical context. To benchmark this setting, we construct SurgRS, a surgical reasoning segmentation dataset consisting of 41,000 image-text pairs, which aligns instance-level masks with structured query-answer supervision to enable semantic grounding at the pixel level. Based on SurgRS, we propose Surgical Instrument Reasoning and Segmentation Assistant (SIRA), a multimodal framework that disentangles target-level and query-level semantics and integrates them with visual features through query-anchored dual alignment. By aligning query semantics with spatial features and segmentation prompts, SIRA enhances semantic-visual consistency in mask prediction. Extensive experiments on SurgRS demonstrate improvements over existing reasoning-aware baselines. Code is available at https://github.com/linxir226/SIRA.

# SIRA：基于查询锚定对齐的推理感知手术器械分割——论文总结

## 1. 核心问题与整体含义

- **研究背景**：手术器械分割（SIS）是机器人辅助手术与手术工作流分析的关键技术，用于导航、技能评估等场景。
- **核心问题**：现有 SIS 方法（如 CNN、Transformer、Mask2Former、SAM 系列，以及 SP-SAM、TP-SIS 等文本提示扩展）普遍将分割视为**类别驱动的定位问题**，主要依赖视觉外观匹配，文本仅作为辅助条件。
- **关键局限**：这些方法无法显式地将分割锚定到**手术流程中的程序性角色**或**任务相关上下文线索**。在真实手术中，外科医生是根据器械在特定手术阶段的功能角色（如"执行缝合的器械"、"维持暴露的器械"）来识别器械，而非直接使用类别名称。
- **整体含义**：论文提出 **RA-SIS（推理感知手术器械分割）** 这一新任务设定，将分割建模为**手术上下文下的查询条件推理**——模型必须先推断程序意图与上下文语义，再输出像素级掩码。这是首个显式建模任务驱动、上下文依赖查询的手术器械分割形式化工作。

## 2. 方法论

### 2.1 核心思想

- 将分割从"给定类别标签预测掩码"转变为"给定结构化推理查询，先理解程序意图再定位目标"。
- 通过**解耦目标级语义与查询级语义**，并利用**查询锚定双重对齐**将查询语义注入视觉特征与分割提示，增强语义-视觉一致性。

### 2.2 SurgRS 数据集构建

- **基础数据**：基于 SAR-RARP50 数据集（机器人辅助根治性前列腺切除术），使用其 RGB 帧、语义掩码与动作标注。
- **阶段一：实例级掩码精炼**
  - 剔除 201 个无有效目标的帧。
  - 设计**基于规则的分解策略（RBDS）**：对每个语义工具区域做连通分量分析，大分量保留为实例候选，因遮挡或细结构产生的小区域合并到语义最近的分量；多实例工具按相对位置与时间连续性分配角色。
  - 随后进行 **Supervisely 人工精炼（MR）**，修正合并区域、边界模糊与标注错误。
- **阶段二：结构化描述与推理查询生成**
  - 定义 **9 类推理查询类型**（外加 Other 类）：LT（主导工具）、SE（支持暴露）、SGT（缝合引导/张力）、PAI（程序动作推断）、NSI（下一步重要性）、NDL（近/深布局）、OR（遮挡关系）、PL（位置定位）、CR（常识引用）、OT（其他）。
  - 使用 **GPT-5-mini**，以 RGB 图像、标注叠加、可见器械类别、动作标注和器械功能常识提示为条件，联合生成临床自然的帧描述与 1–3 个查询-答案对。
  - **强制对齐约束**：每个答案必须用精确类别名引用对应分割目标，并附加 `<SEG>` 标记；所有查询-答案对均经人工核对。
- **规模**：约 16,000 张手术图像（1920×1080），约 41,000 个结构化图像-文本对，覆盖 20 个器械类别，超过 127,000 个实例级分割目标；按 4:1 划分训练/测试集。

### 2.3 SIRA 架构

- **整体组成**：多模态大语言模型（MLLM）+ 查询锚定双重对齐模块 + 基于 SAM2 的分割模型。
- **MLLM**：采用 **Chat-UniVi**，通过 **LoRA** 适配器进行手术领域适应。
- **输出三类内容**：
  - 来自 `<SEG>` token 的**目标级嵌入** $h_{seg} \in \mathbb{R}^{K \times d}$；
  - 来自 `<QUERY>` token 的**查询级嵌入** $h_{query} \in \mathbb{R}^{N_q \times d}$；
  - 解释性文本。

- **解耦语义编码**：
  - 现有方法仅用单一 `<SEG>` token 同时编码目标激活与查询推理，导致耦合不足。
  - 本文引入固定长度的 $N_q$ 个可学习 `<QUERY>` token，独立建模全局推理语义，实现目标级与查询级的显式解耦。

- **查询锚定双重对齐**：
  - **(1) 查询到视觉对齐（QVA）**：将 $h_{query}$ 通过 MLP 投影到视觉特征空间，经轻量 Transformer 块建模查询间依赖后，以空间特征为 query、查询嵌入为 key/value 做交叉注意力，得到查询条件化视觉特征 $\hat{F}_{seg}$。
  - **(2) 目标到查询对齐（TQA）**：将 $h_{seg}$ 投影到 SAM2 提示嵌入空间，再与查询表示做交叉注意力，使目标激活锚定于共享查询语义，得到 $\hat{h}_{seg}$。
  - QVA 与 TQA 共享同一解耦查询表示作为跨模态语义锚点。

- **训练目标**：
  - $L_{total} = \lambda_{bce} L_{bce} + \lambda_{dice} L_{dice} + \lambda_{txt} L_{txt}$
  - 其中 $L_{bce}$ 与 $L_{dice}$ 为掩码预测损失，$L_{txt}$ 为自回归文本生成交叉熵损失。
  - 对齐后的视觉特征与目标提示嵌入输入 SAM2 掩码解码器，每个目标生成一个二值掩码，天然支持单查询下的多目标预测。

## 3. 实验设计

- **数据集/场景**：在自建的 **SurgRS** 数据集上评估，仅聚焦根治性前列腺切除术场景。
- **Benchmark**：SurgRS 作为推理感知手术器械分割的基准，包含 20 类器械、约 41,000 图像-文本对、127,000+ 实例级目标。
- **对比方法**：四个最先进推理分割模型，均采用 7B 规模语言骨干以保证公平：
  - **LISA**
  - **GSVA**
  - **PathMR**
  - **VRS-HQ**（基于 SAM2 的强基准）
- **评估指标**：
  - **gIoU**（广义 IoU）
  - **cIoU**（完整 IoU）
  - **Dice** 系数（医学分割常用）
- **结果概览**：
  - SIRA 在所有整体指标和所有推理查询类型上均取得最优：
    - 整体：gIoU **72.24**、cIoU **81.78**、Dice **80.93**
    - 对比 VRS-HQ（70.79 / 80.60 / 79.61）、PathMR（66.42 / 75.14 / 76.25）、GSVA（65.30 / 75.08 / 74.39）、LISA（65.05 / 74.32 / 74.21）
- **定性结果**：在边界模糊、小尺度器械、低光照、罕见目标、运动模糊等挑战场景下，SIRA 掩码更完整、空间更连贯，减少了部分激活、遗漏与碎片化伪影。

- **批大小**：每 GPU batch size = 1，梯度累积 = 1，总 batch size = 2。

  - 训练对齐模块（ViT、交叉注意力、MLP 投影）与 SAM2 掩码解码器，冻结 SAM2 视觉骨干；

  - WarmupDecayLR 调度器，100 次预热迭代；
  - 训练 **10 个 epoch**（每 epoch 13,000 次迭代）；

## 5. 实验数量与充分性

- **主要对比实验**：1 组，在 SurgRS 上与 4 个基线方法对比，报告 3 项整体指标 + 9 类查询类型细分指标（含 OT 共 10 类）。
- **消融实验**：1 组，针对 QVA 与 TQA 两个模块的组合（4 种配置：基线、仅 TQA、仅 QVA、两者同时启用），报告 3 项指标。
- **定性实验**：1 组，展示多种挑战条件下的可视化对比。
- **充分性评估**：
  - **优点**：查询类型细分指标较细致，消融实验验证了两模块的互补性，定性分析覆盖多种困难场景。
  - **局限**：仅在单一数据集（SurgRS）上评估，未在 EndoVis-17/18、SAR-RARP50 原始任务或其他手术数据集上验证泛化性；消融维度较单一，未对 $N_q$、LoRA rank、损失权重等超参数做敏感性分析；基线数量为 4 个，未涵盖更多近期方法。

## 6. 主要结论与发现

- SIRA 在 SurgRS 上全面优于 LISA、GSVA、PathMR、VRS-HQ，验证了**查询锚定双重对齐**在推理感知手术器械分割中的有效性。
- QVA 与 TQA **互补**：单独启用任一模均可提升性能，QVA 增益略大，两者结合取得最佳结果。
- 解耦目标级与查询级语义，并将查询语义同时注入空间特征与分割提示，能显著增强**语义-视觉一致性**，提升复杂手术场景下的鲁棒性。
- 未来工作将把 RA-SIS 扩展到**基于视频的手术理解**，以应对时间一致性与运动动态带来的新挑战。

## 7. 优点

- **任务设定新颖**：首次将手术器械分割形式化为任务驱动、上下文依赖的查询条件推理，贴合真实手术中按功能角色识别器械的认知过程。
- **数据集贡献扎实**：SurgRS 规模较大（41,000 图文对、127,000+ 实例目标），构建流程包含规则分解 + 人工精炼 + GPT-5-mini 生成 + 人工核验，具有较好的标注质量与结构化监督。
- **查询分类体系临床相关**：9 类推理查询类型覆盖主导工具、暴露、缝合张力、动作推断、遮挡关系等真实手术推理技能。
- **架构设计合理**：显式解耦 `<SEG>` 与 `<QUERY>` token，并通过 QVA/TQA 双重对齐共享语义锚点，思路清晰、模块化程度高。
- **实验指标全面**：同时报告 gIoU、cIoU、Dice，并按查询类型细分，便于分析不同推理能力下的表现差异。
- **资源需求适中**：2 张 RTX 3090 即可完成训练，具备一定的可复现性与实用性。

## 8. 不足与局限

- **数据集覆盖有限**：SurgRS 仅基于 SAR-RARP50，聚焦机器人辅助根治性前列腺切除术，器械类别与场景多样性受限，结论向其他术式（如腹腔镜、胃肠手术）的泛化性未知。
- **仅图像级评估**：论文明确未来工作才扩展到视频，当前方法未利用时间信息，而手术场景中器械运动与遮挡具有强时序性。
- **数据生成依赖闭源模型**：查询-答案对由 GPT-5-mini 生成，虽经人工核验，但仍可能引入模型偏见或遗漏罕见但重要的临床推理情形。
- **对比基线有限**：仅对比 4 个方法，且部分基线并非专为手术场景设计，缺乏与更多近期手术专用推理分割方法的比较。
- **消融维度单一**：未对 $N_q$ 取值、LoRA rank、损失权重、对齐模块结构等关键超参数进行敏感性分析，也未分析不同 MLLM 或分割骨干的影响。
- **公平性隐忧**：SIRA 使用 SAM2 分割骨干，而部分基线可能使用不同分割架构，性能差异可能部分来源于骨干能力而非对齐机制本身。
- **临床落地限制**：推理查询类型依赖预定义分类，真实手术中查询形式可能更开放、更口语化，方法的开放世界泛化能力有待验证。

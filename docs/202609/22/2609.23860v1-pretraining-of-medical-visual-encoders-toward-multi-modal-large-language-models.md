## 摘要
多模态大语言模型（MLLMs）通常复用使用 CLIP 预训练的视觉编码器，尽管这些 ViT 的特征最终由自回归 LLM 使用。我们将这种不匹配称为语义-接口鸿沟，并引入 MedMLIP，一个通过冻结 LLM 进行报告生成来预训练视觉编码器的框架，同时采用局部关系蒸馏（LRD）来保留视觉图像块之间的关系，以避免视觉坍塌。我们在 IU-Xray 和 Open-PMC-300K 上预训练 MedMLIP，并在 VQA-RAD 和 SLAKE 上评估所得编码器。仅迁移 ViT，而引导 LLM 和投影器被替换，从而使我们能够评估跨 LLM 的可迁移性。我们的跨 LLM 迁移实验证明了为视觉编码器预训练其自回归 LLM 接口的价值，同时尝试保留更细粒度的视觉信息。代码和预训练模型可在 https://github.com/SkyCol/MedMLIP 获取。

## Abstract
Multimodal Large Language Models (MLLMs) commonly reuse visual encoders pretrained with CLIP, although the features of these ViTs are ultimately consumed by autoregressive LLMs. We refer to this mismatch as the semantic-interface gap and introduce MedMLIP, a framework that pretrains the visual encoder through report generation with a frozen LLM, while employing Local Relational Distillation (LRD) to preserve relationships among visual patches to avoid visual collapse. We pretrain MedMLIP on IU-Xray and Open-PMC-300K and evaluate the resulting encoders on VQA-RAD and SLAKE. Only the ViT is transferred, while the guiding LLM and projector are replaced, allowing us to assess cross-LLM transferability. Our cross-LLM transfer experiments demonstrate the value of pretraining visual encoders for their autoregressive LLM interface while trying to preserve more fine-grained visual information. Code and the pretrained model are available at https://github.com/SkyCol/MedMLIP

## 1. 核心问题与整体含义（研究动机与背景）

- **语义-接口鸿沟（semantic-interface gap）**：当前多模态大语言模型（MLLM）普遍直接复用 CLIP 预训练的 ViT 作为视觉编码器，但 CLIP 的优化目标是**对比式图文对齐**——视觉表示与一个成对文本编码器对齐；而在构建 MLLM 时，这个文本编码器被**丢弃**，视觉特征被投影进自回归 LLM 的嵌入空间。因此，视觉表示是为"跨模态相似度匹配"而学，而非为"LLM 的 token 级理解与生成"而学。
- **问题的本质不是"信息有没有"，而是"信息以什么形式表示"**：CLIP 编码器是否包含有用语义并非关键，关键是这些语义是否能被自回归 LLM 有效消费。
- **医学场景的放大效应**：医学推理既需要高层语义理解，又依赖细微、局部的视觉证据（小的局部病灶可能直接决定答案），因此接口不匹配的代价更高。
- **经验证据（来自 LLaVA-Med）**：在可比训练设置下，把通用 CLIP 换成 BioMedCLIP 视觉编码器，VQA-RAD/SLAKE/PathVQA 平均分从 73.90 提升到 75.40；SLAKE 开放式从 82.30→87.11，PathVQA 开放式从 37.59→39.60。说明**视觉表示的质量本身就能影响下游 MLLM 能力**。
- **但仅换域内对比编码器不够**：BioMedCLIP 等仍以对比对齐为优化目标，接口错配依旧存在。
- **由此提出核心研究问题**：能否**直接为视觉编码器在 MLLM 中的最终角色**进行预训练，同时保留医学任务所需的细粒度视觉证据？

## 2. 方法论

### 2.1 核心思想

MedMLIP（Medical Multimodal Language–Image Pretraining）通过**冻结 LLM 的报告生成任务**来优化视觉编码器，使其产出"LLM-ready"的视觉 token；同时用**局部关系蒸馏（LRD）**作为结构锚，防止语言级监督导致的视觉细节坍缩。目标是"让视觉编码器对 LLM 友好，而非更像语言、牺牲视觉感知"。

### 2.2 关键技术流程

- **预训练流程**：`x → Eθ → Pψ → Fϕ → y`
  - `Eθ`：可训练 ViT 视觉编码器；`Pψ`：视觉投影器；`Fϕ`：**冻结**的自回归 LLM。
  - 图像先编码为视觉特征 `Hθ = Eθ(x)`，再投影到 LLM 嵌入空间 `Vθ,ψ = Pψ(Hθ)`。
- **生成损失（自回归目标）**：
  - `Lgen = −Σ_{t=1}^{T} log pϕ( y_t | y_{<t}, Vθ,ψ )`
  - LLM 参数 ϕ 冻结，充当"语义解码器"；其预训练语言知识与临床文本先验提供结构化监督，梯度经投影器回传至 ViT，驱动视觉通路适配 LLM 期望的表示接口。
- **下游复用方式（跨 LLM 迁移协议）**：
  - `(x, q) → Eθ → P*ψ → F*ϕ → a`
  - **仅保留预训练 ViT**；投影器与 LLM 均被替换（上标 * 表示重新初始化）。更换投影器是因为不同 LLM 的 tokenizer、词表与隐藏维度不同。

### 2.3 局部关系蒸馏（LRD）

- **动机**：报告生成是语言级、较粗粒度的信号，会把编码器推向报告级语义，削弱 patch 级视觉区分度，作者称之为**语言诱导的视觉坍缩（language-induced visual collapse）**。
- **教师**：冻结的原始 CLIP ViT（不被报告生成目标更新，保留原始 patch 关系几何），也可替换为对学生做滑动平均的教师。
- **做法（不复制特征，只蒸馏关系几何）**：
  1. 取同一图像在教师与学生中**去掉 CLS token** 后的上下文 patch 特征 `H0`、`Hθ`；
  2. 对每个 patch 特征做 L2 归一化（仅用于计算 patch-to-patch 余弦关系）；
  3. 分别计算师生 patch 关系矩阵 `S0_ij = ⟨h̄0_i, h̄0_j⟩`、`Sθ_ij = ⟨h̄θ_i, h̄θ_j⟩`；
  4. **LRD 损失**：`L_LRD = 1/(P(P−1)) · Σ_{i≠j} ( Sθ_ij − sg(S0_ij) )²`，其中 `sg(·)` 为 stop-gradient，P 为 patch 数。
- **总目标**：`L = Lgen + λ·L_LRD`（λ 为权重，文中未给出具体取值或敏感性分析）。
- 因此模型同时优化两个互补属性：**与自回归 LLM 的兼容性**（报告生成）与**细粒度证据保留**（LRD）。

## 6. 主要结论与发现

- **MedMLIP 显著优于对比式预训练**：在四个配对比较中，完整 MedMLIP 相对 CLIP-style 对比预训练提升 2.53–7.14 点，平均约 **+4.40 点**。
  - VQA-RAD：Qwen0.5B→Qwen3B 方向，对比预训练 67.06% → MedMLIP 74.20%（+7.14）；相对原始 CLIP 提升 10.71 点。
  - Qwen3B→Qwen0.5B 方向：61.87% vs 57.14%（对比预训练）vs 55.15%（原始 CLIP）。
  - SLAKE：Qwen0.5B 下游 83.14%（比对比预训练 +2.53）；Qwen3B 下游 80.08%（+3.94）。
- **LRD 是关键且一致的增益来源**：加入 LRD 后四个设置全部提升，VQA-RAD 平均 +2.76 点、SLAKE 平均 +5.21 点，总体平均约 **+3.99 点**。**仅用 Lgen 时在 SLAKE 上甚至低于原始 CLIP**（76.68 vs 79.77；76.12 vs 83.98），说明纯自回归监督会损伤对下游仍有用的视觉结构，LRD 能把这种退化逆转或大幅收窄。

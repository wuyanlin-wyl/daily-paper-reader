## 摘要
大多数医学视觉-语言模型（VLM）在开放式报告生成和VQA方面表现出色，但在统一界面内对结构化、细粒度临床感知的支持有限。我们提出QwenVLConnector，一种基于Qwen2.5-VL的医学聊天机器人，在单一的下一个词元预测目标下统一了分类、多标签分类、文本化检测、计数、回归和自由形式报告生成。我们的关键组件是一个轻量级密集多层Connector，它聚合低层和高层视觉特征，通过预训练的视觉Merger进行对齐，并将它们与最终视觉表示融合，且不增加序列长度。该设计以互补的空间和语义线索丰富视觉token，同时保持高效性。在FLARE-2D上，QwenVLConnector将检测F1从0.55提升至0.85，将单标签分类从0.37提升至0.51，并将报告生成的GREEN较Qwen2.5-VL基线最多提升18.3个点。我们进一步探索用于报告生成的多模态上下文学习，在无需更新模型参数的情况下展现出额外提升。总体而言，QwenVLConnector为将结构化医学感知与开放式临床文本生成相结合提供了一个统一且高效的框架。我们的代码可在 https://github.com/plnguyen2908/QwenConnector 获取。

## Abstract
Most medical vision-language models (VLMs) excel at open-ended report generation and VQA but provide limited support for structured, fine-grained clinical perception within a unified interface. We present QwenVLConnector, a Qwen2.5-VL-based medical chatbot that unifies classification, multi-label classification, textualized detection, counting, regression, and free-form report generation under a single next-token objective. Our key component is a lightweight dense multi-layer Connector that aggregates low- and high-level visual features, aligns them through the pretrained vision Merger, and fuses them with the final visual representation without increasing sequence length. This design enriches visual tokens with complementary spatial and semantic cues while preserving efficiency. On FLARE-2D, QwenVLConnector improves detection F1 from 0.55 to 0.85, raises single-label classification from 0.37 to 0.51, and boosts report-generation GREEN by up to 18.3 points over the Qwen2.5-VL baseline. We further explore multimodal in-context learning for report generation, showing additional improvements without updating model parameters. Overall, QwenVLConnector offers a unified and efficient framework for combining structured medical perception with open-ended clinical text generation. Our code can be found at https://github.com/plnguyen2908/QwenConnector.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：医学视觉-语言模型（VLM）已从任务专用工具发展为可描述、推理并对话临床影像的助手。LLaVA-Med、HuatuoGPT-Vision 等系统在开放式报告生成和 VQA 上表现强劲。
- **核心问题**：现有医学 VLM 大多针对**文本生成**优化，回答流畅但缺乏临床医生日常所需的**结构化、细粒度感知**能力——检测、计数、回归——难以在单一对话界面内统一支持。
- **整体含义**：FLARE 2D 挑战（涵盖多模态、多任务类型）使这一缺口尤为突出。论文旨在构建一个**统一且高效**的医学 VLM 聊天机器人，在单一 next-token 目标下同时完成开放式文本生成与结构化临床感知任务。

## 2. 方法论

### 核心思想
- 基于 **Qwen2.5-VL** 架构，引入一个轻量级 **密集多层 Connector（QwenVLConnector）**，融合视觉编码器低层与高层特征，在不增加序列长度的前提下丰富视觉 token 的空间与语义线索。

### 关键技术细节
- **视觉编码器**：ViT，共 L=32 个 block；窗口注意力后第 ℓ 个 block 的隐状态为 h^(ℓ) ∈ R^(N×dv)，N 为视觉 token 数，dv 为 ViT 宽度。
- **编码器内置 Merger** 输出高维视觉 token Z0 ∈ R^(N×dm)，并被复用为映射 mμ 来对齐中间特征。
- **深度分组平均**：
  - G1 = {1,…,16}（偏边缘/纹理）
  - G2 = {17,…,32}（偏语义）
  - A1、A2 分别为两组特征的均值，∈ R^(N×dv)。
- **对齐与去置换**：每组特征经 Merger 对齐并做 P⁻¹ 去窗口置换（P 为窗口化引起的排列）。
- **通道级拼接与投影**：将 Z0、P⁻¹mμ(A1)、P⁻¹mμ(A2) 沿通道拼接（维度 3dm），经轻量 MLP cψ 投影到 LLM 嵌入维度 dt。
- **核心公式**：˜Z = cψ([Z0, P⁻¹mμ(A1), P⁻¹mμ(A2)])，输出 ˜Z ∈ R^(N×dt)，**token 长度仍为 N，不增加序列长度**。
- 融合后的视觉 token 前置于文本 token，由 decoder-only LLM 以自回归方式生成。

### 多模态上下文学习（ICL）
- 用于报告生成：从支持池 S 中均匀采样 k 个演示（图像-提示-回答三元组），拼接在用户查询前，**不更新模型权重**，仅通过条件化生成提升报告质量。

## 6. 主要结论与发现

- **检测显著提升**：F1 从 0.55 → **0.85**（8-bit，+0.30），4-bit +0.25，16-bit +0.28；8-bit 为效率-精度最佳点。
- **单标签分类提升**：从 0.37 → **0.51**（4-bit），8-bit +0.10，16-bit +0.15。
- **多标签分类略有下降但差距缩小**：Micro-F1 从 −0.08 缩小至 **−0.03**（16-bit 时 0.54 vs 0.57）。
- **报告生成提升**：GREEN 最高提升 **+18.28**（8-bit，55.77→74.05），4-bit +10.27，16-bit +0.15。
- **ICL 有效**：加入 k 个演示后，BLEU、GREEN Clinical Significance、GREEN Entity Matching、GREEN Score 一致提升，且无需更新参数。
- **仍未解决**：实例检测 F1 全为 0；回归 MAE 上升（+3.61~+5.94）；计数小幅下降。

## 7. 优点

- **统一框架**：在单一 next-token 接口下同时支持开放式生成与结构化感知（分类、多标签、检测、计数、回归），架构简洁。
- **高效设计**：密集多层 Connector 在不增加序列长度的前提下融合高低层视觉特征，符合挑战“快且高效”的要求。
- **量化友好**：在 4/8/16-bit 三种精度下均有提升，8-bit 呈现明显效率-精度折中优势。
- **无参数 ICL**：利用上下文示例提升报告生成质量，无需额外训练，具备实用潜力。
- **客观报告**：论文如实披露实例检测失败、回归退化等负面结果，并给出定性案例（超声分类与检测 IoU 0.70 vs 0.25）。

## 8. 不足与局限

- **实例级预测缺失**：文本化检测输出无法满足实例级评分协议，实例检测 F1 全为 0。
- **数值定位能力弱**：回归指标全面变差，计数仅有小幅改善（实际为轻微下降），纯数值目标仍是明显短板。
- **对量化/精度敏感**：不同 bit-width 下结果波动较大，最优设置因任务而异。
- **计算成本高**：三阶段训练总计 11 天 × 8×A40，训练仍属算力密集。
- **ICL 部署受限**：显著增加 prompt 长度与推理内存/延迟，因容器限制未在提交中启用，需进一步研究演示预算（demonstration budgeting）。
- **安全与一致性**：相对临床要求，安全/一致性检查仍然有限。
- **对比覆盖有限**：未与其他主流医学 VLM 直接比较，方法消融不足，外部泛化性证据偏弱。
- **未来方向**：探索更强的 Connector 架构以更有效融合多层视觉线索，在保持效率的同时增强结构化预测。

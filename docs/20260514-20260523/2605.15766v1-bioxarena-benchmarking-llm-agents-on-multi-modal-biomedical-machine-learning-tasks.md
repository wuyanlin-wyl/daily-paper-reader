## 摘要
大型语言模型（LLM）智能体在自动化机器学习开发的各个环节方面能力日益增强，然而现有的生物医学基准测试主要关注问答、推理和工具使用，或仅评估生物医学ML编码的狭窄方面。我们提出了BioXArena，这是一个生物医学机器学习基准测试，旨在评估智能体是否为异构和多模态生物医学数据集生成特定任务的模型训练流程。BioXArena包含9个领域的76项端到端任务，包括序列建模、单细胞分析、结构生物学、网络生物学、化学生物学、扰动动力学、表型-疾病建模、生物医学成像和文本整合学习。每项任务均从主要生物医学来源精心整理到一个统一的评估框架中，该框架具有隐藏标签、保留的评分器以及归一化到0到1尺度的生物学感知指标。智能体需要编写可执行代码、训练预测模型，并为私有测试样本生成提交。大多数任务涉及多种输入模态，包括表格数据、图像、自然语言、分子序列、组学矩阵和蛋白质结构。我们在标准化的2小时单GPU环境中评估了11种智能体配置。基于Gemini-3.1-Pro的MLEvolve取得了最高平均分0.666，其次是GPT-5.4的0.636，但没有一个智能体在所有领域都始终占据主导地位。此外，我们进行了广泛的消融研究、鲁棒性评估、扩展分析、成本分析和失败模式调查，以更好地理解模型骨干、智能体框架、推理预算和生物医学领域如何影响BioML编码性能。我们将公开发布所有基准任务、评分器、执行运行器、排行榜结果和智能体轨迹。

## Abstract
Large language model (LLM) agents are increasingly capable of automating components of machine learning development, yet existing biomedical benchmarks mainly focus on question answering, reasoning, and tool usage, or evaluate only narrow aspects of biomedical ML coding. We present BioXArena, a biomedical machine learning benchmark designed to evaluate whether agents can generate task-specific model training pipelines for heterogeneous and multi-modal biomedical datasets. BioXArena contains 76 end-to-end tasks across 9 domains, including sequence modeling, single-cell analysis, structural biology, network biology, chemical biology, perturbation dynamics, phenotype-disease modeling, biomedical imaging, and text-integrated learning. Each task is curated from primary biomedical sources into a unified evaluation framework with hidden labels, held-out graders, and biology-aware metrics normalized to a 0 to 1 scale. Agents are required to write executable code, train predictive models, and generate submissions for private test samples. Most tasks involve multiple input modalities, including tabular data, images, natural language, molecular sequences, omics matrices, and protein structures. We evaluate 11 agent configurations in a standardized 2-hour single-GPU environment. MLEvolve with Gemini-3.1-Pro achieves the highest average score of 0.666, followed by GPT-5.4 with 0.636, while no single agent consistently dominates across all domains. We additionally perform extensive ablation studies, robustness evaluations, scaling analyses, cost analyses, and failure-mode investigations to better understand how model backbones, agent scaffolds, inference budgets, and biomedical domains influence BioML coding performance. We will publicly release all benchmark tasks, graders, execution runners, leaderboard results, and agent trajectories.

### 2. 方法论

- **核心思想**：基准测试的核心原则是让LLM智能体通过**编写并运行代码**来解决生物医学机器学习（BioML）任务，训练一个预测模型并提交对私有测试集的预测结果，而不仅仅是给出分析答案或执行管道。

    - **专家策展**：任务由ML和生物学专家从顶级期刊、会议和公共数据库中筛选、清洗和预处理。

- **执行流程**：所有智能体在统一的**2小时墙钟时间、单GPU沙箱环境**中运行，通过一个提示模板接收任务路径，必须编写并执行 `solution.py`，生成符合格式的 `submission.csv`。

### 3. 实验设计

- **数据集/场景**：使用 BioXArena 自身构建的**76个任务**，数据来源于超过40个主要生物医学数据库和文献，如TCGA, GTEx, PDB, OpenProblems, TDC等。
- **基准对比**：评估了**11种智能体配置**，分为四类：
    - **7个通用LLM**（搭载于一个自定义的简朴代码提取-执行-修复循环框架）：GPT-5.4, Claude Opus 4.6, Gemini-3.1-Pro, Qwen3.6-Plus (闭源); GLM-5.1, Gemma-4-31B, DeepSeek-V3.2 (开源)。
    - **2个生物医学智能体**：Biomni (使用Claude Sonnet 4), STELLA (使用Claude Sonnet 4.6和Gemini-3.1-Pro混合配置)。

- **主要评估场景**：对所有11个代理在全部76个任务上进行了评测，以**惩罚后的全任务平均分**（失败任务记0分）为主要排名指标。

### 4. 资源与算力

- **GPU型号与数量**：每个任务使用**1块NVIDIA A100 GPU**，服务器节点配置为4×A100 GPU和64GB RAM。
- **运行时间**：每个智能体-任务对的核心执行时间限制为**2小时**的墙钟时间。所有实验（包括主实验和消融实验）的总集群时间**约为700 GPU小时**。

### 5. 实验数量与充分性

- **主实验**：1组，包含11种智能体配置在所有76个任务上的全面评估。实验设计客观、公平，所有代理在相同的硬件、时间限制和隐藏评估器下运行。
- **鲁棒性分析**：对最强（GPT-5.4）和最弱（DeepSeek-V3.2）的通用LLM各进行了**3次全任务重复实验**，以评估分数和成功/失败状态的方差。
- **能力扩展分析**：对MLEvolve进行了**时间预算扩展实验**，将2小时限制提升至**12小时**，在两个完整领域（化学生物学和表型-疾病）上运行。

- **人类专家基线**：邀请了2名博士级研究人员在没有AI辅助的情况下，用相同2小时预算完成了**10个随机抽样任务**，作为与最强4个智能体的性能对比。
- **分析与审计**：进行了详尽的领域级、任务级分析，统计了智能体**选择的ML模型类型**，进行了**失败模式分类**，并提供了**运行时间与API成本分析**。

### 6. 主要结论与发现

- **整体性能**：没有单一智能体在所有领域占据主导。基于Gemini-3.1-Pro的搜索型智能体 **MLEvolve 以66.6的最高惩罚平均分领先**，其后是GPT-5.4（63.6分）和STELLA（61.3分）。
- **执行可靠性是关键瓶颈**：大量的失败发生在模型评分之前，**52%的失败是由于根本没有生成有效提交文件**，其次是ID不匹配和无效数值等格式问题。这表明提升执行稳健性比提升模型本身质量更为迫切。
- **领域难度差异巨大**：化学生物学是最容易的领域（平均分0.77），而扰动动力学是现有技术下最难的领域（平均分0.42）。
- **骨干与框架的相互作用**：
    - **固定骨干时**，专门的智能体框架（如MLEvolve）优于简单的代码提取循环。
    - **改变骨干时**，一个更强的骨干LLM能带来比升级框架更大的性能提升，显示出**骨干模型能力仍然是主导因素**。
- **模型选择实用化**：成功的提交中，超过一半使用了提升树、随机森林等**传统机器学习方法**，神经网络模型在图像和序列等特定任务上才占主导，这表明高分智能体选择了现实而资源高效的建模方法。

### 7. 优点

- **设计全面且现实**：基准覆盖了9个广泛的生物医学领域，包含60%以上的多模态任务，数据格式异构且原生，非常贴近真实的生物医学ML研究场景。
- **评估方法严谨**：采用隐藏标签和统一离线评分，有效防止数据泄露。引入惩罚分数机制将对执行可靠性的评估纳入总分，更全面地衡量智能体能力。
- **实验分析深入**：实验设计远超简单的排行榜，包含了鲁棒性、扩展性、成本、消融、失败模式等多维度分析，提供了对智能体行为深刻、可操作的洞见。
- **公平对比框架**：所有智能体均在统一的2小时单GPU沙箱中测试，确保了对比的公平性。通过固定骨干的消融实验，巧妙地将框架设计与模型能力的影响解耦。

### 8. 不足与局限

- **领域覆盖非穷尽**：未能涵盖一些重要的生物医学数据类型，如空间组学、全切片病理、质谱流式等。76个任务也无法覆盖所有BioML子问题。
- **计算预算限制**：2小时的严格限制虽然务实，但对于需要多日训练的大型、工业级任务来说是不足的。此限制也可能让某些强搜索型智能体未能充分发挥潜力。
- **训练数据污染风险**：许多源数据集是公开的，可能已包含在LLM的训练语料库中，导致分数不能完全代表泛化能力，尽管论文已采取了重分数据集和代码轨迹审计等措施来缓解。
- **人类基线有限**：人类专家对比仅在10个任务的小子集上进行，且参与者数量少（2人），结论可能不具备广泛代表性。
- **临床部署限制**：基准分数仅代表智能体在计算评估中的表现，不能直接解读为临床诊断或治疗决策能力。

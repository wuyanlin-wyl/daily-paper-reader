## Abstract
Large Vision Language Models (LVLMs) show promise in medical applications, but their inability to faithfully ground responses in visual evidence raises serious concerns about clinical trustworthiness. While visual attribution methods are widely used to explain LVLM predictions, whether these explanations actually reflect the visual evidence underlying the model's decision is largely unverified, since ground-truth annotations for internal model reasoning are typically unavailable. We address this question for chest X-ray (CXR) reasoning by developing a causal evaluation framework that retains only CXR-VQA samples for which the expert-annotated region is verified, via counterfactual editing, to be causally responsible for the model's prediction. Using this framework across 11 attribution methods, six open-source LVLMs, and two output modes (direct answer and step-by-step reasoning), we find that existing attribution methods often fail to identify the evidence used by LVLMs. To address this failure, we propose MedFocus, a concept-based attribution method that localizes clinically meaningful anatomical regions via unbalanced optimal transport and measures their causal effect on model outputs through targeted interventions. MedFocus produces spatial, concept-level, and token-level attributions and substantially outperforms prior methods, taking a step toward more trustworthy attribution for medical LVLMs. Our data and code are available at https://github.com/gzxiong/medfocus/.

### 2. 论文提出的方法论

论文包含两大部分：一个用于**评估**归因方法的因果基准，以及一个用于**改进**归因效果的新方法。

#### 2.1 因果评估框架：MedGround-Bench
该框架的核心思想是，利用反事实编辑来筛选出模型预测与专家标注区域存在可靠因果联系的样本，以此作为评估归因方法的“真值”。

*   **数据构建**：从ImaGenome、VinDR-CXR等三个带有专家边界框标注的CXR数据集中，将标注结果重铸为二元视觉问答（VQA）问题，例如：“图像中是否存在心脏肥大的证据？”。
*   **三步因果过滤**：
    1.  **正确性过滤**：仅保留LVLM回答正确的问题。
    2.  **前景反事实编辑**：使用扩散模型 `RadEdit`，根据专家标注的边界框抹除框内区域（使目标属性消失），生成反事实图像。若模型在编辑后图像上答案翻转，则证明该区域内含有关键证据。
    3.  **背景反事实编辑**：对编辑区域（背景）进行反事实编辑，若模型答案不变，则进一步确证模型的决策变化仅由前景区域引起。
*   **结果**：经过严格筛选，得到一个包含3940个样本的基准数据集 `MedGround-Bench`，每个样本的专家标注区域均被验证为模型预测的因果证据。

#### 2.2 基于概念的归因方法：MedFocus
为了解决现有方法的失败，作者提出了一种面向临床可解释性的新归因方法。

*   **核心思想**：将模型输出归因于具有临床意义的解剖结构（如“左肺”、“心脏轮廓”），而非无意义的像素区域。
*   **关键技术细节与流程**：
    1.  **概念分割 (Concept Segmentation)**：
        *   **不平衡最优传输 (UOT) 映射**：首先，利用UOT算法将一张带有已知解剖结构标注的“参考”CXR图像上的概念区域映射到“目标”图像上。UOT的优势在于它能容忍病理变化导致的两张图像在组织分布上的“不平衡”。
        *   **掩膜优化**：将UOT映射得到的粗略区域输入医学分割基础模型 `MedSAM`，生成精细、干净的概念掩膜 `Mc`。
    2.  **因果归因 (Causal Attribution)**：
        *   **概念干预**：针对每个解剖概念 `c`，通过将该概念区域的边界框替换为零值（`˜xc`）来生成反事实干预图像。
        *   **测量输出变化**：将干预后的图像输入LVLM，计算模型对原始输出序列的令牌级对数概率的累积下降量 `∆c`。这一设计巧妙地衡量了该概念对模型产生当前输出的因果贡献，避免了重新生成文本的噪声。
    3.  **多层级归因输出**：`MedFocus` 最终输出三种形式的归因：
        *   **空间归因**：导致最大因果效应 `c*` 的解剖区域的边界框。
        *   **概念级归因**：该区域的临床名称（如“心脏轮廓”）。
        *   **令牌级归因**：在推理模式下，可视化推理过程中哪些单词受到概念干预的影响最大。

*   **现有方法普遍失败**：在严格的因果基准测试下，主流的视觉归因方法（包括广泛使用的 GradCAM、Integrated Gradients 等）都无法可靠地识别LVLM在医学影像推理中真正使用的视觉证据。它们要么给出过于弥散的高亮区域，要么错失了关键证据。

*   **模型与推理模式的影响**：
    -   医学专用模型（如MedGemma）比通用模型的视觉归因忠实度更高。
    -   逐步推理模式下，模型的归因效果普遍优于直接回答模式，显示出思维链对视觉证伪过程的积极作用。

*   **开创性的评估框架**：提出的 `MedGround-Bench` 是首个利用反事实因果逻辑来验证归因方法忠实度的基准，解决了领域内缺乏真实归因标准的核心痛点。其构建思路（三步过滤）非常严谨。
*   **方法创新性强**：`MedFocus` 巧妙地将“临床概念”作为中介，结合不平衡最优传输和因果干预，把黑盒归因问题转化为对临床可解释单元的因果效应度量。这一思路新颖且合理。
*   **可解释性输出**：提供空间、概念和令牌级多层级归因，特别是令牌级归因，能够分析推理过程中模型对不同证据的逐步依赖，解释深度远超简单的热力图。
*   **实验扎实全面**：在多个模型、数据集、任务模式上与大量基线方法进行了详尽的比较，并通过全面的消融实验和敏感性分析证实了方法设计的有效性和鲁棒性。

### 8. 不足与局限

*   **模态与任务的局限性**：研究聚焦于胸部X光片（CXR）和二元VQA任务。这是因为该模态同时具备专家空间标注和区域级反事实编辑工具两个必要条件。对于CT、MRI等其他医学模态及更复杂的报告生成等任务，该框架的推广受到现有工具的限制。
*   **概念词汇表的依赖**：`MedFocus`的归因粒度完全依赖于预定义的解剖概念集（11个ImaGenome区域）。对于弥漫性病变、极小病灶或超出此词汇表的异常发现，其精细定位能力受限。方法本身虽然可以扩展词汇表，但当前实验并未涉及。

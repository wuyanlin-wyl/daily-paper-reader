## 摘要
医学时间序列（MedTS）支撑着许多临床分类任务，然而现有方法通常仅将其表示为数值序列，未能充分利用波形观察中显式呈现的形态学信息。为弥合这一差距，我们提出了视觉信息引导的检索（ViRe），它使用冻结的VLM派生波形表示作为形态感知查询，以引导从原始数值MedTS特征中进行检索。具体而言，使用预训练的视觉-语言模型（VLM）提取视觉查询，以从波形图中获得形态感知先验。随后，一种定制的基于注意力的跨模态检索机制利用该视觉查询，从数值表示中选择与形态相关的时间与通道证据。ViRe在十个已有基线上展现出显著有效性，在六个公开基准上相比此前最先进方法总体相对提升6.42%。代码、训练脚本和可复现性材料已在GitHub仓库公开：https://github.com/Levi-Ackman/ViRe。

## Abstract
Medical time series (MedTS) underpin many clinical classification tasks, yet existing methods usually represent them only as numerical sequences and underuse the morphology that is explicit in waveform inspection. To bridge this gap, we introduce Vision-Informed Retrieval (ViRe), which uses a frozen VLM-derived waveform representation as a morphology-aware Query to guide retrieval from raw numerical MedTS features. Specifically, a Vision Query is extracted using pre-trained vision-language models (VLMs) to obtain morphology-aware priors from waveform plots. A tailored attention-based cross-modal retrieval mechanism then uses the Vision Query to select morphology-relevant temporal and channel evidence from the numerical representation. ViRe demonstrates strong effectiveness against ten established baselines, yielding an overall 6.42% relative improvement over the previous state of the art across six public benchmarks. Code, training scripts, and reproducibility materials are publicly available in the GitHub Repository: https://github.com/Levi-Ackman/ViRe.

## 1. 核心问题与整体含义

- **关键机会**：视觉-语言模型（如 CLIP）的视觉编码器经大规模图文预训练，能把图像组织到与人类可描述概念对齐的空间中。将波形图输入冻结的 CLIP 视觉编码器，可获得紧凑的、形态感知的先验。
- **整体含义**：论文提出 **ViRe（Vision-Informed Retrieval）**，用视觉先验"重塑并增强"从原始数值信号学到的 MedTS 表示，弥合"模型怎么看"与"医生怎么看"之间的差距。

## 2. 方法论

### 2.1 核心思想：非对称双路径 + 视觉查询检索

- **双视图**：(i) 数值视图由时间序列 Transformer 建模；(ii) 波形视图由**冻结的 CLIP 视觉编码器**编码。
- **关键设计**：视觉嵌入不作为独立诊断通路，而是作为**全局 Vision Query（Q）**，去检索数值序列中的时序与通道证据；所有 Key/Value 均保持为数值 token。即"视觉选择检索什么证据，但不成为独立诊断路径"。

### 2.2 关键技术细节

- **问题定义**：输入 $X \in \mathbb{R}^{T \times C}$，预测标签 $\hat{Y} \in \mathbb{R}^{K}$。
- **数值建模（双轴 token 化）**：
  - **Temporal embedding**：将信号按长度 $L$ 切分为非重叠段，每段跨所有通道展平为一个 token，共 $P=\lceil T/L \rceil$ 个 token，加位置嵌入得到 $U \in \mathbb{R}^{P \times D}$。
  - **Channel embedding**：将每个通道整条轨迹聚合成一个 token，共 $C$ 个 token，加位置嵌入得到 $V \in \mathbb{R}^{C \times D}$。
  - 两个独立 Transformer Encoder 分别输出时序特征 $\bar{U}$ 和通道特征 $\bar{V}$。
- **Vision Query**：
  - 用**确定性可视化算子** $V(\cdot)$ 把同一 $X$ 渲染为堆叠波形图 $I = V(X) \in \mathbb{R}^{H \times W \times 3}$（每通道独立面板、固定坐标轴、去除刻度/边框/图例/网格，再纵向拼接）。
  - 冻结 CLIP 视觉编码器提取 $Z = f_{CLIP}(I)$，经维度对齐层投影到共享隐空间，得到 $\bar{Z} \in \mathbb{R}^{D}$ 作为全局 Vision Query。
- **跨模态对齐（非对称交叉注意力）**：
  - 将 Vision Query 重塑为 $Q \in \mathbb{R}^{1 \times D}$；$\bar{U}$、$\bar{V}$ 分别作为 Key/Value。
  - $e_U = \text{CrossAttn}(Q, \bar{U}, \bar{U})$，$e_V = \text{CrossAttn}(Q, \bar{V}, \bar{V})$。
  - 融合：$O = e_U + e_V$，再线性投影得到 logits $\hat{Y} = OW_y + b_y$。
- **训练**：CLIP 全程冻结，仅训练数值编码器、维度对齐层、两个检索块和分类器；损失为标准交叉熵。训练时每次只施加一种增强（时域翻转、通道打乱、时域/频域掩码、抖动、dropout），且增强同步作用于信号与其渲染图；验证/测试仅用确定性渲染。
- **理论支撑（附录 A）**：
  - **Lemma 1**：交叉注意力可通过 $W_Q=0$ 退化为均值池化。
  - **Theorem 1**：ViRe 的假设类包含均值池化数值模型，故经验风险 $\leq$ 纯数值模型。
  - **Proposition 1**：若 $I(Y;\bar{Z}|S)>0$，则加入视觉表示后贝叶斯风险下降。
  - **Proposition 2**：注意力权重构成由 Vision Query 与数值 token 共同索引的样本自适应池化规则。

- **整体性能**：6 个基准平均 Avg 达 **82.90**，Medformer 为 77.90，相对提升 **6.42%**；在 5/6 数据集上排名第一，PTB-XL 排名第二（69.47，仅低于 PatchTST 的 69.90 约 0.43 分）。
- **最大增益**：APAVA 从 79.74 提升到 92.79（+16.37%）；ADFTD +9.52%、PTB +5.18%、MIMIC +4.06%、TDBrain +3.95%。
- **增益来源**：Vision Query 是主要贡献（平均 +7.72%），远高于 Zero（+1.92%）和 Gaussian（+0.76%）；交叉注意力检索（+7.72%）优于简单 Add（+4.05%）和 Concat（+3.02%）。

- **数据效率**：视觉先验在所有训练集比例下均提升 F1，且在标注有限时增益最大。
- **表示质量**：Vision Query 检索到的特征聚类 DBI 最低、NMI/Homogeneity/Completeness 最高；t-SNE 显示类间分离更好；Vision Query 位于表示流形最密区域附近，而非离群点。

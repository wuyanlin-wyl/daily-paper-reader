## 摘要
长视觉 token 序列通常占多模态大语言模型（MLLMs）计算开销的很大一部分。现有方法通过剪枝冗余视觉 token 来降低这一开销，但会永久丢弃可能在后续层中有用的视觉证据。我们转而探究：是否能在保留所有视觉 token 的同时，降低通过 Transformer 反复演化其表示的成本？为回答这一问题，我们对视觉到文本的信息流进行低秩干预。我们发现，在阻断视觉到文本注意力后，仅恢复少数几个方向即可找回大部分丢失的准确率，这表明相关的视觉影响集中在一个低维子空间中。我们进一步观察到，逐层视觉状态具有很强的可预测性：轻量级 MLP 能以高余弦相似度和低重建误差对其进行近似。受这些发现启发，我们提出 $δ$-Vision，它用轻量级低秩适配器替代视觉 token 在 Transformer 中的反复演化，构建逐层视觉记忆，同时保留所有视觉 token 以供文本检索。在图像和视频基准上，$δ$-Vision 在相当或更低计算量下取得了比视觉 token 剪枝基线更高的准确率，同时在不丢弃视觉 token 的情况下提供有竞争力的推理效率。

## Abstract
Long visual token sequences often account for a substantial fraction of the computational overhead in multimodal large language models~(MLLMs). Existing approaches reduce this cost by pruning redundant visual tokens, but permanently discard visual evidence that may become useful in subsequent layers. We instead ask whether all visual tokens can be preserved while reducing the cost of repeatedly evolving the representations through the Transformer. To answer this question, we perform low-rank interventions on visual-to-text information flow. We find that, after visual-to-text attention is blocked, restoring only a few directions recovers most of the lost accuracy, suggesting the relevant visual influence is concentrated in a low-dimensional subspace. We further observe strong predictability in layer-specific visual states: lightweight MLPs approximate them with high cosine similarity and low reconstruction error. Motivated by these findings, we propose $δ$-Vision, which replaces repeated Transformer evolution of visual tokens with lightweight low-rank adapters that construct layer-wise visual memories while preserving all visual tokens for text retrieval. Across image and video benchmarks, $δ$-Vision achieves higher accuracy than visual token pruning baselines at comparable or lower computation, while delivering competitive inference efficiency without discarding visual tokens.

# 论文总结：Just MLPs: Efficient Visual State Reconstruction for Multimodal Language Models

## 1. 核心问题与整体含义

- **研究动机**：多模态大语言模型（MLLMs）在处理高分辨率图像和视频时，会产生极长的视觉 token 序列。这些视觉 token 需要在内部 LLM 的每一层 Transformer 中参与自注意力与前馈计算，导致计算开销随层数线性放大。
- **现有方案的局限**：主流方法（如 FastV、VisionZip、DivPrune 等）通过剪枝冗余视觉 token 来缩短序列长度。但剪枝是**不可逆**的——一旦某个视觉 token 被丢弃，后续层便永久失去该视觉证据，可能损害需要细粒度视觉信息的推理任务。
- **本文的核心问题**：能否**保留全部视觉 token**，同时降低它们在 Transformer 中逐层反复演化的计算成本？
- **整体含义**：论文提出一条与序列长度压缩**互补的效率轴**——在隐藏通道维度上压缩视觉状态的构建过程，而非减少视觉 token 的数量。这为 MLLM 高效推理提供了新的方向。

## 2. 方法论

### 2.1 核心思想

- 通过对视觉到文本信息流的**低秩干预**实验发现：
  - 阻断视觉到文本注意力后，仅恢复少数几个方向即可找回大部分准确率，说明关键视觉影响集中在**低维子空间**。
  - 逐层视觉状态具有**强可预测性**：轻量级 MLP（d→d→d）能以高余弦相似度和低重建误差近似 Transformer 演化后的视觉状态。
- 据此提出 **δ-Vision**：用轻量级低秩适配器替代视觉 token 在 Transformer 中的反复演化，为每一层构建视觉记忆，同时保留所有视觉 token 供文本检索。

### 2.2 关键技术细节

**（1）逐层视觉记忆预测**

将第 $l$ 层的视觉记忆参数化为全维度的残差修正：

$$A_l(X) = X + \Delta_l(X), \quad \Delta_l(X) = \phi(XD_l)U_l$$

- $D_l \in \mathbb{R}^{d \times r}$ 为下投影矩阵，$U_l \in \mathbb{R}^{r \times d}$ 为上投影矩阵，$r \ll d$ 为瓶颈维度；
- $\phi(\cdot)$ 为 SiLU 激活函数；
- $U_l$ 初始化为零，使 $A_l$ 初始为恒等映射；
- 残差更新 $\Delta_l(X)$ 位于 $U_l$ 张成的子空间内，秩不超过 $r$，但输出仍为完整 $d$ 维表示。

**（2）两种适配器变体**

- **Embedding Adapter（嵌入适配器）**：直接从初始视觉嵌入预测每层记忆
  $$M_l = A_l(E) = E + \Delta_l(E)$$
  各层记忆在给定 $E$ 的条件下相互独立，可并行构建。
- **Recurrent Adapter（循环适配器）**：通过逐层低维修正构建视觉记忆轨迹
  $$M_0 = E, \quad M_l = A_l(M_{l-1}) = M_{l-1} + \Delta_l(M_{l-1})$$
  保留显式的层间状态，是对视觉状态演化的轻量近似。

**（3）视觉记忆作为只读上下文**

- 预测的视觉记忆 $M_l$ 经原始冻结的 LayerNorm 和 K/V 投影生成视觉键值：
  $$K_{v_l} = W_{K,l}\,\text{LN}_l(M_l), \quad V_{v_l} = W_{V,l}\,\text{LN}_l(M_l)$$
- 文本 token 按原始 Transformer 计算生成 $Q_t, K_t, V_t$，然后与视觉记忆拼接进行联合注意力：
  $$O_{t_l} = \text{Attn}(Q_{t_l}, [K_{v_l}; K_{t_l}], [V_{v_l}; V_{t_l}])$$
- **省略**了视觉 query、视觉注意力输出和视觉 FFN 更新；$M_l$ 不被文本注意力更新，用完即弃，下一层记忆由适配器直接生成。

**（4）训练目标**

- 冻结视觉编码器、多模态投影器和 LLM 主干，**仅优化视觉记忆适配器**；
- 采用 **Supervised-KD**（监督知识蒸馏）：原始 MLLM 为教师，δ-Vision 为学生；
- 最小化教师与学生在答案 token 位置上的前向 KL 散度：
  $$\mathcal{L}_{KD} = \frac{1}{|\Omega|}\sum_{t \in \Omega} D_{KL}(p_T(\cdot | I, x_{1:T}, y_{<t}) \,\|\, p_S(\cdot | I, x_{1:T}, y_{<t}))$$

## 6. 主要结论与发现

- **核心发现**：保留全部视觉 token 的前提下，用轻量低秩适配器重建逐层视觉状态，可在隐藏通道维度上有效

降低视觉计算成本，且性能优于或接近主流 token 剪枝方法。

- **性能表现**：
  - 在 Qwen3-VL-4B 上，δ-Vision 在 20% 保留率下平均分接近原始模型，显著优于 FastV、VisionZip、SparseVLM、DART、DivPrune、ZOO-Prune 等免训练剪枝方法；
  - 在 5% 极端保留率下优势更为明显，说明当视觉 token 被大幅压缩、剪枝方法损失细粒度证据时，δ-Vision 的"全 token 保留 + 状态重建"策略更能维持推理能力；
  - 在多图像（MuirBench）与视频（Video-MME、MVBench）任务上同样保持竞争力，验证了方法的跨任务泛化性。
- **跨骨干结论**：
  - 在 Qwen3-VL-30B-A3B（MoE）与 Qwen3.5-4B 上，δ-Vision 仍能有效恢复性能，说明适配器机制不依赖于单一架构；
  - 在 LLaVA-1.5-7B 等骨干上，δ-Vision 与 DivPrune 表现互有胜负，提示其收益与骨干的视觉-语言融合方式、视觉 token 冗余程度相关。
- **效率结论**：
  - 由于省略了视觉 query、视觉注意力输出与视觉 FFN 更新，δ-Vision 在 prefill 与 decode 阶段均获得加速；
  - FLOPs 与峰值内存随保留率下降而显著降低，在 Video-MME 上实现了可观的总加速比，证明"通道维度压缩"确实能转化为实际推理收益。
- **机制性发现**：
  - 低秩干预实验表明，视觉到文本的信息流可由极少方向（rank-32 至 rank-128）承载，且首层与中间层的可压缩性强于尾部层；
  - 视觉计算谱分析显示视觉状态演化具有低有效秩（$r_{95}$ 较小）的结构特征，为低秩适配器提供了理论依据；
  - 逐层适配器跳过实验表明，并非所有层都同等重要，中间层适配器对性能贡献最大；
  - 在混合注意力骨干（Gated DeltaNet）上的读写干预分析进一步支持了"视觉状态可预测"的假设。
- **与剪枝的兼容性**：δ-Vision 可与 DART、DivPrune 等剪枝方法叠加使用，在进一步压缩序列长度的同时保持较高准确率，说明两者作用于互补的效率轴。

## 7. 局限性与潜在问题

- **训练依赖**：δ-Vision 需要为每个骨干单独训练适配器，且依赖教师模型进行知识蒸馏，相比免训练剪枝方法部署成本更高。
- **骨干相关性**：在部分骨干（如 LLaVA 系列）上相对 DivPrune 的优势不稳定，方法的普适性仍需更多验证。
- **硬件信息缺失**：论文未报告 GPU 型号与显存占用细节，效率结论的可复现性与横向可比性受到一定限制。
- **秩与层选择**：瓶颈秩 $r$ 与适配器层选择对性能影响较大，论文虽给出消融，但未提供自动化的秩/层配置策略。
- **评测覆盖**：主实验集中于 Qwen3-VL-4B，30B 级 MoE 与其他骨干的结论主要位于附录，主表证据强度有限。

## 8. 总体评价与启发

- **贡献定位**：论文提出了一条与 token 剪枝正交的效率优化路径——在隐藏通道维度重建视觉状态，而非削减视觉 token 数量，为 MLLM 高效推理提供了新视角。
- **方法优雅性**：以零初始化的低秩残差适配器近似逐层视觉演化，设计简洁、训练目标清晰（Supervised-KD），且天然兼容现有剪枝方法。
- **实证价值**：跨任务、跨骨干、多保留率的实验矩阵较为完整，机制分析（低秩干预、谱结构）增强了结论的可信度与解释性。
- **启发**：视觉 token 的"数量"与"逐层演化成本"是两个可独立优化的维度；未来工作可探索适配器的跨骨干迁移、自适应秩分配，以及与其他模态（如音频、点云）状态重建的结合。

## 摘要
测试时训练（TTT）在传统微调不可行时，使模型适应传入的测试样本（例如分布外（OOD）样本）。现有面向视觉语言模型（VLM）的 TTT 方法从多个增强视图构造监督，每个视图都需要对整个 VLM 进行一次前向（且常常还有后向）传播，带来大量计算成本。我们观察到，一次包含所有中间层输出的前向传播所产生的信号，已远多于所有增强视图的最终嵌入。我们提出层查询网络（LQN），一种轻量级方法，可通过一个小模型（学生）在 VLM 的单次前向传播中适配冻结的 VLM（教师）。LQN 使用位置感知蒸馏（PAD），通过查询中间 token 的空间坐标来模仿教师 VLM 的中间层空间 token。LQN 还依赖位置一致性正则化（LCR），一种自监督技术，用 O(1) 坐标采样替代昂贵的 O(H×W) 图像增强。综合这些，LQN：i) 在 OOD ImageNet 上对零样本 CLIP ViT-B/16 进行适配，并提升 9.8% Top-1；ii) 在细粒度分类上以 3.9% Top-1 超越此前最佳的 GS-Bias；iii) 对于 CLIP ResNet-50，比 TPS 收敛更快（47 分钟 vs 55 分钟）；iv) 将适配泛化到 SigLIP、EVA-CLIP 和 CoCa 等 VLM，以及 MLP、ResNet、VGG 等轻量级学生模型；v) 扩展到全景、实例和语义分割。

## Abstract
Test-Time Training (TTT) adapts models to incoming test samples (e.g. out-of-distribution, (OOD)) when conventional fine-tuning is infeasible. Existing TTT methods for Vision-Language Models (VLMs) create supervision from several augmented views, each requiring forward (and often backward) passes through the entire VLM, incurring substantial computational cost. We observe that one forward pass with all the intermediate layer outputs already yields far more signal than the final embedding from all augmentations. We introduce Layer Query Network (LQN), a lightweight approach that can adapt a frozen VLM (teacher) in a single forward pass of the VLM via a small model (student). LQN uses Position-Aware Distillation (PAD) to mimic the teacher VLM's intermediate-layer spatial tokens by querying spatial coordinates of intermediate tokens. LQN additionally relies on Location Consistency Regularization (LCR), a self-supervision technique, replacing expensive O(H x W) image augmentation with O(1) coordinate sampling. Integrating these, LQN i) adapts and improves zero-shot CLIP ViT-B/16 by 9.8% Top-1 on OOD ImageNet, ii) outperforms the previous best GS-Bias on fine-grained classification by 3.9% Top-1, iii) achieves faster convergence than TPS for CLIP ResNet-50 (47 mins vs 55 mins), iv) generalizes adaptation to VLMs like SigLIP, EVA-CLIP, and CoCa, and lightweight students like MLP, ResNet, VGG, and v) extends to panoptic, instance, and semantic segmentation.

## 1. 核心问题与研究动机

- **背景**：CLIP 等视觉语言模型（VLM）虽具备强大的零样本泛化能力，但在分布偏移（OOD）场景下性能显著下降。
- **现有方案的困境**：
  - 参数高效微调（Adapter、LoRA、VPT 等）需要**带标注的目标域数据**，现实中难以满足。
  - 测试时自适应（TTA）依赖**多个测试样本**（缓存历史样本）来稳定预测，在数据受限场景（如医学诊断）中不适用。
  - 测试时训练（TTT，如 TPT、TPS）只需**单个测试样本**，但需对每张图的**多个增强视图**分别做完整 VLM 前向（甚至反向）传播，计算开销巨大。
- **核心观察（论文切入点）**：一次前向传播产生的**所有中间层空间 token（L 层 × H×W × D 的 3D 隐状态体）**，其蕴含的信号远多于"所有增强视图的最终嵌入"。
- **整体含义**：论文主张"信号本就存在于 VLM 内部"，无需增强即可实现高效 TTT，从而在性能、收敛速度与任务泛化性之间取得更优平衡。

## 2. 方法论：Layer Query Network (LQN)

### 2.1 核心思想
- 采用**教师-学生蒸馏**框架：教师为**冻结的 VLM**（如 CLIP），学生为**轻量级小网络**（约 25M 参数）。
- 学生仅在**一次教师前向传播**的基础上，用 N 次迭代（默认 N=15）在单张 OOD 测试样本上适配，避免对整个 VLM 反复前向/反向。
- 关键抽象：把教师中间特征视为以 **3D 坐标 (i, j, l)**（空间位置 i,j + 层深 l）寻址的"隐状态体"，学生成为**坐标条件化的查询网络**。

### 2.2 关键技术细节

**（1）学生网络输入**
- 输入测试图像 `x_ood`、源坐标 `src`、目标坐标 `dest`。
- 坐标经 **3D RoPE 位置编码** `P(i,j,l)` 编码，并拼接一个常量正弦"标志" `P_T` 以区分 src / dest：
  `src = [P_{is,js,ls} | P_T[0]]`，`dest = [P_{id,jd,ld} | P_T[1]]`

**（2）位置感知蒸馏（PAD）**
- 从教师所有 L 层空间 token `Y^{1..L}_img ∈ R^{H×W×L×D}` 中**均匀随机采样**目标坐标 `(id, jd, ld)`。
- 学生以固定 src=(0,0,0) 学习模仿该位置的教师特征，损失为**余弦损失**：
  `L_PAD = 1 − cos⟨S_img(src, dest, x_ood), Y_img[id,jd,ld]⟩`
- 与经典逐层蒸馏不同，PAD **不需要教师-学生块间一一对应**，一个共享网络即可拟合所有层。

**（3）位置一致性正则化（LCR）**
- 自监督目标：对同一 `dest`，采样两个不同的 `src1`、`src2`，要求学生输出一致：
  `L_LCR = 1 − cos⟨S_img(src1,dest,x), S_img(src2,dest,x)⟩ − ⟨log‖w_src‖² + ε⟩`
- 用 **O(1) 坐标采样**替代 **O(H×W) 图像增强**，同时减少对 OOD 样本上可能不可靠的教师输出的盲目依赖。
- 末尾的正则项防止 `w_src → 0` 的平凡解（即忽略 src），ε=1e-7，上限截断 0.7。

**（4）总损失与推理**
- `Loss = L_PAD + α·L_LCR`（α 按数据集网格搜索，多数为 0.7）。
- 推理阶段：固定 src=(0,0,0)，对最后一层 L 的所有 (i,j) 位置查询，空间平均得到 `Y^{Student}_img`，再与教师文本嵌入 `Y_text` 做点积分类；分割任务则直接送入冻结的 mask head。
- **每次测试样本后重置学生权重**，防止跨样本信息泄漏。

### 2.3 算法流程（Algorithm 1 概述）
1. 教师提取所有层图像特征 `Y^{1..L}_img` 与文本特征 `Y_text`；
2. 随机初始化学生；
3. 循环 N 次：采样 dest → 计算 PAD 损失；采样 src1、src2 → 计算 LCR 损失 → 更新学生；
4. 对最后一层所有空间位置查询并平均，与文本特征点积得到分类预测。

## 6. 主要结论与发现

1. **单次前向即可高效适配**：无需任何图像增强，LQN 在 1 次 VLM 前向 + 轻量学生迭代下即可超越依赖多视图的 TTT 方法。
2. **中间层蒸馏优于仅蒸馏最终嵌入**：随蒸馏位置增多，性能持续提升（Fig 5(ii)），验证"信号在层内"的假设。
3. **可外推到未见层**：仅用前 20 层训练，推理到第 24 层性能仍从 56.2 升至 60.3，说明坐标条件化学生具备层间外推能力。
4. **坐标一致性可替代增强**：LCR 以 O(1) 代价提供自监督，减少对 OOD 上不可靠教师的依赖。
5. **广泛泛化**：可适配 SigLIP、EVA-CLIP、CoCa 等教师，MLP/ResNet/VGG 等学生，以及分类、全景/实例/语义分割多任务。

- **实验相对充分**：消融维度全面，含 FLOPs、墙钟时间、显存、边缘设备延迟等实用指标。
- **附加价值**：补充材料展示了在 ImageNet-C、CIFAR-10-C、医学数据、Vision Mamba、重复纹理等场景下的有效性。

## 8. 不足与局限

- **逐样本迭代开销**：虽比 TPT 便宜，但每张测试图仍需 N=15 次学生反向与中间特征存储，作者也承认可通过 top-k token 选择与特征压缩进一步优化。
- **超参数敏感**：α 按数据集分别网格搜索（0.5–0.8），迭代次数 N 存在峰值（N=15 最优，N=25 明显下降），实际部署需调参。
- **视频/流式场景未验证**：论文仅在单帧静态图像上做 TTT，作者将流式视频适配列为未来工作。
- **教师-学生同步调优未涉及**：明确声明教师与学生并行更新不在本文范围。
- **潜在风险**：LQN 与教师可能形成"递归互相学习"，作者提出需要研究其理论性能上限与安全对齐问题；伦理上不应用于监控、操纵或欺骗性内容生成。
- **算力细节不完整**：SSL 预训练（LQN-Pretrained）的算力与时长未披露；部分大规模数据训练的影响未知。
- **对比公平性**：部分 TTA 方法对比置于补充材料，主线表格中 TTA 与 TTT 混排可能影响直观比较。

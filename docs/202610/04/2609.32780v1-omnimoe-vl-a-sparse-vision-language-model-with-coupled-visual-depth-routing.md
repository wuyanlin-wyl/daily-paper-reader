## 摘要
视觉-语言模型（VLM）越来越多地使用稀疏混合专家（MoE）来扩展语言侧计算，但视觉信息通常仅在经过固定的跨模态接口之后才被路由。这留下了一个尚未解决的重要决策：对于给定问题，应当将哪些中间视觉表示暴露给语言计算？我们提出了 OmniMoE-VL，一种带有耦合视觉-深度路由投影器的稀疏 VLM。对于每个图像-提示对，该投影器选择一组稀疏的中间视觉深度，并复用由此得到的全局偏好来指导局部图像块融合以及向语言模型中的动态视觉注入。该设计在保留原生视觉 token 序列的同时，实现了取决于问题的视觉访问，并补充了视觉与语言栈中的 token 级专家路由。在八个基于图像的基准上，OmniMoE-VL 以 28B 总参数和 9B 激活参数取得了 85.9 的平均分数。受控比较表明，路由视觉接口带来了主要的架构增益，而匹配的路由与组件控制、同图路由分析以及路由干预进一步支持了耦合和问题条件化视觉访问的价值。

## Abstract
Vision-language models (VLMs) increasingly use sparse mixture-of-experts (MoE) to scale language-side computation, yet visual information is typically routed only after passing through a fixed cross-modal interface. This leaves an important decision unresolved: which intermediate visual representations should be exposed to language computation for a given question? We introduce OmniMoE-VL, a sparse VLM with a coupled visual-depth routed projector. For each image-prompt pair, the projector selects a sparse set of intermediate visual depths and reuses the resulting global preference to guide both local patch fusion and dynamic visual injection into the language model. This design enables question-dependent visual access while preserving the native visual-token sequence, and complements token-level expert routing in the vision and language stacks. Across eight image-based benchmarks, OmniMoE-VL achieves an average score of 85.9 with 28B total and 9B activated parameters. Controlled comparisons show that the routed visual interface provides the dominant architectural gain, while matched route and component controls, same-image route analysis, and route interventions further support the value of coupling and question-conditioned visual access.

# OmniMoE-VL 论文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言模型（VLM）越来越多地采用稀疏混合专家（MoE）来扩展语言侧计算，通过将 token 分配给少量参数专家实现容量-计算权衡。
- **关键瓶颈**：视觉信息通常只在经过一个**固定的跨模态接口（投影器）之后**才被路由。语言路由器可以决定如何处理已暴露的视觉 token，却**无法恢复接口处未被暴露的视觉流**。
- **未解决的决策**：对于给定问题，究竟哪些**中间视觉表示**应被暴露给语言计算？不同编码器深度承载不同证据——浅层保留局部外观与文字细节，中层将相邻 patch 组织为物体，深层提供更广的上下文结构。
- **后果**：密集投影器或固定视觉流在语言路由器看到表示之前就已合并了深度轴；即使视觉 token 被前置到首个 LLM 块，仍属于"后投影路由"问题，源深度决策已经做出。
- **下游两个目的地**：投影器将融合后的视觉 patch 送入语言模型输入序列；深度视觉注入则向中间语言状态补充信息。若二者独立选择深度，同一图像-问题对可能在两条通路上强调不同的视觉证据。

## 2. 方法论

### 2.1 核心思想
- OmniMoE-VL = **token 级视觉/语言专家** + **样本级视觉深度投影器**。
- 对每个图像-提示对，投影器选择一组稀疏的中间视觉深度，并复用一个**全局偏好 w** 同时指导局部 patch 融合与动态语言层注入，保持原生视觉 token 序列不变。

### 2.2 关键技术细节
- **视觉深度采样**：从视觉编码器 blocks 1, 5, 9, …, 37（即 π(s)=1+4(s−1)）提取 S=10 个流，patch 位置对齐。
- **提示条件化查询参与**：
  - 学习一个 Q=16 的原型库 C，对提示嵌入 H_T 做交叉注意力，得到原型 q_i 及参与权重 p。
  - 公式：`p = (1 − Q·ε_q)·softmax(u(x_T)) + ε_q·1`，ε_q=10⁻⁴ 保证每个原型可用。
  - 长度自适应目标：`n_eff(p) = 1/Σp_i²`，损失 `L_q = (n_eff(p) − n_tgt(L_T))²`，其中 `n_tgt = clip(log(1+L_T)+4, 2, Q)`；提示越长，参与目标越大。
  - 通过 `α_ri = softmax_i(M_ri + log p_i / τ_q)`（τ_q=0.9）混合出 R=8 个 router 查询。
- **全局深度选择**：
  - 深度特定投影 `Ṽ_s = P_s(V_s)`，评分网络计算每个深度的分数 d_s，`w = TopKSoftmax_4(r/T)`（top-4，其余置零）。
  - **早期训练探索**：用 EMA 使用统计 c_s，经高斯核 `K_ij = e^{−(i−j)²/γ}` 平滑得到历史先验 p̄，并加入欠使用 bonus b_s；探索 12,000 步后禁用，评估时仅由内容分数决定路由。
- **局部 patch 融合**：
  - 将 patch 划分为连续 32 个 token 的组 B_b。
  - 局部权重：`g_b = TopKSoftmax_4( ⟨v_{b,s}, t̄⟩/τ_g + log max(w_s, ε_w) )`，τ_g=0.7，ε_w=10⁻¹²。
  - 融合：`Z_Bb = LN( Σ_s g_{b,s} Ṽ_{s,Bb} )`，拼接各组恢复原始 patch 序列。
  - 全局先验决定深度偏好，局部兼容性在不同 patch 组间调整；`log(g_i/g_j) = log(w̄_i/w̄_j) + (c_i−c_j)/τ_g`。
- **路由视觉注入**：
  - 注意力分别从提示和视觉流构造方向 U(x_T) 与 B_s(x_V)，系数 β_s 由配对方向相似度决定。
  - 变换 `T_s(x) = B_s(x_V) diag(β_s) U(x_T)^T`，秩 r_T=32。
  - 学习秩 32 的适配器 G_{a(s)}，按固定锚点 a(s)=s 映射到语言层 1…10。
  - 更新：`δ_{ℓ,t} = η_{ℓ,t} A_ℓ(x) h_{ℓ,t}`，`H_{ℓ+1} = Φ_ℓ(H_ℓ + ∆_ℓ)`，其中 A_ℓ 由**同一个 w_s** 加权，与融合共享深度偏好。
- **梯度耦合**：两条通路都通过语言建模损失训练 w，`∇_w L_LM = J^T_{Z,w} ∇_Z L_LM + Σ_ℓ J^T_{A_ℓ,w} ∇_{A_ℓ} L_LM`。

## 4. 主要结果与分析

- **整体表现**：OmniMoE-VL 在八个基准上相对同规模密集基线（Qwen3-VL-8B-Instruct、Qwen2.5-VL-7B）取得一致提升，并在多学科推理（MMMU）与文档/图表类（DocVQA、ChartQA、OCRBench）上优势更明显——这与"深度选择可召回浅层文字细节与中层物体结构"的动机一致。
- **与稀疏模型对比**：相比激活参数更多的 Step-3（321B/38B），以更小的激活规模达到可比或更优的若干指标；相比 MoE-LLaVA、EvoMoE，在公共 recipe 下投影器变体即可带来增益，说明收益主要来自**投影前的深度决策**而非单纯参数扩容。
- **栈放置消融**：LLM-only MoE → LLM+Projector MoE 的增益集中在文字识别与幻觉抑制；进一步加入 Depth-Injection 后，MMMU、ChartQA 等需要跨深度证据整合的任务提升最大，表明两条通路互补而非冗余。
- **路由粒度**：token 级深度选择显著弱于样本级——token 级选择在 patch 组间引入噪声，破坏同一物体跨 patch 的一致性；随机/均匀深度加权接近密集基线，验证了内容驱动稀疏选择的必要性。
- **深度集合**：固定单深度普遍劣于多深度稀疏组合；更密的深度网格带来递减收益并增加计算，1+4(s−1) 的 10 流设置在成本-收益上最均衡。
- **共享 w vs 独立路由**：独立路由导致融合与注入强调不同深度，性能低于共享 w 的版本，支持"同一图像-问题对应在两条通路共享一致的视觉证据偏好"的设计假设。
- **提示条件化参与**：去除长度自适应目标后，长提示样本的参与度坍塌到少数原型，MMMU/ChartQA 长链推理样本退化最明显；说明 n_eff 约束是维持长提示路由覆盖的关键。
- **探索机制**：禁用早期探索会造成部分深度长期欠使用、w 熵偏低，最终基准分数略降；探索期结束后关闭 bonus 不影响评估稳定性。
- **诊断观察**：w 在样本间呈现明显分化（不同问题类型偏好不同深度带），融合权重 g_b 在同一图像不同 patch 组间确有调整（如文字区域偏浅层、物体区域偏中层），注入强度 η_{ℓ,t} 随语言层加深而衰减。

## 5. 贡献与意义

- 将"跨模态接口"从固定投影器重新表述为**可学习的、样本级的视觉深度路由问题**，指出源深度决策发生在语言路由之前这一被忽视的顺序性事实。
- 提出用**单一全局偏好 w** 耦合局部 patch 融合与动态语言层注入，使两条视觉信息通路共享证据选择，并给出可端到端训练的梯度耦合形式。
- 在 16.2M 指令数据、SigLIP2-Giant + Qwen3-8B 配置下给出完整验证，并通过公共 recipe 对比证明收益可迁移至既有 MoE-LLaVA/EvoMoE 配方。

## 6. 局限与展望

- 深度采样为固定步长的均匀网格，未探索内容自适应的非均匀深度搜索。
- 原型库规模 Q=16 与 Top-K=4 为经验设定，更大规模提示下的参与度标定仍依赖手工的 n_tgt 曲线。
- 早期探索依赖 EMA 统计与人工设定的 12,000 步退出点，缺少自适应停止准则。
- 评估限于八个基准与 8B 级语言模型，未验证在更大语言骨干与视频/多图输入下的可扩展性；视频时序上的"深度"维度是否同样成立尚待检验。

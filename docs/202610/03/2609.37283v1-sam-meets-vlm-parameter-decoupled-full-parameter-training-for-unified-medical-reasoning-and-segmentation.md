## 摘要
医学多模态大语言模型（MLLMs）正日益被期望不仅能够回答临床问题，还能够定位其预测背后的视觉证据。一种常见策略通过特殊的 <SEG> 标记将视觉-语言模型（VLM）与 SAM 风格的分割相连接，但对该统一架构进行全参数训练十分困难，因为图像级推理与像素级分割对共享表示空间提出了不同的要求。为解决这一问题，我们提出了一种用于统一医学推理与分割的参数解耦训练框架。该框架将 <SEG> 隐藏状态视为掩码解码器的语义到空间提示，并促使其与通用语言状态可分离，从而减少模糊的分割提示以及对推理表示的潜在干扰。它首先进行医学浅层对齐，在不干扰 LLM 的情况下使视觉特征适应临床语言；然后通过受控指令微调塑造可分离的 <SEG> 提示状态，并以 Davies-Bouldin 指数（DBI）进行监测，同时缩放进入语言主干的分割梯度；最后，在冻结 VLM 的情况下对 SAM 分支进行专门化，以提高掩码精度而不改变推理参数。在医学指代分割、定位、视觉问答和文本问答基准上的实验表明，我们的框架在保持有竞争力的推理能力的同时，实现了强大的语言条件分割。消融实验表明，两阶段指令微调、梯度缩放和分割专门化都对模型有贡献。

## Abstract
Medical multimodal large language models (MLLMs) are increasingly expected not only to answer clinical questions, but also to localize the visual evidence behind their predictions. A common strategy connects a vision--language model (VLM) with SAM-style segmentation through a special <SEG> token, yet full-parameter training of this unified architecture is difficult because image-level reasoning and pixel-level segmentation impose different requirements on the shared representation space. To address this issue, we propose a parameter-decoupled training framework for unified medical reasoning and segmentation. The framework treats the <SEG> hidden state as a semantic-to-spatial prompt for the mask decoder and encourages it to become separable from generic language states, reducing ambiguous segmentation prompts and potential disruption to reasoning representations. It first performs medical shallow alignment to adapt visual features to clinical language without disturbing the LLM; then controlled instruction tuning shapes separable <SEG> prompt states, monitored by the Davies--Bouldin Index (DBI), while scaling segmentation gradients entering the language backbone; finally, the SAM branch is specialized with the VLM frozen to improve mask precision without altering reasoning parameters. Experiments on medical referring segmentation, grounding, visual QA, and textual QA benchmarks show that our framework achieves strong language-conditioned segmentation while preserving competitive reasoning ability. Ablations show that two-phase instruction tuning, gradient scaling, and segmentation specialization all contribute to the model.

## 1. 核心问题与研究动机

- **背景**：医学多模态大语言模型（MLLMs）不仅需回答临床问题，还需定位预测背后的视觉证据（病灶、解剖结构等），即同时支持图像级推理与像素级分割。
- **主流方案**：借鉴 LISA、GLaMM，通过特殊 `<SEG>` token 将 VLM 与 SAM 风格分割器连接，`<SEG>` 的隐状态经投影后作为隐式分割提示送入掩码解码器。
- **核心矛盾**：图像级推理偏好高层语义抽象，像素级分割需要细粒度空间线索与稳定提示。两者在同一共享表示空间中联合优化时，会把表示拉向不兼容的视觉细节层级，导致分割提示歧义、掩码不稳定，并干扰语言推理表示。
- **已有工作的局限**：MIMO、UniBioMed 采用 LoRA/adapter 调优规避梯度干扰；MedPLIB 采用独立预测头。但**全参数训练**下如何学习表达性强的分割提示而不侵蚀医学视觉-语言推理能力，仍是一个开放问题。
- **本文定位**：不把 `<SEG>` 当作被动接口，而是显式监测并正则化其隐状态分布，使其成为稳定、可被 SAM 寻址的提示空间；提出三阶段参数解耦训练框架。

## 2. 方法论

### 2.1 统一架构

- 骨干：Qwen2.5-VL（7B/32B）+ SAM2 分割头，经轻量投影模块连接。
- 输入医学图像 x 与文本指令 t，VLM 生成 token 序列；需要分割时 LLM 生成 `<SEG>` token，其最终层隐状态 \(h^{(seg)} \in \mathbb{R}^d\) 投影为隐式提示，送入 SAM2 解码器生成掩码。
- 其他输出（VQA 答案、诊断文本）经标准语言头生成。

### 2.2 训练干扰分析

- 两类干扰：
  1. 密集分割损失与语言生成损失在尺度和频率上差异大；
  2. `<SEG>` token 需同时兼容 LLM 隐空间并成为 SAM 的信息性空间提示，若与通用语言 token 纠缠，SAM 收到模糊提示。
- 监测手段：对验证集分割样本收集 `<SEG>` 最终层隐状态，按目标解剖/任务标签分组，计算 **Davies–Bouldin Index（DBI）**。DBI 越低表示类内越紧凑、类间越分离。DBI **仅用于监控与阶段选择，不参与反向传播**。
- 图 2 显示训练推进中 `<SEG>` 隐状态更可分离，DBI 从 3.75 降至 1.75。

### 2.3 三阶段参数解耦训练（Algorithm 1）

- **Stage 1：医学浅层对齐**
  - 动机：通用视觉预训练与医学图像存在域差（纹理、对比度、视角、模态伪影）。
  - 做法：冻结大部分参数，仅更新视觉编码器与投影器；LLM 与 SAM 冻结；使用大量图像-描述对。
  - 目的：在不让语言主干和 SAM 受噪声/稀疏掩码梯度影响的前提下，建立医学视觉-文本基础。

- **Stage 2, Phase I：结构化状态分离**
  - 用标准分割指令任务损失训练，**不优化聚类损失，不把 DBI 纳入目标**。
  - 每轮后在留出验证集上计算 DBI，按解剖/任务类标签分组，计算各类质心仅用于度量分离度。
  - DBI 公式：\(\text{DBI} = \frac{1}{K}\sum_{i=1}^{K}\max_{j\neq i}\frac{\sigma_i+\sigma_j}{d(c_i,c_j)}\)，其中 \(\sigma_k\) 为类内平均距离，\(d(c_i,c_j)\) 为质心欧氏距离。

- **DBI 引导的阶段转换**
  - 当验证集 DBI < 1.9 时从 Phase I 转入 Phase II；该阈值对应 `<SEG>` 状态空间可见分离，通常 2–4 个 epoch 达到。

- **Stage 2, Phase II：正则化协同训练**
  - 所有 MLLM 参数联合优化。
  - 对从 `<SEG>` 投影接口流入 LLM 主干的分割梯度乘以缩放因子 \(\gamma_{seg}=0.01\)；语言建模损失与 SAM 编码器/解码器更新不缩放。
  - 联合损失：\(\mathcal{L}_{II} = \lambda_1 \mathcal{L}_{per\text{-}token} + \lambda_2 \mathcal{L}_{Dice} + \lambda_3 \mathcal{L}_{BCE}\)，其中 \(\lambda_1=1, \lambda_2=2, \lambda_3=1\)。

- **Stage 3：分割增强**
  - 冻结整个 MLLM，仅微调 SAM2 分割模块，使用额外分割数据。
  - 目的：让掩码解码器适应医学图像外观（模态纹理、低对比边界、小结构），提升边界精度而不扰动已建立的语义接口与推理能力。
  - **无额外推理开销**：测试时单次前向传播。

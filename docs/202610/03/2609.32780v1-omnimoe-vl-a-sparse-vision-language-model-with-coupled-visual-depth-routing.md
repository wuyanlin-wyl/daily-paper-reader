## 摘要
视觉语言模型（VLM）越来越多地使用稀疏专家混合（MoE）来扩展语言侧计算，但视觉信息通常只有在经过固定的跨模态接口之后才会被路由。这留下了一个尚未解决的重要决策：对于给定问题，哪些中间视觉表征应被暴露给语言计算？我们提出 OmniMoE-VL，一种带有耦合视觉-深度路由投影器的稀疏 VLM。对于每个图像-提示对，该投影器选择一组稀疏的中间视觉深度，并复用由此得到的全局偏好来指导局部图像块融合以及向语言模型中的动态视觉注入。该设计在保留原生视觉 token 序列的同时，实现了依赖问题的视觉访问，并补充了视觉与语言栈中的 token 级专家路由。在八个基于图像的基准上，OmniMoE-VL 以 28B 总参数和 9B 激活参数取得 85.9 的平均分。受控比较表明，路由式视觉接口提供了主要的架构增益，而匹配的路由与组件对照、同图路由分析以及路由干预进一步支持了耦合和问题条件化视觉访问的价值。

## Abstract
Vision-language models (VLMs) increasingly use sparse mixture-of-experts (MoE) to scale language-side computation, yet visual information is typically routed only after passing through a fixed cross-modal interface. This leaves an important decision unresolved: which intermediate visual representations should be exposed to language computation for a given question? We introduce OmniMoE-VL, a sparse VLM with a coupled visual-depth routed projector. For each image-prompt pair, the projector selects a sparse set of intermediate visual depths and reuses the resulting global preference to guide both local patch fusion and dynamic visual injection into the language model. This design enables question-dependent visual access while preserving the native visual-token sequence, and complements token-level expert routing in the vision and language stacks. Across eight image-based benchmarks, OmniMoE-VL achieves an average score of 85.9 with 28B total and 9B activated parameters. Controlled comparisons show that the routed visual interface provides the dominant architectural gain, while matched route and component controls, same-image route analysis, and route interventions further support the value of coupling and question-conditioned visual access.

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）通过多模态接口把视觉编码器接到语言模型上；近期工作（MoE-LLaVA、EvoMoE）用稀疏专家混合（MoE）在**语言侧**扩展容量，实现"容量—计算"解耦。
- **被忽视的瓶颈**：视觉信息通常**只在经过固定的跨模态接口之后**才被路由。也就是说，"哪些中间视觉表征应被暴露给语言计算"这一决策，在语言路由器启动之前就已被接口固定下来。
- **为什么这很重要**：视觉编码器不同深度的信息性质不同——浅层保留局部外观与文字细节，中层把邻近 patch 组织成物体，深层提供更广的上下文结构。稠密投影器或单一固定视觉流会把这条"深度轴"提前合并掉。
- **不可恢复性**：即使把视觉 token 前置到第一个 LLM block 之前，本质上仍是"投影后路由"（post-projection routing）：语言路由器能决定**如何处理**这些 token，但无法找回**未被暴露**的视觉流。
- **额外难点**：问题依赖的源访问有两个下游目的地——（1）投影器把对齐的视觉 patch 融合进语言模型输入序列；（2）深层视觉注入为中间语言状态补充信息。若两者独立选深度，同一图像—问题对可能强调不同视觉证据，造成不一致。
- **论文主张**：应要求一个**共享的全局深度偏好**，再让每个目的地做各自需要的操作，从而把"源访问决策"显式化，作为稀疏 VLM 中独立于 token 级专家路由的第二条条件计算轴。

## 2. 方法论

### 2.1 整体架构
- **模型组成**：token 级的视觉专家 + 语言专家（参数专家 MoE），外加一个**样本级视觉深度投影器**。
- **流抽取**：从视觉编码器 block 1, 5, 9, …, 37（即 π(s)=1+4(s−1)）抽取 **S=10 个中间视觉流**，patch 位置对齐。
- **统一符号**：对图像—提示对 x=(x_V, x_T)，投影器输出融合后的视觉 token Z(x) 与语言层变换 A_ℓ(x)，二者共享同一路由 w(x)：

  - Z(x) = P(V_{1:S}, H_T; w(x))
  - A_ℓ(x) = Σ_{s: a(s)=ℓ} w_s(x) G_ℓ T_s(x)
  - 固定锚点 a(s)=s，即第 s 个流注入第 s 个语言层。

### 2.2 提示条件查询参与（Query Participation）
- 学习一个查询银行 C ∈ R^{Q×d}（Q=16），对提示嵌入 H_T 做交叉注意力，得到 16 个提示条件原型 q_i 及参与权重 p_i；残差 ρC 保留每个种子的贡献，概率下限 ε_q=10⁻⁴ 保证所有原型可用。
- **长度自适应目标**：用有效参与数 n_eff(p)=1/Σp_i²，损失 L_q=(n_eff(p)−n_tgt(L_T))²，其中 n_tgt=clip(log(1+L_T)+4, 2, Q)——提示越长，允许参与的原型越多，但银行容量固定。
- **8 个 router query**：α_ri=softmax_i(M_ri + log p_i / τ_q)，τ_q=0.9，t_r=Σ_i α_ri q_i。

### 2.3 全局深度选择与局部块融合
- 每个流先投影到语言宽度（Ṽ_s = P_s(V_s)），打分网络给出深度分数 d_s(x)，r_s=f_s(d_s(x))；推理时 **w = TopKSoftmax₄(r/T)**（10 选 4 的稀疏全局路由）。
- **早期训练探索机制**：对历史使用率 c 做高斯核平滑（K_ij=e^{−(i−j)²/γ}）得到有序先验 p̄，再加欠使用奖励 b_s(c)：z_s = r_s/T + λ_h log p̄_s + b_s(c)。探索结束后与评测时全部关闭，仅由内容分数决定路由。
- **局部 patch 融合**：把 patch 分成 32 个连续 token 的组 B_b，组内均值 v_{b,s} 与文本均值 t̄ 计算局部兼容性，并叠加全局先验：

  g_b = TopKSoftmax₄( ⟨v_{b,s}, t̄⟩/τ_g + log max(w_s, ε_w) )，τ_g=0.7，ε_w=10⁻¹²
  Z_{B_b} = LN( Σ_s g_{b,s} Ṽ_{s,B_b} )

  拼接各组即恢复原生 patch 序列（576 token 进、576 token 出），语言输入长度不增加。
- **解析形式**：对局部 top-k 保留的两个深度，log(g_{b,i}/g_{b,j}) = log(w̄_i/w̄_j) + (c_{b,i}−c_{b,j})/τ_g——共享先验设定深度偏好，局部兼容性按 patch 组做调整。

### 2.4 路由式视觉注入
- 提示侧注意力得到方向 U(x_T)∈R^{d×r_T}，每个流侧注意力得到 B_s(x_V)∈R^{d×r_T}（r_T=32）；配对相似度给出系数 β_s，构造 T_s(x)=B_s diag(β_s) U^T。
- 学习一个 rank-32 适配器 G_{a(s)} 把残差映射到指定语言层，并用**同一个 w_s** 加权：
  δ_{ℓ,t} = η_{ℓ,t} A_ℓ(x) h_{ℓ,t}，H_{ℓ+1} = Φ_ℓ(H_ℓ + Δ_ℓ)
- η 综合注入增益、token 类型权重（视觉 token 为 1，文本 token 为 0.25）与残差范数控制；因式分解避免 d×d 稠密矩阵。
- **梯度耦合**：∇_w L = J^T_{Z,w} ∇_Z L + Σ_ℓ J^T_{A_ℓ,w} ∇_{A_ℓ} L——两条视觉通路都通过语言建模损失训练同一路由。

### 2.5 容量与计算
- 融合只读一次视觉编码器前向的 10 个流，深度选择**改变特征而非延长语言输入**。
- 注入成本 O(L d (r_T + r_G))，每锚点复合秩 ≤ min(r_T, r_G)=32。
- 总参数 28B，激活 9B；存储覆盖完整专家池。

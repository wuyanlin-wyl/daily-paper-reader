### 1. A Human-in-the-Loop Framework for Efficient Prompt Selection in Microscopy Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.20495v1
- 方法流程：
  - 初始化：从训练动物中随机选择两个动物（每类一个）的10张图像作为种子集，初始化提示集P(0)和无标注池Du。
  - 每一轮r：①从Du中候选子集C(r)（|C(r)|=100）通过采集函数选择m=10张图像得到主动集A(r)；②对于每张x∈A(r)，用VLM（输入：x, 系统提示S, 上一轮提示集P(r-1)）生成预测标签和候选理由描述；③领域专家验证并校正预测标签和理由描述，得到验证集bA(r)；④更新提示集P(r)=P(r-1)∪bA(r)，并从Du中移除A(r)；⑤在验证集上评估当前提示集下的分类准确率；⑥检查停止条件（验证准确率≥80%、总标注数超过预算、轮次≥Rmax=7），满足则终止，否则进入下一轮。
  - 推理：使用最终提示集和系统提示S作为少样本上下文，对测试图像进行分类预测。
- 关键模块/机制：
  - 不确定性引导采集（Uncertainty-Guided Acquisition）：从无标注池中选择当前模型预测最不确定的样本，以高效降低不确定性。；对于每个候选图像x，通过T次随机解码（温度采样）生成T组随机预测{(ŷ^(t), ĉ^(t))}，构建经验类分布p_y(x;P(r-1))=1/T∑1[ŷ^(t)=y]。不确定性用熵衡量：u_ent(x)= -∑ p_y log p_y。选择熵最高的m个图像构成A(r)。
  - 复杂度感知不确定性采集（Complexity-Aware Uncertainty Acquisition）：在选择不确定样本的同时，偏好预期添加的标注说明简洁且语义非冗余的样本，以优化提示集质量。；定义预测不确定性u(x)=1-max_y p_y（基于随机解码的类分布）。定义预期标注复杂度κ̂(x)=αℓ(ĉ)+βρ(ĉ;P(r-1))，其中ℓ为归一化token长度，ρ为与当前提示集标注的平均余弦相似度（反映冗余度）。通过拉格朗日松弛将约束优化转化为最大化s(x)=u(x)-λ_c κ̂(x)，选择得分最高的m个样本。
  - 密度树边界采集（Density-Tree Boundary Acquisition）：在图像编码器嵌入空间中识别位于密度簇边界（谷底）的样本，这些样本通常决策模糊，能高效利用标注预算。；用VLM图像编码器提取所有无标注图像的嵌入向量。构建kNN图，定义局部密度ρ_i = (1/k_ρ ∑_{j∈N_{k_ρ}(i)} d(z_i,z_j))^{-1}。对每个点i，寻找密度更高且距离在阈值内的候选父节点，通过最大密度梯度确定父指针π(i)，形成密度树（根为密度模式）。定义边界得分b(i)=1 - (1/k_b)∑_{j∈N_{k_b}(i)} 1[r(j)=r(i)]，其中r(i)为根。选择b(i)最高的m个样本，但限制小簇和同一簇重复选择。
  - 人机协同标注（Annotation with Human-in-the-Loop）：利用VLM生成候选标注，专家仅需验证和轻微编辑，大幅降低手工注释成本。；对于主动集中每张图像，使用VLM（系统提示S和当前提示集P(r-1)）生成预测标签和理由描述。领域专家检查并校正标签和理由描述，确保正确性和清晰度。校正后的图像-描述对加入提示集。
  - 停止准则（Stopping Criteria）：决定何时终止主动轮换，避免过度标注。；每轮后，在保留验证集上计算平均类准确率。若达到预设目标（80%），或累计标注数超过预算，或达到最大轮次（7轮），则停止。
- 公式/目标函数/指标定义：
  - 经验类分布：p_y(x;P(r-1)) = 1/T ∑_{t=1}^T 1[ŷ^{(t)}=y] (式2)
  - 熵不确定性：u_ent(x,P(r-1)) = -∑_{y=1}^K p_y(x,P(r-1)) log p_y(x,P(r-1)) (式3)
  - 约束优化：max_{x∈D_u} u(x;P(r-1)) s.t. κ̂(x;P(r-1)) ≤ τ (式5)
  - 不一致不确定性：u(x;P(r-1)) = 1 - max_y p_y(x;P(r-1)) (式6)
  - 冗余度：ρ(c;P(r-1)) = 1/|P(r-1)| ∑_{(x',c')∈P(r-1)} (1+sim(ψ(c),ψ(c')))/2 (式7)
  - 预期复杂度：κ̂(x;P(r-1)) = α ℓ(ĉ(x;P(r-1))) + β ρ(ĉ(x;P(r-1));P(r-1)) (式8)
- 算法细节：
  - 不确定性估计采用随机解码：对每张图像生成T=5次随机输出（通过温度采样），记录预测标签，统计频率分布。
  - 密度树构建步骤：对所有无标注嵌入计算kNN图（距离度量默认为欧氏距离）；设置k=30？具体值见原文），局部密度计算使用k_ρ个最近邻；对每个点，候选父节点为该点kNN中密度更高且距离小于阈值t_i的点，父指针选择使(ρ_j-ρ_i)/d(z_i,z_j)最大的节点；无候选父节点则作为根。
  - 边界得分计算：使用k_b个最近邻统计邻居根与自身根相同的比例，得分越高表示越靠近簇边界。
  - 主动集选择：每轮从无标注池中随机抽取100张图像作为候选子集（低资源约束），然后在候选子集中根据采集函数得分选取top-10。
  - 停止条件：验证准确率阈值80%，最大轮次7，预算限制（未明确具体数值但通过轮次和每轮10张隐含）。
- 训练/推理细节：
  - VLM（GPT-4o）保持冻结，不进行参数更新；仅通过优化提示集（即少样本示例）来适应任务。
  - 推理时，将最终提示集和系统提示S拼接作为输入上下文，对测试图像生成预测标签。
  - 每轮标注后，提示集动态扩展，VLM的上下文长度受限制（通过轮次上限和每轮10张控制）。
  - 不确定性估计和采集函数计算均依赖冻结VLM的前向传播，无需额外训练。

### 2. Claim-Selective Certification for High-Risk Medical Retrieval-Augmented Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.21949v1
- 方法流程：
  - 输入医疗问题q和检索证据E；
  - 声明分解：生成可验证声明骨架C和元数据mi（包括问题意图和声明类型）；
  - 关系评分：对每个声明-证据对计算支持、冲突、限制得分，最大池化聚合得到Ssup, Sconf, Slim；
  - 意图感知选择：根据得分和问题意图，将每个声明映射为certified/condition-limited/conflicting/omitted，并汇总为最终动作full/partial/conflict/abstain；
  - 输出：证据链接的声明状态表和最终动作。
- 关键模块/机制：
  - 声明分解模块：将输入问题拆分为一组可验证的声明骨架，并附带问题意图元数据。；基于预定义模板生成声明，例如对于剂量、妊娠、相互作用等类别，输出关键声明列表C和每个声明的question_intent。
  - 关系评分模块：评估每个声明与每条证据之间的支持、冲突和限制关系。；使用词汇重叠和提示词典（cue lexicon）估计s(ci, ej) = (ssup, sconf, slim) ∈ [0,1]^3，然后对每个声明跨证据进行最大池化得到Ssup, Sconf, Slim（公式7-9）。
  - 意图感知风险校准选择器：将聚合后的关系分数和问题意图映射到声明状态，并汇总为最终动作。；根据问题意图分组（如indication/effectiveness, pregnancy/lactation等），应用不同的映射规则从(Ssup, Sconf, Slim)到声明状态（certified/condition-limited/conflicting/omitted），并包含scoped源家族先验（例如openFDA剂量提示提升支持分数，PubMed文献降级full为partial）。最终动作由声明状态集决定：全部关键声明certified→full，部分certified且有限制→partial，存在冲突→conflict，无可表达→abstain。
  - 弱标签认证协议：定义评估指标和基准，用于测量声明级风险与效用。；使用构建派生弱标签（construction-derived weak labels）评估UCCR（未支持关键声明率）和PAU（部分答案效用），并记录动作准确率。
- 公式/目标函数/指标定义：
  - 关系向量: s(ci, ej) = (ssup, sconf, slim) ∈ [0,1]^3
  - 聚合得分: Sℓ(ci) = max_{ej∈E} sℓ(ci, ej), ℓ∈{sup, conf, lim}
  - UCCR = |{c∈P : c is critical and c∉Guse}| / |{c∈P : c is critical}|
  - PAU = |P ∩ Guse| / |Guse|
  - PAU Precision = |P ∩ Guse| / |P|
- 算法细节：
  - 声明分解：使用预定义模板生成声明，每个问题附带question_intent。
  - 关系评分：lexical overlap + cue lexicon估计支持、冲突、限制分数。
  - 聚合：对每个声明，跨所有检索证据最大池化三个分数。
  - 选择器：按问题意图分组（full-certify oriented, partial-oriented, conflict-oriented, mixed, dosage-specific），应用不同阈值/规则从得分到声明状态；包含scoped源先验（openFDA剂量提示可提升support得分，PubMed文献可降级full为partial）。
  - 最终动作：若所有关键声明certified则full；部分certified且存在限制则partial；存在conflicting声明则conflict；无certified/condition-limited声明则abstain。
  - 阈值基线：在dev集上网格搜索全局阈值（support=0.35, conflict=0.55, condition_limited=0.30）。
- 训练/推理细节：
  - 弱标签协议：所有评估基于构建派生弱标签。
  - 阈值基线：在dev集（n=314）上网格搜索全局阈值，选定support=0.35, conflict=0.55, condition_limited=0.30，固定用于测试。
  - 全风险校准选择器：固定策略规范，无训练参数；包含scoped源先验（固定实现）。
  - 推理输入：问题、声明骨架、意图、检索证据、关系分数、源/上下文字段。
  - 消融实验对比：仅检索、仅关系、阈值选择、全风险校准。

### 3. Case-Aware Medical Image Classification with Multimodal Knowledge Graphs and Reliability-Guided Refinement
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.22547v2
- 方法流程：
  - 阶段1: 输入查询图像，经MedMamba编码器提取视觉特征，在CH-MKG中自适应检索相似图像，并一跳扩展提取子图（包含图像、症状、疾病节点）
  - 阶段2: 子图经图像中心GAT（两层4头，隐层768维）传播语义，得到知识特征；通过双向CrossModalBlock（两层多头交叉注意力，4头）与查询视觉特征对齐，融合后经MLP分类器产生初始预测P_q
  - 阶段3: 每个检索案例单独通过相同管道得到预测分布P_i，CDR模块综合各案例相似度和预测置信度生成辅助分布P_sim，与P_q自适应融合（默认权重α=β=1）得到最终预测P_final
- 关键模块/机制：
  - Case-aware Hierarchical Multimodal Knowledge Graph (CH-MKG)：构建结构化诊断记忆，支持自适应案例检索与子图提取；层次化组织：顶层为疾病节点（语义锚点），中层为代表性图像节点（案例），底层为症状节点（细粒度临床属性）。边表示图像-疾病（类别归属）和图像-症状（临床表现）。离线从训练集提取代表性图像特征构建FAISS索引。查询时计算相似度，按相邻对数比u_i=log(S_i/S_{i+1})截断（阈值u_th），保留有效案例，并一跳扩展连接症状和疾病节点形成子图。
  - Knowledge Propagation and Injection (KPI)：从子图中提取知识特征并与查询视觉特征对齐融合；包含两部分：1) 图像中心GAT（两层，每层4头注意力，隐层768维，dropout 0.2）在子图上传播信息，聚合图像、症状、疾病节点语义得到知识特征；2) 双向CrossModalBlock（两层，每层多头交叉注意力4头，嵌入768维，dropout 0.2，后接残差、LayerNorm和MLP）分别实现知识到视觉和视觉到知识的对齐，最终将查询视觉特征与知识特征拼接为4×768维向量。
  - Confidence-calibrated Decision Refinement (CDR)：评估检索案例可靠性，重加权融合得到稳健预测；对每个检索案例i，通过相同管道（视觉编码+KPI+分类头）得到预测分布P_i，计算其置信度（如最大概率）。结合该案例与查询的相似度S_i，生成加权辅助分布P_sim = 归一化加和(权重*P_i)，权重由置信度和相似度共同决定。初始预测P_q与P_sim自适应融合（默认α=1, β=1）得最终P_final。
- 公式/目标函数/指标定义：
  - 自适应检索截断: u_i = log(S_i / S_{i+1})，当u_i > u_th时从位置i截断
  - 训练目标: 交叉熵损失
  - 融合: P_final = α * P_q + β * P_sim（默认α=1, β=1）
- 算法细节：
  - 检索: 使用FAISS索引，余弦相似度计算；相邻相似度对数比截断自适应选择k'个案例；一跳扩展子图
  - GAT传播: 两层多头注意力，每层4头，隐层768维，dropout 0.2
  - 双向跨模态: 两层CrossModalBlock，每层多头交叉注意力4头，embedding 768，dropout 0.2，残差+LayerNorm+MLP（两层ReLU）
  - 融合: 查询视觉特征与知识特征拼接为4×768，经两层MLP分类器（ReLU，dropout 0.4）输出logits
  - CDR: 每个检索案例前向传播得到预测分布，计算置信度（max概率），与相似度加权生成辅助分布
- 训练/推理细节：
  - 图像resize到224×224×3
  - MedMamba预训练编码器提取特征
  - GAT和CrossModalBlock参数量：两层4头，hidden=768
  - 优化器AdamW，初始lr=5e-5，weight decay=0.02，StepLR step=25 gamma=0.5
  - batch size=64，epoch=40，early stopping
  - 梯度裁剪应用于稳定优化

### 5. Evi-Steer: Learning to Steer Biomedical Vision-Language Models through Efficient and Generalizable Evidential Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.26292v1
- 方法流程：
  - 输入：图像和类别提示文本；使用冻结的BiomedCLIP视觉编码器和文本编码器提取预训练特征。
  - 在视觉和文本编码器的前d层注入跨模态低维适配器（r维潜空间）。
  - 每层适配器：将当前令牌表示投影至潜空间，得到均值更新和不确定性通道；通过softplus变换获得证据和认知不确定性。
  - 将不确定性转化为信念质量，对视觉和文本分别计算H1（应用更新）和H0（忽略）的信念。
  - 文本不确定性通过[EOS]令牌聚合，转换为调节视觉更新的信念质量；使用Dempster-Shafer组合规则融合视觉和文本信念，得到融合后信念。
  - 通过线性层将LD信念质量聚合为令牌级置信权重，加权的低维更新乘以可学习缩放系数后加到原始令牌表示上。
  - 输出：更新后的视觉和文本令牌表示，用于分类。
- 关键模块/机制：
  - 跨模态低维适配器 (Cross-modal Low-dimensional Adapter)：在激活空间生成低维表征更新并估计不确定性；将令牌表示T(n)和V(n)分别通过下投影矩阵W↓_t和W↓_v映射到2r维潜空间，拆分为均值更新Zμ和不确定性Zσ。Zμ通过上投影生成原始更新˜T(n)和˜V(n)；Zσ通过softplus平方加常数得到证据e，进而得到Dirichlet浓度β=e+1，认知不确定性u=β^{-1}。
  - 不确定性门控 (Uncertainty Gating)：根据置信度加权低维更新，抑制不确定的调整；对于文本和视觉，基于不确定性u分别定义信念质量：mH1=1-u (应用更新)，mH0=u (忽略)。文本的信念质量通过线性层wt和sigmoid得到门控权重G_t；视觉的门控权重G_v基于融合后的信念mH1_t×v通过w_v和sigmoid得到。最终更新∆=G⊙˜表示，再乘以可学习缩放α加到原始表示上。
  - 跨模态信念融合 (Cross-modal Belief Fusion)：基于Dempster-Shafer理论融合视觉和文本证据，调节视觉适应；将文本的[EOS]令牌对应的不确定性在类别上平均得到¯u_t，转换为信念mH1_t→v=1-¯u_t, mH0_t→v=¯u_t。视觉信念mH1_v, mH0_v由视觉不确定性得出。使用Dempster-Shafer组合规则：mH1_t×v = (mH1_t→v * mH1_v) / (1 - (mH1_t→v*mH0_v + mH0_t→v*mH1_v) + epsilon)。融合信念强调两模态一致的高置信度证据。
- 公式/目标函数/指标定义：
  - 潜空间投影: [Zμ_t, Zσ_t] = T(n) W↓_t, W↓_t ∈ R^{D_t×2r}；[Zμ_v, Zσ_v] = V(n) W↓_v, W↓_v ∈ R^{D_v×2r}
  - 证据和不确定性: e = softplus((Zσ)²) + ϵ, β = e + 1, u = β^{-1}

### 9. Gaze into the Details: Locality-Sensitive Enhancement for OCTA Retinal Vessel Segmentation

  - MFF中的多尺度特征提取：使用1×1、3×3、5×3卷积并行提取特征，拼接后通过通道注意力（CA）模块对通道维度加权，然后与下采样特征拼接融合。
  - CRD中的特征融合：将上采样特征与PIE输出在通道维度拼接，经1×1卷积压缩通道，再经两个3×3卷积学习细化。最终输出使用11×11大核卷积，无偏置，感受野覆盖更大邻域。

- 训练/推理细节：

### 12. D-Convexity: A Unified Differentiable Convex Shape Prior via Quasi-Concavity for Data-driven Image Segmentation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.19210v1
- 方法流程：
  - 输入图像I经过Swin-Unet编码器-解码器提取特征o
  - 对o应用sigmoid函数得到概率图u（值域[0,1]）
  - 将u输入凸梯度投影模块(CGPM)，迭代调整像素值以确保在梯度非零区域满足二阶条件Q2<0
  - 同时使用交叉熵损失L_fid和凸性正则损失L_reg联合训练网络
  - 推理时直接输出经CGPM投影后的u，无需后处理阈值
- 关键模块/机制：
  - 凸梯度投影模块(CGPM)：强制输出掩膜满足拟凹性（凸性先验）；对每个像素x，计算梯度∇u(x)和Hessian矩阵，构造二次型Q2(x)=u_x^2 u_yy - 2u_x u_y u_xy + u_y^2 u_xx。若Q2(x)≥0，则通过迭代更新u(x)=u(x)-η·sign(Q2)·(d^T∇^2u d)（其中d为切线方向），使Q2<0。迭代步数由T_max控制，保证收敛到局部满足负定条件。
  - 拟凹性损失（二阶条件）：可微的正则项，用于训练过程约束凸性；基于二阶条件Q2<0构造损失L_reg = max(0, Q2)的某种聚合（如均值或最大），可逐像素计算并反向传播，与分割损失联合优化。
- 公式/目标函数/指标定义：
  - 拟凹性定义：u是拟凹函数 ⇔ 所有超水平集Sγ = {x∈Ω | u(x)≥γ}是凸集
  - 零阶条件：u(λx+(1-λ)y) ≥ min{u(x), u(y)}, ∀ x,y∈Ω, λ∈[0,1]
  - 一阶条件：若u(x)≥u(y)，则∇u(y)^T (x-y) ≥ 0
  - 二阶条件（2D）：Q2(x) = u_x^2 u_yy - 2u_x u_y u_xy + u_y^2 u_xx < 0，其中∇u(x)≠0
  - 与曲率关系：κ(x) = -Q2(x) / ||∇u(x)||^3，凸形状要求κ≥0等价于Q2≤0
  - 训练损失：L = L_fid(u,g) + λ L_reg(u)，L_fid为交叉熵或Dice损失，L_reg为凸性正则项
- 算法细节：
  - CGPM基于梯度投影法：对于每个像素，若Q2≥0，则沿切线方向d=( -u_y, u_x )调整u值，使Hessian在切线方向负定。具体更新规则：u_new = u - η * (d^T ∇^2 u d) * d / ||d||^2 的某种形式（原文未给出显式公式，此处为合理推断）。
  - 零阶条件可通过全局中点约束实现，但论文主要使用二阶条件作为损失。
  - 一阶条件可用于构造支持超平面约束，但实验中使用二阶条件。
- 训练/推理细节：
  - 骨干网络：Swin-Unet，输入图像resize到224x224
  - 优化器：AdamW，学习率调度：OneCycle，最大学习率1e-4
  - 训练轮数：200 epoch，batch size：6
  - CGPM参数：η=1e-2, λ=1, T_max=100
  - 推理时间：Swin-Unet单张0.01秒，加CGPM后0.12秒
  - 数据增强：随机水平/垂直翻转、旋转、缩放、高斯噪声、高斯平滑、亮度对比度扰动

### 16. Rotation-Aligned Key Channel Pruning for Efficient Vision-Language Model Inference
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.19218v1
- 方法流程：
  - 预填充阶段：1) 获取视觉token的Key状态K∈R^{N×d}和最近W个预填充查询QW∈R^{W×d}；2) 计算查询加权协方差Cq = diag(σW) C diag(σW)，其中σW为QW的通道L2范数，C为K的协方差；3) 通过Cholesky子空间迭代求解Cq的top-k特征向量构成旋转矩阵R；4) 旋转Key：K_rot = K R，保留前k列得到压缩Key ˜K = K_rot[:,:k]；5) 缓存˜K和R。
  - 解码阶段：1) 对每个新查询qt，旋转并截断：˜qt = qt R[:,:k]；2) 使用融合注意力核，对视觉token用˜qt和˜K计算稀疏通道注意力，对文本/prompt token用全通道；3) 添加偏置项补偿旋转丢弃的均值分量。
- 关键模块/机制：
  - 查询加权PCA：构造旋转矩阵R，使通道重要性对齐到查询相关方向；计算最近W个预填充查询的每通道L2范数向量σW，然后计算Key协方差C = (K-μ)^T(K-μ)，通过Hadamard积得到Cq = (σW σW^T) ⊙ C，最后对Cq进行Cholesky子空间迭代得到top-k特征向量矩阵R。
  - Cholesky子空间迭代：高效近似计算top-k特征空间，替代高开销的完整特征分解；从随机初始化V^{(0)}∈R^{d×k}开始，每步迭代：V^{(t)} ← Cq V^{(t-1)}，然后通过Cholesky分解进行正交化：计算LL^T = (V^{(t)})^T V^{(t)}，再解三角方程组得到正交基。T=5次迭代后，V^{(T)}即为近似的top-k特征向量。
  - 后处理重加权：避免显式构造加权Key矩阵，减少内存和计算开销；直接利用原始协方差C通过外积和元素乘计算Cq = (σW σW^T) ⊙ C，无需构建N×d的Kq矩阵，复杂度O(d²)与N无关。
  - 融合稀疏注意力Triton内核：在解码阶段高效执行支持不同通道维度的注意力计算；对视觉token的Key使用k个通道（稀疏），对prompt/text token使用全通道d，内核在Triton中实现，避免全通道计算，减少内存访问和计算量。
- 公式/目标函数/指标定义：
  - 注意力精确保持： (qtR)(KR)^T = qt R R^T K^T = qt K^T
  - 剪枝后近似注意力： ˜qt ˜K^T = qt P_k K^T，其中P_k = R_k R_k^T
  - 近似误差： qt K^T - ˜qt ˜K^T = qt (I - P_k) K^T
  - 查询加权协方差： C_q = diag(σ_W) C diag(σ_W) = (σ_W σ_W^T) ⊙ C，其中C = (K-μ)^T(K-μ)
- 算法细节：
  - 预填充阶段每层每个注意力头独立执行：1) 收集N个视觉token的Key矩阵K和最近W个查询QW；2) 计算每个查询通道的L2范数σW = ||QW[:,j]||_2；3) 计算Key协方差C = K^T K（已中心化处理）；4) 获取查询加权协方差Cq = (σW σW^T) ⊙ C；5) 初始化随机正交矩阵V∈R^{d×k}，迭代5次：V = Cq V，然后Cholesky正交化（计算V^TV的Cholesky分解L，再解V = V L^{-T}）；6) 旋转Key：K_rot = K V，保留前k列得到˜K，并缓存V和均值μ。
  - 解码阶段：对每个新查询qt，计算˜qt = qt V[:,:k]；计算注意力分数：对视觉token部分使用˜qt ˜K^T，对文本部分使用qt K_text^T（全通道）；输出融合。
  - 偏置修正：在注意力分数中加上q_t^T (I - V_k V_k^T) μ，其中μ是预填充时计算的Key均值。
- 训练/推理细节：
  - 无需训练，完全在线校准，每个预填充阶段重新计算旋转矩阵。
  - 预填充计算复杂度：协方差O(N d^2) + 子空间迭代O(T d^2 k)（T=5通常足够），总开销低于标准注意力O(N^2 d)。
  - 解码阶段：仅需对视觉token的Key使用k个通道，通过融合Triton内核减少计算和内存带宽。
  - 旋转矩阵在预填充后固定，用于同一序列的所有后续解码步骤。

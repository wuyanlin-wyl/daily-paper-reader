### 1. A Human-in-the-Loop Framework for Efficient Prompt Selection in Microscopy Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.20495v1
- 方法流程：
  - 初始化：从训练动物中随机选取10张图像（每类5张）作为初始标注集，构建初始提示集P(0)
  - 每一轮r：对未标注池Du，使用获取函数选择m=10张图像作为活动集A(r)
  - 对A(r)中每张图像，VLM结合系统提示S和当前提示集P(r-1)生成候选标签和描述
  - 专家验证标签并编辑描述，得到验证集Â(r)并加入P(r)
  - 从Du中移除已标注图像，在验证集上评估平均类准确率
  - 若准确率达到目标阈值（80%）或超过预算或最大轮数（7轮），停止；否则进入下一轮
  - 推理时，使用最终提示集作为少样本上下文，对测试图像进行分类
- 关键模块/机制：
  - 不确定性引导获取函数：选择模型预测最不确定的图像；对每个候选图像，通过随机解码（T=5次采样）生成经验类别分布py(x)，计算熵作为不确定性分数，选择top-m高熵图像。
  - 复杂度感知不确定性获取函数：平衡不确定性与描述复杂度及冗余度；定义复杂度指标ˆκ=α·归一化描述长度+β·平均语义相似度（与现有提示集描述）；使用拉格朗日松弛：s=不确定性-λc·复杂度，选择分数最高的top-m图像。
  - 密度树边界获取函数：选择位于密度簇边界附近的图像；基于VLM图像编码器特征构建kNN图；定义局部密度ρ；通过最陡上升树将点划分为密度簇；对每个点计算边界得分b(i)=1-（同簇邻居比例），选择得分最高的top-m图像。同时限制极小簇和同一簇的重复选择。
- 公式/目标函数/指标定义：
  - 经验类别分布：py(x)=1/T Σ_t=1^T 1[ŷ(t)=y]
  - 熵不确定性：uent(x)= -Σ_y py log py
  - 复杂度感知拉格朗日分数：s(x)=u(x) - λc·ˆκ(x)，其中ˆκ=α·ℓ(ˆc)+β·ρ(ˆc;P)
  - 边界得分：b(i)=1 - (1/kb)Σ_{j∈N_kb(i)} 1[r(j)=r(i)]
- 算法细节：
  - 不确定性估计使用随机解码，通过温度采样生成T=5个输出，构建经验分布
  - 复杂度度量中，描述长度归一化至[0,1]，语义相似度使用余弦相似度并映射至[0,1]
  - 密度树构造：定义局部密度ρi=( (1/kρ)Σ_{j∈N_kρ(i)} d(zi,zj) )^{-1}；父指针选择候选集中密度差与距离比值最大的点；根节点为局部密度模式
  - 边界得分计算中，kb设为kNN参数k的子集，避免小簇干扰
- 训练/推理细节：
  - VLM（GPT-4o）在整个过程中保持冻结，不进行梯度更新
  - 初始提示集由10张随机标注图像构成（每类5张）
  - 每轮添加10个新标注示例，最多7轮
  - 停止准则是验证集平均类准确率达到80%或累计标注数超过预算或达到最大轮数
  - 推理时使用最终提示集作为少样本上下文

### 2. Claim-Selective Certification for High-Risk Medical Retrieval-Augmented Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.21949v1
- 方法流程：
  - 输入：医疗问题q和检索证据集E={e1,...,ek}
  - 阶段1：声明分解（Claim Decomposition）——基于模板生成可验证声明骨架C={c1,...,cn}和每个声明的元数据mi（包括问题意图和声明类型）
  - 阶段2：关系评分（Relation Scoring）——对每个声明-证据对估计支持、冲突、限制分数，通过max池化得到每个声明的聚合分数S_sup, S_conf, S_lim
  - 阶段3：意图感知风险校准选择（Intent-Aware Risk-Calibrated Selection）——将S_sup, S_conf, S_lim和mi映射到声明状态（certified/condition-limited/conflicting/omitted），最终根据声明集产生动作a∈{full, partial, conflict, abstain}
- 关键模块/机制：
  - Claim Decomposition：将医疗问题分解为可验证的声明骨架，并提取问题意图和声明类型；使用模板生成，每个查询对应一组高层面关键声明，而非无限制的细粒度提取。问题意图涵盖indication, dosage, contraindication等8种。
  - Relation Scorer：为每个声明-证据对生成支持、冲突、限制三维分数；组合词汇重叠和线索词典（cue lexicon）来估计分数。分数向量s(ci, e_j) = [s_sup, s_conf, s_lim] ∈ [0,1]^3。通过max池化跨证据聚合：S_ℓ(ci) = max_{e_j∈E} s_ℓ(ci, e_j), ℓ∈{sup,conf,lim}。
  - Intent-Aware Risk-Calibrated Selector：根据聚合分数和意图，将每个声明映射到四种状态之一，并产生最终动作；根据问题意图分组到策略族（完整导向、部分导向、冲突导向、混合、剂量特定），每组有不同从(S_sup,S_conf,S_lim)到声明状态的映射。包含两个领域先验：1) openFDA剂量指示线索可以挽救剂量支持；2) PubMed Literature综述级证据可将完整答案降级为部分。
  - Certificate Protocol：定义弱标签下的评估指标：UCCR（非支持关键声明率）、PAU（部分答案效用）等；UCCR = |{c∈P: c关键且c∉G_use}| / |{c∈P: c关键}|，目标为零。PAU = |P ∩ G_use| / |G_use|，衡量保留的可用信息。动作准确率评估四类动作。
- 公式/目标函数/指标定义：
  - 关系分数向量：s(ci, e_j) = [s_sup, s_conf, s_lim] ∈ [0,1]^3
  - 聚合分数：S_ℓ(ci) = max_{e_j∈E} s_ℓ(ci, e_j), ℓ∈{sup,conf,lim}
  - UCCR = |{c∈P: c is critical and c∉G_use}| / |{c∈P: c is critical}|
  - PAU = |P ∩ G_use| / |G_use|
- 算法细节：
  - 输入问题q和检索证据集E
  - 通过模板生成声明集C和意图元数据m_i
  - 对每个声明-证据对(ci, ej)计算s_sup, s_conf, s_lim（基于词汇重叠和线索词典）
  - 应用max池化跨证据得到每个声明三分数
  - 根据问题意图选择策略族，将三分数映射到声明状态：certified（S_sup高于阈值且无冲突/限制）、condition-limited（有限制且无冲突）、conflicting（S_conf高）、omitted（其余）
  - 从声明状态集产生最终动作：所有必要声明certified→full；部分certified且有限制→partial；存在conflicting→conflict；无certified→abstain
  - 使用两个领域先验：openFDA剂量线索提升dosage支持分数；PubMed Literature证据将full降级为partial
- 训练/推理细节：
  - 弱标签构造：通过构建规则从数据和证据生成gold声明和动作，训练/调参不使用人工标注
  - 阈值选择器在开发集上网格搜索support=0.35, conflict=0.55, condition_limited=0.30，最大化PAU后动作准确率
  - 完整选择器为固定策略规范，无学习参数，使用意图条件分支和全局回退阈值
  - 推理时使用问题、声明骨架、意图、检索证据、关系分数和来源/上下文字段

### 3. Case-Aware Medical Image Classification with Multimodal Knowledge Graphs and Reliability-Guided Refinement
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.22547v2
- 方法流程：
  - 输入：查询图像。第一阶段（CH-MKG）：用MedMamba编码器提取视觉特征，从FAISS索引中自适应检索k个相似图像，构造查询特定子图（包含图像节点及其连接的疾病、症状节点）。
  - 第二阶段（KPI）：在子图上运行图像中心的多头GAT（2层，4头），传播信息生成知识特征；通过双向交叉注意力（2层，4头）将知识特征注入查询视觉特征，融合后经MLP分类器输出初始预测P_q。
  - 第三阶段（CDR）：对每个检索案例图像重复上述流程得到各自预测分布P_i，计算每个案例的置信度（如预测概率最大值）和与查询的余弦相似度；为每个案例计算权重w_i = α * sim_i + β * conf_i，归一化后加权融合得到辅助分布P_sim；将P_q与P_sim自适应融合（如相加或可学习加权）得到最终预测P_final。
- 关键模块/机制：
  - Case-aware Hierarchical Multimodal Knowledge Graph (CH-MKG)：构建结构化的诊断记忆，存储疾病-图像-症状的层次关系，支持自适应检索。；为每个数据集离线构建：选择代表性医学图像作为图像节点，每个图像连接其疾病类标签节点和专家标注的症状节点。边有2种类型：image-disease（类隶属）和image-symptom（临床特征）。图结构为三层：顶层疾病节点，中层图像节点，底层症状节点，实现双向信息流。
  - Adaptive Case Retrieval：根据查询图像自适应确定检索的相似案例数量，过滤无关噪声。；计算第i个检索图像的相似度S_i，定义u_i = log(S_i / S_{i+1})。当u_i超过阈值u_th时，截断检索列表，只保留前i个图像。然后对每个选中图像做一跳扩展，包含其症状和疾病节点，形成查询特定子图。
  - Image-centric GAT-based Knowledge Enhancement：在案例子图上传播信息，聚合图像、症状、疾病节点的语义生成知识特征。；使用2层多头图注意力网络（4头），隐藏维度768，dropout 0.2。以图像节点为中心，聚合邻居（疾病和症状节点）的特征。经过GAT后，图像节点的输出作为知识特征。
  - Bidirectional Cross-modal Alignment：对齐知识特征与查询视觉特征，实现跨模态融合。；采用2层双向CrossModalBlock，每个块含多头交叉注意力（4头，维度768，dropout 0.2），后接残差连接、LayerNorm和模态特定MLP（2层FFN，ReLU，dropout 0.4）。分别进行Knowledge->Vision和Vision->Knowledge交互，最终得到4×768的融合表示。
  - Confidence-calibrated Decision Refinement (CDR)：利用检索案例的预测置信度和与查询的相似度加权融合，生成更可靠的最终预测。；对每个检索案例图像，再次通过KPI和分类器得到其预测分布P_i。计算每个案例的置信度conf_i（如预测概率的最大值）和相似度sim_i（与查询视觉特征余弦相似度）。权重w_i = α·sim_i + β·conf_i，α=β=1。归一化后加权平均各P_i得到P_sim。最终预测P_final为P_q与P_sim的融合（如相加）。
- 公式/目标函数/指标定义：
  - 相似度下降比例：u_i = log(S_i / S_{i+1})，用于自适应截断
  - 案例权重：w_i = α * sim_i + β * conf_i，其中α=β=1
  - 损失函数：交叉熵损失
- 算法细节：
  - 离线构建FAISS索引：使用训练集中代表性图像的特征（MedMamba编码）建立向量库
  - 自适应检索：按相似度降序排列后，计算连续相似度比的log，超过阈值则截断
  - 知识图构建：每个数据集独立构造，实体包含疾病、图像、症状，边根据标注关系建立
  - GAT传播：在查询子图上运行2层多头GAT，每个头独立计算注意力权重，输出拼接
  - 双向交叉注意力：先Knowledge->Vision，再Vision->Knowledge，两个方向均采用标准交叉注意力公式
  - 决策细化：每个检索案例需单独前向一次（共享参数），计算softmax后取最大值为置信度
  - 最终融合：P_final = P_q + P_sim（直接相加）或通过可学习参数融合
- 训练/推理细节：
  - 图像分辨率统一为224×224×3
  - 优化器：AdamW，初始学习率5e-5，权重衰减0.02
  - 学习率调度：StepLR，step=25，gamma=0.5
  - 训练epochs：最多40，早停基于验证集
  - batch size：64
  - 梯度裁剪用于稳定优化

### 4. Benchmarking Convolutional, Transformer, Hybrid, and Vision Language Models for Multi Disease Retinal Screening
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.26283v1
- 方法流程：
  - 数据准备：使用RFMiD数据集（训练/验证/测试分割），图像读取为RGB PNG，应用随机裁剪/翻转/归一化等增强，VLM使用原生预处理。
  - 模型微调：加载预训练权重，对CNN/ViT/混合模型采用双学习率策略（backbone 5e-5, head 5e-4）；对CLIP采用两阶段训练（先只训练logit scale和bias，再解冻最后transformer块）。
  - 训练优化：使用AdamW优化器，余弦学习率调度+warmup，混合精度训练，梯度裁剪（max norm=1.0），早停（patience=10, min delta=1e-4），最大20epoch。
  - 校准与阈值选择：对验证集logits进行温度缩放（L-BFGS最小化BCE），然后对每个类别扫描ROC曲线选择特异性最接近0.8的阈值；二分类任务选择最大化F1的阈值。
  - 评估：在测试集上计算二分类AUC、F1max、多标签macro/micro AUC、特异性校准后的macro/micro F1和灵敏度。
  - 外部验证：将RFMiD训练的模型直接应用于Messidor-2进行二分类评估。
- 关键模块/机制：
  - 多标签分类头：将骨干网络输出的特征向量映射到28个疾病类别的logits；全连接层后接ReLU和Dropout，输入为骨干网络的单特征向量，输出logits，与BCE损失配合训练。
  - 温度缩放（Temperature Scaling）：校准模型预测概率，使其更准确反映真实可能性；使用L-BFGS优化器在验证集上学习单一温度参数T，将logits除以T后再计算概率，最小化BCE损失。
  - 每类阈值校准：为每个疾病类别选择决策阈值以匹配临床特异性要求；在验证集上对每个类别c，扫描阈值t，选择使|Spec_c(t) - 0.80|最小的t作为该类别固定阈值。
  - 类别权重损失：缓解多标签分类中的类别不平衡问题；从训练数据中计算每个类别的正样本权重，加权到BCE损失中，权重与类别频率成反比。
  - 双阶段CLIP微调策略：适应视网膜筛查任务，同时保留预训练的对齐能力；第一阶段冻结图像编码器，只训练logit scale和每类bias；第二阶段解冻最后若干transformer块，以较低学习率继续训练。
- 公式/目标函数/指标定义：
  - 优化目标：L = Σ_c [w_c * BCE(y_c, p_c)]，其中w_c为类别c的正样本权重，BCE为二值交叉熵
  - AUC_macro = 1/|C'| * Σ_{c∈C'} AUC_c
  - AUC_micro = AUC(D_micro)，其中D_micro = {(y_{ic}, p̂_{ic}) | 1≤i≤N, c∈C'}
  - F1(t) = 2 * Prec(t) * Rec(t) / (Prec(t) + Rec(t))
  - Spec_c(t) = TN_c(t) / (TN_c(t) + FP_c(t))
  - 阈值选择：τ_c = argmin_{t∈[0,1]} |Spec_c(t) - 0.80|，τ_any = argmax_{t∈[0,1]} F1(t)
- 算法细节：
  - 优化器：AdamW，backbone学习率5e-5，head学习率5e-4，权重衰减0.05（head无权重衰减）
  - 学习率调度：余弦退火，带warmup阶段
  - 混合精度训练（AMP）
  - 梯度裁剪：最大范数1.0
  - 早停：验证AUROC在10个epoch内未改进且delta<1e-4则停止
  - 最大训练epoch：20
  - Batch size：CNN/ViT/混合模型=16，VLM模型=4（梯度累积4步，有效batch=16）
  - 温度缩放使用L-BFGS优化器最小化验证集BCE
- 训练/推理细节：
  - 训练期间监控验证集AUROC，保存最优checkpoint
  - 推理时先对logits除以温度T进行校准，然后应用每类阈值τ_c获取二值预测
  - 二分类任务使用单阈值τ_any（从验证集最大化F1得到），多标签任务使用每类阈值τ_c
  - 外部验证时直接使用RFMiD训练的模型和校准参数，不做任何调整

### 5. Evi-Steer: Learning to Steer Biomedical Vision-Language Models through Efficient and Generalizable Evidential Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.26292v1
- 方法流程：
  - 输入：图像和类别提示文本；BiomedCLIP视觉和文本编码器提取预训练特征。
  - 在前d层编码器注入跨模态低维适配器：对每层，计算激活的低维残差更新和估计LD认知不确定性。
  - 文本不确定性聚合后经Dempster-Shafer融合与视觉证据结合，得到融合信念，用于调制视觉更新权重。
  - 使用学习到的缩放因子和置信门控更新原始激活，得到修正后的视觉和文本表示。
  - 最终表示用于分类（使用对比学习或线性分类头）。
- 关键模块/机制：
  - 低维表示适配器：在激活空间中生成低维更新方向和不确定性估计；对于文本和视觉编码器每层，使用下投影将激活投影到r维潜在空间，分为均值更新通道Zμ和不确定性通道Zσ，然后上投影回原始维度，初始化为零。
  - 证据不确定性估计模块：从Zσ计算LD认知不确定性；Zσ经过平方和softplus得到证据e，Dirichlet浓度β=e+1，认知不确定性u=1/β。
  - 跨模态信念融合模块：基于Dempster-Shafer理论融合视觉和文本不确定性，生成条件化视觉置信门控；文本不确定性经[EOS] token池化后转换为信念质量：m_H1_t→v=1-ū_t, m_H0_t→v=ū_t；视觉信念类似。Dempster-Shafer组合公式融合两个信念源得到m_H1_t×v，用于计算视觉门控权重。
  - 置信门控生成模块：将融合信念映射为token-wise门控权重，加权更新；使用线性层和sigmoid将信念质量压缩为门控权重G_t和G_v，与上投影更新逐元素相乘，再经缩放因子α加入原始激活。
- 公式/目标函数/指标定义：
  - 文本LD表示：Z_μt, Z_σt = T^{(n)} W_t^↓, W_t^↓ ∈ R^{D_t×2r}
  - 视觉LD表示：Z_μv, Z_σv = V^{(n)} W_v^↓, W_v^↓ ∈ R^{D_v×2r}
  - 上投影更新：T̃^{(n)} = Z_μt W_t^↑, Ṽ^{(n)} = Z_μv W_v^↑
  - 证据：e = softplus((Z_σ)^2) + ε, β = e + 1, u = 1/β
  - 信念质量：m_{H1}=1-u, m_{H0}=u
  - Dempster-Shafer融合：m_{H1}^{t×v} = (m_{H1}^{t→v} m_{H1}^v) / (1 - (m_{H1}^{t→v}m_{H0}^v + m_{H0}^{t→v}m_{H1}^v) + ε)
- 算法细节：
  - 低维投影：使用单一下投影矩阵将token激活映射到2r维（前r维均值，后r维不确定性）。
  - 不确定性计算：通过softplus和平方将不确定性通道映射为非负证据，并转换为Dirichlet浓度和认知不确定性。
  - 信念生成：每个模态的每个token产生两个信念质量（H1：应用更新；H0：忽略），总和为1。
  - 文本不确定性聚合：取所有类别提示的[EOS] token不确定性的平均，作为全局文本不确定性。
  - Dempster-Shafer融合：利用组合公式合并视觉信念和条件文本信念，分母包含冲突项，当冲突大时融合信念降低。
  - 门控权重：融合信念经线性层和sigmoid转换为0-1之间的权重，逐元素与上投影更新相乘。
  - 残差更新：加权更新乘以可学习标量α（初始微小值，在训练中学习）后加到原始激活上。
- 训练/推理细节：
  - 训练：使用交叉熵损失+KL散度正则化（λ_KL=1e-4），优化器Adam，学习率7.5e-4，批次大小16，训练100 epochs。

### 9. Gaze into the Details: Locality-Sensitive Enhancement for OCTA Retinal Vessel Segmentation
- 区域：quick；分数：8.0

- 方法流程：

  - 编码器阶段：使用轻量U-Net编码器（通道数固定64），在每个编码层输出特征图X_down
  - 在每个编码层之后，MFF模块接收原始输入的平均池化下采样版本X_in和上一层的下采样特征X_down，提取多尺度特征并经通道注意力筛选，输出64通道特征给PIE模块
  - PIE模块替代标准跳跃连接：对编码器特征进行intra-patch注意力（含平移窗口）、inter-patch注意力，三分支融合后经ReLU和残差连接，输出增强特征X_PIE
  - 解码器阶段（CRD）：依次上采样，每步将上采样特征X_up与对应PIE输出X_PIE拼接，经1×1卷积融合，再经两个3×3卷积块细化，输出X_CRD
  - 最终输出层：使用11×11无偏置卷积将64通道映射为单通道分割图，后接Sigmoid激活
  - 损失计算：Binary Cross-Entropy (BCE)损失和Dice损失之和
- 关键模块/机制：
  - Patch Information Enhance (PIE)：替换标准跳跃连接，增强局部特征，解决血管不连续；PIE模块包含三个并行分支：1) Intra-patch Attention：将输入对称填充至可被patch size P整除，生成Q、K（5×5卷积）和V（1×1卷积），重塑为N×C×P^2块（N=H/P×W/P），在每个块内独立计算带相对位置编码的注意力；2) Shifted Intra-patch Attention：将输入四周填充P/2，重复上述操作，然后裁剪回原尺寸，实现跨patch信息流动，有效感受野加倍；3) Inter-patch Attention：对每个patch进行空间平均池化得到N个token，使用线性层生成Q、K、V，计算跨patch的全局注意力，输出经双线性插值恢...
  - Multiscale Feature Fusion (MFF)：为PIE提供丰富的多尺度视觉可解释特征；MFF模块有两个输入：X_down（上一层MFF输出或编码器下采样特征）和X_in（原始输入经平均池化下采样到当前分辨率）。X_in首先经过3×3卷积块，然后分别经过1×1、3×3、5×5卷积块提取多尺度特征，拼接后通过通道注意力（CA）筛选重要通道。筛选后的特征与X_down拼接，再经1×1和3×3卷积块融合，输出64通道特征。所有卷积块使用GroupNorm（每组8通道）和ReLU。
  - Connectivity Refinement Decoder (CRD)：细化分割特征，消除血管断裂和碎片；CRD在每个解码阶段：将上采样特征X_up与对应PIE输出X_PIE拼接，通过1×1卷积块融合，再连续经过两个3×3卷积块细化。最终输出层使用11×11无偏置大核卷积（替代标准1×1卷积），扩大感受野以捕获血管上下文，增强连通性。所有卷积块包含卷积、GroupNorm和ReLU。
- 公式/目标函数/指标定义：
  - Intra-patch Attention: Attn_intra = Attn(Q_intra, K_intra, V_intra), 其中Attn(Q,K,V) = Softmax((QK^T + P_pos)/√C) V
  - Inter-patch Attention: 对每个patch做平均池化得到N个token，计算标准注意力Attn_inter，然后双线性插值恢复原尺寸
  - PIE输出: Attn_X = (Attn_intra + Attn_intra,padding)/2 + Attn_inter; X_PIE = ReLU(Attn_X) + X
  - MFF: X_pre = ConvBlock_3×3(X_in); X_n×n = ConvBlock_n×n(X_pre) for n∈{1,3,5}; X_multi = Concat(X_1×1, X_3×3, X_5×5); X_att = CA(X_multi); X_concat = Concat(X_att, X_down); X_fusion = ConvBlock_1×1(X_concat); X_MFF = ConvBlock_3×3(X_fusion)
  - CRD: X_refine = ConvBlock_1×1(Concat(X_up, X_PIE)); X_CRD = ConvBlock_3×3(ConvBlock_3×3(X_refine))
  - 损失函数: Loss = Loss_BCE + Loss_Dice, 其中 Loss_BCE = -1/n Σ[yi log(ŷ_i) + (1-yi)log(1-ŷ_i)], Loss_Dice = 1 - 2Σyi ŷ_i / (Σyi + Σŷ_i)
- 算法细节：
  - patch划分：输入填充到能被patch size P整除，然后重塑为不重叠的patch块；shifted分支填充P/2并裁剪回原尺寸
  - intra-patch注意力：将patch内的P^2个像素作为序列长度，计算带相对位置编码的自注意力
  - inter-patch注意力：将每个patch池化为一个token，计算跨patch的自注意力，然后双线性插值恢复到原空间大小
  - 多尺度特征提取：对同一输入使用1×1、3×3、5×5卷积并行提取不同尺度特征
  - 通道注意力：使用SE-like的通道注意力机制（原文引用[26]）筛选多尺度特征通道
  - 特征融合：MFF中将多尺度特征与下采样特征拼接后通过1×1和3×3卷积融合
  - 大核卷积：最终输出层使用11×11卷积，无偏置，以扩大感受野
  - GroupNorm：所有卷积块使用GroupNorm（每组8通道）替代BatchNorm，以适应小batch size

- 算法细节：
  - CGPM算法：输入初始概率图u0，迭代T_max步，每步计算凸性梯度并更新u，然后投影到[0,1]区间

  - 梯度计算：利用自动微分或数值梯度，反向传播L_conv到u

  - 超参数：η=1e-2，λ=1，T_max=100

### 18. X-Ray cardiac angiographic vessel segmentation based on pixel classification using machine learning and region growing
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.20073v1
- 方法流程：
  - 输入：X射线心脏造影图像（512x512像素）
  - 特征提取：对每个像素提取28维特征向量（包括简单环绕信息4维、各向异性扩散4维、数学形态学开闭操作6维、Kuwahara滤波2维、Rodrigues Sobel滤波2维、Hessian矩阵4维（原文公式(5)计算Frangi等特征）、连通性特征2维（即时连通性和径向连通性））
  - 分类：使用随机森林分类器对每个像素预测是否为血管（二分类）
  - 区域生长控制：采用ELEMENT方法，将分类结果反馈到后续像素的分类中（通过连通性特征动态更新）
  - 输出：血管分割二值图像
- 关键模块/机制：
  - ELEMENT区域生长控制：将像素分类结果动态反馈给后续像素特征，形成迭代分类机制；提出一种耦合区域生长与像素分类的框架：每次分类后，更新连通性特征（即时连通性：像素邻域内已分类为血管的像素数量；径向连通性：半径为7的圆内已分类为血管的像素数量），这些特征作为下一轮分类的输入，使得分类结果影响后续像素的分类
  - 各向异性扩散特征：去除噪声同时保留血管边缘，生成4个扩散参数组合下的特征；采用各向异性扩散方程：an(x,y)=I(x,y)+λ∑(c(x,y)∇I(x,y))，其中c(x,y)=e^((|∇I|/K)^2)。选取4组参数组合：(λ=0.3,i=20,K=4)、(i=10,λ=0.5,K=3)、(i=35,λ=2,K=3)、(K=6,i=40,λ=0.8)，对每个像素计算扩散后图像灰度值作为特征
  - 数学形态学开闭操作特征：提取血管的形态学结构特征；基于灰度膨胀和腐蚀定义开运算和闭运算。使用两种结构元素：B1（3x3交叉）和B2（10x10圆形）。提取6个特征，对应不同参数组合：(B=B1, j=1, i=1), (B=B1, j=1, i=3), (B=B1, j=3, i=1), (B=B2, j=1, i=1), (B=B2, j=1, i=3), (B=B2, j=3, i=1)，其中i为腐蚀次数，j为膨胀次数。对每个像素计算开运算和闭运算后的灰度值
  - Kuwahara滤波器特征：保持边缘的同时平滑图像，提取均匀区域纹理信息；在像素周围定义四个象限（窗口大小2a+1），计算每个象限的均值m_i和标准差σ_i，输出中心像素值为标准差最小的象限的均值。使用窗口大小10x10和20x20，得到2个特征
  - Rodrigues Sobel滤波器特征：检测阴影/光照方向的边缘，提取血管边界信息；定义Light Sobel滤波器：LS(d,t,x,y)=1如果满足水平方向差值大于t且垂直方向差值大于t，否则0。参数组合：(t=-10,d=2)和(t=-10,d=5)，得到2个特征
  - 连通性特征：利用已分类像素的邻域信息指导当前像素分类，实现区域生长；实时提取：1) 即时连通性：当前像素4邻域中已分类为血管的像素个数；2) 径向连通性：以当前像素为中心、半径为7的圆内已分类为血管的像素个数。这些特征在ELEMENT迭代中动态更新
- 公式/目标函数/指标定义：
  - 各向异性扩散：an(x,y)=I(x,y)+λ∑(c(x,y)∇I(x,y))，其中c(x,y)=e^((|∇I|/K)^2)
  - 灰度膨胀：dil^B(x,y)=max_{b∈B}{I((x,y)_b)+B(b)}

- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.30510v1
- 方法流程：

  - 数据划分：将预处理后的图像分为训练集、验证集和测试集。
  - 二分类模型训练：为每个肿瘤类别（全肿瘤W、肿瘤核心T、增强肿瘤E）独立训练一个GCSER-UNet模型，使用数据增强。
  - 集成推理：将三个模型输出的二值分割图合并为最终多类分割结果。
- 关键模块/机制：
  - ResNet块：编码器和解码器的基本构建单元，通过残差连接缓解梯度消失并促进特征学习。；每个ResNet块包含两个卷积层，每个卷积层后接批归一化和ReLU激活，并通过跳跃连接将输入与输出相加。
  - Global Context-aware Squeeze and Excite (GCSE)：动态重新校准通道特征并融合空间注意力，增强模型对全局上下文信息的捕获能力。；输入特征图首先经过全局池化层计算每个通道的均值和标准差，拼接后送入两个全连接层（降维后升维）生成通道权重，与原始特征图逐通道相乘得到通道加权特征。随后，对通道加权特征应用空间注意力模块（通过1x1卷积和sigmoid生成空间注意力图），将空间注意力图与通道加权特征逐元素相乘，得到最终输出。
  - ASPP模块：在编码器瓶颈处提取多尺度上下文信息。；包含多个并行分支，每个分支使用不同扩张率的空洞卷积（如1,6,12,18），后接批归一化和ReLU，以及一个图像级池化分支，所有分支输出拼接后经1x1卷积融合。
  - 分类头：将解码器输出映射为二值分割图。；使用1x1卷积将特征通道数降为1，接sigmoid激活输出每个像素的肿瘤概率。

- 算法细节：
  - GCSE算法：1) 对输入特征图X（尺寸HxWxC）计算通道均值μ_c = (1/(H*W)) Σ_i Σ_j X_{i,j,c} 和标准差σ_c = sqrt((1/(H*W)) Σ_i Σ_j (X_{i,j,c} - μ_c)^2)。2) 拼接μ和σ得到2C维向量，通过全连接层W1（降维至C/r）→ReLU→全连接层W2（升维至C）→sigmoid生成通道权重s。3) 将s与X逐通道相乘得到X'。4) 对X'应用空间注意力：通过1x1卷积生成单通道注意力图，sigmoid激活后与X'逐元素相乘得到最终输出。
  - ASPP使用四个并行3x3空洞卷积（扩张率1,6,12,18）和一个全局平均池化分支，每个分支输出尺寸相同，拼接后经1x1卷积调整通道数。
  - 集成策略：三个独立的GCSER-UNet分别输出全肿瘤、肿瘤核心、增强肿瘤的似然图，通过阈值（如0.5）得到二值图，然后合并为多类分割（优先级：增强肿瘤>肿瘤核心>全肿瘤）。

### 6. EfficientGraph-RAG: Structured Retrieval-State Management for Cross-Task Retrieval-Augmented Generation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.25379v1
- 方法流程：
  - 阶段1：语料预处理与TAM构建。将语料D分割为原子证据单元L，递归聚类构建层次树T，每个内部节点v通过小模型生成自然语言抽象av=f_sum(children abstractions)。
  - 阶段2：查询状态初始化。给定查询q，初始化检索状态sq=(pq, πq, Eq, zq, Uq)，其中pq由Planner智能体生成初始计划，πq初始化为根节点，Eq为空，zq为未验证，Uq为空。
  - 阶段3：TAM自顶向下遍历。基于当前计划pq，Navigator智能体逐层比较查询q与候选子节点的抽象au，使用式(2)选择top-k子节点更新光束B(t+1)，更新πq。
  - 阶段4：证据检索与验证。Retriever智能体根据πq的叶子节点获取原始证据Eq，Verifier智能体对Eq进行验证，输出验证信号zq（PASS或FAIL）；若PASS则进入阶段6，若FAIL则返回阶段3重新规划或细化。
  - 阶段5：状态复用与协调（SMP）。在遍历和验证过程中，将中间计划、路径、证据及验证结果写入SMP，SMP根据层次化访问权限（全局Mg、任务级Mt、智能体私有Ma）控制读写，支持同一查询内多智能体协调和跨查询复用。
  - 阶段6：最终答案生成。当证据通过验证后，由大模型Reasoner智能体基于验证后的证据Eq和查询q生成最终答案。
- 关键模块/机制：
  - TAM (Tree-based Abstract Memory)：定义检索状态中的结构化的状态空间和遍历路径；将语料构建为类型化层次树。叶子节点存储原始证据（文本、图文对、表格片段），中间节点分为两级：高层节点编码主题级概念和可复用推理模式，中低层节点编码局部区域内的实体-关系抽象。每个非叶子节点通过小模型摘要器从子节点抽象生成自然语言抽象av（公式1）。路由时，Navigator将查询与各层抽象比较，使用公式2的Top-K选择子节点，逐步缩小搜索范围。导航器利用层级特定的语义：高层强调宽泛主题，低层强调实体关系，从而适应不同查询需求。
  - MARS (Multi-Agent Retrieval State)：更新和验证检索状态；包含四个专用智能体，每个由小语言模型实现：Planner根据查询生成初始检索计划pq；Navigator执行TAM中的自适应路由，更新遍历路径πq；Retriever根据πq的叶子节点获取候选证据Eq；Verifier评估Eq是否充分且相关，输出PASS/FAIL信号zq。若FAIL则触发重新规划或细化，形成迭代循环。大模型Reasoner仅在验证通过后调用，用于最终答案合成，从而降低大模型token使用（实验降低3.51倍）。
  - SMP (State Management for Persistence)：存储和复用可重用的状态工件；实现层次化访问控制的状态存储，将状态工件（计划、路径、证据、验证结果）分为三种级别：全局级Mg（跨查询可复用，如缓存块、嵌入、已验证证据）、任务级Mt（同一查询内多智能体共享）、智能体私有Ma（仅单个智能体可读写）。SMP支持查询内协调（如Navigator写入路径供Retriever读取）和跨查询复用（如已验证证据缓存，在后续类似查询中直接使用）。实验显示跨查询缓存命中率3.77%-23.18%。
- 公式/目标函数/指标定义：
  - 状态定义：sq = (pq, πq, Eq, zq, Uq)，其中pq为计划，πq为TAM遍历路径，Eq为证据集，zq为验证信号，Uq为可复用工件。
  - 节点抽象生成：av = f_sum({au | u ∈ Child(v)}) (公式1)，其中f_sum为小模型摘要器。
  - 光束更新：B(t+1) = TopK_{u ∈ S} g(q, a_u) (公式2)，其中S = ∪_{v∈B(t)} Child(v)，g为查询与抽象间的文本相关性度量，k为光束宽度（通常k=1时退化为贪心路由）。
- 算法细节：
  - TAM构建算法：先对语料进行语义分割得到叶子节点，然后自底向上进行层次聚类，每层使用小模型摘要生成内部节点抽象。聚类停止条件为根节点覆盖整个语料。
  - 自适应路由算法：Navigator维护一个光束集合B，初始为根节点。在每一层，计算查询与所有候选子节点抽象的余弦相似度（或嵌入匹配），保留top-k个节点。当到达叶子层时，停止遍历。
  - 验证与重规划机制：Verifier根据检索到的证据进行相关性判断，输出PASS或FAIL。若FAIL，Planner根据当前状态生成新的计划（如扩大搜索范围或改变方向），Navigator重新从根或当前节点开始遍历。
  - 状态复用机制：SMP维护三个存储空间（全局、任务、私有）。写入时根据智能体角色和任务ID自动分配权限。读取时，智能体只能访问其被授权级别的内容。缓存采用LRU策略淘汰。
  - 自适应旁路：当Verifier对当前证据验证通过且计划未要求更多信息时，直接跳过后续检索步骤，调用Reasoner生成答案。
- 训练/推理细节：
  - 所有智能体（Planner, Navigator, Retriever, Verifier）均使用小型语言模型（如Qwen2.5-7B或类似规模），无需额外训练，通过prompt指令驱动。
  - 大模型Reasoner仅在验证通过后调用一次，采用标准提示模板基于证据生成答案。
  - TAM构建无需训练，仅需使用小模型摘要器和聚类算法。
  - 推理时，检索状态在查询间独立初始化，但可通过SMP的全局缓存实现跨查询复用（如已计算的嵌入和已验证证据）。

### 7. Closed-Loop Bidirectional Prompting for Adversarial Robustness of Vision Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.25922v1
- 方法流程：
  - 0. 语义引导初始化（Semantic Bootstrapping）：使用通用模板（如'a photo of a {class}'）通过冻结文本编码器得到固定的文本特征W(0)作为语义锚，并初始化视觉特征z(0)=Hx(W(0))
  - 1. 主动视觉去噪（T2V step）：给定当前文本原型W(k)，T2V适配器ΦT2V生成视觉提示P(k)，将其拼接到图像patch前，通过冻结图像编码器得到去噪视觉特征z(k)(x)
  - 2. 实例自适应精炼（V2T step）：V2T适配器ΘV2T将z(k)映射为文本提示偏移δ(k+1)，通过Compose模块（小MLP）将此偏移加到可学习上下文token上，再通过冻结文本编码器得到新的文本原型W(k+1)
  - 3. 迭代更新：重复步骤1-2共N次（N=1已足够），得到最终视觉特征z(N)和文本原型W(N)
  - 4. 多视图聚合：对输入图像进行随机增强（如随机ResizedCrop），得到多个视图，分别通过上述闭环得到logits，加权平均后得到最终预测
- 关键模块/机制：
  - Semantic Anchor：提供稳定的先验特征，初始化循环并约束迭代过程，防止噪声传播导致特征偏离预训练流形；由通用模板（如'a photo of a {class}'）通过冻结文本编码器生成固定文本特征W(0)，该特征在整个循环中保持不变，作为隐式约束；同时初始化视觉特征z(0)=Hx(W(0))，确保起始点接近干净语义空间
  - T2V Adapter (Text-to-Vision)：根据当前文本原型生成实例自适应的视觉提示，通过cross-attention机制使视觉特征从文本信号中滤除噪声；ΦT2V是一个轻量网络，输入为当前文本原型W(k)（C×d），输出为视觉提示P(k)（L×d），L为提示token数。这些提示token被拼接到图像patch序列前，作为图像编码器的额外输入，通过cross-attention在视觉特征中融入文本语义
  - V2T Adapter (Vision-to-Text)：将去噪后的视觉特征映射为文本提示的实例自适应偏移，使文本描述适应具体图像内容；ΘV2T是一个轻量MLP，输入为视觉特征z(k)(x)（d维），输出为偏移δ(k+1)（其形状与可学习上下文token相同）。Compose模块通过一个更小的MLP将δ(k+1)转换为每个可学习上下文token的加性偏置，与固定类名token拼接后输入冻结文本编码器
  - Multi-View Aggregation：通过多个随机增强视图的预测加权平均，抑制单次增采样引入的噪声，提高鲁棒性；对输入图像x进行N_views次随机增强（如随机ResizedCrop），每个增强视图单独通过CLBP闭环得到logits ℓ_i，然后使用softmax权重（基于熵或置信度）进行加权平均，得到最终预测
- 公式/目标函数/指标定义：
  - 余弦相似度预测：p(y=c|x) = exp(⟨z(x), w_c⟩/τ) / Σ_j exp(⟨z(x), w_j⟩/τ)
  - T2V步：P(k)=ΦT2V(W(k)), z(k)(x)=Norm(fV(x|P(k)))
  - V2T步：δ(k+1)=ΘV2T(z(k)(x)), w_c^{(k+1)}=Norm(fT(Compose(t_c^{(0)}, δ(k+1))))
  - 闭环更新映射：Tx = Hx∘G，其中G: z→W(z)（V2T），Hx: W→Norm(fV(x|ΦT2V(W)))（T2V）
  - 最终logits：ℓ(x)=s·z(N)(x) (W(N)(x))^⊤
  - 训练总损失：L = λ_ce L_ce + λ_kl L_kl + λ_margin L_margin，其中L_ce为对抗样本的交叉熵，L_kl为对抗logits与干净logits的KL散度，L_margin为边际损失max(wrong - gt + m, 0)
- 算法细节：
  - 闭环迭代：从语义锚初始的文本原型W(0)开始，通过T2V生成视觉提示，得到增强视觉特征；再通过V2T生成文本偏移更新文本原型；单次迭代（N=1）即接近不动点，因此推理时只循环一次
  - 固定点分析：证明闭环映射Tx在语义锚附近是压缩的（局部Lipschitz常数q<1），因此单步更新后即接近不动点，避免多次迭代的计算开销
  - Compose机制：V2T输出δ(k+1)通过一个轻量MLP映射为每个可学习上下文token的加性偏置，类名token保持固定（使用原始词嵌入）
  - 多视图聚合：对每个增强视图独立执行闭环，得到logits后使用softmax加权（权重为1/熵或直接平均），最终预测为聚合logits的argmax
- 训练/推理细节：
  - 训练阶段：冻结CLIP图像和文本编码器，仅训练T2V适配器、V2T适配器和可学习上下文token（初始化为CoOp的上下文）
  - 每一训练迭代：先对干净图像生成干净logits（用于KL散度），再对对抗样本（PGD-3攻击）执行闭环得到对抗logits，计算三部分损失之和
  - 使用对抗训练：对每个训练图像生成对抗样本，攻击目标为分类损失，攻击步数3步，ϵ=4/255，步长1/255
  - 推理阶段：输入图像经过随机增强（如随机ResizedCrop）得到多个视图，每个视图通过一次闭环（N=1）得到logits，最后多视图加权平均
  - 训练超参数：学习率0.0001，权重衰减0.1，训练轮数10（ImageNet）或更少（其他数据集），使用SGD优化器

### 9. Normal Guidance is what Attention Needs
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.27306v1
- 方法流程：
  - 输入：3D CT扫描，每个2D切片作为一个实例，仅提供扫描级标签。
  - 步骤1：使用预训练编码器（如ResNet）将每个切片映射为嵌入向量。
  - 步骤2：通过注意力池化（如ABMIL或TransMIL）计算每个切片的注意力权重，并聚合为袋级嵌入。
  - 步骤3：袋级嵌入经线性分类器得到扫描级预测概率。
  - 步骤4：训练时，损失函数包含二分类交叉熵和Normal Guidance正则项（散度乘以超参数λ）。正则项计算：根据当前注意力权重计算经验均值E[J]和方差Var(J)，构造离散正态参考分布r_i，然后计算r_i与注意力a_i之间的散度（如平方误差、前向KL或反向KL）。
  - 输出：训练后的注意力权重可用于切片级定位，扫描级预测用于分类。
- 关键模块/机制：
  - 注意力池化（ABMIL / TransMIL）：将实例嵌入聚合为袋级嵌入，同时输出每个实例的注意力权重。；ABMIL使用可学习的注意力网络计算权重；TransMIL使用多头自注意力建模实例间依赖。
  - Normal Guidance正则化：约束注意力分布服从钟形曲线，提升定位性能。；每个批次前向传播时，根据当前注意力权重计算经验均值和方差，然后构建离散正态参考分布（对正态PDF在整数索引上归一化）。在损失函数中加入D(r_i, a_i)项，其中D可为平方误差或KL散度。反向传播时对r_i使用stop-gradient。
  - 散度计算模块：量化参考分布与注意力分布之间的差异。；支持三种散度：平方误差（对称，鼓励均值）、前向KL（模式覆盖）、反向KL（模式寻求）。
  - Multi-Head Normal Guidance：允许注意力在多个头部中呈现多峰分布，适用于多个相关区域。；对每个注意力头独立应用Normal Guidance，每个头有自己的经验均值和方差。
- 公式/目标函数/指标定义：
  - 引导目标函数: L_Guided = (1/N) Σ_i ℓ_BCE(y_i, ŷ_i) + λ D(r_i, a_i)
  - 离散正态参考分布: r_ij = NormPDF(j | E[J], Var(J)) / Σ_k NormPDF(k | E[J], Var(J))
  - 经验均值和方差: E[J] = Σ_j j·a_ij, Var(J) = Σ_j j²·a_ij - (E[J])²
  - 散度选项: 平方误差 D(r_i, a_i) = Σ_j (r_ij - a_ij)²; 前向KL D_KL(r_i || a_i) = Σ_j r_ij log(r_ij / a_ij); 反向KL D_KL(a_i || r_i) = Σ_j a_ij log(a_ij / r_ij)
- 算法细节：
  - 在每个训练批次中，先通过前向传播计算注意力权重a_i和袋级预测ŷ_i。
  - 对每个袋，根据a_i计算E[J]和Var(J)（使用整数索引j从1到S_i）。
  - 构造离散正态参考分布r_i：计算每个j处的正态PDF值（均值=E[J]，方差=Var(J)），然后归一化使得和为1。
  - 计算r_i与a_i之间的散度D(r_i, a_i)，注意在反向传播时对r_i使用stop-gradient，确保梯度只更新a_i。
  - 总损失为BCE损失加上λ乘以散度。
- 训练/推理细节：
  - 训练：仅使用扫描级标签，超参数λ通过验证集选择，λ通常取0.1或1.0。
  - 所有模型使用相同的预训练编码器（冻结特征），在弱监督设置下训练。
  - 推理：注意力权重直接用于定位，扫描级预测通过分类器得到。
  - 不使用切片级标签进行训练或超参数选择。

### 13. Tool-Schema Compression Enables Agentic RAG Under Constrained Context Budgets
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.26165v1
- 方法流程：
  - 1. 上下文预算形式化：定义零和分配模型 B_RAG = B - B_sys - B_schema(f,n) - B_hist - B_out，计算可用检索token数
  - 2. 工具模式压缩：使用TSCG保守压缩规则（确定性、结构保留）将JSON Schema压缩50%，从~11K token降为~5.5K
  - 3. Agent循环（ReAct风格）：最多3步迭代，每步接收系统提示、压缩后工具模式、检索chunks（按B_RAG预算填充）、对话历史；输出工具调用或最终答案
  - 4. 评估：计算Exact Match和Token F1，使用配对Wilcoxon符号秩检验和bootstrap置信区间
- 关键模块/机制：
  - 上下文预算模型：形式化工具模式与检索chunks的零和资源竞争；给定总上下文窗口B，系统提示350 token，工具模式成本Bschema(f,n)，对话历史1500 token，输出512 token，可用检索预算B_RAG = B - 350 - Bschema - 1500 - 512。当Bschema> B_RAG时发生溢出，检索chunk数k=0。
  - TSCG保守压缩器：对JSON Schema进行确定性结构保留压缩，节省44-50% token；采用基于规则的压缩策略：移除可选字段、简化为缩短的键名、压缩枚举值、合并相邻属性等。保留所有参数的必需性、类型和描述语义，确保工具调用准确性不变。
  - NovaTech-28基准：模拟中型技术公司的agentic RAG场景，提供28个工具和40个检索chunks；包含100个问题，分为单跳文档(25)、单跳数据库(25)、多跳(20)、工具需求(20)、不可回答(10)。每个问题需要1-3个金chunks。chunks平均350 token，总共14000 token。
  - ReAct Agent循环：执行工具选择和答案生成的多步推理；最多3次迭代：每次迭代，模型观察系统提示、工具模式、检索chunks（按预算填充）和历史，然后输出工具调用（包含工具名和参数）或最终答案。工具结果追加到历史中。
- 公式/目标函数/指标定义：
  - B_RAG = B - B_sys - B_schema(f,n) - B_hist - B_out
  - Exact Match (EM): 1 iff 模型最终答案与标准答案（归一化后）完全匹配
  - Token F1: 预测答案与标准答案在token级别的精确率与召回率的调和平均
- 算法细节：
  - 上下文预算计算：根据总窗口大小B、工具数n、格式f，计算Bschema，再得B_RAG。若B_RAG<0则溢出，无法检索；否则根据平均chunk大小c_bar计算可填充chunk数k=floor(B_RAG/c_bar)，并采用自适应截断确保至少1个chunk
  - TSCG压缩规则：确定性规则集，包括删除不必要字段（如additionalProperties）、缩短键名、压缩枚举值为编号、移除默认值描述等，保持JSON Schema语法有效
  - ReAct循环：初始提示包含系统prompt、工具schemas（压缩或未压缩）、RAG chunks（按上文代码填充）、对话历史为空；模型生成token，若包含函数调用则执行并将结果以system消息追加，最多3轮；若模型给出最终答案则停止
  - 分心稀释效应分析：当TSCG提供更多chunks（如16K下25-28个）时，小模型（≤8B）受中间信息丢失影响，EM下降，作者拟合模型C(k)=C_max(1-e^{-λk})+C0
- 训练/推理细节：
  - 无训练组件，所有模型均为预训练模型，推理时使用确定性TSCG压缩
  - 推理时所有模型（1.5B-32B + Claude Sonnet 4）通过Ollama本地部署或API调用，使用ReAct agent框架，温度等超参数固定
  - 唯一变量为工具模式格式（json或tscg），确保性能差异仅来自预算机制

  - 轨迹定义：τ = [(I0, q), (r1, a1, I1), (r2, a2, I2), ..., y]，其中rt是思想，at是动作，It是草图，y是最终答案。

  - RL优化：使用PPO算法，奖励由逐步奖励和最终答案奖励加权组合。逐步奖励在每一步工具执行后立即给出，实现密集奖励。
  - 错误注入方式：参数错误示例——在排列操作中产生重复索引；推理路径错误示例——基于错误的历史上下文生成不合理的动作。

  - 两阶段训练：第一阶段使用92k合成轨迹进行SFT；第二阶段在SFT模型上使用RL（PPO）优化，逐步奖励权重调参。
  - 推理过程：模型进行多轮生成，每轮输出<think>思想文本和<tool_call>动作命令，外部工具执行后新草图加入上下文，直至生成<answer>。支持任意多轮，无需预设步数。
  - 训练数据：合成数据集涵盖几何推理、空间导航、视觉搜索、OCR数学、拼图、迷宫等任务，每个样本包含完整的交错轨迹和反思步骤。

## 摘要
口内扫描图像分割对于数字牙科中的计算机辅助诊断和治疗规划至关重要。然而，现有的视觉状态空间模型（SSMs）通常依赖手动设计的扫描顺序将图像块展平为序列，这破坏了语义空间连续性，并阻碍了从关键前景区域中提取连贯特征。此外，数据采集过程中光照不一致、反射表面和噪声等因素会破坏频率分布，削弱高频细节同时增强低频分量，从而妨碍边界的准确定位。针对这些挑战，我们提出了FU-Mamba，一种在SSM架构中集成动态扫描和频域增强的创新框架。具体来说，动态Mamba块（DMB）通过可训练的偏移预测网络自适应学习采样偏移，并执行灵活的双线性插值，从而实现保留空间连贯性的内容感知扫描。此外，频域增强块通过小波引导的分解和频谱池化平衡频谱分量，提高了在不利成像条件下的鲁棒性。实验结果表明，FU-Mamba在牙科分割数据集上取得了显著的分割精度提升，平均交并比（mIoU）指标提高了1.1%。项目页面：https://byte2bite.github.io/FU-Mamba/

## Abstract
Oralscan image segmentation is essential for computer-aided diagnosis and treatment planning in digital dentistry. However, existing visual state space models (SSMs) often rely on manually designed scanning orders to flatten image patches into sequences, which disrupts the semantic spatial continuity and hinders coherent feature extraction from key foreground regions. Moreover, elements such as inconsistent lighting, reflective surfaces, and noise during data acquisition disrupt the frequency distribution by diminishing high-frequency details while enhancing low-frequency components, consequently hindering the accurate localization of boundaries. In response to these challenges, we introduce FU-Mamba, an innovative framework that incorporates dynamic scanning and frequency domain enhancement within the SSM architecture. Specifically, the Dynamic Mamba Block (DMB) adaptively learns sampling offsets via a trainable offset prediction network and performs flexible bilinear interpolation, enabling content-aware scanning that preserves spatial coherence. Furthermore, a frequency domain enhancement block balances spectral components through wavelet-guided decomposition and spectrum pooling, improving robustness under adverse imaging conditions. Experimental findings indicate that FU-Mamba attains a notable enhancement in segmentation accuracy, evidenced by a 1.1% increase in the mean intersection over union (mIoU) metric when evaluated on the dental segmentation dataset.   - **频率分布失衡**：口腔图像在采集过程中常受到**光照不均、牙齿及金属修复体表面反射、运动模糊、噪声**等因素干扰，这些伪影会削弱高频细节（如边缘、纹理）并将能量向低频转移，使模型难以准确定位牙齿边缘、牙龈形态等精细结构。
- **整体意义**：论文旨在解决数字牙科中复杂口腔环境下图像分割鲁棒性不足的问题，将**内容自适应动态扫描**与**频域均衡增强**两者融入 SSM 框架，为 Mamba 架构在医学图像分割中的应用提供了新思路，同时为低光照、强噪声等不利条件下的牙科分割提供了更优方案。

## 2. 论文提出的方法论

### 2.1 总体架构
- 论文提出 **FU-Mamba**，基于 **U-Net 架构**，由编码器、解码器和跳跃连接构成：
  - 编码器由多个 **DMB（Dynamic Mamba Block，动态 Mamba 块）** 堆叠而成；
  - 跳跃连接由 **FEB（Frequency Enhancement Block，频域增强块）** 构建。

### 2.2 动态 Mamba 块（Dynamic Mamba Block, DMB）
- **核心思想**：放弃固定的手工扫描路径，改为根据输入图像内容**自适应地学习采样位置和扫描顺序**。
- **关键组件——偏移预测网络（OPN）**：
  - 轻量级结构：3×3 深度卷积 → Layer Normalization → GELU 激活 → 线性投影。
  - 输出每个图像块的坐标偏移量 Δr，限定在归一化坐标范围 [-1,1] 内；并通过 tanh 约束在 [-0.25, 0.25] 之间，保证动态采样的稳定性。
- **动态采样过程**：
  1. OPN 从特征图 X 预测偏移 Δr；
  2. 更新采样坐标：p' = p + Δr；
  3. 利用**双线性插值**（bilinear interpolation）从特征图中获取对应位置的特征；
  4. 将所有越界坐标裁剪回有效范围内，避免无效采样；
  5. 根据 p' 的空间邻近关系对采样后的特征进行**重新排序**（sort），再送入 SSM 进行序列建模。
- **算法流程**（Algorithm 1）：特征图输入 → 偏移预测 → 坐标更新 → 双线性采样 → 语义感知排序 → 序列化输出。
- **设计优势**：动态调整采样位置使模型能够聚焦关键前景区域（如牙齿）而忽略无关背景；同时所学的采样偏移隐式提供了相对位置信息，帮助 SSM 更好地捕捉局部特征关系。该模块在四个编码器阶段均被采用，通道数配置为 {64, 128, 256, 512}。

### 2.3 频域增强块（Frequency Enhancement Block, FEB）
FEB 由两个关键子模块构成：

#### （1）小波引导的频谱池化模块（WSPM）
- **动机**：受人类视觉系统对比度敏感函数启发——人眼对**中频信号**最敏感，因此该模块在增强低频的同时平衡融入高频细节，将频谱分布向中频引导。
- **DWT-Conv（深度小波卷积）**：
  - 使用单层 Haar 小波变换，将特征分解为 LL、LH、HL、HH 四个子带：
    [X_LL, X_LH, X_HL, X_HH] = DWT(X)
  - 将四个子带沿通道拼接后通过 1×1 卷积进行跨频带建模，再切分为四个增强子带，最后通过逆小波变换（IWT）重构特征，并引入残差连接和 Layer Normalization。
  - 使用**固定 Haar 小波核**而非可学习基，以保持分解稳定性并避免额外参数。
- **多分支设计**：WSPM 采用多分支结构，结合 1×n/n×1 可分离卷积增强方向敏感性，以及膨胀率 {1, 3, 5, 7} 的膨胀卷积扩大感受野，最后通过 1×1 卷积进行自适应通道融合。
- **低通半径自适应设置**：低频区域的圆形半径 r = min(H, W)/8，随各编码器阶段特征图分辨率动态调整。

#### （2）频谱池化滤波器（SPF）
- **流程**：将空间特征经 2D DFT 变换至频域 → 频谱中心化 → 划分为低频分量 S_lf 和高频分量 S_hf → 分别经逆变换回空间域 → 按权重融合：
  Z̃ = λ·f_lp(Z) + (1-λ)·f_hp(Z)
- **作用**：抑制高频噪声干扰，保持低频结构信息，其中 λ 在实验中设为 0.7（低通分量占比更大）。

### 2.4 损失函数
- **分割损失**：L_seg = L_Dice + L_CE（Dice 损失 + 交叉熵损失），缓解多类牙科分割中的类别不平衡问题。
- **偏移正则化损失**：L_reg = (1/N) Σ||Δr_i||²₂，约束采样偏移的幅度，保证动态采样的平滑性和稳定性。
- **总损失**：L = L_seg + λ_reg·L_reg，其中 λ_reg = 0.01。

1. **动态扫描相比固定扫描显著更优**：DMB 相比连续扫描（CS）在 DSD 上 mIoU 提升 1.2%，相比局部扫描（LS）提升 0.7%，证明了内容自适应扫描策略在保持空间连续性、聚焦关键区域方面的有效性。

## 8. 不足与局限

1. **对极端条件的鲁棒性仍有限**：论文承认，在严重噪声、强反射、低对比度和牙结石遮挡等极端条件下，模型仍会出现边界泄漏与局部结构遗漏。DMB 在局部特征不可靠时可能产生不稳定的采样偏移，FEB 在高频噪声占主导时也难以有效区分边界信号与干扰。
2. **对比方法覆盖不够全面**：虽然对比了 12 种方法，但未包含论文参考文献中提到的较新的医学图像分割方法（如 MedSAM-Agent、P2SAM、GTP-4O 等前沿模型），也没有与 3D 分割方法对比。论文提到 OralVision 数据集可能包含 3D 特性，但仅进行了 2D 评价。
3. **训练细节报告不完整**：未明确说明训练所需的总 GPU 小时数或多 GPU 并行训练策略，复现成本难以精确评估。
4. **可视化分析样本量偏少**：定性的可视化结果展示（图 5、图 7、图 8）均只展示了少量示例图像，虽然分析文字较详细，但样本丰富度有限。
5. **频率增强模块的泛化性有待验证**：FEB 和 DMB 的设计虽然在牙科场景中验证成功，但其在自然图像或 CT、MRI 等其他医学模态中的推广价值未被实验证明。
6. **数据来源限制**：数据集包含的临床病例多样性、设备类型覆盖面未被详细说明，模型的跨中心、跨设备泛化能力尚未验证。

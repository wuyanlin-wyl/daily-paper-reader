## 摘要
视觉语言模型（VLMs）在临床流程中的应用日益增多，在这些流程中，胸部X光片会与检索到的报告、初步笔记或既往影像一起被解读。现有基准测试衡量的是模型在孤立条件下能否正确回答，而非在合理上下文与图像冲突时，模型是否能保持基于图像本身的正确决策。我们提出了多情境胸部X光基准（MC-CXR），这是一个包含240个病例、扩展为2,522个实例的基准，通过配对扰动来隔离上下文诱发的干扰。每个病例固定当前图像和目标发现，同时跨文本和既往CXR提供匹配的可靠与误导性上下文，并在可用时提供视觉叠加层。MC-CXR定义了三个任务族和两个配对指标，即“转错率”和“上下文一致错误率”。我们评估了十个VLM，涵盖开源通用模型、医学领域模型和闭源系统。仅基于图像的准确性是必要但不充分的。误导性文本来源的平均转错率为45.6%-78.1%，误导性视觉来源的平均转错率为35.7%-61.7%。在转变的预测中，文本有74.6%与误导性标签一致，而视觉上下文仅有17.6%，差距为57.0个百分点（95% CI 50.9-62.8）。这种文本-视觉不对称性在标准化直接回答协议下可观察到。该数据集可在PhysioNet上获取。

## Abstract
Vision-language models (VLMs) are increasingly used in clinical pipelines where a chest X-ray is interpreted alongside retrieved reports, preliminary notes, or prior imaging. Existing benchmarks measure whether models answer correctly in isolation, but not whether they preserve a correct image-only decision when plausible context conflicts with the image. We introduce Multi-Context Chest X-ray (MC-CXR), a benchmark of 240 cases expanded into 2,522 instances that isolates context-induced disruption through paired perturbation. Each case fixes the current image and target finding while presenting matched reliable and misleading context across text and prior CXR, with visual overlays where available. MC-CXR defines three task families and two paired metrics, the switch-to-wrong rate and the context-aligned error rate. We evaluate ten VLMs spanning open-source general, medical-domain, and closed-source systems. Image-only accuracy is necessary but insufficient. Mean switch rates range from 45.6-78.1% across misleading textual sources and 35.7-61.7% across misleading visual sources. Among switched predictions, 74.6% align with the misleading label for text versus 17.6% for visual context, a 57.0-point gap (95% CI 50.9-62.8). This text-visual asymmetry is observed under the standardized direct-answer protocol. The dataset is available on PhysioNet.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉语言模型（VLMs）越来越多地被整合到临床工作流中，在解读当前胸部X光片（CXR）的同时，模型还会接收检索到的既往报告、初步笔记（preliminary notes）或既往影像作为辅助上下文。在放射科实践中，结合临床指征、既往影像和既往报告是诊疗标准的一部分。
- **核心问题**：现有医学VQA 与 CXR 基准（如 ReXVQA、MS-CXR-T、MI-CXR）只评估模型在孤立条件下的识别能力，或假设上下文可靠并测试模型的利用能力，但均未回答一个关键问题：**当临床上下文与当前图像证据发生冲突时，模型能否保持基于图像本身的正确决策？**
- **研究空白**：仅用聚合准确率衡量模型能力会掩盖一种临床安全风险——模型可能“静默地”屈从于不可靠的外部证据，放弃自己原本正确的图像判断。这种上下文诱发的不稳定既不同于文本领域的阿谀奉承（sycophancy），也不同于知识冲突（knowledge conflict），但在多模态临床场景中缺乏系统性的评测工具。
- **核心主张**：作者将“有条件地使用上下文”定义为 **上下文鲁棒的视觉推理（context-robust visual reasoning）** ，需要四种子能力：识别当前图像证据、解析上下文来源、识别图像与上下文的一致/冲突、以及决定冲突时由哪个证据源主导答案。其中，**仲裁（arbitration）** 能力是现有基准完全没有触及的部分，也是 MC-CXR 的直接评测目标。

### 2. 方法论

- **总设计思路**：MC-CXR 采用 **配对扰动（paired perturbation）** 设计——固定当前图像 Iᵢ 和目标发现 Xᵢ，仅改变上下文的可靠性与模态。每个病例都包含可靠与误导两种配对的上下文变体，以此区分“模型是否会使用上下文”与“模型是否能分辨何时该使用上下文”。
- **三种任务族**：
  - **IOR（Image-only Recognition，纯图像识别）**：模型仅根据当前图像从12个标签中选择目标发现，作为无上下文的基线；
  - **RCS（Reliable Context Stability，可靠上下文稳定性）**：模型在收到与图像一致的可靠上下文后，能否保持原本正确的图像决策；
  - **MCR（Misleading Context Resistance，误导上下文抵抗）**：模型在收到临床合理但指向错误标签的误导上下文后，能否抵抗这种干扰并维持正确的图像判断。
- **五种上下文来源、三种模态**：
  - **文本**：临床指征（indication）、既往报告（prior report）、初步笔记（preliminary note）；
  - **视觉—既往影像**：同一患者或不同患者的既往 CXR；
  - **视觉—叠加标注**：PACS 风格的箭头叠加层，指向病灶（on-finding）或偏离病灶（off-finding）。
- **两个核心指标**（均仅在模型 IOR 正确的子集上计算，以隔离上下文干扰与基础识别错误）：
  - **Switch-to-wrong rate（转错率）**：P(C→W | c) = 在上下文条件 c 下，原本图像判断正确的样本中预测翻转的比例；
  - **Context-aligned error rate（上下文一致错误率）**：P(W_Y | C→W, c) = 在所有翻转错误中，预测恰好落在误导上下文所暗示的标签 Y 上的比例。
- **设计原则**：当前图像优先、配对扰动（可靠 vs 误导保持 Iᵢ 和 Xᵢ 不变）、方向性错误归因（误导上下文必须明确指向一个具体标签 Y，以便将错误归因于上下文牵引而非随机不稳定）。
- **评测协议**：零样本约束字母多项选择（A–L 对应12个标签），强制模型输出单个字母，无弃权选项，解析失败记为错误。

### 3. 实验设计

  - 基础数据来源：MIMIC-CXR 与 MIMIC-CXR-JPG；

  - 放射科医师在 240 例中有 26 例（10.8%）覆盖了 CheXpert 源标签的误标，说明人工审核环节的必要性。

### 6. 主要结论与发现

- **图像-only 准确率必要但不充分**：所有模型的 IOR 准确率仅为 8.3%–35.8%，Cohen's κ 最高为 0.282（NV-Reason-CXR-3B），处于“微弱至一般”的一致性范围，说明基础识别能力本身就很薄弱。
- **误导性文本是更强的干扰源**：重写的初步笔记导致 78.1% 的图像正确决策被翻转，其中有 85.3% 落在误导标签上；既往报告和临床指征的翻转率分别为 60.9% 和 45.6%，对齐率均为约 64%。
- **误导性视觉是“干扰但不是定向牵引”**：跨患者既往影像翻转率 35.7% 但 Y 对齐率仅 18.0%；偏离病灶的箭头叠加翻转率高达 61.7% 但 Y 对齐率仅 16.5%。视觉干扰使模型“迷失”但不使模型“跟随”。
- **文本—视觉不对称性显著且稳健**：合并十模型数据后，文本误导产生的翻转错误中 74.6% 对齐误导标签，视觉仅为 17.6%，差距 57.0 个百分点；排除最强条件后差距仍有 47.7 个百分点；所有 10 个模型均表现出一致方向（符号检验 p = 0.002）。
- **可靠上下文也并非安全**：即使上下文与图像一致，模型平均仍有 28.8% 的概率放弃原本正确的答案；其中指向病灶的箭头叠加竟是最具破坏性的可靠条件（42.4% 翻转率）。
- **领域专业化不能提供免疫**：医学领域模型（MedGemma、NV-Reason-CXR）在误导文本条件下也出现显著翻转，其图像到误导笔记的准确率落差（12.5–17.5 个百分点）甚至大于其他类别。

### 7. 优点

- **问题定义精准且有临床意义**：将“上下文鲁棒性”从“识别准确率”中分离出来，提出了可直接量化的仲裁能力评估框架，填补了现有基准的空白。
- **配对扰动设计干净有力**：固定当前图像和目标标签，仅操控上下文的可靠性和模态，因果归因清晰；可靠/误导条件的对照天然剔除了“是否使用上下文”与“使用方式是否正确”的混淆。
- **方向性错误归因指标设计精妙**：通过强制误导上下文指向一个具体标签 Y，使得“转错率”（测干扰强度）和“上下文一致错误率”（测干扰方向性）正交互补，能区分“随机不稳定”与“系统性被上下文牵引”。
- **多模态、多源头的上下文覆盖**：同时涵盖指示文本、报告文本、初步笔记、既往影像和视觉叠加五类上下文，是目前 CXR 评测中覆盖最全面的基准。
- **承认基准构建过程中的主观性与噪声**：放射科医师覆盖了 10.8% 的自动标签错误，并提供了第二读者审计和提示词敏感性测试作为附加证据，增强了可信度。
- **开源发布且避免数据泄露风险**：不重新分发原始 MIMIC-CXR 影像，仅提供可复现的数据标识符，符合 PhysioNet 数据使用规范。

---

### 8. 不足与局限

- **IOR 准确率过低带来条件化子集的脆弱性**：最低的模型（Llama-3.2-11B-V）只有 20 个 IOR 正确案例，条件化后的切换率统计稳定性不足；即便 κ 高于 0.2 的模型，也无法排除机会校正（chance-correct）的样本混入。
- **单次确定性运行的统计效力有限**：所有报告为单次运行结果，没有多次采样或置信区间（除对齐差异的 bootstrap 外），对模型的随机性缺乏刻画。
- **单医生标注与验证覆盖不全**：主要标注由一位委员会认证的放射科医生完成；第二读者审计仅覆盖 51 例和 3 个文本误导条件，未验证既往影像和叠加箭头条件的 Y 可识别性；视觉条件低对齐率可能部分源于误导视觉线索的区分度不足，而非单纯的模态偏好。
- **协议依赖性强**：结果基于固定格式的约束字母选择题；在 GPT-5.5 上的冲突感知提示试点中，误导文本的翻转率显著下降（如初步笔记从 76.7% 降至 41.1%），说明现象存在—但严重程度高度依赖提示词设计。
- **闭源 API 的不可复现性**：闭源模型使用服务别名而非固定版本快照，无法保证后续复现时后端一致；论文中存储的预测与试点运行时的预测存在少量差异（d2 有 5 例、e2 有 8 例不同）。
- **可靠上下文条件的隐含缺陷**：除初步笔记外，可靠的指征和既往报告来自真实临床资料而非验证必须指向 X；因此 RCS 条件下的切换可能混入了“部分上下文不匹配”的因素，而不仅是“在一致证据下的不稳定性”。
- **可推广性受限**：单一数据集（MIMIC-CXR）、单一人群、单一语言（英文）、单一体位（前后位）、12 标签限制和强制选择设计，限制了结果向自由文本报告、其他模态（如 CT）或更丰富标签空间的推广。

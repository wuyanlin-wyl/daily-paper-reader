## 摘要
指代表达式分割（RES）旨在为语言表达式指定的对象生成像素级掩码。最近基于多模态大语言模型（MLLMs）的方法通常依赖单次坐标预测进行视觉定位，这将连续的空间位置序列化为离散的文本令牌，可能导致定位偏差和对齐错误。为解决这些问题，我们提出了DRAgent，一种用于RES的MLLM驱动的判别式推理（DR）框架。DRAgent不要求MLLM生成定位坐标，而是首先构建一个检测器生成的候选空间，然后将MLLM用作视觉语义目标判别器。具体来说，MLLM通过两阶段DR机制在潜在干扰物中进行可靠的目标选择，该机制首先筛选高召回率候选，然后进行实例级验证。所选的目标框随后用作基础分割模型的空间提示，以生成最终的像素级掩码。此外，我们构建了一个自一致性过滤的推理链数据管道，用于基于LoRA的微调，为增强MLLM的判别式推理能力提供更可靠的监督。实验表明，DRAgent在RefCOCO、RefCOCO+和RefCOCOg上取得了有竞争力的性能。

## Abstract
Referring Expression Segmentation (RES) aims to generate a pixel-level mask for the object specified by a language expression. Recent methods based on multimodal large language models (MLLMs) often rely on one-pass coordinate prediction for visual localization, which serializes continuous spatial locations as discrete text tokens and may lead to localization bias and alignment errors. To address these issues, we propose DRAgent, an MLLM-driven discriminative reasoning (DR) framework for RES. Instead of requiring the MLLM to generate localization coordinates, DRAgent first constructs a detector-generated candidate space and then uses the MLLM as a visual-semantic target discriminator. Specifically, the MLLM performs reliable target selection among potential distractors through a two-stage DR mechanism, which first screens high-recall candidates and then performs instance-wise verification. The selected target box is subsequently used as a spatial prompt for a foundation segmentation model to produce the final pixel-level mask. Furthermore, we construct a self-consistency-filtered reasoning-chain data pipeline for LoRA-based fine-tuning, providing more reliable supervision for enhancing the MLLM's discriminative reasoning capability. Experiments demonstrate that DRAgent achieves competitive performance on RefCOCO, RefCOCO+, and RefCOCOg.

### 1. 论文的核心问题与整体含义（研究动机和背景）

指代表达式分割（Referring Expression Segmentation, RES）的核心任务是根据自然语言表达，在图像中生成对应目标物体的像素级掩码，在机器人、辅助驾驶等感知-控制系统中具有重要应用价值。

**研究动机：**
- 近年来，基于多模态大语言模型（MLLMs）的RES方法通常将视觉定位视为**生成式坐标预测**问题——MLLM以自回归方式输出边界框坐标，作为下游分割模型（如SAM）的空间提示。

**论文指出的两大核心问题：**
1. **定位偏差与对齐错误**：坐标被序列化为离散文本token，破坏了坐标的连续性及其空间关系，易导致定位粗糙或偏置；在目标密集、外观相似的复杂场景中，单次（one-pass）定位方法易与干扰物混淆。
2. **推理链数据缺乏可靠验证**：现有方法依赖人工标注或外部MLLM生成的推理链数据来训练模型，人工标注成本高、难以规模化；外部生成则易产生逻辑不一致的推理，导致模型学习到不稳定或错误的推理模式。

**核心论点：**
论文主张RES的理想路径不应是让MLLM"生成"坐标，而是引入**判别式目标选择器**——由MLLM在候选空间中通过筛选和实例级验证来选出所指对象，同时将**闭环一致性**（closed-loop consistency）作为推理链数据可靠性的信号。

### 2. 论文提出的方法论

#### 核心思想
DRAgent将MLLM的角色从"视觉定位生成器"**重构为"视觉语义判别器"**，将RES任务分解为三阶段级联管线：候选目标检测 → 判别式目标选择 → 像素级分割。

#### 整体管线公式
整个任务表示为复合映射：
`M = f_seg(I, Φ_select(I, Q, g_det(I, LLM(Q))))`
其中：
- `g_det`：开放词汇检测器（Grounding DINO），构建候选空间
- `Φ_select`：核心判别式目标选择模块（两阶段DR）
- `f_seg`：分割模型（SAM），将目标框转化为像素级掩码

#### 关键技术细节

**（1）候选目标检测**
- 用LLM从查询文本Q中提取目标类别L = LLM(Q)
- 将类别输入开放词汇检测器Grounding DINO，获得候选集合O = {o₁, o₂, ..., oₙ}，每个候选由边界框表示

**（2）两阶段判别式推理机制（Two-Stage DR）**

*阶段一：候选级初步筛选（Candidate-Level Preliminary Screening）*
- 在图像上以索引化的Set-of-Mark (SoM)边界框可视化所有检测候选
- MLLM选出与查询最匹配的Top-K候选
- 为弥补密集布局下MLLM判断的不足，补充与所选框IoU超过阈值γ的候选，得到第二阶段候选集O_top

*阶段二：基于验证分数的实例级判别验证（Discriminative Verification）*
- 每个候选框单独渲染SoM标注后，通过指令Prompt_DR(Q)引导MLLM进行二选一回答："Look at the red bounding box. Does it tightly enclose the object described as '{Q}'? Answer yes or no."
- 不使用简单的argmax解码（易受概率分布模糊影响），而是定义验证分数：

`S_i = exp(z_i,V_pos) / [exp(z_i,V_pos) + exp(z_i,V_neg)]`

其中V_pos和V_neg分别对应肯定/否定答案token集合，z_i,V表示平均logits。
- 最终目标为验证分数最高的候选：`t = argmax S_i`

**（3）自一致性过滤的推理链数据管道**
- 阶段1（自一致性生成）：渲染目标区域（可能是真目标或硬负样本干扰物），让MLLM输出结构化JSON格式的推理链R₁、视觉描述D₁和答案A₁
- 阶段2（自我验证）：用D₁构造新查询Prompt_CoT(D₁)，进行闭环验证，得到推理链R₂和答案A₂
- 仅当A₁与真实标签一致且A₂确认重建描述为"Yes"时，该推理链样本才被保留用于训练

**（4）训练策略**
- 使用过滤后的推理链数据进行LoRA-based SFT（监督微调）
- 在视觉层和语言层均应用LoRA，rank和α都设为16

### 6. 论文的主要结论与发现

1. **判别式推理优于生成式坐标预测**：将MLLM作为目标判别器（而非坐标生成器）的设计能有效缓解定位偏差，尤其是在表达更复杂、更组合式的RefCOCOg上优势明显——DRAgent在RefCOCOg val(U)达76.78%、test(U)达77.54%，均为最佳结果。
2. **两阶段DR机制显著提升选择精度**：从baseline的66.84%提高到75.42%（RefCOCOg平均cIoU），证明候选筛选+实例级验证的级联设计能有效降低干扰物混淆。
3. **自一致性过滤的推理链数据优于未过滤数据**：全模型（77.16%）优于未经一致性过滤的raw CoT（74.59%）和无CoT监督（72.51%），证明文本层面的"自洽"不足以保证视觉语义对齐，需要闭环验证。
4. **参数选择的折中效应**：K=4和γ=60%时性能最优，表明候选集合需要保持召回率与噪声控制间的平衡。
5. **在RefCOCO和RefCOCO+上**：DRAgent取得competitive而非state-of-the-art的成绩，总体表现与近期显式定位生成器方法相当，但未完全超越。

### 7. 优点

**方法论层面的亮点：**

1. **问题重构新颖**：将RES中的视觉定位从"坐标生成"重构为"候选判别选择"，从范式层面回应了MLLM坐标序列化带来的根本性缺陷，具有较清晰的洞察力。
2. **解耦式设计**：将候选生成（检测器）与目标判别（MLLM）分离，各模块可独立优化、替换，架构灵活度高。
3. **两阶段级联判别**：先高召回筛选、后实例级验证的设计符合认知上的由粗到精策略，有效控制干扰物对MLLM判断的影响。
4. **验证分数的构造**：用正负答案token集合的平均logits软分数替代单向argmax解码，增强了判别信号在候选间比较的稳定性。
5. **数据质量闭环验证**：提出"生成推理链→用描述重建做自验证→过滤不一致样本"的管道，为推理链数据可靠性提供了一种低成本、可扩展的筛选机制，而非简单信任外部生成的文本。

**实验设计层面的优点：**
- 消融设计层次分明，能清晰区分"推理机制"与"训练信号"两方面的贡献
- 对两类关键参数作了敏感性分析
- 使用较小训练预算（6K样本 + LoRA）达到竞争性能，具有成本效益方面的启示

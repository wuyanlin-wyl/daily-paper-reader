## 摘要
视觉-语言模型（VLMs）展现了卓越的视觉推理能力，然而随着视觉标记（visual tokens）的激增，其推理成本迅速上升。现有的视觉标记剪枝方法存在两个根本性局限。第一，大多数方法仅在视觉编码器之后运行，导致视觉编码阶段的大量延迟未被优化。第二，在严格的标记预算下，这些方法往往无法同时保留整体视觉上下文和细粒度细节，导致性能下降。为解决这些瓶颈，我们提出了PACE（Pixel-Adaptive Condense and Extract，像素自适应压缩与提取），这是一种无需训练的推理框架，通过统一的压缩-提取范式同时加速视觉编码器和大语言模型（LLM）。在压缩阶段，自适应像素压缩器（APC）在编码前评估视觉信息密度，自适应地下采样冗余输入，减少编码器计算量，同时保留全局上下文和关键视觉线索。在提取阶段，动态双注意力提取器（DDAE）通过融合来自编码器的内部视觉信号和来自LLM的语义信号，选择性保留视觉标记，从而保护任务关键细节。通过将PACE集成到Qwen2.5-VL-7B中，该模型在仅使用10%视觉标记的情况下保留了原始性能的93.8%，并实现了3.1倍的首令牌时间（TTFT）加速。我们的代码可在 https://github.com/jjL357/PACE 获取。

## Abstract
Vision-Language Models (VLMs) demonstrate exceptional visual reasoning capabilities, yet their inference costs escalate rapidly with the proliferation of visual tokens. Existing visual token pruning methods exhibit two fundamental limitations. First, most approaches operate exclusively post-vision encoder, leaving the substantial latency of the visual encoding phase unoptimized. Second, under strict token budgets, these methods often fail to jointly preserve holistic visual contexts and fine-grained details, leading to performance degradation. To address these bottlenecks, we propose PACE (Pixel-Adaptive Condense and Extract), a training-free inference framework that accelerates both the vision encoder and the Large Language Model (LLM) via a unified Condense-and-Extract paradigm. During the Condense stage, an Adaptive Pixel Compressor (APC) evaluates visual information density prior to encoding, adaptively downsampling redundant inputs, curtailing encoder computation while preserving global context and essential visual cues. In the Extract stage, a Dynamic Dual-Attention Extractor (DDAE) selectively retains visual tokens via a fusion of internal visual signals from the encoder and semantic signals from the LLM, safeguarding task-critical details. By integrating PACE into Qwen2.5-VL-7B, the model retains 93.8% of its original performance while utilizing only 10% of the visual tokens, yielding a 3.1x speedup in time to first token (TTFT). Our code is available at https://github.com/jjL357/PACE.

## 一、论文核心问题与研究动机

视觉-语言模型（VLMs）在视觉推理任务上表现卓越，但其推理成本随着视觉 token 数量的激增而急剧上升。现代 VLM 支持原生动态分辨率，处理高分辨率图像或长视频时会生成海量视觉 token，例如 Qwen2.5-VL 编码一张 4K 图像会生成超过 42,000 个 patch，即使经过空间池化后仍有超过 10,500 个视觉 token 进入 LLM 上下文，造成严重的推理瓶颈。

现有视觉 token 剪枝方法存在两大根本性缺陷：

1. **双瓶颈问题（Dual Bottleneck）**：绝大多数剪枝方法仅在视觉编码器之后操作（post-encoder），只优化 LLM 侧上下文序列，但忽略了视觉编码阶段本身的高昂计算开销。论文通过实验证明（图 2），在高分辨率输入下，ViT 编码和 LLM prefill 阶段共同主导推理延迟，只削减 LLM 侧序列只能解决一半瓶颈。
2. **信息与细节损失（Information and Detail Loss）**：在严格的 token 预算下（如 5%–10%），现有方法无法同时保留整体视觉上下文和细粒度细节。激进剪枝会破坏视觉布局结构、丢失关键视觉线索（如文本笔画、对齐锚点），在细节敏感任务（ChartQA、DocVQA）上性能严重下降（图 3）。

因此，论文提出需要范式转变：视觉 token 压缩应同时涵盖编码前压缩（保留布局完整性）和编码后提取（保留任务关键细节），以实现高效且高保真的推理。

## 二、方法论：PACE 框架

### 2.1 核心思想

PACE（Pixel-Adaptive Condense and Extract，像素自适应压缩与提取）是一个**无需训练**、即插即用的推理加速框架，围绕统一的“压缩-提取”（Condense-and-Extract）范式组织：

- **Condense 阶段（编码前）**：自适应像素压缩器（APC）在视觉编码前评估视觉信息密度，动态降低冗余输入的解析度，减少 ViT 计算量，同时保留全局上下文和关键视觉线索。
- **Extract 阶段（编码后）**：动态双注意力提取器（DDAE）融合 ViT 内部视觉信号与 LLM 语义信号，选择性保留关键视觉 token，保护任务关键细节。

### 2.2 Condense 阶段：自适应像素压缩器（APC）

APC 的目标是解决“静态均匀下采样会模糊细节”与“启发式丢弃 patch 会破坏 2D 拓扑布局”之间的两难。其核心流程如下：

1. **浅层特征预览（Shallow Feature Preview）**：使用 ViT 第一个 block（K=1）计算轻量级特征预览，得到 ℓ2 归一化的 token 嵌入，提供语义先验。相比 RGB 统计、熵、边缘密度、Laplacian 等像素级统计更可靠（附录 B.2 消融验证）。
2. **全局信息密度（ρg）**：计算所有视觉 token 间的平均余弦相似度 φ，定义 ρg = 1 − φ。φ 越高表示冗余越大（如大面积均匀区域），ρg 越低表示全局信息密度越低。
3. **局部细节对比（ρd）**：计算所有 token 的全局背景基线 c，然后度量每个 token 到基线的欧氏距离 di，取 top 10% 距离的均值 ¯d_top，线性缩放到 ρd = min(¯d_top/γ, 1)。这能捕捉均匀背景上稀疏但关键的高频细节（如白底文档上的微小文字），防止细节被误删。
4. **自适应压缩**：将全局与局部得分加权融合为统一保留比率 ρ = αρg + (1−α)ρd（默认 α = 0.6），据此将图像按 √ρ 因子缩放。若硬性内存预算更低，则按硬预算裁剪。

### 2.3 Extract 阶段：动态双注意力提取器（DDAE）

DDAE 解决单一注意力信号的偏置问题：仅依赖 LLM 交叉注意力会过度聚焦于文本明确引用的区域，忽略图表网格线等未提及的关键视觉锚点；仅依赖 ViT 自注意力虽能刻画视觉边界，但不受查询条件约束，常保留任务无关的背景噪声。DDAE 的融合机制如下：

1. 从指定 LLM 层（提取深度 Lext，默认第 2 层）提取语义注意力图 Sllm，min-max 归一化到 [0,1]。
2. 从 ViT 末端层提取自注意力图 Svis，同样归一化。
3. 以两种注意力图的标准差（σllm、σvis）作为无监督置信度代理，通过 Softmax 动态分配融合权重：αweight, βweight = Softmax([σllm, σvis]/τ)，其中 τ 为温度参数（默认 0.5）。
4. 最终显著性分数为 Sfinal = αweight·Sllm + βweight·Svis，保留 top-K 个视觉 token 作为 LLM 上下文。

### 2.4 计算复杂度分析（附录 C）

论文从理论上分析了复杂度削减：APC 使 ViT 编码 token 数从 N 降为 p₁N（p₁ 为保留面积比），DDAE 使 LLM prefill 长度从 T + N_cvis 缩减到 T + N_keep（最终 token 比约为 B = p₁p₂）。由于 DDAE 在 LLM 第 Lext 层提前剪枝，后续 (Ll − Lext) 层只需在短序列上计算，从而显著降低 prefill 成本。

## 六、主要结论与发现

1. **PACE 在 10% token 预算下保留 93.8% 原始性能**，平均分超过最强基线（VisionZip）12.7 个百分点，超过 FastV 13.9 个百分点。
2. **TTFT 加速 3.1 倍**：视觉编码器延迟从 148.84ms 降至 49.47ms（3.01×），LLM prefill 从 217.05ms 降至 32.69ms（6.64×）。
3. **细节敏感任务优势显著**：以 10% 预算为例，DocVQA 上 PACE 达 69.55，远超 FastV（59.56）和 VisionZip（49.55）；OCRBench 超越最强基线 17.90 个绝对点。
4. **APC 具有正交性**：增强 VisionZip 和 MMTok 后，在 ChartQA、OCRBench 上各提升 15+ 点，证明编码前压缩与现有编码后剪枝方法兼容互补。
5. **DDAE 动态融合优于单模态或固定融合**：仅用 LLM 注意力导致 ChartQA 下降 10+ 点；仅用 ViT 注意力则削弱任务对齐；动态置信度加权最均衡。
6. **提取深度是质量-延迟权衡旋钮**：Lext = 2 优先效率（prefill 2.11× 加速），Lext = 24 优先质量（ChartQA 从 73.52 提至 78.96）但仅 1.09× 加速。

## 七、优点

1. **训练无关、即插即用**：无需微调或架构修改，可直接集成到现有模型，实用价值高。
2. **统一优化双瓶颈**：同时压缩视觉编码器输入和 LLM 上下文，是首个同时优化两阶段延迟的通用框架。
3. **全局与细节兼顾**：通过全局冗余度量（ρg）和局部细节对比（ρd）的动态组合，避免了静态压缩在均匀背景上过度模糊细节的问题。
4. **双注意力融合机制新颖**：利用标准差作为无监督置信度代理，自适应分配语义与视觉信号权重，比固定权重更稳健。
5. **正交可组合性**：APC 作为独立模块可与任何现有剪枝方法叠加，具有良好的生态兼容性。
6. **跨架构泛化**：在 Qwen（原生动态分辨率）和 InternVL（多 tile）两种异构架构上都验证了有效性。
7. **实验规范**：统一的 lmms-eval 框架、greedy decoding、固定随机性，保证了与基线对比的公平性。

## 八、不足与局限

### 8.1 论文自述的局限

1. **APC

1. **APC 对极端输入的压缩上限受限于预设公式**：ρ = αρg + (1−α)ρd 是一个启发式线性组合，对高度紧凑的“一寸图”（信息密度极高的单点图像）或极度稀疏的“白纸图”可能给出不理想的压缩比率；硬性内存预算虽能兜底，但可能在信息密集输入上造成意外细节损失。
2. **浅层预览仅使用单层特征，感知范围有限**：APC 依赖 ViT 第一个 block 的特征计算显著性，对依赖深层语义的视觉模式（如抽象图形、跨区域对应关系）可能不够敏感；论文在附录中对比了像素级统计，但未与更深层（如中间层）特征方案对比，深层特征方案的扩展代价也未分析。
3. **DDAE 的置信度代理依赖注意力分布的可区分性**：标准差是对注意力“集中程度”的粗略度量。若某个 head 的注意力本身就呈现均匀分布（尤其在长上下文高冗余场景），标准差信号可能失真，导致融合权重偏离最优。
4. **单卡、单请求评测粒度**：TTFT 效率测量在单张 RTX 4090、单 batch 条件下完成，未验证多请求并发、连续批处理（continuous batching）或 KV cache 复用等实际服务场景下的收益；批量推理时 ViT 的静态缩放收益可能被 batch 维度摊薄，DDAE 的提前剪枝对 KV 缓存命中的优化也未量化。

**（补充客观性说明）** 论文自述局限篇幅较短，以上第 1、2 点可在正文推导得到，第 3、4 点为基于实验设计的合理外推，论文未明确承认。

## 九、对领域的影响与可复现性

### 9.1 方法论影响

PACE 的核心贡献不仅在于性能提升，更在于范式层面的启示：

1. **“编码前压缩”补全了优化版图**：此前 token 剪枝领域被“后编码器剪枝”垄断，PACE 证明 ViT 编码阶段同样存在巨大冗余，且剪枝必须前置到像素/分辨率层面才能保住 2D 拓扑布局。这为后续工作打开了“输入分辨率自适应”与“token 交互联合剪枝”的研究方向。
2. **双阶段解耦设计便于模块复用**：APC 是一个独立的输入预处理模块，DDAE 是一个独立的上下文筛选模块；二者可以分别嵌入任意 VLM 管线，无需同时启用，这种“积木式”设计提高了方法的工程可推广性。
3. **为无训练加速方法提供了强基线**：在 Scissorhands、FastV 等基于“早期层注意力近似最终注意力”的启发式方法之外，PACE 展示了将“全局结构保真”与“局部任务对齐”分离考虑的新思路——前者交给几何/像素级处理，后者交给注意力信号融合。

### 9.2 可复现性评估

- **代码与配置**：论文未在正文提供代码链接，但按摘要与实验描述，实现细节（超参数 α、τ、Lext、归一化方式）均已披露，足以复现核心结果。
- **框架依赖**：基于 lmms-eval 评测框架，Qwen2.5-VL 与 InternVL 均为公开模型，数据集体量适中（9 个 benchmark），单卡即可完成效率评估；但完整复现需多日单卡运行，论文未提供官方仓库，复现门槛中等。
- **随机性与稳定性**：论文固定解码策略（greedy）并报告了多次运行的稳定性（附录 B 有标准差），这在视觉 token 剪枝领域属于规范做法。

## 十、改进方向与未来工作建议

基于论文的局限与实验结果，以下方向值得后续探索：

1. **将 APC 从启发式公式升级为可学习的轻量决策器**：当前 ρ 由固定权重 α 融合，可尝试用一个小型 MLP 或回归头预测最优压缩比，输入为浅层特征统计量，在少量样本上微调即可，保持“训练仅需极小代价”的同时获得更强的输入自适应性。
2. **多级压缩粒度**：PACE 只做单一的全局缩放，未来可探索“分块分辨率分配”（类似 foveation）——对信息密度高的图像区域保留高分辨率，对冗余区域低分辨率，同时用 2D 位置嵌入保持布局。
3. **DDAE 与 KV cache 的联合优化**：DDAE 在 LLM 深层剪枝后，被删除 token 在更浅层的 KV 缓存成了死重；可在剪枝时刻显式释放这些 KV 条目，进一步降低显存占用，并评估对吞吐量的影响。
4. **扩展至视频输入**：视频 VLM 的 token 规模远超图像，APC 的逐帧自适应压缩与 DDAE 的跨帧显著性融合有天然结合空间，论文仅验证了图像场景。
5. **与投机采样/并行解码结合**：PACE 显著缩短 prefill 阶段，若与投机解码（speculative decoding）相结合，长视觉上下文的端到端解码延迟可进一步下降。

## 十一、总结评价

PACE 是一篇工程价值与学术启示并重的高质量论文。它准确地识别的真实痛点——高分辨率 VLM 推理中视觉编码器与 LLM prefill 的双重瓶颈——并提供了一个设计精巧、无需训练、即插即用的解决方案。其最突出的贡献在于**将视觉 token 压缩的思考原点从“编码后选择”前移到“编码前压缩”，并证明两者可以正交互补**，实验数据扎实，跨模型、跨预算、跨任务的验证矩阵完整度在同类工作中位居前列。

从审稿角度看，论文的局限主要在于：缺乏与自适应分辨率类方法的直接对比、InternVL 实验缺少延迟数据、以及启发式公式的普适性论证还可以加强。但这并不影响其结论的可信度——在 9 个基准、3 个模型、3 个严格预算下的一致性优势已经充分证明了 PACE 范式的有效性。

一句话概括：**PACE 不是又一个“剪掉不重要的 token”的技巧，而是把“视觉冗余”这个问题的处理边界从 LLM 侧扩展到整个视觉-语言管线——它教会模型在“看”之前就决定看多少，在“读”之前就决定读哪行——并给出了一个简洁、有效、可复用的实现范式。**

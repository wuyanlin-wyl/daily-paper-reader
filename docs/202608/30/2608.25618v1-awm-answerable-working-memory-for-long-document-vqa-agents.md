## 摘要
长文档视觉问答日益依赖于VLM智能体，这些智能体检索候选页面、检查页面图像、将发现写入工作记忆并综合答案。工作记忆应在各页面检查之间携带支持答案的证据，以供后续基于证据的回答，然而现有评估主要检查最终答案的正确性和证据页面的访问情况。这造成了记忆质量的盲区：智能体可能到达正确页面并正确回答，同时留下的记忆过于笼统或不完整，一旦页面上下文被移除便无法支持回答。我们引入了\emph{仅记忆可回答性}这一诊断指标，用于判断阅读器能否仅凭问题和最终工作记忆作答。基于此诊断，\emph{可回答工作记忆}（AWM）将最终工作记忆视为可回答的证据工件，AWM-GRPO在保留最终答案优先级的同时，将此信号纳入GRPO奖励中。在GRPO下，该奖励为最终工作记忆仍可回答的答案正确轨迹赋予更高的优势。在\textsc{MMLongBench-Doc}上，即使提供了金标准证据页面，仍有42.5%的正确答案无法仅从最终工作记忆中得出。AWM-GRPO在\textsc{MMLongBench-Doc}和\textsc{LongDocURL}上将最终答案准确率较RAG基线分别提升了8.1和11.9个百分点，并将记忆缺失正确率较仅答案GRPO降低了2.7个百分点。

## Abstract
Long-document visual question answering increasingly relies on VLM agents that retrieve candidate pages, inspect page images, write findings to working memory, and synthesize answers. Working memory should carry answer-supporting evidence across page inspections for later grounded answering, yet existing evaluation mainly checks final-answer correctness and evidence-page access. This creates a memory-quality blind spot: an agent may reach the right page and answer correctly while leaving behind memory too generic or incomplete to support answering once page context is removed. We introduce \emph{memory-only answerability}, a diagnostic that asks whether a reader can answer from the question and terminal working memory alone. Building on this diagnostic, \emph{Answerable Working Memory} (AWM) treats terminal working memory as an answerable evidence artifact, and AWM-GRPO incorporates this signal into the GRPO reward while preserving final-answer priority. Under GRPO, this reward assigns higher advantages to answer-correct trajectories whose terminal working memory remains answerable. On \textsc{MMLongBench-Doc}, even when gold evidence pages are provided, 42.5\% of correct answers still cannot be answered from terminal working memory alone. AWM-GRPO improves final-answer accuracy over the RAG baseline by 8.1 and 11.9 points on \textsc{MMLongBench-Doc} and \textsc{LongDocURL} and reduces the memory-missing-correct rate by 2.7 points over answer-only GRPO.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：长文档视觉问答（Long-document VQA）任务中，主流做法是采用 VLM（视觉语言模型）智能体，通过「检索候选页面 → 检查页面图像 → 将发现写入工作记忆 → 综合最终答案」的循环完成推理。工作记忆（working memory）在此过程中的核心职责，是在多次页面检查之间持续携带支持最终答案的证据，以便后续基于证据给出有依据的回答。
- **核心问题**：现有评估体系仅关注两个维度——最终答案是否正确、证据页面是否被访问，却从不检查**终端工作记忆本身是否足以支撑答案**。这造成了一个"记忆质量盲区"：一个智能体完全可能检索到了正确的页面、最终也答对了问题，却留下过于笼统或残缺的工作记忆；一旦移除页面上下文，仅靠这些记忆根本无法推导出正确答案。
- **实证支撑**：论文通过诊断实验指出，即使在金标准证据页面已提供的受控条件下，MMLongBench-Doc 上仍有 **42.5%** 的正确回答无法仅从终端工作记忆中恢复出来，直接暴露了这一盲区的严重性。
- **整体含义**：论文主张工作记忆不应只是一个"过程性副产品"，而应被当作**可回答的证据工件（answerable evidence artifact）** 来显式优化，从而保证在页面上下文被移除后，智能体的推理链路依然可追溯、可复现、有依据。

### 2. 论文提出的方法论

#### 2.1 核心思想

- 引入 **仅记忆可回答性（memory-only answerability）** 诊断：给定问题 \( q \) 和终端工作记忆 \( M_{term} \)，使用一个**冻结的阅读器（reader）\( R \)** 在无页面图像、无轨迹上下文的条件下回答，再由**官方裁判（judge）\( J \)** 对阅读器的回答评分，得到 \( s_{mem} \)。

#### 2.2 关键技术细节

- **四格结果分类**：由「最终答案正确性 \( s_{ans} \)」×「仅记忆可回答性 \( s_{mem} \)」构成四种情形：
  - **记忆支持正确**（\( s_{ans}=1, s_{mem}=1 \)）：正确且记忆可回答
  - **记忆缺失正确（MMC）**（\( s_{ans}=1, s_{mem}=0 \)）：答对了但记忆不足以支撑答案
  - **回答错误**（\( s_{ans}=0, s_{mem}=1 \)）：答错但保留了有用证据
  - **未解决错误**（\( s_{ans}=0, s_{mem}=0 \)）：完全失败

- **核心指标**：\( P_{mmc} \)——在所有答案正确的样本中，终端工作记忆不可回答的比例。条件化于 \( s_{ans}=1 \) 可排除整体答题失败这一混淆因素，直接衡量"答对了但记忆不行"的现象。

- **AWM-GRPO 奖励机制**：
  - 设 \( r_{11}=\beta, r_{10}=0, r_{01}=\gamma, r_{00}=\omega \)，且满足 \( \beta > 0 > \gamma > \omega \)；默认参数为 \( (2, 0, -0.1, -1) \)。
  - 奖励的排序设计体现了三条偏好：
    - **记忆细化**：答对且记忆可回答 > 答对但记忆不可回答（\( r_{11} > r_{10} \)）；
    - **最终答案门控**：答对但记忆缺失 > 答错但记忆可回答（\( r_{10} > r_{01} \)），保持最终答案的绝对优先；
    - **有用记忆失败**：答错但记忆可回答 > 完全失败（\( r_{01} > r_{00} \)）。
  - GRPO 将原始奖励转换为组内相对优势：\( A_i = (r(\tau_i) - \mu_g) / (\sigma_g + \epsilon) \)。
- **与仅答案奖励（answer-only GRPO）的本质区别**：仅答案奖励无法区分 \( (1,1) \) 与 \( (1,0) \)，将两者压缩为同一区域；而 AWM 奖励在正确答案轨迹内部也保持记忆质量的排序，使记忆可回答性成为可见的训练信号。

#### 2.3 完整流程（AWM-GRPO）

1. 策略 \( \pi_\theta \) 为每个问题采样一组 \( G \) 条轨迹；
2. 每条轨迹同时输出最终答案 \( \hat{y} \) 和终端工作记忆 \( M_{term} \)；
3. 冻结的阅读器 \( R \) 仅凭 \( (q, M_{term}) \) 产生仅记忆答案；
4. 冻结的裁判 \( J \) 分别评估最终答案与仅记忆答案的正确性，得到 \( s_{ans} \) 与 \( s_{mem} \)；
5. 按四格奖励表计算 \( R_{AWM}(s_{ans}, s_{mem}) \)，在组内归一化得到优势；
6. 用优势更新策略参数，奖励对记忆可回答性形成持续的梯度压力。

### 6. 论文的主要结论与发现

- **记忆质量缺口是真实存在的**：即使给定金标准证据页，正确回答中仍有 42.5% 的轨迹无法从终端工作记忆恢复答案（EP-given 设置），说明页面访问与正确回答并不蕴含可回答的记忆。
- **改善记忆本身就能改善回答**：在受控干预中，空记忆的正答率仅 2.8%，原始 4B 记忆为 36.2%，GPT-4o 改进记忆提升至 44.4%——证明终端记忆质量对最终回答有直接的因果影响。
- **AWM-GRPO 显著提升最终答案准确率**：
  - MMLongBench-Doc：53.9%（较 RAG +8.1、较 SFT +4.7、较 Answer-GRPO +2.3）；
  - LongDocURL：60.1%（较 RAG +11.9、较 SFT +4.4、较 Answer-GRPO +2.7）。
- **AWM-GRPO 在提升准确率的同时改善了记忆质量**：完整多轮设置下 Pmmc 由 Answer-GRPO 的 19.9% 降至 17.2%；EP-given 设置下由 19.1% 降至 16.4%；记忆准确率从 42.5% 提升至 44.5%。
- **训练信号有效**：AWM-GRPO 训练过程中记忆准确率从 step 40 的 38.8% 单调上升至 step 280 的 43.5%。

### 7. 优点

- **问题定义清晰、诊断指标新颖**："仅记忆可回答性"是一个轻量、可复现、架构无关的评估维度，填补了"最终答案/页面访问"二元评估之外的关键盲区。
- **方法与架构解耦**：AWM 不改变智能体架构、记忆 schema 或工具集，仅通过奖励信号塑造终端记忆质量，通用性和可移植性较强。
- **无需金标准记忆**：奖励完全基于冻结阅读器从智能体自写记忆中恢复答案的能力，避免了人工标注记忆的昂贵成本。
- **实验控制严谨**：五个 Qwen3-VL-4B 变体共享全部组件、EP-given 隔离检索、受控记忆干预锁定因果关系，构成清晰的方法论链条。
- **奖励设计有理论支柱**：通过蒙特卡洛模拟（15,000 组 × 8 轨迹）展示 AWM 奖励在不同组分布下如何改变优势排序，说明"答案优先、记忆精化随后"的动态偏好机制。

### 8. 不足与局限

- **模型规模与分布覆盖有限**：所有受控实验仅使用 Qwen3-VL-4B 单模型；30B+ 参数模型或其他文档分布（科学论文、金融申报、幻灯片等）是否受益于 AWM-GRPO 尚未验证。
- **评估依赖单阅读器**：仅记忆可回答性依赖冻结的 Qwen3-14B 阅读器，论文未使用第二个阅读器验证该诊断的稳健性。
- **裁判误差风险**：GPT-4o 答案提取步骤存在偏差；100 例人工审计发现 6 处不一致，但样本有限，无法排除系统性误差。
- **类别效果不均衡**：按证据源拆解显示 AWM-GRPO 在表格和布局类问题上 Pmmc 反而**升高**（表格 15.2→23.9，布局 4.8→15.8），说明记忆奖励并未均匀解决所有结构证据的保留问题。
- **可回答性 ≠ 可溯源（grounding）**：可回答的记忆可能包含无依据的猜测或答案的复述；论文的审计仅验证来源页合法性与精确字符串复制的排除，未建立逐条记忆的声明级溯源。
- **受控干预的局限性**：GPT-4o 改进记忆干预是单次、单种子实验，且在部分结果单元中反而损害了记忆可回答性（如记忆支持正确类中 16 例变差），不能视为全序优。

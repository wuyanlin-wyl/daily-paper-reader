## 摘要
当前临床视觉大语言模型（C-VLLMs）的进展显著提升了数字诊断能力，但这些框架在复杂临床病例中经常面临病灶噪声、模态错位、幻觉以及上下文基础缺失等问题。此外，现有的智能体系统通常依赖于静态且不可适应的流水线，缺乏复杂医学推理所需的通用性。为解决这些困难，我们提出了BioMed-Agent-RL，一个统一的医学智能体，它整合了自适应编排、策略和基于奖励的强化学习（RL）模型，用于生物医学应用。为确保可靠性，它引入了临床上下文感知的偏好优化（CPO）、直接偏好优化（DPO）和具有动态熵调节的组相对策略优化（GRPO）。该流水线采用多模态元学习方法，作为领域特定专家和人类判断合成器运行。该智能体通过利用迭代且自适应的RL方法，跨多种临床模态（如X射线）自适应地利用一组模型级专业知识，如临床基础和推理器、病灶分割器和领域特定合成器。智能体学会认真综合误导性的、冲突的视觉线索，并在专家建议有误时信任内在推理。我们在多个基准上进行了深入的消融研究，该智能体显著优于现有最先进模型，如GPT-5，在当代基线上达到了高达约73%的准确率（提升约5%）。因此，该框架为构建事实性、可靠、稳健且类专家的独立临床推理智能体系统提出了新标准。

## Abstract
The current progress of Clinical Vision Large Language Models (C-VLLMs) has substantially improved digital diagnostics, still these frameworks often endure lesion noises, modality misalignment, hallucination, and missed contextual grounding in complex clinical cases. Moreover, prevailing agent systems usually depend on static and non-adaptable pipelines and lack the versatility necessary for complex medical reasoning. To resolve these difficulties, we present BioMed-Agent-RL, a unified medical agent that incorporates adaptive orchestration, policy, and reward-based reinforcement learning (RL) models for biomedical applications. To ensure reliability, it invokes clinical context-aware preference optimization (CPO), direct preference optimization (DPO), and group relative policy optimization (GRPO) with dynamic entropy regulation. This pipeline utilizes a multimodal meta-learning approach that operates as a field-specific expert and human judgment synthesizer. The agent adaptively utilizes a set of model-level expertise, such as clinical grounding and reasoner, lesion segmenter, and field-specific synthesizer, across various clinical modalities (e.g., X-ray) by utilizing an iterative and adaptive RL approach. The agent learns to seriously synthesize misleading, conflicting vision cues and trust in inherent reasoning, while specialist advice is faulty. An intensive ablation study is conducted across multiple benchmarks, and the agent significantly outperforms existing state of the art models, such as GPT-5, attaining up to ~73% accuracy (gain of ~5%) over contemporary baselines. As a result, the framework suggests a new standard for building factual, reliable, robust, and expert-like intelligent agent systems for independent clinical reasoning.

## 二、论文提出的方法论

### 2.1 核心思想

- 提出一个多模态元学习驱动的统一医疗智能体，将“领域专家模型”与“人类判断合成器”相结合。
- 智能体通过迭代式 RL 自适应地在不同临床模态（如 X 射线）之间切换和组合模型级专业知识（临床基础与推理器、病灶分割器、领域特定合成器等）。
- 关键能力：当专家建议错误或冲突时，智能体学会综合误导性视觉线索，并信任内在推理，从而减少幻觉与错误传播。

### 2.2 关键技术细节

#### 1. 多智能体协作框架
- 系统包含三类核心智能体：
  - **任务描述智能体（Captioning Agent）**：根据输入选择任务类别，通过排序分数路由到对应的领域专家。
  - **领域专家智能体（Role Specialist）**：由 K 个专家模型构成（本工作中 K=7），提供初步临床评估。
  - **聚合智能体（Aggregation Agent）**：融合各专家输出，生成最终临床判断。
- 该方法避免了简单多数投票导致的少数意见被压抑问题，通过自适应策略进行决策融合。

#### 2. 三种偏好优化方法
- **DPO（Direct Preference Optimization）**：直接通过二元交叉熵优化策略，无需外部奖励模型，方法轻量但精度有限。
- **CPO（Context-aware Preference Optimization）**：在 DPO 基础上引入上下文感知的归一化评分，对样本进行加权，强调视觉特征优于文本幻觉，降低区域噪声的影响。
- **GRPO（Group Relative Policy Optimization）**：无需 critic 模型，利用组内相对奖励计算优势值，更新策略；在此之上引入**动态熵正则化**，形成 **C-GRPO**。

#### 3. 课程学习设计（C-GRPO）
- 根据专家评估的准确度（S = ACC(y_rd, y*)），将数据集划分为三个复杂度等级：
  - **Easy**：S=1，完全正确；
  - **Medium**：0<S<1，部分正确；
  - **Hard**：S=0，完全错误。
- 训练过程采用三阶段课程：从易到难，逐步学习何时依赖专家知识、何时依靠自身推理。
- 动态熵系数 γ 随难度调整：易样本 γ≈0（低探索），难样本 γ≈1（强制探索），以帮助智能体摆脱对错误专家建议的依赖。

#### 4. 关键公式（文字描述）
- **DPO 损失**：利用 sigmoid 函数对偏好/非偏好的对数概率差进行建模，并通过交叉熵损失优化。
- **CPO 损失**：在 DPO 基础上对临床相关性评分进行归一化裁剪（映射到 [α, β]），并作为权重调整损失。
- **GRPO 优化目标**：每组输入采样 N 个输出，计算各自的奖励，使用裁剪代理目标与 KL 散度约束更新策略；优势值通过对组内奖励标准化得到。
- **C-GRPO 最终目标**：将 GRPO 损失与熵正则项结合，即 L_C-GRPO = E[L_GRPO + γ_s · H_t(π_agg)]，其中 H_t 为 softmax 温度调节后的熵。

#### 5. 训练流程
- 初始描述智能体使用有监督训练，随后通过 GRPO 联合奖励模型（格式奖励 0~0.5，准确率奖励 0~1）进行优化。
- 专家输出作为人类专家意见的替代，用于数据构造与基准对比。
- 聚合智能体采用熵控制的 RL 策略，在低熵时利用共识，在高熵时探索不确定性。

## 六、论文的主要结论与发现

1. **C-GRPO 显著优于 DPO 和 CPO**：在所有骨干和数据集上，C-GRPO 均获得更高的 F1 分数，最高达到约 **73.08%**（RAD-VQA 上的 MMedAgent 骨干）。
2. **相对 GPT-5 等现有最优模型有明显提升**：提升约 **5%**，最大增益可达 **10.5%**（相比 DPO）。
3. **性能提升具有架构无关性**：不同骨干（LLaVA-Med、DeepSeek-VL、GPT-5、MMedAgent）上 C-GRPO 均稳定提升，证明方法普适性强。
4. **对复杂查询和困难样本具有鲁棒性**：虽在开放式问题与高难度问题上存在性能下降，但整体下降趋势平缓，且远优于其他 RL 方法。
5. **有利于减少幻觉和错误传播**：定性结果中，BioMed-Agent-RL 能提供更准确的病灶定位框、更专业的临床语义描述（如“右下叶斑片状实变”“急性肺炎”），而 DPO/CPO 只给出表面化描述。
6. **为医疗智能体建立了新标准**：表示该框架可用于构建事实性、可靠、稳健、类专家的独立临床推理系统。

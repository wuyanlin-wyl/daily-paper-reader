## 摘要
视觉语言模型（VLMs）越来越多地用于临床流程中，其中胸部X光片与检索到的报告、初步说明或既往影像一起被解读。现有基准衡量模型在孤立情况下是否回答正确，但不衡量当合理情境与图像冲突时，模型是否保持仅基于图像的正确决策。我们引入了多情境胸部X光基准（MC-CXR），这是一个包含240个案例、扩展为2,522个实例的基准，通过配对扰动来隔离情境诱发的干扰。每个案例固定当前图像和目标发现，同时呈现匹配的可靠和误导性情境，涵盖文本和既往胸部X光，并在可用时提供视觉叠加。MC-CXR定义了三个任务族和两个配对指标，即切换到错误率和情境对齐错误率。我们评估了十个VLM，涵盖开源通用模型、医学领域模型和闭源系统。仅基于图像的准确性是必要的但不充分。在误导性文本来源中，平均切换率范围为45.6%-78.1%；在误导性视觉来源中，范围为35.7%-61.7%。在切换的预测中，74.6%与误导性文本标签对齐，而视觉情境中仅为17.6%，差距为57.0个百分点（95%置信区间50.9-62.8）。这种文本-视觉不对称性在标准化直接回答协议下观察到。该数据集可在PhysioNet上获取。

## Abstract
Vision-language models (VLMs) are increasingly used in clinical pipelines where a chest X-ray is interpreted alongside retrieved reports, preliminary notes, or prior imaging. Existing benchmarks measure whether models answer correctly in isolation, but not whether they preserve a correct image-only decision when plausible context conflicts with the image. We introduce Multi-Context Chest X-ray (MC-CXR), a benchmark of 240 cases expanded into 2,522 instances that isolates context-induced disruption through paired perturbation. Each case fixes the current image and target finding while presenting matched reliable and misleading context across text and prior CXR, with visual overlays where available. MC-CXR defines three task families and two paired metrics, the switch-to-wrong rate and the context-aligned error rate. We evaluate ten VLMs spanning open-source general, medical-domain, and closed-source systems. Image-only accuracy is necessary but insufficient. Mean switch rates range from 45.6-78.1% across misleading textual sources and 35.7-61.7% across misleading visual sources. Among switched predictions, 74.6% align with the misleading label for text versus 17.6% for visual context, a 57.0-point gap (95% CI 50.9-62.8). This text-visual asymmetry is observed under the standardized direct-answer protocol. The dataset is available on PhysioNet.

## 1. 论文的核心问题与整体含义

- **研究动机**：在实际临床流程中，胸部 X 光（CXR）判读很少是“仅看图像”的任务，放射科医生通常会结合临床指征、既往影像、既往报告和初步草稿等辅助情境进行综合判断。但随着视觉语言模型（VLM）越来越多地嵌入这类工作流，它们可能被不可靠的情境信息“带偏”，即使模型在仅凭图像时做出了正确判断。
- **核心问题**：现有 CXR 基准只测试模型“在孤立条件下回答是否正确”，未测试模型在“可靠/误导性情境与图像冲突时”是否能保持基于图像的正确决策。这种被情境诱发、偏离图像证据的失败模式，现有的聚合准确率指标无法揭示。
- **整体含义**：论文提出 **context-robust visual reasoning（情境鲁棒的视觉推理）** 概念，要求模型具备四个子能力：识别当前图像证据、解析情境来源、识别图像与情境的一致/冲突、以及在冲突时裁决哪个证据源应决定答案。现有基准只测了第一个，仲裁能力完全未覆盖。

## 2. 提出的方法论

- **核心思想**：通过**配对扰动**构造可靠与误导性变体的同源情境，在固定当前图像和目标发现的前提下，测试模型的条件性情境使用能力，而非简单惩罚“使用情境”本身。
- **任务公式化**：每个案例包含当前 CXR 图像 \( I_i \)、当前图像目标发现 \( X_i \)、情境隐含发现 \( Y_i \)。模型在情境条件 \( c \) 下从 12 个 CheXpert 标签子集中输出一个预测 \( \hat{p}_{i,c} \)，当 \( \hat{p}_{i,c} = X_i \) 时判定为目标正确。
- **三个任务族**：
  - **IOR（Image-only Recognition，仅图像识别）**：无情境基线，测试模型仅从当前图像中识别目标发现的能力。
  - **RCS（Reliable Context Stability，可靠情境稳定性）**：提供与图像一致的情境，测试模型是否能在情境支持下保持正确决策。
  - **MCR（Misleading Context Resistance，误导情境抵抗）**：提供临床合理但误导的情境，测试模型是否能抵抗并保持正确决策。
- **情境来源**（5 种），覆盖文本、视觉两类模态：
  - **文本**：临床指征（indication）、既往报告（prior report）、初步说明（preliminary note）。
  - **视觉**：既往 CXR 图像（prior image，同患者 vs 跨患者）、PACS 风格视觉叠加（overlay，指向病灶 vs 偏离病灶）。
- **配对指标**：
  - **切换至错误率（Switch-to-wrong rate）**：在 IOR 正确子集 \( I^M \) 中，加入情境后预测翻转（变错）的比例，公式为 \( P(C \to W | c) = \frac{\#\{i \in I^M : \hat{p}_{i,c} \neq X_i\}}{|I^M|} \)。
  - **情境对齐错误率（Context-aligned error rate）**：在翻转的错误中，预测恰好落在误导情境隐含标签 \( Y \) 上的比例，公式为 \( P(W_Y | C \to W, c) = \frac{\#\{i \in I^M : \hat{p}_{i,c} = Y_i\}}{\#\{i \in I^M : \hat{p}_{i,c} \neq X_i\}} \)。两个指标联合区分“随机不稳定”与“方向性情境拉拽”。
- **构建流程**：从 MIMIC-CXR 和 MIMIC-CXR-JPG 过滤出符合条件的病例 → 放射科医生逐例确认目标发现 \( X \) 并选择一个临床可合理的误导标签 \( Y \)（与 \( X \) 不同且不共现）→ 对 5 种情境源分别构建配对可靠/误导变体 → 最终形成 240 个案例、233 位独特患者、11 种情境条件、2,522 个可评估实例。放射科医生在 26/240（10.8%）案例中修正了 CheXpert 源标签，印证了人工把关的必要性。

## 3. 实验设计

- **数据集/基准**：
  - 数据来源：MIMIC-CXR 与 MIMIC-CXR-JPG。
  - 输出空间：12 个标签，即 No Finding、Enlarged Cardiomediastinum、Cardiomegaly、Lung Opacity、Lung Lesion、Edema、Consolidation、Pneumonia、Atelectasis、Pneumothorax、Pleural Effusion、Fracture。排除了 Support Devices 和 Pleural Other。
  - 评估协议：零样本、约束字母（A–L）选择题式直接回答提示，模型只能输出单个大写字母，无法选择弃权；无效输出判为错误。
- **核心评估策略**：首先确定每个模型在 IOR（仅图像）条件下回答正确的案例子集，然后在该子集上测量各情境条件下的切换行为。这种条件化方法避免了将基线识别失败误算为情境诱导干扰。
- **对比的模型（共 10 个，分 3 类）**：
  - 开源通用模型（5 个）：InternVL3-8B、Qwen3.5-9B、Gemma-3-12B-IT、Llama-3.2-11B-Vision-Instruct、Phi-4-multimodal-instruct。
  - 医学领域开源模型（2 个）：MedGemma-1.5-4B、NV-Reason-CXR-3B。
  - 闭源前沿模型（3 个）：Claude Opus 4.7、GPT-5.5、Gemini 3.5 Flash。
- **补充实验**：对 GPT-5.5 进行了提示词消融试点（PB 基线提示 vs PI 图像优先提示 vs PC 冲突感知提示），对 51 个案例子集进行了第二位放射科医生的盲法复核审计，以及闭源 API 溯源记录。

## 4. 资源与算力

- **开源模型**：在单节点 4×NVIDIA RTX A6000（各 49 GB）上运行，使用 bfloat16 权重、确定性贪心解码（do_sample=false）、max_new_tokens=8。
- **耗时**：每个模型评估全部 2,522 个实例约需 12–125 分钟（视架构而定），完整开源模型扫描总计约 10 GPU 小时。
- **闭源模型**：通过 Anthropic、OpenAI、Google 官方 API 访问，temperature=0、max_tokens=1024、最低推理预算，产生 API 费用而非本地 GPU 开销。
- **说明**：论文对算力披露是充分的，给出了硬件型号、数量、解码设置和总耗时量级。

## 5. 实验数量与充分性

- **实验规模**：
  - 10 个 VLM × 11 种情境条件，共 2,522 个模型可评估实例。
  - 主实验覆盖 5 种可靠情境 + 5 种误导情境 + 1 个无情境基线（IOR）。
  - 另含 1 项提示词消融试点（GPT-5.5，73 例 IOR 正确子集，3 种提示指令）、51 例第二位阅读者审计。
- **充分性分析**：
  - **优点**：模型类型覆盖广（通用/医学/闭源），情境源种类多样（文本 3 种、视觉 2 种），配对设计使可靠与误导条件可直接对比；切换指标基于逐模型的 IOR 正确子集，隔离了基线识别错误。
  - **不足**：所有模型均为单次确定性运行，无多次运行的方差估计；闭源 API 的版本固定性无法保证（论文承认这一点）；多位审计仅覆盖误导性文本条件（b2/d2/e2），未覆盖视觉条件；提示词消融仅 1 个模型、2 个文本条件，推广性有限。

## 6. 主要结论与发现

- **仅图像准确率必要但不充分**：IOR 准确率仅为 8.3–35.8%（跨模型），Cohen's κ 最高仅 0.282，多数模型处于 0.00–0.25 的“轻微到一般”一致性区间，说明当前 VLM 即便在无情境条件下也远非可靠的 CXR 分类器。
- **可靠情境也导致不稳定**：在 RCS 条件下，模型平均有 28.8% 的 IOR 正确决策发生翻转。指向真实病灶的叠加箭头（42.4%）和可靠指征（31.3%）最具干扰性，而来自当前报告的简明初步说明（13.3%）最稳定。
- **核心不对称发现（文本 vs 视觉）**：
  - **误导性文本具有强方向性拉拽**：切换率 45.6–78.1%（重写初步说明最严重为 78.1%）；切换错误中 85.3% 对齐到误导标签；Qwen3.5-9B 在重写初步说明条件下 Y 对齐率达 93.0%。
  - **误导性视觉虽然也能翻转预测，但缺乏方向性**：跨患者既往图像切换率 35.7%、偏离病灶叠加 61.7%，但仅 18.0% 和 16.5% 对齐误导标签。
  - **汇总差距**：合并所有模型的切换案例，文本产生 713/956（74.6%）Y 对齐错误，而视觉仅 78/443（17.6%），差距 57.0 个百分点（95% CI 50.9–62.8）。10 个模型无一例外方向一致（符号检验 p = 0.002）。
- **领域专业化不免疫**：医学领域模型在重写初步说明下的准确率降幅（12.5–17.5 个百分点）最大，说明领域特化并不能防止文本覆盖。
- **提示词敏感**：GPT-5.5 在冲突感知提示下，误导性初步说明的切换率从 76.7% 降至 41.1%（-35.6 pp），说明该现象是可缓解的、与协议相关，而非不可改变的模型固有属性。

## 7. 优点

- **问题定义新颖且具有临床实际意义**：将“情境仲裁”从聚合准确率中剥离出来，直接测量模型在可靠/误导情境下能否保持基于图像的决策，弥补了现有 CXR 基准的盲区。
- **配对扰动设计严谨**：固定当前图像与目标发现，仅变化情境的可靠性与模态，实现了对情境诱导干扰的干净隔离；借鉴 NLP 对比集方法论，并成功扩展到多模态临床推理。
- **指标设计精细**：切换率与 Y 对齐率联合使用，能够区分“随机不稳定”与“方向性情境拉拽”，且基于逐模型的 IOR 正确子集进行条件化，最大程度排除了基线识别噪声的干扰。
- **医学专家全流程把关**：放射科医生确认目标标签、选择误导标签、撰写/审核可靠与误导情境文本、验证跨患者图像与叠加放置；对源标签的 10.8% 修正率印证了标签噪声的客观存在。
- **模型覆盖面广、结论稳健**：10 个代表三个类别的模型在统一的直接回答协议下呈现一致的文本-视觉不对称方向，结论具有较好的模型层面推广性；汇总统计采用 case-cluster bootstrap 和符号检验提供统计支持。

## 8. 不足与局限

- **IOR 基底准确率偏低**：各模型 IOR 准确率仅为 8.3–35.8%、κ 最高 0.282。论文承认 IOR 正确子集中可能包含“偶然正确”的案例，这对切换率指标有一定污染，且无法完全排除。
- **协议依赖性强**：所有数字基于单一确定性运行和约束字母直接回答提示。GPT-5.5 提示词试点表明冲突感知提示能大幅减少文本切换，说明该现象并非提示不变（prompt-invariant）；改用其他提示风格或其他解码策略时结论可能发生变化。
- **单标注者偏差**：数据整理由一位作者（放射科医生）完成。51 例第二位阅读者审计覆盖了误导性文本条件且一致确认 Y 方向成立，但未覆盖视觉条件、未计算 κ，也不构成全基准的验证。可靠情境中的部分材料（指征、既往报告、既往图像）为真实数据，未必精确指向 X，RCS 条件下的切换可能部分反映情境的部分错位。
- **文本-视觉不对称的可能混淆**：误导性视觉条件（跨患者图像、偏离叠加）虽经放射科医生确认隐含 Y，但未单独标定 Y 在视觉上的可识别性，低对齐率可能部分归因于视觉线索特异性不足，而非纯粹的模态偏好不对称。
- **闭源 API 不可严格复现**：闭源模型通过服务别名访问，无不可变后端快照标识，无法保证论文评估时的模型版本与读者复现时完全一致。
- **无弃权选项**：12 标签约束字母协议不提供弃权，与自由文本报告不等价。真实临床场景中模型可以表示不确定或转给人类复核。
- **数据不可直接重发布**：原始 MIMIC-CXR 影像不重新分发，仅提供可复现的图像标识符；使用门槛受 PhysioNet 认证健康数据许可约束。
- **结论的时间与模型范围限制**：评测时间为 2026 年 5 月，模型代表性受限于当期主流 VLM；论文明确声明不应依据基准表现推断模型在临床上的安全或不安全性。

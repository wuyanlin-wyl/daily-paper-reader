## 摘要
手术时空定位（STG）要求在每个由程序性问题指定的视频时间点，定位问题所询问的对象。现有方法面临权衡：视觉语言模型理解问题上下文但生成不精确的坐标，而开放集检测器提供局部候选框，但其置信度并不反映哪个框回答了问题。我们引入了RefineRank，在候选框层面弥合了这一差距。一个紧凑的可训练模块RefineNet，结合了冻结的医学视觉语言模型的语言和区域特征，以及冻结的开放集检测器的提议：它为每个候选框预测一个有界的坐标校正和一个质量分数，并采用固定解码规则返回得分最高的原始或细化框。在MedVidBench官方排行榜（已验证）上，RefineNet记录了0.421的STG mIoU，这是显示的最高STG分数，而其全局多指标排名为第11位。在针对独立训练和评估视频的受控评估中，坐标校正将候选oracle上界从0.6772提高到0.7302，并且通过RefineNet分数对原始和细化候选的联合池进行排序，将STG mIoU从0.2719提高到0.4534，而在同一池上单独训练的选择器最多达到0.4186。这些结果表明，一个小的框级模块可以在不重新训练任一骨干网络的情况下，协调问题理解与精确定位。代码可在[https://github.com/linzhe001/RefineRank](https://github.com/linzhe001/RefineRank)获取。

## Abstract
Surgical spatio-temporal grounding (STG) requires locating, at each video time specified by a procedural question, the object that the question asks about. Existing approaches face a trade-off: vision language models understand the question context but produce imprecise coordinates, whereas open-set detectors provide localized candidate boxes whose confidence does not reflect which box answers the question. We introduce RefineRank, which closes this gap at the candidate-box level. A compact trainable module, RefineNet, combines the language and regional features of a frozen medical vision language model with the proposals of a frozen open-set detector: it predicts a bounded coordinate correction and a quality score for every candidate box, and a fixed decoding rule returns the original or refined box with the highest score. On the MedVidBench Official Rankings (Verified), RefineRank records 0.421 STG mIoU, the highest displayed STG score, while its global multi-metric rank is 11. In a controlled evaluation on separate training and evaluation videos, coordinate correction raises the candidate oracle upper bound from 0.6772 to 0.7302, and ranking the joint pool of original and refined candidates by their RefineNet scores improves STG mIoU from 0.2719 to 0.4534, whereas separately trained selectors over the same pool reach at most 0.4186. These results show that a small box-level module can reconcile question understanding with precise localization without retraining either backbone. Code is available at [https://github.com/linzhe001/RefineRank](https://github.com/linzhe001/RefineRank).

# RefineRank 论文总结

## 1. 核心问题与研究动机

- **任务定义**：手术时空定位（Spatio-Temporal Grounding, STG）要求系统在程序性问题的每个指定时间点，定位问题所询问的对象（如手术器械、解剖区域或医生手部）。对象可能尺寸小、被遮挡或与邻近物体视觉相似，对空间、时间与语言交互能力提出了很高要求。
- **现有方法的两难困境**：
  - **医学视觉语言模型（MedVLM）**：擅长理解复杂临床问题语义，但生成的坐标不精确；
  - **开放集检测器（如 GroundingDINO）**：能提供局部化候选框，但检测器置信度衡量的是框与检测查询的匹配程度，而非"哪个框回答了完整的时间戳手术问题"——最佳答案框往往不是检测器打分最高的框。
- **核心挑战**：将两类模型结合时，直接学习两者特征空间的稠密对齐需要跨越不同的分词方式、维度、空间网格和预训练目标，难度极高。
- **本文思路**：候选框是天然的"中间媒介"——每个候选框已包含坐标、检测器分数和 MedVLM 视觉特征中的对应区域，因此可以通过框本身而非内部特征来连接两个模型。

## 2. 方法论

### 2.1 核心思想

RefineRank 保持 MedVLM 和 GroundingDINO 完全冻结，仅训练一个紧凑模块 **RefineNet**。每个候选框同时输出：
- **有界坐标修正**（bounded coordinate correction）：改善框的定位；
- **质量分数**（quality score）：反映该框回答问题的程度。

推理时通过**固定解码规则**（无学习参数）从原始框与细化框的联合池中返回分数最高的框。

### 2.2 RefineNet 输入（四个特征源）

| 输入 | 来源 | 维度 |
|---|---|---|
| $q_{last}$ | MedVLM 最终语言隐藏状态（最后一层、最后提示词 token） | 3584 |
| $r_{inter}$ | 视觉块 23 的中间视觉网格，按框重叠面积加权 ROI 池化 | 1280 |
| $r_{final}$ | 最终视觉网格（token 合并后），加权 ROI 池化 | 3584 |
| $f_{dino,i}$ | GroundingDINO 框元数据向量（24维：检测器置信度、时间选择分、管覆盖度、管平滑度、时间偏移、框坐标、log面积、log纵横比等） | 24 |

### 2.3 网络结构与输出

- 四个输入经投影后组合（区域特征与元数据相加，再与查询特征做逐元素乘积），送入两层 MLP；
- **排序头 $h_{rank}$**：输出原始框分数 $s_i$ 和细化框分数 $\hat{s}_i$；
- **框头 $h_{box}$**：输出修正量 $\delta_i = (\delta_{x,i}, \delta_{y,i}, \delta_{w,i}, \delta_{h,i})$。

### 2.4 坐标修正解码公式

中心偏移经 tanh 约束在 $[-0.5, 0.5]$，对数尺度偏移约束在 $[-\log 2, \log 2]$：

$$c'_{x,i} = c_{x,i} + \delta_{x,i} w_i, \quad c'_{y,i} = c_{y,i} + \delta_{y,i} h_i$$
$$w'_i = w_i \exp(\delta_{w,i}), \quad h'_i = h_i \exp(\delta_{h,i})$$

### 2.5 训练损失

- **RankingLoss**（两个分数分别训练）：列表式交叉熵（softmax 温度 $\tau=0.1$）+ Smooth L1 校准项（$\lambda_{cal}=0.25$），目标为框与真值的 IoU；
- **BoxLoss**：对每帧 top-8 有效原始框，施加 Smooth L1 回归损失 + 广义 IoU（GIoU）损失；
- 细化框的 IoU 目标用 StopGradient 截断，避免框修正目标影响排序学习；
- 总损失 = 两个 RankingLoss + BoxLoss，仅优化 RefineNet 参数。

### 2.6 推理时的解码流程

1. 联合池包含所有原始框（由 $s_i$ 打分）与细化框（由 $\hat{s}_i$ 打分）；
2. 先保留 16 个原始框，再按 $U(c)=\lambda_q \sigma(s(c)) + \lambda_d d(c|S)$ 贪心填充至最多 48 个候选（$\lambda_q=0.7$，$\lambda_d=0.3$，$d(c|S)$ 为多样性项：1 减去与已选框的最大 IoU）；
3. 固定解码规则直接取分数最高的候选框——**无需单独训练任何选择器**。

1. **坐标修正确实提升候选池定位潜力**：候选 oracle 上界从 0.6772 提升至 0.7302；

## 7. 优点

- **避免密集特征对齐**：通过候选框作为中介连接两个异构模型，规避了跨分词/维度/空间网格对齐的难题；
- **极致高效**：仅约 125 万可训练参数，两个骨干完全冻结，算力需求低；
- **推理透明**：固定解码规则无学习参数，可解释性强，无需额外选择器；
- **受控评估分离变量**：通过候选 oracle 和统一候选池，清晰区分"修正是否产生更好的框"与"排序是否选出更好的框"两个问题；
- **消融设计清晰**：特征研究、选择器研究、视觉块比较均保持其他条件不变；
- **统一多样性机制**：过滤阶段的质量-多样性加权（$\lambda_q/\lambda_d$）避免候选冗余。

## 8. 不足与局限

- **实验覆盖有限**：仅一个固定视频分离划分；额外划分上的稳定性验证留待未来；
- **无学习式融合基线**：未与端到端学习的 MedVLM-检测器融合方案比较，无法声明框级融合优于其他学习式融合设计；
- **区域特征不回传更新**：细化框不重新编码，其分数无法利用修正后新纳入或排除的视觉内容；
- **依赖检测器召回**：当 GroundingDINO 未提出覆盖目标的候选框时，系统无法恢复目标（不可恢复性上界）；

- **训练细节报告有限**：未披露 GPU 型号与数量、训练总时长等资源信息。

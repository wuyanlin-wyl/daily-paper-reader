## 摘要
4D理解与推理是具身AI智能体在动态物理环境中运行的基本能力。然而，现有的视觉编码器大多局限于静态2D图像或缺乏时间建模的3D点云，或者局限于缺乏精确几何深度推理的2D视频。因此，当前方法无法在动态场景中联合捕捉空间结构和运动演化。我们提出了CL4D，这是第一个直接操作动态点云的基础4D视觉编码器，通过对比学习目标进行训练，将时空几何表示与自然语言描述对齐。通过在学习文本与4D场景动态之间的共享嵌入空间，CL4D能够在动态环境中实现零样本的运动到文本和文本到运动检索，并作为下游4D视觉-语言任务的基础4D视觉编码器。基于该编码器，我们引入了4DVLM，这是一种4D视觉-语言模型，将语言生成条件建立在动态几何表示之上。4DVLM是第一个直接操作4D点云而不依赖2D图像、2D视频或静态3D点云的视觉-语言模型。我们在一个新构建的数据集DynAction4D上训练CL4D及后续的4DVLM，该数据集涵盖了不同物体交互和场景环境下的多样化人体运动。在多个4D人体动作基准上的大量实验表明，CL4D达到了最先进的性能，相比先前方法提升了约16.75%。此外，即使为前沿视频视觉语言模型（如Gemini和GPT-5）提供与4DVLM所处理的4D点云对应场景的RGB视频序列，4DVLM仍优于这些模型。

## Abstract
4D understanding and reasoning is a fundamental capability for embodied AI agents operating in dynamic physical environments. However, existing vision encoders are largely limited to static 2D images or 3D point clouds without temporal modeling, or to 2D videos that lack accurate geometric depth reasoning. Consequently, current approaches fail to jointly capture spatial structure and motion evolution in dynamic scenes. We present CL4D, the first foundational 4D vision encoder that directly operates on dynamic point clouds, trained with a contrastive learning objective to align spatio-temporal geometric representations with natural language descriptions. By learning a shared embedding space between text and 4D scene dynamics, CL4D enables zero-shot motion-to-text and text-to-motion retrieval in dynamic environments and serves as a foundational 4D vision encoder for downstream 4D vision-language tasks. Building on this encoder, we introduce 4DVLM, a 4D vision-language model that conditions language generation on dynamic geometric representations. 4DVLM is the first VLM designed to operate directly on 4D point clouds without relying on 2D images, 2D videos, or static 3D point clouds. We train CL4D and subsequently 4DVLM on a newly constructed dataset termed DynAction4D capturing diverse human motions across varying object interactions and scene environments. Extensive experiments across multiple 4D human action benchmarks demonstrate that CL4D achieves state-of-the-art performance, with improvements of approximately ~16.75% over prior methods. Furthermore, 4DVLM outperforms frontier video VLMs such as Gemini and GPT-5 even when these models are provided with RGB video sequences corresponding to the same scenes represented as 4D point clouds for 4DVLM.

- **核心问题**：缺乏一个能够直接处理**动态点云序列 (x,y,z,t)**、并且与自然语言对齐的基础 4D 视觉编码器，使得动态场景中的零样本检索和语言推理无法实现。

## 2. 方法论

- **总体框架**：两阶段训练策略。
  - **阶段 A：CL4D 对比预训练** —— 将动态点云序列编码为 4D 视觉嵌入，并与文本嵌入通过对比损失对齐到共享潜在空间。
  - **阶段 B：4DVLM 语言生成** —— 将 CL4D 提取的空间-时间嵌入投影后注入 LLaMA 语言模型，实现 4D 场景的视觉问答与指令跟随。

### 2.1 DynAction4D 数据集构建

- **三个主要 segment**：
  - **HumanOnly**：来源于 HumanML3D，23k 训练序列 + 4k 测试序列，覆盖日常动作、运动、杂技、舞蹈等。
  - **ObjInteractions**：来源于 Humoto，人类与物体交互，72 个物体、735 种交互；510 训练 + 219 测试。
  - **Cluttered**：将 HumanML3D 动作放入有 Humoto 物体杂乱布局的场景中，23k 训练 + 4k 测试。
- **数据生成流程**：SMPL 参数 → Unity 动画 → 随机体型/纹理/位置增强 → 均匀表面点云采样（约 2048 点/帧，20 FPS）→ 形成 4D 点云序列。
- **4D-VQA 子集**：通过 Gemini 3.0 Flash 从渲染视频 + 文本描述生成结构化 QA 对，分三类：Action（动作）、Body-Spatial（身体空间）、Temporal（时序）。总计 27,279 个 QA 文件、159,187 对问答。

### 2.2 CL4D 编码器架构

- **Point Encoder (PE)**：标准 PointNet，每帧点云分为 k=64 组（每组 g=32 点），生成每帧特征 ft ∈ R^(k+1)×d1（含 CLS token）。
- **Spatio-Temporal Transformer Encoder (Vst)**：
  - 空间编码器 Vs：对每帧特征独立建模全局空间关系；
  - 对每帧输出 ht 取 {MAX, CLS, MEAN} 得到 ˜ht，堆叠为 3×d2×N 的张量 Hs；
  - 将 Hs 按 m×m（m=16）切成 patches，线性投影后输入时间编码器 Vt（由 ViT-B/16 初始化），最后取均值得到 Hst。
- **Text Encoder (TE)**：DistilBERT-base-uncased，使用 CLS 嵌入作为文本表示。
- **对比对齐目标**：使用 InfoNCE 对称损失（motion-to-text 与 text-to-motion），余弦相似度 + 温度系数 τ：

  ```
  L = L_m2t + L_t2m
  ```

  其中：

  ```
  L_m2t = -1/B * Σ_i log[ exp(s(v_i, t_i)/τ) / Σ_j exp(s(v_i, t_j)/τ) ]
  L_t2m = -1/B * Σ_i log[ exp(s(v_i, t_i)/τ) / Σ_j exp(s(v_j, t_i)/τ) ]
  ```

- **训练细节**：150 epochs，batch size 72，AdamW，Vst 与投影头学习率 1e-4，文本编码器 1e-5。

### 2.3 4DVLM 视觉-语言模型

- 将 Vst 输出的时空嵌入线性投影到 4096 维，匹配 LLaMA hidden size；
- 语言模型初始化为 LLaVA-v1.5-7B（Vicuna 7B 骨干）；
- 训练目标：标准自回归语言建模损失，冻结语言编码器和 CL4D 编码器，只训练投影层 10 epochs，lr=1e-3。

## 6. 主要结论与发现

1. **CL4D 显著优于先前 4D 编码器**：在 text-to-motion 检索的 Batch R@1 上，相对最佳基线分别提升 **16.75%（HumanOnly）、8.1%（ObjInteractions）、13.36%（Cluttered）**。
2. **CL4D 具有跨领域泛化能力**：在真实机器人操作数据 RH20T 上，CL4D-mini 以较小参数和 60% 的 GFLOPs 减少仍达到最优，说明 4D 点云表示不局限于人体动作。
3. **4DVLM 超越前沿视频 VLM**：即使将同一场景渲染为 RGB 视频输入给 Gemini 3.0 Flash/3.1 Pro、GPT-5，4DVLM 在 BLEU、ROUGE、METEOR、SimCSE 等指标上仍全面领先，证明了**几何感知的 4D 表示**在动作语言推理中的优势。
4. **对比预训练是有效的**：InfoNCE 优于 SigLIP；冻结文本编码器会显著降低性能；预训练 ViT 初始化时间编码器至关重要（未训练 ViT 性能下降）。
5. **时序建模与数据规模重要性**：帧数增加提升性能；batch size 增大提升对比学习效果，符合 InfoNCE 的负样本特性。

## 7. 优点

- **首创性**：首次将对比语言预训练范式扩展到 4D 动态点云，填补了“空间+时间+语言”联合对齐的空白。
- **架构设计合理**：采用 PointNet + 空间 Transformer + 时间 Transformer 的模块化组合，并巧妙利用 3D 张量 patch 化方法将空间特征序列转化为类似 Visual Transformer 的输入，从而可初始化自预训练 ViT，促进迁移学习。
- **数据工程扎实**：构建了包含人类动作、物体交互、杂乱场景和 VQA 的多样基准 DynAction4D，公开数据与代码（项目主页），促进可复现性。
- **公平对比意识强**：
  - 对先前 4D 编码器使用相同对比损失重训；
  - 对视频模型提供对应的渲染视频，并额外提供多视角输入，降低模态差异带来的不公平。
- **鲁棒性分析**：考虑 LiDAR 真实点云退化（部分点云、重建误差），并验证帧洗牌导致性能显著下降，证明了模型确实在利用时序信息。
- **实用优势**：只使用几何坐标 (x,y,z)，不依赖外观/纹理，支持隐私保护部署。

## 8. 不足与局限

- **数据偏向合成环境**：DynAction4D 主要由 Unity 渲染生成，与真实 LiDAR/深度传感器数据存在域差距；RH20T 实验仅用 CL4D-mini，且仅覆盖操作任务，真实场景泛化验证不足。
- **人类中心主义偏重**：虽然 CL4D 声称面向任意动态实体，但主要训练数据来自人类动作，非人体（如机械臂）的泛化仅在 RH20T 上部分验证。
- **缺少大规模真实 4D 点云-语言数据集**：真实世界 4D 点云序列标注文本稀缺，限制了模型的进一步扩展。
- **4DVLM 评估指标有限**：主要使用自动自然语言指标（BLEU/ROUGE/METEOR/BERTScore/SimCSE），未能充分反映空间/时间推理的正确性，且缺少人工评分或细粒度事件准确率评测。
- **算力细节缺失**：论文未报告 GPU 型号、数量、训练时间，影响复现成本评估。
- **检索性能的 Global 设置很低**：例如 HumanOnly Global R@1 仅约 8%，虽然 Batch 指标很高，但实际大规模开放检索性能仍弱，说明对比对齐强度有限。
- **基线对比范围有待扩展**：未与视频点云 VLM（如直接处理 4D 数据的现有模型），或更近期的 3D 基础模型（如 ULIP/OpenShape 的 4D 扩展）进行比较。
- **文本生成任务相对简单**：VQA 问题基于同一数据源生成，可能引入模型偏置（Gemini 生成的答案作为 ground truth 存在主观性风险）。

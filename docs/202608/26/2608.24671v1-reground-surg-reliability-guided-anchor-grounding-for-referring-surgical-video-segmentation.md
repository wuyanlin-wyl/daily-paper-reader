## 摘要
手术视频指代分割要求根据自然语言表达在视频帧中分割出目标器械或组织区域。近期基于Segment Anything Model 2（SAM2）的两阶段方法（如ReSurgSAM2）首先在初始帧或选定帧中对所指目标进行定位，然后通过跟踪传播选定的掩码。尽管这些方法有效，但其性能对初始定位掩码的质量高度敏感：一旦选择了错误的锚点，后续跟踪往往会传播错误。这一问题在手术视频中尤其具有挑战性，因为器械外观相似、存在遮挡以及复杂的组织-器械交互。为解决该问题，我们提出了ReGround-Surg，一种轻量级的可靠性引导锚点定位框架，以改进基于SAM2的手术视频指代分割。它首先根据指代表达和当前帧视觉特征预测一个文本条件空间可靠性图。该图随后在两个互补分支中被复用：门控侧适配器在文本-视觉融合前增强与表达相关的视觉区域，而可靠性加权视觉-文本注意力模块在提示词聚合过程中抑制目标外的视觉证据。在Ref-EndoVis17和Ref-EndoVis18上的实验表明，在三个评估划分上相比最先进方法均取得了一致的改进，且速度下降可忽略不计。代码公开于https://github.com/JiaxinWen1/ReGround-Surg。

## Abstract
Referring surgical video segmentation requires segmenting a target instrument or tissue region across video frames according to a natural language expression. Recent Segment Anything Model 2 (SAM2) based two-stage methods (e.g., ReSurgSAM2) first ground the referred target in an initial or selected frame, then propagate the selected mask via tracking. Although effective, their performance is highly sensitive to the quality of the initial grounded mask: once an incorrect anchor is selected, subsequent tracking tends to propagate the error. This issue is especially challenging in surgical videos due to visually similar instruments, occlusion, and complex tissue-tool interactions. To address this issue, we propose ReGround-Surg, a lightweight reliability-guided anchor grounding framework to improve SAM2-based referring surgical video segmentation. It first predicts a text-conditioned spatial reliability map from the referring expression and current-frame visual features. The map is then reused in two complementary branches: a Gated Side Adapter enhances expression-relevant visual regions before text-to-vision fusion, while a Reliability-Weighted Vision-to-Text Attention module suppresses off-target visual evidence during prompt-token aggregation. Experiments on Ref-EndoVis17 and Ref-EndoVis18 show consistent improvements over state-of-the-art methods across three evaluation splits with negligible speed reduction. Code is publicly available at https://github.com/JiaxinWen1/ReGround-Surg.

**整体含义**

- 论文并非要修改 SAM2 跟踪阶段，而是聚焦于 Stage I 的锚定质量，提出一个轻量级、即插即用的可靠性引导框架，从根源上缓解锚定误差的传播问题。

## 论文提出的方法论

**核心思想**

- 预测一个**文本条件空间可靠性图（text-conditioned spatial reliability map）**，刻画每个空间位置与指代表达的语义对齐程度；然后将该图同时复用于两个互补分支：
  1. **Gated Side Adapter（GSA）**：在文本→视觉（T2V）融合前对视觉特征进行可靠性调制，增强指代相关区域；
  2. **Reliability-Weighted V2T Attention（RW-V2T）**：在视觉→文本（V2T）聚合时以可靠性图为权重抑制非目标视觉证据。

**关键技术细节**

1. **Text-Guided Reliability Gate（文本引导可靠性门）**
   - 对文本 token 序列做元素级 max-pooling（对应名词性判别特征）：\( n_c = \max_{i=1}^{N} Q_{:,i,c} \)
   - 将文本特征与当前帧视觉特征分别投影到 64 维瓶颈，再通过逐通道点积与 sigmoid 得到可靠性图 \( G \in [0,1]^{B×1×H×W} \)（公式见论文 Eq. 1–2）。
   - 在三个 TwoWayTokenAttentionBlock 层中分别独立计算，适应不同层级的表征细化。

2. **Gated Side Adapter（GSA，门控侧适配器）**
   - 可靠性图以**软残差门控**方式调制视觉特征：\( \tilde{K} = \hat{K} \cdot [\alpha + (1-\alpha)G] \)，其中 α=0.3 为网格搜索选取的软性下限（公式见论文 Eq. 3）。
   - 采用残差调制而非直接掩码，避免在表达模糊或目标被遮挡时过度抑制上下文信息。
   - 通过零初始化的 1×1 卷积残差添加回原特征（Eq. 4），保证适配器在初始状态与基线完全等价，保留预训练表征。
   - 只调制当前帧特征，保留 CIFS 选定的参考帧特征不变，避免破坏时间锚定的稳定性。

3. **Reliability-Weighted V2T Attention（RW-V2T，可靠性加权视觉-文本注意力）**
   - 将可靠性图 G 作为视觉 key 的乘法权重：\( K_{v2t} = \text{LayerNorm}[K + W_v(K \cdot v_{full})] \)（Eq. 5），使指代相关区域在 prompt token 聚集中贡献更大。
   - 残差接回原 K 而非加权版本，保证下游视觉特征信息无损（information-lossless design）。
   - 可靠性门没有显式监督，通过分割损失隐式学习。

4. **训练与推理**
   - SAM2 图像编码器、CLIP 文本编码器、掩码解码器与全部 Stage II 组件冻结；仅更新 CrossModalFusionModule（原 CSTMamba 权重 + 约 0.5M 新增参数）。
   - 损失函数与 ReSurgSAM2 一致（组合掩码 BCE、Dice、IoU、分类损失）。
   - 推理时只用于 Stage I 检测，锚点掩码送入原 SAM2 跟踪阶段，与 Stage II 完全解耦，具备即插即用性。

## 论文的主要结论与发现

1. **性能提升显著**：在 Ref-EndoVis17（tool）、Ref-EndoVis18（tool）、Ref-EndoVis18（tissue）上分别实现 J&F 提升 **+3.77、+3.09、+0.94**，且速度几乎不变（仅 −0.3 FPS）。
2. **误差源头确认**：初始锚定质量（Init. J&F +9.52、AnchorAcc +8.98）是最终视频分割性能的主要瓶颈；跟踪只能平滑小幅噪声，无法纠正错误锚点。
3. **模块互补性**：GSA 与 RW-V2T 的联合增益（+3.09）超过各自单独增益之和（+1.81 + +0.60 = +2.41），证明共享可靠性图可实现两个注意力方向上的协同调制。
4. **场景鲁棒性**：在同类型器械混淆（+5.62）、部分遮挡（+4.17）、多器械场景（+4.15）下均有较大提升，说明可靠性门控能有效抑制视觉相似干扰物。
5. **组织类目标增益有限**：对空间上弥散的组织区域提升较小（+0.94），反映该方法的优势集中在边界明确的刚性器械上。

## 优点

1. **直击痛点，机制清晰**：精准定位了两阶段方法的锚定瓶颈，并用量化证据（Table 8、Fig. 4）支撑问题分析，研究动机扎实。
2. **轻量高效**：仅新增 0.5M 参数，推理速度几乎无损，满足手术视频分析对实时性的需求。
3. **即插即用设计**：仅改动 Stage I，与 Stage II 跟踪完全解耦，便于集成到现有 SAM2-based 框架。
4. **信息无损的残差设计**：GSA 的零初始化残差和 RW-V2T 的残差回接，在初始状态保持与基线完全一致，训练稳定且保留预训练能力（Table 7 验证）。
5. **同一可靠性图的多路复用**：一个共享的文本条件可靠性图同时服务于两个注意力方向，既节省参数又实现协同调制，设计优雅。
6. **实验分析深入**：从模块消融到初始锚定分析、难例分层再到散点图（Fig. 4），多角度验证了方法的机制合理性，说服力强。

## 不足与局限

1. **组织类目标改进有限**：空间弥散的组织区域边界不清晰，可靠性门控的空间聚焦收益较小（仅 +0.94），方法适用范围存在偏置。
2. **超参数需人工调节**：门控下限 α 在不同手术领域可能需要重新网格搜索，缺乏自适应性。
3. **Stage II 未改进**：锚定帧之后的记忆漂移或长期遮挡导致的错误仍无法解决，属于“治标不治本”的范畴（作者在结论中承认此局限）。
4. **对比方法覆盖不全**：SurgRef（最新 motion-guided 方法）因权重未公开而缺席对比，缺少与该方法的直接竞争证据。
5. **泛化性证据不足**：仅在 EndoVis 系列（同一手术场景）上验证，未在多种手术类型、不同成像条件下的跨域评估，也没有使用不同骨干网络（如 Hiera-Base/Large）做稳健性测试。
6. **算力细节不完整**：未报告具体训练时长和显存消耗，复现成本不透明。
7. **可靠性图缺乏显式监督**：虽然隐式学习可行，但缺少可解释性保障，极端情况下可能产生“高置信错误”的可靠性估计。

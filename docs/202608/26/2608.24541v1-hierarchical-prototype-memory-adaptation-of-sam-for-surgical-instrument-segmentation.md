## 摘要
手术器械分割（SIS）是计算机辅助手术的基础，可靠的器械掩膜能够实现精准的场景理解和临床辅助。近年来，通过提示学习将诸如Segment Anything Model（SAM）等基础模型适配到手术领域已显示出令人鼓舞的结果。然而，这些适配模型在具有挑战性的手术条件下的性能受到次优适配机制的限制。具体而言，仅通过下游分割损失来优化提示或原型往往会使它们退化为特定任务的参数，而非作为持久、稳定的类别记忆，从而降低其对复杂术中变化的鲁棒性。此外，通过单一提示路径路由多尺度视觉线索造成了瓶颈，阻碍了有效的尺度匹配耦合。为解决这些限制，我们提出了HPMA，一种用于SAM的层次原型记忆适配框架。具体而言，HPMA从标注的手术场景中构建一个冻结的多尺度视觉原型记忆库，并使用轻量级适配器将其整合到SAM的特征空间中，以保留稳定的类别证据。为最大化多尺度线索的效用，我们引入了一种尺度匹配耦合机制，其中全局原型校准类别级提示特征，结构原型指导解码器的目标查询，局部原型通过局部对齐目标对齐高分辨率特征图。在公开的EndoVis2017和EndoVis2018数据集上进行的大量实验表明，我们的方法达到了最先进的性能，优于现有的基础模型适配方法。

## Abstract
Surgical instrument segmentation (SIS) is fundamental for computer-assisted surgery, where reliable instrument masks enable precise scene understanding and clinical assistance. Recently, adapting foundation models like the Segment Anything Model (SAM) to the surgical domain via prompt-learning has shown encouraging results. However, the performance of these adapted models under challenging surgical conditions is constrained by suboptimal adaptation mechanisms. Specifically, optimizing prompts or prototypes purely via downstream segmentation loss tends to cause them to degenerate into task-specific parameters rather than serving as persistent, stable category memory, thereby degrading their robustness against complex intraoperative variations. Moreover, routing multi-scale visual cues through a single prompt pathway creates a bottleneck that hinders effective scale-matched coupling. To address these limitations, we propose HPMA, a Hierarchical Prototype-Memory Adaptation framework for SAM. Specifically, HPMA constructs a frozen, multi-scale visual prototype memory bank from annotated surgical scenes and integrates it into SAM's feature space using lightweight adapters to preserve stable category evidence. To maximize the utility of multi-scale cues, we introduce a scale-matched coupling mechanism where global prototypes calibrate class-level prompt features, structural prototypes guide decoder object queries, and local prototypes align high-resolution feature maps through a local alignment objective. Extensive experiments on the public EndoVis2017 and EndoVis2018 datasets demonstrate that our approach achieves state-of-the-art performance, outperforming existing foundation model adaptation methods.

## 2. 方法论

### 核心思想
- **解耦知识存储与特征适配**：不再盲目优化提示，而是从标注手术图像中提取多尺度视觉原型，构建冻结的原型记忆库，保持类别证据的持久稳定；随后用轻量适配器将这种稳定证据注入 SAM 的特征空间。
- **层次化尺度匹配耦合**：将不同层级（全局、结构、局部）的视觉证据分别注入到最匹配的模型组件中，避免单一路径瓶颈。

### 关键技术细节
1. **多尺度原型记忆库构建**：
   - 使用冻结的 SAM3 图像编码器从 FPN 中提取多尺度特征。
   - 对每个尺度（global、structural、local）和每个器械类别，利用真实掩膜做 masked average pooling 聚合图像级特征。
   - 通过 K-Means 聚类离线划分为 K 个原型向量（本文 K=4），构成记忆库 P ∈ R^{3×|C|×K×d}。
   - 记忆库在训练中保持冻结，仅通过轻量适配器注入。

2. **适配器形式**：
   - 对于尺度 s，给定目标 SAM 特征 Z，适配器计算残差：
     \[
     \tilde{Z} = Z + \alpha_s \Psi_s(Z, P_s)
     \]
     其中 α_s 为可学习的标量（初始值很小），Ψ_s 为轻量映射函数（LayerNorm + 两层 MLP + GELU）。

3. **全局级适配（注入文本特征）**：
   - 以文本 token 为查询，全局原型为键/值，通过交叉注意力更新文本特征：
     \[
     \tilde{T}_c = T_c + \alpha_g \cdot \text{softmax}(Q_c K_c^\top / \sqrt{d_k}) V_c W^O
     \]
   - 作用：将抽象文本嵌入锚定到手术域视觉流形中，校准类别语义。

4. **结构级适配（注入解码器对象查询）**：
   - 将结构原型映射为查询残差，直接加到解码器可学习对象查询 Q 上：
     \[
     \tilde{Q}_c = Q + \alpha_p \Phi_p(P_p^c)
     \]
   - 作用：赋予对象查询几何先验（如轴、钳口、尖端），帮助解析高度关节化的器械结构。

5. **局部级适配（训练-only 对齐目标）**：
   - 对高分辨率特征图 F0 在目标区域做空间池化（masked pooling），得到紧凑表示 φ。
   - 使用余弦距离作为局部对齐损失，将 φ 拉向对应类别的局部原型：
     \[
     L_{\text{align}} = \frac{1}{N}\sum_i \min_{k} (1 - \cos(\phi_i, p_{c_i,k}^l))
     \]
   - 作用：在不增加推理开销的情况下，细化器械边界和纹理细节。

6. **总体训练目标**：
   \[
   L = L_{\text{SAM3}} + \lambda_{\text{align}} L_{\text{align}}
   \]
   其中 L_SAM3 包含掩膜分类损失（focal）、Dice 损失、边界框损失、广义 IoU 损失、类别分类损失和存在性监督损失。

## 3. 实验设计

### 数据集与基准
- **EndoVis2017**：包含 8 个视频用于交叉验证，共 7 个器械类别（双极镊、Prograsp 镊、大持针器、血管封堵器、抓持牵开器、单极弯剪、超声探头）。使用 Shvets 等人的 4-fold 交叉验证。
- **EndoVis2018**：包含 11 个训练视频和 4 个验证视频，同样 7 个类别（替换为吸引管和施夹钳）。使用 González 等人的器械类型分割标注。
- **评价指标**：Challenge IoU、IoU、mean class IoU（mc IoU）、mean Dice（mDice）。Challenge IoU 只评估当前帧中实际出现的器械类别。

### 对比方法
- **专用手术分割模型**：ISINet、MATIS Frame、S3Net、SCI-Net。
- **SAM 基础适配方法**：TrackAnything、PerSAM、SurgicalSAM、MA-SAM2、Distillation-SAM。
- **额外基线**：GT Centroid + SAM3（使用真值质心作为空间提示）。

### 实验结果
- **EndoVis2017**：HPMA 获得 Challenge IoU 79.63，IoU 79.63，mc IoU 76.34，mDice 83.87，大幅优于所有对比方法（如 SurgicalSAM 的 Challenge IoU 69.94）。

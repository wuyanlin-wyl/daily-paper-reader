## 摘要
临床决策本质上是由经验驱动的：医生通过综合患者病史、多模态观察结果以及跨交互的既往诊断经验，逐步完善其推理过程。相比之下，当前基于多模态大语言模型（MLLM）的医疗AI代理大多作为无状态推理系统运行，每次交互独立生成决策，既不保留也不内化经验知识。这种差异限制了它们通过使用逐步提高推理可靠性，并在真实临床工作流程中适应纵向患者情境的能力。在本研究中，我们提出了医学结构化多模态记忆（MSM-Mem），一种智能体记忆框架，使医疗AI代理能够通过积累临床经验而进化。MSM-Mem将异质的临床经验组织为语义记忆、情景记忆和视觉记忆，并在推理过程中增量更新它们，使代理能够检索先前经验以指导当前推理，并随着时间推移逐步优化决策。在MoE-LLaVA骨干上的评估显示，性能持续提升，并且通过持续使用观察到进一步的增益。总的来说，MSM-Mem为医疗AI代理提供了一条可行的途径，使其能够以类似于临床医生随时间从实践中学习的方式进化其推理能力。

## Abstract
Clinical decision-making is inherently experience-driven: physicians progressively refine their reasoning by synthesizing patient history, multimodal observations, and prior diagnostic experiences across interactions. In contrast, current multimodal large language model (MLLM)-based medical AI agents largely operate as stateless inference systems, generating decisions independently for each interaction without retaining or internalizing experiential knowledge. This discrepancy limits their ability to progressively improve reasoning reliability through usage and adapt to longitudinal patient contexts in real-world clinical workflows. In this study, we propose Medical Structured Multimodal Memory (MSM-Mem), an agentic memory framework that enables medical AI agents to evolve through accumulated clinical experiences. MSM-Mem organizes heterogeneous clinical experiences into semantic, episodic, and visual memory and incrementally updates them during inference, allowing the agent to retrieve prior experiences to inform current reasoning and progressively refine decision-making over time. Evaluations on MoE-LLaVA backbones demonstrate consistent performance improve- ments with further gains observed through continued usage. In general, MSM-Mem offers a viable pathway toward medical AI agents capable of evolving their reasoning competence in a manner analogous to the way clinicians learn from practice over time.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：构建一个结构化的多模态记忆框架（MSM-Mem），将异构临床经验分解为三类互补的记忆组件，并在推理过程中增量更新，使代理能够检索既往经验来指导当前推理。

- **记忆形式化定义**：记忆库定义为 `M = {MS, ME, MV}`，其中：
  - **MS（语义记忆）**：按患者维护的纵向诊断摘要，通过确定性聚合近期情景印象生成：`M_p^S(t) = US(M_p^S(t−1), a(t), d(t))`，其中 `US` 为患者特定更新算子，`a(t)` 为当前印象，`d(t)` 为决策结果；
  - **ME（情景记忆）**：存储既往患者-临床医生交互记录，每条记录为 `e_i = (subj_i, epi_i, t_i, z_i, q_i, a_i, d_i, vis_path_i, vis_desc_i)`，涵盖主体ID、交互ID、时间戳、视觉嵌入、临床查询、生成响应、决策结果和影像引用；
  - **MV（视觉记忆）**：存储既往视觉观测的紧凑表征，记录为 `v_i = (subj_i, epi_i, vis_i, t_i, z_i, vis_tag_i, vis_path_i)`，用于原型级检索和比较。

- **离线循环（Offline Loop）**：
  - 仅执行一次，用于构建基础记忆（Base Memory）；
  - 包括多模态编码器、记忆索引构建器和基础记忆构建；
  - 使用 ImageBind 视觉编码器（224×224分辨率，L2归一化）生成 d=1024 维嵌入；
  - 采用 FAISS（IndexFlatIP）索引，L2归一化后与余弦相似度等价；
  - 按患者ID（`patient_id`）对记忆进行分区管理。

- **在线循环（Online Loop）**：
  - 在每次训练、测试和推理时执行；
  - 包含统一检索器、提示构建器、带有自适应路由的推理模型；
  - 逐步增强世界记忆，确保持续写入新临床数据后推理结果逐步逼近真实值。

- **检索与融合**：
  - 对查询计算检索键：`z_p(t) = f_θ(x_p(t)) / ‖f_θ(x_p(t))‖₂`；
  - 通过余弦相似度检索情景和视觉记忆：`R_k(z_p(t)) = TopK_{m_i∈M_p^k}(z_p(t)ᵀ ẑ_i)`，k∈{E,V}；
  - 语义记忆作为患者特定上下文状态直接并入；
  - 最终提示为：`P(t) = Fuse(M_p^S, R_E(z_p(t)), R_V(z_p(t)), Q(t)))`；
  - 推理通过 `y_t = MLLM(P(t), x_p(t))` 完成。

- **输出驱动的记忆更新（Writeback）**——三重门控条件：
  - **新颖性门槛**：当前交互的感知表征需与已存储经验有足够差异，即 `max_i(z_p(t)ᵀ ẑ_i) < τ`，默认 `τ=0.90`；
  - **最小长度要求**：生成的印象文本需超过 k 个词（默认120词）；
  - **临床相关性关键词**：生成的印象需包含至少一个临床相关关键词（如"severe"、"worse"、"effusion"等）；
  - 语义记忆在每次交互后都更新，而情景和视觉记忆仅在满足上述条件时更新；
  - 记忆容量限制：每位患者最多200条情景/视觉记忆条目。

- **自适应路由（MoE Router Gating）**：
  - 仅微调路由门控权重 `W_g`，保持所有专家参数固定；
  - 路由过程：`g(x) = TopK(W_gx)`，动态选择最相关的专家子集；
  - 根据记忆特征的排序和余弦相似度实现自适应路由。

### 6. 论文的主要结论与发现

- **记忆组件均有增益**：在无记忆基线上，加入任意单一记忆模块（语义、情景或视觉）都能带来一致的性能提升。
- **情景记忆贡献最大**：在单模块配置中，情景记忆带来的性能增益最大，说明既往交互层面的决策轨迹提供了高信息量的经验上下文。
- **组合记忆显著增强**：情景+视觉联合带来大幅提升（MoE-FT上F1从18.43提升到44.80），完整记忆（E+V+S）在所有配置中取得最佳性能（MoE-FT上F1达54.92，EM达51.50）。
- **持续使用带来持续提升**：从基础记忆到WB4阶段，所有记忆配置的性能都呈现单调递增趋势，验证了代理能够从经验中自我进化。
- **更强的骨干仍受益于记忆**：MoE-FT骨干结合完整记忆的配置达到最高总体性能，说明记忆增强推理可以提供超出骨干能力本身的互补增益。
- **MoE门控的有效性**：相比常规FT，MoE-FT门控网络在不同记忆模态下带来7.16%-8%的额外增益。

### 7. 优点

- **问题定义精准**：准确把握了医疗AI代理"无状态"的根本缺陷，与临床"经验驱动"的决策本质形成鲜明对比，动机扎实且有说服力。
- **记忆分解设计合理**：将临床经验分解为语义、情景、视觉三类记忆，分别对应患者纵向状态、交互决策轨迹和感知影像证据，与认知科学中人类记忆组织的理论相呼应。
- **完整的记忆生命周期**：涵盖记忆构建（离线）→ 检索（在线）→ 推理 → 选择性写入（writeback）→ 持续更新的完整流程。
- **受控的记忆更新机制**：新颖性阈值 + 最小长度 + 临床关键词的三重门控，有效避免冗余记忆积累和检索质量退化，体现了工程上的周密考量。
- **对幻觉问题的针对性缓解**：通过真实影像证据和既往决策轨迹的锚定，直接回应了医疗AI中的幻觉问题。
- **实验设计系统性较强**：全组合消融 + 多骨干对比 + 渐进式writeback分析，论证层次清晰。
- **MoE自适应路由与记忆特征的结合**：将记忆检索结果与MoE专家路由相结合，在推理效率与性能之间取得了平衡。

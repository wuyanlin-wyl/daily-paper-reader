## 摘要
任务特定的LoRA适配器为大型语言模型和视觉-语言模型提供了一种模块化的专门化方式。然而，现有的适配器组合方法大多是静态的，无法适应单个测试输入。为解决这些问题，我们提出了LiST，一个无标签的测试时LoRA融合框架，它将现有的LoRA库转换为目标条件下的局部单纯形，并在推理时搜索样本特定的融合权重。LiST从LoRA参数锚点和提示级行为向量构建联合任务表示，检索邻近适配器作为局部搜索空间，并在不更新骨干网络或适配器的情况下执行保留分支的融合。候选权重通过带有先验、几何和随机一致性约束的提示级能量进行选择，并且仅当它们通过安全接受规则时才被部署。否则，LiST回退到目标条件下的先验。在多模态和语言基准上的实验表明，LiST优于静态LoRA合并和传统的测试时自适应基线，同时保持了任务特定适配器的效用，并提高了在未见任务上的鲁棒性。

## Abstract
Task-specific LoRA adapters offer a modular way to specialize large language and vision-language models. However, existing adapter composition methods are mostly static and cannot adapt to individual test inputs. To address these issues, we propose \textbf{LiST}, a label-free test-time LoRA fusion framework that converts an existing LoRA bank into a target-conditioned local simplex and searches sample-specific fusion weights at inference time. LiST builds joint task representations from LoRA parameter anchors and prompt-level behavior vectors, retrieves neighboring adapters as a local search space, and performs branch-preserving fusion without updating the backbone or adapters. Candidate weights are selected by a prompt-level energy with prior, geometric, and stochastic-consistency constraints, and are deployed only when they pass a safe acceptance rule. Otherwise, LiST falls back to a target-conditioned prior. Experiments on multimodal and language benchmarks show that LiST outperforms static LoRA merging and conventional test-time adaptation baselines, while preserving task-specific adapter utility and improving robustness on unseen tasks.

# LiST: 局部单纯形测试时LoRA融合 论文总结

## 1. 核心问题与研究动机

- **背景**：多模态大语言模型（MLLMs）和语言模型在部署时常面临多任务场景，LoRA作为参数高效的微调方式，被广泛用于构建任务特定的适配器库（LoRA Bank）。
- **现有问题**：
  - 现有适配器组合方法（如任务算术、TIES、DARE、AdaMerging等）大多是**静态的**，即对全部测试样本使用同一组固定融合权重，无法根据单个测试输入进行实例级调整。
  - 直接对LoRA参数进行平均会扭曲其低秩分支结构，导致不稳定的知识迁移或负迁移。
  - 多模态生成任务缺乏统一的损失函数，难以套用传统测试时自适应（TTA）方法（如熵最小化等）。
- **研究目标**：在不更新骨干网络（backbone）和任何适配器参数的前提下，实现**无标签、样本特定（sample-specific）的测试时LoRA融合**，同时保持任务特定适配器效用并提升对未见任务的鲁棒性。

## 2. 方法论

### 核心思想

LiST将原有的LoRA库转换为一个**目标条件局部单纯形**（target-conditioned local simplex），在推理时为每个测试样本在单纯形上搜索最优的低维融合权重。整个框架分为**离线准备**和**在线测试时搜索**两个阶段。

### 关键技术细节

1. **任务表示构建（任务级离线准备）**：
   - **参数锚点（Anchor）**：将每个任务的所有LoRA张量展平拼接为参数向量 $\ell_t$，再经PCA投影为低维锚点 $a_t = U^T \ell_t$。
   - **行为向量（Behavior Vector）**：用小支持集 $Q_t$ 运行带适配器的骨干网络，对隐藏状态取平均得到 $v_t$。将锚点与行为向量拼接得到最终任务表示 $r_t = [a_t; \tilde{v}_t]$，用于计算任务间余弦相似度。

2. **局部单纯形构建**：
   - 对目标任务 $t$，检索Top-K个最相似适配器，构成局部邻居集合 $S_t = \{t\} \cup \text{TopK} \sin(t,i)$。
   - 定义目标条件先验 $\alpha_t^{(0)}$：目标LoRA获得质量 $\rho$，邻居按相似度分配剩余权重。
   - 估计局部锚点协方差的精度矩阵 $\Lambda_t$，作为几何约束的信任区域。
   - 针对未见域任务，退化为仅基于检索相似度的归一化先验。

3. **分支保留融合（Branch-Preserving Fusion）**：
   - 不直接平均LoRA参数，而是在线性层输出处按权重融合各适配器的分支输出：$y = W_0 x + \sum_{i \in S_t} \alpha_i s_i B_i(A_i x)$。
   - 通过围绕先验的 simplex-logit 扰动 $\delta$ 参数化融合权重：$\alpha(\delta) = \text{softmax}(\log \alpha_t^{(0)} + \delta)$。

4. **提示级能量与约束（Prompt-level Energy）**：
   - **任务能量**：对候选 $\delta$ 做 M 次随机前向（MC dropout等），取不确定性函数 $U(q_m)$ 的平均作为 $E_{\text{task}}$。
   - **三种可行性约束**：先验偏离（KL散度）、几何距离（融合锚点重心到目标锚点的马氏距离）、随机一致性（M次预测的JS散度）。
   - **能量归一化**：各分量经相对归一化（相对先验基线或阈值违规率）后组合为最终能量 $E(\delta | x, t)$，使用固定系数在不同任务间共享。

5. **搜索与安全接受规则**：
   - 使用**CMA-ES**优化器（仅 $\delta$ 为优化变量，维度为 $|S_t|$）搜索低能量解 $\delta^*$。
   - 接受条件：能量改进 $\Delta E > m_{\text{accept}}$ 且最大归一化违规 $\nu(\delta^*) \leq \tau_{\text{feasible}}$。
   - 满足条件时部署 $\alpha(\delta^*)$，否则**回退到目标条件先验** $\alpha_t^{(0)}$，防止不可靠低能量候选带来的负迁移。

## 6. 主要结论与发现

- LiST 在**多模态和语言基准上均取得最优平均成绩**：
  - Qwen3-VL-8B 已见任务平均 83.84，未见任务平均 68.18，均显著超过最佳基线（如MEMO、TENT）；
  - LLava-V1.5-7B 平均 73.53 / 56.15，同样优于所有对比方法；
  - 语言任务：DeepSeek-7B 平均 87.88、Qwen3-8B 平均 87.70，接近甚至超过单任务 LoRA 上限。
- 在未见任务上，LiST 因仅从已见域适配器构建局部单纯形并结合先验与安全回退，**极大减轻了负迁移**（负迁移从0.10+降至0.02），说明样本级局部单纯形搜索能有效进行跨域知识复用。
- 安全接受规则并非保守退步：接受率约42%~60%，拒绝的候选大多是能量改善不足或约束违规过大的搜索点；正确使用回退机制带来了鲁棒性提升。
- 能量分析表明，提示级能量与任务指标呈正相关，但**必须与可行性约束相结合**，否则低能量不代表好性能。

## 7. 优点

- **方法新颖且实用**：将LoRA组合建模为测试时连续搜索，实现了真正的样本自适应，同时保持骨干和适配器完全冻结，参数开销极低（只优化 $|S_t|$ 维 simplex-logit）。可复用，计算开销小，适合多任务部署。
- **分支保留融合**：避免参数平均带来的结构破坏，在概念上更贴合LoRA的线性低秩分支特性。
- **安全机制设计合理**：先验回退规则与能量-可行性的双重判断，显著提升了可靠性，可解释性强。
- **框架适配面广**：覆盖多模态和纯语言两类大模型，支持已见与未见任务评测，能直接复用已有LoRA库。
- **验证充分**：除主实验外，对能量组成、邻居检索策略、接受规则和关键超参数均做了系统消融，且提供了能量-任务指标对齐关系分析。

## 8. 不足与局限

- **对适配器库的依赖**：LiST 性能依赖于存在高质量、邻近的适配器；若LoRA库中缺乏与目标任务相关的适配器，则搜索无明显增益甚至有害（K=0与K=1实验也显示个别情况下效果退化）。
- **推理成本增加**：测试时需多次MC前向（M=8）和CMA-ES搜索，相比直接使用单适配器开销显著增加；尽管维度低，但延迟仍较静态方法高。
- **能量代理的局限**：所提出的提示级不确定性能量对高度开放的自由生成任务（如长文生成、创作型对话）与任务指标的关联可能减弱，论文对此未充分验证（仅覆盖GLUE和MM-MergeBench的封闭式/VQA类任务）。
- **消融对象局限**：核心消融只在单一骨干（Qwen3-8B）和单一基准（GLUE）上完成，缺少在多模态骨干上的组件级验证。
- **未来展望不足**：对更极端分布偏移、适配器数量扩展、更大模型（如100B+参数）下的可扩展性未做讨论或试验验证。

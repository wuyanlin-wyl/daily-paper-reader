### 1. An Edge-aware Prompt-enhanced SAM for Ultrasound Image Segmentation
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2607.07240v1
- 方法流程：
  - 输入图像I∈R^{H×W×3}，经过SAM图像编码器（含Mona Adapters）提取4个阶段的特征图g1,g2,g3,g4（分辨率H/8×W/8）。
  - EAM模块接收g1~g4，通过4个Edge-Aware Block依次处理：每个Block对当前特征进行残差卷积精炼，与下一阶段特征拼接，经门控空间交互输出下一阶段边缘特征si+1；同时每个阶段投影出边缘概率图Ei并计算边缘损失。
  - PEM模块将g1~g4与对应的边缘特征s2~s4（边界对齐后）拼接，经1×1卷积降维并上采样至H/2×W/2，通过4个并行1×1卷积头生成粗掩码m1~m4，再经动态门控加权融合得到最终粗掩码M_coarse。
  - M_coarse作为掩码提示输入SAM的原生提示编码器，生成密集提示嵌入，与图像编码器最终特征一起送入SAM掩码解码器，输出最终分割结果。
- 关键模块/机制：
  - Edge-Aware Module (EAM)：从SAM图像编码器的中间Transformer特征中提取边界感知表示，为后续提示生成提供结构信息。；包含4个Edge-Aware Block (EAB)。每个EAB对输入特征进行残差卷积精炼，然后与下一阶段的Transformer特征gi+1拼接，通过门控空间交互（类似动态卷积）自适应强调边界响应、抑制纹理激活。每个阶段输出si+1，并通过投影头P(·)和sigmoid生成边缘概率图Ei，与真实边界计算损失进行监督。
  - Prompt Enhanced Module (PEM)：融合多级图像特征和边缘特征，生成边界信息增强的粗掩码，作为掩码提示输入SAM提示编码器。；将图像编码器的中间特征gi与对应EAM输出边缘特征si+1（边界对齐）拼接，经1×1卷积降维，双线性上采样至H/2×W/2。然后通过4个并行1×1卷积头预测4个粗掩码mi，再经动态门控：全局池化后经轻量门控网络（含softmax）生成权重wi，加权求和得到最终粗掩码M_coarse=∑wi·mi。M_coarse直接作为掩码提示输入SAM提示编码器。
- 公式/目标函数/指标定义：
  - 边缘概率图：Ei = σ(P(si))，其中P(·)为轻量投影头，σ为sigmoid。
  - 粗掩码融合：M_coarse = ∑_{i=1}^n w_i · m_i，其中权重w由动态门控网络通过全局池化和softmax生成。
  - 总损失：L_total = λ1 * L_seg + λ2 * L_edge，其中L_seg为最终掩码与真值的损失（如Dice+CE），L_edge为各阶段边缘概率图与真值边界之间的损失（如BCE）。
- 算法细节：
  - 特征提取阶段：SAM图像编码器（ViT）的每个Global Transformer Block后插入Mona Adapter，输出4个中间特征图g1~g4，分辨率均为H/8×W/8。
  - EAB处理：对于第i个EAB（i=1时输入g1），先经残差卷积（Conv-BN-ReLU-Conv）精炼，输出特征f_i；然后将f_i与gi+1拼接，经门控：先通过卷积+sigmoid生成空间门控图，与拼接特征逐元素相乘，再经卷积输出si+1。
  - PEM动态门控：对4个粗掩码mi分别进行全局平均池化，得到4个标量，通过全连接层和softmax生成权重w1~w4，然后加权求和。
  - 推理时：输入图像，经过图像编码器、EAM、PEM生成M_coarse，输入提示编码器（原SAM提示编码器，处理掩码提示得到密集嵌入），与图像编码器最终特征（来自最后一个Transformer Block）一起输入SAM掩码解码器（原SAM解码器），输出最终分割掩码。
- 训练/推理细节：
  - 训练时冻结SAM图像编码器（除Mona Adapters外）、提示编码器和掩码解码器的原始权重，仅训练EAM、PEM、Mona Adapters以及粗掩码预测头。
  - 边缘真值：通过形态学操作从分割真值中提取边界（如使用Sobel或Canny，但论文明确使用真值派生边界）。
  - 损失函数：总损失包括最终掩码分割损失（Dice Loss + Cross Entropy）和边缘预测损失（Binary Cross Entropy），边缘损失应用于所有4个边缘概率图。
  - 推理时：EAM和PEM为前馈过程，无需额外优化。直接输出M_coarse作为掩码提示，无需用户交互。

### 6. Repurposing CLIP to Localize at Pixel Level
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.05253v2
- 方法流程：
  - 输入：图像I和文本描述'[cls]'；CLIP文本编码器生成文本向量V_text∈R^{1×D}，CLIP图像编码器生成第一ViT层输入X=[E,C]∈R^{(N+1)×D}（E为图像块特征，C为类别token）
  - 提取初始定位线索：通过回溯CLIP分类过程，从关键层提取类特定注意力区域作为初始定位信息
  - 噪声抵抗校正：根据初始定位信息重分配patch权重，构建类原型并细化类别token，减少全局偏差引起的噪声
  - 定位嵌入：将校正后的定位信息嵌入到图像特征中，生成增强的高层特征，融合细节信息
  - 解码：将增强特征与图像特征合并，通过解码器生成最终分割图
- 关键模块/机制：
  - 回溯分类生成定位线索模块：从CLIP分类决策中提取对象特定的注意力区域，作为像素级定位的初始线索；使用文本模板'a photo of [cls]'通过CLIP文本编码器得到文本向量V_text；对输入图像I，CLIP图像编码器输出第一ViT层输入X=[E,C]，通过反向传播或注意力机制提取类特定激活图，得到初始定位热图
  - 噪声抵抗校正策略：细化初始定位线索，减少全局特征偏差带来的噪声，提升定位精度；基于初始定位信息，对图像块权重进行重新分配，构建类原型（class prototype）并更新类别token，使模型更聚焦于目标对象区域，抑制背景干扰
  - 定位嵌入策略：将校正后的定位信息与图像特征融合，保留原始定位线索的同时增强细节，支持高分辨率分割；将校正后的定位信息作为嵌入信号，与CLIP图像特征（如中间层特征）进行融合，生成对象感知的增强特征，再与解码器特征结合以细化分割边界
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 文本编码：使用CLIP文本编码器处理模板'a photo of [cls]'得到文本嵌入
  - 图像编码：使用CLIP图像ViT编码器得到图像块嵌入和类别token
  - 初始定位线索提取：通过梯度反向传播或注意力图生成每个图像块与目标类别的关联得分
  - 噪声校正：对关联得分进行归一化或阈值处理，根据得分重新分配注意力权重，并利用加权平均构建类原型，再与类别token进行融合更新
  - 定位嵌入：将校正后的定位得分图作为空间权重，与图像特征进行逐元素乘法或拼接，生成定位增强特征
  - 解码：使用轻量级分割头（如多层CNN或Transformer解码器）将增强特征映射为像素级二值分割图
- 训练/推理细节：
  - 训练阶段：在训练集（类别C_train）上微调模型，固定CLIP骨干参数，仅训练解码器及可选的适配层；使用二值交叉熵损失监督分割
  - 推理阶段：模型参数固定，输入任意类别文本（包括未见类C_test），直接输出分割掩码，无需额外参考图像或手工提示

### 7. Analysis-by-Proxy: Localization Signals in VLMs Operating as Condition Encoders
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.06445v1
- 方法流程：
  - 将VLM作为条件编码器，输入图像和文本提示，进行单次前向传播，提取中间层表示。
  - 在中间表示上训练一个轻量代理模型（如线性探针或小型MLP），以预测物体的边界框或定位信号。
  - 通过代理模型的预测准确性，评估各中间层中包含的定位信息量。
  - 分析定位信号在各层中的分布，发现信号并非集中在预定义的条件层，而是根据输入动态变化。
- 关键模块/机制：
  - VLM条件编码器：作为条件编码器提取图像-文本联合表示；输入图像和文本，冻结权重，进行单次前向传播，产生一系列中间层表示。
  - 轻量代理模型：从VLM中间表示解码定位信息；使用辅助定位任务（如边界框回归）训练，评估中间表示的空间信息含量，通常为线性探针或小型MLP。
  - 定位信号分析器：量化各中间层定位信号强度，发现依赖输入的分布；通过比较代理模型在不同层上的性能，定位信号最强的层即为关键层，揭示其随输入提示变化。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 预训练VLM权重固定，冻结所有参数。
  - 对于每个输入样本，从VLM的多个中间层提取特征。
  - 对每层特征，训练一个独立的代理模型进行定位预测。
  - 比较代理模型在不同层的性能，定位信号最强的层即为关键层。
- 训练/推理细节：
  - 训练阶段：使用标注了边界框的数据集，固定VLM，仅训练代理模型。代理模型可以是线性回归或小型MLP，在每层的特征上独立训练。
  - 推理阶段：VLM单次前向传播，从所有中间层提取特征，通过代理模型预测定位，但实际编辑管线并未使用此信息，仅作分析。

- 方法流程：

  - 多分辨率特征茎：将输入图像分别下采样至不同分辨率（如512x512和1024x1024）并提取初始特征
  - 并行多尺度特征提取
  - 特征融合后输入UNet++编码器
  - UNet++解码与跳跃连接
  - 输出分割掩膜
- 关键模块/机制：
  - Multi-Resolution Feature Stem：输入级多尺度特征提取；使用并行分支处理不同分辨率输入，每个分支包含少量卷积层生成特征图，然后融合（可能通过上采样对齐后拼接或相加）后送入主网络。
  - UNet++ backbone：分割骨干网络；密集跳跃连接结构，通过嵌套的卷积块和深监督进行特征传播。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 多分辨率特征茎包含多个并行处理不同分辨率输入的分支，每个分支对输入进行下采样到目标尺寸（例如通过双线性插值），然后通过少量卷积层提取特征。
  - 之后，这些特征被上采样到同一空间尺寸（通常是最高分辨率），并通过拼接或逐元素相加融合。

  - 探针分类头（Probe Head）：将池化隐藏状态映射到49个源的概率，通过独立逻辑单元和全局阈值产生多标签预测；对于每个源c，一个线性层+逻辑斯蒂函数：p_{qc}=σ(w_c^T h_ℓ + b_c)；训练时使用类别平衡的二元交叉熵损失，权重α⁺_c=N/(2n_c), α⁻_c=N/(2(N-n_c))，n_c为源c的频次；推理时使用全局阈值τ（在交叉验证中调整）
  - 层选择策略（Layer Selection）：确定从LMs中提取隐藏状态的层索引，提升探针性能；通过迭代分层5折交叉验证遍历所有隐藏层（包括嵌入层），选择使out-of-fold微F1最高的层。所有模型的最佳层均为1-4（浅层），因为源名称是近词汇属性
  - 池化策略（Pooling Strategy）：将变长token序列压缩为固定维度的向量，供分类头使用；平均池化：对所有token隐藏状态取均值；最后token池化：取最后一个token的隐藏状态。实验表明平均池化在所有模型和几乎所有层上优于最后token池化，因此最终采用平均池化
  - 类别不平衡处理（Class-Imbalance Handling）：应对长尾分布（26个源出现<20次，最少的仅2次），提升稀有源的召回；在训练中为每个源独立使用带权重的二元交叉熵，正类权重α⁺_c = N/(2 n_c)，负类权重α⁻_c = N/(2(N-n_c))，使稀有样本获得更高梯度；并使用迭代分层多标签划分确保跨折中稀有源的出现
- 公式/目标函数/指标定义：
  - 多热标签编码：y_{qc} = 1[s_c ∈ S⋆_q]，S⋆_q为空查询对应空集
  - set-exact准确率：Acc = (1/N) Σ_q 1[Ŝ_q = S⋆_q]
  - 微F1：F1_micro = 2 Σ_c TP_c / (2 Σ_c TP_c + Σ_c FP_c + Σ_c FN_c)
  - 宏F1：F1_macro = (1/K) Σ_c F1_c
  - 类别平衡二值交叉熵：L_c = -Σ_q [α⁺_c y_{qc} log p_{qc} + α⁻_c (1-y_{qc}) log(1-p_{qc})]
  - 池化：h^{mean}_ℓ = (1/T_q) Σ_t h^{(t)}_ℓ, h^{last}_ℓ = h^{(T_q)}_ℓ
- 算法细节：
  - 5折交叉验证时使用迭代分层策略（iterative-stratification）确保每个折叠中稀有源分布均衡
  - 层选择：对每个可能的层ℓ，训练49路逻辑回归头并评估out-of-fold微F1，选取最优层
  - 阈值τ选择：在out-of-fold概率上调整阈值以最大化set-exact准确率
  - 尺寸实验：对比135M、360M、0.5B、1.5B参数模型，显示135M模型性能与1.5B差距在1.5%以内
  - 推理时仅需部分前向传播至选定浅层，然后进行平均池化和线性变换，无需完整模型推理
- 训练/推理细节：
  - 训练：冻结LM参数，仅训练49维线性分类头；使用类别平衡二元交叉熵损失；优化器未说明（默认逻辑回归）/ 线性头可视为正则化逻辑回归
  - 推理：输入查询，LM部分前向传播至选定层ℓ，得到隐藏状态；对T_q个token状态进行平均池化；输入线性头，经sigmoid得到49个概率；应用全局阈值τ（从验证集选定），输出概率≥τ的源集合
  - 训练和推理均无需API调用，完全本地运行

### 19. CoRE-VLA: Towards Scalable and Robust Vision-Language-Action Modeling via Conditional Routing of Experts
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.03693v1
- 方法流程：
  - 输入：多视角RGB图像、语言指令、本体感知状态、可选辅助深度图像。VLM编码RGB和语言得到视觉-语言条件序列C；深度编码器（DA-V2）提取深度特征（若可用）。

  - CoRE块迭代：每个CoRE块包括：a) 意图引导表示选择：根据公式(2)计算每个动作表示的得分，选择TopK（容量ρLa）个表示；b) 条件注意力：所选表示对条件序列C做交叉注意力；c) 专家路由：根据公式(4)-(6)计算路由logits，应用模态掩码后选择每个表示对应的专家（通用或模态专用），输出与软路由概率相乘；d) 合并：更新后的表示与未选择的表示拼回完整序列。
  - 动作预测：经过多层CoRE块后，最终动作表示通过线性层输出预测速度场，再经流匹配ODE求解得到动作块。
- 关键模块/机制：
  - 条件路由专家模块（CoRE block）：根据任务意图和传感器可用性稀疏地选择动作表示和专家，实现自适应计算。；每个CoRE块包含表示选择器和专家路由器。表示选择器根据任务意图g和动作表示h的拼接，通过sigmoid计算得分，取TopK（容量ρ）。所选表示与条件序列C交叉注意力后，由路由器根据注意力输出和g计算专家logits，使用模态可用性掩码（若辅助模态不可用则-∞），softmax后选取最高分专家，输出乘以路由概率。
  - 模态dropout与专家掩码：训练时随机禁用辅助模态并掩码模态专用专家，增强策略对传感器缺失的鲁棒性。；训练时采样zmod~Bernoulli(1-pdrop)，当zmod=1时启用辅助模态分支和模态专用专家；zmod=0时禁用辅助模态输入并将模态专用专家logits设为-∞。推理时根据实际传感器可用性设置zmod。
  - 意图引导表示选择：稀疏选择与当前任务最相关的动作表示，提高计算效率并减少任务间干扰。；动作表示序列中每个表示h与任务意图g拼接，经线性层wsel得到标量得分pi=σ(w_sel^T[h;g])。选择得分最高的前K个表示，K=max(1, floor(ρLa))。所选表示进入后续计算，未选表示直接跳过。
  - 通用专家与模态专用专家分离：通用专家学习共享操作模式，模态专用专家处理模态特定特征，支持模块化扩展。；专家集分为Egen和Emod。路由时，若zmod=0则Emod被完全掩码（logits置-∞），仅Egen可选；若zmod=1则两者均可选。训练时先训练仅RGB的密集模型，再复制FFN作为通用专家，新增Emod，加辅助编码器进行继续训练。
- 公式/目标函数/指标定义：
  - 任务意图嵌入: g = AvgPool(C_text) ∈ R^{dc}
  - 表示选择得分: p_i = σ(w_{sel}^T [h_i; g])
  - 容量控制: K = TopK({p_i}, max(1, floor(ρ L_a)))
  - 专家路由 logits: r_{i,e} = w_e^T [\tilde{h}_i; g]
  - 模态掩码后 logits: \bar{r}_{i,e} = r_{i,e} (若 e∈E_gen 或 e∈E_mod且z_mod=1); 否则 -∞
  - 专家选择: e_i = argmax_e \bar{r}_{i,e}, π_i = softmax(\bar{r}_{i,:})_{e_i}
- 算法细节：
  - 动作表示序列长度为La（动作块长度），每个表示为d维。CoRE块中仅K个表示被选中参与后续计算，未选中直接跳过，减少计算量。
  - 条件注意力：每个被选中的表示作为query，与条件序列C（包括视觉、语言、本体感知，若深度可用则包含深度特征）做交叉注意力。
  - 专家路由：每个被选中的表示经过交叉注意力后得到tilde h，与g拼接，通过可学习路由权重w_e得到各专家logits。应用模态掩码后，选取得分最高的专家（hard selection），但路由概率仍通过softmax计算并与专家输出相乘，实现可微。
  - 流匹配推理：从高斯噪声x0开始，通过ODE求解器沿τ=0→1积分速度场f_θ，得到最终动作块hat a_{t:t+H}。
  - 模态dropout仅在训练时以概率pdrop随机禁用辅助模态，使模型适应缺失情况。
- 训练/推理细节：
  - 训练阶段：先使用RGB-language-proprioception输入从头训练一个密集Action DiT作为基础；然后将FFN模块复制作为通用专家，新增模态专用专家和辅助编码器，使用RGB-D数据继续训练（带模态dropout）。
  - 训练目标包含动作流匹配损失L_act、表示选择正则化L_sel和MoE负载均衡损失L_moe。
  - 推理时根据实际传感器可用性设置zmod，无需重新训练或微调。

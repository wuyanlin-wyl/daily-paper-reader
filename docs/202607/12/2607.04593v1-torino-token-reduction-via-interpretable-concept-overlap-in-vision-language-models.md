## 摘要
视觉-语言模型（VLM）在各种任务中展示了令人印象深刻的能力，但其计算成本主要源于馈送给语言模型的大量视觉令牌。现有的令牌缩减方法依赖于基于注意力的分数或成对相似性，而没有对每个令牌进行明确的语义表示。我们提出了TORINO（通过可解释的概念重叠进行令牌缩减），这是一个即插即用的框架，用于VLM中的自适应视觉令牌缩减，无需对底层模型进行微调。TORINO利用稀疏自编码器（SAE）将视觉令牌投影到一个可解释的潜在空间中，在该空间中可以通过共享的概念激活来分析令牌之间的关系。具体来说，我们将概念重叠定义为活跃SAE潜在变量之间的一致程度，并利用它来分组共享语义内容的令牌。然后，通过剪枝或合并对每组进行缩减，提供了一个统一的框架，在去除冗余的同时保留了语义上重要的视觉信息。与固定预算的方法不同，TORINO动态地根据输入复杂度调整缩减率，允许不同图像保留不同数量的令牌。在多个视觉-语言基准上的实验表明，TORINO在效率与准确性之间取得了有利的权衡，以最小的性能损失减少了视觉令牌的数量。

## Abstract
Vision-Language Models (VLMs) have demonstrated impressive capabilities across different tasks, but their computational cost is dominated by the large number of visual tokens fed to the language model. Existing token reduction methods rely on attention-based scores or pairwise similarity, without an explicit semantic representation of each token. We introduce TORINO (TOken Reduction via Interpretable coNcept Overlap), a plug-and-play framework for adaptive visual token reduction in VLMs that requires no fine-tuning of the underlying model. TORINO leverages Sparse Autoencoders (SAEs) to project visual tokens into an interpretable latent space where token relationships can be analyzed through shared concept activations. Specifically, we define concept overlap as the degree of agreement between active SAE latents and use it to group tokens that share semantic content. Reduction within each group is then performed by either pruning or merging, providing a unified framework that preserves semantically important visual information while removing redundancy. Unlike fixed-budget approaches, TORINO dynamically adapts the reduction rate to input complexity, allowing different images to retain different numbers of tokens. Experiments across multiple vision-language benchmarks show that TORINO achieves favorable efficiency-accuracy trade-offs, reducing the number of visual tokens with minimal performance loss.

- **核心问题**：视觉-语言模型（VLM）如 LLaVA 在处理图像时，视觉编码器（例如 CLIP ViT）会输出数百个 **patch token**，这些 token 全部传给大语言模型（LLM）。LLM 的自注意力机制与序列长度呈二次方复杂度，导致推理延迟高、内存占用大。
- **现有方法局限**：已有的 token 缩减方法（剪枝或合并）通常依据注意力分数、CLS token 相似度或原始嵌入距离来评估 token 重要性，缺乏对每个 token **所表示语义概念的显式建模**。因此，外观不同但语义冗余的 token 可能被错误保留，而共享抽象概念的 token 可能被分开处理。
- **整体含义**：论文提出利用**可解释性工具（稀疏自编码器 SAE）** 的语义潜在特征来指导 token 缩减，实现内容自适应的动态压缩，同时保持模型准确性。

## 2. 论文提出的方法论

### 2.1 核心思想
- 使用预训练的 **Matryoshka BatchTopK SAE**（扩展因子 ε=64）将视觉 token 投影到一个高维、稀疏、可解释的概念空间（latent vector），每个维度对应一个相对单语义的视觉概念。
- 通过 **概念重叠（Concept Overlap）** 度量 token 之间的语义相似性：两个 token 共享的 top-k 活跃概念索引超过阈值 δ 即认为语义重叠。
- 基于概念重叠构建无向图（token 为节点，重叠达标则连边），**连通分量即为语义组**。组内进行剪枝（保留峰值激活最高的 token）或合并（取对数尺寸加权平均）操作，实现 token 缩减。

### 2.2 关键技术细节
- **SAE 特征提取**：从 VLM 视觉编码器中间层（block 22）提取 patch 嵌入 \( v_i \)，送入 SAE 编码器得到稀疏潜在向量 \( z_i = \phi(v_i) \)，并计算峰值激活 \( a(i) = \|z_i\|_\infty \)。
- **概念分组参数**：
  - \( k \)：每个 token 保留的 top 活跃概念数（用于构建活跃集 \( A_i \)）。
  - \( \delta \)：要求两个 token 共享至少 δ 个活跃概念才连边。
  - 不同 \( (k, \delta) \) 组合控制分组粒度：\( k=1,\delta=1 \) 直接将每个 token 的 argmax 概念作为组，组数最多；\( k=2,\delta=1 \) 允许更松散连接，组数减少；\( k=2,\delta=2 \) 要求严格一致，组数介于中间。
- **缩减策略**：
  - **TORINO-P（剪枝）**：每组选择峰值激活最高的原始 token 作为代表，其余丢弃。
  - **TORINO-M（合并）**：对组内所有 token 取均值并乘以 \( 1+\log|G_g| \)（对数尺寸缩放因子），生成虚拟 token。
- **动态特性**：输出 token 数 \( G_{\text{dyn}} \)（即组数）由图像内容自适应决定。简单图像产生较少大组，压缩更激进；复杂图像产生较多小组，保留更多 token。
- **固定预算变体**：当需要精确控制输出数量 B 时，先按组大小排序保留前 B 大组（截断），若组数不足则从候选池中补齐峰值激活最高的 token（填充）。

### 2.3 公式与算法流程（文字说明）
1. **输入**：图像 x → 视觉编码器 → N 个 patch 嵌入 \(\{v_i\}\)（N=576，d=1024）。
2. **SAE 编码**：每个 \( v_i \) 经 SAE 编码器得 \( z_i \in \mathbb{R}^{\omega} \)（ω=65536），保留 top-k 索引 \( A_i \)。
3. **分组**：构建图 H，边条件 \((i,i') \in E \iff |A_i \cap A_{i'}| \ge \delta\)。连通分量即为组 \(\{G_g\}\)。
4. **缩减**：对每组按模式（P/M）生成代表 token。
5. **输出**：将代表 token 序列传给 LLM 投影层。（详细伪代码见论文 Algorithm 1 & 2）

## 6. 论文的主要结论与发现

1. **中等缩减率下 TORINO 最优**：
   - ~62% 缩减（保留 ~217 tokens）：TORINO-M 达 **98.7%** 相对分数，优于 PruneSID (96.7%) 和 PruMerge (96.7%)。
   - ~78% 缩减（保留 ~129 tokens）：TORINO-P 达 **97.1%**，高于基线。
2. **极端压缩（~92% 缩减）**：PruneSID 以 92.8% 领先，TORINO-P 仍以 91.1% 位居第二，优于其他方法。
3. **内容自适应有效**：动态变体在中等压缩时优于固定预算变体，表明自适应分配 token 预算能提升性能。不同基准（如 SQA vs. GQA）的压缩率差异反映了图像复杂度。
4. **SAE 分组优于原始嵌入**：消融实验证明 SAE 带来的概念空间是关键增益（+5.2pp）。
5. **扩展因子选择重要**：小字典（ε=1,2）导致概念多义；中等字典（ε=4）在中低压缩达最佳；大字典（ε=64）在极端压缩最稳定。
6. **剪枝 vs. 合并**：TORINO-P 在更高压缩下表现更好，TORINO-M 在低压缩时稍优，符合预期。

## 7. 优点

- **新颖性**：首次将 Sparse Autoencoder 的可解释概念特征应用于视觉 token 缩减，连接了机械可解释性与实用模型效率。
- **即插即用、无需微调**：TORINO 完全在推理时运行，仅需前向传播一个冻结的 SAE，不修改 VLM 权重。
- **内容自适应**：输出 token 数自动匹配图像复杂度，无需人工设定每个图像的预算，实用性强。
- **统一框架**：支持剪枝（P）和合并（M）两种模式，且提供固定预算变体以适配实际部署。
- **效率优势**：在中等压缩下 TORINO 的延迟（~27ms）远低于 PruneSID（~64ms）和 PruMerge（~71ms）。
- **深入分析**：对 SAE 扩展因子、训练 token 类型、分组参数等进行了详尽消融，验证了设计选择。

## 8. 不足与局限

- **评估范围局限**：仅在 LLaVA 系列（7B/13B）上验证，未覆盖其他 VLM 架构（如 Qwen-VL、Flamingo）。应用到不同视觉骨干需要重新训练对应 SAE。
- **SAE 训练数据限制**：实验中使用的 SAE 仅在 **CLS token 激活** 上训练（ImageNet-1K），未使用完整的 patch token，可能降低概念空间的覆盖率和细粒度。作者承认训练 full patch SAE 有望进一步提升性能。
- **查询无关分组**：当前分组与问题无关，所有 token 平等处理。无法根据用户问题选择性保留相关概念。作者提出未来可与跨模态 SAE 结合实现查询条件化。
- **极端压缩失效**：当保留 token 少于 ~50 时，小物体区域可能被完全剪枝导致失败（图 4 第三列示例）。
- **超参数通用性**：分组参数 (k,δ) 目前为固定值（实验中仅使用 k=δ 的组合），对于不同任务可能需要调整以平衡压缩与精度。
- **算力报告不完整**：未提及 SAE 训练的资源消耗，尽管使用的是预训练模型，但训练此类大型 SAE（ε=64，ω=65536）本身需要显著算力。

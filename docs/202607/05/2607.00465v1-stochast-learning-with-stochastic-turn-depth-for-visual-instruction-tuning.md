## 摘要
大型视觉-语言模型（LVLMs）广泛依赖视觉指令调优（VIT）来激发其多模态推理能力。然而，我们发现一个差异：VIT通常将关于同一图像的多个语言任务打包成对话式多轮训练，而现有基准测试却在孤立的单轮场景下评估LVLMs。模型在多轮训练中可能遭受视觉注意力衰减和上下文过拟合，使其难以在错配的测试阶段充分发挥潜力。为弥合这一差距，我们提出利用随机轮次深度（StochasT）进行学习，该方法将同一图像的多个语言任务随机分组为不同大小（轮次深度）的集群，同时保留其有机顺序。因此，虽然StochasT借鉴了ResNet中的Dropout和随机深度，但它实际上并没有丢弃任何内容，以最大化训练数据的效用。此外，我们引入了一种基于平衡拉丁方设计的、与基准无关的挑战性评估机制，用于测量LVLMs在不同上下文依赖下的鲁棒性。大量实验表明，StochasT有效地赋予了LVLMs在单轮和多轮用例中强大且协调的能力。

## Abstract
Large Vision-Language Models (LVLMs) rely extensively on Visual Instruction Tuning (VIT) to elicit their multimodal reasoning capabilities. However, we find a discrepancy: VIT often packs multiple language tasks about the same image for conversational, multi-turn training, whereas existing benchmarks evaluate LVLMs in isolated, single-turn scenarios. The models can suffer from visual attention decay and contextual overfitting during multi-turn training, making it hard for them to realize their full potential in the mismatched test phase. To close the gap, we propose learning with Stochastic Turn Depth (StochasT), which stochastically groups language tasks for the same image into clusters of varying sizes (turn depth) while preserving their organic order. Hence, while StochasT draws on Dropout and stochastic depth for ResNets, it does not actually drop anything to maximize the utility of the training data. Furthermore, we introduce a challenging, benchmark-agnostic evaluation mechanism based on the Balanced Latin Square to measure LVLMs' robustness under varying contextual dependencies. Extensive experiments demonstrate that StochasT effectively grants LVLMs strong, harmonized capabilities for both single-turn and multi-turn use cases.

# StochasT：利用随机轮次深度进行视觉指令调优的学习

## 1. 核心问题与整体含义（研究动机和背景）

- **训练与评测的严重不匹配**：当前大型视觉-语言模型（LVLMs）的视觉指令调优（VIT）普遍采用多轮对话格式：同一张图像对应多个语言任务（提问-回答），打包成一个训练样本。然而，主流评测基准（如MMMU、MathVista、MMBench等）却采用孤立的单轮评测方式——每个问题独立地与图像关联。这导致模型在多轮训练中可能依赖上下文中的文本捷径，忽略视觉特征，产生“视觉注意力衰减”和“上下文过拟合”，在单轮测试时能力无法充分发挥。
- **问题表现**：论文实验发现，同样一个模型，若按多轮方式评测，性能显著高于单轮评测；而大多数已有工作忽视了这一差异，导致模型鲁棒性评估失真。
- **目标**：设计一种能够弥合多轮训练与单轮评测之间差距的训练策略，使模型在两种场景下均表现良好，并提出更合理、更鲁棒的评估机制。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 受 **Dropout** 和 **随机深度（Stochastic Depth）** 启发，提出 **Stochastic Turn Depth（StochasT）**。它不是丢弃神经元或网络层，而是**随机改变对话历史上下文的长度**：将同一图像的多轮对话动态地构建成不同深度的分支结构，让模型在训练时接触多样化的上下文配置，从而隐式地训练一个“对话树集成”。
- 该策略无需额外数据，不增加计算开销，只是通过修改注意力掩码和位置编码来模拟不同的历史依赖关系。

### 2.2 关键技术细节
- **算法流程**（Algorithm 1）：
  - 对于每个多轮对话样本，共有 N 轮（turn）。
  - 从第 1 轮到第 N 轮，采用**反向回溯**方式：对于第 n 轮，从 k = n-1 开始依次向前检查，每一跳以概率 p_k 决定是否丢弃该历史轮次（实际是决定父节点）。若丢弃，则继续向前；保留则连接为父节点。若所有前驱都被丢弃，则直接连接到根（即图像+系统提示）。
  - 概率 p_k 从 **Beta(α, β)** 分布中采样，可灵活控制倾向于短历史（类似单轮）或长历史（类似多轮）。
  - 保留了所有损失 token（不丢弃数据），仅改变其依赖关系。
- **与Chinese Restaurant Process (CRP)** 的区别：CRP 是无序的聚类分配，而 StochasT 保持因果顺序，通过连续伯努利试验实现。
- 边界情况：当 Beta(α,β) → (∞, 1) 退化为多轮训练，当 → (1, ∞) 退化为单轮训练。

### 2.3 新评估机制：平衡拉丁方轮次置换（BLS）
- 针对现有单轮/多轮评估的不足，提出基于**平衡拉丁方设计**的评测框架。
- 构建 `N × N` 矩阵，每一行是一种轮次顺序排列，使得每个问题在每个位置出现一次，且每个问题恰好出现一次作为前驱。通过评估所有排列下的正确率，得到：
  - **Context-Robust Accuracy (CRA)**：平均正确率。
  - **Strict Context-Robust Accuracy (CRA+)**：必须所有排列下都正确才算正确，衡量真正上下文不变的知识。
- 对于奇数 N，插入占位指令（“请简要描述图像”）以保证偶数，不影响最终分数。

## 6. 主要结论与发现

1. **训练-评测不匹配问题确实存在且严重**：多轮训练后的模型在多轮评测下比单轮评测平均高出 7%（LLaVA）和 6%（Qwen），而 StochasT 将此差距缩小至 3.5% 和 3.3%，接近预训练原模型的鲁棒性。
2. **StochasT 在单轮和多轮评测上均超越 MultiT**：在 LLaVA 上单轮评测平均提升 9.19%，多轮提升 3.08%；Qwen 类似。
3. **StochasT 计算效率优于 SingleT**：SingleT 需要约两倍训练 token 数才能达到相似单轮性能，而 StochasT 更高效。
4. **StochasT 提升了视觉注意力利用**：通过量化 Visual Contribution 指标，StochasT 模型更依赖视觉特征而非文本捷径。
5. **平衡拉丁方评估框架有效**：CRA 和 CRA+ 提供更全面的鲁棒性度量，StochasT 取得最高 CRA，SingleT 在 CRA+ 上略优但牺牲了多轮能力。

## 7. 优点

- **创新性**：首次系统指出多轮训练与单轮评测的差异，并提出简单有效的 StochasT 解决方案。将 Dropout/Stochastic Depth 思想创新地应用于对话历史深度控制。
- **实用性**：不增加额外数据、计算量，无需修改模型结构，可直接应用于现有训练 pipeline，兼容各种训练目标和数据。
- **评估贡献**：提出 BLS 评估框架及两个新指标（CRA, CRA+），弥补了现有评测的缺失，有助于更公平地评估 LVLM 的鲁棒性。
- **实验设计全面**：覆盖多领域、多模型、多种对比设置，消融和可视化分析充分，结果可信。

## 8. 不足与局限

- **假设前提**：BLS 评估和 StochasT 方法适用于轮次间**相对独立**的对话（即下一问题不强烈依赖上一回答）。对于紧密耦合的对话（如逐步推理、问答链），应用受限。论文也承认了这一局限。
- **偶数性限制**：BLS 要求轮次数为偶数，奇数时需填充占位指令，虽验证影响很小，但引入额外假设。
- **模型规模**：主实验仅采用 3B/7B 模型，未验证更大规模（如 72B/100B+）上的效果。附录中有 32B 的初步结果但仍有限。
- **领域范围**：实验集中在视觉理解任务（分类、QA、计数等），未涉及更复杂的 agentic 场景（如 GUI 控制、导航）。
- **消融细节**：尽管研究了 Beta 参数影响，但未深入分析不同对话长度分布下的最优策略选择。
- **公平性**：所有实验使用 LoRA 微调，未评估全参数微调下的方法有效性（除 MME 全微调实验）。需注意 LoRA 可能影响方法泛化。

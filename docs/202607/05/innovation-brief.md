### 1. Does Your ViT Still Need U-Net for Segmentation?
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2607.00223v1
- 方法流程：
  - 输入图像送入ViT骨干网络，提取不同块（block）的多级特征图
  - 针对每个层级，使用一组可学习的查询嵌入（query embeddings）与该层特征图进行交叉注意力操作，生成该层级的查询表示
  - 将所有层级的查询表示通过可学习块融合模块（如加权求和或注意力聚合）进行整合，得到融合的全局查询表示
  - 将融合查询表示通过线性层上采样至输入图像分辨率，得到最终分割图
- 关键模块/机制：
  - 多级查询建模模块：从ViT不同层次提取语义丰富的区域特征，适配编码器-only架构；使用一组可学习的查询嵌入（数量等于预设目标类别数），对每个ViT块的输出特征图应用交叉注意力（cross-attention），查询作为Q，特征图作为K,V，输出所有层级的查询表示
  - 可学习块融合模块：动态整合不同层级的查询表示，以捕获多尺度信息并生成最终分割预测；将各层级的查询表示通过可学习权重（如MLP或注意力机制）进行加权融合，输出单一融合表示，再经线性映射和上采样得到像素级分割
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 1. 前向传播：图像经ViT得到多级特征图 F_l (l=1..L) 2. 每个层级 l：计算交叉注意力 Q=A_l, K=F_l, V=F_l，得到查询表示 H_l = CrossAttn(A_l, F_l, F_l) 3. 可学习融合：H_fused = Fusion({H_l})，其中Fusion为可学习模块（如加权求和+非线性激活） 4. 分割头：S = Upsample(Linear(H_fused))

### 2. On Test-Time Scaling for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.28864v1
- 方法流程：
  - 输入: 图像I和文本问题Q，可选附加图像（根据方法是否使用caption或scene graph）
  - 阶段1: 将图像通过视觉编码器编码为视觉token序列，通过适配器投影到LLM嵌入空间，得到视觉token序列P_v_ad
  - 阶段2: 构建输入文本提示: 将问题Q、think-prompt（如'think step-by-step'）和post-prompt（要求格式化输出）拼接为文本token序列P_t
  - 阶段3: 将视觉token和文本token拼接成总序列P = [P_v_ad; P_t]
  - 阶段4: 输入LVLM生成推理链r和答案a（自回归生成）
  - 阶段5: 后处理: 如果答案提取失败，使用第二遍: 输入{问题Q; 推理链r; answer-only prompt; post-prompt}重新生成答案
  - 输出: 最终答案，格式为单个字母（MCQ）或单词/短语（开放式问答）
- 关键模块/机制：
  - Chain-of-Thought (CoT) prompting：通过单次前向传播生成逐步推理链，增加'思考'token来提升性能；think-prompt设为'think step-by-step'，模型单次生成推理链后直接输出答案。使用1个前向传播，消耗更多'tokening' token。
  - Structured Chain-of-Thought (S-CoT) prompting：引导模型进行结构化推理：分解问题、组织信息、逻辑推理、最终总结；使用更详细的think-prompt（具体内容见附录S8），单次前向传播，生成结构化推理链。
  - Plan-and-Solve (PaS) prompting：先制定计划再逐步执行，提升复杂问题解决能力；think-prompt要求模型首先理解问题并制定计划，然后逐步执行计划得到答案。单次前向传播。
  - Self-Consistency：通过多次采样和多数投票提高答案稳定性和正确性；对同一问题使用CoT采样b次（b为超参数，实验中b=5），生成b条推理链和答案，然后选择出现频率最高的答案作为最终输出。需要b个前向传播。
  - Self-Aggregation：将多次采样的推理链聚合为一条综合链，然后生成最终答案；先采样b条推理链（同Self-Consistency），然后保留所有链及其答案，将它们拼接成一个长链，再输入LVLM要求其聚合信息生成最终推理链和答案。需要b+1个前向传播。
  - Self-Refinement：通过迭代自修正逐步改善推理链；首先生成一条CoT推理链，然后逐次将当前推理链和问题一起输入，要求模型改进，重复k轮（实验中k=1？默认k=1？具体见附录）。需要k+1个前向传播。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 所有测试时缩放方法均通过附加think-prompt实现，不改变模型权重
  - Self-Consistency采样次数b=5（由附录S11指定）
  - Self-Refinement迭代次数k在原文中未明确给出，推测为k=1或较小值
  - 答案提取失败时的第二遍机制：提供推理链r和answer-only prompt（如'Answer the question based on the above reasoning.'），强制模型输出规范答案
  - Prompt Repetition利用自回归模型无法双向注意的弱点，通过重复问题使前面的token能间接关注后面的信息
- 训练/推理细节：
  - 所有方法均为推理阶段使用，无需训练或微调

### 3. On Test-Time Scaling for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.28864v2
- 方法流程：
  - 输入：图像（I∈R^{3×H×W}）和问题文本（含post-prompt）。
  - 视觉编码：视觉编码器将图像编码为视觉token序列P_v∈R^{N×d}。
  - 适配投影：适配器将视觉token投影到LLM嵌入空间，得到P_v^{ad}∈R^{Nm×d}（可能经过压缩）。
  - 文本编码：问题与think-prompt和post-prompt拼接后，经token化得到文本token序列P_t∈R^{T×d}。
  - 输入拼接：将视觉token和文本token拼接为P∈R^{(Nm+T)×d}，输入LLM。
  - 推理生成：LLM依次生成推理链r和最终答案。若答案提取失败，则进行第二轮：输入{问题；r；answer-only；post-prompt}重新提取答案。
- 关键模块/机制：
  - 视觉编码器：将图像编码为视觉token序列；输出P_v∈R^{N×d}，N为视觉token数，d为维度。例如Qwen系列使用压缩，Nm=N/4。
  - 适配器：将视觉token投影到LLM的嵌入空间；输出P_v^{ad}∈R^{Nm×d}，使视觉表示与文本表示对齐。
  - LLM：基于多模态输入生成推理链和答案；接收拼接后的token序列P∈R^{(Nm+T)×d}，自回归生成推理链r和最终答案，最大token长度设为1024。
  - 测试时扩展方法（9种）：通过附加think-prompt引导模型生成更深入推理，增加推理计算量；包括CoT、S-CoT、PaS、Self-Consistency、Self-Aggregation、Self-Refinement、Describe-Answer、Compositional CoT、Prompt Repetition，每种策略有特定think-prompt和推理步骤。
  - 后处理（答案重提取）：当模型未按格式输出答案时，进行二次推理；若首次答案提取失败，使用{问题；推理链；'answer-only'；post-prompt}进行第二轮生成，确保答案可解。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - CoT：单个前向传播，think-prompt='think step-by-step'，生成逐步推理后输出答案。
  - S-CoT：结构化CoT，引导模型先分解问题、组织信息、逻辑推理、最终总结。单次前向。
  - PaS：先制定计划，再逐步执行计划。单次前向。
  - Self-Consistency：采样b个独立CoT（b次前向），对每个CoT取答案，通过多数投票选择最终答案。
  - Self-Aggregation：采样b个CoT，保留所有推理链和答案，拼接后输入模型（b+1次前向），让模型聚合信息生成最终推理和答案。
  - Self-Refinement：首先生成一个CoT推理链，然后迭代k轮（共k+1次前向），每轮让模型对当前推理链进行自我修正和改进。
  - Describe-Answer：首先生成图像详细描述（一次前向），然后将描述与图像、问题一起输入模型（第二次前向）生成答案。
  - Compositional CoT：首先生成场景图（一次前向），然后将场景图与图像、问题一起输入模型（第二次前向）生成答案。
- 训练/推理细节：
  - 所有测试时扩展方法均在推理时应用，不改变模型权重，不进行额外训练。
  - 每个方法通过附加think-prompt实现，即输入格式为：{question};{think-prompt};{post-prompt}。
  - 最大生成token长度设置为1024。
  - 若答案提取失败，则进行第二轮推理：{question};{previous reasoning chain};{answer-only};{post-prompt}。
  - 实验使用单块NVIDIA H200 GPU（140GB VRAM），Qwen-2.5-VL-72B因内存限制使用两块H200并行。

### 4. Learning from Acquisition: Metadata-driven Multimodal Pre-training for Cardiac MRI
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.28991v1
- 方法流程：
  - 预处理：从MMCMR-427K数据库重建k-space数据（SOS），z-score归一化，resize至224×224，每序列采样最多3个切片和4帧，应用随机翻转/旋转/平移/高斯噪声
  - 文本生成：对每个序列，根据成像模态、解剖视图、扫描仪厂商、场强、扫描仪模型使用模板生成描述文本（如“cine cardiac MRI in short-axis view acquired on a 3.0T scanner”）
  - 特征提取：图像编码器（单通道ResNet-50）提取每张图像特征（2048维），对同一序列所有图像特征取平均得到序列级表示；文本编码器（DistilBERT）提取文本特征
  - 投影与归一化：通过可学习的线性投影层将图像和文本特征映射到256维共享空间，并L2归一化
  - 对比学习：计算图像-文本相似度矩阵，使用元数据感知的软标签（匹配对权重1，同模态或同视图对权重0.05），双向软标签交叉熵损失训练
  - 下游任务：预训练后保留图像编码器，采用线性探测+微调（Probe+FT）两阶段训练，先冻结编码器训练分类头/分割解码器，再联合微调
- 关键模块/机制：
  - 元数据文本生成器：将结构化元数据转换为自然语言描述，作为文本监督信号；使用预定义模板，将采集参数（模态、视图、厂商、场强、型号）填入固定句式，如“{modality} cardiac MRI in {view} view acquired on a {field_strength} scanner”。所有描述自动生成，无需人工标注。
  - 软标签对比损失 (Metadata-aware Soft Contrastive Loss)：替代CLIP的标准一对多对比损失，处理医学影像中不同序列可能共享部分语义（如同模态）的情况；对批次中所有图像-文本对，匹配对目标值为1；非匹配对若共享相同模态或相同解剖视图，则赋予弱正权重α=β=0.05（两个条件可叠加）。将目标矩阵行归一化为概率分布，计算双向交叉熵损失（image-to-text和text-to-image方向）。
  - 序列级特征池化：将同一序列采样的多张图像特征聚合为序列级表示；对序列i采样的Ti张图像，分别用ResNet-50提取2048维特征，然后取所有图像特征的均值，得到序列级向量h̄_i。
- 公式/目标函数/指标定义：
  - 文本生成：t_i = T(a_i1, ..., a_iK) # T为模板函数
  - 图像特征：h_it = f_θ(x_it) ∈ R^2048
  - 序列级表示：h̄_i = (1/T_i) Σ_{t=1}^{T_i} h_it
  - 投影并归一化：v_i = (W_v h̄_i) / ||W_v h̄_i||, u_i = (W_u g_ϕ(t_i)) / ||W_u g_ϕ(t_i)||
  - 相似度矩阵：S_ij = v_i^T u_j
  - 软目标：Q̃_ij = I(i=j) + α I(i≠j, m_i=m_j) + β I(i≠j, r_i=r_j), 归一化得 Q_ij = Q̃_ij / Σ_k Q̃_ik
- 算法细节：
  - 每个预训练批次包含B个序列（每个序列对应一张图像和一条文本），每个序列从原始数据中随机采样最多3个切片和4帧，产生最多12张图像，然后取均值作为序列级图像表示
  - 文本由元数据通过固定模板自动生成，不使用手工标注
  - 软标签：对于批次中第i个序列（图像）和第j个序列（文本），若i=j则目标权重为1；若i≠j但序列i和j的模态相同，则加α=0.05；若视图相同，则加β=0.05（仅当视图标注有效时）。然后每行归一化使和为1
  - 损失为双向（image→text和text→image）soft cross-entropy的平均，温度τ可学习
  - 预训练后丢弃文本编码器和投影头，仅保留图像编码器用于下游任务
  - 下游采用两阶段：先线性探测（冻结编码器），再端到端微调（编码器用较小学习率）
- 训练/推理细节：
  - 预训练使用AdamW优化器，训练30个epoch
  - 输入图像尺寸224×224，z-score归一化
  - 数据增强：随机水平翻转、旋转±10°、平移最多10%、高斯噪声σ∈[0.005,0.05]，同一序列内所有图像共享相同空间变换
  - 预训练数据集：MMCMR-427K子集，共7,057个序列，其中4,672用于预训练，2,385用于评估（分类任务）。分割任务使用ACDC（100/50例）和M&Ms（150/136例）
  - 对比学习温度τ初始化为0.07，可学习
  - 批次大小未明确给出，但一般认为CLIP中批次较大（论文未提供具体值）

### 5. FADE: Mitigating Hallucinations by Reducing Language-Prior Dominance in Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29431v1
- 方法流程：
  - 输入图像和文本，经过LVLM前向传播
  - 每个Transformer层：先计算注意力输出并残差相加得到˜h(l)
  - 若当前层在关键层集合中（如LLaVA-1.5-7B的16-22层），则FFN输出乘以衰减因子(1-α)后残差相加：h(l+1)=˜h(l)+(1-α)·FFN(l)(˜h(l))
  - 非关键层正常计算FFN
  - 最后通过LM头输出token分布，标准自回归解码生成文本
- 关键模块/机制：
  - 注意力模块：聚合视觉证据，推动预测朝向正确答案；对于正确样本和错误样本，注意力贡献均为正（+1.2和+0.8），表明其可靠地提供视觉信息
  - FFN模块（关键层）：引入语言先验，可能覆盖视觉证据导致幻觉；在层16-22，FFN对正确样本贡献+8.4，对错误样本贡献-3.5，是预测漂移的直接原因。FADE通过衰减其输出来抑制语言先验
- 公式/目标函数/指标定义：
  - 注意力和FFN贡献分析：Δ^{(l)}_{Attn}(t) = LM head(˜h^{(l)})_t - LM head(h^{(l)})_t；Δ^{(l)}_{FFN}类似
  - 正确方向度量：C^{(l)} = Δ^{(l)}(t_{correct}) - Δ^{(l)}(t_{incorrect})
  - FADE修改公式：h^{(l+1)} = ˜h^{(l)} + (1-α) · FFN^{(l)}(˜h^{(l)})，α∈[0,1]
- 算法细节：
  - 使用差分logit lens方法分解注意力和FFN贡献，避免层归一化非线性影响
  - 关键层选择：基于LLaVA-1.5-7B实验确定16-22层，其他模型按比例映射到中间层（如总层数32则对应16-22层）
  - 推理时仅修改指定层的FFN残差路径，不修改模型参数
- 训练/推理细节：
  - 无训练，推理时干预
  - 单次前向传播，无额外参数和显著开销
  - 衰减强度α可调，不同任务可能需微调
  - 关键层配置需根据模型架构预先确定（见附录D）

### 6. CellDETR: A Detection-Guided Framework for Scalable Cell Representation Learning from Histopathology Images
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29463v1
- 方法流程：
  - 输入：全切片图像（WSI）
  - 处理：通过Deformable DETR检测细胞候选框，并提取特征
  - 处理：应用位置特征解耦，分离位置编码与内容特征
  - 处理：利用框约束注意力机制，限制注意力在检测框内
  - 输出：细胞级嵌入向量
- 关键模块/机制：
  - Deformable DETR：作为基础检测器，可变形注意力机制处理多尺度特征，适应细胞形态变化；使用可变形注意力的transformer编码器-解码器结构，通过参考点采样特征，生成细胞检测框和初始特征
  - 位置特征解耦：分离细胞的位置信息与内容特征，使嵌入更聚焦于形态学特征；将检测框的位置编码与从对应区域提取的视觉特征解耦，分别处理后再融合
  - 框约束注意力：限制注意力范围在检测框内部，抑制背景噪声，提升细胞特异性；在注意力计算时，根据检测框坐标生成attention mask，只允许框内特征参与交互
  - 对比学习预训练：利用无标签WSI学习通用细胞表示，提升下游性能；采用对比学习框架，正样本为同一细胞不同增强视图，负样本为其他细胞，最大化正样本相似度
- 公式/目标函数/指标定义：
  - 对比学习损失函数（InfoNCE），具体公式未提供
  - 输入信息未提供明确公式
- 算法细节：
  - Deformable DETR中的可变形注意力：对每个查询学习偏移量，从特征图采样关键点进行加权聚合

### 13. Breaking Failure Cascades: Step-Aware Reinforcement Learning for Medical Multimodal Reasoning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.31825v1
- 方法流程：
  - 1. 使用多模态大语言模型生成推理链（包含中间步骤和最终答案）
  - 2. 对每个推理步骤计算过程奖励：若最终答案正确则奖励为正，若错误则对每个token分配惩罚权重，早期步骤权重指数增大
  - 3. 将过程奖励与最终答案奖励结合作为整体奖励信号
  - 4. 采用策略梯度方法（如GRPO变体）更新模型参数，优化期望奖励

- 关键模块/机制：
  - 过程奖励函数（Process Reward Function）：为推理链中每个token提供细粒度奖励信号；当最终答案错误时，按时间步t分配惩罚权重w_t = exp(α * t)，其中t为token在推理链中的位置，α为超参数；对正确推理路径的token奖励为0或正数
  - 失败级联分解（Failure Cascade Decomposition）：识别并惩罚导致级联错误的早期推理步骤；通过指数惩罚权重使早期错误token获得更大负奖励，迫使模型在早期步骤做出正确推理，防止后续错误累积
  - 策略优化引擎（Policy Optimization Engine）：在GRPO基础上集成过程奖励进行参数更新；使用KL散度约束的近似策略优化，目标函数为最大化过程奖励与答案奖励的加权和，同时限制策略偏移
- 公式/目标函数/指标定义：
  - 过程奖励：R_process = Σ_t w_t * r_t，其中w_t = exp(α * t)（当最终答案错误时），r_t为步骤t的二元正确性指示
  - 最终奖励：R_total = β * R_answer + (1-β) * R_process，其中R_answer为最终答案正确性（0或1）
  - 策略优化目标：J(θ) = E[ R_total - KL(π_θ || π_ref) ]
- 算法细节：
  - 使用蒙特卡洛采样生成多个推理链
  - 对每个推理链，从模型分布中采样动作（token），计算累计过程奖励
  - 利用重要性采样权重更新策略，并裁剪概率比以保证稳定性
  - 过程奖励的惩罚系数α通过消融实验确定
- 训练/推理细节：
  - 训练：在医学VQA数据集上，使用Qwen2.5-VL-7B-Instruct等模型进行RL微调，batch size、学习率等未提供
  - 推理：直接使用训练后的模型生成推理链和答案，无需额外计算过程奖励

### 15. StochasT: Learning with Stochastic Turn Depth for Visual Instruction Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.00465v1
- 方法流程：
  - 输入：多轮对话数据集，每轮包含指令和响应，共享同一图像
  - 对于每轮对话，从当前轮次-1开始向前遍历，依次采样伯努利变量决定是否停止；若停止，则当前轮的父节点设为该节点；若全部丢弃则连接到根节点（图像）
  - 根据父节点分配，构建因果注意力掩码，使得每轮只能看到其父节点及其之前的上下文
  - 计算损失时保留所有轮次的token，但注意力的历史依赖被随机化
  - 训练完成后，模型在推理时使用标准的多轮或单轮设置
- 关键模块/机制：
  - 随机父节点分配算法（Stochastic Turn Depth Tree Expansion）：决定每一轮对话在训练中依赖的历史上下文；对于第n轮，从n-1开始反向遍历，每步k采样pk~Beta(α,β)和mask~Bernoulli(1-pk)，若mask=1则停止并将父节点设为k；若遍历完所有前驱节点均为0，则父节点设为根（图像）。此过程生成因果对话树，保持时间顺序并引入随机性。
  - 因果注意力掩码动态构建：在自回归生成中实现随机历史依赖；基于父节点分配，构建每轮token的注意力掩码，使得每个token只能注意到其父节点及其之前轮次的所有token，以及当前轮次之前的token。这与标准多轮训练不同，标准多轮是连续链式依赖。
- 公式/目标函数/指标定义：
  - 多轮训练目标：L_multi = -∑_{n=1}^{N} ∑_{i=1}^{L_n} log P_θ(x_{a,i}^{(n)} | X_v, H^{(n)}, x_{a,<i}^{(n)})，其中H^{(n)}是累积历史上下文
  - 单轮训练目标：L_single = -∑_{n=1}^{N} ∑_{i=1}^{L_n} log P_θ(x_{a,i}^{(n)} | X_v, X_q^{(n)}, x_{a,<i}^{(n)})，即丢弃历史上下文
  - StochasT的drop概率采样：p_n ~ Beta(α, β)，然后mask m_n ~ Bernoulli(1-p_n)，但实际算法中是对每个前驱节点采样
- 算法细节：
  - StochasT算法：输入对话轮次N和Beta参数α,β，输出父节点数组P。对于n=1..N，从k=n-1开始反向遍历，每一步采样pk~Beta, mk~Bernoulli，若mk=1则break并设P[n]=k；若k降到0，则P[n]=0（根）。
  - 在训练时，根据父节点P构建注意力掩码：每个轮次的token只能看到其父节点及之前轮次的token。
  - 丢弃概率的Beta分布允许控制偏向短历史或长历史。α和β是超参数。
- 训练/推理细节：
  - 训练时保留所有N轮对话的token，通过因果掩码实现随机上下文，不减少token数量，最大化数据利用率
  - 使用LoRA微调，基座模型为Qwen2.5-VL-3B和LLaVA-1.5-7B
  - 训练时每个epoch对每个样本重新采样父节点，产生不同的对话树
  - 推理时使用标准的多轮或单轮设置，不应用StochasT

### 16. Prior-Anchored Debiasing for Long-Tailed Multi-Organ Pathology Report Generation

  - 跨模态解码器：融合视觉特征和文本先验，通过交叉注意力生成报告
- 训练/推理细节：
  - 训练时联合优化报告生成损失（如交叉熵）和L_VPAB损失
  - MRAB构建在训练集上离线完成，模板经人工验证
  - 推理时VPAB选择top-m补丁，MRAB检索top-M元报告，解码器自回归生成报告

### 22. Spatio-Temporal and Clinical Conditioning for Fine-Grained Radiology Report Retrieval
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.02024v1
- 方法流程：
  - 步骤1：解剖区域检测与特征提取。使用在Chest ImaGenome上预训练的目标检测器EI，从当前和先前的胸部X光片中定位29个解剖区域，输出区域级视觉嵌入y_t^k和y_{t-1}^k。
  - 步骤2：区域级时间建模。对于每个区域k，以当前嵌入y_t^k为查询，当前和先前嵌入{y_t^k, y_{t-1}^k}为键值，通过多头注意力得到时间融合特征z_k。若先前片不可用，用可学习嵌入代替。
  - 步骤3：临床条件化。将临床指示文本（如症状、病史）通过文本编码器得到文本特征，通过交叉注意力将文本特征与区域特征z_k融合，产生时空-临床特征。
  - 步骤4：多任务解剖dropout。包含两个头：区域选择头输出每个区域是否应被用于报告（基于注意力权重），病理头预测每个选中的区域是否为异常。丢弃未选中区域，保留N_sel个区域表示b_n及其病理标签。
  - 步骤5：跨模态检索。将b_n通过视觉投影头映射到共享图像-文本嵌入空间，根据病理标签（正常/异常）在预构建的区域级句子索引中检索余弦相似度最高的句子。
  - 步骤6：后处理过滤。去除重复和冗余句子，根据标签逻辑过滤包含关系，利用极性（阴性/阳性）和发现组减少矛盾，优先保留含时间线索的句子。最终按顺序组装成报告。
- 关键模块/机制：
  - 目标检测器EI：定位并提取29个解剖区域的视觉特征，确保区域级一致性；基于Faster R-CNN或类似架构，在Chest ImaGenome上训练，输出每个区域的边界框和特征嵌入y∈R^{D_roi}。推理时同时处理当前片和先前片。
  - 区域级时间建模模块（MHA）：融合当前和先前片的区域特征，编码纵向变化；对每个区域k，将当前嵌入y_t^k作为query，当前和先前嵌入{y_t^k, y_{t-1}^k}作为key和value，通过多头注意力产生时间感知特征z_k = f_temporal(y_t^k, y_{t-1}^k)。
  - 临床条件模块：将临床指示文本融入区域特征，实现文本引导的检索条件；临床文本通过文本编码器（如ClinicalBERT）提取特征，然后通过交叉注意力机制与各区域时间特征z_k交互，输出临床感知的区域表示。
  - 多任务解剖dropout模块：选择报告相关区域并预测病理状态，筛除非关键区域；包含区域选择头和病理头。区域选择头为每个区域计算选择概率，基于与临床条件的相关性；病理头预测每个区域为正常或异常（二分类）。只保留选择头输出的前N_sel个区域及其病理预测。
  - 半监督跨模态对比学习：对齐区域视觉特征与对应句子嵌入，构建检索空间；使用InfoNCE损失，正样本对为选中区域特征与其对应的区域级报告句子嵌入，负样本为批次内其他句子。同时保留检测、区域选择和病理分类的辅助损失。
- 算法细节：
  - 区域级时间建模的多头注意力操作：对于每个区域k，令Q=y_t^k, K=V=[y_t^k; y_{t-1}^k]（拼接），通过MHA得到z_k = Attention(Q,K,V)。
  - 解剖dropout的联合损失：L_dropout = L_selection + L_pathology，其中L_selection为区域选择头的二分类交叉熵（选择/不选择），L_pathology为病理头的正常/异常分类交叉熵。
  - 跨模态对比损失：L_contrastive = -log(exp(sim(v_i, t_i)/τ) / (Σ_j exp(sim(v_i, t_j)/τ)))，其中v_i为选中区域特征b_n映射后的视觉嵌入，t_i为对应的句子嵌入，sim为余弦相似度，τ为温度系数。
  - 后处理中的句子过滤规则：先删除完全相同句子；再基于编辑距离删除高度相似者；利用句子的结构化标签去掉被更具体句子包含的句子；根据标签极性（positive/negative）和发现组去掉矛盾句子；优先保留含时间线索词（如new, increased, improved）的句子。
- 训练/推理细节：

  - PPR扩展：将检索到的top-k页面对应的所有实体作为种子节点集合S。查询分析器输出一个标量α∈[0,1]控制扩展程度（α=0仅种子节点，α=1整个图）。PPR运行m次迭代，得到每个节点的平稳分布。选择分布值大于阈值β的节点构成子图。

### 25. PSP: Harnessing Position and Shape Priors for Cross-Domain Few-Shot Medical Image Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.28799v1
- 方法流程：
  - 输入：支撑图像Is、查询图像Iq、支撑掩码Ms。
  - 特征提取：使用权重共享的ResNet-50编码器提取支撑特征Fs和查询特征Fq（C×H×W）。
  - PCE：对Fs和Fq分别注入位置嵌入，通过极坐标映射、位置映射（2层MLP）、通道映射（1×1卷积）、自注意力机制生成位置增强特征F̂s和F̂q。
  - SPM：利用F̂s和Ms提取显式形状先验（几何统计+傅里叶描述子），通过特征-形状对齐计算通道注意力权重w，调制初始原型Ps得到形状原型P's。
  - HPP：使用P's对F̂q进行余弦相似度生成粗预测M̂coar_q，通过掩码平均池化提取查询原型Pq，经交叉注意力融合P's和Pq得到混合原型P*，最终通过带自适应阈值的余弦相似度生成预测掩码M̂q。
  - 输出：查询图像的分割掩码M̂q。
- 关键模块/机制：
  - Position Coordinate Embedding (PCE)：注入显式空间位置信息，减少纹理依赖；对特征F*（支撑或查询），构建中心极坐标系，计算每个像素的归一化径向距离ρ和极角θ，得到2×H×W坐标图Mpos；通过2层MLP（位置映射）投影为C维位置嵌入Fp；将F*与Fp拼接，经1×1卷积（通道映射）降维至C，再通过自注意力模块（SA）区分空间不同的语义特征；最后通过动态残差连接（β可学习，初始0.1）得到位置增强特征F̂* = (1-β)F* + β SA(CM(Concat(F*, Fp)))
  - Shape Prototype Modulation (SPM)：利用显式形状先验调制原型，解耦结构与纹理；显式形状先验编码：从支撑掩码Ms计算符号距离图（SDM），提取前景区域的最大、均值、方差形成几何向量vgeo∈R³；提取边界坐标经离散傅里叶变换，取低频频谱幅度归一化得到频谱向量vspec∈R^Nspec，拼接后经MLP映射为形状先验Pprior∈R^1×Cs。特征-形状对齐：将增强支撑特征F̂s掩码得到前景Ffg，经自适应平均池化和展平后通过MLP生成通道描述符Fseq∈R^C×Cs；计算每个通道描述符与Pprior的余弦相似度，经ReLU得到通道注意力权重w∈R^C。原型调制：通过掩码平均池化（MAP）得到初始原型Ps∈R^1×C，与w逐元素相乘得到形状原型P's = Ps ⊙ w。
  - Hybrid-Prototype Prediction (HPP)：校准支持原型到查询分布，缓解特征错位；粗预测：用形状原型P's与增强查询特征F̂q计算余弦相似度，生成粗预测M̂coar_q。查询原型提取：在粗预测引导下对F̂q进行掩码平均池化得到查询原型Pq∈R^1×C。原型融合：以P's为query，Pq为key和value，经交叉注意力（CA）加残差得到混合原型P* = P's + CA(P's, Pq, Pq)。最终预测：对每个查询像素计算余弦相似度，经缩放（α=20）和自适应阈值τ（由两个全连接层预测）后通过sigmoid得到预测掩码M̂q。
- 公式/目标函数/指标定义：
  - 归一化径向距离和极角：ρ_h,w = √(h̄² + w̄²), θ_h,w = arctan2(w̄, h̄)，其中(h̄,w̄)为相对中心坐标。
  - 位置增强特征：F̂* = (1-β)F* + β SA(CM(Concat(F*, Fp)))，β可学习。
  - 频谱向量：vspec(i) = |Z_{i+1}|/|Z_1|, i=0,...,N_spec-1，其中Z_u为DFT系数。
  - 通道注意力权重：w_i = ReLU( (F^{(i)}_seq · Pprior) / (||F^{(i)}_seq||₂ ||Pprior||₂) )。
  - 形状原型：P's = Ps ⊙ w，Ps = MAP(F̂s, Ms)。
  - 混合原型：P* = P's + CA(P's, Pq, Pq)。
- 算法细节：
  - PCE中，位置嵌入通过2层MLP将2D坐标映射到高维特征空间，并与原始特征拼接后经1×1卷积融合，最后通过自注意力动态残差融合。
  - SPM中，显式形状先验结合几何统计（SDM统计量）和频谱描述子（归一化傅里叶系数），通过MLP生成紧凑表示；特征-形状对齐通过余弦相似度和ReLU生成通道注意力，逐通道调制原型。
  - HPP中，粗预测引导查询原型提取，交叉注意力融合支持原型和查询原型，自适应阈值由查询特征经全连接层预测，α固定为20放大相似度差异。
  - 对齐损失：利用查询特征和预测掩码反向推断支撑预测，与支撑真值计算交叉熵，正则化模型。
- 训练/推理细节：
  - 骨干网络使用在MS-COCO上预训练的ResNet-50，权重共享。
  - 训练损失为查询交叉熵损失L_prim与对齐损失L_align之和。
  - 自适应阈值τ由两个全连接层基于增强查询特征F̂q预测。
  - 动态残差系数β初始化为0.1，可学习。
  - 缩放因子α固定为20。
  - 推理时，使用支撑图像和掩码生成原型，对查询图像进行分割预测。

- 算法细节：
  - 自适应预算循环: 初始检索量为0或预设最小值，每轮生成答案后计算置信度，若低于阈值且未超预算，则增加检索深度（如多检索top-k个段落），更新prompt后重新生成答案，循环直至停止条件满足
  - 自洽性近似: 对于封闭API，对同一问题采样n次（论文中使用n=5），计算生成答案的众数频率作为确定性信号
  - 检索策略: 使用混合检索（BM25 + BGE密集检索）并通过RRF融合，再经交叉编码器重排序，选取最相关段落
  - 阈值控制: 训练时无需调参，阈值作为超参数可调节，控制成本-准确率权衡
- 训练/推理细节：
  - 无需训练: 框架无需微调或训练任何模型，直接使用预训练生成模型和检索组件
  - 推理流程: 对每个问题执行自适应循环，检索预算（最大段落数）预先设定，例如8个段落
  - 封闭API适配: 由于无法获取token概率，通过多次查询API并自洽性近似确定性，增加了API调用次数但仍在低成本约束内

### 34. Dynamic Parsing and Updating Natural Language Specification using VLMs for Robust Vision-Language Tracking
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2606.29357v1
- 方法流程：
  - 输入：视频帧序列和初始自然语言规范（如'一只白色小狗在草地上跑'）。
  - 阶段1：语言依赖解析（Dependency Parsing）——利用依存句法分析将初始文本分解为目标物体（如'狗'）、外观概念（如'白色'、'小'）和背景上下文（如'草地'）。
  - 阶段2：成分自适应更新——对每个成分分别使用Qwen-VL进行精细化更新，其中目标成分保持不变（防止漂移），概念成分通过目标条件Top-K视觉调制根据搜索区域实时视觉信息选择性地更新，背景成分可选择性更新。
  - 阶段3：结构化语言表示融合——将更新后的三元组重新组合成优化后的文本描述，并与视觉特征（来自跟踪骨干网络）进行跨模态匹配，输出目标位置。
- 关键模块/机制：
  - 语言依赖解析模块 (Language Dependency Parsing Module)：将原始自然语言规范分解为目标物体、外观概念和背景上下文三个语义成分，为细粒度更新提供结构化基础。；基于依存句法分析（如Stanford Parser或类似工具），识别句子中描述目标主体的名词短语、修饰性形容词/属性短语以及背景场景短语，分别归类为目标（target）、概念（concept）和背景（background）三元组。
  - 目标条件Top-K视觉调制策略 (Target-conditioned Top-K Visual Modulation)：根据搜索区域中与目标（保持不变的成分）最相关的视觉特征，动态选择前K个视觉线索来更新外观概念描述，避免无关背景干扰和幻觉。；首先计算目标成分的文本嵌入与搜索区域视觉特征（如特征图）的相似度，选择相似度最高的K个空间位置对应的视觉特征；然后将这些视觉特征作为上下文输入Qwen-VL，与当前概念文本共同生成新的概念描述，实现视觉引导的语义更新。
  - Qwen-VL成分更新模块 (Qwen-VL Component Update Module)：利用预训练视觉语言模型Qwen-VL对每个语义成分进行精细化生成或修正，提升语义准确性并消除歧义。；对目标成分：直接保留原始文本（防止漂移）；对概念成分：输入当前概念文本 + Top-K视觉调制得到的视觉Token，让Qwen-VL生成更准确的外观描述；对背景成分：可选择性地使用Qwen-VL根据当前帧整体场景生成背景描述。所有生成均通过Qwen-VL的指令微调能力实现。
- 算法细节：
  - 使用依存句法分析器（如spaCy）将初始文本T解析为三元组(T_target, T_concept, T_background)。
  - 对于每一帧，提取搜索区域特征图F（来自跟踪骨干网络，如Swin Transformer或Siamese网络）。
  - 计算目标文本嵌入e_target与F每个特征向量的余弦相似度，取前K个位置的特征V_topk。
  - 将V_topk编码为视觉令牌，连同当前概念文本T_concept输入Qwen-VL，经指令提示（如'请根据视觉信息更新当前外观描述'）生成新概念T_concept'。
  - 目标文本T_target保持不变。背景文本T_background可选地通过Qwen-VL结合全局特征生成T_background'。
  - 将更新后的三元组重新组合为描述T' = [T_target, T_concept', T_background']，并输入跟踪头（如MDNet或TransT）进行目标定位。
- 训练/推理细节：
  - Qwen-VL部分使用预训练权重，不进行额外训练，直接通过零样本推理实现文本更新。
  - 跟踪骨干网络（如JointNLT或All-in-One）在VLT数据集上预训练或微调，参数固定。
  - 推理时：每N帧（如5帧）执行一次文本更新，或者当检测到跟踪置信度下降时触发更新。
  - 未提及训练阶段的特殊设计，仅推理阶段使用提出的模块。

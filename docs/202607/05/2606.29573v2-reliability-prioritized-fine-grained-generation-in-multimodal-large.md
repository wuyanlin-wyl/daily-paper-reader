## 摘要
多模态大语言模型（MLLMs）越来越需要生成视觉内容的细粒度描述。然而，我们观察到并从理论上证明，生成细粒度响应带来了可靠性挑战，即细粒度生成比粗粒度生成更容易出错。这一现象表明，模型应生成最可靠而非仅仅更具体的描述。为研究此问题，我们开发了GranFact，一个包含专家验证的多物体图像及其从粗到细类别注释的粒度感知基准。然后，我们设计了一种层次感知评估算法，既能评估模型预测在视觉上是否正确，也能评估正确预测的具体程度。我们还提出了一种基于直接偏好优化的可靠性优先偏好优化方法，该方法惩罚不可靠的细粒度声明，同时奖励可靠的细粒度描述。在GranFact上的实验表明，我们的方法在保持可靠性的同时提高了细粒度生成的质量。代码和数据见此处。

## Abstract
Multimodal large language models (MLLMs) are increasingly expected to generate fine-grained descriptions of visual content. However, we observe and theoretically show that generating fine-grained responses poses a reliability challenge, \textit{i.e.}, fine-grained generation is more error-prone than coarse-grained generation. This phenomenon suggests that models should generate the finest description that remains reliable rather than simply produce more specific outputs. To investigate this problem, we develop \textsc{GranFact}, a granularity-aware benchmark consisting of expert-verified multi-object images with coarse-to-fine category annotations. Then, we design a hierarchy-aware evaluation algorithm, which assesses both whether model predictions are visually correct and how specific the correct predictions are. We also propose a reliability-prioritized preference optimization method based on Direct Preference Optimization, which penalizes unreliable fine-grained claims while rewarding reliable specificity. Experiments on \textsc{GranFact} show that our method improves fine-grained generation while preserving reliability. Code and data are available \href{https://github.com/WeiWu2025/GranFact}{here}.

- **问题**：多模态大语言模型（MLLMs）被期望生成视觉内容的细粒度描述，但细粒度生成比粗粒度生成更容易出错。例如，模型能正确识别“iPhone 17 Pro”为“智能手机”，但可能误将其识别为相似的“iPhone 17 standard”。
- **含义**：模型不应一味追求最具体的描述，而应生成“最可靠且尽可能细粒度”的描述——即可靠性优先的细粒度生成。当前缺乏能同时评估正确性和细粒度程度的基准与评估指标。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 提出 **GranFact 基准**：包含581张多目标图像，每张图像的多物体均有人工标注的从粗到细的类别层次路径（如：智能手机 → iPhone → iPhone 17系列 → iPhone 17 Pro）。
- 提出 **层次感知评估算法**：将开放式响应解析为结构化预测实体，在数量约束下将预测与真实目标进行最优分配，优先保证类别兼容性，再评估细粒度程度。
- 提出 **可靠性优先的偏好优化方法（RP-DPO）**：基于直接偏好优化（DPO），构建可靠性偏好和细粒度偏好两组偏好对，并引入指标驱动的margin，确保可靠性优先。

### 关键技术细节
#### 评估算法（公式化描述）
- 定义预测集合 \(P\) 和真实目标集合 \(G\)，并引入虚拟“幻觉实体” \(g_{n+1}\)。
- 分配矩阵 \(X \in \mathbb{R}^{m \times (n+1)}\) 满足：每个预测的总分配量等于其预测数量 \(s_i\)，每个真实目标的总接收量不超过其标注容量 \(d_j\)。
- 可靠性分数 \(M(X)\) 统计分配到类别兼容真实目标的总量；细粒度分数 \(M_{\text{gran}}(X)\) 进一步考虑类别深度和属性一致性。
- 最优分配通过**词序优化**实现：先最大化 \(M(X)\)，再最大化 \(M_{\text{gran}}(X)\)。求解采用**最小费用流算法**。

#### RP-DPO方法
- **可靠性引导语义回退（RSR）**：对模型输出中的幻觉预测，若其祖先类别与真实目标无交集则删除；若存在共享祖先则回退至最细共享祖先。得到修正响应 \(y_{\text{rect}}\)。
- **偏好构建**：
  - 可靠性偏好 \(D_{\text{rel}}\)：\((y_{\text{rect}}, y_{\text{orig}})\)，鼓励模型避免不可靠预测。
  - 细粒度偏好 \(D_{\text{gran}}\)：从修正响应池中选取 \(F1_{\text{gran}}\) 更高的对，鼓励更细粒度描述。
- **指标驱动的margin**：对每个偏好对，根据性能差距 \(\delta\) 设置 margin \(m = \gamma + \alpha \delta\)，可靠性偏好使用更大的 \(\gamma_{\text{rel}}, \alpha_{\text{rel}}\)。
- 损失函数：\(\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{rel}} + \lambda \mathcal{L}_{\text{gran}}\)，其中 \(\mathcal{L} = -\mathbb{E} \log \sigma(\Delta_\theta - m)\)。

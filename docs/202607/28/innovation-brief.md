### 3. HPD-Parsing: Hierarchical Parallel Document Parsing
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.18839v1
- 方法流程：
  - 输入文档图像
  - 通过视觉编码器提取视觉特征
  - 主布局分支自回归生成布局令牌，决定文档结构并动态分配块解码任务到并发分支
  - 各并发分支并行解码对应块的文本内容，使用P-MTP每次预测多个token
  - 合并布局和块内容输出，得到结构化文档解析结果
- 关键模块/机制：
  - 主布局分支：解析全局文档结构，输出布局令牌并动态分配并发分支；基于自回归解码，逐步生成布局序列，每个布局令牌对应一个块或结构元素，同时为每个块分配一个唯一的并发分支标识
  - 并发分支：解码每个块的文本内容；每个分支独立解码，使用相同的解码器权重，并行执行，分支数量由主布局分支动态决定
  - 渐进多token预测(P-MTP)：减少每个分支内的解码步数；在解码每个块时，每次预测多个连续的token（例如4个），通过模型头部输出多个位置的概率分布，加速推理
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 主布局分支生成布局序列，每个布局令牌表示一个块或结构元素，同时输出一个分支ID
  - 并发分支根据分支ID并行解码，每个分支使用P-MTP，例如每次预测4个token，减少解码步数
  - 合并布局和块内容得到完整解析结果
- 训练/推理细节：
  - 训练阶段：端到端训练，损失函数包括布局分支交叉熵和块内容分支交叉熵（可能包含P-MTP的多token预测损失）
  - 推理阶段：主布局分支逐步生成布局，同时动态启动并发分支，并发分支并行解码，使用P-MTP加速

### 6. Scaling Native Multimodal Pre-Training From Scratch
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.22043v1
- 方法流程：
  - 数据混合与token化：将文本数据（250B token）和图像数据（75B多模态token，通过patch embedding转换为连续嵌入）按比例r混合
  - 模型训练：采用decoder-only MoE架构（auxiliary-loss-free），在固定计算预算C下训练不同模型大小N和token数D的配置，记录语言损失Ltext和多模态损失Lmm
  - IsoFLOP曲线生成：对每个计算预算C，绘制损失与log N的曲线，用抛物线拟合得到最小点对应的Nopt(C)，再计算Dopt(C)=C/(6Nopt)
  - 训练曲线包络验证：对所有训练轨迹（损失 vs C）取下包络线，得到最小损失函数L(C)=E+(Cc/C)^β，并从包络点回归Nopt和Dopt
  - 分配指数拟合：对每个r，用对数线性回归拟合Nopt∝C^a和Dopt∝C^b，得到a和b
  - 效率前沿构建：固定计算预算C，变化r，得到不同r下的最优(N,D)配置，绘制语言损失-多模态损失Pareto前沿
  - 下游评估：在纯文本空间推理和多模态上下文学习任务上验证跨模态迁移效果
- 关键模块/机制：
  - IsoFLOP profile 方法：主要估计器，用于从固定计算预算下的训练集合中识别最优模型大小；对每个预定计算预算C，训练多个不同模型大小N的模型，每个模型的训练token数D由C/(6N)确定，并设置余弦周期长度匹配C。绘制损失与log N的散点图，用二次抛物线拟合，抛物线最低点即为Nopt(C)，进而得到Dopt(C)=C/(6Nopt)。
  - 训练曲线包络法：独立交叉验证方法，对IsoFLOP结果进行验证；对每个固定模型大小N，记录训练过程中损失随总计算量C=6ND的变化曲线。将所有曲线的下包络线提取出来，该包络线上的每个点对应特定的(N,D)配置。通过在该包络线上回归log N与log C、log D与log C，得到分配指数a,b的独立估计。
  - 计算前沿拟合 (Compute Frontier)：提供下包络线的平滑解析形式，用于外推更大计算预算下的损失；沿下包络线，损失满足幂律：L(C)=E+(Cc/C)^β，其中E为不可约损失下限，Cc为临界计算量，β为衰减指数。通过对数空间的线性最小二乘拟合（使用log-sum-exp参数化确保正性）得到参数。
  - 数据组成调制 (Data Composition Modulation)：分析多模态数据比例r对缩放行为的影响；将计算预算按有效计算量分离：语言有效计算Ctext=6NDtext，多模态有效计算Cmm=6NDmm，其中Dtext=D/(1+r)，Dmm=Dr/(1+r)。独立拟合不同r下的分配指数a,b，发现语言a,b对r几乎不变，而多模态a,b随r单调变化（r增大时b增大，a减小）。
- 公式/目标函数/指标定义：
  - 优化问题: Nopt(C), Dopt(C) = argmin_{N,D s.t. 6ND=C} L(N, D)
  - 幂律分配: Nopt(C) ∝ C^a, Dopt(C) ∝ C^b, a+b=1
  - 计算前沿: L(C) = E + (Cc / C)^β
  - 有效计算: Ctext = 6 D / (1+r) * N, Cmm = 6 D r / (1+r) * N
- 算法细节：
  - IsoFLOP曲线生成：对于每个计算预算C（如10^19, 10^20, 10^21 FLOPs），选择一组模型大小N（如100M, 300M, 1B, 3B参数），设置每个训练的token数D=C/(6N)，采用余弦学习率衰减，周期为训练总步数。训练完成后记录最终损失。对每个C，用二次函数L = α(logN)^2 + βlogN + γ拟合，最小值点即最优Nopt。
  - 训练曲线包络：对每个模型大小N，记录每个checkpoint的损失和累计计算量C。将所有训练曲线（L vs C）绘制在同一坐标上，取每个C处的最低损失值形成下包络线。从包络线上提取(N,D)对，其中D=C/(6N)。然后用对数线性回归拟合Nopt∝C^a和Dopt∝C^b。
  - 数据组成扫描：对多模态数据比例r∈{0,0.1,0.2,0.3}，分别重复上述过程，得到不同r下的分配指数a,b。然后分析a,b随r的变化趋势。
  - 效率前沿构建：对于固定的计算预算C，遍历r的连续值，利用插值得到每个r下最优的Nopt和Dopt，以及对应的语言损失Ltext和多模态损失Lmm。在Ltext-Lmm平面上绘制Pareto前沿曲线。
- 训练/推理细节：
  - 模型架构：采用decoder-only MoE Transformer，使用auxiliary-loss-free的MoE训练方法，无需额外的负载平衡损失。视觉部分直接使用单层patch embedding将图像映射为连续嵌入，不使用传统视觉编码器。
  - 训练数据：文本数据共250B token，来自网页、书籍、学术论文等。多模态数据共75B token，来自网络爬取的图像-文本对和交错图像-文本文档。图像通过patch embedding转换为token序列。
  - 训练设置：使用余弦学习率衰减，周期长度与总训练步数匹配。计算预算C固定时，通过调整模型大小N和训练token数D保持6ND=C。所有实验在相同硬件条件下完成。
  - 损失函数：语言目标采用自回归交叉熵损失（预测下一个文本token），多模态目标同样采用自回归损失（但考虑了图像嵌入的logits）。具体损失函数形式原文未给出，但明确优化两个独立目标Ltext和Lmm。

### 9. Post-Operative Glioma Segmentation via Loss Stabilization, Normalization and Subspace Attention
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.22749v1
- 方法流程：
  - 输入：多模态MRI体积（T1n, T1c, T2w, FLAIR），通道对齐，RAS方向，前景裁剪（10体素边距），填充至160×160×160。
  - 预处理/归一化：Baseline和SACA Variant使用标准通道级非零体素Z-score；Norm Variant使用脑掩膜百分位裁剪（1st-99th）后进行有效组织Z-score。
  - 数据增强：随机翻转、旋转、强度偏移、随机补丁提取（每体积2补丁，前景中心体素采样比例80/20）。
  - 特征提取：SwinUNETR编码器，4阶段下采样，输出瓶颈特征 f ∈ R^{B×N×C} (C=768, N=空间token数)。
  - SACA模块（仅SACA Variant）：将f沿通道分成S=4个子空间（每个d_sub=192），使用K=4个可学习类别查询向量Q_cls，通过共享投影W_K, W_V计算子空间-类别注意力，加权求和并拼接恢复C维，经门控残差（初始为0）输出校准特征。
  - 分割解码：SwinUNETR解码器，CNN块与跳跃连接恢复空间分辨率，输出4类分割（ET, NETC, SNFH, RC）。
  - 损失计算（训练）：DiceWCE（Dice Loss + 0.6*加权交叉熵），Norm Variant额外加对比损失L_contra（α_contra(e)加权）。
  - 后处理/集成：将SwinUNETR模型与独立训练的3D nnU-Net的软概率取平均，得到最终分割。
- 关键模块/机制：
  - Subspace-Aware Class Attention (SACA)：在瓶颈层对特征进行类别感知的校准，增强增强肿瘤（ET）等小目标的表示。；将瓶颈特征f（B×N×768）沿通道均分为S=4个子空间（各192维），对应类别数K=4。为每个类别学习可查询向量Q_cls（K×192）。每个子空间通过共享线性投影W_K, W_V（192×192）计算键K_s和值V_s。对每个空间token n，计算Q_cls与K_s的点积注意力（softmax over K维），得到B×N×S×K权重，加权求和V_s得到A(n)∈R^{K×192}。将K个表示沿类轴拼接恢复768维，经线性层Wo和层归一化，通过门控残差（σ(γ)初始0）与原始f相加。
  - Voxel-Level Contrastive Learning：使瓶颈特征对域迁移不敏感，区分易混淆组织。；从瓶颈特征f中采样体素特征，通过两层MLP投影到128维并L2归一化。以增强肿瘤（ET）为正样本，背景和水肿（SNFH）为负样本，构建对比对（正样本最多64，负样本最多128）。使用温度τ=0.5的InfoNCE损失。对比损失权重α_contra随训练epoch线性从0增加到0.15（warmup后ramp up）。
  - Brain-Masked Percentile Normalization：减少手术伪影和强度异常值的影响，使特征更一致。；在脑掩膜内，将体素强度裁剪至1st-99th百分位范围，然后在有效组织（非零掩膜内）进行Z-score归一化（减均值除标准差）。替代标准通道级非零体素Z-score。
  - Hybrid DiceWCE Loss：替代不稳定的广义Dice损失，提高域迁移下的收敛稳定性。；组合Dice Loss（平方预测，排除背景）和加权交叉熵损失，其中交叉熵权重对活跃肿瘤子类（ET, NETC等）赋予更高权重。总分割损失L_seg = LDice + 0.6 * L_CE。
  - Ensemble with nnU-Net：进一步提升分割精度和稳健性。；将训练好的SwinUNETR变体模型与独立训练的3D nnU-Net进行集成，通过逐体素软概率平均得到最终分割。
- 公式/目标函数/指标定义：
  - SACA模块注意力公式：A(n) = Σ_{s=1}^S Softmax_K( (Q_cls (K_s(n))^T) / √d_sub ) V_s(n)
  - 总损失：L_total = L_seg + α_contra(e) * L_contra
  - L_seg = LDice + 0.6 * L_CE
  - α_contra(e) = 0 (if e ≤ e_warm), else 0.15 * (e - e_warm) / e_ramp
  - 对比损失采用InfoNCE（温度τ=0.5）
- 算法细节：
  - SACA门控机制：输出f' = f + σ(γ) * LN( O * W_o )，其中γ初始为0，σ为sigmoid，LN为层归一化，O为拼接后的类注意力特征。
  - 对比学习采样策略：从瓶颈特征中随机采样正样本64个（ET类），负样本128个（背景和SNFH类），形成对比对。
  - 集成方法：将SwinUNETR和nnU-Net输出的软概率逐体素平均。

- 方法流程：

- 公式/目标函数/指标定义：

  - 空间调制：对高频子带乘以尺度因子λ（默认1.5），公式为H'_band = λ * M_t * H_band（其中H_band为LH/HL/HH子带）

  - 帧间差异门控：计算相邻帧D的绝对值差，作为权重调整高频系数，最终预算分配权重w_t = softmax( A_t + γ * |D_t - D_{t-1}| )
  - 2D DWT：采用db4小波基，对特征图进行单级分解，得到四个子带
  - 逆小波变换：使用对应小波基进行重建，得到压缩后的特征图

- 训练/推理细节：
  - 无训练：所有参数（小波基、分解级别、调制尺度λ等）均为固定超参数，无需梯度更新
  - 即插即用：可无缝集成到现有LVLM（如LLaVA-OneVision、LLaVA-Video、Qwen2.5-VL）的推理流程中，仅需在视觉编码后增加WaveZip压缩模块
  - 使用冻结的跨模态评分器（BLIP-ITM），不参与训练
  - 推理时，每帧处理分为两部分：跨模态评分（额外开销约2ms/帧）和WaveZip压缩（快速）

### 18. PRiSM: Prototype Regularization for Few-Shot VLMs
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2607.17820v2
- 方法流程：
  - 输入：支持集图像和标签、零样本原型 u_c、基线方法产生的初始原型 a_c。
  - 步骤1：构建多术语损失 L = λ1 * L_align + λ2 * L_fidelity + λ3 * L_sep，其中 L_align 促进支持特征与对应原型对齐，L_fidelity 限制原型偏离基线原型，L_sep 最大化类间余弦距离。
  - 步骤2：使用块Majorize-Minimize算法交替优化：更新类原型时，对每个块构造上界函数并通过近端算子更新；轻量级微调视觉编码器（仅少量参数）。
  - 输出：正则化后的类原型 a_c^opt，用于查询集分类。
- 关键模块/机制：
  - 多术语损失函数：综合监督信号，同时优化支持特征对齐、原型保真度和类间分离。；包含三项：L_align = Σ_{n} ||v_n - a_{y_n}||^2（支持特征与对应原型距离）；L_fidelity = Σ_c ||a_c - a_c^base||^2（约束原型偏离基线原型）；L_sep = Σ_{i≠j} max(0, m - ||a_i - a_j||)（或负余弦距离，最大化类间距离）。总损失为三者的加权和。
  - 块Majorize-Minimize优化器：高效求解多术语损失，避免整体梯度计算，利用块结构加速。；将原型分为多个块，每个块内构造一个上界函数（通过二阶泰勒展开并利用Gershgorin圆定理估计Hessian谱范数上界作为Lipschitz常数），然后通过闭式解更新块。交替进行原型更新和视觉编码器轻量微调（如仅更新分类头或少量Adapter参数）。
- 公式/目标函数/指标定义：
  - L(a) = λ1 Σ_n ||v_n - a_{y_n}||^2 + λ2 Σ_c ||a_c - a_c^base||^2 - λ3 Σ_{i≠j} ⟨a_i, a_j⟩（余弦相似度负项，最大化类间距离）
  - 优化器通过块近端梯度更新：a_c^(t+1) = a_c^(t) - η · (∇_c L(a^(t)))，其中η由Lipschitz常数决定，Lipschitz常数通过Gershgorin圆定理计算上界。
- 算法细节：
  - 给定支持集特征和初始原型，构建多术语损失。
  - 块划分：按类别或随机将C个原型分为B个块，每个块大小相等。
  - 对每个块，计算该块在损失函数上的梯度和Hessian近似，利用Gershgorin圆定理得到Hessian谱范数上界作为块Lipschitz常数。
  - 近端梯度更新：a_block^(t+1) = prox_{λ/L}(a_block^(t) - (1/L) ∇_{block} L)，其中prox为近端算子（此处为L2范数投影）。
  - 所有块更新完毕后，轻量微调视觉编码器（如仅更新最后一个Transformer层或额外的Adapter），用支持集交叉熵损失。
  - 重复交替直至收敛（固定迭代次数）。
- 训练/推理细节：
  - 训练-free基线方法+PRiSM：基线方法（如Tip-Adapter）先生成初始原型，PRiSM在此基础上进行无梯度回传的原型优化（仅需支持集）。
  - PRiSM优化过程不涉及大规模反向传播，仅需前向传播和近端梯度更新，计算高效。
  - 推理时，使用正则化后的原型替换原始原型，采用与零样本相同的余弦相似度分类器。

  - 环境采样：从环境分布p(E)中采样任务，包括遗忘目标z、元学习条件c等，并构建对应的文本遗忘和保留批次
  - 内环更新：在语言主干上，使用文本遗忘和保留批次执行K步遗忘（如GradDiff），更新主干参数θ
  - 重组合：将更新后的语言主干与冻结的VLM视觉组件重新组合，得到完整VLM
  - 外环评估：在重组后的VLM上采样多模态遗忘和保留批次，计算外环损失（多模态交叉熵）
  - 元更新：通过外环损失的梯度更新初始语言主干参数θ，使其更适应未来遗忘任务
  - 元测试：从学习到的初始化出发，对新的遗忘目标执行少量文本遗忘步骤，再重组VLM评估多模态表现
- 关键模块/机制：
  - 内环遗忘模块：在语言主干上执行文本遗忘，使用梯度上升或NPO/RMU等目标。输入为文本遗忘和保留批次，输出更新后的语言主干参数。；内环损失L_in = γL_f + αL_r，其中L_f使用梯度上升（-CE）或NPO/ RMU的遗忘损失，L_r为保留集上的NLL或KL损失。执行K步梯度下降更新θ。
  - 外环评估模块：将更新后的语言主干与冻结的视觉组件重组，计算多模态遗忘和保留损失，提供元学习反馈。；外环损失L_outer = λ_f L_mm_f + λ_r L_mm_r，其中L_mm_f和L_mm_r分别为重组VLM在多模态遗忘和保留批次上的交叉熵损失。
  - 元学习器：根据外环损失更新语言主干的初始参数，学习可迁移的遗忘初始化。；多个任务的外环损失平均后，通过梯度下降更新初始参数θ：θ ← θ - β ∇θ (1/S Σ L_outer)。
  - 环境采样与任务构建：基于聚类构建语义一致的遗忘和保留集，并采样不同的遗忘目标和条件。；对训练样本特征进行PCA降维后聚类（KMeans, k=10），选择目标簇作为遗忘集，其余为保留集。采样不同的遗忘目标z、元学习条件c等构成任务。
- 公式/目标函数/指标定义：
  - 内环遗忘损失（以GradDiff为例）：L_in = γ L_f + α L_r，其中L_f = -CE(θ_T; D_f), L_r = CE(θ_T; D_r) 或 KL散度
  - 外环元损失：L_outer = λ_f L_mm_f + λ_r L_mm_r，其中L_mm_f和L_mm_r是重组VLM在多模态遗忘/保留批次上的交叉熵损失
  - 元学习参数更新：θ_T ← θ_T - β ∇_θ (1/S Σ_{s=1}^S L_outer^{(s)})
- 算法细节：
  - 元训练算法（Algorithm 1）：采样S个任务，每个任务内环执行K步文本遗忘（如GradDiff），更新语言主干θ；然后重组VLM计算外环损失；累积外环损失后对初始θ进行元梯度下降。
  - 元测试算法（Algorithm 2）：从学习到的初始化θ*出发，在文本遗忘和保留数据上执行K步内环遗忘，得到更新后的主干，再与冻结视觉组件重组进行多模态评估。
  - 内环操作符支持GradDiff（梯度上升）、NPO（DPO风格的遗忘损失）、RMU（激活匹配随机向量）。元训练默认使用GradDiff。
  - 外环损失基于重组VLM的多模态输出计算，梯度仅回传到语言主干参数（视觉组件冻结）。
- 训练/推理细节：
  - 预训练：LoRA rank 8, 学习率1e-4, 余弦调度, warmup 0.1, batch size 1, 梯度累积8, bf16, 3 epochs
  - 元训练：内环学习率1e-5, 内环步数K=4, 内环1 epoch; 外环5 epochs, 元学习率1e-5, 梯度裁剪1.0, 外环损失权重λ_f=λ_r=1.0
  - 元测试：从学习到的初始化出发，使用与内环相同的文本遗忘操作（如GradDiff）执行K步，然后重组VLM评估
  - 推理时：使用元测试后的语言主干与冻结视觉组件组成完整VLM，输入文本和图像进行预测

### 24. Dual Adversarial Fine-tuning for Enhancing Robustness of Large Vision Language Model
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2607.18958v1
- 方法流程：
  - 输入：原始图像x、对抗性图像x_adv、对应标题t、不相关标题t_neg（batch内）
  - 视觉分支：冻结的原始视觉编码器F_θ_clean提取x的特征，可训练的视觉编码器F_θ_adv提取x_adv的特征，计算MSE损失最小化两者距离
  - 语义分支：对抗样本特征与原始标题特征进行对比学习（InfoNCE损失），使其靠近匹配标题、远离不匹配标题
  - 总损失：L_total = L_visual + λ * L_semantic，联合优化更新F_θ_adv
  - 输出：微调后的视觉编码器，替换原LVLM（如LLaVA）的CLIP视觉编码器用于下游任务
- 关键模块/机制：
  - 视觉监督分支 (Visual Supervision Branch)：保持预训练知识，防止语义监督过拟合；使用冻结的原始CLIP视觉编码器提取干净图像特征，对抗图像通过可训练编码器后计算特征距离（L2损失），迫使对抗特征靠近干净特征。
  - 语义监督分支 (Semantic Supervision Branch)：利用描述性标题提供丰富的语义上下文，增强跨任务鲁棒性；将对抗图像的特征与原始图像的描述性标题特征进行对比学习。正样本对为同一图像的标题，负样本为batch内其他图像的标题。使用InfoNCE损失函数，对齐对抗样本与正确语义。
- 公式/目标函数/指标定义：
  - L_visual = ||F_θ_adv(x_adv) - F_θ_clean(x)||_2^2
  - L_semantic = -log( exp(sim(z_i, c_i)/τ) / Σ_j exp(sim(z_i, c_j)/τ) )，其中z_i为对抗图像特征，c_i为匹配标题特征，c_j为batch内所有标题特征，τ为温度系数
  - 总目标：min L_total = L_visual + λ L_semantic
- 算法细节：
  - 对抗样本生成：使用PGD（Projected Gradient Descent）方法，在L∞范数约束下生成对抗噪声，扰动预算ϵ=2/255
  - 对比学习：batch内计算图像-标题相似度矩阵，正样本对为同一样本的图像和标题，负样本为其他标题
  - 训练时冻结原始视觉编码器，仅更新当前微调的视觉编码器参数
  - 微调完成后，直接替换原LVLM中的CLIP视觉编码器，无需额外对齐训练
- 训练/推理细节：
  - 训练数据集：使用ImageNet-1K训练集，并为每张图像获取描述性标题（可能使用预训练标题生成模型或公开caption）
  - 训练策略：对抗微调，每个batch生成对抗样本后同时计算两个分支损失，联合更新视觉编码器
  - 推理：将原始CLIP编码器替换为微调后的编码器，在零样本分类、图像描述、VQA等任务上评估鲁棒性

### 26. Anticipate Before Acting: Future-State-Conditioned Vision-Language Navigation
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.18042v2
- 方法流程：
  - 冻结视觉编码：使用SigLIP和MLP投影器将当前观测和历史观测编码为视觉token，与指令token交错拼接成上下文Ct
  - 插入查询token：在上下文后添加可学习的future query (qF)和action query (qA)，形成序列 [Ct, qF, qA]
  - 因果Transformer处理：使用Qwen2-7B因果Transformer处理序列，得到隐藏状态hFt和hAt
  - 训练时未来目标构建：对专家轨迹中Δ步后的图像ot+Δ，通过相同冻结视觉编码器得到视觉token网格，平均池化得到目标z*_{t+Δ}，应用stop-gradient
  - 投影未来状态对齐：通过投影网络g将hFt和z*_{t+Δ}映射到低维空间，计算L1损失Lfuture
  - 语言模型损失：对动作token序列计算标准交叉熵损失LLM
  - 联合优化：最小化Ltotal = LLM + λF Lfuture，更新因果LM和查询嵌入，冻结视觉编码器
- 关键模块/机制：
  - Future query (qF)：预测未来观测的潜在表示；可学习向量，维度为d，初始化为高斯分布。在因果序列中位于上下文Ct之后，action query之前。其隐藏状态hFt通过投影网络与冻结编码器编码的未来图像池化特征对齐。
  - Action query (qA)：作为动作生成的前缀状态，利用future query的信息；可学习向量，维度为d，位于future query之后。在因果注意力下可以attend到future query的表示，其隐藏状态hAt作为首个动作token的输入到LM head。
  - 投影网络 (g)：将未来状态表示映射到低维空间进行对齐；可学习的MLP，将d维向量投影到d'维（d'<<d），用于计算L1损失，减少对单个特征离群值的敏感度。
  - 未来目标分支：提供稳定的未来状态监督信号；训练时使用与在线分支相同的冻结视觉编码器（SigLIP+MLP）编码ot+Δ，输出视觉token网格，经平均池化和stop-gradient得到目标z*_{t+Δ}。仅训练时使用。
- 公式/目标函数/指标定义：
  - L_future = || g(ĥFt) - g(z*_{t+Δ}) ||_1
  - L_LM = -1/|S| Σ_{i∈S} log pθ(Yi | Y<i, Ct, qF, qA)
  - L_total = L_LM + λF L_future
- 算法细节：
  - 因果序列构造：上下文Ct（指令+当前与历史视觉token）后接qF、qA，然后自回归生成动作token at
  - 未来目标构建：冻结视觉编码器处理ot+Δ得到视觉token网格，平均池化为单向量，施加stop-gradient
  - 梯度流：Lfuture梯度仅更新因果LM和qF，不进入冻结编码器；动作预测梯度通过因果依赖qF→qA→at影响qF
  - 投影网络g参数与策略联合训练
- 训练/推理细节：
  - 训练：冻结SigLIP和MLP投影器，优化Qwen2因果LM、LM head、future query和action query嵌入；使用bfloat16、DeepSpeed ZeRO-2、梯度检查点；超参数λF=0.1，学习率2e-5，cosine调度，4 GPU，全局batch size 64
  - 推理：丢弃未来目标分支，仅用在线分支单次因果预填充；future query不参与自回归解码，其隐藏状态作为预测的未来表示；action query和后续动作token可attend到future query前缀；不需要未来观测或目标编码器

### 27. jina-reranker-v3.5: An Efficient Listwise Reranker with Hybrid Attention and Self-Distillation

- 方法流程：
  - Step 1: 查询和候选列表拼接——给定查询q和k个候选文档{d_i}，使用列表式提示将所有段落与分隔符标记连接，将查询放在末尾块。

  - 混合注意力调度（3L2G）：降低计算复杂度，同时保持长距离依赖。；28层中重复3个滑动窗口层（窗口大小w=1024）后跟2个全局层，终端层固定为全局注意力。滑动窗口层复杂度O(L·w)，全局层每3步周期性刷新全局信号。
  - 三阶段自蒸馏管道：将全注意力教师的知识迁移到稀疏注意力学生，弥合注意力掩码差异。；Stage I: 从jina-reranker-v3初始化，全注意力微调。 Stage II: 启用3L2G，先冻结非注意力层训练注意力投影（注意力重对齐），再解冻全参数微调。 Stage III: 冻结教师，使用多级损失（L_rank, L_score, L_state, L_embed）加上自监督辅助损失（L_sim, L_disp）进行蒸馏。
  - 多领域训练混合物：增强领域鲁棒性，特别是结构化数据。；覆盖法律（EUR-Lex, CLERC等）、医疗（MIRIAD, PubMed等）、金融（FiQA, 表格感知段落）、结构化（STARK, Struct-IR, 表格来源）和多语言（WebFAQ, SWIMIR, Ruri-v3, MIRACL）。难负例来自多个检索器（BM25, Jina, BGE, GTE, E5, ColBERT）。
  - 结构化数据合成管道（Struct-IR）：生成字段级排序训练实例。；从锚记录采样类型化约束，由LLM改写为查询；扰动1-2个受约束字段生成近重复难负例；密集挖掘更多候选；LLM评判列表以提升真匹配、细化过宽查询、丢弃模糊案例，并循环反馈。
- 公式/目标函数/指标定义：
  - 余弦相似度得分：s_i = cos(P_ϕ(˜q), P_ϕ(˜d_i))，其中P_ϕ是两层MLP，˜q和˜d_i是LBNL提取的上下文嵌入。
  - 蒸馏总损失：L = L_rank + β1 L_score + β2 L_state + β3 L_embed + α1 L_sim + α2 L_disp
  - 排名级对齐（KL散度）：L_rank = KL(Softmax(s_teach/τ) ∥ Softmax(s_stu/τ))，温度为τ=0.25。
  - 分数级对齐（MSE）：L_score = (1/K) Σ_{i=1}^K (s_stu,i - s_teach,i)^2，权重β1=0.65。
  - 状态级对齐（MSE）：L_state = (1/(T·H)) Σ_{t=1}^T ||h_stu,t - h_teach,t||_2^2，权重β2=0.65。
  - 嵌入余弦对齐：L_embed = 1 - (1/(1+K)) Σ_{j=1}^{1+K} cos(e_stu,j, e_teach,j)，权重β3=0.65。
- 算法细节：
  - 混合注意力调度：在28层中，按3L2G模式重复，即第1-3层滑动窗口，第4-5层全局，第6-8层滑动，第9-10层全局，以此类推，第28层固定为全局。
  - 滑动窗口层使用窗口大小w=1024，将注意力复杂度从O(L^2)降至O(L·w)。

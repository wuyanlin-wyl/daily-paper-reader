## 方向 1：面向医学图像的自监督与弱监督表示学习与分割
探讨如何利用自监督、弱监督（语言、涂鸦）和结构先验，在标注稀缺条件下学习鲁棒的医学图像表示与分割模型。

### 代表论文

- [OrganLens: Organ-Specific Representation Learning for CT Foundation Models](https://arxiv.org/abs/2607.25164v1)：通过自监督学习，使用器官身份条件化共享编码器、器官引导裁剪、器官特定蒸馏和解剖掩膜监督，从同一CT体积中产生多个器官特定表示，推理时无需外部分割掩膜。
- [Bi-Level Collaborative Learning for Few-Shot Scribble-Supervised Medical Image Segmentation](https://arxiv.org/abs/2607.25432v1)：提出双层协作学习框架BiSCL，通过上层可学习超像素网络与下层分割模型的双向交互协作，在少样本涂鸦监督下生成高质量伪标签，显著提升医学图像分割性能。
- [Open-Ended CT Volume Segmentation with Weak Supervision from Language](https://arxiv.org/abs/2607.25860v1)：提出一种结合体素级强监督和来自报告的切片级弱监督的训练方法，用于文本条件CT分割，显著减少所需完全标注数据量。

### 共同创新点
- 利用自监督或弱监督信号（器官身份、涂鸦、报告文本）减少对密集标注的依赖
- 引入结构先验（解剖掩膜、超像素、切片级标签）引导特征学习
- 在有限标注下实现器官特定表示或高质量分割

### 尚未解决的问题
- 自监督和弱监督方法对噪声标注的鲁棒性不足
- 结构先验的生成质量（如超像素、掩膜预测）在域外数据上下降
- 多器官、多病变场景下表示和分割的统一框架缺乏

### 二次创新路线
#### 路线 1：语言-结构协同的自监督器官分割框架
- 核心想法：结合OrganLens的器官条件化自监督表示和Open-Ended CT Volume Segmentation的报告级别弱监督，构建一个语言-结构协同的自监督框架，用于器官级分割。OrganLens提供器官特定表示，但缺乏分割能力；文本条件分割提供粗粒度分割，但依赖伪标签。融合后，利用语言指导器官条件化编码器生成文本对齐的表示，并联合优化自监督对比损失和分割损失。
- 新问题定义：给定CT体积和文本查询（如“肝脏”），要求输出该器官的分割掩膜，且仅使用少量体素级标注（如10%体积）和大量报告级弱标签。训练时，模型同时学习器官条件化自监督表示和文本驱动的分割，推理时无需外部分割掩膜。
- 机制来源：
  - OrganLens的器官身份条件化机制：将器官嵌入添加到CLS令牌，使编码器特征适应特定器官，提供器官敏感的表示基础。它解决如何从同一体积产生多个器官特定表示的问题。
  - Open-Ended CT Volume Segmentation的切片级分类损失：利用报告中的切片标签，通过分类损失使模型关注器官存在的切片。它解决如何利用文本弱监督增强分割的问题，但缺乏器官条件化。
  - OrganLens的解剖掩膜监督：训练解码器预测器官掩膜，提供结构先验。它解决如何在推理时实现无外部掩膜的加权池化。
- 为什么值得做：OrganLens已经证明器官条件化能提取器官特定特征，而文本条件分割证明报告弱标签可以提升分割性能。两者互补可同时提升表示判别性和分割精度，且对完全标注的需求可进一步降低。
- 理论/数学创新理由：
  - 数学对象：联合优化目标函数，包含自监督对比损失、分割损失和文本对齐损失。
  - 来源分解：OrganLens使用自监督蒸馏损失L_distill和掩膜监督损失L_mask；Open-Ended方法使用分割损失L_seg（Dice+CE）和切片级分类损失L_cls。两者各自处理特征学习和弱监督信号，但未统一。
  - 新建模方式：定义联合损失 L = λ1 * L_distill(θ, θ_tea) + λ2 * L_mask(θ_enc, θ_dec) + λ3 * L_seg(θ_enc, θ_seg) + λ4 * L_cls(θ_enc, θ_cls)，其中L_distill为DINOv2风格自蒸馏，L_mask为预测掩膜与真实掩膜的BCE+Dice，L_seg为预测分割与体素标签的Dice+CE，L_cls为切片级分类交叉熵。编码器θ_enc共享，通过器官嵌入c调整特征。
  - 公式草图：令 v = f_enc(x, c) 为器官条件化后的补丁特征，z = Pool(v, m) 为掩膜加权池化生成器官表示，其中 m = g_dec(v) 为预测掩膜。分割头输出 s = h_seg(v)，切片分类头输出 p = h_cls(z)。总损失： L = λ1 * H(tea(v_crop), student(v_crop)) + λ2 * (BCE(m, m_gt) + Dice(m, m_gt)) + λ3 * (Dice(s, y_seg) + CE(s, y_seg)) + λ4 * CE(p, y_slice)
  - 为什么可能有效：器官条件化编码器通过调节特征使后续模块更易区分器官边界；切片级分类损失提供全局上下文，引导掩膜预测关注正例切片；自监督蒸馏增强特征鲁棒性。三者联合优化可缓解弱监督噪声，降低对精确体素标注的需求，同时提升分割准确性。
- 可验证实验：在CT-RATE或LiTS数据集上，设置仅10%体素标注和全部报告弱标签，对比OrganLens+弱监督分割基线（如仅用文本条件模型或仅用OrganLens加线性分割头），使用Dice和NSD评估。
- 主要风险：报告标签提取可能引入噪声；多任务权重调节敏感；计算开销增加。

#### 路线 2：超像素引导的器官特定伪标签传播与分割
- 核心想法：将BiSCL的超像素区域先验与OrganLens的器官条件化表示结合，用于少样本涂鸦标注下的器官分割。BiSCL使用可学习超像素网络提供区域结构先验，但依赖于涂鸦标注；OrganLens提供器官条件化自监督表示。结合后，利用器官条件化特征增强超像素划分的语义一致性，并利用超像素传播细化的伪标签训练器官条件化分割模型。
- 新问题定义：在仅有少量涂鸦标注（如每器官2-3条涂鸦）的CT图像上，进行器官特定分割。模型通过器官条件化编码器提取特征，并利用超像素网络生成区域先验，在区域内传播涂鸦标签，生成高质量伪标签，用于自训练。
- 机制来源：
  - BiSCL的可学习超像素网络（SSN）：通过低层特征生成超像素，并利用语义重构损失接收分割反馈，提供弹性区域先验。它解决如何从稀疏涂鸦传播标签的问题。
  - OrganLens的器官身份条件化：通过嵌入调整编码器特征，使其对目标器官敏感。它解决如何区分不同器官的特征，避免超像素跨器官合并。
  - BiSCL的自适应扩散策略：在超像素区域内基于统计传播伪标签。它解决伪标签空间一致性问题。
- 为什么值得做：BiSCL已证明超像素先验能提升涂鸦标注下的分割效果，但未利用器官身份信息；OrganLens的器官条件化特征更聚焦于目标器官，两者结合可更准确地传播伪标签，减少边界模糊。
- 理论/数学创新理由：
  - 数学对象：双层优化目标，上层超像素网络L_ssn，下层分割模型L_seg，再加器官条件化引导项。
  - 来源分解：BiSCL的双层框架中，L_ssn包含低层重建、语义重构和紧凑性损失，L_seg包含部分交叉熵、伪标签和一致性损失。OrganLens提供器官条件化特征f_c = f_enc(x, c)。
  - 新建模方式：在BiSCL中引入器官条件化特征f_c替代原始特征用于超像素生成和伪标签传播。上层目标：L_ssn = L_low + λ_sem * L_sem(f_c, f_seg) + λ_c * L_compact，其中L_sem使用分割模型中间特征f_seg作为语义监督。下层目标：L_seg = L_pce(y_scrib, pred) + λ_pseudo * L_pseudo(˜y, pred) + λ_cons * L_cons，其中伪标签˜y通过超像素区域内在f_c上的自适应扩散获得。
  - 公式草图：令x为输入，c为器官嵌入。特征f_c = f_enc(x, c)。超像素网络S输出超像素分配图s。区域伪标签：对于第i个超像素，˜y_i = majority(pred_j | s_j = i)。分割损失：L_seg = CE(pred, y_scrib) * mask_scrib + α * CE(pred, ˜y) * conf_mask + β * MSE(pred_aug, pred)。超像素损失包含语义重构：‖f_c - f_seg‖^2，其中f_seg为分割编码器特征。
  - 为什么可能有效：器官条件化特征f_c更集中于目标器官，使得超像素划分更符合器官边界，减少跨器官伪标签扩散错误；同时，语义重构损失将分割反馈传递到超像素网络，对齐划分与分割任务，进一步提升伪标签质量。
- 可验证实验：使用CHAOS或BTCV数据集，设置每器官2条涂鸦标注，对比BiSCL、OrganLens+Scribble（直接使用OrganLens表示加线性分割头）和本方法，评估Dice和HD95。
- 主要风险：双层优化计算成本高；超像素数量需要针对器官大小调整；器官条件化可能过度依赖固定嵌入，对新器官不适应。

## 方向 2：多模态智能体系统在医疗场景的设计与评估
针对面向患者的健康智能体、兽医筛查系统和临床数据科学代理，探讨如何设计可交互、可审计、安全的医疗智能体系统及对应评估基准。

### 代表论文

- [PatientAgentBench: A Benchmark Framework for Evaluating Patient-Facing Health AI Agents](https://arxiv.org/abs/2607.25485v1)：提出PatientAgentBench基准框架，用于评估面向患者的健康AI代理。该框架将基础模型封装为代理，配备医疗工具沙盒，与模拟患者对话，并由LLM陪审团根据100余条临床标准在六个维度评分。验证显示陪审团与专家评分者的一致率达79-93%。在1200个场景中对10个模型进行基准测试，发现分诊质量差异显著（通过率32%-88%），最强模型总分仅4.25/5。静态基准不足以评估代理系统，该框架作为可重复的临床验证标准发布。
- [VetClaw: An Edge-Cloud Multimodal Agentic System for Veterinary Disease Screening](https://arxiv.org/abs/2607.26042v1)：VetClaw 提出了一个边缘-云多模态智能体系统，将静态的视觉语言模型分类转变为具备工具调用、工作流管理、安全检查和失败处理的协调系统，用于早期兽医疾病筛查。
- [ClinLens: Towards Long-Horizon Coding Agents for Longitudinal Multimodal Clinical Data Science](https://arxiv.org/abs/2607.26155v1)：提出CLINLENS基准，通过200个可执行任务和程序优先反向合成方法，系统评估纵向多模态临床数据科学中长周期编码代理的性能，揭示执行成功与正确分析之间的巨大差距。

### 共同创新点
- 将LLM/VLM集成到智能体系统中执行多步推理和工具调用
- 设计工作流编排或评估框架确保安全性和可追溯性
- 利用模拟患者或任务包进行可重复的自动评估

### 尚未解决的问题
- 如何跨不同医疗场景（患者沟通、诊断、数据分析）迁移工作流设计
- 现有基准任务规模有限且仅覆盖部分模态
- 智能体在执行过程中缺乏从错误中学习的机制

### 二次创新路线
#### 路线 1：融合诊断推理与数据分析的统一医疗智能体框架
- 核心想法：将VetClaw的LangGraph工作流编排与ClinLens的多模态数据科学任务结合，构建一个既能进行患者对话诊断又能执行复杂数据查询的统一医疗智能体。VetClaw擅长工具调用和安全性检查，但数据分析能力弱；ClinLens基准覆盖结构化数据、影像和文本，但未提供完整智能体框架。统一框架可使用LangGraph管理多步推理，调用ClinLens定义的数据科学工具（如SQL、影像处理API），并在安全规则下完成诊断和数据报告。
- 新问题定义：给定患者主诉及多模态数据（EHR、影像、心电图），智能体需通过多轮对话收集信息，调用数据分析工具进行队列查询、关联分析或预测，最终输出诊断建议和证据报告。评估使用ClinLens的STRICT PASS标准，并增加对话自然度评分。
- 机制来源：
  - VetClaw的LangGraph工作流引擎：管理状态化的筛查流程，包含输入验证、模型调用、安全规则、条件路由和失败处理。它解决如何安全可控地协调多步骤推理的问题。
  - ClinLens的程序优先反向合成方法：生成可执行任务包和参考工作流，确保任务客观可评估。它解决如何系统评估智能体长周期任务的问题。
  - VetClaw的分离式架构：边缘代理（OpenClaw）负责交互，云端工作流负责编排。它解决如何解耦用户接口和核心推理的问题。
- 为什么值得做：VetClaw的工作流状态机提供了安全的模型调用和失败处理；ClinLens的任务包生成方法确保了任务的多样性和可验证性。两者结合可产生一个既实用又可审计的医疗智能体系统。
- 理论/数学创新理由：
  - 数学对象：带安全约束的有限状态机（FSM）联合任务定义元组。
  - 来源分解：VetClaw使用FSM定义节点和条件边，状态包括输入验证、工具调用、安全检查等。ClinLens用元组τ = (q, P, A, f, ϵ)定义任务，其中f是参考工作流。
  - 新建模方式：定义统一智能体框架Agent作为扩展的FSM，其状态集S包含对话状态s_d、工具调用状态s_t、安全验证状态s_s等。每个转换由LLM决策或确定性规则控制。任务执行记录轨迹T = (s0, a0, s1, a1, ..., s_n)，评估条件由ClinLens的匹配函数ϵ扩展为ϵ'(回答正确, 对话合规, 安全无事故)。
  - 公式草图：Agent状态转移：s_{t+1} = F(s_t, o_t, r_t)，其中o_t为LLM输出，r_t为安全规则验证结果。安全规则：if confidence_threshold < δ then route_to_human。任务完成度：Score = I(ϵ'(answer==ref, dialog_ok, safety_ok))。优化目标：最大化通过率，同时最小化人工干预次数。
  - 为什么可能有效：FSM结构保证了执行的可预测性和安全性；ClinLens的任务包确保评估标准化；结合后，LLM仅在安全边界内决策，减少幻觉风险，同时数据分析能力由工具保证，提升准确性和可审计性。
- 可验证实验：在ClinLens的126个任务套件中，选出20个需要多轮交互的任务（如关联分析+预测），构建患者模拟器。比较本方法（LangGraph + 诊断工具 + 安全规则）与直接使用LLM+工具（ReAct）的通过率和平均轮次。
- 主要风险：状态机设计复杂，可能产生组合爆炸；安全规则需要领域专家精心设计；跨任务泛化性不足。

#### 路线 2：面向患者智能体的可迁移安全评估框架
- 核心想法：结合PatientAgentBench的LLM-as-a-Jury评估方法和VetClaw的安全规则设计，构建一个可迁移的患者面向智能体安全评估框架。PatientAgentBench提供多维度评分（准确性、安全性、同理心等）和临床标准；VetClaw提供确定性安全规则（如置信度阈值、症状紧急判断）。提出新框架将规则嵌入评估流程，自动检测危险输出并扣分，同时保持评估的可重复性。
- 新问题定义：设计一个评估框架，给定模拟患者对话历史和智能体响应，输出六个维度的分数（准确性、安全性、同理心、效率、可解释性、对话流畅性），其中安全性分数由一项可编程规则库和LLM评判共同决定。规则库可从VetClaw中迁移。
- 机制来源：
  - PatientAgentBench的LLM-as-a-Jury机制：使用100余条临床标准，由LLM按六维度打分。它解决如何自动评估对话质量的问题。
  - VetClaw的确定性安全规则：例如置信度阈值<0.5则升级人工，症状描述包含紧急词则报警。它解决如何捕捉LLM评分可能忽略的硬性安全违规。
  - PatientAgentBench的模拟患者和场景生成：使用GPT-4o生成患者角色和病历。它解决如何构建可重复测试场景的问题。
- 为什么值得做：PatientAgentBench已经验证了LLM陪审团与临床专家的一致性，但未包含可编程安全规则；VetClaw的安全规则虽简单但有效。二者结合可更全面地评估智能体在真实对话中的安全性。
- 理论/数学创新理由：
  - 数学对象：加权评分函数，包含LLM软评分和硬规则二值惩罚。
  - 来源分解：PatientAgentBench使用LLM直接输出1-5分；VetClaw使用if-else规则触发升级。两者未融合。
  - 新建模方式：定义总安全分数 S_safety = β * S_LLM - γ * (1/H) * Σ_i penalty_i，其中S_LLM是LLM对安全维度的软评分，penalty_i是第i条硬规则触发的惩罚（0或1），H是规则总数。其他维度分数保持不变。最终总分 = Σ (w_j * S_j)。
  - 公式草图：规则库R = {r_1, ..., r_H}，每个r_k定义触发条件和惩罚值p_k ∈ [0,1]。对于对话D，触发集合K = {k | r_k(D)=true}。安全性分数：S_safety = clip( S_LLM - λ * (1/|K|+1)*Σ p_k, 0, 5 )，其中λ为缩放因子。整体评分向量S = (S_accuracy, S_safety, ...)。
  - 为什么可能有效：硬规则可捕获LLM评分可能遗漏的严重错误（如推荐禁忌药物），而LLM评分提供细微违规的区分度。两者加权平衡，既保持自动性又提高评估的准确性和鲁棒性。
- 可验证实验：使用PatientAgentBench的1200个场景和GPT-4o生成的响应，人工标注300个对话的安全性细节。比较仅LLM评分、仅规则评分和结合方法的准确率、召回率和F1。
- 主要风险：规则库的设计可能引入偏见或遗漏；不同场景规则阈值需调整；LLM评分与规则之间存在冗余或冲突。

## 方向 3：医学视觉语言模型中视觉信息的有效编码与利用
研究多模态大语言模型在医学影像中视觉信息的编码完整性与利用效率，探索令牌压缩和控制视觉-语言先验权衡的方法。

### 代表论文

- [Seeing or Knowing? Visual Context Sensitivity in Multimodal Large Language Models](https://arxiv.org/abs/2607.26326v1)：揭示多模态大语言模型（MLLM）编码了粗粒度视觉证据但无法可靠控制其使用，通过引入WhatIfVis基准和两种诊断范式，并提出通过监督微调、激活修补和可学习向量改善视觉-先验权衡的可控性。
- [MedARC: Training-Free Adaptive Redundancy Compression of Visual Tokens for 3D Medical Vision-Language Models](https://arxiv.org/abs/2607.26554v1)：针对3D医学视觉语言模型中视觉令牌冗余导致计算成本高的问题，提出MedARC框架，通过整合自注意力、文本相似性和结构特征三种线索自适应估计令牌重要性，采用保留重要令牌并合并冗余令牌的策略，在CT-RATE和MR-RATE上减少令牌数量并提升诊断性能。

### 共同创新点
- 揭示MLLM中视觉编码的充分性与利用的不足（Seeing or Knowing）
- 提出自适应令牌压缩框架（MedARC）减少冗余同时保留关键信息
- 两者均关注视觉信息在VLM中的表示与使用

### 尚未解决的问题
- 现有VLM对细粒度视觉属性（纹理、形状）的编码是否充分未知
- 令牌压缩方法对视觉-先验权衡的影响未探索
- 未见将控制策略（如可学习向量）与压缩结合的工作

### 二次创新路线
#### 路线 1：视觉-先验权衡引导的自适应令牌压缩与激活调控
- 核心想法：将MedARC的自适应令牌压缩与Seeing or Knowing揭示的视觉-先验控制机制结合。MedARC通过多线索融合估计令牌重要性，但未考虑语言先验的干扰；Seeing or Knowing发现可学习向量可以连续调节模型偏向。新方法在压缩时根据当前任务的视觉依赖性（如由WhatIfVis评估得分）动态调整压缩策略，对视觉重要性高的区域保留更多令牌，并使用可学习向量增强视觉信息利用。
- 新问题定义：在3D医学VLM（如CT-RATE）上，给定文本查询和CT体积，要求模型输出关于视觉属性（如病变大小、是否存在）的答案。模型先进行自适应令牌压缩，再使用可学习控制向量增强视觉感知，压缩比例动态调整以适应不同查询。
- 机制来源：
  - MedARC的多线索重要性估计：融合自注意力、文本相似性和结构特征三种线索。它解决如何识别和保留重要令牌的问题。
  - Seeing or Knowing的可学习控制向量：离线训练一个向量，加在模型隐藏层上以调节视觉-先验偏好。它解决如何在不改变模型参数下控制视觉利用的问题。
  - MedARC的保留+合并策略：对重要令牌保留，对冗余令牌合并。它解决压缩后信息丢失的问题。
- 为什么值得做：MedARC已经证明多线索融合优于单一信号，但未动态调节；Seeing or Knowing表明控制向量可改善视觉利用。两者结合有望在压缩的同时提升视觉推理准确性。
- 理论/数学创新理由：
  - 数学对象：可微的令牌重要性权重与可学习控制向量的联合优化目标。
  - 来源分解：MedARC通过加权融合三个线索得到每个令牌的重要性w_i；Seeing or Knowing通过优化一个方向向量v使模型更依赖视觉。两者独立。
  - 新建模方式：定义联合重要性权重 w_i' = α * w_i_MedARC + β * g_i(v)，其中g_i(v)为控制向量v对第i个令牌的影响度（如隐藏状态点积）。压缩后令牌集合T' = Top_k(w') ∪ Merged(其余)。训练时，冻结VLM骨干，仅优化v和压缩阈值τ。损失包含任务答案正确性L_task和压缩比约束L_comp = τ / max_tokens。
  - 公式草图：令h_i为第i个视觉令牌的隐藏状态。MedARC得分s_i = σ(λ1 * attn_i + λ2 * sim_i + λ3 * struc_i)。控制影响g_i = v^T h_i / ||h_i||。最终权重w_i = s_i + η * tanh(g_i)。压缩：保留w_i > δ的前K个令牌，其余合并为m个平均令牌。VLM处理压缩后序列输出答案y，优化L = CE(y, y_gt) + μ * (K/max_tokens - τ)^2。
  - 为什么可能有效：控制向量v可增强视觉重要令牌的权重，使压缩更偏向视觉相关令牌，减少对语言先验的依赖。同时，MedARC的多线索确保结构信息保留。联合优化可使模型在压缩率较高时仍保持视觉推理准确。
- 可验证实验：在CT-RATE数据集上，使用文本查询（如“左肺上叶结节大小”），比较原始MedARC、原始MLLM（无压缩）和本方法，在不同压缩率（50%、30%）下的回答准确率和令牌数。
- 主要风险：可学习向量v可能过拟合特定查询；联合优化需要平衡任务损失和压缩约束；3D体积令牌数量大，计算成本高。

#### 路线 2：基于视觉上下文敏感性的细粒度属性评估与压缩动态调节
- 核心想法：利用Seeing or Knowning的WhatIfVis基准测试视觉-先验权衡，设计一个元评估器，对每个输入查询预测其视觉依赖性（视觉重要性分数），然后动态调整MedARC的压缩策略：高视觉依赖性任务保留更多令牌，低依赖任务允许更高压缩。同时，在推理时对视觉-先验冲突问题应用激活修补。
- 新问题定义：在3D医学VLM中，输入为CT体积和文本查询，输出为答案和评估报告。系统包含一个视觉依赖性预测器（基于查询文本），根据预测分数动态设定压缩比率，并在遇到视觉-先验冲突时自动应用激活修补（如增大图像token的激活值）。
- 机制来源：
  - Seeing or Knowing的WhatIfVis基准：分类任务并按维度（颜色、计数等）测量视觉敏感性。它提供任务类别与视觉依赖性的映射。
  - Seeing or Knowing的激活修补：在推理时对特定层图像token激活进行缩放以增强视觉影响。它解决如何临时控制视觉利用的问题。
  - MedARC的自适应压缩框架：根据重要性评分保留或合并令牌。它解决如何压缩令牌的问题。
- 为什么值得做：Seeing or Knowing发现不同任务视觉依赖性差异大（如颜色 vs. 计数），但当前压缩方法统一处理。动态调节可避免在简单任务上过度压缩导致性能下降，或在复杂任务上保留不足。
- 理论/数学创新理由：
  - 数学对象：任务视觉依赖性评分函数和压缩比调度函数。
  - 来源分解：WhatIfVis提供任务类别标签（如color, count）；激活修补通过乘法缩放图像token的隐藏状态；MedARC压缩通过重要性阈值决定令牌保留。三者未联合。
  - 新建模方式：定义视觉依赖性预测器D: query -> d ∈ [0,1]，可由轻量分类器基于查询嵌入训练。压缩比ρ = ρ_max - (ρ_max - ρ_min) * d，即高依赖性保留更多令牌。激活修补缩放因子λ = 1 + γ*(1-d)，即低依赖性时增强视觉。最后令牌序列送入VLM。
  - 公式草图：令q为查询文本，经BERT编码得e_q。D(e_q) = σ(W e_q + b)输出d。令牌压缩：重要性w_i = Attn_i + Sim_i + Struc_i，保留前K = ratio * N个令牌，其中ratio = ρ_max - Δρ * d。激活修补：图像token h_i被缩放为h_i' = (1 + α*(1-d)) * h_i。最终损失L = CE(y_pred, y) + β * (ratio - target_ratio)^2。
  - 为什么可能有效：依赖预测器使得模型能够自适应性分配计算资源，对视觉要求高的任务保留更多细节；激活修补增强视觉信号，弥补压缩可能带来的信息损失。整体在保持高压缩比的同时，视觉推理性能更稳定。
- 可验证实验：在CT-RATE数据集中创建适用于WhatIfVis维度的任务（如颜色=病变密度，计数=结节数量），测量本方法与固定压缩方法的准确率和压缩比。
- 主要风险：任务依赖性预测器的训练需要标注；激活修补可能对某些模型产生副作用；不同层激活缩放效果差异大，需调参。

## 摘要
许多高性能的体积分割模型维护密集的多尺度特征图，导致激活内存和推理成本高昂。本文提出BATS（边界感知令牌选择），一种3D医学图像分割架构，该架构将精细分辨率处理集中在预测的类别边界附近。一个密集的边界预测器识别需要额外分辨率的位置，而精细优先的上下文级联构建了一个输入依赖的混合分辨率层次。均匀区域被粗略表示，而更精细的令牌保留在边界、薄结构和小目标周围。稀疏层次被细化并栅格化为密集分割。BATS在每个分辨率级别独立预测边界相关性，防止错误的粗尺度决策抑制细尺度证据。父簇注意力进一步将层级祖先令牌注入局部注意力邻域，提供了无需密集多尺度特征图或跨尺度邻域搜索的跨尺度上下文。我们使用标准化的nnU-Net Revisited协议在五个公开CT和MRI数据集上评估BATS。BATS在比较方法中实现了最高的LiTS Dice，并且在五个数据集上平均距离最强的密集基线MedNeXt-L仅0.37个Dice点。相对于MedNeXt-L，它在KiTS、LiTS和BraTS上将峰值分配的GPU内存减少了超过53%。在保留较少令牌的KiTS和LiTS上，推理速度提高了30%，但在令牌更密集的BraTS上较慢。因此，混合分辨率处理提供了持续的内存节省，而运行时和准确性的提升取决于数据集边界密度。

## Abstract
Many high-performing volumetric segmentation models maintain dense multi-scale feature maps, leading to high activation memory and inference cost. We present BATS (Boundary-Aware Token Selection), a 3D medical image segmentation architecture that concentrates fine-resolution processing near predicted class boundaries. A dense boundary predictor identifies where additional resolution is needed, while a fine-first context cascade constructs an input-dependent mixed-resolution hierarchy. Homogeneous regions are represented coarsely, with finer tokens retained around boundaries, thin structures, and small targets. The sparse hierarchy is refined and rasterised into a dense segmentation.   BATS predicts boundary relevance independently at every resolution level, preventing an erroneous coarse-scale decision from suppressing fine-scale evidence. Parent cluster attention further injects hierarchical ancestor tokens into local attention neighbourhoods, providing cross-scale context without dense multi-scale feature maps or cross-scale neighbour search.   We evaluate BATS on five public CT and MRI datasets using the standardised nnU-Net Revisited protocol. BATS achieves the highest LiTS Dice among the compared methods and averages within 0.37 Dice points of the strongest dense baseline, MedNeXt-L, across the five datasets. Relative to MedNeXt-L, it reduces peak allocated GPU memory by more than 53% on KiTS, LiTS, and BraTS. Inference is up to 30% faster on KiTS and LiTS, which retain fewer tokens, but slower on the more token-dense BraTS. Mixed-resolution processing therefore provides consistent memory savings, while runtime and accuracy gains depend on dataset boundary density.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有高性能3D医学图像分割模型（如nnU-Net、MedNeXt、SwinUNETR等）均维护稠密的多尺度特征图，在每一空间位置都采用相同分辨率处理，导致计算和内存开销随分辨率立方增长。然而，医学图像中并非所有区域都需要精细表示：边界、小病灶、薄结构需要高分辨率，而均匀组织或背景可以用粗分辨率表示。因此，亟需一种能根据输入内容自适应分配计算资源的方法，在保持精度的同时降低资源消耗。

- **核心问题**：如何设计一个输入依赖的混合分辨率令牌层次，使精细令牌仅集中在关键位置，并实现高效的跨尺度交互，同时避免迭代粗到细策略中粗尺度错误不可逆地丢失细尺度信息。

- **整体含义**：BATS（Boundary-Aware Token Selection）是一种新颖的3D医学图像分割架构，它通过密集边界预测器独立评估每个尺度的边界相关性，采用细优先上下文级联构建稀疏混合分辨率层次，并通过父簇注意力注入跨尺度上下文。该方法在五个公开数据集上实现了与最强稠密基线MedNeXt-L相当的平均精度（仅低0.37 Dice），同时减少峰值GPU内存超过53%，并在部分数据集上提升推理速度达30%。这为资源受限的医学影像应用（如边缘设备、实时系统）提供了可行方案。

## 2. 方法论

### 2.1 核心思想
- 利用密集边界预测器对所有分割尺度（16³、8³、4³、2³）进行并行评分，识别需要精细处理的区域。
- 采用**细优先上下文级联**：从最细尺度向最粗尺度施加分割决策，并保留所有选中令牌的祖先链，确保即使粗尺度预测为负，也不抑制细尺度证据。
- 构建**输入依赖的混合分辨率令牌层次**：同质区域用粗令牌表示，边界附近保留细令牌。
- 通过**父簇注意力**机制，将祖先令牌注入局部注意力邻域，提供跨尺度上下文，避免重建密集多尺度特征图或进行3D空间近邻搜索。

### 2.2 关键技术细节
- **边界预测器**：3D ConvNeXt金字塔 + FPN，在四个分割尺度并行输出分割概率。采用学习门控残差连接，使粗预测能增强细预测但非硬性门控。
- **令牌选择**：边界概率超过阈值τ=0.5时执行分割。细优先级联确保每个被选细令牌的祖先都被保留。
- **令牌融合**：每个令牌结合原始图像块嵌入和边界预测器FPN特征，通过可学习门控融合。
- **父簇注意力**：基于AutoFocusFormer的平衡聚类，每个查询的局部邻域由R个最近聚类中的令牌组成。额外注入该令牌的所有祖先令牌（通过哈希网格直接检索），祖先密钥梯度被停止以减轻写争用。单个softmax联合计算查询、局部邻居和祖先。
- **密集分割头**：将精炼后的令牌栅格化为体素级特征，结合卷积图像跳跃连接，预测最终分割。

### 2.3 算法流程（文字描述）
1. 输入128³裁剪，通过密集边界预测器获得四个尺度的分割概率图。
2. 细优先上下文级联：从2³尺度开始，根据概率>0.5决定是否分割，保留选中令牌及其所有祖先（包括16³固定保留）。
3. 为每个保留令牌提取图像嵌入和FPN特征，融合为初始特征。
4. 从粗到细逐步处理：先处理16³令牌，然后每阶段引入更细令牌并联合处理整个活动层次。
5. 在每个精炼块中应用父簇注意力：先对令牌进行空间聚类，每个查询的局部邻域由簇级近邻确定，再注入祖先令牌；所有键值参与softmax，进行多头注意力。
6. 精炼后，各尺度令牌投影到共享输出宽度，通过栅格化（每个体素取最细覆盖令牌的特征）得到密集体积。
7. 轻量残差CNN结合图像跳跃连接，输出最终分割logits。

1. **精度表现**：BATS在LiTS上取得最高Dice（83.39），超过MedNeXt-L k3 1.25点；在五个数据集上平均Dice比MedNeXt-L k3低0.37点，差距很小。

4. **消融关键发现**：

   - 父簇注意力优于局部簇注意力（+0.99 Dice on KiTS），且优于单独交叉注意力。
   - Oracle预热和辅助损失每个贡献约0.7–1.0 Dice提升。

## 7. 优点

- **方法创新**：首次在3D医学分割中实现输入依赖的混合分辨率令牌，无需预设预算。细优先级联避免迭代方法的不可逆错误。
- **跨尺度交互设计**：父簇注意力通过确定性哈希网格注入祖先，无需近邻搜索，计算高效且保证了上下文一致性。
- **实验严谨**：采用标准化的nnU-Net Revisited协议，与多个强基线在统一设置下比较，结果可重复。
- **消融全面**：对令牌构建策略、跨尺度机制、组件贡献均进行了深入分析，验证了每个设计选择的有效性。
- **效率提升显著**：内存降低超过53%，在边界稀疏数据集上同时获得精度和速度提升（如LiTS呈现Pareto改进）。

## 8. 不足与局限

- **实验覆盖局限**：效率对比仅与MedNeXt-L（一个主用密集基线）进行，未与所有对比方法（如SwinUNETR、nnFormer）进行同等条件的效率和内存对比。训练时间取自外部报告，可能因环境差异不精确。
- **硬件/环境依赖性**：稀疏算子的性能可能因GPU架构、CUDA实现而异，论文仅使用A100测试，未验证其他设备（如T4、V100）。
- **运行时条件性**：在密集边界数据集（BraTS）上推理比MedNeXt-L k3慢，限制了通用性。需进一步优化稀疏操作的固定开销。
- **边界预测局限**：边界预测对图像对比度敏感（如LiTS中非语义边缘引起不必要细令牌），导致精度稍低，浪费计算资源。需要更好校准精度-成本权衡。
- **应用限制**：对于依赖弥散纹理而非局部边界结构的任务（如某些纹理区分病变），自适应分辨率可能收益有限。
- **未提供训练/推理在不同批大小下的扩展性分析**：当前训练批大小为2，推理批大小为1，未讨论更大批量下的内存与速度表现。

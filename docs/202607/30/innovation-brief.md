### 1. Be Consistent! Enhancing Robust Visual Reasoning in LVLMs with Consistency Constraints
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.21722v1
- 方法流程：
  - 阶段1: 逻辑等价问题生成 —— 输入图像及其标题、物体信息（边界框和类别），使用 GPT-4.1 作为 proposer 模型生成两个逻辑等价问题及其伪答案，输出 {(q1, a1), (q2, a2)}
  - 阶段2: 基于一致性的强化学习 —— 对于每个图像的问题对，将两个问题分别输入当前策略模型 πθ 采样输出答案，计算准确性奖励 racc 和一致性奖励 rcon，通过 GRPO 更新策略参数 θ
  - 训练数据: 采集自 SA-1B 等数据集，经过过滤和 GPT-4.1 生成，人工校验后共 468,000 对问答对，覆盖六个类别
  - 推理: 模型对单一问题直接生成答案，无需额外流程
- 关键模块/机制：
  - Proposer 模块（GPT-4.1）：自动生成逻辑等价问题对和伪答案，提供弱监督信号；输入图像、标题、物体边界框和类别信息，根据类别特定指令生成两个逻辑等价问题及其答案。生成的问答对经过人工校验以确保质量。
  - 一致性奖励（rcon）：衡量模型对逻辑等价问题对的回答是否一致；对于通过 proposer 生成的逻辑等价问题对 (q1, q2)，若模型对两者的回答（经二元化处理后）一致，则 rcon=1；否则 rcon=0。可基于字符串匹配或语义等价判断（论文中采用二元化处理，如对选择题选项进行匹配）。
  - GRPO 优化器：基于分组相对策略优化，结合双重奖励更新策略模型参数；每个问题采样 G 个输出（论文中 G=4），计算每个输出的奖励 r = racc + γ·rcon，然后对组内奖励做归一化得到优势值 A_i = (r_i - mean(r)) / std(r)，通过最大化分组相对优势的对数概率更新策略模型。
  - 双重奖励设计：结合准确率奖励和一致性奖励，平衡正确性与一致性；总奖励 r = racc + γ·rcon，其中 racc 为0/1（基于答案正确性），rcon 为0/1（基于一致对）。γ 为超参数，实验中 γ=0.5。也可单独使用 rcon 进行训练。
- 公式/目标函数/指标定义：
  - 优化目标（公式3）: max_θ E_{I,q,o} [racc(I,q,o)] + γ E_{I,(q1,q2),o1,o2} [rcon(o1,o2)]
  - 逻辑一致性指标: 对于逻辑等价问题对，模型回答一致的比例
  - 鲁棒准确率: 两个问题均回答正确的比例
- 算法细节：
  - GRPO 分组采样: 每个问题从策略模型采样 G=4 个输出，计算组内优势值进行相对奖励归一化
  - 二元化处理: 对于选择题或 yes/no 问题，将模型输出映射为标准选项（如 A/B 或 yes/no），以计算一致性和准确率
  - 数据生成过滤: 基于图像标题关键词筛选类别图像，使用 GPT-4.1 生成问题对，经人工校验去除错误或修改
  - 训练数据类别: 动作与状态、复杂计数、空间推理、因果与意图、常识推理、时间感知
- 训练/推理细节：
  - 基础模型: Qwen2.5-VL-7B
  - 训练数据: 468,000 个逻辑等价问答对（图像-问题对），来自 SA-1B 等数据集，由 GPT-4.1 生成并人工校验
  - 优化器: GRPO，batch size 256，学习率 2e-6，训练 250 步，γ=0.5
  - 推理: 直接使用 Qwen2.5-VL-7B（训练后）对单个问题生成答案，无需特殊处理

### 2. RadSight: Towards Perceptually Reliable Multimodal Radiology Image Understanding
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.22293v1
- 方法流程：
  - Stage 1: Visual-Language Alignment - 输入图像和0.42M长/短文本对，将视觉特征与语言模型对齐，输出对齐后的多模态表示。
  - Stage 2: Fine-grained Visual Perception - 输入图像和细粒度感知查询（如位置、大小、密度），训练模型识别病灶属性并进行空间定位，输出属性预测和空间定位结果。
  - Stage 3: Clinical Diagnosis - 输入图像和诊断问题（如疾病存在与否），基于已习得的感知证据进行疾病预测和异常检测，输出诊断结论。
  - Stage 4: Diagnostic Interpretation - 输入图像，生成完整的放射学报告或诊断解释，融合前三个阶段的能力。
- 关键模块/机制：
  - Dual 2D/3D Encoder Architecture：分别编码2D医学图像和3D CT体积，保留空间结构信息，将特征投影到共享语言模型接口。；使用专用2D图像编码器（如ViT）处理X光或CT切片，专用3D体积编码器（如3D ViT或CNN）处理CT序列，通过投影层将特征映射到LLM的输入空间。
  - Progressive Curriculum Learning with Four Stages：分阶段训练，逐步从低级视觉感知过渡到高级临床推理，避免直接学习高层任务而忽略感知基础。；训练顺序：视觉-语言对齐（0.42M样本）→ 细粒度视觉感知（病灶属性、定位）→ 临床诊断（疾病预测、异常检测）→ 诊断解释（报告生成）。每个阶段基于前阶段已学习能力进行训练。
  - Perception-Oriented Corpus Construction Pipeline：自动从报告-图像对中提取细粒度感知数据，用于第二和第三阶段训练。；流程：原始报告→器官级报告分割→疾病类型提取→病灶属性提取（位置、大小、计数、密度、形态等）→与图像空间标签（器官/病灶/疾病mask）配对，形成感知问答对。

### 4. UltraViT: Latency-Optimized On-device Vision Encoder for Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.23373v1
- 方法流程：
  - 阶段1: 密集蒸馏——使用结构重对齐将教师模型高分辨率特征图与学生特征对齐，通过L2损失训练学生编码器。
  - 阶段2: 生成式预训练——将学生编码器输出视觉token与冻结的混合容量LLM连接，通过自回归next-token预测损失训练学生编码器。
  - 整体流程: 图像→UltraViT编码器（四阶段金字塔）→视觉token→MLP投影器→LLM生成文本。
- 关键模块/机制：
  - 异构空间混合器：在不同阶段以不同方式混合空间信息，平衡效率与表示能力。；包含四种混合器：卷积混合器（DWConv5x5+Pointwise）、稀疏混合器（单头注意力+通道压缩）、通道分区注意力混合器（仅对通道子集进行单头注意力）、单头注意力混合器。每种混合器遵循相同的Meta Architecture Block（残差连接+TokenMixer+MLP）。
  - Meta Architecture Block：标准化的Transformer块结构，保证所有深度一致。；定义为 Y = TokenMixer(Norm(X)) + X, Z = MLP(Norm(Y)) + Y。仅替换内部的TokenMixer模块。
  - 稀疏混合器优化：降低标准稀疏注意力的设备延迟。；四项优化：(S1) 单头注意力替代多头；(S2) 将稀疏采样融合到Q/K/V投影（使用步长卷积）；(S3) 用最近邻上采样替代转置深度卷积；(S4) 降低查询/键维度至16，值压缩4倍。
  - 通道分区注意力混合器：在部分通道上应用单头注意力以减少计算。；X_att, X_res = Split(X, [Cp, C-Cp])，仅对X_att进行单头注意，然后与X_res拼接后经过输出投影。Cp = C/4, Cqk=16。
  - 多尺度特征聚合器：融合晚期语义特征与早期高分辨率特征以支持密集预测。；各阶段特征通过步长卷积投影到统一空间分辨率，沿通道拼接，再经1x1卷积融合。
- 公式/目标函数/指标定义：
  - Meta Architecture Block: Y = TokenMixer(Norm(X)) + X; Z = MLP(Norm(Y)) + Y
  - 卷积混合器: X_proj = Conv1x1(X); Y = Conv1x1(DWConv5x5(X_proj))
  - 稀疏混合器（原版）: X_sparse = S(X); X̃_global = Attention(X_sparseW_Q, X_sparseW_K, X_sparseW_V); Y = ConvTrans_DW(X̃_global)
  - 稀疏混合器（优化版）: Q,K,V = Conv_stride(X; W_Q), Conv_stride(X; W_K), Conv_stride(X; W_V); X̃_global = SH-Attention(Q,K,V); Y = Upsample_NN(X̃_global)W_O
  - 通道分区注意力: X_att, X_res = Split(X, [Cp, C-Cp]); X̃_att = SH-Attention(X_attW_Q, X_attW_K, X_attW_V); Y = Concat(X̃_att, X_res)W_O
  - 训练目标：第一阶段密集蒸馏使用L2损失；第二阶段生成式预训练使用自回归next-token预测损失。
- 算法细节：
  - 块选择过程：在真实设备上测量各混合器在不同通道数和token数下的延迟，绘制吞吐量图，然后训练候选配置并用SigLIP损失+零样本评估，最后根据延迟和精度排名选择每个阶段的最佳混合器。
  - 两阶段预训练：第一阶段，学生特征与教师特征对齐，通过结构重对齐避免空间信息损失；第二阶段，冻结一个容量混合的LLM（结合不同大小LLM的中间层），学生编码器输出作为前缀，LLM自回归生成文本，梯度仅回传至编码器。
- 训练/推理细节：
  - 训练：使用SigLIP损失（多caption）进行零样本评估和块选择；预训练第一阶段为密集蒸馏，第二阶段为生成式预训练（冻结LLM）。
  - 推理：设备延迟测量使用真实NPU/移动CPU，而非FLOPs或GPU延迟。最终模型以1.7倍速度运行（相比于基线）。

### 6. Parameter-Efficient Adaptation of SAM3 for Prompt-Driven Surgical Concept Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.23694v1
- 方法流程：
  - 输入：手术视频帧I和文本提示c（如“grasper”）
  - 步骤1：统一输入表示：将数据集原生标签映射到共享概念词汇V，形成三元组(I, mgt, c)
  - 步骤2：SAM3图像-提示编码器（含LoRA）生成联合图像文本token
  - 步骤3：DETR式检测器（含LoRA）解码概念条件化的框和掩码候选
  - 步骤4：记忆库跟踪器（含LoRA）通过记忆缓冲Bt跨帧传播掩码
  - 步骤5：通过置信度加权NMS融合检测器提议和跟踪器传播的掩码，输出最终预测masklets M
  - 输出：M = { (mk, sk, pk) }，包括二进制掩码、置信度、跟踪ID
- 关键模块/机制：
  - 统一输入表示层：将不同数据集的类别标签标准化为共享概念词汇，减少冗余提示调优；将CholecSeg8k、EndoVis18、CaDISv2的原始标签映射到统一概念字典V，每个训练样本为三元组(I, mgt, c)
  - 提示编码器（Prompt Encoder）中的LoRA：对齐手术术语与预训练文本嵌入；在交叉模态对齐层注入低秩适配器（r=16），使手术专业词汇（如L-hook electrocautery）适应预训练文本嵌入空间
  - DETR风格检测器中的LoRA：处理预训练中未见的手术器械；在所有注意力投影（q, k, v, out_proj）上应用LoRA，使检测器能够解码罕见手术物体的框和掩码
  - 跟踪器（Tracker）中的LoRA：稳定跨帧掩码传播；在跟踪注意力层添加低秩分支，适应手术视频中的运动特征，提升时序一致性
- 公式/目标函数/指标定义：
  - LoRA权重更新：W = W0 + BA，其中B∈R^(d×r), A∈R^(r×k), rank r≪min(d,k)
  - SAM3预测输出：M = { (mk, sk, pk) }_k=1^K，mk∈{0,1}^(H×W)为二进制掩码，sk∈[0,1]置信度，pk∈N跟踪ID
- 算法细节：
  - LoRA注入位置：提示编码器的交叉模态对齐层、DETR检测器的所有注意力投影（q,k,v,out_proj）、跟踪器的跟踪注意力层
  - 冻结策略：冻结视觉骨干（图像编码器）和所有未注入LoRA的组件
  - 训练配置：bf16混合精度，batch size 1，梯度累积8，AdamW优化器（β1=0.9, β2=0.999, ε=1e-8），权重衰减0.01，余弦学习率1e-4，200步预热，梯度裁剪范数1.0，训练10个epoch，选择验证mIoU最高checkpoint
- 训练/推理细节：
  - 训练：LoRA参数r=16, α=32, dropout=0.1；仅优化8.32M参数（总参数849M的0.98%）；单RTX 3090 GPU，峰值显存9GB
  - 推理：输入视频帧与文本提示，输出每个概念的二进制掩码及置信度；无需额外后处理，可直接用于下游重建和仿真

### 8. Grounded in Consensus, In Step With Emerging Science: A Consensus-Anchored Multi-Corpus Clinical Chatbot for Long COVID
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.25038v1
- 方法流程：
  - 步骤1：用户查询输入，系统始终包含共识语料库（向量相似度检索），其他三个源（PubMed、临床试验、动态系统综述）由用户选择（默认启用）。
  - 步骤2：选中的源并行检索。PubMed通过NCBI E-utilities，LLM辅助查询模块识别临床意图并构建布尔查询，应用过滤器；临床试验从ClinicalTrials.gov索引的887条记录中用查询实体排序返回短名单；动态系统综述索引74篇RCT，链接GRADE评估。
  - 步骤3：所有检索结果传递给单一合成模型（Claude Opus 4.8），围绕共识语料库框定回答，整合其他源发现。
  - 步骤4：后处理：将内联源标记转换为编号引用，去重重叠记录，渲染带标签的参考文献列表和证据卡片。
  - 步骤5：用户界面展示：先显示临床底线，内联引用，临床试验卡片等。
- 关键模块/机制：
  - 共识语料库模块：提供基础共识框架，确保回答权威性；包含8份专家共识文件，经语义分块后使用text-embedding-3-large索引，通过向量相似度检索相关段落。
  - PubMed检索模块：检索当前最新文献证据；使用NCBI E-utilities，LLM辅助查询模块识别临床意图和必要研究特征，构建布尔查询（含LC同义约束），应用出版类型和时效过滤器，返回结构化文章发现。
  - 临床试验检索模块：表征试验格局，报告干预和状态；从ClinicalTrials.gov索引的887条记录，使用查询派生的临床实体对记录排序，返回短名单（含试验状态、设计特征和可得结果摘要）。
  - 动态系统综述模块：提供高级别证据和确定性评估；索引74篇RCT（来自动态系统综述，涵盖8个干预类别），将研究与干预-结局特定GRADE确定性评估关联，展示试验级别发现和证据确定性。
  - 合成模型（Claude Opus 4.8）：整合多源证据并生成临床回复；将来自所有启用源的检索结果作为输入，围绕共识语料库框架，生成包含临床底线和内联源标记的回复。
  - 后处理模块：转换引用格式并去重渲染；应用层后处理：将内联源标记转换为编号引用，去重重叠PubMed和Living SR记录，渲染带标签的参考文献列表和证据卡片。

- 区域：quick；分数：8.0

- 方法流程：
  - 输入：测试实例包含图像x、问题q、候选答案集A；定义两种提示顺序：图像优先o_IF和问题优先o_QF。
  - 初始化：使用预训练参数θ(0)=θ0。对于每个测试实例，执行K步适应。
  - 教师计算：在第k步，用当前参数计算图像优先分布p_IF(θ(k); s)，并停止梯度得到¯p_IF(k)(s)。
  - 损失计算：计算KL散度L_align = D_KL(¯p_IF(k)(s) || p_QF(θ(k); s))，其中p_QF是问题优先分布。
  - 梯度更新：θ(k+1) = θ(k) - η ∇_θ(k) L_align。
  - 评估：完成K步后，对两个顺序评估模型，然后重置参数到θ0，处理下一个实例。
- 关键模块/机制：
  - 不对称KL散度损失：将问题优先分布对齐到图像优先分布，利用图像优先更强的特性引导问题优先方向。；损失函数为L_align = KL(¯p_IF || p_QF)，梯度仅通过p_QF传播，教师¯p_IF不接收梯度。每步重新计算教师，称为移动教师。
  - 移动教师策略：每步根据当前模型参数重新计算教师分布，使教师随模型更新而改善，避免固定教师导致过拟合。；在每步适应中，先计算当前参数下的图像优先分布并停止梯度，作为该步的教师。教师能动态提升，从而更有效地引导问题优先。
  - 参数重置与实例独立适应：确保适应无标签且独立于之前实例，保留预训练知识。；每个测试实例适应结束后，模型参数重置为初始预训练权重θ0。适应步数K较小（例如2步），学习率η适中。
  - 中层窗口适应：利用定位到的中层网络失效区域，将梯度更新限制在中层Transformer层，提高效率并减少对图像优先的负面影响。；通过激活修补确定模态顺序失败集中在中层网络。在测试时训练中，只对一层或一段中层窗口进行更新，其他层冻结。实验表明中层窗口效果最佳。
- 公式/目标函数/指标定义：
  - L_align(θ(k); s) = D_KL( p̄_IF(k)(s) || p_QF(θ(k); s) )
  - p_IF(θ; s) = softmax( z_IF(θ; s) ), p_QF(θ; s) = softmax( z_QF(θ; s) )
  - θ(k+1) = θ(k) - η ∇_θ(k) L_align(θ(k); s)
- 算法细节：
  - 对于每个测试实例，初始化模型参数为θ0。
  - 设定适应步数K=2（默认），学习率η。
  - 在第k步（0 ≤ k < K）：a) 用当前参数θ(k)分别计算图像优先和问题优先的logits z_IF和z_QF；b) 对图像优先logits应用softmax并停止梯度得到教师分布；c) 对问题优先logits应用softmax得到学生分布；d) 计算KL散度损失；e) 仅更新问题优先分支对应的参数（通常限制在中层窗口）。
  - K步后，使用更新后的模型评估两个顺序的准确率。
  - 评估完成后重置参数为θ0。
- 训练/推理细节：
  - 测试时训练仅在推理阶段进行，无需训练数据或标签。
  - 每个测试实例独立适应，参数重置避免跨实例信息泄露。
  - 适应步数K设为2（默认），学习率η通过验证集选择（如1e-5）。
  - 可限制梯度更新到特定的Transformer层窗口（如第16-24层），基于激活修补结果。
  - 教师分布使用移动教师而非固定教师，每步重新计算。

  - 原始编码器（RGB和Depth）：从预训练模型中提取完整模态特征，在ConD阶段被冻结，保留全模态知识。；分别对RGB和深度图像进行特征提取，参数固定不变，输入缺失时喂入零张量。
  - 复制编码器（Copy Encoders）：在ConD阶段学习缺失模态下的补偿特征，通过零初始化避免干扰原始特征，仅在缺失时被激活。；与原始编码器结构相同但参数独立，初始化为全零。训练时仅当对应模态缺失时才有较大梯度更新，从而学习到缺失模态下的合理特征填充。
  - 零初始化特征注入（Zero-initialized Feature Injection）：将复制编码器的输出以残差形式加到原始编码器输出上，实现特征级补偿。；设原始编码器特征为F_orig，复制编码器特征为F_copy，则最终特征F = F_orig + F_copy。训练初期F_copy接近零，不破坏全模态性能；随着缺失样本训练，F_copy逐渐学会补偿。
  - 随机模态缺失模拟：在ConD训练中按概率随机丢弃RGB或深度通道，模拟传感器故障。；每个训练步骤以概率p_rgb丢弃RGB（其余模态正常），以概率p_depth丢弃深度，以概率1-p_rgb-p_depth保留完整。丢弃时将对应输入置为零张量。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - ConD训练算法：每个batch随机选择缺失模式（完整、RGB缺失、深度缺失），根据模式构造输入。前向传播：完整模态通过原始编码器，缺失模态的原始编码器输入零，同时所有模态都通过对应的复制编码器（初始为零）。将原始特征与复制特征相加送入融合模块和分割头。计算语义分割损失（如交叉熵），反向传播更新复制编码器、融合模块和分割头，冻结原始编码器。
  - 零初始化确保训练开始时复制编码器输出为零，模型行为与预训练模型一致；随着缺失样本训练，复制编码器逐渐学习补偿，而完整模态下复制编码器梯度极小（因原始特征已足够），从而不破坏原有性能。
  - 推理时若缺失某模态，则对应原始编码器输入零，复制编码器自动提供补偿；若完整，复制编码器输出接近零，模型退化为原始模型。
- 训练/推理细节：
  - 训练分两阶段：第一阶段标准预训练（任意RGB-D语义分割方法，如ACNet、3D-Former等），第二阶段ConD微调（冻结原始编码器，仅训练复制编码器、融合模块和分割头）。
  - 超参数：缺失概率p_rgb和p_depth为超参数（文中建议设为0.2-0.5），学习率通常低于预训练阶段，训练epoch数较少（如10-20个epoch）。
  - 推理时无需改变模型结构，直接使用ConD微调后的权重，可处理任意输入完整性。

### 32. One Round Is All You Need: Analytic Federated Learning for Task-Heterogeneous Multi-Label Medical Image Classification
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.20641v1
- 方法流程：
  - 步骤1: 每个客户端使用冻结预训练编码器提取特征，计算局部充分统计量：特征自相关矩阵 X^T X 和特征-标签互相关向量 X^T y。
  - 步骤2: 服务器收集所有客户端的充分统计量，应用平衡标签投影调整类别不平衡：归一化正负贡献至相等总质量。
  - 步骤3: 服务器针对每个疾病类别 c，仅聚合标注了该类的客户端的充分统计量，通过绝对聚合法则独立求解岭回归分类器：W_c = (Σ X^T X + λI)^{-1} Σ X^T y_c。
  - 步骤4 (可选): 执行一轮解析伪标签精炼：服务器用第一轮得到的分类器作为教师，对非标注客户端的样本预测，经置信度过滤后生成伪标签；非标注客户端利用伪标签重新计算统计量并上传，服务器再次聚合更新分类器。
- 关键模块/机制：
  - 平衡标签投影：消除类别不平衡偏差；通过归一化正样本和负样本的贡献，使两者总质量相等，从而修正由于缺失标签导致的系统假阴性偏差。
  - 绝对聚合法则：独立组装每类的分类器；对于每个疾病类别，只聚合标注了该类别的客户端的充分统计量（X^T X 和 X^T y），独立求解岭回归权重，避免未标注客户端的干扰。
  - 解析伪标签精炼：传播缺失类知识；利用第一轮得到的分类器作为教师，对未标注客户端的样本生成预测，仅保留高置信度（如概率>阈值）的预测作为伪标签，然后将伪标签以监督方式用于更新客户端的统计量，再行聚合。
- 公式/目标函数/指标定义：
  - 岭回归目标：min ||XW - Y||^2 + λ||W||^2，其中X为特征矩阵，Y为标签矩阵，W为权重，λ为正则系数。
  - 平衡标签投影：通过调整正负样本权重，使正样本总贡献等于负样本总贡献。
  - 绝对聚合求解：W_c = (Σ_{k: annotating c} X_k^T X_k + λI)^{-1} Σ_{k: annotating c} X_k^T y_{k,c}
- 算法细节：
  - 客户端对本地数据用冻结编码器抽取特征，计算自相关矩阵和互相关向量。
  - 服务器按类别分别聚合：对于每个类别c，只累加标注c的客户端的统计量。
  - 对聚合后的矩阵求逆（添加正则项），得到该类别分类器权重。
  - 可选第二轮：基于第一轮分类器生成伪标签，置信度过滤后用于未标注客户端的统计量更新。
- 训练/推理细节：
  - 训练过程为解析形式，无梯度迭代，无需反向传播。
  - 推理时，输入图像经冻结编码器提取特征，然后通过所有类别分类器分别计算得分，经sigmoid得到多标签概率。
  - 通信轮次：第一轮上传统计量，可选第二轮上传伪标签更新后的统计量。

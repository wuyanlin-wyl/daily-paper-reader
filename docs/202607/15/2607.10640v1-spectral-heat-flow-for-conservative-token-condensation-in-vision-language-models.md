## 摘要
视觉语言模型（VLM）在推理时成本高昂，因为它们必须处理长序列的视觉令牌。现有的令牌剪枝方法在高压缩率下往往表现不佳，原因在于它们盲目丢弃信息、破坏空间结构或导致多样性丧失。我们提出SpecFlow，一种无需训练的框架，将范式从破坏性剪枝转向保守凝聚，严格保证空间覆盖和统计守恒以确保稳定性。将视觉令牌视为kNN图中的节点，SpecFlow (i) 通过谱热流计算稳定的重要性场以保持结构连贯性，(ii) 通过自适应空间划分分配预算以保障覆盖，(iii) 将丢弃的信息聚合到核心集接收器中以维持统计守恒。该方法即插即用，无需微调，且与FlashAttention兼容。实验证明，我们的SpecFlow在多种任务、VLM架构和剪枝比率下均优于现有最先进方法。值得注意的是，使用SpecFlow的LLaVA-1.5在剪除88.9%的视觉令牌后仍能保留原始性能的95.6%，实现了卓越的效率-精度平衡。代码已开源：https://github.com/Lzy-dot/SpecFlow

## Abstract
Vision-Language Models (VLMs) are costly at inference time because they must process long sequences of visual tokens. Existing token pruning methods often degrade under high compression by blindly discarding information, breaking spatial structure or collapsing diversity. We propose SpecFlow, a training-free framework that shifts the paradigm from destructive pruning to conservative condensation, strictly enforcing spatial coverage and statistical conservation to ensure stability. Treating visual tokens as nodes in a $k$NN graph, SpecFlow (i) computes a stable importance field via spectral heat flow to preserve structural coherence, (ii) allocates budgets via adaptive spatial partitioning to guarantee coverage, and (iii) aggregates discarded information into coreset sinks to maintain statistical conservation. The method is plug-and-play, requires no fine-tuning, and is compatible with FlashAttention. Experiments confirm that our SpecFlow outperforms SOTA methods across tasks, VLM architectures, and pruning ratios. Notably, LLaVA-1.5 with SpecFlow retains 95.6\% of original performance despite pruning 88.9\% of visual tokens, offering an exceptional efficiency-accuracy balance. Code is available at https://github.com/Lzy-dot/SpecFlow

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉语言模型（VLM）推理时成本高昂，因为视觉编码器产生大量视觉 token（如 LLaVA-1.5 的 576 个），导致预填充阶段计算量巨大。现有 token 剪枝方法（如基于注意力分数的 Top-K 选择）在高压缩率下表现不佳，有两个主要失败模式：
  - **空间碎片化**：注意力分数集中，导致选中 token 空间不连贯，在物体内部产生“空洞”，破坏物体结构。
  - **上下文缺失**：过于保留前景而激进地去除背景，损害依赖空间关系和场景语义的任务。
- **解决思路**：从“破坏性剪枝”转向“保守凝聚”，严格保证空间覆盖和统计守恒。提出 **SpecFlow**，一种无需训练的框架，通过图传播、自适应分区和核心集聚合来保留结构信息并避免信息丢失。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
将视觉 token 建模为 **kNN 图**上的节点，通过谱热流传播初始重要性，得到平滑且区域一致的重要性场；然后利用自适应四叉树分区按能量比例分配预算，保证空间覆盖；最后将丢弃的 token 压缩成两个核心集“sink” token（均值和残差），维持统计信息。

### 关键技术细节

1. **CLS-seeded 热流扩散**（Algorithm 1）
   - 初始能量来自视觉 [CLS] token 的自注意力权重：\( e^{(0)}_i = A_{0,i} \)，可选多头平均。
   - 构建 kNN 图（余弦相似度，softmax 归一化）得到行随机转移矩阵 \(W\)（式 5）。
   - 迭代扩散：\( e^{(t+1)} = (1-\alpha)e^{(0)} + \alpha W^\top e^{(t)} \)，迭代 \(T_{\text{diff}}\) 次后得到最终能量 \(e^*\)。
   - 该过程等价于优化一个平衡种子保真度和图平滑性的凸目标（式 4），有理论保证。

2. **自适应四叉树分区与能量分配**（Algorithm 2）
   - 将能量 \(e^*\) 重塑为 H×W 网格，递归划分区域：若区域大小≥2m 且能量标准差 > δ，则划分为四象限（式 8）。
   - 按叶区域能量质量比例分配 token 预算：\( \hat{q}_c = K \cdot M(c) / \sum M(c) \)（式 10），该分配对应比例公平优化（Proposition 4.1）。
   - 对每个叶区域，保留能量最高的 \(q_c\) 个 token（TopK）。
   - 整数调整：先向下取整并裁剪至区域大小，再将剩余预算按能量降序分配，确保总数为 K。

3. **Sink token 构造**
   - 对丢弃的 token 集 \(\bar{S}\)，计算均值 sink \(u_{\text{mean}} = \frac{1}{|\bar{S}|}\sum_{i\in\bar{S}} Z_i\)，以及残差 sink \(u_{\text{res}} = Z_{\arg\max \|Z_i - u_{\text{mean}}\|_2}\)。
   - 将两个 sink 追加到选中 token 序列后，形成最终视觉 token 序列 \(Z' = [\tilde{Z}; u_{\text{mean}}; u_{\text{res}}]\)。

### 流程总结
1. 利用 CLS 注意力初始化能量；
2. 在 kNN 图上进行数次热流扩散（式 2），得到平滑能量；
3. 对能量网格进行自适应四叉树划分，并按能量比例分配 token 预算；
4. 在每个叶区域选择 TopK token，并构造两个 sink 保留丢弃信息；
5. 将选中 token 与 sink 送入语言模型（兼容 FlashAttention）。

## 6. 主要结论与发现

- **SpecFlow 在所有压缩率下均取得最优或持平的平均相对性能**，例如在 LLaVA-1.5 上 66.7% 压缩时平均 98.7%，88.9% 压缩时仍达 95.6%，损失极小。
- **性能优势源于结构感知的重要性传播 + 自适应空间覆盖 + 信息保留**：图扩散避免了稀疏注意力的碎片化；四叉树保证了令牌覆盖；sink token 保留了背景和边缘信息。
- **跨架构泛化性强**：在 LLaVA-1.5、LLaVA-NeXT、Qwen2.5-VL 上均优于或相当于 SOTA。
- **训练-free 且兼容 FlashAttention**，适合实际部署。

## 7. 优点

- **无需训练、即插即用**：仅需推理时计算 kNN 图和扩散，不改变 VLM 参数。
- **理论支撑**：扩散过程有凸优化解释（Dirichlet 能量），预算分配有比例公平性保障。
- **保持空间与统计结构**：四叉树和 sink token 分别是空间覆盖和信息保存的有效手段。
- **广泛实验验证**：多个架构、压缩率、图像/视频任务，消融证明各组件必要性。
- **效率高**：附录中提供 FLOPs 对比和端到端延迟分析，验证了低开销（约 1% 延迟）。
- **开源代码**：便于复现与扩展。

## 8. 不足与局限

- **依赖中间表示**：需要从视觉编码器获取 CLS 注意力和 token embedding，不适合完全黑箱的 API 或无法暴露这些信息的模型。
- **超参数敏感**：扩散步数 \(T_{\text{diff}}\)、温度 \(\tau\)、四叉树最小尺寸 \(m\) 和阈值 \(\delta\) 等需针对模型调整，论文中仅使用统一设置（\(T_{\text{diff}}=2, m=4\)），但未讨论泛化性。作者在附录中承认需要自适应超参数。
- **视频时序未建模**：四叉树只在空间上划分，未利用时序相关性，可能限制长时间视频任务。
- **Sink token 数量固定**：仅用两个 sink（均值 + 残差），对于包含小物体、密集文本、计数等需要细粒度信息的任务可能不足。作者也提及此局限，并建议未来探索自适应 sink 数量。
- **未进行大规模系统性能测试**：虽然测量了延迟和 FLOPs，但未在更大 batch、高分辨率、长视频等场景下深入分析瓶颈。
- **偏差与安全考虑**：论文在影响声明中讨论了加速可能带来的滥用风险，但未在实际实验中评估公平性或鲁棒性。

### 2. SAMPLe: SAM-based Optimizer for Prompt Learning in VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.05727v1
- 方法流程：
  - 输入：预训练的VLM（如CLIP），可学习提示向量v，训练数据集D。
  - 第一阶段（前向）：计算当前参数θ下的损失L(θ;D)及梯度∇L(θ;D)。
  - 第二阶段（SAM扰动）：计算扰动ε* = ρ * ∇L(θ;D)/||∇L(θ;D)||。
  - 第三阶段（梯度计算）：计算在扰动点θ+ε*处的梯度∇L(θ+ε*;D)。
  - 第四阶段（约束调整）：确保SAM梯度与ERM梯度对齐，并与全批量梯度正交，计算最终更新方向。
  - 第五阶段（参数更新）：θ <- θ - η * (对齐后的梯度方向)。
- 关键模块/机制：
  - 双目标优化：同时考虑最小化训练损失和寻找平坦最小值，平衡探索与利用。；在每一步优化中，SAMPLe同时优化两个目标：最小化经验风险（exploitation）和最小化损失景观锐度（exploration），通过约束实现平衡。
  - 梯度对齐：确保SAM在扰动点的梯度与ERM梯度方向一致，避免方向冲突导致的不稳定。；通过约束SAM梯度与ERM梯度的内积为正或满足一定角度，使得更新方向不偏离最小化训练损失的方向。
  - 正交约束：约束SAM梯度与全批量梯度正交，使更新方向在保持低损失的同时探索平坦区域。；对SAM梯度施加正交于全批量梯度的约束，使得梯度分量在垂直于全批量梯度的方向上探索，促进平坦最小值。
  - 自适应平衡：根据当前优化状态自动调整对齐和正交的权重，无需手动设置超参数。；通过优化目标函数同时满足两个约束，动态调整探索与利用的比例，适应不同的优化阶段。
- 公式/目标函数/指标定义：
  - 经验损失：L(θ;D) = (1/N) Σ ℓ(f(x_i;θ), y_i) (公式3)
  - SAM min-max: min_θ max_{||ε||≤ρ} L(θ+ε;D) (公式4)
  - 近似扰动：ε* ≈ ρ * ∇L(θ;D)/||∇L(θ;D)|| (公式5)
  - 更新规则：θ_{t+1} = θ_t - η * ∇L(θ_t+ε*;D) (公式6)
  - 交叉熵损失用于提示学习：L_CE(v) = -Σ y_m log p(m|x) (公式1)
  - 条件概率：p(m|x) = exp(cos(I(x),T(t_m))/τ) / Σ exp(cos(I(x),T(t_j))/τ) (公式2)
- 算法细节：
  - 使用SAM框架，但改进了梯度计算：先计算当前参数的梯度用于扰动，再计算扰动点梯度。
  - 在每次迭代中，计算两个约束：对齐ERM梯度，以及SAM梯度与全批量梯度正交。
  - 通过优化目标函数满足这两个约束，动态调整探索与利用的平衡。
- 训练/推理细节：
  - 训练时：仅更新可学习提示向量，冻结VLM主干。
  - 使用小批量数据计算梯度。
  - 全批量梯度（full-batch gradient）用于正交约束。
  - 学习率η和扰动半径ρ为超参数。
  - 集成到多个提示学习框架（CoOp, CoCoOp, MaPLe, TCP, Co-Prompt）中，作为优化器替换。

### 3. When Structured Sparse Autoencoders Learn Consistent Concepts Across Modalities
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.08605v1
- 方法流程：
  - 输入：从VLM（Qwen2.5-VL-7B-Instruct）的某一层（如第5层）提取图像patch和文本token的残差流表示作为输入x。
  - 图像patch分组：基于Transformer注意力相似性和空间邻近性，将图像patch划分为若干语义连贯的视觉区域（分组）。
  - SAE编码：每个输入x通过编码器z = σ((x - b_dec) W_enc + b_enc)得到稀疏特征激活向量z（使用Top-K激活函数）。
  - 结构化稀疏正则化：在训练损失中加入组间独占稀疏性和组内组稀疏性，作用于z中对应图像部分的激活。
  - SAE解码：通过解码器x̂ = z W_dec + b_dec重建输入。
  - 输出：训练好的SAE特征（概念特征）用于后续的单义性评估和跨模态一致性分析。
- 关键模块/机制：
  - 图像patch分组模块：生成语义连贯的视觉区域，为结构化稀疏正则化提供分组先验；联合利用Transformer注意力相似性（计算patch间的注意力权重）和空间邻近性（欧几里得距离）对图像patch进行聚类，形成多个不相交的分组，每个分组对应一个可能的概念区域。
  - 组间独占稀疏性正则化（Exclusive Sparsity）：鼓励不同分组的SAE特征相互竞争，实现跨组解耦；对属于不同分组的SAE特征激活施加类似ℓ1,2范数的正则化，使得每个SAE特征仅在一个或少数几个分组上强激活，避免一个特征同时响应多个不同区域的概念。
  - 组内组稀疏性正则化（Group Sparsity）：鼓励同一分组内的SAE特征覆盖整个区域，提升区域一致性；对同一分组内的SAE特征激活施加组稀疏约束（如ℓ2,1范数），促使一个概念特征激活时覆盖该分组内的大部分patch，而非仅覆盖零星碎片。
  - 跨模态自动可解释性评估管道：自动化评估SAE特征的单义性和跨模态一致性；使用VLM（Qwen3-VL-8B-Instruct）将激活掩码图像转为文本描述，再与掩码文本上下文一起输入LLM（Qwen3-30B-Instruct）进行层次化总结，生成每个模态的概念解释并评估一致性。
- 公式/目标函数/指标定义：
  - Vanilla SAE目标：ℒ_vanilla = ||x - x̂||² + λ||z||₁
  - S2AE目标（结构已知）：ℒ_S2AE = ℒ_vanilla + λ_ex * exclusive_sparsity(z, groups) + λ_gr * group_sparsity(z, groups)，其中exclusive_sparsity和group_sparsity的具体形式为基于分组结构的ℓ1/ℓ2混合范数。
- 算法细节：
  - 使用Top-K SAE作为基础SAE，隐层维度N远大于输入维度D，激活函数为Top-K（保留最大的K个激活值，其余置零）。
  - 解码器权重初始化为编码器权重的转置（W_dec = W_enc^T），并辅以辅助损失利用未激活神经元重建。
  - 分组算法：对图像patch，计算自注意力相似度矩阵（从VLM的注意力层获得）和空间坐标距离，通过图分割（如谱聚类）生成分组，每个patch属于一个分组。
  - 训练时，每个batch内对图像部分的SAE特征激活向量根据分组标识分别计算exclusive sparsity和group sparsity损失。
- 训练/推理细节：
  - 训练：在Qwen2.5-VL-7B-Instruct的第5层和第15层分别训练SAE（视频文本多模态输入），使用Top-K SAE初始化技巧和辅助损失，批量大小、学习率等未提及具体数值。
  - 推理：训练好的SAE用于提取输入的概念特征，然后通过自动管道评估每个特征的激活掩码与分组区域的IoU，以及跨模态的语义一致性和单义性分数。

### 4. MedRealMM: A Real-World Multimodal Benchmark for Chinese Online Medical Consultation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09142v1
- 方法流程：
  - 阶段1: 语料构建 - 从JD Health原始咨询日志C0出发，依次经过图像筛选Φimg保留含患者上传图像咨询、完整性筛选Φcmpl去除不完整记录、部门平衡Φbal均衡科室分布、去标识化Φdeid、医生审核Φrev，得到最终语料C
  - 阶段2: MCCP提取 - 使用LLM agent对每个咨询轨迹C，遍历回合识别临床挑战点（医师响应用于收集信息/解读图像/鉴别诊断/治疗建议/风险沟通），提取该点及前文文本-图像上下文，构建单轮实例（输入：前文上下文，任务：生成医师下一响应），并通过验证器确保质量
  - 阶段3: 评分细则构建 - LLM初始生成病例特定评分细则（包含阳性标准如合理用药建议，阴性标准如无依据主张），医生评估并迭代反馈修改，最终得到批准细则R*
  - 阶段4: 自动评估 - 以评分细则为标准，使用LLM agent（Grader）对模型生成的响应进行评分，输出可解释分数
- 关键模块/机制：
  - MCCP提取框架：从真实多回合多模态咨询中提取有临床挑战性的单轮评估实例；给定咨询轨迹C = (e1,...,eT)，LLM agent遍历每个医师回合et，判断该回合是否包含信息收集、图像解读、鉴别诊断、治疗建议或风险沟通等行为。若为临床挑战点，则提取该点前所有对话回合（文本+图像）作为上下文，以生成医师该点实际响应为任务，构造实例。额外使用验证器LLM检查提取实例的合理性和完整性。
  - 医师参与迭代评分布局：生成并细化每个病例的评估细则；LLM Generator根据实例上下文生成初始细则R0，包含一组阳性标准（各带权重）和阴性标准。医师检查并反馈修改意见，生成修正后细则R1。重复此迭代直至医师满意，得到最终细则R*。细则用于后续自动评估。
  - 自动评估评分器：基于细则对模型生成的开放响应进行打分；采用LLM agent作为Grader，输入包含病例上下文、模型响应和细则R*。Grader逐条检查每个标准是否满足，输出每个标准的得分（+10、+8、+5等阳性加分，或阴性扣分），最终汇总为可解释分数。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - MCCP提取算法：LLM agent扫描咨询轨迹，对每个医师回合输出是否为临床挑战点的判断，并提取前文上下文；使用验证器过滤低质量实例
  - 评分细则迭代算法：LLM初始生成标准列表，医师以反馈形式编辑，LLM根据反馈更新列表，重复直到医师接受

### 5. LongMedBench: Benchmarking Medical Agents for Long-Horizon Clinical Decision-Making
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09322v2
- 方法流程：
  - Step 1: Event & Patient Filtering — 输入MIMIC-IV原始数据，过滤保留异常实验室结果、完整出入院记录且住院次数≥15的患者，输出355名患者、6,999次住院
  - Step 2: Event Stream Construction — 为每位患者构建事件流S={V1,...,Vn}，每次住院Vi包含Eadm_i、系列医疗事件Ek_i={ak_i, tk_i, pk_i, ok_i}、Edis_i，输出结构化事件序列
  - Step 3: Memory Dataset Generation — 基于历史访问Vi、当前访问Vj和时间戳T，生成三种记忆：Note Memory（访问级摘要）、Event Memory（所有扁平化事件）、Contextual Memory（当前访问已发生事件的LLM风格轨迹）
- 关键模块/机制：
  - Note Memory (M_N)：提供从Vi到Vj-1的访问级摘要，强调全局轨迹而非事件细节；由每次住院的出院摘要Ni组成，按时间顺序排列，作为高压缩的历史总结输入给代理
  - Event Memory (M_E)：提供从Vi到Vj-1的所有临床事件，无访问边界，形成统一患者轨迹；将所有事件扁平化为单一时间序列，每个事件包含动作、时间戳、参数和结果，用于细粒度检索
  - Contextual Memory (M_C)：模拟当前访问中截至T的即时交互状态，用于决策任务；将当前Vj中时间小于T的事件转换为(角色, 消息)对：assistant发出动作，user返回模拟临床反馈，构成对话历史
  - Factual QA：评估精确检索和时间对齐能力；从Vi中随机采样事件，以显式（含时间戳）或相对（如第2个事件）形式提问，代理需从M_E窗口（Vi前后m个访问）中恢复事实细节
  - Temporal Reasoning：评估不同粒度的时间顺序重建能力；三个子任务：事件排序（掩码并打乱事件后重新插入）、访问排序（打乱摘要后按临床进展排序）、联合排序（打乱多个访问的片段后重建全局顺序），评分使用Kendall's τ
  - Long-Horizon Decision：评估长期历史下的主动临床规划能力；包括下一动作预测（从动作空间选择）、参数预测（如选择最合适的3项实验室检查）、出院决策（是否在6小时内出院），评分使用准确率和top-k准确率，并采用时间衰减机制
- 公式/目标函数/指标定义：
  - 事件定义：Ek_i = {ak_i, tk_i, pk_i, ok_i}，其中ak_i ∈ A（动作空间），tk_i为时间戳，pk_i为动作参数，ok_i为结果
  - Kendall's τ：用于时间排序任务的评分，衡量预测顺序与真实顺序的一致性
  - 时间衰减机制：在决策任务T3-N/A中，当预测动作时间与真实时间差为0时得满分，否则按时间差衰减（具体函数未明确给出）
  - LLM-based matching score：用于Factual QA，判断答案是否覆盖所有GT关键词
- 算法细节：
  - 事件流构建：对每位患者，按时间顺序聚合所有访问，每个访问内事件按时间排序，保留异常实验室事件，忽略正常值
  - 记忆生成：Note Memory直接从出院摘要提取；Event Memory将所有历史事件按时间扁平化；Contextual Memory使用LLM将当前访问事件转换为对话格式，仅保留时间<T的事件
  - 问题生成：Factual QA从事件记忆中随机选事件，生成显式或相对问题；Temporal Reasoning从事件流中掩码事件或打乱访问序列；Long-Horizon Decision基于Contextual Memory和当前状态，生成多选问题
  - 评分机制：Factual QA用LLM判断关键词覆盖率；Temporal Reasoning用Kendall's τ；Decision任务用准确率/top-k准确率，加入时间衰减（预测动作时间与真实时间差越小得分越高）
- 训练/推理细节：
  - 未涉及模型训练，仅进行推理评估

### 6. Decoupling Language Guidance from Backbones for Text-Guided Medical Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09481v1
- 方法流程：
  - 输入：多尺度视觉特征{F^s_v}（s=8,16,32）和文本表示F_t（来自任何视觉编码器和文本编码器）。
  - SAGSG适配器处理：对每个尺度，SAGSG将(F^s_v, F_t)映射为融合特征˜F^s_v，保持空间大小和通道数不变。
  - 融合特征传递给现有解码器（UNETR风格重建路径），生成最终分割掩码。
  - 训练时应用分层粗到细监督：全局图像-文本对比损失（ITC）、多尺度辅助分割头损失（1/32,1/16,1/8分辨率）、最终边界感知损失。
- 关键模块/机制：
  - SAGSG Adapter：形状保持的跨模态融合模块，将文本语义注入多尺度视觉特征；包含掩码交叉注意力、双门控残差细化和SE通道重校准。分辨率特定门控自适应控制文本注入强度，通道重校准抑制冗余跨模态响应。输入视觉特征和文本特征，输出与输入视觉特征相同形状的融合特征。
  - Hierarchical Coarse-to-Fine Supervision Strategy：分层监督策略，分解训练目标；包含三个子目标：全局图像-文本对比对齐（ITC损失）、中间特征上的辅助分割损失（1/32,1/16,1/8分辨率）、最终边界感知损失（混合损失含Dice、Focal、Edge、Lovász-hinge）。辅助头仅在训练时使用，推理时丢弃。
  - Image-Text Contrastive (ITC) Module：全局语义对齐；通过轻量线性头投影并L2归一化到共享嵌入空间，使用对称交叉熵对比损失对齐匹配的图像-文本对。
- 公式/目标函数/指标定义：
  - Image-Text Contrastive (ITC) loss: L_ITC = 1/2 [CE(s, y) + CE(s^T, y)]，其中s是缩放余弦相似度矩阵，y是匹配对索引。
  - 混合分割损失：L_main = λ_d L_Dice + λ_f L_Focal + λ_e L_Edge + λ_l L_Lovasz，用于主预测和辅助头。
  - 辅助头损失L^s_aux使用与主损失相同的混合损失公式，但不同尺度的权重系数不同（深层增强Dice，浅层增强边界）。
- 算法细节：
  - SAGSG适配器：输入多尺度视觉特征和文本特征，通过掩码交叉注意力融合，然后经双门控残差细化，最后通过SE通道重校准模块输出。每个尺度有独立门控参数。
  - 分层监督：在1/32,1/16,1/8分辨率上附加辅助分割头，预测logits上采样到全分辨率，与真值计算混合损失。最终预测也使用相同损失。
  - 训练时使用ITC损失作为全局对齐。
- 训练/推理细节：
  - 训练时：使用分层粗到细监督策略，包括ITC损失、多尺度辅助损失和最终主损失。辅助头在训练后丢弃，推理时仅使用主分支。
  - 默认骨干：ConvNeXt-Tiny视觉编码器，CXR-BERT文本编码器，UNETR风格解码器。
  - 损失权重分配：深层特征增加Dice损失权重，浅层特征增加边界损失权重。
  - 推理时仅需SAGSG适配器后的融合特征输入解码器，无需辅助头。

### 7. Evolution of Accuracy and Visual-Cognitive Errors in a Decade of Vision-Language AI Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09654v1
- 方法流程：
  - 数据收集：从MS-COCO随机选取100张图片，另由10名研究助理从电影帧中收集100张复杂社交行为图片组成CSB数据集。
  - 描述收集：通过Amazon Mechanical Turk为每张图片收集20条人类描述。
  - 黄金标准建立：另组50名Turk工人对每张图片的5条描述进行投票（每张图片800试次），得票最多的描述作为黄金标准，其余描述按得票排名取top-4和bottom-4。
  - 模型描述生成：对9个模型（4个pre-MLLM和5个MLLM）输入相同提示，生成场景描述。
  - 相似度计算：用Gemini-SI/GPT-SI（基于Gemini/GPT嵌入的余弦相似度）计算模型描述与黄金标准的相似度作为准确度指标。
  - 错误分类：对pre-MLLM利用ResNet-101的目标检测和分类结果，结合人工判断，将错误分为五类；对MLLM由多名作者基于描述内容人工标注错误类型。
  - 统计分析：使用bootstrap重抽样评估结果变异性，比较不同模型和人类描述的性能。
- 关键模块/机制：
  - CSB数据集：提供复杂社交交互场景，用于区分模型与人类在简单场景外的能力差距。；包含100张电影场景截图，每张图包含多人复杂行为或社交互动（如拥抱、争论、合作等），由研究助理选取并经过审核，与MS-COCO形成对比。
  - 黄金标准描述投票排序机制：确保gold standard由多数人认可的最佳描述构成，减少主观偏差。；对每张图片的20条人类描述，由50名Turk工人进行800试次（每试次看图片和5条描述，选出最佳），累计票数最高者为gold standard；其余描述按票数排名，取top-4和bottom-4用于对比。
  - Gemini-SI/GPT-SI相似度指标：替代传统NLP指标，更准确衡量描述语义相似度。；使用Gemini或GPT模型生成描述文本的嵌入向量（3,072维），计算与gold standard嵌入的余弦相似度。与人工评分相关性高于BERTScore。
  - 错误分类系统：系统分析模型在视觉认知上的具体缺陷类型。；五类错误：检测错误（相关对象无边界框且未提及）、识别错误（对象错分或无关对象被误认）、幻觉（提及图片中不存在的对象）、场景理解错误（正确检测但被忽略）、空间依赖错误（描述依赖的图片区域与人类不同）。对pre-MLLM基于ResNet-101输出，对MLLM由人工判断。
- 公式/目标函数/指标定义：
  - Gemini-SI = cos_angle(v_model, v_gold) 其中v_model和v_gold分别为模型描述和gold标准描述的嵌入向量(3072维)。
  - GPT-SI类似，使用GPT嵌入。
  - 输入信息未提供明确公式。
- 算法细节：
  - 黄金标准投票算法：独立50个worker进行800试次（200图像 * 4种描述拆分），每个试次从5条描述中选最佳；累计票数排序，最高票者为gold standard。
  - 描述拆分策略：20条描述拆成4组（每组5条），每个worker在每张图上看到4组，确保每张图被50个worker评估4次，且每个worker看到不同的描述组合以避免顺序偏差。
  - 对于MLLM的错误分类，由多位作者基于描述内容与图像内容的对比逐条标注，最终通过协商确定分类。
- 训练/推理细节：
  - 模型均为预训练或公开发布版本，本研究未进行微调或重新训练。
  - MLLM推理时使用统一提示语：'Make your best guess of what might be happening in this scene in one sentence. Avoid mentioning objects that do not aid in understanding the context of the scene.'
  - OFA（pre-MLLM）使用输入文本'Describe Image'进行零样本场景描述。
  - 所有模型在标准硬件上运行，无特殊推理优化。

### 8. BiLoG-Net: A Bi-Context Location-Guided Network for Breast Mass Segmentation and Malignancy Classification in Mammography
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10188v1
- 方法流程：
  - 输入预处理：乳腺X线图像归一化、裁剪至固定尺寸（如512×512）
  - 编码器：使用Fire模块（SqueezeNet变体）逐步下采样提取多尺度特征图
  - 双上下文建模：对编码器输出分别经过GFEM（捕获长程依赖）和LFEM（保留边界细节）
  - 自适应门控融合：ALAG模块根据空间位置自适应融合GFEM和LFEM输出，生成位置感知特征
  - 解码器：对称上采样，通过跳跃连接与编码器特征拼接，逐步恢复分辨率，输出分割概率图
  - 分类分支：对解码器最深层的特征图进行全局平均池化，结合分割掩码引导的注意力，输出恶性/良性概率
- 关键模块/机制：
  - Fire模块：轻量特征提取骨干；由squeeze层（1×1卷积降维）和expand层（1×1和3×3混合卷积）组成，参数量少，用于编码器各阶段提取多尺度特征。
  - 全局特征增强模块 (GFEM)：捕获长程上下文依赖；采用非局部注意力或自注意力机制，计算特征图所有位置之间的相似性，生成全局上下文向量，加强远距离像素关联。
  - 局部特征增强模块 (LFEM)：保留边界敏感细节；使用多尺度空洞卷积或小核卷积组合，聚焦局部邻域特征，增强边缘和纹理信息，防止下采样导致细节丢失。
  - 自适应位置感知门控 (ALAG)：动态融合全局与局部特征；输入为GFEM和LFEM输出，通过可学习的门控权重（由当前位置特征生成）加权求和，实现空间自适应融合。
  - 分割引导分类 (SGC)：利用分割信息提升分类准确性；将解码器最后的分割掩码通过逐元素乘法应用于分类分支的全局特征图上，强调病灶区域，抑制背景噪声。
- 公式/目标函数/指标定义：
  - 联合损失函数：L_total = λ_seg * L_seg + λ_cls * L_cls，其中L_seg为Dice损失或交叉熵损失，L_cls为二元交叉熵损失
  - 输入信息未提供明确公式
- 算法细节：
  - Fire模块编码：输入图像经过多个Fire模块，每个Fire模块执行squeeze→expand操作，步长2进行下采样
  - GFEM实现：对编码器最后一层特征图，采用自注意力机制计算注意力权重，加权求和获得全局上下文增强特征
  - LFEM实现：使用并行的3×3和5×5空洞卷积核（膨胀率=2）提取多尺度局部特征，然后拼接并通过1×1卷积降维
  - ALAG门控：将GFEM和LFEM特征在通道维度拼接，通过一个小型网络（如1×1卷积+sigmoid）生成空间门控图，再分别与两路特征相乘后相加
  - 解码器上采样：每级使用双线性插值或转置卷积，与编码器对应层通过跳跃连接拼接
- 训练/推理细节：
  - 端到端联合训练，优化器使用Adam，初始学习率1e-4，权重衰减1e-5
  - 数据增强：随机旋转、翻转、弹性变形、亮度对比度调整
  - 输入尺寸：512×512，批量大小因GPU内存而定（如8或16）
  - 损失平衡：λ_seg=1.0，λ_cls=0.5（推测，原文未明确）
  - 推理时只需单次前向传播，同时得到分割掩码和分类概率

### 11. Spectral Heat Flow for Conservative Token Condensation in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10640v1
- 方法流程：
  - 输入视觉token嵌入Z和CLS自注意力A，构建kNN图并计算转移矩阵W
  - 从CLS注意力多头的平均值得到初始能量种子s
  - 通过迭代扩散e ← (1-α)s + αW^T e得到平滑重要性场E
  - 自适应四叉树划分图像空间，按区域总能量比例分配保留预算
  - 基于E在每区域内选取能量最高的token保留，其余剪除
  - 将剪除的token加权平均生成sink token，并额外保留一个能量最高的锚点token
- 关键模块/机制：
  - HeatFlow：通过谱热流扩散初始能量，得到区域连贯的重要性场；在kNN图转移矩阵W上迭代执行e^{(t+1)} = (1-α)s + αW^T e^{(t)}，其中s为CLS注意力种子，α为扩散系数，迭代Tdiff步后得到平滑能量e。
  - Adaptive Quadtree Partitioning：保证空间覆盖，避免重要性集中在局部区域；递归将图像等分为四个子区域，直到区域大小或能量阈值满足条件；然后在每个区域按能量比例分配保留token数量，确保所有区域都有代表。
  - Coreset Sink Aggregation：统计守恒：将剪除token的信息聚合到少量sink token中，减少信息损失；对每个区域被剪除的token，取其特征向量的加权平均（权重为能量）作为sink token；此外保留一个能量最高的原始token作为锚点，维护多样性。
- 公式/目标函数/指标定义：
  - 重启扩散更新：e^{(t+1)} = (1-α)e^{(0)} + αW^⊤ e^{(t)}
  - 扩散稳态的等价目标函数：e* = argmin_e 1/2 ||D^{-1}e - D^{-1}e^{(0)}||_D^2 + α/(2(1-α)) (D^{-1}e)^⊤(D-S)(D^{-1}e)

  - CLS注意力种子初始化：e^{(0)}_i = A_{0,i}，可选多个头平均
- 算法细节：
  - 算法1：CLS-seeded heat flow：遍历每个batch b，从CLS注意力的选定的头取平均得到s，归一化；构建kNN图转移矩阵W；迭代Tdiff步：e ← (1-α)s + αW^⊤ e，并归一化；最终输出扩散能量E
  - 自适应四叉树划分：从整图开始，递归分割直到区域边长或总能量小于阈值；对每个区域，计算总能量占全图的比例，分配保留token数（至少1个）
  - 核心集聚合：对于每个区域中不保留的token，计算加权特征均值（权重为扩散能量）作为sink token；额外保留该区域能量最高的一个token作为锚点，构成最终保留集合

### 12. Mixture of Cognitive Experts in Large Vision-Language Models

- 方法流程：

  - 阶段1 - 专家选择与感知：LLM-guided router选择相关视觉专家，产生结构化感知输出。
  - 阶段2 - Literal Evidence Summary：对每个专家输出进行原子言语化，分解为短文本证据语句并附带元数据，形成统一证据存储E。
  - 阶段3 - Bloom Verbalization：基于E和q，Bloom言语器生成Bloom结构化草稿答案y_Bloom，包含分步推理和证据引用。

- 关键模块/机制：

  - Reasoning Trace Module：定量分析推理轨迹。；解析y_Bloom中步骤标记和证据引用，恢复起始认知层级、执行过的Bloom步骤、每步引用的证据集以及证据类型使用频率，输出结构化轨迹T˜。

  - E = {e_i}_{i=1}^M, e_i = (id_i, type_i, text_i, ref_i) (3)：统一证据存储。

- 算法细节：
  - 路由选择：LLM对查询编码后通过提示决定启用哪些专家（例如，涉及文本则激活OCR专家）。
  - 原子言语化：DETR输出（框+标签）被转换为“存在[标签]在[坐标]”的短句；OCR输出转换为“文本“[内容]”位于[框]”；SAM掩码转换为区域描述。
  - Bloom言语化：在提示中设定Bloom六层结构，LLM逐步生成，每步强制要求引用证据id。
  - 轨迹解析：正则表达式或结构化解析从y_Bloom中提取步骤编号、层级标签和引用证据列表。
- 训练/推理细节：
  - 推理时集成：使用预训练LLaVA（CLIP-L + Vicuna-7B）作为骨干，直接注入专家输出和Bloom草稿。
  - 无需额外训练：所有专家模型和LLM均为预训练，路由器、言语器和轨迹模块通过输入提示实现。
  - Bloom提示设计：在系统提示中定义Bloom层级和输出格式，引导生成结构化中间推理。

### 32. Segmentation before Answering: Pixel Grounding for MLLM Visual Reasoning
- 区域：quick；分数：7.0

- 方法流程：
  - Stage 1: 像素定位 (Pixel Grounding) - 输入: 图像+文本描述（如“Segment the 'food wrapped up closest to plate' in the image”）；处理: MLLM生成<|seg|> token，提取其隐藏状态，经MLP投影器映射到SAM2.1掩码解码器，解码得到分割掩码；输出: 像素级分割掩码。

  - Stage 3: 带像素定位的推理 (Reasoning with Pixel Grounding) - 输入: 多步推理轨迹（包含<|seg|>分割步骤）；处理: 使用强化学习优化模型在推理中主动进行分割以获得更精确细节；输出: 正确答案。
- 关键模块/机制：
  - <|seg|> token：接口标识，用于触发分割操作并提取对应隐藏状态。；在MLLM前向传播时，模型生成<|seg|> token，提取该token最后一层的隐藏状态，作为分割信号的输入。
  - Projector（MLP）：将MLLM的隐藏状态映射到SAM2.1掩码解码器的输入空间。；简单的多层感知机，训练初期仅更新此模块以对齐特征，后期联合微调。
  - Mask Decoder（SAM2.1）：根据投影后的特征解码生成像素级分割掩码。；采用SAM2.1的掩码解码器，输入为经过投影器映射的token特征，输出为二值分割掩码。解码过程包括多个Transformer层和动态掩码预测头。
  - LoRA：对MLLM进行参数高效微调。；在Stage1第二阶段应用Low-Rank Adaptation，仅训练低秩矩阵，最后合并到主干参数中。
- 公式/目标函数/指标定义：
  - 训练目标：\( \mathcal{L} = \mathcal{L}_{\text{NTP}} + \mathcal{L}_{\text{seg}} \)，其中 \( \mathcal{L}_{\text{NTP}} \) 为下一个词预测损失，\( \mathcal{L}_{\text{seg}} \) 为SAM2.1组合损失。
  - SAM2.1损失：\( \mathcal{L}_{\text{seg}} = \lambda_1 \mathcal{L}_{\text{focal}} + \lambda_2 \mathcal{L}_{\text{dice}} + \lambda_3 \mathcal{L}_{\text{IoU}} + \lambda_4 \mathcal{L}_{\text{obj}} \)，分别对应focal loss、dice loss、IoU预测的MAE损失和对象预测的交叉熵损失。
- 算法细节：
  - 分割步骤：MLLM生成<|seg|> token → 提取隐藏状态 → MLP投影 → SAM2.1掩码解码器 → 输出二值掩码。
  - 位置索引保持：分割后的图像块保留其在原图中的位置索引(h,w)，使得稀疏的掩码块仍能反映空间关系。
  - 强化学习推理：在Stage3，模型生成包含<|seg|>操作的推理轨迹，根据最终答案的正确性使用奖励函数（如正确+1，错误-1）进行策略梯度优化。
- 训练/推理细节：
  - 训练分三阶段：Stage1包括两阶段——先冻结MLLM和SAM2.1仅训练投影器，再对MLLM应用LoRA并联合训练投影器、SAM2.1和LoRA层。
  - Stage1结束后LoRA权重合并到MLLM中。
  - Stage2使用多轮对话数据，模型在中间步骤执行分割，将分割后图像作为新视觉输入。
  - Stage3使用强化学习（如GRPO或PPO）优化模型的分割决策和推理能力。
  - 推理时，模型可主动生成<|seg|> token来分割感兴趣区域，并使用分割后的图像和原始图像共同推理。

  - M2O损失算法: 对每个OBB实例，通过逐元素乘分离预测掩码，旋转变换对齐坐标轴，两个正交方向的最大投影压缩形状信息，保留位置和尺寸，最后反变换回原空间进行损失计算

## 摘要
预训练的视觉语言模型（如CLIP）已被证明作为各种下游应用的基础模型非常有效。然而，视觉语言模型中的提示学习面临着性能-泛化困境：虽然可以调整提示以在已见分布上实现高精度，但这种调整过程往往会削弱其对未见数据的泛化能力。有限的可学习提示集，用于对输入进行上下文化调节以引导其朝向预训练VLM中的任务，往往过度拟合训练数据，导致任务特定性能与保持泛化之间的权衡。为了解决这一困境，我们引入了SAMPLe（锐度感知最小化提示学习），一种即插即用的锐度感知优化器，通过考虑损失景观锐度来增强提示的泛化能力。与传统方法不同，SAMPLe通过每一步满足目标函数约束来平衡探索与利用，基于局部曲率和梯度属性动态适应当前优化状态。这种方法减少了对已见分布的过度拟合，提高了对未见数据的适应性，保留了预训练VLM模型的泛化潜力。我们将SAMPLe集成到多个提示学习框架中，包括CoOp、CoCoOp、MaPLe、TCP和Co-Prompt，展示了其在不同方法中的有效性。实验表明，SAMPLe提升了提示学习框架，并在各种设置中始终优于现有优化器，确立了其作为提示学习的稳健、模型无关解决方案的地位。

## Abstract
Pre-trained Vision-Language Models (VLMs) like CLIP have proven highly effective as foundation models for various downstream applications. However, prompt learning in VLMs encounters a performance-generalization dilemma: while prompts can be tuned to achieve high accuracy on seen distributions, this tuning process often undermines their generalizability to unseen data. The limited set of learnable prompts, which contextualize and condition the input to steer it toward the task within the pretrained VLM, tends to overfit the training data, leading to a trade-off between task-specific performance and preserving generalization. To address this dilemma, we introduce SAMPLe (Sharpness-Aware Minimization Prompt Learning), a plug-in sharpness-aware optimizer that enhances prompt generalizability by accounting for loss landscape sharpness. Unlike conventional methods, SAMPLe balances exploration and exploitation by satisfying objective function constraints at each step, dynamically adapting to the current optimization state based on the local curvature and gradient properties. This approach reduces overfitting on seen distributions and improves adaptability to unseen data, preserving the generalization potential of pre-trained VLM models. We integrate SAMPLe into multiple prompt learning frameworks, including CoOp, CoCoOp, MaPLe, TCP, and Co-Prompt, demonstrating its effectiveness across diverse methods. Experiments show that SAMPLe elevates prompt learning frameworks and consistently outperforms existing optimizers across diverse settings, establishing itself as a robust, model-agnostic solution for prompt learning.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**: 视觉语言模型（如CLIP）在下游任务中常采用提示学习（Prompt Learning）方式，即通过少量可学习提示（prompt）适配预训练模型，而无需全模型微调。然而，提示学习面临**性能-泛化困境**：提示在已见分布上可达到高精度，但极易过拟合，导致对未见类别或分布泛化能力下降。
- **背景**: 有限的可学习参数空间使得优化过程对损失景观的锐度高度敏感，容易收敛到尖锐最小值（sharp minima），从而损害泛化。现有方法（如CoOp、CoCoOp等）虽通过正则化或图像条件化改进泛化，但很少从优化器层面显式考虑损失景观的锐度。SAM（Sharpness-Aware Minimization）是一种寻找平坦最小值的通用优化框架，但直接应用于提示学习时存在全批梯度偏差，限制探索能力。
- **整体含义**: 本文提出SAMPLe，一种专为提示学习设计的锐度感知优化器，通过动态平衡“利用（低训练损失）”和“探索（平坦最小值）”，在保持已见分布精度的同时显著提升对未见分布的泛化能力。

## 2. 方法论
### 核心思想
- 将提示学习视为一个双目标优化问题：既要在训练数据上达到低损失（exploitation），又要寻找损失景观中的平坦区域（exploration）。
- 基于SAM框架，但通过梯度分解和自适应约束，使SAM扰动后的梯度与**批特定梯度（batch-specific gradient）**对齐，同时与全批梯度正交，从而消除全批梯度对探索的抑制作用，实现动态平衡。

### 关键技术细节
- **梯度分解**: 将小批量梯度分解为沿全批梯度方向的分量和正交于全批梯度的批特定分量：
  \[
  \nabla L(\theta; \mathcal{D}) = \nabla^{\mathcal{B}}L(\theta; \mathcal{D}) + \xi\sigma \nabla^{\mathcal{F}}L(\theta; \mathcal{D})
  \]
  其中 \(\nabla^{\mathcal{F}}L\) 由EMA近似，\(\xi\) 为余弦相似度，\(\sigma\) 为范数比。
- **SAMPLe目标函数**:
  \[
  \min_\theta \left[ L(\theta) + L(\theta + \epsilon^* - \alpha \nabla^{\mathcal{B}}L(\theta)) \right]
  \]
  其中 \(\epsilon^*\) 为SAM标准扰动，\(\nabla^{\mathcal{B}}L = \nabla L - \xi\sigma \nabla^{\mathcal{F}}L\)。
- **算法流程**（算法1）:
  1. 初始化提示参数 \(\theta_0\)。
  2. 每步迭代：采样小批量，计算梯度 \(\nabla L(\theta_t)\)；更新EMA全梯近似 \(m_t\)；计算SAM扰动 \(\epsilon_t^*\)；计算余弦相似度 \(\xi_t\) 和归一化因子 \(\sigma_t\)；构造目标函数 \(L(\theta_t) + L(\theta_t + \epsilon_t^* - \alpha_t \nabla^{\mathcal{B}}L)\)；执行梯度下降更新。
- **理论保证**: 定理1证明在K-Lipschitz和梯度有界假设下，SAMPLe收敛率为 \(O(\log T / \sqrt{T})\)，与SGD等一阶方法相当。

## 6. 主要结论与发现
- SAMPLe在所有测试设置下**一致优于**SAM、F-SAM、SAGM及原始基线，显著提升谐波均值（HM）和未见类精度，同时保持基类精度。
- 在Base-to-New场景中，各提示学习方法（CoOp、CoCoOp、MaPLe等）集成SAMPLe后，平均HM提升1～2个百分点（例如CoOp从77.65提升至78.88）。
- Cross-Dataset和Cross-Domain泛化实验中，SAMPLe同样带来稳定增益，平均精度提升0.5～1.5个百分点。
- 超参数敏感性分析显示SAMPLe对扰动半径和EMA衰减更加鲁棒，相比F-SAM和SAGM方差更小。

## 7. 优点
- **模型无关与即插即用**: SAMPLe可作为优化器直接替换任何提示学习框架中的优化器，无需修改模型结构。
- **动态自适应平衡**: 通过梯度对消机制，自动根据当前优化状态调整“探索-利用”平衡，避免固定超参数导致的次优。
- **理论收敛保证**: 提供了与一阶方法同阶的收敛率证明。
- **实验充分且公平**: 在多数据集、多场景、多基线下进行系统对比，消融实验验证各组件贡献。
- **泛化提升显著**: 尤其在新类/未见分布上提升明显，同时不牺牲基类性能。

## 8. 不足与局限
- **计算开销**: SAM需要两次前向传播（计算扰动点和更新点），SAMPLe在此基础上增加了EMA和梯度分解计算，虽增加不大但仍有额外计算代价，文中未对比训练时间。
- **对EMA的依赖**: 全批梯度近似依赖EMA，在训练早期或数据分布剧烈变化时可能不准确，影响性能。
- **超参数调优**: 虽然SAMPLe对\(\rho\)和\(\lambda\)更鲁棒，但仍需针对不同方法调整（表5），未完全实现无超参数自适应。

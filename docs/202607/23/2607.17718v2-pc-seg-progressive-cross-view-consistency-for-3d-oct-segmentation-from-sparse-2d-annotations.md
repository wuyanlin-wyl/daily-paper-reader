## 摘要
光学相干断层扫描（OCT）图像的体积分割对于诊断眼部疾病至关重要，但需要耗费大量人力进行体素级标注。虽然半监督学习（SSL）可以降低标注成本，但现有方法大多逐切片处理数据，未能利用固有的三维空间上下文。我们提出PC-Seg，一种渐进式跨视角一致性框架，能够从稀疏的二维标注中学习高精度的三维分割模型。与传统多视角方法不同，PC-Seg使用单一二维模型从标准B扫描和正交切片中学习跨视角一致性，从而生成可靠的三维伪标签。这些伪标签随后被蒸馏到三维模型中，再进入协同训练阶段，其中二维和三维模型通过集成伪标签相互优化。在MSHC和Duke DME数据集上的实验表明，PC-Seg在使用仅约0.7%训练数据的标注时，达到了与全监督学习相当的精度，优于现有最先进的半监督和视网膜层分割方法。我们的代码开源在https://github.com/gsisaoki/pc-seg-official。

## Abstract
Volumetric segmentation of optical coherence tomography (OCT) images is essential for diagnosing ocular diseases but requires labor-intensive voxel-wise annotations. While semi-supervised learning (SSL) can reduce annotation costs, most existing methods process data slice by slice and fail to exploit the inherent 3D spatial context. We propose PC-Seg, a progressive cross-view consistency framework that learns high-accuracy 3D segmentation models from sparse 2D annotations. Unlike conventional multi-view approaches, PC-Seg uses a single 2D model to learn cross-view consistency from standard B-scans and orthogonal slices, thereby generating reliable volumetric pseudo-labels. These pseudo-labels are then distilled into a 3D model, followed by a co-training stage in which the 2D and 3D models mutually refine each other through ensemble pseudo-labeling. Experiments on the MSHC and Duke DME datasets demonstrate that PC-Seg achieves accuracy comparable to fully supervised learning while using labels for only about 0.7% of the training data, outperforming state-of-the-art semi-supervised and retinal layer segmentation methods. Our code is publicly available at https://github.com/gsisaoki/pc-seg-official.

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- **渐进式课程学习**：通过五阶段课程学习策略，逐步扩展目标维度和视角，从2D B扫描 → 正交切片 → 3D体积，生成并利用高质量的伪标签，抑制误差累积，最终实现2D/3D模型协同优化。
- **跨视角一致性**：使用单一2D模型学习标准B扫描与正交切片之间的跨视角一致性，生成可靠的3D伪标签，再蒸馏至3D模型，最后通过集成伪标签进行2D/3D协同训练。

### 关键技术细节
1. **基线架构与SSL框架**：
   - 采用残差U-Net（ResUNet）作为基础模型（2D和3D版本，深度=4，基础通道数=32）。
   - 基线与SSL框架使用UniMatch[29]——一种弱到强一致性正则化方法：对未标注图像弱扰动生成伪标签（置信度阈值τ），然后计算多强扰动预测与伪标签之间的无监督一致性损失。总损失为监督损失与一致性损失的加权和（均用交叉熵）。
2. **PC-Seg的五阶段课程学习**：
   - **Stage 1（2D热身）**：在标注和未标注的B扫描切片上训练2D模型。结束时用该模型预测所有B扫描，生成正交切片的初始伪标签。
   - **Stage 2（适应正交切片）**：引入未标注的正交B扫描切片，利用Stage 1生成的伪标签。对正交切片计算四种扰动（1弱+1特征级+2强）下的预测与伪标签的一致性损失。结束时用最佳权重预测所有正交切片，生成为Stage 3准备的B扫描伪标签。
   - **Stage 3（正交交叉教学）**：在正交平面间进行交叉教学，即一个平面的伪标签由另一个平面的预测生成。结束时集成两个平面的预测，生成高质量3D伪标签。
   - **Stage 4（知识蒸馏至3D模型）**：在稀疏标注和未标注的体积数据上，以Stage 3生成的3D伪标签为指导，半监督训练3D模型。标注切片处的伪标签替换为真值。结束时集成2D两平面预测和3D预测，得到进一步精化的3D伪标签。
   - **Stage 5（2D/3D协同训练）**：交替训练2D和3D模型，动态更新集成伪标签（来自两模型预测），实现联合优化。
3. **动态阈值调整**：在Stage 4和5中，对病变类别的置信度阈值从0.95动态降至0.5，以增强对低置信度病理区域的学习（因集成预测更鲁棒）。

## 3. 实验设计
### 数据集与场景
- **MSHC数据集**：35个体积（14健康+21多发性硬化），每体积49张B扫描（496×1024像素），标注9个层边界。按12训练/3验证/20测试划分，经视网膜展平（至128像素高度）和裁剪为128×128块。半监督设置：随机选6、30或60个标注块（约0.07%、0.3%、0.7%），其余视为未标注。推理使用滑动窗口（128×128×48 voxels，重叠1/3）。
- **Duke DME数据集**：10个体积（糖尿病黄斑水肿患者），每体积61张B扫描（496×768像素），标注8个层边界和液体区域。按6训练/2验证/2测试划分，展平后随机裁剪为224×224×48。半监督设置：66标注B扫描（每体积11 slices），剩余300未标注。推理使用滑动窗口（224×224×48，重叠1/3）。

### Benchmark与对比方法
- **全监督方法**：Structured-Layer、1D+2D U-Net、Language、Alignment、ReLayNet、Y-Net、TCCT、SA CNN、GD-Net、标准U-Net。

- **通用半监督框架**：SemiVL、UniMatch（以ResUNet为骨架）。

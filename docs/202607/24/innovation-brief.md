### 1. Cura 1T: Specialized Model for Agentic Healthcare
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.15314v1
- 方法流程：
  - 计划阶段：训练代理定义目标行为、选择基准与指标、设计数据方案、提出超参数，经人类审核
  - 训练阶段：先SFT验证数据混合和超参数稳定性，然后RL，最后SDFT（自蒸馏微调）
  - 评估阶段：运行基准测试，收集轨迹，分析失败原因
  - 精炼阶段：根因分析，针对性地综合和筛选数据，提出下一步建议，人类决定保留或回退
  - 部署：经过多轮循环积累的验证数据混合用于最终模型训练
- 关键模块/机制：
  - 训练代理：自动规划和管理进化循环，选择目标能力、设计数据方案、发起训练、评估结果、提出改进；在每个进化轮次中，训练代理根据人类指导或自主制定计划，定义目标行为和评估指标，设计数据配方，建议超参数，并在训练后评估模型轨迹，分析失败模式，改进数据混合。
  - 训练堆栈（SFT→RL→SDFT）：按顺序执行监督微调、强化学习和自蒸馏微调，实现模型参数更新；SFT作为低成本验证步骤，确认数据混合和超参数可行；RL进一步优化；SDFT通过KL散度最小化学生分布与特权上下文教师分布的距离，防止长链推理时发生遗忘。
  - SDFT（自蒸馏微调）：利用模型自身生成轨迹和特权上下文进行知识蒸馏，稳定长推理链；目标函数 L(θ)=D_KL(π_θ(·|x) ∥ π(·|x,c))，其中c是特权上下文（如干预后的轨迹、参考行为等），学生仅见原始提示x。通过最小化KL散度，模型学习生成更接近教师分布的轨迹。
  - 数据精炼流水线：从失败轨迹中分析根因，针对性地合成和筛选数据，形成持续改进的数据混合；包含Reasoning Correction（推理纠正）、Knowledge Injection（知识注入）、Behavior Calibration（行为校准）、Retention Anchors（保留锚点）、Skill-driven Data Synthesis（技能驱动数据合成）等操作，经格式检查、安全与PII过滤、数据去重后加入混合。
  - 人类审核门控：在计划阶段和执行后决策阶段引入人类判断，确保进化安全且有效；人类审核计划后才能开始训练；评估后人类决定保留（继续迭代）、回退（反思并重计划）或部署（模型训练完成）。
- 公式/目标函数/指标定义：
  - SDFT目标函数：L(θ) = D_KL(π_θ(·|x) ∥ π(·|x,c)) = E_{y~π_θ(·|x)} [log π_θ(y|x) / π(y|x,c)]，其中π_θ为学生分布，π为特权上下文教师分布，x为提示，c为特权上下文。
- 算法细节：
  - 每轮进化：训练代理规划 → SFT验证 → RL → SDFT → 评估 → 根因分析 → 数据精炼 → 人类审核
  - SDFT实现：学生采样y ~ π_θ(·|x)，教师使用特权上下文c生成参考分布，通过梯度下降最小化KL散度
  - 数据混合管理：每个保留的轮次贡献其验证的数据精炼，累积到综合混合中，避免单次更新破坏其他能力
- 训练/推理细节：
  - 基础模型：Kimi-K2.6
  - LoRA秩：32
  - 学习率：3×10^{-4}，线性调度
  - 批次大小：128
  - 序列长度：256K tokens
  - 训练周期：6个epoch，带早停

### 2. One Modality to Forget Them All: Enhancing Cross-Modal Unlearning in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16442v1
- 方法流程：
  - 数据准备：分别使用PKU-SafeRLHF（文本有害）、JailbreakV-28K（视觉有害）作为遗忘集，TruthfulQA（文本）、VQA-v2（视觉）作为效用保持集，FigStep等作为跨模态评估集
  - 模型选择：采用三种VLM架构（LLaVA-1.5-7B、InstructBLIP-7B、IDEFICS-9B），所有模型加载4-bit NF4量化
  - 干预点控制：定义四种条件（视觉仅、融合仅、LLM仅、融合+LLM），只在指定组件应用LoRA适配器
  - 遗忘训练：使用QLoRA，仅更新LoRA参数，优化器AdamW，1000迭代，batch size 2
  - 评估：同模态评估（遗忘模态X测试X）、跨模态评估（遗忘模态X测试Y），使用ASR_TS、ASR_LG和效用指标
  - CrossInf选择：基于模型特定度量（如梯度或影响函数）计算每个Transformer块对跨模态泛化的贡献，选择前k个关键块进行强化遗忘
- 关键模块/机制：
  - CrossInf模块：指导遗忘应聚焦于哪些Transformer块以最大化跨模态转移减少；通过计算每个Transformer块对跨模态泛化性能的影响（例如使用梯度或近似影响函数），选择影响最大的多个块，在遗忘过程中对这些块施加更高的学习率或更强的更新约束。
  - 干预点控制 (Intervention Point Control)：隔离每个架构组件（视觉编码器、融合模块、LLM）对跨模态遗忘转移的作用；在QLoRA微调中，只对指定组件添加可训练LoRA适配器，其他组件冻结。四种条件：vision-only、fusion-only、LLM-only、fusion+LLM。
  - VLM架构（三种）：提供不同融合机制以对比跨模态转移行为；LLaVA-1.5: 2层MLP投影；InstructBLIP: Q-Former压缩为32个查询token；IDEFICS: 门控交叉注意力（Flamingo风格）。
- 公式/目标函数/指标定义：
  - ASR_TS = (1/N) * ∑_{i=1}^N (1 - 𝟙_refuse(r_i))，其中𝟙_refuse(r_i)=1若响应包含28种拒绝子串之一
  - ASR_LG = (1/N) * ∑_{i=1}^N 𝟙_unsafe(r_i)，其中𝟙_unsafe由Llama-Guard-4多模态分类器判定
  - VQA准确率 Acc_VQA = (1/N) * ∑_{i=1}^N min(|{j: â_i ∈ a^(j)_i}| / 3, 1)
  - Fleiss's κ = (p_o - p_e) / (1 - p_e)，用于人类评估一致性
- 算法细节：
  - CrossInf算法：在每个训练步骤前，计算各Transformer块对跨模态损失的影响（如通过Hessian向量积或梯度点积），按影响分数排序，对前k个块的学习率放大λ倍。具体影响度量在输入片段中未详述。
  - QLoRA：4-bit NF4量化基模型，仅训练LoRA（rank=32, α=16, dropout=0.05），优化器AdamW，学习率3e-4，梯度裁剪1.0
  - 干预点控制：根据条件设置可训练模块，例如LLM-only条件只在语言模型的LoRA层更新，视觉和融合冻结
- 训练/推理细节：
  - 所有模型加载4-bit NF4量化，使用QLoRA微调
  - 训练超参数：1000迭代，batch size 2，AdamW (lr=3e-4, weight decay=0.01, gradient clip norm=1.0)
  - 推理时使用Llama-Guard-4-12B在4-bit下分类安全
  - 人类评估：3名标注者，250个样本（175共享），Fleiss' κ=0.77

### 3. Look Clearly Before Answering: Mitigating Hallucinations in LVLMs via Saliency-Driven Perceptual Realignment
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16841v1
- 方法流程：
  - 输入：图像I和查询Q，通过视觉编码器和投影得到视觉token，与系统提示S拼接。
  - 阶段1：Saliency-Driven Attention Redistribution (SDAR)：在语言主干的多头自注意力层中，基于梯度显著性计算每个注意力头的sink程度，然后调整注意力权重，将注意力从sink token重分配到语义显著的视觉token。
  - 阶段2：Saliency-Driven Cache Alignment (SDCA)：在KV缓存中，利用查询相关的显著性图（从SDAR获得）加权key缓存，以增强查询相关视觉特征的检索。
  - 阶段3：Prior-Constrained Contrastive Decoding (PCD)：从早期解码层的隐藏状态构建语言先验参考分布，对比当前logits，惩罚被语言先验主导的预测，得到最终输出。
  - 输出：生成的文本回答。
- 关键模块/机制：
  - Saliency-Driven Attention Redistribution (SDAR)：纠正多模态交互阶段的注意力劫持，恢复关键视觉证据。；在每个注意力头计算梯度显著性，识别sink head（高gini系数和top-1注意力集中度），然后通过重加权或掩码方式，将注意力从非语义的sink token（如背景区域）重新分配到语义显著的视觉token（如人物、物体）。具体实现：对每个头，计算每个token对模型输出的贡献（梯度×注意力），然后根据贡献度调整注意力分布。
  - Saliency-Driven Cache Alignment (SDCA)：缓解KV缓存中视觉表示的位置依赖失真，保留查询相关的视觉特征。；在预填充阶段，将SDAR得到的查询相关显著性图注入到key缓存中，具体通过对每个视觉token的key进行加权（权重来自显著性图），使得后续解码时，与查询更相关的视觉token具有更高的注意力权重。
  - Prior-Constrained Contrastive Decoding (PCD)：抑制语言先验主导的预测，确保解码忠实于视觉证据。；在解码每一步，从早期解码层的隐藏状态（如第0层或前几层）计算一个语言先验参考分布（通常偏向语言模式），然后使用对比解码公式：logits_final = logits_original - λ * logits_prior，其中λ是超参数，从而惩罚那些被语言先验主导但缺乏视觉支持的token。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式。
- 算法细节：
  - SDAR算法：1) 对每个注意力头，计算梯度显著性：∂loss/∂A (A为注意力权重)；2) 计算每个头的注意力集中度指标（Gini系数、top-1/5/10比例）；3) 识别sink head（注意力集中度高于阈值）；4) 对sink head，将注意力从sink token重分配到视觉token（根据显著性分数加权）。
  - SDCA算法：1) 从SDAR获得每个视觉token的显著性分数；2) 在预填充阶段，对每个视觉token的key向量的每个维度乘以对应的显著性分数（或使用门控机制）；3) 存放到KV缓存中。
  - PCD算法：1) 在解码第t步时，获取当前层的隐藏状态h_t和早期层（如第一层）的隐藏状态h_0；2) 通过语言模型头计算两个logits：logits_full和logits_early；3) 计算对比logits：logits_cont = logits_full - λ * logits_early；4) 对logits_cont进行softmax得到最终概率分布。
- 训练/推理细节：
  - 无需训练，直接应用于预训练LVLM的推理阶段。
  - SDAR和SDCA在预填充阶段执行，PCD在自回归解码步骤中执行。
  - 额外计算开销小：仅增加梯度显著性计算和KV缓存加权，无额外模型训练。

### 4. Searching for Task-Specific Vision Paths: Evolutionary Block Pruning Across Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17052v1
- 方法流程：
  - 1. 初始化：从总视觉块集（Qwen:32块, SmolVLM2:27块）中随机采样若干候选路由（每组包含K个块索引）。
  - 2. 评估：对每个候选路由，将对应视觉块替换为恒等映射（跳过），在开发集上计算每个能力-源单元格的配对损伤∆。
  - 3. 源平衡目标：对于共享路由，计算均值损伤μ、最差源损伤w、源间标准差σ；对于能力特定路由，额外计算目标能力的均值μt、最差wt、标准差σt，以及非目标能力的平均附带损伤κ。
  - 4. 进化选择：使用多目标Pareto排序（共享：最小化(μ,w,σ)；能力特定：最小化(μt,wt,κ,σt)），并采用锦标赛选择、交叉和变异生成下一代。
  - 5. 最终路由：进化结束后，使用标量损失L（共享：L=0.50μ+0.30w+0.20σ；能力特定：L=0.45μt+0.30wt+0.15κ+0.10σt）对Pareto前沿候选手动排序，选取L最小的路由。
  - 6. 输出：固定K块的路由索引，在推理时跳过对应块，其余块正常计算。
- 关键模块/机制：
  - 源平衡配对评估：公平评估路由对不同能力-数据源组合的影响，避免大样本源主导指标。；将测试集按能力c和数据源d分成单元格Ic,d，计算每个单元格的配对精度∆c,d(S)=100×(A0_c,d - A(S)_c,d)。共享路由的损伤向量为(μ, w, σ)，其中μ=所有单元格∆的均值，w=最大单元格∆，σ=单元格∆的标准差。
  - 进化搜索算法：在不微调前提下，通过进化优化找到固定预算的块路由。；采用实数编码（块索引的集合），种群大小、交叉率、变异率等超参数通过初步实验确定（论文未给出具体数值，但描述为锦标赛选择、单点交叉、随机变异）。进化代数为固定值（如50代），每代评估所有候选路由的损伤向量，保留Pareto非支配解。
  - 能力特定目标函数：针对目标能力优化路由，同时通过附带损伤项约束对其他能力的破坏。；对于目标能力t，定义目标单元格损伤μt, wt, σt，以及非目标单元格的均值损伤κ。进化时最小化(μt, wt, κ, σt)，最终标量损失Lt=0.45μt+0.30wt+0.15κ+0.10σt。
- 公式/目标函数/指标定义：
  - 配对损伤：∆c,d(S) = 100 × (A0_c,d - A(S)_c,d)，其中A0是全模型精度，A(S)是路由S的精度。
  - 共享路由损伤向量：q_shared(S) = (μ(S), w(S), σ(S))，其中μ(S)=|G|^{-1}∑_g ∆g(S)，w(S)=max_g ∆g(S)，σ(S)=√(|G|^{-1}∑_g (∆g(S)-μ(S))²)。
  - 共享路由标量损失：L_shared(S) = 0.50μ(S) + 0.30w(S) + 0.20σ(S)。
  - 能力特定路由目标损伤：μ_t(S)=|T_t|^{-1}∑_{g∈T_t} ∆g(S)，w_t(S)=max_{g∈T_t} ∆g(S)，σ_t(S)=√(|T_t|^{-1}∑_{g∈T_t}(∆g(S)-μ_t(S))²)。
  - 附带损伤：κ_t(S)=|C_t|^{-1}∑_{g∈C_t} ∆g(S)。
  - 能力特定标量损失：L_t(S) = 0.45μ_t(S) + 0.30w_t(S) + 0.15κ_t(S) + 0.10σ_t(S)。
- 算法细节：
  - 进化搜索采用源平衡目标，共享路由的适应度由均值、最差源、源标准差三个维度共同决定，通过Pareto排序选择非支配解。
  - 能力特定路由额外考虑附带损伤κ，防止路由为了目标能力而严重损害其他能力。
  - 最终路由选择时，使用固定系数的标量损失对Pareto前沿所有解排序，选取损失最小的路由。
  - 搜索过程在开发集（904样本）上进行，最终路由在分离的876样本上评估，但876样本并非完全密封（因为参与过早期单块发现）。
- 训练/推理细节：
  - 训练：无训练，模型权重不变。搜索过程仅在开发集上评估候选路由，不需要梯度更新。
  - 推理：对于每个输入（图像+问题），跳过选定的一组视觉块（替换为恒等映射），其余块正常计算。共享路由对所有问题使用同一组跳过块；能力特定路由根据已知的能力标签选择对应路由。
  - 批量大小：推理时批量大小为1，使用确定性贪婪解码。

### 5. Understanding From Human Perspective: A Multi-agent System for Interactive Egocentric Medical Image Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17341v1
- 方法流程：
  - 输入：用户指令和egocentric视频流。
  - 阶段1-目标确认工作流：Detection Agent检测当前帧候选目标，Confirmation Agent将指令与候选目标接地并计算可靠性得分；若得分高于阈值则直接确定用户意图目标，否则请求用户澄清，从而确认分割目标。
  - 阶段2-定位引导传播工作流：在视频帧序列中，Propagation Agent从目标初始位置传播掩码，Detection Agent每帧重新定位目标；系统评估传播掩码与定位结果的一致性，若分歧则重新初始化传播。
  - 输出：每帧的目标分割掩码。
- 关键模块/机制：
  - Detection Agent：检测候选目标并在每帧重新定位目标；使用现成的目标检测模型（如YOLO）从当前帧中检测所有可能的医学目标，输出候选框和类别；在传播阶段每帧重新定位用户意图目标的位置。
  - Confirmation Agent：将指令与候选目标接地并评估可靠性；使用现成的视觉-语言接地模型（如GroundingDINO）将指令与Detection Agent输出的候选目标进行匹配，输出每对匹配的可靠性得分；当最高得分低于阈值时触发用户澄清。
  - Propagation Agent：从初始位置传播掩码并维持时间连续性；使用现成的视频分割模型或掩码传播模型（如SAM with memory）从确认的目标首帧掩码开始，逐帧传播掩码；当检测与传播结果不一致时，从检测位置重新初始化传播。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 目标确认工作流：用户指令输入后，Detection Agent提取候选目标，Confirmation Agent计算指令与每个候选的接地可靠性得分，若最高得分≥阈值则直接确认目标，否则系统生成澄清问题（如“左肾还是右肾？”）等待用户回答后重新接地。
  - 定位引导传播工作流：每帧中，Propagation Agent基于上一帧掩码传播当前帧掩码，同时Detection Agent重新检测目标位置；计算传播掩码与检测框的IoU或中心距离，若差异超过阈值则将传播掩码替换为检测框引导的掩码（如通过SAM生成），并更新传播状态。

### 6. Retrieval-Augmented Interpretable Learning: Towards Task-Specific Zero-Shot Models in Healthcare
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17508v1
- 方法流程：
  - 输入: 自然语言任务描述和任务特征矩阵。
  - 步骤1: 任务编码: 用语言模型将任务描述编码为任务嵌入向量。
  - 步骤2: 检索: 基于任务嵌入度量学习计算与源任务集中每个任务的相似度，通过Gumbel-Softmax松弛得到检索索引的后验分布。
  - 步骤3: 系数先验构建: 根据检索结果，从记忆模块中读取对应源任务的系数后验统计量，组合成目标任务系数的条件先验。
  - 步骤4: 变分推断: 在目标任务（有标签或零样本）上，优化系数后验的变分参数，使得后验接近先验，并通过ELBO目标平衡数据似然和KL正则。
  - 输出: 系数后验分布（均值向量、方差向量）和检索后验分布；预测时可采样系数得到线性预测。
- 关键模块/机制：
  - 检索模块 (Retrieval Module)：根据任务描述从源任务记忆中选择相关任务，生成检索索引后验分布。；使用语言模型将任务描述编码为嵌入，与源任务嵌入计算余弦相似度；通过Gumbel-Softmax重参数化得到分类分布的后验概率π_post，与均匀先验π_prior（或基于频率的先验）计算KL散度。
  - 系数生成模块 (Coefficient Generator)：将检索到的源任务系数结构转移到目标任务，生成任务的系数先验和变分后验分布。；假设系数服从对角高斯分布：先验μ_ϕ,σ^2_ϕ由检索到的源任务后验均值加权组合得到（例如加权平均），后验μ_q,σ^2_q通过一个小型神经网络（或直接参数化）输出，方差与先验绑定（σ^2_q = σ^2_ϕ），简化KL计算。
  - 不确定性校准模块 (Uncertainty Calibration)：量化预测不确定性，标记不稳定预测或解释。；通过系数后验的方差和检索后验的熵计算不确定性信号，低置信度时触发人工审查。
- 公式/目标函数/指标定义：
  - ELBO目标函数（负变分自由能）：L(θ, I) = E_q[log p(y|x,θ)] - β_θ KL(q(θ)||p(θ|I)) - β_I KL(q(I)||p(I))
  - 系数KL散度（简化后）：KL(q(θ)||p(θ|I)) = 1/2 ∑_r (μ_q,r - μ_ϕ,r)^2 / σ^2_ϕ,r
  - 检索KL散度：KL(q(I)||p(I)) = ∑_j π_post,j log(π_post,j / π_prior,j)
  - 数据项：BCE(y, σ(θ^T x))，二分类交叉熵。
- 算法细节：
  - 使用Gumbel-Softmax松弛使检索索引可微，梯度可通过分类分布反向传播。
  - 系数后验的均值参数直接优化，方差参数与先验绑定，减少参数数量并强制锚定。
  - 训练时每个minibatch从系数后验中采样一个系数，计算数据项和KL项，使用重参数化技巧。
  - 推理时，直接使用后验均值作为系数预测，同时输出方差和检索熵作为不确定性指标。
  - 记忆模块存储每个源任务学习后的系数后验统计量（均值和方差），更新方式为在线更新或冻结。
- 训练/推理细节：
  - 训练：元学习阶段，在多个源任务上训练检索编码器和系数生成器，优化ELBO；目标任务阶段，对于有少量标签的目标任务（few-shot），微调系数后验并可能更新检索编码器。
  - 零样本推理：直接使用自然语言任务描述，检索后利用预训练的先验（不更新），采样系数预测。
  - 超参数：β_θ和β_I控制KL权重，实验中设为1。
  - 优化器：Adam，学习率等未提供。

### 8. Advancing Multimodal Fusion on Heterogeneous Medical Data with Hybrid Geometry Attention
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.19086v1
- 方法流程：
  - 阶段1: Multimodal Shared Information Learning (MSIL) —— 输入：m个异构模态数据（成像或非成像）；处理：将非成像数据重塑为伪图像张量，然后依次通过m个HyFuse层，每个层处理一个模态并渐进融合；输出：模态顺序不变鲁棒共享表示x^C。
  - 阶段2: Heterogeneous Modality-Specific Multitask Learning (HMML) —— 输入：共享表示x^C；处理：用于多个下游任务（如多疾病分类、患者生存预测）；输出：各任务预测结果。
- 关键模块/机制：
  - Efficient Multimodal Residual Convolution (EMRC)：在HyFuse层中逐步细化多模态表示，捕获多尺度特征。；包含Modality-specific Heterogeneous Convolutions Fusion (MHCF)块，使用组逐点卷积（GPC）、膨胀深度可分离卷积（DDC）、深度可分离卷积（DWC）和通道混洗，结合不同尺度卷积核（1x1,3x3,5x5），通过GeLU激活和残差连接。
  - Hybrid-Space Aware Attention Mixer (HySAM)：学习粗到细的结构线索，生成混合空间感知共享注意力图。；包含Multimodal Hyperbolic Dual-Geometry Attention (MHDGA)和Multimodal Quantum-Inspired Attention (MQIA)，两者输出的注意力图通过MAFG（Multimodal Attention Fusion Gate）进行融合（加法或Hadamard积），生成共享注意力图A_i。
  - Shared Information Refinement (SIR)：对HySAM产生的共享表示进行细化，增强表征多样性。；在HyFuse层中，将HySAM输出的共享表示通过SIR模块（包含加法融合和批归一化）得到细化后的共享表示x̂^S_i。
  - 可学习晚期融合 (Complementary Learnable Late-Fusion)：以模态顺序不变的方式融合各模态的共享表示。；在MSIL阶段最后，使用可学习参数对各模态细化后的共享表示进行加权融合，得到最终鲁棒共享表示x^C。
- 公式/目标函数/指标定义：
  - 训练目标：分类任务使用交叉熵损失（Cross-Entropy Loss），生存预测使用负对数似然损失（Negative Log-Likelihood Loss）。
  - 优化器：Adam，初始学习率1e-3，调度器ReduceLROnPlateau降至1e-6。
- 算法细节：
  - 非成像数据（如多组学/EHR）重塑为伪图像张量（R^{H_i×W_i×C_i}）以适配统一处理。
  - MSIL阶段按模态顺序依次处理：对每个模态i，当前融合表示与模态i特征通过HyFuse层进行融合。
  - HyFuse层内：先通过EMRC提取多尺度特征，再通过HySAM学习注意力图并与原始特征结合，然后通过SIR细化，最后与累积共享表示残差连接。
  - 不同模态顺序实验表明CURE对模态顺序不敏感（表8）。
  - 适配16个数据集，根据模态类型分为四个训练组，每组同时训练多个流。
- 训练/推理细节：
  - 所有模型训练200个epoch，单卡NVIDIA A100 80GB GPU。
  - Dropout概率p=0.25应用于融合后用于正则化。
  - 数据增强：标准增强（具体未列出），图像resize至128×128×3（某些实验224×224×3）。
  - 训练/验证/测试划分：80/10/10，5个随机种子报告均值±标准差。

### 10. LAVIFT: Latent-Action-Guided Vision Fine-Tuning for Surgical Interaction Recognition
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.19889v1
- 方法流程：
  - 输入：视频帧序列和对应文本描述，预训练视觉编码器（如ViT）和文本编码器（如CLIP）
  - 阶段1 - 逆动力学建模：从连续帧的视觉特征中预测潜动作，通过逆动力学模型学习动作引起的视觉变化
  - 阶段2 - 前向世界模型：基于当前帧特征和潜动作预测下一帧特征，迫使编码器关注动作区域
  - 阶段3 - SIG正则化：在补丁特征上施加结构相似度正则化，防止局部邻域特征坍塌
  - 阶段4 - 联合训练：结合逆动力学损失、前向模型损失、SIG损失和对比损失（图像-文本对齐）微调视觉编码器
- 关键模块/机制：
  - 逆动力学模型（Inverse Dynamics Model）：从相邻帧特征中推断潜动作，捕捉动作引起的视觉变化；将t帧和t+1帧的视觉特征拼接，通过小型MLP预测潜动作向量，训练目标为最小化预测潜动作与真实动作标签（若存在）或通过对比学习约束。
  - 前向世界模型（Forward World Model）：基于当前帧特征和潜动作预测下一帧特征，驱动编码器学习动作相关表示；将当前帧的视觉特征和逆动力学模型预测的潜动作作为输入，通过另一个MLP预测下一帧特征，使用L2损失或余弦相似度约束预测与真实下一帧特征一致。
  - 补丁级SIG正则化（Patch-level SIG Regularizer）：避免补丁特征在空间上趋于一致，增强局部多样性；对每个图像补丁的特征计算其与空间相邻补丁的相似度（如余弦相似度），引入正则化项使相邻补丁特征差异保持在一定范围内，防止坍塌。
- 公式/目标函数/指标定义：
  - 逆动力学损失：L_inv = ||a_pred - a_gt||^2 或基于对比学习的InfoNCE损失
  - 前向模型损失：L_fwd = ||f_{t+1} - pred(f_t, a_pred)||^2
  - SIG正则化：L_sig = Σ_{i,j} sim(z_i, z_j) 的约束项（具体细节未提供明确公式）
  - 总损失：L = L_inv + L_fwd + L_sig + L_clip（图像-文本对比损失）
- 算法细节：
  - 逆动力学模型：输入连续两帧的视觉特征（来自编码器），输出潜动作向量
  - 前向世界模型：输入当前帧特征和潜动作，输出下一帧预测特征
  - SIG正则化：对每个补丁特征计算与其空间邻域补丁的相似度，施加惩罚使相似度不过高
  - 联合优化：随机采样视频帧对，计算各部分损失并反向传播更新编码器和两个模型
- 训练/推理细节：
  - 训练时：冻结文本编码器，只微调视觉编码器和逆动力学/前向模型小网络
  - 使用视频帧对（t, t+1）作为训练样本，同时需要文本描述进行对比学习
  - 推理时：仅使用微调后的视觉编码器提取特征，逆动力学和世界模型可丢弃

- 关键模块/机制：

  - 移动教师机制（Moving Teacher）：教师每步随模型更新而变化，比固定初始教师更好；在第k步，使用当前参数θ(k)计算图像优先分布，并通过stop_grad截断梯度，作为第k步的教师。
  - 层窗口适配（Layer Window Adaptation）：将梯度更新限制在特定层范围，基于激活补丁定位的中部区域；根据激活补丁实验，顺序失败集中在网络中部连续层；测试时训练仅对中部层窗口进行更新，加速收敛并提升效果。
- 公式/目标函数/指标定义：
  - L_align(θ; s) = D_KL( stopgrad(p_IF(θ; s)) || p_QF(θ; s) )
  - 更新规则: θ^{(k+1)} = θ^{(k)} - η ∇_θ L_align(θ^{(k)}; s) for k=0,...,K-1
- 算法细节：
  - 对每个测试实例，首先使用当前模型参数计算两种顺序的logits，应用softmax得到分布。
  - 令图像优先分布梯度停止，作为固定教师；计算其与问题优先分布的KL散度。
  - 对KL散度关于模型参数求梯度，执行一步SGD更新（论文中K=1步即够）。
  - 更新参数后，用新参数重新计算问题优先分布（用于评估）；之后重置参数为初始状态。
  - 在层窗口消融中，限制梯度更新仅作用于指定层范围（如第14-25层）。
- 训练/推理细节：
  - 测试时训练，无需标签或额外数据，仅利用单个测试实例。
  - 每个实例独立进行适应，处理后重置参数。
  - 默认使用K=1步（表4显示1步即可），学习率η很小。
  - 教师每步重新计算（moving teacher）优于固定教师。
  - 不对称目标（仅更新问题优先分支）比对称目标（同时更新两个分支）效果更好。

  - 步骤2：对于每个放射学发现c，在校准集上计算每个通道j的选择性分数˜A_{c,j}（基于正负样本对中值比较的胜率减去0.5）。
  - 步骤3：按˜A_{c,j}降序排列，选取top-K通道构成集合S_Kc。
  - 步骤4：在校准集上，计算S_Kc上正负样本均值差方向w_c，并归一化。
  - 步骤5：对每个测试体积，提取其S_Kc上的子向量，与w_c做点积得到连续分数score_c(i)。
  - 步骤6：在校准集上搜索每个发现c的阈值τ_c（最大化F1或基于ROC左上角点），将连续分数转为二值检测d_{i,c}=I(score_c(i) ≥ τ_c)。
  - 步骤7：将所有二值检测向量di输入模板报告生成器，得到最终报告。
- 关键模块/机制：
  - CCP-K探测模块：从冻结嵌入中提取每个放射学发现的稀疏通道及其检测分数。；对每个发现c，计算每通道的˜A_{c,j}（等于AUROC-0.5），取top-K通道，然后计算这些通道上正负样本均值差方向w_c，测试时用该方向投影得到分数。整个过程仅需校准集，无需训练。
  - 因果消融模块：验证所选通道的必要性。；对于源发现c，将其top-K通道置零后重新计算所有发现的AUROC，计算目标发现AUROC下降量Δ_{c→c'}，然后计算平均自身下降与平均非自身下降的差值作为selectivity指标，越大说明通道专有性越强。
  - 模板报告生成模块：根据检测向量生成结构化放射学报告。；从训练报告中提取最频繁的FINDINGS模板T0和每个发现最常出现的正向句子u_c。测试时，根据检测向量d_i，删除T0中对应于未发现发现的句子，添加u_c用于阳性发现，并生成IMPRESSION部分。
- 公式/目标函数/指标定义：
  - 选择性分数：˜A_{c,j} = (1/(|P_c||N_c|) ∑_{p∈P_c}∑_{n∈N_c} I(x_{p,j} > x_{n,j})) - 0.5
  - 均值差方向：w_c = (μ^P_{S_Kc} - μ^N_{S_Kc}) / ||μ^P_{S_Kc} - μ^N_{S_Kc}||
  - 连续得分：score_c(i) = ⟨x_i,{S_Kc}, w_c⟩ = ∑_{j∈S_Kc} x_{i,j} w_{c,j}
  - 二值检测：d_{i,c} = I(score_c(i) ≥ τ_c)
  - 消融指标：sel = (1/C) ∑_c (Δ_{c→c} - (1/(C-1))∑_{c'≠c} Δ_{c→c'})
- 算法细节：
  - 通道排名基于逐通道AUROC的变形（中心化到0），对类别不平衡鲁棒。
  - 均值差投影避免了最小二乘拟合对不平衡的敏感，且是闭式解。
  - 阈值校准：报告生成时用最大化F1的阈值，分类时用ROC左上角最近点阈值。
  - 因果消融通过将top-K通道置零后重新计算AUROC，比较自身下降与跨发现下降的差异。
  - K的选取：在训练集保留集上网格搜索，选最小K使得AUROC与全通道相差不超过0.005。
- 训练/推理细节：
  - 整个方法无训练，仅需校准集（约600-800样本）进行通道排名、均值差计算和阈值校准。
  - 推理时模型和探测器完全冻结，仅需提取嵌入并计算与预存w_c的点积。
  - 报告生成同样无需训练，基于语料库模板编辑。

### 23. IoUPD: IoU-Aware Privileged Distillation for Visual Grounding with Multimodal Large Language Models

- 原文链接：https://arxiv.org/abs/2607.15732v1
- 方法流程：

  - 将ŷ作为蒸馏目标序列，在ŷ的每个token位置计算教师分布与学生的KL散度，并对每个token赋予权重w̄_t
  - 权重w̄_t综合IoU（预测框与真实框的IoU）、坐标误差（各坐标差值）、数字位置（高位权重高）、教师置信度（熵）以及师生一致性（分布KL散度）

  - SFT锚点损失：确保学生不偏离真实坐标答案，保留基本监督；在真实响应序列y*上计算标准自回归交叉熵损失，L_sft = -Σ log pθ(y*_t | xs, y*_<t)
  - IoU感知token加权策略：将蒸馏损失与几何定位质量对齐；对于学生当前解码的响应序列ŷ，解析为预测框b̂，计算每个token t的权重w_t = exp(γ·factor_t)，其中factor_t综合：(1) IoU基准g_IoU = IoU(b̂, b*)，(2) 坐标误差系数c_t = |b̂_j - b*_j|（根据token对应坐标轴），(3) 数字位置权重p_t（高位数字权重更大），(4) 教师置信度r_t = 1 - H(p_T)/log V（H为分布熵，V为词表大小），(5) 师生一致性d_t = KL(p_T || p_student)；之后对序列内权重归一化得w̄_t
  - 加权特权蒸馏损失：将教师分布的知识迁移到学生，并聚焦于定位关键token；L_kd = Σ_t w̄_t · KL(p_T(· | xt) || p_student(· | xs))，其中KL在ŷ序列的token位置上计算
- 公式/目标函数/指标定义：
  - SFT损失: L_sft = - Σ_{t∈Y*} log pθ(y*_t | xs, y*_<t)
  - 蒸馏损失: L_kd = Σ_t w̄_t · D_KL(p_T(· | xt) || p_θ(· | xs))
  - 总损失: L = L_kd + α L_sft，其中α为平衡系数
  - token权重w_t = exp(γ · factor_t)，factor_t = g_IoU + c_t + p_t + r_t + d_t（各分量具体定义见原文）
  - 教师置信度r_t = 1 - H(p_T)/log V
- 算法细节：
  - 每个mini-batch迭代：对每个样本，构建学生输入xs和教师输入xt，格式化真实坐标为y*，学生自回归解码得到预测坐标字符串ŷ（教师停止梯度）

  - 解析ŷ为预测框b̂，计算与真实框b*的IoU，并根据token所属坐标轴和数字位置计算每个token的几何权重
  - 计算教师分布熵和师生分布KL散度作为可靠性因子，组合成最终权重
  - 在ŷ序列上计算加权KL散度L_kd，在y*上计算L_sft
  - 总损失L = L_kd + α L_sft，反向传播更新学生参数
- 训练/推理细节：
  - 训练：教师模型与学生同架构，从相同基座检查点初始化，训练期间冻结，不更新；学生可训练
  - 训练：SFT损失在真实坐标字符串上计算，蒸馏损失在学生自回归解码的当前序列上计算（on-policy）
  - 推理：仅使用原始图像和原始提示，不叠加框、不使用特权提示、不使用教师分支或额外预测模块
  - 推理：学生以标准自回归方式生成坐标，无需特殊解码策略

- 算法细节：
  - 稀疏性计算：对第一个去噪步骤的MLP输出，计算每个token维度上的零值比例，得到稀疏性向量s ∈ [0,1]^N。
  - 边界检测：对s进行滑动窗口分析，计算每个位置k的SNR：SNR(k) = (mean(s[:k]) - mean(s[k:]))^2 / (var(s[:k]) + var(s[k:]))，选择SNR最大的k作为边界。
  - 截断：将所有后续去噪步骤的序列长度固定为L（边界位置），丢弃超过L的token，仅计算前L个token的注意力与MLP。
  - 混合执行：在批处理中，根据每个样本的实际长度L_i动态分配计算资源，采用bucket-based lowering，将相似长度的样本放入同一patch，避免全局最大长度padding。

  - 混合执行策略适用于批处理推理服务器，提升并发吞吐。

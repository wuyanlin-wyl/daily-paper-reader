## 摘要
交互式自我中心医学图像分割（IEMIS）在智能眼镜辅助的医学图像审阅中扮演重要角色，从临床医生的视角分割其所指的医疗目标。一旦成功，其提供的对象级视觉证据会加强审阅，支撑细粒度分析和临床决策。然而，指令和视频均来自用户的自我中心视角，这带来了两个挑战：（1）语义模糊性使得模型无法确认用户意图的目标。（2）视觉变异性导致分割在帧间跳跃。本文中，我们提出EgoMed-Agent，一种通过两个工作流从人类视角理解目标的多智能体系统。（1）“目标确认工作流”将指令与候选目标基于可靠性分数进行关联，当关联可靠时确认目标，否则请用户澄清，从而确认分割目标。（2）“定位引导传播工作流”将掩码传播与逐帧目标定位相结合，当两者出现分歧时使用定位的目标来纠正传播的掩码，从而确保分割在整个自我中心视频中始终对准目标。大量实验表明，EgoMed-Agent达到了71.34%的平均Dice分数，远高于最佳文本提示基线（11.70%）。我们的代码可在 https://github.com/wdyyyyyy/EgoMed-Agent 获取。

## Abstract
Interactive egocentric medical image segmentation (IEMIS) plays an important role in smart-glasses-assisted medical image review, segmenting the medical targets a clinician refers to from their egocentric view. Once it succeeds, the object-level visual evidence it provides strengthens the review and underpins fine-grained analysis and clinical decision-making. However, the instruction and the video both come from the user's egocentric perspective, which poses two challenges. (1) Semantic ambiguity leaves the model unable to confirm the user-intended target. (2) Visual variability makes the segmentation jump from frame to frame. In this paper, we propose EgoMed-Agent, a multi-agent system that understands the target from the human perspective through two workflows. (1) The \textit{Target Confirmation Workflow} grounds the instruction against candidate targets with a reliability score, confirming the target when the grounding is reliable and asking the user to clarify when it is not, thereby confirming the segmentation target. (2) The \textit{Localization-Guided Propagation Workflow} couples mask propagation with per-frame target localization, using the localized target to correct the propagated mask whenever the two diverge, so the segmentation stays on the target across the egocentric video. Extensive experiments show that EgoMed-Agent reaches 71.34\% average Dice, far above the best text-prompted baseline (11.70\%). Our code is available at \href{https://github.com/wdyyyyyy/EgoMed-Agent}{our project page}.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：在智能眼镜辅助的医学图像审阅场景中，医生通过自我中心（egocentric）视角观看屏幕上的医学图像，并发出自然语言指令（如“分割右肾”），希望系统能实时分割出所指的医疗目标。这种交互式自我中心医学图像分割（IEMIS）为医生提供对象级视觉证据，支撑细粒度分析与临床决策。
- **核心问题**：从自我视角出发的交互存在两个固有挑战：
  1. **语义模糊性**：用户指令常缺失区分性细节（如“分割肾脏”未指定左或右），模型难以唯一确定用户意图。
  2. **视觉变异性**：头部运动、视角变化和光照变化导致目标在帧间位置、尺度和形状剧烈变化，分割结果在帧间不稳定（抖动或漂移）。
- **研究动机**：现有文本提示分割方法（如Grounded SAM2、LangSAM、LISA、MedSAM3等）直接将指令映射到像素掩码，无法处理模糊指令且对视觉变异性脆弱；而单一模型难以同时解决这两个耦合问题。因此，作者提出将IEMIS分解为两个子任务，由多智能体系统协同完成。

## 2. 方法论

### 2.1 核心思想

提出**EgoMed-Agent**，一个多智能体系统，包含三个专门智能体（检测智能体、确认智能体、传播智能体），设计两个协作工作流：
- **目标确认工作流**（Target Confirmation Workflow）：基于可靠性评分，确认或通过用户澄清明确分割目标。
- **定位引导传播工作流**（Localization-Guided Propagation Workflow）：将掩码传播与逐帧目标定位耦合，当两者不一致时用定位结果纠正传播掩码，保持分割在目标上。

### 2.2 关键技术细节

- **检测智能体 (Detection Agent)**：配备工具包，包含针对CT、MRI、超声、X光、内镜五类影像的专用检测器（基于YOLO26）。首先对初始帧进行影像类型分类，选择对应检测器，输出候选目标集（类别+边界框）。
- **确认智能体 (Confirmation Agent)**：基于DeepSeek-V4-Flash大语言模型，将用户指令与候选目标进行关联，输出关联结果（目标ID）和**可靠性分数** s。若 s ≥ τ₁（阈值设为0.8），则直接确认目标；否则请求用户澄清（如“左肾还是右肾？”），根据用户回答确定最终目标。
- **传播智能体 (Propagation Agent)**：基于SAM2（原始权重，无需微调），从被确认目标的初始边界框出发，生成首帧掩码并向后传播，实现时间连续性。
- **一致性评估 (Consistency Evaluation)**：对每一帧，检测智能体输出目标定位框 blocᵢ，同时将传播智能体输出的掩码转换为传播框 bproᵢ。计算二者IoU，若IoU < τ₂（阈值设为0.6），则认为传播漂移，用检测定位框重新初始化传播智能体，纠正偏差。

### 2.3 算法流程（文字说明）

1. **交互循环**：医生发出指令I，智能眼镜获取自我中心视频流V₁:ₜ，系统需输出对应掩码序列M₁:ₜ。
2. **目标确认**：
   - 检测智能体对首帧提取候选目标集O。
   - 确认智能体关联指令与O，得到（θ*, s）。
   - 若s≥τ₁，则θ=θ*；否则向用户澄清，得到θᵣ。
3. **定位引导传播**：
   - 用检测智能体在首帧定位θ的边界框，初始化传播智能体得到首帧掩码。
   - 对于后续每帧vᵢ：
     - 传播智能体生成预测掩码m_proᵢ，转换为bproᵢ。
     - 检测智能体输出blocᵢ。
     - 计算IoU(bproᵢ, blocᵢ)：
       - ≥τ₂：继续传播。
       - <τ₂：用blocᵢ重新初始化传播智能体。
4. 输出最终掩码序列。

## 6. 主要结论与发现

1. **EgoMed-Agent在所有指令引导方法中表现最佳**：平均Dice 71.34%，远超最佳基线MedSAM3（11.70%），且每个目标均显著优于所有基线（p<0.001）。接近全监督nnU-Net（81.69%）而无须针对分割任务训练。
2. **直接接地自由文本到掩码在IEMIS中不可靠**：文本提示基线<12%平均Dice，SAM3在多数目标上无效（平均0.17%），表明开放词汇文本接地难以转移到自我中心医学解剖目标。
3. **目标确认工作流有效解决语义模糊性**：通过可靠性评分和澄清机制，在200条指令上达到100% GSA和100% TCA（使用DeepSeek-V4-Flash）。
4. **定位引导传播工作流有效抑制视觉变异性**：与仅传播或仅检测相比，耦合二者带来显著提升（平均Dice从50.46%/59.27%提升至71.34%）；一致性评估能及时纠正传播漂移。
5. **系统运行近实时**：10.7 FPS，支持交互式辅助。

## 7. 优点

- **问题分解巧妙**：将语义模糊性与视觉变异性解耦为两个工作流，符合人类审阅逻辑（先确认目标，再跟踪分割），降低单一模型复杂度。
- **训练免费**：分割核心（SAM2、DeepSeek）使用预训练权重，仅检测器需针对模态微调，但整体不需要端到端分割训练，易于推广到新影像类型。
- **鲁棒性高**：通过可靠性评估和澄清主动处理模糊指令，而非依赖指令的完备性；通过一致性评估容忍检测误差，但利用检测结果纠正传播漂移。
- **实验充分且公平**：基线性方法包括当前主流文本提示分割模型，评估指标全面（Dice、GSA、TCA），消融实验清晰展示组件贡献。
- **实际场景模拟**：数据集涵盖多种影像类型、真实环境、头部运动，贴近临床使用。

## 8. 不足与局限

- **检测工具箱依赖特定训练**：每个模态需训练专用检测器（YOLO26），若遇到新模态或罕见病变类型，可能缺少对应检测器，限制可覆盖范围。作者指出可通过扩展工具箱（如开放词汇检测）缓解，但未在本文实现。
- **数据集构建方式**：视频录自屏幕显示而非真实临床工作站环境（如PACS）。虽然模拟了典型场景，但未考虑实际临床工作站的使用习惯、多显示器布局、环境干扰等。作者承认此为未来发展。
- **确认智能体依赖强LLM**：DeepSeek-V4-Flash达到100%精度，但轻量模型DeepSeek-Chat在空间指令上表现不佳（TCA仅约40%）。实际部署中若使用较弱LLM，目标确认质量可能下降。
- **实时性**：10.7 FPS接近实时但未达到完全流畅（如30 FPS），且检测和传播串行运行，进一步优化延迟可能需硬件加速或模型轻量化。
- **未与更复杂基线（如视频分割模型）对比**：仅对比了图像级文本提示方法，未对比视频实例分割或目标跟踪方法，但后者通常需要标注序列训练，而EgoMed-Agent强在无需训练。
- **假设每个指令对应单一目标**：未考虑多目标同时分割或指令涉及多个结构的情况。

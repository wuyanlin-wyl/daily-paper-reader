### 1. One Modality to Forget Them All: Enhancing Cross-Modal Unlearning in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16442v1
- 方法流程：
  - 单模态遗忘阶段：在单一模态（文本或图像）上使用有害数据（PKU-SafeRLHF或JailbreakV-28K）对VLM进行遗忘训练，保留其他模态能力（TruthfulQA或VQA-v2），使用LLM-only干预条件（LoRA仅应用于LLM部分）。
  - 跨模态评估阶段：评估遗忘后另一模态是否仍产生有害输出，使用FigStep（文本→视觉）或自定义文本探针（视觉→文本）进行攻击。
  - CrossInf缓解阶段：利用小探测集计算每个Transformer块对跨模态泛化的影响分数，选择高影响块进行额外遗忘，减少转移差距。
- 关键模块/机制：
  - MLP投影器 (LLaVA-1.5)：将CLIP ViT-L/14视觉特征映射到Vicuna-7B LLM的token空间；轻量双线性MLP投影器，将视觉特征线性投影为与文本token同样维度的向量，实现早期融合。
  - Q-Former (InstructBLIP)：压缩视觉特征为固定数量的查询token，与文本对齐；Q-Former包含交叉注意力层，将EVA-CLIP ViT-G输出的视觉特征与32个可学习查询token交互，输出固定长度的视觉token序列，实现瓶颈式融合。
  - 门控交叉注意力 (IDEFICS)：在LLM各层中插入视觉特征，实现深层融合；遵循Flamingo架构，使用OpenCLIP ViT-H/14编码器+Perceiver重采样器，在LLM的每个Transformer块中通过门控交叉注意力机制融合视觉和文本特征。
  - CrossInf影响选择：识别对跨模态泛化最重要的Transformer块；在少量其他模态探测集上评估各块被mask后的性能下降，计算每个块对跨模态泛化的影响分数，选择影响最大的块进行针对性遗忘。
- 公式/目标函数/指标定义：
  - 目标字符串攻击成功率 (ASR_TS): ASR_TS = (1/N) * Σ_{i=1}^N (1 - 𝟙_refuse(r_i))，其中𝟙_refuse(r_i) = 1若响应包含任一拒绝子串，否则0。
  - LlamaGuard攻击成功率 (ASR_LG): ASR_LG = (1/N) * Σ_{i=1}^N 𝟙_unsafe(r_i)，其中𝟙_unsafe(r_i)为Llama-Guard-4-12B对响应r_i的有害性判定。
  - VQA准确率: Acc_VQA = (1/N) * Σ_{i=1}^N min(|{j: a_hat_i in a_i^(j)}| / 3, 1)，其中a_hat_i为预测答案，a_i^(j)为第j个标注者答案。
  - Fleiss' κ: κ = (p_o - p_e) / (1 - p_e)，其中p_o为观测一致率，p_e为期望一致率。
- 算法细节：
  - CrossInf算法：使用小探测集（如少量其他模态的有害样本）计算每个Transformer块在交叉注意力或前馈网络被mask前后的性能变化，得到影响分数，选择分数最高的k个块进行后续遗忘训练。
  - LoRA微调：所有模型采用QLoRA（秩32，alpha=16，dropout=0.05），仅训练LoRA适配器参数，基座模型冻结。
  - 干预点控制：设置四种条件（vision-only, fusion-only, LLM-only, fusion+LLM）以隔离不同组件对跨模态转移的贡献。
- 训练/推理细节：
  - 训练：使用AdamW优化器，学习率3e-4，权重衰减0.01，梯度裁剪范数1.0，训练1000步，batch size 2，所有模型以4-bit NF4量化加载。
  - 推理：评估时使用目标字符串匹配和LlamaGuard多模态分类器，以文本或图像输入，未修改模型权重。
  - 排版攻击：采用FigStep方法生成包含禁止文本的图像（如直接询问、角色扮演等），测试视觉通道的恢复能力。

### 2. Searching for Task-Specific Vision Paths: Evolutionary Block Pruning Across Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17052v1
- 方法流程：
  - 阶段1：数据准备。构建包含5种能力（属性、计数、物体、OCR、空间）的876例图像不重叠的选择分区，每个能力来自特定源数据集。
  - 阶段2：单块损伤测量。对每个视觉块，计算跳过该块后每个能力-源单元相对于完整模型的准确率下降（∆），用于初始化搜索。
  - 阶段3：进化搜索。种群初始化（随机路线或基于单块损伤的启发式），进行交叉和变异，使用源平衡目标函数作为适应度，选择优胜者。
  - 阶段4：路由选择。从多个种子的进化结果中选择最终路线（共享路线或能力特定路线），并评估在保留测试集上的准确率。
- 关键模块/机制：
  - 源平衡目标函数：评估路线的损伤，避免大源主导；对每个能力-源单元（c,d）计算配对损伤∆_{c,d}(S)=100*(A0_{c,d}-A^S_{c,d})。共享路线优化三个指标：平均损伤μ(S)，最差源损伤w(S)，源变异性σ(S)。能力特定路线额外优化附带损伤κ_t(S)（非目标单元的平均损伤）。最终标量损失为加权和：共享路线L_shared=0.50μ+0.30w+0.20σ；能力特定路线L_t=0.45μ_t+0.30w_t+0.15κ_t+0.10σ_t。
  - 进化搜索算法：组合优化搜索固定预算的跳过块集合；种群由随机路线和基于单块损伤的贪婪构造初始化。每代通过锦标赛选择、两点交叉和随机变异生成子代。多目标优化采用帕累托前沿保存，最终使用标量损失排序。搜索运行多个种子以增加多样性。
  - 身份跳跃（Identity Skipping）：跳过视觉块的方式；被跳过的块不执行，其输入直接传递到下一个块（恒等映射）。不进行任何微调或权重修改。
  - 共享路线 vs 能力特定路线：两种路由策略；共享路线对所有问题使用同一组K个跳过块；能力特定路线根据能力标签选择不同的K块集合，但每个能力内共享。优化时能力特定路线使用附带损伤项限制对其他能力的破坏。
- 公式/目标函数/指标定义：
  - 配对损伤: ∆_{c,d}(S) = 100 * (A0_{c,d} - A^S_{c,d})，其中A0是完整模型准确率，A^S是跳过路线S的准确率
  - 共享路线目标: μ(S) = mean_g ∆_g(S), w(S) = max_g ∆_g(S), σ(S) = std_g ∆_g(S)
  - 共享路线标量损失: L_shared(S) = 0.50 μ(S) + 0.30 w(S) + 0.20 σ(S)
  - 能力特定路线目标: μ_t(S) = mean_{g in T_t} ∆_g(S), w_t(S) = max_{g in T_t} ∆_g(S), σ_t(S) = std_{g in T_t} ∆_g(S), 附带损伤 κ_t(S) = mean_{g in C_t} ∆_g(S)
  - 能力特定路线标量损失: L_t(S) = 0.45 μ_t(S) + 0.30 w_t(S) + 0.15 κ_t(S) + 0.10 σ_t(S)
- 算法细节：
  - 进化搜索的种群大小和代数未明确给出，但多个种子运行。
  - 交叉操作：两点交叉，将两个父代路线（二进制掩码）切分后重组。
  - 变异操作：随机翻转掩码中的一位（即添加或移除一个块），确保总跳过数K不变。
  - 选择：锦标赛选择（大小未指定），并保留每代最佳个体。
  - 多个种子（seed-level winners）独立运行，最终选出一个路线（通过Jaccard重叠或无）。
- 训练/推理细节：
  - 无需微调：跳过块后直接进行推理，模型权重完全冻结。
  - 推理时，被跳过的块执行恒等传递，不计算前向传播。
  - 使用贪婪解码和batch-size-one推理。
  - 模型：Qwen2.5-VL-3B-Instruct（32个视觉块）和SmolVLM2-2.2B-Instruct（27个视觉块）。

### 3. Induce to Empower: Improving Lightweight Baselines via Foundation Model Induction for Generalized Polyp Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17208v1
- 方法流程：
  - 输入：结肠镜图像。
  - 阶段1 - 基础模型特征提取：使用预训练的基础模型（DINOv2、SAM、OneFormer）提取多尺度特征图。
  - 阶段2 - 原型生成：为每个基础模型生成原型表示（prototype representations），捕获该模型的特有先验知识。
  - 阶段3 - 语义对齐：通过重建监督损失（reconstruction-based supervision），将轻量基线模型（如U-Net）的中间特征与对应基础模型的原型表示进行对齐，使轻量模型学习到基础模型的泛化能力。
  - 阶段4 - Transformer融合：将多个对齐后的原型表示通过Transformer模块进行融合，输出突出息肉区域和边界信息的增强特征。
  - 阶段5 - 分割预测：将融合特征输入轻量基线的解码器或分割头，生成最终的息肉分割掩码。
- 关键模块/机制：
  - FM-specific Prototype Generator：为每个基础模型生成定制化的原型表示，编码该基础模型的特有先验信息。；可能通过可学习的映射网络将基础模型的特征图转换为紧凑的原型向量或特征图，具体实现未详细说明，但强调'FM-specific'，即针对不同基础模型设计不同的生成方式。
  - Reconstruction-based Semantic Alignment：通过重建损失监督轻量模型的特征去拟合基础模型的原型表示，实现知识迁移。；在训练过程中，计算轻量模型中间特征与对应基础模型原型之间的重建误差（如MSE或余弦相似度），作为辅助损失函数，迫使轻量模型学习基础模型的泛化特征分布。
  - Transformer-based Fusion：融合多个基础模型的原型表示，突出息肉相关特征并保留互补语义和边界信息。；采用Transformer架构（可能包含自注意力和交叉注意力）将来自不同基础模型的原型表示进行交互，使得融合后的特征能够强调对分割任务有用的区域（如息肉主体和边界），同时抑制噪声。
- 公式/目标函数/指标定义：
  - 重建损失 L_recon = ||F_light - P_FM||^2 或相似度损失（具体形式未给出）。
  - 总损失 L_total = L_seg + λ * L_recon，其中L_seg为分割损失（如Dice损失或交叉熵），λ为平衡系数。
- 算法细节：
  - 训练时，固定基础模型参数，仅训练轻量模型、原型生成器和融合模块。
  - 对不同基础模型（DINOv2、SAM、OneFormer）分别生成原型表示，分别计算重建损失。
  - 融合模块使用Transformer，输入为多个原型表示，经过多层自注意力后输出融合特征。
  - 轻量基线模型的特征提取部分被保留，并在重建损失约束下更新参数。
- 训练/推理细节：
  - 训练阶段：使用息肉数据集，同时优化分割损失和重建损失。基础模型参数冻结。
  - 推理阶段：轻量模型和训练好的原型生成器、融合模块协同工作，无需基础模型推理，保持计算轻量。
  - 实验设置：在五个标准息肉分割数据集（如Kvasir、CVC-ClinicDB等）上进行评估。

### 4. PRiSM: Prototype Regularization for Few-Shot VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17820v1
- 方法流程：
  - 输入：支持集图像-标签对、零-shot文本原型（来自CLIP文本编码器）、基线方法得到的初始原型（或零-shot原型）。
  - 步骤1：构建多术语损失函数，包含支持特征对齐项、基线原型保真项、类间成对距离最大化项。
  - 步骤2：使用块Majorize-Minimize算法交替更新类原型和视觉编码器（轻量级微调）。
  - 步骤3：输出修正后的类原型，用于查询集分类（余弦相似度+softmax）。
- 关键模块/机制：
  - 多术语损失函数：联合优化目标，同时促进原型与支持特征对齐、保持与初始原型的相似性、增大类间距离。；包含三项：L_align（支持特征到对应原型的距离，如交叉熵或L2距离）、L_fidelity（修正原型与基线原型的距离，如L2）、L_sep（最大化不同类原型间距离，如负的成对余弦相似度和）。总损失为加权和。
  - 块Majorize-Minimize (MM) 优化器：高效优化非凸损失，交替更新类原型和视觉编码器参数。；每次迭代：对类原型块，构造替代函数（上界），通过闭式解更新；对视觉编码器，使用梯度下降微调少量参数（如偏置或低秩适配器）。块步长通过Gershgorin圆定理估计的Lipschitz常数自适应确定。
  - Gershgorin圆定理用于Lipschitz常数估计：提供块Hessian矩阵谱范数的上界，无需计算全矩阵，保证MM算法单调下降。；将损失函数对每个原型的二阶导数矩阵视作对角占优，利用Gershgorin圆盘估计最大特征值，作为块步长的倒数。
  - 轻量级视觉编码器微调：小幅度更新视觉特征提取器，进一步适配任务分布。；仅更新编码器中的少量参数（如LayerNorm的γ/β或添加的线性适配器），保持大多数参数冻结，避免过拟合。
- 公式/目标函数/指标定义：
  - 总损失：L_total = L_align + λ1 L_fidelity + λ2 L_sep，其中L_align = Σ_n ||v_n - a_{y_n}||^2（或交叉熵），L_fidelity = Σ_c ||a_c - u_c||^2，L_sep = -Σ_{i≠j} ||a_i - a_j||^2（或余弦相似度）。
  - 块MM更新：a^{t+1} = argmin_a [ L(a) + (1/2η) ||a - a^t||^2 ] 的近似，其中η = 1/L_block，L_block通过Gershgorin圆定理估计。
  - 视觉编码器更新：ϕ' = ϕ - α ∇_ϕ L_total，仅更新少量参数。
- 算法细节：
  - 初始化：类原型a设为基线方法输出（如Tip-Adapter的缓存模型输出），视觉编码器参数为冻结状态。
  - 外循环：对每个任务，重复T次迭代（T通常为10-20）。
  - 内循环步骤1：固定视觉编码器，计算损失关于每个原型a_c的梯度，利用块MM算法更新a：计算每个块（每类原型）的Lipschitz常数，执行梯度下降或近端梯度更新。
  - 内循环步骤2：固定原型，对视觉编码器执行一次或多次梯度下降，仅更新可训练参数（如偏置）。
  - 输出最终原型a用于查询集评估。
- 训练/推理细节：
  - 训练-free：PRiSM不需要在训练集上学习额外参数，优化过程直接在支撑集上执行，无需验证集。
  - 推理：使用优化后的原型a与查询图像embedding计算余弦相似度，softmax得到分类概率。温度τ设为CLIP默认值（如0.01）。
  - 视觉编码器微调仅涉及少量参数（如LayerNorm的缩放系数），总微调参数量小于模型总参数的1%。

### 6. PathReportEval: A Systematic Benchmark for Pathology Report Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.18448v1
- 方法流程：
  - 输入：WSI图像和对应病理报告参考文本
  - 预处理：标准化数据划分、分词、特征提取（TRIDENT工具提取视觉特征）
  - 特征提取：使用三种病理基础编码器（CONCHv1.5, UNI2-h, H-Optimus-1）提取特征
  - 模型训练：在统一框架下训练四种方法（WSI-Caption, HistGen, BiGen, SCOUT）
  - 解码：固定解码策略生成报告文本
  - 评估：计算传统NLG指标（BLEU, ROUGE-L, METEOR）和CRQS指标
- 关键模块/机制：
  - 结构化临床提取函数 E：将自由文本报告映射到预定义临床属性集，用于CRQS计算；使用结构化LM管道，提取诊断、分级、分期等字段，进行同义词解析、否定处理和值标准化。返回 {(fi, vi)} 键值对集合。
  - Clinical Fact Coverage (CFC)：衡量生成报告覆盖参考报告中临床字段的比例；CFC = (∑_{f∈F_R} 1[ˆv_f ≡ v_f]) / |F_R|，其中F_R为参考报告中出现的字段集，≡表示临床等价。
  - Key Information Recall (KIR)：强调关键诊断属性（如诊断、分级）的召回；KIR = (∑_{f∈K_R} 1[ˆv_f ≡ v_f]) / |K_R|，其中K_R为关键字段集合（参考报告中与关键字段的交集）。
  - Hallucination Rate (HR)：度量生成报告中未被参考报告支持的字段比例；HR = (∑_{f∈F_ˆR} 1[f∉F_R 或 ˆv_f≠v_f]) / |F_ˆR|，其中F_ˆR为生成报告中出现的字段集。
  - Clinical Discordance Score (CDS)：度量生成与参考报告同时存在的字段上值不一致的比例；CDS = (∑_{f∈F_R∩F_ˆR} 1[ˆv_f≠v_f]) / |F_R∩F_ˆR|。
  - CRQS综合得分：综合四个子指标得出最终临床质量分数；CRQS_raw = w1*CFC + w2*KIR + w3*(1-HR) + w4*(1-CDS)，权重默认 w1=0.30, w2=0.40, w3=0.20, w4=0.40；最终CRQS = CRQS_raw / 0.7，取值范围[0,1]。
- 公式/目标函数/指标定义：
  - E(R) = {(fi, vi)}_{i=1}^n：结构化提取函数

- 方法流程：

- 关键模块/机制：

- 公式/目标函数/指标定义：
  - SFT损失: L_sft = - Σ_{t∈Y*} log p_θ(y*_t | xs, y*_{<t})
  - 蒸馏损失: L_kd = Σ_t w_t · KL(p_T(·|xt, ŷ_{<t}) || p_θ(·|xs, ŷ_{<t}))
  - 总损失: L = L_kd + α L_sft

- 算法细节：

  - 解码时使用学生当前参数，蒸馏目标针对学生自己的解码轨迹（on-policy distillation）。
- 训练/推理细节：
  - 训练：教师模型使用与学生相同的架构并冻结，从同一基础检查点初始化。无需EMA教师。训练时学生输入为标准图像和提示，教师输入为带框图像和增强提示。
  - 推理：仅使用学生模型，输入为标准图像和提示，无框叠加、无特权提示、无教师分支或额外预测模块。输出为自动回归生成的坐标字符串。

  - Attention-based Frame Scorer：利用选定层ℓ*的文本到视觉注意力计算帧相关性，无需训练。；从MLLM选定层提取注意力矩阵A^(ℓ*) ∈ R^{T × (F·P)}，先对每个视觉token求和到帧：S_{t,j} = sum_p A^(ℓ*)_{t,(j,p)}，然后对重要token集合T_imp进行max pooling：φ_j = max_{t∈T_imp} S_{t,j}。重要token根据任务定义：多选题包含选项token，开放式QA用LLM提取实体中心token。
  - Dynamic Programming Budget Allocator：联合优化候选帧数量F(d)和每帧token数P(d)，在总token预算B下最大化选择效用。；建模为离散优化：给定视频时长d，选择F(d)和P(d)使得F(d)*P(d) ≤ B，并以某种效用函数（如预期覆盖度）为目标，通过动态规划求解最优分配。具体地，将时长分段，每个时段对应一组可能的(F,P)组合，利用DP选择全局最优。
- 公式/目标函数/指标定义：
  - S_{t,j} = ∑_{p=1}^{P} A^{(ℓ*)}_{t,(j,p)}，其中t为文本token索引，j为帧索引，p为帧内视觉token索引。
  - φ_j = max_{t∈T_imp} S_{t,j}，T_imp为重要文本token集合。
  - 优化目标：在总视觉token预算B下，最大化所选帧的预期效用（如相关性总和或覆盖度），离散决策变量为F(d)和P(d)，约束F(d)*P(d) ≤ B。
- 算法细节：
  - 选定层ℓ*通过验证集（Charades-STA/NExT-GQA）上的层搜索确定，选取在Hit@32、Cov@32和Attn指标上表现最佳的中间层（如L11-L15）。
  - 重要token集合T_imp的构建：对于多选题，直接使用选项的文本token；对于开放式QA，使用LLM从问题中提取实体关键词的token。
  - 动态规划求解预算分配：将视频时长划分为若干区间，每个区间对应一个候选帧数量F和每帧token数P的二元组，通过DP选择使总得分最大化的分配方案。
  - 最终选择时，将排名最高的K帧以原始分辨率（不压缩）送入答案MLLM。
- 训练/推理细节：
  - 训练无关：选择器完全基于冻结的小MLLM（如Qwen3-VL-2B），无需额外训练或微调。
  - 推理时单次前向传播：仅需将候选帧和查询输入小MLLM一次，提取选定层注意力即可获得所有帧的分数，无需自回归生成。
  - 选择器的上下文窗口有限，因此需要通过动态压缩和预算分配保证输入总token数不超过限制。

  - 深度协方差模型参数a, b, z0根据传感器标定设定
  - 逐点Mahalanobis距离d_M，以χ²分布门限（α=0.05）做假设检验
  - 实例级得分取75百分位数以减少异常点影响
  - 融合规则中阈值τ_o, κ_o, ρ_τ为可调超参数
  - 查询路由：规则解析器识别意图（moving/movable/static）映射到特定字段，并应用语义相似度阈值θ_s（余弦>0.5）过滤

  - VLM/LLM可动性先验每类仅查询一次并缓存，无逐帧开销

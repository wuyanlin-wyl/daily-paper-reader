## 摘要
实现可解释的零样本分类的一种流行方法是让大型语言模型（LLM）描述每个类别名称，并用得到的描述符提示CLIP。我们发现这些描述符本身携带的视觉证据很少：从提示中移除类别名称会将ImageNet准确率从59.5%降至15.5%。诊断结果是，描述符是以标签为条件，而非以图像为条件，因此它们描述了概念的总体情况，并且在数据分布变化时恰好产生误导；LLM坚持草莓是红色的，但ImageNet-Sketch中的每个草莓都是无色的线条画。因此，我们转而从目标图像集合中选择属性：我们在CLIP的联合嵌入空间中对大量属性池进行评分，并保留每个类别中得分最高的属性。通过这种方式选择，无类别名称的属性提示在ImageNet上达到23.8%（而LLM描述符为15.5%），该增益在四个偏移的ImageNet变体上保持一致，并且从LLM自身的池中重新选择将选择机制隔离为原因。在每类一张图像的情况下，所选属性比提示调优方法CoOp高出3个百分点，同时在不到一分钟内完成拟合，而CoOp需要14小时，并且没有学习到的软提示来模糊决策。因为属性集由数据选择，它也可以作为数据集的可读摘要，我们用它来描述分布偏移的词语。

## Abstract
A popular route to interpretable zero-shot classification asks a large language model (LLM) to describe each class name and prompts CLIP with the resulting descriptors. We show that these descriptors carry little visual evidence of their own: removing the class name from the prompt collapses ImageNet accuracy from 59.5% to 15.5%. The diagnosis is that the descriptors are conditioned on the label rather than on the images, so they describe the concept in general and mislead exactly when the data shifts; an LLM insists that strawberries are red, but every strawberry in ImageNet-Sketch is a colorless line drawing. We therefore select attributes from the target image collection instead: we score a large attribute pool against the images in CLIP's joint embedding space and keep the top-scoring attributes per class. Selected this way, class-name-free attribute prompts reach 23.8% on ImageNet (against 15.5% for LLM descriptors), the gain holds on four shifted ImageNet variants, and reselecting from the LLM's own pool isolates the selection mechanism as the cause. With one image per class, the selected attributes outperform the prompt-tuning method CoOp by 3 points while fitting in under a minute instead of 14 hours, with no learned soft prompt to obscure the decision. Because the attribute set is chosen by the data, it doubles as a readable summary of a dataset, which we use to describe distribution shift in words.

## 2. 论文提出的方法论

### 核心思想
- **分布条件属性选择（Distribution-Conditioned Attribute Selection）**：在CLIP的联合嵌入空间中，对大量候选属性文本与目标图像集合进行相似度评分，为每个类别保留得分最高的属性，用于零样本分类。整个过程无需类别名称参与。

### 关键技术细节
1. **属性池构建**：使用VAW（Visual Attributes in the Wild）和LSA（Large-Scale Attribute）等大规模属性词汇库，构成候选属性池。
2. **特征提取**：用冻结的CLIP图像编码器提取目标图像的嵌入向量，同时用CLIP文本编码器提取每个属性文本的嵌入向量。
3. **属性评分**：计算每个属性与每张图像的余弦相似度，形成每个图像的属性特征向量。对每个类别，计算该类所有图像上各属性特征向量的均值，作为该类别的属性权重。
4. **属性选择**：为每个类别选择权重最高的top-k属性，构成该类别的属性提示集。
5. **零样本分类**：在推理时，将测试图像与每个类别的属性提示集进行相似度计算（可选择加权或简单投票），预测类别。

### 算法流程
- 输入：目标图像集合（每类若干张）、属性池、CLIP编码器（冻结）。
- 步骤：
  1. 编码所有图像与所有属性文本。
  2. 计算每张图像与每个属性的余弦相似度，生成图像级属性特征向量。
  3. 按类别聚合，计算每类的平均属性得分向量。
  4. 对每类选取top-k属性作为该类别的描述。
  5. 测试时，用所选属性进行零样本分类。
- 输出：分类结果、每类的属性列表。

## 6. 论文的主要结论与发现

1. **LLM生成描述符严重依赖类别名称**：去除类名后，ImageNet准确率从59.5%降至15.5%，表明这些描述符本身缺乏视觉证据。

## 7. 优点

- **方法简单高效**：仅需对CLIP嵌入进行余弦相似度计算和排序，无需训练或微调任何模型，训练时间极短（分钟级）。
- **鲁棒性强**：在多种分布偏移场景下表现稳定，对比LLM描述符大幅提升。
- **可解释性强**：选择的属性是自然语言词汇，可以直观理解模型决策依据；同时可生成数据集的文字摘要。
- **无需类别名称**：真正实现了“视觉证据驱动”的分类，避免了LLM的语言偏差。
- **通用性好**：既适用于标准图像集，也适用于分布偏移数据集；可扩展到无类名定位任务（Fig. 7）。
- **实验公平**：严格控制变量，隔离了选择机制与属性池的影响。

## 8. 不足与局限

- **依赖属性池质量**：方法性能受限于候选属性词汇的覆盖度和准确性。如果属性池缺少与目标分布相关的语义属性，选择可能失效。
- **实验覆盖有限**：
  - 仅使用CLIP-RN50和RN50x64两种模型，未验证在更大或不同架构的视觉语言模型上的表现。
  - 分布偏移类型主要基于ImageNet变体，未覆盖细粒度分类、跨域迁移（如医疗影像、卫星图像）等场景。
- **属性选择假设分布内一致性**：要求每类有若干张目标分布下的图像。在完全零样本（无任何目标图像）情况下无法应用，必须依赖LLM或知识库。
- **未考虑属性间冗余**：选择的top-k属性可能语义重叠（如“red”和“crimson”），文中仅通过互信息分析指出相关性，但未专门处理冗余。
- **分类准确率相对较低**：无类名属性提示在ImageNet上仅23.8%，远低于有类名提示的59.5%，说明属性本身表达能力有限。论文强调其作为可解释性工具而非替代标准方法。
- **应用限制**：对于类别极多（如1000类）且每类图像很少的场景，属性评分统计可能不稳定。

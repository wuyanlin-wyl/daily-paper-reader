## 摘要
提升视觉语言模型（VLM）在视觉推理上的能力通常需要重新训练或手工设计的提示与工具。我们提出Dynamo，一种无需训练即可适应冻结VLM的框架，无需任何权重更新。在一个小型标注训练子集上，智能体检查自身正确与错误的尝试，并进化出两种互补能力：针对认知瓶颈的可复用推理技能，以及针对感知瓶颈的可执行视觉工具。每个生成的工具都与一个指定何时调用它的技能配对，两种能力类型都累积在持久库中。在四个视觉推理基准和五个VLM主干上，Dynamo提升了所有20个模型-基准设置的直接推理能力（平均+5.6准确率）。当预先给定工具集时，该框架学习何时调用每个工具，且每步工具选择在所有测试主干上均有改进。针对特定任务的强化学习（VTool-R1, DeepEyes），Dynamo以极小的计算量弥补了65-99%的RL差距，并在可用时与RL相加性结合。

## Abstract
Improving vision-language models (VLMs) on visual reasoning typically requires retraining or hand-designed prompts and tools. We present Dynamo, a training-free framework that adapts a frozen VLM without any weight updates. On a small labeled training subset, the agent inspects its own correct and incorrect attempts and evolves two complementary capabilities: reusable reasoning skills for cognitive bottlenecks, and executable visual tools for perceptual ones. Each generated tool is paired with a skill that specifies when to invoke it, and both capability types accumulate in a persistent library. Across four visual reasoning benchmarks and five VLM backbones, Dynamo improves direct inference on all 20 model--benchmark settings (avg. +5.6 acc). When the tool set is given in advance, the framework learns when to call each tool, and per-step tool choice improves on every tested backbone. Against task-specific RL (VTool-R1, DeepEyes), Dynamo closes 65--99% of the RL gap at a fraction of the compute, and combines additively with RL when available.

- **背景**：视觉语言模型（VLM）在视觉推理任务上表现出强劲性能，但适应新任务家族通常需要手工整理监督微调（SFT）数据或设计强化学习（RL）管道。这种范式成本高、难以规模化。

## 6. 主要结论与发现

1. **自主进化显著提升推理**：在所有20个模型-基准单元上，Full Dynamo相比零样本基线平均提升+5.6准确率点，最大提升在o4-mini/V*（+14.1）和o4-mini/HRBench4K（+12.7）。
2. **技能与工具互补**：认知瓶颈任务（ChartQA, MathVista）上Skill Only占优；感知瓶颈任务（HRBench4K, V*）上Tool Only和Full占优。
3. **能学习工具调用时机**：在GTA上，Dynamo Mode B在所有骨干上提升每步工具选择、参数预测、指令遵循和最终答案准确率，优于零样本暴露和通用技能注入。
4. **接近或匹配RL性能**：在结构化VQA（ChartQA/TableQA）上缩小65-99%的RL差距；在高分辨率感知上（V*, HRBench4K）Dynamo单独即可与RL相当甚至更好（V* 7B: Dynamo 85.86 vs. RL 84.82）。且Dynamo+RL在所有单元上达到最强，表明两者可加性复合。
5. **在线适应能力强**：在线自适应策略接近Oracle上界（精度0.83 vs. 0.74静态），在困难流上恢复至0.95，检测延迟2-7个案例。
6. **机制消融证实关键设计**：通用提示注入不能解释增益；视觉诊断对生成有用工具必不可少；必须同时分析正确和错误案例。

## 7. 优点

- **完全免训练**：无需梯度更新，计算成本极低，易于部署和迁移。
- **通用性强**：跨5种不同骨干、4类视觉推理任务、不同工具环境均有效。
- **自动化能力进化**：智能体自主诊断瓶颈、生成技能/工具、验证提升，近乎无人干预。
- **工具掌握学习**：每个工具附带掌握技能，自动学习适用边界，避免误用，优于先前工具创建方法。
- **在线自适应**：能检测分布漂移并动态更新能力库，适合真实流式部署。
- **与RL可互补**：Dynamo提供正交增益，与RL结合达最优（Dynamo+RL比单独RL高1-3点）。
- **实验设计严谨**：多基准、多骨干、多种子、多种配置对比、机制消融，支持结论可靠。

## 8. 不足与局限

- **诊断依赖主干自省能力**：AnalyzerDecider和Generator由同一冻结VLM完成，若主干自我反思能力弱，可能误分类瓶颈类型，导致能力低效；提升门只拒绝低分候选，不能纠正上游诊断错误，因此小模型可能收敛慢。
- **基准范围有限**：仅限于图像类视觉推理（ChartQA, MathVista, HRBench4K, V*, GTA），未扩展到3D、医学影像等其他模态；认知/感知二分法及工具接口是否适用需未来验证。
- **依赖正确性信号**：进化循环和在线适应都需要每个案例的正确性信号（实验中用基准标签），在生产中需要人工审核、自动化QA或LLM验证器，完全无监督（无任何反馈信号）场景不适用。
- **统计偏差风险**：提升规则基于训练集准确率，虽然训练/验证集不重叠，但候选选择可能过拟合Dtrain，论文承认存在的选择偏差，但认为候选集很小（M个位数）使偏差对数级增长，未做大规模实证估计。
- **持久化价值在HRBench4K试点中未充分验证**：由于生成候选被拒绝，无法评估“无持久化”的消融效果，持久化的跨案例复用收益在本次试点中未体现，需更大子集验证。
- **实验规模**：尽管覆盖多骨干和基准，但训练集大小仅10%（~几十到几百案例），进化迭代只有3轮，单次试点仅30例，较大规模的机制性实验（如多候选探索vs单候选）未完成。

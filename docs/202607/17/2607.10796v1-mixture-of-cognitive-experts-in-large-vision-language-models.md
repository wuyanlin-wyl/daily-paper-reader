## 摘要
大型视觉语言模型（LVLMs）需要对视觉和文本输入进行强大的推理。近期研究表明，认知元素，尤其是多样化表征和元认知，与更好的性能相关。许多所需的感知功能已由专门的领域特定计算机视觉模型提供，这些模型作为感知子系统，用于检测对象、定位对象、推断状态、恢复空间布局和读取文本。关键挑战在于将这些多编码器专家整合成可信、可解释且连贯的表征，从而提高可验证性并减少幻觉。这之所以困难，是因为视觉语言问题涵盖不同认知层级，而大多数LVLMs流水线对每个查询都应用相同的感知-推理路由，无论其需求如何。我们提出了一种证据驱动的多模态推理框架，该框架利用受布鲁姆启发分类法作为分层推理协议。两阶段认知言语化首先通过将专家输出分解为简短、原子化的证据陈述，生成字面证据摘要。然后执行布鲁姆言语化，将这些证据项转化为分阶段推理轨迹，轻量级推理轨迹模块对轨迹进行定量分析，使证据使用和推理进展显式化。通过这种整合，我们观察到感知和推理能力的多项改进。此外，轨迹模块提供了定量证据，表明不同查询会诱导不同的认知进入层级和证据使用轨迹，从而能够进行细粒度分析。

## Abstract
Large Vision Language Models (LVLMs) require strong reasoning over both visual and textual input. Recent work suggests that cognitive elements, especially diverse representations and metacognition, correlate with better performance. Many of the needed perceptual functions are already provided by specialized domain-specific computer vision models, which act as the perceptual subsystem for detecting objects, localizing them, inferring states, recovering spatial layout, and reading text. The key challenge is to integrate these multi-encoder experts into a trustworthy, interpretable, and coherent representation that improves verifiability and reduces hallucinations. This is difficult because vision-language questions span different cognitive levels, yet most LVLM pipelines apply the same perception-reasoning routing regardless of the demand of each query. We propose an evidence-driven multimodal reasoning framework that utilizes a Bloom-inspired taxonomy as a hierarchical reasoning protocol. The two-stage cognitive verbalization first produces a Literal Evidence Summary by decomposing expert outputs into short, atomic evidence statements. It then performs Bloom Verbalization to turn these evidence items into a staged reasoning trace, and a lightweight Reasoning Trace Module quantitatively analyzes the trace to make evidence usage and reasoning progression explicit. Through this integration, we observed several improvements in perception and reasoning abilities. Moreover, the trace module provides quantitative evidence that different queries induce different cognitive entry levels and evidence-use trajectories that enable fine-grained analysis.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有大型视觉语言模型（LVLMs）在处理视觉‑语言查询时，对所有问题采用统一的感知‑推理路径，忽略了不同查询在认知需求上的本质差异（例如，简单回忆 vs. 高阶逻辑推理）。这导致三个关键缺陷：
  - 可验证性差：模型推理过程不透明，难以追溯证据来源。
  - 幻觉严重：缺乏显式的感知证据约束，模型容易生成与视觉输入不符的答案。
  - 专家整合困难：虽然已有多种高性能领域专用视觉模型（如OCR、检测、分割），但缺乏有效机制将其输出融合为可信、可解释且连贯的表征用于推理。
- **背景**：认知科学和机器学习研究提示，具备多样化内部表征和元认知能力的模型更容易成功。Bloom 分类法提供了从低层回忆到高层分析的分层认知结构，但尚未被系统性地用于 LVLM 的推理架构设计。
- **整体含义**：本文试图将认知心理学中的分层推理协议（Bloom 分类法）引入 LVLM 推理流程，通过显式的证据提取和层级化言语化，实现更可信、可分析且幻觉更少的视觉‑语言推理。

## 2. 论文提出的方法论

### 核心思想
- 采用 **证据驱动** 的多模态推理框架，将推理过程划分为**感知证据提取**和**认知分层合成**两个阶段，显式分离感知与高层推理。
- 利用 **Bloom 分类法**（记忆→理解→应用→分析→评价→创造）构建分层推理协议，使得推理步骤可追踪、可量化。

### 关键技术细节
- **两阶段认知言语化**：
  1. **字面证据摘要（Literal Evidence Summary）**：将选定的专用视觉专家的输出分解为**原子化、可引用**的证据语句（每个语句带唯一 ID、类型（TEXT/ENTITY/REGION/TABLE）和元数据引用）。这些语句构成统一的证据库 E，不包含任何推理或任务推断。
  2. **Bloom 言语化（Bloom Verbalization）**：基于查询 q 和证据库 E，按 Bloom 认知层级顺序（LIST → EXPLAIN → ILLUSTRATE → COMPARE → HYPOTHESIZE → FINAL ANS.）逐步生成论证轨迹。每一步输出简短文字，并显式引用证据 ID。初步生成的 “Bloom 草案答案” y_Bloom 作为文本令牌，与图像和查询一同输入最终 LLM（公式5）。
- **轻量级推理轨迹模块（Reasoning Trace Module）**：确定性地从 y_Bloom 中解析出起始认知层级 ℓ₀、执行的 Bloom 步骤集合、每步引用证据集及其类型分布，从而支持细粒度定量分析（如层级分布、证据使用模式）。
- **路由与适配**：
  - **Router**：利用 LLM 的指令跟随能力，根据查询和粗粒度图像嵌入，从专家池中选择最相关的 K 个专家。
  - **Adapter**：参考 MoVA，将路由的专家特征与基础视觉特征融合（多块 Transformer），最终映射到 LLM 嵌入空间。
- **模型基础**：采用 LLaVA 架构（CLIP‑L 336px 作为视觉编码器 + Vicuna‑7B 语言模型），专家池包括 DETR（检测）、SAM（分割）、Pix2Struct（OCR/图表）、DePlot（图表）、Vary（文档）等。
- **训练范式**：完全**训练自由**，所有组件（路由、专家推理、言语化、最终生成）均在推理时执行，无需额外预训练或微调。

## 6. 论文的主要结论与发现

- **性能提升显著**：MoCE 在所有基准上优于或追平现有方法，尤其在 MMBench（75.7 vs LLaVA‑1.5 64.3）、MMVet（49.0 vs 43.9）、POPE（87.8 vs 86.5）上增益明显。
- **感知与推理能力均衡提升**：在 MMBench 四个二级能力上的表现均超越基线，特别是 Fine-grained Perception (FP‑S) 从约 68% 提至 79.5%，Logical Reasoning 从约 33% 提至 50%，Relation Reasoning 从约 56% 提至 78.3%。
- **Bloom 模块带来额外收益**：在视觉专家基础上加入 Bloom 言语化，在 MMBench 上提升 5.3 点，SEED 文本理解提升 4.7 点，代价是约 30% 的延迟增加。
- **认知层级分布可解释**：通过推理轨迹诊断发现，83.82% 的查询从 LIST 层级（基本回忆）开始，仅约 16% 从更高层级（COMPARE、EXPLAIN、ILLUSTRATE）开始，印证了大多数任务主要依赖基础感知；框架能自动适应不同难度查询。

- **幻觉缓解**：在 POPE 对抗设置下仍保持高得分（87.8），对比基线退化更小，说明预测更稳定、更少受假关联影响。

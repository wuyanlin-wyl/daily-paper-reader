### 1. Dive Into the Implicit Biases of Low-rank Vision-language Alignment
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.08194v1
- 方法流程：
  - 输入：图像和对应文本描述（如ShareGPT4V-PT数据集）。
  - 视觉编码：使用CLIP ViT-L/14（336分辨率）提取图像特征，选择第二层作为输出。
  - 连接器：通过全秩视觉-语言连接器（LDPNetv2）将视觉特征映射到LLM的嵌入空间。
  - 低秩对齐：冻结预训练LLM的大部分参数，仅对LLM的线性层应用低秩适应（LoRA/LoHa/LoKr），在视觉-语言对齐数据上以1e-3学习率、AdamW优化器、余弦衰减训练。
  - 可选项：后训练：在LLaVA-Instruction数据集上以4e-5学习率进行指令微调（可全参数或低秩）。
  - 输出：对齐后的多模态模型，可用于视觉问答、字幕生成等任务。
- 关键模块/机制：
  - 低秩适应模块（LoRA/LoHa/LoKr）：对LLM的权重更新施加低秩约束，引入隐式正则化，替代全参数更新。；将权重更新矩阵ΔW分解为两个低秩矩阵的乘积（LoRA），或使用Hadamard积（LoHa）/Kronecker积（LoKr）等变体。在训练时冻结原始权重，仅优化低秩因子，推理时合并回原始权重。支持多种秩（32/64/128），α=256。
  - 全秩连接器（LDPNetv2）：将视觉特征映射到LLM输入空间，保持特征多样性。；采用全秩设计（非低秩），以免丢失token特定的视觉结构。由于参数量极小（<0.3%），不增加计算负担。
  - 隐式偏置分析机制：解释低秩对齐为何有效，包括经验观察和理论证明。；经验上：测量每token线性可分离性（LS）发现低秩对齐保持LS而全参数破坏（LS-curse）；几何上分析视觉表征的均匀性和结构稳定性。理论上：证明低秩适应偏好参数子空间中的平坦梯度方向（定理1）和鲁棒特征子空间（定理2），从而保留模态特定知识。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
  - 论文定理提及低秩适应诱导的隐式偏好在理想假设下（无约束特征、小步噪声梯度）成立，但具体公式未在提供的片段中给出。
- 算法细节：
  - 低秩更新：对于LLM中每个选定的权重矩阵W（形状p×q），学习两个低秩因子A（r×q）和B（p×r），更新为ΔW = BA（LoRA）或使用Hadamard乘积变体ΔW = B ⊙ A（LoHa）或Kronecker乘积ΔW = C ⊗ D（LoKr）。
  - 合并策略：训练后，将低秩因子与原始权重合并：W' = W + ΔW，形成新的线性层权重。
  - 对齐阶段：使用视觉语言对齐损失（如对比损失或生成损失）反向传播，仅更新低秩因子和连接器参数。
  - 后训练阶段：可选择全参数微调或继续低秩微调，学习率更低。
- 训练/推理细节：
  - 训练数据集：视觉-语言对齐使用ShareGPT4V-PT 1.2M子集（包含LAION、CC、SBU、MS-COCO）；后训练使用LLaVA-Instruction 665K（含多个VQA数据集）。
  - 优化器：AdamW，余弦学习率调度。对齐阶段学习率1e-3，后训练阶段4e-5。
  - 批量大小：对齐阶段256，后训练阶段128。
  - 低秩配置：秩r∈{32,64,128}，α固定为256。
  - 模型规模：MobileVLM-v2（1.4B/2.7B）及Vicuna-7B等，LLM为MobileLLaMA或Vicuna。
  - 推理：将低秩因子合并回原权重，与全参数模型推理过程一致。

### 2. MedRealMM: A Real-World Multimodal Benchmark for Chinese Online Medical Consultation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09142v3
- 方法流程：
  - Phase 1: 真实多模态咨询语料库构建 - 输入：原始医患交互记录；处理：依次经过图像存在筛选、完整性过滤、科室平衡采样、LLM辅助去标识、人工审核；输出：包含5620个完整多模态咨询轨迹的语料库。
  - Phase 2: 多模态临床挑战点（MCCP）提取 - 输入：咨询轨迹；处理：Cropper LLM agent根据临床参与性筛选候选位置，Verifier LLM agent验证多模态相关性，若多个候选则选择得分之和最高者；输出：截断至MCCP的实例（文本+图像）及真实医生响应。
  - Phase 3: 医生指导的案例特定评分标准构建 - 输入：实例及原始医生响应；处理：Generator LLM生成初始rubric（正负标准及权重），医生提供结构化反馈，Refiner LLM迭代修正直到医生批准；输出：医生批准的rubric。
  - Phase 4: 基于评分标准的自动评估 - 输入：实例、模型生成的响应、rubric；处理：Grader LLM逐条判断响应是否满足每个标准并给出理由，加权归一化得到实例分数；输出：基准总分。
- 关键模块/机制：
  - MCCP提取框架：从真实咨询轨迹中识别临床关键点，将原始对话转化为标准化评估实例。；包含两个LLM agent：Cropper (ϕA) 评估每个医生回复前的回合，输出临床参与性决策(l_A)和分数(s_A)；Verifier (ϕM) 评估候选回合的咨询历史，输出多模态相关性决策(l_M)和分数(s_M)。有效MCCP需同时满足临床参与性和多模态相关性，若多个候选则选择s_A+s_M最大的回合。
  - 案例特定评分标准生成与修正：为每个实例生成细粒度的临床评估标准，替代单一参考答案。；Generator LLM (ϕR) 基于实例和原医生响应生成初始rubric，包含正负标准及权重。Refiner LLM (ϕ'R) 根据医生结构化反馈迭代修改rubric，直到医生无进一步修改意见。rubric大小取决于临床复杂度。
  - 评分标准引导的自动评估器：利用LLM作为裁判，根据rubric对模型生成的响应进行自动化评估。；Grader LLM (ϕJ) 输入实例x、模型响应y和标准c_j，输出二元判断v_j（是否满足）和文本理由。聚合时使用公式S = Clip( (Σ w_j v_j) / (Σ max(w_j,0)), 0, 1)，归一化至[0,1]。
- 公式/目标函数/指标定义：
  - 咨询轨迹表示: C = (e_1, e_2, ..., e_T), e_t = (c_t, m_t, s_t, τ_t)，其中c_t为内容，m_t为模态集，s_t为发送者，τ_t为时间戳。
  - 语料库构建流程: C0 → C1 (Φimg) → C2 (Φcmpl) → C3 (Φbal) → C4 (Φdeid) → C (Φrev)。
  - MCCP条件: A(t*; C) = 1 ∧ M(t*; C) = 1。
  - 实例得分: S(x, y, R*) = Clip( Σ_{j=1}^{N_x} w_j v_j / Σ_{j=1}^{N_x} max(w_j,0), 0, 1)。
  - 基准总分: Score(M) = (1/|D|) Σ_{i=1}^{|D|} S(x_i, M(x_i), R*_i)。
- 算法细节：
  - MCCP提取使用两个LLM agent依次处理：首先Cropper对所有医生回复前的回合进行评估，保留满足临床参与性的回合；然后Verifier对候选回合的咨询历史（截至该回合）进行评估，保留满足多模态相关性的回合；若多个保留则按分数和选择最优。
  - 评分标准生成：Generator ϕR基于实例x和原医生响应y_orig输出一组标准{(c_j, w_j)}，其中w_j∈[-20,20]表示重要性（正为奖励，负为惩罚）。
  - 评分标准迭代修正：医生审查rubric，提供结构化反馈（如缺失标准、权重错误），Refiner ϕ'R根据反馈修正rubric，循环直到医生无反馈。
  - 自动评估：Grader ϕJ仅基于实例x、响应y和标准c_j进行判断，不依赖原医生响应。聚合分数时负权重不参与分母计算，并截断至[0,1]。
- 训练/推理细节：
  - 无模型训练过程，基准构建和评估均为推理阶段操作。
  - 评估时，模型M根据实例x生成响应y，然后由Grader LLM进行打分。
  - 评分器采用Gemini-3-Pro-Preview，rubric生成与修正采用Claude-Opus-4.7。

### 5. Mixture of Cognitive Experts in Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10796v1
- 方法流程：
  - 输入：图像I和查询q；经过Router（LLM引导选择）选出top-K视觉专家集合G
  - 专家推理：执行G中专家（如DETR、SAM、Pix2Struct等）获得结构化感知输出O = {O^(e)}
  - Literal Evidence Summary：将O通过verbalizer ve转换为原子证据语句{(s_k, m_k)}，并归一化为统一证据存储E = {e_i}，每个证据包含id、type、text、ref
  - Bloom Verbalization：以q和E为输入，按Bloom层次L = [LIST, EXPLAIN, ILLUSTRATE, COMPARE, HYPOTHESIZE, FINAL ANS]逐步生成分段推理文本y_Bloom，每步引用证据ID
  - Adapter：将选中的专家特征融合到视觉表征中，经L个堆叠块处理，再经MLP投影匹配LLM嵌入空间
  - 最终回答：LLM以q、图像I和y_Bloom为条件生成最终答案ŷ
- 关键模块/机制：
  - Router：从专家池中为当前查询选择最相关的top-K视觉专家；使用LLM进行指令跟随式选择：将查询q、各专家简短描述、基础视觉编码器的下采样图像特征组成路由提示，LLM输出专家选项字母并解析为索引集G，仅执行G中的专家。
  - Literal Evidence Summary (LES)：将异构的专家感知输出转化为统一的、原子化的可引用证据集合；对每个选中的专家e，定义verbalizer ve将其输出O^(e)分解为多个短语句(s_k, m_k)，其中s_k是文字陈述，m_k是元数据（如边界框）。所有语句归一化为证据存储E = {e_i = (id_i, type_i, text_i, ref_i)}，type_i ∈ {TEXT, ENTITY, REGION, TABLE, CHART}，ref_i指向来源。
  - Bloom Verbalization：按照Bloom认知层次生成结构化的分步推理轨迹并引用证据；给定q和E，选择起始层次ℓ0（由查询决定），然后依次执行后续层次至FINAL ANS。每层ℓ输出短文本c_ℓ，并显式引用证据ID集U_ℓ。所有c_ℓ拼接为y_Bloom。例如LIST层枚举证据中的事实，EXPLAIN层解释相关性，ILLUSTRATE层构造示例，COMPARE层对比替代解释，HYPOTHESIZE层选择最佳解释，FINAL ANS层输出答案。
  - Reasoning Trace Module：定量分析Bloom Verbalizer输出的推理轨迹，提供可解释性指标；从y_Bloom中解析出步骤标题（如LIST）和证据引用（如[E12]），结合E得到每步引用的证据ID和类型。输出结构化记录：起始层次ℓ0、执行步骤集L(q)、每步引用证据集{U_ℓ}、证据类型混合。可聚合生成数据集级统计，如各步骤出现比例、平均引用证据数、入口层次分布等。
  - Adapter：将多专家特征融合为统一的LLM兼容视觉表征；采用L个堆叠块：初始基特征X，每块将选中的top-K专家特征{F_j}插值对齐后融合，经Transformer子块处理后输出下一状态。L块后经池化/残差头和MLP投影得到与LLM嵌入空间匹配的视觉token图。
- 公式/目标函数/指标定义：
  - O = {O^(e)}_{e∈G} # 选中的专家集G产生的原始感知输出
  - v_e: O^(e) → {(s_k, m_k)}_{k=1}^{n_e} # verbalizer将专家输出分解为原子语句
  - E = {e_i}_{i=1}^M, e_i = (id_i, type_i, text_i, ref_i) # 统一证据存储
  - y_Bloom, T̃ = f_Bloom(q, E) # Bloom Verbalizer生成草稿答案和可选轨迹
  - ŷ = f_LLM(q, I, y_Bloom) # LLM最终答案生成
  - L = [LIST, EXPLAIN, ILLUSTRATE, COMPARE, HYPOTHESIZE, FINAL ANS] # Bloom认知步骤有序集
- 算法细节：
  - Router算法：基于LLM的指令跟随，输入为查询、专家描述、下采样图像特征，输出为专家选项字母，解析为G。
  - Literal Evidence Summary算法：对每个专家，通过预定义模板将结构输出转换为多行文本，每行一个证据语句，并附加类型和元数据，然后汇总去重。
  - Bloom Verbalization算法：根据查询确定起始层次，对每个层次依次生成文本；每一层使用LLM（或规则）生成自然语言，并强制引用证据ID（如[E1]），最终拼接所有层次文本。
  - Reasoning Trace Module算法：正则匹配y_Bloom中步骤标题和证据引用模式，与E映射，输出结构化JSON。
- 训练/推理细节：
  - 整个框架是训练无关的（training-free），所有组件在推理时执行，无需额外预训练或微调。
  - Adapter模块中的投影MLP和Transformer块是预先训练好的（来自其他相关工作），不在本方法中更新。
  - 推理流程：Router→专家推理→LES→Bloom Verbalization→Adapter→LLM生成。
  - Bloom Verbalization使用预训练LLM（如Vicuna-7B）生成文本，但通过提示工程强制引用证据和分步输出。

### 6. Learning Anatomy-Grounded CT Vision-Language Representations with Organ-Hierarchical Report Knowledge
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10953v1
- 方法流程：
  - 输入：CT体积 x_i 和对应的自由文本报告 r_i。
  - 报告知识提取：通过报告解析和LLM语义结构化，从r_i中提取每个器官o的异常状态a_i^o、疾病概念c_i^o、位置l_i^o和属性h_i^o，构成器官条件知识 z_i^o = {a_i^o, c_i^o, l_i^o, h_i^o}。
  - Stage 1 - 层次引导的视觉证据学习：视觉编码器 E_v 将CT体积编码为3D特征晶格 F_i。全局分支使用可学习查询 Q_i 聚合全局表示 g_i，经疾病分类头进行case级疾病概念预测。器官分支使用器官mask m_i^o 从F_i中提取器官条件视觉 tokens v_i^o，通过四个头（abnormality/concept/location/attribute head）分别预测对应的器官条件标签。总损失 L1 = L_global + λ1 * L_organ。
  - Stage 2 - 层次引导的结构对齐：冻结视觉编码器，保留视觉几何。全局分支提取全局表示 g_i，与整报告文本嵌入 t_i 进行对比学习。器官分支提取器官视觉特征 v_i^o，与器官特定文本嵌入 u_i^o 进行对比学习。对比过程中使用从器官层级推导的语义软目标 T_ij，对共享器官级发现的非配对样本赋予弱正性。总损失 L2 = L_global_contrast + λ2 * Σ_o L_organ_contrast^o。
  - 输出：训练好的视觉编码器和文本编码器，可用于零样本诊断（通过全局CT表示与疾病标签文本匹配）和检索任务。
- 关键模块/机制：
  - 报告知识提取模块：将自由文本报告转换为结构化的器官条件知识，为两阶段提供监督信号。；首先使用报告解析器提取观察、解剖实体和修饰词，然后利用LLM进行语义结构化，将每个器官的发现填充为四个槽：abnormality status (a), disease/concept (c), location evidence (l), severity attribute (h)。
  - 视觉编码器：从CT体积提取3D特征晶格，作为全局和器官分支的共享表示。；基于3D CNN或ViT架构，输入CT体积 x_i，输出3D特征图 F_i ∈ R^{H×W×D×C}。
  - 全局分支（Query-based Global Branch）：聚合疾病相关体积证据，生成整扫全局CT表示。；使用可学习查询 Q_i 通过交叉注意力从特征晶格 F_i 中提取疾病相关信息，输出全局表示 g_i，用于case级疾病概念预测（Stage1）和全局对比学习（Stage2）。
  - 器官分支（Organ Branch）：根据器官mask提取器官条件视觉特征，并预测器官级属性。；利用器官mask m_i^o 对特征晶格 F_i 进行空间选择性池化或注意力，得到器官视觉 tokens v_i^o。在Stage1，通过四个独立的预测头（abnormality head, concept head, location head, attribute head）分别输出对应的器官条件预测。在Stage2，v_i^o 直接与器官文本嵌入进行结构对比。

- 算法细节：
  - 器官条件视觉特征提取：使用器官mask对3D特征晶格进行加权平均或基于注意力池化，得到每个器官的紧凑特征向量。

### 9. Attention-Free and Lightweight Token Reduction for Efficient Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13500v1
- 方法流程：
  - 输入: 视觉编码器输出的N个视觉token序列 X = {x_i}
  - 步骤1: 对每个token x_i计算熵值 H(x_i) = -∑ p_j log p_j (基于特征激活的概率分布)，保留Top-m个高熵token作为重要token子集
  - 步骤2: 对所有token计算变换诱导的一致性信号 s_i = f(x_i) (f为共享网络层，如线性投影)，得到标量信号；按s_i排序，使相似token相邻；以步长d采样K_d个token作为多样性token子集
  - 步骤3: 根据超参数α分配token预算: m = α·K, K_d = (1-α)·K，合并两个子集得到最终K个token
  - 输出: 紧凑视觉token集 Z' 送入LLM
- 关键模块/机制：
  - 熵基重要性估计模块：在无注意力图条件下识别信息量最大的视觉token；将token特征视为概率分布，计算每个token的熵值 H(x_i) = -∑_{j} p_{ij} log p_{ij}，其中p_{ij}通过softmax归一化特征向量得到。保留熵值最高的m个token，因其特征更丰富、退化更少。
  - 变换诱导一致性多样性模块：在免成对比较条件下获取视觉多样性token；对所有token应用同一个轻量变换层（如线性投影或单层MLP），得到标量信号s_i；由于变换的连续性，相似token产生相近的s_i。将token按s_i升序排列，然后以固定步长d（d = N/K_d）采样，确保覆盖不同信号区域，对应视觉内容的多样性。
  - 联合选择与预算分配：将重要性和多样性token合并为最终输出；通过超参数α ∈ [0,1]控制两种准则的token数：m = α·K个来自重要性模块，K_d = (1-α)·K个来自多样性模块，不足时补足。合并时去重，保留全部K个token。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 1. 输入视觉token序列 {x_i ∈ R^D}，目标保留K个token
  - 2. 熵计算: 对每个x_i，计算其特征维度上的softmax得到概率p_{ij}，然后 H_i = -Σ_j p_{ij} log p_{ij}
  - 3. 按熵降序排列，取Top-m个作为重要集S_imp
  - 4. 变换: 对所有token应用共享线性层 φ: R^D → R，得到标量信号 s_i = φ(x_i)
  - 5. 按s_i升序排列整个token序列，以步长 d = floor(N / K_d) 均匀采样（从随机起始位置偏移），得到多样性集S_div
  - 6. 合并S_imp和S_div，若总数不足K则从剩余token中补充（按熵降序优先），确保最终|S| = K
  - 7. 输出S作为压缩后的视觉token序列

  - 虚拟桶机制：处理非信息帧（噪声帧或背景异常帧），避免这些帧与语言嵌入错误对齐；在相似度矩阵中扩展一行和一列，用虚拟值s̃填充，对应虚拟桶。在OT耦合矩阵中，非信息帧的质量分配给虚拟桶，不参与与语言嵌入的匹配。

- 公式/目标函数/指标定义：
  - 最优传输目标（音频-文本）：max_{Q∈Q(μ_a,μ_t)} ⟨Q, S^{a→t}⟩ + λ_a H(Q)，其中S^{a→t}为余弦相似度矩阵，H(Q)为熵正则项
  - 最优传输目标（视觉-文本）：max_{Q∈Q(μ_v,μ_t)} ⟨Q, S^{v→t}⟩ + λ_v H(Q)
  - Sinkhorn求解：Q* = diag(u) K diag(v)，其中K_{i,j}=exp(-S_{i,j}/λ)，u和v通过迭代更新：u^{(k+1)}=p1/(K v^{(k)}), v^{(k+1)}=p2/(K^T u^{(k+1)})
  - 虚拟桶扩展相似度矩阵：S̃_{i,j}=S_{i,j} (i≤m, j≤n)，扩充行和列设为常数s̃
- 算法细节：
  - Sinkhorn算法：初始化u和v为全1向量，交替更新u和v直至收敛，每次迭代计算K = exp(-S/λ)，然后更新u和v。
  - 对比学习损失：使用OT耦合矩阵Q作为软标签，计算声学特征与语言嵌入相似度的交叉熵，以及视觉特征与语言嵌入相似度的交叉熵，两者加权求和。
  - 虚拟桶实现：将相似度矩阵扩展为(m+1)×(n+1)，新增行和列的元素设为s̃，然后在Sinkhorn迭代中保持对应分布质量。
- 训练/推理细节：
  - 训练阶段：声学编码器（Whisper）和视觉编码器（AV-HuBERT）冻结，LLM（LLaMA3.2-3B）使用LoRA微调。对齐模块和投影层可训练。
  - 损失函数：总损失为ASR损失（交叉熵或CTC）与对齐损失L_align的加权和。
  - 推理阶段：移除对齐模块，仅使用训练好的声学/视觉编码器、投影层和融合模块，输入到LLM进行自回归解码。

### 26. Slide-Level Active Learning Reduces Annotation Burden in H&E images
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.09831v1
- 方法流程：
  - 初始化：从190张WSI的未标注池中随机选择少量幻灯片作为初始训练集。
  - 训练分割网络：使用U-Net++（EfficientNet-B2编码器）在当前训练集上训练，损失函数为Dice损失+Focal损失。
  - 生成预测与不确定性：对未标注池中每张WSI的512×512 patches，用当前模型预测并计算每个patch的三种不确定性：预测熵、认知不确定性（MC dropout多次前向传播的方差）、前景感知不确定性。
  - 计算patch级混合得分：根据当前轮次，动态加权预测熵和认知不确定性，并对少数类别区域乘以奖励系数。剔除超过50%区域未标注的patches。
  - 聚合slide级得分：将属于同一WSI的所有patch得分通过top-k平均（取前K个最高不确定性patch的均值）得到幻灯片级得分。
  - 选择top-k幻灯片：将未标注池中得分最高的幻灯片（每轮约50张）移入训练集。
  - 迭代：重复步骤2-6，直到达到标注预算或性能饱和。
- 关键模块/机制：
  - 前景感知不确定性：抑制未标注背景对不确定性估计的干扰；由于WSI是部分标注的，只有部分区域有像素级标签。该模块在计算不确定性时，仅考虑那些在标注掩码内的像素区域，排除大量未标注背景（视为忽略区域）。patch级不确定性仅基于模型在标注组织区域上的预测计算。
  - 阶段自适应混合不确定性：在不同主动学习轮次动态融合认知不确定性和预测熵，平衡探索与利用；设当前轮次为r，总轮数为R。预测熵权重α = r/R，认知不确定性权重β = 1 - r/R。早期（r小）侧重认知不确定性（MC dropout），晚期侧重预测熵。混合不确定性 = α * (预测熵) + β * (认知不确定性)。
  - 类别感知获取奖励：缓解多类分割中的类别不平衡，优先选择包含稀有但诊断相关组织类别的patch；对于每个patch，计算模型预测中少数类别（如淋巴细胞、坏死）的概率平均值。将该平均值作为乘性奖励系数，与混合不确定性相乘得到最终patch得分。少数类别定义为训练集中面积占比低的类别。
- 公式/目标函数/指标定义：
  - 混合不确定性：U_hybrid = α * H(p) + β * U_epistemic，其中H(p)为预测熵，U_epistemic为MC dropout方差，α = r/R，β = 1 - r/R。
  - 最终patch得分：S_patch = U_hybrid * (1 + λ * p_minority)，其中p_minority为patch中少数类别的平均预测概率，λ为奖励强度超参数。
  - slide级得分：S_slide = (1/K) * Σ_{i=1}^{K} S_patch_i，其中K为取前K个最高得分的patch（默认K=10）。
  - 训练损失：L = L_Dice + γ * L_Focal，其中L_Dice为Dice损失，L_Focal为Focal损失，γ为平衡权重。
- 算法细节：
  - MC dropout：在每个patch上运行T次前向传播（T=10），计算softmax输出的均值作为预测概率，方差作为认知不确定性。
  - top-k聚合：对每张WSI所有有效patch（剔除>50%未标注区域后的patch）的得分排序，取前K个（K=10）的均值作为slide得分。
  - 动态权重：轮次r从0到R（R=6），α线性从0增加到1，β从1减小到0。
  - 奖励系数：λ设为0.5，少数类别定义为训练集中平均像素占比低于总体1%的类别（淋巴细胞、坏死等）。
- 训练/推理细节：
  - 分割网络：U-Net++，编码器为预训练EfficientNet-B2。
  - 输入patch大小：512×512@10x放大。
  - 损失函数：Dice损失 + Focal损失。
  - 优化器：Adam，初始学习率1e-4，每轮AL后重新从头训练？原文未明确，但通常重训练。
  - 批量大小：未明确，推测16或32。
  - 主动学习设置：总标注预算190张WSI，每轮选择50张（共6轮？实际标注100%需要190张，但文中说26%达到0.80 Dice，即50张，阶段可能包括初始随机和后续5轮）。

## 摘要
思维链（CoT）提示被广泛用作视觉语言模型（VLM）的测试时扩展策略，但目前尚不清楚当VLM生成长推理轨迹时，究竟是在扩展什么。我们提出一个问题：CoT是否需要持续访问图像标记，还是主要依赖于前向传播中早期已经可用的视觉信息？我们引入了视觉访问扫描（Visual Access Sweep），这是一种因果干预方法，沿着层深度和生成时间屏蔽从生成的标记查询到图像标记键的注意力，并将视觉访问边界（VAB）定义为能够保持任务准确性的最小访问区域。在Qwen2.5-VL和InternVL3的六种模型配置中，无论是无CoT的直接回答还是CoT提示，都表现出有限的VAB。在Qwen2.5-VL-32B以及14B和38B规模的InternVL3中，当CoT与无CoT的全访问目标进行比较时，其VAB层与无CoT边界最多相差两层，尽管其生成长度显著增加。这表明CoT并非主要通过延长整个推理轨迹中的直接图像标记访问来提升性能，而是通过扩展基于图像派生隐藏状态信息的语言端计算。我们进一步表明，CoT的收益受到感知读出能力的限制。当查询的视觉属性能够被模型可靠地读出时，CoT会有所帮助，但当读出不可靠时则不然。一个符号属性预言实验表明，一旦将真实属性作为文本提供，CoT可以改进计数能力，而一个单目标探测与解码检查表明，困难属性可以从隐藏状态中线性恢复，但模型本身难以输出。这些分析共同将瓶颈定位在读出环节而非计数环节。

## Abstract
Chain-of-Thought (CoT) prompting is widely used as a test-time scaling strategy for Vision-Language Models (VLMs), but it remains unclear what is extended when VLMs generate longer reasoning traces. We ask whether CoT requires continued access to image tokens, or whether it mainly operates over visual information already made available earlier in the forward pass. We introduce Visual Access Sweep, a causal intervention that masks attention from generated-token queries to image-token keys along layer depth and generation time, and define the Visual Access Boundary (VAB) as the minimal access region that preserves task accuracy. Across six model configurations from Qwen2.5-VL and InternVL3, both no-CoT direct answering and CoT prompting exhibit finite VABs. In Qwen2.5-VL-32B and InternVL3 at 14B and 38B scales, when CoT is evaluated against the no-CoT full-access target, its VAB layer differs from the no-CoT boundary by at most two layers, despite substantially longer generations. This suggests that CoT does not primarily improve performance by prolonging direct image-token access throughout the reasoning trace, but by extending language-side computation over image-derived hidden-state information. We further show that CoT gains are constrained by perceptual readout. CoT helps when the queried visual attribute can be reliably read out by the model, but not when that readout is unreliable. A symbolic-attribute oracle shows that CoT can improve counting once ground-truth attributes are supplied as text, while a single-object probe-vs-decode check shows that hard attributes can be linearly recoverable from hidden states yet difficult for the model itself to output. Together, these analyses place the bottleneck at readout rather than counting.

- **核心问题**：链式思维（CoT）提示在视觉语言模型（VLM）中是否通过延长对图像标记的直接访问来提升性能，还是主要依赖于早期前向传播中已获取的视觉信息进行语言侧计算？

- **背景意义**：现有研究仅观察注意力衰减等关联现象，无法区分“不再需要图像信息”与“获取失败”两种截然不同的状态。本文通过因果干预填补这一空白，为理解VLM推理中的视觉信息流提供新视角。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：通过因果干预操作（而非仅观察注意力值）判断直接图像标记访问的必要性。提出**视觉访问扫描（Visual Access Sweep）** 和**视觉访问边界（VAB）** 两个概念。
- **关键技术细节**：
  - **干预方式**：在自注意力机制中，对生成标记查询到图像标记键的注意力施加掩码。具体地，对于层$\ell$、生成步骤$t$，设置掩码矩阵$M_{\ell}$，当干预激活时$M_{\ell}^{ij} = -\infty$，使得softmax后的注意力权重为零。
  - **扫描策略**：沿两个维度进行扫描：**层深度**（$\ell$）和**生成时间**（$t$）。允许直接访问的区域为矩形$\{ \ell \leq \ell_{\text{cutoff}}, t \leq t_{\text{cutoff}}\}$，其他区域被屏蔽。
  - **VAB定义**：在容忍度$\epsilon$（取5个百分点）内保持任务准确性的最小访问区域$(\ell^*, \tau^*)$。定义三种准确率下降量：$\Delta_D$（Direct自身）、$\Delta_{\text{CoT}}$（CoT自身）、$\Delta_{DA}$（CoT对Direct全访问基线）。对应定义Direct边界$\ell^*_D$、CoT-own-max边界$\ell^*_{\text{CoT}}$、Direct-anchored CoT边界$\ell^*_{DA}$。通过比较$\Delta \ell^*$来量化CoT与Direct的边界差异。
- **控制实验**：设置**晚期层查询文本块控制**（同时屏蔽查询文本→图像注意）和**空汇点控制**（将移除的注意力质量重定向到虚拟非视觉槽），排除查询中介重读和注意力重分配等干扰项。

### 3. 实验设计：数据集、基准、对比方法

- **数据集/场景**：
  - **合成属性计数任务**：程序生成的多物体场景，每个物体有5个属性（颜色、形状、位置、角度、大小，各4类）。对同一场景下发5个不同属性的计数问题，固定推理操作（计数），仅改变视觉属性，隔离感知难度影响。
  - **真实图像场景图QA**：从GQA平衡验证集中抽取100个yes/no问题，减少分布偏差。用于验证VAB结构在真实图像上是否复现。
- **基准评估**：
  - **Direct提示**：直接输出答案，最小化中间输出。
  - **CoT提示**：要求输出中间推理步骤后给出答案。
  - 通过选项键准确率（合成任务）或二分类准确率（GQA任务）评估。
- **对比方法**：主要对比Direct与CoT两种提示策略下的VAB，并跨模型家族（Qwen2.5-VL 3B/7B/32B、InternVL3 8B/14B/38B）及跨架构（前缀融合与交叉注意力融合的Llama-3.2-11B-Vision-Instruct）进行验证。

### 5. 实验数量与充分性

- **实验数量**：覆盖6种模型配置（Qwen2.5-VL 3个尺度 + InternVL3 3个尺度）、两种任务类型（合成计数 + 真实图像GQA）、两种提示方式（Direct & CoT），并额外进行了交叉注意力融合模型（Llama-3.2-11B-Vision-Instruct）的试点扫描。共计生成约12组主实验的VAB热力图和边界数据。

### 6. 论文的主要结论与发现

1. **CoT不延长直接图像标记访问**：在Qwen2.5-VL-32B和InternVL3（14B/38B）上，CoT的VAB层与Direct的VAB层差异不超过2层（以Direct全访问准确率为锚），尽管CoT生成长度增加了约50倍。这证明CoT并非通过在整个推理轨迹中维持对图像标记的直接注意力来提升性能。
2. **CoT收益受限于感知读出能力**：在Qwen2.5-VL三个尺度上，多物体感知读出准确率与CoT增益呈正相关（3B: Pearson r=+0.92, 7B: r=+0.88, 32B: r=+0.51）。当所需属性无法可靠读出时（如角度、大小），CoT几乎没有增益甚至为负。
3. **瓶颈在读出而非计数**：预言绕过实验表明，一旦将真实属性以文本形式提供，CoT对所有属性（包括困难属性）都能带来一致增益，说明计数操作本身不是限制因素。单物体探测-解码差距实验进一步显示，困难属性可以从隐藏状态中线性恢复，但模型自身输出解码准确率很低（如角度解码0.383 vs 探测0.954），证明瓶颈在于从隐藏状态中读出可用符号。
4. **VAB结构普遍存在**：在所有测试模型（前缀融合和交叉注意力融合）及真实图像任务上均观测到有限VAB，说明该现象具有跨架构和跨域一致性。

### 7. 优点：方法或实验设计的亮点

- **因果干预范式**：从观察注意力值转向直接因果干预（掩码注意力），能够严格区分“是否必要”而非仅“关注程度”，提供了更可靠的机制解释。
- **二维扫描系统**：同时沿层深度和生成时间两个关键维度扫描，揭示了VAB的二维结构，比单维度分析更全面。
- **控制变量设计**：合成任务中固定计数操作、只改变视觉属性，巧妙分离推理难度和感知难度，使CoT增益差异可归因于感知因素。
- **多重验证链**：从宏观VAB结构到微观感知读出-增益相关性，再到预言绕过和探测-解码差距，层层递进，形成完整证据链。
- **跨模型规模与架构验证**：覆盖3个模型家族、6种不同尺度和两种融合架构（前缀融合、交叉注意力），增强结论的普适性。

### 8. 不足与局限

- **任务覆盖狭窄**：主要基于合成属性计数任务，真实图像仅使用GQA yes/no子集（100样本），缺乏需要迭代视觉检查的复杂多步推理场景（如计数变化、空间关系推理）。结论可能不适用于需要反复“看”的任务。
- **未解释内部机制**：VAB测量了直接图像注意力是否必要，但未揭示生成VAB的具体计算机制（例如是早期视觉信息被绑定到残差流，还是CoT将感知提取集中到早期生成标记）。需要辅以残差流干预。
- **交叉注意融合模型验证不完整**：对Llama-3.2-11B-Vision-Instruct仅进行了CoT侧扫描（Direct格式不可靠），未做完整比较，削弱了跨架构论证的强度。
- **感知读出诊断的间接性**：多物体读出准确率本身也是一个可能与CoT产生共同原因变量的代理指标（如模型对整个场景的理解能力），相关性不能完全证明因果关系。
- **实际部署限制**：虽然提出了一种粗略的CoT路由启发式（基于读出准确率阈值），但阈值未优化，且仅在两个尺度上验证，实用性需进一步评估。

### 1. Visual Access Boundaries in Vision-Language Model Reasoning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.12815v1
- 方法流程：
  - 1. 全访问基线：在不施加任何掩码的情况下，计算模型在直接推理或CoT推理下的任务准确率。
  - 2. 层-时间步扫描：对于每一层ℓ（从浅到深）和每一个生成时间步τ（从开始到结束），逐步掩码从该时间步之后的所有生成token查询到图像token键的注意力。
  - 3. 准确率测量：对每个(ℓ, τ)组合，计算掩码后的任务准确率，并与全访问基线比较，得到变化量Δ(ℓ, τ)。
  - 4. 边界确定：找到最小的ℓ和τ使得Δ(ℓ, τ) ≤ ε，记录为(ℓ*, τ*)，即为VAB。
  - 5. 边界比较：使用CoT-own-max准则（以CoT自身全访问准确率为基线）和direct-anchored准则（以直接推理全访问准确率为基线）比较不同条件下的VAB差异。
- 关键模块/机制：
  - Visual Access Sweep：核心因果干预方法，用于测量模型在推理时对图像token访问的依赖程度。；在推理过程中，对每个生成时间步τ和Transformer层ℓ，动态掩码从生成token查询到图像token键的注意力权重。具体地，对于所有大于τ的生成时间步生成的token，阻止其注意力到图像token键；同时，对于ℓ小于某一深度的层，也阻止相应注意力。通过逐步调整ℓ和τ，观察准确率变化，从而确定模型不再需要直接图像访问的边界。
  - Visual Access Boundary (VAB)：量化模型推理时所需的最小图像token访问区域。；VAB定义为满足条件Δ(ℓ, τ) ≤ ε的最小ℓ和τ组合，其中Δ(ℓ, τ)是掩码后准确率相对于基线的变化（ε=0.05）。ℓ代表层深度，τ代表生成时间步。边界后的层和时间步被认为不再需要直接的图像token访问。
  - 符号属性Oracle（Symbolic-Attribute Oracle）：用于诊断CoT改进是否受限于感知读出。；在计数任务中，将地面真值属性（如颜色、形状）作为文本输入提供给模型，而不是依赖视觉编码器提取。比较在此条件下CoT与直接推理的准确率，如果CoT提升更明显，则说明原始瓶颈在于从图像中可靠读出属性。
  - 单目标探测-解码检查（Single-Object Probe-vs-Decode）：验证硬属性（如精确计数）在隐藏状态中是否线性可恢复但模型难以直接输出。；从模型中间隐藏状态中提取向量，训练线性分类器预测该属性（如物体数量），同时记录模型在该属性上的原始输出准确率。如果线性分类器准确率高而模型输出准确率低，则表明属性信息存在于隐藏状态但模型读出机制不足。
- 公式/目标函数/指标定义：
  - Δ(ℓ, τ) = accuracy(ℓ, τ) - accuracy(full_access)，其中accuracy(ℓ, τ)为在时间步τ后掩码层ℓ及以上层的注意力后的任务准确率，accuracy(full_access)为无掩码基准准确率。
  - VAB定义为使Δ(ℓ, τ) ≥ -ε的边界，ε=0.05。实际使用Δ_CoT(ℓ, τ) ≤ ε的形式，其中ε为容忍阈值。
  - |Δℓ*_own| = |ℓ*_CoT - ℓ*_Direct|（基于CoT自身全访问目标）和|Δℓ*_DA| = |ℓ*_CoT - ℓ*_Direct|（基于直接推理全访问目标），用于量化边界层差异。
- 算法细节：
  - Visual Access Sweep算法：对于每个实验设置，先计算全访问准确率作为基线。然后，对每一层ℓ（从顶层到底层）和每一生成时间步τ（从最后一个token到第一个），构造注意力掩码矩阵，使得所有时间步大于τ的生成token在层ℓ之前的注意力被阻止到图像token键。逐步减小ℓ和τ，直到准确率下降超过0.05。记录临界点(ℓ*, τ*)。
  - 对于跨注意力融合架构（如Llama-3.2-11B-Vision-Instruct），干预改为掩码生成token查询到图像键的跨注意力，而非自注意力中的前缀图像token。
- 训练/推理细节：
  - 仅涉及推理阶段干预，无需额外训练。
  - 在Qwen2.5-VL（3B/7B/32B）、InternVL3（8B/14B/38B）和Llama-3.2-11B-Vision-Instruct上进行推理实验，使用CLEVR风格合成数据和GQA真实图像问答任务。
  - CoT提示采用少样本示例引导模型逐步推理；直接推理使用直接答案提示。

### 2. Multimodal Semantic-Aware Contrastive Learning For False Negative Mitigation in 3D Medical Imaging
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.14995v1
- 方法流程：
  - 输入：N对3D脑MRI和对应放射报告
  - 编码：MRI编码器（3D ResNet+自注意力）输出全局嵌入（最后层）和局部嵌入（倒数第二层）；文本编码器（Clinical Longformer）输出全局嵌入（[CLS] token）和局部嵌入（除[CLS]外所有token）
  - 全局对齐：计算全局图像与文本嵌入的余弦相似度矩阵M；计算报告嵌入的语义相似度矩阵S，经mask和softmax得到S̄；根据S̄计算自适应边距m_ij；计算全局双向对比损失L_global
  - 局部对齐：对局部文本和局部MRI嵌入应用交叉注意力（文本为query，MRI为key/value，反之亦然）得到加权局部嵌入；原始局部嵌入和加权局部嵌入分别计算局部对比损失，损失形式同全局但使用相同语义矩阵S̄，得到L_local
  - 总损失：L_total = α * L_global + β * L_local，α和β为可训练参数
  - 输出：预训练后的图像编码器用于下游任务微调
- 关键模块/机制：
  - 自适应边距生成器：根据语义相似性动态调整负样本对的对比边距；计算报告嵌入的余弦相似度S_ij，mask掉正样本（i=j设为-∞），softmax归一化得到S̄_ij，然后m_ij = m_base * (1 - S̄_ij)。当S̄_ij接近1时m_ij接近0，允许高语义相似负样本靠近；S̄_ij接近0时m_ij接近m_base（设定为0.5）。
  - 交叉注意力加权模块：生成局部层次的跨模态加权表征，用于局部对比学习；对于局部文本特征作为query，局部MRI特征作为key和value，通过多头交叉注意力得到加权局部文本特征；反之，MRI特征作为query，文本特征作为key和value得到加权局部MRI特征。加权后的特征与原始局部特征共同参与局部对比损失计算。
  - 全局-局部双层次对比损失：同时对齐全局语义和局部细节，增强表征鲁棒性；全局层次使用图像和文本的[CLS]或全局池化嵌入，局部层次使用来自编码器中间层的嵌入和交叉注意力加权嵌入。两层次均使用相同的语义相似性矩阵S̄指导，但局部层次的嵌入维度可能不同。损失函数为双向（i2t和t2i）的正负项之和，负项使用ReLU(margin - logit)^2形式。
- 公式/目标函数/指标定义：
  - L2归一化：Î_i = I_i / ||I_i||_2, T̂_i = T_i / ||T_i||_2
  - 报告余弦相似度：S_ij = (T_i · T_j) / (||T_i||_2 ||T_j||_2)
  - 自适应边距：m_ij = m_base * (1 - S̄_ij)，其中S̄_ij = softmax(mask(S_ij))
  - 对比logits：M_ij = Î_i^T T̂_j
  - 正对损失：L_pos = (1 - M_ii)^2
  - 负对损失：L_neg = Σ_{j≠i} [ReLU(M_ij - m_ij)]^2
- 算法细节：
  - 全局级：将N个样本的全局图像嵌入和文本嵌入L2归一化，计算点积矩阵M(N×N)。用文本嵌入计算余弦相似度矩阵S，对角设-∞，softmax得到S̄。对每个负样本(i≠j)，计算边距m_ij=0.5*(1-S̄_ij)。正项损失鼓励M_ii接近1，负项损失惩罚M_ij超过m_ij的部分（ReLU平方）。双向（i2t和t2i）平均得L_global。
  - 局部级：从编码器中间层提取局部嵌入（图像取倒数第二层特征图，文本取最后层除[CLS]外所有token）。通过交叉注意力生成加权局部嵌入：文本为query，图像为key/value得加权文本；图像为query，文本为key/value得加权图像。原始局部嵌入与加权局部嵌入分别以相同方式（同全局损失计算）与同一S̄矩阵计算局部对比损失，两个子损失相加得L_local。
  - 语义相似性矩阵S̄仅依赖全局文本嵌入，但被重用于局部层次，保证跨层次一致性。
  - 训练时α和β作为可训练参数，与网络权重同时更新，自动平衡全局和局部损失贡献。
- 训练/推理细节：
  - 预训练：batch size=16，优化器AdamW，base margin=0.5，训练400 epochs。图像编码器为3D ResNet+自注意力，文本编码器为Clinical Longformer。
  - 下游微调：仅微调图像编码器，冻结前两个卷积层，更新后两个卷积层和自注意力模块，训练5 epochs，使用交叉熵损失（标签平滑0.1，类别权重均衡），学习率：卷积骨干1e-4，分类头5e-4，StepLR每10 epoch衰减0.5。
  - 推理时：使用预训练图像编码器提取全局嵌入（最后一层）或局部嵌入（倒数第二层），但下游任务直接使用分类头，不涉及文本。
  - 评估：内部5折交叉验证，外部独立测试集（不同时间、不同MRI扫描仪）测试泛化性。

### 4. Can Multimodal Large Language Models Understand OCT?
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16609v1
- 方法流程：
  - 数据收集：从7个公开OCT数据集筛选4137张图像，确保质量控制和多样性
  - 问题构建：由眼科专家基于临床解读流程设计20个任务的多选题，每张图像可对应多个问题，共10076题
  - 能力分类：将每个问题归属到层次化分类体系中的特定任务与维度
  - 模型评估：对20个MLLMs（闭源、开源通用、医学领域）进行零样本评估，计算每个任务和维度的准确率
- 关键模块/机制：
  - 层次化能力分类体系：定义评估框架，将OCT理解分解为感知、认知、推理三个递进层次，每个层次包含细粒度任务；该体系由L1（3维度）、L2（9能力组）、L3（20具体任务）三级组成，例如L1-A感知包含L2-A1基本感知、L2-A2形态感知、L2-A3空间与量化感知，L3任务如T01模态感知、T07空间定向识别等。每个任务对应一个或多个选择题，用以测试特定能力。
  - 多选题数据构建与质量控制：提供标准化、专家验证的评估数据；从7个公开数据集（如OCTID、RETOUCH等）中筛选4137张图像，由眼科医生设计问题并验证答案，保证每道题有且仅有一个正确答案，覆盖20个任务。问题格式为4选1的多选题。
  - 模型评估协议：确保公平、可复现的模型比较；采用零样本评估，对每个模型输入图像和问题文本，使用统一提示格式，记录模型输出并与标准答案比对。评估20个模型，包括GPT-4o、Gemini、LLaVA、InternVL、HealthGPT等。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 无新算法提出，评估流程为：输入(OCT图像 + 问题文本) → MLLM编码生成回答 → 与标准答案比对计算准确率
  - 能力瓶颈分析：通过对不同层次任务准确率的对比，诊断模型在感知、认知、推理阶段的缺陷，例如感知任务准确率最高75.8%，推理任务仅42.9%
- 训练/推理细节：
  - 所有模型均采用零样本推理，不进行微调
  - 使用统一提示模板，例如'Choose the correct answer: (A) ... (B) ... (C) ... (D) ...'
  - 对于无法直接输出选项字符的模型，使用精确匹配或正则匹配提取答案

### 5. Look Clearly Before Answering: Mitigating Hallucinations in LVLMs via Saliency-Driven Perceptual Realignment
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16841v1
- 方法流程：
  - 输入：图像I、查询Q、系统提示S拼接为完整输入序列
  - 阶段1（感知干预）：在语言骨干的注意力层中，通过梯度显著性图识别沉没token，重新分配注意力权重到显著视觉token（SDAR）
  - 阶段2（记忆干预）：将查询相关显著性图注入KV缓存的key部分，增强缓存中视觉表示的查询相关性（SDCA）
  - 阶段3（解码干预）：从早期隐藏状态构建语言先验参考，对比约束解码概率（PCD）
  - 输出：最终解码序列，减少幻觉
- 关键模块/机制：
  - Saliency-Driven Attention Redistribution (SDAR)：修复多模态交互中的注意力劫持，将注意力从非语义沉没token重新分配到显著视觉特征；对每层注意力权重计算梯度显著性，识别沉没token（注意力集中但非语义的token），然后将其注意力权重按比例重新分配给其他token（特别是视觉token），以恢复关键视觉证据。
  - Saliency-Driven Cache Alignment (SDCA)：增强KV缓存中视觉表示的查询相关性，改善自回归生成中对相关视觉特征的检索；在预填阶段，利用查询token对视觉token计算显著性图，并将此显著性图注入key缓存中，使后续生成时查询相关的视觉特征更容易被注意力机制激活。
  - Prior-Constrained Contrastive Decoding (PCD)：抑制语言先验主导的预测，通过对比解码约束语言先验；利用早期生成的隐藏状态（如第一个token的隐藏状态）构建一个纯语言先验参考分布，在每一步解码时，从原始logits中减去加权后的参考logits，惩罚与语言先验一致但与视觉证据不符的预测。
- 公式/目标函数/指标定义：
  - 下一个token概率：y_t ~ p(y_t|I, Q, y_<t) = softmax(φ(H^L_t))
  - 注意力权重计算：AW^l_i = softmax(Q_i K_i^T / sqrt(d_k) + M)
  - KV缓存更新：K^l_t = [K^l_{t-1}; K^l_t], V^l_t = [V^l_{t-1}; V^l_t]
- 算法细节：
  - SDAR：对每个注意力头，计算注意力权重相对于损失（如语言模型损失）的梯度，得到每个token的显著性分数。对沉没token（显著性低但注意力高），将其注意力权重按其他token的显著性分数重新归一化。
  - SDCA：在预填阶段，计算查询token（如最后一个系统提示token）与所有视觉token的注意力权重作为显著性图；将该显著性图与key缓存相乘或加性注入，调整key表示。
  - PCD：首先从早期解码步骤（如步骤1）的隐藏状态中提取语言先验向量，作为参考；在后续每一步，计算参考模型（由该先验向量生成的logits）与当前模型logits的差异，减去先验项以抑制语言偏差。
- 训练/推理细节：
  - SDPR是完全训练无关的推理时框架，无需微调或额外训练
  - SDAR和SDCA均在前向传播过程中进行，仅需少量额外计算
  - PCD在每个解码步执行对比操作，引入的计算开销极小

### 6. SkyVLaM: Multimodal Large Language Model for UAV Video Understanding in Remote Sensing
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17386v1
- 方法流程：
  - 输入：无人机视频帧和查询文本
  - 提取patch级视频表示
  - 时态基础感知器从patch表示构建稀疏令牌，并正则化稀疏基础以鼓励互补时态线索
  - 自适应选择时态一致的密集片段用于高分辨率检查
  - 将稀疏令牌和密集令牌联合输入大语言模型
  - 大语言模型输出查询条件分割结果
- 关键模块/机制：
  - Temporal Basis Perceiver：从patch级视频表示构建稀疏令牌，并通过正则化稀疏基础捕获互补时态线索；输入patch级视频表示，通过感知器生成稀疏基础令牌，应用正则化鼓励基础之间正交或互补，以表示不同的时间模式。
  - Adaptive Dense Segment Selection：自适应选择时态一致的密集视频片段进行高分辨率检查，提供细粒度细节；基于稀疏令牌或查询条件，从完整视频中选出时态连贯的密集片段，用于提取高分辨率特征。
  - Large Language Model (LLM) Joint Processing：联合处理稀疏和密集令牌，实现查询条件分割；将稀疏令牌和密集片段特征作为视觉输入，与查询文本共同输入LLM，通过自回归或编码器-解码器生成分割掩码。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 稀疏令牌构建：通过时态基础感知器，将视频patch序列映射为少量基础令牌，每个基础捕获独特时间模式

### 16. Attention-Free and Lightweight Token Reduction for Efficient Vision-Language Models

- 方法流程：
  - 输入：视觉编码器输出的N个令牌特征序列X。
  - 步骤1：对每个令牌计算熵值（基于特征激活的softmax分布），保留重要性最高的前αK个令牌。

### 21. UMSS: Towards Unsupervised Multi-modal Semantic Segmentation
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.12372v1
- 方法流程：
  - 输入RGB图像I和辅助模态X（如深度）
  - 双模态分别通过冻结的DINOv3骨干提取密集特征图frgb和fX
  - 特征图经模态特定网络（MSN）精炼
  - 精炼后的特征通过可学习的Conv Fusion模块Ψ融合得到ffus
  - 融合特征经分割头S投影到低维嵌入空间得到s
  - 通过CMCS损失训练，其中s受frgb和fX的结构相关性约束，对辅助模态使用CMH缓冲
  - 最终聚类得到语义分配
- 关键模块/机制：
  - Cross-modal Correspondence Synergy (CMCS)：训练目标，将单模态的结构相关性蒸馏到统一嵌入空间；对于训练对(G1,G2)，计算RGB特征的对应张量F_rgb和辅助特征的F_X，以及融合嵌入的对应S。损失为Lrgb和LX的加权和，其中LX使用经CMH处理的嵌入sX计算。损失形式：L=-Σ(F-b)⊙max(0,S)。
  - Cross-modal Harmonizer (CMH)：缓解模态冲突，在辅助模态监督和融合嵌入之间提供可学习缓冲；CMH是一个轻量级两层卷积网络，将融合嵌入s映射为sX=CMH(s)。在计算LX时，使用sX与目标嵌入的余弦相似度SX，而非直接使用s，从而允许自适应吸收辅助线索而不扭曲主语义流形。
  - Modality-Specific Networks (MSN)：对单模态特征进行精炼；由两个卷积层和ReLU激活组成，对frgb和fX分别处理。
  - Conv Fusion Module Ψ：融合精炼后的多模态特征；将MSN输出的特征拼接后通过卷积层（cat+conv），生成融合特征ffus。
  - Segmentation Head S：将融合特征投影到低维嵌入空间；由两个卷积层和中间激活层组成，输出低维语义嵌入s。
- 公式/目标函数/指标定义：
  - 特征对应余弦相似度: F_hwij = (f1_hw^T f2_ij) / (||f1_hw|| ||f2_ij||)
  - 分割对应余弦相似度: S_hwij = (s1_hw^T s2_ij) / (||s1_hw|| ||s2_ij||)
  - 蒸馏损失: L = -Σ_{hwij} (F_hwij - b) ⊙ max(S_hwij, 0)，其中b为偏置（依对类型不同）
  - CMCS损失: L_cmcs = L_rgb + λ L_X
  - L_rgb = -Σ (F_rgb_hwij - b) ⊙ max(0, S_hwij)
  - L_X = -Σ (F_X_hwij - b) ⊙ max(0, S_X_hwij)，其中S_X使用经CMH处理的嵌入计算
- 算法细节：
  - 训练对采样扩展：将原USS的Self/KNN/Random对扩展到多模态组，每组包含RGB和辅助模态。
  - CMH设计为轻量级两层卷积，作为可学习缓冲，将主嵌入s映射为sX。
  - 总损失由两部分构成，分别对应RGB和辅助模态的结构蒸馏，通过λ平衡。
  - 在训练中，冻结DINOv3骨干，仅优化MSN、Conv Fusion、分割头S和CMH。
- 训练/推理细节：
  - 使用冻结的DINOv3作为骨干网络。
  - 采用5-crop预处理增强分辨率。
  - 优化器：Adam，学习率5e-4，batch size 32。
  - 训练时间：单张NVIDIA RTX 5090 GPU上<2小时。
  - 超参数通过200次贝叶斯优化调整。

### 24. Screening Is Effective for Visual Recognition
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.13983v1
- 方法流程：
  - 1. 图像分块与嵌入：将输入图像划分为非重叠patch，通过线性投影得到patch token序列X ∈ R^{N×d}，并记录每个patch的二维坐标p_n=(x_n, y_n)
  - 2. 查询、键、值、门控投影：对每个head，将patch token分别投影为查询、键、值、门控向量，并进行单位长度归一化
  - 3. 2D RoPE编码：将查询和键向量的特征维度分为水平和垂直两组，每组按对应坐标旋转，得到位置编码后的查询˜q和键˜k
  - 4. 相关性计算：计算查询˜q_n与所有键˜k_m的点积得到相似度s_{nm}
  - 5. Trim变换：对相似度s_{nm}应用Trim变换（截断/阈值处理）得到内容相关性α_{nm}
  - 6. 空间软掩码：根据patch间欧氏距离d_{nm}和可学习窗口w计算空间权重m_{nm}，与α_{nm}相乘得到最终相关性α^s_{nm}
  - 7. 门控聚合：以α^s_{nm}为权重对值向量加权求和，得到聚合特征；同时用门控向量经SiLU和Tanh激活后调制聚合特征，再经线性投影输出
- 关键模块/机制：
  - 2D RoPE (二维旋转位置编码)：将空间位置信息注入查询-键相似度，使模型感知patch间的相对空间关系；将查询和键向量的特征维度分为水平、垂直两组，每组内每对维度按公式R(p_a^n, t)旋转，旋转角度依赖于patch坐标p_a^n和频率θ_t=10000^{-t/(d_h/4)}，分别得到两组旋转后的向量，拼接形成位置编码后的查询˜q和键˜k。
  - 空间软掩码 (Spatial Softmask)：根据patch间的欧氏距离，为相关性分数施加空间衰减权重，限制每个patch的聚合范围；定义可学习窗口大小w = exp(s_w)+1，对每个查询-键对(p_i, p_j)，计算欧氏距离d_{ij}，当d_{ij} < w时，m_{ij}=0.5*(cos(π d_{ij}/w)+1)，否则为0。该权重乘以内容相关性α_{ij}得到最终相关性α^s_{ij}。
  - Trim变换与TanhNorm：替代softmax，实现绝对相关性估计，排除低相关patch；Trim变换对原始相似度s_{ij}进行裁剪或阈值处理（原文未详述具体函数，但指出与原始Screening一致），得到α_{ij}；然后应用TanhNorm进行归一化（原文未详述）。
  - 门控机制 (Gating)：对聚合后的特征进行通道级调制，增强有用信息，抑制无用信息；由门控线性投影、SiLU激活和Tanh激活组成，输出与聚合后的值向量逐元素相乘，再经最终线性投影输出。
- 公式/目标函数/指标定义：
  - 旋转位置编码：R(p_a^n, t) = [[cos(θ_t p_a^n), -sin(θ_t p_a^n)], [sin(θ_t p_a^n), cos(θ_t p_a^n)]]
  - 频率定义：θ_t = 10000^{-t/(d_h/4)}
  - 位置编码后的查询/键：˜q_{n,a,t} = ¯q_{n,a,t} R(p_a^n, t)^⊤, ˜k_{n,a,t} = ¯k_{n,a,t} R(p_a^n, t)^⊤
  - 相似度：s_{nm} = ˜q_n ˜k_m^⊤
  - 欧氏距离：d_{ij} = |p_i - p_j|_2
  - 窗口大小：w = exp(s_w) + 1
- 算法细节：
  - 查询/键/值/门控的线性投影后，对查询和键进行单位长度归一化
  - 2D RoPE：将查询和键的d_h维分为两个d_h/2组，分别对应水平和垂直轴；每组内每两维按坐标旋转
  - Trim变换：对相似度s进行截断（具体细节参考原始Screening论文）
  - 空间软掩码：按式(7)计算，使得距离w内的patch获得余弦衰减权重，之外的patch权重为0，不参与聚合
  - 门控聚合：聚合后的特征为∑_m α^s_{nm} v_m，然后与门控输出（经过SiLU和Tanh）逐元素相乘，再经线性投影
- 训练/推理细节：
  - 模型架构：12层，3个head，嵌入维度192，patch size 16×16
  - 训练数据：ImageNet-1k和CIFAR-100，从头训练
  - 优化器：AdamW
  - 训练配置：ImageNet-1k全局batch size 1024，CIFAR-100全局batch size 512；训练300 epochs；前5 epochs学习率warmup，之后余弦退火
  - 数据增强：仅随机裁剪和水平翻转，无高级增强或正则化
  - ViT-Tiny/16对比：使用相同模型规模，但ViT使用可学习的绝对位置编码，VisionScreen使用2D RoPE；ViT的查询/键维度为64，VisionScreen为16

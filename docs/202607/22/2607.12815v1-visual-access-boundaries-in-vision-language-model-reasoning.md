## 摘要
思维链（CoT）提示被广泛用作视觉语言模型（VLM）的测试时扩展策略，但当VLM生成更长的推理轨迹时，尚不清楚究竟扩展了什么。我们探究CoT是否需要持续访问图像标记，还是主要利用前向传播早期已提供的视觉信息。我们引入了视觉访问扫描（Visual Access Sweep），这是一种因果干预方法，沿着层深度和生成时间掩蔽从生成的token查询到图像token键的注意力，并将视觉访问边界（VAB）定义为保持任务准确性的最小访问区域。在来自Qwen2.5-VL和InternVL3的六种模型配置中，无论是否使用CoT直接回答，还是CoT提示，都表现出有限的VAB。在Qwen2.5-VL-32B以及14B和38B规模的InternVL3中，当CoT与无CoT的完全访问目标进行对比评估时，其VAB层与无CoT边界的差异最多为两层，尽管生成了更长的序列。这表明，CoT并非主要通过在整个推理过程中延长对图像标记的直接访问来提高性能，而是通过扩展语言端对图像派生隐藏状态信息的计算。我们进一步表明，CoT的收益受到感知读取（perceptual readout）的限制。当询问的视觉属性能够被模型可靠地读取时，CoT有帮助，但当读取不可靠时则不然。一个符号属性预言机（symbolic-attribute oracle）表明，一旦真实属性以文本形式提供，CoT可以改善计数，而单对象探测与解码检查（single-object probe-vs-decode check）表明，困难属性可以从隐藏状态中线性恢复，但模型自身却难以输出。总之，这些分析将瓶颈定位在读取环节而非计数环节。

## Abstract
Chain-of-Thought (CoT) prompting is widely used as a test-time scaling strategy for Vision-Language Models (VLMs), but it remains unclear what is extended when VLMs generate longer reasoning traces. We ask whether CoT requires continued access to image tokens, or whether it mainly operates over visual information already made available earlier in the forward pass. We introduce Visual Access Sweep, a causal intervention that masks attention from generated-token queries to image-token keys along layer depth and generation time, and define the Visual Access Boundary (VAB) as the minimal access region that preserves task accuracy. Across six model configurations from Qwen2.5-VL and InternVL3, both no-CoT direct answering and CoT prompting exhibit finite VABs. In Qwen2.5-VL-32B and InternVL3 at 14B and 38B scales, when CoT is evaluated against the no-CoT full-access target, its VAB layer differs from the no-CoT boundary by at most two layers, despite substantially longer generations. This suggests that CoT does not primarily improve performance by prolonging direct image-token access throughout the reasoning trace, but by extending language-side computation over image-derived hidden-state information. We further show that CoT gains are constrained by perceptual readout. CoT helps when the queried visual attribute can be reliably read out by the model, but not when that readout is unreliable. A symbolic-attribute oracle shows that CoT can improve counting once ground-truth attributes are supplied as text, while a single-object probe-vs-decode check shows that hard attributes can be linearly recoverable from hidden states yet difficult for the model itself to output. Together, these analyses place the bottleneck at readout rather than counting.

# 视觉语言模型推理中的视觉访问边界（Visual Access Boundaries in Vision-Language Model Reasoning）——论文总结

## 1. 论文的核心问题与整体含义

- **研究动机**：思维链（Chain-of-Thought, CoT）提示在视觉语言模型（VLM）中被广泛用于测试时扩展（test-time scaling），但其提升性能的机制尚不明确。具体而言，CoT的延长推理过程是否依赖于对图像token的持续直接访问（即后续生成的token不断通过注意力机制重新读取图像），还是主要利用前向传播早期已提取并存储在隐藏状态中的视觉信息？
- **核心问题**：CoT帮助VLM推理时，究竟“扩展”了什么？是扩展了直接图像访问的窗口，还是扩展了语言侧对已编码视觉信息的计算？
- **整体含义**：该研究通过因果干预而非仅观察注意力衰减，揭示了CoT提升并非源于更长时间地直接“看”图像，而是依赖于语言侧对早期视觉信息的推理能力。此外，CoT增益受限于模型对视觉属性的“感知读取”（perceptual readout）能力，即能否将视觉信息可靠地转换为可用符号。

## 2. 论文提出的方法论

- **核心思想**：定义“视觉访问边界”（Visual Access Boundary, VAB）作为度量——即在不显著降低任务准确率的前提下，可以屏蔽从生成token到图像token的直接注意力的最小区域（由层深度和生成时间两个维度定义）。通过沿这两轴进行系统的因果干预（掩码注意力），判断哪些直接视觉访问是功能上必要的。
- **关键技术细节**：
  - **Visual Access Sweep**：对每个生成步骤 t 和每个层 ℓ，设定两个截止点（t_cutoff, ℓ_cutoff）。仅当 t ≤ t_cutoff 且 ℓ ≤ ℓ_cutoff 时，允许生成token查询对图像token键的直接注意力；否则将对应注意力权重强制设为0（掩码为 -∞ 在 softmax 前）。
  - **边界定义**：在准确率下降不超过容忍度ε（取5个百分点）的前提下，最小的 (ℓ*, τ*) 对（τ为有效生成token窗口）即为VAB。
  - **三种比较指标**：
    - Δ_D(ℓ, τ): Direct full-access 准确率与干预后Direct准确率之差。
    - Δ_CoT(ℓ, τ): CoT full-access 准确率与干预后CoT准确率之差。
    - Δ_DA(ℓ, τ): Direct full-access 准确率与干预后CoT准确率之差（用于“直接锚定”比较）。
  - 通过直接锚定准则（Direct-anchored）比较CoT边界与Direct边界，控制二者full-access水平的差异。
- **控制实验**：
  - 后期层查询文本块控制（Late-layer query-text block）：额外屏蔽查询文本到图像token的注意力，排除通过查询文本间接重新读取图像的可能。
  - 空汇控制（Null-sink control）：将去除的图像注意力质量重定向到一个虚拟非视觉汇点，排除注意力质量重新分配导致的伪影。
  - 这些验证实验表明VAB结构并非干预伪影。

## 3. 实验设计

- **数据集/场景**：
  - **受控合成属性计数任务（Controlled attribute-counting tasks）**：程序生成图像，每幅包含多个对象，每个对象有5个属性（颜色、形状、位置、角度、大小，各4类）。固定推理操作为计数，仅改变询问的属性，以便隔离感知难度对CoT增益的影响。每个场景对应5个问题（每属性一个）。评价指标为多选选项键准确率。
  - **真实图像场景图QA任务（GQA-derived real-image yes/no task）**：从GQA验证集平衡子集中选取二值答案问题（yes/no），共100个样本，标签平衡。用于验证VAB现象是否在真实图像上出现。
- **Benchmark**：无标准公开基准；采用受控合成任务（类似CLEVR风格）和GQA子集进行内部比较。
- **对比方法**：
  - Direct 提示（无中间推理，仅要求给出最终选项键） vs. CoT 提示（要求逐步思考再回答）。
  - 仅对比自身两种模式，未与其他VLM推理增强方法（如主动感知、视觉记忆等）进行比较，因为论文目的是诊断性分析而非竞争性评测。
- **评估模型**：
  - Qwen2.5-VL：3B、7B、32B（前缀融合架构，Qiwen ViT + MLP投影）
  - InternVL3：8B、14B、38B（InternViT + MLP投影）
  - 额外交叉注意力融合模型：Llama-3.2-11B-Vision-Instruct（作为鲁棒性检查，仅做CoT侧扫描）。
- **实验规模**：
  - 合成计数任务：每个属性每个模型规模均执行完整二维扫描（层×生成时间）或一维层扫描（对Direct）。
  - 控制实验：两个，分别在Qwen2.5-VL-32B颜色计数上进行。
  - 感知读取分析：多对象读取任务、单对象探测-解码差距分析。
  - 符号属性预言机实验：在Qwen2.5-VL-3B上去掉图像输入，将地面真实属性序列化为文本。
  - 选择CoT路由实验：基于读取阈值的自适应策略。
  - GQA实验：仅在Qwen2.5-VL-32B上进行。

- **实验组数**：主干实验覆盖6种模型配置（Qwen2.5-VL×3 + InternVL3×3），每个模型通常测试颜色计数和形状计数两个基本任务（因其他属性读出不稳而在部分模型中仅报告易读属性）。此外包括角度计数（作为极限情况）、真实图像任务、交叉注意力架构检查、两个控制实验、感知读取分析（三尺度各五个属性点）、符号预言机实验（两个条件）、误差分类、敏感性分析（4个ε值）、选择路由实验（2个模型）。

  - **正面**：跨两大模型家族和多个规模，覆盖了前缀融合和交叉注意力架构；控制实验排除常见伪影；敏感性分析显示核心比较对ε选择稳健；真实图像验证扩展了外部有效性。

## 6. 论文的主要结论与发现

1. **VAB普遍存在**：无论是Direct还是CoT，在测试的所有模型/任务设置下，均存在有限的VAB。后期层和后期生成token的直接图像访问被移除后，准确率仍保持，只在早期层和早期token处才发生急剧下降。
2. **CoT不延长必要直接图像访问**：在最大模型（Qwen2.5-VL-32B, InternVL3-14B/38B）上，CoT的VAB层与Direct的VAB层差异不超过2层（在直接锚定准则下），尽管CoT生成token数增加约50倍。这表明CoT不是通过延长对整个推理轨迹的直接图像访问来提高性能，而是通过利用已在隐藏状态中传递的图像派生信息进行更长时间的语言侧计算。
3. **感知读取是CoT增益的瓶颈**：在Qwen2.5-VL上，每个属性的CoT增益与该属性的多对象读取准确率呈正相关（Pearson r=0.92/0.88/0.51 在3B/7B/32B）。当模型不能可靠读出视觉属性（如角度、大小、位置的低阶读取）时，CoT增益很小或为负。
4. **符号预言机验证了计数操作非限制因素**：在无图像输入、直接提供地面真值属性的条件下，CoT在所有属性（包括困难属性）上均一致提升，表明一旦属性信息以可用符号形式提供，语言侧的计数推理就能受益于CoT。瓶颈是感知读出步骤。
5. **单对象探测-解码差距**：困难属性（角度、位置、大小）可以从隐藏状态中通过线性探针高准确率预测，但模型自身解码输出准确率低，进一步证实问题在于模型能否将编码的视觉信息转化为可用符号，而不在于信息缺失。
6. **选择CoT路由可行**：基于读取准确率简单阈值（>0.5），可保留CoT大部分增益（75-87%）而节省约一半输出token成本。

## 7. 优点

- **因果干预研究范式**：从观察注意力衰减到主动遮蔽必要性的因果测试，有力区分了关联与因果。
- **精确定义了“视觉访问”**：通过层和生成时间两个维度操作，明确了直接注意力通道的功能必要性。
- **控制实验完善**：后期层查询文本块控制和空汇控制排除了常见流偏（通过查询文本间接读取或注意力重分布）。
- **将感知读取和计数操作分离**：通过固定计数操作、变化视觉属性，结合预言机实验和探测-解码分析，严格定位瓶颈为读出不计数。
- **跨家族和规模验证**：覆盖两个主流VLM家族和多个规模，以及交叉注意力架构的初步检查，增加结论稳健性。
- **提供实用启发**：选择CoT路由启发法具有实际效率改进意义。

## 8. 不足与局限

- **实验覆盖有限**：
  - 主要使用合成计数任务，复杂度低；CoT在更复杂多跳推理场景（如空间场景图推理、文档理解）的行为未验证。
  - GQA仅使用100例二值答案子集，统计效力不足，且CoT准确性反而略低于Direct，虽然不影响VAB但削弱了CoT增益模式的检验。
  - 角度、大小、位置等属性因读出不准确导致VAB不清晰，论文将其列为极限情况，但未提出解决方案或深入分析为何CoT无法改善这些属性的读数。
- **方法假设**：VAB仅衡量直接注意力通道的必要性；视觉信息通过残差流间接传播的容量未受干预，因此VAB并不排除后期层仍使用图像派生信息。论文承认需进一步干预残差流来区分不同机制。
- **可能偏差**：
  - 提示模板差异可能影响CoT vs. Direct公平性（CoT要求“逐步思考”可能鼓励更详细输出，但也可能引入格式噪声）。
  - 贪心解码可能限制CoT表现，其他解码策略（束搜索、抽样）未探索。
  - 所有模型为公开冻结检查点，可能存在预训练或对齐阶段的隐性偏差。
- **应用限制**：
  - 不能直接推广到需要迭代视觉检查的任务（如多视图推理、细节放大），这些任务可能是CoT的另一作用方式。
  - 实验未涵盖新型架构（如MoE、视觉专家模块）或训练过程中特别强调CoT推理的模型（如LLaVA-CoT），结论可能不通用。
- **算力披露尚有提升空间**：虽然给出了GPU小时总数，但未细分为每个实验的实际运行时间，也未说明是否包含开发调试开销。

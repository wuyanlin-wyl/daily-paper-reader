### 2. Robustifying Vision-Language Models via Test-Time Prompt Adaptation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09450v1
- 方法流程：
  - 输入对抗样本x_t，通过随机裁剪、缩放、水平翻转等数据增强生成N个视图{x_{t,n}}_1^N；输出增强图像集。
  - 用CLIP图像编码器提取每个视图的视觉特征{x_hat_{t,n}}；同时为每个类别k由M个可学习提示（初始化为"a photo of a"+类别名）通过文本编码器得到文本特征{z_{k,m}}，形成视觉分布P和文本分布Q。
  - 计算视觉分布与每个文本原型分布之间的最优传输距离d_OT(P, Q_k; C)，其中C为余弦代价矩阵；通过Sinkhorn算法优化传输计划，最小化对齐损失。
  - 根据对齐损失和额外熵正则项优化提示参数ω；同时使用动态缓存：将当前样本对齐后的低熵预测（熵<γ=0.8）及其特征存入缓存，后续样本利用缓存中累积的分布进行在线更新。
- 关键模块/机制：
  - 多原型分布对齐模块：将单点特征匹配扩展到分布级结构对齐，增强对对抗扰动的鲁棒性；对于每个类别k，构建M个可学习提示（M=4），得到M个文本特征z_k^m。将测试图像的N个增强视图特征作为视觉分布P，文本特征作为分布Q_k。定义代价矩阵C中元素为余弦距离。通过熵正则化最优传输计算d_OT(P, Q_k; C)，使用Sinkhorn算法迭代求解传输计划T，实现对分布间语义对应关系的鲁棒度量。
  - 动态缓存模块：在线积累可靠样本特征，为后续样本提供更稳定的分布先验；维护一个缓存池，初始为空。对于每个测试样本，完成分布对齐后，计算预测熵；若熵低于阈值γ=0.8，则认为该样本可靠，将其视觉特征和对应的优化后文本特征存入缓存。后续样本到来时，将自身增强视图分布与缓存中累积的分布联合进行对齐，缓存大小无上限（实验中累积所有低熵样本）。
- 公式/目标函数/指标定义：
  - 预测概率：p(k|x_t^n; ω) = exp(cos(x_t^n, z_k)/τ) / Σ_j exp(cos(x_t^n, z_j)/τ)
  - TPT熵最小化目标：ω* = argmin_ω [ - Σ_k ¯p(k|x_t; ω) log ¯p(k|x_t; ω) ]
  - 熵正则化OT距离：d_OT(P, Q; C) = min_{T∈Π(a,b)} ⟨T, C⟩ - λ h(T)
  - 对抗攻击目标：x' = argmax_{||x'-x||_p≤ε_adv} L_CE(p(·|x'; z), y)
- 算法细节：
  - 对抗样本生成：使用PGD攻击，L∞约束ε=4.0，7步迭代
  - 多提示生成：M=4个可学习提示，初始化为"a photo of a"，也可用LLM生成类别描述
  - 分布对齐算法：采用Sinkhorn算法计算OT距离，λ=0.1（默认），迭代次数20
  - 动态缓存更新：每次TTA后计算预测熵，若小于0.8则将该样本的特征及当前提示加入缓存；后续样本对齐时，将视觉分布与缓存中所有文本原型分布进行OT对齐
  - 参数优化：使用AdamW优化器，学习率0.005，单步TTA（每个样本只更新一次提示）
- 训练/推理细节：
  - 训练：仅更新提示参数ω，CLIP图像和文本编码器完全冻结
  - 推理：每个测试样本独立自适应，不依赖其他样本（实例级TTA），但动态缓存跨样本累积
  - 数据增强：N=64个增强视图（包括原始图），含随机裁剪、缩放、水平翻转
  - 提示数量M=4，文本模板初始化为"a photo of a"
  - 优化器AdamW，学习率0.005，单步迭代
  - 动态缓存熵阈值γ=0.8

### 3. MC-RAG System: A Structure-Driven RAG System for Multi-Constraint Queries
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10151v1
- 方法流程：
  - 数据层：从原始知识中提取实体和关系，构建知识图谱，并构建路径级索引；每条路径编码为标签嵌入（语义）和主导嵌入（GNN结构模式），所有路径嵌入组织在R*-Tree中
  - 检索层：输入自然语言查询，转换为查询图；将查询图分解为若干路径；在R*-Tree中进行路径级匹配；聚合匹配路径并进行验证，输出满足所有约束条件的候选子图
  - 生成层：将候选子图作为结构化上下文传递给生成模块，产生最终答案
  - 用户层：交互式可视化界面，实时展示查询解析、子图检索和答案生成全过程
- 关键模块/机制：
  - 数据层 - 双嵌入与索引：为子图匹配提供语义与结构混合表示和高效检索索引；每条路径编码为两个嵌入：标签嵌入（节点语义）由预训练语言模型生成；主导嵌入由图神经网络（GNN）学习路径的结构模式。所有路径嵌入存储在R*-Tree中，支持多维空间搜索。
  - 检索层 - 查询图分解与路径匹配：将多约束自然语言查询转化为结构化查询图，并通过子图匹配检索相关知识；自然语言查询首先通过语义解析转换为查询图；查询图被分解为若干路径；每条路径在R*-Tree中匹配相似路径（基于双嵌入相似度）；所有匹配路径聚合形成子图，经约束验证（检查条件一致性）后输出候选子图。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 路径编码：每条路径p生成标签嵌入e_label(p)和主导嵌入e_dom(p)，用于度量路径间的语义与结构相似度
  - R*-Tree索引：将每条路径的多维嵌入向量作为键，构建R*-Tree，支持近似最近邻搜索
  - 查询图分解：将查询图按边或连接点拆分为一组路径集Q_paths
  - 路径匹配：对Q_paths中每条路径，在R*-Tree中检索相似路径集，通过综合相似度阈值筛选
  - 子图聚合：利用图匹配算法（如图同构或子图同构）将匹配路径组合成候选子图，校验是否包含所有约束实体和关系
  - 如果候选子图空缺，则退化为基于语义嵌入的软匹配

### 4. Toward Efficient Weakly Supervised Semantic Segmentation Using Only Low-Magnification Histopathological Images
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10783v1
- 方法流程：
  - 输入原始40×病理图像块（224×224），降采样至20×（112×112）或10×（56×56）。
  - 重建阶段：将低分辨率图像通过bilinear插值或STAR-RL重建至40×尺寸（224×224）。
  - 弱监督分割阶段：将重建后的图像输入WSSS-Tissue框架，使用patch-level多标签分类标签训练，生成伪掩码并训练分割网络。
  - 评估：使用类IoU、mIoU、FwIoU指标衡量分割性能。
- 关键模块/机制：
  - WSSS-Tissue - Progressive Dropout Attention：减少CAM仅关注最具判别性区域的倾向，扩大激活区域。；在分类网络的后几层使用渐进式dropout，迫使网络利用更多区域进行分类，从而生成更完整的伪掩码。
  - WSSS-Tissue - Multi-Layer Pseudo-Supervision：缩小patch级标签与像素级掩码之间的差距。；利用分类网络多个特征层的CAM生成多个伪掩码，并联合监督分割网络训练。
  - WSSS-Tissue - Classification Gate：抑制不存在的组织类别的误报预测。；在分割网络的输出端增加一个门控，基于分类网络的预测结果，将缺失类别的分割激活置零。
  - STAR-RL - Spatial Manager：选择需要修复的退化区域。；将图像划分为块，根据退化程度（如梯度信息）决定哪些块需要进一步处理。
  - STAR-RL - Temporal Manager：决定何时停止修复过程。；通过强化学习中的时序决策，当修复达到预期质量时终止迭代。
  - STAR-RL - Patch Worker：对选定区域执行像素级修复操作。；动作空间包括边缘增强、对比度增强、平滑、锐化、加、减、无操作等滤波器，通过强化学习策略选择。
- 公式/目标函数/指标定义：
  - 低分辨率图像重建流程：ILR → bicubic → ILR_192 → STAR-RL → ISR_192 → bicubic → ISR_224
  - 评估指标：mIoU = (1/C) * Σ IoU_c，其中C为类别数，IoU_c = TP_c / (TP_c + FP_c + FN_c)
  - FwIoU = Σ (w_c * IoU_c)，其中w_c为类别c的像素频率
- 算法细节：
  - STAR-RL推理时：低分辨率图像先通过bicubic插值调整为192×192，输入STAR-RL，输出再通过bicubic插值调整为224×224。
  - WSSS-Tissue两阶段：阶段1训练多标签分类网络（使用交叉熵损失），并通过CAM生成初始伪掩码；阶段2训练分割网络（使用伪掩码作为监督，损失函数为Dice或交叉熵）。
  - 实验中所有设置固定WSSS-Tissue的超参数（学习率、批次大小、epoch数等），仅改变输入图像。
- 训练/推理细节：
  - STAR-RL预训练于HistoSR数据集（192×192配对图像），目标数据集LUAD-HistoSeg和BCSS-WSSS的推理使用该预训练模型，未进行微调。
  - WSSS-Tissue在每种输入设置下独立训练，使用patch-level多标签分类标签，验证集用于早停。

### 5. FM$^2$: Unified Federated Foundation Models for Heterogeneous Multimodal Medical Imaging
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13386v1
- 方法流程：
  - 阶段1：每个客户端在本地数据上训练视觉编码器F(·)={F_b, F_h}，骨干F_b作为冻结的Observer V，对每类进行Top-K采样提取代表性子集，形成采样数据集D_s
  - 阶段2：在D_s上训练两个MoE模块：类级MoE M_c和域级MoE M_d，Observer V保持冻结
  - 阶段3：本地更新后，V和M_d上传至服务端进行全局聚合；M_c保留本地用于个性化
  - 阶段4（可选）：字幕增强学习，利用本地生成的GPT-4o字幕作为文本语义桥梁，通过共享MoE增强视觉骨干实现表示迁移
- 关键模块/机制：
  - Observer V（冻结骨干）：作为冻结的特征提取器，对每类图像进行Top-K采样，生成代表性子集，并在阶段2后上传至服务端聚合和重分发；视觉编码器F_b在阶段1训练后冻结为Observer V，对每个客户端每类样本执行Top-K采样（K由类样本数决定），形成采样数据集D_s，用于后续MoE训练。V在每轮通信上传给服务端，服务端聚合后返回更新后的骨干初始化下一轮阶段1。
  - Class-wise MoE M_c：提取类别特定的个性化知识，仅本地保留，不参与通信；门控网络根据输入特征选择对应类别的专家，输出组合特征，用于增强分类器对客户端特有类别分布的表达。训练在采样数据集D_s上进行，优化目标为分类损失。
  - Domain-wise MoE M_d：学习跨模态共享表示，参与全局聚合；门控网络根据输入特征选择对应模态的专家，输出模态不变表示。其参数通过联邦平均聚合，使各客户端能利用其他客户端的模态信息，实现跨模态泛化。
  - 异构模态对齐正则化器（HMA）：显式对齐模态特定专家参数，增强模态间一致性；在Domain-wise MoE的专家参数上加入正则项，迫使不同模态的专家参数向量在特征空间中保持接近，从而促进跨模态表示对齐。数学形式为参数差异的L2范数。
  - 字幕增强学习（CEL）：利用文本字幕作为语义桥梁，在非重叠模态客户端间传递知识；每个客户端使用本地保留的GPT-4o生成的字幕（描述图像内容），将图像和字幕配对进行对比学习，使得不同模态的表示在文本空间对齐。字幕仅本地使用，不共享原始图像或字幕文本，仅共享更新后的表示。
- 算法细节：
  - Top-K采样：每个客户端对每类样本，根据骨干特征距离选出K个代表性样本，构建紧凑的采样数据集D_s，降低MoE训练计算开销
  - 双MoE门控机制：每个MoE模块包含多个专家网络和一个门控网络，输入特征经门控加权融合多个专家输出。Class-wise MoE中门控按类别路由，Domain-wise MoE中门控按模态路由
  - HMA正则化：在Domain-wise MoE的专家参数上施加L2正则项，惩罚不同模态专家参数向量之间的距离，强制模态间对齐
  - 全局聚合：服务端对Observer V和Domain-wise MoE M_d的参数进行联邦平均（FedAvg），Class-wise MoE M_c完全本地化
  - 两阶段训练：前50轮训练Observer V（骨干），后50轮冻结V训练MoE模块，总通信轮数100
- 训练/推理细节：
  - 所有基线（FedAvg等）使用ResNet-4骨干，SGD优化器，学习率5e-3，100个通信轮，1个本地epoch
  - FM²两阶段协议：前50轮Observer训练+后50轮MoE训练，每轮1个本地epoch，总计算量与基线一致
  - 超参数设置：γ_c=0.5, γ_d=0.5, λ=0.1（HMA强度）
  - FM²三种规模：Tiny/Medium/Large对应2×/4×/8× MLP层数每专家
  - 字幕生成：使用GPT-4o为每张图像生成描述性字幕，仅本地存储，不参与通信
  - 训练在NVIDIA A5500上完成，结果取5次平均

### 6. TS-Mask VLA: 2D Temporal-Spatial Masking for Vision-Language-Action Model with Effective Bridging
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2607.09818v1
- 方法流程：
  - 阶段1：VLM编码。输入：第三视角图像I_vt、夹爪图像I_gt、语言指令L_t、可学习动作查询令牌AQ_t。处理：DINOv2和SigLIP提取视觉特征，投影到语言空间；Qwen2.5-0.5B骨干生成所有L层的隐藏状态H={H^(l)}。输出：多层隐藏状态H和AQ特征。
  - 阶段2：离散扩散动作专家。输入：VLM隐藏状态H、AQ特征。处理：通过L层桥接注意力块，每层将当前动作表示与AQ令牌、任务令牌融合，更新动作表示。输出：更新后的动作表示。
  - 阶段3：动作令牌化与2D掩码。输入：连续动作。处理：均匀量化到256个离散令牌，组织成T×D的2D网格。应用2D时空掩码（训练时随机掩码，推理时逐步去掩码）。输出：掩码后的2D动作网格。
  - 阶段4：训练/推理。训练：掩码去噪学习，恢复掩码令牌。推理：从全掩码网格开始，多轮并行精炼，保留高置信度预测，重新掩码低置信度，逐步降低掩码率。
- 关键模块/机制：
  - VLM骨干：多模态编码器，提取视觉语言表示和动作查询特征；采用Qwen2.5-0.5B，输入第三视角图像I_vt、夹爪图像I_gt、语言指令L_t和动作查询令牌AQ_t，输出所有L层的隐藏状态H={H^(l)}，其中每个H^(l)∈R^(N×d)。
  - 桥接注意力块：融合自注意力、AQ注意力、任务注意力，实现条件注入；共享查询Q来自当前动作特征，独立MLP投影生成自、AQ、任务分支的K和V。注意力logits拼接后softmax：α=softmax([QK_self^T, QK_AQ^T, tanh(g)QK_task^T]/√d_h)。输出Z_bridge=α[V_self, V_AQ, V_task]。g为可学习门控标量，RoPE独立应用于各key分支。残差连接和FFN后输出。
  - 离散扩散动作专家：生成离散动作令牌的条件专家模块；由L层桥接注意力块组成，每层接收VLM对应层的隐藏状态作为条件，逐步精炼动作表示。采用离散扩散范式，训练时掩码预测，推理时多轮去噪。
  - 均匀量化器：将连续动作离散化为令牌；将归一化到[-1,1]的每个动作标量均匀量化为V=256个bin，bin边缘e_j=-1+2j/256（j=0,...,256），左闭右开（最后一个闭区间），索引q_i∈{0,...,255}。解码时映射回bin中心。

### 15. SigLIP-HD by Fine-to-Coarse Supervision
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2607.09488v1
- 方法流程：
  - 输入：训练时每张图像生成两个分辨率版本——中等分辨率（512×512）和高分辨率（1024×1024）。
  - 特征提取：分别通过SigLIP 2视觉编码器（共享权重）得到特征图，高分辨率特征图尺寸更大。
  - 特征对齐：将高分辨率特征图通过双线性插值下采样至与中等分辨率特征图相同的尺寸（例如32×32）。
  - 损失计算：对下采样后的高分辨率特征与中等分辨率特征计算L1损失，作为监督信号更新编码器权重。
  - 推理：仅使用中等分辨率（512×512）图像，编码得到标准数量的视觉tokens（如32×32），用于下游多模态大模型。
- 关键模块/机制：
  - 细到粗监督模块：训练阶段引导视觉编码器从高分辨率特征中学习细粒度信息，增强标准分辨率下的表征质量。；训练时，对同一图像，分别以512px和1024px分辨率输入共享权重的SigLIP 2编码器。高分辨率输出特征图通过双线性插值下采样至与512px输出相同的空间尺寸，然后计算二者之间的L1损失作为监督信号。该损失仅用于训练，不参与推理。
  - 多尺度特征融合模块（训练/推理兼容）：在推理时可选，当使用AnyRes策略处理原生分辨率图像时，用于合并不同尺度剪裁块的特征。；将图像按照不同网格划分（如1×1,2×2,3×3）分别编码，各尺度特征通过双线性插值统一到相同尺寸，然后直接取平均值得到最终视觉特征。论文实验表明等权平均优于加权平均。
- 公式/目标函数/指标定义：
  - L1损失：L = (1/N) * ∑|f^med_i - f^high_i|，其中f^med为中等分辨率图像编码器的输出特征，f^high为同一图像高分辨率版本编码器输出并下采样后的特征，N为特征元素总数。
  - 多尺度特征融合：F_fused = (1/K) * ∑_{k=1}^K Interp(F_k)，其中F_k为第k个尺度的特征图，Interp为双线性插值到目标尺寸。
- 算法细节：
  - 训练阶段：每batch包含图像的中等分辨率和高分辨率版本，通过共享权重的SigLIP 2前向得到特征图，对高分辨率特征图进行双线性插值下采样至与中等分辨率相同空间尺寸（32×32），计算L1损失，反向传播更新编码器参数。
  - 推理阶段：仅使用中等分辨率输入，编码器输出单尺度特征图，直接送入后续多模态大模型。
  - AnyRes扩展：将原生分辨率图像按最近可用的网格划分（如1×1至3×3），每个网格块缩放到512px，编码后所有块的特征图插值到相同尺寸并平均，最终tokens数量为32×32乘以网格块数（上限限制）。
- 训练/推理细节：
  - 优化器：AdamW，初始学习率5e-5，权重衰减0.04。
  - 训练步数：90K迭代，总batch size 512。
  - 学习率调度：余弦退火，预热4K迭代。
  - 计算资源：32张A100 GPU，BF16精度，训练耗时约34小时。
  - 训练数据：Cambrian-1收集的4.5M原始图像（包含自然图像、场景文本、文档等多样场景）。
  - 损失函数：仅使用L1损失进行特征对齐，无其他辅助损失。

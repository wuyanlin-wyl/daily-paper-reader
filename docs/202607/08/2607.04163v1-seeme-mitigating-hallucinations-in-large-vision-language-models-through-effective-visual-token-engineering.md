## 摘要
大型视觉语言模型在图像描述和视觉问答等视觉理解任务中取得了显著进展。然而，它们仍然容易产生幻觉，生成与实际视觉输入不一致的内容。现有方法主要干预解码阶段，而忽略了幻觉的一个关键来源：误导解码过程的不相关或嘈杂的视觉标记。为了解决这个问题，我们提出了SeeMe，一个无需训练的框架，将传统机器学习中的特征工程概念引入大型视觉语言模型。SeeMe通过三阶段标记工程过程重构视觉标记，以抑制幻觉源同时保留信息性的视觉证据。在四个大型视觉语言模型上的MME、POPE和AMBER基准实验中，SeeMe持续减少了幻觉并提高了输出一致性，为缓解大型视觉语言模型中的幻觉提供了新的视角。

## Abstract
Large Vision-Language Models (LVLMs) have achieved remarkable progress in visual understanding tasks such as image captioning and visual question answering. However, they remain susceptible to hallucinations, generating content that is inconsistent with the actual visual input. Existing methods primarily intervene at the decoding stage, while overlooking a critical source of hallucinations: irrelevant or noisy visual tokens that mislead the decoding process. To address this issue, we propose SeeMe, a training-free framework that introduces the concept of feature engineering from traditional machine learning into LVLMs. SeeMe restructures visual tokens through a three-stage token engineering process to suppress hallucination sources while preserving informative visual evidence. Experiments on MME, POPE, and AMBER benchmarks across four LVLMs demonstrate that SeeMe consistently reduces hallucinations and improves output consistency, providing a novel perspective for mitigating hallucinations in LVLMs.

### 2. 论文提出的方法论

**核心思想**：将视觉标记视为可编辑的特征，通过“扩展-压缩”范式进行三阶段重构，在不改变模型架构或额外训练的条件下，生成高质量、语义保真的视觉表示。

**关键技术细节**：

1. **Stage 1: 交叉注意力选择器（Cross-Modal Attention Selector）**  
   - 在解码器中间层（如第K层）提取交叉注意力权重，计算每个视觉标记被所有文本标记关注的平均分作为重要性分数。  
   - 保留分数最高的前`k = ⌊P·L_v⌋`个视觉标记（P为保留比例，实验中设为0.05），硬剪枝掉其余标记，减少冗余和噪声。

2. **Stage 2: 高质量标记扩展器（High Quality Token Expander）**  
   - 对原始嵌入层的视觉标记进行ℓ₂归一化，计算余弦相似度矩阵，屏蔽自相似对角线。  
   - 为每个标记选取`top-t`个最相似邻居（t=1或2），通过加权融合生成新标记：`ˆx_i^(j) = α_ij·x_i + (1-α_ij)·x_j`，其中`α_ij = s_ij/(s_ij+1)`。  
   - 所有融合标记与原始标记拼接，形成扩充池，用于恢复被剪枝丢失的局部细节信息。

3. **Stage 3: 交叉注意力标记精炼器（Cross-Modal Token Refiner）**  
   - 将扩充后的标记序列再次送入解码器第K层，利用自注意力图计算每个融合标记从文本接收的平均注意力分数。  
   - 选择分数最高的`n`个融合标记（n≈54或27），与Stage 1保留的标记拼接，作为最终视觉输入。

**算法流程**（文字说明）：  
输入 → 在解码层K-1获取交叉注意力，计算重要性分数，按比例P剪枝（Stage 1）→ 对原始图像标记进行相似性融合，生成扩展标记并与原始标记合并（Stage 2）→ 在解码层K获取自注意力，选择前n个最相关融合标记，与剪枝保留标记拼接（Stage 3）→ 生成最终标记序列。

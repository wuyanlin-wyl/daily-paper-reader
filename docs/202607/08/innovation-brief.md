### 1. Seeing Through Multiple Views: Parameter-Efficient Fine-Tuning via Selective Neurons for Consistent Radiology Report Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.31099v1
- 方法流程：
  - 输入：多视图（如正位和侧位）X光图像，以及对应的文本提示（如'请描述这张胸部X光片'）。
  - 阶段1 - 视图特异性神经元检测（VND）：对每个视图，使用检测集样本计算每个神经元的归因分数（激活幅度），取每层前γ比例的神经元，再取所有样本的交集得到视图特异性神经元集合N_v。
  - 阶段2 - 神经元验证（VNV）：在验证集上，通过扰动（置零）检测到的神经元与随机神经元对比性能下降程度，确认神经元特异性。
  - 阶段3 - 视图特异性神经元微调（VNF）：冻结模型大部分参数，仅更新N_v中的参数，使用标注的视图特定报告文本进行交叉熵损失优化（式5）。
  - 输出：每个视图的独立报告，以及通过LLM（如GPT-4）整合生成的完整放射学报告。
- 关键模块/机制：
  - View-specific Neuron Detector (VND)：识别与特定视图（如正位/侧位）高度相关的神经元子集；基于激活幅度归因分数Attr(n_kl | x_v) = Σ_t |f(x_v, w_kl)_t|_1，对每一层每个神经元计算该分数，然后取检测数据集中所有样本的top γ%神经元的交集，得到视图特异性神经元集合N_v (式3)。
  - View-specific Neuron Verification (VNV)：验证检测到的神经元确实是视图特异性的；在验证集上，分别将N_v和同等大小的随机神经元集合置零，计算生成质量的下降程度L∆（损失/临床指标增加），若N_v的下降显著大于随机组（式4），则确认特异性。
  - View-specific Neuron Fine-tuning (VNF)：仅微调视图特异性神经元，保持其他参数冻结；优化目标为标准交叉熵损失（式5），仅更新参数θ_{N_v}，其余参数冻结。训练用视图特定微调集D_ft。
  - LLM-based Integration and Evaluation：将视图特定报告整合为完整报告，并评估临床一致性；使用大语言模型（如GPT-4o）将正位和侧位报告合并；评估视图特定报告时采用LLM而非传统NLG指标，因为NLG无法捕捉临床差异（如Tab.4 vs Tab.5）。
- 公式/目标函数/指标定义：
  - I(n_kl | x_v) = ||RRG(x_v, θ) - RRG(x_v, θ \ w_kl)||_2 (式1，神经元影响度量)
  - Attr(n_kl | x_v) = Σ_t |f(x_v, w_kl)_t|_1 (式2，归因分数，激活幅度和)
  - N_v = ∩_{b=1}^B { n_kl | rank(Attr(n_kl | x_v^b)) ≤ γN } (式3，检测策略)
  - D_X L∆(N_v_deact) >> D_X L∆(N_rand_deact) (式4，验证条件)
  - L_VNF = - Σ_{(x,y)∈D_ft} Σ_{t=1}^T log P(y_t | y_{<t}, x; θ_{N_v}) (式5，微调目标，交叉熵损失)
- 算法细节：
  - 神经元检测阶段：遍历所有层（线性层和自注意力层）的所有神经元，计算每个样本的归因分数（激活幅度），按降序排列，取前γ%（如5%）的神经元；再取所有检测样本的交集作为视图特异性神经元。
  - 神经元验证阶段：将检测到的神经元权重置零（deactivate），在验证集上计算生成损失增量；随机选取同等数量神经元做同样操作，比较增量是否显著更大。
  - 微调阶段：使用AdamW优化器，学习率4e-6，余弦退火调度，权重衰减0.5，batch size 8，训练1 epoch，warmup ratio 0.3。仅更新N_v中的神经元参数，其余参数冻结。
  - 报告生成阶段：分别对每个视图输入图像和文本提示，通过VLM生成视图特定报告，再用LLM（如GPT-4o）整合为完整报告。
- 训练/推理细节：
  - 训练硬件：2块NVIDIA A6000 GPU，PyTorch实现。
  - 优化器：AdamW，初始学习率4e-6，余弦学习率调度，权重衰减0.5，warmup比例0.3。
  - 训练轮数：1 epoch。
  - 批次大小：8。
  - 微调时冻结大部分参数，仅更新检测到的视图特异性神经元参数（参数高效）。
  - 推理时分别对每个视图进行报告生成，然后通过LLM整合。

### 3. MedCAGD: Context-Aware Gated Decoder for Efficient Medical Image Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.00409v1
- 方法流程：
  - 输入图像经PVTv2-B2编码器提取多尺度特征图{c_i}（i=1..4），通过1×1卷积投影到固定解码器通道维度（64,128,320,512），得到p_i。
  - 解码开始：最深层特征p_4经Bottleneck模块（ECA-MSP → 卷积 → RA）处理得到B。
  - 逐阶段上采样：当前解码特征上采样2倍后与对应编码器跳跃特征通过SCA-Gate进行门控融合，生成融合特征。
  - 并行：Context Aggregator对编码器多尺度特征进行投影、对齐、平均和RA处理，产生全局上下文特征F_ctx，残差加到融合特征上。
  - 融合特征经Refinement Block（深度可分离卷积 → 点卷积 → GN+SiLU → ECA-MSP）细化，得到当前阶段输出。
  - 重复步骤3-5直到最高分辨率，最终特征送入分割头产生主预测。
  - 训练时，中间解码特征连接辅助分割头和边缘预测头，输出辅助logits并计算损失。
- 关键模块/机制：
  - Bottleneck (BT)：在最深层编码特征上注入全局上下文并细化，为解码提供上下文感知的语义表示；输入为投影后的最深编码特征F4，先经过ECA-MSP进行通道重校准，再通过卷积层ρ进行空间细化，最后经过RA模块注入全局上下文，输出B = R(ρ(E(F4)))
  - Efficient Channel Attention with Multi-scale Pooling (ECA-MSP)：自适应重校准通道响应，捕捉多尺度上下文信息；对输入特征X，使用一组自适应平均池化（尺度s∈{1,2,4}）得到多尺度通道描述符，每个描述符经一维卷积ψ（局部跨通道交互），取平均后经sigmoid生成注意力权重，与X逐元素相乘：X' = X ⊙ σ( (1/|S|) Σ_s ψ(AdaptiveAvgPool_s(X)) )
  - Residual Attention (RA)：以残差形式高效建模全局空间依赖；输入X，先通过点卷积P0和softmax计算空间注意力分布，加权聚合全局空间响应，再通过P1（含激活）和P2变换，最后与X残差相加：Y = X + P2(δ(P1( Σ_i Softmax(P0(X))_i X_i )))
  - Spatially Competitive Attention Gate (SCA-Gate)：选择性调控编码器跳跃特征，抑制语义不兼容信息；输入解码器特征g和编码器跳跃特征x，先分别经ECA-MSP重校准，再经轻量变换θ和ϕ投影到共享空间，计算交互图f = θ(E(g)) ⊙ ϕ(E(x))。然后通过H(f,g,x) = f ⊙ (1+G(g,x)) ⊙ (1+S(f))得到融合激活，其中G为全局通道调制，S为空间竞争（并行DW3和DW5卷积后经softmax归一化）。最后生成掩码σ(H)与x相乘得到门控特征x'
  - Context Aggregator (CA)：聚合多编码器阶段的全局上下文，注入每个解码阶段；对来自K个编码器阶段的特征{F_k}，分别通过可学习点卷积P_k投影到统一通道空间，再插值对齐到目标解码器分辨率，取平均后经RA处理得到F_ctx = R( (1/K) Σ_k P_k(F_k) )，然后残差加给当前解码特征
  - Refinement Block (RB)：通过局部空间滤波和自适应通道重校准增强解码特征；输入特征先经深度可分离卷积（3×3深度卷积 + 1×1点卷积）进行空间滤波和通道混合，每组后接GroupNorm和SiLU激活，最后通过ECA-MSP进行通道重校准
- 公式/目标函数/指标定义：
  - Residual Attention公式: Y = X + P2(δ(P1( Σ_i Softmax(P0(X))_i X_i )))，其中P0,P1,P2为点卷积，δ为非线性激活
  - ECA-MSP公式: X' = X ⊙ σ( (1/|S|) Σ_{s∈S} ψ(AdaptiveAvgPool_s(X)) )，其中S={1,2,4}
  - SCA-Gate公式: x' = x ⊙ σ(H(f,g,x))， H = f ⊙ (1+G(g,x)) ⊙ (1+S(f))，其中f=θ(E(g))⊙ϕ(E(x))
  - 训练采用二元交叉熵损失(BCE)，包含主分割损失、辅助分割损失（深度监督）和辅助边缘损失，总损失为加权和
- 算法细节：
  - 特征投影：编码器多尺度特征通过1×1卷积映射到固定解码器通道。
  - 门控跳跃融合：解码特征与编码特征经ECA-MSP重校准后，通过逐元素乘法生成交互图，再经全局调制和空间竞争（并行深度可分离卷积+softmax）得到门控掩码，与编码特征相乘。
  - 全局上下文注入：多编码器特征经投影、对齐、平均后通过RA模块，残差加到解码特征。
  - 逐阶段细化：每个解码阶段包含上采样、门控融合、上下文注入、局部细化（RB）。
  - 辅助边缘预测：从中间解码特征生成边缘logits，与从GT mask提取的二元边缘监督。
- 训练/推理细节：
  - 训练时使用深度监督（3个辅助分割头）和边缘监督（3个辅助边缘头），所有损失为BCE，加权求和。
  - 在11个医学图像分割基准上进行实验，使用PVTv2-B2作为编码器，ImageNet预训练。
  - 推理时仅保留最终分割预测，不使用辅助头。
  - 数据增强和优化细节未在原文中详细给出。

### 4. MindEdit-Bench: Benchmarking Object-Level Counterfactual Spatial Reasoning in VLMs from In-the-Wild Photos

- 原文链接：https://arxiv.org/abs/2607.00491v1
- 方法流程：
  - 数据采集：使用智能手机在室内场景拍摄三张照片（不同视角），共120个私有场景。
  - 3D场景图提取：对每张照片进行前馈深度估计和分割，然后通过跨视图对象关联构建对象级别的3D场景图，包括对象位置、朝向、大小等属性。
  - 问题生成：基于场景图自动生成六类空间推理问题，包括感知任务（L1-L3b）和反事实任务（L4-L5）。L4要求预测对象虚拟移动/旋转后的空间关系变化；L5要求预测哪些虚拟编辑会使对象在另一视图中出现/消失。
  - 答案选项构建：为每个问题生成8-24个结构化答案选项，包括正确选项和干扰项。
  - 人工验证：所有问题经过众包人工验证，最终得到1003个问题。
  - 模型评估：使用15个VLM在问题和答案选项上进行评估，比较准确性。

  - Counterfactual Question Generation：生成L4和L5反事实推理问题的模块；基于3D场景图，对目标对象施加虚拟变换（平移、旋转或可见性编辑），然后根据场景图模拟变换后的空间关系，生成问题（如关系变化或可见性变化）和正确答案。同时生成干扰项。
  - Structured Answer Space：提供8-24个结构化选项，便于诊断误差类型；每个问题有多个选项，每个选项对应一个字母，模型输出单个字母。通过分析错误响应的分布，可以识别模型在特定空间关系（如深度轴）上的弱点或fallback行为。

  - 输入信息未提供明确公式
- 算法细节：
  - 自动管道中的核心算法包括：深度估计（前馈模型），图像分割（SAM），跨视图对象关联（可能使用SIFT特征匹配或基于极线几何的匹配）。
  - 对于反事实问题生成，需要对3D场景图进行虚拟变换并重新计算空间关系。

### 5. AdaBoosting Text Prompts for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.00684v1
- 方法流程：
  - Step 1: 构造大型提示池：为每个类别k从手工模板、LLM生成句子及两者拼接中收集提示，形成池P_k。
  - Step 2: 初始化样本权重：对少样本训练集D，每个样本赋予均匀权重w_i^{(1)}=1/n。
  - Step 3: 每轮提升(m=1,...,M)：a) 基于当前权重w^{(m)}，通过GPC从P_k中选择提示集合B^{(m)}（两阶段：先选共享模板初始化，再逐类添加提示最小化加权误差）；b) 用B^{(m)}对每张图像预测，计算加权误差和分类器权重α^{(m)}；c) 更新样本权重：增加误分类样本权重，减小正确分类样本权重。
  - Step 4: 聚合所有弱分类器：对新图像，通过加权多数投票（式6）得到最终预测。
- 关键模块/机制：
  - Greedy Prompt Composition (GPC)：每轮提升中的弱学习器，从提示池中选择一组类级提示集合以最小化当前加权误差。；GPC分两阶段：第一阶段从80个共享模板中选出使加权分类误差最小的模板，作为每个类别的初始提示集合；第二阶段对每个类别，依次从该类提示池中添加一个提示，若添加后加权误差降低则保留该提示，否则跳过，直至遍历所有候选提示。
  - AdaBoost重加权与集成：通过迭代重加权数据样本，使后续弱学习器聚焦前一轮的误分类样本；最终通过加权投票集成所有弱分类器。；采用SAMME.R变体：每轮计算弱分类器的加权误差率，据此计算分类器权重α^(m)=log((1-error)/error)-log(K-1)，样本权重更新为w_i^(m+1)=w_i^(m)*exp((K-1)/K * α^(m) * I[y_i≠y_hat_i])，并归一化。最终预测为argmax_k Σ_m α^(m)*I[y_hat^(m)=k]。
- 算法细节：
  - GPC两阶段搜索：阶段1遍历80个模板，计算每个模板下所有类别的加权误差，选最小者；阶段2对每个类k，遍历该类提示池P_k中的提示，贪心地添加使当前分类器（结合已选提示）加权误差降低的提示，直至无改进。

- 算法细节：
  - RAG 门控融合：可学习标量 γ 在训练中自适应平衡放射组学通道注意力（α_c·α_s）与纯空间注意力（α_s）的贡献
  - 放射组学特征提取：在数据增强前从原始图像中提取固定 13 维特征，保持物理可解释性
  - 通道注意力生成：放射组学嵌入 ˆr 经过两层全连接和 sigmoid 得到通道权重
  - 空间注意力生成：跳接特征经 7x7 卷积和 sigmoid 得到空间权重
  - 边界损失 L_bnd：对分割边界周围 α=3 像素区域的预测错误施加更高惩罚

  - 差异化学习率：编码器 1e-5，解码器 1e-4

  - 梯度裁剪：范数 1.0

  - DA-MoE层操作：DER生成稀疏门控权重，选择top-k专家，DPE专家输出加权求和后经GELU激活；
  - 输出分割掩码。
- 关键模块/机制：
  - 动态专家路由（DER）：生成token-wise门控权重，稀疏激活最相关的专家；通过CrossAttn(Ctok, Pool(V))计算全局域上下文hctx；融合token特征hjl、hctx和停止梯度的概念嵌入ec，经可学习投影Wr得到路由分数sji；采用top-k门控（k=2）得到稀疏权重pji。
  - 分解参数化专家（DPE）：表示每个专家为共享冻结基座加低秩增量，减少参数；基座W0来自预训练FFN且冻结；增量ΔWi = AiBi^T，其中Ai∈R^{D×r}, Bi∈R^{D_ff×r}, r<<D；专家输出Ei(x) = (W0 + ΔWi)x；MoE层输出为加权求和后经GELU激活。
  - 层次化MoE放置：模拟临床推理的多阶段过程；在解码器深度L/6放置MoE层进行粗全局对齐，L/4进行语义结构识别，L/2进行精细边界细化。
  - 两阶段训练策略：确保专家稳定特化和有效路由；热身阶段：初始化低秩增量为零、路由器随机，训练分割损失Lseg和负载平衡损失Lbalance；微调阶段：固定专家参数，仅微调路由器，在更广泛数据集上训练。
- 公式/目标函数/指标定义：
  - X0 = [Vtok; Ctok; Stok] + P
  - hctx = CrossAttn(Ctok, Pool(V))
  - sji = Wr · [hjl; hctx; StopGrad(ec)]
  - ΔWi = AiBi^T, Ai∈R^{D×r}, Bi∈R^{D_ff×r}
  - Ei(x) = (W0 + ΔWi)x
  - yjl = Σ_{i∈TopK} pji · GELU(Ei(hjl))
- 算法细节：
  - DER：通过CrossAttn从概念token和池化视觉特征计算全局上下文向量；路由分数由token特征、全局上下文和停止梯度的概念嵌入拼接后经线性投影得到；选取top-2专家。
  - DPE：每个专家由共享冻结基座W0和可训练低秩增量AiBi^T组成，r远小于隐藏维度。
  - 层次化布局：在解码器层深L/6, L/4, L/2处插入DA-MoE层，其他层保留标准FFN。
  - 两阶段训练：第一阶段训练所有可训练参数（低秩增量和路由器）并加入负载平衡损失；第二阶段冻结专家，仅训练路由器。
- 训练/推理细节：
  - 图像编码器和文本编码器完全冻结；仅训练DA-MoE层和Layer Normalization参数。
  - 优化器：AdamW，学习率0.0005，权重衰减0.1，batch size 8。
  - 数据集：Synapse CT（224×224），其他256×256；数据增强：翻转、旋转、缩放、强度移位。

- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2607.00774v1
- 方法流程：
  - 输入图像，经Patch Projection和位置编码得到初始token序列X(0)。
  - 通过多个SoftMoR单元（每个单元包含共享参数的递归单元、Step Transform和SoftMixture）。
  - 每个SoftMoR单元内：递归单元重复应用T次，产生X(1)...X(T)；Step Transform在步间插入；Soft Router从X(0)预测每个token的T个权重；Soft Mixture加权求和得到输出。

- 关键模块/机制：
  - Soft Router：为每个token生成T个递归步的混合logits；轻量线性层G: R^D -> R^T，应用于每个token，输出logits Z，再经softmax得权重α。
  - Soft Mixture：聚合所有递归步的输出；对每个token n，输出 = sum_{t=1}^T α_n^{(t)} * X_n^{(t)}，其中α由Soft Router从X(0)预测。
  - Step Transform：在相邻递归步间引入独立变换，鼓励步特异性表示；每个步间插入一个独立参数化的token-wise线性投影加残差连接：X' = Linear(X) + X。
  - Recursive Unit (共享ViT blocks)：重复应用共享参数的Transformer块序列以增加有效深度；包含K个连续ViT块，参数Θ={θ1,...,θK}，应用T次得X^{(t+1)} = R_Θ(X^{(t)})。
- 公式/目标函数/指标定义：
  - X^{(t+1)} = R_Θ(X^{(t)})，递归步定义
  - α_n^{(t)} = exp(Z_n^{(t)}) / sum_{k=1}^T exp(Z_n^{(k)})，软混合权重计算
  - Xout_n = sum_{t=1}^T α_n^{(t)} X_n^{(t)}，软混合输出
  - Deff = K × T，有效计算深度
- 算法细节：
  - 软路由：输入X(0)经线性层得到T维logits，对每个token独立计算。
  - 软混合：对每个token，将T个递归步的输出按softmax权重加权求和。
  - Step Transform：在每步递归后，对输出施加独立线性层+残差，作为下一递归步的输入。
  - 递归单元组织：采用coarse-to-fine结构，即深层单元包含更多块，浅层单元更少。
- 训练/推理细节：
  - 训练协议与DeiT标准一致：300 epochs，无额外超参调优。
  - 使用DeiT风格蒸馏时，采用硬蒸馏和RegNetY-16GF教师。
  - 推理时递归步数T固定，每个递归单元运行T次共享参数。

### 40. MalariAI: A Label-Resilient Decoupled Framework for Universal Cell Segmentation and Explainable Stage Classification in Dense Malaria Blood Smears
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.00385v1
- 方法流程：
  - 输入：1600×1200全血涂片图像
  - Stage1 - 无监督分割：计算距离变换图，检测局部极大值作为种子点，应用分水岭算法分割出每个细胞轮廓，输出细胞质心和边界
  - Stage2 - 分类与解释：对每个细胞裁剪64×64 patch，送入EfficientNet-B0网络，输出5类（环状体、滋养体、裂殖体、配子体、白细胞）概率，同时生成Grad-CAM++热力图
- 关键模块/机制：
  - 距离变换分水岭分割模块：无监督分离所有细胞，无需标注，避免检测器召回偏差；对图像进行距离变换得到距离图，寻找局部极大值作为初始标记，然后运行分水岭算法从标记处扩展，分割出每个细胞区域。该方法对标注不完整鲁棒，在BBBC041上召回75.95%的细胞质心。
  - EfficientNet-B0分类模块：对每个分割出的细胞进行阶段分类，区分感染类型；输入64×64 crop，使用EfficientNet-B0，训练时采用Focal Loss (gamma=2.0) 并基于每类样本数设置逆频率权重，缓解类别不平衡。在BBBC041上达到98.36%总体准确率，罕见裂殖体87.5%、配子体75.0%。
  - Grad-CAM++解释模块：为每个分类结果提供空间热力图，增强可解释性；在推理阶段，对每个检测到的细胞，计算分类输出的Grad-CAM++热力图，叠加在原始patch上，显示模型关注的图像区域，帮助专家验证预测。
- 公式/目标函数/指标定义：
  - Focal Loss: FL(p_t) = -α_t (1-p_t)^γ log(p_t)，其中γ=2.0，α_t为每个类别样本数的逆频率权重。
- 算法细节：
  - 距离变换分水岭算法：先二值化图像（如Otsu）获得前景掩膜，计算前景到背景的欧氏距离变换图，然后在距离图上寻找局部最大值作为种子，最后用分水岭算法将每个种子扩张至细胞边界。
  - 裁剪策略：以分割获得的细胞质心为中心，裁剪64×64 patch，覆盖整个细胞及周围背景。
  - Grad-CAM++：通过梯度加权类激活映射，为每个预测类别生成热力图，突出对分类决策贡献大的区域。
- 训练/推理细节：
  - 训练：Stage2分类网络在64×64 crop上训练，使用Adam优化器，初始学习率0.001，批次大小32，训练100轮，采用Focal Loss (γ=2.0) 和类别逆频率权重。
  - 推理：先运行Stage1无监督分割，获取所有细胞质心；再对每个细胞提取patch，送入EfficientNet-B0得到分类结果和Grad-CAM++热力图。整个流程无需人工标注。

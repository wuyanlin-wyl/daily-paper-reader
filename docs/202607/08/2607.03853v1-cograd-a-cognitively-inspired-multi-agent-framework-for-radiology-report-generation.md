## 摘要
自动放射学报告生成（RRG）可以减轻放射科医生的工作负担，但现有大多数系统以单次前向传递方式生成报告，缺乏在生成后对照图像核实陈述或重新审视发现结果的机制。我们提出CogRad，这是一种认知启发的多智能体框架，围绕放射科医生阅读过程的四个阶段构建生成流程。探索智能体（Scout agent）通过插槽注意力直接从图像块中识别解剖区域，并分配区域级和疾病级分流评分；调查智能体（Investigator agent）将表征能力集中在探索智能体标记为可疑的区域上；撰写智能体（Writer agent）将这些信号编译为疾病门控视觉前缀，输入大型语言模型；验证智能体（Verifier agent）通过视觉蕴涵损失监督训练，并在推理时逐句重新检查其生成的草稿，重新生成任何它认为不够基于图像的报告。在CheXpert Plus上，CogRad的BLEU-4为0.316，CIDEr为0.322，是我们对比方法中的最佳分数。在IU X-Ray上，其BLEU-4为0.201，CIDEr为0.724，在所有标准NLG指标上领先所有基线。我们进一步使用RadGraph F1、CheXbert F1和幻觉分析评估CogRad，以评估超出标准文本重叠指标的临床准确性，并通过消融研究和基于Grad-CAM的可视化来表征每个智能体的贡献以及模型的视觉基础。

## Abstract
Automated radiology report generation (RRG) can ease radiologist workload, yet most existing systems produce a report in a single forward pass, with no mechanism to check a claim against the image or revisit a finding once stated. We present CogRad, a cognitively inspired multi-agent framework that structures generation around four stages of a radiologist's reading process. A Scout agent discovers anatomical regions directly from image patches via slot attention and assigns region and disease-level triage scores; an Investigator agent concentrates representational capacity on the regions Scout flags as suspicious; a Writer agent compiles these signals into a disease gated visual prefix for a large language model; and a Verifier agent supervises training with a visual entailment loss and, at inference, re-examines its own draft sentence by sentence, regenerating any report it judges insufficiently grounded. On CheXpert Plus, CogRad attains a BLEU-4 of 0.316 and a CIDEr of 0.322, the best scores among the methods we compare against. On IU X-Ray, it attains a BLEU-4 of 0.201 and a CIDEr of 0.724, leading every baseline on every standard NLG metric. We further evaluate CogRad with RadGraph F1, CheXbert F1, and a hallucination analysis to assess clinical accuracy beyond standard text-overlap metrics, complemented by ablation studies and Grad-CAM-based visualizations that characterize each agent's contribution and the model's visual grounding.

### 方法论
- **核心思想**：将报告生成分解为四个协作智能体（Scout、Investigator、Writer、Verifier），它们通过结构化张量表示（而非文本）进行通信，并在推理时允许模型重新审视自身输出。
- **关键技术细节**：
  - **共享视觉编码器**：Swin Transformer-Base，输出补丁特征 \( F_{vis} \in \mathbb{R}^{B \times N_p \times C_v} \)。
  - **Scout Agent（探索智能体）**：使用**槽注意力（slot attention）**从图像补丁中动态学习\( |R|=5 \)个解剖区域特征\( H \in \mathbb{R}^{B \times |R| \times C_v} \)，并通过MLP输出区域分流分数\( r \)和全局疾病分类概率\( c \)（基于14种胸科疾病标签，通过BCE损失\( \mathcal{L}_{\text{Scout}} \)监督）。
  - **Investigator Agent（调查智能体）**：对区域特征进行自注意力以捕捉区域间依赖，再通过**分流引导的聚焦权重**\( \phi \)（由\( r \)和\( H \)计算），使模型将更多计算资源分配给可疑区域，经\( L=2 \)层交叉注意力（聚焦补丁特征）细化区域表征，选择前\( K=3 \)个区域传递到Writer。
  - **Writer Agent（撰写智能体）**：组装**疾病门控视觉前缀**：将疾病分数\( c \)通过门控机制（\( p_k = e_k \odot \sigma(V_{\text{gate}} c_k + b) \)）转换为软提示令牌；将疾病令牌、调查上下文、选中区域特征、全局补丁特征串联形成前缀\( Q \)（令牌数因分辨率而异），输入LLM（LLaMA-2-7B-Chat，LoRA微调，\( r=16, \alpha=16 \)）进行自回归报告生成，损失为交叉熵\( \mathcal{L}_{\text{CE}} \)。
  - **Verifier Agent（验证智能体）**：
    - **训练时**：将视觉特征与目标文本嵌入通过交叉注意力对齐，设计**视觉蕴涵损失**\( \mathcal{L}_{\text{Ver}} \)，包含视觉一致性项、疾病一致性项（MSE）、全局对齐项（余弦相似度）。
    - **推理时**：使用轻量句子置信度头对生成的报告逐句评估，若置信度低于阈值\( \tau=0.5 \)则触发反馈循环：提升Scout分流分数→重走Investigator/Writer→重新生成全报告，最多两轮。损失函数联合优化：\( \mathcal{L} = \mathcal{L}_{\text{CE}} + \lambda_s \mathcal{L}_{\text{Scout}} + \lambda_v \mathcal{L}_{\text{Ver}} \)，在CheXpert Plus上\( \lambda_s=0.1, \lambda_v=0.2 \)；在IU X-Ray上\( \lambda_s=0.1, \lambda_v=0.1 \)。

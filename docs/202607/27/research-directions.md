## 方向 1：视觉语言模型的空间与逻辑一致性增强
本方向着眼当前视觉语言模型在动态场景空间推理与逻辑一致性上的根本性缺陷，通过融合朝向感知建模、逻辑一致性强化学习和定性时空评估，构建更鲁棒且可解释的多模态理解框架。

### 代表论文

- [OrientSAM: Mitigating Camera-Centric Shortcut in Multimodal Spatial Reasoning via Orientation-Aware Spatial Alignment](https://arxiv.org/abs/2607.17657v1)：提出OrientSAM框架，通过朝向感知token和傅里叶角度编码注入显式朝向信息，并采用课程学习策略，缓解多模态大模型空间推理中的相机中心捷径问题。
- [Be Consistent! Enhancing Robust Visual Reasoning in LVLMs with Consistency Constraints](https://arxiv.org/abs/2607.21722v1)：提出ConVBench基准和ConVLM方法，通过GRPO强化学习与一致性奖励提升LVLM视觉推理的准确性和逻辑一致性。
- [ViSTR-Bench: Can MLLMs Reason from Continuous Visual Cues in Dynamic Scenes?](https://arxiv.org/abs/2607.20868v1)：提出ViSTR-Bench，一个系统评估MLLMs在动态场景中从连续视觉线索进行定性时空推理能力的基准，包含4个维度15个子任务1340个视频QA对。

### 共同创新点
- 共同揭示了VLM在空间推理中依赖相机中心捷径、缺乏逻辑一致性和定性时空推理能力的普遍问题
- 分别从朝向感知注入、一致性约束和评估维度三方面提供互补性解决思路
- 均采用了课程学习或渐进式训练策略降低优化难度

### 尚未解决的问题
- 缺乏统一的框架同时解决空间准确性和逻辑一致性，且对动态场景的泛化能力不足
- 现有方法未将朝向信息与一致性约束联合优化
- 定性时空推理任务与定量评估之间的鸿沟尚未弥合

### 二次创新路线
#### 路线 1：朝向感知的一致性强化学习框架
- 核心想法：将OrientSAM的朝向感知token和傅里叶角度编码植入ConVBench的GRPO强化学习流程，使模型在非相机视角下也能维持逻辑等价问题输出的一致性，同时利用ViSTR-Bench的定性时空任务作为验证集指导训练。
- 新问题定义：新任务：在具有相机视角变化的动态视频中，训练VLM使其在空间推理时既满足逻辑一致性又避免相机中心捷径，同时通过定性时空问题评估其理解深度。
- 机制来源：
  - OrientSAM通过朝向感知token和傅里叶角度编码显式注入对象朝向信息，使模型从参考对象视角推理而非依赖相机平面
  - ConVBench通过逻辑等价问题对和一致性奖励（r_con）强制模型在等效问题上输出一致，缓解预测偶然性
  - ViSTR-Bench提供了四个维度（运动感知、空间关系、结果预测、物理动力学）的定性评估任务，可用来设计更丰富的训练奖励信号
- 为什么值得做：朝向感知解决了相机中心捷径的根本原因（缺少参考对象视角），一致性约束确保输出可靠，两者互补能显著提升动态场景下的鲁棒性，已有基准验证需求强烈。
- 理论/数学创新理由：
  - 数学对象：联合优化目标包含空间一致性损失L_spatial、逻辑一致性损失L_con和生成损失L_gen，其中L_spatial度量不同视角下朝向增强表示的距离，L_con基于等效问题对的输出一致性（二元奖励）。
  - 来源分解：OrientSAM解决了朝向建模的几何先验（L_spatial对应视角不变性），ConVBench解决了逻辑一致性（L_con对应等价问题输出一致），ViSTR-Bench提供了定性评估框架但未参与损失函数。
  - 新建模方式：总损失 L = L_gen + λ1 * L_spatial + λ2 * L_con，其中L_spatial = E[||f_θ(I, q, orient) - f_θ(I', q', orient')||_2^2]（I,q和I',q'为不同视角下的等价空间问题，orient来自OrientSAM），L_con = E[1_eq(q1,q2) * (1 - indicator(o1==o2))]（o1,o2为模型对等价问题的输出）。
  - 公式草图：L = L_gen + λ1 * ||Φ(I, q, E_orient) - Φ(I', q', E_orient')||² + λ2 * (1 - δ(o1, o2))，其中Φ为VLM编码器，E_orient为朝向嵌入，δ为克罗内克函数。
  - 为什么可能有效：朝向感知使模型直接规避相机中心捷径，一致性约束抑制了因随机性导致的输出不一致，两者联合迫使模型学到真正的空间关系而非表面相关，从而在视角变化和动态场景中同时提升准确性和可靠性。
- 可验证实验：在ViSTR-Bench的1340个视频QA对上评测，对比基线（ConVLM+OrientSAM）与联合框架。指标：准确率、逻辑一致性（等效问题对一致率）、朝向鲁棒性（相机视角变化下的准确率维持度）。假设联合框架在动态场景中准确率提升≥10%，一致性提升≥15%。
- 主要风险：联合优化可能增加收敛难度，L_spatial和L_con的权重需仔细调节；朝向感知token可能引入额外计算开销（约2倍推理时间增加）。

#### 路线 2：基于定性时空推理的课程学习增强策略
- 核心想法：利用ViSTR-Bench定义的四个维度（运动感知、空间关系、结果预测、物理动力学）设计渐进式训练任务，结合OrientSAM的朝向感知，构建从简单到复杂的课程，并在每个阶段注入ConVBench的一致性检查，防止模型产生捷径。
- 新问题定义：新系统设定：设计一种多阶段课程，第一阶段训练基础运动感知（朝向感知辅助），第二阶段空间关系，第三阶段结果预测，第四阶段物理动力学，每个阶段结束时通过一致性奖励确保基本技能掌握。
- 机制来源：
  - ViSTR-Bench提供了四个维度的定性时空任务和子任务分类，可作为课程阶段的划分依据
  - OrientSAM的朝向感知token可在每个阶段提供几何先验，尤其对空间关系和结果预测任务关键
  - ConVBench的一致性奖励作为阶段间验证指标，确保前一阶段技能在后续阶段不退化
- 为什么值得做：课程学习已被多个工作证明能有效降低复杂度，ViSTR-Bench的任务覆盖了从低级运动到高级物理推理，为渐进训练提供了天然难度阶梯。
- 理论/数学创新理由：
  - 数学对象：课程学习的目标函数为各阶段损失之和，每个阶段L_stage包含任务特定损失L_task和一致性正则化L_con，其中L_task基于ViSTR-Bench子任务的交叉熵或对比损失。
  - 来源分解：ViSTR-Bench定义了任务难度阶梯，OrientSAM提供了朝向几何先验，ConVBench提供了跨阶段一致性检查。三者在课程中分别扮演任务设计、几何指导和质量控制角色。
  - 新建模方式：总损失 L = Σ_{stage} (L_task_stage + μ * L_con_previous)，其中L_con_previous度量当前预测与前阶段最好模型在等价问题上的差异。每个stage的L_task_stage = -log P(answer|I, q, orient_token)。
  - 公式草图：L_stage_t = -log P(y_t|I, q, E_orient) + μ * ||f_θ_t(I, q1) - f_θ_{t-1}(I, q2)||，其中θ_t为当前阶段模型，θ_{t-1}为冻结的前一阶段模型，q1,q2为等价问题。
  - 为什么可能有效：渐进式任务设计匹配人类认知发展，朝向感知提供关键几何线索，一致性正则化避免灾难性遗忘，使得模型在学习更复杂任务时保留基础能力。
- 可验证实验：在ViSTR-Bench上按四阶段训练，每个阶段结束时测试该维度准确率并检验前一维度的退化情况。预期最终在所有维度上准确率均超过直接训练模型，且未出现显著遗忘。
- 主要风险：阶段划分的粒度需要实验确定，可能某些子任务难度顺序不严格。训练时间约为基础训练的4倍。

## 方向 2：交互式半监督3D医学图像分割
本方向结合PC-Seg的渐进跨视图一致性与SLIP的低延迟交互式分割，将用户少量修正信号高效融入半监督训练流程，实现以极低标注成本达到全监督级别的3D分割精度。

### 代表论文

- [PC-Seg: Progressive Cross-View Consistency for 3D OCT Segmentation from Sparse 2D Annotations](https://arxiv.org/abs/2607.17718v1)：提出PC-Seg，一种五阶段渐进课程学习框架，通过从稀疏2D标注逐步扩展跨视图一致性（B-scan→正交切片→体积→2D/3D协同训练），实现仅用0.7%标注数据即达到全监督水平的3D OCT分割。
- [SLIP: Segmentation with Low-latency Interactive Prompting for 3D Medical Images](https://arxiv.org/abs/2607.22332v1)：SLIP通过解耦图像编码与提示引导细化，利用轻量级补丁记忆库实现低延迟和可逆提示的交互式3D医学图像分割。

### 共同创新点
- 两者均针对3D医学图像分割的标注瓶颈，分别从半监督伪标签生成和交互式高效修正角度突破
- 都采用了解耦或渐进式策略避免误差累积：PC-Seg通过课程学习，SLIP通过解耦编码和记忆库
- 都具备即插即用的潜力，可适配不同分割骨干网络

### 尚未解决的问题
- PC-Seg的伪标签质量完全依赖训练流程，用户无法纠正错误；SLIP的交互从头开始，未利用半监督先验
- 缺少一种机制将高度可靠的用户点击直接用于指导伪标签蒸馏
- 两者在计算效率和交互延迟上的优势尚未融合

### 二次创新路线
#### 路线 1：交互引导的渐进伪标签蒸馏框架
- 核心想法：在PC-Seg的五阶段课程中，于阶段3（正交交叉教学）后插入SLIP的交互模块：用户对模型预测低置信度区域点击修正，修正结果作为硬标签加入后续阶段的有监督损失，并动态调整该区域的伪标签阈值。
- 新问题定义：新系统设定：在3D OCT分割的半监督训练流程中，允许用户对模型预测的疑似错误区域进行少量点击修正（≤10次/例），修正后自动更新伪标签并重新进入课程学习循环，最终实现与全监督相当的性能。
- 机制来源：
  - PC-Seg解决了从稀疏2D标注生成3D伪标签的逐步蒸馏问题，但无法利用用户反馈纠正伪标签错误
  - SLIP解决了低延迟可逆交互的关键技术：图像特征一次性编码、补丁记忆库维护状态、支持撤销操作，使得用户修正几乎不增加训练时间成本
- 为什么值得做：PC-Seg的伪标签在病变区域置信度低（动态阈值已降为0.5），正是用户需介入点；SLIP的补丁记忆库可高效记忆修正状态，避免重复计算。
- 理论/数学创新理由：
  - 数学对象：优化目标包含有监督损失L_sup（用户标注和交互修正区域）、一致性损失L_cons（无标签区域）、以及修正引导项L_correct（用户点击区域的强约束）。
  - 来源分解：PC-Seg贡献了L_sup和L_cons的课程安排和动态阈值，SLIP贡献了高效计算交互修正的机制（无需重新编码图像）。
  - 新建模方式：总损失 L = L_sup + λ_cons L_cons + λ_correct L_correct，其中L_sup仅作用于初始标注切片和用户修正切片（交叉熵），L_cons作用于伪标签区域（原有方式），L_correct = E[CE(pred, y_click)]，y_click为用户点击确定的标签。修正区域的伪标签权重提高至0.9。
  - 公式草图：L = Σ_{i∈L} CE(p_i, y_i) + λ_cons Σ_{j∈U} CE(p_j, ŷ_j) + λ_correct Σ_{k∈C} CE(p_k, y_click_k) 其中L为标注集，U为无标签集，C为用户修正集，ŷ_j为动态阈值的伪标签。
  - 为什么可能有效：用户修正直接纠正了伪标签中最重要的错误（如病变边缘），防止这些错误在后续蒸馏中放大；SLIP的高效性确保交互不会显著拖慢训练；动态阈值与修正区域权重提升共同作用，逐步提高伪标签整体质量。
- 可验证实验：在MSHC和Duke数据集上，使用1%稀疏2D标注，进行10次/例的交互修正，对比PC-Seg原始版本和SLIP交互式分割（从零开始交互）的性能。预期PC-Seg+交互的DSC提升3-5%，接近全监督水平。
- 主要风险：用户点击质量可能不稳定，需设计用户引导界面；修正次数增加可能边际效益递减，需确定最优交互量。

#### 路线 2：记忆库驱动的伪标签动态融合策略
- 核心想法：利用SLIP的补丁记忆库维护PC-Seg各阶段生成的伪标签及对应置信度，在2D/3D协同训练（阶段5）中，根据不同补丁的历史一致性和用户修正记录，动态加权融合多个来源的伪标签，形成更可靠的整体伪标签。
- 新问题定义：新方法：在3D半监督分割的协同训练阶段，维护一个覆盖全体积的补丁级记忆库，记录每个补丁在之前阶段的预测历史、置信度及用户修正状态，以此计算融合权重，减少不可靠伪标签的影响。
- 机制来源：
  - PC-Seg通过2D和3D模型集成预测提升伪标签质量，但集成权重固定（等权）
  - SLIP的补丁记忆库设计了补丁级状态存储（预测和不确定性），支持交互感知的上下文传播，提供了动态融合所需的存储和查询机制
- 为什么值得做：PC-Seg阶段5的集成预测仅简单平均，未考虑不同模型在不同区域的可靠性差异；记忆库可存储历史预测方差，为融合提供置信度先验。
- 理论/数学创新理由：
  - 数学对象：动态融合权重基于每个补丁的历史预测一致性（方差）和用户修正标记，权重w = exp(-α * var / (1 + β * corr_flag))，其中var为历史预测方差，corr_flag为是否被用户修正。
  - 来源分解：PC-Seg提供了多阶段多模型的预测历史，SLIP提供了记忆库数据结构以及不确定性估计方法。
  - 新建模方式：全局伪标签 ŷ_global = Σ w_m * ŷ_m，其中w_m ∝ exp(-γ * Var_m) 经softmax归一化，Var_m为第m个来源在补丁上的历史方差。用户修正过的补丁权重提升至1.5倍基础值。记忆库在每阶段结束后更新Var_m。
  - 公式草图：w_{m}(p) = exp(-λ * Var(p, m)) / Σ_{k} exp(-λ * Var(p, k)) ŷ(p) = Σ w_m(p) * ŷ_m(p) 其中Var(p,m) = E_t[(ŷ_m^t(p) - μ_m(p))²] 跨阶段方差。
  - 为什么可能有效：通过记忆库利用历史信息，动态融合可自动降低高波动区域（即可能不可靠区域）的权重，减少了错误伪标签对训练的干扰；用户修正标记进一步提升可靠区域的贡献，使伪标签更精准。
- 可验证实验：在MSHC数据集上，比较PC-Seg原版阶段5集成（等权平均）与记忆库动态融合的性能。指标：伪标签准确率、最终分割DSC。预期伪标签准确率提升2%，分割DSC提升1.5%。
- 主要风险：记忆库维护需要额外存储和计算，补丁数量大时可能影响速度；方差估计需要多阶段历史，初期历史不足时效果有限。

## 方向 3：多智能体医疗咨询代理的可信评估与优化
本方向融合诊断解耦评估、多角色交叉审查与层归属行为诊断，构建可归因、可审计的多轮医疗咨询代理，提升评估可靠性和策略优化效率。

### 代表论文

- [MedDDC-Eval: Diagnosis-Decoupled Evaluation of Multi-Turn Medical Consultation Agents](https://arxiv.org/abs/2607.18999v1)：提出MedDDC-Eval，通过固定共享冻结阅读器将策略引发的对话历史与诊断生成解耦，实现可归因的多轮医疗咨询代理评估，并利用GRPO基于诊断和轨迹反馈优化策略。
- [Systematic Literature Reviews With Two Multi-Agentic Systems And Human-In-The-Loop](https://arxiv.org/abs/2607.21920v1)：提出两个多智能体系统（筛选MAS和提取MAS）配合人类在回路，系统性提升文献综述中文献筛选和数据提取的准确性与可扩展性。
- [A Diagnostic Framework for AI Agent Behavior](https://arxiv.org/abs/2607.17149v1)：提出一个针对AI Agent行为的层归属诊断框架，将行为来源归因于基础计算层（架构、记忆、感知等）或行为调制层（身份、目标、规则等），强调行为诊断应先于解释、验证和治理。

### 共同创新点
- 均关注医疗AI代理的评估与可靠性，从不同层面（评估解耦、系统架构、行为理论）提出创新
- 都采用了人类在回路（HITL）确保临床安全性
- 均强调归因分析：MedDDC-Eval将历史质量与诊断生成解耦，SLR通过交叉审查识别错误源，诊断框架提供分层归因理论

### 尚未解决的问题
- 三者相互独立，未形成一个端到端的可信代理评估与训练框架
- 诊断解耦评估依赖固定阅读器，多角色审查尚未与策略优化奖励结合
- 层归属理论的实证应用缺乏具体实现

### 二次创新路线
#### 路线 1：诊断解耦的多角色交叉审查咨询策略优化
- 核心想法：将SLR的多角色交叉审查机制引入MedDDC-Eval的策略优化流程：用多个LLM代理模拟不同医疗角色（如全科、专科、药师），对策略引发的对话历史进行独立诊断，通过交叉诊断一致性产生更准确的奖励信号，再经共享阅读器解耦评估历史质量。
- 新问题定义：新系统设定：多轮医疗咨询代理的训练中，每轮对话后多角色LLM代理各自生成初步诊断，通过交叉审查识别分歧和错误，然后利用共享阅读器（DeepSeek-v3）从历史中提取标准化诊断，结合多角色投票给出奖励。
- 机制来源：
  - MedDDC-Eval提供了诊断解耦的评估框架（共享阅读器、D/T/E指标、GRPO奖励），但奖励仅基于单一阅读器输出
  - SLR提供了多角色+交叉审查+自我修订机制，可生成更可靠的诊断，同时产出置信度标签
  - Diagnostic Framework提供了两层层归属理论（计算层vs调制层），可分析咨询失败的根源是能力不足还是角色/规则问题
- 为什么值得做：SLR已证明多角色交叉审查能提升筛选准确性，MedDDC-Eval的GRPO框架可直接扩展为多角色奖励，诊断框架提供理论支撑。
- 理论/数学创新理由：
  - 数学对象：GRPO的组内相对奖励融合多角色诊断F1和轨迹F1，加入分歧惩罚项。
  - 来源分解：MedDDC-Eval贡献了基础奖励函数（D_F1, T_F1）和共享阅读器，SLR贡献了多角色诊断聚合方法，Diagnostic Framework贡献了归因分类（用于事后分析）。
  - 新建模方式：Reward = w1 * D_F1_multi + w2 * T_F1 - w3 * Disagreement，其中D_F1_multi = (平均多角色F1) * (1 - 最大角色差异)，Disagreement = 角色间诊断标签的约登J统计量差异。使用诊断框架的层归属标签（0/1）调整w3。
  - 公式草图：R = α * (Σ_i F1_i / M) * (1 - β * max_{i,j}|D_i - D_j|) + γ * T_F1 - δ * (1 - Jaccard_index) 其中F1_i是第i个角色的诊断F1，D_i是诊断向量，T_F1是轨迹F1。
  - 为什么可能有效：多角色交叉审查减少单一LLM的偏见，分歧惩罚鼓励策略生成清晰无歧义的历史，解耦评估确保奖励归因于历史质量而非诊断生成能力，层归属理论为事后调整提供方向。
- 可验证实验：在MedDDC-Eval的100+70例测试集上，对比单角色GRPO与多角色GRPO。指标：诊断F1、轨迹F1、获取效率。预期多角色方法在诊断F1上提升3-5%，分歧度降低10%。
- 主要风险：多角色推理增加计算成本（约5倍），需优化并行化；角色设计需专家参与，可能引入新偏差。

#### 路线 2：基于层归属的自适应调制层干预策略
- 核心想法：利用Diagnostic Framework的层归属分析，对多轮咨询代理的失败轨迹进行归因识别（计算层或调制层），然后针对调制层问题进行干预：调整身份角色提示、目标指令或交互结构，而非修改模型参数。
- 新问题定义：新任务：在医疗咨询代理静态部署后，自动检测低性能轨迹并归因于计算层或调制层，对调制层问题自动尝试一组预设干预（如切换角色描述、增加确定性问题约束），通过少量交互验证最优干预。
- 机制来源：
  - Diagnostic Framework提供了两层层归属方法和比较实验设计（相同模型不同提示/身份下的行为差异）
  - MedDDC-Eval提供了标准化的D/T/E量化指标和共享阅读器，可用作干预效果的快速评估
- 为什么值得做：诊断框架强调行为可能源于调制层而非计算层，特别是医疗场景中角色和目标设定对行为影响大；MedDDC-Eval的D/T/E指标可量化干预效果。
- 理论/数学创新理由：
  - 数学对象：干预选择最大化诊断F1和轨迹F1的联合期望，通过贝叶斯优化搜索最佳调制参数。
  - 来源分解：诊断框架给出了归因逻辑：若改变调制层参数（身份、目标）后性能大幅变化则问题在调制层；MedDDC-Eval提供了客观度量和快速反馈（共享阅读器固定）。
  - 新建模方式：干预策略π(θ)选择调制参数θ（如角色提示模板、置信阈值），优化目标max E_{τ～π}[D_F1(τ) + λ T_F1(τ)]，使用贝叶斯优化或Thompson采样。每次干预后通过共享阅读器快速评估。
  - 公式草图：θ* = argmax_{θ∈Θ} U(θ) 其中 U(θ) = E[ F1_diag(τ|θ) + γ * F1_traj(τ|θ) ]，使用GP回归建模U(θ)。
  - 为什么可能有效：层归属诊断快速识别问题来源，避免无效的重新训练。调制层干预成本低（仅修改提示），可在运行时自适应调整，适用于多变的临床场景。
- 可验证实验：在MedDDC-Eval的测试集上，对低分轨迹（D_F1<0.6）应用层归属分析，若归类为调制层则随机尝试干预（角色提示变化、目标调整），并与不干预对照组比较D/T/E提升比例。预期干预组提升有效率≥60%。
- 主要风险：层归属分析需要多次对比实验（改变调制参数），在线部署时可能影响用户体验；干预空间可能很大，需要高效搜索策略。

## 方向 4：隐私高效与数据自适应的少样本VLM微调
本方向结合原型正则化、子空间分解和数据驱动属性选择，解决少样本VLM适应中的类别不均衡、隐私泄露和跨域泛化问题，实现即插即用的高效微调。

### 代表论文

- [PRiSM: Prototype Regularization for Few-Shot VLMs](https://arxiv.org/abs/2607.17820v1)：提出PRiSM，一种类原型正则化模块，通过多术语损失（类间距离最大化、支持特征对齐、保真度）和基于Gershgorin圆定理的块Majorize-Minimize优化器，在现实不平衡少样本设定下显著提升多种训练无关VLM方法的性能。
- [Towards Privacy-Preserving Federated Prompt Tuning under Data Heterogeneity: A Subspace-Decomposed Expert Approach](https://arxiv.org/abs/2607.21417v1)：提出FedSEPT，通过子空间分解专家建模压缩多专家提示的通信和DP噪声空间，并设计实例感知专家融合实现鲁棒的语义组合，在隐私约束下提升联邦提示调优的个性化与泛化权衡。
- [Attributes Should Come from Images, Not Class Names: Distribution-Conditioned Attribute Selection for Vision-Language Models](https://arxiv.org/abs/2607.18695v1)：提出分布条件属性选择方法，从目标图像集合中直接选择属性用于CLIP零样本分类，避免LLM描述缺乏视觉证据的问题。

### 共同创新点
- 均针对VLM少样本或零样本场景下的关键瓶颈（原型偏差、隐私噪声、属性来源），提出轻量级正则化或表示压缩方法
- 都是即插即用模块，可融入现有基线方法
- 都利用了共享表示空间（CLIP嵌入空间）进行优化或选择

### 尚未解决的问题
- PRiSM未考虑隐私保护，FedSEPT未解决类不平衡，Attributes from Images未利用少样本标注
- 三者缺乏协同，未形成统一框架同时处理隐私、不平衡和属性选择
- 属性选择方法依赖全量图像集，联邦场景下不可行

### 二次创新路线
#### 路线 1：隐私保护的原型正则化联邦少样本适应
- 核心想法：将PRiSM的多损失原型正则化嵌入FedSEPT的联邦流程，各客户端本地优化PRiSM损失（类间分离、支持对齐、保真度），仅通信低秩因子，并通过差分隐私保护；服务器端聚合时采用实例感知融合的加权平均，平衡全局和局部。
- 新问题定义：新系统设定：在联邦学习下，各客户端数据服从Dirichlet采样的类不平衡分布，每个客户端只能访问少量标注样本（如5-shot），要求训练一个全局VLM模型，客户端通过差分隐私保护，同时保证个性化性能。
- 机制来源：
  - PRiSM通过支持特征对齐损失、基线保真度损失和类间分离损失修正原型偏差，解决类不平衡导致的性能下降
  - FedSEPT通过子空间分解专家建模压缩通信维度（低秩因子），并利用Gershgorin圆定理高效优化，添加DP噪声时维度更低更鲁棒
- 为什么值得做：PRiSM在类不平衡下有效，FedSEPT解决了隐私和通信瓶颈，两者互补可同时应对现实联邦场景中的两大挑战。Dirichlet采样基准可直接用于评估。
- 理论/数学创新理由：
  - 数学对象：联合损失包含客户端本地PRiSM损失和服务器端聚合约束，通信对象为低秩因子α（维度k<<d），DP噪声添加在α上。
  - 来源分解：PRiSM贡献了损失函数三项（L_align, L_fidelity, L_sep），FedSEPT贡献了参数化（P_i = basis*α_i + residual_i）和优化器（块MM）。
  - 新建模方式：客户端优化 L_local = L_CE + λ1 * L_align(α_i) + λ2 * L_fidelity(α_i, α_global) + λ3 * L_sep(α_i) + DP噪声项。服务器聚合α_global = mean(α_i + noise_i)。推理时使用FedSEPT的实例感知融合（IEF）结合本地α_i和全局α_global。
  - 公式草图：L_local = CE(y, p) + λ1 * Σ||f_α(x_s) - proto||² + λ2 * ||α_i - α_global||² + λ3 * Σ_{c1≠c2} softplus(cos(proto_c1, proto_c2)) + (1/ε) ℓ1(α_i) 其中proto为类原型。
  - 为什么可能有效：PRiSM的正则化使得本地原型在类不平衡下更稳健，子空间分解使得低维α_i对DP噪声更不敏感（相比全维度），联邦聚合同时保留全局知识，IEF保证个性化。
- 可验证实验：在Dirichlet采样基准（严重不平衡+部分覆盖）上，比较FedSEPT、PRiSM+中央训练、FedSEPT+PRiSM的性能。预期联合方法相比FedSEPT单独提升3-5%准确率，相比PRiSM中央训练提升隐私保护下的2-3%准确率。
- 主要风险：联合损失超参数增多（λ1-λ3和DP预算ε），需要仔细调优；子空间分解假设（固定基）可能限制某些客户端特有语义的表示。

#### 路线 2：数据驱动属性引导的跨域零样本-少样本迁移
- 核心想法：利用Attributes from Images的方法从目标图像集合中选出判别属性，然后将这些属性作为PRiSM的原型正则化中的辅助语义提示，同时利用FedSEPT的实例感知融合来动态选择最相关的属性组合，提升跨域适应能力。
- 新问题定义：新任务：在少样本跨域分类中（如自然图像→医学图像），源域有丰富数据，目标域仅有少量样本（如3-shot），利用目标域图像集合自动选出判别属性，通过属性增强的原型正则化实现高效迁移。
- 机制来源：
  - Attributes from Images解决了属性来源问题：从目标图像在CLIP空间中自动选择top-k属性，这些属性更符合目标分布
  - PRiSM的原型正则化需要良好的初始原型（基线原型），属性可以监督原型的学习（属性对齐损失），提升原型判别性
  - FedSEPT的实例感知融合可动态组合多个属性提示，适应不同输入的特征
- 为什么值得做：属性选择解决了LLM描述缺乏视觉证据的问题，PRiSM的原型正则化需要高质量原型，属性可提供更细粒度的语义锚点；FedSEPT的实例感知路由可自适应聚合不同属性通道。
- 理论/数学创新理由：
  - 数学对象：目标函数在PRiSM三项基础上增加属性对齐损失L_attr（使原型与相应属性嵌入对齐）和属性选择正则化（稀疏性）。
  - 来源分解：Attributes from Images贡献了属性池和评分机制，PRiSM贡献了原型正则化框架，FedSEPT贡献了实例感知权重分配。
  - 新建模方式：L = L_CE + λ1 L_align + λ2 L_fidelity + λ3 L_sep + λ4 L_attr，其中L_attr = Σ_c ||proto_c - (1/k) Σ_{a∈A_c} emb(a)||²，A_c为类别c选出的属性集合。推理时实例感知融合用路由网络输出属性组合权重。
  - 公式草图：L_attr = Σ_c ( proto_c - (1/k) Σ_{a∈A_c} φ_attr(a) )² 其中φ_attr为属性编码器（CLIP文本编码器），A_c从目标图像池选出。
  - 为什么可能有效：目标域属性提供了准确的视觉语义先验，减少了原型对源域分布的依赖；属性对齐强制原型位于类别语义中心，提升类间分离性；实例感知融合使属性组合自适应于不同样本，增强泛化。
- 可验证实验：在跨域基准（如ImageNet→Sketch, Office-Home）上，使用3-shot少样本，比较基线、PRiSM、PRiSM+属性引导的效果。预期属性引导PRiSM在域偏移下准确率提升5-8%。
- 主要风险：属性选择依赖目标图像集合，在极端小样本下（如1-shot）可能不靠谱；属性池大小和k的选择需调参。

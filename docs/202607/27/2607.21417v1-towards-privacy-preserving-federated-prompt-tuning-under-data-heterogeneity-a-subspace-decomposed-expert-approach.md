## 摘要
联邦提示微调（FPT）能够通过轻量级提示实现视觉-语言模型（VLM）的协同适应。现有方法通常通过本地差分隐私（DP）下的分离提示设计来处理异质性和隐私问题，将用于全局迁移的共享提示与用于本地适应的私有提示相结合。然而，单个共享提示可能会过度平滑多样化的可迁移知识，削弱个性化与泛化之间的平衡。多专家提示（MEPs）能更好地捕捉这种多样性，但会扩大通信空间，增加DP噪声和通信成本，并使鲁棒的专家组合更加困难。我们提出FedSEPT，一种隐私保护的联邦子空间分解专家提示微调方法。具体而言，我们采用子空间分解专家建模（SEM），通过共享低秩因子、固定公共基和私有残差来参数化多个提示专家，从而将通信和DP扰动限制在紧凑的因子空间中，并支持在公共坐标系中直接进行服务器聚合。我们进一步设计了实例感知专家融合（IEF），通过设备端路由自适应地组合语义互补的专家，并使用缓存的专家特定文本特征进行高效的logit级融合。在11个异质性基准上的大量实验表明，在相同隐私约束下，FedSEPT相比强基线在本地适应与全局泛化之间取得了更好的平衡。

## Abstract
Federated prompt tuning (FPT) enables collaborative adaptation of vision--language models (VLMs) using lightweight prompts. Existing methods often address heterogeneity and privacy through a split-prompt design under local differential privacy (DP), combining a shared prompt for global transfer with private prompts for local adaptation. However, a single shared prompt may over-smooth diverse transferable knowledge, weakening the balance between personalization and generalization. Multi-expert prompts (MEPs) can better capture this diversity, but enlarge the communicated space, increasing DP noise and communication cost while making robust expert composition more difficult. We propose FedSEPT, a privacy-preserving Fed}erated Subspace-decomposed Expert Prompt Tuning. Specifically, we employ Subspace-decomposed Expert Modeling (SEM) to parameterize multiple prompt experts with shared low-rank factors, a fixed public basis, and private residuals, thereby confining communication and DP perturbation to a compact factor space while enabling direct server aggregation in a common coordinate system. We further design Instance-aware Expert Fusion (IEF), which adaptively combines semantically complementary experts via on-device routing and performs efficient logit-level fusion using cached expert-specific text features. Extensive experiments on 11 heterogeneous benchmarks show that, under the same privacy constraints, FedSEPT achieves a better trade-off between local adaptation and global generalization than strong baselines.

## 1. 论文的核心问题与整体含义（研究动机和背景）

联邦提示微调（Federated Prompt Tuning, FPT）是一种利用轻量级提示（prompt）在分布式环境中协同适配视觉-语言模型（VLM）的有效范式。它通过仅更新少量可学习向量而冻结主干网络，实现了参数高效的模型适配。然而，实际FPT系统面临两个根本问题：

- **数据异质性**：客户端数据统计分布差异大（标签分布、视觉域、语义概念不同），单一全局提示无法适应多样化本地上下文。
- **隐私威胁**：提示更新可能泄露敏感信息，半诚实或不可信服务器可通过成员推断攻击或梯度反演攻击推断客户端私有属性。

现有方法多采用“分离提示”范式（全局共享提示+本地私有提示），但单个共享提示易导致可迁移知识过度平滑，削弱个性化与泛化之间的平衡。引入多专家提示（MEPs）可以更好地捕捉多样化的可迁移知识，但会带来两个新挑战：
1. **隐私-效率维度诅咒**：MEPs增大了通信参数空间的维度，本地DP注入高斯噪声的期望范数随维度线性增长，导致语义几何结构被严重破坏。
2. **鲁棒专家组合障碍**：每个专家受到独立DP扰动，传统硬路由（Top-1选择）对噪声专家脆弱，均匀平均则削弱实例级适应能力。

## 2. 论文提出的方法论

**整体思想**：FedSEPT（Federated Subspace-decomposed Expert Prompt Tuning）通过子空间分解的专家建模和实例感知的专家融合，在保持隐私高效的同时，实现更强的个性化-泛化权衡。

### 2.1 子空间分解专家建模（SEM）

- **专家参数化**：每个客户端维护 \( M \) 个提示专家。对于客户端 \( k \)，第 \( m \) 个专家提示定义为：
  \[
  \mathbf{P}^m_k = \mathbf{A}^m_k \mathbf{B}_0 + \mathbf{R}_k
  \]
  其中：
  - \(\mathbf{A}^m_k \in \mathbb{R}^{L \times r}\) 是低维专家因子（共享、可传输）。
  - \(\mathbf{B}_0 \in \mathbb{R}^{r \times d}\) 是固定公共基（数据无关，所有客户端共用）。
  - \(\mathbf{R}_k \in \mathbb{R}^{L \times d}\) 是客户端私有残差（保留本地个性化，不上传）。
  - \(L\): 提示长度，\(d\): 嵌入维度，\(r \ll d\): 子空间维度。

- **DP-SGD仅应用于共享因子**：本地差分隐私通过DP-SGD仅对\(\mathbf{A}^m_k\)施加保护，通信和噪声扰动被限制在紧凑的因子空间（\(MLr\) vs \(MLd\)）。

- **专家多样性正则化**：通过Gram矩阵的离对角线惩罚防止专家冗余，鼓励互补的可迁移知识。

### 2.2 实例感知专家融合（IEF）

- **实例感知路由**：输入图像\(x\)经过图像编码器得到视觉特征\(\mathbf{v}(x)\)，客户端使用可学习的探测查询\(\mathbf{u}_k\)和多头注意力机制得到任务表征，再通过线性门控和Softmax预测样本级专家权重\(\boldsymbol{\pi}_k(x)\)。所有路由参数（\(\mathbf{u}_k\)和\(\mathbf{W}_{\text{gate},k}\)）为客户端私有。
- **负载均衡正则化**：防止少数专家垄断路由权重。
- **Logit级融合**：预先为每个专家计算并缓存文本特征\(\mathbf{t}^m_{k,c}\)，推理时仅需计算余弦相似度并由路由权重加权融合：
  \[
  z_{k,c}(x) = \sum_{m=1}^M \pi_{k,m}(x) \cdot \langle \mathbf{v}(x), \mathbf{t}^m_{k,c} \rangle / \tau
  \]
  避免反复执行文本编码器，显著降低计算开销。

### 2.3 联邦私有优化流程

1. 服务器初始化全局专家因子\(\mathcal{A}^{(0)}\)，分发公共基\(\mathbf{B}_0\)。
2. 每个客户端本地优化总损失：\(\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{ce}} + \lambda_{\text{div}}\mathcal{L}_{\text{div}} + \lambda_{\text{gate}}\mathcal{L}_{\text{gate}}\)。
3. 对共享因子\(\mathcal{A}_k\)执行DP-SGD（梯度裁剪+高斯噪声）。
4. 上传\(\mathcal{A}_k\)到服务器；服务器按专家索引加权平均聚合（式12），得到新的全局因子并广播。
5. 隐私保证：每个客户端满足\((\epsilon, \delta)\)-本地DP（通过矩会计师分析）。

### 1. PC-Seg: Progressive Cross-View Consistency for 3D OCT Segmentation from Sparse 2D Annotations
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17718v1
- 方法流程：
  - Stage 1 (2D Warm-up): 输入：有标注和无标注的B-scan图像；处理：使用UniMatch半监督框架训练2D ResUNet；输出：对所有B-scan预测得到初始伪标签，用于Stage 2的正交切片。
  - Stage 2 (Adaptation to Orthogonal Slices): 输入：B-scan图像+新引入的无标注正交切片（使用Stage 1的伪标签）；处理：扩展UniMatch，对正交切片计算四种扰动（弱、特征级、两种强）的伪标签一致性损失；输出：训练后预测所有正交切片，生成下一阶段的B-scan伪标签。
  - Stage 3 (Orthogonal Cross-teaching): 输入：B-scan和正交切片，各自有来自上一阶段的伪标签；处理：交叉教学：用B-scan模型预测正交切片伪标签，用正交模型预测B-scan伪标签，互相监督；输出：将两个平面的预测集成（ensemble）生成高质量的3D伪标签。
  - Stage 4 (Knowledge Distillation to 3D Model): 输入：稀疏标注和未标注的体积，以及Stage 3生成的3D伪标签；处理：使用UniMatch半监督框架训练3D ResUNet，有标注的切片用真实标签替换伪标签；输出：集成2D模型的两个平面预测和3D模型预测，生成更精细的3D伪标签。
  - Stage 5 (2D/3D Co-training): 输入：Stage 4生成的3D伪标签；处理：交替训练2D和3D模型，动态更新集成伪标签（使用两个模型的最佳预测）；输出：最终集成三个预测（2D B-scan、2D Ortho、3D Volume）得到最终分割结果。
- 关键模块/机制：
  - UniMatch半监督基线：提供弱到强一致性正则化框架，用于每个阶段的训练；对无标签图像，在弱扰动下生成高置信度伪标签（阈值τ），然后对强空间和特征扰动下的预测计算与伪标签的一致性损失（交叉熵）。有标签数据计算监督损失。总损失L_SSL = 监督损失 + λ * 一致性损失。论文使用四种扰动：弱（随机裁剪、水平翻转）、特征级（dropout 0.5）、两种强（颜色抖动、模糊、垂直缩放、FDDA、PRLC）。
  - 2D ResUNet / 3D ResUNet：基础分割网络，2D用于处理B-scan和正交切片，3D用于处理体积；Residual U-Net，深度4，基础通道数32。2D模型每次输入单张切片，3D模型输入体积块（MSHC: 128×128×48，Duke: 224×224×48）。参数显著少于Vision Transformer模型。
  - 动态置信阈值调整：适应病变类别的低置信度预测，避免有用伪标签被丢弃；在Stage 4和Stage 5中，将病变类别的置信阈值τ从0.95动态降低到0.5。因为阶段3之后集成预测更稳健，即使低阈值也不引入错误伪标签。
  - 伪标签集成与动态更新：在各阶段末尾生成更可靠的伪标签用于下一阶段；使用当前阶段验证集准确率最高的模型 checkpoint 生成伪标签。Stage 3集成两个正交平面的预测得到3D伪标签；Stage 4集成2D两平面和3D预测；Stage 5使用2D和3D模型的预测动态更新集成伪标签。
- 公式/目标函数/指标定义：
  - L_SSL = L_sup + λ * L_unsup，其中L_sup和L_unsup均为交叉熵损失
  - 伪标签生成：pseudo = argmax(p_weak) if max(p_weak) > τ，其中p_weak为弱扰动下的预测概率
  - 一致性损失：L_unsup = CE(p_strong, pseudo)，p_strong为强扰动下的预测
  - 动态阈值：τ = 0.95 for 正常类别, τ = 0.5 for 病变类别（Stage 4/5）
- 算法细节：
  - 五阶段课程学习，每个阶段运行固定轮数，伪标签仅使用验证集最优checkpoint生成
  - Stage 2中对正交切片使用所有四种扰动（弱、特征级、两种强）计算一致性损失，不同于标准UniMatch仅对强扰动计算
  - Stage 3交叉教学：交换两个正交平面的伪标签来源，即用B-scan模型预测正交切片的伪标签，反之亦然
  - Stage 4中伪标签替换：有真实标签的切片使用真实标签，无标签的切片使用Stage 3集成伪标签
  - Stage 5交替训练：在一个epoch内交替训练2D模型和3D模型，集成伪标签由两者共同预测并动态更新
  - 推理时使用滑动窗口平均：MSHC窗口128×128×48，Duke窗口224×224×48，步长1/3重叠
- 训练/推理细节：
  - 优化器：AdamW，初始学习率5e-5
  - 批量大小：2（一个标注+一个未标注）
  - 数据增强：弱扰动包括随机裁剪(100%)、水平翻转(50%)、垂直缩放(80%)、FDDA(80%)、PRLC(80%)；未标注数据弱扰动仅包括随机裁剪和水平翻转；特征级扰动：dropout 0.5；强扰动：颜色抖动(80%)、模糊(20%)、垂直缩放(80%)、FDDA(80%)、PRLC(80%)
  - 训练数据：MSHC数据集标注6/30/60张切片（约0.07%/0.3%/0.7%），其余为未标注；Duke DME使用66张标注B-scan（每卷11张），其余300张未标注
  - 预处理：视网膜展平（flattening）至128像素高度（MSHC）或原尺寸（Duke），强度归一化
  - MSHC训练时切分成128×128 patch，水平重叠64像素，共8820个训练patch；Duke随机裁剪为224×224×48体积块

### 2. PRiSM: Prototype Regularization for Few-Shot VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17820v1
- 方法流程：
  - 阶段1: 输入支持集图像和标签、零样本文本原型uc、基线方法得到的初始原型ac。
  - 阶段2: 构造多术语损失：L = λ1*L_inter + λ2*L_alignment + λ3*L_fidelity，分别对应类间距离最大化、支持特征对齐、保真度。
  - 阶段3: 使用块Majorize-Minimize优化器：固定视觉编码器，通过闭式解更新原型；固定原型，利用Lipschitz学习率轻量微调视觉编码器。
  - 阶段4: 输出正则化后的原型，用于推理时计算余弦相似度。
- 关键模块/机制：
  - 多术语损失函数：目标函数；包含三个项：类间成对距离最大化（提高分离性）、支持特征对齐（使原型与支持集视觉特征对齐）、保真度（保持接近基线原型）。
  - 块Majorize-Minimize优化器：优化算法；利用Gershgorin圆定理推导每个块的Lipschitz常数，实现高效迭代更新，交替优化原型（闭式解）和视觉编码器参数（轻量微调）。
  - Dirichlet采样基准：评估设置；使用Dirichlet分布采样支持集和查询集的类别比例，控制类别不平衡程度和有效类别数，模拟现实场景。支持集和查询集独立采样，允许分布偏移。

### 3. PRiSM: Prototype Regularization for Few-Shot VLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.17820v2
- 方法流程：
  - 输入：支持集图像-标签对、零-shot文本原型（来自CLIP等VLM）
  - 步骤1：使用基线方法（如Tip-Adapter、GDA等）从支持集获得初始任务原型（或直接使用零-shot原型）
  - 步骤2：构建多损失函数，包含支持特征对齐（将支持图像嵌入与对应类原型对齐）、基线原型保真度（保持与基线原型接近）和类间距离最大化（增大不同类原型间的余弦距离）
  - 步骤3：采用块Majorize-Minimize优化器，交替更新类原型（闭式解）和视觉编码器（轻量微调），迭代至收敛
  - 输出：修正后的类原型，用于查询集分类
- 关键模块/机制：
  - 多损失正则化函数：同时对齐支持特征、保留基线原型信息并强制类间分离，纠正不平衡导致的偏差；包含三项：支持特征对齐损失（最小化支持图像嵌入与其对应类原型的欧氏距离）、基线保真度损失（L2正则化，防止原型偏离基线原型）、类间分离损失（最大化不同类原型之间的余弦相似度负值，即最小化相似度）。总损失为加权和，超参数控制平衡。
  - 块Majorize-Minimize优化器：高效求解非凸多损失优化问题，交替更新类原型和视觉编码器；通过推导每个变量块的块状Lipschitz常数（利用Gershgorin圆定理估计Hessian谱范数），构建易于优化的上界函数，然后交替执行：1）类原型更新：固定编码器，通过闭式解或简单梯度步骤更新原型；2）视觉编码器微调：固定原型，进行少量梯度更新（参数高效）。每个子问题保证单调下降。
- 算法细节：
  - 基于Gershgorin圆定理计算每个变量块的Lipschitz常数，避免直接计算Hessian矩阵
  - 块MM优化器每次迭代：对每个变量块，利用其上界函数构建代理问题，得到闭式解或快速梯度步骤
  - 原型更新时，利用支持特征和基线原型形成二次型，解析求解；编码器更新时，采用轻量级LoRA或仅更新偏置项
  - 整个优化过程无需验证集调参，所有超参数（如各项权重）固定或由任务统计量自适应设定
- 训练/推理细节：
  - PRiSM作为即插即用模块，无需单独训练，直接在推理时基于支持集进行优化
  - 优化过程仅需少量迭代（通常10-20步），计算效率高
  - 视觉编码器仅进行参数高效微调（如仅更新偏置或使用低秩适应），避免过拟合
  - 不需要验证集或额外标注数据，完全基于支持集和零-shot原型

### 5. Attributes Should Come from Images, Not Class Names: Distribution-Conditioned Attribute Selection for Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.18695v1
- 方法流程：
  - 1. 构建属性池：从LLM或预定义集合中获取大量属性候选。
  - 2. 属性评分：将每个属性编码为文本，将目标图像编码为图像，在CLIP嵌入空间中计算属性与各类别图像的平均相似度作为得分。
  - 3. 属性选择：对每个类别，保留得分最高的k个属性。
  - 4. 零样本分类：用选出的属性组成文本提示（不含类名），计算与测试图像的平均相似度，预测最匹配的类别。
- 关键模块/机制：
  - 属性评分机制：评估每个属性与目标图像集合的语义关联强度，为后续选择提供依据。；使用CLIP的联合嵌入空间，将属性文本和图像分别编码为向量，计算属性与每个类别所有图像的平均余弦相似度作为得分。
  - 属性选择模块：从属性池中为每个类别筛选出最相关的属性，去除无关或误导性描述。；对每个类别，按属性得分降序排列，取前k个属性作为该类的代表属性。k是超参数，实验中可能通过验证集确定。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 属性池构建：可利用LLM生成大量属性候选（如描述类别外观的词汇），或使用现成属性列表。
  - 评分计算：对于每个属性文本a和每个类别c，计算属性与c中所有图像的平均相似度：score(a,c) = (1/|Ic|) Σ_{i∈Ic} sim(CLIP_text(a), CLIP_image(i))，其中sim为余弦相似度。
  - 选择top-k：对每个c，按score降序选取k个属性，构成最终提示。
  - 分类：测试图像j，计算其与每个类别c的提示的相似度：sim(j,c) = (1/k) Σ_{a∈top_k(c)} sim(CLIP_image(j), CLIP_text(a))，取argmax。
- 训练/推理细节：
  - 方法无需训练，所有操作在推理阶段完成。
  - 属性选择和分类均基于CLIP的预训练嵌入，不涉及梯度更新。
  - 每类仅需一张图像即可有效选择属性，耗时约1分钟（vs CoOp的14小时训练）。

### 6. MedDDC-Eval: Diagnosis-Decoupled Evaluation of Multi-Turn Medical Consultation Agents
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.18999v1
- 方法流程：
  - 输入：策略π与患者模拟器交互多轮，产生对话历史hπ。
  - 历史收集：hπ包含患者初始主诉和所有问答回合，作为预诊断上下文。
  - 诊断生成：将hπ输入共享冻结阅读器（DeepSeek-v3），使用固定提示p_diag和解码参数生成诊断输出。
  - 评估计算：对诊断输出与参考诊断集计算定向语义覆盖，然后进行确定性一对一分配，得到诊断F1和轨迹F1。
  - 效率计算：基于轨迹中首次获取每个关键事实的轮次与总轮次计算获取效率。
  - 输出：D/T/E度量值（诊断F1、轨迹F1、效率）。
  - 训练阶段：使用GRPO在交互式rollout中优化策略，奖励信号结合诊断结果匹配和轨迹覆盖。
- 关键模块/机制：
  - 共享冻结阅读器：将任意策略引发的对话历史映射到诊断，保持映射恒定，隔离诊断生成变异。；使用DeepSeek-v3作为固定阅读器，采用统一的诊断提示和解码设置，对所有历史应用相同的输入-输出映射。
  - 定向语义覆盖与确定性一对一分配：将开放式的诊断预测和参考转化为可计算的精确率-召回率计数，避免重复信用。；首先对每个预测和参考生成语义候选集合（如同义词、变体），然后通过确定性匈牙利或贪心算法进行一对一匹配，确保每个预测最多匹配一个参考，每个参考最多匹配一个预测，最后基于匹配计算精确率和召回率。
  - D/T/E度量框架：从下游诊断有用性、信息获取和效率三个维度综合评估策略引发的历史。；诊断F1：基于诊断输出与参考诊断集的语义匹配F1；轨迹F1：基于历史中覆盖的专家预定义关键信息（轨迹目标）的F1；获取效率：衡量早期轮次中正确获取关键信息的比例，如早期覆盖率或平均获取轮次。
  - GRPO训练框架：利用诊断结果和轨迹覆盖作为奖励信号，优化策略的问题选择能力。；在交互式多轮rollout中，每组采样多个轨迹，计算每个轨迹的诊断F1和轨迹F1作为奖励，进行组内归一化，使用标准GRPO更新策略参数。
- 公式/目标函数/指标定义：
  - 诊断F1 = 2 * Precision_diag * Recall_diag / (Precision_diag + Recall_diag)，其中Precision_diag和Recall_diag基于定向语义覆盖和确定性一对一来计算。
  - 轨迹F1 = 2 * Precision_traj * Recall_traj / (Precision_traj + Recall_traj)，类似定义，针对预定义轨迹目标。
  - 效率度量Efficiency = 平均(正确获取关键事实时的轮次索引) / 总轮次，或早期覆盖率。
  - GRPO目标：最大化组内归一化奖励的期望，即 max_θ E[ A(s,a) ]，其中A(s,a) = (R_i - mean(R_group)) / std(R_group)，R_i = λ * DiagnosisF1 + (1-λ) * TrajectoryF1。
- 算法细节：
  - 定向语义覆盖：对预测和参考诊断，使用医学同义词库或嵌入相似度生成语义候选集，每个原始项扩展为包含近义项的集合。
  - 确定性一对一分配：在预测-参考之间进行最大二分匹配，常用匈牙利算法，确保每个预测和参考最多一次匹配，避免冗余计数。
  - GRPO算法：从策略中采样一组轨迹，计算每个轨迹的奖励（诊断F1+轨迹F1），对组内奖励进行z-score归一化，然后使用策略梯度更新，无critic网络。
  - 奖励设计：诊断奖励基于诊断输出与参考诊断集的F1，轨迹奖励基于历史中覆盖的轨迹目标的F1，两者线性组合。
- 训练/推理细节：
  - 训练数据来源：912个来自医院记录的病例，每个病例在3-4轮和5-7轮两种提示桶下生成，共1824个提示行。
  - 基模型：Qwen3-32B，使用GRPO在交互式多轮仿真中训练。
  - 推理时：策略与患者模拟器交互，收集完整对话历史后，通过共享阅读器生成诊断并计算D/T/E指标。
  - 训练超参数：未详细给出，但为标准GRPO设置，如组大小、学习率等。

### 7. ViSTR-Bench: Can MLLMs Reason from Continuous Visual Cues in Dynamic Scenes?
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.20868v1
- 方法流程：
  - 1. 任务设计：基于三个原则（时间强调、推理导向、定性评估）定义四维评估空间。

- 原文链接：https://arxiv.org/abs/2607.21417v1
- 方法流程：
  - 初始化：服务器初始化一个公共基矩阵（固定）和共享低秩因子矩阵，每个客户端初始化其私有关键残差。

  - 隐私处理：对共享低秩因子的梯度进行剪辑和加噪（DP-SGD），仅扰动低秩因子空间。
  - 通信：客户端仅将带噪的共享低秩因子上传至服务器。
  - 服务器聚合：服务器对来自客户端的共享低秩因子进行加权平均，更新全局共享低秩因子。
  - 推理阶段：客户端根据输入图像，通过路由网络生成各专家的权重，利用缓存的专家特定文本特征计算融合logit，得到预测结果。
- 关键模块/机制：
  - 子空间分解专家建模（SEM）：将多专家提示参数化为低秩结构，减少通信和DP噪声维度。；每个专家提示表示为 P_i = basis * alpha_i + residual_i，其中basis是固定的公共基矩阵（维度d×k，k远小于d），alpha_i是共享的低秩因子（在所有客户端间共享），residual_i是客户端私有的残差（保留在本地）。通信和DP扰动仅作用于alpha_i，其维度远小于直接通信完整专家提示。
  - 实例感知专家融合（IEF）：根据输入实例自适应融合多个专家logit，提高鲁棒性和适应性。；在客户端本地，训练一个轻量级路由网络（如小MLP），以图像特征为输入，输出每个专家的权重（softmax归一化）。推理时，对每个专家，其文本特征（通过CLIP文本编码器预先计算并缓存）与图像特征计算相似度得到logit，然后按路由权重加权融合得到最终logit。这种logit层融合避免了为每个实例重新编码混合提示。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 低秩因子通信：客户端上传带噪低秩因子alpha_i（经DP-SGD处理后），服务器聚合平均。
  - 专家重构：本地利用公式 P_i = basis * alpha_i + residual_i 重构专家提示。
  - 实例感知路由：路由网络输出权重向量w = softmax(MLP(image_features))，其中image_features来自冻结的视觉编码器。
  - logit层融合：第c类的logit = sum_j w_j * (text_feature_j * image_features)，其中text_feature_j是第j个专家的文本编码。
- 训练/推理细节：
  - 训练中，每个客户端同时优化专家提示（通过SEM参数化）和路由网络，共享低秩因子梯度被裁剪并加噪，私有关键残差和基础不参与通信。
  - 推理时，客户端的路由网络直接输出权重，利用预缓存的专家文本特征（来自公共文本编码器）快速计算融合logit，无需为每个输入动态编码提示。

### 9. Be Consistent! Enhancing Robust Visual Reasoning in LVLMs with Consistency Constraints

- 关键模块/机制：
  - 预言机模型（Proposer）：自动生成逻辑等价问题-答案对，提供弱监督信号。；使用GPT-4.1，基于图像、标题和目标框/类别信息，生成{(q1,a1),(q2,a2)}。

  - 逻辑一致性指标：模型对同一图像两个逻辑等价问题回答一致的比率。

  - 准确率奖励基于伪答案（自动生成或人工校验）计算，一致性奖励基于回答的逻辑匹配（如答案是否蕴含相同事实）。
- 训练/推理细节：
  - 训练：使用自动生成的逻辑等价问答对进行GRPO强化学习，每个批次包含图像及其两个等价问题。
  - 奖励设计：同时使用准确率奖励和一致性奖励（权重γ），或仅使用一致性奖励。

### 11. TextSLIP: Text Self-Supervised CLIP for Medical Report Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.21970v1
- 方法流程：
  - 预训练阶段：输入7M脑MRI图像-文本对，使用图像编码器ViT-B-16和文本编码器BioMed-BERT分别提取嵌入，同时使用动量文本编码器提取文本嵌入存储于FIFO队列；计算CLIP损失（跨模态）和ESimCSE损失（文本自监督），联合优化。
  - 微调阶段：将预训练的视觉编码器（ViT-B-16）替换R2Gen中的原始视觉提取器，在BRATS2023-GLI数据集上端到端微调，从三个解剖轴（轴向、矢状、冠状）提取嵌入并拼接，输入解码器生成报告。
- 关键模块/机制：
  - 图像编码器 (ViT-B-16-quickgelu)：将医学图像映射到共享潜空间，输出视觉嵌入z_i^I；采用Vision Transformer架构，预训练后用于下游报告生成特征提取。
  - 文本编码器 (BioMed-BERT)：将文本报告映射到共享潜空间，输出文本嵌入z_i^T；同时作为动量编码器的更新目标；基于BERT的医学领域语言模型，处理原始文本和增强文本。
  - 动量文本编码器 (Momentum Text Encoder)：为ESimCSE生成负样本嵌入，参数通过指数移动平均从文本编码器更新；参数θ_m ← αθ_m + (1-α)θ，其输出嵌入z_i^M存储在FIFO队列中作为负样本。
  - FIFO队列 (First-In-First-Out Queue)：存储动量编码器产生的文本嵌入，作为ESimCSE的负样本集合；队列大小固定，新嵌入入队时最旧嵌入出队，用于计算ESimCSE损失中的负样本项。
  - 词重复增强 (Word Repetition, f_WR)：生成文本正样本T^+；随机重复输入文本中的某些词，构造语义相似但形式不同的正样本对。
- 公式/目标函数/指标定义：
  - 图像-文本对比损失 L_CLIP = 1/2 (L_I→T + L_T→I)
  - L_I→T = -1/N Σ_i log[exp(sim(z_i^I, z_i^T)/τ) / Σ_j exp(sim(z_i^I, z_j^T)/τ)]
  - L_T→I = -1/N Σ_j log[exp(sim(z_j^T, z_j^I)/τ) / Σ_i exp(sim(z_j^T, z_i^I)/τ)]
  - ESimCSE损失 L_ESimCSE = -1/N Σ_i log[exp(sim(z_i^T, z_i^{T+})/τ) / (Σ_j exp(sim(z_i^T, z_j^{T+})/τ) + Σ_k∈Q exp(sim(z_i^T, z_k^M)/τ))]
  - 总损失 L = L_CLIP + λ * L_ESimCSE
  - 动量参数更新 θ_m ← αθ_m + (1-α)θ
- 算法细节：
  - 预训练：每个batch包含N个图像-文本对；图像编码器和文本编码器分别生成z_i^I和z_i^T；对每个文本T_i进行词重复得T_i^+，编码得z_i^{T+}；动量编码器处理T_i得z_i^M并推入FIFO队列；计算CLIP损失和ESimCSE损失，联合反向传播更新图像和文本编码器；动量编码器通过EMA更新。
  - 负样本队列：ESimCSE的负样本包括batch内其他增强文本和队列中的动量嵌入，避免直接使用同一batch的原始文本（防止结构相似性过大）。
  - 微调：将预训练视觉编码器接入R2Gen，从MRI体积的三个轴（轴向、矢状、冠状）提取2D切片嵌入，拼接后输入Transformer解码器生成报告。
- 训练/推理细节：
  - 预训练：6块A100 80GB GPU，batch size=1536，学习率4e-5，warm-up 5k步，训练20轮（约80小时）。
  - 微调：单块A100 80GB GPU，30轮，遵循R2Gen默认配置。
  - 推理：从三个解剖轴提取视觉嵌入并拼接，输入解码器生成报告。

- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2607.17386v1
- 方法流程：

  - 步骤1：将视频帧划分为patch，提取patch级视频表示

- 关键模块/机制：

  - 密集段选择器 (Dense Segment Selector)：自适应地从视频中挑选时间连续的高分辨率区域进行精细分析；基于稀疏令牌输出和文本查询，选择最相关的短时间窗口内的所有patch，形成密集令牌，用于高分辨率检测。
  - 联合稀疏-密集LLM处理器：融合稀疏和密集两种令牌以生成最终分割结果；将稀疏令牌（全局时间线索）和密集令牌（局部高分辨率细节）拼接或交叉注意力输入大语言模型，LLM输出查询条件分割掩码。

  - 正则化项：鼓励不同时间基础向量之间的余弦相似度最小化，即 L_reg = ∑_{i≠j} cos(b_i, b_j) 的均值或最大值

  - 密集段选择：根据稀疏令牌输出的注意力权重或与查询的相似度，定位时间窗口，抽取该窗口内所有patch特征作为密集令牌。

  - 推理：输入视频帧和文本查询，经时间基础感知器得到稀疏令牌，选择密集段，联合送入LLM输出分割掩码。

### 26. DA-Fusion: Deformable Attention-Based RGB-D Fusion Transformer for Unseen Object Instance Segmentation
- 区域：quick；分数：6.0

- 方法流程：

  - 特征提取：两个并行的4层Swin Transformer骨干分别提取RGB和深度多级特征图frgb^i和fd^i (i=1..4)

  - 可变形交叉注意力（DC）：以精炼特征为输入，RGB查询偏移到深度特征采样键值，深度查询偏移到RGB特征采样键值，进行交叉注意力计算，得到融合特征fi
  - 多级特征拼接：将4个阶段的融合特征f1,f2,f3,f4拼接

  - Deformable Self-Attention (DS)：对单模态特征图进行精炼，通过可变形采样关注关键空间区域；从均匀网格生成参考点R，通过偏移网络θ_offset从查询Q学习偏移Δp，得到变形点D=R+Δp（钳位到[0,1]²）。使用双线性插值在变形点采样键K̃和值Ṽ，计算多头注意力得分e = (Q_i^(m)·K̃_k^(m)⊤)/√d_h，结合相对位置偏置插值后经Softmax加权求和，最终拼接所有头输出并投影得到精炼特征f'。
  - Deformable Cross-Attention (DC)：跨模态融合RGB和深度特征，实现双向信息交互；以DS输出f'_rgb和f'_d为输入。对RGB查询Q'_rgb，通过偏移网络预测偏移Δp_rgb→d，应用于深度参考点R'_d采样变形深度特征f̃'_d，得到键K̃'_d和值Ṽ'_d；类似地深度查询Q'_d偏移到RGB特征采样。然后进行交叉注意力：RGB查询注意力得分为Q'_rgb与K̃'_d点积除以√d_h加相对位置偏置插值，Softmax后加权Ṽ'_d；深度查询同理。最后将两路输出拼接形成融合特征fi。
  - 多层级特征融合：利用不同尺度的RGB-D融合信息，增强分割细节和鲁棒性；将骨干网络4个阶段的DC输出fi（i=1,2,3,4）进行拼接，作为像素解码器的输入，使最终解码能同时利用低层纹理/几何细节和高层语义信息。
- 公式/目标函数/指标定义：

  - Q = fW_Q # 查询投影
  - φ(z; (p_x,p_y)) = Σ_{(r_x,r_y)} g(p_x,r_x)g(p_y,r_y)z[r_y,r_x,:] # 双线性插值采样函数
  - e^(m)_{i,k} = (Q_i^(m) · K̃_k^(m)⊤)/√d_h # 单头注意力得分
  - z^(m) = Softmax_k(e^(m) + φ(B̂; R)) Ṽ^(m) # 单头输出
  - f' = Concat(z^(1),...,z^(M)) W_o # 多头拼接输出
- 算法细节：
  - 参考点生成：在特征图上生成均匀网格点，坐标归一化到[0,1]
  - 偏移网络：轻量级子网络（如线性层+激活），从查询特征预测每个参考点的K个偏移（每个头独立）
  - 采样点钳位：将R+Δp限制在[0,1]²内，防止越界
  - 双线性插值采样：在连续坐标处从特征图采样，保证可微
  - 相对位置偏置插值：从预定义的相对位置偏置表中根据参考点坐标插值获取偏置项
  - 多头注意力：使用M个注意力头（K=4个采样点/头），并行计算后拼接投影
  - 跨模态偏移：RGB和深度各自预测指向另一模态采样点的偏移，实现相互导向
- 训练/推理细节：
  - 骨干网络使用Swin Transformer（可能ImageNet预训练）
  - 损失函数采用Mask Transformer的标准损失（包括交叉熵损失和Dice损失等，论文未明确公式，沿用Mask2Former设定）
  - OCBD数据集用于训练和评估，采集自真实杂乱箱子场景（顶视图）
  - 输入深度图像转换为HHA格式（3通道）以匹配RGB通道数
  - 推理时直接将RGB和深度图像输入模型，端到端输出实例掩码

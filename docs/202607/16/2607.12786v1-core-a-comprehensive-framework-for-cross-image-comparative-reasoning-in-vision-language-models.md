## 摘要
跨图像比较推理对视觉语言模型（VLM）仍具挑战性，尤其是在正确预测需要细粒度属性定位和全局一致推理时。我们提出CoRe，一个针对该问题的统一框架。CoRe包括：（i）CoRe-20K，一个大规模基于三元组的训练集，通过多专家协作流水线从结构化视觉元数据自动构建，涵盖计数、深度、距离和空间关系；（ii）TriSR，一个结构化奖励框架，在GRPO优化下联合监督属性定位、判断对齐和三重组一致性；（iii）CoRe-Bench，首个专用于细粒度跨图像比较推理的基准。实验表明，CoRe在CoRe-Bench上显著优于现有VLM，同时在标准多模态基准上保持竞争力，在最强基线上实现了28.2个百分点的部分准确率提升。

## Abstract
Cross-image comparative reasoning remains challenging for vision-language models (VLMs), especially when correct prediction requires fine-grained attribute grounding and globally consistent reasoning. We present CoRe, a unified framework for this problem. CoRe includes: (i) CoRe-20K, a large-scale triplet-based training set automatically constructed from structured visual metadata through a multi-expert collaborative pipeline, covering counting, depth, distance, and spatial relations; (ii) TriSR, a structured reward framework that jointly supervises attribute grounding, judgment alignment, and triplet consistency under GRPO optimization; and (iii) CoRe-Bench, the first benchmark dedicated to fine-grained cross-image comparative reasoning. Experiments show that CoRe substantially outperforms existing VLMs on CoRe-Bench while remaining competitive on standard multimodal benchmarks, achieving a 28.2-point gain in partial accuracy over the strongest baseline.

- **问题识别**：现有视觉语言模型（VLM）在标准多模态任务上表现良好，但在需要**细粒度属性定位**和**全局一致推理**的**跨图像比较推理**任务（例如比较多张图片中物体的数量、深度、距离或空间关系）上表现严重不足。
- **背景分析**：
  - 现有基准多聚焦于**单图感知**（如MME、CV-Bench）或**整体多图语义理解**（如MuirBench、MMRB），缺乏对**细粒度跨图像比较推理**的系统评测。
  - 单纯优化最终答案正确性（outcome-only optimization）会产生“正确答案+错误推理链”的伪成功（作者分析发现，最强基线有高达17.1%的预测虽然答案正确但推理链无效）。
  - 使用LLM作为裁判评估推理链也存在与人类判断严重对齐偏差的问题（图2示例）。
- **整体含义**：跨图像比较推理是VLM的一个独立且尚未被充分服务的能力维度，需要**可验证的中间结构监督**而非仅最终答案或主观评价。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 利用**结构化元数据**自动构建带确定性标签的三元组训练数据（CoRe-20K），并提出**TriSR结构化奖励框架**，在GRPO优化下联合监督属性定位、判断一致性和三重组逻辑一致性，从而引导模型生成既正确又接地气的推理链条。

### 关键技术细节

#### 2.1 数据构建：CoRe-20K（多专家协作流水线）
- **Metric Extraction Expert**：从源数据集的结构化标注中提取每个图像的度量值（计数→实例数，深度→中位深度，距离→欧氏距离，空间关系→区域框标签）。
- **Quality Control Expert**：通过噪声阈值（小差异→噪声）和难度阈值（过大差异→简单伪信号）筛选三元组；对空间关系确保标签多样性。
- **Question Generation Expert**：从模板库生成三对比较子问题（Fig1 vs. Fig2, Fig1 vs. Fig3, Fig2 vs. Fig3），并使用选项随机化消除位置偏置。
- **产出**：CoRe-20K = 20,000个三元组（每任务维度5000），对应60,000个QA对；其中16,000训练，4,000构成**CoRe-Bench**（每任务1,000个三元组）。

#### 2.2 结构化奖励：TriSR
每个模型的输出o包含推理链t和最终答案ŷ，通过规则解析器提取三个中间成分：
- **Attribute Grounding Reward** (R_ag)：衡量模型估计的属性值ˆv_k与元数据真值v_k的差异（使用指数衰减函数），鼓励正确接地。
  - 公式：$R_{ag}(o) = \frac{1}{3} \sum_{k=1}^3 s_m(\hat{v}_k, v_k)$，其中 $s_m(\hat{v}_k, v_k) = \exp\left(-\frac{|\hat{v}_k - v_k|}{\max(|v_k|, \epsilon)}\right)$。
- **Judgment Alignment Reward** (R_ja)：同时检查推理链中的判断是否与真值一致，以及是否与最终答案一致。
  - 公式：$R_{ja}(o) = \frac{1}{2|P|} \sum_{(i,j)\in P} [\mathbb{1}[\tilde{y}_{ij} = y^*_{ij}] + \mathbb{1}[\tilde{y}_{ij} = \hat{y}_{ij}]]$。
- **Triplet Consistency Reward** (R_tc)：由任务特定验证器τ_m检查三元组内部逻辑一致性（如传递性），惩罚矛盾输出。
- **总奖励**：$R(o) = R_{task}(o) + \lambda_{ag} R_{ag}(o) + \lambda_{ja} R_{ja}(o) + \lambda_{tc} R_{tc}(o)$，其中 $R_{task}$ 为子问答正确率。

#### 2.3 优化策略：GRPO
- 对每个查询采样G个响应，计算组归一化优势，结合KL约束更新策略。
- 实验中设置 $\lambda_{ag}=0.2, \lambda_{ja}=0.2, \lambda_{tc}=0.3$，KL系数 $\beta=0.01$，采样数 G=4。

## 3. 实验设计

### 3.1 基准与对比方法
- **核心基准**：**CoRe-Bench**（4,000个三元组，覆盖计数、深度、距离、空间关系）。
- **基线模型**：Qwen3-VL-4B-CoT（基础模型）、InternVL3-2B/8B、LLaVA-OneVision-4B/8B、SSRL-4B、ReMoT-4B；以及部分闭源模型（GPT-4o、Claude-3.7等，仅用于其他基准）。
- **评估指标**：
  - **总体准确率**（Ov.）：三元组内所有三个子问答全部正确。
  - **部分准确率**（Par.）：子问答正确比例的平均值。
- **训练基模型**：Qwen3-VL-4B-Thinking，保持思维链模式。

### 3.2 泛化测试

### 3.3 消融与诊断实验

## 6. 主要结论与发现

1. **跨图像比较推理是VLM系统性的弱项**：所有基线在CoRe-Bench上的总体准确率均低于11%，部分模型仅0.1%~2%。
2. **CoRe显著提升该能力**：在CoRe-Bench上达到22.2%总体准确率（+15.6点）和54.0%部分准确率（+28.2点），超越最强基线ReMoT-4B（10.8%总体）。
3. **结构化奖励优于仅最终答案奖励**：TriSR完整版相比仅R_task在部分准确率上提升2.1点（10%子集上45.7% vs 43.6%），且各组件均有独立贡献，去掉R_tc下降最大。
4. **减少了伪正确推理**：CA+WR（正确答案+错误推理）比例从R_task-only的17.1%降至CoRe的8.3%，同时CA+CR大幅提升。
5. **泛化性强**：在OOD二元比较任务上四个维度均提升，在9个标准VLM基准上保持竞争力，其中5个达到开源最佳（如CV-Bench 85.5%）。
6. **小模型可超越大模型**：4B参数的CoRe在多个基准上匹配或超过7B/8B开源模型，表明精准数据与奖励设计比单纯增大规模更关键。

## 7. 优点

- **问题新颖且实用**：首次系统定义细粒度跨图像比较推理，并提供专用基准，填补了VLM评估空白。

- **实验全面**：囊括主任务、消融、泛化、推理诊断、主流基准、定性分析，结论说服力强。
- **计算效率高**：仅用4B模型和单epoch GRPO训练，资源需求相对低，却达到优秀效果。
- **开源友好**：提供完整框架（数据、代码、基准），便于社区复现和扩展。

## 8. 不足与局限

- **任务覆盖有限**：仅包含计数、深度、距离、空间关系四类。未覆盖颜色、纹理、形状、运动等其它比较维度，评估场景可能不够全面。

- **模型泛化验证不足**：仅基于Qwen3-VL-4B训练和测试，未在LLaVA、InternVL等其他架构上验证TriSR的通用性；也未测试更大参数规模（如7B/8B）上的效果。
- **奖励权重手动调整**：λ_ag、λ_ja、λ_tc的值均凭经验设定，缺乏自适应或搜索机制。
- **消融实验规模小**：10%子集可能引入采样偏差，且未报告在完整训练集上的消融重复结果。

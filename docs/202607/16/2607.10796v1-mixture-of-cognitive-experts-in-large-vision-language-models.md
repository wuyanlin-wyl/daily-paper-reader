## 摘要
大型视觉语言模型（LVLM）需要对视觉和文本输入进行强推理。最近的研究表明，认知元素，特别是多样化的表征和元认知，与更好的性能相关。许多所需的感知功能已经由专门的领域特定计算机视觉模型提供，这些模型作为感知子系统用于检测物体、定位物体、推断状态、恢复空间布局和读取文本。关键挑战在于将这些多编码器专家整合到一个可信、可解释且连贯的表征中，从而提高可验证性并减少幻觉。这很困难，因为视觉-语言问题涵盖不同的认知层次，然而大多数LVLM流程无论每个查询的需求如何，都应用相同的感知-推理路由。我们提出了一种基于证据的多模态推理框架，该框架利用受Bloom启发的分类法作为层次化推理协议。两阶段认知言语化首先通过将专家输出分解为简短、原子的证据陈述，生成字面证据摘要。然后执行Bloom言语化，将这些证据项转化为分阶段推理轨迹，而轻量级的推理轨迹模块则定量分析该轨迹，使证据使用和推理进展明确化。通过这种整合，我们观察到感知和推理能力的若干提升。此外，轨迹模块提供了定量证据，表明不同查询诱导不同的认知入口水平和证据使用轨迹，从而实现细粒度分析。

## Abstract
Large Vision Language Models (LVLMs) require strong reasoning over both visual and textual input. Recent work suggests that cognitive elements, especially diverse representations and metacognition, correlate with better performance. Many of the needed perceptual functions are already provided by specialized domain-specific computer vision models, which act as the perceptual subsystem for detecting objects, localizing them, inferring states, recovering spatial layout, and reading text. The key challenge is to integrate these multi-encoder experts into a trustworthy, interpretable, and coherent representation that improves verifiability and reduces hallucinations. This is difficult because vision-language questions span different cognitive levels, yet most LVLM pipelines apply the same perception-reasoning routing regardless of the demand of each query. We propose an evidence-driven multimodal reasoning framework that utilizes a Bloom-inspired taxonomy as a hierarchical reasoning protocol. The two-stage cognitive verbalization first produces a Literal Evidence Summary by decomposing expert outputs into short, atomic evidence statements. It then performs Bloom Verbalization to turn these evidence items into a staged reasoning trace, and a lightweight Reasoning Trace Module quantitatively analyzes the trace to make evidence usage and reasoning progression explicit. Through this integration, we observed several improvements in perception and reasoning abilities. Moreover, the trace module provides quantitative evidence that different queries induce different cognitive entry levels and evidence-use trajectories that enable fine-grained analysis.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：大型视觉语言模型（LVLM）在视觉和文本推理中常采用统一的感知-推理流程，忽视不同查询所需的认知深度差异（如简单物体识别 vs. 复杂关系推理）。这种同质化处理导致：① 推理过程难以验证和解释；② 易于产生幻觉（hallucination）。作者受认知心理学中 **Bloom 分类法** 启发，旨在将人类分层次认知过程引入 LVLM，使推理更可解释、更可信。
- **背景**：现有工作主要关注评估和数据层面，而本文从**架构设计**出发，通过分离感知与推理、显式构造证据链和分阶段推理轨迹，提升模型在感知、推理和鲁棒性上的表现。

## 2. 方法论
### 核心思想
- 基于 Bloom 分类法（记忆→理解→应用→分析→评估→创造）的层次推理协议，将推理过程分解为从低到高的多个认知步骤，并强制每个步骤引用来自视觉专家提取的原子证据。
- 采用“训练无关”的推理时框架：不加微调，完全依靠 LLM 推理能力整合专家输出和 Bloom 引导。

### 关键技术细节
1. **视觉专家池（Vision Experts Pool）**：包含多个领域专用模型，如 DETR（检测）、SAM（分割）、Pix2Struct / DePlot / Vary（OCR / 图表 / 文档理解）。
2. **路由（Router）**：LLM 根据用户查询和粗略图像嵌入（压缩后的视觉 token）选择最相关的 K 个专家，避免执行全部专家以节省计算。
3. **两阶段认知语言化（Two-stage Cognitive Verbalization）**：
   - **字面证据摘要（Literal Evidence Summary）**：将选定专家的结构化输出（如检测框、OCR 文本）转化为统一的原子证据集合。每条证据包含唯一 ID、类别（TEXT/ENTITY/REGION/TABLE）、简练陈述和引用元数据（如边界框坐标）。
   - **Bloom 语言化（Bloom Verbalization）**：定义有序步骤列表 L = [LIST, EXPLAIN, ILLUSTRATE, COMPARE, HYPOTHESIZE, FINAL ANS.]。查询确定起始步骤 ℓ0，模型依次执行后续所有步骤直至 FINAL。每个步骤生成短文本并引用证据 ID，最终形成完整的结构化草稿答案 \(y_{\text{Bloom}}\)。
4. **推理轨迹模块（Reasoning Trace Module）**：轻量级确定性组件，解析 \(y_{\text{Bloom}}\) 提取起始水平、步骤集合、每步引用的证据 ID 及其类型，用于定量分析推理轨迹。
5. **适配器（Adapter）**：参考 MoVA 的适配器，将路由后的专家特征与基础视觉特征融合，形成丰富的视觉表示，与查询和 \(y_{\text{Bloom}}\) 一起输入最终 LLM 生成答案。

### 公式/算法流程（文字描述）
1. 输入图像 I 和查询 q。
2. Router 选择专家子集 G。
3. 专家池生成结构化输出 O = {O(e)}_{e∈G}。
4. 原子语言化生成证据集 E = {e_i}（包含 id, type, text, ref）。
5. Bloom 语言化生成 \(y_{\text{Bloom}} = f_{\text{Bloom}}(q, E)\)。
6. Reasoning Trace Module 从 y_Bloom 中解析轨迹。
7. 最终 LLM 生成答案 \(\hat{y} = f_{\text{LLM}}(q, I, y_{\text{Bloom}})\)。

- **场景维度**：细分为 Coarse Perception (CP)、Fine-grained Perception (FP-S)、Logical Reasoning (LR)、Relation Reasoning (RR) 等 L-2 能力。

## 6. 主要结论与发现
- **性能提升**：MoCE 在 TextVQA (+3.6 vs LLaVA-1.5 7B)、MMBench (+11.4)、MMVet (+5.1)、POPE (+1.9)、SEED (+6.5) 上一致改进，尤其在感知和推理密集子集（FP-S, LR, RR）上提升显著。
- **Bloom 结构有效性**：相比仅用专家，Bloom 在 MMBench 提升 5.3，SEED 文本理解提升 4.7；同时增加合理计算开销。
- **不同查询触发不同认知深度**：诊断显示 83.8% 的查询起始于 LIST（最低层），其余起始于更高层（如 COMPARE 8.3%），验证了分类法的适应性。
- **可解释性**：每步推理均显式引用证据，使中间过程可审计；轨迹模块提供细粒度定量分析。

## 7. 优点
- **理论创新**：将 Bloom 分类法系统性地引入 LVLM 推理，提供了可操作的认知层次分解。
- **可解释性与可信性**：原子证据存储和 Bloom 言语化使模型输出可验证，每个推理步骤都有明确证据引用。
- **无需重新训练**：所有组件在推理时运行，兼容现有预训练 LVLM，部署成本低。
- **定量诊断能力**：轻量级轨迹模块无需隐藏链式思维，即可分析推理轨迹和认知入口水平。
- **稳健性增强**：在 POPE 等幻觉压力测试下表现更稳定，显示更强抗幻觉能力。

## 8. 不足与局限
- **计算效率**：启用专家池和 Bloom 后延迟增加约 30%，算力消耗提高约 13.75%，实时性可能受限。
- **依赖多模型**：需要同时运行多个专用 CV 模型（检测、分割、OCR 等），增加了系统复杂度和维护成本。
- **规模验证单一**：仅在 7B 级别模型上测试，未在不同参数量（如 13B、34B）上验证方法泛化性。
- **分类学固定**：Bloom 步骤顺序（LIST→...→FINAL）是硬编码的，可能不适合某些需要跳跃式推理或创造性生成的任务。
- **数据集覆盖**：主要评估自然场景和 OCR/图表，未涵盖如医疗、遥感等专业领域，或开放式对话生成。
- **潜在偏差**：路由和言语化依赖 LLM 的指令遵循能力，若基座 LLM 本身对某些查询理解有偏，可能放大错误。
- **公平性考量**：未讨论不同专家组合的公平性，或对罕见物体/语言的性能影响。

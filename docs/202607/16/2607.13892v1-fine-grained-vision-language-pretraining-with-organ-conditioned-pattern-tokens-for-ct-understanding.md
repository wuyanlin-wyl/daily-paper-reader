## 摘要
计算机断层扫描（CT）视觉-语言预训练利用配对的三维体积与放射报告是一项可扩展但极具挑战性的任务。现有方法通常采用全局扫描-报告对比，这种方法虽可扩展但模糊了异质性器官证据。同时，直接进行器官级对齐仍然粗糙，因为同一解剖结构可能呈现多种不同的放射学表现。因此，预训练需要更精细的对齐单元：器官条件化的放射学模式。本文提出OCP-CT，一种基于器官条件模式标记对齐的CT视觉-语言预训练框架。具体地，OCP-CT保留稳定的全局CT-报告对比分支，并引入器官模式接口：稀疏专家混合（MoE）根据潜在放射学模式路由图像与文本标记，可学习槽将路由标记查询为连续模式标记，配对标记对比通过基于报告导出的临床相似性构建的结构化软目标对齐图像-文本模式标记。在公开的CT-RATE和RAD-ChestCT基准上，OCP-CT在零样本异常诊断中分别达到84.5%和69.9%的平均AUROC。与先前报道的最强结果相比，这些结果分别带来了6.7和0.8个百分点的绝对AUROC提升。

## Abstract
Computed tomography (CT) vision-language pretraining from paired volumes and radiology reports is a scalable yet challenging task. Existing methods commonly adopt global scan-report contrast, which is scalable but obscures heterogeneous organ evidence. Meanwhile, direct organ-level alignment remains coarse, since the same anatomy can exhibit multiple distinct radiological appearances. Therefore, pretraining requires a finer alignment unit: the organ-conditioned radiological pattern. In this work, we propose OCP-CT, an organ-conditioned pattern-token alignment framework for CT vision-language pretraining. Specifically, OCP-CT preserves a stable global CT-report contrastive branch and introduces an organ pattern interface: sparse Mixture-of-Experts (MoE) routes image and text tokens according to latent radiological patterns, learnable slots query the routed tokens into continuous pattern tokens, and paired token contrast aligns image-text pattern tokens with structured soft targets built from report-derived clinical similarity. On the publicly available CT-RATE and RAD-ChestCT benchmarks, OCP-CT achieves average AUROCs of 84.5% and 69.9% for zero-shot abnormality diagnosis, respectively. Compared with the strongest prior reported results, these results yield absolute AUROC gains of 6.7 and 0.8 percentage points.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：计算机断层扫描（CT）视觉-语言预训练（VLP）从配对的CT体积与放射学报告中学习可扩展的表示，是医学影像分析的重要方向。现有方法多采用全局扫描-报告对比（如CLIP范式的3D扩展），虽可扩展但将多器官、多模式的证据压缩为一个单一匹配信号，模糊了异质性器官证据。
- **核心矛盾**：
  - 全局对比：粗粒度，忽略不同器官（肺、心、食管、主动脉）的特定发现。
  - 器官级对齐：仍粗糙，因为同一器官（如肺）可能同时包含正常实质、弥漫性磨玻璃影、局灶结节、胸腔积液等多种不同放射学模式。
- **研究目标**：提出一个**更细粒度的对齐单元——器官条件下的放射学模式（organ-conditioned radiological pattern）**，在保留全局对比可扩展性的同时，暴露器官内部的模式异质性，提升CT表示学习的质量。

## 2. 论文提出的方法论（核心思想、关键技术细节）

### 2.1 核心思想
- 在全局对比分支基础上，插入一个**器官条件模式令牌瓶颈**，将图像/文本的器官级令牌通过稀疏混合专家（MoE）路由到模式特定的变换，再通过可学习槽（slot queries）池化为固定数量的连续模式令牌，最后用**配对模式令牌对比**与**结构化软目标**进行局部跨模态对齐。

### 2.2 关键技术细节

#### a) 全局对比骨干
- 图像编码器：ResNet-18，输出3D特征图 $F_i$。
- 全局令牌 $z_i^g$：平均池化 + 可学习门控查询残差（初始残差接近0，避免干扰预训练初始化）。
- 文本编码器：BioMedVLP-CXR-BERT，输出全局报告令牌 $u_i^g$。
- 全局对比损失 $L_{\text{global}}$：标准对称交叉熵，温度 $\tau_g$。

#### b) 器官条件模式路由
- 使用器官掩码（如果可用）从特征图中选择器官图像令牌 $V_{i,o}$，报告侧通过字段解析获得器官文本令牌 $T_{i,o}$（覆盖肺、心、食管、主动脉）。
- **稀疏MoE**：为每个器官独立设置图像MoE和文本MoE，每个MoE包含 $M=4$ 个专家，top-2路由。每个令牌 $v$ 经过路由器 $p_I(v)$ 选出前2个专家，加权聚合得到路由后的令牌 $\tilde{v}$。
- 负载平衡损失 $L_{\text{moe}}$ 防止专家崩塌。

#### c) 连续模式令牌（Slot Pool）
- 每个器官有 $K_s=6$ 个可学习槽查询 $Q_o \in \mathbb{R}^{K_s \times C}$。
- 使用注意力将路由后的令牌池化为模式令牌：$S_{i,o}^I = A_{i,o}^I \tilde{V}_{i,o}$，其中 $A$ 是槽查询与路由令牌的softmax注意力矩阵。
- 多样性损失 $L_{\text{div}}$：鼓励不同槽之间的余弦相似度低（避免复制相同特征）。

#### d) 配对模式令牌对比
- **器官内模式匹配**：对同一器官，图像模式令牌 $S_{i,o,k}^I$ 与文本模式令牌 $S_{j,o,k}^T$ 按索引k计算对角相似度，平均得到整体相似度 $p_{ij}^{(o)}$。
- **结构化软目标**：构造目标矩阵 $T^{(o)} = \lambda_d I + \lambda_a A_{\text{abn}} + \lambda_c A_{\text{concept}} + \lambda_l A_{\text{loc}} + \lambda_r A_{\text{attr}}$，其中 $A_{\text{abn}}$ 基于18个异常标签，$A_{\text{concept}}$ 基于器官映射的疾病概念重叠，$A_{\text{loc}}$ 和 $A_{\text{attr}}$ 基于位置/属性（从报告中用RadGraph-XL和LLM提取）。
- **批量模式对比损失** $L_{\text{pITC}}$：将归一化后的软目标作为标签分布，对预测相似矩阵做交叉熵（双向），允许相关样本获得弱正监督，避免硬负样本过度惩罚。

#### e) 辅助损失
- **病理提示锚定损失** $L_{\text{prompt}}$：将正/负病理提示编码为模式令牌，与图像/报告模式令牌做二元交叉熵。
- **器官分类损失** $L_{\text{organCls}}$：基于平均模式令牌预测器官映射的发现（多标签分类）。

#### f) 总训练目标
- $L = L_{\text{global}} + \lambda_{\text{local}} L_{\text{pITC}} + \lambda_{\text{div}} L_{\text{div}} + L_{\text{moe}} + L_{\text{prompt}} + L_{\text{organCls}}$

- **训练流程**：先使用多标签CT异常分类预训练视觉编码器（无报告对比），再联合优化上述所有损失。

## 3. 实验设计

### 3.1 数据集
- **CT-RATE**：50,188个胸部CT扫描，21,304患者，18个异常标签（训练/验证/测试拆分按CT-CLIP）。
- **RAD-ChestCT**：36,316个非增强胸部CT，来自杜克大学（2012-2017），83个异常标签，公开子集3,630扫描用于外部验证。

### 3.2 基准与对比方法
- 对比方法包括：CT-Net（仅视觉）、CT-CLIP、BIUD、Merlin、COLIPRI-C（对比变体）、fVLM（解剖感知方法，最相关基线）。
- 评估任务：
  1. **零样本异常诊断**：AUROC、ACC、F1、Precision。
  2. **图像-图像检索**：MAP@5/10/50（基于异常标签相似度）。
  3. **报告-图像检索**：Recall@5/10/50/100。

### 3.3 实验结果摘要
- **诊断**：CT-RATE上AUROC 84.5%（+6.7 vs fVLM），RAD-ChestCT上69.9%（+1.9 vs fVLM）。
- **检索**：Img2Img MAP@50 53.5（+4.6 vs 最佳基线）；Rpt2Img Recall@100 48.6（+19.9 vs CT-CLIP）。
- **器官组分析**：所有器官组AUROC均有提升（肺+8.9，心+5.4，主动脉+3.7，食管+8.0，其他+9.6）。

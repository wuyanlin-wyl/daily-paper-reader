### 1. Bi-PT: Bidirectional Cross-Attention Point Transformers for Four-Chamber Heart Reconstruction from Sparse Cardiac MRI Data
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.06923v1
- 方法流程：
  - 输入：从临床CMR长轴和短轴视图提取的稀疏点云(SPC)和模板点云(Atlas)
  - 特征提取：使用点变换器对SPC和Atlas分别编码点特征
  - 双向交叉注意力：在Atlas和SPC之间进行双向交叉注意力聚合，获得增强的点特征，同时预测每个点的语义标签
  - 变形场生成：将增强特征输入NODE，输出每个点的仿射变换矩阵和位移向量，形成局部仿射微分同胚变形场
  - 网格重建：将Atlas点根据变形场进行变换，得到与目标形状匹配的完整四腔心网格
  - 输出：三维四腔心网格
- 关键模块/机制：
  - 双向点交叉注意力模块：学习Atlas与SPC之间的对应关系和鲁棒点特征；使用两个交叉注意力层：一个以Atlas点为查询、SPC点为键和值，另一个以SPC点为查询、Atlas点为键和值。通过多头注意力聚合特征，并输出每个点的语义标签预测。
  - 神经常微分方程(NODE)变形场模块：参数化变形场，保证局部仿射微分同胚；将变形场建模为ODE的解，其中每个点的速度场由神经网络参数化，网络输出每个点的仿射变换矩阵A和位移向量b，使得最终变形为局部仿射变换，并且通过ODE积分保证微分同胚性。
  - 多任务损失模块：联合优化点位置、语义标签一致性和变形光滑性；损失函数包括Chamfer距离（用于点位置）、语义标签交叉熵损失（用于标签一致性）、以及变形场二阶导数的L2正则化（光滑性）。
- 公式/目标函数/指标定义：
  - L = L_chamfer + λ_label * L_label + λ_smooth * L_smooth
  - L_chamfer = Σ_{x∈S} min_{y∈T} ||x - y||^2 + Σ_{y∈T} min_{x∈S} ||x - y||^2
  - L_label = -Σ_i log p(l_i | f_i) (交叉熵损失)
  - L_smooth = ||∇^2 Φ||^2 (变形场二阶光滑正则)
  - 变形场 Φ(x) = x + ∫_0^1 v(x(t), t) dt, v由网络输出局部仿射参数(A,b)定义
- 算法细节：
  - 使用点变换器(Point Transformer)对每个点云进行特征编码，得到逐点特征向量
  - 双向交叉注意力：先对Atlas特征用SPC特征加权求和，再对SPC特征用Atlas特征加权求和，得到增强的对应感知特征
  - 从增强特征中通过全连接层预测每个点的语义标签
  - 将增强特征输入一个MLP，输出每个点的仿射变换参数(3x3矩阵A)和位移(3维向量b)，组成局部仿射变换
  - 将Atlas点初始位置输入NODE，通过RK4等积分器迭代更新位置，得到变形后的点云
  - 使用倒角距离和语义标签损失计算差异，反向传播更新网络参数
- 训练/推理细节：
  - 训练时，输入为SPC和Atlas，监督信号为目标完整心腔网格（可能来自注释或模拟）
  - 使用Adam优化器，学习率1e-4
  - 损失权重λ_label和λ_smooth通过网格搜索调节
  - 推理时，给定新的SPC，直接通过前向传播得到变形后的完整网格

### 2. FabriVLA: A Lightweight Vision-Language-Action Model for Precise Multi-Task Manipulation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.08575v1
- 方法流程：
  - 输入：RGB图像（resize至448×448）和任务指令文本，通过InternVL3.5-1B（保留14层）提取多模态上下文令牌
  - 状态编码：机器人状态s∈R24经两层MLP（ReLU）编码为状态令牌z_s∈R1024，拼接到上下文令牌序列前
  - 动作编码：噪声动作x_t∈R^{50×24}通过共享MLP（24→1024→1024→1024）和位置编码生成动作令牌序列A∈R^{50×1024}
  - 浅层融合：取VLM第6层和第14层输出令牌，沿特征维度拼接，经线性投影W∈R^{2048×1024}（初始化[I|0]）降回1024维，作为融合上下文C
  - 动作头处理：8个TransformerBlock处理动作令牌A和上下文C，每个块包含门控自注意力、交叉注意力、带时间条件的FFN，输出经层归一化、序列池化和MLP得到预测速度场v_θ∈R^{50×24}
  - 推理：从均匀噪声x_0~U([-1,1]^{50×24})开始，用欧拉积分迭代50步生成最终动作，反归一化后执行
- 关键模块/机制：
  - 门控自注意力层：使动作令牌间可进行自注意力，但初始门控值为0，训练中逐步打开以平滑引入时间依赖；在每个TransformerBlock中，动作令牌A先进行多头自注意力，输出乘以可学习门g（初始0）后再加残差：A' = A + g·SelfAttn(LayerNorm(A))
  - 浅层VLM层融合：结合深层语义和浅层空间细节，为动作头提供更丰富的上下文，提升精细操作性能；将VLM第6层（浅层）和第14层（深层）的输出令牌在特征维度拼接，通过线性层W∈R^{2048×1024}投影回1024维，W初始化为[I|0]以保证初始输出与纯深层一致
  - 流匹配动作头：学习从噪声分布到专家动作分布的速度场，通过欧拉积分生成动作序列；训练时，从Beta(2,2)采样t，构造插值x_t=(1-t)ε+ta，预测速度v_θ，损失L=E[||v_θ-(a-ε)||^2]。推理时从均匀噪声开始，逐步积分50步得动作
- 公式/目标函数/指标定义：
  - 门控自注意力：A' = A + g · SelfAttn(LayerNorm(A))
  - 流插值：x_t = (1-t) ε + t a
  - 流匹配损失：L(θ) = E_{t,ε,a}[∥v_θ(x_t, t | ·) - (a - ε)∥²]
  - 欧拉积分：x_{t+Δt} = x_t + v_θ(x_t, t | ·) · Δt, Δt=1/50
  - 时间嵌入：TimeEmb(t) 使用正弦位置编码，p=⌊1000t⌋，维数d=1024
- 算法细节：
  - 门控参数g为标量，初始化为0，随梯度更新逐渐调整
  - 浅层融合线性投影W初始化为[I|0]确保与纯深层基线一致
  - 时间t从Beta(2,2)分布采样，集中在0.5附近
  - 推理时使用50步均匀间隔的欧拉积分，从均匀噪声x_0~U([-1,1]^{50×24})开始
  - 动作编码器为共享MLP，对每个动作步独立投影并加上可学习位置编码
  - TransformerBlock中时间嵌入在FFN前添加到LayerNorm后的令牌
- 训练/推理细节：
  - 单阶段联合训练，所有参数（VLM骨干和动作头）从起始一起优化
  - 使用DeepSpeed ZeRO-2和FP32主权重，避免BF16导致VLM更新量过小
  - 学习率：线性预热W步后余弦衰减，具体W值未提供
  - 梯度裁剪范数c，优化器AdamW，权重衰减λ（具体值未提供）
  - 训练数据：Evo-1 Meta-World数据集，共2500条轨迹（每任务50条）
  - 推理时动作以闭环回退方式执行，每次预测50步但仅执行当前动作

### 3. MedRealMM: A Real-World Multimodal Benchmark for Chinese Online Medical Consultation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09142v2
- 方法流程：
  - Phase 1: 真实多模态咨询语料构建 - 输入原始医患交互记录，经过图像存在过滤、完整性过滤、科室平衡采样、去标识化、人工审核五阶段，输出最终语料C
  - Phase 2: MCCP提取 - 输入语料C和咨询轨迹，Cropper agent筛选临床参与度高的时刻，Verifier agent验证多模态相关性，选择得分最高的位置t*，输出截断后的实例x = C≤t*及预测目标y_target = c_{t*+1}
  - Phase 3: 医生引导的案例特定评分标准构建 - 输入实例x和原始医生响应y_orig，Generator生成初始评分标准R(0)，医生反馈后Refiner迭代优化至R*
  - Phase 4: 基于评分标准的自动评估 - 输入实例x、模型生成响应y、评分标准R*，Grader逐准则判定v_j，按权重聚合得到分数S并计算整体Score
- 关键模块/机制：
  - MCCP提取框架 (Multimodal Clinical Challenge Point Extraction)：从真实咨询轨迹中定位临床关键且多模态相关的时刻，构建标准化评估实例；包含两个LLM agent: Cropper ϕA评估每个医生回复前的时刻是否涉及实质性临床参与（如病史采集、鉴别诊断等）；Verifier ϕM验证该时刻之前患者上传的图像是否对合理响应至关重要。选择两者得分之和最大的时刻t*，截取轨迹至该时刻作为评估输入。
  - 医生引导的案例特定评分标准 (Physician-Guided Case-specific Rubric)：为每个实例生成可操作的正负评价准则，避免参考答案匹配的局限性；Generator ϕR基于实例x和原始医生响应y_orig生成初始准则集合R(0) = {(c_j, w_j)}，w_j ∈ [-20,20]且非零，正准则奖励临床正确行为，负准则惩罚不安全/矛盾。医生人工审查并提供结构化反馈F(k)，Refiner ϕ'R迭代修订直至无反馈。最终R*包含3-19条准则。
  - Rubric-grounded LLM-as-a-judge 评估 (Rubric-Grounded Automated Evaluation)：可扩展地评估模型生成的开放响应，保留案例特定临床期望；使用Grader ϕJ逐准则判断响应是否满足c_j，输出v_j ∈ {0,1}和理由r_j。聚合时，计算加权和除以正准则总权重，并裁剪到[0,1]：S = Clip( Σ w_j v_j / Σ max(w_j,0), 0, 1)。整体分数为所有实例平均。
- 公式/目标函数/指标定义：
  - 咨询轨迹表示：C = (e1, e2, ..., eT)，其中 et = (ct, mt, st, τt)，ct内容，mt模态集合，st发送者，τt时间戳
  - 语料构建流程：C0 → C1 (图像存在) → C2 (完整性) → C3 (科室平衡) → C4 (去标识) → C (审核)
  - MCCP候选集：TA(C) = {t ∈ T | lA(t)=1}，TM(C) = {t ∈ TA(C) | lM(t)=1}，t* = argmax (sA+sM)
  - 评分标准生成：R(0) = ϕR(x, y_orig) = {(c_j, w_j)}，迭代R(k+1)=ϕ'R(x,R(k),F(k))
  - 准则级评估：(v_j, r_j) = ϕJ(x, y, c_j), v_j∈{0,1}
  - 案例分数：S(x,y,R*) = Clip( Σ w_j v_j / Σ max(w_j,0), 0, 1)
- 算法细节：
  - 多阶段语料构建：先过滤仅含患者图像的咨询，再去除过短或不完整的案例，然后按科室分布采样以平衡数据，接着用LLM辅助去标识化（移除个人可识别信息且保留临床内容），最后人工审核隐私和临床可用性
  - MCCP提取：Cropper和Verifier均为LLM agent，对每个候选时刻分别输出二元决策和得分；多候选时选择得分和最大的时刻；无候选时丢弃该咨询
  - 评分标准迭代：医生在每轮审查当前标准R(k)，指出缺失、权重错误或临床考虑不足，Refiner根据反馈修改，直到医生批准（无反馈）
  - 评估时Grader仅基于实例x、生成响应y和准则c_j做判定，不参考原始医生响应，避免对风格偏差的惩罚
- 训练/推理细节：
  - 评估为推理阶段，模型输入为截断的咨询历史x（包含文本和图像），输出医生回复y；模型输出长度受JD Health平台严格限制（简短回复要求）
  - 评分标准生成和评估使用特定LLM：Claude-Opus-4.7用于生成和修改rubric，Gemini-3-Pro-Preview作为Grader和去标识agent；rubric迭代3轮以达到收敛

### 4. ShapKO: Shapley-Adaptive Modality Knockout for Robust Multimodal Learning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.09884v1
- 方法流程：
  - 输入：多模态训练样本 (xi, yi)，观测模态集合 O_i ⊆ O
  - 阶段1（优化模型）：对每个样本，根据当前敲除概率 rm 对观测模态进行伯努利采样，得到掩码向量 zm；构建敲除后的嵌入集合 ê_m；计算损失 L(1/|O_i| Σ L(f_θ(ê_m), yi))；更新模型参数 θ
  - 阶段2（更新敲除率）：每K个epoch后，冻结模型，在验证集上评估所有模态子集 S ⊆ O 的效用 v(S)=J(S)；计算每个模态的Shapley值 ϕ_m；通过权重转换和clip更新敲除率 rm
  - 输出：训练好的鲁棒预测模型 f_θ
- 关键模块/机制：
  - 模态编码器：将各模态原始输入映射为固定维度的嵌入向量；针对不同模态使用专用编码器：Prostate MRI使用U-Net 3D CNN；MMD使用病理、影像、基因、人口学各自编码器；FlexCare使用三模态Transformer架构。
  - 效用评估与Shapley计算模块：评估当前模型在各模态子集上的性能，计算每个模态的Shapley值；对验证集上每个子集S，用当前模型使用S中模态（其余用占位符）计算评价指标J(S)，得到效用v(S)。随后按Shapley公式（式1）计算各模态边际贡献的加权平均。
  - 自适应敲除率更新模块：将Shapley值转化为敲除概率，动态调整各模态的掩码频率；将Shapley值最小-最大归一化到[0,1]区间得权重wm；计算基敲除率r=1-0.5^{1/d}；更新rm = clip(r * (wm / w̄)^δ, rmin, rmax)，其中δ控制敏感度。
- 公式/目标函数/指标定义：
  - Shapley值：ϕ_m = Σ_{S⊆O\{m}} (|S|! (|O|-|S|-1)! / |O|!) [v(S∪{m}) - v(S)]
  - 权重转换：w_m = (ϕ_m - ϕ_min) / Σ_{m'∈O} (ϕ_{m'} - ϕ_min)
  - 敲除率更新：r_m = clip( r * (w_m / w̄)^δ, r_min, r_max )，其中r = 1 - 0.5^{1/d}
  - 训练损失：L(ê_m, y_i) = (1/|O_i|) Σ_{m=1}^{|O_i|} L(f_θ(ê_m), y_i)
- 算法细节：
  - 训练时对每个样本观测模态进行伯努利采样，强制至少保留一个模态（通过拒绝采样确保Σ z_m ≥ 1）
  - 缺失模态（结构缺失或合成缺失）均用固定占位符嵌入代替，不同数据集选用不同占位符（零向量、-1向量、可学习[MISS]/[KO] token）
  - Shapley值计算需要枚举所有模态子集（2^d），因此d较小（3-4）
  - 阶段2每K个epoch触发，K根据任务设定（如10或20）
  - 使用AdamW优化器，权重衰减5e-5至1e-5
- 训练/推理细节：
  - 训练：两阶段交替，阶段1更新模型参数，阶段2固定模型更新敲除率
  - 推理：任意模态子集可输入，缺失模态用结构占位符填充，模型直接预测
  - 超参数：学习率1e-4至3e-4，批量大小未提及，训练epochs 100-300

### 6. SynthDocBench: Controlled Benchmark for Long-Context Visual Document Understanding
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10400v1
- 方法流程：
  - 阶段1：文档生成 (Document Generation): 输入主题种子τ，通过内容生成、视觉语法设计、可视化合成（D3.js + 元数据）、验证与组装，输出视觉报告D和结构化清单M（HTML/PDF+元数据）。
  - 阶段2：QA生成 (QA Generation): 输入文档D和清单M，解析文本、表格、可视化通道，恢复图表元数据，合成证据单元，生成三类问题（chart-reading/cross-modal/complex multi-hop）并标注难度L1-L5，经过验证过滤后输出QA对。
  - 阶段3：视觉-only评估 (Vision-only Evaluation): 输入渲染页面图像序列I和问题q，模型在无元数据条件下生成答案ˆa，使用GPT-5评分器计算与标准答案a*的得分，输出ACC和平均分。
- 关键模块/机制：
  - Topic-grounded content generation：生成报告语义主干，从主题种子提取证据并组织为结构化中间表示，明确章节边界和数据跨度；给定主题τ，检索主题相关证据，重组织为结构化中间表示，暴露节边界、数据承载跨度和显著内容单元

### 13. Attention-Free and Lightweight Token Reduction for Efficient Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13500v1
- 方法流程：
  - 输入：视觉编码器输出的视觉令牌序列 X = {x_i} (N个)，每个令牌为D维特征向量。
  - 重要性评估：对每个令牌计算熵值，保留Top-K1个高熵令牌。熵计算基于令牌特征向量的激活值分布。
  - 多样性评估：对令牌施加线性变换得到标量一致性分数，按分数排序后以步长采样保留K2个令牌。
  - 合并：根据比例超参数α分配预算K1和K2，将两组令牌合并得到最终紧凑令牌集。
  - 输出：缩减后的令牌集送入LLM进行多模态推理。
- 关键模块/机制：
  - 熵引导重要性估计模块：评估每个令牌的信息量，保留信息丰富的令牌。；对于每个令牌特征向量，将其视为概率分布（例如通过softmax归一化），计算熵 H(x_i) = -Σ p_j log p_j。熵高的令牌被认为具有更丰富和退化的特征表示，因此被保留。该计算不依赖注意力图，线性复杂度。
  - 变换一致性多样性采样模块：确保保留令牌的视觉多样性，避免冗余。；对令牌施加一个固定或学习的线性变换（如单层MLP），得到每个令牌的标量响应。由于相似令牌在相同变换下产生相似响应，排序该响应值使得相似令牌相邻，然后按固定步长（stride = N / K2）采样，从而获得多样性令牌子集。无需成对比较，计算开销极低。
- 公式/目标函数/指标定义：
  - 熵计算公式：H(x_i) = -∑ p_j log p_j，其中 p_j 是令牌特征在第j维上的归一化值。
  - 目标：选择K个令牌，同时最大化信息量和多样性。实际通过分离的两步实现。
- 算法细节：
  - 重要性估计：对每个令牌计算熵，无需注意力图，只需一次前向。

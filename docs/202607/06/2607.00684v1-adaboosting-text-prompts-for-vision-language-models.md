## 摘要
预训练视觉-语言模型（VLM）的分类精度依赖于文本提示的质量。手工设计的模板和大语言模型（LLM）生成的描述不仅使预测更具可解释性，还能在不同的VLM之间重用相同的提示。最近的研究利用少量标注图像构建任务适应的文本提示。然而，现有的少样本文本提示方法在提示构建过程中并未明确关注误分类样本，导致即使随着可用样本增加，改进也仅微乎其微。为充分利用少样本监督，我们提出文本提示提升（TPB），一种受AdaBoost启发的框架，将每个基于文本提示的分类器视为弱学习器，并通过明确针对困难、误分类样本，依次将它们聚合成一个强集成。大量实验表明，TPB在文本空间中保留了任务固有、模型无关的线索，从而实现鲁棒的跨模型迁移。在十一个分类基准测试中，TPB在源模型上提高了准确率，并在迁移到更大、更强的VLM时保持了基于样本的改进，而现有方法难以维持这种改进。

## Abstract
The classification accuracy of pretrained Vision-Language Models (VLMs) relies on the quality of the text prompts. Handcrafted templates and Large Language Model (LLM)-generated descriptions not only make predictions more interpretable, but also enable reuse of the same prompts across heterogeneous VLMs. Recent works construct task-adapted text prompts with a small number of labeled images. However, existing few-shot text prompting methods do not explicitly focus on misclassified examples during prompt construction, leading to only marginal improvements even as more shots become available. To fully exploit few-shot supervision, we propose Text Prompt Boosting (TPB), an AdaBoost-inspired framework that treats each text-prompt-based classifier as a weak learner and sequentially aggregates them into a strong ensemble by explicitly targeting hard, misclassified examples. Extensive experiments show that TPB preserves task-intrinsic, model-agnostic cues in text space, enabling robust cross-model transfer. Across eleven classification benchmarks, TPB improves accuracy on the source model and preserves shot-driven gains when transferred to larger, more capable VLMs, where existing methods struggle to sustain such improvements.

## 1. 核心问题与整体含义（研究动机与背景）

视觉-语言模型（VLM，如CLIP）的零样本分类性能高度依赖文本提示的质量。现有的少样本文本提示方法（如LLMbo、ProAPO等）虽然利用少量标注图像来构造任务适应提示，但存在一个根本问题：它们优化的是整体验证准确率等单一聚合指标，容易被易识别样本主导，导致对困难/误分类样本关注不足。因此，即使增加标注样本（shots），性能提升也趋于饱和（图1b展示了这一现象）。为了解决该问题，论文受经典AdaBoost算法启发，提出**文本提示提升（Text Prompt Boosting, TPB）**框架，通过迭代地构建自然语言提示集成，明确聚焦于被前一轮误分类的样本，从而有效利用少样本监督。

## 2. 方法论

### 2.1 核心思想
- 将每个由**类级提示集合**（class-wise prompt bank）定义的分类器视为一个**弱学习器**。
- 采用AdaBoost的多类扩展版本**SAMME.R**，进行迭代重加权和聚合。
- 每一轮通过**Greedy Prompt Composition (GPC)**算法构建弱分类器，GPC从预定义的大规模提示池中贪婪地选择提示，以最小化当前加权错误率。

### 2.2 关键技术细节

#### 2.2.1 提示池构建
- 对每个类别，构建包含**80个CLIP手工模板**、多个LLM生成的描述（来自DCLIP、CuPL等）以及它们的拼接结果的大规模提示池，确保语义多样性。

#### 2.2.2 Greedy Prompt Composition (GPC)
- **阶段1：单模板初始化**：在所有类别上使用一个共享模板（从80个模板中选出使加权错误最小的那个）作为初始提示集。
- **阶段2：类级贪心插入**：按类别循环，从该类提示池中选取能最大程度降低加权错误的提示（允许重复拷贝，以近似连续权重），反复迭代直到无改进。

#### 2.2.3 加权错误最小化
- 对每个候选提示t和复制数d，计算加入d份后加权错误的变化Δε(k,t,d)，并利用翻转条件（upside/downside flips）的闭式表达式高效计算。
- 同时引入归一化惩罚（Δε/d）以鼓励提示多样性，防止单一提示被过度复制。

#### 2.2.4 增强与集成
- 在每轮GPC前对训练集应用**图像增强**（随机裁剪、水平翻转），增强因子a=4，防止过拟合。
- 每轮生成弱分类器后，根据SAMME.R更新样本权重，增加误分类样本的权重。
- 最终通过加权投票（基于类概率的对数）聚合所有弱分类器。

### 2.3 算法流程（文字说明）
1. 初始化样本权重均匀分布。
2. 构建类别提示池。
3. 对每一轮m=1..M：
   - 对训练集应用增强，复制样本并调整权重。
   - 执行GPC得到当前轮的最优提示集合B^(m)，构成弱分类器。
   - 用原始训练集评估，并依据SAMME.R更新权重。
4. 集成M个弱分类器，输出最终预测。

## 6. 主要结论与发现

- TPB在源模型上显著优于所有文本基线，且shot可扩展性明显：从1-shot到16-shot平均提升6.5 pp，而ProAPO仅提升1.7 pp（RN50上）。
- 在跨模型迁移上，TPB能保持shot驱动的增益：在ViT-L目标上从76.76%提升到82.07%，而ProAPO几乎饱和；转移鲁棒性优于连续提示方法（CoOp+EFT等）和梯度优化方法（PEZ）。
- PEZ虽然优化了离散提示，但生成的是无意义的文字序列，无法跨模型迁移（表3）。
- 增强是TPB有效性的关键：没有增强时，训练精度很快饱和，后续提升轮次不再有益（图5）。
- 提示池的多样性有助于提升性能，即使弱描述也能在集成中发挥作用。

## 7. 优点

- **方法创新**：将AdaBoost成功应用于离散文本提示构建，首次在VLM少样本适应中利用集成思想明确聚焦困难样本。
- **强适应性**：在多种VLM间无需任何微调即可迁移，且保持shot增益。
- **高效推理**：文本嵌入可预计算，仅需一次前向传播。
- **可解释性**：生成的提示是自然语言，可读且可重用。
- **实验充分**：涵盖大量数据集、多种模型架构、多层级消融，验证了方法的鲁棒性。

## 8. 不足与局限

- **构建代价**：在大规模数据集上，提示池和GPC的贪心搜索可能计算成本较高（但论文指出推理无额外开销）。
- **噪声敏感性**：AdaBoost式的重加权可能过度强调少数噪声样本，对标注质量有一定依赖。
- **固定提示池**：提示选择仅从预设池中挑选，无法生成全新提示，限制了灵活性；对于细粒度或模糊类别可能不够精确。
- **超参数敏感**：弱分类器数量M、增强因子a等需要调节，且M=30-50时性能才充分。
- **未探索复杂训练场景**：如多模态、视频理解等更复杂任务，尚未验证。

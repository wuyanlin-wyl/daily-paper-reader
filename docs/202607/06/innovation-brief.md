### 1. Enhancing Part-Level Point Grounding for Any Open-Source MLLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29267v1
- 方法流程：
  - 输入：图像I和文本描述T，通过MLLM的视觉编码器得到图像特征Vv，文本编码器得到文本特征Qt（来自特定层和注意力头）。
  - Q-Synth模块：初始化N个可学习潜向量Z0，以Qt为K/V，通过T层交叉注意力迭代注入语义，得到Z_T。用MLP加权聚合各潜向量得到合成查询qs。
  - 合成注意力图：用qs与图像特征Kv（来自MLLM的键）计算点积，得到低分辨率注意力图As（尺寸Ph×Pw）。
  - Attention-to-Point解码器：将As与Vv进行空间调制（加权）得到特征图F；对k个注意力头的特征图通过MLP加权并拼接，经1×1卷积降维为F_fused；通过卷积和双线性上采样生成高分辨率热图H。
  - 点预测：从H中取最大值坐标作为最终预测点。
- 关键模块/机制：
  - Q-Synth模块：从所有文本token中提取与目标相关的语义，合成单个查询向量qs，用于生成注意力图。；初始化N个可学习潜向量Z0，以文本特征Qt为K和V，经过T层残差交叉注意力更新：Z^{(t)} = Z^{(t-1)} + CrossAttn(Z^{(t-1)}, Qt, Qt)。最后通过MLP计算每个潜向量的权重α=softmax(MLP(z_i))，加权求和得到qs=∑α_i z_i。每个选定的注意力头都有一个独立的Q-Synth模块。
  - Attention-to-Point解码器：将低分辨率注意力图转换为高分辨率点热图，实现精确定位。；输入k个合成注意力图As_i和图像特征Vv。对每个头：F_i = As_i * Vv（逐像素加权）。用轻量MLP学习每个头的权重，加权求和后沿特征维度拼接，经1×1卷积降维为F_fused。然后通过一系列卷积层和双线性上采样逐步提升分辨率，最终输出热图H。
- 公式/目标函数/指标定义：
  - Z^{(t)} = Z^{(t-1)} + CrossAttn(Z^{(t-1)}, K_s, V_s)，其中K_s=V_s=Qt。
  - qs = ∑_{i=1}^N α_i z_i, α_i = softmax(MLP(z_i))。
  - L_bce = BCE(q_s K_v^T, M_p)，其中M_p为下采样后的部件分割掩码。
  - f(x) = softplus(x/τ) + γ(e^{x/τ} (x≤0) ? e^{x/τ} : 1)，其中x为SDF值，τ和γ为超参数。
  - L_sdf = ∑_{u,v} softmax(H(u,v)) * f(D(u,v))。
  - L_total = L_bce + λ L_sdf。
- 算法细节：
  - Q-Synth使用T层残差交叉注意力，T为超参数（论文未明确数值，但提到multiple rounds）。
  - 在MLLM中，选择前k个具有最高相关性（实验未详述如何选择）的注意力头作为定位头，每个头独立使用Q-Synth，生成k个注意力图，然后在A2P中融合。
  - A2P解码器中，先对每个头的特征图F_i用MLP学习权重w_i，然后加权求和得到加权特征，再拼接并通过1×1卷积得到F_fused。
  - 上采样部分：卷积层与双线性插值交替，逐步将分辨率从Ph×Pw提升到H×W（原始图像尺寸）。
  - 点预测：从最终热图H中取最大值坐标作为预测点。
- 训练/推理细节：
  - 训练时冻结所有原始MLLM参数，仅训练Q-Synth模块和A2P解码器。
  - 使用三部分损失：L_bce监督Q-Synth产生与目标区域对齐的注意力模式；L_sdf监督A2P产生集中在目标内部的热图；λ为平衡系数。
  - SDF损失中，先计算地面真值掩码的符号距离场D，然后通过f变换得到惩罚场，再与H的softmax输出的乘积求和。
  - 推理时，输入图像和文本，前向传播一次，直接获得热图H，取最大值点。无需额外后处理。

### 2. FADE: Mitigating Hallucinations by Reducing Language-Prior Dominance in Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29431v2
- 方法流程：
  - 输入图像和文本查询，经视觉编码器和语言嵌入得到初始隐藏状态h^(0)
  - 对每一层：先计算注意力得到˜h^(l) = h^(l) + Attn^(l)(h^(l))
  - 在关键层（如LLaVA-1.5-7B的16-22层）对FFN输出进行衰减：h^(l+1) = ˜h^(l) + (1-α)·FFN^(l)(˜h^(l))
  - 其他层正常计算：h^(l+1) = ˜h^(l) + FFN^(l)(˜h^(l))
  - 经过所有层后，使用语言模型头将最终隐藏状态映射为输出token概率
- 关键模块/机制：
  - Attention模块：聚合来自不同位置的视觉证据，在所有层中一致地推动预测朝向正确答案；通过残差流计算注意力贡献，使用差分logit lens度量每个注意力层的推动方向
  - FFN模块：在关键层（16-22）引入语言先验，当与视觉证据冲突时覆盖注意力结果导致预测漂移；对隐藏状态进行逐位置变换，在正确样本中强化正确答案，在幻觉样本中主动推高错误答案概率
  - FADE衰减机制：在关键层衰减FFN输出以抑制语言先验，同时保持注意力贡献不变；对选定关键层的FFN输出乘以衰减系数(1-α)，α∈[0,1]为超参数，控制衰减强度
- 公式/目标函数/指标定义：
  - 注意力贡献差分：Δ^(l)_Attn(t) = LM_head(˜h^(l))_t - LM_head(h^(l))_t
  - FFN贡献差分：Δ^(l)_FFN(t) = LM_head(h^(l+1))_t - LM_head(˜h^(l))_t
  - 正确方向度量：C^(l) = Δ^(l)(t_correct) - Δ^(l)(t_incorrect)
  - FADE前向公式：h^(l+1) = ˜h^(l) + (1-α)·FFN^(l)(˜h^(l))
- 算法细节：
  - 使用logit lens技术从残差流投影到词汇空间，逐层跟踪正确答案概率
  - 通过差分logit lens分离每个模块的贡献，并定义正确方向度量进行跨样本比较
  - 识别关键层：对LLaVA-1.5-7B为第16-22层，其他模型按比例映射到中间偏后层
  - FADE无需额外训练或参数，仅在推理时对指定层的FFN输出进行标量缩放
- 训练/推理细节：
  - FADE是训练无关方法，不修改模型参数，仅在推理时应用
  - 衰减强度α需要根据模型和任务调整（通常在0.2-0.5之间）
  - 关键层选择基于预分析：对LLaVA-1.5-7B固定为16-22层，其他模型按比例映射
  - 单个前向传播即可完成，与标准解码相比仅增加少量乘法计算

### 3. ScAle: Attention Head Scaling as a Minimal Adapter for Spatial Reasoning in Vision Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.29579v1
- 方法流程：
  - 输入：图像I和问题q，通过冻结的VLM编码，获取每层中间激活。
  - 对第l层每个注意力头h，提取最后token输出z_{l,h}，应用可学习有界缩放因子eff(u_attn_{l,h})，得到缩放后激活 ilde{z}_{l,h}。
  - 对第l层MLP，提取最后token输出Y_l，应用可学习有界缩放因子eff(u_MLP_l)，得到缩放后激活 ilde{Y}_l。
  - 缩放后的激活传入后续层，最终使用最后token的logits对候选答案进行评分。
  - 训练：最小化交叉熵损失加L2正则化，仅更新缩放参数ϕ，冻结所有预训练权重θ。
- 关键模块/机制：
  - 有界缩放函数：生成稳定缩放因子；使用eff(u)=1+smax*tanh(u)将标量参数u映射到(1-smax,1+smax)区间，实验中smax=10，确保缩放因子有界且可导。
  - 注意力头缩放模块：逐头调整最后token注意力输出幅度；对第l层第h个注意力头，学习标量u_attn_{l,h}，缩放因子eff(u_attn_{l,h})乘以后头输出z_{l,h}（最后token），参数数量L×H。
  - MLP缩放模块：逐层调整最后token MLP输出幅度；对第l层MLP，学习标量u_MLP_l，缩放因子eff(u_MLP_l)乘以MLP输出Y_l（最后token），参数数量L。
  - 训练目标与优化：指导缩放参数学习；损失函数L(ϕ)=CE(ℓ_ϕ(I,q), c⋆) + λ_attn Σ||u_attn||₂² + λ_MLP Σ||u_MLP||₂²，使用AdamW优化器，学习率1e-3，λ=1e-4，冻结原参数。
- 公式/目标函数/指标定义：
  - 缩放函数：eff(u) = 1 + smax * tanh(u), smax=10
  - 注意力头缩放：\tilde{z}_{l,h} = eff(u_attn_{l,h}) * z_{l,h}
  - MLP缩放：\tilde{Y}_l = eff(u_MLP_l) * Y_l
  - 损失函数：L(ϕ) = CE(ℓ_ϕ(I,q), c⋆) + λ_attn Σ_{l,h} (u_attn_{l,h})^2 + λ_MLP Σ_l (u_MLP_l)^2
  - 优化目标：ϕ^* = arg min_ϕ E_{(I,q,c⋆)∼D_train} L(ϕ)
- 算法细节：
  - 前向：每个样本通过冻结VLM，对每层每个注意力头最后token输出乘以对应缩放因子，对每层MLP最后token输出乘以对应缩放因子，其余计算不变。
  - 反向：仅计算缩放参数ϕ的梯度，更新ϕ，保持预训练权重θ不变。
  - 缩放因子受有界函数约束，不会出现极端值。
- 训练/推理细节：
  - 训练使用SpatialEval的小样本分割（5%、10%、20%共75/150/300样本），每个任务独立训练。
  - 学习率1e-3，λ_attn=λ_MLP=1e-4，AdamW优化器，微批大小1，训练5个epoch。
  - 推理时，加载训练好的缩放因子，冻结模型，仅进行前向传播。

### 4. VisReflect: Latent Visual Reflection for Fine-Grained Perception in Long Visual Context
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.30288v1
- 方法流程：
  - 输入：高分辨率图像或长视频帧序列，以及对应的文本问题
  - 视觉编码器提取视觉tokens，LVLM骨干网络处理得到隐藏状态
  - 在特定层（如最后一层）插入视觉反射生成模块，根据问题和视觉上下文生成一组连续向量
  - 将视觉反射作为附加的key/value参与注意力计算，引导模型关注与问题最相关的视觉区域
  - 输出：基于聚焦后的视觉表示生成答案
- 关键模块/机制：
  - 潜在视觉反射生成器：根据问题和视觉上下文生成代表相关视觉特征的连续潜在向量；通过一个轻量级网络（如MLP）将问题嵌入和全局视觉特征映射为一组连续向量，这些向量不是离散token，而是直接在潜在空间中优化
  - 注意力引导机制：将生成的视觉反射注入注意力层，增强相关视觉token的注意力权重；在Transformer注意力层中，将视觉反射的向量作为额外的key和value，与原始视觉tokens的注意力计算结合，使得模型更关注与反射特征对齐的区域
- 算法细节：
  - 视觉反射生成：使用文本问题的隐藏状态和视觉tokens的全局池化作为输入，通过线性变换和激活函数产生一组K个连续向量，K远小于视觉tokens数量
  - 注意力注入：在每个解码层，将生成的向量与原始视觉tokens拼接，或作为额外的query/key/value参与交叉注意力，使得每个注意力头都能学习从反射中获取线索
- 训练/推理细节：
  - 训练：保持LVLM主干冻结，仅训练视觉反射生成器，使用原始任务损失（如语言建模损失）端到端优化
  - 推理：单次前向传播，无需额外的边界框预测或裁剪重编码步骤，推理时间降低约44%

### 5. Set-Inclusive Uncertainty Modeling for Robust Brain Tumor Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.30374v1
- 方法流程：
  - 输入：多模态MRI（T1, T1c, T2, FLAIR），每个模态经专用编码器E^{(m)}得到嵌入e_i^{(m)}。
  - 构造三个模态索引集：S_i^{sub} ⊂ S_i^{sup} ⊂ S_i^{full}，其中full为全模态，sub和sup为部分子集。
  - 对每个部分子集，通过共享解码器D聚合对应模态嵌入得到任务表示z_i^k，再经两个头f_θ和f_φ得到均值μ_i^k和标准差σ_i^k。
  - 重参数化采样：r_i^k = μ_i^k + ε ⊙ σ_i^k, ε~N(0,I)。
  - 任务预测：任务头h分别处理r_i^k（部分子集）和μ_i^{full}（全模态），输出预测ŷ。
  - 计算任务损失：L_Task = ℓ(ŷ_sub, y) + ℓ(ŷ_sup, y) + ℓ(ŷ_full, y)，ℓ为Dice损失。
  - 计算不确定性感知对齐损失L_UA（式8）：驱动部分均值靠近全模态均值，方差随差异增大。
  - 计算不确定性排序损失L_UO（式9）：惩罚超集方差大于子集方差。
- 关键模块/机制：
  - 概率表示模块：将任务表示转化为高斯分布参数(μ,σ)，通过重参数化采样引入不确定性；对每个部分子集，通过f_θ和f_φ网络从任务表示z_i^k得到μ_i^k和σ_i^k；采样r_i^k = μ_i^k + ε⊙σ_i^k，ε~N(0,I)。训练时使用r_i^k预测，推理时仅用μ_i^k。
  - 集合包含模态掩码：构建具有包含关系的三个模态子集，为不确定性引导提供层次结构；对每个样本，随机选择两个部分子集S_sub和S_sup满足S_sub⊂S_sup⊂S_full；全模态S_full始终包含所有模态。
  - 不确定性感知对齐损失L_UA：使部分子集均值向全模态均值对齐，同时方差反映对齐残差；逐元素计算高斯负对数似然：L_UA = E[ Σ_{k∈{sub,sup}} ( (μ_k - stopgrad(μ_full))^2 / (2σ_k^2) + 0.5 log(σ_k^2) ) ]。梯度不回传到μ_full。
  - 不确定性排序损失L_UO：强制子集方差大于超集方差，维护层次一致性；L_UO = E[ max(0, (σ_sup)^2 - (σ_sub)^2 ) ]，惩罚违反排序的情况。
- 公式/目标函数/指标定义：
  - 重参数化：r_i = μ_i + ε ⊙ σ_i, ε~N(0,I)
  - 梯度协方差与σ_i的关系：Cov_ε[∇θL(θ;ε)] ∝ σ_i^2
  - 期望损失近似：Eε[L(μ+ε⊙σ)] ≈ L(μ) + 1/2 Tr(∇^2L diag(σ^2))
  - 任务损失：L_Task = ℓ(ŷ_sub, y) + ℓ(ŷ_sup, y) + ℓ(ŷ_full, y)，ℓ为Dice损失
  - 不确定性感知对齐损失：L_UA = E[ Σ_{k∈{sub,sup}} ( (μ_k - μ_full)^2 / (2σ_k^2) + 0.5 log(σ_k^2) ) ]，其中μ_full梯度停止
  - 不确定性排序损失：L_UO = E[ max(0, (σ_sup)^2 - (σ_sub)^2 ) ]
- 算法细节：
  - 训练时每个样本构造三个模态配置：全模态、任意子集S_sub、包含S_sub的超集S_sup，S_sub和S_sup通过随机选择模态生成但保证包含关系。
  - 全模态配置不进行随机采样，直接取均值μ_full预测。
  - 部分子集配置经过重参数化采样后预测，梯度经采样路径回传。
  - L_UA中μ_full的梯度被截断，仅更新部分子集的参数。
  - L_UO使用hinge损失强制方差排序。
  - 优化器采用AdamW，学习率调度等详见实验部分。
- 训练/推理细节：
  - 训练时使用重参数化采样，损失函数包含任务损失和两个正则项，超参数α=0.1, β=0.01（根据实验设置）。
  - 推理时仅使用每个配置的均值μ进行预测，不进行采样。
  - 全模态配置作为不确定性锚点，在L_UA中梯度停止。
  - 采用了模态缺失模拟：训练时随机缺失部分模态，但全模态始终可用以提供锚点。

### 6. PGE-SAM: Prompt-Guided Feature Enhancement for Interactive Segmentation under Degradation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2606.30477v1
- 方法流程：
  - 输入：退化图像I、用户提示（点/框/掩码）
  - 阶段1：通过冻结的SAM图像编码器提取多尺度特征（包括低层和高层）
  - 阶段2：Prompt Guidance Generator (PGG)根据用户提示和SAM解码器返回的先验掩码生成空间引导图
  - 阶段3：特征恢复网络（含MSFI模块）在空间引导下对SAM编码器特征进行增强恢复
  - 阶段4：使用Foreground Reconstruction Loss监督恢复特征与干净图像特征在前景区域的对齐
  - 阶段5：将恢复后的特征送入SAM掩码解码器，结合用户提示生成最终分割掩码
  - 输出：分割掩码
- 关键模块/机制：
  - Prompt Guidance Generator (PGG)：生成空间引导图，使特征恢复聚焦于用户感兴趣区域；PGG接收用户提示（点、框或粗略掩码）以及先验掩码（来自前一迭代），通过轻量级网络生成空间注意力权重图，强调分割目标区域，抑制背景和退化噪声影响。
  - Multi-Scale Features Interaction (MSFI)：融合低层和高层特征，恢复因退化丢失的细粒度细节；MSFI将SAM图像编码器不同阶段的多尺度特征进行交互，特别是将低层（高分辨率但语义弱）特征与高层（低分辨率但语义强）特征通过注意力或卷积融合，以补充细节信息。
  - Foreground Reconstruction Loss (FRL)：约束特征恢复网络只在前景区域进行重建，避免背景噪声干扰；FRL计算恢复后的特征与干净图像编码器特征在前景掩码区域内的L2距离，仅在前景像素上监督特征重建，忽略背景区域。
- 公式/目标函数/指标定义：

### 9. StochasT: Learning with Stochastic Turn Depth for Visual Instruction Tuning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.00465v1
- 方法流程：
  - 输入：多轮对话数据集 D，包含每个图像的 N 轮问答对序列 C = {(X_q^(n), X_a^(n))}_{n=1}^N
  - 阶段1：随机树构建。对每个 turn n，从后向前遍历之前的 turn k，以 Beta 分布采样丢弃概率 p_k，若 Bernoulli 抽样指示保留，则选择 k 为父节点；否则继续，若全部丢弃则连接根节点（图像和系统提示）。
  - 阶段2：掩码生成。根据父节点分配结果，修改因果注意力掩码，使得每个 turn 只能看到其选定父节点及之前的上下文，而非完整的顺序历史。
  - 阶段3：训练。使用修改后的注意力掩码，在保留所有 turn 和 token 的情况下计算负对数似然损失 L_multi（式2），优化模型参数。
  - 输出：训练后的 LVLM，具备在单轮和多轮场景下的鲁棒能力。
- 关键模块/机制：
  - 随机轮次深度机制（Stochastic Turn Depth）：核心训练策略，为每个 turn 随机选择历史上下文，构造隐式对话树集合。；对每个 turn n，从后向前遍历 k=n-1到1，依次采样 pk~Beta(α,β)，mk~Bernoulli(1-pk)，若 mk=1 则停止并选 k 为父节点，否则继续；若全丢弃则选根节点（图像）。通过注意力掩码实现历史依赖的随机化。
  - Beta 分布参数 (α, β)：控制丢弃概率的分布形状，灵活调整对话长度的偏好。；每个 turn 的丢弃概率从 Beta(α, β) 采样，α 和 β 作为超参数，可偏向短对话或长对话。
  - 因果注意力掩码修改：在自回归框架中实现随机历史依赖。；利用因果注意力的性质，为每个 token 设置注意力范围，使得每个 turn 只能注意到其选定父节点序列中的 token，忽略被丢弃的中间 turn。
  - 算法1: Construct Stochastic Tree：生成每个 turn 的父节点分配 P[n]。；输入 N, α, β；输出父节点数组 P。可选随机打乱 turn 顺序。对每个 n，设 k=n-1，循环：pk~Beta, mk~Bernoulli，若 mk=1 则 break 并设 P[n]=k；否则 k--；若 k=0 则 P[n]=0（根）。
- 公式/目标函数/指标定义：
  - 式(1): P_θ(X_a|X_v, X_q) = ∏_{i=1}^L P_θ(x_{a,i} | X_v, X_q, x_{a,<i})
  - 式(2): L_multi = -∑_{n=1}^N ∑_{i=1}^{L_n} log P_θ(x_{a,i}^{(n)} | X_v, H^{(n)}, x_{a,<i}^{(n)})，其中 H^{(n)} 为累积上下文
  - 式(3): L_single = -∑_{n=1}^N ∑_{i=1}^{L_n} log P_θ(x_{a,i}^{(n)} | X_v, X_q^{(n)}, x_{a,<i}^{(n)})
  - 式(4): p_n ∼ Beta(α, β)
  - 式(5): Ĉ = { (X_q^{(n)}, X_a^{(n)}) | m_n=1, n=1..N }，其中 m_n ~ Bernoulli(1-p_n)
- 算法细节：
  - Algorithm 1: 输入 N, α, β；可选随机打乱 turn 顺序；对 n=1..N，设 k=n-1；当 k>0 时：pk~Beta(α,β)，mk~Bernoulli(1-pk)；若 mk=1 则 break；否则 k--；最终 P[n]=k（k=0 表示根）。返回 P。
  - 实现时，根据 P[n] 修改因果注意力掩码：每个 turn 只能看到从根到父节点（包含）的序列，中间被丢弃的 turn 不可见。
  - 训练时保留所有 N 个 turn 的 token 用于损失计算，但历史依赖随机化，不实际删除 token。
- 训练/推理细节：
  - 训练使用 LoRA 微调，基于 Qwen2.5-VL-3B 和 LLaVA-1.5-7B 的官方视觉指令微调检查点。
  - 损失函数为负对数似然，在保留所有 turn token 的情况下优化（式2），但注意力掩码根据随机树调整。
  - 超参数：Beta 分布的 α 和 β 需调优（实验部分显示在平衡 α=β 时表现较好）。
  - 推理时：不使用随机化，直接采用原始多轮对话的完整因果掩码（标准 multiT 模式）或单轮模式。
  - 训练效率：StochasT 相比 SingleT 需要更少的 token（因为不重复图像），收敛更快（见图4）。

  - 阶段3a：使用GPC构建当前弱分类器的提示集合B^{(m)}：
  - 步骤1：单模板初始化：遍历80个模板，选择使加权分类错误最小的模板φ*，用φ*填充每个类别的提示集（每个类别一个提示）。

  - 权重更新采用SAMME.R，使用分类器的实值预测概率而非硬分类结果来调整样本权重。

  - 计算Z_v和Z_t的SIGReg正则化项，加权相加

  - FADE衰减机制：训练无关的推理时干预，通过衰减系数α降低关键层FFN输出强度；关键层FFN输出乘以(1-α)，α∈[0,1]；单次前向传播，无额外参数或对比解码开销
- 公式/目标函数/指标定义：
  - 残差流更新：\tilde{h}^{(l)} = h^{(l)} + \text{Attn}^{(l)}(h^{(l)})
  - 原始FFN步：h^{(l+1)} = \tilde{h}^{(l)} + \text{FFN}^{(l)}(\tilde{h}^{(l)})
  - FADE FFN步：h^{(l+1)} = \tilde{h}^{(l)} + (1-\alpha) \cdot \text{FFN}^{(l)}(\tilde{h}^{(l)})
  - 注意力贡献度量：\Delta_{\text{Attn}}^{(l)}(t) = \text{LM head}(\tilde{h}^{(l)})_t - \text{LM head}(h^{(l)})_t
  - 正确方向度量：C^{(l)} = \Delta^{(l)}(t_{\text{correct}}) - \Delta^{(l)}(t_{\text{incorrect}})
- 算法细节：
  - 基于logit lens的贡献分解方法，通过前后状态差量化注意力与FFN的贡献
  - 使用正确方向度量C^{(l)}比较正确与错误样本的组件贡献
  - 关键层识别：通过概率轨迹（图3）和贡献分析（表1）确定LLaVA-1.5-7B的16-22层为语言先验主导层
  - 跨模型迁移：将关键层索引按模型总层数比例映射到其他架构（如mPLUG-Owl2、InstructBLIP）
  - 单次前向传播中直接修改FFN输出，无需辅助模型或多次前向
- 训练/推理细节：
  - 训练无关：FADE不修改模型参数，仅推理时应用
  - 推理效率：单次前向传播，无额外开销（对比解码需多次前向）
  - 衰减系数α为超参数，论文中通过验证集搜索（如0.2-0.4）
  - 仅对关键层应用衰减，非关键层保持原始FFN输出

### 20. MIRROR: Aligning Semantic Relations from Language to Image via Gromov--Wasserstein
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2606.29462v1
- 方法流程：
  - 输入：视觉token序列和文本token序列；输出：优化后的MLLM参数
  - 步骤1：前向传播：通过视觉编码器（ViT）和大语言模型（LLM）进行前向计算
  - 步骤2：解耦注意力提取：从最终ViT层提取视觉自注意力矩阵Av，从早期LLM层（第1层）提取文本自注意力矩阵At，从中间LLM层（第16层）提取交叉注意力矩阵{Ah}
  - 步骤3：对称化和熵计算：对Av和At进行对称化，计算每个交叉注意力头Ah的熵Hh
  - 步骤4：头选择：选择k个最小熵的头（k=8），平均得到耦合矩阵C
  - 步骤5：非语义token过滤：对At中的非语义token进行衰减，得到˜At
  - 步骤6：SI-GW损失计算：将At和Av转换为距离矩阵Dt和Dv，利用C计算目标结构bDv，然后计算Dv与bDv的Frobenius范数平方作为LSI-GW
  - 步骤7：总损失：L_total = L_LM + λ * L_SI-GW，其中λ=0.002
- 关键模块/机制：
  - 解耦注意力提取：分离不同的注意力来源，为后续对齐提供干净的视觉和文本关系矩阵；从最终ViT层提取视觉自注意力Av（反映视觉token间关系），从LLM第1层提取文本自注意力At（反映语言token间关系），从LLM第16层提取交叉注意力头{Ah}（反映视觉与文本token间耦合）。所有矩阵进行对称化处理。
  - 熵基头选择：筛选出关注最集中、信息最清晰的交叉注意力头，构建可靠的跨模态耦合；计算每个交叉注意力头Ah的熵Hh = -Σ_{i,j} Ah_{ij} log Ah_{ij}，保留k个最小熵的头（k=8），平均这些头得到耦合矩阵C。低熵头具有更聚焦的注意力模式。
  - 非语义token过滤：减弱非语义token（功能词、系统提示等）对关系结构的干扰；对文本自注意力At中的非语义token位置进行衰减，具体通过位置感知的衰减因子α=0.5，得到˜At。衰减方式：˜At = At ⊙ (1 - α * mask)，mask标识非语义token。
  - SI-GW损失计算：强制视觉自注意力矩阵的关系结构接近语言自注意力矩阵的关系结构；将At和Av转换为距离矩阵：Dt = -log(˜At + ε)，Dv = -log(Av + ε)。通过耦合矩阵C计算目标结构：bDv = (C^T Dt C) ⊘ (b b^T)，其中b = C^T 1_{nt}。损失为LSI-GW = || Dv - bDv ||_F^2。该问题具有唯一闭式解。
- 公式/目标函数/指标定义：
  - LLM损失：L_LM = -Σ_t log p(w_t | f(v_1),...,f(v_{n_v}), w_{<t})
  - SI-GW损失：L_SI-GW = || Dv - bDv ||_F^2
  - 总损失：L_total = L_LM + λ * L_SI-GW
  - 距离矩阵：Dt = -log(˜At + ε)，Dv = -log(Av + ε)
  - 目标结构：bDv = (C^T Dt C) ⊘ (b b^T)，其中b = C^T 1_{nt}
- 算法细节：
  - 解耦注意力提取：从不同网络层提取三种注意力矩阵，分别对应视觉内部、文本内部和跨模态关系。
  - 对称化：Av ← (Av + Av^T)/2，At ← (At + At^T)/2，保证距离矩阵对称。
  - 熵基头选择：计算每个交叉注意力头的熵，取最小的k个头平均得到耦合矩阵C。
  - 非语义token过滤：基于token位置和类型（如功能词、系统提示）构建掩码，对At进行衰减。
  - SI-GW计算：通过耦合矩阵C将语言距离矩阵Dt映射到视觉空间，得到目标距离bDv，然后计算视觉距离Dv与目标距离的Frobenius范数平方。
- 训练/推理细节：
  - 微调：在LLaVA-1.5和LLaVA-NeXT的7B/13B模型上进行1个epoch微调，使用8块NVIDIA RTX 6000 Ada GPU (48GB)。
  - SI-GW权重λ=0.002。
  - 头选择k=8，耦合层选择Layer 16。
  - 非语义token衰减α=0.5。
  - 推理时无额外参数或计算开销，因为SI-GW损失仅在训练时使用。

  - 对于选择性弃权，使用实际返回答案的校准置信度（闭书或开书）进行风险覆盖排序
- 关键模块/机制：
  - 校准器（Logistic Calibrator）：将原始不确定性信号映射为正确的概率估计；使用逻辑斯蒂回归拟合：pi = σ(α si + β)，其中si是标量信号（如长度归一化序列对数概率），参数α,β通过最小化交叉熵损失在校准数据集上学习。采用诊断性交叉验证（out-of-fold）或训练/验证/测试分裂。
  - 分级决策策略（Graded Policy）：根据校准概率选择检索预算级别；使用两个阈值τ0和τ1：若pi ≥ τ0则k=0（闭书）；若τ1 ≤ pi < τ0则k=1（紧凑检索）；若pi < τ1则k=5（全面检索）。决策基于校准概率，而非原始信号。
  - 选择性RAG（Selective RAG）：允许系统弃权以降低风险；基于实际返回答案的校准置信度进行弃权：若系统闭书，则置信度为闭书校准概率；若系统检索，则对开书答案的序列对数概率单独校准得到置信度。按置信度排序得到风险覆盖曲线，计算AURC。
- 公式/目标函数/指标定义：
  - 校准公式：pi = σ(α si + β) = 1/(1+exp(-(α si+β)))
  - 分级策略：ai = 0 if pi ≥ τ0; ai = 1 if τ1 ≤ pi < τ0; ai = 5 if pi < τ1
  - 预算轴：xcall = Pr(ai > 0); xfull = Pr(ai = 5); xpassage = (Pr(ai = 1) + 5 Pr(ai = 5))/5
  - 延迟成本模型（二元门控）：C_binary = c_CB + p5 (c_ret,5 + c_OB,5)；分级门控：C_graded = c_CB + p1 (c_ret,1 + c_OB,1) + p5 (c_ret,5 + c_OB,5)
- 算法细节：
  - 校准器训练：从已生成的数据表中提取(si, y(0)_i)对（对于闭书校准），使用逻辑回归训练；对于开书校准，使用(si, y(k)_i)对
  - 诊断性交叉验证：将评估池分成K折，对每折用其他折训练的校准器预测，避免过拟合
  - 阈值选择：在验证集上网格搜索τ0, τ1以优化目标（如准确率-成本权衡）
  - 推理时：对每个查询计算si，加载校准器参数得到pi，比较阈值决定k；若k>0则执行检索并生成答案
- 训练/推理细节：
  - 不训练阅读器或检索器，只训练轻量级逻辑斯蒂校准器
  - 校准器训练数据来自预先生成的答案表（需包含闭书、开书答案及正确性标签）
  - 推理时：每个查询需要计算不确定性信号（如序列对数概率），然后应用校准器（一次前向）
  - 分级策略的阈值可从验证集上选择，也可根据系统约束（如延迟预算）动态调整

### 25. Thinking Before Retrieving: Robust Zero-Shot Composed Image Retrieval via Strategic Planning and Self-Criticism
- 区域：quick；分数：6.0

- 方法流程：
  - 阶段1 (Planner): 输入参考图像IR和修改文本TM，联合分析后输出结构化约束，包括保存属性、修改属性、复杂度等。
  - 阶段2 (Executor): 输入结构化约束，生成多个候选目标描述（如3-5个），每个描述覆盖不同的语义组合。
  - 阶段3 (Critic): 评估每个候选描述与约束的符合程度，选择最满足所有约束的候选作为最终查询Q。
  - 阶段4 (Retrieval): 使用查询Q通过文本编码器f_ϕ编码，与图像编码器f_θ编码的图像库计算余弦相似度，返回相似度最高的图像I*。
- 关键模块/机制：
  - Planner：提取结构化约束；输入参考图像IR和修改文本TM，通过多模态大模型联合理解，输出显式约束包括：保存属性列表（如颜色、类别）、修改属性列表（如替换、添加）、操作类型（如替换颜色、改变场景）、禁止项列表，以及推理复杂度等级（如简单/中等/复杂）。约束以结构化格式（如JSON）表示。

  - Critic：评估并选择最优候选；对每个候选描述，Critic模块基于Planner提取的约束进行逐条检核，评估是否满足所有保存和修改要求。评估方式可以是评分（如0-1分）或二值判断，并可能生成解释。选择得分最高且无违反的候选作为最终查询Q；若无合格候选，则触发反馈循环要求Executor重新生成。

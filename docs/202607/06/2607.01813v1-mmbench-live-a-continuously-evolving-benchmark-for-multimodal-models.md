## 摘要
评估基准对于评估视觉语言模型(VLMs)至关重要，但大多数多模态基准是静态的，容易受到时间陈旧、数据污染和维护成本高的影响。我们提出了MMBench-Live，一个由多智能体驱动的自动化流水线构建的持续演进的多模态基准。我们的框架将基准演进视为任务导向的数据集构建，集成了结构化基准规范、反馈控制的实时数据采集以及具有可执行推理的可验证问答生成。为了保持跨版本的可比性，我们引入了一种分布一致的更新策略，从原始基准中提取与任务相关的视觉模式，以指导数据收集和筛选。基于MMBench实例化，MMBench-Live包含5.9K个新生成的评估实例，具有很高的答案正确率，每次更新成本约为30美元，耗时1-2小时。广泛评估表明，MMBench-Live保持了稳定的模型排名，与原始基准保持了语义一致性，并表现出较弱的污染相关记忆信号，为可持续的多模态基准演进提供了一种实用且可扩展的范式。该项目可在https://github.com/PRIS-CV/MMBench-Live获取。

## Abstract
Evaluation benchmarks are essential for assessing vision-language models (VLMs), but most multimodal benchmarks are static, making them vulnerable to temporal staleness, data contamination, and costly maintenance. We present MMBench-Live, a continuously evolving multimodal benchmark built by a multi-agent-driven automated pipeline. Our framework treats benchmark evolution as task-guided dataset construction, integrating structured benchmark specification, feedback-controlled real-time data acquisition, and verifiable QA generation with executable reasoning. To maintain cross-version comparability, we introduce a distribution-consistent update strategy that extracts task-related visual patterns from the original benchmark to guide data collection and filtering. Instantiated from MMBench, MMBench-Live contains 5.9K newly generated evaluation instances with a high answer correctness rate, while each update costs about USD 30 and takes 1-2 hours. Extensive evaluations show that MMBench-Live preserves stable model rankings, maintains semantic alignment with the original benchmark, and exhibits weaker contamination-related memorization signals, suggesting a practical and scalable paradigm for sustainable multimodal benchmark evolution. The project is available at https://github.com/PRIS-CV/MMBench-Live.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将基准演进视为一个**任务导向的数据集构建**过程。通过一个多智能体驱动的自动化管道，从原始基准出发，持续生成在内容和分布上相似但数据全新的评估实例。

- **关键技术细节（自动化管道）**：
    1.  **结构化基准规范（Structured Benchmark Specification）**：
        - 将原始基准（如MMBench）中的每个评估问题转化为一个结构化描述。该描述包含了核心的任务类型、问题模板、答案格式，以及模型需要关注的**关键视觉模式**。这种描述是生成新数据的基础。
    2.  **反馈控制的实时数据采集（Feedback-Controlled Real-Time Data Acquisition）**：
        - 一个智能体（Acquisition Agent）根据结构化规范，主动从开放的互联网（如搜索引擎、图片网站）中搜索并采集**实时、全新**的图片数据。系统会通过反馈机制验证采集的图片是否包含规范中指定的关键视觉模式，确保数据相关性和质量。
    3.  **可验证的问答生成（Verifiable QA Generation）**：
        - 另一个智能体（Generation Agent）基于新采集的图片和结构化规范，自动生成问题-答案对（QA pairs）。
        - **关键创新**：生成过程利用**可执行推理**。这意味着生成的答案不是简单的文本，而是带有可被程序化验证的推理步骤。例如，回答“图片中有多少只猫？”会附带“1. 检测猫... 2. 计数... 3. 答案为3”这样的逻辑路径，使得答案的正确性可以自动校验。
    4.  **分布一致的更新策略（Distribution-Consistent Update Strategy）**：
        - 为了确保新旧版本基准的可比性，该策略自动从原始基准中提取与每个任务相关的、具有代表性的**视觉模式**。这些模式（如“背景为室外”、“物体处于特定方位”等）会被作为硬约束，指导新数据的采集和筛选，从而保证新生成的数据集在**视觉分布**上与原始基准保持一致，使得模型在新旧基准上的排名具有可比性。

- **算法流程（文字说明）**：
    1.  **输入**: 一个现有的静态基准（如MMBench）。
    2.  **解析与规范**: 分析基准中每个样本，提取问题类型、答案空间和关键视觉模式，形成结构化规范。
    3.  **数据采集**: 利用结构化规范中的线索，通过多智能体协作，从互联网自动采集符合要求的实时图片。
    4.  **数据过滤**: 对采集的图片进行反馈控制，确保其包含指定的视觉模式。
    5.  **QA生成与验证**: 基于新图片和规范，自动生成问题并附带可执行的推理过程，然后通过执行该推理自动验证答案的正确性，剔除错误样本。
    6.  **输出**: 一个全新的、在任务和视觉分布上与原始基准对齐的评估实例集合。

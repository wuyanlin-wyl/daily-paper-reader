## 摘要
3D CT视觉-语言模型（VLM）能够以零样本方式从文本提示中分类异常，从而实现跨机构部署，在这些机构中，标签稀缺且临床任务变化速度快于监督模型的重训练速度。然而，真实的CT扫描通常包含多个共现异常，在分布偏移下零样本多标签预测的可靠性仍不明确。测试时自适应（TTA）在没有源数据或目标标注的情况下，在未标记的目标扫描上更新模型，但现有的TTA方法针对自然图像或2D医学分割的多类softmax预测，且没有一种方法能够解决零样本3D CT VLM的无监督多标签自适应问题。我们研究TTA何时有助于零样本3D CT VLM。一项受控诊断分析表明，TTA是有条件的：体积输入必须保持编码器的深度结构，且基础表征必须能够迁移到目标队列，仅深度缩减就会使内部AUROC下降超过0.12。然后，我们专注于基础模型已能区分存在与不存在异常的情况。我们引入了CARVE（基数感知保留视图熵），这是针对该设置的首个TTA方法。CARVE估计样本特定的正标签基数$\hat{k}$，优化top-$\hat{k}$目标以保留共现异常，并通过在更新保留子集前对弱3D视图进行无梯度评分，执行内存高效的多视图自适应。在对比例CT-CLIP和解剖感知fVLM的实验中，当基础模型已具有区分能力时，CARVE在多标签、三类和二值CT任务上提供了一致的改进。这些结果将零样本3D CT VLM的多标签TTA确立为一个独特问题，并将CARVE作为基数感知的解决方案。

## Abstract
3D CT vision-language models (VLMs) classify abnormalities from text prompts in a zero-shot manner, enabling cross-institution deployment where labels are scarce and clinical tasks shift faster than supervised models can be retrained. A real CT scan, however, typically contains several co-occurring abnormalities, and the reliability of zero-shot multi-label prediction under distribution shift remains poorly understood. Test-time adaptation (TTA) updates a model on unlabeled target scans without source data or target annotations, yet existing TTA methods target multi-class softmax prediction on natural images or 2D medical segmentation, and none addresses unsupervised multi-label adaptation for zero-shot 3D CT VLMs. We study when TTA helps zero-shot 3D CT VLMs. A controlled diagnostic analysis shows that TTA is conditional: the volumetric input must preserve the encoder's depth structure, and the base representation must transfer to the target cohort, with depth reduction alone lowering internal AUROC by more than 0.12. We then focus on the regime where the base model already separates present from absent abnormalities. We introduce CARVE (Cardinality-Aware Retained-View Entropy), the first TTA method for this setting. CARVE estimates a sample-specific positive-label cardinality $\hat{k}$, optimizes a top-$\hat{k}$ objective to preserve co-occurring abnormalities, and performs memory-efficient multi-view adaptation by scoring weak 3D views without gradients before updating on a retained subset. Across contrastive CT-CLIP and anatomy-aware fVLM, CARVE provides the most consistent improvements across multi-label, three-class, and binary CT tasks when the base model is already discriminative. These results establish multi-label TTA for zero-shot 3D CT VLMs as a distinct problem and CARVE as a cardinality-aware solution.

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：针对prompt-pair多标签诊断的结构特点（独立伯努利概率），估计样本特定的正标签基数 $\hat{k}$，利用top-$\hat{k}$目标保留共现异常，避免标准熵最小化导致的阳性标签坍缩。
- **关键技术细节**：
  - **Per-label概率**：对每个异常$j$，计算正负prompt与图像嵌入的余弦相似度差值$d_j$，通过logistic函数得到伯努利概率$p_j$。
  - **弱多视图生成与选择**：对输入体积施加轻微高斯强度抖动和空间平移，生成$V$个弱增强视图。计算每个视图的平均二值熵，保留最低熵的$K$个视图（保留率$\rho$）。
  - **样本特异性基数估计**：用保留视图的平均概率$\bar{p}$求和后四舍五入并裁剪到$[k_{\min}, k_{\max}]$得到$\hat{k}$。
  - **目标函数**：对每个保留视图，取其概率最大的$\hat{k}$个标签作为正集$P$，剩余为负集$N$，优化：
    $$L_{\text{CARVE}}^{(v)} = -\frac{1}{|P|}\sum_{j\in P}\log p_j^{(v)} - \lambda_{\text{neg}}\frac{1}{|N|}\sum_{j\in N}\log(1-p_j^{(v)})$$
- **内存高效适配**：先无梯度对所有视图评分，仅对保留视图用梯度回传更新；仅更新视觉归一化参数，每样本独立重置（episodic）。

### 6. 主要结论与发现

- TTA的帮助是**有条件的**，而非自动有益：需要（1）输入保持预训练时使用的深度结构；（2）基础表征能迁移到目标域。
- 当基础模型已能区分正负异常时，CARVE通过基数感知目标**一致提升AUROC（0.05~0.04增量）和F1/精度-召回平衡**，优于标准熵最小化方法。
- 在严重外部偏移下（如CT-CLIP在RAD-ChestCT AUROC≈0.5），**基础表征差距比任何TTA方法的效果差距更大**，TTA只能轻微移动操作点。
- 标准熵最小化与prompt-pair多标签结构不匹配：交叉标签熵会抑制共现异常，而二值熵在p≈0.5处梯度弱。
- CARVE的弱视图选择、基数估计、两阶段计算等设计在实际部署中有效且内存可行。

### 7. 优点

- **诊断性方法**：先分析条件再提方案，揭示TTA的适用边界，避免盲目使用。
- **目标匹配**：针对prompt-pair多标签诊断独立伯努利概率结构设计了top-$\hat{k}$目标，自然保留共现异常。
- **内存友好**：两阶段计算（先评分后子集回传）使体积数据上的多视图适配可行。
- **实验全面**：涵盖多种骨干、标签设置、内部/外部偏移，且超参数固定后迁移性好。
- **代码开源**：提供GitHub仓库，易于复现。

### 8. 不足与局限

- **严重外部偏移下无效**：当基础模型几乎随机（AUROC≈0.5）时，CARVE不能创造判别能力，仅能微调操作点。
- **基数估计依赖模型校准**：$\hat{k}$基于平均概率求和，若模型未校准则估计可能偏差；裁剪区间$[k_{\min},k_{\max}]$固定且基于内部验证集，可能不适用于极端标签分布。
- **分散门效果弱**：$\sigma_{\text{pred}}$作为门控信号接近随机，仅能保守混叠时跳过更新，无法可靠检测可获益的样本。
- **仅更新归一化层**：未探索更丰富的参数空间（如提示嵌入、投影头）可能收益更大。
- **实验规模有限**：外部数据集大小（RAD-ChestCT 360例、CC-CCII 135例、LUNA16 621例）较小，统计显著性未报告。

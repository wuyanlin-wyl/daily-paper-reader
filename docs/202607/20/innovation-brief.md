### 1. Mixture of Cognitive Experts in Large Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.10796v1
- 方法流程：
  - 输入：图像I和查询q。
  - 路由：LLM-guided router根据查询和粗略图像表征选择top-K视觉专家。
  - 专家推理：选中的专家（如DETR, SAM, Pix2Struct等）产生结构化输出（边界框、掩码、OCR文本等）。
  - 文字证据总结：将专家输出分解为原子化证据语句，并统一存储为证据库E，每条证据包含id、类型（TEXT/ENTITY/REGION）、文本和引用元数据。
  - Bloom表达：基于证据库E和查询q，按Bloom层级（LIST→FINAL ANS）生成带证据引用的推理轨迹yBloom。
  - 适配器融合：将专家特征与基础视觉特征通过交替堆叠的transformer块融合，并映射到LLM嵌入空间。
  - 最终回答：将图像I、查询q和yBloom拼接后输入LLM，生成最终答案ŷ。
  - 推理轨迹分析（可选）：Reasoning Trace Module解析yBloom和E，提取每个步骤的证据引用分布和起始层级。
- 关键模块/机制：
  - Router：选择与当前查询最相关的视觉专家，减少计算开销并聚焦相关感知信息。；使用LLM的指令跟随能力，通过包含查询、专家描述和粗粒度图像嵌入的提示，让LLM输出专家选项字母，解析后得到top-K专家索引集G。
  - Literal Evidence Summary (文字证据总结)：将异构专家输出转化为统一的、可引用的原子化证据语句。；为每个专家e定义verbalizer ve，将原始输出分解为{(sk, mk)}，其中sk是文字陈述，mk是元数据（如边界框）。所有语句归一化为证据库E = {ei}，每个元素包含id, type, text, ref。type有TEXT, ENTITY, REGION, TABLE等。
  - Bloom Verbalization (Bloom表达)：根据查询和证据库，生成遵循Bloom认知层级的带引用推理轨迹。；定义认知步骤序列L = [LIST, EXPLAIN, ILLUSTRATE, COMPARE, HYPOTHESIZE, FINAL ANS.]。查询决定起始层级ℓ0，然后执行后续所有步骤。每一步ℓ输出短文本cℓ，并引用证据子集Uℓ。最终拼接得到yBloom。
  - Reasoning Trace Module (推理轨迹模块)：从Bloom输出中解析出结构化的推理轨迹，用于定量分析和可解释性。；轻量级确定性组件，无需隐藏状态。输入yBloom和E，通过解析步骤头和证据引用，输出起始层级、执行步骤集、每步引用证据集和证据类型分布。支持数据集级诊断。
  - Adapter (适配器)：将路由后的多专家视觉特征融合到统一的LLM兼容表征中。；由L个堆叠块组成，每个块将专家特征通过双线性插值对齐到当前视觉特征，然后经transformer子块融合。最后通过池化和MLP投影到LLM嵌入空间，使LLM可以同时关注融合视觉表征和Bloom文本。
- 公式/目标函数/指标定义：
  - O = {O(e)}_e∈G：选中的专家索引集G对应的原始结构化输出集合。
  - ve: O(e) → {(sk, mk)}_k: 每个专家的verbalizer将原始输出映射为原子陈述和元数据对。
  - E = {ei}_i=1^M, ei = (id_i, type_i, text_i, ref_i): 证据库定义。
  - yBloom = fBloom(q, E): Bloom表达函数，生成带引用的结构化推理文本。
  - ŷ = fLLM(q, I, yBloom): LLM基于图像、查询和Bloom轨迹生成最终答案。
- 算法细节：
  - 路由算法：构造包含查询、专家描述和压缩图像嵌入的提示，调用LLM生成字母选择，解析得到索引集G。
  - 证据构建：对每个选中专家的输出，按模板分解为原子陈述；为每条陈述分配唯一id、类型（根据专家种类）和引用元数据（坐标/掩码等）；所有陈述存入统一列表。
  - Bloom步进算法：根据查询确定起始层级ℓ0（例如通过LLM或规则），然后顺序执行从ℓ0到FINAL ANS的每一步；每步调用LLM生成带明确证据引用的简短文本，引用格式如[E12]。
  - 适配器融合：初始化视觉特征X1为CLIP输出，对每个块i，将专家特征{Fj}插值到X_i尺寸，求和或拼接后经transformer层得到X_{i+1}；最后通过残差和MLP投影到LLM空间。
- 训练/推理细节：
  - 完全训练-free（training-free）：所有组件在推理时执行，无需额外预训练或微调。
  - 推理流程：输入图像和查询后，依次运行路由、专家推理、证据总结、Bloom表达、适配器融合和LLM生成。
  - LLM使用Vicuna-7B，视觉编码器CLIP-L，专家模型均为预训练模型（DETR, SAM, Pix2Struct等）。

### 2. MonkeyOCRv2: A Visual-Text Foundation Model for Document AI
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.11562v1
- 方法流程：
  - 预训练语料构建：收集并整理涵盖17种语言的113M文档图像构成MonkeyDoc v2
  - 视觉编码器预训练：将文档图像输入视觉编码器（如ViT），分别送入两个并行任务头
  - 任务头1-文本生成：通过解码器（如Transformer）预测图像对应的文本序列，学习图像到文本的映射
  - 任务头2-像素重建：通过重建解码器（如卷积或Transformer）输出与输入图像像素级对齐的重建图像，保留细节
  - 联合优化：两个任务的损失加权求和，更新编码器参数
  - 下游应用：替换现有任务模型的编码器（如文本识别、检测等），或作为多模态大语言模型的视觉编码器并冻结
- 关键模块/机制：
  - MonkeyOCRv2视觉编码器：从文档图像中提取多尺度视觉特征，输出高分辨率的字符级和布局级表示；采用预训练的ViT结构，经过文档图像预训练后输出富含文本语义和笔画细节的特征图。
  - 文本生成头：将视觉特征解码为文本序列，实现图像到文本的生成；使用自回归文本解码器（如轻量Transformer），以视觉特征为条件逐步生成字符序列，损失函数为交叉熵。
  - 像素级文档重建头：从视觉特征重建原始图像，强制编码器保留字符笔画和布局细节；采用对称于编码器的解码结构（如卷积或Transformer），输出与输入同分辨率的图像，损失函数为MSE或感知损失。

- 算法细节：
  - 联合损失函数：L = λ1 * L_gen + λ2 * L_recon，其中L_gen为文本生成的交叉熵损失，L_recon为像素重建的MSE损失

  - 预训练后视觉编码器参数可冻结或微调，用于下游任务

### 4. Visual Access Boundaries in Vision-Language Model Reasoning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.12815v1
- 方法流程：
  - 输入：模型、任务（计数/QA）、生成模式（Direct/CoT）
  - 步骤1：定义干预参数——层索引l(从0到L)和生成token索引τ(从0到T)
  - 步骤2：对于每个(l,τ)组合，在生成过程中，掩码所有从位置≥τ的生成token查询到所有图像token键的注意力权重，仅允许前τ个生成token访问图像
  - 步骤3：计算在该干预下的任务准确率Acc(l,τ)
  - 步骤4：与全访问基线准确率Acc_full比较，定义边界点(l*,τ*)为最小区域使得Acc(l,τ) ≥ Acc_full - ε (ε=0.05)
  - 输出：VAB层深度l*和token截止τ*
- 关键模块/机制：
  - Visual Access Sweep：因果干预方法，系统评估模型对图像标记的依赖；在注意力计算中，对每个生成token位置t，动态生成一个掩码矩阵M，其中M[t',:]=0如果t'≥τ，否则1，从而阻止高于τ的生成token关注图像token。按层l和token截止τ进行二维扫描，记录准确率变化。
  - Visual Access Boundary (VAB)：量化指标，定义最小图像访问区域；对于给定的ε（如0.05），VAB由层深度l*和token截止τ*组成，满足Acc(l,τ) ≥ Acc_full - ε，且(l,τ)是最小区域（即更早层或更早token会低于阈值）。
- 公式/目标函数/指标定义：
  - ΔCoT(l,τ) = Acc_full - Acc(l,τ) （准确率损失）
  - 边界条件：ΔCoT(l*,τ*) ≤ ε （ε=0.05）
  - Δl*_own = |l*_CoT - l*_Direct| （CoT与Direct边界层差）
  - Δl*_DA = |l*_CoT - l*_Direct-anchored| （锚定于Direct目标的边界层差）
- 算法细节：
  - 掩码生成：对于每个干预点(l,τ)，在模型的前向传播中，对第l层及之后各层的注意力计算，将生成token查询（位置≥τ）与图像token键之间的注意力分数手动置为负无穷（softmax前），从而消除该部分注意力
  - 二维扫描：遍历层从L-1向下至0（或从后向前），token截止从0至最大生成长度，构建准确率热力图
  - 边界提取：使用二分搜索或阈值穿越点确定满足准确率要求的最大层和最晚token
- 训练/推理细节：
  - 无需重新训练，仅需在推理时进行注意力掩码干预
  - 干预仅修改注意力权重，不改变模型参数
  - 适用于自注意力（前缀融合）和交叉注意力（如Llama-3.2-11B-Vision-Instruct）架构

### 5. Attention-Free and Lightweight Token Reduction for Efficient Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13500v1
- 方法流程：
  - 输入图像经视觉编码器（如ViT）得到N个视觉token序列X = {x_i}。
  - 对每个token x_i计算其特征分布的熵作为重要性分数，保留熵最高的αK个token组成重要集。
  - 对每个token x_i计算变换一致性信号（例如经过一个可学习的线性层后的输出值），按该信号升序排序，以步长N/[(1-α)K]进行均匀采样，得到(1-α)K个token组成多样集。
  - 合并重要集和多样集，得到最终K个token，经投影器送入LLM进行多模态推理。
- 关键模块/机制：
  - 熵重要性估计模块：评估每个视觉token的信息量，保留信息最丰富的token。；对每个token的特征向量x_i，计算其各维度值的分布熵（例如将特征归一化为概率分布后计算熵），熵值越高表示特征表达更丰富、更不退化，从而更可能包含重要视觉信息。此过程无需注意力图，计算复杂度O(N)。
  - 变换一致性多样性选择模块：以极低计算代价保证保留的token在视觉内容上具有多样性。；对每个token x_i，通过一个可学习的线性变换（或固定变换）得到标量信号s_i。由于相似token经过同一变换后输出信号相近，对所有token按s_i排序后，相似token自然聚集。采用步长采样（如固定间隔选取）从排序序列中获取token，步长由目标数量和总token数决定，确保不同区域的token被选中，从而覆盖多样化视觉内容，避免成对相似度计算。
  - token合并与比例控制：将重要性选择与多样性选择的结果整合为最终token集。；通过超参数α∈[0,1]分配保留token总数K，其中αK个来自熵重要性模块（按熵从高到低选取），(1-α)K个来自多样性模块（通过变换一致性排序后步长采样）。最终合并两个子集得到K个token，作为LLM的视觉输入。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式。但方法核心包括：熵H(x_i) = -Σ p_j log p_j（基于token特征归一化后的概率分布）；变换一致性信号s_i = f(x_i)（f为线性层或MLP）；保留token集X* = {重要集} ∪ {多样集}，|X*|=K。
- 算法细节：
  - 一次性token选择：在视觉编码器输出后，并行计算所有token的熵和变换一致性信号，无需迭代或逐步剪枝。
  - 变换一致性信号计算：采用一个与token同维度的可学习向量w，将token x_i投影为标量s_i = w^T x_i，或者使用一个简单的MLP。该变换在训练时更新（若需微调）或固定使用预训练权重。
  - 步长采样策略：设总token数N，需要多样token数M=(1-α)K。排序后的token序列按索引0, step, 2*step, ... 选取，其中step = floor(N/M)。
- 训练/推理细节：
  - 训练：该token减少模块作为即插即用组件，可无缝嵌入预训练VLM（如LLaVA）。若不微调LLM，可仅训练变换一致性模块中的线性层（或MLP），通过任务损失（如交叉熵）反向传播，也可联合整个VLM进行轻量级微调。
  - 推理：在视觉编码器与投影器之间插入该模块，输入所有视觉token，输出压缩后的K个token。因无需注意力图和成对比较，计算开销极低（线性复杂度），且完全兼容FlashAttention等不实例化注意力图的加速框架。

### 6. Stitch-Inferencer: Enhance Endoscopic Video Segmentation and Tracking via Panoramic Reconstruction
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.14968v1
- 方法流程：
  - 输入：当前帧It和之前帧的集合{I1,...,I_{t-1}}
  - 有效观测提取：检测每帧中的器械遮挡区域并生成有效像素掩码Mt，仅保留非遮挡像素
  - 全景拼接：使用运动补偿（如光流或特征匹配）将历史帧有效像素对齐到共同坐标系，并在线融合更新全景画布P_t
  - ROI选择：根据当前相机姿态或感兴趣区域，在全景画布上裁剪紧凑区域R_t
  - 下游推理：对R_t应用预训练的分割或跟踪模型，得到预测结果S_t（如分割图或关键点）
  - 反投影：将S_t从全景坐标系投影回当前帧图像坐标系，得到最终输出O_t
- 关键模块/机制：
  - 有效观测提取模块：识别并保留无器械遮挡的图像区域，避免拼接累积错误；利用器械检测或语义分割获取每帧的遮挡掩码，仅保留非器械像素参与拼接
  - 全景拼接模块：将多帧有效像素对齐并融合为连续全景画布；采用运动补偿（如稠密光流或特征匹配）估计帧间变换，利用加权平均或基于像素有效性的融合策略更新画布，支持在线增量拼接
  - ROI选择模块：在全景画布上裁剪包含当前视野及上下文的关键区域，降低计算量；根据当前帧的视野边界或跟踪目标位置，在画布上选取一个紧凑矩形区域，该区域包含当前帧所需上下文
  - 反投影模块：将全景坐标系下的预测结果映射回当前帧坐标；利用拼接过程中存储的变换矩阵或映射关系，对预测结果进行逆变换，得到与当前帧对齐的输出
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 在线拼接：对每一新帧，通过光流估计与前一帧的运动，将有效像素叠加到全景画布上
  - 融合策略：对于画布上的每个像素位置，若多个帧贡献有效像素，则采用指数移动平均或最新有效像素覆盖
  - ROI裁剪：根据当前帧的相机内参和外参（或近似运动），计算画布上对应的区域边界
  - 反投影：利用累积的变换矩阵，将ROI上的预测结果进行逆仿射变换回到当前帧坐标系
- 训练/推理细节：
  - 推理阶段框架，无需训练，直接结合任意预训练模型
  - 拼接模块无参数，仅依赖图像配准算法（如光流），可实时运行
  - 下游模型（分割/跟踪）保持原有参数和推理逻辑，输入从当前帧替换为全景ROI

- 原文链接：https://arxiv.org/abs/2607.15556v1
- 方法流程：
  - 输入CT体积x，生成V个随机增强视图{x^{(v)}}，其中x^{(0)}=x。
  - 对每个视图，通过无梯度评分选择可靠弱视图，保留子集用于更新。

- 公式/目标函数/指标定义：

  - 分数差：d_j(x;θ) = s_j^+ - s_j^-
  - Bernoulli概率：p_j = σ(d_j) = exp(s_j^+) / (exp(s_j^+) + exp(s_j^-))

  - episodic执行：每个测试样本开始时重置ϕ到源预训练值，进行1-5步梯度更新，输出适应后模型的预测。

### 9. Region-Grounded Vision-Language Learning for Detection-Guided Mammographic Lesion Classification
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.15615v1
- 方法流程：
  - Stage 1 - Region-Text Contrastive Pretraining: 输入全分辨率乳房X线图像和病变标注框，使用预训练Mammo-CLIP视觉编码器生成空间特征图，用ROIAlign提取区域嵌入v；同时根据元数据构造结构化临床描述文本（如"breast type mass with shape irregular and margin spiculated"），通过文本编码器得到文本嵌入t。优化多组件目标Lstage1 = Lpos + λsem Lsem-neg + λbg Lbg-neg。输出对齐的区域和文本嵌入。
  - Stage 2 - Detection-Guided Joint Training: 在Stage 1预训练编码器上附加轻量级FCOS-style检测头（无锚框），联合优化对比分类损失Lcontrastive（基于ROI嵌入和文本嵌入的CLIP对称交叉熵）和检测损失Ldet（focal loss + smooth L1）。输出定位感知的编码器。
  - Inference: 输入图像，通过编码器获得空间特征图，检测头预测候选框；对每个高置信度框（置信度>τ）提取ROI嵌入，计算与"benign lesion"和"malignant lesion"文本prompt的余弦相似度，选高分者为预测。若所有检测置信度≤τ，则使用全局图像嵌入进行prompt-based分类。
- 关键模块/机制：
  - 视觉编码器 + 文本编码器：提取图像和文本特征；初始化自Mammo-CLIP预训练权重；视觉编码器输出空间特征图，文本编码器输出文本嵌入。
  - ROIAlign：从空间特征图中提取病变区域嵌入；使用给定病变标注框或检测头预测框，通过双线性插值提取固定尺寸区域特征。
  - 结构化文本模板：从元数据生成标准化临床描述；固定模板："breast type {mass/calcification} with shape {shape} and margin {margin}"，属性值来自受控词汇表。
  - 多组件对比损失：学习稳定的区域-文本语义对齐；包含三个部分：1) Lpos: CLIP对称InfoNCE，对齐配对区域与文本；2) Lsem-neg: margin ranking loss，使用属性交换的硬负样本（如交换shape或margin）推动与不匹配文本距离增大；3) Lbg-neg: hinge loss，抑制背景区域（低IoU框）与病变文本的相似度。
  - FCOS-style辅助检测头：提供定位监督，保持空间敏感性；无锚框检测头，在空间特征图每个位置预测目标概率和边界框偏移；使用focal loss和smooth L1 loss训练。
  - 置信度门控保险：提升检测质量不佳时的分类鲁棒性；设置阈值τ（实验中τ=0.2），当所有检测框置信度≤τ时，跳过ROI-based评分，改用全局图像嵌入vglobal进行prompt-based分类。
- 公式/目标函数/指标定义：
  - Lstage1 = Lpos + λsem Lsem-neg + λbg Lbg-neg
  - Lpos = 1/2 (L_v->t + L_t->v)，其中L_v->t = -1/B Σ_i log( Σ_{j∈P(i)} exp(S_ij) / Σ_j exp(S_ij) )，S_ij = sim(v_i, t_j)/τ_temp
  - Lsem-neg = 1/B Σ_i 1/K Σ_k max(0, m - sim(v_i, t_i^+) + sim(v_i, t_{i,k}^-))
  - Lbg-neg = 1/B Σ_i 1/R_i Σ_r max(0, sim(v_i,r^bg, t_i^+) - δ)
  - Ltotal = Lcontrastive + Ldet，其中Lcontrastive为对称CLIP交叉熵（基于ROI嵌入和文本嵌入），Ldet = focal_loss(objectness) + smooth_L1(bbox regression)
- 算法细节：
  - 硬负样本构建：对每个病变，通过交换模板中的shape或margin属性生成K个语义错配文本描述（如将'irregular'换为'oval'），使用这些文本嵌入作为负样本。
  - 背景负样本采样：随机选取与所有病变标注框IoU小于阈值的框作为背景区域，经ROIAlign提取嵌入后，通过约束其与病变文本的相似度<δ来抑制（δ=0.1）。
  - 检测训练：FCOS检测头在空间特征图上每个网格预测objectness（二分类）和到四边的距离；objectness使用focal loss，回归使用smooth L1 loss。
  - 推理时的prompt分类：将'benign lesion'和'malignant lesion'作为文本prompt，经文本编码器得到两个嵌入；与ROI嵌入计算余弦相似度，选择相似度更高的类别。
- 训练/推理细节：
  - 训练总epochs: 50，优化器: AdamW，学习率: 1e-4，权重衰减: 0.01，批大小: 8，GPU: NVIDIA H100。
  - 超参数设置：τ=0.2（置信度门控阈值），λ_sem=0.5，λ_bg=1，δ=0.1（背景相似度阈值），m=0.2（margin）。
  - 数据预处理：图像resize到512×512，使用数据集原始train/test划分。
  - 推理时：检测头输出经阈值过滤和NMS后得到候选框；若最大置信度>τ，使用对应ROI嵌入进行分类；否则使用全局图像嵌入（GAP池化自空间特征图）。

### 10. Model Merging for Medical LVLMs: A Benchmark and a Winner-Take-All Approach
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.15661v1
- 方法流程：
  - 1. 获取N个任务上LoRA微调后的低秩矩阵对{(A^(n), B^(n))}_{n=1}^N，每个对应特定医学成像任务。
  - 2. 对每个低秩矩阵Φ∈{A,B}，在其每个参数位置(i,j)，计算每个专家n的归一化幅度评分：S(Φ,n)_l,M,i,j = (Φ^(n)_l,M[i,j] - E[Φ^(n)]) / sqrt(Var[Φ^(n)] + ε)。
  - 3. 在每个参数位置，选择评分最高的专家作为获胜者：n* = argmax_n S(Φ,n)_l,M,i,j。
  - 4. 直接取获胜专家的参数值作为合并后的参数：Φ_merged_l,M[i,j] = Φ^(n*)_l,M[i,j]。
  - 5. 对所有层和权重矩阵重复步骤2-4，得到合并后的B_merged和A_merged。
  - 6. 计算合并后的LoRA更新：ΔW_merged = B_merged * A_merged，加到基础模型θ0上得到θ0 + Δθ_merged。
- 关键模块/机制：
  - 归一化幅度评分函数：量化每个参数在不同专家中的主导程度，解决专家参数尺度差异问题；对于每个低秩矩阵Φ（A或B），在每个参数位置(i,j)，计算归一化值：(Φ - mean) / sqrt(var + ε)，其中mean和var计算自该矩阵的所有条目，ε为小常数。评分越高表示参数越主导。
  - Winner Selection机制：在每个参数位置独立选择最主导的专家参数；对每个参数位置，遍历所有N个专家，根据归一化幅度评分选择最大值对应的专家，然后将该专家的参数值直接复制到合并参数中，不经过任何加权或变换。
- 公式/目标函数/指标定义：
  - 归一化幅度评分：S(Φ,n)_l,M,i,j = (Φ^(n)_l,M[i,j] - E[Φ^(n)]) / sqrt(Var[Φ^(n)] + ε)，其中E和Var为该矩阵所有条目的均值和方差。
  - 获胜专家选择：n*(Φ)_l,M,i,j = argmax_{n∈{1,...,N}} S(Φ,n)_l,M,i,j。
  - 合并参数取值：Φ_merged_l,M[i,j] = Φ^(n*)_l,M,i,j]_l,M[i,j]。
  - 合并LoRA更新：ΔW_merged_l,M = B_merged_l,M * A_merged_l,M。
- 算法细节：
  - 逐位置竞争选择：依次遍历所有参数位置，独立执行专家竞争，互不影响。
  - 无超参数：除评分归一化中的小常数ε外无任何超参数，无需调参。
  - 效率高：仅需一次前向传递比较评分，无迭代优化或子空间投影，合并时间极短（约0.2秒）。
- 训练/推理细节：
  - 本方法无需训练，仅需合并已训练好的LoRA模块。
  - 合并后模型可直接用于推理，无需额外微调。

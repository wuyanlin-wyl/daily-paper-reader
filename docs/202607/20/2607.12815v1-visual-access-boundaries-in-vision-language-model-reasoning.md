## 摘要
思维链（CoT）提示被广泛用作视觉语言模型（VLM）的测试时扩展策略，但尚不清楚VLM生成长推理轨迹时具体扩展了什么。我们探究CoT是否需要持续访问图像标记，还是主要利用前向传播早期已经获取的视觉信息。我们引入了因果干预方法“视觉访问扫描”（Visual Access Sweep），该方法沿层深度和生成时间掩蔽从生成的查询标记到图像标记键的注意力，并将视觉访问边界（VAB）定义为保持任务准确性的最小访问区域。在Qwen2.5-VL和InternVL3的六种模型配置中，无CoT直接回答和CoT提示都表现出有限的VAB。在Qwen2.5-VL-32B以及14B和38B规模的InternVL3中，当CoT与无CoT完全访问目标进行比较时，其VAB层与无CoT边界最多相差两层，尽管生成内容显著更长。这表明CoT并非主要通过在整个推理轨迹中延长直接图像标记访问来提高性能，而是通过扩展基于图像派生隐藏状态信息的语言侧计算。我们进一步证明，CoT收益受限于感知读出能力。当查询的视觉属性可以被模型可靠读出时，CoT有效；当读出不可靠时则无效。一个符号属性基准测试表明，一旦将真实属性作为文本提供，CoT可以提高计数能力；而单目标探针-解码检查表明，困难属性可以从隐藏状态线性恢复，但模型自身难以输出。综合这些分析，瓶颈在于读出而非计数。

## Abstract
Chain-of-Thought (CoT) prompting is widely used as a test-time scaling strategy for Vision-Language Models (VLMs), but it remains unclear what is extended when VLMs generate longer reasoning traces. We ask whether CoT requires continued access to image tokens, or whether it mainly operates over visual information already made available earlier in the forward pass. We introduce Visual Access Sweep, a causal intervention that masks attention from generated-token queries to image-token keys along layer depth and generation time, and define the Visual Access Boundary (VAB) as the minimal access region that preserves task accuracy. Across six model configurations from Qwen2.5-VL and InternVL3, both no-CoT direct answering and CoT prompting exhibit finite VABs. In Qwen2.5-VL-32B and InternVL3 at 14B and 38B scales, when CoT is evaluated against the no-CoT full-access target, its VAB layer differs from the no-CoT boundary by at most two layers, despite substantially longer generations. This suggests that CoT does not primarily improve performance by prolonging direct image-token access throughout the reasoning trace, but by extending language-side computation over image-derived hidden-state information. We further show that CoT gains are constrained by perceptual readout. CoT helps when the queried visual attribute can be reliably read out by the model, but not when that readout is unreliable. A symbolic-attribute oracle shows that CoT can improve counting once ground-truth attributes are supplied as text, while a single-object probe-vs-decode check shows that hard attributes can be linearly recoverable from hidden states yet difficult for the model itself to output. Together, these analyses place the bottleneck at readout rather than counting.

### 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出 **Visual Access Sweep**（视觉访问扫描）干预方法和 **Visual Access Boundary (VAB)**（视觉访问边界）概念。通过系统性地掩蔽（mask）从生成 token 查询到图像 token 键的注意力，沿**层深度**和**生成时间**两个维度进行因果干预，以确定维持任务性能所需的最小直接图像访问区域。
- **关键技术细节**：
  1. **干预定义**：对于每个干预点 (ℓ_cutoff, t_cutoff)，仅允许满足 \( t \leq t_cutoff \) 和 \( \ell \leq \ell_cutoff \) 的生成 token 查询访问图像 token 键；其余情况下将注意力掩码设为 \(-\infty\)，使 softmax 后权重归零。
  2. **VAB 定义**：在容忍度 \( \epsilon = 0.05 \)（5 个百分点的准确率下降）下，能保持任务准确率的最小访问区域 (ℓ*, τ*)。τ 为有效 token 窗口 min(t_cutoff, T_gen)。
  3. **三种对比标准**：
     - ∆_D：Direct 全访问准确率与 Direct 干预后准确率的差 → 得 Direct 边界 ℓ*_D；
     - ∆_CoT：CoT 全访问准确率与 CoT 干预后准确率的差 → 得 CoT 自身最大边界 ℓ*_CoT；
     - ∆_DA：Direct 全访问准确率与 CoT 干预后准确率的差 → 得直接锚定 CoT 边界 ℓ*_DA；并比较 Δℓ*_own 和 Δℓ*_DA。
  4. **控制实验**：通过**后层查询文本块控制**（额外阻止后层查询文本→图像注意力）和**空汇点控制**（将移除的注意力质量重定向到虚拟非视觉汇点）排除干预伪影。结果均保留 VAB 定性结构。

- **无需公式**：注意力掩码机制简单明了：对于掩蔽区域内的 (i, j) 对，设置 M_ℓij = -∞。

  - **Direct 提示**：直接要求模型输出最终答案（选项键），无中间推理。

- **对比方法**：主要比较 Direct 与 CoT 两种提示模式下的 VAB；此外在跨注意力融合架构（Llama-3.2-11B-Vision-Instruct）上做试点验证。

- **模型**：Qwen2.5-VL（3B/7B/32B）和 InternVL3（8B/14B/38B），均为 prefix-based decoder-only VLM；另在跨注意力融合架构上测试。

### 论文的主要结论与发现

1. **有限 VAB 普遍存在**：在 Direct 和 CoT 两种提示下，所有测试模型（Qwen2.5-VL 和 InternVL3 各规模）均表现出有限的 VAB：在阻断大范围后层或后段生成 token 后准确率几乎不变，仅当干预到达较早层或较早生成 token 时准确率急剧下降。
2. **CoT 不依赖延长图像访问**：在最大模型（Qwen2.5-VL-32B、InternVL3-14B/38B）上，CoT 的 VAB 层与 Direct 的 VAB 层相差**最多 2 层**（在直接锚定标准下），尽管 CoT 生成 token 数量增加约 50 倍。说明 CoT 并非通过延长直接图像 token 访问来提升性能，而是利用语言侧对图像派生的隐藏状态进行计算。
3. **感知读出限制 CoT 增益**：CoT 在模型能可靠读出视觉属性（如颜色、形状）时提升明显；但在读出困难属性（角度、大小）时增益微弱甚至为负。探针-解码对比显示：困难属性在隐藏状态中线性可恢复（高探针准确率），但模型自身解码输出困难。
4. **Oracle 实验确认瓶颈在读出而非计数**：当将真实属性作为文本直接供给模型（Oracle 旁路），CoT 在原本困难属性（角度、大小）上也获得显著增益，证明计数推理本身并非瓶颈，问题的根源在于**视觉属性无法被模型自身可靠读出为可用符号**。
5. **真实图像验证**：在 GQA yes/no 任务上，VAB 结构同样出现，且不依赖于 CoT 是否提升准确率（此任务中 CoT 略低于 Direct）。
6. **实际应用启示**：简单路由规则（仅当属性读出准确率 >0.5 时使用 CoT）可保留大部分 CoT 收益（75%–87%），同时减少约一半的生成 token 成本。

### 优点：方法或实验设计亮点

- **因果干预而非相关性分析**：不同于以往仅关注注意力衰减的观察性研究，Visual Access Sweep 直接*移除*特定通道的功能必要性，得到的是因果性结论。
- **双维度扫描**：同时控制层深度和生成时间，精细刻画必要的视觉访问区域。
- **受控任务隔离感知变异性**：固定推理操作（计数），仅变化查询属性，使得 CoT 增益差异能直接归因于感知读出难度。
- **多层面诊断**：结合多目标读出、单目标探针-解码、Oracle 旁路，逐层剥离“属性是否存在”、“能否解码”、“计数能否受益”，清晰定位瓶颈。
- **跨模型家族、规模、任务域验证**：通用性较强。
- **优雅的控制实验**：排除了注意力重分配和查询介导后层重读的可能伪影。

### 不足与局限

- **任务覆盖有限**：主要依赖**属性计数**任务，属于感知-推理分解的测试床。缺少需要**迭代视觉检查**的任务（如复杂的空间关系推理、视觉路线导航、多步视觉搜索），在此类任务中 VAB 可能更宽或 CoT 可能确实需要持续图像访问。
- **内部机制未揭示**：VAB 描述了什么位置不再需要直接图像访问，但未解释具体机制——比如早期哪些层完成了属性绑定？隐藏状态如何通过残差流传递？CoT 模型是否将感知提取集中在前几个生成 token 上？这需要进一步的残差干预。
- **跨注意力融合架构验证**仅作为试点（只有 CoT 侧扫描，未做 Direct 扫描），且仅在 Llama-3.2-11B-Vision 上测试，家族代表性不足。
- **GQA 实验规模较小**：仅 100 幅图像，且 CoT 未比 Direct 更好，但 VAB 仍存在；结论稳健性可能受限于样本量。
- **角度属性在部分设置下接近任务空间下限**，导致 VAB 难以定位（边界不明确），作为限制情况处理，但暗示方法在极低性能条件下的敏感性有限。
- **选择性 CoT 路由仅是启发式演示**，阈值未经系统调优，实际部署需考虑不同属性分布下路由决策的稳定性。
- **数据来源与偏差风险**：合成图像使用 matplotlib 生成，风格与自然图像有差距；GQA 数据集存在场景图标注偏差（如头部物体分布），但受控任务的设计目的正是排除此类偏差。

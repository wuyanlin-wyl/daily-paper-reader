## 摘要
在本文中，我们提出了LongMedBench，一个基于真实世界电子健康记录（EHR）的基准测试，用于评估长程临床决策。以往对基于大语言模型的医学智能体的评估主要侧重于短上下文的知识问答和工具使用。然而，真实世界的医疗本质上是纵向的，临床医生必须在多次就诊、检查和不断演变的治疗中汇总证据。因此，长程交互对于现实评估至关重要。LongMedBench通过一个可复现的流水线构建，将MIMIC-IV入院记录和临床注释整合为时间序列事件流和长上下文记忆数据集，从而实现智能体与临床环境之间的长程多会话交互。它包含335名患者，平均每位患者19.72次住院就诊，每次就诊平均44.91个医疗事件。在长程决策过程的指导下，我们提出了一个包含三个套件的评估分类体系：基于事实的问答、时间推理和长程决策。该分类体系衡量智能体在长时间跨度内理解和利用历史患者信息的能力。我们的实验表明，尽管当前的大语言模型能够很好地利用显式时间戳，但在隐式时间推断方面仍面临挑战；RAG和智能体记忆系统可以提高信息检索任务的性能，但决策任务的性能高度依赖于模型的即时上下文。

## Abstract
In this work, we introduce LongMedBench, a real-world EHR-based benchmark for long-horizon clinical decision-making. Prior evaluations of LLM-based medical agents have largely emphasized short-context knowledge QA and tool use. However, real-world medical care is inherently longitudinal, and clinicians must aggregate evidence across repeated visits, tests, and evolving treatments. Therefore, long-horizon interaction is essential for realistic assessment. LongMedBench is constructed via a reproducible pipeline that integrates MIMIC-IV admission records and clinical notes into time-series event streams and long-context memory datasets, enabling long-horizon, multi-session interactions between agents and a clinical environment. It comprises 335 patients, with 19.72 inpatient visits per patient on average and 44.91 medical events per visit. Guided by the long-horizon decision process, we propose an evaluation taxonomy with three suites: fact-based QA, temporal reasoning, and long-horizon decision-making. This taxonomy measures how agents understand and leverage historical patient information over extended horizons. Our experiments show that while recent LLMs can make good use of explicit timestamps, they have challenges in implicit time inference; The RAG and agent memory system can improve the performance of information retrieval tasks, but the performance of decision-making tasks is highly dependent on the model's immediate context.

## 方法论：核心思想、关键技术细节

- **核心思想**：将MIMIC-IV中的静态EHR记录转换为**时间序列事件流**，构建一个可供智能体交互的临床环境，并通过三层次记忆（Note Memory、Event Memory、Contextual Memory）和渐进式任务分类（事实QA→时间推理→长程决策）来评估智能体对历史信息的利用能力。
- **关键技术细节**：
  1. **数据预处理管道（三阶段）**：
     - **事件与患者筛选**：保留异常检验结果，筛选住院≥15次的355名患者，共6999次就诊，平均19.72次/人。
     - **事件流构建**：为每位患者生成完整事件序列，包括入院事件、具体医疗事件（检验、影像、用药等，带时间戳、动作参数、结果）、出院事件，以及放射/出院小结。每次就诊平均44.91个事件。
     - **记忆数据集生成**：基于历史就诊范围，构建三个粒度的记忆模块：
       - Note Memory：就诊摘要（高维压缩，强调全局轨迹）。
       - Event Memory：所有事件扁平化时间序列（丢弃就诊边界）。
       - Contextual Memory：将当前就诊事件转化为智能体-诊所对话格式，作为即时上下文。
  2. **三种记忆架构**：
     - Naive Long-Context：直接注入所有历史记忆。
     - RAG：使用text-embedding-3-small向量化，检索Top-K相似片段。
     - Agent Memory System (Mem0)：动态更新的外部存储，智能体可主动搜索。
- **三类任务套件（评估分类）**：
  - **Factual QA**：基于显式/相对时间戳的检索，评估事实定位能力（Lab-T召回、Lab-F拒绝）。
  - **Temporal Reasoning**：三子任务——Visit Cloze（事件级排序）、Visit Sorting（无时间戳的摘要排序）、Joint Sorting（多就诊碎片配对+排序），使用Kendall's τ评估时序重建。
  - **Long-Horizon Decision Making**：三子任务——Next Action Prediction、Argument Prediction、Discharge Decision，使用时间衰减评分机制，评估整合长期记忆与即时状态的决策能力。

## 主要结论与发现

1. **显式时间戳利用良好，隐式时间推理困难**：模型在带时间戳的事件排序（Visit Cloze）上接近完美（Kendall's τ 0.925+），但在无时间戳的Visit Sorting任务上显著下降（最高0.424），表明隐式时序推理仍是瓶颈。
2. **记忆架构对检索任务有效，但对决策任务提升有限**：RAG和Mem0在Factual QA中提升了召回和拒绝率（尤其Lab-T和Medication），但在Long-Horizon Decision Making中，性能接近Naive Long-Context基线，甚至部分场景下降。决策质量更依赖模型**即时上下文推理能力**，而非历史记忆量。
3. **思维链（Thinking）模式在推理任务上提升显著**，但在决策任务上未带来额外收益，反而因过度谨慎导致性能持平。
4. **事件记忆在决策任务中略优于笔记记忆**，但差异微小。
5. **历史访问注入增多导致“Lost-in-Middle”效应**，长上下文中模型更难定位关键信息。

## 优点（方法或实验设计亮点）

1. **真实数据驱动**：基于MIMIC-IV真实EHR，构建长程、多轮交互环境，贴近临床实际。
2. **渐进式评估分类**：从简单检索到复杂决策，系统评估不同层次的能力。
3. **三层次记忆模块设计**：Note、Event、Contextual覆盖不同粒度和功能，支持细粒度分析。
4. **时间敏感评估**：显式/相对时间戳对比、时间衰减评分机制，凸显时间推理能力。
5. **综合对比多种记忆架构**：Naive Long-Context、RAG、Mem0，并开展消融实验，结果可信。

## 不足与局限

1. **数据集单一**：仅使用MIMIC-IV（单一医疗系统、有限疾病谱），可能无法代表多样化临床场景。
2. **患者选择偏差**：仅筛选住院≥15次的慢性重症患者，未覆盖常见短期就诊模式。
3. **决策任务设计可能过于简单**：如Next Action Prediction的答案空间有限（动作类型），未考虑动态连续决策树。
4. **缺乏与现有基准确切对比**：未在LongMedBench上运行先前基准（如MedAgentBench）的任务，无法直接对比优劣。
5. **记忆架构评估有限**：Mem0和RAG在决策任务上未显著提升，但未探究更复杂的记忆检索机制或自适应策略。

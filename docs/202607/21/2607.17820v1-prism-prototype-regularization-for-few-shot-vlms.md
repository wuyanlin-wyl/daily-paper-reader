## 摘要
近年来，无需训练的少样本适应方法在视觉语言模型（VLM）中受到广泛关注。然而，当前的基准测试依赖于关于适应数据统计的强假设，例如类别平衡。我们质疑这些简化假设，并引入了一个更现实的基准测试，该基准测试通过狄利克雷采样改变了少样本任务中类别平衡的程度和有效类别的数量。令人惊讶的是，在我们的设置下，观察到最先进方法的性能大幅下降，尤其是在标记样本数量增加时。为了缓解这一问题，我们提出了PRiSM，一种类别原型正则化方法，可以作为即插即用模块部署在任何现有基线方法之上，显著提升性能。我们的方法优化了一个新颖的多项损失，包括一个最大化类别间成对距离的正则化项，以及促进支持特征对齐和与基线原型保真度的附加项。此外，我们引入了一个有效且计算高效的块式最大化-最小化优化器来求解目标函数。更具体地说，我们推导出了有效的块式Lipschitz常数（即Hessian谱范数的边界），该常数可以通过格什戈林圆盘定理高效计算。大量实验表明，PRiSM改进了多个无需训练的基线方法，在处理严重的类别不平衡和高类别数量时取得了巨大收益。

## Abstract
Training-free few-shot adaptation methods have gained significant attention recently in the context of Vision-language Models (VLMs). Yet, current benchmarks rely on strong assumptions about the statistics of the adaptation data, e.g., class balance. We question these simplifying assumptions and introduce a more realistic benchmark that varies both the levels of class balance and the effective number of classes in few-shot tasks via Dirichlet sampling. Surprisingly, under our setting, we observe substantial drops in the performances of state-of-the-art methods, more so when the number of labeled samples increases. To mitigate this, we introduce PRiSM, a class-prototype regularization that can be deployed as a plug and play module on top of any existing baseline method, significantly improving performances. Our method optimizes a novel multi-term loss, which includes a regularizer maximizing inter-class pairwise distances, along with additional terms promoting support-feature alignment and fidelity to the baseline prototypes. Furthermore, we introduce an effective and computationally efficient block Majorize-Minimize optimizer for our objective. More specifically, we derive a valid blockwise Lipschitz constant (i.e., a bound on the Hessian's spectral norm), which can be computed efficiently via the Gershgorin circle theorem. Extensive experiments show that PRiSM improves several training-free baselines, with large gains when dealing with severe class imbalance and high numbers of classes.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有问题**：当前少样本视觉语言模型（VLM）的适应方法（尤其是训练免微调方法）普遍假设适应数据是**类平衡**的（support set 和 query set 均为均匀采样），且任务覆盖全部目标类别。这一假设在真实部署中经常被违反——现实数据高度倾斜、类别可能缺失、分布存在移位。
- **研究动机**：作者质疑这些简化假设，并构建了一个**更现实的基准**——通过狄利克雷（Dirichlet）采样同时控制类别不平衡程度和有效类别数量。在该基准下发现：现有最先进方法（如 Tip-Adapter、GDA、APE、ProKeR）性能大幅下降，且**增加标记样本数反而加剧了主流类别偏差**，导致性能退化。
- **整体含义**：方法瓶颈不在于适应机制本身，而在于类原型的质量——原型估计受不平衡数据严重偏差。因此，**纠正原型偏差**是提升鲁棒性的关键。

## 2. 论文提出的方法论

### 核心思想
提出 **PRiSM（Prototype Regularization for Few-Shot VLMs）**，一种**即插即用的类别原型正则化模块**，可部署在任何现有训练免微调基线之上。通过优化一个新的多项损失函数，同时实现：
1. **支持特征对齐**：使修正后的原型靠近本类视觉特征均值（`β∥wc - μc(ϕ)∥²`）。
2. **基线保真度**：防止偏离基线方法给出的初始原型（`γ∥wc - ac∥²`）。
3. **类间分离**：最大化所有类原型之间的成对距离（`-λ/(2(C-1)) ∑_{c≠c'} ∥wc - wc'∥²`）。

### 关键技术细节
- **损失函数**（式 (2)）：
  ```
  L(w, ϕ) = β Σ_c ∥wc - μc(ϕ)∥² + γ Σ_c ∥wc - ac∥² - λ/(2(C-1)) Σ_{c≠c'} ∥wc - wc'∥²
  ```
  其中 `w` 为修正后的原型，`ϕ` 为视觉编码器参数，`μc(ϕ)` 为图像特征的类内均值，`ac` 为基线原型。
- **优化算法**：采用**块式 Majorize-Minimize (MM) 算法**，交替优化两个变量块：
  - **原型更新块**：基于二次形式的闭式 Lipschitz 常数，推导出隐式步长 `1/ρ`（无需验证集调参），保证目标非增。
  - **视觉编码器块**：使用 **LoRA**（秩 8）对最后三层进行轻量级参数高效微调，学习率 `5×10⁻⁴`。
- **Lipschitz 常数的计算**（命题 1）：通过 Gershgorin 圆盘定理给出上界：
  ```
  ρ = 2(|β + γ - λ| + λ) ≥ 2∥Φ∥₂
  ```
  该步长无需网格搜索，且远大于深度学习常用学习率，收敛更陡峭。

### 算法流程（文字说明）
1. 初始化：令 `w` 等于基线方法给出的原型 `a`，`ϕ` 为预训练视觉编码器（附 LoRA 参数）。
2. 重复交替优化（3 轮）：
   - 固定 `ϕ`，执行 1 次原型更新：`w ← w - (1/ρ) ∇L_w`。
   - 固定 `w`，执行 10 次 LoRA 更新（标准梯度下降更新 `ϕ`）。
3. 最终输出修正后的原型 `w` 和（可选）微调后的视觉编码器 `ϕ`。

## 3. 实验设计

### 使用的数据集与场景
- **10 个分类基准**：涵盖细粒度（Oxford-Pets, Stanford Cars, FGVC Aircraft）、纹理（DTD）、食物（Food-101）、场景（SUN397）、遥感（EuroSAT）、花卉（Oxford Flowers）、通用对象（Caltech-101, UCF101）。
- **保留验证集**：仅将 ImageNet 用作超参数选择的独立验证集（避免下游任务泄露）。

### Benchmark 设置（狄利克雷采样）
- 两个维度：
  - **有效类别覆盖**：低覆盖（10%–30% 类别） / 高覆盖（70%–90% 类别）。
  - **不平衡程度**：严重不平衡（Dirichlet δ∈[0.1,0.3]） / 近平衡（δ≈0.9）。
- 组合成 **4 种评估设置** + 2/4/16 三种 shot 数，共 12 个实验场景。

### 对比的基线方法
- 四种**训练免微调**方法：Tip-Adapter (ECCV'22)、APE (ICCV'23)、GDA (ICLR'24)、ProKeR (CVPR'25)。
- PRiSM 作为插件置于每个基线之上，对比有无 PRiSM 的性能。

### 实验公平性
- 所有实验使用 **固定超参数**（β=0.01, γ=1, λ=0.05），无下游验证集调参。
- 每个任务平均 **400 次随机采样**，报告平均 Top-1 准确率。
- 特征提取时使用数据增强（10 次随机缩放/裁剪/翻转）。
- 与基线在完全相同的支持集和查询集上比较。

## 6. 主要结论与发现

1. **类不平衡是关键失效模式**：在现实狄利克雷基准下，增加 shot 数反而导致多个基线性能下降（如 Tip-Adapter 16-shot 仅 33.25%，低于 2-shot 的 63.66%），说明**更多数据可能放大主流类别偏差**。
2. **PRiSM 显著恢复性能**：尤其是对弱基线（如 Tip-Adapter，在严重不平衡 16-shot 下提升 +35.05%），使其达到甚至超越 ProKeR 水平，证明原型质量是瓶颈。
3. **即插即用有效**：在四种不同机制（缓存、高斯判别、核方法、自适应先验）的基线上均获得一致提升，强基线（ProKeR）也有小幅增益（+0.4% ~ +3.0%）。
4. **Lipschitz 驱动的步长**避免了验证集调参，且性能与最优人工学习率相当。

## 7. 优点

- **问题设定创新**：首次系统暴露了标准平衡基准的偏差，并提出可控的狄利克雷基准，利于未来更现实的评估。
- **方法简洁有效**：三项损失均有明确语义（对齐、保真、分离），且超参数固定（不需下游验证集），适合实用。
- **优化器理论优雅**：利用 Gershgorin 圆盘定理推导显式 Lipschitz 常数，实现无学习率搜索的稳定更新，且步长自然较大。
- **计算高效**：MM 算法仅需 3 轮迭代，每次原型更新一步，LoRA 微调 10 步，额外开销极低。
- **即插即用**：可独立于基线方法使用，扩展性良好。

## 8. 不足与局限

- **仅验证单一骨干**：实验全部基于 CLIP ViT-B/16，未在更大/更多 VLM 上验证泛化性。
- **负增益未深入分析**：在 ProKeR 的某些设置（如 Food101 近平衡 low coverage）出现退化，论文只提及未解释，可能是原型已接近最优时正则化过度。
- **未消融损失项**：三项损失的相对重要性、权重敏感性未被系统研究，仅靠经验固定一组超参数。
- **缺乏标准平衡基准的对照**：未展示在原始平衡设定下 PRiSM 是否仍能保持或轻微改进基线，无法判断是否会引入噪声。
- **假设每个有效类至少有一个样本**：当类别完全缺失时无法应用（但该设置本身不要求所有类出现）。
- **LoRA 引入额外可学习参数**：虽轻量，但严格意义上不再是“完全训练免微调”，不过作者将其归为“少量参数微调”，与本文主题一致。
- **未在更大规模任务（如 ImageNet 子集）上测试**：10 个数据集虽多样但规模不大，极端高冲突类别场景覆盖不足。

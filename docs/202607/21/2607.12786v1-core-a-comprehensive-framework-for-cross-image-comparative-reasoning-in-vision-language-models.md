## 摘要
跨图像比较推理对于视觉语言模型（VLM）仍然具有挑战性，尤其是当正确预测需要细粒度属性定位和全局一致的推理时。我们提出了CoRe，一个针对此问题的统一框架。CoRe包括：(i) CoRe-20K，一个大规模三元组训练集，通过多专家协作流程从结构化视觉元数据自动构建，涵盖计数、深度、距离和空间关系；(ii) TriSR，一个结构化奖励框架，在GRPO优化下联合监督属性定位、判断对齐和三重一致性；(iii) CoRe-Bench，首个专门用于细粒度跨图像比较推理的基准测试。实验表明，CoRe在CoRe-Bench上显著优于现有的VLM，同时在标准多模态基准测试中保持竞争力，在部分准确率上相比最强基线提升了28.2个百分点。

## Abstract
Cross-image comparative reasoning remains challenging for vision-language models (VLMs), especially when correct prediction requires fine-grained attribute grounding and globally consistent reasoning. We present CoRe, a unified framework for this problem. CoRe includes: (i) CoRe-20K, a large-scale triplet-based training set automatically constructed from structured visual metadata through a multi-expert collaborative pipeline, covering counting, depth, distance, and spatial relations; (ii) TriSR, a structured reward framework that jointly supervises attribute grounding, judgment alignment, and triplet consistency under GRPO optimization; and (iii) CoRe-Bench, the first benchmark dedicated to fine-grained cross-image comparative reasoning. Experiments show that CoRe substantially outperforms existing VLMs on CoRe-Bench while remaining competitive on standard multimodal benchmarks, achieving a 28.2-point gain in partial accuracy over the strongest baseline.

### 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉语言模型（VLM）在处理**跨图像比较推理**任务时存在系统性不足。这类任务要求模型在同一场景或相关场景的多张图像之间进行细粒度的属性比较（如物体计数、深度、距离、空间关系），而现有VLM往往依赖粗粒度视觉印象或偶然猜测，导致推理链不可靠或内部不一致。
- **背景与动机**：现有基准测试（如单图像感知任务、多图像语义理解任务）对细粒度比较推理覆盖不足；同时，仅以最终答案正确性进行监督（outcome-only supervision）容易导致模型通过捷径或错误推理获得正确答案，而LLM作为评判者也存在与人类评估不一致的问题。因此，需要可扩展、可验证的监督信号和专用基准来提升这一能力。

### 论文提出的方法论

- **核心思想**：利用跨图像比较推理中**中间推理步骤的可验证性**，通过构造结构化奖励（TriSR）来联合监督属性定位、判断一致性和三元组全局一致性，并用GRPO优化VLM。
- **关键技术细节**：
  1. **CoRe-20K数据集构建**：从结构化视觉元数据（如深度图、3D标注、边界框）出发，经多专家协作管道自动构建三元组训练数据。
     - **Metric Extraction Expert**：从不同源数据格式提取统一度量值（计数、深度中位数、欧氏距离、空间关系标签）。
     - **Quality Control Expert**：通过噪声边界过滤和琐碎样本排除，保留有区分度的三元组。
     - **Question Generation Expert**：基于模板库生成多选问题，并进行选项随机化消除位置偏差。
  2. **TriSR结构化奖励框架**：将推理过程分解为三个可验证部分：
     - **Attribute Grounding**：鼓励模型正确估计每张图像的属性（如人数、距离），使用指数衰减函数度量估计值与真值的接近程度。
     - **Judgment Alignment**：同时检查推理链中的中间判断是否与真值一致，以及是否与最终选择的答案一致，确保自洽。
     - **Triplet Consistency**：检验三个两两比较之间的逻辑一致性（如传递性），对矛盾进行惩罚。
  3. **GRPO优化**：每个查询采样多个响应，计算复合奖励（任务准确率 + 加权结构化奖励），再经组归一化优势更新策略，鼓励模型产生既准确又可靠推理的输出。

- **算法流程**（文字描述）：
  - 输入三元组及对应问题 → 模型生成结构化解码（包含三张图像属性估计、推理链中的成对判断、最终答案）→ 规则解析器提取 → TriSR计算三个奖励 → 与任务奖励组合 → GRPO计算优势并更新策略。

### 论文的主要结论与发现

- Cross-image comparative reasoning是VLM的一项独立且未充分研究的挑战，现有模型表现极差（平均Overall Accuracy<7%）。
- CoRe框架通过结构化数据构建和可验证中间奖励，在CoRe-Bench上显著提升（Overall 22.2% vs 6.6%，Partial 54.0% vs 25.8%）。
- 仅优化最终答案（R_task only）会导致“正确答案+错误推理”比例上升（17.1%），而TriSR有效抑制该现象（降至8.3%），说明结构化监督对于推理可靠性至关重要。
- CoRe在标准多模态基准上保持竞争力，甚至超越部分7B/8B模型，证明数据与奖励设计可弥补模型规模不足。

### 优点

1. **问题定义清晰**：将跨图像比较推理独立提出，填补了VLM能力评估空白。
2. **数据构建自动化**：基于结构化元数据，无需人工标注或VLM生成伪标签，标签确定性高、可扩展。
3. **结构化奖励设计精巧**：利用比较推理的中间可验证性，分解为三个正交信号，比单纯结果监督或LLM评判更可靠。
4. **兼顾精度与可靠性**：消融与推理质量分析证明TriSR不仅能提升准确率，还能改善推理链质量。
5. **广泛的实验验证**：覆盖自身基准、OOD泛化、多个标准基准，综合展示了方法与数据的优势。

### 不足与局限

1. **任务覆盖有限**：仅包括计数、深度、距离、空间关系四类，缺乏更多属性（如颜色、形状、纹理）或更复杂的跨图像推理（如因果推理、情感比较）。
2. **训练数据依赖元数据质量**：CoRe-20K来自结构化元数据，若源数据噪声大或标注误差，可能影响训练信号。质量过滤虽缓解但未消除。
3. **基模型局限**：仅以Qwen3-VL-4B为基座，未在更大模型（7B、32B上验证），方法泛化能力到其他架构/尺度需进一步确认。
4. **OOD泛化测试规模较小**：仅用四个二元子集，且每个任务仅一个外部数据集，覆盖还不够广泛。
5. **推理质量分析样本量有限**：手动标注仅300个三元组，统计上可能不够充分，更大规模标注能增强结论稳健性。
6. **未讨论跨图像弱监督或零样本场景**：CoRe需要三元组训练数据，对于完全无监督或零样本适应尚未涉及。
7. **伦理与偏见**：未讨论模型在多样人群或场景中的公平性风险（如人群计数可能对不同种族产生偏差）。

## 摘要
大型语言模型在医学基准测试中取得了高分，但这些基准测试孤立地评估每个问题，无法衡量系统是否能够区分需要不同干预措施的临床相似表现。我们引入了MamaBench，这是首个用于母婴儿科AI的反事实基准测试：434个由专家撰写的临床叙事，涵盖371种病理，组成217对，通过偏差陷阱率（BTR）进行评估，即在基础案例成功条件下模型在反事实案例上失败的条件概率。我们提出了证据锚定RAG（EA-RAG），这是一种三阶段检索方法，通过临床参数提取、覆盖审计和对比子查询，将聚合相似性替换为证据覆盖目标。在四个前沿LLM的八种配置中，每个模型的基础准确率都高估了鲁棒准确率16-28个百分点。EA-RAG在Claude Sonnet 4.6上实现了20.3%的BTR和65.0%的鲁棒准确率，BTR降低了5.5个百分点，且未降低基础准确率。残余的20% BTR证实了临床AI中的反事实鲁棒性仍然是一个开放的挑战。关键词：反事实评估，临床AI，母婴保健，检索增强生成，诊断鲁棒性

## Abstract
Large language models achieve strong scores on medical benchmarks, yet these benchmarks evaluate each question in isolation, providing no measure of whether a system can distinguish clinically similar presentations requiring different interventions. We introduce MamaBench, the first counterfactual benchmark for maternal and paediatric AI: 434 expert-authored clinical narratives in 217 pairs across 371 pathologies, evaluated via the Bias Trap Rate (BTR), the conditional probability that a model fails the counterfactual given success on the base case. We propose Evidence-Anchored RAG (EA-RAG), a three-stage retrieval method that replaces aggregate similarity with an evidence coverage objective through clinical parameter extraction, coverage auditing, and contrastive sub-queries. Across eight configurations of four frontier LLMs, base accuracy overstates robust accuracy by 16-28 percentage points in every model. EA-RAG achieves 20.3% BTR and 65.0% robust accuracy on Claude Sonnet 4.6, a 5.5 percentage point BTR reduction without degrading base accuracy. The residual 20% BTR confirms that counterfactual robustness in clinical AI remains an open challenge. Keywords: counterfactual evaluation, clinical AI, maternal healthcare, retrieval-augmented generation, diagnostic robustness

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：构建 **MamaBench** 基准（217 对反事实临床叙事，434 例），并提出 **证据锚定 RAG（EA-RAG）**，以解决标准 RAG 中的“检索停滞”（base/counterfactual 查询嵌入相似度高达 0.94，导致检索相同上下文）。
- **EA-RAG 三阶段流程**：
  1. **证据提取**：用结构化 LLM 调用（GPT-5.4-nano）解析患者叙事为类型化临床参数（人口特征、主诉与严重性标志、风险因素、禁忌症、管理相关特征）。提取失败则回退到单次检索。
  2. **双通道检索与覆盖审计**：
     - 通道 1：通过 text-embedding-3-large 检索 top-5 块（余弦相似度）。
     - 覆盖审计：对每个证据元素 e_j，计算其与检索块的最大余弦相似度 cov(e_j, R(1))，若 < θ=0.6 则加入间隙集 G。
     - 通道 2：为每个 e_j ∈ G 生成对比子查询（“该参数如何改变病症的管理？”），检索补充块；去重后（δ=0.82）形成最终集 R_final（最多 8 块）。
  3. **分类学引导生成**：基于 113 次基线失败的错误分类（遗漏关键信息 48.7%、欠思考 31.9%、事实错误 10.6%、过度思考 8.8%），设计结构化指令框架：要求“先基于临床表现诊断，再参考检索证据，允许推翻检索结果”（区别于通用 CoT 和 Self-RAG）。

## 3. 实验设计：数据集、基准、对比方法

- **数据集**：MamaBench 全部由专家创作（妇产科、儿科团队），共 434 例（217 对），覆盖 371 种病理（儿科 58.5%，妇产科 41.0%，未分类 0.5%）。每对反事实基于五种扰动：症状替换、严重性升级、风险因素修改、时间偏移、合并症引入。所有案例通过多阶段临床审查。
- **基准**：无现成可比基准，论文自身构建了 MamaBench。
- **对比方法**：8 种配置：
  - 独立模型：GLM-5, Kimi K2.5, Nemotron Super 120B, GPT-5.4, Claude Sonnet 4.6
  - 标准 RAG 基线：GPT-4o (k=2)
  - EA-RAG 变体：GPT-4o (k=5) 和 Claude Sonnet 4.6
- **评估指标**：
  - 基础准确率 Acc_base = (|PP| + |PF|) / N
  - 偏差陷阱率 BTR = |PF| / (|PP| + |PF|) × 100%（主要指标）
  - 鲁棒准确率 Acc_rob = |PP| / N

- **数据隔离**：MamaBench 案例未包含在检索知识库中（仅教科书指南、WHO 协议、临床管理标准等临床参考材料）。

1. **基础准确率系统性高估鲁棒准确率**：所有模型差距为 16–28 个百分点。例如 GPT-4o：77.4% → 46.5%（BTR=39.9%）。

3. **EA-RAG 在不降低基础准确率的前提下降低 BTR**：Claude Sonnet 4.6 上 BTR 从 25.8% 降至 20.3%（-5.5 pp），基础准确率仅降 0.4 pp。
4. **更强的模型获益更多**：GPT-4o 上 EA-RAG 降低 BTR 4.0 pp，Claude Sonnet 4.6 上降低 5.5 pp，支持“检索质量是瓶颈”的假设。
5. **最佳系统仍失败于约 20% 的反事实对**：Claude + EA-RAG 的 BTR=20.3%，说明反事实鲁棒性仍需进一步研究。
6. **消融显示：仅覆盖审计无效，骨架引导带来最大增益，全管道优于部分**。

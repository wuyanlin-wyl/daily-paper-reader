## 摘要
大型视觉语言模型（LVLM）通常需要处理数百到数千个视觉令牌，导致巨大的推理开销。现有的视觉令牌剪枝方法要么在LLM之前使用与文本无关的启发式方法，要么在LLM内部进行剪枝，但会牺牲效率和产生嘈杂的跨模态注意力。为了解决这些限制，我们提出CRISP，一种在LLM之前但由文本驱动的视觉令牌剪枝框架，它既保留了与指令相关的证据，又保留了基本的场景上下文。CRISP采用两阶段流水线工作：第一阶段首先识别与文本对齐的视觉令牌，第二阶段通过语义多样性增强上下文完整性。在LLaVA-1.5和LLaVA-NeXT上的大量实验表明，CRISP在激进剪枝比率下实现了卓越的性能保持，在将推理成本和延迟降低2倍以上的同时，保持了高达99.5%的准确率。CRISP为高效LVLM推理提供了一种实用解决方案，特别是在资源受限的场景中。

## Abstract
Large Vision-Language Models (LVLMs) typically require processing hundreds to thousands of visual tokens, leading to substantial inference overhead. Existing visual token pruning methods either operate before the LLM using text-agnostic heuristics or prune inside the LLM at the cost of efficiency and noisy cross-modal attention. To address these limitations, we propose CRISP, a pre-LLM yet text-driven visual token pruning framework that preserves both instruction-relevant evidence and essential scene context. CRISP works in a two-stage pipeline: Stage 1 first identifies text-aligned visual tokens, and Stage 2 enhances contextual completeness through semantic diversity. Extensive experiments on LLaVA-1.5 and LLaVA-NeXT demonstrate that CRISP achieves superior performance retention under aggressive pruning ratios, maintaining up to 99.5% accuracy while reducing inference cost and latency by more than 2 times. CRISP serves as a practical solution for efficient LVLM inference, especially in resource-constrained scenarios.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型视觉语言模型（LVLM）在处理图像时需生成数百到数千个视觉令牌，这些令牌被送入大语言模型（LLM）处理，导致巨大的推理计算开销和延迟，阻碍其在资源受限或延迟敏感场景下的部署。
- **现有方法局限**：
  - **预-LLM剪枝**（如基于CLS注意力或特征相似度）仅在视觉侧进行，忽略了文本查询的指导，属于“先看后问”策略，认知负荷高且任务性能差。
  - **LLM内剪枝**（如基于跨模态注意力）虽能利用文本驱动，但早期层剪枝受位置偏差和注意力分散影响，性能下降；深层剪枝虽效果好，但需过多令牌穿越多个LLM模块，大幅削弱效率收益，且从LLM提取注意力权重会破坏FlashAttention加速。
- **本文目标**：提出一种 **在LLM之前但由文本驱动** 的视觉令牌剪枝框架CRISP，结合预-LLM的高效性和文本驱动的精准性，在不访问LLM注意力的情况下实现高效推理。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建两阶段流水线，在投影器之后、LLM之前进行剪枝：
  - **阶段1（Critical-First Token Selection）**：通过跨模态相关性度量，识别与文本查询关键词最相关的视觉令牌。
  - **阶段2（Semantically-Covered Token Completion）**：基于语义多样性，从剩余令牌中补充场景上下文，避免仅依赖文本线索而丢失背景信息。

### 关键技术细节
1. **关键词语提取**：使用轻量级NLP模型提取查询中的名词（如`en_core_web_sm`），将每个名词的子词嵌入平均得到词级嵌入。
2. **跨模态相关性计算**：在LLM嵌入空间中计算每个视觉令牌与每个词嵌入的余弦相似度，得到相关性矩阵 \( S \in \mathbb{R}^{T \times N} \)。
3. **词级配额分配**：根据每个词对应的视觉区域在CLS注意力中的重要性动态分配令牌预算。首先为每个词选出最相关的top-K/N个令牌，累加其CLS注意力得分作为权重，按比例分配预算。
4. **关键令牌选择**：对每个词，按其配额选取相关性最高的视觉令牌，合并得到关键令牌集 \( V_{\text{critical}} \)。若名词提取为空（如“What is it?”），则回退到基于CLS注意力选择。
5. **第二阶段：多样性补充**：从剩余令牌中迭代选择与当前已选集最大相似度最小的令牌（即最不冗余的令牌），直至达到总预算K。
6. **超参数α**：控制第一阶段预算占比（默认0.3；总预算<100时设为0.5）。

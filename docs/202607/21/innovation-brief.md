### 1. Localization-Infused Vision-Language Semantic Fusion for Text-Guided Medical Image Segmentation
- 区域：deep；分数：10.0
- 原文链接：https://arxiv.org/abs/2607.16327v1
- 方法流程：
  - 输入：医学图像和配对文本报告。
  - 阶段1：视觉编码器提取多尺度图像特征，文本编码器提取全局文本嵌入。
  - 阶段2：联合多尺度目标定位任务，从图像和文本中生成多尺度定位图（显式语义）和定位导向特征（隐式语义）。
  - 阶段3：应用LGFF，将定位导向特征与视觉特征融合，提供隐式特征级指导。
  - 阶段4：应用LGAF，利用多尺度定位图调控视觉特征图，强化关键区域。
  - 阶段5：应用LCLF，将多尺度定位图作为空间一致性约束监督分割预测。
  - 输出：最终分割掩码。
- 关键模块/机制：
  - 多尺度目标定位模块：从图像-文本对中提取定位导向的语义，生成多尺度定位图和定位导向特征。；通过联合多尺度定位任务，利用视觉和文本特征预测目标在不同尺度下的位置热图，同时产生对应的特征嵌入，捕获目标身份和位置信息。
  - Localization-Guided Feature Fusion (LGFF)：将定位导向特征注入视觉特征，提供隐式特征级引导。；将定位导向特征与图像特征进行融合（如逐元素相加或拼接），使得视觉特征偏向目标区域，指导后续分割。
  - Localization-Gated Attention Fusion (LGAF)：利用多尺度定位图对视觉特征进行门控调制，强化关键区域。；将多尺度定位图作为注意力门控，对视觉特征图的每个空间位置进行加权，使模型聚焦于定位高响应区域。
  - Localization-Constrained Loss Fusion (LCLF)：以多尺度定位图作为空间一致性约束，监督分割损失。；在损失函数中加入定位约束项，强制分割预测在空间分布上与定位图一致，例如使用KL散度或均方误差。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 多尺度定位任务：在不同分辨率下预测目标位置热图，与分割解码器共享特征。
  - LGFF：定位导向特征与视觉特征在特征空间融合，例如通过可学习的加权求和或跨注意力。
  - LGAF：定位图通过sigmoid或softmax生成权重，逐元素乘以视觉特征，实现门控。
  - LCLF：总损失 = 分割损失（如Dice损失）+ λ * 定位一致性损失（如MSE或KL散度），其中λ为超参数。
- 训练/推理细节：
  - 训练时联合优化分割任务和多尺度定位任务。
  - 使用配对图像和文本报告进行端到端训练。
  - 推理时仅需图像和文本，输出分割掩码。

### 2. CoRe: A Comprehensive Framework for Cross-Image Comparative Reasoning in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.12786v1
- 方法流程：
  - 数据构建阶段：从结构化视觉元数据出发，通过多专家协作流水线自动生成三元组图像及任务相关问题、结构化标注，形成训练样本x=(I1,I2,I3,m,Q,A)
  - 推理阶段：输入三元组查询q，模型输出包含推理轨迹t和预测答案ŷ
  - 奖励计算阶段：计算任务准确率奖励和三种结构化奖励（属性定位、判断对齐、三重一致性），加上辅助奖励（格式、长度、重复惩罚）
  - 优化阶段：采用GRPO算法，综合奖励和KL散度约束更新模型参数
- 关键模块/机制：
  - CoRe-20K数据集构建流水线：自动生成大规模三元组训练数据，覆盖计数、深度、距离、空间关系四种任务；从结构化视觉元数据出发，通过多专家协作流水线，利用确定性任务比较器gm从图像属性ai推导出三元组所有两两比较的标签y*_ij，确保标注一致性
  - TriSR结构化奖励框架：在GRPO优化中提供细粒度监督信号，引导模型生成属性正确、判断一致、三元组全局协调的推理轨迹；包含三种奖励：属性定位奖励（监督推理中提取的属性是否与真实属性匹配）、判断对齐奖励（确保最终预测与推理过程一致）、三重一致性奖励（确保三个两两比较结果满足全局传递性）；奖励权重分别为0.2、0.2、0.3
  - GRPO优化算法：基于群组相对策略优化的强化学习框架，联合优化任务准确率和结构化奖励；采用KL散度约束（β=0.01）防止奖励漂移；每个样本进行4次rollout；使用复合奖励（任务准确率+结构化奖励+辅助奖励）
- 公式/目标函数/指标定义：
  - 训练样本定义：x = (I1, I2, I3, m, Q, A)
  - 属性提取：a_i = f_m(I_i, A_i), i∈{1,2,3}
  - 三元组图像对：P = {(1,2), (1,3), (2,3)}
  - 真实标签：y*_ij = g_m(a_i, a_j), (i,j)∈P
  - 模型输出：o = (t, ŷ)，其中t为推理轨迹，ŷ为预测答案
  - 复合奖励权重：λ_ag=0.2, λ_ja=0.2, λ_tc=0.3
- 算法细节：
  - GRPO：每个样本生成4个rollout，计算每个rollout的奖励，然后基于组内奖励相对值优化策略
  - 奖励组成：任务准确率奖励仅对<answer>块内的token计算；结构化奖励基于完整推理轨迹计算；辅助奖励由训练库提供非本文贡献
  - 数据构建：利用多专家协作流水线自动生成三元组，确保任务相关属性一致性
  - 推理时：模型在thinking模式下生成<think>...</think><answer>ans</answer>格式的输出，从<answer>解析答案
- 训练/推理细节：
  - 基础模型：Qwen3-VL-4B-Thinking，保持Thinking模式以保留内在思维链能力
  - 输入格式：<think>...</think><answer>ans</answer>
  - 强化学习：GRPO，复合奖励（任务准确率+三种结构化奖励+辅助奖励）
  - 训练超参数：batch size=4，每个样本4个rollout，学习率1e-6余弦衰减，AdamW优化器，训练1轮，8×A800 GPU，混合精度
  - 推理：使用VLMEvalKit，统一提示格式和答案提取规则，从最终<answer>标记解析

### 3. Visual Access Boundaries in Vision-Language Model Reasoning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.12815v2
- 方法流程：
  - 输入：图像和文本，VLM生成图像token和文本token
  - 干预：在推理时，对注意力矩阵中生成token query到图像token key的部分，按层索引ℓ和时间索引τ进行掩码（设为负无穷），阻止该区域注意力
  - 评估：在掩码后模型仍生成答案，计算准确率
  - 扫描：改变ℓ和τ，记录准确率变化曲线
  - 定义VAB：准确率相对于完整访问基线下降不超过阈值ϵ的最早层和最早生成位置
- 关键模块/机制：
  - Visual Access Sweep干预模块：在自注意力中按层和生成位置逐步移除生成token对图像token的访问；在注意力计算时，将需要掩码的query-key位置对应的注意力权重设置为-∞（softmax前），从而使softmax后这些位置贡献为0。
  - VAB定义模块：根据准确率变化计算边界(ℓ*, τ*)；对于给定阈值ϵ，找到最小的(ℓ*, τ*)，使得对任意ℓ'≥ℓ*且τ'≥τ*，∆(ℓ', τ') ≤ ϵ。
  - 符号属性oracle：将真实属性以文本形式输入，测试CoT对计数的改善；在计数任务中，将物体真实属性（如颜色、形状）以文本描述形式送入模型，观察CoT是否能提升计数准确率。
  - 单对象探针-解码检查：从隐藏状态线性解码属性，对比模型直接输出；从VLM的最后一层隐藏状态中训练线性探针预测属性，并将探针准确率与模型直接生成的属性准确率比较，判断属性是否线性可恢复。
- 公式/目标函数/指标定义：
  - Δ_CoT(ℓ, τ) = |Acc_CoT,full-access - Acc_CoT,masked(ℓ,τ)|
  - VAB定义：对于阈值ϵ，找到最小(ℓ*, τ*)，使所有ℓ'≥ℓ*, τ'≥τ*满足Δ(ℓ', τ') ≤ ϵ
- 算法细节：
  - 掩码操作：在注意力计算时将query-key位置权重设为-∞，softmax后贡献为零
  - 层扫描：从最后一层向前逐层掩码当前层到最后一层的所有生成token对图像token的注意力
  - 时间扫描：从最后一个生成位置向前掩码该位置之后的所有生成token的注意力
  - 联合扫描：在层和生成时间两个维度进行网格搜索，记录准确率变化，找到边界区域
- 训练/推理细节：
  - 无需额外训练，仅在推理时施加注意力掩码干预
  - 所有模型使用标准自回归生成，解码参数（温度、top-p等）保持一致
  - 比较Direct（直接回答）和CoT（链式思维）两种推理模式
  - 实验在Qwen2.5-VL（3B/7B/32B）和InternVL3（8B/14B/38B）六种配置上进行

### 4. AspectCLIP: Optimizing CLIP Representation Space via Aspect-Guided Consistency Regularization
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13805v1
- 方法流程：
  - 预处理阶段：使用SimCSE提取所有文本嵌入，对文本嵌入执行K-Means聚类，将M个样本划分为K个方面簇C1...CK。
  - 批次采样阶段：从预训练数据中采样一个批次，包含来自各个簇的样本。
  - 损失计算阶段：计算原始CLIP对比损失L_CLIP；对批次内每个簇中的样本对计算簇内循环一致性损失L_intra（包括模态内和跨模态）；对每个样本与其他簇的原型计算簇间循环一致性损失L_inter。
  - 优化阶段：总损失L_total = L_CLIP + λ1·L_intra + λ2·L_inter，反向传播更新图像编码器和文本编码器。
- 关键模块/机制：
  - 方面感知语义聚类（Aspect-aware Semantic Clustering）：将预训练数据集划分为K个方面簇，每个簇内样本描述一致的视觉方面，簇间描述不同方面，为正则化提供结构化基础。；使用预训练语言模型SimCSE提取所有文本嵌入，然后应用K-Means聚类到文本嵌入上，得到K个不相交的簇C1...CK。仅基于文本聚类，因为文本通常只描述图像的一个方面，相似文本更可能对应相同方面。聚类在预训练前静态执行一次。
  - 簇内一致性正则化（Intra-cluster Consistency Regularization）：在同一个方面簇的样本对之间施加完整的循环一致性，强化共享方面的几何对齐。；对于批次中属于同一簇Ck的两个样本对((Iki,Tki),(Ikj,Tkj))，计算跨模态一致性项L_intra_C-Cyclic = (vki·tkj - vkj·tki)^2和模态内一致性项L_intra_I-Cyclic = (vki·vkj - tkj·tki)^2，对所有簇内对平均求和。
  - 簇间一致性正则化（Inter-cluster Consistency Regularization）：对不同方面簇的样本，仅通过原型进行比较，允许方面特异性差异，同时促进高层次结构信息交换。；对每个簇k计算图像原型vk_proto和文本原型tk_proto（当前批次内该簇样本嵌入的均值）。对于簇k中的每个样本，与所有其他簇m（m≠k）的原型计算一致性：L_inter_C-Cyclic = (vki·tm_proto - vm_proto·tki)^2，L_inter_I-Cyclic = (vki·vm_proto - tm_proto·tki)^2，然后对所有簇和样本平均。
- 公式/目标函数/指标定义：
  - CLIP图像到文本对比损失：L_I2T = -1/N Σ_i log [exp(vi·ti/τ) / Σ_j exp(vi·tj/τ)]
  - CLIP文本到图像对比损失：L_T2I = -1/N Σ_j log [exp(vj·tj/τ) / Σ_i exp(vi·tj/τ)]
  - CLIP总损失：L_CLIP = 0.5 (L_I2T + L_T2I)
  - CyCLIP跨模态循环一致性：L_C-Cyclic = 1/N Σ_i Σ_j (vi·tj - vj·ti)^2
  - CyCLIP模态内循环一致性：L_I-Cyclic = 1/N Σ_i Σ_j (vi·vj - tj·ti)^2
  - 簇内跨模态一致性：L_intra_C-Cyclic = 1/|S| Σ_{同簇对} (vki·tkj - vkj·tki)^2
- 算法细节：
  - 静态聚类：使用SimCSE文本嵌入对所有样本进行K-Means聚类（K=4），生成簇分配，在整个预训练过程中固定。
  - 批次构建：每个批次从数据集中随机采样，批次内的样本可能来自不同簇，记录每个样本的簇标签。
  - 原型计算：在每次前向传播中，对当前批次内属于同一簇的样本嵌入计算均值作为该簇原型（图像和文本分别计算）。
  - 损失计算：先计算标准CLIP对比损失；然后对批次内所有来自同一簇的样本对计算L_intra；再对每个样本与所有其他簇的原型计算L_inter。
  - 反向传播：总损失用于更新双编码器参数。
- 训练/推理细节：
  - 预训练数据集：CC3M（约3M图文对）。
  - 预训练配置：从零开始训练64个epochs，batch size 128，使用2块A800 GPU。
  - 模型架构：图像编码器使用ResNet-50，文本编码器使用Transformer。
  - 超参数：λ1=0.25，λ2=0.25，聚类数K=4。
  - 聚类模型：SimCSE（无额外训练，直接使用）。
  - 推理：与标准CLIP相同，使用零样本迁移或线性探测评估。

### 5. Multimodal Assessment of Pancreatic Cancer Resectability Using Deep Learning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.13826v1
- 方法流程：
  - 数据预处理：CT重采样至1mm各向同性，裁剪/填充至160×160×160，z-score归一化，应用随机翻转、旋转、仿射变换、高斯噪声、强度偏移等MONAI增强；临床变量进行缺失值插补（连续变量KNN k=5，分类变量众数）、编码（分类变量独热，连续变量缩放）
  - 图像特征提取：Swin-UNETR编码器将CT补丁嵌入并通过移窗自注意力层输出256维解剖特征向量；解码器进行16类（背景、胰腺、肿瘤、血管等）分割
  - 临床特征提取：17个临床变量通过MLP（隐含层未指定）输出32维临床嵌入
  - 多模态融合：256维图像特征与32维临床嵌入拼接为288维向量
  - 分类：288维向量通过全连接分类头（轻量级）输出三个NCCN类别（可切除、交界可切除、局部晚期）的Softmax概率
  - 训练：总损失为分割损失（Dice+Focal）和分类损失（交叉熵）的加权和，权重根据当前肿瘤分割Dice动态调整
- 关键模块/机制：
  - Swin-UNETR编码器-解码器：提取3D CT图像的解剖特征并进行辅助多器官分割；使用3D移位窗口自注意力（SwinUNETR）作为骨干，输入160×160×160 CT体积，编码器输出256维特征向量，解码器输出16类分割掩码（包括胰腺、肿瘤、血管等）。
  - 临床特征编码器（MLP）：将17个临床变量压缩为32维嵌入；多层感知机，输入17个变量（经编码和缩放），输出32维向量。
  - 多模态融合与分类头：融合图像和临床特征并预测NCCN类别；将256维图像特征与32维临床嵌入拼接为288维，通过全连接层和Softmax输出3个类别概率。
  - 动态多任务目标：自适应平衡分割和分类任务；总损失 L = w_seg * L_seg + (1 - w_seg) * L_cls，其中权重w_seg根据当前epoch肿瘤分割Dice动态设定：当Dice低于阈值时增加w_seg，否则降低。具体调整策略未在摘要中详细说明，但目标是在分割困难时加强解剖引导。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式。损失函数形式推测为：L_total = λ_seg * L_seg + λ_cls * L_cls，其中L_seg为Dice损失和Focal损失的组合，L_cls为交叉熵损失，λ_seg和λ_cls根据肿瘤Dice动态调整。
- 算法细节：
  - 编码器通过3D补丁嵌入和重叠窗口移位自注意力机制提取层次化特征
  - 解码器使用跳跃连接恢复空间分辨率，输出16通道分割图
  - 特征融合采用简单拼接（concatenation），未使用注意力对齐
  - 动态损失调整：监测肿瘤类别的Dice系数，若Dice较低则增大分割损失权重，反之减小
  - 训练时分割和分类梯度同时更新共享编码器，推理时仅使用编码器和分类头
- 训练/推理细节：
  - 训练使用159例患者（85可切除，47交界，27局部晚期），5折交叉验证
  - 分割掩码仅在训练时使用，推理时不需要，实现无掩码推理
  - 数据增强包括随机翻转、90度旋转、仿射变换（±0.1 rad）、高斯噪声（σ=0.01）、随机强度偏移（±0.1）
  - 临床变量缺失值插补：连续变量KNN（k=5），分类变量众数
  - 动态损失权重每epoch根据肿瘤Dice更新

### 6. MamaBench: Benchmarking LLM Robustness in Maternal and Child Health Diagnosis through Counterfactual Clinical Perturbation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.14385v2
- 方法流程：

### 10. Med-OPD: Improving Medical Vision-Language Models via Evidence-Aware On-Policy Distillation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.16303v1
- 方法流程：
  - 输入：学生模型（Med-VLM）和教师模型（预训练医学VLM），医疗图像和问题对。
  - 步骤1：学生模型在教师模型监督下进行on-policy采样，生成回答轨迹（token序列）。
  - 步骤2：教师模型使用answer-aware hint（问题+正确答案作为提示）对学生生成的轨迹进行评分，计算每个token的teacher distribution。
  - 步骤3：对每个token，计算Medical Evidence Advantage (MEA)：比较教师模型在原始图像和证据退化图像（如模糊病变区域）下的似然，得到每个token的evidence依赖分数。
  - 步骤4：在轨迹级别，计算轨迹平均MEA，以此加权每条轨迹的蒸馏损失，使高evidence依赖的轨迹获得更大权重。
  - 步骤5：在token级别，根据MEA阈值将token分为高MEA组和低MEA组，分别计算与教师分布的KL散度，高MEA组施加更高权重。
  - 输出：组合后的蒸馏损失用于更新学生模型参数。
- 关键模块/机制：
  - Medical Evidence Advantage (MEA)：度量每个token对医学视觉证据的依赖程度，提供反事实信号以识别关键诊断token。；对于学生生成的每个token，教师模型在原始图像下计算该token的似然p(w|x,I)，在证据退化图像I'（如掩膜病变区域）下计算似然p(w|x,I')，MEA定义为两者之比（或差值）的对数，即log p(w|x,I)/p(w|x,I')。高MEA表示token强烈依赖原始视觉证据。
  - Answer-Aware Teacher Hint：引导教师评分聚焦于支持目标诊断的视觉证据。；将问题与真实答案拼接作为额外提示输入教师模型，使教师模型在评分时更关注与正确答案相关的图像区域，从而产生更可靠的evidence感知分布。
  - Trajectory-Level Weighting：在轨迹级别重新分配蒸馏信号，强调需要细粒度视觉分析的样本。；计算每条学生轨迹的平均MEA值，将其作为该轨迹的权重系数乘以KL蒸馏损失。平均MEA高的轨迹（即包含更多证据依赖token的轨迹）获得更大的梯度更新。
  - Token-Level Grouped Distillation：防止关键视觉token被大量临床叙述token稀释。；对每个轨迹，根据MEA值将token分为高MEA组（如top 10%）和低MEA组。对高MEA组应用标准KL散度，对低MEA组施加更小的权重（如0.1倍），或者分别计算损失后加权求和，权重参数可调节。
- 公式/目标函数/指标定义：
  - KL散度：KL(p∥q) = Σ_{w∈V} p(w) log(p(w)/q(w))，用于度量教师分布p和学生分布q之间的差异。
  - Medical Evidence Advantage (MEA) 定义（隐含）：MEA(t) = log( P_teacher(w_t | x, I, hint) / P_teacher(w_t | x, I', hint) )，其中I'为证据退化图像，hint为answer-aware提示。
  - 轨迹级加权蒸馏损失：L_traj = Σ_{轨迹} (MEA_avg(轨迹) * L_KL(轨迹))。
  - Token级分组损失：L_token = α * Σ_{高MEA token} KL(p_t || q_t) + β * Σ_{低MEA token} KL(p_t || q_t)，其中α > β（例如α=1, β=0.1）。
  - 总损失：L_total = L_KL_base + λ * (L_traj + L_token) （λ为平衡系数）
- 算法细节：
  - On-policy采样：学生模型在当前参数下对每个问题生成回答（自回归解码），保存token序列及每一步的概率。
  - Evidence degradation：对原始图像，通过在关键病变区域添加模糊或掩膜（可使用分割模型或人工标注）生成退化图像，用于计算反事实似然。
  - MEA计算：对于学生轨迹中的每个token位置t，使用教师模型在原始和退化图像下分别计算该token的概率（条件于之前token），计算对数比值。
  - 分组阈值：根据验证集分布确定MEA阈值（如选择top 10%分位数）来划分高/低MEA组。
  - 梯度更新：通过反向传播总损失更新学生模型参数，教师模型参数冻结。
- 训练/推理细节：
  - 训练：使用OmniMedVQA数据集子集，学生模型为Med-VLM（如LLaVA-Med），教师模型为更强大的VLM（如GPT-4V或专门训练的医学VLM）。
  - On-policy蒸馏：每轮训练，学生先生成一批回答，然后教师对该批回答进行评分并计算MEA，最后计算加权KL损失更新学生。
  - 推理：仅使用学生模型，无需教师或MEA计算，直接输入图像和问题进行生成。
  - 超参数：轨迹级权重系数、token级分组比例（如top 10%）、高低组损失权重（α=1, β=0.1）等。

- 原文链接：https://arxiv.org/abs/2607.16305v1
- 方法流程：
  - 输入：文本token ID（u）、图像特征（通过视觉编码器提取）、中间层隐藏状态H_in
  - 文本查找：通过token ID直接索引文本嵌入表E_text，时间复杂度O(1)，获得R_text
  - 图像查找：对图像特征进行多尺度划分，在每个尺度下进行两阶段查找（场景级→原语级），从图像嵌入表E_img中检索R_img
  - 跨模态查找：以当前层隐藏状态为查询，对跨模态嵌入表E_cross进行两阶段查找（场景级→原语级），获得R_cross
  - 融合：将三个检索结果R_text、R_img、R_cross分别通过FFN融合后相加
  - 稀疏注入：每个LookME层通过SKA仅选择部分token进行增强; 通过NetProp在相邻层间传播关键嵌入（默认Head-Tail连接）
  - 输出：增强后的隐藏状态H_out = DecoderLayer(H_in) + G(R_combined)
- 关键模块/机制：
  - 层级两阶段查找模块：从大规模外部嵌入表中高效检索与当前输入相关的多模态嵌入；第一阶段（场景级）：使用输入特征（图像token或隐藏状态）的全局池化向量，在投影后的场景嵌入簇中进行最近邻查找（top-1），确定候选场景簇; 第二阶段（原语级）：在该场景簇内的原语嵌入中进行top-k查找（k=16），获得最终检索结果。图像查找采用多尺度（Scale 1...s）独立查找后拼接。
  - 稀疏注入模块（SKA + NetProp）：自适应选择关键token进行增强，并在层间传播重用嵌入表；SKA：在每个LookME层，对当前隐藏状态计算注意力稀疏度（基于token与检索嵌入的相似度），仅对得分最高的前K个token（K为超参，默认序列长度的10%）注入检索嵌入，其余token保持不变。NetProp：将当前LookME层中检索到的关键嵌入（即被SKA选中的嵌入）通过键-值缓存机制传递给后续相邻层，使得这些嵌入可以在邻近层被重用，从而减少重复查找开销。默认采用Head-Tail连接（仅在第一和最后一个LookME层之间传播），避免长距离特征漂移。
  - FFN融合模块：将检索到的嵌入与当前隐藏状态融合；每个LookME层包含三个独立的FFN（前馈网络），分别处理文本、图像、跨模态检索结果。检索嵌入R经过FFN后与原始隐藏状态H_in相加（残差连接）。FFN结构为两层MLP，中间维度为隐藏维度，激活函数为SiLU。
- 公式/目标函数/指标定义：
  - H_out = DecoderLayer(H_in) + G(R_text) （文本PLE基础公式，LookME扩展为多模态）
  - R_text = E[u] （文本嵌入表查找）
  - H_out = DecoderLayer(H_in) + G(R_text) + G(R_img) + G(R_cross) （LookME增强公式）
- 算法细节：
  - 文本查找：使用输入文本token ID u直接索引文本嵌入表E_text ∈ R^{|V|×d_e}，其中|V|为词汇量，d_e为嵌入维度（默认512）。时间复杂度O(1)。
  - 图像查找：将视觉编码器输出的图像特征令牌（例如576个）进行多尺度网格划分（例如1×1, 2×2, 4×4），每个尺度下分别执行两阶段查找。第一阶段：对尺度内所有token取平均得到场景级query，与场景嵌入簇做余弦相似度，选择得分最高的簇；第二阶段：在该簇内的所有原语嵌入中，计算与每个token的余弦相似度，取top-k（k=16）个嵌入。不同尺度的检索结果拼接后作为R_img。
  - 跨模态查找：以当前层隐藏状态H_in（L×d_h）中每个位置的向量作为query，直接对跨模态嵌入表E_cross进行两阶段查找（类似图像查找，但无多尺度），取top-k嵌入作为R_cross。
  - 稀疏注入选择：在每个LookME层，计算每个token位置与检索嵌入的融合增益（基于检索嵌入与隐藏状态的交互得分），选择增益最高的前10% token注入；其余90% token旁路。SKA具体实现：对每个token，计算检索嵌入与隐藏状态的点积后通过softmax，以最大值为增益指标。
  - NetProp跨层传播：对于被选中的关键嵌入，将其键（key）和值（value）存入一个轻量传播缓存。在相邻层的LookME中，如果该层也执行查找，则先尝试匹配缓存中的键（通过余弦相似度），若匹配则直接复用其值，否则从外部表重新查找。Head-Tail配置下，缓存仅在第一层和最后一层之间传递。
- 训练/推理细节：
  - 训练数据集：60M样本（约570亿视觉token和140亿文本token），来自开源图像-文本数据集，按视觉任务类别平衡采样。
  - 训练策略：基于Qwen2.5VL-3B骨干网络，全参数微调（full-parameter fine-tuning），训练LookME及所有基线。训练配置和超参数见附录。
  - 推理设置：零样本评估（zero-shot），使用VLMEvalKit在11个基准上测试。
  - 嵌入维度默认512，查找层插入位置默认[2,10,18]（从0开始计）。

  - 对未标注数据，计算Pred与Pfg之间的结构一致性（如Dice系数）作为每个像素/区域的可靠性权重。

  - Reliability-aware Pseudo-label Learning Mechanism：基于结构一致性评估未标注伪标签的可靠性，并进行区域重加权。；对未标注图像，计算主预测Pred与解耦前景响应Pfg之间的Dice系数（或IoU），作为每个像素的可靠性权重。在计算无监督损失时，对每个像素的Dice损失乘以该权重，使不可靠区域（结构一致性低）对训练贡献减小，抑制错误累积。
- 算法细节：
  - 语义-频率双扰动：对输入图像同时进行语义保留增强（如颜色变换）和频率域扰动（如傅里叶幅度替换），增强模型对外观变化的鲁棒性，两阶段均使用此策略。
  - 正交约束：通过设计损失项（如特征正交化或余弦相似度惩罚）促使前景和背景特征表示正交。

### 30. CGRL: Concept-Guided Pruning and Representation Learning for Whole-Slide Image Classification
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2607.12556v1
- 方法流程：
  - 输入：全切片图像（WSI）。输出：滑动级分类标签。
  - 阶段1：补丁嵌入提取 - 将WSI切分为N个补丁，使用预训练特征提取器（如ResNet）得到补丁嵌入集合X={xi}。
  - 阶段2：概念原型获取 - 为每个类别c设计文本提示（如“An H&E image of [类名]”），通过预训练文本编码器得到概念原型tc。
  - 阶段3：投影与相似度计算 - 使用可学习投影头gφ将补丁嵌入映射到概念空间得到ui，然后计算归一化余弦相似度矩阵S（N×C）。
  - 阶段4：概念相关性剪枝 - 对每个补丁取最大相似度作为相关性分数ri，保留top-Kp个补丁形成剪枝袋X̃，输入下游MIL模型。
  - 阶段5：概念引导对比学习（仅训练） - 根据S对每个类别c选取top-Kpos作为正集Pc、bottom-Kneg作为负集Nc，基于投影特征U构建三个InfoNCE损失。
  - 阶段6：联合优化 - 总损失L_total = L_MIL + λ * L_CGRL，其中L_CGRL = Ly + Lsym + Lcross。
  - 推理阶段：仅执行阶段1-4，经过剪枝后直接由MIL模型预测。
- 关键模块/机制：
  - 投影头 (Projection Head)：将补丁嵌入映射到概念空间，使视觉特征与概念原型对齐。；轻量级可学习网络gφ(·)，输入为补丁嵌入xi∈RD，输出为ui∈RDc，通常为1-2层MLP。
  - 概念相关性剪枝 (Concept-Relevance Pruning)：根据补丁与类别概念的相似度选择最相关补丁，降低计算开销并消除冗余。；计算每个补丁的最大余弦相似度ri = max_c Si,c，保留最大的Kp个索引，按原顺序构成剪枝袋X̃，但保留原始补丁嵌入供MIL使用。
  - 目标类对比损失 (Target-Class Loss Ly)：鼓励属于真实类别y的投影特征与该类别原型ty对齐，同时与背景特征分离。；利用公式(10)的InfoNCE损失，Qy = {ui | i∈Py}，正键=ty，负键=My={uj | j∈Ny}，其中Py和Ny由相似度矩阵S第y列排序得到。
  - 对称辅助对比损失 (Symmetric Auxiliary Loss Lsym)：对每个非目标类c≠y，将其最相关投影特征与其原型对齐，同时推远不相关特征。；对每个非目标类c，计算L_sym_c = L_InfoNCE(Q_c, t_c, N_c)，其中Q_c = {ui | i∈P_c}，将所有L_sym_c求和或平均。
  - 跨类分离对比损失 (Cross-Class Separation Loss Lcross)：增强目标类与竞争类别之间的分离度，将目标类正特征与竞争类最相关特征拉开。；对于目标类y，对每个非目标类c计算L_cross_c = L_InfoNCE(Q_y, t_y, {uj | j∈P_c})，即视P_c中特征为负，将所有L_cross_c求和或平均。
- 公式/目标函数/指标定义：
  - 补丁嵌入集合: X = {xi}i=1..N, xi∈RD
  - 类别概念原型: T = {tc}c=1..C, tc∈RDc
  - 投影后特征: ui = gφ(xi), ui∈RDc
  - 相似度矩阵: S = Û · T̂^T, 其中Û和T̂为L2归一化后的U和T，元素Si,c = (ui^T tc)/(||ui|| ||tc||)
  - 概念相关性分数: ri = max_c Si,c
  - 剪枝索引: IKp = TopK_Kp({ri})
- 算法细节：
  - 补丁嵌入使用预训练模型（如ResNet-50）从WSI中提取，固定权重。
  - 文本提示为模板如“An H&E image of {subtype}”，使用预训练文本编码器（如CLIP）获取原型，固定权重。
  - 相似度矩阵计算使用余弦相似度，投影头输出和原型均L2归一化。
  - 剪枝比例由Kp控制，实验中使用Kp=300对比原始N约10000。
  - 对比学习中使用top-Kpos=50和bottom-Kneg=50作为正负样本数量。
  - 三个损失直接相加作为L_CGRL，平衡超参数λ用于加权，原文可能采用λ=0.1（未明确，但输入未提供确切值）。
- 训练/推理细节：
  - 训练时同时优化MIL分类损失和L_CGRL，投影头参数更新，但补丁提取器、文本编码器和下游MIL模型参数可选择冻结或微调（原文未明确，但通常投影头与MIL一起更新）。
  - 推理时移除对比学习分支，仅使用投影头和剪枝模块及MIL模型。
  - 由于剪枝保留固定数量Kp的补丁，推理计算量显著降低。
  - MIL模型可采用ABMIL、CLAM、TransMIL、DS-MIL等，CGRL作为前置轻量模块。

### 31. GFR-SAM: Training-Free Referring Camouflaged Object Segmentation via Cross-Image Prompting
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.11732v1
- 方法流程：
  - 阶段1（生成）：输入参考图像和目标图像，以参考图像作为上下文示例，SAM3进行跨图像推理，生成多个候选掩码。
  - 阶段2（过滤）：对候选掩码进行区域-全局对比过滤，使用DINOv3提取原型特征，通过原型对齐排序候选，抑制背景噪声。
  - 阶段3（细化）：对过滤后的候选掩码进行几何-语义细化，结合边界框（如通过目标检测获得）和文本提示（如“目标物体”），精修边界并补全遗漏实例。
- 关键模块/机制：
  - In-Context Exemplar-guided Segmentation：利用参考图像作为上下文示例，引导SAM3生成候选分割掩码，突破SAM3仅处理单张图像的局限。；将参考图像和目标图像拼接或通过交叉注意力机制输入SAM3，使SAM3基于参考图像中的外观特征在目标图像中定位相似区域，输出前k个候选掩码。
  - Region-Global Contrastive Filtering：对候选掩码进行排序和过滤，选择与参考实例原型最匹配的候选，去除背景干扰。；使用DINOv3从参考图像中提取前景原型向量（全局原型），并从每个候选掩码区域提取区域特征；计算区域特征与全局原型的余弦相似度，按相似度排序，保留高相似度的候选。
  - Geometric-Semantic Refinement：细化候选掩码的边界和完整性，提升分割精度。；利用目标检测器（如基于DINOv3的检测头）生成边界框，结合文本提示（如类名）作为SAM的point/box prompt，对候选掩码进行边缘精细化和遗漏实例补全。
- 公式/目标函数/指标定义：
  - 区域-全局对比过滤：score(m_i) = cos_sim(f_global, f_region_i)，其中f_global为参考图像前景DINOv3原型，f_region_i为第i个候选掩码区域的DINOv3特征，选择score最高的前M个候选。
  - 加权F-measure（F_β^w）：β=1或特定权重，用于评估分割精度，具体公式未在输入中提供。
- 算法细节：
  - 使用SAM3的image encoder和mask decoder，但通过修改prompt encoder支持跨图像输入：将参考图像和目标图像的特征进行交叉注意力融合。
  - 候选掩码生成后，通过阈值过滤掉低概率区域，然后进行非极大值抑制（NMS）减少冗余。
  - DINOv3提取特征后，使用平均池化获得每个候选区域的原型。
  - 几何-语义细化阶段：将保留的候选掩码与检测框结合，通过SAM3的point prompt（框内采样点）进行二次预测，并利用文本提示（如“伪装物体”）增强语义一致性。
- 训练/推理细节：
  - 整个流程为无训练（training-free），所有模块均使用预训练模型（SAM3、DINOv3）在推理时直接组合。
  - 推理时，先使用DINOv3检测器生成目标物体边界框作为几何先验。
  - 文本提示使用预定义模板，不依赖数据集标注。

### 34. Cost-Pragmatic Quality Gating and Selection-Fusion Multi-Model Combiners for BioASQ Phases A+ and B
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.13551v1
- 方法流程：
  - 输入：自然语言问题
  - 阶段1（并行检索）：(a)混合第一阶段：dense BGE检索 + BM25检索 + RRF融合，输出候选文档；(b)智能代理管道：将问题分解，分别查询PubMed、Europe PMC和iCite，输出候选文档。

  - 阶段3（多模型回答组合）：多个LLM（Claude, GPT-5.5, Gemini等）基于候选文档生成答案，再通过选择组件（LLM-as-judge）或融合组件（如synonym-union resolver）输出最终答案。

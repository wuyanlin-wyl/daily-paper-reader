## 方向 1：面向块状缺失的多模态3D高斯关系分割
结合PairGS的成对关系建模和MOSAIC的模式校准框架，解决3D高斯分割中多模态输入块状缺失的问题。PairGS利用多视图线索计算高斯间亲和度，但依赖完整的多视图掩码；MOSAIC通过共享与特定表示学习，实现跨缺失模式校准。通过互补，可提升在缺失模态下3D高斯分割的鲁棒性和准确性。

### 代表论文

- [Relation-Centric Open-Vocabulary 3D Gaussian Segmentation](https://arxiv.org/abs/2607.01140v1)：提出PairGS，通过建模高斯间成对关系实现开放词汇3D高斯分割，无需每场景优化，速度快且性能SOTA。
- [Pattern-Calibrated Multimodal Prediction under Blockwise Missingness](https://arxiv.org/abs/2607.01821v1)：针对多模态数据块状缺失问题，提出模式校准框架MOSAIC，通过学习共享和特定模态表示，利用重叠表示进行第一步预测，再估计校准差距，实现跨模式借力而不混淆预测规则。实验在ICU死亡率预测、情感识别和青光眼分类中验证了有效性。

### 共同创新点
- 将3D高斯分割转化为成对关系建模，避免个体特征噪声（PairGS）
- 利用模式校准框架处理块状缺失，跨模式借力而不混淆预测规则（MOSAIC）

### 尚未解决的问题
- PairGS在多视图掩码缺失时关系计算不准确
- MOSAIC尚未应用于3D高斯表示和关系建模

### 二次创新路线
#### 路线 1：缺失感知的成对亲和度计算
- 核心想法：在PairGS的成对亲和度计算中，当某些视角缺失掩码时，使用MOSAIC的模式校准来估计缺失模态的表示，从而保持亲和度准确性。
- 新问题定义：提出“缺失模态下3D高斯成对亲和度估计”新任务：给定一组高斯和部分视角的掩码，目标是准确预测高斯对属于同一物体的概率，即使某些视角完全缺失。
- 机制来源：
  - PairGS利用多视图掩码证据和视图贡献权重计算成对亲和度（A论文：解决完整视图下的亲和度建模）
  - MOSAIC学习共享表示和模式特定表示，并通过校准差距进行跨模式预测（B论文：补足缺失模态下的表示估计）
  - 结合：当掩码缺失时，用MOSAIC的共享表示替代缺失模态的特征，再输入PairGS的亲和度计算模块
- 为什么值得做：实际场景中多视图掩码常因遮挡或传感器故障而缺失，直接丢弃会损失信息，而简单插值可能引入噪声。MOSAIC的共享表示能在缺失时提供鲁棒的特征，使亲和度计算更可靠。
- 理论/数学创新理由：
  - 数学对象：成对亲和度函数 A_ij = f(visual_i, visual_j, mask_i, mask_j) 在缺失模态下的优化
  - 来源分解：PairGS设计了一个基于多视图线索的亲和度函数 A_ij = Σ_v w_v * I(mask_iv = mask_jv)，其中w_v是视图权重，I是指示函数；MOSAIC提出一个校准损失 L_cal = Σ_p || h_s(z_s) - h_p(z_p) ||^2，其中z_s是共享表示，z_p是模式特定表示，h是预测头。
  - 新建模方式：定义新的亲和度函数 A*_ij = Σ_v w_v * (1(掩码存在) * I(mask_iv = mask_jv) + 1(掩码缺失) * g(shared_i, shared_j) )，其中shared_i = MOSAIC中的共享表示，g(·)是基于共享表示相似度的函数。整体优化目标为最小化校准损失与分割损失的联合。
  - 公式草图：A*_ij = Σ_{v in V_obs} w_v * I(mask_iv = mask_jv) + Σ_{v in V_miss} w_v * σ(shared_i^T shared_j)，其中V_obs为有掩码的视角集，V_miss为缺失视角集，σ为sigmoid函数。共享表示shared_i = Encoder(G_i)，其中G_i为高斯i的属性。
  - 为什么可能有效：当掩码缺失时，共享表示从所有可用模态中学习，比完全丢弃或零填充更鲁棒，能保留物体一致性线索；同时校准保证了共享表示与缺失模式预测的一致性，从而提升亲和度准确性。
- 可验证实验：在3D高斯分割数据集（如ScanNet）上模拟块状缺失：随机丢弃部分视角的掩码。对比PairGS原始版本、零填充版本和本路线版本，评估分割mIoU和亲和度一致性。
- 主要风险：共享表示可能无法充分捕捉多视图细节，导致在严重缺失下性能下降；且需要额外训练MOSAIC模块，增加复杂度。

#### 路线 2：缺失模式感知的层次聚类校准
- 核心想法：将MOSAIC的模式校准方法应用于PairGS的层次聚类树构建，使得在不同缺失模式下得到的聚类结果对齐，提升分割的跨缺失模式一致性。
- 新问题定义：提出“跨缺失模式一致的3D高斯分割”新设定：在测试时遇到训练中未见过的缺失模式，仍能产生稳定的分割结果。
- 机制来源：
  - PairGS构建层次聚类树，基于成对亲和度矩阵（A论文：解决完整缺失模式下的聚类）
  - MOSAIC通过校准机制调整不同缺失模式下的预测分布（B论文：解决缺失模式间的预测漂移）
  - 结合：在聚类中引入校准项，使不同缺失模式下同一高斯对的亲和度保持稳定
- 为什么值得做：实际应用中，不同场景或不同时间点的缺失模式可能不同，导致聚类结果不稳定。利用校准使聚类对缺失模式鲁棒，增强泛化性。
- 理论/数学创新理由：
  - 数学对象：层次聚类中的亲和度矩阵对缺失模式的校准函数
  - 来源分解：PairGS的亲和度矩阵A_ij依赖于当前缺失模式（哪些视角可用），因此不同模式得到的A不同，聚类结果不同；MOSAIC的校准损失L_cal鼓励共享表示与模式特定表示的输出一致。
  - 新建模方式：定义校准后的亲和度矩阵A_cal = A + λ · Gradient( L_cal(A) )，其中L_cal(A) = ||A - A_ref||^2，A_ref是从共享表示计算得到的亲和度。聚类时使用A_cal。
  - 公式草图：A_ref_ij = σ(shared_i^T shared_j)；L_cal = Σ_{i,j} (A_ij - A_ref_ij)^2；A_cal = A - η ∇_A L_cal，其中η为步长。然后对A_cal进行层次聚类。
  - 为什么可能有效：校准项使亲和度矩阵向基于共享表示的不变表示靠拢，减少缺失模式变化带来的波动，从而获得更稳定的聚类结果，提升分割的可重复性和泛化性。
- 可验证实验：在ScanNet上训练PairGS+MOSAIC，然后在不同缺失模式（如只保留前3个视角、随机掩码等）的测试集上评估聚类一致性和分割mIoU。基线包括PairGS和MOSAIC单独应用。
- 主要风险：校准可能过度平滑导致边界模糊，且需要选择合适的λ和η，调参敏感。

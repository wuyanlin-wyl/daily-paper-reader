## 摘要
无提示适应Segment Anything Model (SAM)已成为自动医学图像分割的一种有前景的范式。现有方法主要关注提示生成，而忽略了提示质量从根本上受到解剖表示表达能力的限制。然而，确定性原型或语义标记不足以联合捕捉全局解剖先验、结构内多样性和局部结构可靠性。为解决这一限制，我们提出层次化概率表示（HPR）框架，通过分布解剖表示（DAR）、多组件解剖表示（MAR）和局部可靠性表示（LRR）学习互补的解剖表示，并通过层次化预测融合（HPF）集成其预测，同时保持与原始SAM解码器的兼容性。在Synapse、LA和PROMISE12数据集上的实验表明，HPR-SAM在Synapse上达到了最先进的性能，并在LA和PROMISE12的少样本设置下取得了最佳性能，验证了所提出的层次化概率表示学习框架在无提示医学图像分割中的有效性。代码可在https://anonymous.4open.science/r/HPR-SAM-E4AF获取。

## Abstract
Prompt-free adaptation of the Segment Anything Model (SAM) has emerged as a promising paradigm for automatic medical image segmentation. Existing methods mainly focus on prompt generation, while overlooking that prompt quality is fundamentally constrained by the expressiveness of anatomical representations. However, deterministic prototypes or semantic tokens are insufficient to jointly capture global anatomical priors, intra-structure diversity, and local structural reliability. To address this limitation, we propose the Hierarchical Probabilistic Representation (HPR) framework, which learns complementary anatomical representations through Distributional Anatomical Representation (DAR), Multi-component Anatomical Representation (MAR), and Local Reliability Representation (LRR), and integrates their predictions via Hierarchical Prediction Fusion (HPF) while remaining compatible with the original SAM decoder. Experiments on the Synapse, LA, and PROMISE12 datasets demonstrate that HPR-SAM achieves state-of-the-art performance on Synapse and the best performance under few-shot settings on LA and PROMISE12, validating the effectiveness of the proposed hierarchical probabilistic representation learning framework for prompt-free medical image segmentation. Code is available at https://anonymous.4open.science/r/HPR-SAM-E4AF.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：Segment Anything Model (SAM) 在医学图像分割中展现了强大的泛化能力。但原始 SAM 依赖人工点/框提示，限制了临床实用性。近期无提示（prompt-free）SAM 方法（如 PGP-SAM、SurgicalSAM、DAP-SAM）通过自动生成提示实现全自动分割。
- **核心问题**：现有方法侧重提示生成器设计，却忽视了**提示质量本质上受限于解剖表示的表达能力**。它们通常使用确定性原型或语义令牌表示解剖目标，无法同时捕捉：
  - 全局解剖先验（global anatomical priors）
  - 结构内多样性（intra-structure diversity）
  - 局部结构可靠性（local structural reliability）
- **研究含义**：本文首次从**解剖表示学习**角度重新审视无提示 SAM，提出层次化概率表示（HPR）框架，旨在通过概率建模学习更完整的解剖表示，从而提升自动提示质量和分割性能。

## 二、方法论：核心思想与关键技术细节

### 2.1 整体框架
- 输入图像经 SAM 图像编码器得到图像令牌（tokens） \(E \in \mathbb{R}^{N \times D}\)。
- HPR 从 E 学习三种互补的概率表示：
  - **DAR (Distributional Anatomical Representation)**：建模全局解剖先验
  - **MAR (Multi-component Anatomical Representation)**：建模结构内多样性
  - **LRR (Local Reliability Representation)**：建模局部结构可靠性
- 三种表示分别投影为 SAM 兼容的密集和稀疏提示，经原始 SAM 解码器得到三个预测图 \(Y^{(g)}, Y^{(d)}, Y^{(l)}\)。
- 通过**层次化预测融合 (HPF)** 自适应集成得到最终分割 \(Y^{\text{fuse}}\)。

### 2.2 DAR：分布解剖表示
- 每个解剖目标 \(c\) 建模为高斯分布 \(G_c = (\mu_c, \Sigma_c)\)，\(\mu_c\) 为语义中心，\(\Sigma_c\) 为不确定性。
- 从分布采样多个潜在假设 \(z_{c,m} = \mu_c + \Sigma_c^{1/2} \epsilon_m\)。
- 计算每个图像令牌 \(e_i\) 与目标 \(c\) 的兼容性（使用 log-sum-exp 聚合所有假设的余弦相似度）：
  \[
  \ell_{i,c} = \tau \log \sum_m \exp\left(\frac{\operatorname{sim}(e_i, z_{c,m})}{\tau}\right)
  \]
- 后验分配 \(\pi_{i,c} = \text{softmax}_c(\ell_{i,c})\)，用于加权聚合得到全局表示 \(r_c^g = \sum_i \pi_{i,c} e_i\)。

### 2.3 MAR：多组件解剖表示
- 每个目标由 \(M\) 个概率组件（高斯混合）表示：\(D_c = \{G_{c,1},...,G_{c,M}\}\)，每个组件 \(G_{c,m} = (\mu_{c,m}, \Sigma_{c,m})\)，混合权重 \(\omega_{c,m}\)。
- 从每个组件采样假设 \(z_{c,m,s}\)，计算组件级兼容性 \(\ell_{i,c,m}\)。
- 利用 DAR 的全局后验 \(\pi_{i,c}\) 计算组件级后验：\(\pi_{i,c,m} = \pi_{i,c} \cdot \text{softmax}_m(\ell_{i,c,m})\)。
- 每个组件独立聚合特征 \(r_{c,m} = \sum_i \pi_{i,c,m} e_i\)，最终多样性表示 \(r_c^d = \sum_m \omega_{c,m} r_{c,m}\)。

### 2.4 LRR：局部可靠性表示
- 每个图像令牌 \(e_i\) 参数化为高斯分布：\(\mu_i = h_\mu(e_i), \Sigma_i = h_\Sigma(e_i)\)。
- 维护类级可靠性分布 \(P_c = (\bar{\mu}_c, \bar{\Sigma}_c)\)，通过 EMA 使用低不确定性观测更新。
- 通过互似然（mutual likelihood）评估令牌分布与类可靠性分布的一致性：
  \[
  s_{i,c}^l = -\frac{1}{2}\left( \frac{\|\mu_i - \bar{\mu}_c\|^2}{\Sigma_i + \bar{\Sigma}_c} + \log(\Sigma_i + \bar{\Sigma}_c) \right)
  \]
- 得到可靠性后验 \(\pi_{i,c}^l = \text{softmax}_c(s_{i,c}^l)\)，用于加权聚合得到 \(r_c^l = \sum_i \pi_{i,c}^l e_i\)。

### 2.5 HPF：层次化预测融合
- 全局与多样性分支融合：\(Y_c^{(gd)} = (1-\alpha_c) Y_c^{(g)} + \alpha_c Y_c^{(d)}\)，\(\alpha_c\) 为可学习系数。
- 再与可靠性分支融合：\(Y_c^{\text{fuse}} = (1-\beta_c) Y_c^{(gd)} + \beta_c Y_c^{(l)}\)，\(\beta_c\) 为可学习系数。

### 2.6 训练目标
- 每个分支使用 Dice + CE 损失，总损失为融合损失与分支损失加权和。

## 五、主要结论与发现

1. **Synapse 全监督**：HPR-SAM 达到 Mean Dice 85.09%，优于所有 SAM 基方法（如 +0.44% vs H-SAM，+0.30% vs PG-SAM），且接近传统最优方法 MERIT（84.90%）。
2. **少样本**：在 LA（4 张标注）和 PROMISE12（3 张标注）上分别达到 84.65% 和 81.26%，均显著优于对比方法（如 +0.71% vs H-SAM 于 LA，+4.31% vs H-SAM 于 PROMISE12）。
3. **消融验证**：三个组件均有效，联合使用时最佳（+10.23% Dice 提升，HD95 降低 16.04 mm）；DAR+MAR 组合强于单独使用；LRR 需要其他分支支持才能发挥最大作用。
4. **定性结果**：在模糊边界和低对比区域（如胰腺、主动脉）产生更完整、更符合解剖结构的预测。

## 六、优点

1. **视角创新**：首次从解剖表示学习而非提示生成设计角度解决无提示 SAM 问题，揭示了表示表达力是性能瓶颈。
2. **概率建模充分**：通过高斯分布、混合分布和互似然机制分别建模全局不确定性、结构多样性和局部可靠性，比确定性原型更丰富。
3. **层次化融合**：HPF 通过可学习系数对三个分支进行自适应组合，保留原 SAM 解码器，即插即用。
4. **兼容性**：不修改 SAM 解码器结构，仅训练注入的模块，参数高效（使用 LoRA）。
5. **实验全面**：覆盖多数据集、多模态、不同监督程度，且消融实验设计清晰。

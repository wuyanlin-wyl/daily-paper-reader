### 2. Text as Partial Constraint: Core-Residual Alignment for Robust Vision-Language Learning
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.03143v1
- 方法流程：
  - 多视图文本编码：对每个图像使用K个描述，分别通过文本编码器得到嵌入ti,k，同时图像编码得到vi。
  - 共识核心计算：对所有视图嵌入求均值并归一化，得到共识核心ci = norm((1/K) Σ ti,k)。
  - 单视图核心预测：训练核心预测器ψθ，从单个视图ti,k预测核心嵌入ĉ_i,k = ψθ(ti,k)。
  - 正交分解：将每个视图嵌入ti_k分解为核心部分ĉ_i,k和残差ri,k = ti,k - Ĉ_i,k。
  - 不确定性估计：计算视图嵌入与共识核心的余弦相似度均值偏差，得到ui = avg_k (1 - |cos(ti,k, ci)|)。
  - 不确定性感知对比学习：使用温度τ_i = τ0(1+γui)调整对比损失，并联合优化核心对齐损失、核心一致性损失和非承诺损失。
  - 推理阶段：仅使用单个文本视图，通过核心预测器得到核心嵌入Ĉ_i,k，再与图像嵌入计算相似度。
- 关键模块/机制：
  - 多视角共识核心模块：从多个文本视图中提取稳定语义中心，作为对齐目标；对同一图像所有视图的文本嵌入取均值并归一化：ci = norm((1/K) Σ ti,k)，该核心代表跨视图共享的语义信息。
  - 单视图核心预测器：在推理时仅用单文本视图估计共识核心，使得模型能够适应标准单查询场景；学习一个神经网络ψθ，输入单个视图嵌入ti,k，输出核心嵌入ĉ_i,k = ψθ(ti,k)，训练时通过核心一致性损失使其逼近共识核心ci。
  - 正交分解与残差抑制：将文本嵌入分解为核心和未说残差，并降低视觉嵌入对残差的依赖；对每个视图，残差ri,k = ti,k - Ĉ_i,k，确保核心与残差正交（通过归一化后的正交性）。非承诺损失L_nc = (v_i^T r_i,k)^2，鼓励图像嵌入忽略残差方向。
  - 不确定性感知对比学习：根据视图间不一致程度动态调整对比学习温度，减少弱约束下的过自信；温度τ_i = τ0 (1 + γ u_i)，其中u_i = avg_k (1 - |cos(ti,k, ci)|)表示视图间不确定性。当u_i大时温度升高，软化对齐力度。
- 公式/目标函数/指标定义：
  - 共识核心：ci = norm((1/K) Σ ti,k)
  - 正交分解：ĉ_i,k = ψθ(ti,k), ri,k = ti,k - ĉ_i,k
  - 不确定性：ui = avg_k (1 - |cos(ti,k, ci)|)
  - 温度：τ_i = τ0 (1 + γ ui)
  - 核心对齐损失（对比）：L_match = -log( exp(v_i·ci/τ_i) / Σ_j exp(v_j·ci/τ_i) )
  - 核心一致性损失：L_agree = Σ_k ||ĉ_i,k - ci||^2
- 算法细节：
  - 训练时每个小批量包含B个图像，每个图像对应K个文本视图。
  - 图像和文本分别通过编码器得到归一化嵌入vi和ti,k。
  - 计算共识核心ci，并训练核心预测器ψθ以最小化ĉ_i,k与ci的均方误差。
  - 正交分解后，计算不确定性ui，并按公式调整每个样本的温度。
  - 对比学习使用批量内负样本，同时计算三个损失项。
  - 推理时仅给定一个文本视图，通过ψθ预测核心嵌入，再与图像嵌入计算余弦相似度。
- 训练/推理细节：
  - 训练时使用多视图（K≈5），通过多视图共识和残差抑制学习鲁棒表示。
  - 推理时只需单视图，利用核心预测器输出核心嵌入进行匹配，无需多视图。
  - 温度τ0和γ为超参数，实验中τ0设为标准CLIP值（如0.07），γ设为0.5左右。
  - 损失权重λ_agree和λ_nc通过网格搜索确定，通常λ_agree=1, λ_nc=0.1。
  - 训练基于CLIP预训练模型进行微调，使用相同的数据和步数。

### 3. Pathways of Visual Information Flow in Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.03358v1
- 方法流程：
  - 步骤1：任务和数据准备。定义识别、空间关系、定位三种任务；构建合成数据集（彩色形状在网格中）和自然数据集（COCO、Visual Genome等），每个样本包含图像和文本查询。
  - 步骤2：标记输入token。将输入分为图像token I、文本查询token T和最后token xn。
  - 步骤3：定义候选路径。定义三条路径：直接路径 rI→last（最后token直接注意图像token）、文本介导路径的中间步骤 rI→T（图像token到查询token）和文本介导路径的最后步骤 rT→last（查询token到最后token）。
  - 步骤4：执行干预。对于注意力剔除，修改注意力掩码使指定路径的注意力权重为零，观测准确率变化；对于因果补丁，构造配对样本（原始和反事实），在指定层将反事实的某类token表示替换到原始样本中，计算恢复分数。
  - 步骤5：分析路径使用。通过恢复分数曲线或准确率变化判断模型依赖的路径，并在多个模型（Qwen3-VL、InternVL3.5、LLaVA-1.5）上验证泛化性。
- 关键模块/机制：
  - 因果补丁（Causal Patching）：定位信息从哪类token表示流到最后token；为每对原始输入x和反事实输入˜x，在层ℓ将原始样本中指定类token（图像token/文本token/最后token）的隐藏表示替换为反事实对应的表示，然后继续前向传播。通过恢复分数（归一化的概率增加）衡量替换后的预测向反事实输出移动的程度，分数高表示该层该类token包含足够信息改变预测。
  - 注意力剔除（Attention Knockout）：抑制特定注意力路径，观测模型依赖路径；在注意力softmax之前修改加法掩码，将指定路径对应的位置设为负无穷（公式2），使得softmax后该位置注意力权重为零，其余权重自动重新归一化。通过比较剔除前后准确率变化，判断模型是否依赖该路径，但注意补偿效应。
  - 路径定义与符号化：形式化信息流候选路径；定义token划分为图像token I、文本查询token T、最后token xn。候选路径为rI→last、rI→T、rT→last（公式1），分别对应直接路径和文本介导路径的两段。
- 公式/目标函数/指标定义：
  - 信息路径定义：rI→last = {(j, n) : j ∈ I}, rT→last = {(j, n) : j ∈ T}, rI→T = {(i, j) : i ∈ I, j ∈ T}
  - 注意力剔除掩码修改：M̂_ij^(l) = M_ij^(l) - ∞·1_{(i,j)∈r}
  - 恢复分数（Restoration Score）：(P(y|x; hℓ(x)←hℓ(˜x)) - P(y|x)) / (P(y|˜x) - P(y|x))，限制在[0,1]
  - 基线准确率与NoImg准确率：对比移除图像输入后的准确率下降（表1）
- 算法细节：
  - 因果补丁算法：对于每个层ℓ，选择干预目标token类型（图像/文本/最后token）。对每对样例，将原始样本前向传播至层ℓ，在层ℓ的输出处将指定类型所有token的表示替换为反事实对应位置的表示，之后继续前向传播直至输出层，计算恢复分数。
  - 注意力剔除算法：在前向传播的每个注意力层，根据预定义的路径r，修改注意力mask矩阵，将r中所有索引对(i,j)对应的位置设为负无穷（-∞），然后执行softmax，实现注意力阻断。
  - 任务设计：三个任务共享相同的合成数据基元（6种形状、6种颜色、4个位置），自然数据来自多个公开数据集，统一任务定义。
  - 实验设置：推理仅在A100 GPU上运行，每个实验（数据集、模型、干预）数小时内完成，总计算约数GPU天。
- 训练/推理细节：
  - 所有实验均为推理阶段（inference-only），不涉及模型训练。
  - 使用开放权重的VLM模型：Qwen3-VL-4B、InternVL3.5-4B、LLaVA-1.5-7B。
  - 评估时有两种提示协议：choices（给出候选答案集合）和open（不给出候选，仅限制答案token集合）。
  - 对于自然识别任务，前缀“It is a”用于标准化输出格式。

### 4. ViPo-MLLM: Visual-Pose Multimodal LLM for Gloss-Free Sign Language Translation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.03657v1
- 方法流程：
  - 输入：手语视频X={x_t}。
  - 提取RGB特征：使用预训练USTM编码器（冻结）得到帧级特征Z_s ∈ R^{T×D_s}。
  - 提取姿态特征：使用OpenPose估计人体/手部姿态，取中间特征经空间池化得到Z_p ∈ R^{T×D_p}。
  - 帧内模态建模（IMTM）：分别将Z_s和Z_p线性投影到共享维度D，通过共享的2层1D-TCN（kernel=5）和最大池化捕获局部时间动态，输出T'×D。
  - 跨模态建模（CMTM）：将两个IMTM输出在时间维度拼接得Z_c ∈ R^{2T'×D}，通过4层交叉注意力模块（CMA）建模全局依赖和模态间交互。
  - 投影：用MLP将融合特征映射到LLM嵌入维度D_L，得Z ∈ R^{2T'×D_L}。
  - 构造prompt：指令“Translate the given sentence into <language>”和三个少样本示例的嵌入拼接得E_prompt ∈ R^{L_p×D}。
  - 拼接：将E_prompt与Z拼接得X_joint = [E_prompt; Z] ∈ R^{(L_p+2T')×D_L}。
- 关键模块/机制：
  - USTM编码器：提取时空RGB特征；使用预训练USTM（Swin Transformer + 时间适配器），保持冻结，去除分类头，输出帧级特征Z_s ∈ R^{T×D_s}。
  - OpenPose姿态估计：提取人体和手部姿态特征；估计全身和手部关键点，取热图生成前的中间特征，每帧空间平均池化得Z_p ∈ R^{T×D_p}。
  - IMTM（Intra-Modal Temporal Modeling）：对各模态进行帧内局部时间建模；线性投影到共同维度D，通过共享参数的2层1D-TCN（kernel size 5）和最大池化，输出T'×D。
  - CMTM（Cross-Modal Temporal Modeling）：进行跨模态全局时间建模；将两个IMTM输出沿时间拼接成Z_c ∈ R^{2T'×D}，通过4层交叉注意力（CMA）模块捕获长程依赖，输出融合特征。
  - LLM + LoRA：基于多模态特征和prompt生成翻译；使用mT0-XL作为骨干，LoRA（rank=16）进行高效微调。输入为拼接后的prompt与融合特征X_joint，通过语言建模损失优化。
- 公式/目标函数/指标定义：
  - 对比损失：L_cont = -log(exp(z·y/τ) / Σ_j exp(z·y_j/τ))，其中z为全局视频表征（Z时间池化），y为伪标签文本表征（冻结LLM嵌入池化），τ为可学习温度。
  - 交叉熵损失：L_CE = CrossEntropy(LLM(X_joint), Y_target)，Y_target为真实翻译句子。
  - 总损失：L = L_cont + L_CE。
- 算法细节：
  - 特征提取：USTM编码器使用预训练识别权重并冻结；OpenPose使用中间特征而非最终热图。
  - IMTM中线性投影将Z_s和Z_p映射到共同维度D，共享TCN参数。
  - CMTM中4层交叉注意力模块，每层包含自注意力和跨模态注意力。
  - prompt构造：指令模板+三个少样本示例（西班牙语、法语、英语→目标语言），分别嵌入后拼接。
  - 训练两阶段：前100 epochs仅优化对比损失（warm-up），后50 epochs联合优化L_cont和L_CE。
  - 使用ReduceLROnPlateau调度器（patience=5, gamma=0.2）。
  - LoRA rank=16，应用于mT0-XL的注意力层。
- 训练/推理细节：
  - 训练：两阶段策略，第一阶段100轮仅对比学习，第二阶段50轮联合训练；单卡NVIDIA H100 80GB；使用ReduceLROnPlateau调度。
  - 推理：输入视频，经编码器提取特征、融合，与预构造prompt拼接，送入LLM生成翻译。
  - LLM骨干：mT0-XL，采用LoRA微调。

### 5. Displacement Preserving Relational Distillation for Robust Medical Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.04599v1
- 方法流程：
  - 输入：教师和学生模型的第l阶段特征图。
  - 通过RAFM生成ROI掩码，并应用密度归一化聚合获得紧凑的案例级嵌入。
  - 计算所有案例对之间的成对位移向量。
  - 对位移向量进行异构批量归一化，消除激活尺度差异。
  - 对齐归一化位移向量（轨迹损失）和相对距离（距离正则化），计算关系损失。
  - 多阶段联合优化：总损失为分割损失与各阶段关系损失的加权和。
- 关键模块/机制：
  - 位移保持关系对齐 (DPRA)：通过匹配成对位移向量和距离，提供尺度不变局部关系监督。；计算教师和学生嵌入的成对位移向量Δ，进行批量归一化（除以其平均L2范数）消除激活尺度差异，然后使用Smooth L1损失对齐归一化位移的方向（Ltraj）和相对距离（Ldist）。
  - ROI感知特征掩码 (RAFM)：利用解剖掩码聚焦任务相关结构，避免背景稀释。；通过合并所有前景类别生成统一二进制掩码，对投影后的特征图进行掩码，并使用密度归一化池化（除以掩码密度）获得尺度不变的案例级嵌入。
  - 多阶段联合优化：在不同特征分辨率上应用DPRD，捕获层次解剖结构。；在编码器所有阶段l∈{0,...,5}应用关系损失，使用阶段权重ωl（深层更高，如0.05,0.1,0.1,0.15,0.25,0.35）和超参数λ_traj=1.0, λ_dist=0.5。
- 公式/目标函数/指标定义：
  - Δϕ_ij = vϕ_i - vϕ_j (成对位移向量)
  - μϕ = (1/K) Σ_{i<j} ||Δϕ_ij||_2 (批量平均L2范数)
  - ˆΔϕ_ij = Δϕ_ij / (μϕ + ε) (归一化位移向量)
  - Ltraj = (1/K) Σ_{i<j} Σ_{c=1..C} Ψ(ˆΔS_ij,c - ˆΔT_ij,c) (轨迹损失，Ψ为Smooth L1)
  - Ldist = (1/K) Σ_{i<j} Ψ(||ˆΔS_ij||_2 - ||ˆΔT_ij||_2) (距离正则化)
  - vϕ = P(ˆFϕ ⊙ Mϕ) / (P(Mϕ) + ε) (密度归一化特征聚合)
- 算法细节：
  - DPRA算法：提取案例级嵌入 → 计算所有成对位移向量 → 计算批量平均L2范数μ进行归一化 → 分别计算轨迹损失Ltraj和距离正则化Ldist。
  - RAFM算法：将特征图通过1×1×1卷积投影到128通道 → 生成二进制掩码（合并前景类别） → 对投影特征图进行掩码 → 密度归一化池化（求和除以掩码体素总数）得到紧凑嵌入。
  - 多阶段优化：对编码器每个阶段独立计算关系损失，并按阶段权重求和后与分割损失一起优化学生网络。
- 训练/推理细节：
  - 训练阶段：教师模型（MedNeXt）冻结，学生参数更新；使用投影层（1×1×1卷积）对齐通道；RAFMMask基于训练标签生成，仅在训练时使用。
  - 推理阶段：移除教师和投影层，学生模型参数和FLOPs与原始学生相同。
  - 批量大小：MobileUNetV3为4，PlainConvUNet为2。优化器：SGD。
  - 关系损失仅在训练时施加，计算复杂度为O(N^2)，但操作在紧凑嵌入上，轻量高效。

### 6. DeGenseGS: Geometrically and Semantically Decoupled Surgical Scene Understanding in 4D Gaussian Splatting
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.04761v1
- 方法流程：
  - 输入：多视角图像序列和相应文本提示

### 8. Structured-Condensed Prompt Tuning in Vision-Language Models for Fine-grained Image Recognition
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2607.06185v1
- 方法流程：
  - 输入：类名集合{c_i}、冻结文本编码器f_txt、随机投影矩阵W；处理：将手写提示（如'photo of {classname}'）经f_txt编码得到文本特征X；计算类间余弦相似度矩阵S = XX^T；通过随机投影与符号函数生成语义关系编码P = sign(SW^T)，并取指数得到Ri = exp(Pi)；将Ri与可学习上下文向量V拼接为结构化提示Vi = [Ri, V]；经f_txt得到文本特征Yi。
  - 输入：图像x、冻结图像编码器f_img；处理：提取图像特征z = f_img(x)；计算z与所有Yi的余弦相似度得到logits。
  - 计算交叉熵损失Lce；同时计算语义压缩损失Lsc：对文本特征Yi进行奇异值分解，保留前τ比例的主成分，重构后与原始特征计算差异作为损失，抑制冗余信息。
  - 总损失L = Lce + λLsc，更新可学习上下文向量V。
- 关键模块/机制：
  - 语义关系编码（Semantic Relation Encoding, SRE）：显式建模类间语义拓扑，生成结构化提示以增强类间区分性。；首先，利用手动模板（如'photo of {classname}'）经冻结文本编码器获得所有类别的文本特征向量X（N×d）。计算类间余弦相似度矩阵S（N×N）。通过随机投影矩阵W（d×K）将S降维至N×K，然后应用符号函数sign(·)将连续值映射为+1或-1，形成二进制关系编码P。最后对P的每个元素取指数（e^{Pi}）得到正值的SRE编码Ri（维度K），将其作为前缀与可学习上下文向量V拼接，构成结构化提示。
  - 语义压缩损失（Semantic Condensation loss, ScLoss）：抑制冗余监督，提取全局语义空间中的判别成分。；在训练过程中，对当前批次中所有类别的文本特征Y（N×d）进行SVD分解：Y = UΣV^T。设置阈值τ（如0.3），保留奇异值占比前τ的主成分，其余置零得到低秩近似Y'。计算Y与Y'之间的均方误差（或余弦距离）作为压缩损失，迫使模型聚焦于主要语义方向，忽略噪声和冗余信息。该损失与交叉熵损失联合优化。
- 算法细节：
  - 训练算法（Algorithm 1）：初始化可学习上下文向量V（高斯初始化σ=0.02）；固定编码器f_img和f_txt；预计算类名文本特征X；计算SRE编码Ri；在每个训练迭代中，构建结构化提示Vi，提取文本特征Yi；提取图像特征z；计算余弦相似度logits；计算交叉熵损失Lce；对Yi执行SVD分解，根据阈值τ保留主成分，计算重构损失Lsc；更新V以最小化Lce + λLsc。
  - 随机投影矩阵W随机初始化并固定，不参与训练。
  - 符号函数sign(·)将实数映射为-1或+1，形成二值编码。
  - SVD低秩重构时，保留前r个奇异值使得累计占比大于τ（如0.3）。
- 训练/推理细节：
  - 训练时采用SGD优化器，学习率2e-3，余弦退火调度，训练50个epoch，batch size 32。
  - 可学习上下文向量长度固定为4，初始化高斯分布标准差0.02。
  - 超参数λ=8.0（与KgCoOp一致），阈值τ=0.3。
  - 推理时，SRE编码使用与训练相同的随机投影矩阵，对测试类名构建结构化提示，无需再计算损失。

### 12. ProLaViT: Learning Progressive Latent Visual Thoughts in Structured Latent Space
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2607.02907v1
- 方法流程：
  - 输入: 图像和问题文本，模型通过视觉编码器提取图像特征，并在输入文本前添加特殊标记<latent_start>和<latent_end>
  - 阶段1-粗到细因果链（空间任务）: 模型依次生成K个潜在思维token（每步Ntokens个），逐步从全局定位到局部聚焦再到隔离目标，例如Locate→Focus→Isolate
  - 阶段2-辩证推理链（逻辑任务）: 模型生成假设后，通过自我批判和验证步骤进行纠错，例如Hypothesize→Critique→Verify
  - 输出: 最终的潜在思维token序列与原始图像特征融合，输入语言解码器生成答案
  - 训练: 两轮课程训练，第一轮VQA热身和特征对齐，第二轮用自蒸馏监督生成锚点token序列
- 关键模块/机制：
  - 内生自蒸馏（Endogenous Self-Distillation）：提供潜在思维监督信号；使用模型自身的视觉编码器（Qwen2.5-VL的ViT）作为教师，将每步生成的潜在思维token与教师从图像中提取的对应特征进行对齐，避免依赖外部专家模型，确保特征空间自然对齐。
  - 距离加权多样性损失（Distance-Weighted Diversity Loss）：防止潜在状态退化，保持渐进式区分；对每对推理步(i,j)的潜在表示计算相似度，并根据步数差|i-j|赋予不同权重：相邻步权重低以保持上下文连续性，远距离步权重高以强制区分。损失函数为所有步对相似度的加权惩罚。
  - 粗到细因果链（Coarse-to-Fine Causal Chain）：空间推理的结构化思维流程；模型按顺序生成四个潜在状态：第一步定位全局区域，第二步聚焦局部对象，第三步隔离具体目标，第四步可能执行精确匹配。每一步的注意力受前一步引导。
  - 辩证推理链（Dialectical Reasoning Chain）：逻辑推理的自我验证机制；模型首先生成一个假设的潜在表示，然后生成批判性的潜在表示（指出错误），最后生成验证性的潜在表示（确认或修正），模拟试错过程。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式，但损失函数为距离加权多样性损失，包含权重w_{ij}（基于步差|i-j|）和相似度度量（如余弦相似度），目标是最小化所有步对的加权相似度之和。
- 算法细节：
  - 渐进式分解：将视觉推理分解为K个有序步（K=4），每步生成定长潜在token序列（Ntokens=4），通过自回归方式逐步细化视觉表示
  - 自蒸馏：训练时，冻结视觉编码器，将其中间特征作为锚点，监督每步潜在token的输出特征，损失为均方误差或余弦相似度
  - 距离加权：在多样性损失中，相邻步的相似度允许保持较高（权重低），远距离步的相似度强制降低（权重大），权重函数为w_{ij}=exp(-|i-j|/τ)或类似形式
  - 推理时：不调用外部工具，仅通过模型内部的潜在向量传递，所有步骤在一次前向传播中完成（通过token序列的长注意力）
- 训练/推理细节：
  - 基模型: Qwen2.5-VL-7B-Instruct，使用LoRA（rank=16, α=32, dropout=0.01）微调语言模型，冻结视觉编码器和词嵌入
  - 训练数据: 通过程序化合成管道生成视觉推理轨迹，每个轨迹包含图像、问题、答案以及对应的潜在锚点特征序列

  - 怀疑分数计算模块：量化每个模型在每个查询上的异常程度；置信度公式：Confidence = α·(1 - SE/log k) + (1-α)·(|R∩C_max|/k)，α=0.5，SE为语义熵。分歧度：Divergence = sqrt(JS(P||P_avg))/sqrt(ln2)。怀疑分数=Confidence×Divergence。

  - SE_{M_i} = -∑_{j=1}^K P(C_j|M_i) log P(C_j|M_i)

  - P_{avg} = (1/(m-1))·∑_{j≠i} P_{M_j}
  - Divergence_{M_i} = sqrt(JS(P_{M_i} || P_{avg})) / sqrt(ln2)
  - S_{M_i,q} = Confidence_{M_i} × Divergence_{M_i}

  - 微调实验使用LoRA，学习率1e-3，训练3个epoch，偏置数据集包含100个目标实体负样本文本-图像对和100个无关话题控制对。
  - 推理采样温度T=0.7，采样次数k=10，最大token数1000。
  - 语义蕴含判断使用Qwen3-4B-Instruct模型。

### 14. SNR-Adaptive Unified Diffusion for Multi-Task Medical Image Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2607.03103v1
- 方法流程：
  - 输入：三个异构心脏数据集（LA、MMWHS、MNMS），每个包含少量标注样本和大量无标注样本，图像尺寸各异（统一预处理为相同尺寸）。
  - 阶段1：DiffVNet扩散正过程：对输入图像x和当前噪声标签xt，将图像x作为条件，通过UNet预测噪声，逐步还原干净标签。训练时从xstart（one-hot映射到{-1,1}^11）加噪。
  - 阶段2：模型前向推理：对每个任务k，通过共享UNet输出11通道特征图，取任务专属通道区间[sk, ek)进行softmax，得到分割概率图。
  - 输出：每个任务的分割掩码（类别数分别为2,5,4），用于计算各自的Dice损失，并通过Difficulty monitor动态调整各任务损失权重。
- 关键模块/机制：
  - Unified 11-channel label space：消除跨任务语义碰撞；将输出通道扩展为11个，为每个任务分配不重叠区间：LA:[0,2), MMWHS:[2,7), MNMS:[7,11)。每个voxel的one-hot编码仅在该任务区间内激活，其余通道填充-1。梯度仅从各自任务区间回传，从结构上阻止梯度符号反转。
  - SNR-Adaptive Task Conditioning (SATC)：根据噪声水平自适应调节任务条件强度；使用公式λ_k(t)=σ(τ_k·log SNR(t))作为门控，其中SNR(t)=ᾱ_t/(1-ᾱ_t)，τ_k为任务k的可学习温度。将门控值与任务嵌入相乘后加到时间嵌入上：h_cond = h_time + λ_k(t)·h_task。高噪声时λ_k(t)→0（弱化任务偏差），低噪声时λ_k(t)→1（完全注入任务细节）。
  - Task-Type-Aware Conditional Dropout (TTACD)：选择性丢弃任务条件以匹配任务目标；根据任务类型设定条件丢弃概率：SSL（LA）为20%（补偿有限标注），UDA（MMWHS）为0%（保留跨模态对齐），DG（MNMS）为100%（强制依赖共享中性路径）。训练时按概率随机丢弃任务token，丢弃时仅使用时间嵌入和无条件路径。
  - Independent loss instances and Difficulty monitor：维持各任务稳定训练；为每个任务独立维护一个损失对象和Difficulty monitor。损失对象独立缓存类权重统计，避免批间维度不一致导致梯度异常；Difficulty monitor跟踪每类Dice进展，动态调整监督损失权重。
- 公式/目标函数/指标定义：
  - 训练目标：max_θ Σ_{k=1}^K E_{(x,y)~D_{Lk}} [Dice(f_θ(x)[s_k:e_k], y)]，其中[s_k,e_k)为任务k的通道区间。
  - SNR定义：SNR(t) = ᾱ_t / (1-ᾱ_t)，其中ᾱ_t为累积噪声调度。
  - SATC门控：λ_k(t) = σ(τ_k · log SNR(t))，σ为sigmoid，τ_k为任务k的可学习温度。
  - 条件嵌入：h_cond = h_time + λ_k(t) · h_task。
  - one-hot编码：y_oh[b, τ_k(c), h, w, d] = 1 ⇔ label[b, h, w, d] = c，τ_k(c)=s_k+c。
- 算法细节：
  - SATC门控逻辑：在每个扩散时间步，计算当前log SNR，乘以任务k的温度τ_k后通过sigmoid得到0-1之间的值λ_k(t)，再用λ_k(t)缩放任务嵌入加到时间嵌入上。
  - TTACD实现：对每个输入样本，根据其任务类型，以指定概率（LA:20%, MMWHS:0%, MNMS:100%）将任务嵌入置零，仅保留时间嵌入。
  - 11通道输出分割：UNet输出11通道特征图，对每个任务k，取通道范围[s_k,e_k)做softmax，其余通道忽略。
  - Difficulty monitor更新：每个任务独立维护每类Dice历史，根据当前Dice与历史均值比较调整该任务损失权重（弱类增加权重，强类减少权重）。
- 训练/推理细节：
  - 训练：三个任务的数据以轮流或随机混合方式送入共享UNet，每个任务保持独立损失计算和Difficulty monitor，梯度共同更新全部参数。
  - 推理：对每个测试样本，根据其任务类型（已知）选择对应输出通道区间进行softmax得到分割。对于MNMS（域泛化），TTACD在推理时固定为100%丢弃任务token，即仅用无条件路径生成。
  - 数据预处理：所有图像重采样至相同体素间距（具体值未提及），强度归一化至[-1,1]。
  - 超参数：扩散时间步T=1000，噪声调度为线性；温度τ_k初始化为0.5并作为可学习参数更新。

  - MLLM作为评分oracle，对裁剪区域输出语义相关分数

### 23. PreSIST: Vision-Language-Informed Object Persistence Prediction in Open-World Scenes
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2607.04057v1
- 方法流程：
  - 输入：当前图像I和实例分割掩码M
  - 阶段1：预测生存时间分位数——PreSIST-Lang使用VLM（如GPT-4V）根据图像和掩码输出(q25, q75)；PreSIST-Vis使用轻量级视觉模型直接回归分位数

  - 阶段4：在线更新——每当到达新观测时刻ti，获取检测结果yi（正/负），根据贝叶斯公式更新后验概率p(Xt=1|Y1:N)

### 1. ConceptM$^3$oE: Concept-Guided Multimodal Mixture of Experts for Interpretable Computational Pathology
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.24399v1
- 方法流程：
  - 阶段1：模态编码。WSI通过门控注意力MIL池化得到特征e1；细胞图通过GraphSAGE消息传递加注意力池化得到特征e2。
  - 阶段2：交互感知专家证据。定义M+2个专家（U1, U2, R, S），每个专家fe处理拼接的[e1; e2]输出ze（Rd）。专家语义通过扰动损失L_e_int强制（式1）。
  - 阶段3：概念形成。对每个专家e和每个概念k，通过线性层+LeakyReLU计算正负状态c+_{e,k}和c-_{e,k}（式2），形成概念嵌入。
  - 阶段4：概念层次推理。首先预测K1个形态学概念（软序数目标），可选在此基础上预测K2个生物标志物概念（二分类目标）。
  - 阶段5：最终分类。每个专家的概念嵌入和残差路径输出联合，通过聚合（如加权和）得到最终表示，再映射到诊断类别。
- 关键模块/机制：
  - 交互感知MoE专家：分解多模态证据为模态特定、冗余和协同三类，通过扰动损失（式1）强制专家对模态的敏感/不变性。；定义E=M+2个专家，U_m对模态m敏感（s_{me}=-1），对其它模态不变（s_{me}=+1）；R对所有模态不变；S对所有模态敏感。每个专家输入为拼接的模态嵌入[e1; e2]，输出ze。
  - 概念瓶颈层（每个专家内）：将专家潜在表示映射到可解释概念空间，产生正负概念状态。；对专家e和概念k，使用两个线性层ϕ+和ϕ-后接LeakyReLU，得到c+_{e,k}和c-_{e,k} ∈ R^{d_c}，分别编码概念高表达和低表达的证据。
  - 残差路径：允许任务相关信号绕过概念瓶颈直接流向最终预测，避免信息损失。；在每个专家内，ze除了通过概念形成模块，还直接通过一个线性变换（或恒等映射）得到残差表示，与概念表示相加后用于后续分类。
  - 层次概念组织：建模临床依赖关系：形态学概念先预测，再用于引导生物标志物概念预测。；第一层预测K1个形态学概念（软序数，目标t1∈[0,1]^K1），第二层利用第一层输出和专家表示预测K2个生物标志物概念（二分类，目标t2∈{0,1}^K2）。
- 公式/目标函数/指标定义：
  - 专家扰动损失：L_e_int = Σ_{m=1}^M s_{me} DKL(p_clean_e || p_m_e)，其中p_clean_e为专家e在原始输入上的预测，p_m_e为对模态m添加高斯噪声后的预测，s_{me}∈{-1,+1}根据专家语义设置。
  - 概念状态计算：c+_{e,k} = LeakyReLU(ϕ+_{e,k}(z_e)), c-_{e,k} = LeakyReLU(ϕ-_{e,k}(z_e)), z_e为专家潜在表示。
  - 总损失：L = L_cls + λ1 L_concept + λ2 L_int，其中L_cls为分类交叉熵，L_concept为概念预测损失（形态学使用排序损失或MSE，生物标志物使用二分类交叉熵），L_int为专家扰动损失。
- 算法细节：
  - 专家语义强制算法：对每个专家e，对每个模态m，采样高斯噪声N(0,σ^2)加入em，计算专家输出并得到p_m_e；使用KL散度比较p_clean_e和p_m_e，根据符号s_{me}更新专家参数（鼓励敏感则最小化KL，鼓励不变则最大化KL，实际通过负号实现）。
  - 概念嵌入生成：在每个专家内，将c+_{e,k}和c-_{e,k}拼接或求差得到概念嵌入h_{e,k}，然后所有概念嵌入通过一个线性层映射到概念预测。
  - 残差融合：专家ze同时经过概念路径（产生概念嵌入）和残差路径（线性变换），两者相加后作为专家输出表示。
  - 门控聚合：专家输出表示通过注意力门控（可学习权重或基于内容）加权求和得到全局表示，用于最终分类和概念预测。
- 训练/推理细节：
  - 训练：优化总损失L = L_cls + λ1 L_concept + λ2 L_int，使用Adam优化器，学习率及超参数见附录。
  - 概念标签：形态学概念从病理报告提取软序数目标（0-1），生物标志物概念从分子注释提取二值目标。
  - 推断：输入WSI和细胞图，经过编码和专家融合，输出诊断类别及每个概念的专家/模态归因（通过梯度或注意力权重）。
  - 数据增强：对WSI使用颜色抖动、旋转等；对细胞图使用节点特征噪声。

### 2. ConceptM$^3$oE: Concept-Guided Multimodal Mixture of Experts for Interpretable Computational Pathology
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.24399v2
- 方法流程：
  - 输入：WSI patch特征（经gated-attention MIL聚合）和细胞图特征（经GraphSAGE + 注意力池化）
  - 模态编码：两个模态分别经过编码器得到em（d维）
  - 专家推理：三个专家（模态特有Um、冗余R、协同S）接收[em]并输出ze（d维），专家语义由扰动损失约束
  - 概念形成：对每个专家，通过ϕ+和ϕ-学习概念正负状态c+和c-，得到概念嵌入
  - 残差路径：每个专家还保留直接到任务预测的残差跳跃连接
  - 层次聚合：形态学概念嵌入进一步用于预测生物标志物概念
  - 最终预测：聚合所有专家输出（概念+残差）进行分类
- 关键模块/机制：
  - 模态编码器：将WSI patch和细胞图分别编码为固定维度的特征向量；WSI采用gated-attention MIL聚合，细胞图采用GraphSAGE消息传递+注意力池化
  - 交互感知专家路径：将多模态证据分解为模态特有、冗余和协同三类信号；定义E=M+2个专家（Um, R, S），每个专家接受所有模态嵌入，通过扰动损失强制语义：Um对自身模态敏感，R对单模态扰动不变，S对所有模态敏感
  - 概念形成模块：从每个专家的潜在表示中提取正/负概念状态；使用两个线性层ϕ+和ϕ-，经LeakyReLU激活，输出c+和c-，表示概念高/低证据
  - 残差路径：防止概念瓶颈导致的信息损失，保持高性能；每个专家内部，任务相关信号不仅通过概念嵌入传播，还通过残差连接直接流向最终预测
  - 层次概念推理：建立形态学概念到生物标志物概念的依赖关系；形态学概念嵌入被用作输入来预测生物标志物概念，反映临床中组织学先于分子标记的逻辑
- 公式/目标函数/指标定义：
  - 扰动损失：L_int = Σ_m s_me D_KL(p_clean_e || p_me)，其中s_me在专家敏感时取-1，不敏感时取+1
  - 概念状态计算：c+_{e,k}=LeakyReLU(ϕ+_{e,k}(ze)), c-_{e,k}=LeakyReLU(ϕ-_{e,k}(ze))
  - 总损失：L_total = L_cls + λ_1 L_concept + λ_2 L_int（分类损失+概念预测损失+扰动损失，具体λ未明确给出）
- 算法细节：
  - 模态编码器输出em后，拼接[e1;...;eM]送入每个专家
  - 专家内部结构：ze = fe([e1;e2])，然后通过概念形成层产生c+和c-，概念嵌入与残差路径拼接
  - 专家输出聚合方式未显式指定，可能通过注意力或简单求和，原文未提供细节
  - 层次概念：形态学概念预测后，将其嵌入与专家特征结合预测生物标志物概念
  - 最终分类：聚合所有专家输出（概念嵌入+残差）经全连接层得到类别logits
- 训练/推理细节：
  - 训练目标包括分类损失、概念预测损失和扰动损失，多任务联合优化
  - 概念标注来自病理报告和生物标志物，形态学概念为软序数目标，生物标志物概念为二元目标
  - 使用小批量随机优化，学习率等超参数参见附录
  - 推理时，模型输出概念预测和最终分类结果，并可通过专家权重和概念激活提供归因

### 5. VitalAgent: A Tool-Augmented Agent for Reactive and Proactive Physiological Monitoring over Wearable Health Data
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29483v1
- 方法流程：
  - 反应式模式：用户查询 → LLM规划器根据查询和内存选择工具 → 从生理内存检索相关信号 → 工具执行分析（如心率计算、AF检测） → 证据验证（四维度） → 若验证失败则重规划 → 生成证据支撑的回答
  - 主动式模式：流式ECG/PPG信号按10秒非重叠窗口处理 → 信号分析工具提取心率、HRV等 → 健康状态跟踪器更新 → 警报检测（极端心动过缓/过速、持续心动过速） → 每20个窗口执行LLM自动检测以减少漏报 → 触发警报则存储到内存并输出警报
- 关键模块/机制：
  - 生理内存 (Physiological Memory)：存储和管理纵向生理数据及历史警报；维护紧凑的时间记忆Mt = (x<t, s<t, e<t)，其中x<t为原始ECG/PPG信号窗口历史，s<t为从先前窗口更新的健康状态（心率、HRV、信号质量、节律标签等），e<t为历史主动警报记录。更新规则：Mt+1 = f_update(Mt, xt, st, et)。
  - 统一推理层 (Unified Reasoning Layer)：负责任务规划、工具选择和响应生成；包含三个组件：LLM规划器（根据查询或监控上下文选择工具）、证据验证模块（检查计划完整性、工具成功率、输出字段存在性、跨工具一致性）、LLM响应生成器（基于已验证的工具输出生成最终答案或警报）。
  - 结构化工具接口 (Structured Tool Interface)：提供模块化生理分析和数据访问功能；29个工具分为5类：信号分析（13个，如analyze_heart_rate、ecg_diagnosis）、数据处理（3个，如analyze_icentia11k_ecg_window）、记录查找（6个，如get_ecg_metadata、get_ppg_description）、主动上下文（5个，如get_recent_alerts、explain_last_alert）、医学知识（2个，如retrieve_medical_info_search）。每个工具返回结构化证据（含data、metadata、state、evidence等字段）。
- 公式/目标函数/指标定义：
  - 内存更新：Mt+1 = f_update(Mt, xt, st, et)
  - 主动监测警报条件：极端心动过缓、极端心动过速、持续心动过速（具体阈值未给出）
  - 反应式问答性能提升：相比ReAct基线提升超过30%
- 算法细节：
  - 工具选择：LLM根据用户查询和当前内存内容生成工具调用序列，支持动态规划和预定义工具集
  - 证据验证四维度：1）计划完整性：所有规划步骤是否返回结果；2）工具成功：每个工具是否执行正确；3）输出字段：检查data、metadata等是否齐全；4）跨工具一致性：不同工具结果是否冲突（如心率估计、节律评估）
  - 重规划：若验证失败，以原始查询、原计划、验证反馈和工具模式重新提示LLM，生成新计划
  - 主动模式窗口处理：固定长度10秒非重叠窗口，信号分析工具逐窗口提取测量值
  - 自动警报检测：每20个窗口调用LLM检测所有窗口，以降低漏检
  - 警报存储：触发警报时，将窗口时间、触发规则和解释存入内存，供后续查询引用

### 6. Why Specialist Models Still Matter: A Heterogeneous Multi-Agent Paradigm for Medical Artificial Intelligence
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29744v1
- 方法流程：
  - 输入患者病例C={V, I}，其中V为临床信息（年龄、性别、病史、症状等），I为多模态检查数据（影像、生理信号等）。
  - 协调者O解析病例，根据模态注册表激活相应的专业智能体，并将各模态数据Ii分发给对应的专业智能体Awi。
  - 专业智能体Awi对指定模态数据执行分析，输出发现Fi和置信度ci∈[0,1]。
  - 冲突检测模块计算每个专家发现Fi与其他所有专家发现的平均相似度，得到分歧度δi = 1 - (1/(K-1))∑_{j≠i} sim(Fi, Fj)。
  - 证据加权模块用softmax融合log置信度和log(1-分歧度)计算权重wi = softmax(log ci + log(1-δi))，然后加权求和得到融合证据E_fused = ∑ wi Fi。
  - 推理智能体Ar将融合证据E_fused与临床信息V结合，生成初步决策D_pre以及推理链R = {s1,...,sm}。
  - 不确定性量化模块计算总体不确定性U(D) = (U_conf + U_conflict + U_coherence)/3，U_conf基于置信度，U_conflict基于加权分歧，U_coherence基于推理链内部一致性。
  - 升级门控比较U(D)与自适应阈值θ：若U(D) ≤ θ则自动输出决策D_final = D_pre；否则将D_pre转至临床医生AP进行人工审查，临床医生修改或确认后输出最终决策D_final。
- 关键模块/机制：
  - 冲突检测模块：检测各专业智能体输出发现之间的不一致程度；对于K个专业智能体，将每个发现Fi与其他所有发现两两计算相似度（如余弦相似度或语义相似度），取平均后从1减去得到分歧度δi = 1 - (1/(K-1))∑_{j≠i} sim(Fi, Fj)。δi越大表示该专家与其他专家分歧越大。
  - 证据加权融合模块：基于置信度和分歧度自适应融合多个专业智能体的发现；首先将每个专家的置信度ci和1-分歧度(1-δi)取对数相加，然后通过softmax归一化得到权重wi = softmax(log ci + log(1-δi))。最终融合证据为加权和E_fused = ∑ wi Fi。
  - 不确定性量化模块：从三个维度量化决策的不确定性；三个维度：U_conf（低置信度，基于加权置信度缺失）、U_conflict（跨专家冲突，基于分歧度的加权和）、U_coherence（推理链不一致性，基于推理步骤间的语义连贯性）。总体不确定性U(D) = (U_conf + U_conflict + U_coherence)/3。
  - 升级门控：根据不确定性阈值决定是否将决策升级给临床医生；给定自适应阈值θ，若U(D) ≤ θ则自动输出初步决策，否则触发临床医生进行人工审查。
  - 自适应阈值校准模块：利用临床医生反馈在线调整阈值，优化自动与人工决策的平衡；若临床医生修改了决策（m=1），则θ ← θ + η(1-2m) = θ - η；若未修改（m=0），则θ ← θ + η。η为小步长，通过反馈逐步校准阈值。
  - 记忆模块：存储交互历史、模态注册表和活跃任务，支持智能体间的信息共享；维护交互历史H（时间戳、发送者、消息）、模态注册表L（标记各模态是否存在）、临床决策任务列表D。供协调者和推理智能体查询。
- 公式/目标函数/指标定义：
  - 冲突度量：δ_i = 1 - (1/(K-1))∑_{j≠i} sim(F_i, F_j)
  - 证据权重：w_i = softmax(log c_i + log(1-δ_i))
  - 融合证据：E_fused = ∑ w_i F_i
  - 总体不确定性：U(D) = (1/3)(U_conf + U_conflict + U_coherence)
  - 阈值校准：θ ← θ + η(1-2m)，m∈{0,1}，m=1表示临床医生修改了决策
- 算法细节：
  - 1. 协调者根据病例多模态标签激活对应专业模型，每个专业模型独立生成文本化发现。
  - 2. 冲突检测：对每对发现计算相似度，可采用编码器将文本映射为向量后计算余弦相似度。
  - 3. 证据加权：使用softmax将log置信度与log(1-分歧度)融合，确保高置信度且低分歧的专家获得高权重。
  - 4. 不确定性量化：U_conf = 1 - 加权平均置信度；U_conflict = 加权平均分歧度；U_coherence = 1 - 推理链中相邻步骤间的平均语义相似度。
  - 5. 门控：采用初始阈值θ0（如0.5），在推理过程中动态比较U(D)与当前θ。
  - 6. 临床医生审查流程：查看初步决策、推理链和不确定性分解，选择修改或确认，修改后决策作为最终输出。
  - 7. 阈值在线更新：每轮临床医生反馈后，根据是否修改决策调整θ，使阈值逐渐适应临床偏好。
- 训练/推理细节：
  - 专业智能体（如CNN、Transformer）在各自任务上预训练，直接使用预训练权重，不针对HetMedAgent框架额外训练。
  - 通用LLM使用预训练模型（如GPT、Claude），无需在医疗数据上微调，推理时通过提示工程指导其执行协调和推理角色。
  - 整个框架是推理级的，无需端到端训练；仅阈值θ在推理过程中通过临床反馈在线更新。
  - 推理时，专业模型输出被转成文本化发现，供LLM理解；LLM通过角色提示（协调者/推理者）完成不同功能。
  - 临床医生参与推理循环，其反馈仅用于阈值校准，不用于模型参数更新。

### 9. Normal Guidance is what Attention Needs
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.27306v1
- 方法流程：
  - 输入：3D CT扫描，每个2D切片作为实例，包级二分类标签（弱监督）
  - 编码器：使用预训练CNN（如ResNet）提取每个切片的嵌入向量h_ij
  - 注意力池化：采用ABMIL或Transformer-based MIL计算每个切片的注意力权重a_ij，加权聚合得到包级嵌入z_i
  - 分类：线性分类器g(·)输出包级预测概率ŷ_i
  - 正则化损失计算：对每个包，计算注意力权重的经验均值E[J]和方差Var(J)，构造正态参考分布r_i，计算散度D(r_i, a_i)
  - 总损失：L = 平均BCE损失 + λ * 平均散度D，通过反向传播更新参数
- 关键模块/机制：
  - Guided Attention框架：定义正则化目标，将注意力权重约束到参考分布；损失函数L_Guided = (1/N) Σ BCE(y_i, ŷ_i) + λ D(r_i, a_i)，其中D为散度，λ控制正则化强度。参考分布r_i通过Normal Guidance构造。
  - Normal Guidance参考分布构造：根据当前注意力权重动态生成正态先验；计算经验均值E[J] = Σ_j j·a_ij，方差Var(J) = Σ_j j²·a_ij - (E[J])²。生成离散正态PDF并归一化得到r_ij ∝ NormPDF(j|E[J], Var(J))，使用stop-gradient防止r_i受梯度影响。
  - 散度选择器：提供三种散度以正则化注意力分布；平方误差（对称，均值-seeking）、前向KL（模式覆盖，零避免）、反向KL（模式追求，零强制）。论文实验主要使用平方误差。
- 公式/目标函数/指标定义：
  - L_Guided = (1/N) Σ_i BCE(y_i, ŷ_i) + λ * D(r_i, a_i)
  - 经验均值 E[J] = Σ_j j · a_ij
  - 经验方差 Var(J) = Σ_j j² · a_ij - (E[J])²
  - 参考分布 r_ij = NormPDF(j|E[J], Var(J)) / Σ_k NormPDF(k|E[J], Var(J))
  - 平方误差 D(r, a) = Σ_j (r_j - a_j)²
  - 前向KL D_KL(r||a) = Σ_j r_j log(r_j / a_j)
- 算法细节：
  - 每个训练step：前向传播计算注意力权重a_i，然后计算经验统计量E[J]和Var(J)，构造参考分布r_i（使用stop-gradient），计算散度D，总损失反向传播。
  - 注意力权重计算采用标准ABMIL（gating注意力）或Transformer（多实例自注意力），与Normal Guidance解耦。
  - 正则化应用于所有包（正负样本），不依赖包标签。
  - 超参数λ通过验证集调整，论文在{0.01, 0.1, 1.0, 10.0}中选择。
- 训练/推理细节：
  - 训练仅使用扫描级标签（弱监督），切片级标签仅用于评估定位。
  - 编码器使用ImageNet预训练且冻结，仅训练注意力模块和分类器。
  - 正则化超参数λ在验证集上基于扫描级分类性能选择。
  - 推理时直接使用学习到的注意力权重a_ij进行切片级定位（通过阈值或直接作为概率）。

### 10. Not All NVFP4 QAT Recipes Are Equal: How Architecture and Scale Shape Model Quality for Anomaly Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.27616v1
- 方法流程：
  - 输入：脑MRI切片（LGG数据集，110患者，3929张图像，34.9%阳性），患者级划分为80/10/10训练/验证/测试集。
  - 预处理：训练时Resize至256×256，水平/垂直翻转，亮度-对比度调整，平移-缩放-旋转，ImageNet归一化；验证/测试仅Resize和归一化。
  - 模型：选取三种架构（CNN、ViT、Swin）在三个匹配参数规模（见表1），CNN采用编码器-解码器+跳跃连接，ViT采用标准Transformer+16×16分块+可学习位置编码，Swin采用窗口注意力+移位窗口+转置卷积解码器。
  - 量化：对指定线性层应用NVFP4量化（E2M1），使用两级缩放（per-tensor FP32缩放，per-block FP8 E4M3缩放，块大小16元素）。
  - 训练：使用BCE+Tversky损失（α=0.3, β=0.7），ReduceLROnPlateau调度器（factor=0.5, patience=10），早停（patience=20, warmup=40），优化器按架构选择（CNN: Adamax lr=5e-4; ViT: Adamax/AdamW lr=5e-4(Adamax)/1e-4(AdamW); Swin: AdamW lr=1e-4, weight decay=1e-4）。
  - 输出：像素级异常概率，评估指标为AUPRC（基于最佳验证损失检查点）。
- 关键模块/机制：
  - NVFP4量化格式：实现4位浮点表示，两级缩放减少量化误差。；每个值用E2M1表示（1符号位，2指数位，1尾数位，离散值从-6到6）。全精度张量X先经per-tensor缩放St = max|X|, X1 = X/St；再按连续16元素微块进行per-block缩放Sb = max|X1,b|, qb = FP4(X1/Sb)。反量化：X̂b ≈ BF16(qb) * Sb * St。St为FP32，Sb为FP8 E4M3。
  - 2D块缩放（2D block-scaling）：改进权重量化，使正反向传播使用相同块边界，降低不一致性。；将权重量化的块从1×16（沿行）替换为16×16二维块，使得前向Q(W)和反向Q(W⊤)的量化块对齐，减少因转置导致的量化误差。
  - 随机Hadamard变换（RHT）：在WGRAD路径中对激活和梯度施加随机正交旋转，重新分布块级极值能量，避免单一值主导块缩放。；在量化前，对梯度（或输入）应用随机化的Hadamard矩阵，使能量均匀化，减少块内离群影响。在公式(3)中，对G⊤先应用RHT再量化。
  - 随机舍入（Stochastic Rounding, SR）：替代确定性舍入（round-to-nearest），消除小梯度更新被置零的系统偏差。；对上游梯度进行概率性舍入：以概率p将值向上或向下舍入，期望值等于原始值，避免截断误差累积。在公式(2)和(3)中，QSR表示带有随机舍入的量化。
  - 链式规则重用（Chain Rule）：在反向传播中重用前向已经量化的Q(X)和Q(W)，使梯度反映真实量化噪声。；与独立重新量化不同，Chain Rule在反向传播中使用前向保存的量化值，保证正反向一致，有助于QAT补偿量化误差。
- 公式/目标函数/指标定义：
  - NVFP4量化：L1: St = max|X|, X1 = X/St; L2: Sb = max|X1,b|, qb = FP4(X1/Sb); 反量化: X̂b ≈ BF16(qb)·Sb·St
  - 前向传播（含2D+RHT+SR）：Y_BF16 = X̂_FP4 · Ŵ_FP4^2D (1)
  - 激活梯度（DG）：(∂L/∂X)_BF16 = QSR(G)_FP4 · (Ŵ_FP4^2D)^⊤ (2)
  - 权重梯度（WG）：(∂L/∂W)_BF16 = QSR(RHT(G⊤))_FP4 · Q(RHT(X⊤))_FP4 (3)
  - 训练损失：L_train = BCE(ŷ, y) + 1 - TP_s / (TP_s + α FP_s + β FN_s)，其中α=0.3, β=0.7, TP_s=Σŷy, FP_s=Σŷ(1-y), FN_s=Σ(1-ŷ)y，BCE为二元交叉熵，Tversky项偏重召回（惩罚假阴性2.3倍于假阳性）
  - 评估指标：AUPRC（Precision-Recall曲线下面积），阈值无关，对类别不平衡更敏感。
- 算法细节：

### 17. X-Edit: Exact, Explicit, and Explainable Null-Space Editing for Medical Vision Transformers
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.24932v1
- 方法流程：
  - 输入：预训练ViT模型fθ，待修正错误样本集Dedit，锚定样本集Danchor（正确预测样本）。
  - 阶段1：因果追踪定位影响层。对每个错误样本生成噪声扰动版本，通过三次前向传播计算各层的间接效应（IE），选取IE最高的top-k层作为目标层l*。
  - 阶段2：零空间构建。提取锚定样本在目标层MLP块的输入激活（[CLS] token），组成键矩阵K0∈R^{d_in×K}，计算协方差矩阵K0K0^T，SVD分解后保留零特征值对应的特征向量构成投影矩阵P。
  - 阶段3：闭式编辑。提取错误样本在目标层的输入激活K1，通过少量优化步骤得到目标值V1，根据公式(5)计算最优ΔW*，更新权重W_new=W+ΔW*P。
  - 输出：编辑后的模型f_{θ+Δθ}，正确分类Dedit且锚定样本输出不变。
- 关键模块/机制：
  - 因果追踪层定位模块：定位ViT中与特定错误预测相关的关键MLP层，提供精准编辑目标；对每个错误样本：1) 在patch embedding注入高斯噪声得到x_corrupt；2) 三次前向传播：干净运行缓存各层隐藏状态h^clean_l，损坏运行计算基线概率，恢复运行在特定层恢复干净MLP激活；3) 计算间接效应IE = p_correct(restored) - p_correct(corrupted)，选取IE最高的top-k层（默认k=3）作为目标层l*。
  - 零空间投影矩阵构建模块：从锚定样本的输入激活构造正交投影矩阵，确保参数更新不改变锚定样本的输出；提取Danchor中所有样本在目标层MLP块的[CLS] token输入激活，堆叠为K0∈R^{d_in×K}，计算协方差矩阵C=K0K0^T∈R^{d_in×d_in}；对C进行SVD分解：UΛU^T；滤除特征值大于阈值（10^{-2}）的特征向量，剩余零特征向量构成Û；投影矩阵P=ÛÛ^T。
  - 闭式参数更新模块：直接计算满足零空间约束的最优参数扰动ΔW*，无需迭代优化；输入错误样本激活K1，通过少量优化步骤（5次迭代，lr=0.1）得到目标值V1；定义残差R=V1-WK1；累积先前编辑样本键矩阵Kp；计算ΔW*=R K1^T P (Kp Kp^T P + K1 K1^T P + I)^{-1}；更新W_new=W+ΔW*P。
- 公式/目标函数/指标定义：
  - 目标函数：min_{ΔW} ∥(W+ΔW P)K1 - V1∥^2 + ∥ΔW P Kp∥^2 + ∥ΔW P∥^2
  - 约束：f_{θ+Δθ}(xa) = fθ(xa), ∀(xa,ya)∈Danchor
  - 闭式解：ΔW* = R K1^T P (Kp Kp^T P + K1 K1^T P + I)^{-1}
  - 间接效应（IE）：p_correct(restored) - p_correct(corrupted)
  - Drop Per Edit (DPE): max(0, ΔACC / N_corrected)
- 算法细节：
  - 因果追踪使用32次噪声注入（σ=0.1）计算平均IE
  - 零空间构建基于协方差矩阵的SVD，过滤特征值阈值10^{-2}
  - 锚定集默认500个样本
  - 目标值V1通过5次梯度优化（lr=0.1）从错误样本隐藏表示中优化得到
  - 顺序编辑时，累积所有历史编辑样本的键矩阵Kp，在闭式解中通过KpKp^T项防止覆盖
  - 投影矩阵P仅依赖于协方差矩阵，编辑阶段无需原始锚定图像，支持隐私保护
- 训练/推理细节：
  - 编辑阶段无训练，仅计算闭式解，无需梯度反向传播
  - 因果追踪和零空间构建在编辑前一次性完成
  - 每个错误样本的编辑时间在0.18-1.31秒（GPU RTX 3090）
  - 锚定集来自训练集，不参与编辑过程的梯度计算
  - 对比基线（FineTune等）使用Adam优化10个epoch

### 18. Context-driven Missing-Modality Learning for Robust Medical Diagnosis with Image-Tabular Data
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.25968v1
- 方法流程：
  - 输入：多模态数据（图像和表格），每个模态通过特定编码器提取token序列。训练时应用随机模态dropout模拟缺失。
  - CMC模块：CRTA接收可用模态token和可学习的上下文令牌，通过级联残差Transformer输出缺失模态的基表示；然后从模态特定记忆库检索细节，与基表示融合得到增强的合成表示。
  - ICAR模块：首先将上下文令牌与输出的多模态表示融合，生成实例自适应语义参考；然后利用模态特定交叉注意力将各模态表示（可用与合成）对齐到参考引导的统一空间。
  - CDR阶段：在统一空间上应用类别感知对比学习，拉近同类样本、推开异类样本，输出最终多模态表示用于分类。
  - 输出：分类结果。
- 关键模块/机制：
  - Cascade Residual Transformer-based Autoencoder (CRTA)：利用上下文令牌捕获模态间依赖，合成缺失模态的基表示。；CRTA由多个级联的残差Transformer块组成。输入包括可用模态的token和一组可学习的上下文令牌（作为数据集级语义先验）。通过自注意力和交叉注意力，上下文令牌从可用模态中聚合信息，逐步重建缺失模态的表示。残差连接保证信息流。输出为缺失模态的基表示。
  - 模态特定记忆库 (Modality-specific Memory Banks)：存储各模态的典型特征原型，用于增强合成表示中的模态细节。；每个模态对应一个记忆库，存储训练过程中积累的模态特定原型向量。对于合成的缺失模态基表示，通过检索机制（如最近邻）从相应记忆库中获取最相关的原型，并与基表示融合（如加法或拼接），得到增强后的合成表示。记忆库在训练中动态更新。
  - Instance-adaptive Context-guided Multimodal Alignment (ICMA)：将上下文令牌转化为实例自适应语义参考，引导所有模态表示对齐到统一空间。；从CRTA输出的多模态表示被注入到原始的上下文令牌中，使之携带当前实例的语义，得到实例自适应参考。随后，每个模态的表示（原始可用和增强后的合成表示）分别通过模态特定交叉注意力与该参考交互，投影到参考所在的统一语义空间，从而消除模态间的分布偏移。
  - Class-aware Discriminative Refinement (CDR)：通过对比学习进一步增强统一空间中表示的类别可分性。；在统一空间上应用监督对比损失：以类别标签为正负样本依据，拉近相同类别样本的表示，推开不同类别样本的表示。这有助于提取更区分性的诊断线索。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 训练时采用随机模态dropout：每个批次以一定概率随机丢弃部分模态，促使模型学习任意缺失模式。
  - 记忆库检索：对每个合成基表示，计算其与记忆库中原型的余弦相似度，选取相似度最高的k个原型进行加权融合。
  - 记忆库更新：使用动量更新或队列机制，将当前批次中完整模态的表示入队并替换最旧元素。
  - 交叉注意力对齐：每个模态的表示作为query，实例自适应参考作为key和value，通过交叉注意力得到对齐后的表示。
  - 对比学习：使用NT-Xent损失或其变体，计算类别感知对比损失，结合交叉熵损失联合优化。
- 训练/推理细节：
  - 训练时所有模态均可用，但通过随机dropout模拟缺失，使模型学习鲁棒合成与对齐。
  - 推理时根据实际缺失模态，只处理可用模态，CMC模块生成缺失模态表示，ICAR模块对齐后分类。
  - 损失函数包括：合成表示的重建损失（与真实表示之间的均方误差或余弦相似度）、分类交叉熵损失、对比损失。

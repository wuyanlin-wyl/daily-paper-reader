## 摘要
可穿戴设备能够持续监测心电图（ECG）和光电容积脉搏波（PPG）等生理信号，但现有的移动健康系统大多局限于特定任务的预测流水线或对静态摘要的反应式问答。它们缺乏支持时间推理、持续生理上下文以及对长期信号流进行主动监测的能力。我们提出了VitalAgent，一种基于ECG/PPG的移动健康工具增强型智能体框架，同时支持反应式问答和主动监测。VitalAgent构建于纵向生理记忆和工具增强的推理接口之上，能够对原始信号进行动态计算。我们还引入了VitalBench，一个纵向生理监测基准数据集，包含用于反应式问答的1,862个问答对和用于主动监测的90.2小时连续ECG/PPG记录，涵盖心脏、体力活动和压力相关任务。实验表明，VitalAgent在反应式评估中相比基于提示和ReAct的基线实现了超过30%的提升，并支持对长期生理信号的主动警报监测，突显了动态工具使用和长期生理监测的重要性。

## Abstract
Wearable devices enable continuous monitoring of physiological signals such as ECG and PPG, but existing mHealth systems are largely limited to task-specific prediction pipelines or reactive question answering over static summaries. They lack the ability to support temporal reasoning, persistent physiological context, and proactive monitoring over long-term signal streams. We propose VitalAgent, a tool-augmented agentic framework for ECG/PPG-based mHealth that supports both reactive question answering and proactive monitoring. VitalAgent is built on a longitudinal physiological memory and a tool-augmented reasoning interface that enables dynamic computation over raw signals. We further introduce VitalBench, a longitudinal physiological monitoring benchmark dataset comprising 1,862 QA pairs for reactive question answering and 90.2 hours of continuous ECG/PPG recordings for proactive monitoring, covering cardiac, physical activity, and stress-related tasks. Experiments demonstrate that VitalAgent achieves over 30% improvement over prompt-based and ReAct baselines in reactive evaluation and supports proactive alert monitoring over long-term physiological signals, highlighting the importance of dynamic tool use and long-term physiological monitoring.

- **核心问题**：现有移动健康（mHealth）系统主要依赖任务特定的预测流水线或对静态摘要的反应式问答，缺乏对长期生理信号的时间推理、持续上下文感知以及主动监测能力。用户询问“我的静息心率最近升高了吗？”或“睡眠不好后恢复变差了吗？”等自然语言问题时，现有系统无法动态检索、时间比较和聚合纵向生理历史。

- **整体含义**：该研究旨在开发一个统一的智能体框架，将工具增强的动态推理与持续的生理记忆相结合，同时支持反应式问答（用户发起）和主动式监测（系统自主警报），填补可穿戴健康数据分析与自然语言交互之间的鸿沟。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：基于LLM的智能体系统，通过共享的生理记忆、推理层和工具注册表，实现对原始ECG/PPG信号的按需计算和长期状态跟踪。

- **关键技术细节**：
    - **生理记忆（Physiological Memory）**：维护一个时间索引的记忆 $M_t = (x_{<t}, s_{<t}, e_{<t})$，其中 $x_{<t}$ 是原始信号窗口历史，$s_{<t}$ 是从信号中推导的连续健康状态（心率、HRV、节奏标签等），$e_{<t}$ 是之前的主动警报记录。记忆随着新窗口、新状态和新警报持续更新：$M_{t+1} = f_{update}(M_t, x_t, s_t, e_t)$。
    - **统一推理层**：包含LLM规划器（选择工具）、证据验证模块（四维度：计划完整性、工具成功、输出字段、交叉工具一致性）和响应生成器。若验证失败则重新规划。
    - **工具接口**：共29个工具，分为5类：
        - 信号分析工具（13个）：直接在原始窗口上进行确定性计算（心率、HRV、节奏不规则性、信号质量等）。
        - 数据集特定工具（3个）：处理不同格式、采样率和窗口长度。
        - 记录查找工具（6个）：枚举记录、获取元数据和人类可读描述。
        - 主动上下文工具（5个）：检索缓存的主动警报记录、摘要、解释。
        - 外部知识工具（2个）：接入MedlinePlus和PubMed获取医学知识。
    - **设计原则**：动态工具调用而非静态预计算，将信号处理与语言推理解耦，提高鲁棒性和可解释性。

- **算法流程（文字描述）**：
    - **反应式模式**：用户查询 $q$ → LLM规划器根据查询和记忆选择工具 → 工具检索相关信号窗口，执行查询特定分析，返回结构化证据 → 验证证据（若失败则重新规划） → 生成证据支持的回答。
    - **主动式模式**：10秒非重叠窗口流入 → 信号分析工具提取测量值 → 基于规则检测（极端心动过缓/过速、持续性心动过速）生成警报 → 每20个窗口增加一次LLM判断（减少漏报） → 警报存储到记忆。

## 6. 主要结论与发现

- **反应式性能**：VitalAgent在无泄漏设置下Tier A准确率0.860，Tier B 0.557，相比最强基线LifeAgent分别提升31.5%和25.7%。尤其在Tier B查询类问题（如长期聚合）上，其他基线全部失败，VitalAgent达到0.443。
- **工具动态选择的重要性**：消融实验显示，移除规划器（随机选择工具）导致Tier A准确率从0.860降至0.701，Tier B从0.557降至0.342。
- **主动监测性能**：规则+LLM法官配置将中位警报延迟从220秒降至105秒，但误报率从1.81/h升至2.95/h，体现灵敏度和特异性权衡。
- **AF分类**：每窗口AF检测准确率66.7%（灵敏度75.5%），ECG和PPG上一致。
- **关键发现**：动态工具调用和长期生理上下文是提升mHealth推理可靠性的核心因素。

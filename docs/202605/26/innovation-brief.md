### 3. Parameter-Efficient VLMs for Gastrointestinal Endoscopy: Medical Image Generation and Clinical Visual Question Answering

- 方法流程：
  - VQA流水线：输入胃肠内镜图像和自然语言问题 -> Florence-2模型（经PEFT微调，仅更新少量适配参数） -> 输出答案文本。

  - LoRA（低秩适应）：对Stable Diffusion 2.1的交叉注意力层权重W，分解为W = W0 + BA，其中B∈R^(d×r), A∈R^(r×k)，r=4为超参数，固定W0，仅优化BA。

  - 私有数据集上的微调结果始终优于公共数据集。

### 4. Universal Boosts, Specific Suppressors: Sparse Autoencoder Steering of Medical Vision-Language Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.24977v1
- 方法流程：
  - 训练阶段：在预训练医学VLM的晚层隐藏状态上训练Top-K稀疏自编码器，提取稀疏特征。
  - 因果干预方向提取：通过对比正确报告与错误报告的隐藏状态差异，识别出与临床错误相关的特征方向，分为boost（提升正确）和suppress（抑制错误）方向集。
  - 推理阶段干预：对于每个生成token，通过SAE得到其特征向量，根据预设的boost/suppress方向调整特征值（boost方向增加，suppress方向减小），然后通过SAE解码器重构残差，加到原始隐藏状态上，指导后续生成。
- 关键模块/机制：
  - Top-K稀疏自编码器：将晚层隐藏状态分解为稀疏特征向量，用于因果干预；在模型最后一层或倒数第二层应用Top-K稀疏自编码器，仅保留激活值最大的K个神经元，其余置零，得到稀疏特征表示。
  - 因果干预方向提取：基于临床错误数据识别出应提升或抑制的特征方向；收集模型生成报告中的错误案例（如幻觉、遗漏等），对比正确报告与错误报告在相同token位置的SAE特征差异，统计出与错误相关的特征方向，分别归为boost（在正确报告中更活跃）或suppress（在错误报告中更活跃）。
  - 解码时boost/suppress组合干预：在推理时动态调整模型内部表征，减少幻觉；对每个生成token，先通过SAE编码得到稀疏特征，然后对属于boost方向的特征施加正向权重，对属于suppress方向的特征施加负向权重（或将其置零），再通过SAE解码器重构残差并加到原始隐藏表示上，以修正生成过程。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 逐token残差干预：设h为某token的晚层隐藏状态，经SAE编码得稀疏特征z = SAE_enc(h)。然后对z进行操纵：z' = z + α * boost_mask - β * suppress_mask，其中α,β为超参数。再将z'通过SAE解码器得残差r = SAE_dec(z')，最终隐藏状态h' = h + r，用于后续生成。

  - 推理时无梯度更新，仅通过残差调整，故计算开销较小。

### 6. EchoPilot: Training-Free Ultrasound Video Segmentation via Scale-Space Semantic Prompting and Reliability-Gated Memory

- 原文链接：https://arxiv.org/abs/2605.25944v1
- 方法流程：
  - 第一帧交互：用户提供单点点击和类别名称。
  - 语义定位：冻结的医学VLM接收类别名称和候选上下文视图，输出语义定位信息。
  - 尺度空间语义提示：使用S.E.E.D.准则从多尺度视图中选择最优上下文视图，然后利用VFM提取的密集几何特征合成辅助点提示。

- 关键模块/机制：
  - 尺度空间语义提示：解决初始帧分割的尺度歧义问题；通过参数免费的S.E.E.D.（语义能量熵密度）准则从不同尺度上下文视图中选择最优视图，然后利用VFM（如DINOv2）提取的密集几何特征自动合成具有几何精度的辅助点提示，无需额外用户交互。

  - S.E.E.D.准则基于语义能量和熵密度计算，选择最稳定和具有判别性的视图。
  - 辅助点提示合成：从VFM（如DINOv2）特征图中提取几何对应关系，在选定视图上自动生成额外的正/负点。

### 1. Towards Clinically Interpretable Ophthalmic VQA via Spatially-Grounded Lesion Evidence
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.22414v1
- 方法流程：
  - 阶段一：收集10,719张眼底图像，进行图像级精细病灶标注，得到15,595个病灶
  - 阶段二：使用ETDRS网格将病灶映射到9个标准化视网膜区域，确保解剖一致性和临床有效性
  - 阶段三：基于结构化病灶证据生成72,706个问题，涵盖开放、闭合、单选、多选四种格式
- 关键模块/机制：
  - ETDRS网格病灶定位模块：将图像级病灶标注转化为标准化空间区域，提供解剖位置信息；采用早期治疗糖尿病视网膜病变研究（ETDRS）网格，将视网膜分为9个临床区域（如中心凹、黄斑等），每个病灶被分配一个或多个区域标签
  - 多格式问题生成模块：基于病灶证据生成多样化问答对，覆盖不同临床查询形式；根据病灶类型、位置和数量，使用模板或规则生成open-ended、closed-ended、single-choice、multiple-choice问题
  - 病灶感知训练与推理模块：在微调中强制模型先输出结构化病灶证据再回答，提升可解释性；SFT w/ L设置中，模型需输出<response><lesion><type>...</type><location>...</location></lesion><answer>...</answer></response>格式，实现病灶类型和位置的显式预测
- 公式/目标函数/指标定义：
  - Answer Score: 多项选择、单项选择、闭合式问题使用Accuracy，开放式问题使用BLEU-1
  - Lesion Evidence Score: Lesion Type F1（病灶类型分类的F1分数）和Lesion Location F1（病灶位置区域预测的F1分数）
- 算法细节：
  - 使用正则表达式从模型输出中提取结构化信息（病灶类型、位置、答案）
  - ETDRS网格将病灶位置标准化到9个预定义视网膜区域，实现解剖位置对齐
  - 三种评估设置：Zero-shot（直接提示输出证据和答案）、SFT w/o L（仅微调输出答案）、SFT w/ L（微调输出结构化病灶证据和答案）
- 训练/推理细节：
  - SFT w/ L训练中，模型被要求先输出病灶类型和位置，再输出答案，形成推理链条
  - 推理时使用正则表达式解析<response>内部结构，分别评估答案正确性和病灶级推理
  - 零样本设置下对所有模型直接提示，使用相同解析方式提取信息

### 3. Parameter-Efficient VLMs for Gastrointestinal Endoscopy: Medical Image Generation and Clinical Visual Question Answering
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.24792v1
- 方法流程：
  - 数据准备：Kvasir-VQA数据集6500张图像，80/20训练验证分割，图像缩放到512×512，问题添加<MedVQA>前缀
  - VQA流水线：输入图像和问题→冻结DaViT视觉编码器提取多尺度视觉特征→BART文本编码器生成查询→交叉注意力机制融合视觉和文本特征→BART解码器自回归生成答案
  - 图像生成流水线：输入临床文本提示→随机噪声采样→CLIP文本编码器→LoRA适应的U-Net扩散模型→VAE解码器生成RGB图像
  - 训练交替进行：先训练VQA流水线（10轮），再训练图像生成流水线（5轮），分别优化各自适配器
- 关键模块/机制：
  - Florence-2 VQA模型：实现临床视觉问答，提供诊断支持；包含冻结的DaViT视觉编码器（层次Transformer提取多尺度视觉特征）和BART文本编码器/解码器（序列到序列框架）。问题前添加<MedVQA>标记激活领域特征。交叉注意力机制使模型根据问题内容关注图像特定区域。
  - LoRA适配的Stable Diffusion 2.1：生成隐私保护的高质量胃肠内镜合成图像，增强训练数据；在扩散模型的注意力层中插入低秩矩阵B和A（秩r=4），更新权重W=W0+BA。冻结预训练权重W0，仅训练B和A，参数从dk降至(d+k)r，降低约90%计算成本。使用增强提示如“clinical colonoscopy image”引导医学图像生成。
  - 交叉注意力机制：融合视觉特征和文本查询，实现空间推理；公式：Attention(Q,K,V)=softmax(QK^T/√dk)V，其中Q∈R^{T×dk}为文本查询嵌入，K,V∈R^{N×dk}为视觉键值嵌入。支持针对问题内容定位图像区域，进行空间推理、计数和分类。
- 公式/目标函数/指标定义：
  - 交叉注意力公式：Attention(Q,K,V)=softmax(QK^T/√dk)V
  - VQA损失函数：L_VQA = -∑_{t=1}^T log p_θ(a_t | a_{<t}, I, q)，其中a_t为第t个token，条件为图像I和问题q
  - LoRA权重更新：W = W0 + ∆W, ∆W = BA，其中W0∈R^{d×k}冻结，B∈R^{d×r}, A∈R^{r×k}可训练，r≪min(d,k)
- 算法细节：
  - VQA训练：每批输入图像I、问题q和答案a，通过冻结视觉编码器提取K和V，文本编码器生成Q，计算交叉注意力，解码生成答案，最小化交叉熵损失，更新VQA适配器参数
  - 图像生成训练：采样随机噪声z~N(0,I)，输入文本提示p，通过LoRA适配的U-Net扩散模型生成合成图像x，计算FBD（Fréchet BiomedCLIP Distance）作为损失，更新LoRA权重A和B
  - LoRA实现：仅更新注意力层中的低秩矩阵，秩r=4，保持大部分权重冻结
- 训练/推理细节：
  - VQA训练：优化器AdamW，学习率2×10^{-5}，权重衰减0.01，余弦调度，200预热步，10轮，批量大小2，梯度累积8，混合精度FP16
  - 图像生成训练：优化器AdamW，5轮（论文中未明确轮数，根据算法推断为5轮）
  - 推理：VQA流水线输入图像和问题直接生成答案；图像生成流水线输入文本提示和随机噪声生成合成图像

### 5. Towards Reliable Fetal Ultrasound Interpretation with Multi-Agent Collaboration
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25357v1
- 方法流程：
  - 输入：用户查询Q和超声图像I或视频V；Coordinator Agent分类查询类型τ∈{specific, general}并分配任务t
  - Analyst Agent解析Q和I为结构化上下文A，共享给下游代理
  - Expert Agents根据任务t调用相应视觉工具Sk，获取结构化证据（如平面分类、分割、测量）
  - 工具输出与代理分析存入检索增强证据库
  - 对于specific任务：DPEA综合多个LLM投票者推理和工具证据，输出最终答案
  - 对于general任务：Report Agent基于证据库和RAG知识生成报告/描述/摘要
- 关键模块/机制：
  - Coordinator Agent：中央调度器，路由查询并分配任务；接收输入(I, Q, V)，通过LLM判断查询类型（specific/general）并识别临床任务t，激活对应Expert Agent子集。
  - Analyst Agent：上下文解析，为后续代理提供结构化信息；将用户查询和图像解析为结构化的上下文表示A，包含关键解剖区域和问题意图，传递给所有下游代理。
  - Expert Agents：调用专用视觉工具获取可靠证据；每个Expert Agent负责调用一组相关视觉工具Sk（如平面分类器、分割模型、测量模型），输出结构化数据（如平面标签、分割掩膜、生物测量值）。
  - Dual-Path Evidence Arbitration (DPEA)：整合LLM协商推理与工具证据，提高决策可靠性；设置多个LLM投票者（如Elimination Reasoner, Uncertainty Reviewer等），每个投票者基于工具输出和证据库给出推理；通过多轮协商和投票机制得到最终判断，结合工具证据抑制幻觉。
  - Retrieval-Enhanced Evidence Bank：存储和检索中间证据，支持可追溯结论；将工具输出、代理分析、参考文本等转换为向量嵌入并索引；在生成阶段通过检索相关证据片段增强事实基础，减少幻觉。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 查询路由：LLM根据用户问题结构（是否有选项）和图像内容分类为specific或general
  - 任务分配：Coordinator从预定义任务集合中匹配最相关任务t，激活对应Expert Agent
  - 工具调用：Expert Agent通过API调用视觉工具，工具返回结构化结果（如类别、坐标、测量值）
  - 证据整合：所有中间结果存入证据库，支持后续检索和推理
  - DPEA仲裁：多个LLM投票者分别给出推理，通过多数投票或加权融合产生最终答案
  - 检索增强：报告生成时使用文本嵌入相似度检索证据库中相关片段，作为上下文输入LLM
- 训练/推理细节：

  - FetUS-VQA基准由专家标注构建，用于评估VQA性能

### 6. EchoPilot: Training-Free Ultrasound Video Segmentation via Scale-Space Semantic Prompting and Reliability-Gated Memory
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25944v1
- 方法流程：
  - 输入：单帧超声图像I0，用户点击p0和类别名称C。
  - 阶段一（t=0）：多尺度裁剪，冻结医学VLM提取语义相似度和空间属性图，S.E.E.D.准则选择最优尺度，获取边界框Bk*；在Bk*内用VFM（如DINO）计算以p0为锚点的密集余弦相似度图，通过NMS提取最多3个辅助点；输出精选提示集{p0, p1, p2, p3}。
  - 传递至提示视频分割器（如SAM2/MedSAM2）进行第一帧分割。
  - 阶段二（t>0）：对每帧，分割器生成掩码和内存编码特征；使用掩码平均池化提取目标描述符ft，与第一帧锚点f0计算余弦相似度；若大于阈值τ则写入内存，否则跳过。
  - 输出逐帧掩码。
- 关键模块/机制：
  - 尺度空间语义提示模块（Scale-Space Semantic Prompting）：解决初始化模糊性；对用户点击周围生成K个中心裁剪，尺度因子递减；用冻结医学VLM计算每个裁剪的语义相似度S_sem(k)，并通过反向传播获得文本条件空间属性图A_k；使用S.E.E.D.准则（S_sem * S_spa）选择最优裁剪，其中S_spa包含能量密度和归一化熵；然后从选定裁剪中提取边界框Bk*。
  - 视觉基础模型特征细化：生成几何精确的辅助点提示；使用冻结VFM（如DINO）提取密集特征，计算以用户点击p0为锚点的余弦相似度图M(x)；在Bk*内通过非极大值抑制（半径r）选取最多3个局部最大值作为辅助正点。
  - 可靠性门控记忆更新：减少传播漂移；对于每帧t，在分割器计算的内存编码特征图F_mem_t上，用预测掩码Mt进行掩码平均池化得到特征ft；计算ft与第一帧锚点f0的余弦相似度如果大于阈值τ则写入内存银行，否则跳过。
- 公式/目标函数/指标定义：
  - 公式(1): S_sem(k) = max(0, cos(E_img(C_k), E_txt(C)))
  - 公式(2): 空间属性图A_k通过反向传播语义相似度到VLM注意力层计算，结合通道权重和空间注意力权重。
  - 公式(3): S_spa(k) = 能量密度 * 归一化熵, 其中能量密度 = (1/Np) Σ_i A_k(i), 归一化熵 = - Σ_i P_k(i) log P_k(i) / log Np
  - 公式(4): 最优尺度 k* = argmax ( hat{S}_sem(k) * hat{S}_spa(k) )
  - 公式(5): M(x) = cos(G(p0), G(x))
  - 公式(6): f_t = ( Σ_x M_t(x) F_mem_t(x) ) / ( Σ_x M_t(x) + epsilon )
- 算法细节：
  - 多尺度裁剪：生成K个中心裁剪，尺度因子递减（如从1.0递减）。
  - VLM属性图：使用类似Chefer等的方法，从最后L层聚合。
  - S.E.E.D.计算：先归一化A_k为分布，计算能量密度（均值）和归一化熵，相乘。min-max归一化后结合S_sem。
  - VFM特征：使用预训练DINOv2等。
  - NMS半径r设为（例如）10像素。
  - 门控阈值τ设为（例如）0.85。
  - 记忆银行：SAM2/MedSAM2的固定大小记忆，通过门控决定是否写入。
- 训练/推理细节：
  - 训练-free框架，所有模型（医学VLM、VFM、视频分割器）均冻结。
  - 推理时无需微调。
  - 仅需用户第一帧单点点击和类别名称。
  - 视频分割器使用现成的SAM2或MedSAM2，不修改权重。

### 7. RAPTOR+: A Visually Grounded Vision-Language Framework to Improve Clinical Trust and Auditability in Automated Cancer Referral Processing
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25956v1
- 方法流程：
  - 输入阶段：接受紧急CRC转诊表单图像，标准化为1654×2339像素。
  - 提取引擎：多模态Transformer编码器-解码器，视觉Transformer提取图像块特征，通过交叉注意力与语言标记对齐，联合学习视觉、布局和语义。
  - 输出阶段：生成结构化JSON，每个字段值附带支持证据的边界框坐标。
- 关键模块/机制：
  - 输入阶段：接收并预处理转诊表单图像，确保输入标准化。；将图像缩放至1654×2339像素，边界框坐标归一化以便跨模型比较。
  - 提取引擎：核心处理模块，联合建模视觉与文本信息。；采用多模态Transformer，视觉部分使用Vision Transformer处理图像块，文本部分处理语言标记，通过交叉注意力层融合两种模态，学习整体文档理解。
  - 输出阶段：生成结构化JSON输出。；每个临床字段输出一个值和一个边界框，边界框采用模型原生坐标后归一化，实现可追溯的视觉证据。
  - 视觉接地路径：提供可验证的证据链接。；通过交叉注意力学习，将提取的字段值直接映射回原始文档中的区域，实现端到端的证据定位。
- 公式/目标函数/指标定义：
  - 训练损失：交叉熵损失（值预测）+ 坐标回归损失。
  - Normalized Match (NM)：语义正确性指标，对预测值进行规范化后与真实值比较。
  - Evidence Precision (EP)：预测边界框与任何真实证据区域重叠的比例。
  - Strict Safety：预测边界框与真实边界框的IoU ≥ 0.5。
  - Audit Precision：预测边界框与真实边界框的IoP ≥ 0.5。
- 算法细节：
  - 视觉Transformer将图像分割为固定大小的块，通过线性投影和位置编码生成视觉特征序列。
  - 交叉注意力层将视觉特征作为键/值，语言标记作为查询，实现视觉-语言对齐。
  - 模型自回归生成包含字段值和边界框坐标的JSON字符串。
  - 边界框坐标以模型原生格式输出，后通过归一化转为标准坐标。
- 训练/推理细节：
  - 微调采用监督学习，训练数据为176张配对图像和结构化JSON（包含字段值和边界框）。
  - 损失函数为交叉熵损失（值预测）和坐标回归损失之和。
  - 所有模型（零样本和微调）使用相同的提示，要求输出单一JSON对象，每个字段一个边界框。
  - 测试集为47张独立表单，图像模板和病例场景不重叠。

### 8. MedFM-Robust: Benchmarking Robustness of Medical Foundation Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.19027v3
- 方法流程：
  - 输入干净医学图像（八种模态）
  - 应用模态自适应扰动：先施加12种基础扰动（噪声、退化、几何），再叠加28种医疗特定扰动（如CT金属伪影、MRI偏场、超声声影等）

### 14. ImPartial: Multi-channel Whole-Cell Segmentation using Partial Annotations
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.24128v1
- 方法流程：
  - 1. 输入：多通道噪声图像和稀疏涂鸦标注（前景与背景线条）。
  - 2. 预处理：从N对图像-涂鸦中采样B个128×128的patch，生成盲点版本（随机替换20%像素为邻域值）。
  - 3. 网络：U-Net输出成分掩码ρ_m (W×H×M)和成分统计τ_m (W×H×M×Z，Z=1为均值)。
  - 4. 损失计算：对盲点像素计算混合重建损失L_mix（公式1）；对涂鸦像素计算类平衡分割损失L_seg（公式2）。
  - 5. 联合优化：最小化(1-λ)L_seg + λL_mix（公式3）。
  - 6. 输出：推理时直接使用网络输出的成分掩码求和得到每个类别的概率图，然后进行后处理得到分割结果。
- 关键模块/机制：

  - 高斯混合重建损失（Gaussian Mixture Reconstruction Loss）：通过量化重建提供自监督信号，引导成分掩码学习有意义的聚类。；假设像素强度服从M个固定方差高斯分布（M=4，即2个前景+2个背景成分）。网络输出每个像素属于各成分的概率ρ_m(·)和成分均值τ_m(·)。对盲点像素计算负对数似然：∑_m ρ_m ln p(x_i|τ_m)，其中p为高斯PDF。
  - 涂鸦分割损失（Scribble Segmentation Loss）：利用稀疏涂鸦标注提供类别监督，约束成分掩码的语义一致性。；对每个类别k∈{0,1}，仅对涂鸦标注的像素计算损失：对背景类（k=0）和对前景类（k=1），分别取对应成分掩码的和，计算负对数概率，并除以该类标注像素数实现类平衡。
  - 多通道扩展：处理多通道图像（如多重染色），保持联合损失框架不变。；输入x∈R^{W×H×C}，每个高斯成分的均值τ_m∈R^C（多通道均值），成分掩码ρ_m在所有通道共享。涂鸦掩码通过对前景成分求和获得。
- 公式/目标函数/指标定义：
  - L_mix(B,Θ) = Σ_{b∈B} Σ_{i∈I_b} ℓ_mix(x_i; x̄_b, Θ), ℓ_mix = Σ_m ρ_{m,θ,i}(x̄_b) ln p(x_i | τ_{m,θ',i}(x̄_b))
  - L_k_seg(B,Θ) = Σ_{b∈B} ℓ_k_seg(y_b, x̄_b; Θ) / Σ_{b∈B} |S_{b,k}|, ℓ_k_seg = -log( Σ_{m∈m_k} ρ_{m,θ,i}(x̄_b) )
  - 联合目标: min_Θ Σ_{k∈{0,1}} (1-λ)L_k_seg + λ L_mix
- 算法细节：
  - 盲点像素选择：对每个patch随机选取20%像素位置，将每个位置的值替换为邻域内随机另一个位置的值（非原值）。
  - 混合成分设置：M=4，其中m0=2个背景成分，m1=2个前景成分；每个成分对应固定方差的高斯分布。
  - 成分掩码ρ_m通过softmax归一化，保证和为1。
  - 训练时损失仅回传至盲点像素和涂鸦像素，非盲点非涂鸦像素不贡献损失。
  - 推理时：直接使用网络输出的ρ_m，对每个像素将前景成分（m∈m1）的概率相加作为前景置信度，然后阈值化得到分割。
- 训练/推理细节：
  - 训练数据：从N对图像-涂鸦中随机采样B个128×128的patch，总计N*B个patch；验证集与训练集不重叠。

### 18. Divide-and-Conquer Inference for Large-Scale Visual Recognition with Multimodal Large Language Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.24799v1
- 方法流程：
  - 输入：图像和完整候选类别列表（大小K）
  - 阶段1（划分）：将当前候选类别列表分组为若干子集（每组大小M，如10-20类）
  - 阶段2（局部推理）：对每个子集，MLLM根据图像和子集提示输出最可能的类别（或概率）
  - 阶段3（剪枝与聚合）：从所有子集结果中选出置信度最高的若干类别（如top-k）作为下一轮候选列表
  - 递归：重复划分和推理，直到候选列表缩小到可直接输出（如大小≤阈值）
  - 输出：最终的预测类别
- 关键模块/机制：
  - 递归分解器：将大规模类别列表划分为多个小规模子集，使得每个子集类别数M远小于K，从而简化局部推理任务；基于固定分组大小M（如20）将K个类别均匀划分为ceil(K/M)个子集；也可根据类别语义或随机分组
  - 局部推理模块：利用MLLM在每个子集上独立进行封闭式分类，输出子集内各类别的得分或置信度；输入为图像+子集类别文本列表，MLLM通过自回归生成或注意力计算得到每个候选类别的似然；可并行执行多个子集
  - 动态剪枝模块：从所有子集的局部结果中筛选出全局最可能的少数类别，压缩搜索空间；根据局部置信度排序，保留全局top-k（如k=100）个类别作为下一轮的候选列表；k随递归递减
- 公式/目标函数/指标定义：
  - 标签熵下界：H(Y) ≥ log K - log β (其中β≥1，pk ≤ β/K)
  - 注意力稀释：在softmax注意力下，当候选数增加时，单个候选的注意力权重以O(1/K)衰减
- 算法细节：
  - 递归划分：设类别总数K，分组大小M。第一轮将K个类别分为⌈K/M⌉组，每组M个类别（最后一组可能不足M）
  - 并行推理：对所有分组同时调用MLLM，每个分组获得一个类别概率分布
  - 剪枝：从所有分组中取概率最高的top-k个类别（k远小于K），作为下一轮候选
  - 递归终止条件：当候选列表大小≤阈值T（如1或M）时，直接输出最终预测
- 训练/推理细节：
  - DCI无需额外训练或微调，直接使用预训练MLLM进行推理
  - 推理时计算复杂度：标准flat推理为O(K^2)，DCI每轮复杂度约为O((K/M)*M^2)=O(KM)，多轮后总复杂度接近O(K log K)

## 摘要
放射学报告生成（RRG）通常被表述为单路径生成任务，其中多模态大语言模型（MLLM）产生一个解码后的报告作为最终输出。虽然近期进展主要得益于扩展训练数据、模型容量和检索机制，但在推理阶段提升报告质量仍未被充分探索。在本工作中，我们观察到固定的放射学MLLM在其候选池中产生的报告往往在临床方面比默认解码选择的报告更强，这表明推理时的决策仍然是一个被忽视的瓶颈。为解决这一问题，我们提出了临床共识选择（CCS），一种与解码器无关的推理时选择框架，该框架采样多个候选报告，并选择在展开池中具有最高临床共识的报告。CCS将基于文本的效用与由图像-报告训练的多模态嵌入器计算出的放射学适配效用相结合，该嵌入器衡量超出表面文本相似性的候选一致性。在三个数据集和多个放射学MLLM上，CCS在推理时性能上持续优于单路径解码和通用Best-of-N基线，在临床指标上尤为明显。进一步分析表明，基于图像的效用形成了与文本共识不同的选择轴，并且在推理时改进RRG仍有很大的提升空间。

## Abstract
Radiology report generation (RRG) is commonly formulated as a single-path generation task, where a multimodal large language model (MLLM) produces one decoded report as the final output. While recent progress has largely been driven by scaling training data, model capacity, and retrieval mechanisms, improving report quality at inference time remains underexplored. In this work, we observe that fixed radiology MLLMs often generate clinically stronger reports elsewhere in their candidate pool than the one selected by default decoding, suggesting that inference-time decision making remains an overlooked bottleneck. To address this, we propose Clinical Consensus Selection (CCS), a decoder-agnostic inference-time selection framework that samples multiple candidate reports and selects the one with the highest clinical consensus across the rollout pool. CCS unifies text-based utilities with a radiology-adapted utility computed by an image--report-trained multimodal embedder, which measures candidate agreement beyond surface-level textual similarity. Across three datasets and multiple radiology MLLMs, CCS consistently improves inference-time performance over single-path decoding and generic Best-of-N baselines, with particularly clear gains on clinical metrics. Further analysis shows that image-grounded utility forms a selection axis distinct from textual consensus and that substantial headroom remains for improving RRG at inference time.

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
CCS 将 RRG 重新定义为 **从候选池中选择报告** 的过程。给定同一输入（图像和问题），利用固定 MLLM 采样多个候选报告，然后基于**配对临床共识**（pairwise clinical consensus）评分，选出共识最高的报告作为最终输出。

### 关键技术细节
1. **候选池生成**：从同一个 MLLM 中采样 N 个候选报告（默认 N=8，温度 τ=0.5），不改变模型参数。
2. **配对效用评分**：对于每对候选报告 (y_i, y_j)，计算一个效用分数 U(y_i, y_j)：
   - **文本效用**：使用评估指标（如 BLEU、ROUGE、BERTScore、RadGraph-F1 等）作为配对相似度。
   - **图像接地效用**：使用基于图像-报告对微调的多模态嵌入模型 **Qwen3-VL-Embed**，计算候选报告在嵌入空间中的余弦相似度。该效用不仅依赖文本表层重叠，还通过多模态表示捕捉临床一致性。
3. **共识聚合**：对每个候选报告，计算它与其余 N-1 个候选报告的平均效用分数，作为其“相对共识”：
   - s_i = (1/(N-1)) * Σ_{j≠i} U(y_i, y_j)
4. **最终选择**：选择共识分数最高的候选报告作为输出：ŷ_CCS = argmax_{i} s_i

### 算法流程（文字说明）
```
输入：测试图像 x、问题 q、MLLM、效用函数 U、池大小 N、采样温度 τ
1. 从 MLLM 中采样 N 个候选报告，形成池 Y = {y_1, ..., y_N}
2. 计算所有配对效用，得到分数矩阵 S ∈ R^{N×N}
3. 对每个候选报告计算其平均效用（去掉自身）
4. 选择具有最高平均效用的候选报告作为最终输出
```

## 6. 主要结论与发现

1. **候选池蕴含更强报告**：固定 MLLM 在解码时经常“错过”临床更准确的候选报告，表明推理时选择是重要瓶颈。
2. **CCS 显著提升临床指标**：在所有数据集和骨干上，CCS 均优于单路径解码和通用 Best-of-N 方法，尤其 RadGraph-F1、RaTEScore、CheXbert F1 等临床指标提升明显。
3. **图像接地效用形成独立选择轴**：基于 Qwen3-VL-Embed 的效用与文本效用（如 BLEU、ROUGE）在决策空间上差异显著（Cohen's κ 仅 0.08~0.20），能捕获文本易遗漏的阳性发现（如表4 所示症状级别 F1 提升）。
4. **文本共识存在“沉默偏差”**：基于标签的效用（如 CheXbert）倾向于选择阴性/正常发现较多的保守报告，而图像接地效用更均衡地保留异常。
5. **随着池大小增加性能持续提升**（N=2→16），但边际增益递减，N=8 是实用折衷。
6. **无需修改模型或重训练**，CCS 是一种轻量级、即插即用的推理时优化策略。

## 7. 优点

- **训练无关性**：不改变生成器参数，不引入额外训练，适用于任何预训练 MLLM。
- **参考无关性**：推理时无需任何标准报告，完全自给。
- **多模态信号补充**：使用图像-报告联合嵌入计算共识，超越纯文本相似性，能更好地保留异常发现。
- **系统消融分析**：详细比较了多种效用函数，揭示了不同效用之间的互补性与选择轴差异。
- **跨骨干和跨数据集鲁棒性**：涵盖 3 个骨干（LLaVA-Med、LLaVA-Rad、Libra）和 3 个数据集，一致表现提升。
- **统计严谨**：使用 p 值和置信区间验证显著性。
- **实际部署友好**：批处理推理开销可控，N=8 时仅 2× 耗时。

## 8. 不足与局限

1. **实验覆盖范围有限**：
   - 仅使用标准基准数据集（MIMIC-CXR、IU-Xray、CheXpert Plus），可能未充分反映真实临床环境的噪声（如不同设备、报告风格差异）。
   - 仅评估胸部 X 光正面视图，未涉及侧位、CT、MRI 等其他模态。
2. **缺乏人工评估**：所有评估依赖自动指标，无放射科医师验证临床正确性。自动指标（尤其是词汇指标）可能无法完全反映临床质量。
3. **嵌入模型局限**：图像接地效用基于 Qwen3-VL-Embed（2B），未探索更大更强的嵌入模型（如 7B 或更高）；也未使用 LLM-as-judge 进行辅助评估。
4. **未结合其他推理时技术**：CCS 仅做最终选择，未与对比解码、结果性修订等方法结合，也未探索多步推理或重写策略。
5. **计算开销**：尽管批处理缓解，但 N=16 时仍需约 3× 解码时间，对实时性要求高的场景可能受限。
6. **未解决生成器根本问题**：CCS 依赖生成器的候选质量，如果生成器本身无法产生合格候选（如极端噪声场景），选择空间受限。
7. **伦理风险**：论文明确指出该系统仅为辅助研究，不适用于自主临床决策，但仍需警惕过度依赖自动报告的风险。

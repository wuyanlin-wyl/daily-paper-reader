## 摘要
检索增强生成（RAG）系统部署在多作者机构语料库上，可能会因检索到的来源不同而对同一问题给出不同答案——这是一种主流单一标准答案范式无法诊断的失败模式。我们认为来源依赖性是NLP评估中缺失的一个维度，对其进行审计意味着将评估单位从答案正确性转向来源间关系。我们通过在移植患者教育中具体实现这一点，其中机构来源明显存在分歧，并发布三个产物：TransplantQA，一个真实患者问题基准，每个问题通过将生成基于多个机构手册作为候选来源来回答；HERO-QA，一种分层检索策略，为每个答案提供依据并审计；以及一个结构化输出评判器，根据经过验证的5标签分类对来源间关系进行评分。在规模化上，更好的检索揭示的分歧比先前估计的要多得多——低估了其普遍性，而非强度。该框架是领域无关的，可迁移到法律和教育RAG：衡量来源依赖性通常是已部署的多源NLP的一项责任。

## Abstract
A retrieval-augmented generation (RAG) system deployed over a multi-author institutional corpus can give a different answer to the same question depending on which source it retrieves -- a failure mode the dominant single-gold-answer paradigm cannot diagnose. We argue that source-dependence is a missing axis of NLP evaluation, and that auditing it means shifting the unit of evaluation from answer correctness to the inter-source relationship. We make this concrete in transplant patient education, where institutional sources demonstrably disagree, releasing three artefacts: TransplantQA, a benchmark of real patient questions, each answered by grounding generation in multiple institutional handbooks as candidate sources; HERO-QA, a hierarchical retrieval strategy that grounds and audits each answer; and a structured-output judge that scores inter-source relationships on a validated 5-label taxonomy. At scale, better retrieval reveals far more disagreement than prior estimates suggested -- understating its prevalence, not its intensity. The framework is domain-agnostic and transfers to legal and educational RAG: measuring source-dependence is a responsibility for deployed multi-source NLP generally.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：当前 NLP 评估的主流范式（单一标准答案）无法诊断多源 RAG 系统的“来源依赖性”故障——即同一问题因检索来源不同可能产生不同答案，而系统却以相同置信度输出，不提示用户答案具有机构特异性。
- **研究背景**：在医学、法律、教育等已部署的多作者机构语料库场景下，不同来源（如不同医院的患者教育手册）对同一临床问题可能给出不同指导（如旅行等待期、锻炼时间等），但现有基准（MedQA、MedMCQA、PubMedQA 等）均假设每问题只有一个正确答案，无法捕捉这种差异。
- **整体含义**：作者认为测量来源依赖性是多源 NLP 评估中缺失的维度，评估单位应从“单答案正确性”转向“来源间关系”。论文以移植患者教育为案例，构建了一套完整的审计框架，并证明该框架可领域无关地迁移至法律和教育 RAG。

## 2. 方法论：核心思想、关键技术细节
### 2.1 核心思想
- 将评估单位从单答案正确性转向**来源间关系**：给定同一问题，比较两个不同来源（手册）生成答案之间的结构化关系，而非判断哪个答案“正确”。
- 提出三阶段流水线：结构化提取 → HER-OA 检索增强生成 → 结构化配对评判。

### 2.2 关键技术细节
#### (1) 结构化提取（Stage 1）
- 使用 LlamaParse 将 PDF 手册转为 JSON，保留章节标题、段落、页码，支持后续分层检索。

#### (2) HERO-QA 检索增强生成（Stage 2）
- **层次路由**：短手册（≤80k 字符）直接使用全文，避免检索遗漏；长手册进入分层检索。
- **文档模型**：文档 → 父节（section） → 子块（child chunk，160 词，32 词重叠，前缀父节标题）。
- **四路并行检索 + 融合**：
  - ① 密集检索（FAISS + BAAI/bge-large-en-v1.5）
  - ② 稀疏 BM25（子块）
  - ③ 节体导航（BM25 对节文本）
  - ④ 标题导航（BM25 对节标题）
  - 使用互惠排名融合（RRF，k=60，导航信号降权）
- **交叉编码器重排序**：MiniLM 交叉编码器对 top 候选重排。
- **父段扩展**：top 子块扩展回其父节及邻接节，生成连贯的节级上下文；top-5 扩展段落作为证据。
- **证据充分性检查**：若证据弱则回退至全文。
- **答案生成**：Qwen3-32B，温度 0，严格按照上下文生成，无法回答时输出“NOT ADDRESSED”并引用节标题。

#### (3) 结构化配对评判（Stage 3）
- **缺失预筛**：快速检查“NOT ADDRESSED”前缀 + 二元分类器，缓存缺失状态。
- **五标签分类**：ABSENT、CONSISTENT、COMPLEMENTARY、DIVERGENT、CONTRADICTORY（定义见表 2）。
- **结构化 JSON 输出**：每个配对返回 {classification, reasoning, divergence_topic, clinical_significance, judge_metadata}，支持下游深度分析（如分歧主题聚类、严重度加权聚合）。
- **比较矩阵**：每问题生成 N×N 整数矩阵及所有配对记录，可断点续传。

## 3. 实验设计
### 3.1 数据集 / 基准
- **TransplantQA 基准**：
  - 手册语料：102 本患者教育手册，来自 23 个美国移植中心，5 种器官类型（心、肺、肾、肝、胰腺），分为移植前、移植后、综合三类。
  - 问题集：1,115 个真实患者问题（从 Reddit、Mayo Clinic Connect、National Kidney Foundation 等平台爬取），经去重、匿名化、改写。其中 311 个通用问题（所有手册均可回答），804 个器官特异问题。
  - 每个问题标注：器官类型、临床主题（13 分类）、细粒度子主题（43 个）。

### 3.2 对比方法
- **系统级比较**：将 32B 参考运行（HERO-QA + Qwen3-32B 生成+评判）与早期 14B 运行（混合检索 + Qwen3-14B）对比，评估检索能力升级的影响。
- **评判器消融实验**：结构化单次调用 vs 标签仅+后提取协议，在 200 对样本上比较。

### 3.3 评判器验证
- **人工标注**：200 对分层样本（每非缺失标签 40 对 + 40 ABSENT 对照），两位标注者，κ=0.655（标注者间），与多数标签比较 κ=0.842（几乎完美），加权 F1=0.876。

## 4. 资源与算力
- **集群**：PSC Bridges-2，NVIDIA H100 80 GB GPU。
- **参考运行时间**：
  - 文档提取（CPU）：12 小时
  - 索引：8 GPU 小时
  - 生成（Stage 2）：~130 GPU 小时
  - 配对评判（Stage 3）：~300 GPU 小时
  - **总计**：约 438 H100-80 GB GPU 小时
- **成本估算**：按 $3–4/GPU 小时，约 $1,300–$1,800。
- 可断点续传，小域（10–20 手册）可在单卡 24 小时内完成。

## 5. 实验数量与充分性
- **主要实验**：
  - 完整跑通全基准：生成 48,056 个答案，5,730,465 对比较（4,519,245 对经缺失预筛，1,211,220 对经 LLM 评判）。
  - 每问题生成 N×N 比较矩阵。
- **验证实验**：
  - 200 对人工标注（充分覆盖所有标签及稀有类 CONTRADICTORY 过采样）。
  - 消融实验：结构化 vs 标签仅+后提取（200 对）。
  - 系统级比较：14B 早期运行 vs 32B 参考运行（每器官对比）。
- **充分性评价**：实验数量大（百万级配对），人工验证充分（κ 高），消融实验揭示设计必要性。但存在局限：仅一个领域（移植）的真实数据；仅一种 LLM 族（Qwen3）；未在多个随机种子上重复。

## 6. 主要结论与发现
1. **全局标签分布**：78.9% 配对因至少一手册不包含相关信息而为 ABSENT；非缺失对中 COMPLEMENTARY 占 75.4%，DIVERGENT 12.9%，CONSISTENT 7.1%，CONTRADICTORY <0.1%。
2. **器官间异质性**：缺失率 60–78%，每对分歧率 0.14–0.19，胰腺和通用问题分歧率较高。
3. **系统比较**：更好的检索（HERO-QA）使平均缺失率降低 13.6 个百分点，但每对分歧率基本不变（均值-0.031），而显示任何分歧的问题比例上升 15.9 个百分点。**结论：过去低估了分歧的普遍性（prevalence），而非强度（intensity）。**
4. **结构化输出的必要性**：标签仅+后提取协议丢失 DIVERGENT/COMPLEMENTARY 鉴别力（78% DIVERGENT 被降级为 COMPLEMENTARY）及临床意义分级（全部返回 high）；结构化单次调用是框架设计要求。

## 7. 优点
1. **提出新评估维度**：明确“来源依赖性”作为多源 RAG 的缺失评估轴，并给出操作化定义。
2. **完整的工具体系**：同时发布基准（TransplantQA）、检索策略（HERO-QA）和评判器，易于复现和扩展。
3. **大规模实证**：超 5.7 百万配对人工验证后的结构化输出，是已知最大规模的 LLM-as-judge 医学异质性基准应用。
4. **验证严谨**：200 对人工标注 κ=0.842，消融实验证明结构化设计不可替代。
5. **框架领域无关**：论证法律、教育 RAG 可直接套用相同三要素（多源基准、来源间分类、结构化评判器），具有广泛影响力。
6. **结构化输出赋能深度分析**：分歧主题聚类（991 主题）、临床意义加权聚合，揭示传统标签无法获得的信息。

## 8. 不足与局限
1. **领域和时效性限制**：实证仅限美国固体器官移植患者教育（英语，2024–2025 快照），法律/教育迁移仅为概念性论证，未实际测试。
2. **LLM 评判器偏差**：验证仅在 200 对上衡量总体一致性，无法检测子轴偏见（如机构、器官、答案长度）；存在自偏好（生成器与评判器同一家族）和长度/引用伪影风险。
3. **分歧来源歧义**：表面分歧可能来自检索失败而非真实来源差异；缺失预筛只能部分缓解。
4. **高计算成本**：完整运行需约 438 GPU 小时，对资源有限的研究者不友好。
5. **临床意义分级可靠性**：judge-人类 κ=0.385（一般），仅适合群体级信号，不适合单配对裁决。
6. **未覆盖动态环境**：当前仅静态快照，未考虑手册版本更新或在线 RAG 上下文。
7. **未与其他检索策略（如简单 RAG、HyDE）做基线对比**：系统比较仅自我对比（14B→32B），未与经典检索方法比较。

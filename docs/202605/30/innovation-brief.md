### 1. Same Question, Different Source, Different Answer: Auditing Source-Dependence in Medical Multi-Source RAG
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29084v1
- 方法流程：
  - Stage 1: 结构化提取——使用LlamaParse将PDF手册转换为结构化JSON，保留章节标题、段落边界和页面元数据。输入：原始PDF手册；输出：每个手册的结构化JSON（包含器官类型、机构、护理阶段、来源路径、全文文本和章节列表）。
  - Stage 2: HERO-QA检索增强生成——对短手册（全文≤80k字符）直接使用全文上下文；对长手册进行分层文档分解（父章节+子块），通过长度路由、四路并行检索（密集检索、稀疏BM25、节主体导航、标题导航）、倒数秩融合、MiniLM交叉编码器重排序、父节扩展生成上下文，再输入LLM生成答案。输入：问题+手册；输出：每个手册对应的答案及检索元数据。
  - Stage 3: 结构化输出评判——使用结构化输出评判器对每对答案（来自不同手册）评估跨源关系，输出5标签分类（如符合、分歧等）和叙事元数据。输入：所有答案对；输出：跨源关系矩阵。
- 关键模块/机制：
  - HERO-QA分层检索：实现高召回的证据检索，消除短手册的检索失败，对长手册通过分层结构和多路检索提高覆盖率。；包括长度路由门控（≤80k字符的手册跳过检索，使用全文）、文档→节→块层次结构、四路并行检索（FAISS密集检索、BM25稀疏检索、节主体BM25、标题BM25）、RRF融合（k=60，导航信号降权）、MiniLM交叉编码重排序、父节扩展（返回前k个块后扩展其父节全部文本）。
  - 结构化输出评判器：评估跨源关系，输出结构化标签和叙事元数据，替代单一标量评判。；使用LLM（Qwen3-32B）联合输出5标签分类（COMPLEMENTARY/DIVERGENT等）和叙事字段（如divergence_topic, clinical_significance）；在人工标注上达到κ=0.842的一致性。
- 算法细节：
  - 层级0-1：长度路由——若手册全文≤80k字符，直接使用全文作为上下文，跳过检索。否则进入层级2。
  - 层级2：四路并行检索——（a）密集子块检索：使用BAAI/bge-large-en-v1.5编码子块，FAISS索引；（b）稀疏子块BM25；（c）节主体BM25：将检索结果映射到子块；（d）标题BM25：仅搜索章节标题。
  - 层级3：RRF融合——将四个排序列表合并，导航信号（c和d）降权。
  - 层级4：交叉编码重排序——使用MiniLM交叉编码器对融合后的候选块重排序。
  - 层级5：父节扩展——选择重排序后的top-k子块，将其所在父节的全部文本加入上下文。
- 训练/推理细节：
  - 生成和评判使用Qwen3-32B模型，未提及微调，所有运行基于开放权重模型。
  - 参考运行在SLURM集群上可恢复执行，使用异构资源。

### 2. Brain-IT-VQA: From Brain Signals to Answers
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29588v1
- 方法流程：
  - 输入：fMRI脑活动信号（~40k voxels，主要来自视觉皮层）和文本查询。
  - Brain Tokenization：将voxel信号聚类为128个功能相似簇，通过单头图注意力层映射为512维（后升至768维）Brain Tokens。
  - 跨注意力提取：两个独立堆栈的交叉注意力模块（8头）分别从Brain Tokens提取CLIP视觉对齐表示（1408维）和直接调节令牌（768维）。
  - 双路径融合：CLIP路径使用InstructBLIP的Q-Former（LoRA适配）处理Brain Tokens与查询，输出对齐特征；直接路径预测调节令牌。两路径输出平均得到最终调节令牌。
  - 语言模型解码：调节令牌与文本查询前缀拼接，输入冻结的Flan-T5-XL生成答案或标题。
- 关键模块/机制：
  - BIT-L (Brain Interaction Transformer for Language)：将fMRI信号转换为任务相关表示；包含Brain Tokenizer（单头图注意力层，128簇，输出768维）和两个独立交叉注意力堆栈（各5自注意力+6交叉注意力块，8头），共享Brain Tokens，分别提取CLIP对齐特征和直接调节特征。
  - CLIP对齐路径：提取与CLIP视觉令牌对齐的表示；使用InstructBLIP的Q-Former，通过LoRA（r=4, α=4）微调，以文本查询为条件，从Brain Tokens中提取与CLIP ViT-g/14视觉特征对齐的1408维表示。
  - 直接调节路径：预测直接的语言模型条件令牌；通过另一个交叉注意力堆栈从Brain Tokens学习任务特定软提示，输出768维调节令牌，作为语言模型的条件。
  - Image-to-fMRI编码器：预测未见图像的fMRI响应，用于数据增强；采用已有方法（Scott et al.）将额外自然图像（如COCO）编码为预测的fMRI信号，补充训练数据。
- 公式/目标函数/指标定义：
  - 第一阶段损失：L_stage1 = MSE(CLIP_tokens_pred, CLIP_tokens_gt) + MSE(cond_tokens_pred, cond_tokens_gt)，其中cond_tokens_gt来自InstructBLIP Q-Former处理图像与查询'短图像描述'时的输出。
  - 第二阶段损失：使用InstructBLIP的语言建模损失（交叉熵）进行端到端微调。
  - 评估指标：VQA准确率（短答案），BLEU、METEOR、ROUGE-L、CIDEr、SPICE（全句生成）。
- 算法细节：
  - Brain Tokenizer：对voxel聚类（128簇），每簇内通过图注意力聚合为单个token，维度512（后扩展至768）。
  - 交叉注意力：每个堆栈包含5层自注意力+6层交叉注意力，查询来自可学习查询令牌或直接预测令牌，键和值来自Brain Tokens。
  - 双路径融合：两路径输出（CLIP路径1408维经投影至768维？原文未明确，但最终平均得768维调节令牌）直接逐元素平均。
  - LoRA微调：BIT-L的LoRA参数（r=2, α=2），Q-Former的LoRA（r=4, α=4）。
  - 数据增强：对COCO中无fMRI记录的图像，使用Image-to-fMRI编码器生成预测fMRI，第一阶段使用~120k图像，第二阶段使用所有训练集外COCO图像。
- 训练/推理细节：
  - 两阶段训练：第一阶段冻结除BIT-L外所有组件，训练50 epochs，warmup 15 epochs，学习率5e-4，余弦衰减（patience=5，因子0.1），验证损失早停。第二阶段使用LoRA联合微调BIT-L和Q-Former，冻结语言模型，相同优化器配置。
  - 推理：输入fMRI和文本查询，经BIT-L和双路径生成调节令牌，与查询前缀拼接输入冻结的Flan-T5-XL自回归解码。无需图像。
  - 训练数据：NSD数据集（8 subjects，每subject约9000训练图像），subject特定模型或联合模型？文中提到subject 1,2,5,7，训练joint-subject模型？实验部分报告subject 1或跨subject平均，但实现中训练联合模型（单H200 GPU）。
  - 硬件与时间：单H200 GPU，阶段1约6小时，阶段2约10小时每数据集。

### 3. CCS: Clinical Consensus Selection for Radiology Report Generation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.30131v1
- 方法流程：
  - 阶段1: Rollout Pool Generation - 输入: 胸部X光图像x和问题q; 处理: 使用MLLM在温度τ下随机采样N个候选报告yi ~ pθ(y|x,q;τ); 输出: 候选报告集合Y={y1,...,yN}。
  - 阶段2: Pairwise Utility Scoring - 输入: 候选报告集合Y; 处理: 对每对(yi,yj)计算效用函数U(yi,yj)，包括文本效用（如ROUGE-L）和图像接地效用（Qwen3-VL-Embed的余弦相似度）; 输出: 效用矩阵S∈R^{N×N}。
  - 阶段3: Consensus Aggregation - 输入: 效用矩阵S; 处理: 对每个候选yi，计算其与其他N-1个候选的平均效用si = 1/(N-1) * Σ_{j≠i} U(yi,yj); 输出: 共识分数向量s。
  - 阶段4: Final Selection - 输入: 共识分数向量s; 处理: 选择分数最高的候选i* = argmax si; 输出: 最终报告ŷ_{CCS} = y_{i*}。
- 关键模块/机制：
  - Rollout Pool Generation：生成多样化的候选报告集合，为后续选择提供基础。；使用原始MLLM在随机解码下采样N个报告，温度τ控制多样性（默认使用Transformers库的top-p和top-k默认值），不引入额外参数或训练。
  - Pairwise Utility Scoring：度量候选报告对之间的临床一致性。；支持两种效用：1) Textual Utility: 直接使用文本评估指标（如ROUGE-L、BLEU、BERTScore）作为成对相似度m(yi,yj)；2) Image-Grounded Utility: 使用经图像-报告对微调的多模态嵌入器Qwen3-VL-Embed编码报告，计算余弦相似度CosineSim(f_φ(yi), f_φ(yj))，该效用不直接使用测试图像。
  - Consensus Aggregation：将成对效用量化为每个候选的相对共识分数。；对每个候选yi，计算其与池中所有其他候选的平均效用si = (1/(N-1)) * Σ_{j≠i} U(yi,yj)，所得分数反映该候选在池中的整体共识程度。
  - Final Selection：从候选中选出最一致的报告作为最终输出。；选择共识分数最高的候选i* = argmax_i si，返回对应的报告ŷ_{CCS} = y_{i*}。
- 公式/目标函数/指标定义：
  - 单路径生成: ŷ_{single} ~ p_θ(y | x, q)
  - Rollout池生成: Y = {y_1, ..., y_N}, y_i ~ p_θ(y | x, q; τ)
  - 文本效用: U_{text}(y_i, y_j) = m(y_i, y_j) （m为任意文本评估指标）
  - 图像接地效用: U_{img}(y_i, y_j) = CosineSim(f_φ(y_i), f_φ(y_j))
  - 共识分数: s_i = 1/(N-1) * Σ_{j≠i} U(y_i, y_j)
  - 最终选择: ŷ_{CCS} = y_{i^*}, i^* = argmax_i s_i

### 5. Human-in-the-Loop Multi-Agent Ventilator Decision Support with Contextual Bandit Preference Learning
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.23320v1
- 方法流程：
  - 输入：当前患者状态（如血气、呼吸力学参数）及历史临床医生偏好向量
  - 多智能体组件（如目标设定、参数建议、安全约束）通过契约驱动接口交换结构化信息，生成候选推荐计划
  - 上下文bandit根据当前状态和已学偏好，从候选计划中选择最优推荐
  - 临床医生审查推荐：若接受，则更新偏好（bandit利用该选择作为正反馈）；若拒绝，则提供结构化拒绝反馈（如‘气压过高’）
  - 结构化反馈分解为特定组件目标约束，触发对应组件重新规划，生成更新推荐
  - 重复步骤3-5直至达到可接受计划或最大迭代次数
- 关键模块/机制：
  - Target Setting Agent：根据患者状态设定短期临床目标（如氧合、通气）；接收当前生理指标，通过规则或小型模型生成目标区间，输出为结构化契约。
  - Parameter Suggestion Agent：基于目标设定生成具体呼吸机参数建议（如潮气量、PEEP）；使用生理模型或查找表将目标映射为参数值，输出包含多个候选参数集。
  - Safety Constraint Agent：确保参数建议在安全边界内；应用预定义安全规则（如平台压<30 cmH2O）过滤或调整参数建议。
  - Clinical Preference Learner (CPL)：在线学习临床医生偏好，指导推荐选择；基于上下文bandit算法（如LinUCB），以患者状态和过去偏好为特征，从候选行动中选择，并在医生接受后更新权重。
  - Rejection Feedback Processor：解析医生结构化拒绝反馈，触发重规划；从拒绝文本中提取约束关键词（如‘气压伤风险’），映射到特定组件及其参数范围，发送重规划请求。
  - Contract Interface：定义多智能体间通信的标准化消息格式；每个组件输出遵循预定义schema（如目标、参数、约束），确保可追踪与审计。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 上下文bandit：在每次交互中，模型维护一个特征向量x_t（患者状态+历史偏好），每个候选行动a对应一个参数向量θ_a。选择行动a*=argmax_a (x_t^T θ_a + α sqrt(x_t^T A_a^{-1} x_t))，其中A_a是协方差矩阵，α为探索参数。接受后更新θ_a和A_a。
  - 结构化拒绝反馈处理：将自然语言反馈（如‘PEEP过高’）解析为结构化约束（如PEEP<10），触发对应组件在约束范围内重新生成建议。
- 训练/推理细节：
  - 训练：上下文bandit在线学习，无需离线训练数据，每次医生接受视为正样本更新模型
  - 推理：多智能体协作生成候选推荐，bandit选择最优，循环直至医生接受或达到最大轮次

### 6. Multimodal Distribution Matching for Vision-Language Dataset Distillation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.23482v1
- 方法流程：
  - 数据初始化：提取真实图像-文本对的联合嵌入（拼接投影特征），运行K-means聚类得到K个簇，每个簇内选择距离簇中心最近的样本作为初始合成对
  - 模型初始化：利用两个微调专家的权重位移向量，根据其夹角计算插值比例，以层为单位合并权重，生成混合教师模型；每次蒸馏迭代随机选择专家检查点
  - 联合特征提取：将图像和文本投影后归一化到单位超球面，构造一致性方向向量u=normalize(zv+zt)和差异性方向向量g=normalize(zv-zt)
  - 测地核能量计算：对每个方向上的真实集和合成集，计算高斯测地核相似度，进而计算双向核能量GKE（包含集合内和集合间亲和度）
  - 总损失优化：结合InfoNCE损失、一致性方向测地核能量和差异性方向测地核能量，更新合成图像和文本嵌入
- 关键模块/机制：
  - 合成数据初始化模块：在联合嵌入空间通过聚类选择代表性样本作为合成数据起点，确保语义覆盖且避免冗余；对真实数据对的图像和文本投影特征拼接后，使用K-means聚类，每个簇中选余弦距离最靠近质心的样本作为初始合成对
  - 混合教师模型初始化模块：通过权重空间插值融合多个微调专家，生成具有良好架构泛化性的教师模型；层级别合并：θ_mℓ = θ_0ℓ + α * t_ℓ * (Δ1ℓ+Δ2ℓ)/2，其中t_ℓ=2⟨Δ1ℓ,Δ2ℓ⟩/(||Δ1ℓ||^2+||Δ2ℓ||^2+⟨Δ1ℓ,Δ2ℓ⟩)，t_ℓ由两个专家位移向量的夹角决定，α=0.5控制整体偏移量
  - 跨模态一致性和差异性方向构造模块：从图像和文本嵌入中提取一对方向向量，分别表示模态间的一致性和差异性；对归一化后的图像特征zv和文本特征zt，计算u=normalize(zv+zt)和g=normalize(zv-zt)
  - 测地核能量匹配模块：在单位超球面上通过高斯核衡量集合间和集合内的亲和度，实现几何感知的分布匹配；定义角距离ϕ(a,b)=arccos(⟨a,b⟩)，高斯核k_geo(a,b)=exp(-ϕ^2/(2σ^2))，然后计算GKE(A,B)=[ (1/m^2)Σk_geo(ai,ai') + (1/n^2)Σk_geo(bj,bj') - (2/(mn))Σk_geo(ai,bj) ]^{1/2}
  - 总损失模块：平衡对比对齐和分布匹配，引导合成数据同时保持模态内和跨模态语义；L_MDM = L_InfoNCE + λ_agr * GKE(Ur,Us) + λ_dis * GKE(Gr,Gs)，其中Ur/Us是真实/合成的一致性方向集合，Gr/Gs是差异性方向集合，λ_agr=λ_dis=0.8
- 公式/目标函数/指标定义：
  - 分布匹配扩展式：D*_syn = argmin ϕ( E_{(X,T)~Dreal} Ψ(X,T), E_{(X˜,T˜)~Dsyn} Ψ(X˜,T˜) )
  - InfoNCE损失：L_InfoNCE = (1/(2B˜)) Σ_j [ -log(exp(Z˜_jj)/Σ_k exp(Z˜_jk)) + -log(exp(Z˜_jj)/Σ_k exp(Z˜_kj)) ], Z˜_jk = s(z˜_vj, z˜_tk)/τ
  - 混合教师权重插值：θ_mℓ = θ_0ℓ + α * t_ℓ * (Δ1ℓ+Δ2ℓ)/2, t_ℓ = 2⟨Δ1ℓ,Δ2ℓ⟩/(||Δ1ℓ||^2+||Δ2ℓ||^2+⟨Δ1ℓ,Δ2ℓ⟩)
  - 一致性方向：u = normalize(zv+zt), 差异性方向：g = normalize(zv-zt)
  - 测地核能量：GKE(A,B) = [ (1/m^2)Σ_k_geo(ai,ai') + (1/n^2)Σ_k_geo(bj,bj') - (2/(mn))Σ_k_geo(ai,bj) ]^{1/2}, k_geo(a,b)=exp(-arccos^2(⟨a,b⟩)/(2σ^2))
  - 总目标：L_MDM = L_InfoNCE + λ_agr * GKE(Ur,Us) + λ_dis * GKE(Gr,Gs)

### 10. Measuring Prediction Uncertainty in Neural Cellular Automata
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.26726v1
- 方法流程：
  - 输入RGB图像x，通过NCA迭代T步得到最终状态ST和分割掩码m
  - 向ST添加高斯噪声ε ~ N(0, σ²I)得到扰动状态eST
  - 从eST继续运行NCA T'步得到恢复状态ST+T'和对应掩码m'
  - 计算原始掩码m与恢复掩码m'的IoU，定义不确定性ures = 1 - IoU(m, m')
  - 输出每个测试图像的ures作为不确定性分数
- 关键模块/机制：
  - NCA动力系统：提供迭代状态演化过程，最终状态对应分割预测；状态张量St ∈ R^(H×W×C)，初始由输入图像拼接零初始化潜在通道构成，更新规则Fθ为局部神经网络，每个空间位置和时间步共享，经T步后从指定输出通道读取分割掩码。
  - 扰动-恢复过程（Perturb-and-Recover）：探测NCA状态在微小扰动下的稳定性；对最终状态ST添加独立同分布高斯噪声（每个状态元素独立采样），噪声标准差σ=0.02，然后继续运行T'=12步，通过比较扰动前后分割掩码的IoU度量韧性。
  - 韧性指标（Resilience）：量化不确定性的标量分数；ures = 1 - IoU(m, m')，其中IoU计算原始预测与恢复后预测的交并比。低值表示稳定吸引子（置信预测），高值表示不稳定（不确定预测）。
- 公式/目标函数/指标定义：
  - ST ∈ R^(H×W×C)，初始状态S0由输入图像拼接零矩阵构成
  - 更新规则 St+1 = Fθ(St)（局部神经网络，空间共享）
  - 分割掩码 m = o(ST)（读取操作）
  - 扰动状态 eST = ST + ε, ε ~ N(0, σ²I)
  - 恢复后预测 m' = o(ST+T')
  - IoU(m, m') = |m∩m'| / |m∪m'|
- 算法细节：
  - 高斯噪声扰动：对每个状态张量元素独立采样，σ=0.02，不共享通道间噪声
  - 输入图像在扰动过程中保持不变，仅扰动潜在状态
  - 松弛步数T'=12，单次扰动-恢复过程即生成不确定性分数
  - 其他基线方法：单次rollout熵（single）、停止时间不一致性（stoptime）、晚期漂移（stability）、二值闪烁（flicker）、测试时增强（TTA）——均用于对比
- 训练/推理细节：
  - 训练：C=64状态通道，fire rate=0.5，隐藏层大小128，Adam优化器（lr=1e-3, weight decay=1e-2），训练50epoch，batch size=2
  - rollout长度调度：每次迭代从U(32,64)采样T，仅对最终预测计算交叉熵损失
  - 推理时韧性计算无需额外训练，仅需一次前向传播并额外运行T'=12步
  - 所有实验使用固定σ=0.02，T'=12，每个图像一次扰动-恢复过程

  - Image-to-Label阶段：将每个单词对齐到其右下角对应的视觉token，过滤掉token化长度超过3或高度超过3倍patch尺寸的单词，并剔除同一视觉token被分配多个标签的情况
  - Label-to-Image阶段：使用文档问答数据集，将文本中的每个单词逐词对齐到空白图像的patch网格上，仅对每个单词的最后一个视觉token分配标签（符合自回归特性）
  - 构建视觉标签集Wi：对于每个视觉token vi，得到对应的单词wi（若无可监督，则忽略该token）
  - 训练阶段：将视觉token序列I与文本提示X、响应Y拼接，输入MLLM；对每个有标签的视觉token vi，计算下一个token预测损失：Lv = -1/m * sum_i log P(wi | I<=i; θ)；同时对文本token计算标准语言建模损失Lt
  - 引入Vision Smoothing：修改视觉损失为Lv = -1/m * sum_i [(1-β) log P(wi | I<=i; θ) + β/(|V|-1) * sum_{w'≠wi} log P(w'| I<=i; θ)]，其中β为平滑系数
- 关键模块/机制：
  - Vision Label Construction: Image-to-Label：从真实图像中自动构建视觉token的标签；使用文本检测和识别模型对图像进行OCR，获取单词及其边界框；将每个单词绑定到其右下角对应的视觉token；过滤掉token化后超过3个token的单词以及高度超过3倍patch尺寸的单词；若多个单词映射到同一视觉token，则丢弃该token的标签以避免歧义。
  - Vision Label Construction: Label-to-Image：通过渲染文本到空白图像来构建精确的视觉token标签；利用文档问答数据集中的问答对，使用绘图工具将每个单词逐个对齐到空白图像的patch网格上；对于跨多个视觉token的单词，仅将标签分配给最后一个token，以符合自回归模型的因果顺序。
  - Vision Smoothing：处理视觉编码器双向特性导致的跨token语义信息扩散；在视觉token的损失中加入平滑项，使每个视觉token不仅学习自身标签，还从图像中其他视觉token的标签中学习；修改损失函数为Lv = -1/m * sum_i [(1-β) log P(wi | I<=i; θ) + β/(|V|-1) * sum_{w'≠wi} log P(w'| I<=i; θ)]，其中β为平滑系数，V为标签词汇表大小。
  - Next-Token Prediction on Visual Tokens：将视觉监督建模为与文本相同的下一个token预测任务；对于每个视觉token vi，其标签wi（单词）被token化后取第一个token（或仅取一个token）作为预测目标；模型在视觉token位置输出logits，计算交叉熵损失；训练时仅进行一次自回归步（一步预测），与标准SFT中的文本token处理方式一致。
- 公式/目标函数/指标定义：
  - 文本token的语言建模损失：Lt = -1/n * sum_i log P(y_i | I, X, Y_{<i}; θ)
  - 视觉token的监督损失：Lv = -1/m * sum_i log P(w_i | I_{≤i}; θ)，其中w_i为视觉token v_i的标签
  - 加入Vision Smoothing后的视觉损失：Lv = -1/m * sum_i [(1-β) log P(w_i | I_{≤i}; θ) + β/(|V|-1) * sum_{w'≠w_i} log P(w' | I_{≤i}; θ)]
- 算法细节：
  - 视觉标签构建阶段：使用OCR工具（如PaddleOCR）检测和识别图像中的文字，获取每个单词的边界框坐标；根据MLLM的patch划分策略（例如14x14网格），将每个单词的右下角坐标映射到对应的视觉token索引
  - 在Label-to-Image方法中，使用已知的文档文本和绘图工具（如PIL），将每个单词渲染到空白图像的特定patch区域，确保每个单词占据的patch位置唯一，然后直接分配标签
  - 标签过滤规则：删除token化后长度超过3的单词（避免过长词汇导致语义模糊）；删除高度超过3倍patch尺寸的单词（可能覆盖多个patch）；若同一视觉token被多个单词映射，则放弃该token的标签
  - 训练时，对每个有标签的视觉token仅计算一次交叉熵损失（一步预测），与文本token的教师强制学习一致
- 训练/推理细节：
  - 训练时，模型以标准SFT方式前向传播，输入包含图像、提示和响应；对视觉token的logits使用构建的单词标签计算损失，对文本token使用真实响应计算损失，总损失为L = Lv + Lt（或加权组合）
  - 无需修改模型架构，无需额外的视觉解码器或前向传播；只需在数据预处理阶段构建视觉标签，训练时直接在视觉token上应用交叉熵损失
  - Vision Smoothing的系数β在实验中使用默认值（论文未明确给出，但可调）；训练使用与标准SFT相同的优化器和超参数设置
  - 推理阶段无任何改动：模型接收图像和文本提示，仅基于文本token的logits生成响应，视觉监督仅在训练时起作用

### 14. AsymVLM: Asymmetric Token Pruning for Efficient Vision-Language Model Inference
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.29535v1
- 方法流程：
  - 输入图像和文本，视觉编码器生成N个视觉令牌，文本嵌入生成L个文本令牌
  - 学习的重要性评分器计算视觉令牌重要性分数：先ℓ2归一化视觉和文本嵌入，再通过可学习权重w加权计算相似度矩阵，取每行最大值
  - 根据评分器输出计算重要性差距g = s(k) - s(N-k+1)（k=⌊N/4⌋），通过阈值划分或线性映射得到每样本保留比例r(g)
  - 在预填充阶段，根据保留比例保留top-r*N个视觉令牌，其余丢弃
  - LLM处理保留的令牌进行预填充
  - 解码阶段：文本令牌累积，当超过固定预算时，使用当前步最终层注意力（单轮）或跨模态相似度（多轮）对生成的令牌评分，驱逐最低分数的令牌，直到不超过预算
- 关键模块/机制：
  - Learned Vision Token Scorer：对视觉令牌进行输出感知的重要性排序，指导剪枝；使用可学习权重向量w∈R^D重新缩放ℓ2归一化的视觉嵌入ˆV，再与文本嵌入ˆT计算点积相似度矩阵S=(ˆV⊙w)ˆT^T，每个视觉令牌的重要性分数si=max_j S_ij。训练时通过软掩码使梯度可传播，损失函数为最后隐藏状态的MSE加上正则项λ||w-1||^2，仅更新w，冻结VLM参数。
  - Per-Sample Adaptive Budget：根据样本的重要性差距动态调整视觉令牌保留比例，避免固定比率次优；从评分器输出计算重要性差距g=s(k)-s(N-k+1)（k=⌊N/4⌋），采用两种映射方法：方法A为阈值划分，设定两个阈值g_lo和g_hi分为三个难度等级分配固定保留比；方法B为线性映射r(g)=clamp(r_target + a(g-¯g), r_min, r_max)，斜率a通过校准集优化。默认使用方法A。
  - Threshold-Based Text Token Eviction：在解码阶段控制文本令牌数量，节省KV缓存；设置固定文本令牌预算，未超出时所有令牌保留；超出时驱逐最低重要性令牌。单轮生成时，重要性用当前步最终层注意力平均分数；多轮对话时，以整轮回答为单位，用当前图像和回答的跨模态相似度评分，保留所有问题和图像。预填充令牌（视觉、系统提示等）始终保护不被驱逐。
- 公式/目标函数/指标定义：
  - 视觉令牌重要性评分：S = (ˆV ⊙ w) ˆT^T ∈ R^{N×L}, s_i = max_j S_{i,j}
  - 训练损失：L = (1/L) Σ_{i=1}^{L} ||h_i^{masked} - h_i^{baseline}||_2^2 + λ||w - 1||_2^2, λ=0.001
  - 重要性差距：g = s_{(k)} - s_{(N-k+1)}, k=⌊N/4⌋
  - 自适应预算-方法A：r(g) = { r_conservative if g<g_lo; r_moderate if g_lo≤g<g_hi; r_aggressive if g≥g_hi }
  - 自适应预算-方法B：r(g) = clamp(r_target + a(g - ¯g), r_min, r_max)
- 算法细节：
  - 评分器训练：使用1500个DocVQA样本，每个样本做两次前向（基准和掩码），仅更新w，使用Adam优化器
  - 软掩码机制：在训练时使用soft mask（如sigmoid或softmax）使剪枝决策可微分，允许梯度流回评分器
  - 自适应预算校准：阈值划分方法中，g_lo和g_hi及对应保留比通过在校准子集上网格搜索确定
  - 阈值驱逐：单轮生成时，每步计算当前所有生成令牌的最终层注意力平均分，驱逐最低分的直至预算内；多轮对话时，累积历史回答，用当前图像与每个回答的跨模态相似度评分，驱逐低分回答轮次
- 训练/推理细节：
  - 训练仅更新评分器权重w，VLM参数保持冻结，使用MSE损失和L2正则
  - 训练数据：1500个DocVQA样本，每个样本两遍前向（基准和掩码）
  - 推理时：视觉令牌评分器w已固定，自适应预算基于输入即时计算，文本驱逐在解码阶段实时触发

### 15. H$^{2}$MT: Semantic Hierarchy-Aware Hierarchical Memory Transformer
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.24930v1
- 方法流程：
  - 阶段1：语义层次树构建。根据文档结构（如目录、章节、段落）将上下文组织成树，叶子节点对应最小语义单元（如段落），中间节点对应章节等。
  - 阶段2：层次内存嵌入构建。对每个叶子节点，在对话前缀中加入一个可学习的写嵌入和读嵌入，通过主干模型处理得到该节点的内存嵌入；中间节点的内存嵌入通过自底向上后序遍历聚合子节点内存嵌入得到。
  - 阶段3：层次记忆感知推理。将用户查询转换为查询向量，从根节点开始，每层对父节点的子节点计算路由分数（缩放点积），选择top-k子节点继续，直到到达叶子或预算上限。收集所有被选节点的内存嵌入，堆叠后作为前缀与查询嵌入一起送入主干模型生成答案。
- 关键模块/机制：
  - 语义层次树构建：将长上下文组织成层次结构，作为后续内存构建和路由的基础；根据文档的元数据（如目录、章节标题）构建树，叶子节点通常为段落，中间节点对应章节或文档区域。对于结构化文档，按目录结构；对于叙事文本，按章-节-段落；对于多文档，每个文档标题作为根节点。
  - 层次内存嵌入构建：为每个节点生成一个紧凑的内存嵌入，用于表示该节点对应文本的语义；对每个叶子节点，将节点文本与写嵌入、读嵌入拼接为序列，输入主干模型，取读嵌入位置的最终层隐藏状态作为内存嵌入。中间节点通过自底向上后序遍历，对其子节点内存嵌入进行平均（或使用注意力聚合）得到自身内存嵌入。
  - 粗到细路由（Coarse-to-Fine Routing）：根据查询在层次树中定位相关子区域，剪枝无关分支；使用查询向量与子节点内存嵌入的缩放点积计算路由分数，每个父节点选择分数最高的top-k子节点作为下一层候选。所有被选节点跨越不同深度，最终收集所有被选节点的内存嵌入作为记忆上下文。
  - 查询嵌入生成：将用户问题转化为与内存嵌入同空间的查询向量；将问题截断为前n_q个token，在其前后分别添加写嵌入和读嵌入，输入主干模型，取读嵌入位置的状态作为查询向量。
- 公式/目标函数/指标定义：
  - 路由分数：s(u|q) = (W_q q)^T (W_k m_u) / sqrt(d_h)
  - 每层候选集：S_{ℓ+1} = ∪_{p∈S_ℓ} TopK_{u∈C(p)} s(u|q)
  - 叶子节点语言建模损失：LLM(v) = -1/n_v Σ_t log p_θ(x_{v,t} | x_{v,<t}, m_v)
  - 可选重构损失：LAE(v) 从m_v解码x_v的交叉熵
  - QA生成损失：Lgen = -1/A Σ_t log p_θ(a_t | q, M_ret, a_<t)
  - 单路径路由损失：Lroute = -Σ_{p∈P} log [exp(s_p(g(p))/τ) / Σ_{u∈C(p)} exp(s_p(u)/τ)]
- 算法细节：
  - 语义层次树构建算法：基于文档元数据（目录、章节标题）递归建立树，节点存储对应文本范围。
  - 内存嵌入聚合：中间节点内存通过后序遍历，对其子节点内存嵌入进行平均池化（或可学习的注意力聚合）。
  - 推理时路由算法：初始化候选集S0={根}，从深度0开始，对当前深度的每个父节点p，计算其所有孩子的路由分数，选择top-k孩子加入下一层候选集S_{ℓ+1}，重复直到达到叶子或最大深度或内存预算。
  - 输出生成：将所有被选节点（来自所有深度）的内存嵌入堆叠为M_ret，作为前缀与问题嵌入拼接，输入主干模型生成答案。
- 训练/推理细节：
  - 训练分为两个阶段：语料训练和QA微调。
  - 语料训练：对每个节点v，在文本前插入m_v作为前缀，训练token级语言建模损失LLM(v)，中间节点的m_v通过子节点聚合得到。可选重构损失。
  - QA微调：冻结主干或联合微调，使用生成损失Lgen、路由损失Lroute和选择损失Lsel，以及可选重构损失。路由标签通过将标注证据映射到叶子节点并传播到祖先获得。
  - 推理时：节点内存离线计算并存储。查询向量通过问题前写后读生成。路由无需梯度，仅前向计算。

- 方法流程：
  - 输入完整数据集T = {(xi, mi)}，输出代表性掩码子集M = {mj}：采用类平衡贪心选择，逐步选取最大化加权覆盖得分的掩码，直至达到蒸馏预算。
  - 输入掩码子集M，输出蒸馏数据集S = {(ˆxj, ˜mj)}：对每个掩码mj，使用Freestyle布局到图像扩散模型生成初始图像，经DDIM反演初始化，在引导采样中联合优化Lseg和Lfeat修改噪声预测，最后用分割模型重标注得到合成图像和标签。
- 关键模块/机制：
  - 类平衡贪心选择：从原始数据集中挑选具有代表性和类别平衡的掩码子集；为每个类别c分配权重wc（与频率成反比），每次选择掩码i* = arg max Σ_{c∈Ci} wc * exp(-nc/T)，其中nc为当前c的覆盖计数，T为温度参数，重复直至达到预算。
  - Freestyle布局到图像扩散模型：基于掩码和文本条件生成空间对齐的图像；基于Stable Diffusion，噪声预测器为εφ(zj,t, t, cj, mj)，其中cj为掩码中类名拼接的文本条件，mj为输入掩码。模型在目标数据集上预训练以减少域差距。
  - DDIM反演：改善小物体保留；对真实图像执行DDIM反演得到初始潜变量zj,T，利用公式(4)沿确定性轨迹反向传播，提供更强结构先验。
  - 分割一致性损失Lseg：强制生成图像与目标掩码的像素级对齐；在每步估计干净潜变量ˆzj,0|t并解码为图像ˆxj,0，送入预训练分割模型f计算标准分割损失Lseg(f(ˆxj,0), mj)。
  - 类特征匹配损失Lfeat：对齐生成图像与真实数据集的类级特征分布；计算生成图像各层特征图在各类空间区域上的通道均值ˆμlj,c，与数据集预计算均值μlc计算余弦相似度，损失为1 - cosSim(ˆμlj,c, μlc)在所有层和类上求和。
  - 重标注：修正标签不一致并增强监督信息；对合成图像ˆxj，使用同一分割模型f预测标签˜mj = arg max f(ˆxj)，生成最终蒸馏样本(ˆxj, ˜mj)。
- 公式/目标函数/指标定义：
  - 类平衡贪心选择得分：i* = arg max Σ_{c∈Ci} w_c · exp(-n_c / T)
  - DDIM反演递推：z_{j,t+1} = √α_{t+1} ˆz_{j,0|t} + √(1-α_{t+1}) εφ(z_{j,t}, t, c_j, m_j)
  - 类特征均值：μ_{l,c} = (1/|Ω_{l,c}|) Σ_{(u,v)∈Ω_{l,c}} F_l(u,v)
  - 数据集均值：μ_{l,c} = (1/N_c) Σ_{i:c∈C_i} μ_{l,c}^i
  - 类特征匹配损失：L_feat = Σ_{c∈C_j} Σ_l [1 - cosSim(ˆμ_{l,c}^j, μ_{l,c})]
  - 修正噪声预测：ˆεφ = εφ + ρ_t ∇_{z_{j,t}} L_seg + γ_t ∇_{z_{j,t}} L_feat
- 算法细节：
  - 类平衡贪心选择：初始化空集M，迭代计算每个未选掩码的加权得分，选择最高分者加入M，更新各类覆盖计数n_c，重复直到|M|达到预算。
  - DDIM反演：对每个选定掩码对应的真实图像，使用50步DDIM确定性反向得到初始潜变量。
  - 引导采样：在50步DDIM去噪过程中，每步先计算噪声预测εφ，再计算L_seg和L_feat关于潜变量的梯度，按公式(8)修正预测噪声，然后更新潜变量。
  - 重标注：使用预训练分割模型（如Mask2Former）对合成图像进行推理，取argmax作为新标签。
- 训练/推理细节：
  - 布局到图像扩散模型（Freestyle）在目标数据集上预训练以减少域差距。
  - 蒸馏数据生成使用50步DDIM采样，分类器自由引导尺度设为2.0，DDIM反演也使用50步，尺度1.0。
  - 引导参数：λ_seg=0.05, λ_feat=0.2，引导应用于所有步骤。
  - 重标注使用与引导采样相同的分割模型（如Swin-T）。
  - 蒸馏数据训练时遵循MMSegmentation代码库，对有限数据做少量调整。

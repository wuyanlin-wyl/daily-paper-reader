### 1. Same Question, Different Source, Different Answer: Auditing Source-Dependence in Medical Multi-Source RAG
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29084v1
- 方法流程：
  - Stage 1: 结构化提取——将PDF手册用LlamaParse转换为JSON，保留节标题、段落边界、页元数据。输出：每个手册的JSON结构（含organ, institution, care phase, section列表）
  - Stage 2: HERO-QA检索增强生成——输入：问题+手册JSON。对短手册（<=80k chars）直接使用全文；长手册按文档→section→chunk层级分解，通过长度门控路由，四路检索器（密集、稀疏、节正文、节标题）获取候选，RRF融合，MiniLM交叉编码器重排，再父段落扩展获取上下文。使用Qwen3-32B生成答案并附带检索元数据。
  - Stage 3: 结构化输出评判——对每对答案（A_B），使用结构化输出评判器（Qwen3-32B+JSON mode）在5标签分类上打分，并输出叙事元数据（divergence_topic, clinical_significance）。输出：每问题的源间关系矩阵
- 关键模块/机制：
  - 长度门控（Length Routing Gate）：决定是否跳过检索，直接使用全文，避免短文档的检索遗漏；若手册全文字数≤80k字符，则直接传入全文作为上下文，不进行任何检索；否则进入层级检索流程。
  - 层级文档模型与四路并行检索（Document → Section → Chunk + Four Retrievers）：对长文档提供多视角候选检索，提高召回率；将长文档分解为父节（保留标题）和重叠子块（160词，32词重叠）。四路检索器：(1)稠密检索：使用BAAI/bge-large-en-v1.5对子块做向量检索；(2)稀疏BM25检索子块；(3)节正文导航：BM25检索节正文，命中映射到子块；(4)节标题导航：BM25检索节标题。
  - 融合与重排（Fusion + Rerank）：将四路检索结果合并并提升排序质量；使用Reciprocal Rank Fusion（kRRF=60）融合四个排序，导航信号权重降低。然后将Top- 候选用MiniLM交叉编码器重排，输出最终候选块列表。
  - 父段落扩展（Parent-section Expansion）：恢复候选子块所属的完整节内容，提供更丰富的上下文；重排后的Top-子块回溯到其父节，将整个父节文本作为生成上下文，而非仅子块本身。
  - 结构化输出评判器（Structured-output Judge）：对两个源生成的答案进行源间关系评估，输出5标签分类及叙事元数据；使用Qwen3-32B以JSON模式输出，给定问题、答案A、答案B，输出标签（如COMPLEMENTARY, DIVERGENT等）及divergence_topic和clinical_significance两个字段。经人类标注验证，一致率κ=0.842。
- 公式/目标函数/指标定义：

- 算法细节：
  - HERO-QA层级检索：对每个长手册，先构建文档→节→子块三层索引。查询经长度门控后进入检索阶段：四路检索器并行获取候选，每路返回Top-K（具体K值未给出），然后RRF融合排序（kRRF=60，导航信号权重降低），再经MiniLM交叉编码器重排得到Top-N子块，最后每个子块扩展为其父节全文作为上下文。
  - 评判器评分：使用few-shot提示（未说明shot数），要求LLM以JSON输出5标签之一及元数据字段。

### 2. Brain-IT-VQA: From Brain Signals to Answers
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.29588v1
- 方法流程：
  - 阶段1 - BIT-L预训练：输入fMRI信号和对应图像；Brain Tokenizer将fMRI映射为512维脑令牌（128个簇）；Cross-Transformer通过自注意力和交叉注意力提取表示；分别预测CLIP视觉令牌（1408维）和Q-Former条件令牌（768维），使用两个MSE损失求和训练。
  - 阶段2 - 端到端微调：输入fMRI信号和文本查询；BIT-L生成双通路条件令牌并平均融合；融合后的条件令牌与文本查询前缀共同输入冻结的InstructBLIP（包含冻结EVA-CLIP ViT-g/14图像编码器、可训练Q-Former（LoRA）和冻结Flan-T5-XL语言模型）；使用语言建模损失优化BIT-L和Q-Former。
  - 推理：输入fMRI信号和查询，通过训练好的模型直接生成答案或描述。
- 关键模块/机制：
  - Brain Tokenizer：将fMRI voxel激活映射为紧凑的脑令牌，总结功能相似voxel簇的活性。；使用单头图注意力层，将约40k voxel组织为128个簇，每个簇输出512维脑令牌。
  - Cross-Transformer：脑令牌之间交互，并通过可学习查询令牌提取任务相关表示。；包含5个自注意力块和6个交叉注意力块（8头），隐藏维度768；两个独立的交叉注意力堆栈分别输出CLIP对齐令牌和直接条件令牌，共享同一脑令牌表示。
  - CLIP-aligned pathway：提取与CLIP视觉编码对齐的表示，用于条件语言模型。；查询令牌通过交叉注意力关注脑令牌，输出1408维向量，与EVA-CLIP ViT-g/14的视觉令牌对齐。
  - Direct conditioning pathway：直接从脑活动预测语言模型的条件令牌，学习任务特定软提示。；查询令牌通过独立的交叉注意力堆栈，输出768维条件令牌，直接作为语言模型的前缀/提示。
  - Q-Former (adapted via LoRA)：从脑令牌中提取指令感知特征，结合文本查询进行条件化。；接收来自CLIP对齐通路的表示和文本查询，通过可训练的查询变换器（LoRA微调，r=α=4）输出条件令牌。
  - InstructBLIP (frozen LLM: Flan-T5-XL)：根据条件令牌和文本查询生成最终答案或描述。；冻结的Flan-T5-XL语言模型，以平均后的条件令牌和文本查询前缀为输入，自回归生成答案。
- 公式/目标函数/指标定义：
  - 第一阶段损失：L_stage1 = MSE(CLIP_target, CLIP_pred) + MSE(cond_target, cond_pred)，其中CLIP_target和cond_target分别来自对应图像经InstructBLIP处理后的结果。
  - 第二阶段损失：L_stage2 = Language Modeling Loss，即冻结语言模型的自回归交叉熵损失。
- 算法细节：
  - 脑令牌生成：使用图注意力层聚合voxel信息，每个簇得到一个令牌。
  - 双通路特征提取：两个独立交叉注意力堆栈并行工作，共享脑令牌，分别输出CLIP对齐特征和直接条件特征。
  - 条件令牌融合：将两个通路的输出令牌（经Q-Former处理后的CLIP通路令牌和直接通路令牌）进行平均，得到最终条件令牌。
  - 数据增强：使用预训练Image-to-fMRI编码器（来自[37]）对COCO无标签图像预测fMRI响应，作为额外训练样本。
- 训练/推理细节：
  - 训练分两阶段：第一阶段仅训练BIT-L，冻结其他部分；第二阶段使用LoRA联合微调BIT-L和Q-Former，冻结语言模型。
  - 优化器：AdamW，学习率5e-4，每阶段训练50 epochs，前15 epochs为warmup，学习率在验证集plateau时乘以0.1（patience=5）。
  - LoRA配置：BIT-L LoRA r=α=2；Q-Former LoRA r=α=4。
  - 数据划分：保留10%训练数据作为验证集。
  - 推理：输入fMRI和文本查询，通过模型生成答案，无需图像。
  - 计算资源：单张H200 GPU，阶段1约6小时，阶段2约10小时每数据集。

### 4. GRASP: Plan-Guided Graph Retrieval with Adaptive Fusion and Reranking on Semi-Structured Knowledge Bases
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.30237v1
- 方法流程：
  - Stage 1: 输入查询q，LLM生成JSON计划（含锚点、跳数、目标、风险等级）；执行计划：锚点文本嵌入后在指定类型节点向量索引中查找top-K匹配（name/doc模式），编译为Cypher查询在Neo4j上执行得到每个候选的锚点得分（匹配余弦和）；若目标有relevance_text，对其进行密集编码并计算与候选文档的余弦相似度，加到锚点得分上，得最终图排名。
  - Stage 2: 并行运行多字段密集检索器mFAR得到文本排名；采用RRF融合图排名和mFAR排名：静态RRF使用全局权重w，动态RRF使用由候选数桶和风险等级确定的权重w_hat；融合后得Stage-2排名。
  - Stage 3: 对Stage-2的top-100候选，用LoRA微调的LLM重排序器逐候选计算logit；训练时使用listwise softmax损失（1正+23难负）；推理时将重排序器输出与Stage-2排名再次静态RRF融合，得最终排名。
- 关键模块/机制：
  - Planner (LLM)：将自然语言查询转换为结构化JSON计划，包含锚点（实体提及）、跳数（关系路径）、目标（节点类型和文本约束）和风险等级（控制图分支权重）。；使用指令微调LLM，提示包含角色声明、KG模式、计划结构定义和融合控制块。每个数据集有特定指导（MAG用元路径模板，Amazon用规划规则和少量示例，Prime用示例）。
  - Executor (锚点链接 + Cypher编译 + Neo4j)：执行计划，从SKB中检索候选并赋予锚点得分。；锚点文本用稠密编码器嵌入，在对应节点类型的向量索引中查找top-K匹配（name索引用于短字符串，doc索引用于描述性短语），阈值过滤。将计划编译为单一Cypher查询：锚点展开为UNWIND，跳数展开为MATCH，返回目标变量并计算每行锚点得分（匹配余弦和），若有多路径到达同一目标取最大值。在Neo4j上执行。
  - Dense Rescorer：利用目标中未嵌入图结构的文本约束对候选进行重新评分。；当relevance_text非空时，将其编码为嵌入向量，计算与候选文档嵌入的余弦相似度，加到锚点得分上；若为空则跳过。
  - RRF Fusion (静态/动态)：融合图分支和mFAR分支的排名。；静态RRF：score(c)=w/(k+rank_g)+1/(k+rank_m?) 实际上公式是w/(k+rank_g(c)) + (1-w)/(k+rank_m(c))。动态RRF：w_hat = w_bucket[b(q)] * m_risk[r(q)]，其中b(q)是候选数桶（[1,10],[11,50],...），r(q)是风险等级标签，w_bucket和m_risk为可调向量，在验证集上网格搜索。
  - Multi-Field Dense Retriever (mFAR)：提供基于文本的密集检索结果作为融合的另一分支。；使用现有mFAR模型，它联合编码文档的文本字段和1跳邻居。
  - Fine-tuned LLM Reranker with LoRA：对融合池中的候选进行重新排序。；对每个查询的top-100候选，将候选（节点类型、文本字段、1跳邻居（每关系最多10个））序列化为单文本。使用LoRA适配器微调LLM，采用listwise softmax损失：每个训练步采样组G=24（1正+23难负），计算logits，交叉熵损失将正例排名提升。推理时对top-100输出logits，再与Stage-2排名静态RRF融合。
- 公式/目标函数/指标定义：
  - 静态RRF融合: score(c) = w/(k + rank_g(c)) + (1-w)/(k + rank_m(c))，其中w为全局图权重，k为RRF常数，rank_g和rank_m分别为c在图分支和mFAR分支的排名。
  - 动态RRF融合: score(c) = w_hat(q)/(k + rank_g(c)) + 1/(k + rank_m(c))，其中w_hat(q) = w_bucket[b(q)] * m_risk[r(q)]，b(q)为候选数桶，r(q)为风险等级，w_bucket和m_risk为可调参数。
  - Listwise softmax损失: 对组G=24个候选，LLM输出logits，损失为交叉熵，目标为正例位置。
- 算法细节：
  - 锚点链接：对每个锚点，嵌入文本后在指定类型节点向量索引中查找top-K相似节点，且相似度超过阈值（附录A给出具体值，但原文未在方法中明确阈值数字）。
  - Cypher编译：将JSON计划中的anchors转化为UNWIND子句，hops转化为MATCH模式，target转化为RETURN子句，并计算锚点得分（路径上每个锚点余弦和）。
  - 每查询候选数n_cand与风险等级risk_level传递给Stage 2用于动态权重计算。
  - 动态RRF中的桶划分：n_cand ∈ {[1,10], [11,50], [51,100], [101,500], >500}；风险等级 ∈ {no_trade, weak, normal, aggressive}。
  - 重排序训练：每个查询存储所有正例和top-30最难负例，每个训练步均匀采样1正+23难负，独立采样使每个正例与不同负例配对。
  - 重排序推理：对top-100候选进行批处理评分，输出logits与Stage-2排名用静态RRF融合（w和k在验证集上调优）。
- 训练/推理细节：
  - 训练：使用LoRA微调LLM，优化器、学习率、批次大小等详见附录A（未在提供片段中给出具体值）。
  - 推理：先运行Stage 1和Stage 2得到排名，然后Stage 3对top-100重排序并融合。
  - Amazon和Prime选用动态RRF，MAG选用静态RRF（基于验证集Hit@1选择）。

### 6. Multimodal Distribution Matching for Vision-Language Dataset Distillation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.23482v1
- 方法流程：
  - 数据初始化：使用编码器Ψ提取所有真实图像-文本对的联合嵌入（拼接图像和文本特征），运行K-means聚类（K=合成样本数），选择每个簇中离质心余弦距离最近的样本作为初始合成对。
  - 模型初始化：对图像编码器和文本投影器，将预训练锚点参数与两个独立微调专家的参数在每层进行加权融合，融合系数由专家位移向量的夹角决定（角度越大越依赖锚点），再乘以缩放因子α得到混合教师。

  - 测试时适应机制：在推理阶段将网络适应到目标域，无需真实标注；对测试体积的随机补丁施加相同掩码策略，计算重建损失，仅更新编码器中实例归一化层的参数，保持其他权重冻结。一个epoch后使用完整图像前向得到分割结果。
- 公式/目标函数/指标定义：
  - 总损失函数: L_total = α L_CE + β L_Dice + γ L_cbDice + λ L_rec，其中α=0.1, β=0.9, γ=0.2, λ=0.1
  - L_CE: 交叉熵损失，用于逐体素分类
  - L_Dice: Dice损失，用于体积重叠
  - L_cbDice: 中心线边界Dice损失，基于软骨架化对齐预测和真值中心线与边界
  - L_rec: 重建损失，用于自监督掩码重建任务
- 算法细节：
  - 分支生长：广度优先顺序，每步分支概率随深度指数衰减，半径按Murray's law（r_parent^k = Σ r_child^k, k≈3）缩放
  - 碰撞避免：分支尝试多个方向（最多设定次数），若所有方向均与现有结构碰撞则终止该分支
  - 质量检查：自动筛选子体积，要求流连续（无断开）、无浮岛（小孤立段）、血管体素占比≥5%
  - 训练掩码：随机掩码多个立方体区域，大小从2×2×2到16×16×16体素，掩码内强度设为-1
  - TTA中：从4个扫描随机采样24个96×96×96补丁，单epoch适应，学习率1e-4，仅更新实例归一化层
- 训练/推理细节：
  - 训练硬件：单张NVIDIA H100 GPU，batch size=16
  - 优化器：初始学习率1e-4，线性衰减至1e-5直至收敛
  - 输入预处理：所有图像强度归一化到[0,1]
  - 推理时：首先用TTA适应（1 epoch，仅更新InstanceNorm参数），然后对完整未损坏体积前向传播获得分割，最后移除体积小于预定义阈值的小连通分量

### 13. DV-SFT: Direct Vision Supervision for Fine-Grained Visual Understanding
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.26656v1
- 方法流程：
  - 输入图像，使用文本检测和识别模型进行字级OCR，获取单词及其空间位置。
  - 通过Image-to-Label方法：将单词与视觉token对齐，选取单词右下角对应的视觉token作为标签；过滤过大单词和词化长度超过3的单词，并去重。
  - 通过Label-to-Image方法：使用文档问答数据集和绘图工具，将单词逐个渲染到空白图像的补丁网格上，每个单词仅作为其所在最后一个视觉token的标签。
  - 将视觉标签和文本标签混合，进行端到端微调。训练时，计算文本损失L_t和视觉损失L_v，视觉损失使用下一个token预测目标，仅预测视觉标签的第一个子词。
  - 应用视觉平滑：视觉token的损失不仅包含自身标签，还均匀学习图像中所有其他视觉标签，类似于标签平滑。
- 关键模块/机制：
  - Vision Label Construction：为每个视觉token自动生成显式的单词标签。；包含两种互补方法：Image-to-Label使用OCR（文本检测+识别）提取单词及其边界框，将单词分配给其右下角对应的视觉token；Label-to-Image使用文档数据集和绘图工具，将单词精确渲染到空白图像的补丁网格上，每个单词仅作为其占据的最后一个视觉token的标签。过滤规则：词化长度>3或高度>3倍补丁大小的单词被丢弃；同一视觉token被分配多个标签时只保留一个。
  - Vision Smoothing：缓解视觉编码器双向特性导致的后续token信息泄露，提高监督稳定性。；借鉴标签平滑思想，修改视觉损失：每个视觉token的损失由自身标签项（权重1-β）和均匀分布的其他所有视觉标签项（权重β/(|V|-1)）组成，其中|V|为图像中视觉标签集合大小。最终损失为L_v = -1/m * Σ_i[(1-β)logP(w_i|I≤i;θ) + β/(|V|-1) * Σ_{w'≠w_i} logP(w'|I≤i;θ)]。
  - Unified Next-Token Prediction Training：实现视觉和文本监督的统一端到端训练。；保持标准SFT的架构和训练流程不变，仅修改损失计算：对visual tokens施加与text tokens相同形式的下一个token预测损失。视觉标签仅使用tokenize后的第一个子词进行单步预测，符合视觉logits的首词偏好特性。
- 公式/目标函数/指标定义：
  - 文本损失：L_t = -1/n Σ_i log P(y_i | I, X, Y_{<i}; θ)
  - 视觉损失（基本形式）：L_v = -1/m Σ_i log P(w_i | I_{≤i}; θ)
  - 视觉平滑后损失：L_v = -1/m Σ_i [ (1-β) log P(w_i | I_{≤i}; θ) + β/(|V|-1) Σ_{w'≠w_i} log P(w' | I_{≤i}; θ) ]
  - 总训练损失：L = L_t + λ L_v（λ为平衡系数，论文中默认λ=1）
- 算法细节：
  - 离线标签构建：使用开源OCR检测和识别模型对图像进行字级OCR，得到单词列表和边界框。计算每个视觉token对应的图像区域（基于补丁网格划分），将单词分配给其右下角所在的视觉token。对于Label-to-Image方法，使用绘图工具将单词按对齐位置渲染到空白图像的补丁网格上，每个单词仅作为其占据的最后一个视觉token的标签。
  - 标签过滤：丢弃tokenize后长度>3的单词（避免多子词标签歧义）；丢弃高度>3倍补丁大小的单词（确保标注精确）；同一视觉token若有多个标签，仅保留置信度最高的一个。
  - 训练时，对每个视觉token只计算其标签tokenize后第一个子词的预测损失（one-step prediction），与文本的teacher-forcing不同，视觉token仅需预测当前token的标签。
  - 视觉平滑中，β取0.1，|V|为图像中所有不重复的视觉标签集合大小。
- 训练/推理细节：
  - 训练阶段：在标准SFT流程中，额外为视觉token计算损失。采用离线构建的视觉标签，每张图像对应一组视觉token及其标签。训练时，模型正常前向传播，对每个位置（包含文本和视觉）计算logits，文本部分使用标准交叉熵，视觉部分使用上述视觉损失。反向传播时同时优化文本和视觉损失。
  - 推理阶段：与标准MLLM完全一致，不需要任何额外模块或计算。视觉token的监督仅用于训练，推理时模型正常自回归生成文本。
  - 实验设置：基于Qwen3-VL-2B模型，使用OCR相关的训练数据（如文档理解、图表问答等），训练1个epoch，学习率1e-5，batch size 128，视觉平滑β=0.1。

### 14. AsymVLM: Asymmetric Token Pruning for Efficient Vision-Language Model Inference
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.29535v1
- 方法流程：
  - 输入图像和文本，视觉编码器产生N个视觉token，文本嵌入产生L个文本token
  - 视觉令牌剪枝：学习型评分器计算每个视觉token的重要性分数，基于重要性差距计算自适应保留比例，仅保留top-k视觉token
  - LLM预填充：将保留的视觉token与文本token拼接输入LLM
  - 解码阶段：若生成token超过固定预算，基于当前解码步最后一层平均注意力分数驱逐最低重要性的生成token；多轮对话中按轮次驱逐
  - 输出压缩后的KV cache用于后续生成
- 关键模块/机制：
  - Learned Vision Token Scorer：学习视觉令牌重要性，以输出保留为目标；使用可学习权重w对视觉和文本嵌入进行加权余弦相似度：S = (V_hat ⊙ w) T_hat^T，si = max_j S_ij。通过最小化剪枝前后最后隐藏层的MSE损失训练w，仅更新w，模型冻结，正则化使w接近1。
  - Per-Sample Adaptive Budget：动态调整视觉token保留比例；计算重要性差距g = s_{(k)} - s_{(N-k+1)}，k=floor(N/4)，将g映射到保留比例r(g)。方法A：阈值划分三档（保守/中等/激进）并分配固定比例；方法B：连续线性映射r(g)=clamp(r_target + a(g-g_bar), r_min, r_max)。默认方法A。
  - Threshold-Based Text Token Eviction：在解码阶段控制文本token数量；单轮生成：当生成token超过固定预算时，根据当前解码步最后一层平均注意力分数驱逐最低分数的token。多轮对话：按轮次驱逐，使用跨模态相似度（同一评分器）评分整个上一轮回答，保留所有问题和图像。
- 公式/目标函数/指标定义：
  - S = (\hat{V} \odot w) \hat{T}^\top \in \mathbb{R}^{N \times L}, s_i = \max_j S_{ij}
  - L = \frac{1}{L} \sum_{i=1}^{L} \|h_i^{\text{masked}} - h_i^{\text{baseline}}\|_2^2 + \lambda \|w - 1\|_2^2
  - g = s_{(k)} - s_{(N-k+1)}, \text{其中 } k = \lfloor N/4 \rfloor
  - r(g) = \text{clamp}( r_{\text{target}} + a(g - \bar{g}), r_{\text{min}}, r_{\text{max}} )
- 算法细节：
  - 训练学习评分器：对每个训练样本（DocVQA），做两次前向——基线（无mask）和masked（基于分数mask），计算MSE损失，只更新w。评分器先L2归一化，再加权点积取最大值。
  - 自适应预算：方法A的阈值(g_lo, g_hi)和比例通过网格搜索在验证集上确定。
  - 文本驱逐：单轮使用当前解码步最后一层注意力分数（跨头平均），多轮使用跨模态相似度按轮次驱逐，每个轮次内保留问题与图像。
- 训练/推理细节：
  - 训练：在1500个DocVQA样本上训练学习评分器，冻结VLM所有参数，仅更新w，学习率等超参数未明确提供。
  - 推理：视觉令牌剪枝在预填充前执行，文本驱逐在解码过程中按需触发。

### 2. MARVEL: Universal Murray's Law-informed Vessel Tree Segmentation and Topology Estimation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25363v1
- 方法流程：
  - 输入：医学图像（如视网膜眼底图像、CT/MR血管造影）
  - 阶段1：任意分割骨干网络（如U-Net）输出像素级分割掩膜和半径图
  - 阶段2：从预测的半径图中提取二分叉点（通过骨架化或拓扑分析），获取父血管与子血管半径
  - 阶段3：根据经验宽度-指数映射，为每个分叉点分配目标Murray指数α
  - 阶段4：计算物理损失L_phys，惩罚预测半径偏离目标指数α_Murray约束
  - 总损失：L_total = L_seg (Dice/Cross-Entropy) + λ L_phys，端到端训练
  - 输出：生理合理的血管分割掩膜和半径估计
- 关键模块/机制：
  - 分割与半径预测骨干网络：从输入图像中同时预测像素级分割概率和连续半径值；可替换任意分割backbone（如U-Net、Transformer），在输出层增加一个半径回归头，与分割头并行，共享编码器特征。
  - 拓扑提取与分叉识别模块：从预测的半径图中自动定位二分叉点并提取父子血管半径；对分割掩膜进行骨架化，检测骨架交叉点作为分叉；沿骨架测量每个分支的半径（如距离变换或直接回归值），并匹配父子关系。
  - 经验宽度-指数映射：根据血管宽度（直径）动态确定对应的Murray指数α，替代固定指数；基于高分辨率图像数据拟合的全局映射函数：α = f(d)，其中d为血管直径；反映大血管(α≈3)、中间血管(α≈2)、毛细血管(α>3)的生理规律。
  - 物理损失计算模块：计算可微的Murray定律一致性损失，指导网络输出生理合理的半径关系；对每个二分叉，计算预测的父半径r0和子半径r1, r2代入Murray公式：r0^α_pred = r1^α_pred + r2^α_pred，其中α_pred由宽度映射得到；损失为预测α与目标α_Murray的偏差，或直接度量半径不匹配度。
- 公式/目标函数/指标定义：
  - Universal Murray's Law: r0^α = Σ_{i=1}^N ri^α，其中r0为父血管半径，ri为子血管半径，α为Murray指数
  - 物理损失（示例形式，原文未给出精确函数）：L_phys = (1/N_bif) Σ |α_pred(bif) - α_target(bif)|，或基于半径比的约束
  - 总目标函数：L_total = L_seg + λ L_phys
- 算法细节：
  - 分叉识别：对预测分割掩膜执行骨架化（如zhang-suen算法），检测度数为3的骨架像素作为二分叉点，沿骨架追踪确定父子分支。
  - 半径提取：在骨架点上，利用预测半径图或距离变换获取分支的平均半径（或中值半径）。
  - 经验映射实现：可能通过多项式插值或预计算查找表，将血管直径映射到α值。
  - 物理损失反向传播：整个损失关于网络参数可微，包括骨架化和分叉匹配步骤（通过近似或重参数化）以使梯度传播。
- 训练/推理细节：
  - 训练：端到端训练，同时优化分割损失和物理损失；物理损失权重λ通过交叉验证调节。
  - 推理：直接应用训练好的网络输出分割和半径图，无需额外后处理或显式分叉提取。
  - 骨干网络无关性：适用于CNN、Transformer等不同架构，仅需增加半径预测头。
  - 数据增强：可能包括随机旋转、缩放、弹性变形等，但需保持半径的相对关系。

### 3. CNNs, Transformers, Hybrid, and Vision Language Models for Skin Cancer Detection
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.26294v1
- 方法流程：
  - 患者级别划分：将PAD-UFES-20数据集按患者划分为70%训练、15%验证、15%测试，确保同一患者的所有图像只出现在一个子集中
  - 数据预处理：加载原始RGB图像，不进行裁剪/分割/伪影去除；根据不同模型家族使用对应的预处理（timm的resolve_data_config/create_transform或OpenCLIP预处理），包括调整大小、中心裁剪、规范化
  - 模型适配：替换所有模型的最终分类层为统一的二分类头（Dropout + 256全连接ReLU + Dropout + 线性层输出单个logit），CLIP模型除外（使用提示驱动的余弦相似度分类）
  - 训练优化：使用AdamW优化器、余弦学习率调度带预热、加权BCEWithLogitsLoss处理类别不平衡；混合精度训练、梯度缩放/裁剪、早停（验证AUC早停，耐心10轮）
  - 评估：在测试集上计算AUC、扫描阈值[0,1]得到F1max及对应精确率/召回率/阈值，以及在验证集上选择使特异性约80%的阈值后报告测试集上的灵敏度
  - 视觉语言模型两阶段微调：先冻结编码器训练轻量头，然后解冻最后几个transformer块以较低学习率微调
- 关键模块/机制：
  - 统一二分类头：确保不同骨干网络的特征提取结果被映射到相同的输出空间，实现公平比较；由Dropout (0.5)、256单元全连接层+ReLU、Dropout、线性层组成，输出单个logit表示恶性概率。所有非VLM模型（CNN、ViT、混合）均使用此头，VLM中SigLIP使用相同头，CLIP使用提示分类
  - CLIP提示分类模块：利用CLIP的文本-图像对齐能力进行零样本或微调分类；将恶性病变提示（如'malignant skin lesion'）编码为单个恶性原型向量，通过计算图像嵌入与原型向量的余弦相似度得到logit，并加上可学习的logit缩放因子和类别偏置
  - SigLIP两阶段微调：在冻结骨干下训练分类头后再解冻部分骨干，平衡特征迁移与新任务适应；第一阶段冻结SigLIP图像编码器所有权重，仅训练附加的二分类头；第二阶段解冻最后几个transformer块，以较低学习率与分类头一起微调
  - 加权BCEWithLogitsLoss：处理皮肤癌数据集中类别不平衡（癌症样本较少）；根据训练集中癌症与非癌症样本比例计算权重，在BCEWithLogitsLoss中为每个类别分配权重，使模型更关注少数类
  - 患者级别数据划分：防止因同一患者的不同图像出现在不同划分中导致的数据泄露；基于患者ID将数据集分为训练（70%）、验证（15%）、测试（15%），确保患者级别的严格分离
- 公式/目标函数/指标定义：
  - F1分数：F1 = 2·precision·recall / (precision + recall) （公式1）
  - 加权BCE损失：L = -w_pos·y·log(σ(logit)) - w_neg·(1-y)·log(1-σ(logit))，其中w_pos和w_neg根据类别频率设置
  - AUC：ROC曲线下面积
  - 灵敏度 at 80%特异性：在验证集上选择使特异性≈80%的阈值，在测试集上报告该阈值下的灵敏度
- 算法细节：
  - 梯度累积：在显存受限时累积多个小批量的梯度后更新，增加有效批量大小
  - 混合精度训练（torch.amp）：使用自动混合精度加速训练并减少显存消耗，同时应用梯度缩放避免精度下溢
  - 早停：监控验证AUC，若连续10轮无改善则停止训练
  - 阈值选择：对于F1max，在[0,1]区间内逐点计算F1，取最大值对应的阈值；对于80%特异性，在验证集ROC曲线上找到最接近80%特异性的阈值，然后应用于测试集
  - 温度缩放（VLM）：对VLM输出的logits应用温度缩放（除以温度参数）以改善校准，温度参数在验证集上通过最小化负对数似然学习
- 训练/推理细节：
  - 固定随机种子确保可重复性
  - 优化器：AdamW，参数分组：骨干网络较低学习率（如0.00001）和较高权重衰减（如0.05），分类头较高学习率（如0.001）和较低权重衰减（如0.01）
  - 学习率调度：余弦退火调度，包含热身（warmup）阶段（通常5轮）
  - ViT模型使用更强的训练增强：随机调整大小裁剪、水平翻转、颜色抖动、随机擦除
  - VLM的两阶段训练：第一阶段冻结骨干训练头（约10轮），第二阶段解冻最后块微调（约20轮）
  - 所有训练使用批量大小视显存调整，配合梯度累积达到有效批量大小

### 4. Toward Semantic-Agnostic and Shape-Aware Vision-Language Segmentation Models
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.28348v1
- 方法流程：
  - 阶段1：对象裁剪。使用GT二值掩码将目标对象从原图中裁剪出来，仅保留对象本身，去除上下文干扰。
  - 阶段2：描述生成。将裁剪后的对象图像输入描述VLM (InternVL 2.5)，并执行以下两种策略之一：DISP策略强制VLM从预定义的语义无关词典中选择词汇生成描述；EXSP策略通过提供正负例子（不含/含语义的描述）引导VLM生成描述。
  - 阶段3：后处理/过滤。对于DISP描述，使用外部LLM (Mistral 7B) 将其重写为更自然的句子，且不添加新信息；对于EXSP描述，使用LLM-as-a-judge (LLMJ) 判断是否包含语义，过滤掉语义描述。
  - 阶段4：微调分割VLM。将生成的SANSA提示（描述）与原始图像配对，使用LoRA微调LISA 7B的LLaVA部分和视觉解码器，训练分割模型根据提示输出对应掩码。
- 关键模块/机制：
  - 描述VLM (InternVL 2.5)：根据裁剪对象图像生成文本描述，用于构建语义无关提示；接收掩码裁剪后的对象图像和指令，输出描述。在DISP中，输出词汇被限制在预定义字典内；在EXSP中，通过正负样本示例引导输出。
  - DISP: 词典约束提示生成：强制VLM只使用语义无关的词汇生成描述，彻底避免语义；定义只包含颜色、形状、纹理、图案、光照等感知属性的词汇字典，以及连接词。VLM的输出被限制为仅从该字典中选取词汇。
  - EXSP: 示例引导提示生成：通过示例让VLM学习生成语义无关描述，允许更多样化的输出；提供一组正面例子（不含语义的描述）和负面例子（含语义的描述），引导VLM生成类似正面例子的描述，不限制词汇。
  - LLM后处理 (Mistral 7B)：将DISP生成的不连贯词典描述重写为自然流畅的句子；接收DISP输出的词汇序列，使用外部LLM重新组织成完整的句子，严格保持原始描述中的信息（只换叙述方式，不增删属性）。
  - LLMJ过滤 (LLM-as-a-judge)：检查EXSP生成的描述是否含有语义词汇，确保提示的语义无关性；不给允许词列表，仅让LLM判断一段文本描述是否为语义无关（仅包含感知属性）。若判断为含语义则丢弃该提示。
  - 分割VLM (LISA 7B) + LoRA微调：接收图像和SANSA提示，输出分割掩码；通过LoRA轻量微调适应新任务；使用LISA 7B架构（基于LLaVA），冻结大部分参数，对LLaVA的多模态模块应用LoRA（秩参数未明确），并训练视觉解码器（生成mask的decoder）。损失函数为BCE+Dice组合。
- 公式/目标函数/指标定义：
  - L = λ1 * BCE(Ŷ, Y) + λ2 * Dice(Ŷ, Y)，其中λ1=0.25, λ2=1, Ŷ为预测掩码, Y为真实掩码
- 算法细节：
  - 对每个训练样本：根据GT掩码裁剪目标对象，得到仅含对象的图像。
  - DISP：使用预定义语义无关词典，通过描述VLM生成由该词典内词汇组成的描述。然后LLM后处理重写为完整句子。
  - EXSP：提供正负示例，让描述VLM生成描述。然后LLMJ判断：若含语义则丢弃该样本，否则保留。
  - 微调阶段：将保留的(图像, SANSA描述)对输入LISA 7B，使用LoRA（秩r=8? 论文未明确但通常）微调LLaVA，同时微调视觉解码器。
  - 推理时：使用相同的描述VLM生成提示（测试时EXSP也经过LLMJ过滤），然后使用微调后的LISA模型进行分割。
- 训练/推理细节：
  - 训练时只对EXSP生成的描述不进行LLMJ过滤（允许少量语义保留），以帮助模型维持语义分割能力；测试时对EXSP描述严格进行LLMJ过滤以准确评估语义无关性能。
  - 使用LISA 7B作为基础分割VLM，采用LoRA微调LLaVA（多模态部分），并训练视觉解码器。
  - 损失函数为加权BCE+Dice损失，权重λ1=0.25, λ2=1。
  - 训练数据来自合成生成的SANSA提示（基于COCO等数据集），具体数据集细节见补充材料。

### 6. Correcting Visual Blur Induced by Attention Distraction to Reduce Hallucinations: Algorithm and Theory
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.24602v1
- 方法流程：
  - 输入：当前解码步的Transformer层多头注意力分数（对图像和文本令牌）
  - 步骤1：跨头注意力分散校正：选择top-k注意力头计算平均注意力图和方差图，利用方差作为正则项惩罚分散区域，得到修正后的视觉注意力分数Δ₁ = Avg - α·Var
  - 步骤2：动态历史注意力增强：维护历史步的视觉注意力记忆，计算当前注意力与历史注意力的峰值差异，动态门控系数Δ₂ = γ·HistoricalVisualAttn，形成最终修正注意力 = 原始注意力 + Δ₁ + Δ₂
  - 输出：修正后的视觉注意力分数，用于后续解码和令牌生成
- 关键模块/机制：
  - 跨头注意力分散校正模块 (Head-Level Attention Distraction Correction)：修正多头注意力在空间上的不一致，集中视觉焦点；从所有注意力头中选出与视觉令牌注意力分数最高的top-k个头，计算这些头在图像位置的注意力均值和方差。通过均值保留高置信区域，方差惩罚分散区域，形成校正项Δ₁ = Avg - α·Var，其中α是超参数，然后叠加到原始注意力上。
  - 动态历史注意力增强模块 (Dynamic Historical Attention Enhancement)：缓解视觉注意力随解码步数增加而衰减的现象；维护一个历史视觉注意力列表（每个解码步的视觉注意力分数），在当前步计算视觉注意力与文本注意力的峰值差，作为动态门控信号。当检测到当前视觉注意力峰值低于历史峰值时，从历史中选择相关步的注意力（通过相似度或峰值匹配），融合成增强项Δ₂ = γ·HistoricalVisualAttn，其中γ由门控生成。最终注意力为原始+Δ₁+Δ₂。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 推理时，对于每个解码步，首先获取MLLM中所有注意力头的注意力矩阵，筛选出与图像令牌对应的部分
  - 计算每个注意力头在图像区域的注意力熵，选择熵最低（最集中）的top-k个注意力头
  - 将选定头的注意力图进行平均得到Avg，并计算方差得到Var，得到校正项Δ₁ = Avg - α·Var
  - 同时，维护一个固定长度的历史注意力队列，存储最近若干步的视觉注意力图
  - 计算当前步视觉注意力最大分数与文本注意力最大分数之差，若差大于阈值，则从历史队列中检索与当前图像区域最匹配的历史注意力（通过拓扑结构比较），使用动态门控生成融合权重γ
  - 将历史增强项Δ₂ = γ * 历史注意力图加到当前注意力上
  - 最终注意力分数 = 原始注意力分数 + Δ₁ + Δ₂，用于后续层和输出
- 训练/推理细节：
  - AFIP是训练自由方法，无需任何额外训练或微调
  - 在推理阶段作为即插即用模块嵌入MLLM的注意力层之后

### 9. Leveraging Visual Signals for Robust Token-Level Uncertainty in Vision-Language Generation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.27136v1
- 方法流程：
  - 输入：图像x_v和文本x_l，生成自回归令牌序列y_1,...,y_T。
  - 对于每个生成令牌y_t：a) 计算令牌熵H(y_t|x,y_{<t})；b) 计算分布视觉接地得分S_JSD(y_t,x)=JSD(p_θ(·|x_v,x_l,y_{<t}) || p_θ(·|∅,x_l,y_{<t}))；c) 计算注意力视觉接地得分S_A^{(l)}(y_t,x)=平均跨头视觉补丁注意力总和；d) 加权得分=α_JSD S_JSD + α_A S_A；e) 加权令牌不确定性=加权得分 * H。
  - 输出：序列总不确定性为令牌加权不确定性的和（或平均/最大）。
- 关键模块/机制：
  - 分布视觉接地得分：量化视觉输入对令牌预测分布的贡献；计算有图像分布与无图像分布（图像置为∅）之间的Jensen-Shannon散度，值越大表示视觉影响越大。
  - 注意力视觉接地得分：量化令牌预测时对视觉补丁的注意力强度；在特定层l，对所有注意力头，将分配给所有视觉补丁的注意力权重求和，再平均头数，得到该令牌的视觉注意力质量。
  - 加权融合机制：将两种视觉接地得分线性组合后乘以令牌熵；使用超参数α_JSD和α_A（默认各0.5）加权组合两种得分，再乘以令牌熵H，得到最终令牌级不确定性。
- 公式/目标函数/指标定义：
  - 令牌熵：H(y_t|x,y_{<t}) = -∑_{v∈V} p_θ(v|x,y_{<t}) log p_θ(v|x,y_{<t})
  - 分布视觉接地得分：S_JSD(y_t,x) = JSD( p_θ(·|x_v,x_l,y_{<t}) || p_θ(·|∅,x_l,y_{<t}) )
  - 注意力视觉接地得分：S_A^{(l)}(y_t,x) = (1/H) ∑_{h=1}^H ∑_{i=1}^{|x_v|} [α^{(l,h)}_v]_i
  - 加权令牌不确定性：U_t = (α_JSD S_JSD + α_A S_A^{(l)}) * H(y_t|x,y_{<t})
  - 序列总不确定性：U(y) = ∑_{t=1}^T U_t （或平均/最大）
- 算法细节：
  - 分布得分计算需要两次前向：一次使用原始图像，一次使用空图像（∅），对比两种条件下的预测分布。
  - 注意力得分从选定的LLM层l（实验中通常选最后层）提取，对所有注意力头的视觉补丁注意力权重求和并平均。
  - 加权系数α_JSD和α_A在实验中设为0.5，可调节。
  - 整个过程无需额外训练，仅依赖一次生成（但分布得分需要两次前向，可与生成并行计算）。
- 训练/推理细节：
  - 训练：无需训练，完全无需修改模型参数或添加可学习模块。
  - 推理：单次前向生成序列，同时计算每个令牌的熵（从softmax分布直接获得）；分布得分需要二次前向（空图像），注意力得分从中间层提取。总计算量为两次前向加轻量后处理。

### 12. Mitigating Object Hallucinations in Vision-Language Models through Region-Aware Attention Recalibration
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.24957v1
- 方法流程：
  - 输入：图像和文本提示，进入LVLM的中间到深层transformer层
  - 步骤1：在自回归解码阶段，对每一层，计算所有注意力头的注意力图，获取稳健中位数共识（Robust Median Consensus）作为视觉锚点
  - 步骤2：计算跨头分歧的空间方差图（Spatial Variance Map），评估每个空间区域的幻觉风险，据此分配动态干预预算
  - 步骤3：基于干预预算生成自适应软掩码（adaptive soft mask），对注意力路径进行连续惩罚调制，抑制高分歧区域的注意力
  - 输出：重校准后的注意力，用于生成下一个token
- 关键模块/机制：
  - 稳健中位数共识 (Robust Median Consensus)：建立稳定的视觉锚点，提供可靠的视觉表示；在每层中，对所有注意力头的注意力图逐位置计算中位数，得到稳健的中间表示，对异常头不敏感。
  - 空间方差图 (Spatial Variance Map)：评估每个空间区域跨注意力头的分歧程度，以确定幻觉风险；计算每个空间位置上所有注意力头注意力值的方差或差异度量，生成方差图，高方差区域表示头间分歧大，可能包含幻觉诱导路径。
  - 动态干预预算分配 (Dynamic Intervention Budget)：根据空间方差图决定每个区域需要抑制的程度；将方差图映射到干预预算，方差越高的区域分配越大的抑制预算，实现自适应调整。
  - 自适应软掩码 (Adaptive Soft Mask)：对注意力路径进行连续惩罚调制，而非硬截断；根据干预预算生成连续的掩码值（0到1之间），与原始注意力权重相乘，平滑抑制高分歧区域的注意力，保留低分歧区域的原始注意力。
- 公式/目标函数/指标定义：
  - CHAIR指标：C_S = N_hal_cap / N_all_cap, C_I = M_hal_obj / M_all_obj
  - POPE：平均F1分数（Random, Popular, Adversarial三个设置）
  - MME：多维度感知和认知评估
- 算法细节：
  - SADI在自回归解码阶段操作，仅在中间到深层transformer层进行干预。
  - 算法步骤：1) 计算每层所有注意力头的注意力图A_h；2) 逐位置取中位数得到共识注意力图A_med；3) 计算每个位置上的跨头方差V = var_h(A_h)；4) 根据V映射到动态预算B，例如B = sigmoid(alpha * (V - threshold))；5) 生成软掩码M = 1 - B（或类似形式）；6) 修正注意力: A_h' = A_h * M + A_med * (1 - M) 或类似加权组合。
  - 干预预算由空间方差图动态决定，确保只在分歧大的区域施加抑制。
- 训练/推理细节：
  - 训练无关：SADI不需要任何额外训练，是即插即用的推理策略。
  - 推理时：基于贪心解码，仅需单次前向传播，无需对比解码的额外计算开销。
  - 超参数：干预层范围、空间预算的边界可根据不同LVLM架构微调。

### 16. Structure-Aware RAG: Structured Retrieval Augmented Generation from Noisy Data for Conversational Agents

- 方法流程：

  - 步骤3：检索增强生成 - 输入：用户查询和生成的表格集合；处理：检索相关表格（可能通过向量相似度），将表格内容用于LLM生成；输出：最终回答

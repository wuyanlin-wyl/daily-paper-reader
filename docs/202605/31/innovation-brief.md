### 2. MARVEL: Universal Murray's Law-informed Vessel Tree Segmentation and Topology Estimation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25363v1
- 方法流程：
  - 输入图像进入分割网络（如U-Net）
  - 网络同时输出分割掩膜和半径映射
  - 对分割掩膜进行骨架化提取血管中心线
  - 检测中心线上的分叉点（bifurcation points）
  - 在分叉点处，根据预测的半径计算Murray定律偏差
  - 将偏差作为物理正则化损失加入总损失，与分割损失一起优化
- 关键模块/机制：
  - 半径预测头：从分割网络的特征图中预测每个像素对应的血管半径；作为解码器的一个分支，输出连续值半径映射，通常在分割掩膜内部预测半径
  - 分叉点提取模块：定位血管树中的分叉位置，用于施加Murray定律约束；对分割掩膜进行骨架化（如Distance Transform + thinning），然后识别度≥3的节点作为分叉点
  - 宽度-指数映射：根据血管宽度确定Murray指数α，适应不同尺度的生理规律；从高分辨率血管图像中统计建立宽度与α之间的经验映射函数，训练时从预测半径索引对应α
  - 物理损失函数：惩罚分叉处预测半径偏离Murray定律的程度；对每个分叉点计算 L_phys = |r0^α - Σ ri^α| 或类似形式，作为可微分的正则化项
- 公式/目标函数/指标定义：
  - Universal Murray's law: r0^α = Σ_{i=1}^N ri^α
  - 总损失 L_total = L_seg + λ * L_phys
  - 物理损失 L_phys 计算分叉处半径的Murray定律偏差
- 算法细节：
  - 半径预测：通过解码器分支直接回归连续半径值
  - 分叉检测：对二值掩膜骨架化，通过卷积核检测连接数≥3的像素
  - 宽度-指数映射：在训练前从数据统计确定，如对不同直径区间赋予不同α
  - 物理正则化梯度回传：L_phys对半径预测可微分，从而更新整个网络
- 训练/推理细节：
  - 训练时同时优化分割损失和物理正则化损失
  - 推理时仅使用分割网络，无需额外的物理约束计算
  - 基于八个公开数据集训练，覆盖视网膜、冠脉、脑血管等多种模态
  - 可适配多种分割主干（如U-Net、TransUNet等）

- 原文链接：https://arxiv.org/abs/2605.26294v1
- 方法流程：

- 公式/目标函数/指标定义：
  - F1 = 2 * precision * recall / (precision + recall)
  - 损失函数：加权二值交叉熵损失（weighted BCEWithLogitsLoss）

- 算法细节：

  - 学习率调度：余弦退火，含线性warmup。
  - 梯度累积：增加有效批次大小以适应显存限制。

### 5. SliceWorld: A Predictive and Controllable World-State Model for CT Report Generation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.24371v1
- 方法流程：
  - 输入：CT轴向切片序列 V = {x_t}_{t=1}^T
  - 阶段1 - CT编码：对每个切片x_t，用图像编码器f_img提取视觉特征e_t，加位置编码，通过因果序列编码器f_seq得到上下文表示h_t
  - 阶段2 - 世界状态构造：从h_t分别通过三个线性层得到解剖状态a_t、病灶状态l_t、不确定性状态u_t，构成s_t = [a_t; l_t; u_t]；并附加病灶存在头预测概率b_mt
  - 阶段3 - 世界令牌投影：用ftok将s_t投影为世界令牌w_t，再经过两层MLP映射为LLM输入空间z_t
  - 阶段4 - 报告生成：将z_1:T序列作为前导令牌输入LLM，自回归生成报告R
  - 阶段5（可选） - 病灶因子干预：构造病灶中性化状态s_t^(lesion-zero)=[a_t;0;u_t]，投影为令牌后生成反事实报告
- 关键模块/机制：
  - 因果切片序列编码器 (f_seq)：编码当前前缀切片的历史信息，确保不使用未来信息；输入e_1:t + p_1:t，输出h_t ∈ R^{d_h}，只依赖x_1:t
  - 因子感知状态构造器 (fanat, fles, func)：将上下文表示分解为解剖、病灶、不确定性三个因子；a_t = fanat(h_t), l_t = fles(h_t), u_t = func(h_t)；各为独立线性层
  - 病灶存在头 (f_occ)：预测当前切片是否为病灶相关切片；b_mt = σ(f_occ(l_t))，使用sigmoid输出概率
  - 多步未来预测头 (f_pred,k^h 和 f_pred,k^w)：从隐藏状态或世界令牌预测第k步未来切片特征；两组预测头，分别接h_t和w_t，输出预测特征ê_(t+k)
  - 世界令牌投影器 (ftok)：将因子感知状态映射为LLM可用的令牌；单层线性投影：w_t = ftok(s_t)；再用两层MLP flm映射到LLM隐藏空间
- 公式/目标函数/指标定义：
  - 整体损失: L = α_mfp L_mfp + α_fas L_fas + α_cf L_cf + α_ctrg L_ctrg
  - 多步未来预测损失: L_mfp = λ_h L_mfp^h + λ_w L_mfp^w，其中L_mfp^h = 1/(K(T-K)) Σ_{t=1}^{T-K} Σ_{k=1}^K ||ê_{t+k}^{(h,k)} - e_{t+k}||_2^2，L_mfp^w类似
  - 因子感知状态损失: L_fas = λ_smooth L_smooth + λ_sparse L_sparse + λ_unc L_unc + λ_occ L_occ
  - 解剖连续性: L_smooth = 1/(T-1) Σ_{t=2}^T ||a_t - a_{t-1}||_2^2
  - 病灶稀疏性: L_sparse = 1/T Σ_{t=1}^T ||l_t||_1
  - 不确定性对齐: L_unc = 1/(T-K) Σ_{t=1}^{T-K} ||g_unc(u_t) - sg[1/K Σ_{k=1}^K Err(ê_{t+k}^{(h,k)}, e_{t+k})]||_2^2
- 算法细节：
  - 因果编码：序列编码器采用因果掩码，每个h_t仅从当前及之前切片计算
  - 状态分解：三个分支独立线性层，无交互，分别输出解剖、病灶、不确定性因子
  - 多步预测：为每个未来步k设置独立的预测头f_pred,k，从h_t或w_t映射到特征空间
  - 反事实中性化：保持解剖和不确定性不变，将病灶因子设为零向量
  - 损失计算中的梯度停止：在不确定性对齐中，对平均预测误差使用stop-gradient
  - 预训练与微调分离：预训练时α_ctrg=0，参数优化；微调时冻结预训练参数，仅优化令牌投影和LLM
  - 病灶存在监督：使用DeepLesion的病灶切片范围标签作为m_t
- 训练/推理细节：
  - 预训练阶段：在DeepLesion数据集上，使用多步未来预测、因子感知和反事实目标优化世界状态编码器和预测头，不包括报告生成损失
  - 微调阶段：在M3D-Cap和CT-RATE数据集上，冻结预训练模型参数，只训练世界令牌投影器ftok和LLM（或仅调整LLM）以最小化报告生成负对数似然
  - 推理时：可进行病灶因子干预，生成中性化报告用于反事实分析
  - 输入格式：DeepLesion的切片序列按轴向排序；M3D-Cap保持原有图像组；CT-RATE将NIfTI体积转换为窗口化RGB切片序列

### 6. Correcting Visual Blur Induced by Attention Distraction to Reduce Hallucinations: Algorithm and Theory
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.24602v1
- 方法流程：
  - 输入：当前解码步的原始注意力分数（所有头）
  - 头级注意力分散纠正：选择top-k个注意力头（基于注意力熵），计算这些头的视觉注意力分布的均值μ和方差σ，得到修正项Δ1 = μ - α·σ
  - 动态历史注意力增强：从历史注意力记忆中检索前一步的视觉注意力概率，基于当前峰值视觉与文本注意力的差异计算门控值γ，得到修正项Δ2 = γ·历史注意力
  - 融合：将Δ1和Δ2加到原始视觉注意力分数上，得到修正后的视觉注意力分数
  - 输出：修正后的注意力分数用于后续解码
- 关键模块/机制：
  - Cross-head Attention Enrichment：纠正多头注意力的空间不一致，聚焦高置信度区域；对每个解码步，计算所有注意力头的视觉注意力分布的熵，选择熵最小的top-k个头。然后计算这些头的注意力分布的均值μ和方差σ，得到浓缩修正项Δ1 = μ - α·σ，其中α是正则化系数。
  - Dynamic Historical Attention Enhancement：缓解视觉注意力随时间衰减的问题；维护一个历史视觉注意力概率记忆（每步的视觉注意力分布）。当前步根据动态门控值γ（由当前峰值视觉注意力与峰值文本注意力的差值决定）将历史注意力加权融合到当前注意力中，得到修正项Δ2 = γ·历史注意力。
  - Dynamic Gating Mechanism：控制历史注意力的融合程度，防止过度调整；计算当前解码步中视觉注意力最大值与文本注意力最大值的差值，通过映射函数得到门控值γ∈[0,1]。当视觉注意力峰值明显高于文本时，γ较大，历史注意力贡献更多。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
  - 可推断的修正关系：修正后注意力 = 原始注意力 + Δ1 + Δ2
  - Δ1 = μ - α·σ (来自top-k头)
  - Δ2 = γ·历史视觉注意力
  - γ = f( max(视觉注意力) - max(文本注意力) )
- 算法细节：
  - 头部选择：基于注意力熵对注意力头排序，选择熵最小的k个头
  - 方差惩罚：在跨头聚合中引入方差作为正则项，抑制分散的头
  - 历史记忆：存储每步解码后的视觉注意力概率分布
  - 门控计算：当前步视觉注意力最大值与文本注意力最大值的差值，经sigmoid或线性映射得到γ
  - 融合操作：将Δ1和Δ2直接加到原始视觉注意力分数上，然后可能进行softmax归一化
- 训练/推理细节：
  - 无需训练，推理时即插即用
  - 不引入额外的推理开销（参数可预先确定）

### 7. MAIL++: Multi-Modal Bi-directional Agent Layer for Vision-Language Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.25479v1
- 方法流程：
  - 输入：预训练CLIP模型（冻结图像编码器V和文本编码器T），下游任务少样本数据。
  - 步骤1：为每个L层Transformer块中的目标模块（如LayerNorm）后插入对应的智能体层（AL），每个AL包含可学习的缩放向量s和偏移向量b。
  - 步骤2（MAIL）：文本侧AL的缩放向量s_t通过文本到图像桥函数（瓶颈结构）映射到图像侧，生成图像侧AL的缩放向量s_v，实现单向耦合。
  - 步骤3（MAIL++）：引入一个元缩放向量s_meta，通过元文本桥和元图像桥分别映射到文本侧和图像侧AL，实现双向信息交换。
  - 步骤4：训练时，仅优化所有AL和桥函数的参数，保持冻结主干不变；梯度通过桥函数跨模态传播。
  - 推理时：将所有AL的参数重参数化到对应的冻结层中（合并缩放和偏移），不增加额外计算。
- 关键模块/机制：
  - 智能体层 (Agent Layer, AL)：附加在目标计算模块（如LayerNorm）之后，近似该模块在完全微调下的参数更新。；由可学习的缩放向量（Scaling Vector）和偏移向量（Shifting Vector）组成，对目标模块的输出进行仿射变换。
  - 文本到图像桥 (Text-to-Image Bridge)：将文本侧的缩放向量传播到图像侧，实现单向跨模态耦合。；采用瓶颈结构（如全连接层+激活函数+全连接层），输入文本侧缩放向量，输出图像侧缩放向量。
  - 元智能体层 (Meta Agent Layer)：在MAIL++中生成元缩放向量，用于双向调节两模态的智能体层。；由可学习的向量或小型网络生成元缩放向量s_meta，通过元文本桥和元图像桥分别映射到文本和图像智能体层。
  - 元文本桥和元图像桥：实现双向跨模态信息传递，去除MAIL的单向偏差。；分别为从元缩放向量到文本侧和图像侧缩放向量的映射函数，通常为线性投影或小型MLP。
- 算法细节：
  - 智能体层的参数更新通过桥函数耦合：在MAIL中，图像侧智能体层的缩放向量由文本侧缩放向量通过桥函数生成；在MAIL++中，文本和图像侧缩放向量分别由元缩放向量通过各自桥函数生成。
  - 桥函数设计为瓶颈结构（降维-激活-升维），以控制参数量。
  - 训练时，所有智能体层和桥函数参数通过对比损失（如CLIP的InfoNCE）联合优化。
- 训练/推理细节：
  - 训练：冻结CLIP双编码器主干，仅优化智能体层和桥函数参数；梯度通过桥函数跨模态反向传播。
  - 推理：将智能体层的缩放和偏移合并到对应的冻结层中（例如，调整LayerNorm的权重和偏置），使得推理时网络结构与原始CLIP完全一致，无额外计算开销。

- 区域：quick；分数：8.0

- 方法流程：

  - 加权组合：VIG-TUQ得分 = α_JSD * SJSD + α_A * SA(l)

- 关键模块/机制：

  - 注意力基视觉接地得分模块：通过注意力权重度量视觉令牌对生成令牌的影响；从选定的Transformer层中，提取所有注意力头中分配给视觉令牌的注意力权重，求平均和总和（在视觉令牌上求和，在头上平均）作为得分。
  - 令牌熵计算模块：计算语言模态下每个令牌的预测不确定性；使用标准自回归分布计算每个令牌的负对数似然熵。
  - 加权融合模块：将视觉接地得分与令牌熵结合；线性组合：VIG-TUQ_t = α_JSD * SJSD(yt,x) + α_A * SA(l)(yt,x)，然后乘以令牌熵 H(yt|x) 得到加权不确定性。α_JSD和α_A为超参数。
- 公式/目标函数/指标定义：
  - 分布基得分：S_JSD(y_t, x) = JSD(p_θ(·|x_v,x_l,y_{<t}) || p_θ(·|∅,x_l,y_{<t}))
  - 注意力基得分：S_A^{(l)}(y_t, x) = (1/H) ∑_{h=1}^H ∑_{i=1}^{|x_v|} [α_v^{(l,h)}]_i
  - 令牌熵：H(y_t|x) = -∑_{v∈V} p_θ(v|x,y_{<t}) log p_θ(v|x,y_{<t})
  - VIG-TUQ序列级不确定性：VIG-TUQ(x) = (1/T) ∑_{t=1}^T [α_JSD S_JSD(y_t,x) + α_A S_A^{(l)}(y_t,x)] H(y_t|x)

  - 算法1：VIG-TUQ。输入：图像 x_v，文本提示 x_l；输出：序列级不确定性得分。

  - 步骤2：对于每个令牌 t=1..T：
  - a) 执行两次前向传播：一次有图像，一次无图像（图像注意力掩码或嵌入置零），获取 logits；计算 JSD 得到 S_JSD。
  - b) 从第 l 层收集注意力权重，计算视觉令牌上的平均注意力质量 S_A^{(l)}。
  - c) 从有图像的前向传播中获取词汇分布，计算令牌熵 H。
  - d) 计算加权得分 w_t = α_JSD S_JSD + α_A S_A^{(l)} (α 为超参数)。
  - 步骤3：计算序列级不确定性为 (1/T) ∑ w_t H_t 或 max_t w_t H_t。
- 训练/推理细节：

  - 推理时只需一次（或两次）前向传播，无需采样或外部模型。
  - 适用于早期融合、晚期融合和原生融合等多种LVLM架构。

### 12. Mitigating Object Hallucinations in Vision-Language Models through Region-Aware Attention Recalibration
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.24957v1
- 方法流程：
  - 输入：当前解码步骤中某一Transformer层的所有注意力头输出（键值或注意力加权值）。
  - 步骤1：稳健中位数共识：对所有注意力头的输出特征逐元素取中位数，得到一个全局共识特征作为视觉锚点。
  - 步骤2：空间方差图计算：计算每个空间位置上各注意力头输出的方差，得到空间方差图，用于指示跨头分歧程度。
  - 步骤3：动态干预预算分配：根据空间方差图的值，为每个位置分配一个连续的干预强度（预算），方差越大则干预越强。
  - 步骤4：自适应软掩码生成：基于干预预算生成一个软掩码，对原始注意力头输出进行加权，抑制高分歧位置的异常注意力，同时保留低分歧位置的正常特征。
  - 输出：经重校准后的注意力头输出，用于后续层或预测。
- 关键模块/机制：
  - Robust Median Consensus：建立稳定的视觉锚点，作为可靠注意力模式的参考基准；对给定层中所有注意力头的输出特征（如注意力加权后的视觉特征）沿头维度逐元素取中位数，得到共识向量。中位数对异常值具有鲁棒性，避免少数幻觉主导的注意力头扭曲锚点。
  - Spatial Variance Map：量化跨注意力头在空间位置上的不一致性，用于识别高幻觉风险区域；计算每个空间位置（如图像patch对应位置）上各注意力头输出值的方差，形成二维方差图。方差越高，说明头间注意力分歧越大，指示潜在语义漂移。
  - Adaptive Soft Mask：动态抑制高分歧区域的异常注意力路径，同时保持低分歧区域的正常语义；根据空间方差图映射得到的干预预算（可能通过归一化或单调映射函数），生成一个与注意力图同形的软掩码。对于每个位置，软掩码值介于0和1之间，高方差位置分配低权重，低方差位置分配高权重。将原始注意力输出与软掩码逐元素相乘，实现连续惩罚调制。
- 公式/目标函数/指标定义：
  - CHAIR句子级度量：C_S = N_hal_cap / N_all_cap
  - CHAIR实例级度量：C_I = M_hal_obj / M_all_obj
  - 其中N_hal_cap为包含幻觉对象的描述数，N_all_cap为所有描述数；M_hal_obj为幻觉对象实例数，M_all_obj为所有被提及的对象实例数。
- 算法细节：
  - 在自回归解码过程中，仅对选定的中间至深层Transformer层（视觉语义交互最活跃的层）施加干预。
  - 计算每个注意力头输出的中位数，作为共识锚点，该操作是逐空间位置和特征维度的。
  - 空间方差图通过计算所有注意力头输出在头维度上的方差得到，该方差图作为幻觉风险的指示器。
  - 干预预算为单调递增函数，将方差图从高到低映射到从强到弱的干预强度。
  - 软掩码生成后，原始注意力头输出乘以软掩码（可能配合残差连接），得到重校准后的输出。
  - 整个流程无需训练，配置参数（干预层范围、预算映射函数）可基于验证集微调。
- 训练/推理细节：
  - SADI是训练无关的推理策略，无需任何微调或额外训练。
  - 基于贪心解码作为基础策略，每次生成仅需一次前向传播，无需对比解码的多次前向。
  - 干预仅应用于解码时选定的中深层Transformer层，浅层和深层保持不变。
  - 默认配置适用于多种LVLM架构，但干预层范围和预算边界可针对不同模型进行实证调整。

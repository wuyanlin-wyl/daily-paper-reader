## 摘要
基于查询的视觉Transformer分割模型通常重构密集空间特征图以预测掩码，继承了卷积架构的设计模式。我们证明这种显式的图像空间重构并非必要。我们提出TokenMask，一种在token空间中的掩码头，直接从查询-令牌亲和度计算掩码logits，并在logit空间而非特征空间中进行插值。这种重新表述保留了原始的线性评分机制，同时简化了计算结构。在不同的ViT骨干网、数据集和分割任务中，TokenMask通过降低计算和内存需求，同时保持竞争性精度，持续提升了相较于先前方法的效率，在使用TensorRT FP16推理的NVIDIA Jetson AGX Orin上实现了显著的加速。总体而言，TokenMask为嵌入式视觉系统提供了更简单、更易于部署的设计。

## Abstract
Query-based Vision Transformer segmentation models typically reconstruct dense spatial feature maps to predict masks, inheriting design patterns from convolutional architectures. We show that this explicit image-space reconstruction is not required. We introduce TokenMask, a token-space mask head that computes mask logits directly from query-token affinities and performs interpolation in logit space rather than feature space. This reformulation preserves the original linear scoring mechanism while simplifying the computational structure. Across diverse ViT backbones, datasets and segmentation tasks, TokenMask consistently improves efficiency over prior approaches by reducing computational and memory requirements while maintaining competitive accuracy, leading to tangible speedups on NVIDIA Jetson AGX Orin using TensorRT FP16 inference. Overall, TokenMask yields a simpler and more deployment-friendly design for embedded vision systems.

- **整体含义**：提出了TokenMask，一种直接在token空间预测掩码的轻量级机制，统一支持语义、实例和全景分割，更适合嵌入式部署。

## 2. 方法论

### 核心思想
- **摒弃特征空间重建**：传统做法是 `T → reshape(F) → upscale(F) → dot_product(m(Q), F)`。TokenMask改为：`L = m(Q) · T^T` 直接在token空间计算每个查询与所有令牌的亲和度（线性打分），再reshape到网格并对logit进行上采样（Q通道，远小于C通道）。
- **上采样位置迁移**：从C通道的特征空间上采样变为Q通道的logit空间上采样（Q ≪ C），计算量大幅降低。甚至可完全去除上采样（仅在patch网格上输出），精度损失极小。

### 关键公式
- 输入：ViT输出补丁令牌 `T ∈ R^{B×N×C}`（N=Hp×Wp），查询 `Q ∈ R^{B×Q×C}`。
- 传统（图像空间）掩码头：`M = m(Q) · F`，其中F是reshape并上采样后的特征图（C通道→C通道上采样）。
- TokenMask：`L = m(Q) T^T` → `L ∈ R^{B×Q×N}`，然后reshape为 `B×Q×Hp×Wp`，最后在logit空间上采样到所需分辨率（Q通道上采样）。

### 算法流程（文字说明）
1. ViT backbone处理图像，输出patch tokens T。
2. 查询Q经过线形投影m(·)得到查询嵌入。
3. 通过矩阵乘法`L = m(Q) T^T`计算所有查询与令牌的相似度，即每个查询对每个令牌的掩码logits。
4. 将L reshape成网格形状（Hp×Wp），得到粗分辨率掩码logits。
5. 可选的logit空间上采样（例如双线性插值）恢复全分辨率掩码logits。
6. 对掩码logits应用softmax或sigmoid，配合类预测进行最终分割。

## 6. 主要结论与发现

- **TokenMask显著提升效率**：与EoMT相比，GFLOPs降低28.3%~53.6%，FPS在Jetson Orin上提升15%~60%，峰值内存减少15%~37%。
- **精度损失可控**：PQ通常下降1.5~2.8点，实例分割mAP下降约2~3.5点（COCO），语义mIoU在多数骨干上几乎持平或略微下降。
- **上采样可以完全去除**：在logit空间去除上采样后，GFLOPs仅额外减少0.1（<1%），PQ最多再降0.4点，说明大部分计算开销来自特征空间的重建而非上采样本身。
- **输出步长为4时最佳**：相对于全分辨率（stride 1），stride 4以几乎无精度损失实现了显著提速（+27% FPS），更大的步长则导致明显质量下降。
- **适合嵌入式部署**：TokenMask简化了计算图，充分利用GEMM优化，减少内存移动，在Jetson Orin上取得实际加速。

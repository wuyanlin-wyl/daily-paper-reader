## 摘要
全切片图像视觉问答（WSI-VQA）将病理学问题构建为极端上下文搜索问题：要回答一个自由形式的临床查询，系统必须首先在严格的检查预算下导航千兆像素级别的切片，以定位稀疏的高分辨率证据。现有方法主要分为两种范式：i) 监督式病理学多模态大语言模型（MLLMs）和代理可以将定位和推理吸收到学习模块中，但它们通常将导航与任务特定监督和重新训练耦合，限制了其实用性；ii) 无训练病理学代理通过保持核心模型冻结来避免这种成本，但通常遵循问题优先设计，主要从查询条件相关性构建初始候选集。这可能会遗漏问题中未命名的决定性形态，并迫使更重的推理时支撑。为了解决这一挑战，我们引入了PathNavigate，一种基于扫描-搜索-读出例程构建的无训练病理学代理。在问题匹配之前，PathNavigate以低放大倍数扫描当前切片，使用共享在线记忆模块在冻结的病理学特征上生成切片特定的惊奇场，标出异常区域池。然后它仅在此池内应用问题条件的PLIP相关性来选择高放大倍数搜索目标。最后，它提取局部高放大倍数证据，并使用冻结的感知器-裁决器堆栈进行回答，使用相同的在线记忆作为切片级上下文。在WSI-VQA和SlideBench-BCNB上的实验表明，所提出的扫描-搜索-读出设计提高了答案准确性，并产生了更具可解释性的证据选择轨迹，同时具有更高的效率。代码已在线提供。

## Abstract
Whole-slide image visual question answering (WSI-VQA) frames pathology as an extreme-context search problem: to answer a free-form clinical query, a system must first navigate a gigapixel slide under a strict inspection budget to locate sparse, high-resolution evidence. Existing approaches largely fall into two paradigms: i) supervised pathology multimodal large language models (MLLMs) and agents can absorb localization and reasoning into learned modules, but they often couple navigation to task-specific supervision and retraining, limiting their practicality; ii) training-free pathology agents avoid this cost by keeping core models frozen, but often follow a question-first design, constructing the initial candidate set mainly from query-conditioned relevance. This can miss decisive morphology that is not named in the question, and force heavier inference-time scaffolding. To address this challenge, we introduce PathNavigate, a training-free pathology agent built around a scan-search-readout routine. Before question matching, PathNavigate scans the current slide at low magnification with a shared online memory module over frozen pathology features, producing a slide-specific surprise field that marks an abnormal-region pool. It then applies question-conditioned PLIP relevance only within this pool to select high-magnification search targets. Finally, it extracts local high-magnification evidence and answers with a frozen perceptor-adjudicator stack, using the same online memory as slide-level context. Experiments on WSI-VQA and SlideBench-BCNB show that the proposed scan-search-readout design improves answer accuracy and yields more interpretable evidence-selection trajectories with higher efficiency.The code is available online.

## 1. 核心问题与整体含义（研究动机和背景）

全切片图像视觉问答（WSI-VQA）要求在千兆像素级别的病理切片中定位稀疏高分辨率证据来回答自由形式的临床问题，本质上是一个极端上下文搜索问题。现有方法分两类：
- **监督式病理MLLMs/代理**：将定位和推理融入学习模块，但需要任务特定监督和重训练，实用性受限。
- **无训练病理代理**：保持核心模型冻结，但通常采用“问题优先”设计——初始候选集主要基于查询条件相关性构建。这会遗漏问题中未命名的决定性形态（如组织学类型、分级关键病灶），且需更重的推理时支撑（如长轨迹、反射、缓存）。

**本文核心挑战**：如何让无训练代理在问题匹配前建立切片特定的搜索先验，同时保持答案时切片上下文与导航状态一致。

## 2. 方法论：核心思想、关键技术细节与流程

**整体思想**：模仿病理医生先低倍浏览建立典型形态认知、再搜索相关发现的流程，提出“扫描-搜索-读出”（Scan-Search-Readout）三阶段例程。

### 2.1 共享在线记忆模块（Shared Online Memory）
- **作用**：为每张切片维护一个在线状态，同时用于扫描时的惊奇分数计算和答案时的上下文读取。
- **结构**：两层GELU MLP，输入/输出维度768（CONCH特征），每张切片重新初始化。
- **更新**：基于自监督重建损失（Huber损失），计算重建梯度范数作为惊奇分数$\sigma_i$。预热期$T_w$内所有图块更新记忆；之后仅当$\sigma_i > \tau_{sur}$时更新，其余应用乘法衰减。
- **读出**：答案时将运行统计（均值、标准差、高惊奇比例、候选数量）压缩为“导航摘要”供裁决器使用。

### 2.2 惊奇引导扫描（Surprise-Guided Scan）
- 在低倍率下提取所有图块，计算惊奇分数形成全场惊奇图。
- 通过阈值化和基于距离的非极大值抑制（NMS）获得ROI池$R(q)$，其中距离参数$\rho(q)$由问题类型（形态学/临床）动态调整。
- 此阶段**仅**由切片内在形态驱动，问题只影响覆盖范围和间距，不参与语义排序。

### 2.3 任务条件搜索（Task-Conditioned Search）
- 在ROI池$R(q)$内，计算每个候选的**PLIP相似度**（问题-图像相关性）和**惊奇分数**。
- 进行池内归一化后融合：$f_\alpha = \alpha \hat{r}_{PLIP} + (1-\alpha)\hat{\sigma}$，默认$\alpha=0.5$。
- 选取top-$K_{search}(q)$作为搜索目标$C(q)$。

### 2.4 证据读出与QA（Evidence Readout and QA）
- 对每个目标，在其高倍邻域内用**局部在线记忆**再次计算惊奇分数，保留top-T高倍图块作为证据$E(q)$。
- 可选：从参考档案中检索k=3个相似案例摘要作为参考上下文。
- 最终：冻结病理VLM（Patho-R1-7B）作为感知器将图块转为证据字符串，冻结语言模型（Qwen3.5-4B）作为裁决器综合区域证据、导航摘要和参考上下文输出答案。

**核心贡献**：记忆状态在扫描和答案阶段共享，避免引入第二个独立存储。

- **依赖H&E形态**：无法直接利用IHC或基因表达信息（如HER2表达级别），限制了在依赖多模态证据场景下的表现。
- **在线记忆仅用于单一切片**：未利用跨切片先验知识（如常见组织形态），可能在某些异常区域不明显时漏检。
- **计算资源要求较高**：虽然无训练，但推理仍需多GPU（RTX 4090）和较长延迟（84秒/问题），实时应用有困难。
- **动态路由简单**：问题类型分类仅通过关键字启发式，对于复杂或模糊问题可能不准确。
- **PLIP融合固定权值**：默认α=0.5，虽通过消融验证，但未实现自适应权值，可能在某些情况下次优。
- **缺乏与其他训练-free代理（如AgentClinic、MedAgents等）的对比**：仅对比了PathAgent，通用性对比不足。

## 摘要
准确的胰腺分割对于早期癌症诊断至关重要，而标注的稀缺性使得半监督学习成为必需。然而，由于样本间显著的形态变异性，现有半监督方法在稀疏监督下泛化能力严重受限，导致监督偏差问题。为此，我们提出基于结构一致性的KAN原型学习（SCKAN），该方法首次利用柯尔莫哥洛夫-阿诺德网络（KANs）构建跨样本结构一致性学习，以实现更泛化和准确的分割。具体而言，SCKAN包含两个关键设计：结构约束原型一致性学习（SPCL）通过原型级对比优化强制跨样本一致性，从而促进无偏结构表征；以及基于一致性的柯尔莫哥洛夫-阿诺德融合（CKaF）通过KAN的自适应B样条非线性聚合稳定一致性并过滤样本级噪声，从而减少形态特异性偏差。在两个公开胰腺数据集上的大量实验证明了SCKAN的有效性。代码见https://github.com/rhodaliu17/SCKAN。

## Abstract
Accurate pancreas segmentation is critical for early cancer diagnosis, where annotation scarcity necessitates Semi-Supervised Learning (SSL). However, due to significant inter-sample morphological variability, existing SSL methods face severe generalizability limitations under sparse supervision, leading to the Supervision Bias problem. To address this, we propose Structural Consensus-based KAN Prototype Learning (SCKAN), which constructs the first cross-sample structural consensus learning with Kolmogorov-Arnold Networks (KANs), to achieve more generalizable and accurate segmentation. Specifically, SCKAN contains two key designs: Structure-constrained Prototype Consistency Learning (SPCL), which prompts unbiased structural representation by enforcing cross-sample consistency via prototype-level contrastive optimization, and Consensus-based Kolmogorov-Arnold Fusion (CKaF), which reduces morphology-specific bias by aggregating stable consensus and filtering sample-wise noise via KAN's adaptive B-spline nonlinearity. Extensive experiments on two public pancreas datasets demonstrate the effectiveness of SCKAN. Code is at https://github.com/rhodaliu17/SCKAN.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：胰腺分割对于早期癌症诊断至关重要，但标注稀缺使得半监督学习（Semi-Supervised Learning, SSL）成为必要手段。然而，胰腺形态在不同样本间存在显著的变异（如头、体、尾位置和形状差异），导致现有SSL方法在仅有少量标注时**泛化能力严重不足**，产生“监督偏差”（Supervision Bias）——模型过分依赖有限标注，对未标注样本预测不稳定，出现欠分割或过分割。
- **背景**：现有SSL方法主要分为一致性正则化（CR）方法和原型学习（PL）方法。CR方法只强制样本级一致性，缺乏跨样本交互；PL方法虽能捕获类别级紧凑表征，但对形态多样的样本泛化差，原型质量受限于稀疏监督。根本原因在于**缺乏跨样本共享的结构先验知识**。
- **动机**：解剖上胰腺可分解为头、体、尾三个子区域，每个子区域的结构语义在不同样本间保持一致性（结构共识），但跨样本关系复杂且高度非线性。柯尔莫哥洛夫-阿诺德网络（KAN）具有强大的非线性拟合能力和自适应B样条局部支持特性，能有效建模复杂关系并过滤形态特异性噪声，因而被引入以解决监督偏差。

## 2. 方法论：核心思想、关键技术、流程

### 2.1 整体框架
- 采用**Mean-Teacher**半监督框架（学生模型+教师模型通过EMA更新）。
- 包含两个核心模块：**SPCL**（结构约束原型一致性学习）和**CKaF**（基于共识的柯尔莫哥洛夫-阿诺德融合），两者通过**共识引导协同学习**联合优化。

### 2.2 SPCL：促进无偏结构表征
- **结构感知空间分解（SSD）**：对预测掩码内的胰腺区域，利用K-means聚类（基于空间坐标）分解为K个空间连贯的子区域（K=3对应头、体、尾），并按空间顺序对齐，保证跨样本的结构对应关系。然后从特征图中提取每个子区域的原型向量（平均池化）。
- **位置一致性校准（PCC）**：包含两个约束：
  - **位置加权对比学习**：在原型空间中，根据区域关系分配权重（同一子区域为正对权重1.0，同一类别不同子区域为0.1），优化跨样本同一子区域对齐和不同类别间的判别性。
  - **位置去相关正则化**：对同一样本内不同子区域原型，限制其余弦相似度不超过阈值α，保持子区域特征多样性。
- **损失**：`L_SPCL = (1-λ_div)*L_opt + λ_div*L_div`，其中L_opt为对比损失，L_div为多样性损失。

### 2.3 CKaF：减少形态特异性偏差
- 将标注样本和未标注样本的结构感知原型分别通过独立的**KAN线性层**提取源特定特征，然后对批次内特征取平均，再通过两层KAN融合获得共享的**结构共识原型**。
- KAN使用可学习的B样条函数，其局部支持特性可以过滤掉个别样本的形态噪声，同时保留跨样本稳定的共识信息。

### 2.4 共识引导协同学习
- 分割网络的预测和基于共识原型的预测（通过特征图与原型相似性得到S）均参与训练，通过混合损失（Dice+CE）和一致性正则化（对未标注数据使用教师伪标签）联合优化。
- 总损失包含监督损失、一致性损失、原型预测损失以及SPCL损失，其中原型相关损失使用高斯预热函数逐渐增加权重。

- SCKAN在**极低标注比例**（如NIH-PAN 5%）下相比所有对比方法取得显著提升：Dice 78.91% vs 第二名MPER 74.88%；在10%时也最优（83.91%）。在MSD-PAN上同样达到最佳或接近最佳。

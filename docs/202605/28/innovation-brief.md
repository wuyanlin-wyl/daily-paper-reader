### 3. DeCoDrift: Stabilizing Decoder Coupling in Closed-Loop Foundation Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25730v1
- 方法流程：
  - 输入: 冻结的SAM ViT-H解码器生成候选掩码和注意力图
  - 阶段1: 注意力引导提示提取 - 使用头平均注意力Ft加权掩码质心/边界框，得到候选提示pt
  - 阶段2: 近端锚定正则化 - 将候选提示pt与锚点p0和上一提示pt-1混合，得到稳定提示pt (有效谱半径≈0.76)
  - 阶段3: 解码器感知候选评分 - 对K个候选掩码，用加权目标函数选择最佳候选，权衡置信度、连续性、不确定性、散度和泄漏
  - 阶段4: 软对象持久化 - 基于AAD/TCS阈值和锚点保留对象，允许最多Kmax次连续丢失后恢复
  - 输出: 稳定后的提示反馈回解码器进行下一次迭代
- 关键模块/机制：
  - Attention-guided prompt extraction：利用解码器自身的注意力作为空间先验，从掩码中提取更准确的提示；通过公式 W(x) = Ft_up(x) * Mt(x) 计算权重，然后加权质心 ct = sum_x x*W(x) / sum_x W(x)，偏置提示到解码器正在关注的区域。
  - Proximal anchor regularization：通过锚定项和平滑项防止注意力漂移和振荡；将注意力提取的提示pt与初始锚点p0和上一时刻提示pt-1进行加权融合，公式隐含：pt = (1-λa-λs)*pt + λa*p0 + λs*pt-1，其中λa=0.4, λs=0.3，有效谱半径约0.76。
  - Decoder-aware candidate scoring：选择既自信又与注意力耦合的候选掩码；目标函数：k* = argmax_k [α*conf_k + β*cont_k - γ*unc_k - δ*div_k - η*leak_k]，其中α=0.35, β=0.25, γ=0.15, δ=0.15, η=0.10。
  - Soft object persistence：通过软保持和锚点恢复处理暂时遮挡对象；对象保留条件：keep(i) = (conf_i > τs) ∨ (AAD_i < τd) ∨ (TCS_i > τc)，允许最多Kmax=3次连续丢失后从锚点恢复，其中τs=0.30, τd=0.20, τc=0.70。
- 公式/目标函数/指标定义：
  - 注意力引导提示提取：W(x) = Ft_up(x) * Mt(x), ct = sum_x x*W(x) / sum_x W(x)
  - 近端锚定正则化：pt = (1-λa-λs)*pt + λa*p0 + λs*pt-1 (隐含公式，具体参数λa=0.4, λs=0.3)
  - 候选评分目标：k* = argmax_k [α*conf_k + β*cont_k - γ*unc_k - δ*div_k - η*leak_k]
  - 指标定义：AAD (Attention Alignment Drift) 衡量注意力偏移，TCS (Temporal Consistency Score) 衡量时间一致性，PDE (Prompt Decoupling Energy) 衡量提示解耦能量
  - 有效谱半径：ρ ≈ 0.76 (由λa和λs决定)
- 算法细节：
  - 每个对象进行10次迭代提示反馈
  - 注意力提取时使用头平均注意力图，大小为64x64
  - 候选评分中K=3个候选掩码
  - 软持久化中允许最多连续3次丢失后从锚点恢复
  - 超参数在表1中给出，默认λa=0.4, λs=0.3, τ=0.15等
  - 运行时开销：每次迭代约4.1ms (4.9%)
- 训练/推理细节：
  - DeCoDrift是推理时框架，无需梯度、权重修改或额外训练数据
  - 使用冻结的SAM ViT-H解码器
  - 默认超参数见表1，算法稳定对候选评分权重扰动不敏感
  - 锚点p0来自初始自动分割掩码，可容忍一定噪声（σ≤20像素）

### 7. Interpretability Transfer from Language to Vision via Sparse Autoencoders
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.24946v1
- 方法流程：
  - 阶段1: 视觉编码 → 输入图像I，使用冻结视觉编码器V（如DINOv2）提取视觉token v ∈ R^{N×D_v}
  - 阶段2: 投影映射 → 可训练线性投影器P_θ将视觉token映射到LLM嵌入空间，得到e_v = P_θ(v) ∈ R^{N×D_llm}
  - 阶段3: SAE正则化 → 在LLM的选定层l∈M上，用冻结文本SAE对视觉token隐藏状态e^l_v计算重建损失L_SAE = (1/|M|) Σ_l ||SAE_l(e^l_v) - e^l_v||_2^2，强制e^l_v位于文本SAE流形
  - 阶段4: 多模态生成 → 将e_v与文本嵌入e_t拼接，送入冻结LLM生成文本，训练总损失L_total = L_CE + L_SAE
- 关键模块/机制：
  - 视觉编码器V：从输入图像提取视觉token，冻结不训练；使用DINOv2或CLIP等视觉编码器，输出N个视觉token v ∈ R^{N×D_v}，N为token数，D_v为编码器维度
  - 线性投影器P_θ：将视觉token映射到LLM嵌入空间，可训练；线性变换，参数θ，将视觉维度D_v映射到LLM维度D_llm，输出e_v = P_θ(v)
  - 文本稀疏自编码器SAE：提供预训练的稀疏流形，用于约束视觉token的可表示性；在LLM残差流上预训练的SAE，包含编码器E和解码器D，将激活x映射到稀疏隐空间E(x)，重建ˆx≈D(E(x))。训练时固定，用于计算L_SAE
  - 冻结LLM（如Gemma）：接收多模态序列并生成文本，不参与投影器训练；视觉token嵌入e_v与文本嵌入e_t拼接后输入LLM，LLM在训练中保持冻结
  - SAE重建损失L_SAE：辅助损失，约束视觉token被文本SAE可重建；计算视觉token在LLM选定层隐藏状态e^l_v与其SAE重建SAE_l(e^l_v)的均方误差，促使视觉特征符合文本SAE结构
- 公式/目标函数/指标定义：
  - 总损失 L_total = L_CE + L_SAE，其中L_CE为交叉熵损失
  - SAE重建损失 L_SAE = (1/|M|) Σ_{l∈M} ||SAE_l(e^l_v) - e^l_v||_2^2，M为应用损失的LLM层集合
  - SAE训练损失（基础）: ||x - ˆx||_2^2 + λ||E(x)||_1
- 算法细节：
  - 训练时，前向传播一次，同时计算L_CE和L_SAE，反向传播只更新投影器P_θ参数
  - SAE重建损失在多个LLM层（如第0、1、n层）上计算，取平均
  - 概念干预时：对特定视觉token的隐藏状态e^l_v，沿目标概念对应的SAE特征方向加减幅值，实现物体移除或替换
  - 匹配率计算：对于每个视觉token，取最激活的SAE概念标签，由LLM验证该标签是否准确描述对应图像区域
- 训练/推理细节：
  - 训练分两阶段？实际只训练投影器，视觉编码器和LLM均冻结
  - 使用标准LLaVA训练数据（图像-描述对），优化器细节未提及
  - 推理时：视觉投影器正常映射，不计算L_SAE，直接送入LLM生成
  - 概念干预在推理时进行：从LLM某层取出视觉token隐藏状态，修改后继续前向

### 10. Detail Consistent Stage-Wise Distillation for Efficient 3D MRI Segmentation
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.26382v1
- 方法流程：
  - 输入：3D多模态MRI体积x，教师模型（冻结）和学生模型（待训练），通道缩减因子r=4。
  - 前向传播：教师和学生分别提取M个编码器阶段特征F_i^(t)和F_i^(s)，学生特征通过可学习1×1×1卷积ϕ_i投影到与教师相同通道数。
  - 小波分解：对每个阶段特征（教师和投影后学生）进行3级3D DWT（db4），得到子带集合，划分A={LLL}, S={HHH}, D=其余子带。
  - 细节重建：对教师和学生分别应用投影P_D：仅保留D子带系数，其余置零，然后通过3D IDWT重建空间域细节特征。
  - 蒸馏损失：计算教师和学生细节特征的MSE，归一化除以特征元素数N_i，求和所有阶段得L_DCD。
  - 总损失：L_total = L_seg (Dice+交叉熵) + μ L_DCD，μ=0.05。
  - 输出：训练后的学生模型，推理时无额外操作。
- 关键模块/机制：
  - 3D Discrete Wavelet Transform (DWT)：将特征分解为多分辨率子带，分离低频近似和方向细节。；对每个通道独立应用3级3D DWT（Daubechies-4），递归变换到近似子带LLL，得到子带β∈{L,H}^3，共8×l级子带（此处l=3，实际子带数为1+7+7+7=22？论文设定l=3，通过递归三次，子带数动态增加，但描述简化为β索引）。
  - Detail Subspace Selection (D band)：选择用于蒸馏的频带，排除低频A和极端高频S，保留方向细节。；定义A={LLL}, S={HHH}, D={L,H}^3 \ {LLL, HHH}。理论依据：低频A主导能量会弱化细节监督；S在MRI中噪声敏感，信噪比低。仅保留D子带，包含单轴或双轴高通滤波的细节。
  - Detail Projection P_D：从细节子带重建空间域细节特征，用于蒸馏对齐。；对教师和学生特征，分别取各子带F^(β)，将β∈D的子带保留，其他子带置零，然后通过3D IDWT重建空间域张量，确保几何一致性。
  - Learnable 1×1×1 Projection ϕ_i：将学生特征通道数映射到与教师一致，以进行蒸馏。；每个编码器阶段i使用一个可学习的卷积核大小为1×1×1的卷积层，输入通道C_i^(s)，输出通道C_i^(t)，用于对齐通道维度。
- 公式/目标函数/指标定义：
  - 激励不等式：‖P_hi(F_i^(t)) - P_hi(F_i^(s))‖² > ‖P_lo(F_i^(t)) - P_lo(F_i^(s))‖² （P_hi和P_lo为高低频投影）。
  - 小波分解：{F_l^(β)}_{β∈{L,H}^3} = ξ_l(F)，β索引低/高通滤波组合。
  - 子带划分：A={LLL}, S={HHH}, D={L,H}^3 \ {LLL, HHH}。
  - 细节投影：P_D(F) = ξ_l^{-1}({êF_l^(β)}), 其中êF_l^(β)=F_l^(β) if β∈D else 0。
  - 蒸馏损失：L_DCD^(i) = (1/N_i) ‖P_D(F_i^(t)) - P_D(ϕ_i(F_i^(s)))‖²，N_i为特征元素数。
  - 总损失：L_total = L_seg + μ L_DCD。
- 算法细节：
  - 教师学生架构：教师为nnU-Net，学生通过统一通道缩减（r=4）得到，即所有编码器层通道数除以4。
  - 小波分解级别：对所有阶段固定l=3。
  - 蒸馏仅应用于编码器阶段（M个），解码器不进行蒸馏。
  - 教师参数冻结，仅更新学生和投影层ϕ_i。
  - DWT/IDWT在训练时计算，推理时移除，不增加开销。
- 训练/推理细节：
  - 优化器：SGD with Nesterov momentum (m=0.99)，初始学习率0.01，权重衰减3e-5。
  - 蒸馏权重μ=0.05。
  - 小波基：Daubechies-4 (db4)。
  - 训练在单张NVIDIA A100 GPU上进行。
  - 推理时仅运行学生模型，无DWT/IDWT或投影层。

### 11. Local-sensitive connectivity filter (ls-cf): A post-processing unsupervised improvement of the frangi, hessian and vesselness filters for multimodal vessel segmentation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.21251v1
- 方法流程：
  - 输入：原始图像（例如眼底图像或血管造影图）
  - 步骤1：提取绿色通道并转换为灰度图像
  - 步骤2：应用Frangi滤波器，得到灰度响应图
  - 步骤3：固定阈值（灰度值100）二值化，得到初始血管分割二值图
  - 步骤4：应用连通性滤波器（CF）：计算每个连通分量的像素数作为连通性分数，生成灰度连通图（分数为每个像素所属连通分量的大小）
  - 步骤5：应用局部敏感连通性滤波器（LS-CF）：对连通图进行局部窗口扫描，若窗口内存在高连通像素（分数>τ）且中心像素为背景，则根据局部容忍度启发式将其标记为血管；最终通过阈值（连通分数>1）生成分割掩膜
  - 输出：最终血管分割二值图
- 关键模块/机制：
  - 连通性滤波器 (Connectivity Filter, CF)：计算每个像素的连通性分数，生成灰度级连通图；接收二值输入，通过连通组件标记算法识别所有连通区域，每个像素的分数赋值为其所属连通区域的总像素数（连通分量大小）。孤立像素分数为1，大血管分支分数高。

- 方法流程：
  - 输入：冻结的VLM编码器输出的嵌入向量z ∈ R^D。
  - 步骤1：计算均值b，并中心化z得到z-b。
  - 步骤2：应用可逆正交变换U得到˜z = U(z-b)。
  - 步骤3：对˜z应用top-k算子Πk，只保留绝对值最大的k个坐标，其余置零，得到稀疏表示˜z_sparse。

  - 输出：稀疏重建嵌入ˆz。
- 关键模块/机制：
  - 可逆正交变换层：将原始嵌入旋转到新的坐标系，使语义信息沿坐标轴集中。；参数化为U = exp(A - A^T)，其中A是待学习的斜对称矩阵（通过参数化保证正交）。由于U正交，其逆等于转置，计算高效。
  - top-k稀疏瓶颈：在变换后的空间中强制稀疏性，只保留k个最大激活值。；对变换后的嵌入˜z，取绝对值最大的k个维度，其余置零。k远小于D，且在训练中逐渐从较大的初始值减小到目标值，并随机采样。

- 公式/目标函数/指标定义：
  - 重建目标： min_U E_z [ || z - (U^{-1} Π_k (U(z-b)) + b) ||_1 ]
  - 正交变换： U = exp(A - A^T)，保证U^T U = I。
  - 稀疏约束： ||˜z_sparse||_0 ≤ k。
- 算法细节：
  - 对于每个嵌入向量，先减去训练集均值b进行中心化。
  - 应用正交变换U得到˜z。
  - 计算˜z各坐标的绝对值，选择top-k坐标索引，其他坐标设为零。
  - 应用U^{-1}（即U^T）将稀疏表示映射回原始空间，再加上均值b。
  - 使用L1损失优化重建误差，利用梯度下降更新参数矩阵A。
- 训练/推理细节：

  - 推理：直接使用学习到的U和设定好的k（如1% D）对每个嵌入进行变换、top-k稀疏化、逆变换，得到稀疏重建。解释时，可直接分析变换后的非零坐标对应的语义含义（通过文本概念对齐或解码）。

  - 计算Weierstrass椭圆函数℘(z)及其导数℘′(z)，使用模排序截断级数求和（式4）进行数值计算。
  - 提取四维特征f=[Re(℘(z)), Im(℘(z)), Re(℘′(z)), Im(℘′(z))]^T。

- 关键模块/机制：
  - 坐标归一化与复平面映射：将2D patch坐标标准化并映射到复平面，保留几何结构并避免极点落在patch中心。；归一化坐标为u=(j+0.5)/W, v=(i+0.5)/H，有效范围略小于[0,1]；映射公式z=αu·u·2Re(ω1)+i·αv·v·2Im(ω3)，其中αu,αv为可调尺度因子，ω1为实半周期，ω3为虚半周期（可学习）。
  - Weierstrass函数计算与特征提取：计算℘(z)和℘′(z)并取其实部和虚部，形成四维位置特征向量。；℘(z)通过截断级数求和近似（式4），对晶格点按模排序加速收敛。特征向量f=[Re(℘(z)), Im(℘(z)), Re(℘′(z)), Im(℘′(z))]^T。
  - 数值稳定性与自适应压缩：防止函数值爆炸和梯度不稳定。；对接近极点（|z|<15ϵ）的值裁剪为常数Clarge；每个特征分量应用tanh(αscale·fi)，αscale=softplus(αraw)可学习。
  - 预计算查找表与双线性插值：实现分辨率无关的高效推理，避免在线复杂计算。；训练后固定参数，在高分辨率网格上预计算四维特征；推理时用归一化坐标查询，GPU通过硬件加速双线性插值获取编码。
- 公式/目标函数/指标定义：
  - 归一化坐标：u=(j+0.5)/W, v=(i+0.5)/H
  - 复平面映射：z = α_u·u·2Re(ω1) + i·α_v·v·2Im(ω3)
  - 特征提取：f1=Re(℘(z)), f2=Im(℘(z)), f3=Re(℘′(z)), f4=Im(℘′(z))
  - 截断级数近似：℘(z) ≈ 1/z^2 + Σ_{|m|≤M,|n|≤N,(m,n)≠(0,0)} [1/(z-ω_mn)^2 - 1/ω_mn^2]
  - tanh压缩：˜f_i = tanh(α_scale · f_i), α_scale = softplus(α_raw)
  - 投影：PE_ij = LayerNorm(W_proj ˜f_ij + b_proj)
- 算法细节：
  - 模排序截断级数求和：将晶格点按模从小到大排序后累加，加速收敛，误差界为O(1/√K)。
  - 预计算查找表生成：训练后固定参数，在细粒度固定网格上计算四维特征向量。
  - 推理时插值：将归一化坐标作为查询点，GPU利用双线性插值从查找表快速获取编码。
  - 可学习半周期：虚半周期ω3通过参数α_learn和softplus函数确保正性：ω3=i·softplus(α_learn)，ω1固定以防过拟合。
- 训练/推理细节：
  - 训练时使用直接数值计算（截断级数求和）并应用tanh压缩和裁剪以稳定训练。
  - 训练完成后固定所有参数（包括可学习半周期、尺度因子、投影层），生成高分辨率查找表。
  - 推理时仅需归一化坐标和双线性插值，无额外计算开销。
  - 分类token使用独立可学习位置编码PE_cls∈R^{1×d}。
  - 线性投影可替换为MLP增强表示能力。

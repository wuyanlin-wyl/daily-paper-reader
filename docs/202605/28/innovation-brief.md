### 2. CLIP-Guided SAM: Parameter-Efficient Semantic Conditioning for Promptable Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.24807v1
- 方法流程：
  - 输入：图像和类别文本（如“cat”）
  - CLIP 特征提取：用 CLIP 图像编码器提取补丁嵌入 V∈R^{N×C_c}（N=HW），用文本编码器提取全局文本嵌入 t∈R^{C_c}
  - 相似度计算：计算每个补丁嵌入与文本嵌入的余弦相似度 s_p = (V_p/||V_p||) · (t/||t||)，得到相似度图 S∈R^{H×W}
  - 生成提示：对 S 进行上采样、最小-最大归一化和阈值化得到二值掩码 B；从 B 采样 5 个正点（半自动模式）或从 GT 采样点（手动模式）；将 B 调整到 SAM 掩码提示分辨率作为密集提示
  - 特征注入：将纹理嵌入 t 投影并激活，将视觉-相似度融合特征 U = V + s 投影到 SAM 通道维度并空间对齐，得到 Uℓ 和 Tℓ
  - 语义适配器前向：在每个 ViT 块的 MLP 之前，将特征图 Fℓ 与 Uℓ 和 Tℓ 相加，得到条件化特征 F̂ℓ = Fℓ + Uℓ + Tℓ，然后通过适配器输出并加回 MLP 输出
  - SAM 解码：条件化后的图像特征与点/密集提示一起输入 SAM 的掩码解码器，生成最终掩码
- 关键模块/机制：
  - 多模态语义适配器：将 CLIP 语义特征注入 SAM 图像编码器的每个 ViT 块；适配器并行于 MLP 块（常规适配器并行于注意力块）。接收 CLIP 的视觉-相似度融合特征（U = V + s，投影并空间对齐至当前层特征尺寸）和文本特征（t 经线性投影和 GELU 激活后广播至空间维度）。通过残差加法 F̂ℓ = Fℓ + Uℓ + Tℓ 注入，适配器输出再与 MLP 输出相加。
  - CLIP 语义提示生成器：从 CLIP 输出生成密集掩码提示和点提示；计算图像补丁嵌入与文本嵌入的余弦相似度，得到相似度图 S；上采样并归一化后阈值化得到二值掩码 B；在半自动模式下从 B 采样 5 个正点；在手动模式下点由用户/GT 提供。B 作为密集掩码提示输入 SAM 提示编码器。
  - 训练-测试提示一致性设计：确保半自动模式在训练和推理时使用相同来源的点提示（从相似度图采样），手动模式则始终使用 GT/用户点；半自动模式：训练和测试均从相似度图 B 采样点，保持一致性；手动模式：训练和测试均使用 GT/用户点，避免分布不匹配。
- 算法细节：
  - CLIP 补丁嵌入尺寸：V∈R^{N×C_c}（N=H×W，C_c 为 CLIP 通道）
  - 相似度图 S 形状：H×W，上采样至 256×256，最小-最大归一化，阈值 0.5 得到二值掩码
  - 点提示采样：从二值掩码 B 中随机选择 5 个正点（半自动模式）
  - 特征投影：U′ = U W_v, W_v∈R^{C_c×C_ℓ}，然后 reshape 和双线性插值至当前层空间尺寸
  - 文本投影：t′ = GELU(W_t t), W_t∈R^{C_c×C_ℓ}，然后广播至空间维度
  - 适配器内结构：依次为下投影、非线性、上投影（类似 bottleneck）
- 训练/推理细节：
  - 端到端训练 SAM 和 CLIP，仅使用 SAM 输出的掩码监督
  - 因为阈值化不可微，CLIP 的梯度仅通过特征注入路径传播
  - 可训练参数：SAM 的图像编码器（含适配器）16.6M + 掩码解码器 4.1M + 提示编码器；CLIP 视觉编码器的注意力块 28.3M（冻结 MLP 块和文本编码器）；总共 49.0M 参数
  - 推理时部署参数：SAM + CLIP 视觉 = 197.1M（文本嵌入可预计算缓存）
  - 半自动模式：训练和推理均从相似度图采样点；手动模式：训练和推理均使用 GT/用户点击点

### 3. DeCoDrift: Stabilizing Decoder Coupling in Closed-Loop Foundation Segmentation
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.25730v1
- 方法流程：
  - 输入：当前图像、上一时刻提示pt-1、初始锚点p0、冻结的SAM ViT-H解码器
  - 阶段1—注意力引导提示提取：使用解码器头平均注意力图Ft与掩码Mt加权，按式(5)计算候选提示ˆpt，偏置提示至解码器活跃注意区域
  - 阶段2—近端锚点正则化：将ˆpt与锚点p0和上一提示pt-1混合，公式为pt = λa p0 + λs pt-1 + (1-λa-λs)ˆpt，其中λa=0.4, λs=0.3
  - 阶段3—解码器感知候选评分：当SAM生成K个候选时，依据综合得分k* = argmax[α conf + β cont - γ unc - δ div - η leak]选取最佳候选，权衡置信度、连续性、不确定性、锚点偏离和泄漏
  - 阶段4—软目标持久性：根据条件 keep(i) = (conf_i > τ_s) ∨ (AAD_i < τ_d) ∨ (TCS_i > τ_c) 决定保留目标，允许最多Kmax=3次连续丢失后锚点恢复
  - 输出：稳定后的提示pt，反馈至解码器进行下一轮
- 关键模块/机制：
  - 注意力引导提示提取：利用解码器自身注意力作为空间先验，改进提示提取；使用头平均注意力图Ft（64×64）上采样至输入尺寸，与当前掩码Mt逐元素相乘得权重W(x)=Ft↑(x)·Mt(x)，再计算加权质心ˆct=∑x W(x)/∑W(x)。抑制背景噪声，聚焦活跃注意区域。
  - 近端锚点正则化：防止提示无界漂移并抑制振荡；将注意力提取的候选提示ˆpt与初始锚点p0和上一时刻提示pt-1线性组合：pt = λa p0 + λs pt-1 + (1-λa-λs)ˆpt，λa=0.4, λs=0.3，有效谱半径≈0.76，确保误差不放大。
  - 解码器感知候选评分：替代简单的argmax IoU，选择与注意力耦合良好的候选；对SAM输出的K个候选（默认K=3），计算加权得分：α·conf_k + β·cont_k - γ·unc_k - δ·div_k - η·leak_k，其中conf为置信度，cont为连续性（与上一帧掩码IoU），unc为不确定性（熵），div为与锚点偏离，leak为泄漏（掩码外区域比例）。默认α=0.35, β=0.25, γ=0.15, δ=0.15, η=0.10。
  - 软目标持久性：避免硬IQR过滤导致暂时遮挡目标丢失；对每个目标，若满足以下任一条件则保留：置信度>τ_s(0.30) 或 平均注意力偏差AAD<τ_d(0.20) 或 时间一致性得分TCS>τ_c(0.70)。若连续丢失≤Kmax=3次，通过锚点恢复提示；否则丢弃。
- 公式/目标函数/指标定义：
  - 注意力引导提取：W(x)=F_t↑(x)·M_t(x)，ˆc_t = (∑_x x·W(x))/(∑_x W(x)) (式5)
  - 近端锚点正则化：p_t = λ_a p_0 + λ_s p_{t-1} + (1-λ_a-λ_s)ˆp_t，其中λ_a=0.4, λ_s=0.3 (隐含于式4)
  - 候选评分目标：k* = argmax_k [α·conf_k + β·cont_k - γ·unc_k - δ·div_k - η·leak_k]
  - 软持久判断：keep(i) = (conf_i > τ_s) ∨ (AAD_i < τ_d) ∨ (TCS_i > τ_c)
- 算法细节：
  - 初始化：在参考切片上使用SAM自动掩码获得初始提示p0，作为锚点和第一帧提示。
  - 迭代过程：对每个后续切片，先执行注意力引导提取得到候选提示ˆp_t，再经近端正则化更新p_t，然后以SAM多掩码模式生成候选，用解码器感知评分选择最佳，最后通过软持久机制决定是否保留目标或锚点恢复。
  - 锚点恢复：若目标连续丢失不超过Kmax次，使用锚点p0作为当前提示；否则彻底丢弃。
  - 超参数选择：推荐在保留微体积上最大化TCS同时保持AAD低于未正则化基线来选择λ_a, λ_s。
  - 运行时开销：单次迭代约84ms/对象，DeCoDrift增加约4.1ms（4.9%），仪器化钩子额外1.8ms（可禁用）。
- 训练/推理细节：
  - 完全推理时方法，无需梯度计算、权重修改或额外训练数据。
  - 使用冻结的SAM ViT-H解码器，无需微调。
  - 在单个A5000 GPU上运行，轻量模式内存<40GB。
  - 仪器化钩子用于提取注意力图和计算耦合指标，部署时可关闭。

### 5. VITAL: Visual-Semantic Dual Supervision for Enhanced and Interpretable Latent Reasoning in Medical MLLMs
- 区域：deep；分数：9.0
- 原文链接：https://arxiv.org/abs/2605.28422v1
- 方法流程：
  - 阶段1-前缀编码：使用冻结的多模态骨干（Qwen3-VL）编码医学图像I和问题q，生成视觉token和前缀KV缓存C_prefix
  - 阶段2-循环潜在推理：从前缀最后隐藏状态z0开始，循环K步，每步用公式zk = fθ(zk-1; C_prefix ∪ {z<k})生成连续潜在状态，更新KV缓存，形成自回归因果链
  - 阶段3-答案解码：将K步潜在状态注入KV缓存，自回归解码答案token序列，首个token直接由zK预测
  - 阶段4-辅助监督（训练时）：每个潜在状态zk输入两个并行分支：(a)文本解码器通过投影层pj_in映射后与真实推理链ek嵌入拼接，自回归预测ek并计算交叉熵L_text；(b)视觉投影器VP将zk投影到冻结医学视觉编码器特征空间，与预提取的ROI特征fROI计算L1损失L_visual
  - 阶段5-推理部署：丢弃所有辅助模块（文本解码器、视觉投影器、pj_in），仅保留冻结骨干+LoRA+循环潜在循环+语言模型头，推理代价与标准LoRA微调模型相同
- 关键模块/机制：
  - 循环潜在循环：生成K步连续潜在状态，替代显式token推理，避免语言瓶颈和推理开销；从前缀最后隐藏状态z0开始，每步执行单token前向传递，输入为前一步输出，KV缓存实时更新，公式为zk = fθ(zk-1; C_prefix ∪ {z<k})，训练和推理路径完全一致，无teacher forcing或调度采样
  - 辅助文本解码器：为每个潜在状态提供语义监督，强制其编码可解释的推理逻辑；独立的轻量级因果语言模型（Qwen3-1.7B，全微调），将zk通过线性投影pj_in: Rd→Rd_dec后与真实推理链ek的嵌入拼接，自回归预测ek，计算交叉熵损失L_text = (1/K) Σ CE(Decoder(h_dec_k), e_k)
  - 视觉投影器 (VP)：为每个潜在状态提供视觉监督，将其锚定到细粒度视觉特征空间；基于归一化稳定的残差MLP：VP(z) = LN(W2(GELU(W1 LN(z)) + z))，输入LayerNorm消除LLM隐藏状态与视觉特征的范数不平衡，残差连接保留表达丰富性，输出LayerNorm匹配ℓ2归一化尺度。将zk投影到dv维空间，与预提取的ℓ2归一化ROI特征fROI计算L1损失L_visual = (1/K) Σ ||VP(z_k) - f_ROI||_1
  - 辅助投影层 pj_in：将潜在状态zk映射到文本解码器的隐藏维度；可学习的线性层 Rd → Rd_dec，用于将zk投影后与文本解码器的嵌入拼接
- 公式/目标函数/指标定义：
  - 潜在状态生成: zk = fθ(zk-1; C_prefix ∪ {z<k})
  - 答案解码: p(a) = Π_{t=1}^T p(at | z1:K, a<t)
  - 语义损失: L_text = (1/K) Σ_{k=1}^K CE(Decoder(h_dec_k), e_k), 其中 h_dec_k = [pj_in(zk); Embed_dec(ek)]
  - 视觉损失: L_visual = (1/K) Σ_{k=1}^K ||VP(z_k) - f_ROI||_1
  - 总损失: L_total = L_task + λ1 L_text + λ2 L_visual, 其中L_task为答案token的标准交叉熵
- 算法细节：
  - 循环潜在循环算法: 输入前缀隐藏状态z0, 循环K步, 每步输入为前一步输出的连续向量, 执行单token前向传递, 更新KV缓存, 生成z1...zK
  - 自适应ROI特征提取: 当分割掩膜覆盖≥20%图像面积时, 从全图提取patch特征并通过掩膜池化; 当掩膜较小时, 紧密裁剪ROI区域(加5%边距), 填充为正方形, 池化有效patch, 所有特征ℓ2归一化到单位超球面
  - 教师蒸馏: 使用专有MLLM作为教师, 输入带半透明分割掩膜的重叠图像(隐藏目标身份元数据), 教师被指示仅基于原始图像生成输出(重叠仅用于内部正确性), 生成推理链和答案, 经过多轮质量门控(违禁词列表、步数验证、格式规范化)和5%人工审核, 泄漏率低于0.3%
  - 训练-推理一致性: 训练和推理使用相同的循环路径, 无teacher forcing、调度采样或并行计算潜在状态
- 训练/推理细节：
  - 训练: 冻结Qwen3-VL-8B骨干和医学视觉编码器, 仅训练LoRA适配器(r=64, α=128)插入所有36层Transformer的注意力和前馈投影, 以及训练时辅助模块(文本解码器全微调、视觉投影器、pj_in), 总可训练参数1.93B/510.07B(19.1%)
  - 三阶段课程学习: Phase1 (K=1) 单步潜在推理; Phase2 (K≤2) 两步链; Phase3 (K≤4) 所有深度, 每阶段从上一阶段热启动
  - 推理: 丢弃所有辅助模块(文本解码器、视觉投影器、pj_in), 仅保留冻结骨干+LoRA+循环潜在循环+语言模型头, 参数仅174.6M(LoRA), 零额外延迟/内存/参数
  - 事后双重可解释性: 推理后可重新附加文本解码器解码任意潜在状态为文本推理链(文本窗口), 同时视觉投影器输出可进行最近邻检索恢复视觉内容(视觉窗口)

### 8. MAGIC: Multimodal Alignment & Grounding-aware Instruction Coreset for Vision-Language Models
- 区域：quick；分数：8.0
- 原文链接：https://arxiv.org/abs/2605.26004v1
- 方法流程：
  - 阶段1: 过滤低增益样本 - 对每个样本计算Multimodal Gain gi，若gi低于阈值则过滤，保留视觉上有用的样本。
  - 阶段2: 质量排序 - 对剩余样本计算归一化质量分数 qi = gi * bi / (归一化因子)，按qi降序排序，选择top-k候选样本（通常为预算的2倍）。
  - 阶段3: 分桶预算分配 - 将候选样本按其Skill-Neuron Signature ϕi分配至桶中，每个桶对应一个唯一的签名模式，在桶内均匀分配预算，最终选择M个样本构成核心集。
- 关键模块/机制：

- 算法细节：

  - 阶段1: 特征提取 - 输入视频帧，分别用EndoFM-LV提取时序特征序列，用DINOv3 ViTL/16提取每帧视觉特征
  - 阶段2: 多样头部集成 - 对每个特征流训练多个分类头（DHE），产生多组帧级概率预测
  - 阶段3: 验证引导加权融合 - 在验证集上学习每个预测头的权重，加权平均两流预测得到融合帧级概率
  - 阶段4: 解剖感知时序解码 - 根据解剖区域先验，将帧级概率序列通过非极大抑制等操作解码为事件（起始帧、结束帧、类别）
  - 阶段5: 后处理阈值搜索 - 初始基于F1阈值，再结合局部精细搜索[bc-0.15, bc+0.15]和全局粗搜索[0.05,0.95]选择每类最优阈值
- 关键模块/机制：
  - Diverse Head Ensemble (DHE)：为每个特征流生成多个多样化预测头，提高预测鲁棒性；对每个特征流（时序/视觉）独立训练多个分类头，每个头可能采用不同初始化或训练子集，输出多组帧级概率。
  - Validation-Guided Weighted Fusion (VGWF)：基于验证集性能自适应融合两流预测，减少领域差异；利用验证集上的时序mAP作为评价指标，学习每个预测头（来自不同流不同头）的融合权重，对帧级概率进行加权平均。
  - Anatomy-Aware Temporal Event Decoding (ATED)：将融合后的帧级概率序列转换为事件级检测结果；利用胶囊内镜解剖区域（如胃、小肠）先验，对帧级概率进行时序平滑，通过阈值和区域约束识别事件起止，并去除重叠事件（类似非极大抑制）。
- 公式/目标函数/指标定义：
  - 最终候选阈值集公式 (6): T_c^thr = Local(b_c, 0.15) ∪ Global(0.05, 0.95)，其中b_c为基于F1导出的初始阈值
  - 评估指标：时序mAP@0.5和时序mAP@0.95（事件级平均精度，交并比阈值为0.5/0.95）
- 算法细节：
  - 双骨干特征提取：EndoFM-LV处理连续帧序列输出时序嵌入，DINOv3处理单帧输出视觉嵌入，两者对齐到相同帧率
  - DHE训练：每个流使用不同随机种子或数据子集训练多个分类头，增加预测多样性
  - VGWF：在验证集上计算每个预测头的mAP，并学习权重系数（可能通过网格搜索或简单平均），输出加权帧级概率
  - ATED：首先对每个帧类别的概率应用阈值得到二值图，再根据解剖标签对连续阳性段进行合并，仅保留持续时间合理的候选事件，最后对重叠事件按置信度排序保留最高分
  - 赛后阈值搜索：对每个类别，在局部范围（F1阈值±0.15）和全局范围（0.05至0.95步长0.05）内搜索最大化验证集时序mAP@0.5的阈值，替换原有局部搜索
- 训练/推理细节：
  - 双骨干使用预训练基础模型（EndoFM-LV和DINOv3），在训练期间可能微调（原文未明确），但DHE和VGWF在验证集上确定参数
  - 训练数据：使用比赛提供的训练集，DHE在各自特征流上训练，VGWF权重基于验证集性能选择
  - 赛后改进仅改变阈值搜索策略，不涉及模型重新训练
  - 推理时：先提取双特征，经过DHE得到多组概率，VGWF加权融合，ATED解码事件，最后应用每类搜索所得阈值

### 16. Conceptualizing Embeddings: Sparse Disentanglement for Vision-Language Models
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.22679v1
- 方法流程：
  - 输入：冻结视觉编码器的嵌入向量z ∈ R^D（对于CLIP为单向量，对于BLIP为序列令牌）
  - 中心化：减去训练集均值b，得到z' = z - b
  - 正交变换：应用U(z') = exp(A - A^T)(z')得到˜z
  - 稀疏化：通过top-k算子Π_k保留绝对值最大的k个坐标，其余置零，得稀疏˜z_sparse
  - 逆变换与恢复：应用U^{-1}得到̂z'，再加回均值b得重建̂z = ̂z' + b
  - 输出：重建嵌入̂z（用于训练），或稀疏嵌入˜z_sparse（用于解释）
- 关键模块/机制：
  - 可逆正交变换模块：将原始嵌入映射到新坐标系，使语义信息集中于少数维度，且保持内积和范数；参数化为U = exp(A - A^T)，其中A是斜对称矩阵（保证指数映射结果正交），训练时仅优化A。正交性U^T U = I确保几何不变。
  - top-k稀疏化算子Π_k：引入稀疏瓶颈，强制每个样本仅由k个活跃坐标表示，促进坐标专业化；对变换后的˜z，取绝对值最大的k个坐标保留原值，其余置零。k是超参数，训练时采用课程策略从高到低过渡并最终随机采样。
  - 中心化（均值减法）：去除全局偏移，使变换在原点附近更有效；计算训练集所有嵌入的均值b，预处理时减去b，重建后加回。
- 公式/目标函数/指标定义：
  - 目标函数：min_U E_z[ || z - (U^{-1} Π_k (U(z - b)) + b) ||_1 ]
  - 正交变换：U = exp(A - A^T)，其中A为斜对称矩阵，U^T U = I
  - 稀疏约束：||̂z||_0 ≤ k（隐式通过Π_k实现）
- 算法细节：
  - 采用随机梯度下降优化目标函数，每次前向对每个嵌入独立处理
  - 训练中使用课程学习：初始k较大（接近D），逐渐减小至目标值，之后在每个batch随机采样k（在预设范围）
  - 对于CLIP类模型，直接使用全局嵌入；对于BLIP/CoCa等序列模型，对每个视觉令牌独立应用同一U
- 训练/推理细节：
  - 训练：在冻结编码器输出上优化U，无需重新训练骨干网络；使用L1损失重建；可选数据增强（如随机裁剪）
  - 推理：应用训练好的U和固定k（用户指定）得到稀疏表示；对CLIP用文本概念对齐各坐标（通过余弦相似度），对BLIP用解码器生成描述
  - 无需在推理时优化，直接前向即可

### 17. Weierstrass Positional Encoding for Vision Transformers
- 区域：quick；分数：6.0
- 原文链接：https://arxiv.org/abs/2605.23719v1
- 方法流程：
  - 输入图像划分为H×W个patch，计算归一化坐标(u,v) = ((j+0.5)/W, (i+0.5)/H)；
  - 将(u,v)映射到复平面：z = α_u·u·2Re(ω1) + i·α_v·v·2Im(ω3)；
  - 计算℘(z)和℘'(z)的实部与虚部，得到四维特征向量f = [Re(℘(z)), Im(℘(z)), Re(℘'(z)), Im(℘'(z))]^T；
  - 对f进行数值稳定处理：接近极点时裁剪为常数，其他情况使用截断晶格求和计算，并对各分量施加tanh(α_scale·f_i)压缩；
  - 通过线性层或MLP将四维特征投影到模型维度d，然后执行LayerNorm得到最终位置编码PE；
  - 将PE加到对应patch的token嵌入上，组成Transformer输入序列。
- 关键模块/机制：
  - 复平面映射模块：将归一化2D坐标映射到复平面，保留原始几何结构，并作为椭圆函数的输入；使用公式z = α_u·u·2Re(ω1) + i·α_v·v·2Im(ω3)，其中α_u, α_v为可调缩放因子，ω1和ω3分别为实半周期和虚半周期（晶格参数）。
  - 特征提取模块：从复坐标z提取Weierstrass椭圆函数及其导数的实部和虚部，构成四维位置特征；计算f1=Re(℘(z)), f2=Im(℘(z)), f3=Re(℘'(z)), f4=Im(℘'(z))。℘(z)通过截断晶格求和近似，并采用模长排序加速收敛。
  - 数值稳定模块：防止℘(z)在极点附近爆炸，确保训练稳定性；当|z|<15ε时，将℘(z)裁剪为大常数C_large；使用tanh(α_scale·f_i)对四维特征各分量进行压缩，α_scale=softplus(α_raw)；对截断求和中的项进行幅度裁剪。
  - 预计算查找表模块：推理时加速WePE计算，避免实时求值；训练后固定所有参数，在精细固定网格上预计算四维特征向量；推理时根据归一化坐标通过GPU双线性插值从查找表快速获取位置编码。
- 公式/目标函数/指标定义：
  - 归一化坐标: u = (j+0.5)/W, v = (i+0.5)/H (公式1)
  - 复平面映射: z = α_u·u·2Re(ω1) + i·α_v·v·2Im(ω3) (公式2)
  - 四维特征: f1=Re(℘(z)), f2=Im(℘(z)), f3=Re(℘'(z)), f4=Im(℘'(z)) (公式3)
  - ℘(z)截断近似: ℘(z) ≈ 1/z^2 + Σ_{|m|≤M,|n|≤N,(m,n)≠(0,0)} [1/(z-ω_mn)^2 - 1/ω_mn^2] (公式4)
  - 截断误差上界: E_trunc ≲ 2C_Λ|z|/R_max (公式7)
  - tanh压缩: ˜f_i = tanh(α_scale·f_i), α_scale=softplus(α_raw)
- 算法细节：
  - ℘(z)计算采用截断晶格求和，通过按模长排序加速收敛，并使用积分近似控制误差；
  - 数值稳定处理包括极点附近裁剪、tanh压缩和项幅度裁剪，确保机器精度内稳定；
  - 推理时使用预计算高分辨率查找表，并通过GPU双线性插值快速获取四维特征；
  - 位置编码与patch token相加前通过线性层+LayerNorm投影。
- 训练/推理细节：
  - 训练时直接计算℘(z)（带截断和数值稳定），反向传播通过自动微分；
  - 虚半周期ω3初始化后通过softplus参数化使其为正数并可学习，ω1固定为常数；
  - 推理时使用预计算查找表，避免实时复数运算，时间开销与简单网格编码相当；
  - 分类token使用独立可学习位置编码。

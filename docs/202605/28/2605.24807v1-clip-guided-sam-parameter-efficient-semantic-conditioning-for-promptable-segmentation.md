## 摘要
诸如Segment Anything Model (SAM) 等可提示基础模型能够生成高质量掩码，但在语义上是盲目的，依赖外部提示来指定类别。现有的视觉-语言方法通过使用外部提示耦合来解决这一限制，其中视觉-语言模型作为独立阶段为SAM生成空间提示。我们提出CLIP引导的SAM，这是一种基于内部语义条件的参数高效分割框架。我们不仅利用语义信号生成提示，而且通过轻量级多模态语义适配器将CLIP派生的文本、视觉和相似性特征直接注入SAM的图像编码器。这些适配器调节SAM的内部特征表示，使语义信息能够影响掩码预测，同时保持SAM原有的可提示接口。我们的框架设计适用于低标注数据场景，并适用于通用领域基准和特定下游任务。它支持两种操作模式：手动模式，用于同时使用文本和空间提示的交互式分割；以及半自动纯文本模式，用于仅使用文本输入需要特定概念分割的应用。我们表明，鲁棒性取决于训练与推理时使用的提示类型的一致性，使训练-测试提示一致性成为一个重要的设计原则。通过大量实验和消融研究，我们将我们的方法与无语义条件的SAM+PEFT基线、视觉-语言+SAM流水线、SAM 3以及依赖大量无标注数据的强半监督分割方法进行了比较。在这些设置中，CLIP引导的SAM在训练和部署中保持参数高效的同时，始终实现优越或具有竞争力的性能。

## Abstract
Promptable foundation models such as the Segment Anything Model (SAM) produce high-quality masks but remain semantically blind, relying on external prompts to specify categories. Existing vision-language approaches address this limitation by using external prompt coupling, where a vision-language model generates spatial prompts for SAM as a separate stage.   We propose CLIP-Guided SAM, a parameter-efficient segmentation framework built on internal semantic conditioning. Instead of using semantic signals only to generate prompts, we inject CLIP-derived text, vision, and similarity features directly into SAM's image encoder through lightweight multi-modal semantic adapters. These adapters condition SAM's internal feature representations, allowing semantic information to influence mask prediction while preserving SAM's original promptable interface.   Our framework is designed for low labeled-data settings and applies to both general-domain benchmarks and specialized downstream tasks. It supports two operating modes: Manual mode, for interactive segmentation with both text and spatial prompts, and Semi-Automatic text-only mode, for applications that require concept-specific segmentation using only textual input. We show that robustness depends on aligning training with the type of prompts used at inference, making train-test prompt consistency an important design principle.   Through extensive experiments and ablations, we evaluate our method against SAM+PEFT baselines without semantic conditioning, vision-language + SAM pipelines, SAM 3, and strong semi-supervised segmentation methods that rely on large amounts of unlabeled data. Across these settings, CLIP-Guided SAM consistently achieves superior or competitive performance while remaining parameter-efficient in both training and deployment.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：Segment Anything Model (SAM) 能够根据空间提示（点、框、掩码）生成高质量分割掩码，但它是**类别无关**的，即不具备语义理解能力，需要外部提示指定要分割什么。现有视觉-语言模型（如CLIP）虽然能提供语义对齐，但缺乏空间精度。
- **现有方法局限**：主流的 VLM+SAM 系统采用**外部提示耦合**——先用 VLM 生成空间提示（点、框），再喂给 SAM。这种阶段式、浅层集成使得语义信号仅通过稀疏或嘈杂的间接提示影响 SAM，SAM 的内部特征表示仍然缺乏语义信息；尤其在低标注数据和纯文本提示场景下效果差。
- **本文目标**：提出一种**内部语义条件化**框架，将 CLIP 的语义特征直接注入 SAM 图像编码器的特征表示中，让语义信息在掩码预测过程中发挥作用，同时保持 SAM 原有的可提示接口和参数高效特性。

## 2. 论文提出的方法论

- **核心思想**：通过轻量级**多模态语义适配器**将 CLIP 派生的**文本嵌入、视觉嵌入和相似度特征**注入到 SAM 的 ViT 图像编码器的每个 MLP 块中，实现内部语义条件化。与外部提示耦合不同，这里 CLIP 不再是独立提示生成器，而是与 SAM 共同适应（co-adaptation）。
- **技术细节**：
  - **CLIP 语义信号生成**：给定图像和类别文本，计算 CLIP 的 patch-wise 余弦相似度得到相似度图 S；阈值化得到二值掩码 B 作为密集提示；从 B 采样 K=5 个正点作为点提示（半自动模式）；保留文本嵌入 t、视觉嵌入 V 和相似度分数 s 用于特征注入。
  - **语义适配器**：在每个 ViT 块的 MLP 旁并行插入适配器。先融合视觉特征 V 和相似度 s（广播相加），投影到 SAM 特征通道，空间对齐后得到 U_ℓ；文本嵌入 t 经线性投影+激活后广播得到 T_ℓ；将 U_ℓ 和 T_ℓ 残差加到 SAM 主路径特征 F_ℓ 上，再合并回 MLP 输出。
  - **操作模式**：①手动模式（用户提供点提示 + 文本提示）；②半自动（纯文本）模式：点提示和密集提示均来自 CLIP 相似度图，训练时也使用模拟的噪声提示以对齐训练-测试分布。
  - **训练策略**：端到端联合优化 SAM 和 CLIP，仅使用掩码监督损失（BCE+Dice+IoU）。由于阈值化不可导，CLIP 仅通过注入的特征路径接收梯度。可训练参数：CLIP 视觉编码器的注意力块（冻结 MLP 和文本编码器）、SAM 的提示编码器、掩码解码器以及插入的适配器。总训练参数量 49.0M，部署时仅需 SAM+CLIP-Vision（197.1M）。

## 6. 论文的主要结论与发现

- **内部语义条件化优于外部提示耦合**：直接向 SAM 编码器注入 CLIP 特征的 CLIP-Guided SAM 在所有基准上显著优于 CLIPSurgery+SAM 变体及 GroundedSAM，证明了内部特征级联合适应的优势。
- **联合 co-adaptation 至关重要**：冻结 CLIP 或独立预微调 CLIP 后再联合训练均会降低性能；端到端联合优化使 CLIP 学习到与 SAM 特征空间对齐的语义信号。
- **不对称的微调预算**：增加 CLIP 容量（ViT-L）带来更大增益（COCO 1/512: 60.5→65.0），而增加 SAM 容量（ViT-H）增益较小（60.5→61.2）；适配器层数增加收益边际递减。这表明语义引导者的能力是主要瓶颈。
- **训练-测试提示对齐的重要性**：训练时使用 GT 点、测试时使用 CLIP 采样点会导致性能大幅下降（78.3→69.8），因此半自动模式中必须使用模拟噪声点进行训练。
- **相似度特征是主要注入信号**：消融显示单独使用相似度特征即可达到接近完整模型的效果（77.5 vs 78.3），文本和视觉特征仅提供边际改进。
- **参数高效**：仅训练 49M 参数（SAM+CLIP 总 260.5M），在低标注数据下接近或超越 SAM 3 零样本性能，且可与强半监督方法竞争。

## 7. 优点

- **参数高效**：仅微调适配器等少量参数，在消费级 GPU 上可训练，且部署时只需 SAM+CLIP 视觉编码器（197M），适合资源受限场景。

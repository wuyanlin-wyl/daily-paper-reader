### 1. Pre-Deployment Robustness Stress Testing for CT Segmentation Systems Using Clinically Motivated Multi-Corruption Augmentation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.00491v1
- 方法流程：
  - 输入：归一化后的CT图像 (x ∈ [0,1]^DxHxW) 和对应分割标签 y
  - 步骤1：解剖约束空间扰动 - 随机翻转（每轴概率0.5）和弹性变形（概率0.15，α=80，σ=10），图像用线性插值，标签用最近邻插值
  - 步骤2：CT强度变换 - 独立应用多级Gamma变换、窗宽窗位偏移、直方图多项式扭曲、自适应局部对比度调整、随机锐化，各操作按各自概率触发
  - 步骤3：随机多退化组合 - 以概率 p_RAMP=0.85 启用，从13种退化池中无放回采样k∈{2,3,4}个算子顺序应用，退化强度连续采样
  - 输出：增强图像 ẝ_x 和变换后标签 ẝ_y（标签仅受空间变换影响）
- 关键模块/机制：
  - 解剖约束空间扰动：提高几何不变性，避免不真实的解剖变形；随机沿深度、高度、宽度轴以0.5概率独立翻转；弹性变形以0.15概率使用高斯平滑随机位移场（α=80, σ=10），图像线性插值，标签最近邻插值。
  - CT强度变换：模拟不同窗宽、重建、局部对比和强度分布带来的图像外观变化；包含多级Gamma变换（γ1∈[0.6,1.6], γ2∈[0.7,1.3]，p=0.45）、窗宽窗位偏移（中心偏移∈[-0.15,0.15]，宽度缩放∈[0.7,1.3]，p=0.45）、三次多项式直方图扭曲（系数std=0.2，p=0.40）、自适应局部对比度调整（4x4x4网格，最大混合0.35，p=0.35）、随机锐化（高斯σ∈[0.5,2.5]，强度α∈[0.2,1.5]，p=0.30）
  - 随机多退化组合：模拟临床中复合图像退化（同时存在噪声、模糊、伪影等）；以概率0.85激活，均匀采样k∈{2,3,4}个退化算子（从13种算子池中无放回），顺序应用到图像上。退化强度连续采样自参数范围（如高斯噪声σ∈[0.02,0.20]），不固定测试严重性级别。
  - nnU-Net基线框架：提供标准化、可复现的分割管道，自动适配预处理、网络配置、训练计划和后处理；采用3D U-Net结构，自动根据数据集属性配置。作为比较基准，所有方法使用相同骨干和训练协议，仅增强策略不同。
- 公式/目标函数/指标定义：
  - 增强图像生成：\tilde{x} = c_{j_k} \circ c_{j_{k-1}} \circ \cdots \circ c_{j_1} \circ \mathcal{I}_i \circ \mathcal{S}_s (x)
  - 标签变换：\tilde{y} = \mathcal{S}_s (y)
  - 鲁棒性差距：Robustness Gap = Dice_clean - Dice_corr
  - 最差退化Dice：Worst-case Dice = \min_{c \in \mathcal{C}_{test}} Dice_c
- 算法细节：
  - 训练时，对每个样本以概率p_RAMP=0.85决定是否应用多退化组合，若应用则从13种退化池中无放回均匀采样k∈{2,3,4}个算子
  - 退化算子包括：加性高斯噪声、各向同性模糊、Rician噪声、方向运动模糊、椒盐噪声、乘性散斑噪声、偏置场、鬼影伪影、全局强度偏移、对比度降低、分辨率退化、条纹伪影、复合退化（噪声+模糊+偏置）
  - 所有强度/退化操作在归一化[0,1]空间进行，操作后裁剪到[0,1]
  - 空间扰动（翻转、弹性变形）同时应用于图像和标签，强度/退化操作仅应用于图像
- 训练/推理细节：
  - 训练：nnU-Net自动配置预处理、网络结构、训练计划和后处理，增强策略作为唯一变量
  - 评估：在清洁图像和退化图像上分别计算Dice，退化图像使用测试时固定的严重性级别
  - 退化图像评估：从13种退化类型中按严重性级别施加单一退化（非复合），用于度量鲁棒性差距和最差情况Dice

### 2. EMA: Approximate Nearest Neighbor Search with General Attribute Filtering and Dynamic Updates
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.00734v1
- 方法流程：
  - 索引构建阶段：构建基础图（如HNSW），为每条边附加一个Marker（紧凑摘要），该摘要编码了边所连接节点对之间的谓词属性和几何信息（如距离范围）。
  - 查询处理阶段：输入查询向量和谓词条件，执行Marker增强的联合搜索：在图中从入口点开始，遍历邻居时首先检查Marker是否可能满足谓词，若Marker指示可能满足则加入候选集，否则跳过；同时采用边界恢复机制，当因Marker过滤导致候选数不足时，从被跳过的边中恢复部分以保持搜索宽度。
  - 动态更新阶段：插入或删除节点时，更新受影响边的Marker信息，保持一致性。
- 关键模块/机制：
  - Marker（标记）：附加在图边上的紧凑摘要，提供谓词和几何信息的保守近似，用于过滤不满足谓词的边，保证零假阴性（即不会错过任何真实符合谓词的节点）。；每个Marker编码了与边连接节点相关的属性值范围和向量距离范围，采用编码簿（Codebook）方式压缩存储（如s=256），并通过哈希或量化实现快速判断。在查询时，对于给定的谓词条件，Marker可以快速判断该边所连接的节点是否可能满足谓词，若不满足则直接跳过该边，避免进一步的距离计算和谓词评估。
  - 边界恢复机制（Bounded Edge Recovery）：当Marker过滤导致搜索过程中候选邻居数量不足时，从被Marker跳过的边中恢复部分边，以保证搜索的连通性和质量。；在每一层搜索中，如果当前候选集大小小于预设阈值（如d_min=16），则从之前因Marker检查而跳过的边中，按某种策略（如随机或基于几何优先级）恢复一定数量的边，重新加入候选集进行扩展。
  - Marker增强的联合搜索（Marker-Augmented Joint Search）：将Marker检查与图的贪婪搜索结合，实现谓词过滤和向量近邻搜索的联合执行。；从入口点开始，维护一个候选队列（按距离排序）。对于当前节点的每个邻居，首先检查其边的Marker：如果Marker指示该邻居可能满足谓词，则计算实际距离并加入候选队列；否则跳过。当候选队列大小不足时触发边界恢复。最终返回距离最近的满足谓词的节点。
- 公式/目标函数/指标定义：
  - 输入信息未提供明确公式
- 算法细节：
  - 图构建：采用HNSW结构，设置M=40，efConstruction=300。为每条边计算并存储Marker，Marker大小由编码簿大小s=256控制。
  - 查询参数：设置efSearch=300，top-layer搜索宽度ef_top=1，最大多样性度M_div=16，最小候选数d_min=16。
  - 查询过程：从图顶层入口点开始，逐层向下。在每一层中，执行Marker检查：对每个邻居，若其Marker与查询谓词相交，则计算该邻居与查询向量的距离并加入候选；否则跳过。若当前候选数小于d_min，从之前跳过的边中随机恢复若干边加入候选。最终在底层返回efSearch个候选，再从中筛选出满足谓词且距离最小的k个结果。
  - 动态更新：插入新点时，更新其邻接边的Marker；删除时，移除对应边的Marker或标记为无效。
- 训练/推理细节：
  - 无需训练阶段，索引构建参数如编码簿大小s通过经验设定（s=256），无参数学习过程。
  - 推理阶段为单线程执行，查询时所有操作（Marker检查、距离计算、谓词评估）均为在线计算。

### 4. ResNet-34 with Lightweight Decoder for Accurate and Efficient Segmentation of Fetal Brain MRI
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.01293v1
- 方法流程：
  - 输入：T2加权胎儿脑MRI二维切片，尺寸固定为256×256
  - 预处理：应用CLAHE（clip limit=2.0，tile size=8×8）进行局部直方图均衡化，增强组织边界对比度
  - 编码器：使用ResNet-34（预训练或从头训练）提取多层级特征图（从低层到高层）
  - 解码器：轻量级MLP解码器，接收编码器输出的多尺度特征，通过MLP模块进行自适应特征细化，并逐步双线性上采样至原图分辨率
  - 输出：7个类别的分割图（白质、灰质、侧脑室、深灰质、脑外脑脊液、小脑、脑干）
- 关键模块/机制：
  - ResNet-34编码器：提取多尺度分层特征，为后续解码器提供丰富的语义和空间信息；标准ResNet-34结构，包含5个阶段（conv1到conv5），输出特征图尺寸逐级减小，通道数增加。用于捕捉从低级边缘到高级语义的特征。
  - 轻量MLP解码器：对编码器输出的多尺度特征进行自适应细化和融合，恢复空间分辨率并输出分割图；解码器由多个MLP模块组成，每个MLP模块包含多层全连接层（隐含层）和激活函数，对每个空间位置的特征进行非线性变换实现自适应特征细化。使用双线性上采样逐步增大特征图尺寸，避免转置卷积带来的参数开销和棋盘伪影。最终通过1×1卷积输出7通道分割图。
  - CLAHE预处理：增强局部对比度，改善组织间边界可分离性，尤其在低对比度区域；对每个图像块执行局部直方图均衡化，clip limit=2.0限制对比度放大，tile size=8×8控制局部区域大小。显著提升分割性能（DSC从76.54%提升至90.33%）。

  - 运动模糊度量：M(I) = Var(∇²I)，其中∇²I为Laplacian算子响应，Var为方差

- 算法细节：
  - 编码器-解码器结构：ResNet-34前向传播生成5个stage的特征图，解码器接收这些特征图并逐级上采样至输入尺寸。
  - MLP模块处理：对每个空间位置的通道特征向量，通过多层全连接层（例如两层MLP，隐藏层维度与输出相同）进行非线性映射，实现自适应特征细化。

### 5. Quality-Guided Semi-Supervised Learning for Medical Image Segmentation
- 区域：deep；分数：8.0
- 原文链接：https://arxiv.org/abs/2606.01753v1
- 方法流程：
  - Phase 1: 训练质量预测器——输入：小批量标注数据（图像与真实掩膜）；处理：对每个真实掩膜应用随机形态学腐蚀（类型1）或弱模型预测（类型2）生成可变质量掩膜，计算Dice分数作为真值；训练ResNet-18回归模型最小化均方误差；输出：冻结的质量预测器g_phi
  - Phase 2: 质量引导半监督训练——输入：少量标注数据（DL）和大量未标注数据（DU）；处理：标注数据计算监督损失L_sup；未标注数据通过两种可选机制利用g_phi：(a) QAR：将分割网络预测经g_phi评估，最小化1-g_phi(x_u, f_theta(x_u))；(b) PL-QW：生成伪标签后，用g_phi计算权重并加权分割损失。输出：训练好的分割网络f_theta
- 关键模块/机制：
  - 质量预测器（Quality Predictor）：对任意图像-掩膜对输出一个0~1的质量分数（预测Dice），用于引导半监督训练；采用ResNet-18编码器，输入为图像与掩膜通道级联，后接回归头（含dropout 0.15）。在由标注数据经可变质量掩膜生成的数据集上训练150 epoch，优化器AdamW，学习率3e-4，权重衰减5e-4，余弦退火调度，损失为均方误差。
  - 可变质量掩膜生成（Variable Quality Mask Generation）：为质量预测器提供覆盖全范围的训练数据，使其能泛化到真实网络预测；两种类型：(1) 类型1：随机形态学操作（腐蚀/膨胀、平移、弹性形变、加性噪声、边界扰动）;(2) 类型2：来自部分训练U-Net（在标注数据上训练至早停epoch 1,3,5,10,15,20）的预测掩膜。采样概率p_weak选择类型2，1-p_weak选择类型1。每张图像生成K个退化掩膜，计算Dice分数作为真值。
  - 质量感知正则化（QAR）：以可微方式引导分割网络产生高质量预测，无需伪标签；对每个未标注样本，将分割网络输出f_theta(x_u)输入g_phi，计算1-g_phi(x_u, f_theta(x_u))作为损失。梯度通过预测掩膜反向传播至分割网络参数theta，鼓励产生g_phi评分高的预测。总损失L_QAR_total = L_sup + lambda_qar * L_qar。
  - 质量加权伪标签（PL-QW）：基于预测质量对伪标签损失进行加权，提升高质量伪标签贡献，抑制低质量；对每个未标注样本，先用任意SSL方法生成伪标签y_hat_u，然后将(x_u, y_hat_u)输入g_phi（冻结且不计算梯度）得到权重w = g_phi(x_u, y_hat_u)，加权损失L_qw = (1/M) * sum(w_j * l_seg(f_theta(x_u), y_hat_u))。总损失L_QW_total = L_sup + lambda_qw * L_qw。g_phi不参与反传。
- 公式/目标函数/指标定义：
  - DSC(y, y_hat) = 2|y ∩ y_hat| / (|y| + |y_hat|)
  - 退化掩膜生成：y_tilde_{i,k} = h(y_i; ξ_k), q_{i,k}=DSC(y_i, y_tilde_{i,k}) (式1)
  - 质量预测输出：q_hat = g_phi(x, y_tilde) (式2)
  - 质量预测器训练损失：L_quality = sum_{(x,y_tilde,q)∈DQ} l_reg(g_phi(x,y_tilde), q) (式3)
  - 监督损失：L_sup = (1/N) sum_i l_seg(f_theta(x_i), y_i) (式4)
  - QAR损失：L_qar = (1/M) sum_j [1 - g_phi(x_u_j, f_theta(x_u_j))] (式5)
- 算法细节：
  - Phase1数据生成：对每张标注图像，以概率p_weak从弱模型预测中采样，否则使用随机形态学操作（类型1），生成K个退化掩膜并计算Dice分数
  - 质量预测器训练：ResNet-18输入为图像与掩膜通道级联，输出标量，损失函数为MSE，使用AdamW优化器，训练150 epoch

### 6. CausalFlow: Causal Attribution and Counterfactual Repair for LLM Agent Failures
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.25338v1
- 方法流程：
  - 输入：失败轨迹 τ = (s1,...,sn) 和实例 x，以及验证器 V
  - 步骤1：对前 n-1 步，每步 si 生成 K 个干预提案 s'^{(k)}_i（通过LLM基于上下文和反馈生成）
  - 步骤2：对每个提案执行顺序重执行（替换 si 并重运行后续步骤），用 V 检查结果是否成功
  - 步骤3：计算 CRS(si) = 1 若存在至少一个提案翻转结果，否则为 0
  - 步骤4：对 CRS=1 的步骤，在所有成功干预中选择最小性最高（公式2）的修正 s*_i
  - 步骤5：三智能体验证（提出、批评、元批评），计算共识分数（公式4），保留 ≥τc 的步骤
  - 输出：已验证的对比对 (si, s*_i) 和因果步骤集
- 关键模块/机制：
  - Causal Responsibility Scoring (CRS)：识别执行轨迹中导致失败的因果步骤；对每一步 si，生成 K 个替换提案，对每个提案执行顺序重执行（替换 si 并执行后续步骤），若验证器输出从失败变为成功，则 CRS(si)=1，否则为0。定义见公式(1)：CRS(s_i)=max_{k} I[V(y(τ[i←s'^{(k)}_i]),x)=1]。
  - Minimality-based Repair Selection：在多个成功干预中选择与原始步骤最相似的修正，保持局部性；使用公式(2)计算最小性：Minimality(s_i, s'_i) = (m/L) * (1 - 0.5*| |x|-|y| | / L)，其中 x 和 y 是原始和修正步骤的 token 序列，L=max(|x|,|y|)，m 是位置一致匹配数。在符合验证成功的候选中选择最大化最小性的修正（公式3）。
  - Multi-Agent Validation：对CRS归因结果进行交叉验证，减少LLM噪声；使用三个智能体：Agent A提出因果步骤，Agent B批评，Agent C元批评。每个返回同意标签（AGREE/PARTIAL/DISAGREE）及置信度 c_j。映射标签为 a_j∈{1,0.5,0}。共识分数公式(4)：Consensus(s_i)=1/3[CRS(s_i)+∑_{j∈{B,C}} c_j a_j]。保留 Consensus ≥ τc=0.5 的步骤。
  - Intervention Proposal Generation：为候选步骤生成反事实修正提案；用结构化提示模板，输入包括之前步骤上下文、失败步骤内容、失败反馈。LLM以温度采样生成 K=3 个最小编辑修正提案。推理步骤修正逻辑错误，工具调用修正参数或工具选择。
- 公式/目标函数/指标定义：
  - Causal Responsibility Score (公式1): CRS(s_i) = max_{k∈{1,...,K}} I[V(y(τ[i←s'^{(k)}_i]), x)=1]
  - Minimality Score (公式2): Minimality(s_i, s'_i) = (m/L) * (1 - 0.5*| |x|-|y| | / L)，其中 L=max(|x|,|y|)，m 为位置一致匹配数
  - 最优修复选择 (公式3): s*_i = argmax_{s'_i} Minimality(s_i, s'_i) s.t. V(y(τ[i←s'_i]), x)=1
  - 共识分数 (公式4): Consensus(s_i) = (1/3)[CRS(s_i) + ∑_{j∈{B,C}} c_j a_j]
- 算法细节：
  - 算法1: 因果责任评分 - 输入失败轨迹 τ 和实例 x；对每个 si (i=1..n-1) 初始化 CRS=0；调用 GenerateInterventions 得到 K 个提案；对每个提案执行 SequentialReExec 重执行；若 V 返回成功则设 CRS=1 并跳出循环；返回 CRS 列表
  - 顺序重执行：替换步骤 si 后，重新执行从 si+1 到 sn 的所有步骤，保持之前步骤不变。有确定性执行器（如Python解释器）时使用；否则使用预测性重执行（LLM评估）
  - 最小性计算：token级位置匹配，长度归一化，并加入长度差异惩罚
  - 多智能体共识：先计算CRS，再结合两个批评者的同意置信度加权平均
- 训练/推理细节：
  - 测试时修复：对失败轨迹运行CausalFlow，将失败步骤替换为选定的最小修正，然后继续执行
  - 训练时监督：将成功验证的对比对 (si, s*_i) 作为训练数据，可用于离线偏好优化（如DPO）或奖励模型训练
  - 实验设置：GSM8K使用Gemini 2.0 Flash Lite + 计算器；MBPP使用GPT-5 Chat + Docker执行；SealQA Hard和MedBrowseComp使用Gemini 3 Flash Preview + 网页搜索。所有智能体输出结构化轨迹（步骤类型、依赖）
  - 干预生成：温度采样，K=3，每个候选步骤生成3个提案

### 7. Beyond Surrogate Gradients: Fully Differentiable Token Pruning for Vision-Language Models
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.28051v1
- 方法流程：
  - 输入：图像I，冻结的视觉编码器生成视觉token Xv ∈ R^{N×dv}
  - 阶段1：Scorer Sθ对每个视觉token预测标量重要性logit s
  - 阶段2：Budgeted Soft Top-K ΦK将s/τ转换为连续保留权重α ∈ [0,1]^N，满足∑α_i = K
  - 阶段3：Throttler T使用VP-Noise：x̃_i = √α_i x_i + √(1-α_i) ϵ_i，得到扰动后的表示X̃v
  - 阶段4：Denoiser Dϕ（单层对角注意力Transformer块）对X̃v进行独立变换，得到对齐后的X̅v
  - 阶段5：冻结的LLM处理多模态序列Z = [Pv→ℓ(X̅v); Et(W)]，训练最小化负对数似然
  - 推理：移除Throttler和Denoiser，直接使用Scorer得分进行硬Top-K选取原始token，得到X̂v = TopK(Xv; Sθ(Xv), K)
- 关键模块/机制：
  - Scorer Sθ：为每个视觉token分配重要性分数；两层Transformer编码器后接线性头，输出每个token的标量logit。仅预测排序信号，预算控制由ΦK负责。
  - Budgeted Soft Top-K ΦK：将重要性分数转换为满足固定预算的连续保留权重；可微Top-K算子，输出α ∈ [0,1]^N且∑α_i=K。温度τ通过余弦退火逐渐降低，使α趋近于硬二元掩码。训练与推理的极限一致。
  - Information Throttler T (VP-Noise)：根据保留权重连续调节每个token的信息量；使用方差保持噪声形式：x̃_i = √α_i x_i + √(1-α_i) ϵ_i。高α≈1时保留原表示，低α≈0时替换为各向同性噪声。对归一化token保持特征尺度稳定，全可微。
  - Diagonal-Attention Denoiser Dϕ：在训练时对齐被噪声扰动的token表示，不撤销信息限制；单层Transformer块，使用单位矩阵作为注意力掩码（每个token独立变换），包含投影、归一化和前馈层。仅在训练阶段使用，推理时移除。
- 公式/目标函数/指标定义：
  - 训练目标：min_{θ,ϕ} -∑_t log pΘ(y_t^* | y_{<t}^*, Z)，其中Z = [Pv→ℓ(X̅v); Et(W)]
  - X̅v = Dϕ(T(Xv; α))
  - α = ΦK(Sθ(Xv)/τ)，且∑α_i = K
  - VP-Noise: x̃_i = √α_i x_i + √(1-α_i) ϵ_i, ϵ_i ~ N(0, I)
  - 推理选择：X̂v = TopK(Xv; Sθ(Xv), K) ∈ R^{K×dv}
- 算法细节：
  - 训练时使用连续软门控，避免硬选择；推理时坍缩为硬Top-K，Throttler和Denoiser被移除
  - Soft Top-K的退火机制：温度τ随训练余弦衰减，使α逐渐接近二值掩码
  - VP-Noise的噪声采样独立于每个token，每次前向采样不同的ϵ
  - Denoiser使用对角注意力（identity mask）防止信息跨token传播，仅做逐token变换
- 训练/推理细节：
  - 仅训练Scorer和Denoiser（约84M参数），基座VLM冻结
  - 训练数据：10%的ImageNet-1K训练集，带ImageNet-1K-VL-Enriched标题
  - 推理时只需一次Scorer前向和索引收集操作，额外开销0.69ms（A6000, FP16）
  - 基座模型可采用LLaVA-1.5-7B、LLaVA-NEXT-7B、Qwen2.5-VL-7B等，无需架构调整

### 9. CRITIC-R1: Learning Structured Critics for Retrieval-Augmented Generation
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.29886v1
- 方法流程：
  - 输入：问题、检索到的文档、当前推理轨迹（如Search-R1的搜索-推理链）。
  - 步骤1：批评模型（基于LLM）根据预定义结构化格式生成批评输出，包含<verdict>（CORRECT/INCORRECT/UNSURE）、<location>（错误阶段或证据索引）、<reason>（错误分析）、<fix>（建议修正）。
  - 步骤2：使用过程级监督（外部LLM教师提供参考标签）计算CJA奖励和DQA奖励。
  - 步骤3：通过GRPO算法优化批评模型策略，第一阶段重点优化高维判断（CJA），第二阶段优化细粒度诊断（DQA）。
  - 输出：训练好的批评模型，可用于对新的RAG轨迹生成结构化批评，指导细化。
- 关键模块/机制：
  - 结构化批评公式：定义批评的输出格式，使反馈可解析且可操作；包含四个字段：<verdict>（CORRECT/INCORRECT/UNSURE）、<location>（错误所在步骤或文档索引）、<reason>（详细错误原因）、<fix>（具体修正建议）。例如：verdict=INCORRECT, location=Doc3, reason=信息不相关, fix=重新搜索。
  - Conservative Judgement Alignment (CJA) 奖励：鼓励批评模型做出校准的高维判断，防止过度干预；包含三部分：(1) verdict可靠性奖励：对正确判断（如正确标记CORRECT、错误标记INCORRECT、不确定时标记UNSURE）给予正奖励，对错误判断（如假警报）给予高惩罚；(2) 格式奖励：满足预定义输出格式时得正奖励α，否则惩罚-γ；(3) 辅助惩罚：抑制退化输出（如过于通用或无意义反馈）。总奖励 r_CJA = r_format + r_verdict + r_aux。
  - Diagnostic Quality Alignment (DQA) 奖励：提升细粒度诊断质量，包括位置、原因和修正；门控机制：仅当高维判断正确（即verdict与参考一致）时激活DQA奖励；否则不激活。DQA奖励基于对location、reason、fix字段与教师标注的一致程度计算，鼓励精准定位错误、解释原因并提供可行修复。
  - 过程级监督收集：为RL提供准确的奖励信号；使用外部LLM（如GPT-4）作为教师模型，对每条推理轨迹生成结构化批评（verdict、location、reason、fix）作为参考标签。教师模型通过提示工程产生高一致性的标注，用于计算CJA和DQA奖励。
  - 两阶段GRPO训练：优化批评模型的策略；第一阶段：使用CJA奖励训练批评模型，使其学会可靠的高维判断（verdict）并减少过度干预。第二阶段：在第一阶段基础上加入DQA奖励，进一步优化细粒度诊断能力。使用Group Relative Policy Optimization (GRPO) 算法，基于组内相对优势更新模型参数。
- 公式/目标函数/指标定义：
  - r_format = α (有效格式) 或 -γ (无效格式)
  - r_CJA = r_format + r_verdict + r_aux
  - r_DQA = 门控函数 * 诊断质量分数，其中门控函数 I[verdict_pred == verdict_ref]
  - GRPO目标：最大化组内奖励的相对优势，具体公式为 L_GRPO = -E[log π_θ(o|q) * A_i]，其中A_i为组内标准化优势。
- 算法细节：
  - 两阶段RL：先优化CJA奖励（高维判断），再优化DQA+ CJA奖励（细粒度诊断）。
  - 门控机制：DQA奖励仅在verdict预测正确时激活，避免错误判断下仍优化诊断。
  - 过程级监督：使用外部LLM教师为每条轨迹生成完整的结构化批评作为参考，用于计算奖励。
  - GRPO：从当前策略采样一组输出，计算每个输出的奖励，然后计算组内优势（相对平均奖励的差值），并用策略梯度更新。
  - 退化抑制：在CJA中引入辅助惩罚，惩罚过于通用或无意义的反馈（如仅重复“请检查”）。
- 训练/推理细节：
  - 训练：使用GRPO算法，初始策略模型为预训练LLM（如Qwen2.5-7B）。训练数据来自RAG系统（如Search-R1）生成的问答轨迹。每轮采样多个输出，计算CJA和DQA奖励后更新。
  - 两阶段训练：第一阶段仅使用CJA奖励训练若干步，第二阶段加入DQA奖励继续训练。
  - 推理：训练好的批评模型接收输入（问题、检索文档、推理轨迹），直接生成结构化批评。下游细化模块根据批评中的fix字段修改生成。
  - 超参数：α=1.0, γ=0.5（格式奖励），verdict奖励细节见表7（附录），GRPO组大小n=8。

### 10. Generalistic or Specific Embeddings, Which is Better? An Empirical Study on Search for Clinical Coding in Non-English Languages
- 区域：quick；分数：7.0
- 原文链接：https://arxiv.org/abs/2605.30529v1
- 方法流程：
  - 合成数据生成：以ICD-10章节和语言为种子，调用Gemini生成包含查询、两个正例、两个硬负例、两个软负例的多语言样本，经去重和质量过滤得到19,502条数据
  - Bi-encoder训练：使用MultipleNegativesRankingLoss，以(bi-encoder嵌入的余弦相似度)为相似度函数，在batch内取负例，微调PlanTL-GOB-ES/bsc-bio-ehr-es模型
  - Cross-encoder训练：从bi-encoder checkpoint初始化，使用listwise softmax交叉熵损失，每个组包含1个正例和至多9个硬负例，仅基于西班牙语CodiEsp数据训练
  - 推理：输入查询，经bi-encoder编码后在Qdrant向量数据库中检索top-10候选码，再由cross-encoder对(查询,候选)对进行相关性评分并重排序
- 关键模块/机制：
  - 合成数据生成器 (Gemini 2.5 Flash Pro)：根据ICD-10章节和语言种子生成多语言训练样本，包括查询、正例、硬负例和软负例；参数化生成：输入ICD-10章号和目标语言，输出JSON格式样本（query, positives[2], hard_negatives[2], soft_negatives[2]）。经规则验证、语义去重、语言一致性检查、人工抽查等流程
  - Bi-encoder：将查询和候选码映射到共享嵌入空间，通过余弦相似度进行初筛；基于PlanTL-GOB-ES/bsc-bio-ehr-es BERT，经MultipleNegativesRankingLoss微调。输出768维向量，采用mean pooling，最大序列长度256。训练时每个batch包含所有6种语言，利用in-batch negatives提供跨语言对比信号
  - Cross-encoder：联合建模查询与候选码对，输出相关性分数，对bi-encoder结果重排序；同为BERT架构，从bi-encoder checkpoint初始化，加上回归头。输入为(查询,候选)拼接序列，输出logits。训练采用listwise softmax交叉熵，每个batch含8个组，每组1正+最多9硬负例
  - 硬/软负例采样策略：生成训练数据时平衡仿射，迫使模型学习细粒度边界和保持全局区分；硬负例取自同ICD-10章内语义相邻的码（仅严重程度、解剖部位等差异），软负例取自无关章节。平衡防止表示坍缩，提升对临床邻近概念的区分能力
- 公式/目标函数/指标定义：
  - MultipleNegativesRankingLoss: L_i = -log( exp( s(q_i, p_i)/τ ) / sum_{j=1}^B exp( s(q_i, p_j)/τ ) )，其中 s 为余弦相似度，τ 为温度参数
  - 批量损失: L = (1/B) * sum_{i=1}^B L_i
  - Cross-encoder listwise softmax交叉熵: 对每个组，logits经softmax后与正例索引0计算交叉熵

  - 阶段5：将N_p个锚点token与N_q个查询token拼接为总长度为B的压缩视觉序列，输入LLM
- 关键模块/机制：
  - 空间池锚点生成：以固定低分辨率网格提供空间布局锚点（低频信息）；对SigLIP输出的16×16特征图进行平均池化，生成4×4（16 tokens）或8×8（64 tokens）的池化特征，作为显式的2D空间锚点
  - 条件弹性查询初始化：生成可学习的查询token，用于补充锚点未覆盖的高频视觉细节；根据总预算B与锚点数量N_p动态分配查询数量N_q=B-N_p，每个查询为可学习嵌入
  - 池条件自注意力：使查询token与空间锚点交互，获取全局布局上下文并消除冗余空间映射；查询token作为Q，池锚点作为K和V，执行单头/多头自注意力，输出重新赋能的查询特征
  - 查询到ViT交叉注意力：使查询token从原始ViT特征中提取精细细节；将池条件自注意力输出的查询作为Q，原始ViT特征作为K和V，执行交叉注意力，输出最终查询token
  - 预算路由策略：根据总预算自动选择锚点分辨率并分配查询数量；B<64时选用16锚点网格，B≥64时选用64锚点网格；采用该简单启发式避免训练时锚点网格切换带来的不稳定性
- 公式/目标函数/指标定义：
  - 池化操作：对H×W网格进行k×k平均池化，输出(H/k)×(W/k)锚点特征
  - 查询token初始化：N_q = B - N_p，其中B为总视觉token预算，N_p为锚点数量
  - 训练时预算采样：B均匀采样自{16,18,...,256}（偶数）
- 算法细节：
  - 预算路由：训练时对每个batch随机采样一个偶数预算B；推理时固定B，根据B选择锚点网格并分配查询数
  - 池锚点生成：使用固定步长的平均池化（核大小2或4），不学习参数
  - 注意力块：使用单层自注意力（Q-KV来自锚点）加单层交叉注意力（Q来自查询，KV来自ViT），不使用重复堆叠
  - 锚点token始终保留在最终视觉序列中，查询token仅补充剩余预算
- 训练/推理细节：
  - 训练：采用与MQT相同的预算采样策略，但预算范围扩展到偶数；锚点网格根据预算自动切换；连接器仅包含两个注意力层（自+交叉）
  - 推理：无需重新训练，可直接指定任意偶数预算B（16~256）；对于B<64自动使用16锚点网格，B≥64使用64锚点网格
  - 与PaliGemma-2基线一致：使用224×224分辨率（默认）或448×448（高分辨率），SigLIP视觉编码器
